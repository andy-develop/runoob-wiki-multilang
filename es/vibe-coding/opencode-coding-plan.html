OpenCode Coding Plan

Actualmente hay muchos fabricantes de modelos de gran tamaño en el mercado: en el extranjero están Anthropic, Open AI, Grok, Gemini, etc., pero acceder a los servicios del extranjero no es conveniente ahora. En China están DeepSeek, Qwen, ZLM, MiniMax, etc.

Al usar Claude Code para escribir código, lo que más cuesta son los tokens. Acceder a servicios en el extranjero es inconveniente y además caro. En China ahora hay planes de suscripción mensual. Si se usa a largo plazo, se recomienda comprar un plan mensual, resulta más económico.

Este artículo presenta el Coding Plan de Alibaba Cloud Bailian, un servicio de suscripción diseñado específicamente para herramientas de programación con IA. Integra los mejores modelos de gran tamaño como Qwen, GLM, Kimi, MiniMax, y es compatible con los principales asistentes de programación con IA (como OpenCode, Claude Code, OpenClaw, etc.). Utiliza un modelo de tarifa mensual fija, con un costo mucho menor que las APIs de pago por uso, y elimina por completo el riesgo de deudas por consumo.

Ventajas principales del Coding Plan:

  • Acceso con un clic a modelos de primer nivel: Sin necesidad de llamar a la API de Bailian, puede usar directamente los modelos más potentes en su herramienta de programación familiar.
  • Costo extremadamente bajo: Tarifa mensual fija (Lite ¥40/mes, Pro ¥200/mes), con descuento de lanzamiento de solo 7,9 yuanes / 39,9 yuanes el primer mes.
  • Seguridad sin preocupaciones: Se prohíbe la conexión directa a la API; solo está permitido su uso en herramientas de programación interactivas, evitando el riesgo de bloqueo por uso indebido.
  • Soporte para comprensión de imágenes: qwen3.5-plus y kimi-k2.5 admiten subir capturas de pantalla/diseños para generar código directamente.

Modelos recomendados(Oficialmente adaptados):

  • qwen3.5-plus (compatible con comprensión de imágenes, recomendado como primera opción)
  • kimi-k2.5 (compatible con comprensión de imágenes)
  • glm-5
  • MiniMax-M2.5

El Coding Plan admite las siguientes herramientas: Cursor, Claude Code, OpenClaw, OpenCode, Cline (extensión de VS Code), Kilo Code / Kilo CLI, Qwen Code, Codex, etc.

El Coding Plan de ArkEs un servicio de suscripción de codificación con IA para desarrolladores que facilita el desarrollo eficiente. Sus ventajas principales son:

  • Gran variedad de modelos: Compatible con los principales modelos de lenguaje de gran tamaño y modelos de embedding, cubriendo series populares como Doubao, DeepSeek, Kimi, GLM, MiniMax.
  • Amplia compatibilidad de herramientas: Adaptado a herramientas de codificación de IA populares como Claude Code, Cursor, Cline, OpenCode, Codex CLI.
  • Cupo compartido: Varias herramientas comparten el cupo del plan, se puede cambiar con flexibilidad para adaptarse a diferentes escenarios de desarrollo.
  • Planes flexibles: Ofrece múltiples niveles, como Lite/Pro, para satisfacer desde necesidades de desarrollo ligeras hasta las de alta intensidad.
  • Alta disponibilidad y estabilidad: Aislamiento de múltiples inquilinos y programación de recursos garantizan que siga siendo estable y fluido incluso en horas punta.

El Base URL configurado en diferentes herramientas varía según el protocolo compatible:

  • Herramientas compatibles con el protocolo de interfaz de Anthropic:https://ark.cn-beijing.volces.com/api/coding
  • Herramientas compatibles con el protocolo de interfaz de OpenAI:https://ark.cn-beijing.volces.com/api/coding/v3

Nota:No utilice https://ark.cn-beijing.volces.com/api/v3: este Base URL no consume el cupo de su Coding Plan, sino que genera costos adicionales.

Configurar OpenCode

Editar el archivo de configuración de OpenCode:

  • macOS / Linux：~/.config/opencode/opencode.json
  • Windows：C:\Users\您的用户名\.config\opencode\opencode.json

Modificar los elementos de configuración

Reemplace el siguiente contenido según su situación real:

  • <ARK_API_KEY>：Obtenga su API Key
  • model: reemplácelo por el nombre del modelo que desee utilizar

Los modelos específicos son: doubao-seed-2.0-code, doubao-seed-2.0-pro, doubao-seed-2.0-lite, doubao-seed-code, minimax-m2.5, glm-4.7, deepseek-v3.2, kimi-k2.5.

  • Nombre de clave del objeto

Cree y abra el archivo de configuración opencode.json en la siguiente ruta:

  • macOS / Linux: ~/.config/opencode/opencode.json
