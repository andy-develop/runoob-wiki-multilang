Tutorial de introducción a Kilo Code

Kilo Code es un agente de programación de IA de código abierto que se ejecuta en tu VS Code, JetBrains o línea de comandos. Admite más de 500 modelos de IA y actualmente cuenta con más de 3 millones de desarrolladores usuarios, habiendo procesado más de 40 billones de tokens.

Kilo Code es un agente de programación de IA de código abierto que se instala en tuIDE actual(VS Code, JetBrains).

Kilo Code no es una bifurcación de un nuevo editor. No cambias de herramientas, ni de atajos de teclado, ni de complementos: obtienes capacidades de Agente de IA directamente en tu entorno de desarrollo actual.

Sitio web oficial:https://kilo.ai/

Resumen de características principales

Conoce rápidamente las principales funcionalidades que ofrece Kilo Code.

  • Compatibilidad multiplataforma: VS Code, JetBrains (IntelliJ, PyCharm, WebStorm, etc.), CLI, aplicación móvil (iOS / Android), Slack.

  • Más de 500 modelos, sin sobreprecio: Claude, GPT, Gemini, Grok, DeepSeek, modelos locales... Cambia libremente, se factura al precio original del proveedor de modelos.

  • Modos de Agente especializados: Code, Ask, Plan, Debug; cada modo tiene permisos de herramientas diferentes y está optimizado para distintas tareas.

  • Autocompletado inteligente: sugerencias de código en línea basadas en FIM (Fill-in-the-Middle), se aceptan con la tecla Tab.

  • Control de terminal y navegador: puede ejecutar comandos Shell y controlar la automatización del navegador.

  • Checkpoints (puntos de control): instantánea automática antes de cada modificación, se puede/rollbackrevertir en cualquier momento.

  • Agente paralelo: ejecuta varios Agentes simultáneamente con git worktrees, sin interferencias.

  • Mercado de MCP: integración integrada de servidores MCP, conecta con un clic a servicios externos como GitHub, bases de datos, Slack, etc.

  • Totalmente de código abierto: licencia MIT, auditable, bifurcable (fork) y personalizable.

Optimización iterativa

Kilo Code trabaja de forma iterativa; una tarea puede completarse en varias rondas de conversación:

第一轮：写一个 Python 函数，计算两个数的最大公约数
第二轮：加上类型注解和 docstring
第三轮：写单元测试
第四轮：重构成 class，支持多个数字的 GCD

En cada ronda, el Agent continúa sobre la base de la ronda anterior; no necesitas volver a describir el contexto.

Modo Agente: elige la herramienta adecuada para cada tarea

Kilo Code ofrece 4 Agents integrados; cada Agent tiene diferentes permisos de herramientas y estrategias de comportamiento.

Elegir el Agent correcto no solo da mejores resultados, sino que también ahorra costos de tokens.

code (predeterminado)

Rol: ingeniero de software todoterreno.

Permisos de herramientas: acceso completo: leer archivos, escribir archivos, ejecutar comandos de terminal, buscar en la web y llamar a servidores MCP.

Adecuado para: escribir código, implementar funciones, corregir bugs y desarrollo diario.

切换方式：默认就是 code，或输入 /agents 选择

ask

Rol: asesor técnico de solo lectura.

Permisos de herramientas: solo lectura: puede leer archivos, ejecutarcat/grep/git logcomandos de solo lectura comono se permiten operaciones de escritura。

Adecuado para: comprender código, explicar la lógica de funciones, explorar la estructura de proyectos y aprender conceptos técnicos.

典型用法：
"解释这个 useEffect 的执行顺序"
"这个 SQL 查询会有性能问题吗？"
"分析整个 src 目录的架构"

Al usar el modo ask para analizar bases de código grandes, puedes estar tranquilo de que el Agent no modificará ningún archivo por error.

plan

Rol: líder técnico y diseñador de sistemas.

Permisos de herramientas: solo lectura + puede escribir.kilo/plans/archivos de plan en el directorio

Adecuado para: diseño de sistemas, planificación de funciones, decisiones de arquitectura y elaboración de planes de implementación.

典型用法：
"设计一个多租户 SaaS 平台的数据库架构"
"规划如何把单体应用拆分成微服务"
"在写代码之前，先给我一个分页功能的实施方案"

Mejores prácticas: primero planifica con el modo plan y, después de confirmar el plan, cambia al modo code para implementarlo.

debug

Rol: experto en resolución sistemática de problemas.

Permisos de herramientas: acceso completo (igual que code).

Adecuado para: rastrear bugs, diagnosticar errores y analizar problemas de ejecución.

El modo debug utiliza un enfoque más sistemático: primero analiza, reduce el alcance y luego corrige, en lugar de intentar modificar el código directamente.

典型用法：
"运行 npm test 后报错，帮我找出根本原因"
"内存一直增长，帮我定位内存泄漏"

Autocompletado inteligente (Autocomplete)

El Autocomplete de Kilo Code analiza en tiempo real el código antes y después del cursor mientras escribes, y ofrece sugerencias de completado en línea.

Cómo funciona

UtilizaFIM（Fill-in-the-Middle）tecnología, enrutado a través de Kilo Gateway hacia un modelo de completado especializado.

Dos modelos disponibles:

Codestral(predeterminado): el modelo de completado de código de Mistral AI, maduro y estable.

Mercury Edit 2: el modelo FIM difusivo de Inception, más rápido (requiere traer tu propia Key con BYOK).

Uso básico

Escribe normalmente en el archivo de código.

Cuando veasel texto fantasma grisaparecer, presionaTabpara aceptar la sugerencia.

Continúa escribiendo para ignorar la sugerencia.

Activación manual

按 Cmd+L(macOS) oCtrl+L(Windows/Linux) para solicitar el completado en la posición actual del cursor.

Debes habilitarkilo-code.new.autocomplete.enableSmartInlineTaskKeybindingen los ajustes de VS Code; está desactivado por defecto.

Guiar el autocompletado con comentarios

Escribir un comentario encima de la función puede mejorar enormemente la calidad del completado:

Agente personalizado (Modos personalizados)

Cuando los 4 Agentes integrados no satisfagan tus necesidades, puedes crear Agentes personalizados, adaptados a tareas específicas o flujos de trabajo de equipo.

La forma más sencilla: deja que el Agente lo cree

创建一个叫 "docs-writer" 的自定义 Agent，
只能读文件和编辑 Markdown 文件，
专门用来写技术文档

Kilo generará automáticamente el archivo de configuración en el directorio.kilo/agents/.

Creación manual: archivo Markdown

Crea en el proyecto.kilo/agents/docs-writer.md：

---
description: 专门用于编写和维护技术文档
mode: primary
color: "#10B981"
permission:
  edit:
    "*.md": "allow"
    "*": "deny"
  bash: deny
---

你是一位技术文档专家，擅长：
- 编写清晰、结构良好的开发文档
- 遵循 Markdown 最佳实践
- 为 API 和函数创建有用的示例

专注于清晰性和完整性，只编辑 Markdown 文件。

El nombre del archivo (sin la extensión [12 ]) es el nombre del Agente..md）就是 Agent 的名字。

Agente compartido en equipo

Los archivos de Agente personalizado se pueden enviar al repositorio git, y todos los miembros del equipo compartirán automáticamente la misma configuración de Agente.

Especialmente adecuado para unificar flujos de trabajo especializados del equipo, como revisión de código, redacción de documentación, generación de pruebas, etc.

Los administradores de la organización también pueden enviar Agentes de nivel organizativo a todos los miembros a través de la plataforma Kilo, sin necesidad de que cada persona lo configure manualmente.

Memory Bank: recuerda tu proyecto

Memory Bank crea en el directorio raíz del proyecto un archivoAGENTS.md(o.kilo/agents.md), almacenando de forma persistente la información clave del proyecto, para que el Agente tenga un contexto completo del proyecto cada vez que se inicie.

El Agente escaneará tu base de código y lo generará automáticamente.

- 运行时：Node.js 22 + TypeScript
- 框架：Fastify
- 数据库：PostgreSQL 16 + Prisma ORM

El CLI de Kilo comparte las mismas sesiones, configuración y contexto que la extensión de VS Code, permitiendo un cambio sin interrupciones.

Gestión de costos y selección de modelos

Comprende la estructura de costos de Kilo Code, las estrategias de ahorro y las recomendaciones de selección de modelos.

Comprender la estructura de costos

El costo de Kilo Code =Input Tokens × precio de entrada + Output Tokens × precio de salida。

Debajo de cada mensaje se muestra en tiempo real el uso de Tokens y el costo estimado de esa llamada.

Auto Model: enrutamiento inteligente para ahorrar costos

La función Auto Model de Kilo Code selecciona automáticamente el modelo más adecuado según el tipo de tarea:

Preguntas y respuestas simples→ modelo rápido y económico (como GPT-4o-mini).

Generación de código complejo→ modelo de mayor capacidad (como Claude Sonnet 4.6).

Diseño de arquitectura→ modelo de vanguardia con la mayor capacidad de razonamiento.

Cómo activarlo: selecciona en el selector de modelosAuto。

Consejos prácticos para ahorrar tokens

Cita con precisión, no incluyas todo el directorio：

不推荐：@./src/   分析这个项目
推荐：@src/auth/login.ts @src/auth/middleware.ts 分析登录流程

Usa el modo ask para explorar y el modo code para implementar: el modo ask prohíbe operaciones de escritura, el Prompt del sistema es más corto y el costo de Tokens es menor.

Primero usa ask para entender el código y, una vez definido el plan, cambia a code para ejecutarlo.

Limpia el contexto a tiempo：

/compact    # 压缩当前会话的历史上下文，节省后续 Token

Desactiva los servidores MCP que no uses: los servidores MCP no utilizados introducen muchas descripciones de herramientas en el Prompt del sistema, desperdiciando Tokens.

Mantén solo los servidores que necesites actualmente.

Establece un límite de costo: configura en los ajustes de Kilo CodeCost Controls, establece el límite máximo de costo por tarea para evitar gastos inesperados.

Recarga automática

在 app.kilo.aiActivaAuto Top-Ups, se recargará automáticamente cuando el saldo sea insuficiente, sin interrumpir las tareas en curso por falta de saldo.
