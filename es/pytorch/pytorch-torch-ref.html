Manual de referencia de Pytorch torch

El paquete de software PyTorch contiene estructuras de datos para tensores multidimensionales y define operaciones matemáticas que se ejecutan sobre estos tensores. Además, proporciona muchas utilidades para serializar eficientemente tensores y datos de cualquier tipo, así como otras herramientas útiles.

También tiene una versión CUDA que te permite ejecutar cálculos con tensores en GPUs NVIDIA con capacidad de cómputo >= 3.0.

Ejemplos

Ejemplos

import torch

# Crear un tensor
x = torch.tensor([1, 2, 3])
y = torch.zeros(2, 3)

# Operaciones matemáticas
z = torch.add(x, 1)  # Sumar 1 elemento a elemento
print(z)

# Indexación y segmentación (slicing)
mask = x > 1
selected = torch.masked_select(x, mask)
print(selected)

# Gestión de dispositivos
if torch.cuda.is_available():
    device = torch.device('cuda')
    x = x.to(device)
    print(x.device)

# Operaciones con matrices
a = torch.randn(3, 4)
b = torch.randn(4, 5)
c = torch.matmul(a, b)
print(c.shape)

# Cálculo de gradientes
x = torch.tensor([1., 2., 3.], requires_grad=True)
y = x.sum()
y.backward()
print(x.grad)

Resultado de salida:

tensor([2, 3, 4])
tensor([2, 3])
