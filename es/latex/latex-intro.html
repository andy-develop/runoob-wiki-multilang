Tutorial de LaTeX
Instalación y configuración de LaTeX

Introducción a LaTeX

LaTeX es un sistema de composición tipográfica basado en TeX, ampliamente utilizado para generar documentos científicos y matemáticos de alta calidad. Fue desarrollado por el informático estadounidense Leslie Lamport en la década de 1980.

TeX es un motor de composición tipográfica de bajo nivel desarrollado por Donald Knuth, utilizado principalmente para manejar fórmulas matemáticas complejas y composición de alta calidad.

LaTeX proporciona una abstracción de mayor nivel sobre TeX, lo que permite a los usuarios centrarse más en el contenido sin preocuparse demasiado por los detalles de composición.

A diferencia de los programas de procesamiento de texto comunes (como Microsoft Word), LaTeX utiliza archivos de texto plano para describir la estructura y el contenido del documento, y genera el archivo PDF final mediante compilación. LaTeX es especialmente adecuado para manejar fórmulas matemáticas complejas, referencias bibliográficas, referencias cruzadas, etc.

El propósito original de LaTeX era facilitar la composición de artículos académicos y documentos técnicos, especialmente en campos como matemáticas, física y ciencias de la computación. Con el tiempo, LaTeX se ha convertido en una de las herramientas estándar en el ámbito académico y editorial.

Características de LaTeX

  • Composición de alta calidad: LaTeX es conocido por su composición profesional, especialmente en el manejo de fórmulas matemáticas. Ajusta automáticamente el formato del documento y produce resultados de composición de alta calidad que cumplen con los estándares de publicación.
  • Basado en lenguaje de marcado: LaTeX utiliza un formato de lenguaje de marcado en texto plano. El usuario define la estructura y el formato del documento mediante comandos y etiquetas específicos. Por ejemplo, se utiliza \section{} para definir secciones y \textbf{} para poner texto en negrita.
  • Compatibilidad multiplataforma: LaTeX es multiplataforma y admite sistemas operativos como Windows, macOS y Linux. Los documentos generados suelen estar en formato PDF y se muestran de manera consistente en diferentes plataformas.
  • Adecuado para escritura académica: LaTeX es muy adecuado para redactar artículos académicos, libros, documentos técnicos, informes, etc., especialmente aquellos con muchas fórmulas matemáticas, referencias bibliográficas y necesidades de composición complejas. Ofrece un excelente soporte para gestión de referencias, entrada de fórmulas y efectos de composición.
  • Gestión automatizada de documentos: LaTeX ofrece potentes funciones de automatización en documentos largos, libros o tesis, como numeración automática, generación automática de índices, referencias cruzadas, composición automática de fórmulas, etc. Puede gestionar automáticamente citas bibliográficas, listas de referencias, etc., siendo ideal para documentos que requieren un formato preciso.
  • Código abierto y gratuito: LaTeX es de código abierto y cualquiera puede descargarlo y usarlo gratuitamente. Además, la comunidad de LaTeX es muy activa y ofrece numerosas plantillas, paquetes y consejos para ayudar a los usuarios a mejorar su eficiencia de composición.

¿Cómo funciona LaTeX?

  • LaTeX no funciona como los editores WYSIWYG (lo que ves es lo que obtienes) tradicionales; no ves directamente el resultado final de la composición. En cambio, editas un archivo de texto plano donde introduces el contenido, la estructura y las instrucciones de formato del documento. Este archivo suele tener la extensión .tex.
  • Escribir el código fuente de LaTeX: Primero, utilizas un editor de texto (como TeXworks o TeXstudio) para escribir el archivo fuente de LaTeX. En el archivo especificas la estructura del documento, títulos, párrafos, fórmulas, tablas, etc., y usas comandos de LaTeX para indicar cómo formatearlos.
  • Compilación: Luego, mediante un compilador de LaTeX (como pdflatex), compilas el archivo .tex a PDF u otro formato de salida. Durante la compilación, LaTeX genera automáticamente el índice, tablas, numeración de fórmulas, referencias bibliográficas, etc.
  • Generación del documento final: La salida compilada es el documento final. Puedes ver el resultado en PDF, que se genera con composición de alta calidad según tus requisitos de formato.

¿Por qué usar LaTeX?

  • Escritura académica: Si eres investigador, académico o estudiante, LaTeX es muy adecuado para redactar artículos académicos, informes, libros, etc., especialmente aquellos que requieren insertar fórmulas matemáticas complejas y referencias bibliográficas.
  • Composición de alta calidad: LaTeX maneja automáticamente los detalles de composición y puede generar formatos de documento que cumplen con los estándares internacionales de publicación. Ya sea la fuente, el interlineado, los márgenes o el formato de los títulos de sección, LaTeX puede controlarlo con precisión.
  • Estructura de documentos complejos: LaTeX es adecuado para manejar documentos grandes (como libros, tesis, manuales técnicos). Puede generar automáticamente índices, referencias bibliográficas, y admite referencias cruzadas y numeración automática.
  • Documentos matemáticos y científicos: LaTeX es la herramienta preferida en campos como matemáticas, física e ingeniería, ya que permite ingresar y componer fórmulas matemáticas complejas de manera sencilla.

El flujo de trabajo de LaTeX se puede resumir en tres pasos: escribir el código fuente, ejecutar la compilación y obtener el PDF.

El archivo .tex que escribimos es un archivo de texto plano normal que puede abrirse con cualquier editor; el compilador se encarga de convertirlo en el PDF final.

Flujo de trabajo básico de LaTeX

El flujo básico para escribir documentos con LaTeX es el siguiente:

  • Escribir el código fuente: utiliza un editor de texto plano para escribir el archivo .tex, cuyo contenido incluye la estructura del documento, texto y comandos.
  • Compilar el documento: mediante un compilador de LaTeX (como pdflatex, xelatex) convierte el archivo .tex a PDF u otros formatos.
  • Ver el resultado: el archivo PDF generado se puede ver directamente; el contenido se compone automáticamente según el código fuente.

Por ejemplo, un documento simple de LaTeX es el siguiente:

Ejemplo

\documentclass{article} % Clase de documento
\title{Mi primer documento LaTeX} % Título
\author{Autor} % Autor
\date{\today} % Fecha

\begin{document}
\maketitle % Generar título

\section{Introducción} % Sección
¡Este es mi primer documento LaTeX!\\ % Salto de línea
Este es un párrafo simple.

\section{Fórmula matemática}
Esta es una fórmula en línea:$E = mc^2$。\\ % Fórmula en línea
Esta es una fórmula en modo display:
\[
\int_a^b f(x) \, dx
\]
\end{document}

La idea central de LaTeX

La idea central de LaTeX es la separación entre contenido y formato:

  • El usuario solo debe preocuparse por el contenido y la estructura del documento; LaTeX se encarga automáticamente de los detalles de composición.
  • Mediante comandos y entornos (como \section, \begin{itemize}) se define la estructura y el estilo del documento.
  • Los ajustes de formato se pueden realizar modificando la clase del documento o cargando paquetes, sin necesidad de modificar directamente el contenido.

Relación entre TeX, LaTeX, paquetes y distribuciones

Este es un conjunto de conceptos que los principiantes suelen confundir. Si los aclaras, no te perderás al elegir herramientas e instalar el entorno.

Todo el ecosistema TeX se puede dividir en cuatro capas, de abajo hacia arriba: motor, formato, paquetes y editor.

El motor es el programa que realmente realiza la composición; los más comunes son TeX, pdfTeX, XeTeX y LuaTeX. Entre ellos, XeTeX y LuaTeX tienen soporte nativo para Unicode y fuentes del sistema, razón por la cual se recomienda usarlos para compilar documentos en chino.

El formato es un conjunto de reglas de comandos construido sobre el motor; LaTeX es actualmente el formato más popular.

Los paquetes son complementos que amplían las funciones sobre el formato, como soporte para chino (ctex), mejora de fórmulas matemáticas (amsmath), configuración de página (geometry). CTAN alberga más de cinco mil paquetes.

Finalmente, la colección que agrupa el motor, el formato y una gran cantidad de paquetes de macros para facilitar una instalación única se llama distribución (Distribution), por ejemplo, TeX Live, MiKTeX.

Cinco términos para recordar en una sola frase

Motor: el programa que realmente compone el código fuente en PDF, como XeTeX.

Formato LaTeX: un conjunto de reglas de comandos útiles definidas sobre el motor.

Paquete de macros: un paquete de extensión de funcionalidades escrito por otros, como el paquete de soporte chino ctex.

Distribución: un paquete de instalación completo que agrupa el motor, el formato y los paquetes de macros.

Editor: el software que usas para escribir código; en sí mismo no participa en la composición.

El editor no es lo mismo que el compilador. Overleaf, TeXstudio y VS Code solo se encargan de escribir código y de lanzar la compilación; quien realmente compone es el motor de la distribución. Por lo tanto, en un entorno local, si solo instalas el editor sin instalar la distribución, no podrás compilar un PDF (Overleaf es la excepción: su nube incluye una distribución completa).

Ventajas de LaTeX y escenarios de uso

LaTeX no es una herramienta universal, pero en los siguientes escenarios sus ventajas de eficiencia y calidad son muy evidentes.

EscenarioPor qué es adecuado
Artículos académicos y tesis de gradoLa gran mayoría de revistas y universidades ofrecen plantillas oficiales de LaTeX; la numeración de fórmulas, figuras y referencias bibliográficas es totalmente automática.
Apuntes de ciencias e ingeniería, como matemáticas y físicaLa entrada de fórmulas es rápida y la calidad de composición de fórmulas complejas (matrices, sistemas de ecuaciones, deducciones multilínea) supera con creces a los editores de texto enriquecido.
Libros e informes extensosGestión automática de capítulos y estilos globalmente unificados; los documentos de cientos de páginas mantienen un formato coherente.
Currículum vitaePlantillas como moderncv tienen una composición excelente; el contenido está separado del estilo, y modificar el contenido no rompe el diseño.
PresentacionesBeamer permite crear diapositivas académicas con una composición de fórmulas perfecta, algo muy difícil de lograr con PPT.

A la inversa, en estos casos no hace falta forzar LaTeX: carteles que requieren mucho diseño gráfico, documentos de oficina que requieren anotaciones en tiempo real y flujo de trabajo entre varias personas, y documentos cortos con pocas fórmulas que deben entregarse el mismo día; con Word o herramientas especializadas será más cómodo.

La curva de aprendizaje de LaTeX es pronunciada al principio y plana después: los primeros días sentirás que «incluso cambiar el tamaño de letra requiere buscar comandos»; si perseveras y terminas los capítulos básicos de esta serie, podrás apreciar los beneficios a largo plazo de la composición automática.

Vista previa: un fragmento completo de código fuente de LaTeX

Antes de configurar formalmente el entorno, echemos un vistazo a cómo es un documento LaTeX real.

El siguiente código fuente está completo y se puede compilar; incluye chino, un título y dos fórmulas matemáticas.

Ejemplo

% Clase de documento: ctexart equivale a article más soporte para chino
\documentclass{ctexart}

\title{Mi primer\LaTeX{} documento}   % Título del documento
\author{RUNOOB}                    % Autor
\date{Agosto de 2026}                % Fecha; escribir \today rellena automáticamente el día actual

\begin{document}                   % El texto principal comienza aquí

\maketitle                         % Generar la zona del título

LaTeX es especialmente bueno en la composición de fórmulas matemáticas. La forma en línea de la ecuación masa-energía es$E = mc^2$，
Para mostrarla centrada y sola (fórmula en modo display), se escribe:

\[ E = mc^2 \]

donde$E$es la energía,$m$es la masa,$c$es la velocidad de la luz en el vacío.

\end{document}                     % El texto principal termina aquí

Es completamente normal no entender estos comandos ahora; cada artículo posterior de esta serie los explicará uno por uno.

Aquí solo necesitas recordar dos estructuras: la parte desde \documentclass hasta \begin{document} se llamapreámbulo, que se usa para la configuración global; la parte entre \begin{document} y \end{document} se llamacuerpo, que es donde escribes tu contenido.
