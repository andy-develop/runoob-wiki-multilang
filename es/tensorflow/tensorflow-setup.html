Configuración del entorno TensorFlow

TensorFlow 2.x tiene requisitos específicos de versión de Python:

Versión de TensorFlow Versiones de Python compatibles
TensorFlow 2.15+ Python 3.9-3.12
TensorFlow 2.12-2.14 Python 3.8-3.11
TensorFlow 2.8-2.11 Python 3.7-3.10

Se recomienda usar Python 3.9-3.11Estas versiones ofrecen la mejor compatibilidad y estabilidad.

Verificar la versión actual de Python

# 检查 Python 版本
python --version
# 或
python3 --version

# 检查 pip 版本
pip --version
# 或
pip3 --version

Opciones de instalación de Python

Opción 1: Python oficial (recomendado para principiantes)

  • Visitapython.orgDescargar e instalar
  • Durante la instalación, marca "Add Python to PATH"
  • Incluye el gestor de paquetes pip

Opción 2: Anaconda/Miniconda (recomendado para ciencia de datos)

  • Anaconda: entorno completo de ciencia de datos
  • Miniconda: versión ligera
  • Gestión integrada de entornos y paquetes

Opción 3: gestor de paquetes del sistema

# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# macOS (使用 Homebrew)
brew install python3

# Windows (使用 Chocolatey)
choco install python3

Configuración del entorno virtual (muy recomendado)

¿Por qué usar entornos virtuales?

Beneficios：

  • Aislamiento de dependenciasEvita conflictos de versiones de paquetes entre proyectos
  • Entorno limpioMantiene limpio el entorno de Python del sistema
  • Fácil gestiónPermite eliminar y recrear entornos fácilmente
  • ReproducibilidadFacilita la reproducción del entorno en diferentes máquinas

Crear un entorno virtual con venv

# 创建虚拟环境
python -m venv tensorflow_env

# 激活虚拟环境
# Windows:
tensorflow_env\Scripts\activate
# macOS/Linux:
source tensorflow_env/bin/activate

# 确认激活（提示符会显示环境名）
which python  # 应该指向虚拟环境中的 python

# 升级 pip
python -m pip install --upgrade pip

Crear un entorno virtual con Conda

# 创建新环境
conda create -n tensorflow_env python=3.10

# 激活环境
conda activate tensorflow_env

# 列出所有环境
conda env list

# 在环境中安装包
conda install pip

Gestión de entornos virtuales

# 查看已安装的包
pip list

# 生成依赖文件
pip freeze > requirements.txt

# 从文件安装依赖
pip install -r requirements.txt

# 退出虚拟环境
deactivate  # venv
conda deactivate  # conda

# 删除虚拟环境
rm -rf tensorflow_env  # venv
conda env remove -n tensorflow_env  # conda

Instalación de TensorFlow

Instalación de la versión CPU (apta para aprendizaje y tareas ligeras)

# 确保在虚拟环境中
pip install tensorflow

# 验证安装
python -c "import tensorflow as tf; print('TensorFlow version:', tf.__version__)"

Características de la versión CPU：

  • VentajasInstalación sencilla, sin configuración adicional
  • DesventajasVelocidad de entrenamiento más lenta; adecuada para datos a pequeña escala
  • Casos de usoAprendizaje, desarrollo de prototipos, despliegue de inferencia

Instalación de la versión GPU (apta para entrenamiento a gran escala)

La aceleración por GPU puede aumentar significativamente la velocidad de entrenamiento, especialmente para tareas de aprendizaje profundo.

3.2.1 Requisitos de GPU NVIDIA

Requisitos de hardware：

  • GPU NVIDIA (capacidad de cómputo 3.5 o superior)
  • 8 GB+ de memoria de video (recomendado)

Consultar información de la GPU：

# Windows
nvidia-smi

# Linux
lspci | grep -i nvidia

Instalación de CUDA y cuDNN

Correspondencia entre TensorFlow 2.15+ y versiones de CUDA：

TensorFlow CUDA cuDNN
2.15+ 12.2 8.9
2.12-2.14 11.8 8.6

Pasos de instalación：

  1. Descargar e instalar CUDA Toolkit

    • VisitaNVIDIA CUDA Toolkit
    • Selecciona la versión correspondiente para descargar e instalar
    • Agregar a la variable PATH del sistema

  2. Descargar e instalar cuDNN

    • VisitaNVIDIA cuDNN
    • Se requiere una cuenta NVIDIA registrada
    • Extraer al directorio de instalación de CUDA

  3. Verificar la instalación de CUDA

    nvcc --version
nvidia-smi

Verificación de la configuración

Script completo de verificación de instalación

Crearverify_installation.pyarchivo:

Ejemplo

#!/usr/bin/env python3
"""
Script de verificación de instalación de TensorFlow
"""

import sys
print("Python version:", sys.version)
print("-" * 50)

# Verificar TensorFlow
try:
    import tensorflow as tf
    print(f"✓ TensorFlow version: {tf.__version__}")
    print(f"✓ Keras version: {tf.keras.__version__}")
   
    # Verificar soporte de GPU
    physical_devices = tf.config.list_physical_devices('GPU')
    if physical_devices:
        print(f"✓ GPU devices found: {len(physical_devices)}")
        for i, device in enumerate(physical_devices):
            print(f"  - GPU {i}: {device}")
        print(f"✓ CUDA built: {tf.test.is_built_with_cuda()}")
    else:
        print("&#x26a0; No GPU devices found (CPU only)")
   
    # Prueba de cálculo simple
    a = tf.constant([1, 2, 3])
    b = tf.constant([4, 5, 6])
    c = tf.add(a, b)
    print(f"✓ Basic computation test: {a.numpy()} + {b.numpy()} = {c.numpy()}")
   
except ImportError as e:
    print(f"✗ TensorFlow import failed: {e}")

print("-" * 50)

# Verificar otros paquetes importantes
packages = ['numpy', 'pandas', 'matplotlib', 'sklearn', 'jupyter']
for package in packages:
    try:
        module = __import__(package)
        version = getattr(module, '__version__', 'unknown')
        print(f"✓ {package}: {version}")
    except ImportError:
        print(f"✗ {package}: not installed")

print("-" * 50)

# Información de memoria y dispositivos
print("System Information:")
if tf.config.list_physical_devices('GPU'):
    for gpu in tf.config.list_physical_devices('GPU'):
        try:
            tf.config.experimental.set_memory_growth(gpu, True)
            print(f"✓ GPU memory growth enabled for {gpu}")
        except:
            print(f"&#x26a0; Could not set memory growth for {gpu}")

print("Installation verification complete!")

Ejecutar la verificación:

python verify_installation.py

Prueba de rendimiento (benchmark)

Crear una prueba de rendimiento simple:

Ejemplo

import tensorflow as tf
import time

print("TensorFlow Performance Test")
print("-" * 30)

# Prueba de multiplicación de matrices
def benchmark_matmul(device_name, size=1000):
    with tf.device(device_name):
        a = tf.random.normal([size, size])
        b = tf.random.normal([size, size])
       
        # Calentamiento (warm-up)
        for _ in range(5):
            c = tf.matmul(a, b)
       
        # Cronometrar
        start_time = time.time()
        for _ in range(10):
            c = tf.matmul(a, b)
        end_time = time.time()
       
        avg_time = (end_time - start_time) / 10
        return avg_time

# Prueba de CPU
cpu_time = benchmark_matmul('/CPU:0')
print(f"CPU ({1000}x{1000} matmul): {cpu_time:.4f} seconds")

# Prueba de GPU (si está disponible)
if tf.config.list_physical_devices('GPU'):
    gpu_time = benchmark_matmul('/GPU:0')
    print(f"GPU ({1000}x{1000} matmul): {gpu_time:.4f} seconds")
    print(f"GPU speedup: {cpu_time/gpu_time:.2f}x")
else:
    print("No GPU available for testing")

Problemas comunes y soluciones

Problemas de instalación

Problema 1: tiempo de espera agotado en la instalación con pip

pip install --user tensorflow

Problema 2: error de permisos

# 创建新的虚拟环境
python -m venv fresh_env
source fresh_env/bin/activate  # Linux/Mac
# 或 fresh_env\Scripts\activate  # Windows
pip install tensorflow

Problema 3: conflicto de versiones

# 创建新的虚拟环境
python -m venv fresh_env
source fresh_env/bin/activate  # Linux/Mac
# 或 fresh_env\Scripts\activate  # Windows
pip install tensorflow

Problemas relacionados con GPU

Problema 1: versión de CUDA no coincidente

  • Verifica la compatibilidad de versiones de TensorFlow y CUDA
  • Reinstala la versión de CUDA compatible

Problema 2: memoria de GPU insuficiente

# 设置 GPU 内存增长
gpus = tf.config.experimental.list_physical_devices('GPU')
if gpus:
    for gpu in gpus:
        tf.config.experimental.set_memory_growth(gpu, True)

Problema 3: no se puede encontrar la GPU

# 检查 NVIDIA 驱动
nvidia-smi

# 检查 CUDA 安装
nvcc --version

# 重新安装 GPU 支持
pip uninstall tensorflow
pip install tensorflow

Problemas relacionados con Jupyter

Problema 1: el entorno virtual no es visible en Jupyter

# 安装 ipykernel
pip install ipykernel

# 添加虚拟环境到 Jupyter
python -m ipykernel install --user --name tensorflow_env --display-name "Python (TensorFlow)"

Problema 2: Jupyter no puede iniciarse

# 重新安装 Jupyter
pip uninstall jupyter notebook
pip install jupyter notebook

# 或使用 conda
conda install jupyter

Optimización del entorno de desarrollo

Gestión de memoria de GPU

# GPU 配置优化
import tensorflow as tf

# 方法 1：设置内存增长
gpus = tf.config.experimental.list_physical_devices('GPU')
if gpus:
    try:
        for gpu in gpus:
            tf.config.experimental.set_memory_growth(gpu, True)
    except RuntimeError as e:
        print(e)

# 方法 2：限制内存使用
if gpus:
    try:
        tf.config.experimental.set_memory_limit(gpus[0], 4096)  # 4GB
    except RuntimeError as e:
        print(e)

Configuración de optimización del rendimiento

# 启用混合精度训练（提升性能）
from tensorflow.keras.mixed_precision import experimental as mixed_precision

policy = mixed_precision.Policy('mixed_float16')
mixed_precision.set_policy(policy)

# 启用 XLA 编译优化
tf.config.optimizer.set_jit(True)
