JSP Configuración del entorno de desarrollo

El entorno de desarrollo JSP es el lugar donde usted desarrolla, prueba y ejecuta programas JSP.

Esta sección le guiará en la configuración del entorno de desarrollo JSP, que incluye los siguientes pasos.

Si usted está usando el entorno Eclipse, puede consultar directamente:Configuración del entorno Eclipse JSP/Servlet。

Configurar las herramientas de desarrollo de Java (JDK)

Este paso implica la descarga de Java JDK y la configuración de la variable de entorno PATH.

Puede descargar el JDK desde la página de Java de Oracle:Java SE Downloads

Después de descargar Java JDK, siga las instrucciones dadas para instalar y configurar el JDK. Finalmente, establezca las variables de entorno PATH y JAVA_HOME para indicar las rutas de las carpetas que incluyen java y javac, normalmente java_install_dir/bin y java_install_dir.

Si está utilizando Windows y el directorio de instalación del JDK es C::\jdk1.5.0_20, entonces necesita agregar las siguientes dos líneas al archivo C:\autoexec.bat:

set PATH=C:\jdk1.5.0_20\bin;%PATH%
set JAVA_HOME=C:\jdk1.5.0_20

O bien, en Windows NT/2000/XP, puede hacer clic derecho en el icono de Mi PC, seleccionar Propiedades, luego Opciones avanzadas, luego Variables de entorno, y a continuación puede configurar convenientemente la variable PATH y confirmar para salir.

En sistemas Linux/Unix, si el directorio de instalación del JDK es /usr/local/jdk1.5.0_20 y está utilizando C shell, entonces necesitará agregar las siguientes dos líneas al archivo .cshrc:

setenv PATH /usr/local/jdk1.5.0_20/bin:$PATH
setenv JAVA_HOME /usr/local/jdk1.5.0_20

O bien, si está utilizando un entorno de desarrollo integrado como Borland JBuilder, Eclipse, IntelliJ IDEA y Sun ONE Studio, puede intentar compilar y ejecutar un programa simple para determinar si el IDE (entorno de desarrollo integrado) ya conoce el directorio de instalación del JDK.

En este paso también puede consultarConfiguración del entorno de desarrollo de Javael tutorial del capítulo.

Configurar el servidor web: Tomcat

Actualmente, hay muchos servidores web en el mercado que admiten el desarrollo de JSP y Servlets. Algunos de ellos se pueden descargar y usar gratuitamente; Tomcat es uno de ellos.

Apache Tomcat es un software de código abierto que puede funcionar como servidor independiente para ejecutar JSP y Servlets, y también puede integrarse en Apache Web Server. A continuación se muestran los métodos de configuración de Tomcat:

  • Descargue la última versión de Tomcat:http://tomcat.apache.org/。
  • Después de descargar el archivo de instalación, descomprima el archivo comprimido en un lugar conveniente, por ejemplo, el directorio C:\apache-tomcat-5.5.29 en Windows o el directorio /usr/local/apache-tomcat-5.5.29 en Linux/Unix, y luego cree la variable de entorno CATALINA_HOME que apunte a estos directorios.

En máquinas Windows, Tomcat se puede iniciar ejecutando el siguiente comando:

%CATALINA_HOME%\bin\startup.bat
或者
C:\apache-tomcat-5.5.29\bin\startup.bat

En máquinas Linux/Unix, Tomcat se puede iniciar ejecutando el siguiente comando:

$CATALINA_HOME/bin/startup.sh
或者
/usr/local/apache-tomcat-5.5.29/bin/startup.sh

Después de iniciar Tomcat correctamente, puede acceder a http://localhost:8080/ para utilizar algunas de las aplicaciones web incluidas con Tomcat. Si todo va bien, debería poder ver la siguiente página:

Puede encontrar más información sobre la configuración y ejecución de Tomcat en la documentación proporcionada por Tomcat, o consultar el sitio web oficial de Tomcat: http://tomcat.apache.org.

En máquinas Windows, Tomcat se puede detener ejecutando el siguiente comando:

%CATALINA_HOME%\bin\shutdown.bat
或者
C:\apache-tomcat-5.5.29\bin\shutdown.bat

En máquinas Linux/Unix, Tomcat se puede detener ejecutando el siguiente comando:

$CATALINA_HOME/bin/shutdown.sh
或者
/usr/local/apache-tomcat-5.5.29/bin/shutdown.sh

Configurar la variable de entorno CLASSPATH

Dado que los servlets no son parte de Java SE, debe indicar el compilador de las clases de servlet.

Si está utilizando una máquina Windows, necesita agregar las siguientes dos líneas al archivo C:\autoexec.bat:

set CATALINA=C:\apache-tomcat-5.5.29
set CLASSPATH=%CATALINA%\common\lib\jsp-api.jar;%CLASSPATH%

O bien, en Windows NT/2000/XP, solo haga clic derecho en Mi PC, seleccione Propiedades, luego haga clic en Opciones avanzadas, luego en Variables de entorno, y a continuación podrá configurar la variable CLASSPATH y confirmar para salir.

En máquinas Linux/Unix, si está utilizando C shell, necesitará agregar las siguientes dos líneas al archivo .cshrc:

setenv CATALINA=/usr/local/apache-tomcat-5.5.29
setenv CLASSPATH $CATALINA/common/lib/jsp-api.jar:$CLASSPATH

Nota: Si su ruta de desarrollo es C:\JSPDev (Windows) o /usr/JSPDev (Linux/Unix), necesitará agregar estas rutas a la variable CLASSPATH.

    Configuración de la variable de entorno Catalina_Home de Tomcat

    1. CATALINA_HOME es un alias de la ruta de instalación de TOMCAT, con el objetivo de facilitar el uso de TOMCAT.

    2. Equipo > Propiedades > Variables de entorno, cree una nueva variable de entorno. El nombre de la variable es CATALINA_HOME, el valor de la variable es el directorio de descompresión de tomcat; en mi computadora es: "D:\apache-tomcat-7.0.12", tenga en cuenta que no necesita agregar "\" o ";" al final.

    3. En la variable de entorno Path, agregue "%CATALINA_HOME%\bin\"

    3. Iniciar tomcat: entre en la línea de comandos cmd y escriba startup.bat

    4. Abra el navegador e introduzca:http://localhost:8080, (si ha modificado el número de puerto, agregue el puerto correspondiente) para ver si tomcat se inició correctamente.

    5. Cerrar tomcat: entre en la línea de comandos cmd y escriba shutdown.bat

    El puerto 8080 de tomcat suele estar ocupado; hay dos soluciones:

    • 1. Cerrar el proceso que ocupa el puerto 8080: si el puerto 8080 está ocupado, ejecutar startup.bat dará un error. Puede ejecutar el comando netstat -ano en cmd para ver si el 8080 está ocupado. Si está ocupado, puede buscar el PID correspondiente en el Administrador de tareas y cerrar el proceso, y luego reiniciar tomcat. La desventaja de este método es que cada vez que el puerto esté ocupado, debe repetir la operación anterior.
    • 2. Cambiar el puerto de tomcat: entre en la carpeta \conf\ del directorio de instalación de tomcat, abra service.xml con el Bloc de notas, especifique un nuevo número de puerto en la posición que se muestra a continuación y reinicie tomcat.
      <Connector port="8022" protocol="HTTP/1.1"
    connectionTimeout="20000" 
    redirectPort="8443" />

    El parámetro protocol se puede modificar aorg.apache.coyote.http11.Http11NioProtocol, puede mejorar la capacidad de concurrencia de tomcat; después de modificar esta configuración, debe reiniciar tomcat para que surta efecto.

    <Connector port="8022" protocol="org.apache.coyote.http11.Http11NioProtocol"
    connectionTimeout="20000" 
    redirectPort="8443" />

    ¿Cómo encontrar la aplicación que ocupa un puerto específico?

    Ejecute la ventana de comandos CMD como administrador.

    netstat -ano |findstr 3306      # 查看3306端口是否存在
tasklist |findstr 3036（PID号）  # 查看pid为3036的是什么程序在用
taskkill /T /F /PID 3036        # 强制（/F参数）杀死pid为3036的所有进程包括子进程（/T参数）

    Consulte más contenido en:En Windows, cómo ver qué proceso ocupa un puerto determinado.
