Operadores de TypeScript

Los operadores se utilizan para realizar operaciones en el código del programa, operando sobre uno o más operandos.

Considere el siguiente cálculo:

7 + 5 = 12

En el ejemplo anterior, 7, 5 y 12 son operandos.

Operador+Se utiliza para sumar.

Operador=Se utiliza para asignar.

TypeScript incluye principalmente los siguientes tipos de operaciones:

  • Operadores aritméticos
  • Operadores lógicos
  • Operadores relacionales
  • Operadores bit a bit
  • Operadores de asignación
  • Operador ternario/condicional
  • Operadores de cadena
  • Operadores de tipo

- Resta x=y-2 3 5
* Multiplicación x=y*2 10 5
/ División x=y/2 2.5 5

x=y++ 5 6

Dados x=6 y y=3, la siguiente tabla explica los operadores lógicos:

Operador Descripción Ejemplo
&& and (x < 10 && y > 1) es true
|| or (x==5 || y==5) es false
! not !(x==y) es true

Ejemplo

var avg:number = 20; var percentage:number = 90; console.log("El valor de avg es:"+avg+", el valor de percentage es:"+percentage); var res:boolean = ((avg>50)&&(percentage>80)); console.log("(avg>50)&&(percentage>80): ",res); var res:boolean = ((avg>50)||(percentage>80)); console.log("(avg>50)||(percentage>80): ",res); var res:boolean=!((avg>50)&&(percentage>80)); console.log("!((avg>50)&&(percentage>80)): ",res);

Usetscel comando para compilar el código anterior y obtener el siguiente código JavaScript:

var avg = 20; var percentage = 90; console.log("El valor de avg es:" + avg + ", el valor de percentage es:" + percentage); var res = ((avg > 50) && (percentage > 80)); console.log("(avg>50)&&(percentage>80): ", res); var res = ((avg > 50) || (percentage > 80)); console.log("(avg>50)||(percentage>80): ", res); var res = !((avg > 50) && (percentage > 80)); console.log("!((avg>50)&&(percentage>80)): ", res);

Operadores de cortocircuito (&& y ||)

Los operadores && y || se pueden utilizar para combinar expresiones. El operador && solo devuelve true si tanto la expresión izquierda como la derecha son true.

Considere el siguiente ejemplo:

var a = 10 
var result = ( a<10 && a>5)

En el ejemplo anterior, a < 10 y a > 5 son expresiones combinadas con el operador &&. La primera expresión devuelve false. Dado que la operación && requiere que ambas expresiones sean true, si la primera es false, no se ejecuta la evaluación posterior (a > 5 se omite) y se devuelve directamente false.

El operador || devuelve true si al menos una de las expresiones de la combinación es true.

Considere el siguiente ejemplo:

var a = 10 
var result = ( a>5 || a<10)

En el ejemplo anterior, a > 5 y a < 10 son expresiones combinadas con el operador ||. La primera expresión devuelve true. Dado que la operación combinada || solo necesita que una expresión sea true, si la primera es true, no se ejecuta la evaluación posterior (a < 10 se omite) y se devuelve directamente true.

Operadores de bits

Las operaciones de bits son operaciones unarias y binarias sobre patrones de bits o números binarios en el diseño de programas.


Operador Descripción Ejemplo Similar a Resultado Decimal
& AND, el AND bit a bit procesa dos números binarios de la misma longitud; si los dos bits correspondientes son 1, el bit de resultado es 1; de lo contrario, es 0. x = 5 & 1 0101 & 0001 0001  1
| OR, el OR bit a bit procesa dos números binarios de la misma longitud; si al menos uno de los dos bits correspondientes es 1, el bit de resultado es 1. x = 5 | 1 0101 | 0001 0101  5
~ NOT (inversión), la inversión es un operador unario que realiza la operación lógica de negación sobre cada bit de un número binario. Hace que el 1 se convierta en 0 y el 0 en 1. x = ~ 5  ~0101 1010  -6
^ XOR, la operación XOR bit a bit realiza la operación lógica XOR bit a bit sobre cada bit de patrones binarios de igual longitud o números binarios. El resultado es que si los bits son diferentes, el bit es 1; de lo contrario, el bit es 0. x = 5 ^ 1 0101 ^ 0001 0100  4
<< Desplazamiento a la izquierda, desplaza todos los bits del operando a la izquierda de << varios lugares. El número a la derecha de << especifica el número de posiciones a desplazar. Los bits altos se descartan y los bits bajos se rellenan con 0. x = 5 << 1 0101 << 1 1010  10
>> Desplazamiento a la derecha, desplaza todos los bits del operando a la izquierda de >> varios lugares a la derecha. El número a la derecha de >> especifica el número de posiciones a desplazar. x = 5 >> 1 0101 >> 1 0010 2
>>> Desplazamiento a la derecha sin signo, similar al desplazamiento a la derecha con signo, excepto que los bits de la izquierda siempre se rellenan con 0. x = 2 >>> 1 0010 >>> 1 0001 1

Ejemplo

var a:number = 2; //Binario 10 var b:number = 3; //Binario 11 var result; result = (a & b); console.log("(a & b) => ",result) result = (a | b); console.log("(a | b) => ",result) result = (a ^ b); console.log("(a ^ b) => ",result); result = (~b); console.log("(~b) => ",result); result = (a << b); console.log("(a << b) => ",result); result = (a >> b); console.log("(a >> b) => ",result); result = (a >>> 1); console.log("(a >>> 1) => ",result);

Usetscel comando para compilar el código anterior y obtener el siguiente código JavaScript:

var a = 2; //Binario 10 var b = 3; //Binario 11 var result; result = (a & b); console.log("(a & b) => ", result); result = (a | b); console.log("(a | b) => ", result); result = (a ^ b); console.log("(a ^ b) => ", result); result = (~b); console.log("(~b) => ", result); result = (a << b); console.log("(a << b) => ", result); result = (a >> b); console.log("(a >> b) => ", result); result = (a >>> 1); console.log("(a >>> 1) => ", result);

Al ejecutar el código JavaScript anterior, el resultado es:

(a & b) =>  2
(a | b) =>  3
(a ^ b) =>  1
(~b) =>  -4
(a << b) =>  16
(a >> b) =>  0
(a >>> 1) =>  1

Los operadores de asignación se utilizan para asignar valores a variables.

Dadox=10 和 y=5, la siguiente tabla explica los operadores de asignación:

Operador Ejemplo Ejemplo Valor de x

+= (realiza la suma y luego asigna) x += y x = x + y x = 15

var a = 12; var b = 10; a = b; console.log("a = b: " + a); a += b; console.log("a+=b: " + a); a -= b; console.log("a-=b: " + a); a *= b; console.log("a*=b: " + a); a /= b; console.log("a/=b: " + a); a %= b; console.log("a%=b: " + a);

Operador ternario (?)

La operación ternaria tiene 3 operandos y necesita evaluar el valor de una expresión booleana. La función principal de este operador es decidir qué valor debe asignarse a la variable.

Test ? expr1 : expr2
  • Test − La sentencia de condición especificada
  • expr1 − Si la sentencia de condición Test devuelve true, se devuelve este valor
  • expr2 − Si la sentencia de condición Test devuelve false, se devuelve este valor

Veamos el siguiente ejemplo:

var num:number = -2 var result = num > 0 ? "Mayor que 0" : "Menor que 0, o igual a 0" console.log(result)

En el ejemplo se usa para determinar si la variable es mayor que 0.

Usando el comando tsc para compilar el código anterior se obtiene el siguiente código JavaScript:

var num = -2; var result = num > 0 ? "Mayor que 0" : "Menor que 0, o igual a 0"; console.log(result);

La salida del ejemplo anterior es la siguiente:

小于 0，或等于 0
