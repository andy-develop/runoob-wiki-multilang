Pandas JSON

JSON（JavaScript Object NNotación de objetos JavaScript, es una sintaxis para almacenar e intercambiar información de texto, similar a XML.

JSON es más pequeño, más rápido y más fácil de analizar que XML. Para más contenido sobre JSON, consulteTutorial de JSON。

Pandas proporciona potentes métodos para manejar datos en formato JSON, admite leer datos desde archivos o cadenas JSON y convertirlos a DataFrame, así como convertir DataFrame de vuelta a formato JSON.

OperaciónMétodoDescripción
Leer datos desde archivo/cadena JSONpd.read_json()Leer datos JSON y cargarlos como DataFrame
Convertir DataFrame a JSONDataFrame.to_json()Convierte DataFrame a datos en formato JSON, se puede especificar el método de estructuración
Métodos de estructuración JSON compatiblesorientParámetroAdmite múltiples métodos de estructuración, comosplit、records、columns

Pandas puede manejar datos JSON convenientemente. Este artículo toma como ejemplosites.jsonpor ejemplo, el contenido es el siguiente:

Ejemplo

[ { "id": "A001", "name": "Tutorial para novatos", "url": "www.runoob.com", "likes": 61 }, { "id": "A002", "name": "Google", "url": "www.google.com", "likes": 124 }, { "id": "A003", "name": "Taobao", "url": "www.taobao.com", "likes": 45 } ]

Cargar datos desde archivos/cadenas JSON

pd.read_json() - Leer datos JSON

read_json() se utiliza para leer datos en formato JSON y cargarlos como un DataFrame. Admite cargar datos desde archivos JSON, cadenas JSON o URLs JSON.

Formato de sintaxis:

import pandas as pd

df = pd.read_json(
    path_or_buffer,      # JSON 文件路径、JSON 字符串或 URL
    orient=None,         # JSON 数据的结构方式，默认是 'columns'
    dtype=None,          # 强制指定列的数据类型
    convert_axes=True,   # 是否转换行列索引
    convert_dates=True,  # 是否将日期解析为日期类型
    keep_default_na=True # 是否保留默认的缺失值标记
)

Descripción de parámetros:

ParámetroDescripciónValor predeterminado
path_or_bufferRuta del archivo JSON, cadena JSON o URLParámetro obligatorio
orientDefine el método de formato de los datos JSON. Los valores comunes son:split、records、index、columns、values。None(inferido automáticamente del archivo)
dtypeForzar la especificación del tipo de dato de las columnasNone
convert_axesSi se convierten los ejes a tipos de datos apropiadosTrue
convert_datesSi se analizan las fechas como tipo fechaTrue
keep_default_naSi se conservan los marcadores de valores faltantes predeterminados (comoNaN）True

Opciones comunes del parámetro orient:

Valor de orientEjemplo de formato JSONDescripción
split{"index":["a","b"],"columns":["A","B"],"data":[[1,2],[3,4]]}Usar clavesindex、columns 和 dataEstructura
records[{"A":1,"B":2},{"A":3,"B":4}]Cada registro es un diccionario, que representa una fila de datos
index{"a":{"A":1,"B":2},"b":{"A":3,"B":4}}Usa el índice como clave y el valor como diccionario
columns{"A":{"a":1,"b":3},"B":{"a":2,"b":4}}Usa los nombres de columnas como claves y los valores como diccionarios
values[[1,2],[3,4]]Devuelve solo los datos, sin incluir el índice ni los nombres de columnas

Cargar datos desde un archivo JSON:

Ejemplo

import pandas as pd

df = pd.read_json('sites.json')
   
print(df.to_string())

Convertir DataFrame a JSON

DataFrame.to_json() - Convertir DataFrame a datos JSON

El método to_json() se utiliza para convertir DataFrame a datos en formato JSON, y se puede especificar el método de estructuración de JSON.

Formato de sintaxis:

df.to_json(
    path_or_buffer=None,    # 输出的文件路径或文件对象，如果是 None 则返回 JSON 字符串
    orient=None,            # JSON 格式方式，支持 'split', 'records', 'index', 'columns', 'values'
    date_format=None,       # 日期格式，支持 'epoch', 'iso'
    default_handler=None,   # 自定义非标准类型的处理函数
    lines=False,            # 是否将每行数据作为一行（适用于 'records' 或 'split'）
    encoding='utf-8'        # 编码格式
)

Descripción de parámetros:

ParámetroDescripciónValor predeterminado
path_or_bufferLa ruta del archivo de salida o el objeto de archivo, si esNone, entonces devuelve una cadena JSONNone
orientEspecifica la estructura del formato JSON, admitesplit、records、index、columns、valuesNone(el valor predeterminado escolumns）
date_formatFormato de fecha, admite'epoch' 或 'iso'formatoNone
default_handlerManejador personalizado para tipos no estándar (comodatetimeetc.) función de procesamientoNone
linesSi se debe generar cada fila de datos como una línea (aplicable arecords 或 split）False
encodingFormato de codificación del archivo de salida'utf-8'

Ejemplo

import pandas as pd

# Crear DataFrame
df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Los Angeles', 'Chicago']
})

# Convertir DataFrame a cadena JSON
json_str = df.to_json()

print(json_str)

Convertir DataFrame a archivo JSON (especificar orient='records'):

Ejemplo

import pandas as pd

# Crear DataFrame
df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Los Angeles', 'Chicago']
})

# Convertir DataFrame a archivo JSON, especificando orient='records'
df.to_json('data.json', orient='records', lines=True)

# Salida del contenido del archivo generado:
# [
#   {"Name":"Alice","Age":25,"City":"New York"},
#   {"Name":"Bob","Age":30,"City":"Los Angeles"},
#   {"Name":"Charlie","Age":35,"City":"Chicago"}
# ]

Convertir DataFrame a JSON y especificar el formato de fecha:

Ejemplo

import pandas as pd

# Crear DataFrame con datos de fecha
df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Date': pd.to_datetime(['2021-01-01', '2022-02-01', '2023-03-01']),
    'Age': [25, 30, 35]
})

# Convertir DataFrame a JSON y especificar el formato de fecha como 'iso'
json_str = df.to_json(date_format='iso')

print(json_str)
