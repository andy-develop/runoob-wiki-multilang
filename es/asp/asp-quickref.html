Resumen de ASP

ASP Referencia rápida

Referencia rápida de ASP del tutorial para novatos. Imprímela, guárdala en tu bolsillo y úsala en cualquier momento.

Sintaxis básica

Los scripts ASP están encerrados entre <% y %>. Para escribir salida en el navegador:

<html>
<body>
<% response.write("Hello World!") %>
</body>
</html>

El lenguaje predeterminado en ASP es VBScript. Para usar otro lenguaje de script, inserte una declaración de lenguaje en la parte superior de la página ASP:

<%@ language="javascript" %>
<html>
<body>

<%
....
%>

Formularios y entrada del usuario

Request.QueryString se usa para recopilar valores de un formulario con method="get". La información enviada desde un formulario mediante el método GET es visible para todos los usuarios (aparece en la barra de direcciones del navegador) y también tiene limitaciones en la cantidad de información enviada.

Request.Form se usa para recopilar valores de un formulario con method="post". La información enviada desde un formulario mediante el método POST no es visible para el usuario y no tiene límite en la cantidad de información enviada.

ASP Cookies

Las cookies se utilizan a menudo para identificar a los usuarios. Una cookie es un pequeño archivo que el servidor deja en el ordenador del usuario. Cada vez que el mismo ordenador solicita una página a través del navegador, enviará la cookie.

El comando Response.Cookies se usa para crear cookies:

<%
Response.Cookies("firstname")="Alex"
Response.Cookies("firstname").Expires="May 10,2002"
%>

Nota:El comando Response.Cookies debe aparecer antes de la etiqueta <html>.

El comando Request.Cookies se utiliza para recuperar el valor de la cookie:

<%
fname=Request.Cookies("firstname")
response.write("Firstname=" & fname)
%>

Incluir archivos

Mediante la directiva #include, puede insertar el contenido de otro archivo ASP en un archivo ASP antes de que el servidor lo ejecute. La directiva #include se usa para crear funciones, encabezados, pies de página u otros elementos que deban reutilizarse en varias páginas.

Sintaxis:

<!--#include virtual="somefile.inc"-->
O
<!--#include file ="somefile.inc"-->

Use la palabra clave virtual para indicar una ruta que comience con un directorio virtual. Si un archivo llamado "header.inc" se encuentra en el directorio virtual /html, la siguiente línea de código insertará el contenido del archivo "header.inc":

<!-- #include virtual ="/html/header.inc" -->

Use la palabra clave file para indicar una ruta relativa. La ruta relativa comienza con el directorio que contiene el archivo. Si usted tiene un archivo en el directorio html y el archivo "header.inc" se encuentra en la cabecera de html, la siguiente línea insertará el contenido del archivo "header.inc" en su archivo:

<!-- #include file ="headersheader.inc" -->

Use la palabra clave file con la sintaxis (..) para hacer referencia a archivos en directorios de nivel superior.

Global.asa

El archivo Global.asa es un archivo opcional que puede contener declaraciones de objetos, variables y métodos que son accedidos por cada página de la aplicación ASP.

Nota:El archivo Global.asa debe estar en el directorio raíz de la aplicación ASP, y cada aplicación solo puede tener un archivo Global.asa.

El archivo Global.asa solo puede contener lo siguiente:

  • Eventos de Application
  • Eventos de Session
  • Declaraciones <object>
  • Declaraciones de TypeLibrary
  • Directivas #include

Eventos Application y Session

En Global.asa, puede indicar a los objetos application y session qué hacer cuando la aplicación/sesión comienza y qué hacer cuando termina. El código que realiza esta tarea se coloca en los controladores de eventos.Nota:Como no podemos insertar scripts en el archivo Global.asa usando los delimitadores de script de ASP (<% y %>), necesitamos colocar las subrutinas dentro de las etiquetas <script> de HTML:

<script language="vbscript" runat="server">
sub Application_OnStart
' some code
end sub
sub Application_OnEnd
' some code
end sub
sub Session_OnStart
' some code
end sub
sub Session_OnEnd
' some code
end sub
</script>

Declaraciones <object>

Puede crear objetos con ámbito de sesión o de aplicación en el archivo Global.asa usando la etiqueta <object>.Nota:La etiqueta <object> debe estar fuera de las etiquetas <script>.

Sintaxis:

<object runat="server" scope="scope" id="id"
{progid="progID"|classid="classID"}>
.......
</object>

Declaración de TypeLibrary

TypeLibrary (biblioteca de tipos) es un contenedor que contiene archivos DLL correspondientes a objetos COM. Al incluir llamadas a TypeLibrary en el archivo Global.asa, puede acceder a las constantes de los objetos COM y el código ASP también puede informar mejor los errores. Si su aplicación web depende de objetos COM con tipos de datos ya declarados en la biblioteca de tipos, puede declarar la biblioteca de tipos en Global.asa.

Sintaxis:

<!--METADATA TYPE="TypeLib"
file="filename"
uuid="typelibraryuuid"
version="versionnumber"
lcid="localeid"
-->

Objeto Session

El objeto Session se utiliza para almacenar información sobre la sesión de un usuario o cambiar la configuración de la sesión. Las variables almacenadas en el objeto Session guardan información de un solo usuario y están disponibles para todas las páginas de la aplicación.

Colecciones

  • Contents: contiene todas las entradas agregadas a la sesión mediante comandos de script.
  • StaticObjects: contiene todos los objetos agregados a la sesión mediante la etiqueta <object> de HTML.
  • Contents.Remove(item/indexContents.Remove() - Elimina un elemento de la colección Contents.
  • Contents.RemoveAll() - Elimina todos los elementos de la colección Contents.

Propiedades

  • CodePage: especifica el juego de caracteres utilizado al mostrar contenido dinámico.
  • LCID: establece el identificador regional que se utiliza para mostrar contenido dinámico.
  • SessionID: devuelve el id de sesión.
  • Timeout: establece o devuelve el tiempo de espera (timeout) de la sesión.

Métodos

  • Abandon: elimina todos los objetos del objeto Session.

Objeto Application

Un grupo de archivos ASP que trabajan juntos para realizar una tarea se denomina aplicación. El objeto Application se utiliza para agrupar estos archivos. Todos los usuarios comparten un objeto Application. El objeto Application contiene información (como información de conexión a la base de datos) que será utilizada por muchas páginas de la aplicación.

Colecciones

  • Contents: contiene todos los elementos agregados a la aplicación mediante comandos de script.
  • StaticObjects: contiene todos los objetos agregados a la aplicación mediante la etiqueta <object> de HTML.
  • Contents.Remove: elimina un elemento de la colección Contents.
  • Contents.RemoveAll: elimina todos los elementos de la colección Contents.

Métodos

  • Lock: evita que los usuarios modifiquen los atributos del objeto Application.
  • Unlock: permite que los usuarios modifiquen los atributos del objeto Application.

Objeto Response

El objeto Response se utiliza para enviar al usuario la salida resultante desde el servidor.

Colecciones

  • Cookies(name): establece el valor de una cookie. Si la cookie no existe, se crea y se le asigna el valor especificado.

Propiedades

  • Buffer: especifica si se debe almacenar en búfer la salida. Cuando la salida está configurada en búfer, el servidor retiene la respuesta dirigida al navegador hasta que todos los scripts del servidor hayan sido procesados, o hasta que el script llame a los métodos Flush o End. Si desea establecer esta propiedad, debe ubicarse antes de la etiqueta <html> en el archivo ASP.
  • CacheControl: establece si un servidor proxy puede almacenar en caché la salida generada por ASP. Si se establece en Public, el servidor proxy almacenará la página en caché.
  • Charset(charset_name) - Agrega el nombre del juego de caracteres (por ejemplo, "ISO8859-1") al encabezado de tipo de contenido en el objeto Response.
  • ContentType: establece el tipo de contenido HTTP del objeto Response (por ejemplo, "text/html", "image/gif", "image/jpeg", "text/plain"). El valor predeterminado es "text/html".
  • Expires: establece el tiempo de almacenamiento en caché del navegador antes de que la página expire (en minutos).
  • ExpiresAbsolute: establece la fecha y hora en que expira la caché de la página en el navegador.
  • IsClientConnected - Indica si el cliente se ha desconectado del servidor.
  • Pics(pics_label) - Agrega un valor a la etiqueta PICS del encabezado de response.
  • Status - Especifica el valor de la línea de estado devuelta por el servidor.

Métodos

  • AddHeader(name, value) - Agrega un nuevo encabezado y valor HTTP a la respuesta HTTP.
  • AppendToLog string - Agrega una cadena al final de la entrada del registro del servidor (server log entry).
  • BinaryWrite(data_to_write) - Escribe datos directamente en la salida sin ninguna conversión de caracteres.
  • Clear - Limpia la salida almacenada en búfer. Use este método para manejar errores. Si Response.Buffer no está establecido en true, este método generará un error en tiempo de ejecución.
  • End - Detiene el procesamiento del script y devuelve el resultado actual.
  • Flush - Envía inmediatamente la salida almacenada en búfer. Si Response.Buffer no está establecido en true, este método generará un error en tiempo de ejecución.
  • Redirect(url) - Redirige al usuario a otra URL.
  • Write(data_to_write) - Escribe texto para el usuario.

Objeto Request

Cuando el navegador solicita una página al servidor, este comportamiento se denomina una request (solicitud). El objeto Request se utiliza para obtener información del usuario.

Colecciones

  • ClientCertificate - Contiene todos los valores de campo almacenados en el certificado del cliente.
  • Cookies(name) - Contiene todos los valores de cookie enviados en la solicitud HTTP.
  • Form(element_name) - Contiene todos los valores de formulario (entrada) enviados mediante el método post desde un formulario.
  • QueryString(variable_name) - Contiene todos los valores de variable en la cadena de consulta HTTP.
  • ServerVariables(server_variable) - Contiene todos los valores de variables del servidor.

Propiedades

  • TotalBytes - Devuelve el número total de bytes enviados por el cliente en el cuerpo de la solicitud.

Métodos

  • BinaryRead - Recupera los datos enviados al servidor desde el cliente como parte de una solicitud post.

Objeto Server

El objeto Server se utiliza para acceder a propiedades y métodos en el servidor.

Propiedades

  • ScriptTimeout - Establece o devuelve el tiempo máximo (en segundos) que un script puede ejecutarse antes de ser terminado.

Métodos

  • CreateObject(type_of_object) - Crea una instancia de un objeto.
  • Execute(path) - Ejecuta otro archivo ASP desde dentro de un archivo ASP. Una vez que el archivo ASP invocado ha terminado de ejecutarse, el control regresa al archivo ASP original.
  • GetLastError() - Devuelve un objeto ASPError que describe el estado del error que ha ocurrido.
  • HTMLEncode(string) - Aplica codificación HTML a una cadena.
  • MapPath(path) - Asigna una ruta relativa o virtual a una ruta física.
  • Transfer(path) - Envía toda la información de estado a otro archivo para su procesamiento. Después de la transferencia, el control del programa no regresa al archivo ASP original.
  • URLEncode(string) - Aplica reglas de codificación URL a una cadena.
