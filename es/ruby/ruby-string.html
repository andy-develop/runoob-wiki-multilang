Ruby Cadena (String)

El objeto String en Ruby se utiliza para almacenar o manipular secuencias de uno o más bytes.

Las cadenas de Ruby se dividen en cadenas con comillas simples (') y cadenas con comillas dobles ("); la diferencia es que las cadenas con comillas dobles pueden admitir más caracteres de escape.

Cadenas con comillas simples

La cadena más simple es la cadena con comillas simples, es decir, almacenar la cadena entre comillas simples:

'Esta es la cadena de un programa Ruby'

Si necesita usar caracteres de comillas simples dentro de una cadena con comillas simples, entonces debe usar una barra invertida (\) dentro de la cadena con comillas simples, para que el intérprete de Ruby no considere este carácter de comilla simple como el símbolo de terminación de la cadena:

'Won\'t you read O\'Reilly\'s book?'

La barra invertida también puede escapar otra barra invertida, de modo que la segunda barra invertida no se interpretará como un carácter de escape.

A continuación se presentan las características relacionadas con las cadenas en Ruby.

Cadenas con comillas dobles

En las cadenas con comillas dobles podemos usar#{}el signo de almohadilla (#) y las llaves ({}) para calcular el valor de expresiones:

Incrustar variables en cadenas:

Ejemplo

#!/usr/bin/ruby # -*- coding: UTF-8 -*- name1 = "Joe" name2 = "Mary" puts "Hola #{name1}, ¿dónde está #{name2}?"

Pruébalo »

El resultado de ejecutar el ejemplo anterior es:

你好 Joe,  Mary 在哪?

Realizar operaciones matemáticas en cadenas:

Ejemplo

#!/usr/bin/ruby # -*- coding: UTF-8 -*- x, y, z = 12, 36, 72 puts "El valor de x es #{ x }" puts "El valor de x + y es #{ x + y }" puts "El promedio de x + y + z es #{ (x + y + z)/3 }"

Pruébalo »

El resultado de ejecutar el ejemplo anterior es:

x 的值为 12
x + y 的值为 48
x + y + z 的平均值为 40

Ruby también admite variables de cadena introducidas con %q y %Q. %q usa las reglas de comillas simples, mientras que %Q usa las reglas de comillas dobles, seguidas de un delimitador de apertura como (!, [, {, etc.) y un delimitador de cierre como (}, ], ), etc.).

El carácter que sigue a q o Q es el delimitador. El delimitador puede ser cualquier carácter de un solo byte que no sea alfanumérico, como [, {, (, <, !, etc. La cadena se leerá hasta que se encuentre el delimitador de cierre correspondiente.

Ejemplo

#!/usr/bin/ruby # -*- coding: UTF-8 -*- desc1 = %Q{Las cadenas de Ruby pueden usar '' y "".} desc2 = %q|Las cadenas de Ruby pueden usar '' y "".| puts desc1 puts desc2

Pruébalo »

El resultado de ejecutar el ejemplo anterior es:

Ruby 的字符串可以使用 '' 和 ""。
Ruby 的字符串可以使用 '' 和 ""。

Codificación de caracteres

El conjunto de caracteres predeterminado de Ruby es ASCII, y los caracteres pueden representarse con un solo byte. Si utiliza UTF-8 u otro conjunto de caracteres moderno, los caracteres pueden representarse con uno a cuatro bytes.

Puede cambiar el conjunto de caracteres al comienzo del programa usando $KCODE, como se muestra a continuación:

$KCODE = 'u'

A continuación se muestran los posibles valores de $KCODE.

Métodos integrados de cadenas

Necesitamos tener una instancia del objeto String para llamar a los métodos de String. A continuación se muestra la forma de crear una instancia del objeto String:

new [String.new(str="")]

Esto devolverá un nuevo objeto de cadena que contiene unastrcopia del nuevo objeto de cadena. Ahora, usando elstrobjeto, podemos llamar a cualquier método de instancia disponible. Por ejemplo:

Ejemplo

#!/usr/bin/ruby myStr = String.new("THIS IS TEST") foo = myStr.downcase puts "#{foo}"

Esto producirá el siguiente resultado:

this is test

56str.split(pattern=$;, [limit])

Divide str en subcadenas según el separador y devuelve un array de estas subcadenas.

Sipatternes una cadena String, se utilizará como separador al dividir str. Si pattern es un único espacio en blanco, str se divide por espacios, ignorando los espacios iniciales y los caracteres de espacio consecutivos.

Sipatternes una expresión regular Regexp, str se divide en los lugares donde pattern coincide. Cuando pattern coincide con una cadena de longitud cero, str se divide en caracteres individuales.

Si se omitepatternel argumento, se utiliza el valor de $;. Si $; es nil (por defecto), str se divide por espacios, como si se hubiera especificado ` ` como separador.

Si se omitelimitel argumento, se suprimen los campos nulos finales. Si limit es un número positivo, se devuelve como máximo esa cantidad de campos (si limit es 1, se devuelve toda la cadena como único elemento del array). Si limit es un número negativo, el número de campos devueltos no tiene límite y no se suprimen los campos nulos finales.

75str.unpack(format)
Decodifica str (que puede contener datos binarios) según la cadena de formato y devuelve un array con cada uno de los valores extraídos. Los caracteres de formato consisten en una serie de instrucciones de un solo carácter. Cada instrucción puede ir seguida de un número que indica el número de veces que se repite dicha instrucción. El asterisco (*) utilizará todos los elementos restantes. Las instrucciones sSiIlL pueden ir seguidas de un guion bajo (_) para usar el tamaño nativo de la plataforma subyacente para el tipo especificado; de lo contrario, se usa un tamaño consistente e independiente de la plataforma. Se ignoran los espacios en blanco en la cadena de formato.
76str.upcase
Devuelve una copia de str en la que todas las letras minúsculas se reemplazan por letras mayúsculas. La operación es insensible a la configuración regional; solo se ven afectados los caracteres de la a a la z.
77str.upcase!
Cambia el contenido de str a mayúsculas; devuelve nil si no hay cambios.
78str.upto(other_str) { |s| block }

ZStringUsado con *, elimina los null finales hasta el primer null.
@ Omite el desplazamiento dado por el parámetro length.
