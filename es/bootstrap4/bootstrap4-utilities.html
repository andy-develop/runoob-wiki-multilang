Bootstrap4 Utilidades

Bootstrap4 proporciona algunas utilidades que nos permiten lograr el efecto deseado sin tener que escribir código CSS.

Bordes

Usando laborderclase puede agregar o eliminar bordes:

Ejemplo

<span class="border"></span> <span class="border border-0"></span> <span class="border border-top-0"></span> <span class="border border-right-0"></span> <span class="border border-bottom-0"></span> <span class="border border-left-0"></span>

Color de borde

Bootstrap4 proporciona algunas clases para configurar el color de los bordes:

Ejemplo

<span class="border border-primary"></span> <span class="border border-secondary"></span> <span class="border border-success"></span> <span class="border border-danger"></span> <span class="border border-warning"></span> <span class="border border-info"></span> <span class="border border-light"></span> <span class="border border-dark"></span> <span class="border border-white"></span>

Configuración de bordes redondeados

Usando laroundedclase puede agregar bordes redondeados:

Ejemplo

<span class="rounded"></span> <span class="rounded-top"></span> <span class="rounded-right"></span> <span class="rounded-bottom"></span> <span class="rounded-left"></span> <span class="rounded-circle"></span> <span class="rounded-0"></span>

Flotación

.float-rightLa clase se usa para hacer flotar el elemento a la derecha,.float-leftpara hacer flotar el elemento a la izquierda,.clearfixy la clase se usa para limpiar la flotación:

Ejemplo

<div class="clearfix"> <span class="float-left">Flotar a la izquierda</span> <span class="float-right">Flotar a la derecha</span> </div>

Flotación responsiva

Podemos configurar la flotación (.float-*-left|right- * es sm, md, lg o xl) la dirección depende del tamaño de la pantalla:

Ejemplo

<div class="float-sm-right">Flotar a la derecha en pantallas mayores que el tamaño pequeño</div><br> <div class="float-md-right">Flotar a la derecha en pantallas mayores que el tamaño mediano</div><br> <div class="float-lg-right">Flotar a la derecha en pantallas mayores que el tamaño grande</div><br> <div class="float-xl-right">Flotar a la derecha en pantallas mayores que el tamaño extra grande</div><br> <div class="float-none">Sin flotación</div>

Alineación centrada

Usando la.mx-autoclase para configurar la alineación centrada:

Ejemplo

<div class="mx-auto bg-warning" style="width:150px">Mostrar centrado</div>

Ancho

Use la clase w-* en el elemento (.w-25, .w-50, .w-75, .w-100, .mw-100) para configurar el ancho:

Ejemplo

<div class="w-25 bg-warning">Ancho 25%</div> <div class="w-50 bg-warning">Ancho 50%</div> <div class="w-75 bg-warning">Ancho 75%</div> <div class="w-100 bg-warning">Ancho 100%</div> <div class="mw-100 bg-warning">Ancho máximo 100%</div>

Alto

Use la clase h-* en el elemento (.h-25, .h-50, .h-75, .h-100, .mh-100) para configurar la altura:

Ejemplo

<div style="height:200px;background-color:#ddd"> <div class="h-25 bg-warning">Altura 25%</div> <div class="h-50 bg-warning">Altura 50%</div> <div class="h-75 bg-warning">Altura 75%</div> <div class="h-100 bg-warning">Altura 100%</div> <div class="mh-100 bg-warning" style="height:500px">Altura máxima 100%</div> </div>

Espaciado

La sintaxis para configurar el espaciado es la siguiente:

{property}{sides}-{size}  // 适用 xs(<=576px)
{property}{sides}-{breakpoint}-{size} // 适用 sm (>=576px), md (>=768px), lg (>=992px), xl (>=1200px)

breakpoints se refiere al ancho de la pantalla: xs (<=576px), sm (>=576px), md (>=768px), lg (>=992px), xl (>=1200px).

propertyRepresenta la propiedad, incluye:

  • m- Se usa para establecermargin
  • p- Se usa para establecerpadding

sidesSe refiere principalmente a la dirección:

  • t- Se usa para establecermargin-top 或 padding-top
  • b- Se usa para establecermargin-bottom 或 padding-bottom
  • l- Se usa para establecermargin-left 或 padding-left
  • r- Se usa para establecermargin-right 或 padding-right
  • x- Se usa para establecer*-left 和 *-right
  • y- Se usa para establecer*-top 和 *-bottom
  • blank - Se usa para establecer el margin/padding del elemento en las cuatro direccionesmargin 或 padding

sizeSe refiere al tamaño del margen:

  • 0- Establecemargin 或 padding 为 0
  • 1- Establecemargin 或 padding 为 $spacer * .25
  • 2- Establecemargin 或 padding 为 $spacer * .5
  • 3- Establecemargin 或 padding 为 $spacer
  • 4- Establecemargin 或 padding 为 $spacer * 1.5
  • 5- Establecemargin 或 padding 为 $spacer * 3
  • auto- Establecemargincomo auto

Margen exteriormarginSe pueden establecer números negativos, añadiendo la letra delante del número"n" :

  • n1- Establece margin a -.25rem (si font-size es 16px, entonces -4px)
  • n2- Establece margin a -.5rem (si font-size es 16px, entonces -8px)
  • n3- Establece margin a -1rem (si font-size es 16px, entonces -16px)
  • n4- Establece margin a -1.5rem (si font-size es 16px, entonces -24px)
  • n5- Establece margin a -3rem (si font-size es 16px, entonces -48px)

Echa un vistazo a la configuración del código fuente de algunos márgenes:

.mt-0 {
  margin-top: 0 !important;
}

.ml-1 {
  margin-left: ($spacer * .25) !important;
}

.px-2 {
  padding-left: ($spacer * .5) !important;
  padding-right: ($spacer * .5) !important;
}

.p-3 {
  padding: $spacer !important;
}

Ejemplo

<div class="mx-auto" style="width: 200px;">Elemento centrado</div> <form > <div class="form-row"> <div class="form-group"> <label for="text" class="mt-2">Configurar margin-top:</label> <input type="text" class="form-control" id="text" placeholder="email"> <label for="color" class="mt-2">Color:</label> <input type="color" id="color" class="form-control" style="width: 60px;padding: 4px;" autocomplete="off" value="#656565"> </div> </div> </form>
