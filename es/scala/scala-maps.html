Scala Map (mapeo)

Colecciones de Scala

Un Map (mapeo) es una estructura iterable de pares clave/valor (key/value).

Todos los valores pueden obtenerse a través de la clave.

Las claves en un Map son únicas.

Un Map también se denomina tabla hash (Hash table).

Hay dos tipos de Map: mutable e inmutable. La diferencia es que un objeto mutable puede modificarse, mientras que un objeto inmutable no.

Por defecto, Scala utiliza Map inmutables. Si necesita usar colecciones mutables, debe importarlas explícitamente.import scala.collection.mutable.Map 类

En Scala, puede usar tanto Map mutables como inmutables. Para los inmutables se usa directamente Map, y para los mutables se usa mutable.Map. El siguiente ejemplo demuestra la aplicación de un Map inmutable:

// 空哈希表，键为字符串，值为整型
var A:Map[Char,Int] = Map()

// Map 键值对演示
val colors = Map("red" -> "#FF0000", "azure" -> "#F0FFFF")

Al definir un Map, es necesario definir el tipo para los pares clave-valor. Si necesita agregar un par key-value, puede usar el signo +, como se muestra a continuación:

A += ('I' -> 1)
A += ('J' -> 5)
A += ('K' -> 10)
A += ('L' -> 100)

Operaciones básicas de Map

Scala Map tiene tres operaciones básicas:

Método Descripción
keys Devuelve todas las claves (keys) del Map
values Devuelve todos los valores (values) del Map
isEmpty Devuelve true cuando el Map está vacío

Ejemplo

El siguiente ejemplo demuestra la aplicación básica de los tres métodos anteriores:

Ejemplo

object Test {
   def main(args: Array[String]) {
      val colors = Map("red" -> "#FF0000",
                       "azure" -> "#F0FFFF",
                       "peru" -> "#CD853F")

      val nums: Map[Int, Int] = Map()

      println( Las claves en colors son: + colors.keys )
      println( Los valores en colors son: + colors.values )
      println( Comprobar si colors está vacío: + colors.isEmpty )
      println( Comprobar si nums está vacío: + nums.isEmpty )
   }
}

Al ejecutar el código anterior, el resultado es:

$ scalac Test.scala 
$ scala Test
colors 中的键为 : Set(red, azure, peru)
colors 中的值为 : MapLike(#FF0000, #F0FFFF, #CD853F)
检测 colors 是否为空 : false
检测 nums 是否为空 : true

Fusión de Map

Puede usar++el operador oMap.++()método para concatenar dos Map. Al fusionar Map, se eliminan las claves duplicadas. A continuación se muestra un ejemplo de fusión de dos Map:

Ejemplo

object Test {
   def main(args: Array[String]) {
      val colors1 = Map("red" -> "#FF0000",
                        "azure" -> "#F0FFFF",
                        "peru" -> "#CD853F")
      val colors2 = Map("blue" -> "#0033FF",
                        "yellow" -> "#FFFF00",
                        "red" -> "#FF0000")

      // ++ como operador
      var colors = colors1 ++ colors2
      println( "colors1 ++ colors2 : " + colors )

      // ++ como método
      colors = colors1.++(colors2)
      println( "colors1.++(colors2) : " + colors )

   }
}

Al ejecutar el código anterior, el resultado es:

$ scalac Test.scala 
$ scala Test
colors1 ++ colors2 : Map(blue -> #0033FF, azure -> #F0FFFF, peru -> #CD853F, yellow -> #FFFF00, red -> #FF0000)
colors1.++(colors2) : Map(blue -> #0033FF, azure -> #F0FFFF, peru -> #CD853F, yellow -> #FFFF00, red -> #FF0000)

Mostrar las claves (keys) y valores (values) de un Map

A continuación, mediante un bucle foreach, se muestran las claves (keys) y valores (values) del Map:

Ejemplo

object Test {
   def main(args: Array[String]) {
      val sites = Map("runoob" -> "http://www.runoob.com",
                       "baidu" -> "http://www.baidu.com",
                       "taobao" -> "http://www.taobao.com")

      sites.keys.foreach{ i =>  
                           print( "Key = " + i )
                           println(" Value = " + sites(i) )}
   }
}

Al ejecutar el código anterior, el resultado es:

$ scalac Test.scala 
$ scala Test
Key = runoob Value = http://www.runoob.com
Key = baidu Value = http://www.baidu.com
Key = taobao Value = http://www.taobao.com

Comprobar si existe una clave especificada en el Map

Puede usarMap.containsmétodo para comprobar si existe una clave especificada en el Map. Ejemplo:

Ejemplo

object Test {
   def main(args: Array[String]) {
      val sites = Map("runoob" -> "http://www.runoob.com",
                       "baidu" -> "http://www.baidu.com",
                       "taobao" -> "http://www.taobao.com")

      if( sites.contains( "runoob" )){
           println(La clave runoob existe, su valor correspondiente es:  + sites("runoob"))
      }else{
           println(La clave runoob no existe)
      }
      if( sites.contains( "baidu" )){
           println(La clave baidu existe, su valor correspondiente es:  + sites("baidu"))
      }else{
           println(La clave baidu no existe)
      }
      if( sites.contains( "google" )){
           println(La clave google existe, su valor correspondiente es:  + sites("google"))
      }else{
           println(La clave google no existe)
      }
   }
}

Al ejecutar el código anterior, el resultado es:

$ scalac Test.scala 
$ scala Test
runoob 键存在，对应的值为 :http://www.runoob.com
baidu 键存在，对应的值为 :http://www.baidu.com
google 键不存在

    var suit1 = Map("red"->"#FFF","blue"->"#FED","yellow"->"#00F","green"->"#0F0")
var suit2 = Map("red"->"#FF1","green"->"#1F1")
var suit3 = suit1++suit2
println("the value of suit1 is:" +suit1)
println("the value of suit2 is:" +suit2)
println("the value of after ++ is:" +suit3)
println("the value of after .++() is:" +suit1.++(suit2))

    Resultado:

    the value of suit1 is:Map(red -> #FFF, blue -> #FED, yellow -> #00F, green -> #0F0)
the value of suit2 is:Map(red -> #FF1, green -> #1F1)
the value of after ++ is:Map(red -> #FF1, blue -> #FED, yellow -> #00F, green -> #1F1)
