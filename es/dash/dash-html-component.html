Componentes HTML comunes de Dash

Uno de los componentes principales de Dash son los componentes HTML, que te permiten incrustar elementos HTML estándar en tu aplicación.

Este artículo presentará en detalle los componentes HTML de uso común en Dash.

1. Introducción a los componentes HTML

En las últimas versiones de Dash, la forma de importar los componentes HTML ha cambiado; podemos, directamente, desdedashimportarhtmlel componente, sin necesidad de, como antes, desdedash_html_componentsimportar.

from dash import html

Componentes HTML comunes

html.Div Crear un contenedor (<div>), utilizado para envolver otros componentes html.Div(children=[html.H1("标题"), html.P("这是一个段落。")])

2. Componentes HTML de uso frecuente

2.1 html.Div

html.Dives uno de los componentes HTML más utilizados en Dash; se utiliza para crear undivelemento.divEl elemento se utiliza generalmente para agrupar contenido y puede recibir estilos mediante CSS.

Ejemplo

html.Div(children=[
    html.H1('Esto es un título'),
    html.P('Este es un párrafo.')
])

En este ejemplo,html.Divincluye un título (html.H1) y un párrafo (html.P)。

2.2 html.H1 到 html.H6

html.H1 到 html.H6se utiliza para crear títulos de diferentes niveles.H1es el título de nivel más alto,H6es el título de nivel más bajo.

Ejemplo

html.H1('Este es el título H1'),
html.H2('Este es el título H2'),
html.H3('Este es el título H3'),
html.H4('Este es el título H4'),
html.H5('Este es el título H5'),
html.H6('Este es el título H6')

2.3 html.P

html.Pse utiliza para crear un párrafo (<p>elemento).

Ejemplo

html.P('Este es un párrafo.')

2.4 html.A

html.Ase utiliza para crear un enlace (<a>elemento). Puedes usar elhrefatributo para especificar la URL de destino del enlace.

Ejemplo

html.A('Haz clic aquí para visitar el sitio oficial de Dash', href='https://dash.plotly.com/')

2.5 html.Img

html.Imgse utiliza para insertar una imagen (<img>elemento). Debes usar elsrcatributo para especificar la URL de la imagen.

Ejemplo

html.Img(src='https://dash.plotly.com/assets/images/logo.png', alt='Dash Logo')

2.6 html.Ul 和 html.Li

html.Ulse utiliza para crear una lista desordenada (<ul>elemento), yhtml.Lise utiliza para crear elementos de lista (<li>elemento).

Ejemplo

html.Ul(children=[
    html.Li('Elemento de lista 1'),
    html.Li('Elemento de lista 2'),
    html.Li('Elemento de lista 3')
])

2.7 html.Ol

html.Olse utiliza para crear una lista ordenada (<ol>elemento).

Ejemplo

html.Ol(children=[
    html.Li('Primer elemento'),
    html.Li('Segundo elemento'),
    html.Li('Tercer elemento')
])

2.8 html.Br

html.Brse utiliza para insertar un salto de línea (<br>elemento).

Ejemplo

html.P('Esta es la primera línea.'),
html.Br(),
html.P('Esta es la segunda línea.')

2.9 html.Hr

html.Hrse utiliza para insertar una línea horizontal (<hr>elemento).

Ejemplo

html.P('Este es el contenido superior.'),
html.Hr(),
html.P('Este es el contenido inferior.')

2.10 html.Span

html.Spanse utiliza para crear un contenedor en línea (<span>elemento), generalmente utilizado para aplicar estilos a una parte del texto.

Ejemplo

html.P('Este es un párrafo que contiene ',
       html.Span('resaltado', style={'color': 'red'}),
       '.')

3. Uso de estilos

Los componentes HTML de Dash admiten el uso de lastylepropiedad para establecer estilos CSS.styleLa propiedad acepta un diccionario, donde las claves son propiedades CSS y los valores son los valores CSS correspondientes.

Ejemplo

html.Div(
    children="Este es un Div con estilos",
    style={
        'color': 'white',
        'backgroundColor': 'blue',
        'padding': '10px',
        'borderRadius': '5px'
    }
)

Este código utiliza el componente html.Div de Dash para crear un elemento div con estilos: un div con fondo azul, texto blanco, esquinas redondeadas y relleno interno.

  1. html.Div: crear un<div>contenedor.

  2. children: establecer eldivcontenido como"这是一个带样式的 Div"。

  3. style: mediante estilos CSS, establecer ladivapariencia:

    • color: white: color del texto blanco.

    • backgroundColor: blue: color de fondo azul.

    • padding: 10px: relleno de 10 píxeles.

    • borderRadius: 5px: radio del borde de 5 píxeles.

Ejemplo

A continuación se muestra un ejemplo completo de una aplicación Dash que demuestra cómo usar html.Div y otros componentes HTML, y cómo establecer estilos mediante la propiedad style.

Ejemplo

from dash import Dash, html

# Crear la aplicación Dash
app = Dash(__name__)

# Definir el diseño de la aplicación
app.layout = html.Div(
    style={
        'fontFamily': 'Arial, sans-serif',  # Establecer la fuente global
        'padding': '20px',  # Establecer el relleno global
        'maxWidth': '800px',  # Establecer el ancho máximo
        'margin': '0 auto'  # Centrar
    },
    children=[
        # Título
        html.H1(
            "Aplicación de ejemplo Dash",
            style={
                'color': 'white',
                'backgroundColor': 'darkblue',
                'padding': '10px',
                'borderRadius': '5px',
                'textAlign': 'center'  # Texto centrado
            }
        ),

        # Párrafo
        html.P(
            "Este es un ejemplo sencillo de una aplicación Dash que muestra cómo usar componentes HTML y estilos.",
            style={
                'fontSize': '16px',
                'color': '#333',
                'marginTop': '20px'
            }
        ),

        # Div con estilos
        html.Div(
            children="Este es un Div con estilos",
            style={
                'color': 'white',
                'backgroundColor': 'blue',
                'padding': '10px',
                'borderRadius': '5px',
                'marginTop': '20px',
                'textAlign': 'center'
            }
        ),

        # Botón
        html.Button(
            "Haz clic en mí",
            style={
                'backgroundColor': 'green',
                'color': 'white',
                'border': 'none',
                'padding': '10px 20px',
                'borderRadius': '5px',
                'cursor': 'pointer',
                'marginTop': '20px'
            }
        ),

        # Imagen
        html.Img(
            src="https://dash.plotly.com/assets/images/language_icons/python_50px.svg",
            style={
                'height': '50px',
                'marginTop': '20px',
                'display': 'block',  # Imagen centrada
                'marginLeft': 'auto',
                'marginRight': 'auto'
            }
        )
    ]
)

# Ejecutar la aplicación
if __name__ == '__main__':
    app.run_server(debug=True)
