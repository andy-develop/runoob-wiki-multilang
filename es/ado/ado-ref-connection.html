Connection 对象 → Objeto Connection

ADO Connection 对象用于创建一个到达某个数据源的开放连接。通过此连接，您可以对一个数据库进行访问和操作。 → El objeto ADO Connection se utiliza para crear una conexión abierta a un origen de datos. A través de esta conexión, puede acceder a una base de datos y operar en ella.

如果需要多次访问某个数据库，您应当使用 Connection 对象来建立一个连接。您也可以经由一个 Command 或 Recordset 对象传递一个连接字符串来创建某个连接。不过，此类连接仅仅适合一次具体的简单的查询。 → Si necesita acceder a una base de datos varias veces, debe usar el objeto Connection para establecer una conexión. También puede crear una conexión pasando una cadena de conexión a través de un objeto Command o Recordset. Sin embargo, este tipo de conexión solo es adecuado para una consulta específica y simple.

set objConnection=Server.CreateObject("ADODB.connection")

属性 → Propiedades

属性 → Propiedad 描述 → Descripción
Attributes 设置或返回 Connection 对象的属性。 → Establece o devuelve los atributos de un objeto Connection.
CommandTimeout 指示在终止尝试和产生错误之前执行命令期间需等待的时间。 → Indica el tiempo que se esperará durante la ejecución de un comando antes de terminar el intento y generar un error.
ConnectionString 设置或返回用于建立连接数据源的细节信息。 → Establece o devuelve la información detallada utilizada para establecer la conexión con un origen de datos.
ConnectionTimeout 指示在终止尝试和产生错误前建立连接期间所等待的时间。 → Indica el tiempo de espera al establecer una conexión antes de terminar el intento y generar un error.
CursorLocation 设置或返回游标服务的位置。 → Establece o devuelve la ubicación del servicio de cursor.
DefaultDatabase 指示 Connection 对象的默认数据库。 → Indica la base de datos predeterminada del objeto Connection.
IsolationLevel 指示 Connection 对象的隔离级别。 → Indica el nivel de aislamiento del objeto Connection.
Mode 设置或返回 provider 的访问权限。 → Establece o devuelve los permisos de acceso del proveedor.
Provider 设置或返回 Connection 对象提供者的名称。 → Establece o devuelve el nombre del proveedor del objeto Connection.
State 返回一个描述连接是打开还是关闭的值。 → Devuelve un valor que describe si la conexión está abierta o cerrada.
Version 返回 ADO 的版本号。 → Devuelve el número de versión de ADO.

方法 → Métodos

方法 → Método 描述 → Descripción
BeginTrans 开始一个新事务。 → Inicia una nueva transacción.
Cancel 取消一次执行。 → Cancela una ejecución.
Close 关闭一个连接。 → Cierra una conexión.
CommitTrans 保存任何更改并结束当前事务。 → Guarda los cambios y finaliza la transacción actual.
Execute 执行查询、SQL 语句、存储过程或 provider 具体文本。 → Ejecuta una consulta, una instrucción SQL, un procedimiento almacenado o texto específico del proveedor.
Open 打开一个连接。 → Abre una conexión.
OpenSchema 从 provider 返回有关数据源的 schema 信息。 → Devuelve información de esquema sobre el origen de datos desde el proveedor.
RollbackTrans 取消当前事务中所作的任何更改并结束事务。 → Cancela cualquier cambio realizado en la transacción actual y finaliza la transacción.

事件 → Eventos

注释： → Nota:您无法使用 VBScript or JScript 来处理事件（仅能使用 Visual Basic、Visual C++ 以及 Visual J++ 语言处理事件）。 → No puede usar VBScript ni JScript para manejar eventos (solo puede manejar eventos con Visual Basic, Visual C++ y Visual J++).

事件 → Eventos 事件 → Evento
BeginTransComplete 在 BeginTrans 操作之后被触发。 → Se desencadena después de una operación BeginTrans.
CommitTransComplete 在 CommitTrans 操作之后被触发。 → Se desencadena después de una operación CommitTrans.
ConnectComplete 在一个连接开始后被触发。 → Se desencadena después de que se inicia una conexión.
Disconnect 在一个连接结束之后被触发。 → Se desencadena después de que finaliza una conexión.
ExecuteComplete 在一条命令执行完毕后被触发。 → Se desencadena después de que se ejecuta un comando.
InfoMessage 假如在一个 ConnectionEvent 操作过程中警告发生，则触发该事件。 → Se desencadena si se produce una advertencia durante una operación ConnectionEvent.
RollbackTransComplete 在 RollbackTrans 操作之后被触发。 → Se desencadena después de una operación RollbackTrans.
WillConnect 在一个连接开始之前被触发。 → Se desencadena antes de que se inicie una conexión.
WillExecute 在一条命令被执行之前被触发。 → Se desencadena antes de que se ejecute un comando.
