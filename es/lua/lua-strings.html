Cadenas de Lua

Una cadena o string está compuesta por una serie de caracteres formados por números, letras y guiones bajos.

En Lua, las cadenas son un tipo de datos básico que se utiliza para almacenar datos de texto.

Las cadenas en Lua pueden contener cualquier carácter, incluyendo letras, números, símbolos, espacios y otros caracteres especiales.

En el lenguaje Lua, las cadenas se pueden representar de las siguientes tres maneras:

  • Una secuencia de caracteres entre comillas simples.

    local str1 = 'This is a string.'
local str2 = "This is also a string."

  • Una secuencia de caracteres entre comillas dobles.

    local str = "Hello, "
str = str .. "World!"  -- 创建一个新的字符串并将其赋值给str
print(str)  -- 输出 "Hello, World!"

  • [[ 与 ]]Una secuencia de caracteres entre ...

    local multilineString = [[
This is a multiline string.
It can contain multiple lines of text.
No need for escape characters.
]]

print(multilineString)

A continuación se muestran ejemplos de cadenas con estos tres métodos:

Ejemplo

string1 = "Lua"
print("\"La cadena 1 es\"",string1)
string2 = 'runoob.com'
print("La cadena 2 es",string2)

string3 = [["Tutorial de Lua"]]
print("La cadena 3 es",string3)

El resultado de ejecutar el código anterior es:

"字符串 1 是"    Lua
字符串 2 是    runoob.com
字符串 3 是    "Lua 教程"

Cálculo de longitud de cadenas

En Lua, para calcular la longitud de una cadena (es decir, el número de caracteres de la cadena), puedes usar lastring.lenfunción o lautf8.lenfunción; en general, para cadenas que contienen chino se usautf8.len，string.lenLa función se utiliza para calcular la longitud de cadenas que solo contienen caracteres ASCII.

Ejemplo

local myString = "Hello, RUNOOB!"

-- Calcula la longitud de la cadena (número de caracteres)
local length = string.len(myString)

print(length) -- Muestra 14

La cadena myString del ejemplo anterior solo contiene caracteres ASCII, por lo que lastring.lenfunción puede devolver correctamente la longitud de la cadena.

Para cadenas que contienen chino se usa lautf8.lenfunción:

Ejemplo

local myString = "Hello, 世界!"

-- Calcula la longitud de la cadena (número de caracteres)
local length1 = utf8.len(myString)
print(length1) -- Muestra 10

-- la función string.len produce un resultado inexacto
local length2 = string.len(myString)
print(length2) -- Muestra 14

Extracción de subcadenas

La extracción de subcadenas utiliza el método sub().

string.sub() se utiliza para extraer una subcadena; su prototipo es:

string.sub(s, i [, j])

Descripción de parámetros:

  • s: la cadena que se va a extraer.
  • i: la posición inicial de extracción.
  • j: la posición final de extracción; el valor predeterminado es -1, el último carácter.

Ejemplo


-- Cadena
local sourcestr = "prefix--runoobgoogletaobao--suffix"
print("\n"Cadena original", string.format("%q", sourcestr))

-- Se extrae una parte, del 4.º al 15.º
local first_sub = string.sub(sourcestr, 4, 15)
print("\n"Primera extracción", string.format("%q", first_sub))

-- Tomar el prefijo de la cadena, del 1.º al 8.º
local second_sub = string.sub(sourcestr, 1, 8)
print("\n"Segunda extracción", string.format("%q", second_sub))

-- Extraer los últimos 10 caracteres
local third_sub = string.sub(sourcestr, -10)
print("\n"Tercera extracción", string.format("%q", third_sub))

-- Índice fuera de rango, se muestra la cadena original
local fourth_sub = string.sub(sourcestr, -100)
print("\n"Cuarta extracción", string.format("%q", fourth_sub))

第二次截取    "prefix--"

第三次截取    "ao--suffix"

第四次截取    "prefix--runoobgoogletaobao--suffix"

Formato de cadenas

Lua proporcionastring.format()funciones para generar cadenas con un formato específico. El primer parámetro de la función es el formato, seguido de varios datos correspondientes a cada marcador del formato.

Gracias a la cadena de formato, la legibilidad de las cadenas largas generadas mejora considerablemente. El formato de esta función se parece mucho al printf() del lenguaje C.

El siguiente ejemplo demuestra cómo dar formato a cadenas:

La cadena de formato puede contener los siguientes códigos de formato:

  • %c - Acepta un número y lo convierte al carácter correspondiente de la tabla ASCII.
  • %d, %i - Acepta un número y lo convierte a un formato de entero con signo.
  • %o - Acepta un número y lo convierte a un formato de número octal.
  • %u - Acepta un número y lo convierte a un formato de entero sin signo.
  • %x - Acepta un número y lo convierte a un formato de número hexadecimal, usando letras minúsculas.
  • %X - Acepta un número y lo convierte a un formato de número hexadecimal, usando letras mayúsculas.
  • %e - Acepta un número y lo convierte a un formato de notación científica, usando la letra e minúscula.
  • %E - Acepta un número y lo convierte a un formato de notación científica, usando la letra E mayúscula.
  • %f - Acepta un número y lo convierte a un formato de número de punto flotante.
  • %g(%G) - Acepta un número y lo convierte al formato más corto entre %e (%E, correspondiente a %G) y %f.
  • %q - Acepta una cadena y la convierte a un formato que el compilador de Lua puede leer de forma segura.
  • %s - Acepta una cadena y la formatea según los parámetros dados.

Para refinar aún más el formato, se pueden añadir parámetros después del signo %. Los parámetros se leen en el siguiente orden:

  • (1) Signo: un signo + indica que el especificador numérico siguiente hará que los positivos muestren el signo más. Por defecto solo los negativos muestran signo.
  • (2) Relleno: un 0, que se usa como relleno cuando se especifica el ancho de la cadena. Si no se indica, el relleno por defecto es un espacio.
  • (3) Indicador de alineación: cuando se especifica el ancho de la cadena, por defecto se alinea a la derecha; añadiendo un signo - se puede cambiar a alineación a la izquierda.
  • (4) Valor del ancho
  • (5) Decimales / truncamiento de cadena: la parte decimal n añadida después del valor de ancho. Si va seguida de f (especificador de coma flotante, como %6.3f), establece que el número de decimales del flotante se conserve solo en n dígitos. Si va seguida de s (especificador de cadena, como %5.3s), establece que la cadena solo muestre los primeros n caracteres.

Ejemplo

string1 = "Lua"
string2 = "Tutorial"
number1 = 10
number2 = 20
-- Formateo básico de cadenas
print(string.format("Formato básico %s %s",string1,string2))
-- Formateo de fecha
date = 2; month = 1; year = 2014
print(string.format("Formato de fecha %02d/%02d/%04d", date, month, year))
-- Formateo decimal
print(string.format("%.4f",1/3))

El resultado de ejecutar el código anterior es:

基本格式化 Lua Tutorial
日期格式化 02/01/2014
0.3333

Patrones de coincidencia

Los patrones de coincidencia en Lua se describen directamente con cadenas normales. Se usan en las funciones de coincidencia de patrones.string.find, string.gmatch, string.gsub, string.match。

También puedes usar clases de caracteres en la cadena de patrón.

Una clase de caracteres es un elemento de patrón que puede coincidir con cualquier carácter de un conjunto específico. Por ejemplo, la clase de caracteres%dcoincide con cualquier dígito. Por lo tanto, puedes usar la cadena de patrón%d%d/%d%d/%d%d%d%dpara buscardd/mm/yyyyfechas con el formato:

Ejemplo

s = "Deadline is 30/05/1999, firm"
date = "%d%d/%d%d/%d%d%d%d"
print(string.sub(s, string.find(s, date)))    --> 30/05/1999

La siguiente tabla enumera todas las clases de caracteres soportadas por Lua:

Carácter individual (excepto^$()%.[]*+-?): coincide con el propio carácter.

  • %a: coincide con cualquier letra

  • %d: coincide con cualquier dígito
  • %l: coincide con cualquier letra minúscula

    Requisito: obtener cadenas con límites especiales.

    Requisito: obtener cadenas numéricas cuyo límite izquierdo sea una letra y el límite derecho sea un espacio.

    1. Obtener todas las cadenas numéricas con límites

    str1 =  "123 h123 hds45678 fdaga123ad  h123s"
string.gmatch(str1,"%D%d+%D")

    Determinar límites: izquierdo: %a derecho: %s

    string.gmatch(str1,"%f[%A]%d+%f[%s]")
    匹配结果：45678

    string.match(str, pattern, init)

    string.match("I have 2 questions for you.", "%d+ %a+")

    Si un patrón de coincidencia individual en el pattern no está entre paréntesis, se devolverá la cadena completa que coincida.

    Por ejemplo:

    c,d=string.match("I have 23 questions for you.", "%d+ %a+")
print(c)        -->23  questions
print(type(c))  -->string
print(d)        -->nil 空的
print(type(d))  -->nil 空的

    Si cada patrón de coincidencia en el pattern está entre paréntesis, se capturarán como múltiples valores de retorno.

    Por ejemplo:

    c,d=string.match("I have 23 questions for you.", "(%d+) (%a+)")
print(c)        -->23
print(type(c))  -->string 即使是%d 最后也仍是string
print(d)        -->questions
print(type(d))  -->string

    De esta manera se puede usar format para formatear la salida.

    string.format("%d, %q",c,d) -->23,"questions"
