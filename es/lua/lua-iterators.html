Un iterador es un objeto que se puede utilizar para recorrer algunos o todos los elementos de los contenedores de la biblioteca de plantillas estándar. Cada objeto iterador representa una dirección determinada dentro del contenedor.

En Lua, un iterador es una estructura que admite tipos de puntero y puede recorrer cada elemento de una colección.

Iteradores del bucle for genérico

El bucle for genérico almacena internamente la función iteradora; en realidad, guarda tres valores: la función iteradora, la constante de estado y la variable de control.

El iterador del bucle for genérico proporciona los pares clave/valor de la colección. La sintaxis es la siguiente:

for k, v in pairs(t) do
    print(k, v)
end

En el código anterior, k y v son la lista de variables; pairs(t) es la lista de expresiones.

Observa el siguiente ejemplo:

Ejemplo

array = {"Google", "Runoob"}

for key,value in ipairs(array)
do
   print(key, value)
end

La salida del código anterior es:

1  Google
2  Runoob

En el ejemplo anterior hemos utilizado la función iteradora ipairs que Lua proporciona por defecto.

A continuación, veamos el proceso de ejecución del bucle for genérico:

  • Primero, la inicialización: se evalúa la expresión después de 'in'. La expresión debe devolver los tres valores que el bucle for genérico necesita: la función iteradora, la constante de estado y la variable de control. Igual que en la asignación múltiple, si la expresión devuelve menos de tres resultados, se completan automáticamente con nil; los resultados sobrantes se ignoran.
  • Segundo, se llama a la función iteradora con la constante de estado y la variable de control como argumentos (nota: para la estructura for, la constante de estado no tiene utilidad; solo se obtiene su valor durante la inicialización y se pasa a la función iteradora).
  • Tercero, los valores devueltos por la función iteradora se asignan a la lista de variables.
  • Cuarto, si el primer valor devuelto es nil, el bucle termina; de lo contrario, se ejecuta el cuerpo del bucle.
  • Quinto, se vuelve al segundo paso para llamar nuevamente a la función iteradora.

En Lua, a menudo usamos funciones para describir iteradores. Cada vez que se llama a la función, esta devuelve el siguiente elemento de la colección. Los iteradores de Lua incluyen los siguientes dos tipos:

  • Iteradores sin estado
  • Iteradores con estado múltiple

Iteradores sin estado

Un iterador sin estado es aquel que no conserva ningún estado. Por lo tanto, en un bucle podemos utilizar iteradores sin estado para evitar el costo adicional de crear cierres (clausuras).

En cada iteración, la función iteradora se llama con los valores de dos variables (la constante de estado y la variable de control) como argumentos. Un iterador sin estado solo necesita estos dos valores para obtener el siguiente elemento.

Un ejemplo típico y sencillo de este tipo de iterador sin estado es ipairs, que recorre cada elemento de un array; los índices de los elementos deben ser numéricos.

En el siguiente ejemplo, usamos una función simple para implementar un iterador que calcula el cuadrado del número n:

Ejemplo

function square(iteratorMaxCount,currentNumber)
   if currentNumber<iteratorMaxCount
   then
      currentNumber = currentNumber+1
   return currentNumber, currentNumber*currentNumber
   end
end

for i,n in square,3,0
do
   print(i,n)
end

La salida del ejemplo anterior es:

1    1
2    4
3    9

El estado de la iteración incluye la tabla que se recorre (la constante de estado que no cambia durante el bucle) y el índice actual (la variable de control). Tanto ipairs como la función iteradora son muy simples; en Lua podemos implementarlos así:

Ejemplo

function iter (a, i)
    i = i + 1
    local v = a[i]
    if v then
       return i, v
    end
end
 
function ipairs (a)
    return iter, a, 0
end

Cuando Lua llama a ipairs(a) para comenzar el bucle, obtiene tres valores: la función iteradora iter, la constante de estado a y el valor inicial de la variable de control 0. Luego Lua llama a iter(a,0), que devuelve 1, a

Iteradores con estado múltiple

En muchos casos, el iterador necesita almacenar múltiples informaciones de estado en lugar de una simple constante de estado y una variable de control. El método más sencillo es usar cierres (clausuras). Otra forma es encapsular toda la información de estado dentro de una tabla y usar esa tabla como la constante de estado del iterador. Dado que en este caso toda la información se puede almacenar en la tabla, la función iteradora generalmente no necesita un segundo argumento.

En el siguiente ejemplo, creamos nuestro propio iterador:

Ejemplo

array = {"Google", "Runoob"}

function elementIterator (collection)
   local index = 0
   local count = #collection
   -- Función de cierre (clausura)
   return function ()
      index = index + 1
      if index <= count
      then
         -- Devuelve el elemento actual del iterador
         return collection[index]
      end
   end
end

for element in elementIterator(array)
do
   print(element)
end

La salida del ejemplo anterior es:

Google
Runoob

En el ejemplo anterior podemos ver que elementIterator utiliza una función de cierre (clausura) para calcular el tamaño de la colección y mostrar cada elemento.

    Diferencia entre pairs e ipairs

    • pairs: itera sobre la tabla y puede recorrer todas las claves de la tabla, pudiendo devolver nil.
    • ipairs: itera sobre el array; no puede devolver nil. Si encuentra nil, sale del bucle.

    Ejemplo de código:

    local tab= { 
[1] = "a", 
[3] = "b", 
[4] = "c" 
} 
for i,v in pairs(tab) do        -- 输出 "a" ,"b", "c"  ,
    print( tab[i] ) 
end 

for i,v in ipairs(tab) do    -- 输出 "a" ,k=2时断开 
    print( tab[i] ) 
end

    Similitudes y diferencias entre pairs e ipairs

    Similitudes: ambos pueden recorrer colecciones (tablas, arrays).

    Diferencias: ipairs solo recorre los valores en orden ascendente de índices y se detiene cuando el índice se interrumpe. Es decir, no puede devolver nil; solo puede devolver el número 0; si encuentra nil, sale. Solo puede recorrer hasta la primera clave de la colección que no sea un entero.

    pairs puede recorrer todos los elementos de la colección. Es decir, pairs puede recorrer todas las claves de la colección y, además del iterador en sí y de la tabla recorrida, también puede devolver nil.

    Ejemplo 1:

    local tabFiles = {
        [1] = "test2",
        [6] = "test3",
        [4] = "test1"
    }

for k, v in ipairs(tabFiles) do    --输出"test2",在key等于2处断开
    print(k, v)
end

    Ejemplo 2:

    local tabFiles = {
    [2] = "test2",
    [6] = "test3",
    [4] = "test1"
}

for k, v in ipairs(tabFiles) do  --[[什么都没输出，为什么？因为控制变量初始值是按升序来遍历的，当key为1时，value为nil，此时便停止了遍历， 所有什么结果都没输出]]--
    print(k, v)
end

    Ejemplo 3:

    local tabFiles = {
    [2] = "test2",
    [6] = "test3",
    [4] = "test1"
}

for k, v in pairs(tabFiles) do  --输出2 test2, 6 test3, 4 test1
    print(k, v)
end

    Ejemplo 4:

    local tabFiles = {"alpha", "beta", [3] = "no", ["two"] = "yes"}  for i,v in ipairs(tabFiles ) do    --输出前三个   备注：因为第四个key不是整数
    print( tabFiles [i] )   
end   
  
for i,v in pairs(tabFiles ) do    --全部输出   
    print( tabFiles [i] )

    local dLen = string.len(delimiter)
    local newDeli = ''
    for i=1,dLen,1 do

        locaStart,locaEnd = string.find(str,newDeli)
    end
    if str ~= nil then

    end
    return arr

    El for genérico mantiene internamente 3 elementos:

    • 1. La propia función iteradora, como pairs(tab)
    • 2. La constante de estado de la función iteradora, como tab
    • 3. La variable de control de la función iteradora, como idx.

    Requisito:Cada vez que se llama a la función iteradora, la variable de control cambia después de la ejecución de la función; una vez que la variable de control cumple la condición, se detiene la llamada a la función iteradora.

    Ejemplo:

    function iter (a, i)
    i = i + 1
    local v = a[i]
    if v then
       return i, v
    end
end

function ipairss (a)
    i=0;
   while(true) do
        k,v=iter(a,i)
        if k=nil then
           break;
       end
end

t={"asdf1","asdf2","asdf3","asdf4"}
for k,v in ipairss(t) do  //--内部维持iter,t,i三个要素,其中i隐含--这是我的理解
    print(k,v)
end
