JavaScript Conversión de tipos

Number() convierte a número, String() convierte a cadena, Boolean() convierte a booleano.

Tipos de datos de JavaScript

En JavaScript hay 6 tipos de datos diferentes:

  • string
  • number
  • boolean
  • object
  • function
  • symbol

3 tipos de objetos:

  • Object
  • Date
  • Array

2 tipos de datos que no contienen ningún valor:

  • null
  • undefined

Operador typeof

Puedes usar eltypeofoperador para ver el tipo de datos de una variable de JavaScript.

Ejemplos

typeof "John"                 // devuelve string
 typeof 3.14                   // devuelve number
 typeof NaN                    // devuelve number
typeof false                  // devuelve boolean
typeof [1,2,3,4]              // devuelve object
 typeof {name:'John', age:34}  // devuelve object
typeof new Date()             // devuelve object
typeof function () {}         // devuelve function
 typeof myCar                  // devuelve undefined (si myCar no está declarado)
 typeof null                   // devuelve object

Pruébalo »

Ten en cuenta:

  • El tipo de datos de NaN es number
  • El tipo de datos de un array (Array) es object
  • El tipo de datos de una fecha (Date) es object
  • El tipo de datos de null es object
  • El tipo de datos de una variable no definida es undefined

Si el objeto es un Array de JavaScript o una Date de JavaScript, no podemostypeofdeterminar su tipo mediante typeof, porque ambos devuelven object.

Propiedad constructor

constructorLa propiedad devuelve el constructor de todas las variables de JavaScript.

Ejemplos

"John".constructor                 // devuelve la función String() { [native code] }
 (3.14).constructor                 // devuelve la función Number() { [native code] }
 false.constructor                  // devuelve la función Boolean() { [native code] }
 [1,2,3,4].constructor              // devuelve la función Array() { [native code] }
 {name:'John', age:34}.constructor  // devuelve la función Object() { [native code] }
 new Date().constructor             // devuelve la función Date() { [native code] }
 function () {}.constructor         // devuelve la función Function(){ [native code] }

Pruébalo »

}

Conversión de tipos en JavaScript

Las variables de JavaScript pueden convertirse en nuevas variables u otros tipos de datos:

  • mediante el uso de funciones de JavaScript
  • mediante la conversión automática del propio JavaScript

Convertir números a cadenas

Método globalString()puede convertir números en cadenas.

Este método se puede utilizar con cualquier tipo de número, letra, variable o expresión:

Ejemplos

String(x)         // convierte la variable x en una cadena y la devuelve
 String(123)       // convierte el número 123 en una cadena y lo devuelve
 String(100 + 23)  // convierte la expresión numérica en una cadena y la devuelve

Pruébalo »

Métodos de NumbertoString()también tienen el mismo efecto.

Ejemplos

x.toString()
(123).toString()
(100 + 23).toString()

Pruébalo »

Convertir cadenas a números

Método globalNumber()puede convertir cadenas en números.

Una cadena que contiene números (como "3.14") se convierte en un número (como 3.14).

Una cadena vacía se convierte en 0.

Otras cadenas se convierten en NaN (no es un número).

Number("3.14")    // devuelve 3.14
 Number(" ")       // devuelve 0
 Number("")        // devuelve 0
 Number("99 88")   // devuelve NaN

Conversión automática de tipos

Cuando JavaScript intenta operar con un tipo de dato "incorrecto", lo convierte automáticamente al tipo de dato "correcto".

El siguiente resultado no es lo que esperabas:

5 + null    // Devuelve 5 — null se convierte a 0
"5" + null  // Devuelve "5null" — null se convierte a "null"
 "5" + 1     // Devuelve "51" — 1 se convierte a "1"
 "5" - 1     // Devuelve 4 — "5" se convierte a 5

Conversión automática a cadena

Cuando intentas mostrar un objeto o una variable, JavaScript llama automáticamente al método toString() de la variable:

document.getElementById("demo").innerHTML = myVar;

myVar = {name:"Fjohn"} // toString lo convierte a "[object Object]"
 myVar = [1,2,3,4] // toString lo convierte a "1,2,3,4"
 myVar = new Date() // toString lo convierte a "Fri Jul 18 2014 09:08:55 GMT+0200"

Los números y los booleanos también se convierten entre sí con frecuencia:

myVar = 123 // toString lo convierte a "123"
 myVar = true // toString lo convierte a "true"
 myVar = false // toString lo convierte a "false"

    Diferencia entre undefined y null:

    En apariencia, undefined y null significan que no hay nada, pero en realidad undefined es no definido (es decir, la variable no ha sido inicializada), mientras que null es una variable que ha sido inicializada pero a la que no se le ha dado ningún valor, solo se le ha asignado un objeto vacío. Además, undefined y null son iguales en valor, pero no en tipo.

    return myArray.constructor.toString().indexOf("Array") > -1; ¿Cómo se interpreta esta sentencia?

    1. myArray es el parámetro de la función isArray; al llamar a la función, se pasa el array fruits.

    2. constructor es una propiedad, la propiedad del constructor. Diferentes tipos de datos obtienen diferentes valores correspondientes. Como myArray es un array, el valor de myArray.constructor aquí esfunction Array() { [native code] }. (Si myArray es una cadena, el valor de myArray.constructor esfunction String() { [native code] }. También number, boolean, object, etc.)

    3. toString() es un método, el método para convertir a cadena. Aquí conviertefunction Array() { [native code] }a cadena para facilitar la búsqueda posterior.

    4. indexOf("Array") es un método que busca en una cadena. Aquí verifica si la cadenafunction Array() { [native code] }contiene "Array". Si lo contiene, devuelve la posición de la primera aparición, que es un número; aquí es 9. Si aparece en el primer carácter, devuelve 0. Los espacios cuentan. Si no lo encuentra, devuelve -1. Mientras sea > -1, significa que hay "Array", por lo que se puede determinar que el fruits pasado en la llamada a la función original es un array. Date.prototype.format = function (fmt) {
    var o = {
        "M+": this.getMonth() + 1,                 //月份 
        "d+": this.getDate(),                    //日 
        "h+": this.getHours(),                   //小时 
        "m+": this.getMinutes(),                 //分

    //处理年份
    var reYear = /(y+)/; 
    var resultYear = reYear.exec(fmt);
    if (resultYear) 
    {
        var yearformatPart = resultYear[0];//匹配到的格式化字符
        var yearVal = (this.getFullYear() + "").substr(4 - yearformatPart.length);
        fmt = fmt.replace(yearformatPart, yearVal);
    }
    for (var k in o) {
        var re = new RegExp("(" + k + ")");
        var re = re.exec(fmt);
        if (re) {
            var Val = "" + o[k];//本次需要替换的数据

            var replaceVal = (formatPart.length == 1) ? (Val) : (("00" + Val).substr(Val.length));

        }
    }
