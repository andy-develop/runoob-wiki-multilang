Claude Code Sistema de Memoria (Memory)

Cada vez que termina una sesión de Claude Code, el contexto se vacía.

¿A veces tenemos que volver a decirle a Claude "usa pnpm en lugar de npm", "nuestra indentación es de 2 espacios"?Sistema de memoria (Memory)Fue creado precisamente para esto.

¿Qué es el sistema de memoria de Claude Code?

Claude Code no tiene memoria automática entre sesiones: cada nueva sesión comienza con una ventana de contexto completamente nueva.

El sistema de memoria, mediante dos mecanismos complementarios, permite que el conocimiento puedapersistir entre sesionesy cargarse automáticamente al inicio de cada conversación:

Mecanismo Quién lo escribe Para qué es adecuado
Archivo CLAUDE.md Lo escribes manualmente tú (el desarrollador) Normas del proyecto, convenciones del equipo, comandos de compilación, etc.
Auto Memory (memoria automática) Claude lo escribe automáticamente Experiencia acumulada a partir de tus correcciones y preferencias

Ambos mecanismos se cargan en el contexto al inicio de cada sesión. Claude los utiliza comocontexto de referencia, no como configuración obligatoria: cuanto más específicas y concisas sean las instrucciones, con mayor consistencia las seguirá Claude.

Estructura jerárquica de los archivos de memoria

Claude Code utiliza unajerarquía de memoria de cuatro niveles, con prioridad de mayor a menor:

1. 企业级配置（Enterprise policy）    ← 最高优先级，只读
2. 用户级 CLAUDE.md                   ← ~/.claude/CLAUDE.md，对所有项目生效
3. 项目级 CLAUDE.md                   ← 项目根目录，随 Git 提交共享给团队
4. 子目录级 CLAUDE.md                 ← src/、api/、tests/ 等子目录，按上下文加载

Las reglas más específicas tienen prioridad: el CLAUDE.md de un subdirectorio sobrescribe las reglas similares de niveles superiores.

Explicación detallada del archivo CLAUDE.md

¿Qué es CLAUDE.md?

CLAUDE.mdEs un archivo Markdown ubicado en el directorio raíz del proyecto (o en un subdirectorio). Claude Code, al iniciar cada nueva sesión, loinyecta automáticamente en el prompt del sistema. Es la memoria a largo plazo que puedes configurar.

Crear CLAUDE.md

Método 1: Usar el/initcomando para generarlo automáticamente

# 在 Claude Code 会话中执行
/init

Claude analizará tu estructura de directorios y generará automáticamente un esqueleto de CLAUDE.md adaptado a tu stack tecnológico. Por ejemplo, al ejecutar/initen un proyecto Node.js, Claude detectará automáticamente el framework, las herramientas de prueba, los comandos de compilación, etc., y generará en 30 segundos un archivo inicial con un 80% de completitud.

Método 2: Crearlo manualmente

touch CLAUDE.md

Estructura recomendada de CLAUDE.md

# 项目约定

## 技术栈
- 前端：Next.js 15、TypeScript 5.7、Tailwind CSS 4
- 后端：Node.js 22、Prisma 6
- 测试：Vitest 3.2

## 代码规范
- 始终使用函数式 React 组件
- 文件名使用 kebab-case
- 测试文件与源码放在同一目录

## 常用命令
- 构建：`pnpm build`
- 测试：`pnpm test`
- 启动开发服务器：`pnpm dev`

## API 约定
- 所有 API 路由以 `/api/v1/` 开头
- 错误响应格式：`{ error: string, code: number }`

Reglas de oro para escribir un buen CLAUDE.md

✅ Hazlo así:

  • Usa oraciones imperativas y listas breves, en lugar de párrafos narrativos
  • Incluye números de versión y comandos específicos
  • Agrega ejemplos de código (un ejemplo de 5 líneas vale más que una explicación de 50 palabras)
  • Mantenlo dentro de200 líneas como máximo(el exceso no se cargará al inicio de la sesión)

❌ Evita hacerlo así:

  • Instrucciones vagas como "sigue las mejores prácticas" o "escribe código limpio"
  • Demasiadas reglas genéricas (incluye solo las convenciones exclusivas de este proyecto)
  • Información desactualizada (se recomienda revisarla una vez al mes)

CLAUDE.md en subdirectorios

my-project/
├── CLAUDE.md              # 全局项目规范
├── src/
│   └── CLAUDE.md          # 仅在处理 src/ 文件时加载
├── api/
│   └── CLAUDE.md          # API 特定约定
└── tests/
    └── CLAUDE.md          # 测试特定规则

Claude Code solo carga el CLAUDE.md de un subdirectorio cuando procesa archivos de ese directorio correspondiente, lo que ahorra tokens y proporciona un contexto más preciso.

Explicación detallada de Auto Memory (memoria automática)

¿Cómo funciona?

Auto Memory permite que Claude puedaacumular conocimiento por sí mismoentre sesiones, sin que necesites escribir nada manualmente. Claude guarda notas automáticamente durante el trabajo, incluyendo:

  • Comandos de compilación y trucos de depuración
  • Notas sobre decisiones de arquitectura
  • Preferencias de estilo de código
  • Hábitos de flujo de trabajo

Claude no guarda contenido cada vez; evalúa qué información seráútil en futuras sesionesy solo entonces la escribe.

Estructura de archivos de la memoria automática

~/.claude/projects/<project>/memory/
├── MEMORY.md          # 简洁的索引文件，每次会话开始时加载（前 200 行）
├── debugging.md       # 调试模式的详细笔记
├── api-conventions.md # API 设计决策
└── ...                # Claude 创建的其他主题文件

MEMORY.mdEs el índice de todo el directorio de memoria; Claude lo usa para rastrear el contenido almacenado en cada archivo.

Activar la memoria automática

Cuando le dices algo a Claude, lo guarda automáticamente en la memoria:

你：始终使用 pnpm，不要用 npm
你：记住 API 测试需要本地运行 Redis 实例
你：我们的日期格式统一用 ISO 8601

¿Quieres guardarlo en CLAUDE.md en lugar de en Auto Memory?Indícalo explícitamente:

你：把这条加到 CLAUDE.md

Activar / desactivar Auto Memory

Método 1: Mediante el/memorycomando para alternar(ver la siguiente sección)

Método 2: Configurarlo en los ajustes del proyecto

// .claude/settings.json
{
  "autoMemoryEnabled": false
}

Método 3: Variables de entorno

export CLAUDE_CODE_DISABLE_AUTO_MEMORY=1
blockquote>

Nota:Auto Memory es anivel de máquina local: todos los worktrees y subdirectorios del mismo repositorio Git comparten un único directorio de memoria, perono se sincroniza entre máquinas ni entornos en la nube。

/memoryGuía de uso de comandos

/memoryEs el comando central para gestionar el sistema de memoria.

/memoryFunciones de los comandos

Al ingresar/memoryen una sesión de Claude Code, puedes:

  • Verla lista de todos los CLAUDE.md y archivos de reglas cargados en la sesión actual
  • Alternarel estado de activación/desactivación de Auto Memory
  • Abrirel enlace a la carpeta de Auto Memory
  • Seleccionar cualquier archivopara abrirlo y editarlo en el editor

#Atajos de teclado: agregar memoria rápidamente

Es una herramienta de productividad oculta:

# 始终在函数参数中使用具名参数（named parameters）

Pulsa la tecla#, escribe lo que quieras recordar y presiona Enter: Claude Code lo escribirá automáticamente en el archivo CLAUDE.md correspondiente. Es ideal para:

  • Registrar convenciones del proyecto
  • Guardar comandos Bash frecuentes
  • Anotar detalles de estilo de código

Preguntas frecuentes y depuración

¿Claude ignora las instrucciones de CLAUDE.md?

  1. Ejecuta/memorypara confirmar que el archivo CLAUDE.md se ha cargado
  2. Asegúrate de que Claude Code se esté ejecutando en el directorio donde se encuentra CLAUDE.md (o en un subdirectorio)
  3. Verifica si las instrucciones son lo suficientemente específicas: "sigue las mejores prácticas" es demasiado vago, mientras que "usa importaciones con nombre (compatibilidad con tree-shaking)" es más efectivo
  4. Verifica si el archivo supera las 200 líneas (el exceso no se carga)

CLAUDE.md es contexto, no una ejecución obligatoria

Claude Claude leey se esfuerza por seguir CLAUDE.md, pero no hay garantía de cumplimiento estricto, especialmente cuando las instrucciones son vagas o entran en conflicto. Entiéndelo como una "guía de trabajo para Claude" y no como "reglas inquebrantables".

Ejemplos de flujos de trabajo reales

Escenario 1: Inicializar un nuevo proyecto

# 1. 在项目根目录启动 Claude Code
cd my-project
claude

# 2. 生成记忆文件骨架
/init

# 3. 审查并完善生成的 CLAUDE.md
/memory  # 打开文件编辑

# 4. 开始工作，Claude 会自动积累记忆

Escenario 2: Registrar hallazgos de depuración

你：记住，运行集成测试前必须先启动 Docker Compose
Claude：好的，我已将这条记录到 Auto Memory 中。
En la próxima sesión, Claude sabrá automáticamente esta relación de dependencia.

Escenario 3: Colaboración en equipo

El del directorio raíz del proyectoCLAUDE.mdEnviar al repositorio de Git: el asistente Claude de cada miembro del equipo leerá las mismas especificaciones, logrando una experiencia asistida por IA consistente.

git add CLAUDE.md
git commit -m "feat: add Claude Code memory configuration"
