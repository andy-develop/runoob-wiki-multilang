npx skills add <owner/repo>

Instalación de ui-ux-pro-max con npx, consulte:Uso de OpenCode skills。

Nota:Si no conoces npx, puedes consultar:Tutorial de introducción a npx

En este capítulo presentaremos un complemento de SKILL UI/UX profesional que admite múltiples plataformas y múltiples frameworks: UI UX Pro Max.

UI UX Pro Max está diseñado para proporcionar soporte inteligente de diseño UI/UX profesional para el desarrollo multiplataforma y multiframework.

UI UX Pro Max es esencialmente una base de datos de diseño consultable que incluye estilos, paletas de colores, tipografías, sugerencias de componentes y pautas de UX, diseñada específicamente para alimentar a asistentes de codificación de IA como Cursor, Claude Code, Windsurf, etc.

Aspectos destacados principales:

  • 67 estilos de UI (desde Minimalism hasta Brutalism, Glassmorphism, Bento Grid, AI-Native, etc.)
  • 96 paletas de colores para industrias (SaaS, Fintech, Healthcare, Beauty, EdTech…)
  • 57 combinaciones de tipografías (selecciones de Google Fonts)
  • 25 tipos de gráficos comunes (adecuados para dashboards)
  • 99 principios de guía de UX (incluyen accesibilidad, rendimiento y normas de interacción)
  • 100 reglas de razonamiento específicas por industria (incluyen patrones anti-patrones / Anti-patterns)
  • Soporta 13 stacks tecnológicos: React / Next.js / Vue / Tailwind / Flutter / SwiftUI / HTML+CSS / Electron, etc.

Principio de funcionamiento:

  • Plantear una necesidad: construir, diseñar, implementar, optimizar o evaluar UI/UX
  • Activación automática de la habilidad: la IA busca internamente en la base de datos de estilos de UI, combinaciones de colores, tipografías y normas de UX
  • Recomendaciones de diseño inteligentes: se combina el sistema de diseño adecuado según el tipo de producto y el escenario de uso
  • Generación directa de código: se genera una implementación de UI con colores, tipografías, espaciados y estructura correctos según las mejores prácticas

Dirección de código abierto:https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Documentación oficial:https://ui-ux-pro-max-skill.nextlevelbuilder.io/

Método de instalación

1. Instalación a través de Claude Marketplace (Claude Code)

En Claude Code, ejecuta los siguientes dos comandos para instalarlo directamente.

Registrar la fuente del mercado de complementos:

/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill

Instalar el complemento:

/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

Una vez instalado correctamente, reinicia Claude Code para poder usarlo:

2. Usar CLI (recomendado)

Instalar CLI globalmente:

npm install -g uipro-cli

# 进入你的项目目录
cd /path/to/your/project

# 为对应 AI 助手安装
uipro init --ai claude      # Claude Code
uipro init --ai cursor      # Cursor
uipro init --ai windsurf    # Windsurf
uipro init --ai antigravity # Antigravity (.agent + .shared)
uipro init --ai copilot     # GitHub Copilot
uipro init --ai kiro        # Kiro
uipro init --ai codex       # Codex CLI
uipro init --ai qoder       # Qoder
uipro init --ai roocode     # Roo Code
uipro init --ai gemini      # Gemini CLI
uipro init --ai trae        # Trae
uipro init --ai all         # 所有助手

3. Otros comandos de CLI:

uipro versions              # 查看可用版本
uipro update                # 更新到最新版本
uipro init --version v1.0.0 # 安装指定版本

2. Usar npx

npx skills add https://github.com/nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max

5. Instalar una versión específica

Después de la instalación, si se usa en Claude, ejecuta el siguiente comando:

uipro init --ai claude

El script de búsqueda requiere Python 3.x:

# 查看 Python  是否已经安装
python3 --version

# macOS
brew install python3

# Ubuntu/Debian
sudo apt update && sudo apt install python3

# Windows
winget install Python.Python.3.12

Luego habilita e introduce el comando para entrar en Claude:

claude

按 EscPulsa una tecla para salir.

Nota: Los Skills instalados mediante complementos se guardan en el directorio～/.claude/plugins/marketplaces。
