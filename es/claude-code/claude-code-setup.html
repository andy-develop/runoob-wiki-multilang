Instalación y uso de Claude Code
Primer uso de Claude Code

Configuración de API de Claude Code

Al usar Claude en China, la API no es muy amigable. Además de los modelos oficiales de Claude, ¿puedo usar otros modelos de IA?

Este capítulo te enseñará en detalle cómo configurar las API de varios modelos de IA principales nacionales para que Claude Code admita:

Fabricante/Marca Introducción Entrada de solicitud de API (haz clic para acceder)
DeepSeek (alta relación calidad-precio nacional) Modelos oficiales:
deepseek-v4-flash
deepseek-v4-pro
deepseek-chat (quedará en desuso el 24/07/2026)
deepseek-reasoner (quedará en desuso el 24/07/2026)		 https://platform.deepseek.com/api_keys
Alibaba Bailian (Tongyi Qianwen) Entrada unificada para modelos grandes de Alibaba Cloud, compatible con las últimas versiones de modelos como Qianwen, GLM, Kimi, MiniMax, etc. https://bailian.console.aliyun.com
GLM (Zhipu Qingyan) Serie ChatGLM de Tsinghua, compatible con GLM-4, GLM-3-Turbo, etc. https://open.bigmodel.cn
MiniMax Multimodal nacional, compatible con llamadas mixtas de texto, voz e imágenes https://platform.minimaxi.com

Después de ingresar a la consola correspondiente, regístrate/inicia sesión → completa la verificación de identidad real → crea una API Key y podrás comenzar a usarla.

Herramienta de gestión de API

Con muchas plataformas, la configuración se vuelve engorrosa. Podemos usar la herramienta de terceros CC Switch, que nos ayuda a gestionar fácilmente las configuraciones de API de estas herramientas populares:https://github.com/farion1231/cc-switch/, compatible con Windows / macOS / Linux.

CC Switch es una herramienta auxiliar integral para Claude Code / Codex / Gemini CLI.

CC Switch puede ayudarnos a gestionar fácilmente las configuraciones de API de estas herramientas populares, como si le dieras a tu caja de herramientas de desarrollo un asistente inteligente de organización; las configuraciones de todas las herramientas se pueden gestionar ordenadamente aquí.

Direcciones de descarga de los paquetes de instalación para cada plataforma:https://github.com/farion1231/cc-switch/releases。

Consulta el artículo para la configuración y operación específica:https://www.runoob.com/ai-agent/cc-switch.html

Si no te importa la molestia, puedes seguir el texto a continuación y configurarlo por tu cuenta.

Integración de DeepSeek con Claude Code

Información necesaria:

  • API key： https://platform.deepseek.com/api_keysSolicita API keys.

  • BASE_URL: la URL de solicitud de API eshttps://api.deepseek.com/anthropic。

Configuración en variables de entorno

Los usuarios de Linux / Mac ejecutan los siguientes comandos para configurar las variables de entorno de la API Anthropic de DeepSeek, donde la API Key se obtiene enDeepSeek Platformobtener:

export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<你的 DeepSeek API Key>
export ANTHROPIC_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash
export CLAUDE_CODE_EFFORT_LEVEL=max

Los usuarios de Windows ejecutan:

$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="<你的 DeepSeek API Key>"
$env:ANTHROPIC_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_SUBAGENT_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_EFFORT_LEVEL="max"

Nota: a la configuración del modelo hay que añadirle [1m], y recuerda activar la intensidad de pensamiento en max, para que pueda ejecutarse a plena potencia.

Descripción de parámetros:

Simplificado a las tres primeras columnas (nombre del parámetro / valor de ejemplo / descripción de la función) como sigue:

Nombre del parámetro Valor de ejemplo Descripción de la función
ANTHROPIC_BASE_URL https://api.deepseek.com/anthropic Especifica la dirección del gateway de API, reenviando las solicitudes del SDK de Anthropic a DeepSeek
ANTHROPIC_AUTH_TOKEN <你的 DeepSeek API Key> Token de autenticación de API, utilizado para acceder al servicio de DeepSeek
ANTHROPIC_MODEL deepseek-v4-pro Modelo principal utilizado por defecto
ANTHROPIC_DEFAULT_OPUS_MODEL deepseek-v4-pro Mapea el modelo Claude Opus
ANTHROPIC_DEFAULT_SONNET_MODEL deepseek-v4-pro Mapea el modelo Claude Sonnet
ANTHROPIC_DEFAULT_HAIKU_MODEL deepseek-v4-flash Mapea el modelo Claude Haiku (ligero y rápido)
CLAUDE_CODE_SUBAGENT_MODEL deepseek-v4-flash Modelo utilizado por el subagente (generalmente para tareas rápidas)
CLAUDE_CODE_EFFORT_LEVEL max Controla la intensidad del razonamiento y la profundidad del pensamiento

Luego entra al directorio del proyecto, ejecuta el comando claude y podrás comenzar a usarlo.

cd my-project
claude

Después de iniciar Claude Code, especifica el uso de DeepSeek:

claude --model deepseek-v4-pro

O cambia en el modo interactivo:

> /model deepseek-v4-pro

Ingresa /model para ver los modelos compatibles:

Documentación de referencia:https://api-docs.deepseek.com/zh-cn/guides/coding_agents

Integración de Alibaba Bailian con Claude Code

Los modelos de la serie Tongyi Qianwen de Alibaba Cloud Bailian admiten interfaces compatibles con la API de Anthropic. Modificando los siguientes parámetros, puedes invocar los modelos de la serie Tongyi Qianwen en Claude Code.

  • ANTHROPIC_API_KEY (o ANTHROPIC_AUTH_TOKEN): reemplázalo con la API Key de Bailian, dirección de solicitud:https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key。

  • ANTHROPIC_BASE_URL: reemplázalo con la dirección del endpoint compatible de Bailianhttps://dashscope.aliyuncs.com/apps/anthropic。

    Puedes comprar directamente paquetes de recursos, así resulta más rentable:https://cn.aliyun.com/benefit?from_alibabacloud=&userCode=i5mn5r7m

  • Nombre del modelo: reemplázalo por el nombre de un modelo compatible con Bailian (por ejemplo, qwen3-max, qwen3-coder-plus, etc.)

macOS/Linux：

Crea y abre el archivo de configuración~/.claude/settings.json。

~Representa el directorio principal del usuario; si el.claudedirectorio no existe, debes crearlo primero; puedes ejecutar en la terminalmkdir -p ~/.claude para crearlo.

Edita el archivo de configuración:

vim ~/.claude/settings.json

Reemplaza YOUR_API_KEY por tu API Key exclusiva.

{
    "env": {
        "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
        "ANTHROPIC_BASE_URL": "https://dashscope.aliyuncs.com/apps/anthropic",
        "ANTHROPIC_MODEL": "qwen3-coder-plus"
    }
}

Vuelve a abrir una nueva terminal para que la configuración de variables de entorno surta efecto.

Windows：

En CMD, ejecuta los siguientes comandos para configurar las variables de entorno:

setx ANTHROPIC_AUTH_TOKEN "YOUR_API_KEY"
setx ANTHROPIC_BASE_URL "https://dashscope.aliyuncs.com/apps/anthropic"
setx ANTHROPIC_MODEL "qwen3-coder-plus"

Reemplaza YOUR_API_KEY por la API Key exclusiva del plan.

Abre una nueva ventana de CMD, ejecuta los siguientes comandos para verificar si las variables de entorno surtieron efecto.

echo %ANTHROPIC_AUTH_TOKEN%
echo %ANTHROPIC_BASE_URL%
echo %ANTHROPIC_MODEL%

En PowerShell, ejecuta los siguientes comandos para configurar las variables de entorno:

# 用套餐专属 API Key 替换 YOUR_API_KEY
[Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "YOUR_API_KEY", [EnvironmentVariableTarget]::User)
[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://dashscope.aliyuncs.com/apps/anthropic", [EnvironmentVariableTarget]::User)
[Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "qwen3-coder-plus", [EnvironmentVariableTarget]::User)

Abre una nueva ventana de PowerShell, ejecuta los siguientes comandos para verificar si las variables de entorno surtieron efecto.

echo $env:ANTHROPIC_AUTH_TOKEN
echo $env:ANTHROPIC_BASE_URL
echo $env:ANTHROPIC_MODEL

Integración de modelos de la serie Tongyi Qianwen en Claude Code

Durante la conversación, ejecuta/model <nombre del modelo>comando para cambiar de modelo.

/model qwen3-coder-plus

También puedes crear en el directorio raíz del proyecto un.claude/settings.jsonarchivo, y escribir en él la información de configuración del modelo para configurarlo permanentemente.

{
  "env": {
    "ANTHROPIC_MODEL": "qwen3-coder-plus",
    "ANTHROPIC_SMALL_FAST_MODEL": "qwen-flash"
  }
}

Integración del modelo grande de Zhipu con Claude Code

En esta parte usamos el archivo ~/.claude/settings.json para configurar el modelo grande. Antes de comenzar, necesitas obtener una API key en la plataforma oficial:GLM Coding Plan。

Edita o agrega el archivo de configuración de Claude Code ~/.claude/settings.json, y agrega o modifica el campo env dentro de él

# 注意替换里面的your_zhipu_api_key 为您上一步获取到的 API Key
{
    "env": {
        "ANTHROPIC_AUTH_TOKEN": "your_zhipu_api_key",
        "ANTHROPIC_BASE_URL": "https://open.bigmodel.cn/api/anthropic",
        "API_TIMEOUT_MS": "3000000",
        "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": 1
    }
}

Ejecuta claude para iniciar Claude Code, ingresa/statusConfirma el estado del modelo:

Si no es así, puedes ingresar/configpara cambiar de modelo.
