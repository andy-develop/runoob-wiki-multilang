C Estructura

Los arrays en C permiten definir variables que pueden almacenar elementos de datos del mismo tipo,La estructuraes otro tipo de datos disponible definido por el usuario en la programación en C, que le permite almacenar elementos de datos de diferentes tipos.

Los miembros de datos en una estructura pueden ser tipos de datos básicos (como int, float, char, etc.), también pueden ser otros tipos de estructura, tipos de puntero, etc.

La estructura se utiliza para representar un registro. Supongamos que desea realizar un seguimiento de los libros en una biblioteca, es posible que necesite rastrear los siguientes atributos de cada libro:

  • Title
  • Author
  • Subject
  • Book ID

Definición de estructura

La definición de una estructura consta de la palabra clavestructy del nombre de la estructura. El nombre de la estructura se puede definir según sea necesario.

La declaración struct define un nuevo tipo de datos que contiene múltiples miembros. El formato de la declaración struct es el siguiente:

struct tag {
    member-list
    member-list
    member-list  
    ...
} variable-list ;

tages la etiqueta de la estructura.

member-listes una definición de variable estándar, por ejemploint i;ofloat f;, u otra definición de variable válida.

variable-listVariables de estructura, definidas al final de la estructura, antes del último punto y coma. Puede especificar una o más variables de estructura. A continuación se muestra la forma de declarar la estructura Book:

struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
} book;  

En general,tag、member-list、variable-listal menos 2 de estas 3 partes deben aparecer. A continuación se muestran ejemplos:

// esta declaración declara una estructura con 3 miembros: a de tipo entero, b de tipo carácter y c de tipo doble
// también declara la variable de estructura s1
// esta estructura no tiene etiqueta especificada
struct
{
    int a;
    char b;
    double c;
} s1;

// esta declaración declara una estructura con 3 miembros: a de tipo entero, b de tipo carácter y c de tipo doble
// la etiqueta de la estructura se llama SIMPLE, no se declara variable
struct SIMPLE
{
    int a;
    char b;
    double c;
};
// usando la etiqueta SIMPLE de la estructura, se declaran además las variables t1, t2, t3
struct SIMPLE t1, t2[20], *t3;

// también se puede usar typedef para crear un nuevo tipo
typedef struct
{
    int a;
    char b;
    double c;
} Simple2;
// ahora se puede usar Simple2 como tipo para declarar nuevas variables de estructura
Simple2 u1, u2[20], *u3;

En las declaraciones anteriores, la primera y la segunda declaración son tratadas por el compilador como dos tipos completamente diferentes, incluso si sus listas de miembros son iguales. Si se hace t3=&s1, es ilegal.

Los miembros de una estructura pueden contener otras estructuras, y también pueden contener punteros a su propio tipo de estructura. Generalmente, la aplicación de tales punteros es para implementar estructuras de datos más avanzadas, como listas enlazadas y árboles.

// la declaración de esta estructura contiene otras estructuras
struct COMPLEX
{
    char string[100];
    struct SIMPLE a;
};

// la declaración de esta estructura contiene un puntero a su propio tipo
struct NODE
{
    char string[100];
    struct NODE *next_node;
};

Si dos estructuras se contienen mutuamente, es necesario hacer una declaración incompleta de una de ellas, como se muestra a continuación:

struct B;    // declaración incompleta de la estructura B

// la estructura A contiene un puntero a la estructura B
struct A
{
    struct B *partner;
    //other members;
};

// la estructura B contiene un puntero a la estructura A; después de declarar A, B se declara a continuación
struct B
{
    struct A *partner;
    //other members;
};

Inicialización de variables de estructura

Igual que con otros tipos de variables, se pueden especificar valores iniciales para las variables de estructura al definirlas.

Ejemplo

#include <stdio.h>

struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
} book = {"Lenguaje C", "RUNOOB", "Lenguaje de programación", 123456};

int main()
{
    printf("title : %s\nauthor: %s\nsubject: %s\nbook_id: %d\n", book.title, book.author, book.subject, book.book_id);
}

El resultado de la ejecución es:

title : C 语言
author: RUNOOB
subject: 编程语言
book_id: 123456

Acceso a los miembros de la estructura

Para acceder a los miembros de la estructura, utilizamosel operador de acceso a miembros (.). El operador de acceso a miembros es un punto entre el nombre de la variable de estructura y el miembro de la estructura al que queremos acceder. Puede utilizarstructla palabra clave para definir variables de tipo estructura. El siguiente ejemplo demuestra el uso de las estructuras:

Puntero a estructura

Puede definir un puntero a una estructura, de manera similar a como se define un puntero a variables de otros tipos, como se muestra a continuación:

struct Books *struct_pointer;

Ahora puede almacenar la dirección de una variable de estructura en la variable de puntero definida anteriormente. Para obtener la dirección de una variable de estructura, coloque el operador & delante del nombre de la estructura, como se muestra a continuación:

struct_pointer = &Book1;

Para acceder a los miembros de la estructura utilizando un puntero a la estructura, debe usar el operador ->, como se muestra a continuación:

struct_pointer->title;

Reescribamos el ejemplo anterior usando punteros a estructura; esto le ayudará a comprender el concepto de punteros a estructura:

Cálculo del tamaño de una estructura

En C, podemos usarsizeofel operador para calcular el tamaño de una estructura,sizeofque devuelve el tamaño en bytes de un tipo o variable determinados.

Para una estructura,sizeofdevolverá el número total de bytes de la estructura, incluido el tamaño de todas las variables miembro y los posibles bytes de relleno.

El siguiente ejemplo demuestra cómo calcular el tamaño de una estructura:

Ejemplo

#include <stdio.h>

struct Person {
    char name[20];
    int age;
    float height;
};

int main() {
    struct Person person;
    printf("El tamaño de la estructura Person es: %zu bytes\n", sizeof(person));
    return 0;
}

En el ejemplo anterior, definimos una llamadaPersonestructura, que contiene un arreglo de caracteresname, un enteroagey un número de coma flotante (float).height。

在 mainEn la función, declaramos una variablePersondel tipoperson, y luego usamossizeofel operador para obtenerpersonel tamaño de la estructura.

Finalmente, usamosprintfla función para imprimir el tamaño de la estructura, el resultado es el siguiente:

结构体 Person 大小为: 28 字节

NotaEl tamaño de una estructura puede verse afectado por la optimización del compilador y las reglas de alineación. El compilador puede insertar algunos bytes de relleno adicionales en la estructura para alinear las variables miembro y mejorar la eficiencia del acceso a memoria. Por lo tanto, el tamaño real de la estructura puede ser mayor que la suma de los tamaños de las variables miembro. Si necesita conocer con exactitud el diseño de memoria y la alineación de la estructura, puede usaroffsetofla macro y__attribute__((packed))los atributos, entre otros, para controlar y consultar aún más el tamaño y la alineación de la estructura.

    Array de estructuras

    En una variable de estructura se puede almacenar un conjunto de datos (como el número de estudiante, nombre, calificaciones, etc.). Si hay datos de 10 estudiantes que necesitan participar en cálculos, obviamente se debe usar una matriz; esto es una matriz de estructuras. La diferencia entre una matriz de estructuras y las matrices de tipos de datos numéricos presentadas anteriormente es que cada elemento de la matriz es un dato de tipo estructura, y cada uno incluye sus respectivos miembros (componentes).

    Definir un array de estructuras

    Similar al método de definir variables de estructura, solo hay que indicar que es una matriz.

    struct student
{
    int num;
    char name[20];
    char sex;
    int age;
    float score;
    char addr[30];
};
struct student stu[3];

    Lo anterior define una matriz stu, cuyos elementos son datos de tipo struct student, y la matriz tiene 3 elementos. También se puede definir directamente una matriz de estructuras. Por ejemplo:

    struct student
{
    int num;
    ....

}stu[3];

或

struct

{
    int num;
    　...
}stu[3];

    Inicialización de un array de estructuras

    Igual que otros tipos de matrices, una matriz de estructuras se puede inicializar así:

    struct student
{
    int mum;
    char name[20];
    char sex;
    int age;
    float score;
    char addr[30];
}stu[3] = {{10101,"Li Lin", 'M', 18, 87.5, "103 Beijing Road"},
            {10101,"Li Lin", 'M', 18, 87.5, "103 Beijing Road"},
            {10101,"Li Lin", 'M', 18, 87.5, "103 Beijing Road"}};

    Al definir la matriz stu, el número de elementos no se puede especificar, es decir, se escribe de la siguiente forma:

    stu[] = {{...},{...},{...}};

    Al compilar, el sistema determina el número de elementos de la matriz según la cantidad de constantes de estructura con valores iniciales proporcionados.

    Por supuesto, la inicialización de la matriz también se puede hacer de la siguiente forma:

    struct student
{
    int num;
    ...
};
struct student stu[] = {{...},{...},{...}};

    Es decir, primero se declara el tipo de estructura, luego se define la matriz como de ese tipo de estructura, e inicializarla al definir la matriz.

    Complemento a lo mencionado en el primer mensaje: principio de alineación del tamaño de memoria de las estructuras

    1. La dirección inicial de una variable de estructura debe ser divisible por el tamaño de su miembro de tipo básico más ancho.
    2. El desplazamiento (offset) de cada miembro de la estructura con respecto a la dirección inicial de la estructura es un múltiplo entero del tamaño del miembro. Si es necesario, el compilador agregará bytes de relleno entre los miembros (internal adding). Es decir, el desplazamiento obtenido al restar la dirección inicial de la estructura (dirección inicial del primer miembro de la estructura) de la dirección final del miembro debe ser un múltiplo entero del tamaño del miembro correspondiente.
    3. El tamaño total de la estructura es un múltiplo entero del tamaño del miembro de tipo básico más ancho. Si es necesario, el compilador agregará bytes de relleno al final de los miembros.

    Primero veamos las características:

    char name[20];
    int arr[];
};

    int num;

    El resultado que produce este programa es:

    El tamaño de la estructura text1 es: 24 El tamaño de la estructura text2 es: 24

    Se puede ver en los resultados que la primera estructura tiene un parámetro más, int arr[], que la segunda estructura, pero el resultado final es que ambas estructuras tienen el mismo tamaño. Esto demuestra que al calcular una estructura, si hay una matriz de longitud no especificada en la estructura, esta matriz se ignorará en el cálculo.

    El siguiente código demostrará cómo implementar una matriz flexible:

    struct text1 {
    int num;
    char name[20];
    int arr[];
};

void main() {
    struct text1 *t1;
    //期望arr是10个整形数组
    int arrNum = 10;
    t1 = (struct text1*)malloc(sizeof(struct text1)+arrNum*sizeof(int));//给arr数组分配空间,申请（原数据结构的大小+arr数组的大小）
    t1->num = arrNum;
    //此时，就已经完成为数组arr分配空间,使用num来记录一下分配的个数
     
    //如果在使用中arr数组个数不足，需要开辟更大的空间
    int addNum = 10;
    struct text1 *pstruct=realloc(t1,sizeof(struct text1)+(t1->num+addNum)*sizeof(int));
    if (pstruct!=NULL) {//为了防止开辟空间失败导致空间丢失
        t1 = pstruct;
        t1->num += addNum;
        pstruct = NULL;
    }
    //给数组赋值
    for (int i = 0; i <= t1->num - 1;i++) {
        t1->arr[i] = i;
    }
    //打印数组
    for (int i = 0; i <= t1->num - 1;i++) {
        printf("%d ",t1->arr[i]);
    }
    //销毁数组
    free(t1);
    t1 = NULL;
}

    Lista doblemente enlazada circular

    Una lista doblemente enlazada circular (Doubly Circular Linked List) es una estructura de datos compuesta por múltiples nodos (Node). Cada nodo contiene dos punteros (Pointer), que apuntan respectivamente a su nodo anterior y a su nodo siguiente. El sucesor del último nodo apunta al nodo cabeza, y el predecesor del nodo cabeza apunta al último nodo, formando una estructura anular.

    A continuación se muestra una implementación simple de una lista doblemente enlazada circular, que incluye la estructura del nodo y la implementación de funciones de operación comunes:

    int data;

    Las reglas de alineación de memoria de las estructuras son muy simples:

    Primero, la posición de inicio relativa de la memoria de una variable miembro debe ser un múltiplo entero de la memoria ocupada por el tipo de dato (por ejemplo: la posición de inicio relativa de un dato de tipo int debe ser un múltiplo entero de 4 bytes en la estructura). Si no es suficiente, se debe alinear la parte faltante de memoria (la memoria se complementa para la variable anterior).

    Segundo, la memoria total ocupada por la estructura debe ser un múltiplo entero del tipo de dato con mayor espacio entre sus variables miembro.

    Tercero, el desplazamiento de cada miembro de la estructura con respecto a la dirección de inicio de la estructura debe ser un múltiplo del tamaño de ese miembro.

    Entre ellos, el tipo básico más ancho se refiere al tipo que ocupa más espacio entre long double, double y long long. Si la estructura no tiene miembros de estos tipos, entonces se usa int o char como el tipo básico más ancho.

    A continuación se muestra un ejemplo que demuestra el proceso de alineación de memoria de una estructura:

    struct example {
    char a;       // 1 byte
    int b;        // 4 bytes
    double c;     // 8 bytes
    short d;      // 2 bytes
};

    Según las reglas de alineación de memoria, las variables miembro de esta estructura se organizarán de la siguiente manera:

    ------------------------|------------------------|
|  char a                |  padding (3 bytes)      |
|------------------------|------------------------|
|  int b                 |                        |
|------------------------|------------------------|
|  double c              |                        |
|------------------------|------------------------|
|  short d               |  padding (6 bytes)      |
|------------------------|------------------------

    Dado que los tamaños de int y double son múltiplos de 4 y de 8, sus desplazamientos y el tamaño total de la estructura son divisibles por 4 y 8. Mientras que el tamaño de short es 2, por lo que es necesario rellenar 6 bytes para cumplir con el requisito de desplazamiento de 8.
