C Funciones

Una función es un grupo de sentencias que ejecutan juntas una tarea. Cada programa en C tiene al menos una función, la función principal.main()Todos los programas simples pueden definir otras funciones adicionales.

Puede dividir el código en distintas funciones. La forma de dividirlo en distintas funciones es decisión suya; sin embargo, lógicamente la división suele hacerse de modo que cada función ejecute una tarea específica.

Declaraciónde funciónle dice al compilador el nombre, el tipo de retorno y los parámetros de la función. Definiciónde funciónproporciona el cuerpo real de la función.

La biblioteca estándar de C ofrece una gran cantidad de funciones integradas que los programas pueden llamar. Por ejemplo, la funciónstrcat()se utiliza para concatenar dos cadenas, la funciónmemcpy()se utiliza para copiar memoria a otra ubicación.

Las funciones también tienen otros nombres, como métodos, subrutinas o programas, etc.

Definir funciones

La forma general de una definición de función en C es la siguiente:

return_type function_name( parameter list )
{
   body of the function
}

En C, una función se compone de un encabezado de función y un cuerpo de función. A continuación se enumeran todos los componentes de una función:

  • Tipo de retorno:Una función puede devolver un valor.return_typeEs el tipo de datos del valor que devuelve la función. Algunas funciones realizan la operación requerida sin devolver un valor; en este caso, return_type es la palabra clavevoid。
  • Nombre de la función:Este es el nombre real de la función. El nombre de la función y la lista de parámetros juntos constituyen la firma de la función.
  • Parámetros:Los parámetros son como marcadores de posición. Cuando se llama a la función, se pasa un valor al parámetro; ese valor se denomina parámetro real. La lista de parámetros incluye el tipo, el orden y la cantidad de los parámetros de la función. Los parámetros son opcionales, es decir, la función puede no contener parámetros.
  • Cuerpo de la función:El cuerpo de la función contiene un conjunto de sentencias que definen la tarea que ejecuta la función.

Ejemplo

Lo siguiente esmax()el código fuente de la función. Esta función tiene dos parámetros, num1 y num2, y devolverá el mayor de los dos números:

/*La función devuelve el mayor de los dos números*/ int max(int num1, int num2) { /*Declaración de variable local*/ int result; if (num1 > num2) { result = num1; } else { result = num2; } return result; }

Declaración de funciones

Declaraciónde funciónle dirá al compilador el nombre de la función y cómo llamarla. El cuerpo real de la función puede definirse por separado.

La declaración de una función incluye las siguientes partes:

return_type function_name( parameter list );

Para la función max() definida anteriormente, la siguiente es la declaración de la función:

int max(int num1, int num2);

En la declaración de la función, el nombre de los parámetros no es importante; solo el tipo de los parámetros es necesario, por lo tanto, la siguiente también es una declaración válida:

int max(int, int);

Cuando define una función en un archivo fuente y la llama en otro archivo, la declaración de la función es necesaria. En ese caso, debe declarar la función en la parte superior del archivo que la llama.

Llamar a una función

Al crear una función en C, se define qué hace la función y luego se completa la tarea definida llamando a la función.

Cuando un programa llama a una función, el control del programa se transfiere a la función llamada. La función llamada ejecuta la tarea definida y, cuando se ejecuta la sentencia de retorno de la función o se llega a la llave de cierre de la función, devuelve el control del programa al programa principal.

Al llamar a una función, se pasan los parámetros necesarios; si la función devuelve un valor, se puede almacenar el valor de retorno. Por ejemplo:

Ejemplo

#include <stdio.h> /*Declaración de función*/ int max(int num1, int num2); int main () { /*Definición de variable local*/ int a = 100; int b = 200; int ret; /*Llamar a la función para obtener el valor máximo*/ ret = max(a, b); printf( "Max value is : %d\n", ret ); return 0; } /*La función devuelve el mayor de los dos números*/ int max(int num1, int num2) { /*Declaración de variable local*/ int result; if (num1 > num2) result = num1; else result = num2; return result; }

Coloque la función max() y la función main() juntas y compile el código fuente. Al ejecutar el archivo ejecutable final, se generará el siguiente resultado:

Max value is : 200

Parámetros de funciones

Si una función va a usar parámetros, debe declarar variables que acepten los valores de los parámetros. Estas variables se denominanparámetros formales。

Los parámetros formales son como las otras variables locales dentro de la función; se crean al entrar en la función y se destruyen al salir de ella.

Cuando se llama a una función, hay dos formas de pasar parámetros a la función:

Tipo de llamadaDescripción
Llamada por valorEste método copia el valor real del parámetro a los parámetros formales de la función. En este caso, modificar los parámetros formales dentro de la función no afecta a los parámetros reales.
Llamada por referenciaMediante el paso por puntero, el parámetro formal es un puntero que apunta a la dirección del parámetro real; cuando se realiza una operación de desreferencia sobre el parámetro formal, equivale a operar sobre el propio parámetro real.

De forma predeterminada, C usallamada por valorpara pasar parámetros. En general, esto significa que el código dentro de la función no puede cambiar los parámetros reales utilizados para llamar a la función.

    Según si una función puede ser llamada por otros archivos fuente, las funciones se dividen en funciones internas y funciones externas.

    Funciones internas

    Si una función solo puede ser llamada por otras funciones del mismo archivo, se denomina función interna. Al definir una función interna, se añade static delante del nombre de la función y del tipo de la función, es decir

    static 类型名 函数名 （形参表）

    Por ejemplo, la primera línea de la función:

    static int max(int a,int b)

    Las funciones internas también se denominan funciones estáticas. El uso de funciones internas permite que el ámbito de la función se limite únicamente al archivo en el que se encuentra. Incluso si hay funciones internas con el mismo nombre en diferentes archivos, no interfieren entre sí. Esto mejora la fiabilidad del programa.

    Funciones externas

    Si al definir una función se añade la palabra clave extern en el extremo izquierdo de la cabecera de la función, entonces esta función es una función externa y puede ser llamada por otros archivos.

    Por ejemplo, el encabezado de la función puede ser

    extern int max (int a,int b)

    El lenguaje C estipula que si se omite extern al definir una función, se considera por defecto una función externa.

    En los otros archivos que necesiten llamar a esta función, deben declarar dicha función (no olvide que incluso si llama a una función en el mismo archivo, debe declararla con un prototipo de función). Al declarar esta función, debe añadir la palabra clave extern para indicar que dicha función es una función externa definida en otro archivo.

    Ejemplo

    El siguiente ejemplo, mediante funciones de varios archivos, permite ingresar una cadena de caracteres y luego eliminar el carácter especificado:

    file1.c (archivo 1)

static void delete_string(char str[],char ch);
int main()
{
    extern void enter(char str[]); // 对函数的声明
    extern void print(char str[]); // 对函数的声明
    char c,str[100];
    enter(str);
    scanf("%c",&c);
    delete_string(str,c);
    print(str);
    return 0;
}

static void delete_string(char str[],char ch)//内部函数
{
    int i,j;
    for(i=j=0;str[i]!='\0';i++)
    if(str[i]!=ch)
    str[j++]=str[i];
    str[j]='\0';
}

    file2.c (archivo 2)

    #include <stdio.h>

void enter(char str[100]) // 定义外部函数 enter
{
    fgets(str, 100, stdin); // 向字符数组输入字符串
}

    file3.c (archivo 3)

    #include <stdio.h>

void print(char str[]) // 定义外部函数 print
{
    printf("%s\n",str);
}

    Ingrese la cadena "abcdef" en el arreglo de caracteres str, y luego ingrese el carácter 'd' que se desea eliminar. Resultado de la ejecución:

    Funciones inline

    Una función inline es una función modificada con la palabra clave inline. Las funciones definidas dentro de una clase se consideran funciones inline por defecto. Desde el nivel del código fuente, una función inline tiene la estructura de una función, pero después de la compilación no tiene las propiedades de una función.

    La expansión inline se utiliza paraeliminar la sobrecarga de tiempode las llamadas a funciones. Generalmente se utiliza para funciones que se ejecutan con frecuencia y es muy beneficiosa para funciones que ocupan poca memoria.

    Al usar funciones inline, se debe prestar atención a lo siguiente:

    • Las funciones recursivas no pueden definirse como funciones inline.
    • Las funciones inline generalmente son adecuadas para funciones pequeñas que no contienen estructuras complejas como while y switch, y que solo tienen de 1 a 5 sentencias; de lo contrario, el sistema de compilación tratará la función como una función normal.
    • Una función inline solo puede utilizarse después de ser definida; de lo contrario, el sistema de compilación también la considerará una función normal.
    • No se puede realizar una declaración de interfaz de excepciones para una función inline.

    Ejemplo:Una función simple de intercambio

    inline void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

    Acerca de los parámetros de la función main

    En algunos libros muy especializados se puede ver el siguiente código:

    int main( int argc, char *argv[] )

    En el código anterior, la función main lleva parámetros.

    Pero a veces también se ve la función main sin parámetros, como sigue:

    int main()

    Entonces, ¿la función main tiene parámetros o no? ¿Afecta en algo que los tenga o no?

    En realidad, la función main no es diferente de las funciones que escribimos; también tiene sus propios parámetros.

    argc y argv son los parámetros formales de la función main.

    Los tipos de estos dos parámetros formales están estipulados por el sistema. Si la función main va a llevar parámetros, son de estos dos tipos; de lo contrario, la función main no tiene parámetros.

    Los nombres de variables argc y argv son nombres convencionales; por supuesto, pueden cambiarse por otros nombres. Después de pasar los parámetros, la función main los recibe y realiza su tarea. Entonces, ¿cómo se pasan los argumentos reales a argc y argv de la función main? Sabemos que, después de compilar y enlazar un programa en C, se genera un archivo exe. Al ejecutar ese archivo exe, se puede ejecutar directamente; también se puede ejecutar con parámetros en la línea de comandos. La forma de ejecución en la línea de comandos es: nombre del archivo ejecutable parámetro 1 parámetro 2 ... ... parámetro n. El nombre del archivo ejecutable y los parámetros, y entre parámetro y parámetro, se separan con espacios.

    , ... y así sucesivamente.

    • (1) El nombre del archivo ejecutable y la suma del número de todos los argumentos se pasan a argc;
    • (2) El nombre del archivo ejecutable (incluida la ruta) se toma como una cadena y su dirección inicial se asigna a argv

    Tres formas comunes de pasar parámetros a las funciones

    Los programas de ejemplo usan el intercambio de dos enteros.

    1. Paso por valor

    #include <stdio.h>

void swap(int x, int y);
void swap(int x, int y)
{
    int temp;
    temp = x;
    x = y;
    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(a, b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    Como el paso por valor es una transferencia unidireccional, durante el proceso solo se cambia el valor de los parámetros formales, no el valor de los argumentos reales, por lo que no cambia los valores originales de a y b.

    2. Paso por puntero

    #include <stdio.h>

void swap(int *x, int *y);
void swap(int *x, int *y)
{
    int temp;
    temp = *x;
    *x = *y;
    *y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(&a, &b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    En el paso por puntero, las direcciones de a y b se pasan respectivamente a x e y; dentro del cuerpo de la función se cambian los valores almacenados en las direcciones de a y b, es decir, se intercambian los valores de a y b.

    3. Paso por referencia

    #include <stdio.h>

void swap(int &x, int &y);
void swap(int &x, int &y)
{
    int temp;
    temp = x;
    x = y;
    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(a, b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    En el paso por referencia, al llamar a swap(a, b); la función usa a y b en lugar de x e y, es decir, x e y referencian respectivamente a las variables a y b; de este modo, los que realmente participan en la operación dentro del cuerpo de la función son los propios argumentos reales a y b, por lo que también se logra el propósito de intercambiar valores.

    Nota:Estrictamente hablando, el paso por referencia no existe en C; es una característica del lenguaje C++. Por lo tanto, usar paso por referencia en un archivo .c provocará errores de compilación.

    Las funciones logran la reutilización del código, simplifican y reducen enormemente el trabajo del programador, y también mejoran en gran medida la legibilidad del programa. La llamada recursiva de funciones es un método para simplificar el código del programa; la llamada recursiva consiste en que la función se llama a sí misma.

    El siguiente ejemplo es un caso recursivo para calcular 1+2+3.....+n:

    #include <stdio.h>  //导如输入输出头文件

int sum(int n);//声明函数 
int main(){
    //主函数 
    int a=sum(4);
    printf("%d",a);
  return 0;
}
int sum(int n){
    //求和函数实现 
    //如果n为1，无需求和，直接返回1 
    if(n==1){
        return 1;
    }
    //如果n大于1，就返回n加上1+2+3.....+n-1的和 
    return n+sum(n-1);
}

    Se puede observar que el código recursivo es muy corto, pero la recursión también tiene desventajas: ocupa más memoria que la iteración y también tarda más tiempo que la iteración.

    Un marcador de posición es un símbolo que ocupa primero un lugar fijo, esperando que luego agregues contenido en él; se usa ampliamente en la edición de diversos documentos en computación.

    El marcador de posición de formato (%) se usa en funciones de entrada/salida con formato en C/C++, como scanf, printf, etc. Su significado es actuar como marcador de formato, indicando que en esa posición hay una entrada o una salida.

    • %d, %iRepresenta un entero
    • %fPunto flotante
    • %sCadena de caracteres
    • %c char
    • %pPuntero
    • %fLlong (entero largo)
    • %eNotación científica
    • %gDecimal o notación científica.
    • %a,%ALee un valor de punto flotante (solo válido en C99).
    • %cLee un carácter.
    • %dLee un entero decimal.
    • %iLee enteros en decimal, octal y hexadecimal.
    • %oLee un entero octal.
    • %x,%XLee un entero hexadecimal.
    • %sLee una cadena; termina al encontrar un espacio, un tabulador o un salto de línea.
    • %f,%F,%e,%E,%g,%GSe usa para ingresar números reales; puede ingresarse en forma decimal o exponencial.
    • %pLee un puntero.
    • %u Lee un entero decimal sin signo.
    • %nEl número equivalente de caracteres del valor leído hasta este punto.
    • %[]Escanea un conjunto de caracteres.
    • %%Lee el símbolo %

    1. Llamada de función: Como el programa se ejecuta de arriba hacia abajo, la función debe declararse antes de llamarse. Este orden es la posición en el documento, no el orden temporal. La siguiente escritura es correcta:

    #include<stdio.h>

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我将在主函数中输出\n");
}

int main(void)
{
    f();  /*调用函数*/
}

    En el ejemplo anterior, la función se llama dentro de la función principalf(), y la declaración de la función se realiza antes de la llamada.

    2. Esta forma de escribir es incorrecta

    #include<stdio.h>

int main(void)
{
    f();/*调用函数*/
}

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我将在主函数中输出\n");
}

    En el ejemplo anterior, la función se llama dentro de la función principal f(), pero la declaración de la función se encuentra después de la llamada. Dado que la función se ejecuta de arriba hacia abajo, esta forma de escribir es incorrecta.

    Si es necesario escribir la función después de la función principal, se puede agregar una declaración previa de la función antes de la función principal.

    La declaración previa es la siguiente:

    #include<stdio.h>

void f(void); /*前置声明*/
int main(void)  
{
    f();  /*调用函数*/
}

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我一定要先声明后调用\n");
}

    En esencia, en C todo paso de parámetros a funciones es paso por valor.

    La razón por la cual el paso por puntero puede cambiar el valor del parámetro variable es que lo que la función swap intercambia no son los punteros en sí, sino los valores a los que apuntan los punteros.

    void swap(int *x, int *y);
void swap(int *x, int *y){
    int temp;
    //这里操作的是指针指向的值 而不是指针
    temp = *x;
    *x = *y;
    *y = temp;
//   倘若直接交换指针 a、b的值不会交换
//    temp = x;
//    x = y;
//    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(&a, &b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}
