C Cadenas

En el lenguaje C, una cadena es en realidad una matriz unidimensional de caracteres que usa el carácter nulo\0como terminación. Por lo tanto,\0se utiliza para marcar el final de la cadena.

El carácter nulo (Null character) también se llama terminador, abreviadoNUL, es un carácter de control con un valor de00,\0es un carácter de escape, lo que significa que le dice al compilador que no es el carácter0, sino el carácter nulo.

La siguiente declaración e inicialización crea unaRUNOOBcadena. Dado que el carácter nulo se almacena al final de la matriz,\0el tamaño de la matriz de caracteres es mayor que la palabra enRUNOOBun carácter.

char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'};

De acuerdo con las reglas de inicialización de matrices, puede escribir la declaración anterior de la siguiente manera:

char site[] = "RUNOOB";

De hecho, no es necesario ponernullel carácter al final de la constante de cadena. El compilador de C colocará automáticamente\0al final de la cadena. Intentemos mostrar la cadena anterior:

Ejemplo

#include <stdio.h> int main () { char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'}; printf("菜鸟教程: %s\n", site ); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

菜鸟教程: RUNOOB

En C hay muchas funciones para manipular cadenas:

No.Función y propósito
1strcpy(s1, s2);
Copia la cadena s2 en la cadena s1.
2strcat(s1, s2);
Concatena la cadena s2 al final de la cadena s1.
3strlen(s1);
Devuelve la longitud de la cadena s1.
4strcmp(s1, s2);
Si s1 y s2 son iguales, devuelve 0; si s1 < s2 devuelve un valor menor que 0; si s1 > s2 devuelve un valor mayor que 0.
5strchr(s1, ch);
Devuelve un puntero a la primera aparición del carácter ch en la cadena s1.
6strstr(s1, s2);
Devuelve un puntero a la primera aparición de la cadena s2 en la cadena s1.

El siguiente ejemplo utiliza algunas de las funciones anteriores:

Ejemplo

#include <stdio.h> #include <string.h> int main () { char str1[14] = "runoob"; char str2[14] = "google"; char str3[14]; int len ; /*Copiar str1 a str3*/ strcpy(str3, str1); printf("strcpy( str3, str1) : %s\n", str3 ); /*Concatenar str1 y str2*/ strcat( str1, str2); printf("strcat( str1, str2): %s\n", str1 ); /*Longitud total de str1 después de la concatenación*/ len = strlen(str1); printf("strlen(str1) : %d\n", len ); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

strcpy( str3, str1) :  runoob
strcat( str1, str2):   runoobgoogle
strlen(str1) :  12

    strlen es una función, sizeof es un operador; el tipo de resultado de ambos es size_t, es decir, tipo unsigned int.

    sizeof calcula el tamaño de la variable; no se ve afectado por el carácter\0nulo;

    mientras que strlen calcula la longitud de la cadena, usando\0como criterio para determinar la longitud.

    Nota sobre las funciones seguras de cadenas strcpy_s y strcat_s en Visual C:

    Dado que MSVC requiere que el código use funciones seguras, estas tienen un parámetro adicional de tipo size_t en comparación con las funciones originales, utilizado como tamaño del búfer. Por lo tanto, se puede usar _countof(dst) (se debe incluir el archivo de encabezado stdlib.h) para obtener el tamaño de la cadena de destino como tamaño del búfer.

    Por ejemplo:

    #include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main()
{
    char s1[] = "Hello world";
    char s2[] = " from secure function";
    char dst[50]; // 此处数组大小根据实际情况调整，或通过calloc、malloc分配动态内存
    strcpy_s(dst, _countof(dst), s1);
    strcat_s(dst, _countof(dst), s2);
    printf_s(dst);
    return 0;
}

    Resultado de la ejecución del código:

    Hello world from secure function
