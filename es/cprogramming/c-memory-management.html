C Gestión de memoria

Este capítulo explicará la gestión dinámica de memoria en C. El lenguaje C proporciona varias funciones para la asignación y gestión de memoria. Estas funciones se pueden encontrar en<stdlib.h>el archivo de cabecera.

En C, la memoria se gestiona mediante variables puntero. Un puntero es una variable que almacena una dirección de memoria, y esta dirección de memoria puede apuntar a variables de cualquier tipo de dato, incluidos enteros, números de punto flotante, caracteres y arreglos, entre otros. El lenguaje C proporciona algunas funciones y operadores que permiten al programador operar sobre la memoria, incluyendo asignación, liberación, movimiento y copia, entre otros.

N.ºFunción y descripción
1void *calloc(int num, int size);
Asigna dinámicamente en memoria num espacios continuos de longitud size, e inicializa cada byte a 0. Por lo tanto, el resultado es que se asigna un espacio de memoria de num*size bytes, y el valor de cada byte es 0.
2void free(void *address);
Esta función libera el bloque de memoria al que apunta address; libera el espacio de memoria asignado dinámicamente.
3void *malloc(int num);
Asigna un bloque de memoria de tamaño específico en el montón (heap) para almacenar datos. Este espacio de memoria no se inicializa después de que la función complete su ejecución, y sus valores son desconocidos.
4void *realloc(void *address, int newsize);
Esta función reasigna memoria, ampliando la memoria anewsize。

Nota:El tipo void * representa un puntero a un tipo no especificado. C y C++ estipulan que el tipo void * puede convertirse forzosamente mediante una conversión de tipo a un puntero de cualquier otro tipo.


Asignación dinámica de memoria

Al programar, si conoce de antemano el tamaño de un arreglo, entonces es más fácil definir el arreglo. Por ejemplo, un arreglo que almacena nombres de personas puede contener como máximo 100 caracteres, por lo que puede definir el arreglo como se muestra a continuación:

char name[100];

Pero si no conoce de antemano la longitud del texto que necesita almacenar, por ejemplo, si desea almacenar una descripción detallada sobre un tema. Aquí, necesitamos definir un puntero que apunte a caracteres cuyo tamaño de memoria requerido no esté definido, y luego asignar memoria según sea necesario, como se muestra a continuación:

Ejemplo

#include <stdio.h> #include <stdlib.h> #include <string.h> int main() { char name[100]; char *description; strcpy(name, "Zara Ali"); /*Asignación dinámica de memoria*/ description = (char *)malloc( 200 * sizeof(char) ); if( description == NULL ) { fprintf(stderr, "Error - unable to allocate required memory\n"); } else { strcpy( description, "Zara ali a DPS student in class 10th"); } printf("Name = %s\n", name ); printf("Description: %s\n", description ); }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Name = Zara Ali
Description: Zara ali a DPS student in class 10th

El programa anterior también se puede escribir usandocalloc()para escribirlo, solo necesita reemplazar malloc por calloc, como se muestra a continuación:

calloc(200, sizeof(char));

Cuando asigna memoria dinámicamente, usted tiene control total y puede pasar valores de cualquier tamaño. En cambio, los arreglos cuyo tamaño se definió previamente no pueden cambiar de tamaño una vez definidos.

Reajustar el tamaño de la memoria y liberar memoria

Cuando el programa termina, el sistema operativo libera automáticamente toda la memoria asignada al programa; sin embargo, se recomienda que, cuando ya no necesite memoria, llame a la funciónfree()para liberar memoria.

O bien, puede llamar a la funciónrealloc()para aumentar o reducir el tamaño del bloque de memoria asignado. Usemos las funciones realloc() y free() para revisar nuevamente el ejemplo anterior:

Ejemplo

#include <stdio.h> #include <stdlib.h> #include <string.h> int main() { char name[100]; char *description; strcpy(name, "Zara Ali"); /*Asignación dinámica de memoria*/ description = (char *)malloc( 30 * sizeof(char) ); if( description == NULL ) { fprintf(stderr, "Error - unable to allocate required memory\n"); } else { strcpy( description, "Zara ali a DPS student."); } /*Suponga que desea almacenar una descripción más grande*/ description = (char *) realloc( description, 100 * sizeof(char) ); if( description == NULL ) { fprintf(stderr, "Error - unable to allocate required memory\n"); } else { strcat( description, "She is in class 10th"); } printf("Name = %s\n", name ); printf("Description: %s\n", description ); /*Use la función free() para liberar memoria*/ free(description); }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Name = Zara Ali
Description: Zara ali a DPS student.She is in class 10th

Puede intentar no reasignar memoria adicional; la función strcat() generará un error, porque no hay suficiente memoria disponible para almacenar description.

Funciones y operadores comunes de gestión de memoria en C

  • Función malloc(): se utiliza para asignar memoria dinámicamente. Acepta un parámetro, que es el tamaño de memoria a asignar (en bytes), y devuelve un puntero a la memoria asignada.

  • Función free(): se utiliza para liberar memoria asignada previamente. Acepta un puntero a la memoria a liberar como parámetro y marca esa memoria como no utilizada.

  • Función calloc(): se utiliza para asignar memoria dinámicamente e inicializarla a cero. Acepta dos parámetros: el número de bloques de memoria a asignar y el tamaño de cada bloque (en bytes), y devuelve un puntero a la memoria asignada.

  • Función realloc(): se utiliza para reasignar memoria. Acepta dos parámetros: un puntero asignado previamente y un nuevo tamaño de memoria, y luego intenta reajustar el tamaño del bloque de memoria asignado previamente. Si el ajuste tiene éxito, devuelve un puntero a la memoria reasignada; de lo contrario, devuelve un puntero nulo.

  • Operador sizeof: se utiliza para obtener el tamaño de un tipo de dato o variable (en bytes).

  • Operador de puntero: se utiliza para obtener la dirección de memoria a la que apunta el puntero o el valor de la variable.

  • Operador &: se utiliza para obtener la dirección de memoria de una variable.

  • *Operador: se utiliza para obtener el valor de la variable a la que apunta el puntero.

  • -> Operador: se utiliza para que un puntero acceda a los miembros de una estructura; la sintaxis espointer->member, que es equivalente a(*pointer).member。

  • Función memcpy(): se utiliza para copiar datos desde un área de memoria de origen a un área de memoria de destino. Acepta tres parámetros: el puntero al área de memoria de destino, el puntero al área de memoria de origen y el tamaño de los datos a copiar (en bytes).

  • Función memmove(): es similar a la función memcpy(), pero puede manejar áreas de memoria superpuestas. Acepta tres parámetros: el puntero al área de memoria de destino, el puntero al área de memoria de origen y el tamaño de los datos a copiar (en bytes).

    Para punteros void, GNU considera quevoid * 和 char *son iguales, por lo que la siguiente forma de escribir es correcta:

    description = malloc( 200 * sizeof(char) );

    Pero según el estándar ANSI (American National Standards Institute), es necesario realizar una conversión forzada del puntero void, como sigue:

    description = (char *)malloc( 200 * sizeof(char) );

    Además, según el estándar ANSI (American National Standards Institute), no se pueden realizar operaciones aritméticas sobre punteros void:

    void * pvoid;
pvoid++; //ANSI：错误
pvoid += 1; //ANSI：错误
// ANSI标准之所以这样认定，是因为它坚持：进行算法操作的指针必须是确定知道其指向数据类型大小的。

int *pint;
pint++; //ANSI：正确

    Para más contenido, consulte:Explicación detallada y aplicaciones de void* en C

    Usar directamente la variable puntero original para recibirreallocel valor de retorno puede provocar una pérdida de memoria. Por ejemplo, la siguiente declaración:

    description = (char *) realloc( description, 100 * sizeof(char) );

    Si la función realloc falla, el espacio al que description apuntaba originalmente no cambia, y la función realloc devuelve NULL.

    En este momento, a description se le asigna el valor NULL, pero el espacio al que apuntaba originalmente no se libera, lo que provoca una pérdida de memoria.

Varias funciones en stdlib.h operan sobre la memoria; calloc() asigna una cantidad especificada de bloques de memoria contiguos de un tamaño especificado, y su valor de retorno es la dirección del gran bloque de memoria compuesto por estos bloques contiguos; malloc() asigna un bloque de memoria de un tamaño especificado, y su valor de retorno es la dirección de la memoria; realloc() expande o reduce el tamaño de la memoria mediante la dirección del bloque de memoria ya asignado; free() libera el bloque de memoria correspondiente a la dirección especificada, sin valor de retorno; alloc es la abreviatura de allocate (asignar); malloc mess+allocate asignación de todo el bloque.

    3. El significado de la gestión de memoria: los arreglos, los tipos de datos básicos, las estructuras y las uniones asignan espacio de memoria de manera fija para los datos, mientras que la gestión de memoria puede solicitar directamente un bloque de memoria, luego asignarle el tipo de dato a almacenar, y a partir de entonces se pueden almacenar datos, y además se puede expandir el espacio de memoria según el tamaño de los datos;
