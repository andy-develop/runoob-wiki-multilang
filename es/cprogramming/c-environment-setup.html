Introducción a C
Estructura de un programa C

C Configuración del entorno

Si desea configurar el entorno de C, debe asegurarse de que su computadora tenga los dos siguientes programas disponibles: un editor de texto y un compilador de C.

Editor de texto

Los archivos creados con un editor generalmente se denominan archivos fuente, y contienen el código fuente del programa.

Los archivos fuente de los programas en C suelen usar la extensión.c。

Antes de comenzar a programar, asegúrese de tener un editor de texto y la experiencia suficiente para escribir un programa de computadora, guardarlo en un archivo, compilarlo y ejecutarlo.

  • Visual Studio Code: Aunque es un editor de texto de propósito general, tiene muchos complementos que admiten el desarrollo en C/C++, lo que lo convierte en una opción popular. Al instalar el complemento C/C++ y ajustar la configuración, puede convertirlo en un buen entorno de desarrollo para el lenguaje C.

    Tutorial de instalación:https://www.runoob.com/w3cnote/vscode-tutorial.html

    Dirección de descarga:https://code.visualstudio.com/

  • Sublime Text: Sublime Text es un editor de texto ligero, rápido y altamente personalizable, con muchos complementos que admiten el desarrollo en C. Tiene potentes funciones de edición de código y atajos de teclado que hacen que la codificación sea más eficiente.

    Dirección de descarga:https://www.sublimetext.com/

  • Atom: Atom es un editor de texto de código abierto desarrollado por GitHub. Tiene muchos complementos y temas que pueden personalizarse para convertirlo en un entorno adecuado para el desarrollo en C.

    Dirección de descarga:https://atom-editor.cc/

  • Vim 和 Emacs: Estos dos son editores de texto tradicionales, con potentes funciones de edición y alta personalización. Son muy poderosos para usuarios experimentados, y tienen muchos complementos y configuraciones que admiten el desarrollo en C.

  • Eclipse: Eclipse es otro entorno de desarrollo integrado muy potente. Aunque originalmente fue diseñado para el desarrollo en Java, al instalar el complemento C/C++ se puede hacer que admita el desarrollo en C.

    • Compilador de C

    El código fuente escrito en el archivo fuente es legible para los humanos. Debe "compilarse" para convertirse en lenguaje de máquina, de modo que la CPU pueda ejecutar el programa de acuerdo con las instrucciones dadas.

    El compilador de C se utiliza para compilar el código fuente en un programa ejecutable final. Aquí se asume que ya tiene un conocimiento básico de los compiladores de lenguajes de programación.

    El compilador gratuito más utilizado es el compilador C/C++ de GNU. Si está utilizando HP o Solaris, puede usar el compilador de su respectivo sistema operativo.

    Las siguientes secciones le guiarán sobre cómo instalar el compilador C/C++ de GNU en diferentes sistemas operativos. Aquí se mencionan C/C++ juntos principalmente porque el compilador gcc de GNU es adecuado para los lenguajes de programación C y C++.

    Instalación en UNIX/Linux

    Si está utilizandoLinux o UNIX, use el siguiente comando en la línea de comandos para comprobar si GCC está instalado en su sistema:

    $ gcc -v

    Si su computadora ya tiene instalado el compilador GNU, se mostrará un mensaje como el siguiente:

    Using built-in specs.
Target: i386-redhat-linux
Configured with: ../configure --prefix=/usr .......
Thread model: posix
gcc version 4.1.2 20080704 (Red Hat 4.1.2-46)

    Si GCC no está instalado, siga lashttp://gcc.gnu.org/install/instrucciones detalladas en el enlace para instalar GCC.

    Este tutorial está escrito basado en Linux, y todos los ejemplos dados se han compilado en un sistema Cent OS Linux.

    Instalación en Mac OS

    Si está utilizando Mac OS X, la forma más rápida de obtener GCC es descargar el entorno de desarrollo Xcode desde el sitio web de Apple y seguir las instrucciones de instalación. Una vez instalado Xcode, podrá usar el compilador GNU.

    Xcode actualmente se puededeveloper.apple.com/technologies/tools/descargar desde.

    Usar GCC en el entorno Windows

    MinGW es la abreviatura de Minimal GNU on Windows, que permite generar programas nativos de Windows en plataformas GNU/Linux y Windows sin necesidad de bibliotecas de tiempo de ejecución de terceros. Este artículo presenta principalmente la instalación y el uso de MinGW.

    (1) Instalación

    • 1. Descargue el instalador de min-gw, el enlace es:http://sourceforge.net/projects/mingw/files/, descargue mingw-get-setup.exe (86.5 kB)
    • 2. Ejecute mingw-get-setup.exe (86.5 kB), haga clic en 'Ejecutar', continúe, etc. Tenga en cuenta recordar el directorio de instalación, comoC:\MinGw, lo necesitará más adelante al modificar las variables de entorno.
    • 3. Modificar variables de entorno: Seleccione Equipo — Propiedades --- Configuración avanzada del sistema --- Variables de entorno, en las variables del sistema busque la variable Path, y agregue al final el directorio de instalación de MinGW, por ejemploC:\MinGw\bin
    • 4. En el menú Inicio, haga clic en "Ejecutar" e ingresecmd, abra la línea de comandos: ingresemingw-get.exe, si aparece la ventana de MinGW Installation Manager, significa que la instalación es correcta. En este momento, cierre la ventana de MinGW Installation Manager; de lo contrario, los siguientes pasos darán error.
    • 5. Ingrese el comando en cmdmingw-get install gcc, espere un momento y gcc se habrá instalado correctamente.

    Si desea instalar g++, gdb, simplemente ingrese el comandomingw-get install g++ 和 mingw-get install gdb

    (2) Uso

    Escriba el programa C test.c en el directorio de trabajo actual de cmd:

    # include <stdio.h>
int main()
{
    printf("%s\n","hello world");
    return 0;
}

    Ingrese el comando en cmdgcc test.c

    En el directorio actual se generará un archivo ejecutable a.exe; ingrese a.exe en cmd para ejecutar el programa.

    Si desea depurar el programa, puede ingresar gdb a.exe

    Al entrar en la funcionalidad de gdb, puede depurar el programa usando los comandos comunes de gdb.

    Usar gcc en Android

    c4droid es un compilador de programas C/C++ en dispositivos Android. Por defecto usa tcc (tiny c compiler) como compilador, y se puede optar por instalar el complemento gcc. Al usar gcc, se pueden utilizar sdl (Simple DirectMedia Layer, se necesita instalar sdl plugin for c4droid) y qt (biblioteca de desarrollo oficial de Nokia, se necesita instalar sdl plugin for c4droid). También se pueden desarrollar aplicaciones nativas de Android (se necesita instalar sdl plugin for c4droid), igual que Google NDK. El software admite resaltado de código, y el tiempo de compilación depende de la frecuencia de la CPU; cuanto mayor sea la frecuencia, más rápida será la compilación. La versión 5.00 del complemento gcc proporciona programas de ejemplo, incluyendo código fuente de sdl, android native, qt y programas de prueba de línea de comandos.

    Enlace de Baidu Cloud: C4droid5.96 (localizado al chino)

    https://pan.baidu.com/s/1kVn5x2Z

    Primero verifique el tipo de su teléfono

    Descargue el software correspondiente

    Después de la descarga

    • 1. Primero instale C4droid y los dos complementos que comienzan con GCC y SDL; tenga en cuenta elegir la versión localizada al chino.
    • 2. Cuando los tres estén completamente instalados, abra C4DROID; aparecerá un aviso para instalar el complemento GCC, seleccione todo y listo.
    • 3. Espere a que se complete la descompresión, abra la configuración y cambie el compilador a gcc, y ya está.

    Instalar gcc en Termux.

    gcc realiza la compilación de lenguaje C en cuatro pasos:

    1. Preprocesamiento, genera el archivo precompilado (archivo .i):

    gcc –E hello.c –o hello.i

    2. Compilación, genera código ensamblador (archivo .s):

    gcc –S hello.i –o hello.s

    3. Ensamblado, genera el archivo objeto (archivo .o):

    gcc –c hello.s –o hello.o

    4. Enlazado, genera el archivo ejecutable:

    gcc hello.o –o hello

    A veces, al depurar, puede ser necesario usar alguno de estos pasos.

    Para compilar C en Win10 usando VSCode, después de instalar MinGW, busque en él mingw32-gcc.bin, mingw32-gcc-g++.bin y mingw32-gdb.bin; el primero es el compilador para archivos de lenguaje C, el segundo para C++, y el tercero se usa para depurar los archivos compilados. Luego configure las variables de entorno, escriba el archivo .c, abra en VSCode la carpeta que contiene el archivo .c (tenga en cuenta que es una carpeta), y luego configure el archivo launch.json de la siguiente manera:

    {

    "version": "0.2.0",
    "configurations": [
        {
            "name": "(gdb) Launch",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceRoot}/${fileBasenameNoExtension}.exe",
            "args": [],
            "stopAtEntry": false,
            "cwd": "${workspaceRoot}",
            "environment": [],
            "externalConsole": true,
            "MIMode": "gdb",
            "miDebuggerPath": "E:\\MinGW\\bin\\gdb.exe",
            "preLaunchTask": "gcc",//tasks.json里面的名字
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                }
            ]
            
        }
    ]
}

    El archivo tasks.json es el siguiente:

    {

    "version": "2.0.0",
    "tasks": [
        {
            "label": "gcc",
            "type": "shell",
            "command": "gcc",
            "args": [
                "-g", "${file}","-o","${fileBasenameNoExtension}.exe"
            ],
            "group":{
                "kind": "build",
                "isDefault": true
            }
        }

    ]
}

    Soy un novato total; busqué en Internet muchos métodos para crear un entorno de programación C/C++ en Win10 y descubrí que todos estaban desactualizados. Después de mucho esfuerzo, finalmente lo logré, así que quiero compartirlo:

    Método para crear un entorno de programación C/C++ usando Eclipse en Win10 (sistema de 64 bits):

    1. Instale Eclipse IDE for C/C++: entre ahttps://www.eclipse.org/downloads/packages/release/oxygen/r/eclipse-ide-cc-developers, seleccione la descarga de 64 bits según el sistema de su computadora; después de descargar, se recomienda extraerlo en el directorio raíz de cualquier unidad.
    2. Instale tdm-gcc: vaya a jmeubank.github.io, haga clic en 'download' en el lado izquierdo de la página, elija tdm64-gcc y descargue el archivo exe. Haga doble clic para abrirlo, haga clic en 'Create', luego seleccione la opción de 64 bits en la parte inferior, 'Next', elija la ubicación de instalación (puede elegir la que quiera; se recomienda crear una carpeta que pueda recordar en el directorio raíz para instalarlo) y espere a que se complete el proceso de instalación.
    3. Configurar las variables de entorno es muy sencillo: abra la ruta de instalación de tdm-gcc que acaba de instalar, haga doble clic en mingwvars.bat y las variables de entorno estarán configuradas. (¡Es demasiado amigable para novatos de computación como nosotros!)
    4. Después puede usar Eclipse para programar en C/C++. Abra la carpeta de Eclipse que descargó y extrajo en el primer paso, abra Eclipse, vaya a File --> New --> Other --> C/C++ --> C Project, en Project type seleccione Executable --> Empty Project, en Toolchains de la derecha seleccione MinGW GCC, ingrese el Project name y haga clic en Finish. En el Project Explorer de la izquierda, haga clic derecho sobre el Project name que acaba de ingresar, luego New --> File, en File name ingrese un nombre; asegúrese de agregar el sufijo '.c' al final, por ejemplo: NewFile.c. Luego haga doble clic en este archivo .c para escribir el código. Cuando quiera ejecutarlo, primero haga clic en el menú desplegable a la derecha del icono del martillo en la parte superior, seleccione Release, y luego haga clic en el botón de inicio en la esquina superior izquierda; ¡podrá ejecutar y ver la salida!
