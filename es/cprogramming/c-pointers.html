C Punteros

Aprender punteros en C es a la vez simple e interesante. Con los punteros, se puede simplificar la ejecución de algunas tareas de programación en C, y hay algunas tareas, como la asignación dinámica de memoria, que no se pueden realizar sin punteros. Por lo tanto, para convertirse en un buen programador de C, es necesario aprender punteros.

Como usted sabe, cada variable tiene una ubicación de memoria, y cada ubicación de memoria define una dirección accesible mediante el&operador para acceder a la dirección, que representa una dirección en la memoria.

Vea el siguiente ejemplo, que mostrará la dirección de la variable definida:

Ejemplo

#include <stdio.h> int main () { int var_runoob = 10; int *p; // Definir variable de puntero p = &var_runoob; printf("Dirección de la variable var_runoob: %p\n", p); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

var_runoob 变量的地址： 0x7ffeeaae08d8

A través del ejemplo anterior, hemos aprendido qué es una dirección de memoria y cómo acceder a ella. A continuación, veamos qué es un puntero.

¿Qué es un puntero?

Un puntero es una dirección de memoria; una variable de puntero es una variable que se utiliza para almacenar direcciones de memoria. Al igual que otras variables o constantes, debe declarar el puntero antes de usarlo para almacenar la dirección de otra variable. La forma general de declaración de una variable de puntero es:

type *var_name;

Aquí,typees el tipo base del puntero, que debe ser un tipo de datos válido de C,var_namees el nombre de la variable de puntero. El asterisco utilizado para declarar punteros*es el mismo asterisco que se usa en la multiplicación. Sin embargo, en esta declaración, el asterisco se usa para especificar que una variable es un puntero. Las siguientes son declaraciones de puntero válidas:

int *ip; /*Un puntero de tipo entero*/ double *dp; /*Un puntero de tipo double*/ float *fp; /*Un puntero de tipo flotante*/ char *ch; /*Un puntero de tipo carácter*/

Todos los tipos de datos reales, ya sean enteros, flotantes, caracteres u otros tipos de datos, el tipo de valor correspondiente al puntero es el mismo: todos son un número hexadecimal largo que representa una dirección de memoria.

La única diferencia entre punteros de diferentes tipos de datos es el tipo de datos de la variable o constante a la que apunta el puntero.

¿Cómo usar punteros?

Al usar punteros, se realizan con frecuencia las siguientes operaciones: definir una variable de puntero, asignar la dirección de una variable al puntero y acceder al valor en la dirección disponible en la variable de puntero. Esto se hace mediante el operador unario*para devolver el valor de la variable en la dirección especificada por el operando. El siguiente ejemplo involucra estas operaciones:

Ejemplo

#include <stdio.h> int main () { int var = 20; /*Declaración de la variable real*/ int *ip; /*Declaración de la variable de puntero*/ ip = &var; /*Almacenar la dirección de var en la variable de puntero*/ printf("Dirección de la variable var: %p\n", &var ); /*La dirección almacenada en la variable de puntero*/ printf("La dirección almacenada en la variable ip: %p\n", ip ); /*Acceder al valor usando el puntero*/ printf("El valor de la variable *ip: %d\n", *ip ); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

var 变量的地址: 0x7ffeeef168d8
ip 变量存储的地址: 0x7ffeeef168d8
*ip 变量的值: 20

El puntero NULL en C

Al declarar una variable, si no hay una dirección exacta para asignar, asignar un valor NULL a la variable de puntero es una buena práctica de programación. Los punteros a los que se les asigna el valor NULL se denominan空punteros NULL.

El puntero NULL es una constante con valor cero definida en la biblioteca estándar. Vea el siguiente programa:

Ejemplo

#include <stdio.h> int main () { int *ptr = NULL; printf("La dirección de ptr es %p\n", ptr ); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

ptr 的地址是 0x0

En la mayoría de los sistemas operativos, los programas no pueden acceder a la memoria en la dirección 0, porque esa memoria está reservada por el sistema operativo. Sin embargo, la dirección de memoria 0 tiene un significado especial: indica que el puntero no apunta a una ubicación de memoria accesible. Pero por convención, si el puntero contiene un valor nulo (cero), se asume que no apunta a nada.

Para comprobar si hay un puntero nulo, puede usar una sentencia if, como se muestra a continuación:

if(ptr) /*Si p no es nulo, entonces*/ if(!ptr) /*Si p es nulo, entonces*/

    Un puntero es una variable cuyo valor es la dirección de otra variable, es decir, la dirección directa de una ubicación de memoria. Al igual que otras variables o constantes, debe declararlo antes de usar el puntero para almacenar la dirección de otra variable.

    Para entender los punteros, primero debe entender la memoria de la computadora. La memoria de la computadora se divide en unidades de memoria numeradas secuencialmente. Cada variable se almacena en una unidad de memoria, que se denomina dirección.

    #include <stdio.h>

int main ()
{
    int var = 20;   /* 实际变量的声明 此时的 VAR 这个变量是存在某个地址的，地址对应某个内存单元，该单元中存储了数据20 */
    int *ip;         /* 指针变量的声明 定义了一个指针 即一个内存单元的地址变量 */

    ip = &var;      /* 在指针变量中存储 var 的地址 就是将地址值赋值给指针这个变量*/

    /* 在指针变量中存储的地址 利用&符号直接输出了var所存储的数据的内存单元的地址*/
    printf("Address of var variable: %p\n", &var );
    
    /* 在指针变量中存储的地址 ip代表的是这个赋值到的地址的值 所以输出的是地址值 */
    printf("Address stored in ip variable: %p\n", ip );
    
    /* 使用指针访问值 *ip代表的是定义到这个内存单元之后，内存单元中所存储的数据的值也就是将20赋值给var中20这个值 */
    printf("Value of *ip variable: %d\n", *ip );

    return 0;
}

    Algunas explicaciones complejas sobre punteros:

    • int p;-- Es una variable entera ordinaria
    • int *p;-- Primero comience desde p, primero se combina con *, por lo que p es un puntero; luego se combina con int, lo que indica que el tipo del contenido al que apunta el puntero es int. Por lo tanto, p es un puntero a datos enteros.
    • int p[3]-- Primero comience desde p, primero se combina con [], lo que indica que p es un arreglo; luego se combina con int, lo que indica que los elementos del arreglo son enteros. Por lo tanto, p es un arreglo compuesto por datos enteros.
    • int *p[3];-- Primero comience desde p, primero se combina con [], porque su prioridad es mayor que la de *, por lo que p es un arreglo; luego se combina con *, lo que indica que los elementos del arreglo son de tipo puntero; luego se combina con int, lo que indica que el tipo del contenido al que apunta el puntero es entero. Por lo tanto, p es un arreglo compuesto por punteros a datos enteros.
    • int (*p)[3];-- Primero comience desde p, primero se combina con *, lo que indica que p es un puntero; luego se combina con [] (el paso con "()" se puede ignorar, solo es para cambiar la prioridad), lo que indica que el contenido al que apunta el puntero es un arreglo; luego se combina con int, lo que indica que los elementos del arreglo son enteros. Por lo tanto, p es un puntero a un arreglo compuesto por datos enteros.
    • int **p;-- Primero comience desde p, primero se combina con *, que indica que p es un puntero; luego se combina con *, lo que indica que el elemento al que apunta el puntero es un puntero; luego se combina con int, lo que indica que el elemento al que apunta el puntero es un dato entero. Dado que los punteros de segundo nivel y los de nivel superior rara vez se usan en tipos complejos, no consideraremos punteros de varios niveles en los tipos más complejos posteriores; como máximo consideraremos punteros de un nivel.
    • int p(int);-- Comience desde p, primero se combina con (), lo que indica que p es una función; luego se analiza dentro de (), lo que indica que la función tiene un parámetro de variable entera; luego se combina con el int exterior, lo que indica que el valor de retorno de la función es un dato entero.
    • int (*p)(int);-- Comience desde p, primero se combina con el puntero, lo que indica que p es un puntero; luego se combina con (), lo que indica que el puntero apunta a una función; luego se combina con el int dentro de (), lo que indica que la función tiene un parámetro de tipo int; luego se combina con el int más externo, lo que indica que el tipo de retorno de la función es entero. Por lo tanto, p es un puntero a una función que tiene un parámetro entero y cuyo tipo de retorno es entero.
    • int *(*p(int))[3];Puedes omitirlo por ahora, no mires este tipo. Es demasiado complejo; empieza desde p, primero se combina con (), indica que p es una función, luego entra dentro de (), se combina con int, indica que la función tiene un parámetro de tipo entero, luego se combina con el * exterior, indica que la función devuelve un puntero, luego a la capa más externa, primero se combina con [], indica que el puntero devuelto apunta a un array, luego se combina con *, indicando que los elementos del array son punteros, luego se combina con int, indicando que el contenido al que apunta el puntero son datos enteros. Por lo tanto, p es una función cuyo parámetro es un dato entero y que devuelve un puntero a un array compuesto por variables puntero a enteros.

    Punteros a funciones

    El código y los datos son iguales; ambos necesitan ocupar cierta memoria, y por supuesto también tendrán una dirección base, por lo que podemos definir un puntero que apunte a esta dirección base; esto es lo que se llama puntero a función.

    Supongamos que tenemos la función:

    double func(int a,char c);
double (*p)(int a,char c);
p=&func;

    Entonces se puede definir un puntero a función.

    Llamar a la función

    double s1=func(100,'x');
double s2=(*p)(100,'x');

    Las dos declaraciones anteriores son equivalentes.

    #include <stdio.h>

void func1(int *a, int **b);

void func1(int *a, int **b)
{
   (*a)++;
   (*b)++;//这里虽然传进来的是指针的形式，但其实是指针c的地址，
          //可以认为这里本质还是值传递，只不过这个值是地址值
}

int main()
{
    int a[2] = {10, 20};
    int *b = &a[0];
    int *c = a+1;
    int **d = &c;
    
    func1(b, d);
    printf("a[0] = %d   a[1] = %d\n", a[0], a[1]);

    return 0;
}

    Resultado de la ejecución:a[0] = 11 a[1] = 20

    Entré en contacto con el lenguaje C en 2016, y en ese entonces no había manera de entenderlo. Especialmente los punteros; ya han pasado más de 2 años y ahora tengo algo de comprensión. Mirando hacia atrás, cada vez que se habla de punteros se menciona el concepto de dirección, así que los conceptos relacionados con punteros se entienden mejor combinándolos con la gestión de memoria de C. A continuación, explico cómo entender mejor los punteros.

    ¿Por qué se llama puntero? En realidad, el puntero es una metáfora muy gráfica. A continuación, expongo mi comprensión personal.

    Una variable int almacena un valor de tipo int, una variable char almacena un valor de tipo char; y un puntero, que es un tipo especial de variable, almacena una dirección de memoria. Siguiendo esta plantilla, se puede entender así:Una "variable de dirección de memoria" almacena una "dirección de memoria", lo que equivale a: una "variable puntero" almacena una "dirección de memoria".

    Cuando el sistema operativo realiza la programación de recursos, solicita y utiliza la región de memoria representada por esa dirección según la dirección almacenada en estas variables. Es como si la dirección almacenada en esta variable apuntara a cierta memoria; las personas usan "puntero" para referirse colectivamente a las llamadas "variables de dirección de memoria".

    Por lo tanto,Cualquier concepto relacionado con punteros puede entenderse en relación con las direcciones de memoria, y ambos están necesariamente relacionados; los arrays y los punteros, las funciones y los punteros, todos son así.

    • La memoria es lineal, la memoria se nos presenta en forma de espacio de direcciones, por lo que se puede decir que el llamado espacio de direcciones también es lineal. El puntero almacena direcciones de memoria, por lo que puedes realizar operaciones como ++ o -- sobre las direcciones.
    • Dejar dos punteros sin asignar NULL es un mal hábito
    • No asignar NULL al inicializar un puntero, porque dicho puntero apuntará a una región desconocida. Este puntero no es un puntero nulo, pero apunta a una región de memoria con acceso restringido; no puedes usarlo. En este caso, la industria le ha dado un nombre gráfico: "puntero salvaje". Además, es difícil de depurar; en muchos compiladores, el debug paso a paso produce errores extraños, pero el error frecuente "Segmentation Fault" es uno de ellos. En la práctica, cuando el código es extenso, este es un error muy molesto; una de sus causas es el puntero salvaje. Así que al ver este error, primero piensa si hay algún puntero que no fue inicializado.
    • No asignar NULL al puntero después de free(), después de asignar memoria a un puntero, este puede apuntar a una región de memoria legal y utilizable. Pero cuando usas free() para liberar esa memoria, el puntero aún conserva la dirección de esa memoria, es decir, sigue apuntando a esa memoria, pero esta ya ha sido liberada y no es accesible. Si en ese momento usas este puntero por descuido, se producirá un error de memoria y aparecerán extraños bugs; cuando el código tiene unos cientos de líneas, es difícil de depurar. La industria también tiene un nombre común para este tipo de puntero: "puntero colgante". Para evitar esta molesta situación, después de liberar la memoria, debes asignar NULL a todos los punteros que apunten a esa memoria. También se puede ver que free() al liberar memoria no tiene nada que ver con los punteros que apuntan a esa memoria, ¡no se encarga de eliminar también los punteros!¡Aprecia la vida y aléjate de los "punteros salvajes" y los "punteros colgantes"!
    • Puntero multinivel, es un puntero que apunta a un puntero; a veces también se le llama puntero multidimensional. Dado que una variable puntero es una variable, una variable puntero puede almacenar la dirección de memoria de una variable.

    Por ejemplo, int * almacena la dirección de una variable int, char * almacena la dirección de tipo char; entonces es natural que un puntero pueda almacenar la dirección de una variable puntero.

    Por ejemplo, int ** almacena la dirección de int *, e int *** almacena la dirección de int **.

    Esto es un puntero de segundo nivel que almacena la dirección de un puntero de primer nivel, un puntero de tercer nivel almacena la dirección de un puntero de segundo nivel. La gente llama a este proceso "puntero a puntero", pero en realidad solo es que un puntero de nivel superior almacena la dirección de un puntero de nivel inferior.

    Por lo tanto, como se mencionó antes, si almacenas su dirección, entonces apuntas a él, así que:

    • Si un puntero de segundo nivel almacena la dirección de un puntero de primer nivel, entonces se puede decir que el puntero de segundo nivel apunta al puntero de primer nivel
    • Si un puntero de tercer nivel almacena la dirección de un puntero de segundo nivel, entonces se puede decir que el puntero de segundo nivel apunta al puntero de primer nivel
    • Los punteros multinivel tienen muchos usos; aquí no daremos ejemplos ni explicaciones detalladas por ahora.

    Personalmente creo que los punteros pueden considerarse la característica más grande de C; a través de este modelo se puede gestionar parte de la memoria de forma gráfica.
