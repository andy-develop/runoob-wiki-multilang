C Biblioteca estándar -<stdarg.h>

<stdarg.h>Es un archivo de cabecera de la biblioteca estándar de C, que proporciona un conjunto de macros para acceder a un número variable de argumentos.

stdarg.hEl archivo de cabecera define un tipo de variableva_listy tres macros, estas tres macros se pueden utilizar para obtener los parámetros de una función cuando el número de parámetros es desconocido (es decir, el número de parámetros es variable).

Las funciones de parámetros variables generalmente usan puntos suspensivos al final de la lista de parámetros...para su definición.

Variables de biblioteca

A continuación se muestran los tipos de variables definidos en el archivo de cabecera stdarg.h:

N.ºVariable y descripción
1va_list
Este es un tipo adecuado parava_start()、va_arg() 和 va_end()almacenar información con estas tres macros. Tipo utilizado para almacenar información de parámetros variables.

Macros de biblioteca

A continuación se muestran las macros definidas en el archivo de cabecera stdarg.h:

N.ºMacro y descripción
1void va_start(va_list ap, last_arg)
Esta macro inicializaapla variable, que se utiliza junto conva_arg 和 va_endla macro.last_arges el último parámetro fijo conocido pasado a la función, es decir, el parámetro anterior a los puntos suspensivos.
2type va_arg(va_list ap, type)
Esta macro recupera de la lista de parámetros de la función el siguiente parámetro de tipotype.
3void va_end(va_list ap)
Esta macro permite que una función con parámetros variables que usava_startla macro regrese. Si no se llamava_endantes de regresar de la función, el resultado es indefinido.

Ejemplo

A continuación se muestra un ejemplo de uso de<stdarg.h>para implementar una función de parámetros variables. Esta función calcula la suma de todos los parámetros:

Ejemplo

#include <stdio.h>
#include <stdarg.h>

// Calcula la suma de los parámetros variables
int sum(int count, ...) {
    int total = 0;
    va_list args;
   
    // Inicializa args para acceder a los parámetros variables
    va_start(args, count);
   
    // Accede a los parámetros variables uno por uno
    for (int i = 0; i < count; i++) {
        total += va_arg(args, int);
    }
   
    // Limpia args
    va_end(args);
   
    return total;
}

int main() {
    printf("Sum of 1, 2, 3: %d\n", sum(3, 1, 2, 3)); // Salida 6
    printf("Sum of 4, 5, 6, 7: %d\n", sum(4, 4, 5, 6, 7)); // Salida 22
    return 0;
}

Resultado de salida:

Sum of 1, 2, 3: 6
Sum of 4, 5, 6, 7: 22

Análisis

  • va_list args;: declara unava_listvariable, utilizada para acceder a los parámetros variables.
  • va_start(args, count);: inicializaargspara recorrer la lista de parámetros variables, comenzando desdecountel primer parámetro después de.
  • total += va_arg(args, int);: obtiene el siguiente parámetro de la lista de parámetros variables y lo acumula entotal. El tipo de parámetro esint。
  • va_end(args);: limpiaargs。

Notas

  • Cada tipo de parámetro en la lista de parámetros variables debe ser explícito y debe pasarse de manera consistente ava_arg。
  • Después de usarva_start, se debe usarva_endpara limpiar lava_listvariable.
  • va_start、va_arg 和 va_endLas macros deben usarse en pares dentro de una función para evitar comportamientos indefinidos.

    ¡¡El método del segundo comentario no es seguro!!

    Al usar el método de parámetros no fijos del segundo comentario, encontré un bug. Los parámetros que pasé eran punteros a estructuras. El código es el siguiente:

    void AddChildren(Node* parent, ...)
{
    if (parent == NULL) return;
    Node* child = NULL;
    va_list child_list;
    va_start(child_list, parent);
    while (child = va_arg(child_list, Node*)) {
        parent->children[parent->child_ptr++] = child;
    }
    va_end(child_list);
    child = NULL;
}

    Pero al imprimir la estructura de árbol, se produjo un error

    Segmentation fault (core dumped)

    En ese momento no sabía la causa del error, y cuando cambié la función a:

    void AddChildren(Node* parent, int childnum, ...)
{
    if (parent == NULL) return;
    va_list child_list;
    va_start(child_list, childnum);
    for (int i = 0; i < childnum; i++) {
        parent->children[parent->child_ptr++] = va_arg(child_list, Node*);
    }
    va_end(child_list);
}

    el código pudo ejecutarse correctamente.

    Más tarde encontré la respuesta relacionada en Stackoverflow:https://stackoverflow.com/questions/9774803/stdarg-h-reads-too-many-arguments

    Parte del contenido se extrae a continuación:

    Don't use va_list, especially in member functions. And you need to know the number of the arguments, va_arg will happily read the entire memory if it can。

    Así que una solución es pasar un número definido de parámetros como hice arriba.

    Y otra persona dio otra solución, que consiste en seguir usando un código similar al del segundo comentario, pero al pasar los parámetros se pasa adicionalmente un 0 como símbolo de terminación para la condición while:

    Variadic function arguments are not typesafe, or any kind of 'safe' for that matter. It is your responsibility to communicate to your function how many arguments there are and what their types are.

    In your code, the only thing that makes the loop terminate is when x evaluates as false. Your data, obscurely typed as it is, seems to consist of integral values, and that would necessitate your last variadic argument to be zero, which it isn't in your example.

    Try calling the function wtih (n, x1, x2, x3, 0).
