C Sintaxis básica

C es un lenguaje de programación de propósito general, ampliamente utilizado en áreas como la programación de sistemas, el desarrollo embebido y la computación de alto rendimiento.

C se caracteriza por ser eficiente, flexible y altamente portátil; es la base de muchos otros lenguajes de programación (como C++, Java y Go), y sigue siendo la opción principal para el desarrollo de sistemas operativos, controladores y bibliotecas de bajo nivel.

En C, los tokens son las unidades básicas que componen un programa. El compilador analiza léxicamente el código fuente y lo descompone en tokens. Un token es la unidad mínima con significado que el compilador puede reconocer; todo programa C está formado por estos tokens.

Los tokens en C incluyen principalmente los siguientes tipos:

  • Palabras clave (Keywords): son palabras reservadas por el lenguaje con un significado especial, comoint、if、return。
  • Identificadores (Identifiers): son nombres definidos por el programador, utilizados para variables, funciones, arreglos, etc.
  • Constantes (Constants): son valores fijos e inmutables en el programa, como enteros42, números de coma flotante3.14。
  • Literales de cadena (String Literals): son secuencias de caracteres encerradas entre comillas dobles, como"Hello"。
  • Operadores (Operators): son símbolos utilizados para realizar operaciones, como+、==、&&。
  • Separadores (Separators): son símbolos utilizados para separar sentencias y bloques de código, como;、{}。

Estructura básica de un programa C

Este es un programa sencillo en C que puede imprimir "Hello, World!":

Ejemplo

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

El código anterior se compone de la siguiente manera:

  • Directiva de preprocesador: como#include 和 #define, se procesa mediante el preprocesador antes de la compilación.
  • Función principal: cada programa C tiene una y solo unamain()función, que es el punto de entrada del programa.
  • Declaración de variables: declara las variables utilizadas en el programa; C89 exige que las declaraciones estén al comienzo del bloque de código.
  • Definición de funciones: define las funciones utilizadas en el programa y describe la lógica de implementación específica de cada función.

A continuación se explica una estructura de programa C un poco más compleja (los capítulos posteriores ampliarán cada punto):

Ejemplo

#include <stdio.h> // Inclusión de archivo de cabecera

#define PI 3.14159 // Definición de macro

// Declaración de la función
int add(int a, int b);

int main() {         // Función principal
    // Declaración de variables
    int num1, num2, sum;

    // Entrada del usuario
    printf("Enter two integers: ");
    scanf("%d %d", &num1, &num2);

    // Llamada a la función
    sum = add(num1, num2);

    // Salida del resultado
    printf("Sum: %d\n", sum);

    return 0;        // Devuelve 0 para indicar que el programa se ejecutó correctamente
}

// Definición de la función
int add(int a, int b) {
    return a + b;
}

Inclusión de archivos de cabecera

  • Los archivos de cabecera generalmente se usan al comienzo del programa mediante la#includedirectiva de inclusión. Los archivos de cabecera proporcionan declaraciones de funciones y bibliotecas, como la biblioteca estándar de entrada/salida<stdio.h>, la biblioteca estándar<stdlib.h>, etc. Definen funciones, macros, constantes, etc., para que el programa pueda utilizar funciones de biblioteca predefinidas.
  • Los archivos de cabecera del sistema se incluyen con corchetes angulares<>, y los archivos de cabecera definidos por el usuario se incluyen con comillas dobles"", la ruta de búsqueda de ambos es diferente.
  • Ejemplo:#include <stdio.h>(archivo de cabecera del sistema),#include "myheader.h"(archivo de cabecera definido por el usuario)

Definición de macros

  • Las macros se definen mediante la#definedirectiva, como constantes simbólicas o fragmentos de código. El preprocesador reemplaza el texto de las macros antes de la compilación; estas no ocupan memoria en tiempo de ejecución y se usan comúnmente para definir constantes o lógica de código en línea simple.
  • Las macros no tienen verificación de tipos, por lo que deben usarse con precaución; para constantes que requieren tipos, se recomienda usarconstvariables en su lugar.
  • Ejemplo:#define PI 3.14159、#define MAX(a, b) ((a) > (b) ? (a) : (b))

Declaración de funciones

  • En C, la declaración de una función (también llamada prototipo) debe aparecer antes de la definición o llamada de la función. La declaración proporciona el tipo de retorno, el nombre de la función y la lista de parámetros, de modo que el compilador pueda realizar la verificación de tipos en el punto de la llamada.
  • Las declaraciones de funciones pueden colocarse en archivos de cabecera para que múltiples archivos fuente las compartan.
  • Ejemplo:int add(int a, int b);

Función principal

  • main()La función `main` es el punto de entrada de un programa C; cada programa C debe contener unamain()función. El programamain()comienza a ejecutarse; el valor de retorno normalmente es0indica que el programa se ejecutó correctamente; un valor distinto de cero indica que se produjo un error.
  • main()La función `main` también puede recibir parámetros de línea de comandos:int main(int argc, char *argv[]), dondeargces el número de argumentos,argves la matriz de cadenas de argumentos.
  • Ejemplo:int main() { ... }

Declaración de variables

  • En un programa C, todas las variables deben declarar su tipo antes de usarse. Las variables pueden declararsemain()dentro de una función (variables locales) o globalmente fuera de una función (variables globales).
  • Al declarar una variable, se puede inicializar al mismo tiempo. Las variables locales no inicializadas contienen valores indeterminados (valores basura), mientras que las variables globales y estáticas se inicializan automáticamente a0。
  • Ejemplo:int count = 0;、float price = 9.99;、char grade = 'A';

Sentencias y expresiones

  • Una sentencia es la unidad básica de ejecución de un programa C; normalmente es una llamada a función, una asignación, una sentencia de control (comoif、foretc.) o una expresión. Una expresión es un fragmento de código compuesto por variables, operadores y constantes, que puede evaluarse para obtener un valor.
  • En C, la asignación en sí misma también es una expresión que tiene un valor (el valor asignado), por lo que se puede escribira = b = c = 0;asignaciones en cadena como esa.
  • Ejemplo:
    printf("Enter two integers: ");
sum = add(num1, num2);

Sentencias de control de flujo

  • Las sentencias de control de flujo se utilizan para controlar el orden de ejecución de un programa, e incluyen la toma de decisiones condicional (if/else、switch) y los bucles (for、while、do-while). También están las sentencias de saltobreak、continue、goto 和 return。
  • Usar adecuadamente las sentencias de control de flujo es clave para escribir programas con lógica clara; se debe evitar el abuso degotopara mantener la legibilidad del código.
  • Ejemplo:
    if (num1 > num2) {
    printf("num1 is greater than num2");
}

Definición de funciones

  • La definición de una función incluye el cuerpo completo de la función y describe su implementación concreta. Una función se compone de tipo de retorno, nombre de función, lista de parámetros y cuerpo de función. Un buen diseño de funciones debe seguir el principio de "responsabilidad única": cada función debe hacer una sola cosa.
  • Las funciones en C no admiten sobrecarga; cada nombre de función debe ser único en el mismo ámbito. Las funciones pueden llamarse a sí mismas de forma recursiva.
  • Ejemplo:
    int add(int a, int b) {
    return a + b;
}

Sentencia de retorno

  • returnLa sentencia `return` se utiliza para terminar la ejecución de una función y devolver el control, junto con el valor de retorno, al llamador.voidLas funciones de tipo `void` pueden usar un `return` sin valorreturn;para salir anticipadamente; también se puede omitirreturnla sentencia.
  • main()El valor de retorno de la función se pasa al sistema operativo,0normalmente indica éxito; se puede usar la macro estándarEXIT_SUCCESS 和 EXIT_FAILURE(definida en<stdlib.h>）。
  • Ejemplo:return 0;、return EXIT_SUCCESS;

Separadores

Los separadores se utilizan para delimitar sentencias, expresiones y bloques de código, ayudando al compilador a entender la estructura del programa. Los separadores comunes incluyen:

  • Coma,: se utiliza para separar múltiples elementos en declaraciones de variables, parámetros de funciones o listas de inicialización.
  • Punto y coma;: se utiliza para terminar una sentencia; es el separador más común en C.
  • Paréntesis：
    • Paréntesis redondos(): se utilizan para la lista de parámetros en llamadas a funciones, las condiciones en sentencias de control de flujo y para forzar el orden de evaluación de expresiones.
    • Llaves{}: se utilizan para definir el cuerpo de una función, bloques de código de control de flujo, y la inicialización de literales compuestos y arreglos/estructuras.
    • Corchetes[]: se utilizan para declarar arreglos y acceder a sus elementos (operación de subíndice).

En un programa C, el punto y coma;es el terminador de sentencias; cada sentencia debe terminar con un punto y coma, que indica el final de una entidad lógica. La falta de punto y coma es uno de los errores de sintaxis más comunes entre principiantes.

Por ejemplo, las siguientes son dos sentencias diferentes:

printf("Hello, World! \n");
return 0;

Un punto y coma por sí solo también puede actuar como una sentencia vacía, que no hace nada; se usa a menudo en ciertas estructuras de bucle:

while (condition);  // 空循环体，等待条件变化

Identificadores

Los identificadores son los nombres de variables, funciones, arreglos, tipos, etc., en un programa, definidos por el programador. Los identificadores se componen de letras (mayúsculas o minúsculas), dígitos y guiones bajos, pero el primer carácter debe ser una letra o un guion bajo, no puede ser un dígito.

Un identificador comienza con una letra A-Z o a-z o un guion bajo _, seguido de cero o más letras, guiones bajos y dígitos (0-9).

No se permiten caracteres de puntuación como @, $ y % dentro de los identificadores de C. C essensible a mayúsculas y minúsculasde programación. Por lo tanto, en C,Manpower 和 manpowerson dos identificadores diferentes. A continuación se enumeran varios identificadores válidos:

Sugerencia de nomenclatura: los identificadores deben ser descriptivos y expresar claramente su propósito. Los estilos de nomenclatura comunes incluyen la notación con guiones bajos (my_variable) y la notación camelCase (myVariable), y en el mismo proyecto basta con mantener la coherencia. Los identificadores que comienzan con doble guion bajo__suelen estar reservados por el compilador o la biblioteca estándar, y deben evitarse en el código de usuario.

Constantes

Las constantes son valores fijos que no cambian durante la ejecución del programa. En C, hay principalmente dos formas de definir constantes: usandoconstla palabra clave o usando#definela definición de macro.

Las constantes pueden ser constantes enteras, constantes de punto flotante, constantes de carácter, constantes de enumeración, etc.:

const int MAX = 100;          // 整型常量
const float PI = 3.14159;    // 浮点型常量
const char NEWLINE = '\n';   // 字符常量（转义字符）

Los caracteres de escape de uso común en las constantes de carácter incluyen:

  • \n: salto de línea
  • \t: tabulación horizontal
  • \\: barra invertida
  • \': comilla simple
  • \0: carácter nulo (marca de fin de cadena)

Usandoconstlas constantes definidas tienen información de tipo, el compilador puede realizar la comprobación de tipos; en comparación con las#definemacros, es más seguro y es la forma recomendada a partir de C99.

Literales de cadena

Los literales de cadena son secuencias de caracteres entre comillas dobles, utilizados para representar datos de texto.

Los literales de cadena se almacenan en memoria como arreglos de caracteres, y al final se agrega automáticamente un carácter nulo\0(es decir, el terminador nulo), que marca el final de la cadena.

char greeting[] = "Hello, World!";  // 编译器自动计算长度（包含 \0）

A continuación se presentan algunos puntos importantes sobre los literales de cadena:

  • El literal "Hello" en realidad ocupa 6 bytes en memoria:'H'、'e'、'l'、'l'、'o'、'\0'。
  • Los literales de cadena se almacenan en un área de memoria de solo lectura y no se pueden modificar; si se necesita modificarlos, se deben copiar a un arreglo de caracteres.
  • Dos literales de cadena adyacentes son concatenados automáticamente por el compilador:"Hello, " "World!"es equivalente a"Hello, World!"。
  • El carácter'A'(constante de carácter) y la cadena"A"(literal de cadena) son diferentes; esta última contiene'A' 和 '\0'dos caracteres.

Operadores (Operators)

Los operadores se utilizan para realizar diversas operaciones, como operaciones aritméticas, lógicas, de comparación, etc. Los operadores actúan sobre operandos, forman expresiones y producen un resultado.

En C hay una gran variedad de operadores; los más comunes incluyen:

  • Operadores aritméticos：+, -, *, /, %(donde/realiza división entera para enteros,%obtiene el residuo).
  • Operadores relacionales：==, !=, >, <, >=, <=(devuelven 1 para verdadero y 0 para falso)
  • Operadores lógicos：&&(Y),||(O),!(NO), con evaluación de cortocircuito
  • Operadores de bits：&(Y a nivel de bits),|(O a nivel de bits),^(XOR a nivel de bits),~(complemento a nivel de bits),<<(desplazamiento a la izquierda),>>(desplazamiento a la derecha)
  • Operadores de asignación：=, +=, -=, *=, /=, %=(asignación compuesta, comoa += bes equivalente aa = a + b）
  • Operadores de incremento/decremento：++(incremento),--(decremento), con dos formas: prefijo (primero realiza la operación y luego toma el valor) y sufijo (primero toma el valor y luego realiza la operación).
  • Otros operadores：sizeof(calcula el tamaño en bytes de un tipo o variable),?:(operador ternario),&(obtener dirección),*(desreferenciar),->(acceder a miembro a través de puntero),.(acceder a miembro directamente)
int a = 5, b = 10;
int sum = a + b;           // 算术运算符 +，sum = 15
int isEqual = (a == b);   // 关系运算符 ==，isEqual = 0（假）
int result = a << 1;      // 位运算左移，result = 10（相当于 a * 2）
a++;                       // 后缀自增，a 变为 6
int max = (a > b) ? a : b; // 三目运算符，max = b = 10

Los operadores tienen precedencia y asociatividad: la precedencia determina el orden de las operaciones, y la asociatividad determina la dirección de evaluación de los operadores del mismo nivel. Cuando no esté seguro de la precedencia, se recomienda usar paréntesis para agrupar explícitamente y mejorar la legibilidad del código.

Espacios en blanco en C

Una línea que contiene solo espacios se denomina línea en blanco, y puede llevar comentarios; el compilador de C la ignora por completo.

En C, el espacio se usa para describir caracteres de espacio en blanco (tecla de espacio), tabulaciones (Tab), saltos de línea y comentarios. Los espacios separan las distintas partes de una sentencia, permitiendo que el compilador reconozca dónde termina un elemento de la sentencia (por ejemplo,int), dónde termina y dónde comienza el siguiente elemento. Por lo tanto, en la siguiente sentencia:

int age;

int 和 ageDebe haber al menos un carácter de espacio entre ellos (normalmente un espacio en blanco), para que el compilador pueda distinguirlos. Por otro lado, en la siguiente sentencia:

fruit = apples + oranges;   // 获取水果的总数

fruit 和 =, o= 和 applesel carácter de espacio entre ellos no es necesario, pero para mejorar la legibilidad, puede agregar algunos espacios según sea necesario.

Los buenos hábitos de espaciado e indentación son una parte importante del código de alta calidad; se recomienda seguir las siguientes normas:

  • Use una indentación consistente (normalmente 4 espacios o 1 tabulación) para representar la jerarquía de los bloques de código.
  • Agregue espacios a ambos lados de los operadores (por ejemplo,a + b), para que las expresiones sean más legibles.
  • Agregue un espacio después de las comas (por ejemplo,int a, b, c;), distingue múltiples elementos.
  • Usa líneas en blanco apropiadamente para separar bloques de código lógicamente relacionados, mejorando la legibilidad general.

    1. Estructura de un programa en C

    • 1) Un programa en C está compuesto por funciones; cada función puede implementar una o más funcionalidades.
    • 2) Un programa correcto puede tener múltiples funciones, pero tiene exactamente una función principal.
    • 3) Las funciones solo se ejecutan cuando son llamadas; la función principal es llamada y ejecutada por el sistema.
    • 4) El formato de las funciones debe escribirse de acuerdo con las especificaciones.
    • 5) La extensión de los archivos de programa en C es .c

    Identificadores

    Identificador:En los lenguajes de programación, un identificador es un nombre que el usuario utiliza al programar; las variables, constantes, funciones y bloques de sentencias tienen nombres. Es un símbolo que identifica una entidad, y se usa para nombrar variables, funciones, etiquetas y otros objetos definidos por el usuario.

    Normas de nomenclatura de identificadores en C:

    • 1. Los identificadores se componen de letras, dígitos y guiones bajos, y el primer carácter no puede ser un dígito.
    • 2. No se pueden usar las palabras clave de C como identificadores de usuario, por ejemplo: if, for, while, etc. (Nota: los identificadores no pueden ser iguales a las palabras clave de C, ni tener el mismo nombre que funciones definidas por el usuario o funciones de la biblioteca de C).
    • 3. La longitud de un identificador está determinada por el sistema de compilación de la máquina; generalmente está limitada a 8 caracteres. (Nota: el límite de 8 caracteres es del estándar C89; el estándar C99 ya ha ampliado la longitud; de hecho, la mayoría de los estándares industriales son más largos).
    • 4. Los identificadores distinguen entre mayúsculas y minúsculas, es decir, se diferencian estrictamente. Generalmente los nombres de variables se escriben en minúsculas y las constantes simbólicas en mayúsculas. (Nota: en C las letras distinguen mayúsculas de minúsculas, por lo que score, Score y SCORE representan tres identificadores diferentes).
    • 5. La nomenclatura de identificadores debe ser 'autodescriptiva' (ver el nombre y saber su significado), por ejemplo, longitud (en inglés: length), suma/total (en inglés: sum), pi (en inglés: pi).

    El lenguaje C tiene dos formas de comentarios:

    • (1) Con//el comentario de una sola línea que comienza con; este tipo de comentario puede ocupar una sola línea o aparecer a la derecha de otro contenido en la misma línea. Ten en cuenta que este comentario no puede abarcar varias líneas. Si el contenido del comentario no cabe en una línea, se puede volver a usar en la siguiente línea.//, continúa escribiendo el comentario.
    • (2) Con/*comienza, y con*/el comentario en bloque que termina con. Este tipo de comentario puede contener varias líneas. Cuando el sistema de compilación encuentra un/*después, comenzará a buscar el marcador de fin de comentario*/y tratará el contenido entre ambos como comentario.

    Debe tenerse en cuenta que ambos, dentro de las cadenas, no se tratan como inicio de comentario, sino como parte de la cadena. Por ejemplo:

    printf("//how do you do!\n");

或

printf("/*how do you do!*/\n");

    Las salidas son respectivamente://how do you do！和 /*how do you do!*/
