C Clases de almacenamiento

Las clases de almacenamiento definen la ubicación de almacenamiento, el ciclo de vida y el alcance de variables/funciones en un programa C.

Estos especificadores se colocan antes del tipo que modifican.

A continuación se enumeran las clases de almacenamiento disponibles en un programa C:

  • auto
  • register
  • static
  • extern

Clase de almacenamiento auto

autoLa clase de almacenamiento auto es la clase de almacenamiento predeterminada de todas las variables locales.

Las variables definidas en una función son por defecto de clase de almacenamiento auto, lo que significa que se crean al inicio de la función y se destruyen al final de la función.

{
   int mount;
   auto int month;
}

El ejemplo anterior define dos variables con la misma clase de almacenamiento. auto solo se puede usar dentro de una función, es decir, auto solo puede modificar variables locales.

Clase de almacenamiento register

registerLa clase de almacenamiento register se utiliza para definir variables locales que se almacenan en un registro en lugar de en la RAM. Esto significa que el tamaño máximo de la variable es igual al tamaño del registro (generalmente una palabra) y no se le puede aplicar el operador unario '&' (porque no tiene ubicación en memoria).

La clase de almacenamiento register define variables almacenadas en un registro, por lo que el acceso a la variable es más rápido, pero no se puede tomar su dirección directamente porque no está almacenada en la RAM. Usar la clase de almacenamiento register en variables que necesitan ser accedidas con frecuencia puede aumentar la velocidad de ejecución del programa.

{
   register int  miles;
}

Los registros se utilizan solo para variables que requieren acceso rápido, como contadores. También debe tenerse en cuenta que definir 'register' no significa que la variable se almacenará en un registro; significa que la variable puede almacenarse en un registro, dependiendo de las limitaciones del hardware y de la implementación.

Clase de almacenamiento static

staticLa clase de almacenamiento static indica al compilador mantener la existencia de una variable local durante todo el ciclo de vida del programa, sin necesidad de crearla y destruirla cada vez que entra y sale de su ámbito. Por lo tanto, usar static para modificar una variable local permite mantener su valor entre llamadas a funciones.

El modificador static también se puede aplicar a variables globales. Cuando static modifica una variable global, limita el alcance de la variable al archivo donde se declara.

Una variable o método static declarado globalmente puede ser llamado por cualquier función o método, siempre que estos métodos aparezcan en el mismo archivo que la variable o método static.

Las variables estáticas se inicializan solo una vez en el programa; incluso si la función se llama varias veces, el valor de la variable no se restablece.

El siguiente ejemplo demuestra la aplicación de static para modificar variables globales y locales:

Ejemplo

#include <stdio.h> /*Declaración de función*/ void func1(void); static int count=10; /*Variable global: static es el predeterminado*/ int main() { while (count--) { func1(); } return 0; } void func1(void) { /*'thingy' es una variable local de 'func1' - solo se inicializa una vez * El valor de 'thingy' no se restablece cada vez que se llama a la función 'func1'.*/ static int thingy=5; thingy++; printf("thingy es %d, count es %d\n", thingy, count); }

En el ejemplo, count como variable global se puede usar dentro de la función; thingy, al estar modificada con static, no se restablece en cada llamada.

Puede que aún no entienda este ejemplo, porque ya he utilizado funciones y variables globales, dos conceptos que hasta ahora no se han explicado. Aunque no lo comprenda completamente por ahora, no importa; en los capítulos siguientes lo explicaremos en detalle. Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

 thingy 为 6 ， count 为 9
 thingy 为 7 ， count 为 8
 thingy 为 8 ， count 为 7
 thingy 为 9 ， count 为 6
 thingy 为 10 ， count 为 5
 thingy 为 11 ， count 为 4
 thingy 为 12 ， count 为 3
 thingy 为 13 ， count 为 2
 thingy 为 14 ， count 为 1
 thingy 为 15 ， count 为 0

Clase de almacenamiento extern

externLa clase de almacenamiento extern se utiliza para definir variables globales o funciones declaradas en otros archivos. Cuando se usa la palabra clave extern, no se asigna ningún espacio de almacenamiento para la variable, sino que solo se indica al compilador que la variable está definida en otro archivo.

externLa clase de almacenamiento extern se utiliza para proporcionar una referencia a una variable global, que es visible para todos los archivos del programa. Cuando se usaexternpara variables que no se pueden inicializar, el nombre de la variable se apuntará a una ubicación de almacenamiento definida previamente.

Cuando tenga varios archivos y haya definido una variable global o función que pueda usarse en otros archivos, puede usar en los otros archivosexternpara obtener una referencia a la variable o función definida. Se puede entender de la siguiente manera:externSe utiliza para declarar una variable global o función en otro archivo.

El modificador extern se utiliza normalmente cuando dos o más archivos comparten la misma variable global o función, como se muestra a continuación:

Primer archivo: main.c

Ejemplo

#include <stdio.h> int count ; extern void write_extern(); int main() { count = 5; write_extern(); }

Segundo archivo: support.c

Ejemplo

#include <stdio.h> extern int count; void write_extern(void) { printf("count is %d\n", count); }

Aquí, en el segundo archivo, la palabra claveexternextern se utiliza para declarar la variable/función que ya está definida en el primer archivo main.c.countAhora, compile estos dos archivos, como se muestra a continuación:

 $ gcc main.c support.c

Esto produciráa.outun programa ejecutable. Cuando se ejecute el programa, producirá el siguiente resultado:

count is 5

    Diferencias entre variables globales, variables locales, variables globales estáticas y variables locales estáticas en C

    Desde el ámbito:

    1. Las variables globales tienen alcance global. Una variable global solo necesita definirse en un archivo fuente para poder actuar en todos los archivos fuente. Por supuesto, otros archivos fuente que no contienen la definición de la variable global necesitan usar la palabra clave extern para declarar esta variable global nuevamente.

    2. Las variables locales estáticas tienen alcance local. Se inicializan solo una vez y existen desde su primera inicialización hasta que el programa termina de ejecutarse. La diferencia con las variables globales es que las variables globales son visibles para todas las funciones, mientras que las variables locales estáticas solo son siempre visibles para el cuerpo de la función que las define.

    3. Las variables locales también tienen alcance local. Son objetos automáticos (auto). No existen durante toda la ejecución del programa, sino solo durante la ejecución de la función. Cuando finaliza una llamada a la función, la variable se destruye y la memoria que ocupaba se recupera.

    4. Las variables globales estáticas también tienen alcance global. La diferencia con las variables globales es que si el programa contiene varios archivos, la variable actúa únicamente en el archivo donde se define y no en otros archivos. Es decir, las variables modificadas por la palabra clave static tienen alcance de archivo. De esta manera, incluso si dos archivos fuente diferentes definen variables globales estáticas con el mismo nombre, son variables diferentes.

    En cuanto a la asignación de espacio de memoria:

    1. Las variables globales, las variables locales estáticas y las variables globales estáticas asignan espacio en el área de almacenamiento estático, mientras que las variables locales asignan espacio en la pila.

    2. Las variables globales en sí mismas son de almacenamiento estático; las variables globales estáticas, por supuesto, también son de almacenamiento estático. No hay diferencia entre ambas en cuanto a la forma de almacenamiento. La diferencia es que el alcance de las variables globales no estáticas es todo el programa fuente. Cuando un programa fuente está compuesto por múltiples archivos fuente, las variables globales no estáticas son válidas en cada archivo fuente. En cambio, las variables globales estáticas limitan su alcance, es decir, solo son válidas dentro del archivo fuente donde se define la variable, y no pueden usarse en otros archivos fuente del mismo programa. Debido a que el alcance de una variable global estática se limita a un archivo fuente y solo puede ser compartida por las funciones de ese archivo, se pueden evitar errores en otros archivos fuente.

    • 1) Las variables estáticas se colocan en el área de almacenamiento de datos estáticos del programa (visible globalmente), de modo que en la siguiente llamada aún pueden conservar el valor original asignado. Esta es la diferencia con las variables de pila y las variables de montón.
    • 2) Una variable usa static para informar al compilador que solo es visible dentro del ámbito de la variable. Esta es la diferencia con las variables globales.

    Del análisis anterior se puede ver que cambiar una variable local a variable estática altera su forma de almacenamiento, es decir, su tiempo de vida. Cambiar una variable global a estática altera su alcance y limita su rango de uso. Por lo tanto, el especificador static tiene diferentes efectos en diferentes lugares. Se debe prestar atención a esto.

    Tips:

    • A. Si una variable global solo se accede en un único archivo C, entonces esta variable se puede cambiar a variable global estática para reducir el acoplamiento entre módulos.
    • B. Si una variable global solo es accedida por una única función, entonces esta variable se puede cambiar a variable local estática de esa función para reducir el acoplamiento entre módulos.
    • C. Al diseñar y usar funciones que acceden a variables globales dinámicas, variables globales estáticas y variables locales estáticas, se debe considerar el problema de la reentrada, porque todas se colocan en el área de almacenamiento de datos estáticos y son globalmente visibles.
    • D. Si necesitamos una función reentrante, debemos evitar el uso de variables static en la función (tales funciones se denominan funciones con funcionalidad de 'memoria interna').
    • E. Casos en los que es necesario usar variables static en una función: por ejemplo, cuando el valor de retorno de una función es de tipo puntero, debe ser la dirección de una variable local static la que se devuelva. Si es de tipo auto, se devuelve un puntero incorrecto.

    auto: variable local de pila ordinariaes almacenamiento automático; este tipo de objeto se crea y destruye automáticamente. Se recomienda que esta variable se coloque en la pila, asignando memoria al llamar a la función y liberando memoria al finalizar la función. Generalmente, auto oculto se establece por defecto como categoría de almacenamiento automático. La mayoría de las variables de nuestros programas son variables automáticas.

    Ejemplo auto.c

    #include <stdio.h>

int main(void)
{
    auto int i = 9; /* 声明局部变量的关键字是 auto; 因可以省略, 几乎没人使用 */   
    printf("%d\n", i);  
    getchar();
    return 0;
}

    Variable RegisterLas variables dinámicas y estáticas se almacenan en la memoria. Cuando el programa encuentra ese valor, usa el controlador para enviar instrucciones y transferir el valor de la variable a la unidad aritmética; si necesita almacenar datos, los guarda de nuevo en la memoria. Si se usa una variable con frecuencia, por ejemplo, múltiples bucles dentro del cuerpo de una función que referencian la variable local cada vez, podemos colocar el valor de la variable local en el registro de la CPU, llamada variable de registro. No es necesario acceder a la memoria varias veces para almacenar y recuperar, lo que mejora la eficiencia. Sin embargo, solo las variables locales automáticas y los parámetros formales pueden ser variables de registro. Al llamar a la función, ocupan algunos registros y se liberan al finalizar la función. Los diferentes sistemas tienen diferentes requisitos para register, como restricciones en la cantidad de variables register definidas, tipos de datos, etc.; algunos las tratan por defecto como variables automáticas. Por lo tanto, generalmente no se usan en los programas.

    Ejemplo register.c

    #include <stdio.h>
#include <time.h>

#define TIME 1000000000
int m, n = TIME; /* 全局变量 */

int main(void)
{   
    time_t start, stop;
    register int a, b = TIME; /* 寄存器变量 */
    int x, y = TIME;          /* 一般变量   */

    time(&start);
    for (a = 0; a < b; a++);
    time(&stop);
    printf("寄存器变量用时: %ld 秒\n", stop - start);
    
    time(&start);
    for (x = 0; x < y; x++);
    time(&stop);
    printf("一般变量用时: %ld 秒\n", stop - start);
    
    time(&start);
    for (m = 0; m < n; m++);
    time(&stop);
    printf("全局变量用时: %ld 秒\n", stop - start);

    return 0;
}

    Resultado de salida:

    寄存器变量用时: 1 秒
一般变量用时: 8 秒
全局变量用时: 9 秒

    En el lenguaje C, static se puede usar para modificar variables locales, variables globales y funciones. En diferentes situaciones, el efecto de static no es el mismo.

    (1) Modificar variables locales

    En general, las variables locales se almacenan en el área de la pila, y su ciclo de vida termina cuando finaliza la ejecución del bloque de sentencias. Sin embargo, si se modifican con static, la variable se almacena en el área de datos estáticos y su ciclo de vida continúa hasta que finaliza la ejecución de todo el programa. Pero cabe señalar que, aunque después de modificar la variable local con static su ciclo de vida y espacio de almacenamiento han cambiado, su ámbito no ha cambiado; sigue siendo una variable local, y su ámbito se limita a ese bloque de sentencias.

    Después de modificar la variable local con static, la variable solo se inicializa en la primera ejecución, y solo se realiza una vez.

    Por ejemplo:

    #include<stdio.h>  
void fun()  
{   
    static int a=1; a++;   
    printf("%d\n",a);  
}  
int main(void)  
{   
    fun();   
    fun();   
    return 0;  
}

    El resultado de ejecución del programa es: 2 3

    Indica que cuando se llama a la función fun() por segunda vez, el valor de a es 2, y no se realiza la asignación de inicialización, sino que se ejecuta directamente la operación de incremento, por lo que el resultado es 3.

    Para las variables locales estáticas, si no se inicializan, para variables enteras el sistema les asigna automáticamente el valor 0; para arreglos de caracteres, les asigna automáticamente '\0'.

    (2) Modificar variables globales

    Para una variable global, se puede acceder a ella tanto en el archivo fuente actual como en otros archivos fuente del mismo proyecto (solo se necesita declararla con extern).

    Por ejemplo:

    //有file1.c  
int a=1;  
file2.c  
#include<stdio.h>  
extern int a;  
int main(void)  
{  
    printf("%d\",a);  
    return 0;  
}

    El resultado de ejecución es 1

    Pero si en file1.c se cambia int a=1 a static int a=1;

    Entonces en file2.c no se puede acceder a la variable a. La razón es que usar static para modificar la variable global cambia su ámbito: pasa de ser visible en todo el proyecto a ser visible solo en el archivo fuente actual.

    (3) Modificar funciones

    Si se usa static para modificar una función, la situación es similar a modificar una variable global; es decir, cambia el ámbito de la función.

    El uso de static

    Se usa para declarar variables estáticas. Si está dentro de una función, su efecto es similar al de una variable global. Sin embargo, las variables definidas con static solo se pueden usar en el archivo de programa C actual; en otro código C, incluso usando la palabra clave extern, no se puede acceder a esta variable static. Si se define dentro de una función, esta variable solo se inicializa una vez. Incluso si se vuelve a llamar a la función, esta variable static no se inicializará de nuevo; el valor de la variable se conservará siempre. Es decir, cuando vuelvas a llamar a la función y uses esta variable static, descubrirás que sigue siendo el resultado de la llamada anterior a la función.

    Ejemplo static.c:

    #include <stdio.h>

void varfunc(void)
{
    int var=0;
    static int static_var=0;
    printf("var equal: %d\n",var);
    printf("static_var equal: %d\n",static_var);
    printf("");
    var++;
    static_var++;
}

int main(int argc, char *argv[])
{
    int i;
    for(i=0;i<3;i++)
        varfunc();
    return 0;
}

    El resultado de ejecución es el siguiente:

    var equal: 0
static_var equal: 0
var equal: 0
static_var equal: 1
var equal: 0
static_var equal: 2

    Se puede ver que las variables locales modificadas con static solo se inicializan una vez.

    La diferencia entre variables globales estáticas y variables globales ordinarias:

    Anteponer static a la declaración de una variable global (variable externa) constituye una variable global estática.

    La diferencia entre ambas radica en que el ámbito de una variable global no estática es todo el programa fuente. Cuando un programa fuente se compone de múltiples archivos fuente, las variables globales no estáticas son válidas en todos los archivos fuente. En cambio, la variable global estática limita su ámbito, es decir, solo es válida dentro del archivo fuente donde se define la variable, y no se puede usar en otros archivos fuente del mismo programa fuente.
