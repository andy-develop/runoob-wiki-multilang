C Arreglos

El lenguaje C admitearreglosEstructura de datos que puede almacenar una colección secuencial de elementos del mismo tipo de tamaño fijo. Los arreglos se utilizan para almacenar una serie de datos, pero a menudo se consideran una serie de variables del mismo tipo.

Declarar un arreglo no es declarar variables individuales, como runoob0, runoob1, ..., runoob99, sino declarar una variable de tipo arreglo, como runoob, y luego usar runoob

Todos los arreglos están compuestos por ubicaciones de memoria contiguas. La dirección más baja corresponde al primer elemento, y la dirección más alta corresponde al último elemento.

Los elementos específicos de un arreglo se pueden acceder mediante un índice; el valor del primer índice es0。

El lenguaje C también nos permite usar punteros para manejar arreglos, lo que hace que las operaciones sobre arreglos sean más flexibles y eficientes.

Declaración de arreglos

En C, para declarar un arreglo, se necesita especificar el tipo de los elementos y la cantidad de elementos, como se muestra a continuación:

type arrayName [ arraySize ];

Esto se llama un arreglo unidimensional.arraySizeDebe ser una constante entera mayor que cero,typePuede ser cualquier tipo de dato C válido. Por ejemplo, para declarar un arreglo de tipo double que contenga 10 elementosbalance, la declaración es la siguiente:

double balance[10];

Ahorabalancees un arreglo utilizable que puede contener 10 números de tipo double.

Inicialización de arreglos

En C, puede inicializar un arreglo individualmente, o también puede usar una instrucción de inicialización, como se muestra a continuación:

double balance[5] = {1000.0, 2.0, 3.4, 7.0, 50.0};

El número de valores entre llaves { } no puede ser mayor que el número de elementos que especificamos entre corchetes [ ] al declarar el arreglo.

Si usted omite el tamaño del arreglo, el tamaño del arreglo será el número de elementos durante la inicialización. Por lo tanto, si:

double balance[] = {1000.0, 2.0, 3.4, 7.0, 50.0};

Usted creará un arreglo que es exactamente igual al arreglo creado en el ejemplo anterior. A continuación se muestra un ejemplo de asignar un valor a un elemento del arreglo:

balance[4] = 50.0;

La declaración anterior asigna el valor 50.0 al quinto elemento del arreglo. Todos los arreglos usan 0 como índice de su primer elemento, también conocido como índice base; el último índice de un arreglo es el tamaño total del arreglo menos 1. Los elementos de un arreglo se pueden acceder mediante el nombre del arreglo más un índice. El índice del elemento se coloca entre corchetes, después del nombre del arreglo. Por ejemplo:

double salary = balance[9];

La declaración anterior asignará el valor del décimo elemento del arreglo a la variable salary. El siguiente ejemplo utiliza los tres conceptos mencionados anteriormente, es decir, declarar un arreglo, asignar valores a un arreglo y acceder a un arreglo:

Nombre del arreglo

En C, el nombre del arreglo representa la dirección del arreglo, es decir, la dirección del primer elemento del arreglo. Cuando declaramos y definimos un arreglo, ese nombre de arreglo representa la dirección del arreglo.

Por ejemplo, en el siguiente código:

int myArray[5] = {10, 20, 30, 40, 50};

Aquí, myArray es el nombre del arreglo, que representa un arreglo de tipo entero que contiene 5 elementos. myArray también representa la dirección del arreglo, es decir, la dirección del primer elemento.

El nombre del arreglo en sí mismo es un puntero constante, lo que significa que su valor no se puede cambiar; una vez determinado, no puede apuntar a otro lugar.

Podemos usar el operador & para obtener la dirección del arreglo, como se muestra a continuación:

int myArray[5] = {10, 20, 30, 40, 50};
int *ptr = &myArray[0]; // 或者直接写作 int *ptr = myArray;

En el ejemplo anterior, la variable puntero ptr se inicializa con la dirección de myArray, es decir, la dirección del primer elemento del arreglo.

Es importante tener en cuenta que, aunque el nombre del arreglo representa la dirección del arreglo, en la mayoría de los casos el nombre del arreglo se convierte automáticamente en un puntero al primer elemento del arreglo. Esto significa que podemos usar directamente el nombre del arreglo en operaciones de puntero, por ejemplo, al pasar parámetros a una función o al recorrer un arreglo:

Ejemplo

void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]); // El nombre del arreglo arr se usa como puntero
    }
}

int main() {
    int myArray[5] = {10, 20, 30, 40, 50};
    printArray(myArray, 5); // Pasar el nombre del arreglo a la función
    return 0;
}

En el código anterior, la función printArray acepta un arreglo de enteros y el tamaño del arreglo como parámetros. Pasamos el nombre del arreglo myArray a la función, y dentro de la función se puede usar el nombre del arreglo arr como si fuera un puntero.

En C, los arreglos son muy importantes, y necesitamos conocer más detalles sobre ellos. A continuación se enumeran algunos conceptos importantes relacionados con los arreglos que los programadores de C deben tener claros:

ConceptoDescripción
Arreglos multidimensionalesC admite arreglos multidimensionales. La forma más simple de arreglo multidimensional es el arreglo bidimensional.
Pasar arreglos a funcionesPuede pasar a una función un puntero al arreglo especificando el nombre del arreglo sin índice.
Devolver un arreglo desde una funciónC permite devolver un arreglo desde una función.
Punteros a arreglosPuede generar un puntero al primer elemento del arreglo especificando el nombre del arreglo sin índice.
Arreglos estáticos y dinámicosLos arreglos estáticos se asignan en memoria en tiempo de compilación y su tamaño es fijo, mientras que los arreglos dinámicos se asignan manualmente en tiempo de ejecución y su tamaño es variable.

    int a=1;
int* p=&a;//&a是指针，int*类型，指向对象a，p是存储指针的变量，但在不混淆的情况下也可以把p叫做指针

    Acceder al objeto al que apunta un puntero mediante el operador * se llama desreferenciar:

    int b=*p;//获取指针指向对象a的值1，初始化b为1
*p=3;//修改指针指向对象a的值为3

    La mayoría de las expresiones lvalue de tipo array se convierten implícitamente a un puntero al primer elemento (también llamado decaimiento), el puntero convertido no es un lvalue. El nombre del array es el identificador del array, no es en sí un puntero. El operador de subíndice [ ] no es un operador de array, es un operador para punteros y enteros.

    。 
    int arr[4]={1,2,3,4};
int *p=arr;//arr隐适转换为首元素指针
int a=arr[1];//arr隐适转换为首元素指针
int (*arrp)[4]=&arr;//不转换成指针
int (*arrp)[4]=&(1,arr);//错误，逗号表达式返回最右侧的表达式的值，作为整个表达式的值，此时arr作为子表达式转换为了指针，不是左值，因此无法用于&运算符

    Los literales de cadena también son de tipo array, por lo que la mayoría también se convierten a puntero al primer elemento, excepto cuando se usan para inicializar un array de caracteres:

    char* cpointer="hello";//转换为首元素指针
char cArr[]="hello";//初始化char[]类型数组，不会隐适转换
