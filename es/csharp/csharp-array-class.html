C# Clase Array

Matrices en C#

La clase Array es la clase base de todas las matrices en C#. Se define en el espacio de nombres System. La clase Array proporciona varias propiedades y métodos para las matrices.

La clase Array en C# es la clase base de todas las matrices y se encuentra en el espacio de nombres System.

Una matriz es una colección que se utiliza para almacenar un número fijo de elementos del mismo tipo. Comprender las características y métodos de la clase Array es muy importante para escribir programas C# de manera eficiente.

A continuación se presenta una introducción detallada a la clase Array de C#, incluyendo sus características, métodos comunes, propiedades y ejemplos de uso.

Características

  • Seguridad de tipos: Las matrices solo pueden almacenar elementos del tipo especificado, y el tipo se determina en el momento de la declaración.
  • Longitud fija: La longitud de una matriz no se puede modificar después de su creación.
  • Acceso por índice: Los elementos de una matriz se acceden mediante un índice, que comienza desde 0.
  • Soporte multidimensional: C# admite matrices unidimensionales, multidimensionales y escalonadas (matrices de matrices).

Ejemplo

El siguiente programa demuestra el uso de algunos métodos de la clase Array:

Ejemplo

using System;
namespace ArrayApplication
{
    class MyArray
    {
       
        static void Main(string[] args)
        {
            int[] list = { 34, 72, 13, 44, 25, 30, 10 };

            Console.Write("Matriz original: ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();
           
            // Invertir la matriz
            Array.Reverse(list);
            Console.Write("Matriz invertida: ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();
           
            // Ordenar la matriz
            Array.Sort(list);
            Console.Write("Matriz ordenada: ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();

           Console.ReadKey();
        }
    }
}

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

原始数组： 34 72 13 44 25 30 10
逆转数组： 10 30 25 44 13 72 34
排序数组： 10 13 25 30 34 44 72

Ejemplos de métodos comunes

1. Array.Clear(Array, int index, int length)

Establece un rango de elementos de la matriz en su valor predeterminado del tipo correspondiente.

int[] arr = {1, 2, 3, 4, 5};
Array.Clear(arr, 1, 2); // arr = {1, 0, 0, 4, 5}

2. Array.Copy(Array sourceArray, Array destinationArray, int length)

Copia elementos de la matriz de origen a la matriz de destino.

int[] source = {1, 2, 3};
int[] destination = new int[3];
Array.Copy(source, destination, 3); // destination = {1, 2, 3}

3. Array.Clone()

Crea una copia superficial de la matriz.

int[] arr = {1, 2, 3};
int[] clonedArr = (int[])arr.Clone();

4. Array.IndexOf(Array array, object value)

Devuelve el índice de la primera aparición del elemento especificado en una matriz unidimensional.

int[] arr = {1, 2, 3, 2};
int index = Array.IndexOf(arr, 2); // index = 1

5. Array.LastIndexOf(Array array, object value)

Devuelve el índice de la última aparición del elemento especificado en una matriz unidimensional.

int[] arr = {1, 2, 3, 2};
int lastIndex = Array.LastIndexOf(arr, 2); // lastIndex = 3

6. Array.Reverse(Array array)

Invierte el orden de los elementos de una matriz unidimensional.

int[] arr = {1, 2, 3};
Array.Reverse(arr); // arr = {3, 2, 1}

7. Array.Sort(Array array)

Ordena los elementos de una matriz unidimensional en orden ascendente.

int[] arr = {3, 1, 2};
Array.Sort(arr); // arr = {1, 2, 3}

8. Array.BinarySearch(Array array, object value)

Busca un elemento en una matriz unidimensional ordenada y devuelve su índice.

int[] arr = {1, 2, 3, 4, 5};
int index = Array.BinarySearch(arr, 3); // index = 2

Nota:Antes de usar BinarySearch, la matriz debe estar ordenada.

9. Array.Resize(ref T[] array, int newSize)

Cambia el tamaño de una matriz unidimensional.

int[] arr = {1, 2, 3};
Array.Resize(ref arr, 5); // arr = {1, 2, 3, 0, 0}

10. Array.Exists<T>(T[] array, Predicate match)

Determina si existe algún elemento que cumpla la condición en la matriz.

int[] arr = {1, 2, 3};
bool exists = Array.Exists(arr, x => x == 2); // exists = true

11. Array.Find<T>(T[] array, Predicate match)

Buscar el primer elemento del array que cumpla la condición.

int[] arr = {1, 2, 3, 4};
int result = Array.Find(arr, x => x > 2); // result = 3

12. Array.FindAll<T>(T[] array, Predicate match)

Buscar todos los elementos del array que cumplan la condición.

int[] arr = {1, 2, 3, 4};
int[] results = Array.FindAll(arr, x => x > 2); // results = {3, 4}

13. Array.FindIndex<T>(T[] array, Predicate match)

Devolver el índice del primer elemento que cumpla la condición.

int[] arr = {1, 2, 3, 4};
int index = Array.FindIndex(arr, x => x > 2); // index = 2

14. Array.FindLast<T>(T[] array, Predicate match)

Buscar el último elemento que cumpla la condición.

int[] arr = {1, 2, 3, 4};
int result = Array.FindLast(arr, x => x > 2); // result = 4

15. Array.FindLastIndex<T>(T[] array, Predicate match)

Devolver el índice del último elemento que cumpla la condición.

int[] arr = {1, 2, 3, 4};
int index = Array.FindLastIndex(arr, x => x > 2); // index = 3

16. Array.TrueForAll<T>(T[] array, Predicate match)

Determinar si todos los elementos del array cumplen la condición.

int[] arr = {1, 2, 3};
bool allPositive = Array.TrueForAll(arr, x => x > 0); // allPositive = true

17. Array.ForEach<T>(T[] array, Action action)

Ejecutar la operación especificada en cada elemento del array.

int[] arr = {1, 2, 3};
Array.ForEach(arr, x => Console.WriteLine(x)); // 输出 1 2 3

18. Array.ConstrainedCopy(Array sourceArray, int sourceIndex, Array destinationArray, int destinationIndex, int length)

Copiar parte de los elementos de un array a otro y garantizar que, si la copia falla, no se produzcan daños en los datos.
int[] source = {1, 2, 3, 4, 5};
int[] destination = new int[5];
Array.ConstrainedCopy(source, 0, destination, 0, 5);

19. Array.Fill<T>(T[] array, T value)

Establecer todos los elementos del array al valor especificado.

int[] arr = new int[5];
Array.Fill(arr, 10); // arr = {10, 10, 10, 10, 10}

20. Array.AsReadOnly<T>(T[] array)

Devolver un envoltorio de solo lectura del array.

int[] arr = {1, 2, 3};
var readOnlyArr = Array.AsReadOnly(arr);
// readOnlyArr[0] = 5; // 编译错误，集合是只读的

Ejemplo

using System;

class Program
{
    static void Main()
    {
        // Crear e inicializar el array
        int[] numbers = {5, 2, 8, 1, 3};

        // Ordenar el array
        Array.Sort(numbers); // numbers = {1, 2, 3, 5, 8}

        // Buscar elementos
        int index = Array.BinarySearch(numbers, 5); // index = 3

        // Invertir el array
        Array.Reverse(numbers); // numbers = {8, 5, 3, 2, 1}

        // Comprobar si existe un elemento mayor que 6
        bool exists = Array.Exists(numbers, x => x > 6); // exists = true

        // Multiplicar los elementos del array por 2
        Array.ForEach(numbers, x => Console.WriteLine(x * 2));

        // Ajustar el tamaño del array
        Array.Resize(ref numbers, 7); // numbers = {8, 5, 3, 2, 1, 0, 0}

        // Rellenar nuevos elementos
        Array.Fill(numbers, 10, 5, 2); // Establecer los 2 elementos a partir del índice 5 en 10
        // numbers = {8, 5, 3, 2, 1, 10, 10}
    }
}
