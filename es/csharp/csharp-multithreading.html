C# Multihilo

HiloSe define como la ruta de ejecución de un programa. Cada hilo define un flujo de control único. Si su aplicación implica operaciones complejas y que consumen tiempo, a menudo es beneficioso configurar diferentes rutas de ejecución de hilos, cada hilo ejecuta un trabajo específico.

Un hilo es unproceso ligero. Un ejemplo común de uso de hilos es la implementación de programación paralela en los sistemas operativos modernos. El uso de hilos ahorra el desperdicio de ciclos de CPU y mejora la eficiencia de la aplicación.

Hasta ahora, los programas que hemos escrito son procesos únicos que se ejecutan como una instancia de ejecución de la aplicación con un solo hilo. Sin embargo, de esta manera la aplicación solo puede ejecutar una tarea a la vez. Para ejecutar varias tareas simultáneamente, puede dividirse en hilos más pequeños.

Ciclo de vida de un hilo

El ciclo de vida de un hilo comienza cuando se crea un objeto de la clase System.Threading.Thread y termina cuando el hilo se termina o completa su ejecución.

A continuación se enumeran los distintos estados del ciclo de vida de un hilo:

  • Estado no iniciado: Es la situación cuando se crea la instancia del hilo pero no se ha llamado al método Start.
  • Estado listo: Es la situación cuando el hilo está listo para ejecutarse y espera un ciclo de CPU.
  • Estado no ejecutable: El hilo no es ejecutable en las siguientes situaciones:
    • Se ha llamado al método Sleep
    • Se ha llamado al método Wait
    • Bloqueado por operaciones de E/S
  • Estado finalizado: Es la situación cuando el hilo ha completado su ejecución o ha sido abortado.

Hilo principal

En C#,System.Threading.Threadla clase se utiliza para el trabajo con hilos. Permite crear y acceder a hilos individuales en una aplicación multiproceso. El primer hilo que se ejecuta en un proceso se denominahilo principal。

Cuando un programa C# comienza a ejecutarse, el hilo principal se crea automáticamente. Los hilos creados con laThreadclase se denominan subprocesos del hilo principal. Puede utilizar laCurrentThreadpropiedad para acceder al hilo.

El siguiente programa demuestra la ejecución del hilo principal:

Ejemplo

using System;
using System.Threading;

namespace MultithreadingApplication
{
    class MainThreadProgram
    {
        static void Main(string[] args)
        {
            Thread th = Thread.CurrentThread;
            th.Name = "MainThread";
            Console.WriteLine("This is {0}", th.Name);
            Console.ReadKey();
        }
    }
}

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

This is MainThread

Crear hilos

Los hilos se crean extendiendo la clase Thread. La clase Thread extendida llama alStart()método para iniciar la ejecución del subproceso secundario.

El siguiente programa demuestra este concepto:

Ejemplo

using System;
using System.Threading;

namespace MultithreadingApplication
{
    class ThreadCreationProgram
    {
        public static void CallToChildThread()
        {
            Console.WriteLine("Child thread starts");
        }
       
        static void Main(string[] args)
        {
            ThreadStart childref = new ThreadStart(CallToChildThread);
            Console.WriteLine("In Main: Creating the Child thread");
            Thread childThread = new Thread(childref);
            childThread.Start();
            Console.ReadKey();
        }
    }
}

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

In Main: Creating the Child thread
Child thread starts

Gestionar hilos

La clase Thread proporciona varios métodos para gestionar hilos.

El siguiente ejemplo demuestra elsleep()uso del método, que se utiliza para suspender un hilo durante un tiempo específico.

Ejemplo

using System;
using System.Threading;

namespace MultithreadingApplication
{
    class ThreadCreationProgram
    {
        public static void CallToChildThread()
        {
            Console.WriteLine("Child thread starts");
            // El hilo se suspende durante 5000 milisegundos
            int sleepfor = 5000;
            Console.WriteLine("Child Thread Paused for {0} seconds",
                              sleepfor / 1000);
            Thread.Sleep(sleepfor);
            Console.WriteLine("Child thread resumes");
        }
       
        static void Main(string[] args)
        {
            ThreadStart childref = new ThreadStart(CallToChildThread);
            Console.WriteLine("In Main: Creating the Child thread");
            Thread childThread = new Thread(childref);
            childThread.Start();
            Console.ReadKey();
        }
    }
}

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

In Main: Creating the Child thread
Child thread starts
Child Thread Paused for 5 seconds
Child thread resumes

Destruir hilos

Abort()El método se utiliza para destruir hilos.

Al lanzar,threadabortexceptionse aborta el hilo en tiempo de ejecución. Esta excepción no puede capturarse; si hay unfinallybloque, el control se transfiere alfinallybloque.

El siguiente programa ilustra esto:

Ejemplo

using System;
using System.Threading;

namespace MultithreadingApplication
{
    class ThreadCreationProgram
    {
        public static void CallToChildThread()
        {
            try
            {

                Console.WriteLine("Child thread starts");
                // Cuenta hasta 10
                for (int counter = 0; counter <= 10; counter++)
                {
                    Thread.Sleep(500);
                    Console.WriteLine(counter);
                }
                Console.WriteLine("Child Thread Completed");

            }
            catch (ThreadAbortException e)
            {
                Console.WriteLine("Thread Abort Exception");
            }
            finally
            {
                Console.WriteLine("Couldn't catch the Thread Exception");
            }

        }
       
        static void Main(string[] args)
        {
            ThreadStart childref = new ThreadStart(CallToChildThread);
            Console.WriteLine("In Main: Creating the Child thread");
            Thread childThread = new Thread(childref);
            childThread.Start();
            // Detiene el hilo principal durante un tiempo
            Thread.Sleep(2000);
            // Ahora se aborta el subproceso secundario
            Console.WriteLine("In Main: Aborting the Child thread");
            childThread.Abort();
            Console.ReadKey();
        }
    }
}

    En C#, después de la versión 4.0, hay 3 formas de crear hilos:

    • 1. Thread: un hilo independiente creado por uno mismo, de alta prioridad, que el usuario debe gestionar por sí mismo.
    • 2. ThreadPool: es gestionado por el propio .Net. Solo necesitas escribir el método que se va a procesar y entregárselo a .Net Framework; después, en cuanto el método se ejecute por completo, sale automáticamente.
    • 3. Task: es un método de operación de hilos añadido después de la versión 4.0, similar a ThreadPool, pero en pruebas de eficiencia es ligeramente superior a ThreadPool. El soporte de Task para múltiples núcleos es más evidente, por lo que en procesadores multinúcleo, la ventaja de Task es más clara.
    class Program
{  
    static void Main(string[] args)
    {  //独立创建线程
        Thread t = new Thread(ThreadProcess);
        t.Start(new object());
        
        //线程池
        ThreadPool.QueueUserWorkItem(ThreadProcess, new object());
        //Task方式创建线程
        System.Threading.Tasks.Task.Factory.StartNew(ThreadProcess, new object());

        //需要手动终止,当然现在终止可能线程还未运行完成,
        t.Abort();
    }
    private static void ThreadProcess(object tag)
    {
        int i = 100;
        while (i > 0)
        {
            Console.WriteLine(string.Format("i:{0} ", i));
            Thread.Sleep(10);
            i--;
        }
    }
}
