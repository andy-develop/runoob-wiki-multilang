C# Matriz dinámica (ArrayList)

Colecciones de C#

ArrayList es una clase de matriz dinámica proporcionada en C#, ubicada en el espacio de nombres System.Collections.

La matriz dinámica (ArrayList) se diferencia de una matriz normal en que su tamaño se puede ajustar dinámicamente, sin necesidad de definir una longitud fija de antemano.

La matriz dinámica (ArrayList) representa una colección ordenada de objetos a los que se puede indexar individualmente; también permite asignación dinámica de memoria, adición, búsqueda y ordenación de elementos en la lista.

ArrayListEsta clase es adecuada para operaciones de matrices que requieren ajustes frecuentes de tamaño, pero debido a su naturaleza no genérica, en el desarrollo moderno de C# está siendo gradualmenteList<T>reemplazada.

Estructura básica

public class ArrayList : ICollection, IEnumerable, IList, ICloneable

Interfaces implementadas:

  • Interfaces implementadas：
    • IList: admite el acceso a elementos por índice.
    • ICollection: admite operaciones básicas de colección, como agregar, eliminar y contar.
    • IEnumerable: admite recorrer los elementos mediante un enumerador.
    • ICloneable: admite clonaciónArrayList。

Características

Expansión dinámica：

  • ArrayListLa capacidad de ArrayList se puede ajustar automáticamente según sea necesario, sin necesidad de especificar un tamaño fijo.
  • Cuando los elementos agregados exceden la capacidad actual,ArrayListla capacidad aumenta automáticamente (generalmente al doble de la capacidad original).

Colección no genérica：

  • ArrayListEs una colección no genérica, todos los elementos se almacenan comoobjecttipo object. Esto significa que puede almacenar objetos de cualquier tipo, pero hay que tener en cuenta el impacto en el rendimiento del boxing y unboxing.

Sin ordenar：

  • Aunque el orden de almacenamiento de los elementos coincide con el orden de inserción, no proporciona una función de ordenación incorporada.

Seguridad para subprocesos：

  • Por defecto no es seguro para subprocesos. Si se necesita un ArrayList seguro para subprocesos,ArrayList, se puede utilizarArrayList.Synchronizedel método para generar una versión segura para subprocesos.

Ejemplo

El siguiente ejemplo demuestra el concepto de la matriz dinámica (ArrayList):

Ejemplo

using System;
using System.Collections;

namespace CollectionApplication
{
    class Program
    {
        static void Main(string[] args)
        {
            // Crear la matriz dinámica e inicializarla
            ArrayList numbers = InitializeArrayList();

            // Mostrar la capacidad y el número de elementos de la matriz
            DisplayArrayListInfo(numbers);

            // Mostrar el contenido de la matriz
            Console.Write("Original Content: ");
            DisplayArrayListContent(numbers);

            // Ordenar el contenido de la matriz
            numbers.Sort();

            // Mostrar el contenido ordenado
            Console.Write("Sorted Content: ");
            DisplayArrayListContent(numbers);

            Console.ReadKey(); // Esperar a que el usuario presione una tecla para salir
        }

        /// <summary>
        /// Inicializa y llena el ArrayList
        /// </summary>
        /// <returns>ArrayList que contiene los datos iniciales</returns>
        static ArrayList InitializeArrayList()
        {
            ArrayList al = new ArrayList();
            Console.WriteLine("Adding numbers to the ArrayList:");
           
            // Agregar elementos iniciales
            int[] initialNumbers = { 45, 78, 33, 56, 12, 23, 9 };
            foreach (int num in initialNumbers)
            {
                al.Add(num);
                Console.WriteLine($"Added: {num}");
            }

            return al;
        }

        /// <summary>
        /// Muestra la capacidad y el número de elementos del ArrayList
        /// </summary>
        /// <param name="al">Objeto ArrayList</param>
        static void DisplayArrayListInfo(ArrayList al)
        {
            Console.WriteLine($"\nCapacity: {al.Capacity}"); // Capacidad actual
            Console.WriteLine($"Count: {al.Count}");         // Número actual de elementos
        }

        /// <summary>
        /// Muestra el contenido del ArrayList
        /// </summary>
        /// <param name="al">Objeto ArrayList</param>
        static void DisplayArrayListContent(ArrayList al)
        {
            foreach (int num in al)
            {
                Console.Write(num + " ");
            }
            Console.WriteLine(); // Nueva línea
        }
    }
}

Precauciones

Evitar el boxing y unboxing frecuentes：

  • Si los datos son principalmente tipos de valor, se recomienda usarList<T>para evitar la sobrecarga de rendimiento.

Usar con precaución datos de tipos mixtos：

  • Evite almacenar objetos de diferentes tipos mezclados para reducir el riesgo de errores en tiempo de ejecución.

Alternativas：

  • En el desarrollo moderno de C#, se recomienda utilizar colecciones genéricas (comoList<T>、Dictionary<TKey, TValue>) para mejorar la seguridad y eficiencia del código.

    Ordenación al almacenar diferentes tipos en ArrayList:

    using System;
using System.Collections;

namespace CollectionApp
{
    class MyComparer : IComparer
    {
        public int Compare(object x, object y)
        {
            // 自定义比较规则
            // 如果x,y都是int，那么按正常流程比较
            // 如果其中一个不是int，那么认为不是int的值小
            // 如果都不是int，那么认为他们相等
            if (x is int)
            {
                if (y is int)
                {
                    if ((int)x < (int)y) return -1;
                    if ((int)x == (int)y) return 0;
                    return 1;
                }
                return 1;
            }
            if (y is int) return -1;
                return 0;
        }
    }

    class Entry
    {
        static void Print(ArrayList l)
        {
            Console.WriteLine("\t大小能力：{0}   实际大小：{1}", l.Capacity, l.Count);
            Console.Write("\t内容：");
            foreach (object obj in l)
            Console.Write("{0} ", obj);
            Console.Write("\r\n");
        }
        static void Main()
        {
            ArrayList l = new ArrayList();
            Console.WriteLine("添加一些不都是Int的数据：");
            l.Add(22);
            l.Add(77);
            l.Add("abc");
            l.Add(33);
            Print(l);
            Console.WriteLine("排序：");
            l.Sort(new MyComparer());
            Print(l);
            Console.ReadKey();
        }
    }
}
