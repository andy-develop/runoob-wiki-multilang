C# Lista ordenada (SortedList)

Colecciones de C#

En C#, la lista ordenada (SortedList) es una colección que se ordena automáticamente por clave. Almacena datos en pares clave-valor y se ordena automáticamente según el orden de las claves (ascendente) al agregar o actualizar.

La clase SortedList representa una serie de pares ordenados por clavekey => valuepares; estos pares clave-valor se pueden acceder mediante la clave y el índice.

La lista ordenada es una combinación de una matriz y una tabla hash. Contiene una lista cuyos elementos se pueden acceder mediante clave o índice. Si accede a los elementos mediante índice, es una matriz dinámica (ArrayList); si accede mediante clave, es una tabla hash (Hashtable). Los elementos de la colección siempre se ordenan por valor de clave.

SortedList tiene dos versiones:

  1. No genéricaSortedList（System.Collections.SortedList）
  2. GenéricaSortedList<TKey, TValue>（System.Collections.Generic.SortedList<TKey, TValue>）

Características:

  • Orden automático: Todas las claves se ordenan de forma ascendente, sin necesidad de llamar manualmente a un método de ordenación.
  • Almacenamiento de pares clave-valor: Cada clave es única; los valores asociados pueden repetirse.
  • Ajuste dinámico de capacidad: Ajusta automáticamente el tamaño del almacenamiento interno según sea necesario.
  • Acceso por índice: Acceda a los datos mediante clave o índice.
  • Operaciones eficientes: La complejidad temporal promedio de búsqueda, inserción y eliminación es O(log n).

Ejemplo

El siguiente ejemplo demuestra el concepto de la lista ordenada (SortedList).

Operación de la versión no genérica:

Ejemplo

using System;
using System.Collections;

namespace CollectionsApplication
{
   class Program
   {
      static void Main(string[] args)
      {
         SortedList sl = new SortedList();

         sl.Add("001", "Zara Ali");
         sl.Add("002", "Abida Rehman");
         sl.Add("003", "Joe Holzner");
         sl.Add("004", "Mausam Benazir Nur");
         sl.Add("005", "M. Amlan");
         sl.Add("006", "M. Arif");
         sl.Add("007", "Ritesh Saikia");

         if (sl.ContainsValue("Nuha Ali"))
         {
            Console.WriteLine("This student name is already in the list");
         }
         else
         {
            sl.Add("008", "Nuha Ali");
         }

         // Obtener la colección de claves
         ICollection key = sl.Keys;

         foreach (string k in key)
         {
            Console.WriteLine(k + ": " + sl[k]);
         }
      }
   }
}

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

001: Zara Ali
002: Abida Rehman
003: Joe Holzner
004: Mausam Banazir Nur
005: M. Amlan 
006: M. Arif
007: Ritesh Saikia
008: Nuha Ali

Versión genérica:

Ejemplo

using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // Crear una SortedList genérica
        SortedList<int, string> sortedList = new SortedList<int, string>();

        // Agregar pares clave-valor
        sortedList.Add(2, "Banana");
        sortedList.Add(1, "Apple");
        sortedList.Add(3, "Cherry");

        // Ordenar automáticamente por clave
        Console.WriteLine("SortedList contents:");
        foreach (var kvp in sortedList)
        {
            Console.WriteLine($"Key: {kvp.Key}, Value: {kvp.Value}");
        }

        // Búsqueda y acceso
        Console.WriteLine($"\nValue for key 2: {sortedList[2]}"); // Salida: Banana

        // Eliminar elemento
        sortedList.Remove(1);
        Console.WriteLine("\nAfter removing key 1:");
        foreach (var kvp in sortedList)
        {
            Console.WriteLine($"Key: {kvp.Key}, Value: {kvp.Value}");
        }

        // Comprobar clave y valor
        Console.WriteLine($"\nContains key 3: {sortedList.ContainsKey(3)}"); // Salida: True
        Console.WriteLine($"Contains value 'Apple': {sortedList.ContainsValue("Apple")}"); // Salida: False
    }
}
