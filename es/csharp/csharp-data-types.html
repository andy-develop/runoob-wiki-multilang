C# Tipos de datos

En C#, las variables se dividen en los siguientes tipos:

  • Tipos de valor (Value types)
  • Tipos de referencia (Reference types)
  • Tipos puntero (Pointer types)

Tipos de valor (Value types)

Las variables de tipo de valor pueden asignarse directamente a un valor. Son de la claseSystem.ValueTypederivadas.

Los tipos de valor contienen datos directamente. Por ejemploint、char、float, almacenan números, caracteres y números de punto flotante, respectivamente. Cuando declara uninttipo, el sistema asigna memoria para almacenar el valor.

Tipos de referencia (Reference types)

Los tipos de referencia no contienen los datos reales almacenados en la variable, pero contienen referencias a las variables.

En otras palabras, se refieren a una ubicación de memoria. Cuando se usan múltiples variables, un tipo de referencia puede apuntar a una ubicación de memoria. Si los datos en la ubicación de memoria son modificados por una variable, las otras variables reflejarán automáticamente este cambio de valor.Los tipos de referenciaintegrados son:object、dynamic 和 string。

Tipo objeto (Object)

Tipo objeto (Object)es la clase base definitiva de todos los tipos de datos en el Sistema de Tipos Comunes (Common Type System - CTS) de C#. Object es un alias de la clase System.Object. Por lo tanto, el tipo objeto (Object) puede asignarse a valores de cualquier otro tipo (tipos de valor, tipos de referencia, tipos predefinidos o tipos definidos por el usuario). Sin embargo, antes de asignar un valor, se debe realizar una conversión de tipos.

Cuando un tipo de valor se convierte a un tipo objeto, se denominaboxing; por otro lado, cuando un tipo objeto se convierte a un tipo de valor, se denominaunboxing。

object obj;
obj = 100; // 这是装箱

Tipo dinámico (Dynamic)

Puede almacenar valores de cualquier tipo en variables de tipo de datos dinámico. La comprobación de tipos de estas variables ocurre en tiempo de ejecución.

Sintaxis para declarar un tipo dinámico:

dynamic <variable_name> = value;

Por ejemplo:

dynamic d = 20;

El tipo dinámico es similar al tipo objeto, pero la comprobación de tipos de las variables de tipo objeto ocurre en tiempo de compilación, mientras que la comprobación de tipos de las variables de tipo dinámico ocurre en tiempo de ejecución.

Tipo de cadena (String)

Tipo de cadena (String)Permite asignar cualquier valor de cadena a una variable. El tipo de cadena (String) es un alias de la clase System.String. Se deriva del tipo objeto (Object). Los valores del tipo de cadena (String) pueden asignarse de dos formas: comillas y @comillas.

Por ejemplo:

String str = "runoob.com";

Una cadena con @comillas:

@"runoob.com";

En C#, la cadena string puede ir precedida de @ (llamada "cadena textual" o "verbo string") para tratar los caracteres de escape (\) como caracteres ordinarios, por ejemplo:

string str = @"C:\Windows";

Equivale a:

string str = "C:\\Windows";

En las cadenas @, se pueden hacer saltos de línea arbitrarios; los caracteres de nueva línea y los espacios de sangría se cuentan dentro de la longitud de la cadena.

string str = @"<script type=""text/javascript"">
    <!--
    -->
</script>";

Los tipos de referencia definidos por el usuario son: class, interface o delegate. Discutiremos estos tipos en capítulos posteriores.

Tipo puntero (Pointer types)

Las variables de tipo puntero almacenan la dirección de memoria de otro tipo. Los punteros en C# tienen la misma funcionalidad que los punteros en C o C++.

Sintaxis para declarar un tipo puntero:

type* identifier;

Por ejemplo:

char* cptr;
int* iptr;

Discutiremos los tipos puntero en el capítulo "Código no seguro".

    Acerca de boxing y unboxing

    Boxing: convertir un tipo de valor a un tipo objeto. Ejemplo:

    int val = 8;
object obj = val;//整型数据转换为了对象类型（装箱）

    Unboxing: el tipo objeto, antes convertido desde un tipo de valor, se vuelve a convertir a un tipo de valor. Ejemplo:

    int val = 8;
object obj = val;//先装箱
int nval = （int）obj;//再拆箱

    Solo los datos que han pasado por boxing pueden pasar por unboxing.

    Diferencia entre String y string en C#

    string es una clase en C#, String es una clase de .NET Framework (no se muestra en azul en el IDE de C#). string en C# se asigna a String de .NET Framework. Si se usa string, el compilador lo compilará como String, por lo que si se usa String directamente, se puede ahorrar un poco de trabajo al compilador.

    Si se usa C#, se recomienda usar string, es más conforme a la norma. string siempre representa System.String (1.x) o ::System.String (2.0). String solo representa System.String cuando hay 'using System;' al frente y no hay ningún tipo llamado String (class, struct, delegate, enum) en el espacio de nombres actual. string es una palabra clave, String no lo es. Es decir, string no puede usarse como nombre de clase, estructura, enumeración, campo, variable, método o propiedad, mientras que String sí puede.

    String es el nombre del tipo en CLR (también se considera una palabra clave), mientras que string es una palabra clave en C#. En tiempo de compilación, el compilador de C# convierte string a String por defecto, lo que añade algunas líneas de código de conversión. En muchas ocasiones, se recomienda usar los tipos de CLR en lugar de los tipos de C# (esto es una recomendación de expertos). Por ejemplo: cuando se usa int, es mejor usar Int32, etc. Muchas veces es una cuestión de hábito o de normas. Otra diferencia es que los colores en VS son diferentes: String es verde, string es azul.

    Cada tipo de valor tiene un área de memoria independiente para guardar su propio valor; al invocarlo, se invoca su valor, mientras que un tipo de referencia invoca la dirección en memoria. Por ejemplo, se define el tipo de referencia a1=10; en este momento, lo que se guarda en memoria es 10. Cuando se asigna a1 a a2, ambos hacen referencia al mismo espacio de memoria, y el valor de a2 se guardará como el valor de a1. Cuando se cambia a2 a 20, como a1 y a2 hacen referencia a lo mismo, a1 también se convierte en 20. Esto es un tipo de referencia. En los tipos de valor, cuando se asigna a1 a a2, se abre un nuevo espacio para a2 y se guarda el valor de a1. Cuando se cambia a2 a 20, se guarda 20 en el espacio de a2, sin relación alguna con a1.

    Sobre la relación entre los tipos de valor, los tipos de referencia y la 'pila' y el 'montón'.

    Tipos de valor: al declarar un tipo de valor, se abre un espacio de memoria en la 'pila' para almacenar el valor correspondiente. Cuando el valor del tipo de valor cambia, se modifica directamente el valor guardado en ese espacio de memoria. Ejemplo:

    int n1 = 5;
int n2 = n1;
Console.WriteLine(n1 + "  "+ n2);    // 5  5
n2 = 7;
Console.WriteLine(n1 + "  " + n2)    // 5  7

    Aquí primero se abre un espacio de memoria en la 'pila' para guardar el valor 5 de n1; luego se abre un nuevo espacio de memoria en la 'pila' para guardar el valor 5 de n2, por lo que el resultado mostrado es 5 5. Después se modifica el valor guardado en el espacio de memoria correspondiente a n2 en la 'pila' a 7, por lo que el resultado mostrado es 5 7.

    Tipos de referencia: al declarar un tipo de referencia, primero se abre un espacio de memoria en el 'montón' para almacenar el valor correspondiente, y luego se abre un espacio de memoria en la 'pila' para guardar la dirección del espacio de memoria abierto en el 'montón'. Cuando el sistema llama a un tipo de referencia, primero obtiene la dirección de la 'pila' y, a continuación, según la dirección, encuentra el espacio de memoria correspondiente en el 'montón' para obtener el valor correspondiente. Por ejemplo,los arraysson un tipo de referencia.

    string[] a1 = new string[]{ "a" , "b" , "c" };
string[] a2 = a1;
for(int i = 0; i < a2.Length; i++)
{
    Console.Write(a2[i] + " ");    //a b c
}
a1[2] = "d";
Console.WriteLine();            //换行
for(int i = 0; i < a2.Length; i++)
{
    Console.Write(a2[i] + " ");    //a b d
}
Console.WriteLine();

    Aquí primero se abre un espacio de memoria en el 'montón' (supongamos: 0X55) para guardar los valores del array a1, y luego se abre un espacio de memoria en la 'pila' (a1) para guardar la dirección 0X55. Cuando se asigna a1 a a2, se asigna la dirección a a2, es decir, se abre un espacio de memoria en la 'pila' (a2) para guardar la dirección 0X55, por lo que el valor de a2 que se muestra es a b c. Cuando se modifica a1

    Mientras que string es un tipo de referencia especial. Veamos primero el siguiente código:

    string a = "123";
string b = a; 
Console.WriteLine(a+" "+b);  //123 123
string b = "456";
Console.WriteLine(a+" "+b);  //123 456

    De manera similar a los arrays, aquí primero se abre un espacio de memoria en el 'montón' (supongamos: 0X88) para guardar el valor 123 de a, y luego se abre un espacio de memoria en la 'pila' (a) para guardar la dirección 0X88.

    A diferencia de los arrays, cuando se asigna a a b, primero se abre un nuevo espacio de memoria en el 'montón' (supongamos: 0X101) para guardar el valor 123, y luego se abre un espacio de memoria en la 'pila' (b) para guardar la dirección 0X101, por lo que el resultado mostrado es 123 123.

    Cuando se modifica el valor de b, no se modifica el valor del espacio de memoria 0X101 en el 'montón', sino que se abre un nuevo espacio de memoria en el 'montón' (supongamos: 0X210) para guardar el valor modificado de b, y luego se cambia la dirección guardada en el espacio de memoria correspondiente a b en la 'pila' a 0X210, por lo que el resultado mostrado es 123 456. El espacio de memoria 0X101 en el 'montón' será reclamado y reutilizado en la próxima recolección de basura.

    Diferencias entre los tipos de valor y los tipos de referencia:

    Desde el punto de vista de la memoria, los tipos de valor operan en la pila, mientras que los tipos de referencia operan en el montón.

    (Consecuencia => los tipos de valor tienen una velocidad de acceso rápida, y los tipos de referencia una velocidad de acceso lenta.)

    En esencia, los tipos de valor representan los datos reales, mientras que los tipos de referencia representan un puntero o referencia que apunta a los datos almacenados en el montón de memoria.

    (El tipo de valor es el tamaño del espacio que ocupa el valor concreto, mientras que el tipo de referencia es la dirección del espacio que almacena ese valor.)

    En cuanto a su origen, los tipos de valor heredan de System.ValueType, y los tipos de referencia heredan de System.Object.

    En particular: las estructuras son tipos de valor, y las clases y string son tipos de referencia.

    Cuando un tipo de valor se convierte en tipo objeto, se denominaboxing; por otro lado, cuando un tipo objeto se convierte en tipo de valor, se denominaunboxing。

    El tipo dinámico es similar al tipo objeto, pero la comprobación de tipos de las variables de tipo objeto se realiza en tiempo de compilación, mientras que la comprobación de tipos de las variables de tipo dinámico se realiza en tiempo de ejecución.
