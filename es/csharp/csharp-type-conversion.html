C# Conversión de tipos

En C#, la conversión de tipos es el proceso de convertir el valor de un tipo de datos a otro tipo de datos.

La conversión de tipos en C# se puede dividir en dos tipos:Conversión implícita de tipos和Conversión explícita de tipos(también llamada conversión forzada).

Conversión implícita de tipos

La conversión implícita es una conversión que no requiere escribir código para especificarla; el compilador la realiza automáticamente.

La conversión implícita se refiere a que cuando se convierte un tipo de datos de rango menor a un tipo de datos de rango mayor, el compilador completa automáticamente la conversión de tipos. Estas conversiones son las que C# realiza de forma segura por defecto y no causan pérdida de datos.

Por ejemplo, de int a long, de float a double, etc.

De un tipo entero pequeño a un tipo entero grande, de una clase derivada a una clase base. Si se asigna una variable de tipo byte a una variable de tipo int, el compilador convertirá automáticamente el tipo byte a tipo int, sin necesidad de conversión explícita.

Ejemplo

byte b = 10;
int i = b; // Conversión implícita, no necesita conversión explícita

Asignar un entero a un entero largo, o asignar un número de punto flotante a un número de punto flotante de doble precisión; esta conversión no causa pérdida de datos:

Ejemplo

int intValue = 42;
long longValue = intValue; // Conversión implícita, de int a long

Conversión explícita

La conversión explícita de tipos, es decir, la conversión forzada de tipos, requiere que el programador la especifique claramente en el código.

La conversión explícita se refiere a que cuando se convierte un tipo de datos de rango mayor a un tipo de datos de rango menor, o cuando se convierte un tipo de objeto a otro tipo de objeto, es necesario utilizar el símbolo de conversión forzada para realizar la conversión explícita. La conversión forzada puede causar pérdida de datos.

Por ejemplo, asignar una variable de tipo int a una variable de tipo byte requiere conversión explícita.

Ejemplo

int i = 10;
byte b = (byte)i; // Conversión explícita, se necesita usar el símbolo de conversión forzada

Conversión forzada a tipo entero:

Ejemplo

double doubleValue = 3.14;
int intValue = (int)doubleValue; // Forzar de double a int, los datos pueden perder la parte decimal

Conversión forzada a tipo de punto flotante:

Ejemplo

int intValue = 42;
float floatValue = (float)intValue; // Forzar de int a float, los datos pueden perder precisión

Conversión forzada a tipo cadena:

Ejemplo

int intValue = 123;
string stringValue = intValue.ToString(); // Convertir int a cadena

El siguiente ejemplo muestra una conversión de tipos explícita:

Ejemplo

using System;

namespace TypeConversionApplication
{
    class ExplicitConversion
    {
        static void Main(string[] args)
        {
            double d = 5673.74;
            int i;

            // Convertir forzosamente double a int
            i = (int)d;
            Console.WriteLine(i);
            Console.ReadKey();
           
        }
    }
}

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

5673

Al realizar conversiones de tipos, se deben tener en cuenta los siguientes puntos:

  • La conversión implícita solo puede convertir tipos de datos de rango menor a tipos de datos de rango mayor; no puede convertir tipos de datos de rango mayor a tipos de datos de rango menor.
  • La conversión explícita puede causar pérdida de datos o reducción de precisión, por lo que es necesario verificar la compatibilidad de los tipos de datos.
  • Para la conversión de tipos de objeto, es necesario realizar la verificación de compatibilidad de la conversión de tipos y la verificación de seguridad de la conversión de tipos.

Métodos de conversión de tipos

C# proporciona varios métodos de conversión de tipos, como la clase Convert, el método Parse y el método TryParse. Estos métodos ayudan a manejar la conversión entre diferentes tipos de datos.

Usando la clase Convert

La clase Convert proporciona un conjunto de métodos estáticos que pueden realizar conversiones entre varios tipos de datos básicos.

Ejemplo

string str = "123";
int num = Convert.ToInt32(str);

Usando el método Parse

El método Parse se utiliza para convertir una cadena al tipo numérico correspondiente; si la conversión falla, se lanza una excepción.

Ejemplo

string str = "123.45";
double d = double.Parse(str);

Usando el método TryParse

El método TryParse es similar a Parse, pero no lanza excepciones; en su lugar, devuelve un valor booleano que indica si la conversión fue exitosa.

Ejemplo

string str = "123.45";
double d;
bool success = double.TryParse(str, out d);

if (success) {
    Console.WriteLine("Conversión exitosa: " + d);
} else {
    Console.WriteLine("Conversión fallida");
}

Conversión de tipos personalizada

C# también le permite definir operaciones de conversión de tipos personalizadas, definiendo las palabras clave implicit o explicit en el tipo.

Ejemplo

using System;

public class Fahrenheit
{
    public double Degrees { get; set; }

    public Fahrenheit(double degrees)
    {
        Degrees = degrees;
    }

    // Conversión implícita de Fahrenheit a double
    public static implicit operator double(Fahrenheit f)
    {
        return f.Degrees;
    }

    // Conversión explícita de double a Fahrenheit
    public static explicit operator Fahrenheit(double d)
    {
        return new Fahrenheit(d);
    }
}

public class Program
{
    public static void Main()
    {
        Fahrenheit f = new Fahrenheit(98.6);
        Console.WriteLine("Fahrenheit object: " + f.Degrees + " degrees");

        double temp = f; // Conversión implícita
        Console.WriteLine("After implicit conversion to double: " + temp + " degrees");

        Fahrenheit newF = (Fahrenheit)temp; // Conversión explícita
        Console.WriteLine("After explicit conversion back to Fahrenheit: " + newF.Degrees + " degrees");
    }
}

En el ejemplo anterior, definimos una clase Fahrenheit e implementamos la conversión implícita de Fahrenheit a double y la conversión explícita de double a Fahrenheit.

El resultado de salida se mostrará de la siguiente manera:

Fahrenheit object: 98.6 degrees
After implicit conversion to double: 98.6 degrees
After explicit conversion back to Fahrenheit: 98.6 degrees

Resumen

En C#, los métodos integrados de conversión de tipos se implementan principalmente de las siguientes maneras: conversión implícita, conversión explícita (conversión forzada), métodos de la clase Convert, método Parse y método TryParse. Estos métodos se aplican ampliamente en la conversión entre diferentes tipos de datos.

    Conversión implícita: la conversión que C# realiza de forma predeterminada de manera segura. En esencia, convierte automáticamente tipos de datos de menor capacidad de almacenamiento a tipos de datos de mayor capacidad, y de una clase derivada a una clase base.

    Diferencia entre Convert.ToInt32() y int.Parse()

    No está claroConvert.ToInt32 和 int.Parse()Cuando no se tengan claras las sutiles diferencias, no los uses a la ligera; de lo contrario, pueden producirse resultados impredecibles. Por ejemplo: si se toma el valor de un parámetro page de la url, sabemos que este valor es un int, por lo que se puede usar tantoConvert.ToInt32(Request.QueryString["page"]), también se puede usarint.Parse(Request.QueryString["page"]), pero si el parámetro page no existe en la url, el primero devolverá 0; 0 puede ser un valor válido, por lo que no sabes que el parámetro no estaba originalmente en la url y continúas con el siguiente paso, lo que puede producir efectos inesperados. Por el contrario, con el segundo método, si no existe el parámetro page, se lanzará una excepción; podemos capturarla y luego realizar el manejo correspondiente, como indicar al usuario que falta el parámetro, en lugar de tratar el valor del parámetro como 0.

    (1) La mayor diferencia entre estos dos métodos es la forma en que manejan el valor null:Convert.ToInt32(null)devolverá 0 sin generar ninguna excepción, peroint.Parse(null)sí generará una excepción.

    (2) Diferencia al redondear datos:

    • a.Convert.ToInt32(double value): si value es un número justo entre dos enteros, devuelve el número par de los dos; es decir, 3.5 se convierte en 4, 4.5 en 4, y 5.5 en 6. Sin embargo, 4.6 se puede convertir en 5 y 4.4 en 4.
    • b.int.Parse("4.5") da un error directamente:"El formato de la cadena de entrada no es correcto."。
    • c.int(4.6) = 4. Cuando Int convierte otros tipos numéricos a Int, no hay redondeo; es una conversión forzada.

    (3) Diferencia en cuanto a los tipos a convertir:int.Parsees convertir String a int,Convert.ToInt32es convertir objetos que heredan de Object a int (puede haber muchos otros tipos de datos). Tienes un objeto object, quieres convertirlo a int, usarint.Parseentonces no es posible; hay que usarConvert.ToInt32。

    Breve análisis sobre la conversión de string a int y el lanzamiento de excepciones

    El tipo de cadena string y int también se pueden convertir. El código de la siguiente línea muestra un método de conversión incorrecto.

    string a = "123";  // 将a设置为字符串“123”
int x = (int) a;   // 转换

    El código anterior, sin duda, es incorrecto. VS no puede pasar la compilación. Entonces, ¿cómo se convierte string a int?

    Aquí necesitamos usar int.Parse(); el código clave es:

    string a = "123";     // 将a设置为字符串“123”
int x = int.Parse(a); // 转换

    Si solo fuera así, no habría problema, pero hagamos un ejemplo a continuación.

    El usuario ingresa un número, y la computadora calculará la respuesta de este número más 1 y la mostrará.

    Lo que ingresa el usuario, es decir,Console.ReadLine(), siempre se presenta en forma de cadena.

    Por lo tanto, usando el método anterior, podemos escribir el siguiente código:

    class 测试
{
    static void Main(string[] args)
    {
        Console.WriteLine("输入数字，将计算出它加一的答案");
        int a = int.Parse(Console.ReadLine());  //转换用户输入的数字
        Console.WriteLine("答案是{0}",++a);     //++a 即 a+1 后的那个数，将它输出出来
        Console.ReadKey();
    }
}

    Cuando el programa se ejecuta, aparece:

    输入数字，将计算出它加一的答案
3
答案是4

    ¿Es perfecto así? ¡¡No!!

    ¿Qué sucede si el usuario ingresa otros caracteres que no son números, como caracteres chinos?

    En este momento, el usuario ingresa王, obviamente, el programa no podrá continuar ejecutándose, porque el tipo int solo puede almacenar enteros, no caracteres.

    En este punto, el programa lanzará una excepción.

    Si se compila con VS, también verás el tipo de excepción: FormatException.

    Por lo tanto, para estar seguros, se puede usar try y catch para resolver este problema. El código clave es:

    try
{
               
}
catch (Exception)
{
                
}

    try en inglés significa intentar. En este código, la parte try{} consiste, como su nombre indica, en intentar ejecutar el código siguiente. La parte catch{} es para detectar excepciones. Así, cuando ocurre una excepción, catch puede capturarla y el programa no se detiene.

    Entonces, el código completo de este programa debería ser:

    using System;
class 测试
{
    static void Main(string[] args)
    {
        try
        {
           Console.WriteLine("输入数字，将计算出它加一的答案");
           int a = int.Parse(Console.ReadLine());   //有可能会抛出异常
           Console.WriteLine("答案是{0}",++a);   //如果没有异常，程序才会进入这一步
        }
        catch (Exception)
        {
            Console.WriteLine("无法转换");  //如果捕获到异常，就说“无法转换”
        }
         Console.ReadKey();
    }
}

    1）Para el objeto de conversión, Convert.ToInt32() puede funcionar con varios tipos (además de los tipos numéricos, bool, DateTime, etc.), int.TryParse() e int.Parse() solo pueden ser tipos de cadena de enteros (es decir, la forma después de ToString() de varios enteros, no pueden ser de punto flotante, de lo contrario int.Parse() arrojaría el error de que el formato de la cadena de entrada es incorrecto, int.TryParse() también devolvería false, y el parámetro de salida sería 0; (int) solo puede ser de tipos numéricos (por ejemplo, float, int, uint, etc.).

    2）Para el valor NULL, desde la perspectiva de errores en tiempo de ejecución, tanto (int) como int.Parse() no pueden aceptar NULL; Convert.ToInt32() en realidad primero hace una comprobación antes de la conversión: si el parámetro es NULL, devuelve 0 directamente; de lo contrario, llama a int.Parse() para convertir. int.TryParse() en realidad maneja excepciones de int.Parse(): si ocurre una excepción, devuelve false y establece el parámetro de salida en 0.

    3）En cuanto a la selección de punto flotante: solo Convert.ToInt32() y (int) pueden convertir tipos de punto flotante, pero también realizan un redondeo/truncamiento. Convert.ToInt32() utiliza redondeo (四舍五入), mientras que (int) trunca la parte entera del tipo de punto flotante e ignora la parte decimal. Por ejemplo, Convert.ToInt32(1.499d) y (int)1.499d devuelven ambos 1; Convert.ToInt32(1.5d) devuelve 2, mientras que (int)1.5d sigue devolviendo 1.

    4）Sobre el desbordamiento: al convertir un tipo de datos grande a un tipo de datos pequeño, Convert.ToInt32() e int.Parse() arrojan un error de desbordamiento, el valor es demasiado grande o demasiado pequeño para Int32; en cambio, (int) no arroja error, pero devuelve -1.

    Así se ve que debemos elegir cuidadosamente el método de conversión antes de realizar la conversión de datos. Si es un tipo numérico, se puede considerar usar directamente la conversión forzada (int); si es un tipo de cadena de enteros, considera usar int.Parse() para convertir; si no es ninguno de estos dos tipos, entonces considera usar Convert.ToInt32() para convertir.
