Uso de jQuery.widget( name [, base ], prototype )

Descripción:Cree complementos (plugins) de jQuery con estado utilizando la misma abstracción que todos los widgets de jQuery UI.

jQuery.widget( name [, base ], prototype )

Parámetros Tipo Tipo
name String El nombre del widget a crear, incluido el espacio de nombres.
base Function() El widget base a heredar. Debe ser un constructor que pueda instanciarse con la palabra clave `new`. El valor predeterminado es jQuery.Widget.
prototype PlainObject El objeto que se utilizará como prototipo del widget.

Puede usar$.Widgetel objeto como base para heredar, o puede crear explícitamente un nuevo widget desde cero basándose en un widget existente de jQuery UI o de terceros. Definir un widget con el mismo nombre para heredar del widget base incluso le permite extender el widget de manera adecuada.

jQuery UI incluye muchos widgets que mantienen estado, por lo que tienen un patrón de uso ligeramente diferente al de los complementos típicos de jQuery. Todos los widgets de jQuery UI utilizan el mismo patrón, definido por el Widget Factory. Por lo tanto, si aprende a usar uno, sabrá cómo usar los demás widgets.

Nota: este capítulo utilizael widget de barra de progreso (Progressbar Widget)como ejemplo de demostración, pero la sintaxis se aplica a todos los widgets.

Inicialización

Para rastrear el estado del widget, debemos presentar el ciclo de vida completo del widget. El ciclo de vida comienza cuando se inicializa el widget. Para inicializar un widget, simplemente llamamos al complemento en uno o más elementos.

$( "#elem" ).progressbar();

Esto inicializará cada elemento del objeto jQuery. En el ejemplo anterior, el elemento con id"elem"。

Opciones

Debido a queprogressbar()al llamarse sin argumentos, el widget se inicializa con las opciones predeterminadas. Podemos pasar un conjunto de opciones en la inicialización para sobrescribir las predeterminadas:

$( "#elem" ).progressbar({ value: 20 });

Podemos pasar tantas opciones como necesitemos; cualquier opción que no pasemos utilizará su valor predeterminado.

Puede pasar múltiples argumentos de opciones, que se fusionarán en un solo objeto (similar a$.extend( true, target, object1, objectN )). Esto es útil para sobrescribir algunas configuraciones para todas las instancias y compartir opciones entre instancias:

var options = { modal: true, show: "slow" };
$( "#dialog1" ).dialog( options );
$( "#dialog2" ).dialog( options, { autoOpen: false });

Todas las opciones pasadas en la inicialización son copias profundas, lo que garantiza que los objetos puedan modificarse posteriormente sin afectar al widget. La única excepción son los arreglos, que se referencian tal cual. Esta excepción existe para admitir adecuadamente el enlace de datos, donde la fuente de datos debe pasarse por referencia.

Los valores predeterminados se almacenan en las propiedades del widget, por lo que podemos sobrescribir los valores establecidos por jQuery UI. Por ejemplo, después de la siguiente configuración, todas las futuras instancias de la barra de progreso tendrán como valor predeterminado 80:

$.ui.progressbar.prototype.options.value = 80;

Las opciones son una parte integral del estado del widget, por lo que también podemos establecer opciones después de la inicialización. Veremos el método `option` más adelante.

Métodos

Ahora que el widget está inicializado, podemos consultar su estado o realizar acciones en él. Todas las acciones posteriores a la inicialización se ejecutan como llamadas a métodos. Para llamar a un método en un widget, pasamos el nombre del método al complemento de jQuery. Por ejemplo, para llamar al métodovalue(), podemos utilizar:

$( "#elem" ).progressbar( "value" );

Si el método acepta parámetros, podemos pasarlos después del nombre del método. Por ejemplo, para pasar el parámetro40 到 value()al método, podemos usar:

$( "#elem" ).progressbar( "value", 40 );

Al igual que otros métodos en jQuery, la mayoría de los métodos de widget devuelven un objeto jQuery:

$( "#elem" )
  .progressbar( "value", 90 )
  .addClass( "almost-done" );

Cada widget tiene su propio conjunto de métodos, basado en la funcionalidad que proporciona. Sin embargo, hay algunos métodos que existen en todos los widgets, como se detalla a continuación.

Eventos

Todos los widgets tienen eventos asociados con sus diversos comportamientos para notificarle cuando cambia el estado. En la mayoría de los widgets, cuando se dispara un evento, el nombre lleva como prefijo el nombre del widget en minúsculas. Por ejemplo, podemos vincular el eventochangede la barra de progreso, que se dispara cuando cambia el valor.

$( "#elem" ).bind( "progressbarchange", function() {
  alert( "The value has changed!" );
});

Cada evento tiene una devolución de llamada (callback) correspondiente, que se expone como una opción. Si es necesario, podemos usar la devolución de llamadachangede la barra de progreso en lugar de vincular el eventoprogressbarchange.

$( "#elem" ).progressbar({
  change: function() {
    alert( "The value has changed!" );
  }
});

Todos los widgets tienen un eventochangeque se dispara en el momento de la instanciación.

Instanciación

La instancia del widget se almacena usando la clave con el nombre completo del widget enjQuery.data(). Por lo tanto, puede usar el siguiente código para recuperar el objeto de instancia del widget de barra de progreso desde el elemento.

$( "#elem" ).data( "ui-progressbar" );

Para saber si un elemento tiene vinculado un widget determinado, puede usar:datael selector para comprobarlo.

$( "#elem" ).is( ":data( 'ui-progressbar' )" ); // true
$( "#elem" ).is( ":data( 'ui-draggable' )" ); // false

También puede usar:datapara obtener una lista de todos los elementos que son instancias de un widget determinado.

$( ":data( 'ui-progressbar' )" );

Propiedades

Todos los widgets tienen las siguientes propiedades:

  • defaultElement: el elemento que se utilizará cuando no se proporcione un elemento al construir la instancia del widget. Por ejemplo, como eldefaultElement 是 "<div>"，$.ui.progressbar({ value: 50 })de la barra de progreso se instancia en un nuevo<div>, se crea una instancia del widget de barra de progreso sobre él.
  • document: el documento que contiene el elemento del widget.documentÚtil si necesita interactuar con el widget dentro de un marco (iframe).
  • element: un objeto jQuery que contiene el elemento utilizado para instanciar el widget. Si selecciona varios elementos y llama a.myWidget(), se creará una instancia de widget separada para cada elemento. Por lo tanto, esta propiedad siempre contiene un elemento.
  • namespace: la ubicación global del objeto jQuery donde se almacena el prototipo del widget. Por ejemplo,"ui" 的 namespaceindica que el prototipo del widget se almacena en$.ui。
  • options: un objeto que contiene las opciones actuales del widget. Durante la instanciación, cualquier opción proporcionada por el usuario se fusiona automáticamente con$.myNamespace.myWidget.prototype.optionslos valores predeterminados definidos en . Las opciones especificadas por el usuario sobrescriben los valores predeterminados.
  • uuid: un entero único que representa el identificador del control.
  • version: la versión de cadena del widget. Para los widgets de jQuery UI, esta propiedad se establece con la versión de jQuery UI que utiliza el widget. Los desarrolladores de complementos deben establecer esta propiedad explícitamente en sus prototipos.
  • widgetEventPrefix: el prefijo que se agrega a los nombres de los eventos del widget. Por ejemplo,el widget arrastrable (Draggable Widget) 的 widgetEventPrefix 是 "drag", por lo que al crear un draggable, el nombre del evento es"dragcreate". De manera predeterminada, elwidgetEventPrefixdel widget es su nombre.Nota: esta propiedad está en desuso y se eliminará en versiones futuras. Los nombres de eventos se cambiarán a widgetName:eventName (por ejemplo,"draggable:create"）。
  • widgetFullName: el nombre completo del widget, incluido el espacio de nombres. Para$.widget( "myNamespace.myWidget", {} )， widgetFullNameserá"myNamespace-myWidget"。
  • widgetName: el nombre del widget. Para$.widget( "myNamespace.myWidget", {} )，widgetNameserá"myWidget"。
  • window: el documento que contiene el elemento del widget.window. Útil si necesita interactuar con el widget dentro de un marco (iframe).
