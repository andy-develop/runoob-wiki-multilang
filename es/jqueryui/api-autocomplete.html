jQuery UI API - Widget de Autocompletar (Autocomplete Widget)

Categoría

Widgets

Uso

Descripción:La función de autocompletar busca y filtra según el valor introducido por el usuario, permitiéndole encontrar rápidamente y seleccionar de una lista de valores predefinidos.

Nuevo en la versión:1.8

Cualquier campo que pueda recibir entrada puede convertirse en Autocomplete, es decir,<input>elementos input,<textarea>elementos textarea ycontenteditableelementos con el atributo contenteditable.

Al dar foco al campo de Autocomplete o al escribir caracteres en él, el plugin comienza a buscar entradas coincidentes y muestra una lista de valores para elegir. Escribiendo más caracteres, el usuario puede filtrar la lista para obtener mejores coincidencias.

Este widget puede utilizarse para seleccionar valores previamente seleccionados, como introducir etiquetas de artículos o introducir direcciones de correo electrónico desde una libreta de direcciones. Autocomplete también puede usarse para rellenar información relacionada, como introducir el nombre de una ciudad para obtener su código postal.

Puede obtener los datos de una fuente local o remota: la fuente local es adecuada para conjuntos de datos pequeños, por ejemplo, una libreta de direcciones con 50 entradas; la fuente remota es adecuada para conjuntos de datos grandes, como una base de datos con cientos o miles de entradas. Para obtener más información sobre fuentes de datos personalizadas, consultesourcela documentación de la opción.

Interacción con el teclado

Cuando el menú está abierto, los siguientes comandos de teclado están disponibles:

  • UP - Mueve el foco al elemento anterior. Si está en el primer elemento, mueve el foco al campo de entrada (input). Si está en el campo de entrada, mueve el foco al último elemento.
  • DOWN - Mueve el foco al siguiente elemento. Si está en el último elemento, mueve el foco al campo de entrada (input). Si está en el campo de entrada, mueve el foco al primer elemento.
  • ESCAPE - Cierra el menú.
  • ENTER - Selecciona el elemento que tiene el foco y cierra el menú.
  • TAB - Selecciona el elemento que tiene el foco, cierra el menú y mueve el foco al siguiente elemento enfocable (focusable).
  • PAGE UP/DOWN - Desplaza una pantalla de elementos (según la altura del menú).

Cuando el menú está cerrado, los siguientes comandos de teclado están disponibles:

  • UP/DOWN - Si se cumpleminLengthla condición, se abre el menú.

Tematización

El widget de Autocompletar (Autocomplete Widget) utiliza elframework CSS de jQuery UIpara definir el estilo de su apariencia y sensación. Si necesita utilizar estilos específicos del widget de Autocompletar, puede usar los siguientes nombres de clase CSS:

  • ui-autocomplete: se utiliza para mostrar elmenú (menu) que coincide con la entrada del usuario.
  • ui-autocomplete-input: el elemento input instanciado por el widget de Autocompletar (Autocomplete Widget).

Notas adicionales

  • Este widget requiere algo de CSS funcional; de lo contrario, no funcionará. Si crea un tema personalizado, use el archivo CSS específico del widget como punto de partida.
  • Este widget manipula el valor del elemento de forma programática, por lo que no se dispara elchangeevento nativo.

source Array o String o Function( Object request, Function response( Object data ) ) Define los datos a utilizar; debe especificarse.

Independientemente de la variable que utilice, la etiqueta siempre se trata como texto. Si desea que la etiqueta se trate como html, puede usarla extensión html de Scott González. La demostración se centra ensourcelas diferentes variantes de la opción: puede encontrar la que coincida con su caso de uso y ver el código correspondiente.

Se admiten varios tipos:

  • Array: un array que se puede usar para datos locales. Se admiten dos formatos:
    • Array de cadenas:[ "Choice1", "Choice2" ]
    • Un array de objetos conlabel 和 valuelas propiedades:[ { label: "Choice1", value: "value1" }, ... ]
    La propiedad label se muestra en el menú de sugerencias. Cuando el usuario selecciona una entrada, el valor (value) se inserta en el elemento input. Si solo se especifica una propiedad, dicha propiedad se tratará como label y value, por ejemplo, si solo proporcionavaluela propiedad, el value también se tratará como etiqueta (label).
  • String: cuando se usa una cadena, el plugin Autocomplete espera que la cadena apunte a un recurso URL que devuelva datos JSON. Puede estar en el mismo host o en un host diferente (debe proporcionar JSONP). El plugin Autocomplete no filtra los resultados, sino que añade una cadena de consulta a través de untermcampo para que el script del lado del servidor filtre los resultados. Por ejemplo, si lasourceopción se establece en"http://example.com"search.php, y el usuario escribefooabc, la solicitud GET seráhttp://example.com?term=foosearch.php?term=abc. El formato de los datos en sí puede ser el mismo que el de los datos locales descritos anteriormente.
  • Function: la tercera variante, una función de callback, ofrece la máxima flexibilidad y puede usarse para conectar cualquier fuente de datos a Autocomplete. La función de callback acepta dos argumentos:
    • unrequestobjeto, con unatermpropiedad, que representa el valor de la entrada de texto actual. Por ejemplo, si el usuario escribe en el campo city"new yo", entonces Autocomplete term es equivalente a"new yo"。
    • unresponsefunción de callback que proporciona un único parámetro: los datos sugeridos al usuario. Estos datos deben filtrarse según el term proporcionado, y pueden estar en cualquiera de los formatos de datos locales descritos anteriormente. Se utiliza para proporcionar un callback de source personalizado durante la solicitud para manejar errores. Incluso si se encuentra un error, debe llamar a laresponsefunción de callback. Esto asegura que el widget esté siempre en el estado correcto.

    Al filtrar datos locales, puede usar la$.ui.autocomplete.escapeRegexfunción incorporada. Acepta un parámetro de cadena, escapa todos los caracteres de expresión regular, lo que permite pasar el resultado de forma segura anew RegExp()。

Ejemplo de código:

Inicialice el autocomplete con lassourceopciones especificadas:

Ejemplo 2:

Utiliza un callback de origen personalizado para coincidir con el inicio de los términos.

<!doctype html>
<html lang="en">

  <meta charset="utf-8">
  <title>自动完成部件（Autocomplete Widget）演示</title>
  <link rel="stylesheet" href="//code.jquery.com/ui/1.10.4/themes/smoothness/jquery-ui.css">
  <script src="//code.jquery.com/jquery-1.10.2.js"></script>
  <script src="//code.jquery.com/ui/1.10.4/jquery-ui.js"></script>
</head>
<body>
 
<label for="autocomplete">选择一个编程语言：</label>
<input id="autocomplete">
 
<script>
var tags = [ "c++", "java", "php", "coldfusion", "javascript", "asp", "ruby" ];
$( "#autocomplete" ).autocomplete({
  source: function( request, response ) {
          var matcher = new RegExp( "^" + $.ui.autocomplete.escapeRegex( request.term ), "i" );
          response( $.grep( tags, function( item ){
              return matcher.test( item );
          }) );
      }
});
</script>
 
</body>
</html>
