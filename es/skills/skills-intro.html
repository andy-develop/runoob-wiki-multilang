Tutorial de Skills
Estructura básica de Skills

Introducción a Skills

Skills es un formato abierto para añadir habilidades y conocimientos especializados a los agentes de IA.

Con Skills, puedes encapsular conocimientos especializados de un dominio, flujos de trabajo y mejores prácticas en paquetes de habilidades reutilizables, permitiendo que el agente de IA los invoque automáticamente cuando sea necesario.

Antes de aprender sobre Skills, aclaremos una pregunta más básica: ¿qué es un agente de IA?

Seguramente todos han usado herramientas como ChatGPT, Doubao o Tongyi Qianwen, ¿verdad? Escribes una pregunta y te da una respuesta en texto. Esto es lo que comúnmente llamamosChatbot de modelos grandes。

Herramientas como ChatGPT, Doubao y Tongyi Qianwen son muy inteligentes, pero tienen un problema fatal:Solo pueden hablar, no pueden actuar.

Si le preguntas: ¿cómo está el clima hoy en Beijing?, solo puede adivinar una respuesta basándose en el conocimiento aprendido durante el entrenamiento, en lugar de consultar el clima realmente.

Agente inteligente = un asistente de IA que puede entender tus palabras, pensar por sí mismo y también ponerse a trabajar.

El chatbot es un sustituto de palabras, el agente inteligente es un sustituto de acciones.

Entonces, ¿qué es un agente inteligente?

Agente inteligente = modelo grande + capacidad para actuar.

Volvamos al ejemplo anterior:

Chatbot Agente inteligente
Preguntas: ¿cómo está el clima en Beijing hoy? Probablemente soleado en Beijing hoy, unos 25 grados (adivinado) Realmente llama a la API del clima y te dice: Hoy en Beijing está nublado, 23°C, humedad 45% (real)
Preguntas: ayúdame a consultar las ventas del mes pasado Lo siento, no puedo acceder a tu base de datos Realmente consulta la base de datos y te muestra los datos
Dices: ayúdame a reservar un boleto de tren de alta velocidad para Shanghai mañana Puedes ir al sitio web 12306 a reservar el boleto Realmente abre 12306 por ti, consulta boletos, elige asientos y hace el pedido

La diferencia se resume en una frase: el chatbot solo habla, el agente inteligente realmente hace.

¿Cómo lo hace el agente inteligente?

Un agente inteligente se compone aproximadamente de las siguientes partes:

Proceso de tres pasos:

  1. Entender lo que quieres(depende del modelo grande)
  2. Decidir qué habilidad usar(depende del modelo grande)
  3. Ejecutar la habilidad y darte el resultado(depende de las Skills)

Los agentes inteligentes que ya puedes ver en tu vida

De hecho, muchos productos ya usan agentes inteligentes:

  • Siri / Xiao Ai / Tmall Genie— Dices "pon una alarma" y realmente la pone, no te dice "puedes ponerla tú mismo".
  • GitHub Copilot— No solo chatea, realmente puede ayudarte a escribir y modificar código.
  • Varios servicios de atención al cliente con IA— No solo responde preguntas, también puede consultar pedidos, reembolsos y cambiar direcciones.
  • Conducción autónoma— También es un tipo de agente inteligente: percibe el entorno, toma decisiones y ejecuta acciones.

¿Qué son las Skills en los agentes inteligentes?

智能体的大模型 = 大脑（负责理解、决策、说话）
Skills = 手和脚（负责动手干活）

Un agente inteligente sin Skills es como una persona con cerebro pero sin manos ni pies: entiende todo, pero no puede hacer nada.

El agente inteligente es muy inteligente, pero necesita que alguien le diga: en este entorno específico, para completar esta tarea específica, qué herramientas usar, qué pasos seguir y qué trampas evitar.

Este manual se llama Skill.

Para entender las Skills con una metáfora más cercana a la vida cotidiana:

把智能体想象成一位聪明的新员工，他能力很强，但第一天来公司什么流程都不懂。
Skill 就是公司的 SOP 手册（标准操作流程）。
有了这本手册，他就知道：遇到客户投诉该怎么处理、出差报销流程是什么、代码提交要走哪些审核……不需要每次都问你，能自己完成任务。

Técnicamente, Skills es un archivo Markdown (SKILL.md) que contiene la guía completa de ejecución de la tarea. Es escrito por humanos y luego leído y seguido automáticamente por el agente inteligente al ejecutar la tarea.

¿Qué problemas pueden resolver las Skills?

Escenario 1: Sin Skills

Supón que le pides a Claude que te ayudea generar un documento de Word：

你：帮我生成一个项目计划书的 Word 文档

Claude：好的，以下是项目计划书内容：
（输出一堆 Markdown 文本……）

Resultado: Claude genera solo texto plano,no es un archivo .docx real. Porque no sabe qué bibliotecas hay en tu entorno, dónde deben ir los archivos o cuáles son los requisitos de formato.

Escenario 2: Con Skills

Cuando el sistema está equipado condocxuna Skill, Claude, al recibir la misma solicitud, hará lo siguiente:

  1. identificar automáticamente "esto es una tarea de documento de Word" → activar ladocx Skill
  2. Leer el archivo de Skill, conocer la biblioteca correcta (python-docx) y la ruta de salida (/mnt/user-data/outputs/）
  3. Según los pasos de la Skill, generar el verdadero.docxarchivo
  4. Entregarte el archivo para que lo descargues

El resultado es completamente diferente— uno es una respuesta de chat, el otro es un archivo de Word que se puede abrir inmediatamente.

Resumen del valor central de las Skills

Después de estudiar este capítulo, debes recordar los siguientes tres puntos:

  • 1. Las Skills hacen que el agente pase de saber chatear a saber trabajar:Sin Skills, el agente es solo un chatbot con amplio conocimiento. Con Skills, se convierte en un ejecutor que realmente completa tareas.

  • 2. Las Skills son paquetes de experiencia reutilizables:Una vez que alguien escribe en una Skill la experiencia de generar documentos de Word, todas las personas, en todas las invocaciones, obtienen resultados estables y consistentes. No fallará solo porque cambie la persona que pregunta.

  • 3. Las Skills son el puente de colaboración entre humanos y la IA:
    Los humanos escriben en la Skill el conocimiento del dominio, la experiencia de procesos y las restricciones del entorno; la IA lo entiende y lo ejecuta. Skills es ese puente: los humanos se centran en definir cómo hacerlo, la IA se encarga de hacerlo realmente.

Concepto Resumen en una frase
Agente de IA Sistema de IA que puede percibir, razonar y actuar; no solo chatea, sino que también ejecuta tareas.
Skills Manual que le dice al agente "cómo completar cierto tipo de tareas" (archivo Markdown)
El valor de las Skills Hace que la ejecución de tareas sea precisa, estable y reutilizable

Diferencia entre Skills y MCP

Skills se usa parareutilización del conocimiento, MCP se usa paraexpansión de capacidades。

Skills

Reutilización del conocimiento

  • Compartir conocimiento: experiencia, mejores prácticas, flujos de trabajo
  • Se basa en archivos Markdown simples; cualquier persona puede crearlo
  • Carga progresiva, alta eficiencia en el uso de tokens
  • No requiere servidor ni configuración de backend
  • Aplicable a Web / Desktop / CLI

MCP

Expansión de capacidades

  • Extensión de funciones: conexión a API, bases de datos y herramientas externas
  • Requiere habilidades de programación y configuración del lado del servidor
  • Carga todas las definiciones de herramientas al inicio
  • Fuerte capacidad de integración con sistemas externos
  • Mayor consumo de tokens y complejidad

Escenarios de uso de las Skills

Agent Skills es adecuado para varios escenarios, incluidos, entre otros:

  • Conocimiento especializado del dominio:encapsular conocimientos de áreas especializadas como revisión legal, análisis de datos y normas de código en habilidades
  • Flujos de trabajo:convertir procesos de tareas de múltiples pasos en habilidades repetibles
  • Normas de la empresa:encapsular normas de código específicas de la empresa, procesos de envío, plantillas de documentos, etc. en habilidades
  • Integración de herramientas:encapsular métodos de uso y llamadas a API de herramientas específicas

Herramientas que admiten Agent Skills

Agent Skills es un estándar abierto, compatible con múltiples herramientas de IA, incluyendo:

  • Claude Code
  • OpenCode
  • GitHub Copilot
  • OpenAI Codex
  • y muchas otras herramientas de agentes de IA

Esto significa que solo necesitas escribir la habilidad una vez y podrás usarla en diferentes herramientas.
