Markdown Imágenes

Las imágenes hacen que los documentos sean más dinámicos y fáciles de entender.

La sintaxis de imágenes de Markdown es simple y flexible.

El formato de la sintaxis de imágenes en Markdown es el siguiente:

![替代文字](图片路径)
![替代文字](图片路径 "图片标题")
  • Empieza con un signo de exclamación !
  • A continuación, un corchete que contiene el texto alternativo de la imagen
  • Después, un paréntesis que contiene la URL de la imagen y, opcionalmente, se puede añadir el texto del atributo 'title' entre comillas.

Ejemplo de ruta relativa:

![项目截图](./images/screenshot.png)
![用户界面](../assets/ui-demo.jpg "用户界面演示")
![图标](images/icon.svg "应用图标")

Ejemplo de ruta absoluta:

![本地图片](/Users/username/Documents/image.png)
![系统截图](C:\Users\username\Pictures\screenshot.png)

Recomendaciones para el uso de rutas:

  • Se recomienda usar rutas relativas para facilitar la portabilidad del proyecto
  • Se recomienda crear una carpeta dedicada para las imágenes (como images/, assets/)
  • Usa nombres de archivo descriptivos para facilitar la gestión
  • Ten en cuenta las diferencias en los separadores de ruta entre sistemas operativos

Consideraciones sobre imágenes de Internet:

  • Asegura la estabilidad y accesibilidad de las URLs de las imágenes
  • Ten en cuenta los problemas de derechos de autor de las imágenes
  • Considera la velocidad de carga y el entorno de red
  • Se recomienda hacer copias de seguridad locales de las imágenes importantes

Importancia del texto alternativo (alt) en las imágenes

El texto alternativo (alt) proporciona información de respaldo cuando la imagen no se puede mostrar, y también es importante para la accesibilidad y el SEO:

Ejemplos de buenos textos alternativos:

![苹果公司总部大楼外观，现代玻璃幕墙建筑](./images/apple-headquarters.jpg)
![网站流量统计图表，显示过去六个月的访问量呈上升趋势](./charts/traffic-stats.png)
![用户登录界面，包含用户名和密码输入框](./screenshots/login-page.png)

Textos alternativos que se deben evitar:

![图片](image.jpg)  // 太简单，没有描述性
![](image.jpg)      // 完全没有 alt 文本
![点击这里](image.jpg)  // 不描述图片内容

Buenas prácticas para el texto alternativo:

  • Conciso pero descriptivo
  • Describe el contenido principal y el propósito de la imagen
  • Evita palabras redundantes como "imagen" o "foto"
  • Para imágenes decorativas, se puede usar un texto alternativo vacío
  • Ten en cuenta el contexto y proporciona información significativa

Control del tamaño de imagen (método HTML)

El Markdown estándar no permite controlar directamente el tamaño de las imágenes, pero se pueden usar etiquetas HTML.

Usar la etiqueta img de HTML:

<img src="image.jpg.html" alt="描述文字" width="300" height="200">
<img src="image.jpg.html" alt="描述文字" width="50%">
<img src="image.jpg.html" alt="描述文字" style="width: 300px; height: auto;">

Imágenes responsivas:

<img src="image.jpg.html" alt="描述文字" style="max-width: 100%; height: auto;">

Alineación de imágenes:

<!-- 居中对齐 -->
<div align="center">
  <img src="image.jpg.html" alt="居中图片" width="400">
</div>

<!-- 左对齐（默认） -->
<img src="image.jpg.html" alt="左对齐图片" style="float: left; margin-right: 20px;">

<!-- 右对齐 -->
<img src="image.jpg.html" alt="右对齐图片" style="float: right; margin-left: 20px;">

Recomendaciones para la planificación de rutas:

  • Crea una carpeta de recursos unificada en el directorio raíz del proyecto
  • Usa nombres de carpeta descriptivos
  • Mantén la coherencia en la estructura de rutas
  • Ten en cuenta las reglas de rutas de los generadores de sitios estáticos

Centrado y alineación de imágenes

Método 1: HTML + CSS

<div style="text-align: center;">
  <img src="image.jpg.html" alt="居中图片" style="max-width: 100%;">
</div>

Método 2: Usar atributos de alineación de HTML

<p align="center">
  <img src="image.jpg.html" alt="居中图片" width="400">
</p>

Método 3: Crear una galería de imágenes

<div style="display: flex; justify-content: space-around; flex-wrap: wrap;">
  <img src="image1.jpg.html" alt="图片1" style="width: 30%; margin: 10px;">
  <img src="image2.jpg.html" alt="图片2" style="width: 30%; margin: 10px;">
  <img src="image3.jpg.html" alt="图片3" style="width: 30%; margin: 10px;">
</div>

Recomendaciones para optimizar el rendimiento:

  • Optimiza el tamaño y formato de las imágenes (WebP > PNG > JPG)
  • Usa dimensiones de imagen adecuadas y evita escalar imágenes grandes en la página web
  • Considera usar herramientas de compresión de imágenes
  • Prepara imágenes de diferentes tamaños para diferentes dispositivos

Solución de problemas con enlaces e imágenes

Problemas comunes y soluciones:

  • El enlace no se puede hacer clic: verifica el formato de sintaxis y asegúrate de que los corchetes y paréntesis estén correctamente emparejados
  • La imagen no se muestra: verifica la ruta de la imagen y que el archivo exista
  • La imagen es demasiado grande: usa HTML para controlar el tamaño u optimiza el archivo de imagen
  • Abrir el enlace en una ventana nueva: usar HTML<a target="_blank">etiqueta
