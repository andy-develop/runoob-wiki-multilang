Clases Number y Math de Java

Java Number

Generalmente, cuando necesitamos usar números, solemos usar los tipos de datos integrados, como:byte、int、long、doubleetc.

Ejemplo

int a = 5000; float b = 13.65f; byte c = 0x4a;

Sin embargo, en el proceso de desarrollo real, a menudo nos encontramos con situaciones en las que necesitamos usar objetos en lugar de tipos de datos integrados. Para resolver este problema, el lenguaje Java proporciona una clase envoltorio (wrapper) correspondiente para cada tipo de datos integrado.

Todas las clases envoltorio（Integer、Long、Byte、Double、Float、Short）son subclases de la clase abstracta Number.

Nombre de claseTipo primitivo correspondienteDescripción
BytebyteClase envoltorio del tipo byte
ShortshortClase envoltorio del tipo short
IntegerintClase envoltorio del tipo int
LonglongClase envoltorio del tipo long
FloatfloatClase envoltorio del tipo float
DoubledoubleClase envoltorio del tipo double
BigInteger-Entero inmutable de precisión arbitraria
BigDecimal-Número decimal con signo inmutable de precisión arbitraria

Este envoltorio, especialmente admitido por el compilador, se denomina autoboxing. Por lo tanto, cuando un tipo de datos integrado se usa como objeto, el compilador envuelve (boxea) el tipo integrado en su clase envoltorio. De manera similar, el compilador también puede desenvolver (unboxear) un objeto a un tipo de datos integrado.

La clase Number pertenece al paquete java.lang.

Number es una clase abstracta cuya función principal es proporcionar métodos de conversión unificados para varios tipos numéricos:

Ejemplo

public abstract class Number implements Serializable {
    // Métodos abstractos
    public abstract int intValue();
    public abstract long longValue();
    public abstract float floatValue();
    public abstract double doubleValue();
   
    // Añadido en Java 8
    public byte byteValue() {
        return (byte)intValue();
    }
    public short shortValue() {
        return (short)intValue();
    }
}

A continuación se muestra un ejemplo que utiliza un objeto Integer:

Código del archivo Test.java:

public class Test{ public static void main(String[] args){ Integer x = 5; x = x + 10; System.out.println(x); } }

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

15

Cuando a x se le asigna un valor entero, como x es un objeto, el compilador debe aplicar autoboxing a x. Luego, para que x pueda realizar la operación de suma, debe aplicar unboxing a x.

Ejemplo de métodos comunes

Conversión de tipos primitivos

Ejemplo

Number num = 1234.56; // En realidad es de tipo Double

System.out.println(num.intValue());    // 1234 (truncando decimales)
System.out.println(num.longValue());   // 1234
System.out.println(num.floatValue());  // 1234.56
System.out.println(num.doubleValue()); // 1234.56

Comparación de valores numéricos

Ejemplo

java
Integer x = 10;
Double y = 10.0;

// Forma correcta de comparar: convertir al mismo tipo y luego comparar
System.out.println(x.doubleValue() == y.doubleValue()); // true

Manejo de números grandes

Autoboxing y unboxing

Java 5+ admite la conversión automática:

Ejemplo

// Autoboxing
Integer autoBoxed = 42; // El compilador lo convierte a Integer.valueOf(42)

// Unboxing automático
int autoUnboxed = autoBoxed; // El compilador lo convierte a autoBoxed.intValue()

Clase Math de Java

La clase Math es una clase de utilidades matemáticas proporcionada por Java, ubicada en el paquete java.lang, que contiene métodos estáticos para realizar operaciones numéricas básicas.

La clase Math de Java contiene propiedades y métodos para realizar operaciones matemáticas básicas, como exponentes elementales, logaritmos, raíces cuadradas y funciones trigonométricas.

Los métodos de Math están definidos como static, por lo que se pueden llamar directamente desde la clase Math en la función principal.

Código del archivo Test.java:

public class Test { public static void main (String []args) { System.out.println("Seno de 90 grados:" + Math.sin(Math.PI/2)); System.out.println("Coseno de 0 grados:" + Math.cos(0)); System.out.println("Tangente de 60 grados:" + Math.tan(Math.PI/3)); System.out.println("Arco tangente de 1:" + Math.atan(1)); System.out.println("Valor en grados de π/2:" + Math.toDegrees(Math.PI/2)); System.out.println(Math.PI); } }

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

90 度的正弦值：1.0
0度的余弦值：1.0
60度的正切值：1.7320508075688767
1的反正切值： 0.7853981633974483
π/2的角度值：90.0
3.141592653589793

Operaciones matemáticas avanzadas

1. Operaciones con exponenciales y logaritmos

Ejemplo

Math.exp(1);    // e^1 ≈ 2.718
Math.log(Math.E); // ln(e) = 1
Math.log10(100); // log10(100) = 2

2. Generación de números aleatorios

Ejemplo

// Genera un número aleatorio entre [0.0, 1.0)
double random = Math.random();

// Genera un entero aleatorio entre [1, 100]
int randomInt = (int)(Math.random() * 100) + 1;

3. Otras operaciones

Ejemplo

Math.hypot(3, 4); // Calcula sqrt(x²+y²) → 5.0
Math.IEEEremainder(10, 3); // Resto IEEE → 1.0

4. Campos constantes

Ejemplo

Math.PI;    // π ≈ 3.141592653589793
Math.E;     // Base del logaritmo natural e ≈ 2.718281828459045

    Diferencia entre int y Integer en Java

    1.int es un tipo de datos primitivo, y una variable int almacena el valor numérico. Integer es un tipo de referencia, en realidad es un objeto, y Integer almacena la dirección del objeto referenciado.

    2.

    Integer i = new Integer(100);
Integer j = new Integer(100);
System.out.print(i == j); //false

    Porque `new` genera dos objetos, sus direcciones de memoria son diferentes.

    3.

    Comparación de memoria ocupada por int e Integer:

    Los objetos Integer ocupan más memoria. Integer es un objeto y necesita almacenar metadatos del objeto. Pero int es un tipo de dato primitivo, por lo que ocupa menos espacio.

    4.Al comparar variables Integer no generadas con new connew Integer()las variables generadas, el resultado es false.

    /**
 * 比较非new生成的Integer变量与new生成的Integer变量
 */
public class Test {
    public static void main(String[] args) {
        Integer i= new Integer(200);
        Integer j = 200;
        System.out.print(i == j);
        //输出：false
    }
}

    Porque las variables Integer no generadas con new apuntan a objetos en el pool de constantes de Java, mientras quenew Integer()las variables generadas apuntan a objetos recién creados en el montón (heap), sus direcciones en memoria son diferentes. Por lo tanto, la salida es false.

    5.Al comparar dos objetos Integer no generados con new, si los valores de las dos variables están en el intervalo[-128,127]entre, el resultado de la comparación es true; de lo contrario, el resultado es false.

    /**
 * 比较两个非new生成的Integer变量
 */
public class Test {
    public static void main(String[] args) {
        Integer i1 = 127;
        Integer ji = 127;
        System.out.println(i1 == ji);//输出：true
        Integer i2 = 128;
        Integer j2 = 128;
        System.out.println(i2 == j2);//输出：false
    }
}

    Java, al compilarInteger i1 = 127se traduce aInteger i1 = Integer.valueOf(127)。

    6.Al comparar una variable Integer (ya sea generada con new o no) con una variable int, siempre que los valores de las dos variables sean iguales, el resultado es true.

    /**
 * 比较Integer变量与int变量
 */
public class Test {
    public static void main(String[] args) {
        Integer i1 = 200;
        Integer i2 = new Integer(200);
        int j = 200;
        System.out.println(i1 == j);//输出：true
        System.out.println(i2 == j);//输出：true
    }
}

    Cuando una variable de la clase envolvente Integer se compara con una variable del tipo primitivo int, Integer se desempaca automáticamente a int y luego se realiza la comparación. En realidad, es la comparación de dos variables int; si los valores son iguales, el resultado es true.

    Math.floorEs redondeo hacia abajo (floor).

    Math.ceilEs redondeo hacia arriba (ceil).

    Math.roundEs redondeo (al entero más cercano), pero hay que tener en cuenta:

    • 1. Si el primer dígito después del punto decimal del parámetro es menor que 5, el resultado es la parte entera del parámetro.
    • 2. Si el primer dígito después del punto decimal del parámetro es mayor que 5, el resultado es el valor absoluto de la parte entera del parámetro +1, el signo (positivo o negativo) no cambia.
    • 3. Si el primer dígito después del punto decimal del parámetro es igual a 5, para números positivos el resultado es la parte entera +1, para números negativos el resultado es la parte entera.
