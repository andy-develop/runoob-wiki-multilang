Clase Character de Java

La clase Character se utiliza para operar con caracteres individuales.

La clase Character envuelve un tipo primitivo en un objeto.charel valor de

Ejemplo

char ch = 'a'; //Representación de caracteres Unicode char uniChar = '\u039A'; //Arreglo de caracteres char[] charArray ={ 'a', 'b', 'c', 'd', 'e' };

Sin embargo, en el proceso de desarrollo real, a menudo nos encontramos con situaciones en las que necesitamos usar objetos en lugar de tipos de datos integrados. Para resolver este problema, el lenguaje Java proporciona la clase envolvente Character para el tipo de datos integrado char.

La clase Character proporciona una serie de métodos para manipular caracteres. Puedes crear un objeto de la clase Character usando su constructor, por ejemplo:

Character ch = new Character('a');

En algunos casos, el compilador de Java crea automáticamente un objeto Character.

Por ejemplo, al pasar un parámetro de tipo char a un método que requiere un parámetro de tipo Character, el compilador convertirá automáticamente el parámetro de tipo char en un objeto Character. Esta característica se denomina boxing (empaquetado) y, a la inversa, unboxing (desempaquetado).

Ejemplo

//El carácter primitivo 'a' se empaqueta en el objeto Character ch. Character ch = 'a'; //El carácter primitivo 'x' se empaqueta mediante el método test. //Devuelve el valor desempaquetado a 'c'. char c = test('x');

Secuencias de escape

Los caracteres precedidos por una barra invertida (\) representan caracteres de escape y tienen un significado especial para el compilador.

La siguiente lista muestra las secuencias de escape de Java:

Secuencia de escape Descripción
\t Inserta un tabulador en ese punto del texto.
\b Inserta una tecla de retroceso en ese punto del texto.
\n Inserta un salto de línea en ese punto del texto.
\r Inserta un retorno de carro en ese punto del texto.
\f Inserta un salto de página en ese punto del texto.
\' Inserta una comilla simple en ese punto del texto.
\" Inserta una comilla doble en ese punto del texto.
\\ Inserta una barra invertida en ese punto del texto.

Ejemplo

    \r: return va al extremo izquierdo de la línea actual.

    \n: newline baja una línea, sin desplazarse a la izquierda ni a la derecha.

    En Linux\nrepresenta: retorno de carro + avance de línea;

    En Windows\r\nrepresenta: retorno de carro + avance de línea.

    En Mac\rrepresenta: retorno de carro + avance de línea.

    Historia:

    El origen y la diferencia de los conceptos 'retorno de carro' (Carriage Return) y 'avance de línea' (Line Feed). Antes de que existieran las computadoras, había un aparato llamado teletipo (Teletype Model 33; el concepto de tty en linux/Unix también proviene de esto) que podía imprimir 10 caracteres por segundo. Pero tenía un problema: al terminar una línea y pasar a la siguiente, se necesitaban 0,2 segundos, tiempo justo para imprimir dos caracteres. Si durante esos 0,2 segundos llegaba otro carácter, este se perdía. Entonces, los desarrolladores idearon una manera de resolver este problema: añadir dos caracteres de fin de línea después de cada línea. Uno se llamaba 'retorno de carro' (return) y le decía a la máquina de escribir que colocara el cabezal de impresión en el borde izquierdo; el otro se llamaba 'avance de línea' (newline) y le decía que moviera el papel una línea hacia abajo. Este es el origen de 'avance de línea' y 'retorno de carro', como también puede apreciarse en sus nombres en inglés.

    Retorno de carro suave y duro:

    Ampliemos un poco más los conocimientos sobre el retorno de carro.

    El retorno de carro duro es el que se produce normalmente al pulsar Enter; además de cambiar de línea, también sirve como separador de párrafos.

    El retorno de carro suave se produce con Shift +Enter; cambia de línea, pero no cambia de párrafo, es decir, el texto anterior y posterior pertenecen al mismo 'párrafo' en Word. Lo notarás al aplicar formato.

    El retorno de carro suave puede reducir considerablemente el espacio entre dos líneas consecutivas, porque no es una marca de párrafo; debe distinguirse de la marca de párrafo estándar: el retorno de carro duro. El código html del retorno de carro duro es <p>..</p>, y el contenido del párrafo queda encerrado entre esas etiquetas, mientras que el código del retorno de carro suave es muy conciso: <br>. Si el texto de una página web se copia en Word, el retorno de carro duro se convierte en una flecha curva y el retorno de carro suave en una flecha hacia abajo.

    El constructor de Character está en desuso desde la versión 9.

    The constructor Character(char) is deprecated since version 9

    Texto original:java.lang.Character​(char)：It is rarely appropriate to use this constructor. The static factoryCharacter.valueOf(char) is generally a better choice, as it is likely to yield significantly better space and time performance.

    Traducción:Rara vez es apropiado usar este constructor. La fábrica estática Character.valueOf(char) suele ser una mejor opción, ya que puede producir un mejor rendimiento de espacio y tiempo.

    Character ch = new Character('a');      // Java9 以前
Character ch = Character.valueOf('a');  // Java9 以后

    Extraer letras mayúsculas y minúsculas de los caracteres:

    public class UpperLowerCase {
    public static void main(String []args) {
        String StrA="I am Tom.I am from China.";
        String StrB="";
        String StrC="";
        for(int i=0;i<StrA.length();i++){
            if(Character.isUpperCase(StrA.charAt(i)))
                StrB +=StrA.charAt(i)+"  ";
            if(Character.isLowerCase(StrA.charAt(i)))
                StrC +=StrA.charAt(i)+"  ";
            }
        System.out.println("字符串中大写字母有："+StrB);
        System.out.println("字符串中小写字母有："+StrC);
    }
}

    El resultado de salida es:

    字符串中大写字母有：I  T  I  C  
字符串中小写字母有：a  m  o  m  a  m  f  r  o  m  h  i  n  a

    Usar Character para extraer las letras mayúsculas y minúsculas de una cadena:

    public class UpperLowerCase {
    
    /*
     * 利用Character类提取字符串中的大写字母和小写字母
     * @auther Anthony-Z
     */

    public static void main(String[] args) {
        
        String sr1 = "I Like JAVA ! I learn Java everyday.";
        String sr2 = "";
        String sr3 = "";
        
        for (int i = 0; i < sr1.length(); i++) {//获取字符串的长度用的是length();
            if(Character.isUpperCase(sr1.charAt(i))){//先将String类型的字符串转换成char类型                                                                            再获取每一个字符元素，用charAt(i)实现
                sr2 += sr1.charAt(i) + " ";//提取大写字母
            }
            
            if(Character.isLowerCase(sr1.charAt(i))){
                sr3 += sr1.charAt(i) + " ";//提取小写字母
            }
        }
        
        System.out.println("大写字母有：" + sr2);
        System.out.println("小写字母有：" + sr3);

    }

}
