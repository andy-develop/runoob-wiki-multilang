Fecha y hora de Java

Java proporciona varios conjuntos de API de fecha y hora. A continuación se presenta una comparación de las principales categorías y un resumen de los métodos comunes:

Categoría Clases principales Seguridad de hilos Mutabilidad Versión de Java Características
Fecha tradicional Date, Calendar，GregorianCalendar 否 Mutable 1.0+ Muchos defectos de diseño, no se recomienda su uso
Nueva fecha y hora LocalDate, LocalTime, LocalDateTime, ZonedDateTime, ChronoUnit 是 Inmutable 8+ Bien diseñado, recomendado su uso
Marca de tiempo Instant 是 Inmutable 8+ Tiempo de máquina, preciso hasta nanosegundos
Formateo DateTimeFormatter 是 Inmutable 8+ Clase de formateo segura para hilos

LocalDate/DateTimeFormatter

LocalDate/DateTimeFormatter son clases de fecha introducidas en Java 8. LocalDate se usa para representar una fecha sin hora (año-mes-día), y DateTimeFormatter se usa para formatear y analizar objetos de fecha y hora.

Ejemplo

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

public class RunoobTest {
    public static void main(String[] args) {
        // Obtener la fecha actual
        LocalDate today = LocalDate.now();
        System.out.println("Fecha actual: " + today);
       
        // Crear una fecha específica
        LocalDate nationalDay = LocalDate.of(2025, 10, 1);
        System.out.println("Día Nacional: " + nationalDay);
       
        // Sumar y restar fechas
        LocalDate tomorrow = today.plusDays(1);
        LocalDate nextMonth = today.plusMonths(1);
        LocalDate lastYear = today.minusYears(1);
       
        System.out.println("Mañana: " + tomorrow);
        System.out.println("Próximo mes: " + nextMonth);
        System.out.println("Hoy hace un año: " + lastYear);
    }
}

La salida de los ejemplos anteriores es:

当前日期: 2025-05-01
国庆节: 2025-10-01
明天: 2025-05-02
下个月: 2025-06-01
去年今天: 2024-05-01

  1. En proyectos nuevos, priorizar el uso del paquete java.time (Java 8+)

  2. Evitar el uso de las antiguas clases Date y Calendar

  3. Distinguir claramente el uso de zonas horarias：

    • Sin necesidad de zona horaria: LocalDate/LocalTime/LocalDateTime

    • Con necesidad de zona horaria: ZonedDateTime

  4. Considerar la seguridad de hilos al formatear: usar DateTimeFormatter en lugar de SimpleDateFormat

  5. Interacción con bases de datos：

    • JDBC 4.2+ admite directamente los tipos java.time

    • Versiones antiguas se pueden convertir a java.sql.Date/Timestamp

El primer constructor utiliza la fecha y hora actuales para inicializar el objeto.

El segundo constructor recibe un parámetro, que es la cantidad de milisegundos desde el 1 de enero de 1970.

Comparación de fechas

Java utiliza los siguientes tres métodos para comparar dos fechas:

  • Usar el método getTime() para obtener los dos valores de fecha (milisegundos transcurridos desde el 1 de enero de 1970) y luego comparar estos dos valores.
  • Usar los métodos before(), after() y equals(). Por ejemplo, el día 12 de un mes es anterior al 18, entoncesnew Date(99, 2, 12).before(new Date (99, 2, 18))devuelve true.
  • Usar el método compareTo(), que está definido por la interfaz Comparable y la clase Date implementa esta interfaz.

1. Comparar usando el método getTime()

Este método compara los milisegundos transcurridos desde el 1 de enero de 1970 (época Unix) de los objetos de fecha.

Ejemplo

import java.util.Date;

public class DateComparison {
    public static void main(String[] args) {
        Date date1 = new Date(121, 5, 15); // 15 de junio de 2021
        Date date2 = new Date(121, 5, 20); // 20 de junio de 2021
       
        // Comparar los milisegundos
        if (date1.getTime() < date2.getTime()) {
            System.out.println("date1 es anterior a date2");
        } else if (date1.getTime() > date2.getTime()) {
            System.out.println("date1 es posterior a date2");
        } else {
            System.out.println("Las dos fechas son iguales");
        }
    }
}

Salida:

date1 在 date2 之前

2. Usar los métodos before(), after() y equals()

Estos métodos son métodos de comparación incorporados de la clase Date, con semántica más clara.

Ejemplo

import java.util.Date;

public class DateComparison {
    public static void main(String[] args) {
        Date date1 = new Date(121, 5, 15); // 15 de junio de 2021
        Date date2 = new Date(121, 5, 20); // 20 de junio de 2021
       
        // Usar el método before()
        System.out.println("¿date1 es anterior a date2? " + date1.before(date2));
       
        // Usar el método after()
        System.out.println("¿date1 es posterior a date2? " + date1.after(date2));
       
        // Usar el método equals()
        System.out.println("¿Las dos fechas son iguales? " + date1.equals(date2));
    }
}

Salida:

date1 在 date2 之前吗？ true
date1 在 date2 之后吗？ false
两个日期相同吗？ false

3. Usar el método compareTo()

La clase Date implementa la interfaz Comparable y se puede utilizar el método compareTo() para comparar.

Ejemplo

import java.util.Date;

public class DateComparison {
    public static void main(String[] args) {
        Date date1 = new Date(121, 5, 15); // 15 de junio de 2021
        Date date2 = new Date(121, 5, 20); // 20 de junio de 2021
       
        int result = date1.compareTo(date2);
       
        if (result < 0) {
            System.out.println("date1 está antes que date2");
        } else if (result > 0) {
            System.out.println("date1 está después que date2");
        } else {
            System.out.println("Las dos fechas son iguales");
        }
    }
}

Salida:

date1 在 date2 之前

Formatear fechas con SimpleDateFormat

SimpleDateFormat es una clase que formatea y analiza fechas de forma sensible al locale. SimpleDateFormat te permite elegir cualquier formato de fecha y hora definido por el usuario. Por ejemplo:

Ejemplo

import java.util.*; import java.text.*; public class DateDemo { public static void main(String[] args) { Date dNow = new Date( ); SimpleDateFormat ft = new SimpleDateFormat ("yyyy-MM-dd hh:mm:ss"); System.out.println("La hora actual es:" + ft.format(dNow)); } }

Ejecutar ejemplo » 
SimpleDateFormat ft = new SimpleDateFormat ("yyyy-MM-dd hh:mm:ss");

Esta línea de código establece el formato de conversión, donde yyyy es el año completo, MM es el mes, dd es el día, y HH:mm:ss son horas, minutos y segundos.

Nota: algunos formatos usan mayúsculas y otros minúsculas; por ejemplo, MM es el mes, mm son los minutos; HH es el formato de 24 horas, mientras que hh es el de 12 horas.

Formatear fechas con printf

El método printf puede formatear horas y fechas fácilmente. Utiliza un formato de dos letras que comienza con%ty termina con una de las letras de la siguiente tabla.

  • %tY: genera el año de cuatro dígitos, por ejemplo: 2023
  • %ty: genera el año de dos dígitos, por ejemplo: 23
  • %tm: genera el mes de dos dígitos, por ejemplo: 02
  • %tB: genera el nombre completo del mes, por ejemplo: February
  • %tb: genera la abreviatura del mes, por ejemplo: Feb
  • %tA: genera el nombre completo del día de la semana, por ejemplo: Wednesday
  • %ta: genera la abreviatura del día de la semana, por ejemplo: Wed
  • %td: genera el día del mes de dos dígitos, por ejemplo: 24
  • %te: genera el día del mes con uno o dos dígitos, por ejemplo: 24 o 02
  • %tH: genera la hora en formato de 24 horas, por ejemplo: 23
  • %tI: genera la hora en formato de 12 horas, por ejemplo: 11
  • %tM: genera los minutos, por ejemplo: 45
  • %tS: genera los segundos, por ejemplo: 30
  • %tp: genera AM o PM, por ejemplo: AM o PM
  • %tZ: genera la zona horaria, por ejemplo: GMT+08:00

Java dormir (sleep)

sleep() hace que el hilo actual entre en estado de estancamiento (bloquea el hilo actual), cediendo el uso de la CPU; el objetivo es evitar que el hilo actual monopolice los recursos de CPU del proceso, dejando tiempo para que otros hilos tengan la oportunidad de ejecutarse.

Puedes hacer que el programa duerma durante un milisegundo o durante cualquier período de tiempo, incluso tan largo como la vida de tu computadora. Por ejemplo, el siguiente programa dormirá durante 3 segundos:

Ejemplo

import java.util.*; public class SleepDemo { public static void main(String[] args) { try { System.out.println(new Date( ) + "\n"); Thread.sleep(1000*3); //Dormir 3 segundos System.out.println(new Date( ) + "\n"); } catch (Exception e) { System.out.println("Got an exception!"); } } }

Ejecutar ejemplo »

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

Thu Sep 17 10:20:30 CST 2015

Thu Sep 17 10:20:33 CST 2015

Clase Calendar

Ahora ya podemos formatear y crear un objeto Date, pero ¿cómo podemos establecer y obtener partes específicas de los datos de fecha, como la hora, el día o los minutos? ¿Y cómo podemos sumar o restar valores a estas partes de la fecha? La respuesta es usar la clase Calendar.

La clase Calendar es mucho más potente que la clase Date, y también es más compleja en su implementación.

La clase Calendar es una clase abstracta; en la práctica se implementan objetos de una subclase específica. El proceso de creación de objetos es transparente para el programador, solo necesita usar el método getInstance.

Crear un objeto Calendar que represente la fecha actual del sistema

Calendar c = Calendar.getInstance();//默认是当前日期

Crear un objeto Calendar con una fecha específica

Para usar la clase Calendar y representar un tiempo específico, primero se debe crear un objeto Calendar y luego establecer los parámetros de año, mes y día en ese objeto.

//创建一个代表2009年6月12日的Calendar对象
Calendar c1 = Calendar.getInstance();
c1.set(2009, 6 - 1, 12);

Tipos de campos de los objetos de la clase Calendar

En la clase Calendar se utilizan las siguientes constantes con diferentes significados; muchas clases dentro del JDK adoptan esta misma idea.

Calendar.HOUR_OF_DAYHora en formato de 24 horas.
Calendar.MINUTEMinuto
Calendar.SECOND秒

Configuración de información de los objetos de la clase Calendar

Configuración con Set

Por ejemplo:

Calendar c1 = Calendar.getInstance();

Llamada:

public final void set(int year,int month,int date)

c1.set(2009, 6, 12);//把Calendar对象c1的年月日分别设这为：2009、6、12

Configuración mediante el tipo de campo.

Si solo se establece un campo, por ejemplo el valor de la fecha, se puede usar el siguiente método set:

public void set(int field,int value)

Establece la fecha representada por el objeto c1 al día 10; todos los demás valores se recalculan.

c1.set(Calendar.DATE,10);

Establece el año representado por el objeto c1 a 2008; todos los demás valores se recalculan.

c1.set(Calendar.YEAR,2008);

El significado de set para otros campos se deduce de manera similar.

Configuración con Add

Calendar c1 = Calendar.getInstance();

Suma 10 a la fecha del objeto c1, es decir, c1 representa la fecha 10 días después; todos los demás valores se recalculan.

c1.add(Calendar.DATE, 10);

Resta 10 a la fecha del objeto c1, es decir, c1 representa la fecha 10 días antes; todos los demás valores se recalculan.

c1.add(Calendar.DATE, -10);

El significado de add para otros campos se deduce de manera similar.

Clase GregorianCalendar

La clase Calendar implementa el calendario gregoriano; GregorianCalendar es una implementación concreta de la clase Calendar.

El método getInstance() de Calendar devuelve un objeto GregorianCalendar inicializado por defecto con la configuración regional y la zona horaria actuales. GregorianCalendar define dos campos: AD y BC. Estos representan las dos eras definidas por el calendario gregoriano.

    Los meses de Calendar son desde0en adelante, pero las fechas y los años son desde1en adelante.

    Código de ejemplo:

    import java.util.Calendar;

public class Test {
    public static void main(String[] args) {
            Calendar c1 = Calendar.getInstance();
            c1.set(2017, 1, 1);
            System.out.println(c1.get(Calendar.YEAR)
                    +"-"+c1.get(Calendar.MONTH)
                    +"-"+c1.get(Calendar.DATE));
            c1.set(2017, 1, 0);
            System.out.println(c1.get(Calendar.YEAR)
                    +"-"+c1.get(Calendar.MONTH)
                    +"-"+c1.get(Calendar.DATE));
    }
}

    Resultado de la ejecución:

    2017-1-1
2017-0-31

    Se puede ver que al establecer la fecha en 0, el mes se convierte en el mes anterior, pero el mes puede ser 0.

    Prueba cambiando el mes a 2:

    import java.util.Calendar;

public class Test {
    public static void main(String[] args) {
            Calendar c1 = Calendar.getInstance();
            c1.set(2017, 2, 1);
            System.out.println(c1.get(Calendar.YEAR)
                    +"-"+c1.get(Calendar.MONTH)
                    +"-"+c1.get(Calendar.DATE));
            c1.set(2017, 2, 0);
            System.out.println(c1.get(Calendar.YEAR)
                    +"-"+c1.get(Calendar.MONTH)
                    +"-"+c1.get(Calendar.DATE));
    }
}

    Resultado de la ejecución:

    2017-2-1
2017-1-28

    Se puede ver que el último día del mes anterior es el 28, por lo que cuando Calendar.MONTH es 1, es febrero.

    Dado que establecer la fecha en 0 representa el último día del mes anterior, ¿se puede establecer como un número negativo?

    import java.util.Calendar;

public class Test {
    public static void main(String[] args) {
            Calendar c1 = Calendar.getInstance();
            c1.set(2017, 2, 1);
            System.out.println(c1.get(Calendar.YEAR)
                    +"-"+c1.get(Calendar.MONTH)
                    +"-"+c1.get(Calendar.DATE));
            c1.set(2017, 2, -10);
            System.out.println(c1.get(Calendar.YEAR)
                    +"-"+c1.get(Calendar.MONTH)
                    +"-"+c1.get(Calendar.DATE));
    }
}

    Resultado de la ejecución:

    2017-2-1
2017-1-18

    Efectivamente se puede, por lo que las fechas se pueden sumar y restar libremente.

    Los meses también pueden ser negativos; la regla es la misma que con las fechas, así que no incluyo el código.

    Al probar, cuando se establece el año como un número no positivo, automáticamente se convierte en valor absoluto + 1; se desconoce su significado.
