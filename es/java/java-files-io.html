Java Flujos (Stream), Archivos (File) e IO

Los flujos (Stream), archivos (File) e IO (entrada/salida) en Java son la infraestructura para manejar la lectura y escritura de datos, y permiten que los programas interactúen con datos externos (como archivos, redes, entrada del sistema, etc.).

El paquete java.io es un paquete central en la biblioteca estándar de Java; proporciona clases para la entrada y salida del sistema, e incluye herramientas para manejar flujos de datos (flujos de bytes y de caracteres), lectura y escritura de archivos, serialización y formato de datos.

java.io es el paquete base para manejar operaciones de archivos, operaciones de flujos y operaciones de IO de bajo nivel.

Los flujos en el paquete java.io admiten muchos formatos, como: tipos primitivos, objetos, conjuntos de caracteres localizados, etc.

Un flujo puede entenderse como una secuencia de datos. Un flujo de entrada representa la lectura de datos desde un origen, y un flujo de salida representa la escritura de datos hacia un destino.

Lectura de entrada de consola

La entrada de consola en Java se realiza mediante System.in.

Para obtener un flujo de caracteres vinculado a la consola, puedes envolver System.in en un objeto BufferedReader para crear un flujo de caracteres.

La siguiente es la sintaxis básica para crear un BufferedReader:

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

Una vez creado el objeto BufferedReader, podemos usar el método read() para leer un carácter desde la consola, o el método readLine() para leer una cadena.

Leer entrada de múltiples caracteres desde la consola

Para leer un carácter de un objeto BufferedReader se utiliza el método read(), cuya sintaxis es la siguiente:

int read( ) throws IOException

Cada vez que se llama al método read(), este lee un carácter del flujo de entrada y lo devuelve como un valor entero. Cuando el flujo llega a su fin, devuelve -1. Este método lanza IOException.

El siguiente programa demuestra el uso del método read() para leer caracteres desde la consola hasta que el usuario ingreseq。

Código del archivo BRRead.java:

//Usar BufferedReader para leer caracteres en la consola import java.io.*; public class BRRead { public static void main(String[] args) throws IOException { char c; //Usar System.in para crear un BufferedReader BufferedReader br = new BufferedReader(new InputStreamReader(System.in)); System.out.println("Ingrese caracteres, presione la tecla 'q' para salir."); //Leer caracteres do { c = (char) br.read(); System.out.println(c); } while (c != 'q'); } }

Leer cadenas desde la consola

Para leer una cadena desde la entrada estándar se necesita usar el método readLine() de BufferedReader.

Su formato general es:

String readLine( ) throws IOException

El siguiente programa lee y muestra líneas de caracteres hasta que ingreses la palabra "end".

Código del archivo BRReadLines.java:

//Usar BufferedReader para leer caracteres en la consola import java.io.*; public class BRReadLines { public static void main(String[] args) throws IOException { //Usar System.in para crear un BufferedReader BufferedReader br = new BufferedReader(new InputStreamReader(System.in)); String str; System.out.println("Enter lines of text."); System.out.println("Enter 'end' to quit."); do { str = br.readLine(); System.out.println(str); } while (!str.equals("end")); } }

Salida de consola

Como se ha explicado anteriormente, la salida de consola se realiza con print() y println(). Estos métodos están definidos por la clase PrintStream, y System.out es una referencia a un objeto de esa clase.

PrintStream hereda de la clase OutputStream e implementa el método write(). De esta manera, write() también se puede usar para escribir en la consola.

El formato más simple de write() definido por PrintStream se muestra a continuación:

void write(int byteval)

Este método escribe el byte de orden inferior de byteval en el flujo.

Ejemplo

El siguiente ejemplo usa write() para enviar a la pantalla el carácter 'A' y el salto de línea que le sigue:

Código del archivo WriteDemo.java:

import java.io.*; //Demuestra System.out.write(). public class WriteDemo { public static void main(String[] args) { int b; b = 'A'; System.out.write(b); System.out.write('\n'); } }

Al ejecutar el ejemplo anterior, se muestra el carácter 'A' en la ventana de salida.

A

Nota:El método write() no se usa con frecuencia, porque los métodos print() y println() son más convenientes de usar.

InputStream f = new FileInputStream("C:/java/hello");

También se puede usar un objeto File para crear un objeto de flujo de entrada y leer el archivo. Primero debemos usar el método File() para crear un objeto File:

File f = new File("C:/java/hello"); InputStream in = new FileInputStream(f);

FileOutputStream

Esta clase se utiliza para crear un archivo y escribir datos en él.

Si el archivo de destino no existe antes de que el flujo abra el archivo para salida, el flujo creará el archivo.

Use un nombre de archivo de tipo cadena para crear un objeto de flujo de salida:

OutputStream f = new FileOutputStream("C:/java/hello")

También se puede usar un objeto File para crear un flujo de salida y escribir en el archivo. Primero debemos usar el método File() para crear un objeto File:

File f = new File("C:/java/hello"); OutputStream fOut = new FileOutputStream(f);

Directorios en Java

Crear directorios:

En la clase File hay dos métodos que se pueden usar para crear carpetas:

  • mkdir( )El método crea una carpeta; si tiene éxito, devuelve true; si falla, devuelve false. El fallo indica que la ruta especificada por el objeto File ya existe, o que la carpeta no se puede crear porque la ruta completa aún no existe.
  • mkdirs()El método crea una carpeta y todas sus carpetas padre.

El siguiente ejemplo crea la carpeta "/tmp/user/java/bin":

Código del archivo CreateDir.java:

import java.io.File; public class CreateDir { public static void main(String[] args) { String dirname = "/tmp/user/java/bin"; File d = new File(dirname); //Ahora creando el directorio d.mkdirs(); } }

Compile y ejecute el código anterior para crear el directorio "/tmp/user/java/bin".

Nota:Java distingue automáticamente los separadores de ruta de archivo según la convención en UNIX y Windows. Si usa el separador (/) en la versión de Java para Windows, la ruta aún se puede analizar correctamente.

Leer directorios

Un directorio es en realidad un objeto File que contiene otros archivos y carpetas.

Si se crea un objeto File y este es un directorio, al llamar al método isDirectory() devolverá true.

Se puede extraer la lista de archivos y carpetas que contiene llamando al método list() de ese objeto.

El siguiente ejemplo muestra cómo usar el método list() para verificar el contenido de una carpeta:

Código del archivo DirList.java:

import java.io.File; public class DirList { public static void main(String args[]) { String dirname = "/tmp"; File f1 = new File(dirname); if (f1.isDirectory()) { System.out.println("Directorio" + dirname); String s[] = f1.list(); for (int i = 0; i < s.length; i++) { File f = new File(dirname + "/" + s[i]); if (f.isDirectory()) { System.out.println(s[i] + "es un directorio"); } else { System.out.println(s[i] + "es un archivo"); } } } else { System.out.println(dirname + "no es un directorio"); } } }

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

bin 是一个目录
lib 是一个目录
demo 是一个目录
test.txt 是一个文件
README 是一个文件
index.html 是一个文件
include 是一个目录

Eliminar directorios o archivos

Para eliminar archivos se puede usarjava.io.File.delete()el método.

El siguiente código eliminará el directorio/tmp/java/. Tenga en cuenta que al eliminar un directorio, debe asegurarse de que no haya otros archivos en ese directorio para poder eliminarlo correctamente; de lo contrario, la eliminación fallará.

Estructura del directorio de prueba:

/tmp/java/
|-- 1.log
|-- test

Código del archivo DeleteFileDemo.java:

import java.io.File; public class DeleteFileDemo { public static void main(String[] args) { //Aquí cámbielo a su propio directorio de prueba File folder = new File("/tmp/java/"); deleteFolder(folder); } //Eliminar archivos y directorios public static void deleteFolder(File folder) { File[] files = folder.listFiles(); if (files != null) { for (File f : files) { if (f.isDirectory()) { deleteFolder(f); } else { f.delete(); } } } folder.delete(); } }

    A veces es necesario listar los archivos de un tipo específico en un directorio, por ejemplo: archivos con extensiones como .java, .txt, etc. Se pueden usar los siguientes dos métodos de la clase File para listar los archivos de un tipo específico:

    • 1、public String[ ] list(FilenameFilter obj)Este método devuelve todos los archivos del tipo especificado en el directorio en forma de cadena.
    • 2、public File[ ] listFile(FilenameFilter obj)Este método devuelve todos los archivos del tipo especificado en el directorio en forma de objeto File.

    El parámetro FilenameFilter de los dos métodos anteriores es una interfaz, y esta interfaz tiene un método:

    public boolean accept(File f,String name);

    Cuando el objeto File f llama al método list, es necesario pasar a este método un objeto que implemente la interfaz FilenameFilter. Cuando se ejecuta el método list, el parámetro obj invoca repetidamente el método de la interfaz accept(File f, String name). En este método, el parámetro f es el directorio actual que llama a list, y el parámetro name se instancia como un nombre de archivo en el directorio actual. Cuando el método de la interfaz devuelve true, el método list guarda el archivo con el nombre name en el array devuelto.

    BufferedReader admite sincronización, mientras que Scanner no. Si manejamos programas multiproceso, se debe usar BufferedReader.

    BufferedReader tiene un búfer de memoria lo suficientemente grande en comparación con Scanner.

    Scanner tiene un búfer muy pequeño (búfer de caracteres de 1KB) en comparación con BufferedReader (búfer de bytes de 8KB), pero esto es más que suficiente.

    BufferedReader es un poco más rápido que Scanner, porque Scanner analiza los datos de entrada, mientras que BufferedReader simplemente lee secuencias de caracteres.

    Usar flujos io para la copia simple de archivos:

    El contenido de test.txt es:

    Código:

    import java.io.*;

public class Test {
    public static void main(String[] args) {
        File sourcefile = new File("./test.txt");
        File copyfile = new File("./testcopy.txt");
        FileInputStream fileInputStream = null;// 从文件中读数据
        FileOutputStream fileOutputStream = null;// 用于把数据写入文件
        BufferedWriter bufferedWriter = null;// 用于把数据写入文件
        try {
            if (!sourcefile.exists()) {
                sourcefile.createNewFile();
                bufferedWriter = new BufferedWriter(new FileWriter(sourcefile));
                // bufferedwriter 自动追加数据
                String s = new String(" I love Java");

                char bchar[] = s.toCharArray();
                for (int i = 0; i < 5; i++) {
                    // 两种方式往文件中写数据
                    bufferedWriter.write(bchar, 0, bchar.length);
                    bufferedWriter.write(", " + s + "\n");
                }
                // 写完之后才能关闭流,
                bufferedWriter.flush();
                bufferedWriter.close();
            }
            copyfile.createNewFile();
            fileInputStream = new FileInputStream(sourcefile);
            fileOutputStream = new FileOutputStream(copyfile);
            byte b[] = new byte[8192];
            int len = b.length;
            while ((len = fileInputStream.read(b, 0, len)) > 0) {
                fileOutputStream.write(b, 0, len);
                fileOutputStream.flush();
            }
            System.out.println("file copied");
            fileInputStream.close();
            fileOutputStream.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
