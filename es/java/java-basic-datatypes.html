Tipos de variables en Java

Tipos de datos básicos de Java

Una variable es solicitar memoria para almacenar valores. Es decir, cuando se crea una variable, es necesario solicitar espacio en la memoria.

El sistema de gestión de memoria asigna espacio de almacenamiento a la variable según su tipo, y el espacio asignado solo puede utilizarse para almacenar datos de ese tipo.

Por lo tanto, al definir variables de diferentes tipos, se pueden almacenar enteros, decimales o caracteres en la memoria.

Los dos grandes tipos de datos de Java:

  • Tipos de datos integrados
  • Tipos de datos de referencia

Tipos de datos integrados

El lenguaje Java proporciona ocho tipos básicos. Seis tipos numéricos (cuatro enteros, dos de coma flotante), un tipo de carácter y un tipo booleano.

byte：

  • El tipo de datos byte es un entero de 8 bits, con signo, representado en complemento a dos;
  • El valor mínimo es-128（-2^7）；
  • El valor máximo es127（2^7-1）；
  • El valor por defecto es0；
  • El tipo byte se utiliza en arrays grandes para ahorrar espacio, principalmente en lugar de enteros, porque el espacio que ocupa una variable byte es solo una cuarta parte del tipo int;
  • Ejemplo: byte a = 100, byte b = -50.

short：

  • El tipo de datos short es un entero de 16 bits, con signo, representado en complemento a dos.
  • El valor mínimo es-32768（-2^15）；
  • El valor máximo es32767（2^15 - 1）；
  • El tipo de datos Short también puede ahorrar espacio como byte. Una variable short ocupa la mitad del espacio que ocupa una variable de tipo int;
  • El valor por defecto es0；
  • Ejemplo: short s = 1000, short r = -20000.

int：

  • El tipo de datos int es un entero de 32 bits, con signo, representado en complemento a dos;
  • El valor mínimo es-2,147,483,648（-2^31）；
  • El valor máximo es2,147,483,647（2^31 - 1）；
  • Generalmente, las variables enteras son de tipo int por defecto;
  • El valor por defecto es0 ；
  • Ejemplo: int a = 100000, int b = -200000.

long：

  • El tipo de datos long es un entero de 64 bits, con signo, representado en complemento a dos;
  • El valor mínimo es-9,223,372,036,854,775,808（-2^63）；
  • El valor máximo es9,223,372,036,854,775,807（2^63 -1）；
  • Este tipo se utiliza principalmente en sistemas que necesitan enteros grandes;
  • El valor por defecto es0L；
  • Ejemplo:long a = 100000L，long b = -200000L。
    En teoría, la 'L' no distingue entre mayúsculas y minúsculas, pero si se escribe como 'l', es fácil confundirla con el número '1', no es fácil de distinguir. Por lo tanto, es mejor usar mayúscula.

float：

  • El tipo de datos float es un número de coma flotante de precisión simple, de 32 bits, que cumple con el estándar IEEE 754;
  • float puede ahorrar espacio de memoria al almacenar grandes arrays de coma flotante;
  • El valor por defecto es0.0f；
  • Los números de coma flotante no se pueden usar para representar valores exactos, como moneda;
  • Ejemplo: float f1 = 234.5f.

double：

  • El tipo de datos double es un número de coma flotante de doble precisión, de 64 bits, que cumple con el estándar IEEE 754;
  • El tipo predeterminado de los números de coma flotante es double;
  • El tipo double tampoco puede representar valores exactos, como moneda;
  • El valor por defecto es0.0d；

  • Ejemplo:

    double   d1  = 7D ;
double   d2  = 7.; 
double   d3  =  8.0; 
double   d4  =  8.D; 
double   d5  =  12.9867;

    7 es un literal int, mientras que 7D, 7. y 8.0 son literales double.

boolean：

  • El tipo de datos boolean representa información de un bit;
  • Solo tiene dos valores: true y false;
  • Este tipo se usa solo como un indicador para registrar situaciones true/false;
  • El valor por defecto esfalse；
  • Ejemplo: boolean one = true.

char：

  • El tipo char es un único carácter Unicode de 16 bits;
  • El valor mínimo es\u0000(el valor equivalente en decimal es 0);
  • El valor máximo es\uffff(es decir, 65535);
  • El tipo de datos char puede almacenar cualquier carácter;
  • Ejemplo: char letter = 'A';.

Tipos de referencia

  • En Java, las variables de tipo de referencia son muy similares a los punteros de C/C++. Un tipo de referencia apunta a un objeto; la variable que apunta al objeto es una variable de referencia. Estas variables se especifican con un tipo concreto en el momento de la declaración, como Employee, Puppy, etc. Una vez que la variable se declara, su tipo no se puede cambiar.
  • Los objetos y los arrays son tipos de datos de referencia.
  • El valor por defecto de todos los tipos de referencia es null.
  • Una variable de referencia se puede utilizar para referenciar cualquier tipo compatible con ella.
  • Ejemplo: Site site = new Site("Runoob").

Constantes de Java

Las constantes no se pueden modificar durante la ejecución del programa.

En Java, se usa la palabra clave final para modificar constantes. La forma de declaración es similar a la de las variables:

final double PI = 3.1415927;

Aunque los nombres de constantes también pueden ser en minúsculas, para facilitar su identificación, normalmente se usan letras mayúsculas para las constantes.

Los literales se pueden asignar a variables de cualquier tipo incorporado. Por ejemplo:

byte a = 68;
char a = 'A'

byte, int, long y short se pueden representar en decimal, hexadecimal y octal.

Al usar literales, el prefijo0indica octal, y el prefijo0xrepresenta hexadecimal, por ejemplo:

int decimal = 100;
int octal = 0144;
int hexa =  0x64;

Como en otros lenguajes, las constantes de cadena de Java son también secuencias de caracteres entre dos comillas. A continuación se muestran ejemplos de literales de cadena:

"Hello World"
"two\nlines"
"\"This is in quotes\""

Las constantes de cadena y las variables de carácter pueden contener cualquier carácter Unicode. Por ejemplo:

char a = '\u0001';
String a = "\u0001";

El lenguaje Java admite algunas secuencias especiales de caracteres de escape.

Conversión automática de tipos

Los datos enteros, reales (constantes) y de carácter se pueden mezclar en operaciones. Durante las operaciones, los datos de diferentes tipos se convierten primero al mismo tipo y luego se realiza la operación.

La conversión va de nivel bajo a nivel alto.

低  ------------------------------------>  高

byte,short,char—> int —> long—> float —> double

La conversión de tipos debe cumplir las siguientes reglas:

  • 1. No se puede realizar conversión de tipos sobre el tipo boolean.

  • 2. No se puede convertir un tipo de objeto a un objeto de una clase no relacionada.

  • 3. Al convertir un tipo de gran capacidad a un tipo de pequeña capacidad, se debe usar una conversión forzada de tipos.

  • 4. El proceso de conversión puede causar desbordamiento o pérdida de precisión, por ejemplo:

    int i =128;   
byte b = (byte)i;

    Debido a que el tipo byte es de 8 bits y su valor máximo es 127, cuando se convierte int forzosamente a byte, el valor 128 causará desbordamiento.

  • 5. La conversión de punto flotante a entero se obtiene descartando la parte decimal, no redondeando, por ejemplo:

    (int)23.7 == 23;        
(int)-45.89f == -45

Conversión automática de tipos

Debe cumplir que el número de bits del tipo de datos antes de la conversión sea menor que el del tipo de datos después de la conversión. Por ejemplo: el tipo de datos short tiene 16 bits y puede convertirse automáticamente al tipo int con 32 bits; de igual forma, el tipo de datos float tiene 32 bits y puede convertirse automáticamente al tipo double con 64 bits.

Ejemplo

public class ZiDongLeiZhuan{ public static void main(String[] args){ char c1='a';//Definir un tipo char int i1 = c1;//char se convierte automáticamente a int System.out.println("El valor de char después de la conversión automática a int es igual a"+i1); char c2 = 'A';//Definir un tipo char int i2 = c2+1;//Cálculo entre el tipo char y el tipo int System.out.println("El valor después del cálculo entre char e int es igual a"+i2); } }

El resultado de la ejecución es:

char自动类型转换为int后的值等于97
char类型和int计算后的值等于66

Análisis:El valor de c1 es el carácteraAl consultar la tabla ASCII, sabemos que el valor int correspondiente es 97, y el valor correspondiente para A es 65, por lo tantoi2=65+1=66。

Conversión forzada de tipos

  • 1. La condición es que el tipo de datos a convertir debe ser compatible.

  • 2. Formato: (type)value type es el tipo de datos después de la conversión forzada Ejemplo:

    Ejemplo

    public class ForceTransform { public static void main(String[] args){ int i1 = 123; byte b = (byte)i1;//Conversión forzada a byte System.out.println("El valor después de la conversión forzada de int a byte es igual a"+b); } }

    Resultado de la ejecución:

    int强制类型转换为byte后的值等于123

Conversión implícita de tipos

  • 1. El tipo predeterminado para enteros es int.

  • 2. Los decimales son por defecto de tipo punto flotante double; al definir un tipo float, se debe agregar F o f después del número.

    Complemento sobre la conversión de tipos de datos

    1. Conversión de tipos de transición con clases envoltorio

    Generalmente, primero declaramos una variable, luego generamos una clase envoltorio correspondiente, y así podemos usar varios métodos de la clase envoltorio para la conversión de tipos. Por ejemplo:

    Cuando se desea convertir float a double:

    float f1=100.00f;
Float F1=new Float(f1);
double d1=F1.doubleValue();//F1.doubleValue()为Float类的返回double值型的方法

    Las variables de tipo simple pueden convertirse a las clases envoltorio correspondientes utilizando los constructores de las clases envoltorio. Es decir: Boolean(boolean value), Character(char value), Integer(int value), Long(long value), Float(float value), Double(double value)

    En cada clase envoltorio, siempre hay un método con la forma ××Value() para obtener su correspondiente tipo de dato simple. Usando este método, también se puede lograr la conversión entre diferentes variables numéricas. Por ejemplo, para una clase real de doble precisión, intValue() puede obtener su variable entera correspondiente, mientras que doubleValue() puede obtener su variable real de doble precisión correspondiente.

    2. Conversión entre cadenas y otros tipos

    Conversión de otros tipos a cadena

    • Llamar al método de conversión a cadena de la clase: X.toString();
    • Conversión automática: X+"";
    • Usar el método de String: String.valueOf(X);

    3. La cadena como valor, conversión a otros tipos

    1. Primero convertir a la instancia envoltorio correspondiente, luego llamar al método correspondiente para convertir a otros tipos

    Por ejemplo, la cadena "32.1" convertida al tipo double tiene el formato: new Float("32.1").doubleValue(). También se puede usar: Double.valueOf("32.1").doubleValue()

    2. Método estático parseXXX

    String s = "1";

short t = Short.parseShort( s );
int i = Integer.parseInt( s );

    3. Método getNumericValue(char ch) de Character

    4. Conversión mutua entre la clase Date y otros tipos de datos

    No existe una correspondencia directa entre el entero y la clase Date, pero puedes usar int para representar año, mes, día, hora, minuto y segundo, estableciendo así una correspondencia entre ambos. Al hacer esta conversión, puedes usar tres formas del constructor de la clase Date:

    • Date(int year, int month, int date): usa int para representar año, mes, día
    • Date(int year, int month, int date, int hrs, int min): usa int para representar año, mes, día, hora, minuto
    • Date(int year, int month, int date, int hrs, int min, int sec): usa int para representar año, mes, día, hora, minuto, segundo

    Existe una correspondencia interesante entre el entero largo y la clase Date: representar un tiempo como milisegundos desde las 00:00:00 del 1 de enero de 1970 GMT. Para esta correspondencia, la clase Date también tiene su constructor correspondiente: Date(long date)

    Para obtener el año, mes, día, hora, minuto, segundo y día de la semana de la clase Date, puedes usar los métodos getYear(), getMonth(), getDate(), getHours(), getMinutes(), getSeconds(), getDay() de la clase Date. También puedes entenderlo como convertir la clase Date a int.

    El método getTime() de la clase Date puede obtener el número de tipo long correspondiente a un tiempo, como mencionamos anteriormente. Igual que las clases envoltorio, la clase Date también tiene un método toString() que puede convertirla a la clase String.

String dateFormat=sy1.format(date);

SimpleDateFormat sy=new SimpleDateFormat("yyyy");
SimpleDateFormat sm=new SimpleDateFormat("MM");
SimpleDateFormat sd=new SimpleDateFormat("dd");
String syear=sy.format(date);
String smon=sm.format(date);
String sday=sd.format(date);

    Resumen:

    1. Solo boolean no participa en la conversión de tipos de datos.

    2. Conversión automática de tipos:

    • a. Las constantes pueden convertirse automáticamente dentro del rango de representación numérica.
    • b. Los datos con un rango menor pueden convertirse automáticamente a un tipo de datos con mayor rango (presta atención a los casos especiales).
    • De float a int, de float a long, de double a int, de double a long, etc.: al convertir de tipos de punto flotante a tipos enteros, la conversión no es automática; de lo contrario se perdería precisión.
    • c. Los tipos de referencia pueden convertirse automáticamente a su clase padre.
    • d. Los tipos primitivos y sus tipos envoltorio pueden convertirse entre sí.

    3. Conversión forzada de tipos: encierra el tipo destino entre paréntesis y colócalo delante de la variable.

    El autoboxing de la clase envoltorio Integer.

    Integer a = 1;

    Cuando un tipo int se asigna a la clase Integer, se encapsula automáticamente llamando al método valueOf(int i) de Integer.

    Integer a = Integer.valueOf(1);
    /**
 * Returns an {@code Integer} instance representing the specified
 * {@code int} value.  If a new {@code Integer} instance is not
 * required, this method should generally be used in preference to
 * the constructor {@link #Integer(int)}, as this method is likely
 * to yield significantly better space and time performance by
 * caching frequently requested values.
 *
 * This method will always cache values in the range -128 to 127,
 * inclusive, and may cache other values outside of this range.
 *
 * @param  i an {@code int} value.
 * @return an {@code Integer} instance representing {@code i}.
 * @since  1.5
 */
public static Integer valueOf(int i) {
    assert IntegerCache.high >= 127;
    if (i >= IntegerCache.low && i <= IntegerCache.high)
        return IntegerCache.cache[i + (-IntegerCache.low)];
    return new Integer(i);
}

    Cuando i >= -128 && i <= 127, Integer.valueOf(i) guarda i en el array static final Integer cache[] de la clase interna IntegerCache. La dirección de memoria de esta caché de un byte es estática; el valor de retorno es:

    IntegerCache.cache[i + (-IntegerCache.low)]

    Por lo tanto:

    Integer a = 1; 
Integer b = 1;

    Las referencias de a y b apuntan al mismo objeto, es decir,a == b。
