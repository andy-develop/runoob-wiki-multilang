Expresiones Lambda en Java

Nuevas características de Java 8

Una expresión Lambda, también llamada clausura, es la característica nueva más importante que impulsó el lanzamiento de Java 8.

Lambda permite usar una función como parámetro de un método (pasar una función como argumento a un método).

El uso de expresiones Lambda puede hacer que el código sea más conciso y compacto.

Sintaxis

El formato de sintaxis de una expresión lambda es el siguiente:

(parameters) -> expression 或 (parameters) ->{ statements; }

parameterses la lista de parámetros,expression 或 { statements; }es el cuerpo de la expresión Lambda. Si solo hay un parámetro, se pueden omitir los paréntesis; si no hay parámetros, también se necesitan paréntesis vacíos.

A continuación se muestra un ejemplo sencillo que demuestra el uso de una expresión Lambda para calcular la suma de dos números:

Ejemplo

// Usando una expresión Lambda para calcular la suma de dos números
MathOperation addition = (a, b) -> a + b;

// Llamando a la expresión Lambda
int result = addition.operation(5, 3);
System.out.println("5 + 3 = " + result);

En el ejemplo anterior, MathOperation es una interfaz funcional que contiene un método abstracto operation. La expresión Lambda(a, b) -> a + bimplementa ese método abstracto, representando la operación de sumar dos parámetros.

Las expresiones Lambda se pueden usar en diversos escenarios, incluyendo operaciones de colecciones, manejo de eventos, etc. A continuación se muestra un ejemplo de recorrido de una lista usando una expresión Lambda:

Ejemplo

List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// Usando una expresión Lambda para recorrer una lista
names.forEach(name -> System.out.println(name));

Las expresiones Lambda introdujeron en Java un estilo más funcional de programación, haciendo el código más conciso y legible. Son una mejora importante de Java 8 hacia la programación funcional.

Características importantes

Concisión

Las expresiones Lambda proporcionan una sintaxis más concisa, especialmente adecuada para interfaces funcionales. En comparación con las clases internas anónimas tradicionales, las expresiones Lambda hacen que el código sea más compacto y reducen la escritura de código repetitivo.

Ejemplo

// Clase interna anónima tradicional
Runnable runnable1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
};

// Usando una expresión Lambda
Runnable runnable2 = () -> System.out.println("Hello World!");

Soporte de programación funcional

Las expresiones Lambda son una manifestación de la programación funcional; permiten pasar funciones como parámetros a métodos o devolver funciones como valores de retorno. Este soporte hace que Java sea más flexible en programación funcional y pueda manejar mejor tareas como operaciones de colecciones y cálculo paralelo.

Ejemplo

// Usando una expresión Lambda como parámetro pasado a un método
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(name -> System.out.println(name));

Captura de variables

Las expresiones Lambda pueden acceder a variables del ámbito externo; esta característica se llama captura de variables. Las expresiones Lambda pueden capturar implícitamente variables locales finales o efectivamente finales.

Ejemplo

// Captura de variables
int x = 10;
MyFunction myFunction = y -> System.out.println(x + y);
myFunction.doSomething(5); // Imprime 15

Referencias a métodos

Las expresiones Lambda se pueden simplificar aún más mediante referencias a métodos. Las referencias a métodos le permiten referirse directamente a métodos de clases u objetos existentes, sin escribir código redundante.

Ejemplo

// Usando una referencia a método
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(System.out::println);

Paralelismo

Las expresiones Lambda permiten implementar operaciones paralelas de forma más conveniente. Al combinar la API Stream con expresiones Lambda, es más fácil realizar cálculos paralelos y mejorar el rendimiento del programa.

Ejemplo

// Usando expresiones Lambda y la API Stream para cálculo paralelo
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
int sum = numbers.parallelStream().mapToInt(Integer::intValue).sum();

La introducción de las expresiones Lambda hace que la programación en Java sea más flexible y concisa, e impulsa el desarrollo de la programación funcional.

Ejemplos de expresiones Lambda

Ejemplos sencillos de expresiones Lambda:

// 1. 不需要参数,返回值为 5  
() -> 5  
  
// 2. 接收一个参数(数字类型),返回其2倍的值  
x -> 2 * x  
  
// 3. 接受2个参数(数字),并返回他们的差值  
(x, y) -> x – y  
  
// 4. 接收2个int型整数,返回他们的和  
(int x, int y) -> x + y  
  
// 5. 接受一个 string 对象,并在控制台打印,不返回任何值(看起来像是返回void)  
(String s) -> System.out.print(s)

Ingrese el siguiente código en el archivo Java8Tester.java:

Archivo Java8Tester.java

public class Java8Tester { public static void main(String args[]){ Java8Tester tester = new Java8Tester(); //Declaración de tipo MathOperation addition = (int a, int b) -> a + b; //Sin declaración de tipo MathOperation subtraction = (a, b) -> a - b; //Declaración de retorno entre llaves MathOperation multiplication = (int a, int b) -> { return a * b; }; //Sin llaves y sin declaración de retorno MathOperation division = (int a, int b) -> a / b; System.out.println("10 + 5 = " + tester.operate(10, 5, addition)); System.out.println("10 - 5 = " + tester.operate(10, 5, subtraction)); System.out.println("10 x 5 = " + tester.operate(10, 5, multiplication)); System.out.println("10 / 5 = " + tester.operate(10, 5, division)); //Sin paréntesis GreetingService greetService1 = message -> System.out.println("Hello " + message); //Con paréntesis GreetingService greetService2 = (message) -> System.out.println("Hello " + message); greetService1.sayMessage("Runoob"); greetService2.sayMessage("Google"); } interface MathOperation { int operation(int a, int b); } interface GreetingService { void sayMessage(String message); } private int operate(int a, int b, MathOperation mathOperation){ return mathOperation.operation(a, b); } }

Al ejecutar el script anterior, el resultado es:

$ javac Java8Tester.java 
$ java Java8Tester

10 - 5 = 5
10 x 5 = 50
10 / 5 = 2

Hello Google

Al usar expresiones Lambda, se deben tener en cuenta los siguientes dos puntos:

  • Las expresiones Lambda se utilizan principalmente para definir interfaces de tipo método que se ejecutan en línea (por ejemplo, una interfaz de método simple). En el ejemplo anterior, usamos varios tipos de expresiones Lambda para definir el método de la interfaz MathOperation, y luego definimos la ejecución de operation.

  • Las expresiones Lambda eliminan la molestia de usar métodos anónimos y otorgan a Java una capacidad de programación funcional simple pero potente.

Ámbito de variables

Las expresiones lambda solo pueden hacer referencia a variables locales externas marcadas como final; esto significa que no se pueden modificar las variables locales definidas fuera del ámbito dentro de la lambda; de lo contrario, se producirá un error de compilación.

Ingrese el siguiente código en el archivo Java8Tester.java:

Archivo Java8Tester.java

public class Java8Tester { final static String salutation = "Hello! "; public static void main(String args[]){ GreetingService greetService1 = message -> System.out.println(salutation + message); greetService1.sayMessage("Runoob"); } interface GreetingService { void sayMessage(String message); } }

Al ejecutar el script anterior, el resultado es:

$ javac Java8Tester.java 
$ java Java8Tester
Hello! Runoob

También podemos acceder directamente a variables locales externas dentro de una expresión lambda:

Archivo Java8Tester.java

public class Java8Tester { public static void main(String args[]) { final int num = 1; Converter<Integer, String> s = (param) -> System.out.println(String.valueOf(param + num)); s.convert(2); //El resultado es 3 } public interface Converter<T1, T2> { void convert(int i); } }

Las variables locales de una expresión lambda no necesitan declararse como final, pero no deben ser modificadas por código posterior (es decir, tienen implícitamente la semántica de final).

int num = 1;  
Converter<Integer, String> s = (param) -> System.out.println(String.valueOf(param + num));
s.convert(2);
num = 5;  
//报错信息：Local variable num defined in an enclosing scope must be final or effectively 
 final

Dentro de una expresión Lambda no se permite declarar un parámetro o variable local con el mismo nombre que una variable local.

String first = "";  
Comparator<String> comparator = (first, second) -> Integer.compare(first.length(), second.length());  //编译会出错

        /*
         * 
         * 1.不需要参数,返回值为5
         * () -> 5
         * 
         * 2.接收一个参数(数字类型),返回其2倍的值
         * x -> 2 * x
         * 
         * 3.接收2个参数(数字类型),返回他们的差值
         * (x,y) -> x - y
         * 
         * 4.接收2个int型整数,返回他们的和
         * (int x, int y) -> x + y
         * 
         * 5.接收一个String对象,并在控制台打印,不返回任何值(返回void)
         * (String s) -> System.out.print(s)
         * 
         * 6.接收2个参数(数字类型),第1个数字加1,第2个数字加2,再求积
         * (int x, int y) -> { x += 1; y += 2; return x * y }
         * 
         */

        /*
         * 
         * MathOperation接口有且只有一个抽象方法operation时,
         * 可以使用 MathOperation addition = (int a, int b) -> a + b;
         * addition为实现了接口的一个对象,
         * (int a, int b) -> a + b;作为一个函数实现了MathOperation的抽象方法operation;
         * 当MathOperation接口存在两个抽象方法时;
         * MathOperation addition = (int a, int b) -> a + b;在编写时报错;
         * 
         */

        // 传入的参数带有类型声明
        MathOperation addition = (int a, int b) -> a + b;

        // 不用带类型声明
        MathOperation subtraction = (a, b) -> a = b;

        // 大括号中带返回语句
        MathOperation multiplication = (int a, int b) -> {
            return a * b;
        };

        // 没有带大括号及返回语句
        MathOperation division = (int a, int b) -> a / b;
        System.out.println("2 * 3 = " + operate(2, 3, multiplication));
        System.out.println("6 / 3 = " + operate(6, 3, (int a, int b) -> a / b));

        // 输出结果,无返回值
        GreetingService greetService = (String message) ->
        System.out.println("hello " + message);
        greetService.sayMessage("world");
    }

    interface MathOperation {
        int operation(int a, int b);
        // int operation2(int a, int b);
        default int operation3(int a, int b) {
            return a + b;
        }
    }

    interface GreetingService {
        void sayMessage(String message);
    }

    private int operate(int a, int b, MathOperation mathOperation) {
        return mathOperation.operation(a, b);

    Lambda

    El formato de una clase interna anónima:

    new 父类或接口() {​
    重写的方法;​ 
}

    En una clase interna anónima, gran parte del contenido es redundante.

    Por ejemplo, en el código que utiliza clases internas anónimas para implementar subprocesos múltiples.

    • Debido a que el constructor de Thread requiere pasar un parámetro del tipo de interfaz Runnable, no tenemos más remedio que usar new Runnable.
    • Porque hay que sobrescribir el método run de Runnable, por lo que no queda más remedio que escribir public void run.

    Lo más crucial en toda la clase interna anónima es el método, y lo más crucial del método tiene tres puntos: el principio, el medio y el final.

    • Principio: parámetros.
    • Medio: cuerpo del método.
    • Final: valor de retorno.

    Lo mejor es centrarse solo en el contenido más esencial de la clase interna anónima (parámetros del método, cuerpo del método, valor de retorno). Si se usa una expresión Lambda, se puede prestar atención solo al contenido más esencial. La expresión Lambda es una forma simplificada de escribir la clase interna anónima.

    Lambda pertenece al paradigma de programación funcional.

    • Paradigma orientado a objetos: cómo hacerlo.
    • Paradigma de programación funcional: qué hacer.
    public class Demo01Inner {
    public static void main(String[] args) {
        //使用匿名内部类的方式实现多线程。
        new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println(Thread.currentThread().getName() + "执行了");
            }
        }).start();

        //使用Lambda表达式实现多线程
        new Thread(() -> System.out.println(Thread.currentThread().getName() + "执行了")).start();
    }
}

    La clase interna anónima puede ahorrarnos la creación separada.javade archivos. Sin embargo, la clase interna anónima también tiene desventajas: la sintaxis es demasiado redundante y contiene muchas partes superfluas.

    La clase interna anónima también tiene una forma simplificada, y esa forma simplificada es la expresión Lambda. Lo más clave de la clase interna anónima son los parámetros del método, el cuerpo del método y el valor de retorno; y en la expresión Lambda, lo que se observa son precisamente estos tres elementos clave.

    Formato estándar de la expresión Lambda:

    (参数类型 参数名) -> {
    方法体;
    return 返回值;
}

    Explicación del formato:

    • Los parámetros entre paréntesis se escriben igual que los parámetros de los métodos anteriores; se pueden escribir cualquier cantidad de parámetros, y si hay varios, deben separarse con comas.
    • -> es un operador que indica una acción direccional.
    • El cuerpo del método entre llaves y la escritura del valor de retorno return son iguales a los de los métodos anteriores entre llaves.

    La expresión Lambda es un paradigma de programación funcional.

    Programación funcional: lo que se puede deducir, se puede omitir.

    • Debido a que el constructor de Thread requiere un parámetro de tipo Runnable, se puede omitir new Runnable.
    • Debido a que Runnable tiene solo un método abstracto, run, lo que se sobrescribe necesariamente es ese método run, por lo que se puede omitir la parte de declaración del método run (public void run).

    La expresión Lambda puede omitir algunas formalidades de la programación orientada a objetos, permitiéndonos centrarnos solo en el contenido más esencial.

    public class Demo02Lambda {
    public static void main(String[] args) {
        //实现多线程（单独创建.java）
        new Thread(new Task()).start();
        //使用匿名内部类的方式实现多线程
        new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println(Thread.currentThread().getName() + "执行了");
            }
        }).start();
        //使用Lambda表达式完成多线程
        new Thread(() -> {
            System.out.println(Thread.currentThread().getName() + "执行了");
        }).start();
    }
}

    Comparación entre clase interna anónima y función Lambda

    public class Demo03Collections {
    public static void main(String[] args) {
        //创建集合
        List<Student> list = new ArrayList<>();
        //添加元素
        list.add(new Student("嫐", 20));
        list.add(new Student("嬲", 18));
        list.add(new Student("挊", 22));
        //使用比较器排序对集合中的学生对象根据年龄升序排序
        //Collections.sort(list, new Rule());

        //使用匿名内部类
        Collections.sort(list, new Comparator<Student>() {
            @Override
            public int compare(Student o1, Student o2) {
                return o1.getAge() - o2.getAge();
            }
        });
       
        //使用Lambda表达式
        Collections.sort(list, (Student o1, Student o2) -> {
            return o1.getAge() - o2.getAge();
        });

        Collections.sort(list, (o1, o2) -> o1.getAge() - o2.getAge());

        System.out.println(list);

    }
}

    Formato Lambda

    Formato estándar de la expresión Lambda:

    (参数类型 参数名) -> {
    方法体;
    return 返回值;
}

    Reglas de omisión de la expresión Lambda:

    • 1. El tipo de los parámetros entre paréntesis se puede omitir.
    • 2. Si solo hay un parámetro entre paréntesis, se pueden omitir los paréntesis.
    • 3. Si solo hay una declaración entre llaves, se pueden omitir las llaves, return y el punto y coma.
    public class Demo04SimpleLambda {
    //定义方法，使用接口当做参数
    public static void method(MyInterface m) {
        m.printStr("hello");
    }

    public static void main(String[] args) {
        //调用method方法，参数传递MyInterface实现类对象
        method(new MyInterface() {
            @Override
            public void printStr(String str) {
                System.out.println(str);
            }
        });
        //使用Lambda表达式的标准格式。
        method((String str) -> {
            System.out.println(str);
        });

        //1. 小括号中的参数类型可以省略。
        method((str) -> {
            System.out.println(str);
        });
        //2. 如果小括号中只有一个参数，那么可以省略小括号。
        method(str -> {
            System.out.println(str);
        });
        //3. 如果大括号中只有一条语句，那么可以省略大括号，return，分号。
        method(str -> System.out.println(str));
    }
}

    Condiciones de uso de Lambda

    Requisitos previos para el uso de la expresión Lambda:

    • Debe haber una interfaz (no una clase abstracta), y la interfaz debe tener exactamente un método abstracto que deba sobrescribirse.
    • Debe admitir inferencia de contexto; debe poder deducirse a cuál interfaz corresponde el contenido representado por la expresión Lambda.

    Se puede usar la interfaz como parámetro y luego pasar una expresión Lambda (común), o se puede asignar la expresión Lambda a una variable de tipo interfaz.

    public class Demo05BeforeLambda {
    //使用接口当做参数
    public static void method(MyInterface m) {//m = s -> System.out.println(s)
        m.printStr("HELLO");
    }

    public static void main(String[] args) {
        //使用接口当做参数，然后传递Lambda表达式。
        //method(s -> System.out.println(s));

        //使用匿名内部类方式创建对象
        /*
        MyInterface m = new MyInterface() {
            @Override
            public void printStr(String str) {
                System.out.println(str);
            }
        };
        */

        MyInterface m = str -> System.out.println(str);
        m.printStr("Hello");
    }
}
