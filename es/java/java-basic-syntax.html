Objetos y clases de Java

Sintaxis básica de Java

Un programa de Java puede considerarse como una colección de objetos que trabajan en conjunto llamando a los métodos de los demás. A continuación se presentan brevemente los conceptos de clase, objeto, método y variable de instancia.

  • Objeto: Un objeto es una instancia de una clase, tiene estado y comportamiento. Por ejemplo, un perro es un objeto; sus estados son: color, nombre, raza; sus comportamientos son: mover la cola, ladrar, comer, etc.
  • 类: Una clase es una plantilla que describe el comportamiento y el estado de un tipo de objetos.
  • Método: Un método es un comportamiento; una clase puede tener muchos métodos. Las operaciones lógicas, la modificación de datos y todas las acciones se realizan dentro de los métodos.
  • Variable de instancia: Cada objeto tiene variables de instancia únicas; el estado del objeto está determinado por los valores de estas variables de instancia.

Primer programa Java

A continuación, veamos un programa Java simple que mostrará una cadena de texto.Hello World

Ejemplo

public class HelloWorld { /*Primer programa Java * Mostrará la cadena Hello World*/ public static void main(String[] args) { System.out.println("Hello World"); //Salida: Hello World } }

Sintaxis básica

Al escribir programas Java, tenga en cuenta los siguientes puntos:

  • Sensible a mayúsculas y minúsculas: Java es sensible a mayúsculas y minúsculas, lo que significa que los identificadores Hello y hello son diferentes.
  • Nombre de clase: Para todas las clases, la primera letra del nombre de clase debe estar en mayúscula. Si el nombre de la clase consta de varias palabras, la primera letra de cada palabra debe estar en mayúscula, por ejemploMyFirstJavaClass 。
  • Nombre de método: Todos los nombres de métodos deben comenzar con una letra minúscula. Si el nombre del método contiene varias palabras, la primera letra de cada palabra posterior debe estar en mayúscula.
  • Nombre del archivo fuente: El nombre del archivo fuente debe ser igual al nombre de la clase. Al guardar el archivo, debe usar el nombre de la clase como nombre de archivo (recuerde que Java es sensible a mayúsculas y minúsculas), y la extensión del archivo es.java. (Si el nombre del archivo y el nombre de la clase no son iguales, se producirá un error de compilación).
  • Entrada del método principal: Todos los programas Java comienzan su ejecución con elpublic static void main(String[] args)método.

Identificadores de Java

Todos los componentes de Java necesitan nombres. Los nombres de clase, nombres de variables y nombres de métodos se denominan identificadores.

Con respecto a los identificadores de Java, hay los siguientes puntos a tener en cuenta:

  • Todos los identificadores deben comenzar con una letra (A-Z o a-z), un signo de dólar ($) o un guion bajo (_).
  • Después del primer carácter, puede ser cualquier combinación de letras (A-Z o a-z), signo de dólar ($), guion bajo (_) o dígitos.
  • Las palabras clave no pueden usarse como identificadores.
  • Los identificadores son sensibles a mayúsculas y minúsculas.
  • Ejemplos de identificadores válidos: age, $salary, _value, __1_value
  • Ejemplos de identificadores no válidos: 123abc, -salary

Modificadores de Java

Al igual que otros lenguajes, Java puede usar modificadores para modificar métodos y atributos de una clase. Principalmente hay dos tipos de modificadores:

  • Modificadores de control de acceso: default, public, protected, private
  • Modificadores de control no de acceso: final, abstract, static, synchronized

En capítulos posteriores, discutiremos en detalle los modificadores de Java.

Variables de Java

En Java hay principalmente los siguientes tipos de variables:
  • Variables locales
  • Variables de clase (variables estáticas)
  • Variables miembro (variables no estáticas)

Arreglos de Java

Un arreglo es un objeto almacenado en el montón (heap) que puede contener múltiples variables del mismo tipo. En capítulos posteriores, aprenderemos cómo declarar, construir e inicializar un arreglo.

Enumeraciones de Java

Java 5.0 introdujo las enumeraciones, que limitan una variable a valores predefinidos. El uso de enumeraciones puede reducir errores (bugs) en el código.

Por ejemplo, si diseñamos un programa para una juguería, limitará los jugos a tamaño pequeño, mediano y grande. Esto significa que no permitirá que los clientes pidan jugos de otros tamaños distintos a estos tres.

Ejemplo

class FreshJuice { enum FreshJuiceSize{ SMALL, MEDIUM , LARGE } FreshJuiceSize size; } public class FreshJuiceTest { public static void main(String[] args){ FreshJuice juice = new FreshJuice(); juice.size = FreshJuice.FreshJuiceSize.MEDIUM ; } }

Nota:Las enumeraciones pueden declararse por separado o declararse dentro de una clase. También se pueden definir métodos, variables y constructores en la enumeración.

Comentarios en Java

Similar a C/C++, Java también admite comentarios de una sola línea y de varias líneas.

Los caracteres en los comentarios serán ignorados por el compilador de Java.

public class HelloWorld { /*Este es el primer programa Java * Mostrará Hello World * Este es un ejemplo de comentario de varias líneas*/ public static void main(String[] args){ //Este es un ejemplo de comentario de una línea /*Este también es un ejemplo de comentario de una línea*/ System.out.println("Hello World"); } }

Para más contenido, consulte:Comentarios de Java。

Líneas en blanco en Java

Las líneas en blanco o las líneas con comentarios serán ignoradas por el compilador de Java.

Herencia

En Java, una clase puede derivarse de otras clases. Si deseas crear una clase y ya existe una clase que tiene las propiedades o métodos que necesitas, entonces puedes hacer que la clase recién creada herede de esa clase.

Utilizando la herencia, se pueden reutilizar los métodos y propiedades de las clases existentes sin tener que reescribir ese código. La clase heredada se llama superclase (super class), y la clase derivada se llama subclase (sub class).

Interfaces

En Java, las interfaces pueden entenderse como protocolos de comunicación entre objetos. Las interfaces desempeñan un papel muy importante en la herencia.

Las interfaces solo definen los métodos que se usarán en la derivación, pero la implementación concreta de los métodos depende completamente de la clase derivada.

    Desbordamiento de tipos de datos

    En Java, solo los tipos numéricos pueden participar en operaciones. Pero cada tipo de datos tiene su rango de valores.

    Por ejemplo, el tipo de datos byte, su rango de valores es-128 - 127 。

    Cuando usamosbyte b = 128;se producirá un error con seguridad.

    Pero si usamosbyte b = 127+1;no se producirá un error.

    Y el resultado de la operación es-128。

    Podemos considerar el rango de valores de un tipo de datos como un círculo. Cada dato adicional avanza una posición; cuando el dato alcanza el valor máximo, si sumamos 1, puede convertirse en el valor mínimo. Esto es el desbordamiento de datos.

    Rango de valores de byte

    En Java, byte ocupa un byte. ¿Por qué el rango de valores es-128~127？（-2^7~2^7-1）

    Las computadoras usan binario para representar datos. Un byte son 8 bits, donde el bit más alto representa el bit de signo (0 positivo, 1 negativo).

    Por lo tanto, el rango de valores de byte es1000 0000 到 0111 1111。

    En Java, los datos se representan mediante complemento a dos.

    El complemento a dos de un número positivo es igual al código original; el complemento a dos de un número negativo se obtiene invirtiendo cada bit del código original y luego sumando 1.

    1000 0000 es complemento a dos; réstale uno y luego invierte bit a bit para obtener su código original 1000 0000. (Resta uno para obtener 0111 1111, luego invierte bit a bit para obtener 1000 0000).

    Como es un número negativo, el valor mínimo de byte es-2^7=-128。

    El decimal de 0111 1111 es 2^7-1=127 (suma de una secuencia geométrica).

    byte es un byte, con 2^8=256 posibilidades en total, es decir, de -128 a 127.

    Lo mismo aplica para los demás tipos de datos primitivos:

    char no tiene valores negativos, ocupa dos bytes, por lo que su rango de valores es0~2^16-1（65535）。
