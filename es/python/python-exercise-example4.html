Problema:Ingresa un año, un mes y un día, y determina qué día del año es esa fecha.

Análisis del programa:Tomando como ejemplo el 5 de marzo, primero se suman los dos primeros meses y luego se agregan 5 días para obtener el día del año. En casos especiales, si es año bisiesto y el mes ingresado es mayor que 2, se debe considerar agregar un día adicional:

Código fuente del programa:

Ejemplo

#!/usr/bin/python3 year = int(input('year:\n')) month = int(input('month:\n')) day = int(input('day:\n')) months = (0,31,59,90,120,151,181,212,243,273,304,334) if 0 < month <= 12: sum = months[month - 1] else: print ('data error') sum += day leap = 0 if (year % 400 == 0) or ((year % 4 == 0) and (year % 100 != 0)): leap = 1 if (leap == 1) and (month > 2): sum += 1 print ('it is the %dth day.' % sum)

El resultado de salida del ejemplo anterior es:

year:

day:

it is the 158th day.

    Calculando los segundos de diferencia entre la fecha ingresada y el 1 de enero del año correspondiente, y luego dividiendo por los segundos de un día, 3600*24, se obtiene el día del año de la fecha ingresada.

    #!/usr/bin/env python3

import time

def datecount(date):
    date0=date[0:4]+"-01-01"
    datet=time.strptime(date,"%Y-%m-%d")     #将输入的字符串转化为时间元组
    date0t=time.strptime(date0,"%Y-%m-%d")  
    dates=time.mktime(datet)                #将时间元组转化为时间戳
    date0s=time.mktime(date0t)
    count=(dates-date0s)/(3600*24)          #输入日期的时间戳减当前年份0101的时间戳除以每天秒数
    return count+1

a=input("请输入日期：格式如2017-06-16\n")
print("{}是{}年第{}天".format(a,a[0:4],int(datecount(a))))

    Calculando el tiempo transcurrido mediante la diferencia entre la marca de tiempo unix del punto de entrada y la marca de tiempo Unix del primer día del año ingresado.

    #coding=utf-8
import time
print "Please Enter full number just like 02 01 03"
y = int(raw_input('Enter the year:'))  #分别输入年月日
m = int(raw_input('Enter the month:'))
d = int(raw_input('Enter the day:'))
a = (y,m,d,00,00,00,00,00,00)  #要求长度为9
b = (y,01,01,00,00,00,00,00,00)  #输入年份的第一天
timestampa = time.mktime(a)      #两个都转换为Unix时间戳，即1970.1.1到现在经过的秒数
timestampb = time.mktime(b)
timec = int((timestampa - timestampb)/(3600*24))  #输入的时间戳减去年份首天的时间戳等于经过的秒数，再换算成天，取整
print("There are {} days goes by!".format(timec))
