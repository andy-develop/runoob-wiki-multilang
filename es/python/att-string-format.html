Python format función de formato

Cadenas de Python

Desde Python2.6, se agregó una función para formatear cadenasstr.format(), que mejoró la funcionalidad del formateo de cadenas.

La sintaxis básica es mediante{} 和 :para reemplazar al anterior% 。

La función format puede aceptar un número ilimitado de parámetros, y las posiciones pueden no estar en orden.

Ejemplo

>>>"{} {}".format("hello", "world") # No se establece una posición específica, se usa el orden predeterminado 'hello world' >>> "{0} {1}".format("hello", "world") # Se establece una posición específica 'hello world' >>> "{1} {0} {1}".format("hello", "world") # Se establece una posición específica 'world hello world'

También se pueden establecer parámetros:

Ejemplo

#!/usr/bin/python # -*- coding: UTF-8 -*- print("Nombre del sitio: {name}, dirección {url}".format(name="Tutorial de Runoob", url="www.runoob.com")) # Establecer parámetros mediante un diccionario site = {"name": "Tutorial de Runoob", "url": "www.runoob.com"} print("Nombre del sitio: {name}, dirección {url}".format(**site)) # Establecer parámetros mediante índice de lista my_list = ['Tutorial de Runoob', 'www.runoob.com'] print("Nombre del sitio: {0".format(my_list)) # "0" es obligatorio

El resultado es:

网站名：菜鸟教程, 地址 www.runoob.com
网站名：菜鸟教程, 地址 www.runoob.com
网站名：菜鸟教程, 地址 www.runoob.com

También se pueden pasarstr.format()objetos a:

Ejemplo

#!/usr/bin/python # -*- coding: UTF-8 -*- class AssignValue(object): def __init__(self, value): self.value = value my_value = AssignValue(6) print('value es: {0.value}'.format(my_value)) # "0" es opcional

El resultado es:

value 为: 6

Base numérica

^, <, >Son respectivamente centrado, alineación a la izquierda y alineación a la derecha, seguidos del ancho,:Después del signo se coloca el carácter de relleno; solo puede ser un carácter; si no se especifica, se rellena con espacios por defecto.

+Indica mostrar antes de los números positivos+, mostrar antes de los negativos-； (espacio) indica agregar un espacio antes de los números positivos

b, d, o, x son respectivamente binario, decimal, octal y hexadecimal.

Además podemos usar llaves{}para escapar llaves, como en el siguiente ejemplo:

Ejemplo

#!/usr/bin/python # -*- coding: UTF-8 -*- print ("La posición correspondiente de {} es {{0}}".format("runoob"))

El resultado es:

runoob 对应的位置是 {0}

    Operador %, el formato es el siguiente:

    %[(name)][flags][width].[precision]typecode
    • (name)es para nombrar
    • flagsPuede ser +, -, ' ' o 0. + indica alineación a la derecha. - indica alineación a la izquierda. ' ' es un espacio, que indica agregar un espacio a la izquierda de los números positivos para alinearlos con los negativos. 0 indica rellenar con 0.
    • widthIndica el ancho de visualización
    • precisionIndica la precisión después del punto decimal

    Los siguientes son los códigos de tipo:

    %s    字符串 (采用str()的显示)
%r    字符串 (采用repr()的显示)
%c    单个字符
%b    二进制整数
%d    十进制整数
%i    十进制整数
%o    八进制整数
%x    十六进制整数
%e    指数 (基底写为e)
%E    指数 (基底写为E)
%f    浮点数
%F    浮点数，与上相同%g    指数(e)或浮点数 (根据显示长度)
%G    指数(E)或浮点数 (根据显示长度)
%%    字符"%"

    Ejemplos

    >>> print("%6.3f" % 2.3)
 2.300
    • El contenido después del primer % es la especificación de formato de visualización; 6 es el ancho de visualización, 3 es el número de decimales, f es el tipo de punto flotante.
    • Después del segundo % está la fuente del contenido mostrado; el resultado se alinea a la derecha, 2.300 tiene una longitud de 5, por lo tanto hay un espacio delante.
    >>> print("%+10x" % 10)
    +a

    x representa hexadecimal, con ancho de visualización 10; delante hay 8 espacios.

    >>>print("%-5x" % -10)
-a

    %-5xEl signo menos indica alineación a la izquierda; con ancho de visualización 5, después de -a hay 3 espacios.

    >>>pi=3.1415
>>>print ("pi的值是%s"%pi)
pi的值是3.1415

>>>print ("pi的值是%.8f"%pi)
pi的值是3.14150000

    Los width y precision anteriores son dos enteros. Podemos usar * para sustituir dinámicamente estas dos cantidades. Por ejemplo:

    >>> print("%10.*f" % (4, 1.2))
  1.2000

    Lo siguiente es un complemento:

    En pocas palabras, esta es una operación que coloca otras variables en posiciones específicas de una cadena para generar una nueva cadena, por ejemplo:

    >>> n = "Runoob"
>>> "My name is %s" % n
'My name is Runoob'

    Este código primero define una variable llamada n, con contenido Runoob. Luego, en la cadena de abajo hay un %s, cuyo significado es "aquí se reemplazará con una nueva cadena"; el contenido utilizado para el reemplazo se coloca después del % que sigue a la cadena, es decir, esa n. Así que finalmente esta cadena se convierte en My name is Runoob.

    Si alstr.format()llamar se utilizan argumentos de palabra clave, se puede hacer referencia a los valores mediante el nombre del parámetro:

    >>> print('This {food} is {adjective}.'.format(
...       food='spam', adjective='absolutely horrible'))
This spam is absolutely horrible.

    Los argumentos posicionales y de palabra clave se pueden combinar libremente:

    >>> print('The story of {0}, {1}, and {other}.'.format('Bill', 'Manfred', other='Georg')) The story of Bill, Manfred, and Georg.

    !a(aplicaascii())， !s(aplica str()) y!r(aplicarepr()) pueden convertir el valor antes del formateo:

    >>> import math
>>> print('The value of PI is approximately {}.'.format(math.pi))
The value of PI is approximately 3.14159265359.
>>> print('The value of PI is approximately {!r}.'.format(math.pi))
The value of PI is approximately 3.141592653589793.

    Después del nombre del campo se permiten opcionales:y directivas de formato. Esto permite un control más profundo sobre el formateo del valor. El siguiente ejemplo convierte Pi a tres dígitos de precisión.

    >>> import math
>>> print('The value of PI is approximately {0:.3f}.'.format(math.pi))
The value of PI is approximately 3.142.

    Después del nombre del campo, el:agregar un entero después limitará el ancho mínimo de ese campo; esto es útil para embellecer tablas:

    >>> table = {'Sjoerd': 4127, 'Jack': 4098, 'Dcab': 7678}
>>> for name, phone in table.items():
...     print('{0:10} ==> {1:10d}'.format(name, phone))
...
Jack       ==>       4098
Dcab       ==>       7678
Sjoerd     ==>       4127

    Si tienes una cadena de formato realmente larga y no quieres dividirla. Sería bueno si pudieras usar nombres para referenciar las variables a formatear en lugar de posiciones. Hay un método simple: pasar un diccionario, usando corchetes ([]) para acceder a sus claves:

    >>> table = {'Sjoerd': 4127, 'Jack': 4098, 'Dcab': 8637678}
>>> print('Jack: {0[Jack]:d}; Sjoerd: {0[Sjoerd]:d}; '
          'Dcab: {0[Dcab]:d}'.format(table))
Jack: 4098; Sjoerd: 4127; Dcab: 8637678

    También se puede usar el**indicador para pasar este diccionario como argumentos de palabra clave:

    >>> table = {'Sjoerd': 4127, 'Jack': 4098, 'Dcab': 8637678}
>>> print('Jack: {Jack:d}; Sjoerd: {Sjoerd:d}; Dcab: {Dcab:d}'.format(**table))
Jack: 4098; Sjoerd: 4127; Dcab: 8637678

    Como se mencionó anteriormente,^, <, >son respectivamente centrado, alineación a la izquierda y alineación a la derecha, seguidos del ancho; por defecto se usa la alineación a la derecha.:signo y el símbolo de alineación (^ > <) entre ellos se coloca el carácter de relleno, solo puede ser un carácter; por defecto se rellena con espacios. La salida de números de punto flotante también se puede alinear como enteros, con las mismas reglas; ejemplo

    >>> from math import pi
>>> '{:a>+10.2f}'.format(pi)
'aaaaa+3.14'

    El orden en el formato anterior es: carácter de relleno a, símbolo de alineación a la derecha >, salida del número con signo +, ancho de la cadena10, conservar 2 decimales.2f 。
