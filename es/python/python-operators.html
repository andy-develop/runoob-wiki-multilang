Python Operadores

¿Qué es un operador?

Este capítulo explica principalmente los operadores de Python. Pongamos un ejemplo sencillo. 4 +5 = 9 .4 和 5se llamaoperando，+se llama operador.

  • Operadores aritméticos
  • Operadores de comparación (relacionales)
  • Operadores de asignación
  • Operadores lógicos
  • Operadores de bits
  • Operadores de pertenencia
  • Operadores de identidad
  • Precedencia de operadores

A continuación, aprendamos los operadores de Python uno por uno.

Operadores de bits de Python

Los operadores de bits tratan los números como binarios para realizar cálculos. Las reglas de los operadores de bits en Python son las siguientes:

En la siguiente tabla, la variable a es 60, b es 13, y su formato binario es el siguiente:

a = 0011 1100

b = 0000 1101

-----------------

a&b = 0000 1100

a|b = 0011 1101

a^b = 0011 0001

~a  = 1100 0011
OperadorDescripciónEjemplo
&Operador AND a nivel de bits: de los dos valores que participan en la operación, si los dos bits correspondientes son 1, el resultado de ese bit es 1; de lo contrario, es 0.(a & b) da como resultado 12, en binario: 0000 1100
|Operador OR a nivel de bits: si al menos uno de los dos bits binarios correspondientes es 1, el bit de resultado es 1.(a | b) da como resultado 61, en binario: 0011 1101
^Operador XOR a nivel de bits: cuando los dos bits binarios correspondientes son diferentes, el resultado es 1.(a ^ b) da como resultado 49, en binario: 0011 0001
~Operador de complemento a nivel de bits: invierte cada bit de la representación binaria, 0 se convierte en 1 y 1 se convierte en 0.~xSimilar a-x-1(~a) da como resultado -61, en binario: 1100 0011 (representado en complemento a dos), en forma de complemento a dos de un número binario con signo.
<<Operador de desplazamiento a la izquierda: todos los bits del operando se desplazan a la izquierda un cierto número de posiciones, determinado por<<el número de la derecha especifica la cantidad de posiciones a desplazar. Los bits altos se descartan y los bits bajos se rellenan con 0.a << 2 da como resultado 240, en binario: 1111 0000
>>Operador de desplazamiento a la derecha: desplaza todos los bits binarios del operando a la izquierda de ">>" hacia la derecha varios lugares,>>El número de la derecha especifica el número de posiciones a desplazar.a >> 2 da como resultado 15, explicación binaria: 0000 1111

El siguiente ejemplo demuestra las operaciones de todos los operadores de bits de Python:

Ejemplo (Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 60 # 60 = 0011 1100 b = 13 # 13 = 0000 1101 c = 0 c = a & b; # 12 = 0000 1100 print "1 - El valor de c es:", c c = a | b; # 61 = 0011 1101 print "2 - El valor de c es:", c c = a ^ b; # 49 = 0011 0001 print "3 - El valor de c es:", c c = ~a; # -61 = 1100 0011 print "4 - El valor de c es:", c c = a << 2; # 240 = 1111 0000 print "5 - El valor de c es:", c c = a >> 2; # 15 = 0000 1111 print "6 - El valor de c es:", c

El resultado del ejemplo anterior es:

1 - c 的值为： 12
2 - c 的值为： 61
3 - c 的值为： 49
4 - c 的值为： -61
5 - c 的值为： 240
6 - c 的值为： 15

OperadorExpresión lógicaDescripciónEjemplo

orx or y"O" booleano: si x es distinto de 0, devuelve el valor calculado de x; de lo contrario, devuelve el valor calculado de y.(a or b) devuelve 10.

OperadorDescripciónEjemplo
inDevuelve True si se encuentra el valor en la secuencia especificada; de lo contrario, devuelve False. x en la secuencia y: si x está en la secuencia y, devuelve True.
not inDevuelve True si no se encuentra el valor en la secuencia especificada; de lo contrario, devuelve False. x no en la secuencia y: si x no está en la secuencia y, devuelve True.

Operadores de identidad de Python

Los operadores de identidad se utilizan para comparar las unidades de almacenamiento de dos objetos.

OperadorDescripciónEjemplo
isis determina si dos identificadores hacen referencia al mismo objeto x is y, similar aid(x) == id(y), si hacen referencia al mismo objeto, devuelve True; de lo contrario, devuelve False.
is notis not determina si dos identificadores hacen referencia a objetos diferentes x is not y, similar aid(a) != id(b). Si no hacen referencia al mismo objeto, devuelve True; de lo contrario, devuelve False.

Diferencia entre is y ==:

is se utiliza para determinar si dos variables referencian al mismo objeto (el mismo espacio de memoria); == se utiliza para determinar si los valores de las variables referenciadas son iguales.

>>> a = [1, 2, 3]
>>> b = a
>>> b is a 
True
>>> b == a
True
>>> b = a[:]
>>> b is a
False
>>> b == a
True

    >>> a=2.0

False
>>> a==b
True

    Python no tiene operadores de autoincremento ++ o --

    Porque en Python, valores numéricos, cadenas y similares son objetos inmutables; las operaciones sobre objetos inmutables generan un nuevo objeto.

    Por ejemplo:

    a = 1
a += 1

    En lenguajes como C/Java, el valor de los datos en la dirección de memoria a la que apunta a se cambia de 1 a 2.

    Pero en Python es un mecanismo completamente diferente.

    El intérprete crea un nuevo objeto entero 2.

    Luego asigna la dirección de este objeto nuevamente a a.

    Ver el siguiente código:

    >>> id(1)
41116008L
>>> a = 1
>>> id(a)
41116008L
>>> id(2)
41115984L
>>>a += 1
>>> id(a)
41115984L
>>>

    Por lo tanto, en Python no es posible tener el estilo de C/Java, ese 'uno por línea'i++，i--de.

    Respondiendo al primer comentario:

    He verificado la respuesta del primer comentario. Tal como se dijo, en Python, usar la palabra clave is para comparar dos números pequeños es ciertamente igual que el operador ==, el resultado también es true. Pero ¿hasta qué valor pequeño llega este número y cuál es el límite superior? Tras las pruebas, cuando el número es menor o igual a 256, ambos resultados son iguales; cuando es mayor que 256, el resultado de is es false.

    Mi suposición: 256 es exactamente un número binario de 8 bits, es decir, un byte, por lo que se puede concluir que cuando un número se puede representar con un byte, is y == dan el mismo resultado; cuando el número excede un byte, se tratan como objetos diferentes. Python asigna memoria distinta a números diferentes; números distintos son objetos distintos, solo que el valor es el mismo; el resultado de is es false, mientras que == sigue siendo true.

    Después de leer la respuesta de arriba, comprendí que Python crea un pequeño pool de enteros para almacenar estos números que se pueden representar con un byte. Esto evita asignar memoria repetidamente para valores numéricos pequeños, es decir, evita crear objetos repetidamente, y mejora el rendimiento del lenguaje.
