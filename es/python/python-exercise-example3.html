Problema:Un número entero, cuando se le suma 100, es un cuadrado perfecto; y al sumarle 168 nuevamente, también es un cuadrado perfecto. ¿Cuál es ese número?

Análisis del programa:

Supongamos que el número es x.

1. Entonces: x + 100 = n2, x + 100 + 168 = m2

2. Calcular la ecuación: m2 - n2 = (m + n)(m - n) = 168

3. Establecer: m + n = i, m - n = j, i * j = 168, i y j al menos uno es par.

4. Se obtiene: m = (i + j) / 2, n = (i - j) / 2, i y j son ambos pares o ambos impares.

5. De 3 y 4 se deduce que i y j son números pares mayores o iguales que 2.

6. Dado que i * j = 168, j >= 2, entonces1 < i < 168 / 2 + 1。

7. A continuación, basta con recorrer todos los valores de i en un bucle para calcular.

Código fuente del programa:

Ejemplo (Python 3.0+)

# Define la función de resolución
def find_integer():
    for i in range(2, 85):  # El rango de i va de 2 a 84
        if 168 % i == 0:  # i es un factor de 168
            j = 168 // i  # Calcula el j correspondiente
            if i > j and (i + j) % 2 == 0 and (i - j) % 2 == 0:  # Asegúrate de que i y j sean ambos pares o ambos impares
                m = (i + j) // 2
                n = (i - j) // 2
                x = n * n - 100
                print(f"x: {x}, m: {m}, n: {n}")

# Llama a la función de resolución
find_integer()

    Todos hicieron los cálculos y, basándome en los cálculos de los compañeros anteriores, ¡resulta que obtuve la respuesta, jajaja!

    Proceso:

    Citando al comentario anterior:

    Sea el número x: x + 100 = n^2, n^2 + 168 = m^2.

    Sea m = n + k (supongamos que m, n, k son números naturales): sustituyendo en m^2 - n^2 - 168, se obtiene k^2 + 2nk = 168.

    Sobre esta base, k(k + 2n) = 168. Si k es impar, k + 2n también es impar, por lo que la ecuación no se cumple; por tanto, k es par.

    Al dividir la ecuación entre 4, se obtiene (k/2)(k/2 + n) = 42. Sea t = k/2, (t > 0).

    t(t + n) = 42, entonces n = 42/t - t. Como n es mayor que 0, t es menor o igual que 6, y 42/t es un número entero, por lo que los valores de t son 1, 2, 3, 6.

    Correspondientemente, se obtiene x = 1581, 261, 21, -99.

    Como el enunciado dice que x es un entero, pero no especifica que n y m deban ser mayores que cero, aquí se considera el caso en que n y m son menores que cero.

    x + 100 = n^2; x + 100 + 168 = m^2; (nota: no se exige que m y n sean mayores que cero).

    m^2 - n^2 = 168, es decir, (m + n)(m - n) = 168;

    Sean m + n = i, m - n = j, entonces m = (i + j) / 2; n = (i - j) / 2. Tenemos i * j = 168. Como m y n son enteros y m != n, j, i != 0. Como i * j es un número positivo, abs(i) >= 1, abs(j) >= 1. Por lo tanto, el límite superior de i y j puede tomarse como 168. Así, el límite superior de m y n también es 168, y el límite inferior puede tomarse como -168 (nótese que los rangos de m y n pueden ampliarse sin afectar el resultado, porque las condiciones restrictivas pueden limitarse por uno mismo, pero el rango elegido debe ser mayor que el rango real).

    Código de prueba en Python3:

    x=[]
for m in range(-168,169):
    for n in range(-168,169):
        if (m+n)*(m-n)==168:#m,n都是整数
            x.append(n**2-100)
x=set(x)#用集合的方法去掉重复值
x=list(x)#将集合类型改为列表类型
print('要求的值为：',x)
