Python Sentencia de bucle for

El bucle for en Python puede iterar sobre los elementos de cualquier secuencia, como una lista o una cadena.

Sintaxis:

El formato de sintaxis del bucle for es el siguiente:

for iterating_var in sequence:
   statements(s)

Diagrama de flujo:

Ejemplo:

Ejemplo

#!/usr/bin/python # -*- coding: UTF-8 -*- for letter in 'Python': # Primer ejemplo print("Letra actual: %s" % letter) fruits = ['banana', 'apple', 'mango'] for fruit in fruits: # Segundo ejemplo print ('Fruta actual: %s'% fruit) print ("Good bye!")

Iterar mediante índice de secuencia

Otra forma de realizar el bucle es mediante el índice, como en el siguiente ejemplo:

Ejemplo

#!/usr/bin/python # -*- coding: UTF-8 -*- fruits = ['banana', 'apple', 'mango'] for index in range(len(fruits)): print ('Fruta actual : %s' % fruits[index]) print ("Good bye!")

El resultado del ejemplo anterior es:

当前水果 : banana
当前水果 : apple
当前水果 : mango
Good bye!

En el ejemplo anterior hemos usado las funciones integradas len() y range(). La función len() devuelve la longitud de la lista, es decir, el número de elementos. range devuelve una secuencia de números.


Usar la sentencia else en bucles

En Python, for … else significa que las sentencias dentro de for no son diferentes de las normales; las sentencias dentro de else se ejecutan cuando el bucle se completa normalmente (es decir, cuando for no se interrumpe mediante break). while … else también es igual.

Ejemplo

#!/usr/bin/python # -*- coding: UTF-8 -*- for num in range(10,20): # Iterar los números entre 10 y 20 (sin incluir) for i in range(2,num): # Iterar según los factores if num%i == 0: # Determinar el primer factor j=num/i # Calcular el segundo factor print ('%d es igual a %d * %d' % (num,i,j)) break # Salir del bucle actual else: # La parte else del bucle print ('%d es un número primo' % num)

prime = []

    print 'i=:', i

print "使用xrange还是一样的效果"
for i in xrange(1,10,1):     #还是只能执行9次,和其他语言的 i=1 to 10 可执行10次是不同的
    print 'i=:', i

    print '没执行这里：i=:', i

for i in xrange(0,10,2):
    print(i)
