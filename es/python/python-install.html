Python Configuración del entorno

Python es un lenguaje de programación multiplataforma que puede ejecutarse en múltiples sistemas operativos.

En este capítulo le mostraremos cómo configurar un entorno de desarrollo de Python localmente.

Python se puede aplicar en múltiples plataformas, incluyendo Windows, Linux y Mac OS X.

Puede ingresar en la ventana de terminalpythonel comando para ver si Python ya está instalado localmente y la versión de Python instalada.

  • Windows: incluye Windows 7 y versiones posteriores.
  • macOS: es compatible con todas las versiones principales de macOS.
  • Linux: casi todas las distribuciones principales de Linux, como Ubuntu, Debian, Fedora, CentOS, etc.
  • Unix: admite sistemas tipo Unix, como FreeBSD, OpenBSD, etc.
  • Sistemas embebidos: dispositivos como Raspberry Pi, etc.
  • Plataformas móviles: admite iOS y Android a través de marcos de trabajo específicos (como Kivy).
  • Plataformas en la nube: admite entornos de servicios en la nube como AWS, Google Cloud, Azure, etc.

Descarga de Python

Sitio web oficial de Python:https://www.python.org/

Puede descargar la documentación de Python en los siguientes enlaces. Puede descargar documentación en formatos HTML, PDF y PostScript, entre otros.

Dirección de descarga de documentación de Python:https://www.python.org/doc/


Instalación de Python

Python ha sido portado a muchas plataformas (modificado para que pueda funcionar en diferentes plataformas).

Debe descargar el código binario correspondiente a su plataforma y luego instalar Python.

Si el código binario de su plataforma no está disponible, debe compilar manualmente el código fuente con un compilador de C.

El código fuente compilado ofrece más opciones en cuanto a funcionalidad y proporciona más flexibilidad para la instalación de Python.

A continuación se muestran las direcciones de descarga de los paquetes de instalación para cada plataforma:

A continuación se muestran los métodos para instalar Python en diferentes plataformas:

Instalación de Python en plataformas Unix y Linux:

A continuación se muestran los pasos sencillos para instalar Python en plataformas Unix/Linux:

  • Abra un navegador web y visitehttps://www.python.org/downloads/source/
  • Seleccione el paquete comprimido de código fuente adecuado para Unix/Linux.
  • Descargue y descomprima el paquete comprimido.
  • Si necesita personalizar algunas opciones, modifiqueModules/Setup
  • Ejecuteel script ./configure
  • make
  • make install

Después de realizar las operaciones anteriores, Python se instalará en el directorio /usr/local/bin y las bibliotecas de Python se instalarán en /usr/local/lib/pythonXX, donde XX es el número de versión de Python que esté utilizando.

Instalación de Python en plataformas Windows:

A continuación se muestran los pasos sencillos para instalar Python en la plataforma Windows:

  • Abra un navegador web y visitehttps://www.python.org/downloads/windows/

  • En la lista de descargas, seleccione el paquete de instalación para la plataforma Windows. El formato del paquete es:python-XYZ.msiarchivo, donde XYZ es el número de versión que desea instalar.

  • Para usar el instaladorpython-XYZ.msi, el sistema Windows debe ser compatible con Microsoft Installer 2.0. Simplemente guarde el archivo de instalación en la computadora local y luego ejecútelo para ver si su máquina es compatible con MSI. Windows XP y versiones posteriores ya tienen MSI, y muchas máquinas antiguas también pueden instalar MSI.

  • Después de la descarga, haga doble clic en el paquete descargado para ingresar al asistente de instalación de Python. La instalación es muy sencilla: solo necesita usar la configuración predeterminada y hacer clic en "Siguiente" hasta que se complete la instalación.

Instalación de Python en plataformas Mac:

Los sistemas Mac generalmente vienen con un entorno de Python 2.x. También puede visitar el enlacehttps://www.python.org/downloads/mac-osx/para descargar e instalar la última versión.


Configuración de variables de entorno

Los programas y archivos ejecutables pueden estar en muchos directorios, y es probable que estas rutas no estén en la ruta de búsqueda de archivos ejecutables proporcionada por el sistema operativo.

La ruta (path) se almacena en variables de entorno, que son cadenas con nombre mantenidas por el sistema operativo. Estas variables contienen información sobre el intérprete de línea de comandos disponible y otros programas.

En Unix o Windows, la variable de ruta es PATH (UNIX distingue entre mayúsculas y minúsculas, Windows no las distingue).

En Mac OS, el proceso de instalación cambia la ruta de instalación de Python. Si necesita hacer referencia a Python en otros directorios, debe agregar el directorio de Python a la ruta (path).

Configurar variables de entorno en Unix/Linux

  • En el shell csh:Ingrese
    setenv PATH "$PATH:/usr/local/bin/python"
    , presioneEnter。
  • En el shell bash (Linux):Ingrese
    export PATH="$PATH:/usr/local/bin/python"
    , presioneEnter。
  • En el shell sh o ksh:Ingrese
    PATH="$PATH:/usr/local/bin/python"
    , presioneEnter。

Nota:/usr/local/bin/python es el directorio de instalación de Python.

Configurar variables de entorno en Windows

Agregue el directorio de Python a las variables de entorno:

En el símbolo del sistema (cmd):Ingrese

path=%path%;C:\Python

presioneEnter。

Nota:C:\Python es el directorio de instalación de Python.

También se puede configurar de la siguiente manera:

  • Haga clic derecho en "Equipo" y luego haga clic en "Propiedades"
  • Luego haga clic en "Configuración avanzada del sistema"
  • Seleccione "Path" en la ventana de "Variables del sistema" y haga doble clic.
  • Luego, en la línea "Path", agregue la ruta de instalación de Python (la mía es D:\Python32), por lo tanto, agregue esa ruta al final.Nota: recuerde que las rutas deben separarse directamente con punto y coma ";" .
  • Después de configurarlo correctamente, en la línea de comandos cmd, ingrese el comando "python" y se mostrará la información correspondiente.

Variables de entorno de Python

Las siguientes son algunas variables de entorno importantes que se aplican a Python:

Nombre de variableDescripción
PYTHONPATHPYTHONPATH es la ruta de búsqueda de Python. De forma predeterminada, los módulos que importamos se buscan en PYTHONPATH.
PYTHONSTARTUP Después de que Python se inicia, primero busca la variable de entorno PYTHONSTARTUP y luego ejecuta el código en el archivo especificado por esta variable.
PYTHONCASEOK Agregar la variable de entorno PYTHONCASEOK hará que Python no distinga entre mayúsculas y minúsculas al importar módulos.
PYTHONHOME Otra ruta de búsqueda de módulos. Generalmente está incrustada en los directorios de PYTHONSTARTUP o PYTHONPATH, lo que facilita el cambio entre dos bibliotecas de módulos.

Ejecutar Python

Hay tres formas de ejecutar Python:

1. Intérprete interactivo:

Puede ingresar a Python a través de la ventana de línea de comandos y comenzar a escribir código de Python en el intérprete interactivo.

Puede realizar trabajos de codificación en Python en Unix, DOS o cualquier otro sistema que proporcione línea de comandos o shell.

$ python # Unix/Linux

o

C:>python # Windows/DOS

A continuación se muestran los parámetros de la línea de comandos de Python:

OpciónDescripción
-dMostrar información de depuración al analizar
-OGenerar código optimizado (archivo .pyo)
-SNo introducir la ubicación de búsqueda de la ruta de Python al iniciar
-VMostrar el número de versión de Python
-XDesde la versión 1.6, las excepciones basadas en cadenas (solo para cadenas) están obsoletas.
-c cmdEjecutar un script de Python y tomar el resultado de la ejecución como una cadena cmd.
fileEjecutar un script de Python en el archivo de Python dado.

2. Script de línea de comandos

En tu aplicación, puedes ejecutar scripts de Python en la línea de comandos introduciendo el intérprete, como se muestra a continuación:

$ python script.py # Unix/Linux

O bien

C:>python script.py # Windows/DOS

Nota:Al ejecutar el script, verifica si el script tiene permisos de ejecución.

3. Entorno de desarrollo integrado (IDE: Integrated Development Environment): PyCharm

PyCharm es un IDE de Python creado por JetBrains, compatible con los sistemas macOS, Windows y Linux.

Funciones de PyCharm: depuración, resaltado de sintaxis, gestión de proyectos, navegación de código, sugerencias inteligentes, autocompletado, pruebas unitarias, control de versiones...

Dirección de descarga de PyCharm:https://www.jetbrains.com/pycharm/download/

Dirección de instalación de PyCharm:https://www.runoob.com/pycharm/pycharm-install.html

Para instalar el plugin de chino en PyCharm, abre la barra de menú File, selecciona Settings, luego elige Plugins, haz clic en Marketplace, busca chinese y luego haz clic en Install para instalarlo:

En el siguiente aprendizaje, asegúrate de que tu entorno se haya configurado correctamente.

Los ejemplos que se dan en los próximos capítulos han sido probados en la versión Python 2.7.6.
