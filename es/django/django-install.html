Django: crear el primer proyecto

Instalación de Django

Antes de instalar Django, el sistema debe tener instalado el entorno de desarrollo de Python.

Si aún no has instalado Python, primero visita el sitio oficial de Pythonhttps://www.python.org/Descarga e instala la última versión de Python.

La instalación de Django también es muy sencilla: basta con usar la herramienta de gestión de paquetes pip:

pip install Django

Una vez completada la instalación, puedes verificar si Django se instaló correctamente ejecutando el siguiente comando:

python3 -m django --version

Si todo va bien, verás el número de versión de Django instalado, por ejemplo:4.2.7。

Entornos de desarrollo recomendados:

  • 1、Herramienta de desarrollo VS Code
  • 2、Herramienta de desarrollo PyCharm
  • 3、Alibaba Qoder
  • 4、Herramienta de desarrollo Trae

Instalación de Django en Windows

A continuación, veamos en detalle la instalación de Django en diferentes sistemas.

Si aún no has instalado el entorno de Python, primero debes descargar el paquete de instalación de Python.

1. Dirección de descarga de Python:https://www.python.org/downloads/

2. Dirección de descarga de Django:https://www.djangoproject.com/download/

Nota:Actualmente, las versiones de Django 1.6.x y superiores son completamente compatibles con Python 3.x.

Instalación de Python (se puede omitir si ya está instalado)

Para instalar Python, solo necesitas descargar el archivo python-x.x.x.msi y luego hacer clic continuamente en el botón "Next".

Después de la instalación, debes configurar las variables de entorno de Python. Haz clic derecho en Equipo -> Propiedades -> Configuración avanzada -> Variables de entorno -> modificar la variable del sistema path y agregar la dirección de instalación de Python. El ejemplo de este artículo usa C:\Python33; debes instalarlo según tu situación real.

Instalación de Django

Descarga el paquete comprimido de Django, descomprímelo y colócalo en el mismo directorio raíz que el directorio de instalación de Python. Entra en el directorio de Django, ejecuta python setup.py install y comienza la instalación. Django se instalará en site-packages, dentro de Lib, en el directorio de Python.

Luego, configura las variables de entorno agregando estos directorios a las variables de entorno del sistema: C:\Python33\Lib\site-packages\django;C:\Python33\Scripts. Una vez agregados, puedes usar el comando django-admin.py de Django para crear un nuevo proyecto.

Verificar si la instalación fue exitosa

Ejecuta el siguiente comando para verificar:

>>> import django
>>> django.get_version()

Si se muestra el número de versión de Django, la instalación es correcta.

Instalación de Django en Linux

Método de instalación con yum

La siguiente instalación se realiza en un entorno CentOS Linux. Si tu sistema Linux es Ubuntu, usa el comando apt-get.

De forma predeterminada, el entorno Linux ya es compatible con Python. Puedes escribir el comando Python en la terminal para ver si ya está instalado.

Python 3.7.4 (default, Aug  1 2012, 05:14:39) 
[GCC 4.6.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>>

Instalar setuptools

Comando:

# Python3 安装
yum install python3-setuptools
# Python2 安装
yum install python2-setuptools

Después de completarlo, puedes usar el comando easy_install para instalar Django.

easy_install django

Luego, escribimos el siguiente código en el intérprete de Python:

[root@solar django]# python
Python 3.7.4 (default, May 15 2014, 14:49:08)
[GCC 4.8.0] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>> import django
>>> django.VERSION
(3, 0, 6, 'final', 0)

Podemos ver que se muestra el número de versión de Django, lo que indica que la instalación fue exitosa.

Método de instalación con el comando pip

Si aún no has instalado la herramienta pip, puedes consultar:Instalación y uso de Python pip。

sudo pip3 install Django -i https://pypi.tuna.tsinghua.edu.cn/simple

-i https://pypi.tuna.tsinghua.edu.cn/simpleEspecifica el mirror de Tsinghua, la descarga será más rápida.

Especifica la versión de Django a descargar (puedes cambiar 3.0.6 por la versión que quieras):

sudo pip3 install Django==3.0.6 -i https://pypi.tuna.tsinghua.edu.cn/simple

Si pip < 1.4, el método de instalación es el siguiente:

pip install https://www.djangoproject.com/download/1.11a1/tarball/

Método de instalación desde el código fuente

Descargar el paquete de código fuente:https://www.djangoproject.com/download/

Ejecuta el siguiente comando e instala:

tar xzvf Django-X.Y.tar.gz    # 解压下载包
cd Django-X.Y                 # 进入 Django 目录
python setup.py install       # 执行安装命令

Después de una instalación exitosa, Django se encuentra en el directorio site-packages del directorio de instalación de Python.

Instalación en Mac

Descargar

从AquíDescarga la última versión estable: Django-3.x.y.tar.gz, desde la lista en el lado derecho de la página, como se muestra a continuación:

Recuerda que debe ser la última versión oficial. Dondex.yes el número de versión. Entra en la carpeta donde descargaste el archivo y ejecuta el siguiente comando: (en Mac, por defecto es /Users/xxx/Downloads, donde xxx es tu nombre de usuario)

$ tar zxvf Django-3.x.y.tar.gz

También puedes descargar la última versión desde GitHub, dirección:https://github.com/django/django：

git clone https://github.com/django/django.git

Instalar

Entra en el directorio descomprimido:

cd Django-3.x.y
sudo python setup.py install

Después de una instalación exitosa, se mostrará la siguiente información:

……
Processing dependencies for Django==3.x.y
Finished processing dependencies for Django==3.x.y

Luego entra en el directorio de nuestro sitio y crea un proyecto Django:

$ django-admin.py startproject testdj

Iniciar el servicio:

cd testdj # 切换到我们创建的项目
$ python manage.py runserver
……
Starting development server at http://127.0.0.1:8000/
Quit the server with CONTROL-C.

La información anterior indica que el proyecto se ha iniciado y la dirección de acceso es http://127.0.0.1:8000/.
