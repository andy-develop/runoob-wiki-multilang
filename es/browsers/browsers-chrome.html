Navegador Google Chrome

El navegador Google Chrome, cuyo nombre en chino es "谷歌浏览器", es un navegador web gratuito y de código abierto, desarrollado por Google y lanzado en 2008.

Cuando Google decidió desarrollar un navegador, necesitaba replantearse por completo este navegador, ya que los navegadores actuales son muy diferentes de cuando solo se navegaban páginas de texto simple; ahora, en el navegador enviamos correos, compramos, pagamos facturas y ejecutamos otras aplicaciones grandes.

Google Chrome es el navegador más utilizado en la actualidad:Descargar Chrome。

Google Chrome 34

Chrome 34 se lanzó el 8 de abril de 2014.

Chrome 34 puede ejecutarse en Windows, Mac, Linux y Android (2 de abril).

Nuevas características:

  • Cuando se establece autocomplete=off, Chrome también recuerda y rellena los campos de contraseña.
  • Compatibilidad con imágenes responsivas:Google introdujo el atributo "srcset", que permite a los desarrolladores web proporcionar múltiples recursos de diferentes resoluciones para una imagen. En resumen, esto significa que el navegador elegirá el recurso que coincida con el dispositivo, ya sea un ordenador de escritorio, portátil, tableta, teléfono móvil o televisión.
  • La versión sin prefijo de la Web Audio API
  • Importar usuarios supervisados a una nueva computadora:Al importar usuarios supervisados, se importan también todos sus permisos, y esto se sincronizará automáticamente con el dispositivo.
  • Muchas nuevas API para aplicaciones y extensiones.
  • Una apariencia diferente para el modo Metro de Windows 8.
  • 31 correcciones de seguridad.

Google Chrome 33

Chrome 33 se lanzó el 20 de febrero de 2014.

Chrome 33 puede ejecutarse en Windows, Mac, Linux y Android (26 de febrero).

Chrome Frame (el complemento de Chrome para Internet Explorer) se ha retirado oficialmente.

Nuevas características:

  • Web Speech API - Funciones de reconocimiento y síntesis de voz.
  • Elementos personalizados:Puede crear nuevos elementos HTML y DOM (puede usar cualquier nombre que desee), también puede extender nuevos elementos a partir de otros elementos y agrupar funcionalidades personalizadas en un solo elemento.
  • En modo sin conexión, se pueden crear, renombrar y eliminar carpetas en Google Drive.
  • En modo sin conexión, se pueden renombrar archivos en Google Drive.
  • 28 correcciones de seguridad.
