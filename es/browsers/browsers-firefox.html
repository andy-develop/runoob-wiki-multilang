Navegador Firefox

El navegador Firefox, llamado en chino 'navegador Zorro de Fuego', es un navegador web gratuito y de código abierto de Mozilla.

Firefox fue lanzado en 2004 y es uno de los navegadores más populares en la actualidad.

Firefox puede ejecutarse en Windows, Mac OS X, Linux y Android.

Nuevas características:

Firefox 26 fue lanzado el 10 de diciembre de 2013.

Firefox 26 puede ejecutarse en Windows, Mac, Linux y Android.

Nuevas características:

  • El administrador de contraseñas es compatible con campos de contraseña generados por script.
  • Compatibilidad con vídeo codificado en H.264 en Linux.
  • Compatibilidad con audio MP3 en Windows XP.- Esto completa la compatibilidad con MP3 en todas las versiones del sistema operativo Windows.
  • Eliminación del aviso cuando un sitio solicita AppCache.
  • Compatibilidad con la propiedad CSS3 image-orientation.
  • Nuevo administrador de aplicaciones (App Manager).- Le permite implementar y depurar programas HTML5 en teléfonos con Firefox OS y en el simulador de Firefox OS.
  • IndexedDB puede utilizarse como un área de almacenamiento 'optimista'.- Utiliza una política de expulsión LRU, no requiere almacenar ninguna sugerencia ni dato en el grupo, solo un almacenamiento temporal de corta duración.
  • Reducción del uso de memoria y mejora del procesamiento de imágenes.

  • Se ha mejorado el soporte para HTML5, MathML y CSS.

Firefox 8

Firefox 8 se lanzó el 8 de noviembre de 2011.

Firefox 8 se puede ejecutar en Windows, Mac OS X y Linux.

Novedades:

  • Instala el motor de búsqueda de Twitter por defecto.
  • Los complementos de terceros están deshabilitados por defecto.
  • Un nuevo «cuadro de diálogo de selección de complementos» que permite verificar los complementos al actualizar.
  • Las pestañas se pueden cargar «bajo demanda», lo que permite almacenar más rápidamente ventanas con varias pestañas.
  • Soporte para el intercambio de recursos de origen cruzado (CORS, Cross-Origin Resource Sharing), que permite a los desarrolladores cargar texturas WebGL desde otros dominios de forma segura.
  • Soporte para menús contextuales de HTML5.
  • Firefox para Android: Mozilla también ha añadido más funciones para que el navegador Firefox pueda ejecutarse en dispositivos Android.

Firefox 7

Firefox 7 se lanzó el 27 de septiembre de 2011.

Firefox 7 se puede ejecutar en Windows, Mac OS X y Linux.

Novedades:

  • Gestión de memoria mejorada.
  • Cuando se utiliza Firefox Sync, los cambios de marcadores y contraseñas se sincronizan siempre al instante.
  • El prefijo de URL «http://» está oculto por defecto (al igual que en Chrome).
  • Se ha actualizado el protocolo WebSocket de la versión 7 a la versión 8.
  • Se ha añadido un sistema para que los usuarios envíen datos de rendimiento a Mozilla.

Firefox 6

Firefox 6 se lanzó el 16 de agosto de 2011.

Firefox 6 se puede ejecutar en Windows, Mac OS X y Linux.

Novedades:

  • La barra de direcciones resalta el dominio del sitio web que visita.
  • Aspecto simplificado del bloque de identidad del sitio.
  • Se ha añadido soporte para la última versión preliminar de WebSockets mediante una API con prefijo.
  • Se ha añadido soporte para EventSource / eventos enviados por el servidor (server-sent events).
  • Se ha añadido soporte para window.matchMedia.
  • Se ha añadido Scratchpad, un entorno interactivo de creación de prototipos en JavaScript.
  • Se ha añadido un nuevo elemento de menú Web Developer, moviendo a él las opciones de desarrollo relacionadas.
  • Se ha mejorado la usabilidad de la Consola web (Web Console).
  • Se ha mejorado la capacidad de descubrimiento de Firefox Sync.
  • Se ha reducido el tiempo de inicio del navegador al usar Panorama.

Firefox 5

Firefox 5 se lanzó en junio de 2011.

Firefox 5 se puede ejecutar en Windows, Mac OS X y Linux.

Novedades:

  • Se ha añadido soporte para animaciones CSS.
  • Ajuste de la lógica de conexiones HTTP inactivas para mejorar el rendimiento.
  • Mejoras en el rendimiento de canvas, JavaScript, memoria y red.
  • Se ha mejorado el soporte de los estándares HTML5, XHR, MathML, SMIL y canvas.
  • Corrector ortográfico mejorado.
  • Mejor integración con el entorno de escritorio para usuarios de Linux.
  • El contenido WebGL ya no carga texturas de otros dominios.
  • Las pestañas en segundo plano limitan setTimeout y setInterval a 1000 ms para mejorar el rendimiento.

Firefox 4

Firefox 4 se lanzó en marzo de 2011.

Firefox 4 se puede ejecutar en Windows, Mac OS X y Linux.

Novedades:

  • ¡Soporte para más de 80 idiomas!
  • El Firefox más rápido de la historia –Firefox es seis veces más rápido que las versiones publicadas anteriormente.
  • Pestañas de aplicación– Una página de inicio permanente que muestra sitios visitados con frecuencia, como correo web, Twitter, Pandora, Flickr.
  • Cambiar a pestaña– Encuentre y cambie fácilmente a cualquier pestaña abierta desde la Awesome Bar.
  • Panorama– Arrastre y suelte las pestañas en grupos gestionables para ahorrar tiempo al navegar por varias pestañas abiertas.
  • Firefox Sync– Acceda a su historial de la Awesome Bar, marcadores, pestañas abiertas, contraseñas y datos en múltiples ordenadores y dispositivos móviles.
  • Nuevo administrador de complementos– Más de 200 000 complementos para personalizar las características, funciones y apariencia de Firefox.
  • No rastrear– Permite a los usuarios optar por no ser rastreados para publicidad conductual.
  • Privacidad primero– Evita que otras personas accedan al historial de su navegador.
  • Transporte seguro estricto de HTTP (HSTS, HTTP Strict Transport Security)Establece conexiones seguras para detener los ataques de “hombre en el medio”, protegiendo así los datos sensibles.
  • Política de seguridad de contenido (CSP, Content Security Policy)Evita ataques de scripting entre sitios al permitir que los sitios web indiquen explícitamente al navegador qué contenido es legítimo.
  • Compilador JITAl mejorar el compilador JIT TraceMonkey existente y el intérprete SpiderMonkey, se obtienen velocidades de carga de página más rápidas y un mejor rendimiento.
  • Soporte de HTML5Incluye aceleración por hardware, video de alta definición (WebM), gráficos 3D, almacenamiento de datos sin conexión, tipografía profesional, interfaz de pantalla táctil y la API de audio de Mozilla.
  • Herramientas existentes mejoradasPor ejemplo, CSS, lienzo (Canvas) y SVG.
  • Navegación ininterrumpidaCuando los complementos de Adobe Flash, Apple QuickTime o Microsoft Silverlight fallan, la navegación del usuario no se interrumpe.

Firefox 3.6

Firefox 3.6 se lanzó en enero de 2011.

Firefox 3.6 se basa en la plataforma de renderizado web Gecko 1.9.2 de Mozilla, que ha estado en desarrollo desde principios de 2009, e incluye muchas mejoras para desarrolladores web, desarrolladores de complementos y usuarios. Esta versión también es más rápida y receptiva que las anteriores, y está optimizada para ejecutarse en sistemas operativos de dispositivos pequeños, como Maemo.

Nuevas características:

  • Temas de PersonasPermite a los usuarios cambiar la apariencia de Firefox con un solo clic.
  • Evita la instalación de complementos desactualizadosMantiene seguros a los usuarios mientras navegan por la web.
  • Los videos locales pueden mostrarse a pantalla completa, con soporte para el marco de anuncios.
  • Rendimiento de JavaScript mejorado
  • Proporciona a los desarrolladores web la capacidad de ejecutar scripts de forma asíncronaPara acelerar el tiempo de carga de las páginas.
  • Soporte para fuentes web descargablesUsa el nuevo formato de fuente WOFF.
  • Mejora el soporte para CSS3, DOM y HTML5.
