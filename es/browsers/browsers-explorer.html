Navegador Internet Explorer

El navegador Internet Explorer, abreviado como navegador IE, es un navegador web gratuito publicado por Microsoft Corporation.

Internet Explorer se lanzó en 1995, alcanzó un pico de uso del 95% en 2002 y 2003, pero actualmente ha dejado de recibir soporte.

El 17 de marzo de 2015, Microsoft anunció que Internet Explorer ya no era el navegador predeterminado de Windows 10, y que abandonaría gradualmente esta marca, sustituyéndola por Microsoft Edge.

Internet Explorer 11

Para Windows 8.1: Internet Explorer 11 se lanzó el 17 de octubre de 2013.

Para Windows 7: Internet Explorer 11 se lanzó el 7 de noviembre de 2013.

Nuevas características:

  • Mejoras de rendimiento
  • Nuevas herramientas F12 Developer Tools (Herramientas de desarrollo F12)
  • Soporte WebGL
  • Soporte de alta resolución
  • Soporte de border-image de CSS3
  • Soporte de CSS Flexbox
  • Soporte para SPDY (solo Windows 8.1)
  • Soporte para la API de pantalla completa y orientación (Full Screen and Orientation API)
  • Soporte mejorado para usuarios de dispositivos táctiles
  • Mejoras de JavaScript
  • Observación de mutaciones del DOM
  • API de criptografía web (Web Cryptography API)
  • Soporte de seguimiento de texto en video
  • Soporte de medios cifrados
  • Editor HTML mejorado

IE 11 Funciones eliminadas：

  • document.all quedó obsoleto- El código que verifica su existencia no podrá detectarlo, pero el código que realmente lo utiliza seguirá funcionando.
  • attachEvent
  • Pestañas rápidas (CTRL+Q)
  • El comando "Work offline" (Trabajar sin conexión) se eliminó del menú File (Archivo)
  • Arrastrar y soltar contenido seleccionado desde IE a otros programas como Word
  • Usar botones de comando con iconos grandes
  • La función de ver todas las cookies a la vez en Developer Tools

IE 11 es rápido y compatible con los estándares. Sin embargo, su principal desventaja es que no se ejecuta en versiones anteriores a Windows 7 y no ofrece sincronización para ese sistema.

Internet Explorer 10

Internet Explorer 10, lanzado el 4 de septiembre de 2012, es el navegador predeterminado de Windows 8.

En febrero de 2013, Internet Explorer 10 estuvo disponible para su descarga para todos los usuarios de Windows 7 SP1.

Nuevas características:

  • 20% más rápido que IE9
  • Soporte actualizado para HTML5- Ahora soporta el atributo async en la etiqueta <script>, AppCache API, mensajes de canal, API de arrastrar y soltar, historial, análisis, sandbox, revisión ortográfica, video, Web Workers y WebSockets.
  • Soporte actualizado para CSS3- Ahora soporta transformaciones, animaciones, fuentes, degradados, efectos de transición, sombras de texto y la eliminación de restricciones de hojas de estilo.
  • Soporte actualizado para DOM- Ahora soporta una API avanzada de pruebas de impacto, escucha de consultas de medios, mejoras de XMLHttpRequest y eventos de gestos de puntero.
  • Soporte actualizado para SVG- Ahora soporta SVG y filtros.
  • Soporte actualizado para la API de base de datos indexada (Indexed Database API)
  • Revisión ortográfica y corrección automática integradas
  • Integración de Adobe Flash- Incluye un Adobe Flash Player integrado.
  • Añade funciones para usuarios de pantallas táctiles.- Navegador táctil de pantalla completa.
  • Deslizar hacia adelante- Muévase rápidamente a la siguiente página de un sitio web mediante gestos de deslizamiento en dispositivos de pantalla táctil.
  • Nueva cadena de agente de usuario - Mozilla/5.0 (compatible; MSIE 10.0; Windows NT 6.2; [platform token] Trident/6.0; Touch)

IE 10 Ya nose admite lo siguiente:

  • Islas de datos XML
  • VML- Lenguaje de marcado vectorial (Vector Markup Language).
  • HTC- Comportamientos de elementos y componentes HTML (Element behaviors and HTML components).
  • Filtros DX- Filtros/efectos de transición basados en DirectX.
  • Comentarios condicionales- Sentencias condicionales interpretadas por IE en el código fuente HTML, como: <!--[if IE 6]>. Se usan para proporcionar y ocultar código a IE.
  • Asesor de contenido (Content Advisor)- Asumido por los controles parentales de Windows.

Internet Explorer 9

Internet Explorer 9 fue lanzado en marzo de 2011.

Nuevas características:

  • Interfaz actualizada- Le permite controlar y enfocar la visualización del sitio web.
  • Rapidez ágil- IE9 es mucho más rápido que las versiones anteriores de IE. El texto, el video y los gráficos acelerados por hardware mejoran el rendimiento del sitio web, como si el programa estuviera instalado en su PC. Además, IE9 utiliza la tarjeta de video para que todo sea más rápido.
  • Fijar sitios web a la barra de tareas de Windows 7- Microsoft tiene asociaciones con muchos sitios web como Facebook, Twitter y Pandora. Puede ver una barra de tareas compatible con listas de acceso rápido (Jump Lists).
  • Barra de direcciones unificada- Barra de direcciones unificada para navegar por sitios web o iniciar una búsqueda.
  • Pestaña nueva rediseñada- Le permite acceder rápidamente a los sitios que visita con frecuencia. También puede volver a abrir pestañas cerradas, su última sesión de exploración o iniciar una nueva sesión de exploración no privada.
  • Gestión mejorada de complementos- Una nueva función llamada Asesor de rendimiento de complementos (Add-on Performance Adviser) le permite saber qué está ralentizando su navegador y le permite eliminarlo.
  • Mejores funciones de protección de privacidad- La protección de seguimiento puede limitar el seguimiento de su información por parte de los sitios web.
  • Mejor soporte para HTML5/CSS3- IE9 también es compatible con SVG y gráficos de lienzo (Canvas graphics).
  • Nuevo administrador de descargas- Le permite ver los archivos descargados a través del navegador y le notifica si el archivo es malicioso o contiene virus. También le permite pausar descargas y reanudarlas más tarde.
  • Gestión mejorada de pestañas- Puede mover pestañas entre ventanas arrastrándolas de una ventana a otra. Cuando coloca una pestaña en una nueva ventana, no necesita volver a cargar la página.

Internet Explorer 8

Internet Explorer 8 fue lanzado en marzo de 2009.

Nuevas características:

  • Aceleradores- Proporcionan acceso rápido a servicios web. Los usuarios pueden buscar y enviar información desde la web. Por ejemplo, en el sitio web de un restaurante, el usuario puede hacer clic dentro de la página para obtener un mapa, noticias e información sobre el restaurante, blogs relacionados, o compartirlo en Sina Weibo.
  • Suscripciones a sitios web- Es una función similar a RSS que permite a los usuarios suscribirse a contenido directamente dentro de la página web.
  • Vista de compatibilidad- Muestra páginas web en IE7.
  • Sugerencias de búsqueda- Proporciona contenido sugerido según lo que usted escribe.
  • Funciones de nuevas pestañas- Vuelve a abrir pestañas cerradas accidentalmente y agrupa pestañas relacionadas mediante códigos de color.
  • Separación de pestañas- Evita que un sitio web con errores cierre todo el navegador; solo se cerrará la pestaña con el error.
  • Navegación InPrivate- Navega por páginas web sin guardar ningún dato (como contraseñas, cookies, historial de exploración, etc.).
  • Filtro SmartScreen- Le protege de instalar software malicioso que podría exponer sus datos, privacidad e identidad, y potencialmente dañar su computadora y sus datos valiosos.

IE8 es totalmente compatible con CSS 2.1. Además, corrigió "muchas inconsistencias entre navegadores, como get/set/removeAttribute, atributos predeterminados, el objeto Attribute y la etiqueta <q>".

Internet Explorer 7

Internet Explorer 7.0 fue lanzado en noviembre de 2006. IE7 es el navegador estándar en Windows XP con Service Pack 2.

Internet Explorer 7 ofrece navegación mejorada, búsqueda web desde la barra de herramientas, impresión avanzada, búsqueda instantánea y fuentes RSS.

Nuevas características:

  • Impresión avanzada- Internet Explorer 7 escala automáticamente la página web que se va a imprimir para que la página completa quepa en la página impresa. Las opciones de impresión también incluyen márgenes ajustables, diseño de página personalizable, encabezados y pies de página eliminables, y la opción de imprimir solo texto seleccionado.
  • Cuadro de búsqueda instantánea- Las búsquedas web con su proveedor de búsqueda favorito ahora se pueden agregar al cuadro de búsqueda de la barra de herramientas, eliminando la confusión de múltiples barras de herramientas independientes. Puede seleccionar fácilmente un proveedor de la lista desplegable o agregar más.
  • Centro de favoritos- Acceso rápido y conveniente a favoritos, grupos de pestañas, historial de exploración y suscripciones a fuentes RSS. El Centro de favoritos se puede expandir según sea necesario y se puede colocar en cualquier lugar para facilitar el acceso.
  • Fuentes RSS- Internet Explorer 7 detecta automáticamente las fuentes RSS en los sitios y ilumina el ícono en la barra de herramientas. Puede hacer clic en el ícono para obtener una vista previa y suscribirse a fuentes RSS, y luego recibirá notificaciones automáticas cuando el contenido se actualice. Puede leer las fuentes RSS directamente en el navegador, ver eventos importantes y filtrar la vista por términos de búsqueda o categorías de sitios específicas.
  • Exploración con pestañas- Vea varios sitios en una sola ventana del navegador. Cambie fácilmente de un sitio a otro mediante las pestañas en la parte superior del marco del navegador.
  • Pestañas rápidas- Al mostrar todas las miniaturas en una sola ventana, puede seleccionar y navegar fácilmente entre las pestañas abiertas.
  • Grupos de pestañas- Las pestañas se pueden agrupar y guardar por categorías lógicas para que pueda abrir varias pestañas con un solo clic. Los grupos de pestañas se pueden establecer convenientemente como grupo de inicio para que todo el grupo de pestañas se abra cada vez que se inicie Internet Explorer.
  • Zoom de página- Amplíe una página individual, incluidos texto e imágenes, para que pueda concentrarse en contenido específico o para que las personas con discapacidad visual puedan ver el contenido con mayor claridad.

Internet Explorer 6

Internet Explorer 6.0 es el navegador estándar en Windows XP. Fue lanzado en agosto de 2001.

Windows XP se basa en Windows 2000 y es el sucesor de Windows 98, Millennium y Windows 2000.

Internet Explorer 5

Internet Explorer 5 es el primer navegador importante compatible con XML.

Version 5.5(Lanzado en julio de 2000), para Windows 95, 98, NT 4.0 y Windows 2000. Compatible con XML/XSL, CSS, impresión (vista previa de impresión) y comportamientos HTC.

Version 5.01(Lanzado en noviembre de 1999), principalmente corrigió un error de 5.0.

Version 5.0(Lanzado en marzo de 1999), fue el primer navegador importante compatible con XML.

Versiones más antiguas de Internet Explorer

La mayoría de los usuarios ya no utilizan las versiones más antiguas de Internet Explorer. Los desarrolladores web las ignoran. Y sus características están obsoletas.

IE 4.0(Lanzado en 1997). Esta versión tiene muy buen soporte para CSS y DOM, pero no es compatible con XML.

IE 3.0(Lanzado en 1996) tiene un uso de menos del 0.1%.

IE 2.0(Lanzado en 1995). Esta versión es demasiado antigua; ya nadie la usa.

IE 1.0(Lanzado en 1995). ¿Alguien todavía lo recuerda?

Internet Explorer for Macintosh

Version 5.1.7Es el último Internet Explorer para Mac OS 8 y 9, lanzado en julio de 2003.

Version 5.2.3Es el último Internet Explorer para Mac OS X, lanzado en junio de 2003.

Notas:La versión 5.2.3 requiere características especiales en Mac OS X. Los usuarios de Mac OS 8 y 9 deben descargar la versión 5.1.7.

Microsoft dejó de ofrecer soporte técnico para Internet Explorer para Mac el 31 de diciembre de 2005.

Se recomienda a los usuarios de Mac que utilicen otros navegadores, comoel navegador Safari de Apple。
