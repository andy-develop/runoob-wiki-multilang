Comandos personalizados de OpenCode

Explicación detallada de la configuración de atajos de teclado de OpenCode

OpenCode ofrece un sistema completo de atajos de teclado que cubre diversas operaciones como control de la aplicación, gestión de sesiones, navegación de mensajes, cambio de modelos y edición de entrada.

Todos los atajos de teclado se pueden personalizartui.jsonmediante el archivo.

Archivo de configuración

La configuración de atajos de teclado se escribe en el campotui.jsondel archivokeybindsdonde el nombre de clave de cada registro es el nombre de la operación y el valor es el atajo de teclado correspondiente:

Ejemplo

{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
"leader": "ctrl+x", // Configuración de la tecla líder (ver explicación a continuación)
"session_new": "<leader>n", // Nueva sesión: presione la tecla líder y luego n
"model_list": "<leader>m", // Abrir la lista de modelos: presione la tecla líder y luego m
"session_compact": "none" // Establecer el valor en "none" deshabilita este atajo
  }
}

Una operación puede vincularse a múltiples atajos de teclado, separados por comas; al presionar cualquiera de ellos se ejecuta la operación:

Ejemplo

{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
// La siguiente notación indica: al presionar pageup o ctrl+alt+b, se puede desplazar una página hacia arriba
    "messages_page_up": "pageup,ctrl+alt+b"
  }
}

Tecla líder (Leader Key)

La mayoría de los atajos de teclado de OpenCode adoptanla tecla líder (Leader Key)como mecanismo: presione primero la tecla líder y luego la tecla de función; la combinación de ambas activa la operación correspondiente. La ventaja de este diseño es evitar conflictos con los atajos de teclado del propio terminal.

La tecla líder predeterminada esctrl+x. Por ejemplo, el atajo para crear una nueva sesión es<leader>n, y la operación real es: presione primeroctrl+x, y luego presionen。

Puede cambiar la tecla líder a cualquier combinación de teclas:

Ejemplo

{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
"leader": "ctrl+x" // Cambiar la tecla líder a otra tecla, como "ctrl+space", "alt+x", etc.
// El marcador de posición <leader> en la configuración se reemplaza automáticamente por la tecla establecida aquí
  }
}

No es obligatorio utilizar el mecanismo de tecla líder para configurar atajos de teclado; también se pueden vincular directamente teclas normales o combinaciones de teclas. Sin embargo, se recomienda usar preferentemente la tecla líder para evitar conflictos con los atajos del terminal.

Deshabilitar atajos de teclado

Establezca el valor de cualquier atajo en"none"para deshabilitar la operación; una vez deshabilitada, ninguna tecla la activará:

Ejemplo

{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
"session_compact": "none", // Deshabilitar el atajo de "compresión de sesión"
"scrollbar_toggle": "none", // Deshabilitar el atajo de "alternar barra de desplazamiento"
"tips_toggle": "none" // Deshabilitar el atajo de "alternar consejos"
  }
}

Configurar Shift+Enter para salto de línea

Algunos terminales, de forma predeterminada, no envían la tecla Enter con modificadores (por ejemplo,Shift+Enter) como una tecla independiente, lo que hace que al presionarShift+Enteren OpenCode no se inserte una nueva línea sino que se envíe el mensaje directamente. Es necesario configurar manualmente la secuencia de escape de esa tecla en el terminal.

Método de configuración en Windows Terminal

Primer paso:Abra elsettings.jsonarchivo de Windows Terminal, cuya ruta es:

%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json

Segundo paso:En el nivel raíz del archivo,actionsagregue la siguiente configuración a la matriz para definir una acción que envíaShift+Enterla secuencia de escape:

Ejemplo

"actions": [
  {
    "command": {
      "action": "sendInput",
"input": "\u001b[13;2u" // Secuencia de escape estándar correspondiente a Shift+Enter (formato CSI u)
    },
    "id": "User.sendInput.ShiftEnterCustom"
  }
]

Tercer paso:En el nivel raíz del archivo,keybindingsagregue un enlace de teclas en la matriz y asígneloShift+Entera la acción definida anteriormente:

Ejemplo

"keybindings": [
  {
    "keys": "shift+enter",
    "id": "User.sendInput.ShiftEnterCustom"
  }
]

Cuarto paso:Guarde elsettings.jsonarchivo y luego reinicie Windows Terminal o abra una nueva pestaña para que la configuración surta efecto.

Si utiliza otros terminales (como iTerm2, Kitty, Alacritty, etc.), consulte la documentación del terminal correspondiente, busque la configuración relacionada con 'mapeo de teclas' o 'Key bindings', y configureShift+Enterpara que envíe\u001b[13;2ula secuencia de escape.
