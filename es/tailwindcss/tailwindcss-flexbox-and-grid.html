Tailwind CSS y los diseños Flexbox y Grid

Tailwind CSS proporciona poderosas clases de utilidad para gestionar diseños, especialmente Flexbox y Grid.

Estas clases de utilidad de Flexbox y Grid te permiten crear diseños receptivos y flexibles de manera muy eficiente, sin necesidad de escribir CSS personalizado.

La filosofía de Tailwind CSS es controlar el diseño mediante clases de utilidad de bajo nivel (utility-first), combinando clases de manera flexible para satisfacer diferentes necesidades de diseño.

1. Diseño Flexbox

Flexbox es un modo de diseño que ayuda a los desarrolladores a crear diseños unidimensionales (horizontales o verticales).

Tailwind CSS ofrece varias clases de utilidad concisas para controlar todos los aspectos del diseño Flexbox, incluyendo dirección, alineación, flexibilidad, etc.

Configurar el contenedor Flex

Para crear un diseño Flexbox, primero debes establecer el elemento como contenedor flex.

Ejemplo

<div class="flex">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

Dirección Flex

flex-direction controla la dirección del eje principal (es decir, la dirección en la que se ordenan los elementos dentro del contenedor Flex).

Tailwind proporciona las siguientes clases de utilidad para establecer la dirección:

  • flex-row: Valor predeterminado, los elementos secundarios se organizan horizontalmente de izquierda a derecha.
  • flex-row-reverse: Los elementos secundarios se organizan horizontalmente de derecha a izquierda.
  • flex-col: Los elementos secundarios se organizan verticalmente de arriba hacia abajo.
  • flex-col-reverse: Los elementos secundarios se organizan verticalmente de abajo hacia arriba.

Ejemplo

<div class="flex flex-row ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-row-reverse ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-col ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

Flex Wrap (ajuste de línea)

De forma predeterminada, los elementos en un contenedor Flexbox se ordenan en una sola línea.

Si deseas que se ajusten a varias líneas, puedes usar la clase de utilidad flex-wrap.

  • flex-wrap: Permite que los elementos se ajusten a varias líneas.
  • flex-nowrap: Evita que los elementos se ajusten a varias líneas.
  • flex-wrap-reverse: Ajuste de línea inverso.

Ejemplo

<div class="flex flex-nowrap">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-wrap">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-wrap-reverse">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

Flexibilidad de los elementos Flex

Flexbox permite que el tamaño de los elementos se expanda o se contraiga según el espacio disponible.

Tailwind CSS proporciona las siguientes clases de utilidad para controlar la flexibilidad:

Nombre de clase de TailwindPropiedad y valor CSSDescripción
flex-1flex: 1 1 0%;Hace que los elementos flex tengan la misma capacidad de crecimiento y contracción, con un tamaño base de 0%, comúnmente usado para crear diseños flex de igual ancho o igual altura.
flex-autoflex: 1 1 auto;Hace que los elementos flex tengan un tamaño base automático y la misma capacidad de crecimiento y contracción, comúnmente usado para que los elementos flex llenen el espacio adicional.
flex-initialflex: 0 1 auto;Hace que los elementos flex tengan un tamaño base automático, no crezcan pero puedan contraerse, para mantener el tamaño natural del elemento a menos que el espacio sea insuficiente.
flex-noneflex: none;Evita que los elementos flex crezcan o se encojan, manteniendo su tamaño base, comúnmente usado para fijar el tamaño de los elementos.

Ejemplo

<div class="flex">
  <div class="flex-none w-14 ...">

  </div>
  <div class="flex-initial w-64 ...">
    02
  </div>
  <div class="flex-initial w-32 ...">
    03
  </div>
</div>

Diseño Grid (cuadrícula)

Grid es otro modelo de diseño que te permite posicionar elementos con precisión en filas y columnas, y crear fácilmente diseños complejos.

Tailwind CSS proporciona potentes clases de utilidad para manejar el diseño de cuadrícula.

Las siguientes son clases de utilidad en Tailwind CSS para especificar el número de columnas en un diseño de cuadrícula y sus propiedades CSS correspondientes:

Nombre de clase de TailwindPropiedad y valor CSSDescripción
grid-cols-1grid-template-columns: repeat(1, minmax(0, 1fr));Crea un diseño de cuadrícula con 1 columna.
grid-cols-2grid-template-columns: repeat(2, minmax(0, 1fr));Crea un diseño de cuadrícula con 2 columnas.
grid-cols-3grid-template-columns: repeat(3, minmax(0, 1fr));Crea un diseño de cuadrícula con 3 columnas.
grid-cols-4grid-template-columns: repeat(4, minmax(0, 1fr));Crea un diseño de cuadrícula con 4 columnas.
grid-cols-5grid-template-columns: repeat(5, minmax(0, 1fr));Crea un diseño de cuadrícula con 5 columnas.
grid-cols-6grid-template-columns: repeat(6, minmax(0, 1fr));Crea un diseño de cuadrícula con 6 columnas.
grid-cols-7grid-template-columns: repeat(7, minmax(0, 1fr));Crea un diseño de cuadrícula con 7 columnas.
grid-cols-8grid-template-columns: repeat(8, minmax(0, 1fr));Crea un diseño de cuadrícula con 8 columnas.
grid-cols-9grid-template-columns: repeat(9, minmax(0, 1fr));Crea un diseño de cuadrícula con 9 columnas.
grid-cols-10grid-template-columns: repeat(10, minmax(0, 1fr));Crea un diseño de cuadrícula con 10 columnas.
grid-cols-11grid-template-columns: repeat(11, minmax(0, 1fr));Crea un diseño de cuadrícula con 11 columnas.
grid-cols-12grid-template-columns: repeat(12, minmax(0, 1fr));Crea un diseño de cuadrícula con 12 columnas.
grid-cols-nonegrid-template-columns: none;No crea columnas de cuadrícula; los elementos secundarios no utilizarán el diseño de cuadrícula.
grid-cols-subgridgrid-template-columns: subgrid;Utiliza un diseño de subcuadrícula; los elementos secundarios heredarán la definición de columnas de la cuadrícula principal.

  • grid: Habilita el diseño Grid.
  • grid-cols-{n}: Establece el número de columnas de la cuadrícula.
  • gap-{size}: Establece el espacio entre columnas y filas.

Filas y columnas de Grid

Mediantegrid-template-columns 和 grid-template-rowscontrolas el ancho y alto de columnas y filas. Tailwind proporciona las siguientes clases de utilidad para controlar:

  • grid-cols-{n}: Establece el número de columnas de la cuadrícula (por ejemplo,grid-cols-3representa tres columnas).
  • grid-rows-{n}: Establece el número de filas de la cuadrícula (por ejemplo,grid-rows-2representa dos filas).
  • col-span-{n}: Establece cuántas columnas ocupa un elemento.
  • row-span-{n}: Establece cuántas filas ocupa un elemento.

Ejemplo

<div class="grid grid-cols-4 gap-4">
  <div>01</div>
  <!-- ... -->
  <div>05</div>
  <div class="grid grid-cols-subgrid gap-4 col-span-3">
    <div class="col-start-2">06</div>
  </div>
</div>

Posicionamiento de los elementos Grid

grid-column y grid-row controlan la posición de cada elemento en la cuadrícula.

Puedes especificarlo mediante las siguientes clases de utilidad:

  • col-start-{n}: Establece que el elemento comience en la columna n.
  • col-end-{n}: Establece que el elemento termine en la columna n.
  • row-start-{n}: Establece que el elemento comience en la fila n.
  • row-end-{n}: Establece que el elemento termine en la fila n.

Ejemplo

<div class="grid grid-cols-6 gap-4">
  <div class="col-start-2 col-span-4 ...">01</div>
  <div class="col-start-1 col-end-3 ...">02</div>
  <div class="col-end-7 col-span-2 ...">03</div>
  <div class="col-start-1 col-end-7 ...">04</div>
</div>

Ejemplo

<div class="grid grid-rows-3 grid-flow-col gap-4">
  <div class="row-start-2 row-span-2 ...">01</div>
  <div class="row-end-3 row-span-2 ...">02</div>

Alineación y distribución

Al igual que Flexbox, Grid también ofrece opciones de alineación y distribución.

La propiedad justify-content se utiliza para alinear los elementos secundarios dentro del contenedor a lo largo del eje principal (dirección horizontal).

Nombre de clase de TailwindPropiedad y valor CSSDescripción
justify-normaljustify-content: normal;Utiliza la alineación predeterminada, generalmente equivalente astart。
justify-startjustify-content: flex-start;Mueve todos los elementos secundarios al inicio del contenedor. En un diseño horizontal, los elementos se alinean a la izquierda.
justify-endjustify-content: flex-end;Mueve todos los elementos secundarios al final del contenedor. En un diseño horizontal, los elementos se alinean a la derecha.
justify-centerjustify-content: center;Centra todos los elementos secundarios.
justify-betweenjustify-content: space-between;Distribuye el espacio uniformemente entre los elementos secundarios, sin dejar espacio en los extremos.
justify-aroundjustify-content: space-around;Distribuye el espacio uniformemente entre los elementos secundarios, dejando la mitad del espacio en los extremos.
justify-evenlyjustify-content: space-evenly;Distribuye el espacio de manera totalmente uniforme entre los elementos secundarios, incluido el espacio en los extremos.
justify-stretchjustify-content: stretch;Los elementos secundarios se estiran para llenar el contenedor, ocupando cada uno el mismo espacio.

Ejemplo

<div class="flex justify-start ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

Pruébalo »

Otras configuraciones de alineación:

  • justify-items: Controla la alineación del contenido de las celdas de la cuadrícula.
  • justify-self: Controla la alineación de un solo elemento de la cuadrícula.
  • align-items: Controla la alineación vertical de las celdas de la cuadrícula.
  • align-self: Controla la alineación vertical de un solo elemento de la cuadrícula.

Ejemplo

<div class="grid justify-items-start ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
  <div>04</div>
  <div>05</div>
  <div>06</div>
</div>
