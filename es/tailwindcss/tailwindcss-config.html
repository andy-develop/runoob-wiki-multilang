Configuración de Tailwind CSS

El archivo de configuración central de Tailwind CSS estailwind.config.js。

tailwind.config.js es el archivo de configuración de Tailwind CSS, utilizado para personalizar la configuración predeterminada de Tailwind.

Al modificar el archivo tailwind.config.js, los desarrolladores pueden personalizar colores, espaciados, fuentes, puntos de interrupción y otros elementos del sistema de diseño para satisfacer las necesidades específicas del proyecto.

Crear archivo de configuración

Usando la herramienta CLI de Tailwind CSS se puede generar rápidamente un archivo tailwind.config.js básico.

Ejecuta el siguiente comando en el directorio raíz del proyecto:

npx tailwindcss init

Esto creará un archivo tailwind.config.js con la configuración básica.

Estructura básica

La siguiente es la estructura de un archivo tailwind.config.js típico:

Ejemplo

/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ["./src/**/*.{html,js,vue}"], // Definir las rutas de archivos de plantilla que se deben escanear
  theme: {
    extend: {}, // Extensión personalizada
  },
  plugins: [], // Configurar plugins
}

El código anterior le indica a Tailwind CSS que escanee todos los archivos .html, .js y .vue en el directorio src.

Principales opciones de configuración

1. Configurar ruta de plantillas: content

En el archivo tailwind.config.js, la opción content se utiliza para especificar qué archivos debe escanear Tailwind CSS para recopilar nombres de clases.
content: [
  "./index.html", // 单文件路径
  "./src/**/*.{html,js,ts,jsx,tsx}", // 包含多个文件类型的路径
],

Esto le indicará a Tailwind CSS que escanee todos los archivos .html, .js, .ts, .jsx y .tsx en el directorio src.

El campo content se utiliza para especificar las rutas de los archivos de plantilla de Tailwind. Tailwind escaneará estos archivos para generar los estilos necesarios, reduciendo el tamaño del archivo CSS generado, ya que solo genera los estilos utilizados en los archivos de plantilla y evita que los estilos no utilizados se compilen en la salida final.

2. Personalizar tema: theme

En la sección theme, puedes definir colores, fuentes, espaciados, tamaños de borde, etc.

Por ejemplo, extender los colores predeterminados o agregar nuevos colores:

theme: {
  extend: {
    colors: {
      cyan: '#9cdbff',
    }
  }
}

Esto agregará un nuevo color llamado cyan, que podrás usar en tu proyecto con nombres de clase como bg-cyan.

theme: {
  extend: {

      },
    },
  },
}

3. Configurar variantes: variants

La opción variants te permite definir qué estados (como hover, focus, etc.) deben incluirse en el CSS final.

Puedes extender o sobrescribir las variantes predeterminadas:

variants: {
  extend: {
    borderColor: ['focus-visible'],
    opacity: ['disabled'],
  }
}

4. Usar plugins: plugins

La opción plugins te permite agregar clases de utilidad personalizadas.

Estos plugins pueden ser proporcionados oficialmente por Tailwind CSS o creados por la comunidad, con el siguiente formato:

plugins: [
  require('some-tailwindcss-plugin')
]

Ejemplo de uso de plugins:

Ejemplo

const plugin = require('tailwindcss/plugin');

module.exports = {
  plugins: [
    plugin(function ({ addUtilities }) {
      addUtilities({
        '.text-shadow': {
          textShadow: '2px 2px 4px rgba(0,0,0,0.5)',
        },
      });
    }),
  ],
}

Importar plugins de la comunidad:

Ejemplo

module.exports = {
  plugins: [
    require('@tailwindcss/forms'), // Plugin de estilos para formularios
    require('@tailwindcss/typography'), // Plugin de tipografía
  ],
}

Configuración de Tailwind CSS

De forma predeterminada, Tailwind busca el archivo tailwind.config.js en el directorio raíz del proyecto, donde puedes establecer la configuración que necesites:

Ejemplo

/** @type {import('tailwindcss').Config} */
module.exports = {
  // Especifica de qué archivos Tailwind CSS debe extraer los nombres de clase. Aquí se configura para extraer de todos los archivos `.html` y `.js` en el directorio `./src`.
  content: ['./src/**/*.{html,js}'],

  theme: {
    // Configuración de colores personalizados
    colors: {
      'blue': '#1fb6ff', // Define un color llamado 'blue' con el valor #1fb6ff
      'purple': '#7e5bef', // Define un color llamado 'purple' con el valor #7e5bef
      'pink': '#ff49db', // Define un color llamado 'pink' con el valor #ff49db
      'orange': '#ff7849', // Define un color llamado 'orange' con el valor #ff7849
      'green': '#13ce66', // Define un color llamado 'green' con el valor #13ce66
      'yellow': '#ffc82c', // Define un color llamado 'yellow' con el valor #ffc82c
      'gray-dark': '#273444', // Define un color llamado 'gray-dark' con el valor #273444
      'gray': '#8492a6', // Define un color llamado 'gray' con el valor #8492a6
      'gray-light': '#d3dce6' // Define un color llamado 'gray-light' con el valor #d3dce6
    },
    // Configuración de familias de fuentes personalizadas
    fontFamily: {
      sans: ['Graphik', 'sans-serif'], // Define una familia de fuentes llamada 'sans', que incluye 'Graphik' y la genérica 'sans-serif'
      serif: ['Merriweather', 'serif'] // Define una familia de fuentes llamada 'serif', que incluye 'Merriweather' y la genérica 'serif'
    },
    // Configuración de extensión personalizada
    extend: {
      // Extensión de espaciados personalizados
      spacing: {
        '8xl': '96rem', // Define un espaciado llamado '8xl' con el valor 96rem
        '9xl': '128rem' // Define un espaciado llamado '9xl' con el valor 128rem
      },
      // Extensión de bordes redondeados personalizados
      borderRadius: {
        '4xl': '2rem' // Define un borde redondeado llamado '4xl' con el valor 2rem
      }
    }
  },
}

A través de tailwind.config.js, puedes personalizar fácilmente las funcionalidades y estilos de Tailwind CSS para adaptarte a diversas necesidades de diseño. Aprovechar adecuadamente características como la extensión (extend), los plugins (plugins) y la configuración del tema (theme) puede mejorar significativamente la eficiencia de desarrollo y la flexibilidad de estilos del proyecto.
