Manejo de estados de Tailwind CSS

Tailwind CSS ofrece potentes clases de estado (modificadores de estado) para controlar los cambios de estilo de los elementos en diferentes estados de interacción.

Tailwind CSS proporciona una variedad de clases de estado (como `hover:`, `focus:`, `active:`, etc.) para ayudar a los desarrolladores a manejar rápidamente los efectos de interacción. Combinando estas clases de estado, puedes lograr fácilmente cambios de estilo en estados como hover, focus, clic, etc., mejorando la experiencia del usuario.

Prefijos de las clases de estado:

EstadoPrefijoFunción
Estado hoverhover:Controla el cambio de estilo del elemento al pasar el ratón por encima.
Estado focusfocus:Controla el cambio de estilo del elemento cuando obtiene el foco.
Estado activoactive:Controla el cambio de estilo del elemento cuando se hace clic en él.
Estado visitadovisited:Controla los cambios de estilo de los enlaces visitados.
Estado focus-withinfocus-within:Controla el cambio de estilo del elemento padre cuando su hijo obtiene el foco.

Referencia de modificadores

Modifier Pseudoclases CSS correspondientes/
Pseudo-elementos o reglas		 Descripción Código de ejemplo
hover :hover Se aplica al pasar el cursor <button class="hover:bg-blue-500">Hover me</button>
focus :focus Se aplica cuando el elemento recibe el foco <input class="focus:ring-2 focus:ring-blue-600" />
focus-within :focus-within Se aplica cuando cualquier elemento secundario dentro del contenedor principal recibe el foco <div class="focus-within:border-blue-500"><input /></div>
focus-visible :focus-visible Foco activado por navegación con teclado o tecnología de asistencia <input class="focus-visible:ring-2 focus-visible:ring-blue-600" />
active :active Se aplica cuando el elemento se presiona o está activo <button class="active:bg-green-700">Click me</button>
visited :visited Enlace visitado <a class="visited:text-purple-600" href="../index.html">Visited link</a>
target :target Se aplica cuando se activa el enlace de destino <div id="section" class="target:bg-yellow-500"></div>
first :first-child Primer elemento secundario <ul><li class="first:text-red-500">First</li><li>Other</li></ul>
last :last-child Último elemento secundario <ul><li>Other</li><li class="last:font-bold">Last</li></ul>
odd :nth-child(odd) Elementos secundarios impares (contando desde 1) <ul><li class="odd:bg-gray-100">Odd</li><li>Even</li></ul>
even :nth-child(even) Elementos secundarios pares <ul><li>Odd</li><li class="even:bg-gray-200">Even</li></ul>
empty :empty Elementos con contenido vacío <div class="empty:bg-gray-50"></div>
disabled :disabled Elementos de formulario deshabilitados <button class="disabled:opacity-50" disabled>Disabled</button>
enabled :enabled Elementos de formulario habilitados <input class="enabled:border-blue-500" />
checked :checked Casillas de verificación o botones de opción seleccionados <input type="checkbox" class="checked:bg-blue-500" checked />
required :required El elemento de formulario es obligatorio <input class="required:border-red-500" required />
before ::before Pseudo-elemento insertado antes del elemento <div class="before:content-['*'] before:text-red-500"></div>
after ::after Pseudo-elemento insertado después del elemento <div class="after:content-['!'] after:text-green-500"></div>
sm @media (min-width: 640px) Pantallas pequeñas (desde 640px) <div class="sm:bg-blue-100">Resize to small screen</div>
dark @media (prefers-color-scheme: dark) Modo oscuro <div class="dark:bg-black dark:text-white">Dark mode content</div>
rtl [dir="rtl"] Dirección de texto de derecha a izquierda <div dir="rtl" class="rtl:text-right">Right to Left</div>
aria-checked [aria-checked="true"] Aplicar estilos a elementos con atributos ARIA <div aria-checked="true" class="aria-checked:bg-green-500">Checked</div>
motion-safe @media (prefers-reduced-motion: no-preference) Preferencia de animación: se aplica cuando no hay preferencia <div class="motion-safe:transition-transform motion-safe:duration-500"></div>
