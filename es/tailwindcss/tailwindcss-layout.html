Clases de diseño de Tailwind CSS

Tailwind CSS proporciona una amplia variedad de clases relacionadas con el diseño, que permiten a los desarrolladores controlar todos los aspectos de la página de una manera extremadamente flexible.

A continuación, explicaremos en detalle algunas de las clases de diseño más importantes.

1. Relación de aspecto (Aspect Ratio)

Las clases de Aspect Ratio te ayudan a establecer la relación de aspecto de un elemento, evitando que se estire o se comprima en el diseño responsive.

Clases principales:

Nombre de la clasePropiedad y valor CSSDescripción
aspect-autoaspect-ratio: auto;Esta clase hace que el elemento mantenga su relación de aspecto natural, sin ningún ajuste forzado. Es adecuada cuando quieres que el elemento se ajuste automáticamente según su contenido, en lugar de forzarlo a rellenar o reducirse a una relación de aspecto específica.
aspect-squareaspect-ratio: 1 / 1;Esta clase fuerza la relación de aspecto del elemento a 1:1, es decir, que el ancho y la altura sean iguales. Se usa comúnmente para crear elementos cuadrados o circulares.
aspect-videoaspect-ratio: 16 / 9;Esta clase fuerza la relación de aspecto del elemento a 16:9, que es una relación de aspecto común para videos. Es adecuada para elementos que necesitan mostrar videos o simular un reproductor de video.

Ejemplo

<!-- Mantener la relación de aspecto 16:9 -->
<div class="aspect-ratio">
  <img src="video.jpg" alt="Video" class="object-cover">
</div>

2. Contenedor (Container)

La clase Container permite que un elemento contenedor se adapte de forma responsive a diferentes tamaños de pantalla. Se usa a menudo para establecer el ancho máximo del contenido.

Clases principales:

  • container: hace que el elemento se convierta en un contenedor responsive.
  • mx-auto: centra el contenedor horizontalmente.
Nombre de la clase Propiedad y valor CSS Descripción
container width: 100%; El ancho del contenedor es del 100% por defecto, ocupando todo el ancho del elemento padre.
sm:container max-width: 640px; Cuando el ancho de la pantalla es mayor o igual a 640px, el ancho máximo del contenedor es de 640px.
md:container max-width: 768px; Cuando el ancho de la pantalla es mayor o igual a 768px, el ancho máximo del contenedor es de 768px.
lg:container max-width: 1024px; Cuando el ancho de la pantalla es mayor o igual a 1024px, el ancho máximo del contenedor es de 1024px.
xl:container max-width: 1280px; Cuando el ancho de la pantalla es mayor o igual a 1280px, el ancho máximo del contenedor es de 1280px.
2xl:container max-width: 1536px; Cuando el ancho de la pantalla es mayor o igual a 1536px, el ancho máximo del contenedor es de 1536px.

Al usar estas clases, puedes crear contenedores con un ancho máximo responsive, lo que es muy útil al crear diseños, especialmente cuando quieres limitar el ancho del contenido para mejorar la legibilidad.

Ejemplo

<div class="container mx-auto">
  <!-- Contenido -->
</div>

<div class="lg:container mx-auto">
  <!-- Contenido con un ancho máximo de 1024px en pantallas grandes -->
</div>

En estos ejemplos, el primer<div>siempre ocupará el 100% del ancho, mientras que el segundo<div>en pantallas grandes (lg) y tamaños de pantalla superiores, su ancho máximo se limitará a 1024px.mx-autoLa clase se utiliza para centrar el contenedor horizontalmente.

4. Paginación

Las siguientes clases ayudan a los desarrolladores a controlar mejor el diseño de paginación y columnas de un documento, para mejorar la legibilidad y la estética de la salida impresa.

Clases principales:

  • break-after-{value}: controla el comportamiento después de un salto de página.
  • break-before-{value}: controla el comportamiento antes de un salto de página.

break-after-allbreak-after: all;Fuerza una división en páginas o columnas después de este elemento, incluso si no es una posición natural para ello.
break-after-avoid-pagebreak-after: avoid-page;Evita en lo posible dividir en páginas después de este elemento, pero permite dividir en columnas.
break-after-pagebreak-after: page;Fuerza una división en páginas después de este elemento, pero no permite dividir en columnas.
break-after-leftbreak-after: left;Fuerza una división en páginas o columnas después de este elemento, prefiriendo la página izquierda.
break-after-rightbreak-after: right;Fuerza una división en páginas o columnas después de este elemento, prefiriendo la página derecha.
break-after-columnbreak-after: column;Fuerza una división en columnas después de este elemento, pero no permite dividir en páginas.

Las clases anteriores se utilizan para controlar el comportamiento de división en páginas o columnas del contenido en impresiones o diseños de columnas:

  • break-inside-autoPermite que el navegador decida si dividir en páginas o columnas dentro de un elemento.

Ejemplo

<div class="columns-2">
  <p>Bueno, déjame contarte algo...</p>
  <p class="break-after-column">Por supuesto, continuemos con nuestro contenido...</p>
  <p>Quizás podamos...</p>
  <p>Si crees que esto es...</p>
</div>

En este ejemplo, el<div>elemento se configura con un diseño de dos columnas (columns-2), que contiene cuatro<p>párrafos. El segundo<p>párrafo tiene unbreak-after-columnClase, esto fuerza un salto de columna después de ese párrafo, pero no permite un salto de página. Esto significa que si el contenido es suficiente, el contenido después del segundo párrafo comenzará en una nueva columna, en lugar de continuar en la siguiente línea de la misma columna. Los demás párrafos no tienen instrucciones especiales de división de columnas, por lo que fluirán naturalmente según su contenido.

5. Salto de línea de texto

A continuación se presentan las clases de utilidad en Tailwind CSS para controlar cómo se renderizan los fragmentos de elementos en múltiples líneas, columnas o páginas, junto con sus propiedades CSS correspondientes:

Nombre de clasePropiedad y valor CSSDescripción
box-decoration-clonebox-decoration-break: clone;Especifica que cuando un cuadro se divide en varios cuadros (por ejemplo, en los límites de columnas o páginas), cada cuadro debe clonar la decoración del cuadro original (bordes, fondo, etc.).
box-decoration-slicebox-decoration-break: slice;Especifica que cuando un cuadro se divide en varios cuadros, cada cuadro debe "cortar" la decoración del cuadro original, de modo que la decoración se muestre de forma continua en cada cuadro.

Las clases anteriores se utilizan para controlar el comportamiento de la decoración de los elementos (como bordes y fondos) en diseños de varias columnas o al paginar.

  • box-decoration-cloneHará que cada fragmento de cuadro muestre la decoración completa.
  • box-decoration-sliceEn cambio, cortará la decoración donde se divide el cuadro, de modo que la decoración permanezca visualmente continua.

Estas clases de utilidad pueden ayudar a los desarrolladores a controlar mejor el efecto visual de los elementos en diseños complejos.

Ejemplo

  Hello<br />
  World
</span>
<span class="box-decoration-clone bg-gradient-to-r from-indigo-600 to-pink-500 text-white px-2 ...">

6. Tamaño de caja

Tailwind CSS proporciona dos clases de utilidad para controlar el modelo de caja (box-sizing) de los elementos:

  • box-border: calcula el tamaño total del elemento incluyendo el relleno y el borde.
  • box-content: calcula el tamaño del elemento sin incluir el relleno ni el borde.

1、box-border

Propiedad CSS:

box-sizing: border-box;

Usa la clase de utilidad `box-border` para establecer la propiedad `box-sizing` del elemento en `border-box`. Esto significa que cuando se especifica una altura o anchura al elemento, el navegador incluirá el borde y el relleno del elemento.

Si un elemento tiene un tamaño de 100px × 100px, con un borde de 2px y un relleno de 4px, el tamaño total de renderizado del elemento será de 112px × 112px.

Ejemplo

<div class="box-content h-32 w-32 p-4 border-4 ...">
  <!-- ... -->
</div>

2、box-content

Propiedad CSS:

box-sizing: content-box;

Usa la clase de utilidad `box-content` para establecer la propiedad `box-sizing` del elemento en `content-box`. Esto significa que el navegador añadirá el borde y el relleno fuera del ancho o la altura especificados del elemento.

Si un elemento tiene un tamaño de 100px × 100px, con un borde de 2px y un relleno de 4px, el tamaño real de renderizado del elemento será de 112px × 112px, con un área de contenido interno de 100px × 100px.

Ejemplo

<div class="box-content h-32 w-32 p-4 border-4 ...">
  <!-- ... -->
</div>

object-fillobject-fit: fill;Ignora la relación de aspecto del elemento, estirándolo o comprimiéndolo para llenar completamente el contenedor.
object-noneobject-fit: none;Mantiene el tamaño original del elemento, sin escalado.
object-scale-downobject-fit: scale-down;Mantiene la relación de aspecto del elemento, de manera similar acontainpero elige el tamaño más pequeño para ajustarse al contenedor, sin dejar espacio en blanco.

Use `object-cover` para ajustar el tamaño del contenido del elemento a fin de cubrir su contenedor:

Ejemplo

<div class="bg-indigo-300 ...">
  <img class="object-cover h-48 w-96 ...">
