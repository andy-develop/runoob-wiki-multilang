Objeto Style

El objeto Style representa una declaración de estilo individual.

Acceder al objeto Style

Se puede acceder al objeto Style desde el área de encabezado del documento, o desde un elemento HTML especificado.

Acceder al objeto style desde el área de encabezado del documento:

var x = document.getElementsByTagName("STYLE"); Inténtalo

Acceder al objeto style de un elemento especificado:

var x = document.getElementById("myH1").style; Inténtalo

Crear un objeto Style

Puede utilizar el método document.createElement() para crear un elemento <style>:

var x = document.createElement("STYLE"); Inténtalo

También puede establecer la propiedad style de un elemento existente:

document.getElementById("myH1").style.color = "red"; Inténtalo
