HTML DOM Evento

Eventos HTML DOM

Los eventos HTML DOM permiten que Javascript registre diferentes manejadores de eventos en elementos de documentos HTML.

Los eventos generalmente se usan en combinación con funciones, ¡las funciones no se ejecutarán antes de que ocurra el evento! (como cuando el usuario hace clic en un botón).

Consejo:El modelo de eventos está especificado en el evento DOM Nivel 2 de W3C.
