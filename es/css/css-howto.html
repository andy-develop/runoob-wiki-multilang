CSS Creación

Cuando el navegador lee una hoja de estilos, formatea el documento HTML de acuerdo con ella.

Cómo insertar una hoja de estilos

Hay tres formas de insertar una hoja de estilos:

  • Hoja de estilos externa (External style sheet)
  • Hoja de estilos interna (Internal style sheet)
  • Estilo en línea (Inline style)

Hoja de estilos externa

Cuando los estilos necesitan aplicarse a muchas páginas, la hoja de estilos externa es la opción ideal. Con una hoja de estilos externa, puedes cambiar la apariencia de todo el sitio modificando un solo archivo. Cada página utiliza la etiqueta <link> para enlazar la hoja de estilos. La etiqueta <link> está en la cabecera (del documento):

<head> <link rel="stylesheet" type="text/css" href="mystyle.css"> </head>

El navegador leerá las declaraciones de estilo del archivo mystyle.css y formateará el documento de acuerdo con ellas.

La hoja de estilos externa puede editarse en cualquier editor de texto. El archivo no debe contener etiquetas HTML. La hoja de estilos debe guardarse con la extensión .css. A continuación se muestra un ejemplo de archivo de hoja de estilos:

hr {color:sienna;} p {margin-left:20px;} body {background-image:url("/images/back40.gif");}

No dejes espacios entre el valor de la propiedad y la unidad (por ejemplo: "margin-left: 20 px"); la forma correcta es "margin-left: 20px".

Hoja de estilos interna

Cuando un solo documento necesita estilos especiales, se debe utilizar una hoja de estilos interna. Puedes definir una hoja de estilos interna en la cabecera del documento usando la etiqueta <style>, así:

<head> <style> hr {color:sienna;} p {margin-left:20px;} body {background-image:url("images/back40.gif");} </style> </head>

Estilo en línea

Dado que mezcla presentación y contenido, el estilo en línea pierde muchas ventajas de la hoja de estilos. Usa este método con precaución, por ejemplo cuando el estilo solo necesite aplicarse una vez a un elemento.

Para usar estilos en línea, necesitas utilizar el atributo de estilo (style) dentro de la etiqueta correspondiente. El atributo style puede contener cualquier propiedad CSS. Este ejemplo muestra cómo cambiar el color y el margen izquierdo de un párrafo:

<p style="color:sienna;margin-left:20px">Este es un párrafo.</p>

Estilos múltiples

Si algunas propiedades están definidas por el mismo selector en diferentes hojas de estilo, el valor de la propiedad se heredará de la hoja de estilos más específica.

Por ejemplo, la hoja de estilos externa tiene tres propiedades para el selector h3:

h3 { color:red; text-align:left; font-size:8pt; }

Mientras que la hoja de estilos interna tiene dos propiedades para el selector h3:

h3 { text-align:right; font-size:20pt; }

Si la página que tiene la hoja de estilos interna también está enlazada con la hoja de estilos externa, el estilo que recibe h3 es:

color:red; text-align:right; font-size:20pt;

Es decir, la propiedad de color se heredará de la hoja de estilos externa, mientras que la alineación del texto (text-alignment) y el tamaño de fuente (font-size) serán reemplazados por las reglas de la hoja de estilos interna.

Prioridad de estilos múltiples

Las hojas de estilo permiten especificar la información de estilo de varias formas. Los estilos pueden definirse en un elemento HTML individual, en el elemento de cabecera de una página HTML, o en un archivo CSS externo. Incluso es posible referenciar múltiples hojas de estilo externas dentro del mismo documento HTML.

En general, la prioridad es la siguiente:

(Estilo en línea) Inline style > (Hoja de estilos interna) Internal style sheet > (Hoja de estilos externa) External style sheet > Estilos predeterminados del navegador

style.cssEl código de los estilos del archivo es el siguiente:

h3 {
    color:blue;
}

Ejemplo

<head> <!--Hoja de estilos externa style.css--> <link rel="stylesheet" type="text/css" href="style.css"/> <!--Configuración: h3{color:blue;}--> <style type="text/css">/* Estilo interno */ h3{color:green;}</style> </head> <body> <h3>Se muestra verde, correspondiente al estilo interno</h3> </body>

    Conceptos avanzados sobre la prioridad de estilos múltiples

    La prioridad es el mecanismo mediante el cual el navegador decide qué valores de propiedad son los más relevantes para un elemento y los aplica a dicho elemento. La prioridad está determinada únicamente por las reglas de coincidencia compuestas por selectores.

    La prioridad es un peso asignado a una declaración CSS específica, determinado por los valores de cada tipo de selector en el selector que coincide.

    Orden de prioridad

    La siguiente es una lista de selectores en orden creciente de prioridad:

    • Selector universal (*)
    • Selector de elemento (tipo)
    • Selector de clase
    • Selector de atributo
    • Pseudo-clases
    • Selector de ID
    • Estilo en línea

    Excepción de la regla !important

    Cuando se aplica la regla !important a una declaración de estilo, esta declaración sobrescribirá cualquier otra declaración en CSS, sin importar dónde se encuentre en la lista de declaraciones. Sin embargo, la regla !important no tiene relación con la prioridad. Usar !important no es una buena práctica, porque cambia las reglas de cascada naturales de tu hoja de estilos, lo que dificulta la depuración.

    Algunas reglas prácticas:

    • AlwaysSe debe considerar optimizar el uso de la prioridad de las reglas de estilo para resolver los problemas en lugar de usar !important.!important
    • OnlyUsar !important solo en páginas específicas donde sea necesario sobrescribir el CSS global o externo (por ejemplo, ExtJs o YUI referenciados).!important
    • NeverNunca usar !important en el CSS de todo el sitio. !important
    • NeverNunca usar !important en tus plugins.!important

    Cálculo de pesos:

    Explicación:

    • 1. La hoja de estilos en línea tiene el peso más alto: 1000;
    • 2. El selector de ID tiene un peso de 100
    • 3. El selector de clase tiene un peso de 10
    • 4. El selector de etiqueta HTML tiene un peso de 1

    Utilizando los pesos de los selectores para calcular y comparar, em se muestra en azul. Ejemplo:https://c.runoob.com/codedemo/3048

    Reglas de prioridad de CSS:

    • A Todo selector tiene un peso; cuanto mayor es el peso, mayor es la prioridad;
    • B Cuando los pesos son iguales, la configuración de la hoja de estilos que aparece después tiene prioridad sobre la que aparece primero;
    • C Las reglas del autor están por encima de las del usuario: es decir, los estilos CSS establecidos por el autor de la página tienen mayor prioridad que los estilos establecidos por el navegador;
    • D Los estilos CSS heredados tienen menor prioridad que los estilos CSS especificados posteriormente;
    • E En el mismo grupo de propiedades, la regla marcada con "!important" tiene la máxima prioridad; ejemplo:https://c.runoob.com/codedemo/3049
