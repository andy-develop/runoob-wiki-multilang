2.2 Representación de valores Verilog

Categorías Tutorial de Verilog

Tipos de valores

Verilog HDL tiene los siguientes cuatro valores básicos para representar la lógica de nivel en circuitos de hardware:

  • 0: Lógica 0 o "falso"
  • 1: Lógica 1 o "verdadero"
  • x o X: desconocido
  • z o Z: alta impedancia

xSignifica que el valor de la señal es incierto, es decir, en el circuito real, la señal puede ser 1 o 0.

zSignifica que la señal está en estado de alta impedancia, comúnmente se ve en el resultado lógico cuando una señal (input, reg) no tiene driver. Por ejemplo, cuando la entrada de un pad está en alta impedancia, su valor lógico depende del estado de pull-up/pull-down. Con pull-up el valor lógico es 1, con pull-down es 0.

Métodos de representación de valores enteros

Al declarar números, hay 4 formatos de base válidos: decimal ('d o 'D), hexadecimal ('h o 'H), binario ('b o 'B), octal ('o o 'O). Los valores pueden especificar el ancho de bits o no.

Especificando el ancho de bits:

Ejemplo

4'b1011         // Valor de 4 bits
32'h3022_c0de   // Valor de 32 bits

Donde, el guion bajo_es para mejorar la legibilidad del código.

Sin especificar el ancho de bits:

Generalmente, al escribir números directamente, se asume representación decimal, por ejemplo, las siguientes 3 formas son equivalentes:

Ejemplo

counter = 'd100 ; // Generalmente el ancho de bits se asigna automáticamente según el compilador, comúnmente 32 bits.
counter = 100 ;
counter = 32'h64 ;

Representación de números negativos

Normalmente se añade un signo menos delante del número que indica el ancho de bits para representar números negativos. Por ejemplo:

-6'd15  
-15

-15 en binario de 5 bits es 5'b10001, en binario de 6 bits es 6'b11_0001.

Cabe señalar que poner el signo menos entre la base y el número es ilegal, por ejemplo, la siguiente representación es incorrecta:

4'd-2 //非法说明

Métodos de representación de números reales

Hay principalmente dos formas de representar números reales:

Decimal:

30.123
6.0
3.0
0.001

Notación científica:

1.2e4         //大小为12000
1_0001e4      //大小为100010000
1E-3          //大小为0.001

Métodos de representación de cadenas

Una cadena es una secuencia de caracteres entre comillas dobles. Una cadena no puede escribirse en varias líneas, es decir, no puede contener caracteres de retorno de carro. Verilog trata las cadenas como una secuencia de caracteres ASCII de un solo byte. Por ejemplo, para almacenar la cadena "www.runoob.com", se necesitan 14*8bit de celdas de memoria. Por ejemplo:

Ejemplo

reg [0: 14*8-1]       str ;
initial begin
    str = "www.runoob.com";
end
