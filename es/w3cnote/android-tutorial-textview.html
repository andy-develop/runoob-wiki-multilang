El control de UI que traemos en esta sección es: TextView (campo de texto), un control utilizado para mostrar texto. Además, aclaro que no estoy traduciendo la documentación de la API, ni voy a analizar cada atributo; solo estudiamos los que son comunes y útiles en el desarrollo real. Si te encuentras con atributos desconocidos, ¡puedes consultar la API correspondiente! Por supuesto, al inicio de cada sección se incluye el enlace a la documentación de la API correspondiente:TextView APIBien, antes de comenzar con el contenido de esta sección, primero presentaremos algunas unidades:

dp(dip):device independent pixels (píxeles independientes del dispositivo). Diferentes dispositivos tienen diferentes efectos de visualización; esto está relacionado con el hardware del dispositivo. Generalmente, para soportar WVGA, HVGA y QVGA, se recomienda usar esto; no depende de los píxeles.px: pixels (píxeles). Diferentes dispositivos muestran el mismo efecto; generalmente HVGA representa 320x480 píxeles, este se usa bastante.pt: point, es una unidad de longitud estándar, 1pt = 1/72 pulgada, utilizada en la industria de la impresión, muy simple y fácil de usar;sp: scaled pixels (píxeles escalados). Se utiliza principalmente para la visualización de fuentes; lo mejor para textSize.

El TextView anterior tiene los siguientes atributos:

  • id：Establece un id de componente para el TextView. Según el id, podemos obtener el objeto en código Java mediante el método findViewById(), y luego configurar los atributos relacionados. O cuando se usa RelativeLayout, ¡el id también se usa para referenciar componentes!
  • layout_width：El ancho del componente, generalmente se escribe: **wrap_content** o **match_parent(fill_parent)**. El primero hace que el control sea tan grande como el contenido que muestra, mientras que el segundo llena el contenedor padre donde se encuentra el control; por supuesto, también se puede establecer un tamaño específico, como aquí, que para el efecto visual lo configuré a 200dp.
  • layout_height：La altura del componente, igual que el contenido anterior.
  • gravity：Establece la dirección de alineación del contenido dentro del control; en TextView es texto, en ImageView es imagen, etc.
  • text：Establece el contenido de texto mostrado. Generalmente escribimos las cadenas en el archivo string.xml y luego obtenemos el contenido de la cadena correspondiente mediante @String/xxx. Aquí, por conveniencia, lo escribo directamente entre "", ¡¡pero no se recomienda hacer esto!!!
  • textColor：Establece el color de la fuente. Igual que arriba, se debe referenciar mediante el recurso colors.xml, ¡no lo escribas directamente así!
  • textStyle：Establece el estilo de la fuente, tres valores opcionales: **normal** (sin efecto), **bold** (negrita), **italic** (cursiva)
  • textSize：Tamaño de la fuente, ¡la unidad generalmente es sp!
  • background：El color de fondo del control, puede entenderse como el color que rellena todo el control; ¡también puede ser una imagen!

Varios atributos involucrados:

  • android:shadowColor:Establece el color de la sombra, ¡debe usarse junto con shadowRadius!
  • android:shadowRadius:Establece el grado de desenfoque de la sombra. Si se establece en 0.1 se convierte en el color de la fuente; se recomienda usar 3.0.

2.2 TextView con borde:

Si quieres establecer un fondo de borde para TextView, ya sea un borde rectangular normal o un borde redondeado, ¡lo siguiente puede ayudarte! Además, TextView es la clase padre de muchos otros controles, como Button, ¡también se pueden configurar con este tipo de borde! El principio de implementación es muy simple: ¡escribe tu propio archivo de recursos ShapeDrawable! Luego, en TextView, establece el blackgroung como este recurso drawable.

Hablemos brevemente de los nodos y atributos del archivo de recursos shapeDrawable:

  • <solidandroid:color = "xxx"> Esto establece el color de fondo.
  • <strokeandroid:width = "xdp" android:color="xxx"> Esto establece el grosor del borde y el color del borde.
  • <paddingandroidLbottom = "xdp"...> Esto establece el margen.
  • <cornersandroid:topLeftRadius="10px"...> Esto establece las esquinas redondeadas.
  • <gradient> Esto establece el color degradado; los atributos opcionales son:startColor: color inicialendColor: color finalcenterColor: color intermedioangle: ángulo de dirección. Cuando es igual a 0, va de izquierda a derecha, y luego gira en sentido antihorario; cuando angle = 90 grados, va de abajo hacia arriba.type: establece el tipo de degradado

public class MainActivity extends Activity {

                drawable[3]);  
    }  
}

2.5 TextView y el manejo de HTML

Como dice el título, además de mostrar texto normal, TextView tiene predefinidas algunas etiquetas similares a HTML. A través de estas etiquetas, podemos hacer que TextView muestre diferentes colores de fuente, tamaños, tipos de letra, e incluso imágenes o enlaces. ¡Solo necesitamos usar algunas etiquetas de HTML, junto con el soporte de la clase `android.text.HTML`, para lograr las funciones anteriores!

PD: Por supuesto, no se admiten todas las etiquetas. Las más utilizadas son las siguientes:

  • <font>: Establecer color y fuente.
  • <big>: Establecer tamaño de fuente grande.
  • <small>: Establecer tamaño de fuente pequeño.
  • <i><b>: Cursiva y negrita.
  • <a>: Enlace a URL.
  • <img>: Imagen.

Si se usa `setText` directamente no tiene efecto; necesitamos llamar al método `Html.fromHtml()` para convertir la cadena en una interfaz `CharSequence`, y luego establecerlo. Si necesitamos la configuración correspondiente, hay que configurar el TextView llamando al siguiente método:Java setMovementMethod(LinkMovementMethod.getInstance())

Bien, a continuación escribamos código para probar:

2.6 Personalización de texto con SpannableString y SpannableStringBuilder

Además del HTML anterior que puede personalizar el estilo de nuestro TextView, también se puede hacer con `SpannableString` y `SpannableStringBuilder`. La diferencia entre ambos: el primero está orientado a texto inmutable, mientras que el segundo está orientado a texto mutable. Aquí solo se explica el primero; si te interesa el segundo, puedes consultar la documentación por tu cuenta.

Las API que `SpannableString` pone a nuestra disposición son las siguientes:

  • BackgroundColorSpanColor de fondo
  • ClickableSpanTexto clicable, con evento de clic
  • ForegroundColorSpanColor de texto (color de primer plano)
  • MaskFilterSpanEfectos de decoración, como desenfoque (`BlurMaskFilter`), relieve (`EmbossMaskFilter`)
  • MetricAffectingSpanClase padre, generalmente no se usa
  • RasterizerSpanEfecto rasterizador
  • StrikethroughSpanTachado (línea media)
  • SuggestionSpanEquivale a un marcador de posición
  • UnderlineSpanSubrayado
  • AbsoluteSizeSpanTamaño absoluto (fuente de texto)
  • DynamicDrawableSpanEstablece imagen, alineada con la línea base del texto o con la parte inferior.
  • ImageSpanImagen
  • RelativeSizeSpanTamaño relativo (fuente de texto)
  • ReplacementSpanClase padre, generalmente no se usa
  • ScaleXSpanEscala basada en el eje X
  • StyleSpanEstilo de fuente: negrita, cursiva, etc.
  • SubscriptSpanSubíndice (se usa en fórmulas matemáticas)
  • SuperscriptSpanSuperíndice (se usa en fórmulas matemáticas)
  • TextAppearanceSpanApariencia del texto (incluye fuente, tamaño, estilo y color)
  • TypefaceSpanFuente de texto
  • URLSpanHipervínculo de texto

Bueno, son bastantes. Aquí te doy el ejemplo más sencillo. Para los demás parámetros, puedes buscar en Baidu o Google por tu cuenta.1) El ejemplo más simple:Imagen del efecto en ejecución:

Código de implementación:

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        TextView t1 = (TextView) findViewById(R.id.txtOne);
        TextView t2 = (TextView) findViewById(R.id.txtTwo);

        SpannableString span = new SpannableString("红色打电话斜体删除线绿色下划线图片:.");
        //1.设置背景色,setSpan时需要指定的flag,Spanned.SPAN_EXCLUSIVE_EXCLUSIVE(前后都不包括)
        span.setSpan(new ForegroundColorSpan(Color.RED), 0, 2, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //2.用超链接标记文本
        span.setSpan(new URLSpan("tel:4155551212"), 2, 5, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //3.用样式标记文本（斜体）
        span.setSpan(new StyleSpan(Typeface.BOLD_ITALIC), 5, 7, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //4.用删除线标记文本
        span.setSpan(new StrikethroughSpan(), 7, 10, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //5.用下划线标记文本
        span.setSpan(new UnderlineSpan(), 10, 16, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //6.用颜色标记
        span.setSpan(new ForegroundColorSpan(Color.GREEN), 10, 13,Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //7.//获取Drawable资源
        Drawable d = getResources().getDrawable(R.drawable.icon);
        d.setBounds(0, 0, d.getIntrinsicWidth(), d.getIntrinsicHeight());
        //8.创建ImageSpan,然后用ImageSpan来替换文本
        ImageSpan imgspan = new ImageSpan(d, ImageSpan.ALIGN_BASELINE);
        span.setSpan(imgspan, 18, 19, Spannable.SPAN_INCLUSIVE_EXCLUSIVE);
        t1.setText(span);
    }
}

2) Implementar un TextView parcialmente clicableCreo que los amigos que han usado QQ Zone y WeChat Moments no son ajenos a lo siguiente: podemos hacer clic en el usuario correspondiente y luego entrar a ver la información relacionada con el usuario, ¿verdad?

A continuación escribamos un ejemplo simple para lograr este efecto:

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        TextView t1 = (TextView) findViewById(R.id.txtOne);

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 20; i++) {
            sb.append("好友" + i + "，");
        }

        String likeUsers = sb.substring(0, sb.lastIndexOf("，")).toString();
        t1.setMovementMethod(LinkMovementMethod.getInstance());
        t1.setText(addClickPart(likeUsers), TextView.BufferType.SPANNABLE);
    }

    //定义一个点击每个部分文字的处理方法
    private SpannableStringBuilder addClickPart(String str) {
        //赞的图标，这里没有素材，就找个笑脸代替下~
        ImageSpan imgspan = new ImageSpan(MainActivity.this, R.drawable.ic_widget_face);
        SpannableString spanStr = new SpannableString("p.");
        spanStr.setSpan(imgspan, 0, 1, Spannable.SPAN_INCLUSIVE_EXCLUSIVE);

        //创建一个SpannableStringBuilder对象，连接多个字符串
        SpannableStringBuilder ssb = new SpannableStringBuilder(spanStr);
        ssb.append(str);
        String[] likeUsers = str.split("，");
        if (likeUsers.length > 0) {
            for (int i = 0; i < likeUsers.length; i++) {
                final String name = likeUsers[i];
                final int start = str.indexOf(name) + spanStr.length();
                ssb.setSpan(new ClickableSpan() {
                    @Override
                    public void onClick(View widget) {
                        Toast.makeText(MainActivity.this, name,
                                Toast.LENGTH_SHORT).show();
                    }

                    @Override
                    public void updateDrawState(TextPaint ds) {
                        super.updateDrawState(ds);
                        //删除下划线，设置字体颜色为蓝色
                        ds.setColor(Color.BLUE);
                        ds.setUnderlineText(false);
                    }
                },start,start + name.length(),0);
            }
        }
    return ssb.append("等" + likeUsers.length + "个人觉得很赞");
    }
}

2.8 Configurar el espaciado entre letras y el interlineado de TextView

Igual que cuando redactamos documentos normalmente, necesitamos maquetar y establecer el interlineado o el espaciado entre caracteres, ¿verdad? El TextView en Android también permite hacer esta configuración:

Espaciado entre caracteres:

Java中setScaleX(2.0f);

Interlineado:En el sistema Android, TextView muestra chino de manera compacta por defecto. Para mantener el interlineado de cada línea

android:lineSpacingExtra：Establecer el interlineado, por ejemplo `"3dp"`android:lineSpacingMultiplier：Establecer el múltiplo del interlineado, por ejemplo `"1.2"`

En código Java se puede mediante:setLineSpacingmétodos para establecerlo

2.9 Ajuste automático de línea

El ajuste automático de línea se realiza medianteandroid:singleLineconfiguración, el valor predeterminado es `false`.

Si necesita ajuste automático de línea, puede usar:

android:singleLine = "false"

Si quiere mostrarlo todo en una sola línea sin saltos, puede usar:

android:singleLine = "true"

Además, también se puede configurar para que si no cabe en varias líneas, basta con añadir el atributo `maxLines`.
