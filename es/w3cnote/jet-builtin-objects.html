2.3 Objetos integrados de Jet

Categorías Tutorial de uso de JMR

Los objetos integrados de Jet son objetos Java proporcionados para cada plantilla; los desarrolladores pueden usarlos directamente sin declararlos explícitamente.

Jet tiene 2 objetos integrados:

  • out: genera objetos dentro de <% %>, con una función similar a <%=%>.
  • context: es un contenedor para variables de plantilla; a través de él se pueden establecer u obtener variables.

objeto out

Método de salida: out.write(Object obj), equivalente a llamar al método toString().

objeto context

context es un contenedor utilizado para transferir variables. Las variables establecidas en context pueden ser reconocidas en plantillas, Actions y etiquetas Jmr.

Establecer variable: context.setVariable(String name, Object object)

Obtener variable: context.getVariable(String name)

Las variables establecidas en context pueden ser obtenidas por etiquetas Jmr.

En la siguiente subsección, se presentará cómo usar context en Action para pasar variables a las plantillas Jet.
