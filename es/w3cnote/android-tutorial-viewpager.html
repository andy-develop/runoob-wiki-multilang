2.6.3 Uso simple de ViewPager

Categoría Tutorial básico de introducción a Android

Introducción de esta sección:

Esta sección presenta un control de UI introducido después de Android 3.0: ViewPager (herramienta de conmutación por deslizamiento de vistas). Realmente no sé cómo llamar a este control; su función aproximada es: mediante el deslizamiento con el dedo se puede completar la conmutación de vistas. Generalmente se usa para las páginas de guía de las apps o para implementar el carrusel de imágenes. Como fue introducido después de 3.0, si quieres usarlo en versiones anteriores, necesitas importar el paquete de compatibilidad v4. También podemos ver que ViewPager está en el directorio: android.support.v4.view.ViewPager ~ A continuación, aprendamos el uso básico de este control ~ Documentación oficial de la API:ViewPager

1. Breve introducción a ViewPager

ViewPager es un componente simple de cambio de páginas. Podemos rellenar múltiples Views en él, y luego podemos deslizar a izquierda y derecha para cambiar entre diferentes Views. Podemos usar el método setPageTransformer() para establecer efectos de animación al cambiar para nuestro ViewPager. Por supuesto, todavía no hemos aprendido animaciones, así que dejaremos el tema de configurar animaciones para ViewPager para el próximo capítulo, ¡Dibujo y Animación! Igual que con ListView y GridView que aprendimos antes, también necesitamos un Adapter (adaptador) para vincular nuestras Views con el ViewPager, y ViewPager tiene un Adapter específico —PagerAdapter¡Además, Google oficialmente recomienda usar Fragment para llenar ViewPager, de esta manera se puede generar cada página más convenientemente y gestionar el ciclo de vida de cada página! Nos proporciona dos Adapters especiales para Fragment:FragmentPageAdapter和FragmentStatePagerAdapterAnalicemos brevemente la diferencia entre estos dos Adapters:

  • FragmentPageAdapter: Igual que PagerAdapter, solo almacena en caché el Fragment actual y el de la izquierda y el de la derecha, es decir, en total solo almacena en caché 3 Fragments. Si hay cuatro páginas 1, 2, 3, 4:
    En la página 1: almacena en caché 1, 2
    En la página 2: almacena en caché 1, 2, 3
    En la página 3: destruye la página 1, almacena en caché 2, 3, 4
    En la página 4: destruye la página 2, almacena en caché 3, 4
    Para más páginas, y así sucesivamente ~
  • FragmentStatePagerAdapter: Cuando el Fragment no es visible para el usuario, todo el Fragment será destruido, y solo se guarda el estado del Fragment. ¡Y cuando la página necesite mostrarse nuevamente, se generará una nueva página!

En resumen, FragmentPageAdapter es adecuado para situaciones con pocas páginas fijas; mientras que FragmentStatePagerAdapter es adecuado para casos con muchas páginas o contenido de página muy complejo (que requiere mucha memoria).

2. Uso de PagerAdapter

Primero presentaremos el PagerAdapter más común. Si quieres usar este PagerAdapter, debes sobrescribir los siguientes cuatro métodos: Por supuesto, esto es solo una sugerencia oficial; en realidad, solo necesitamos sobrescribir getCount() e isViewFromObject() ~

  • getCount(): obtener cuántas views hay en el ViewPager.
  • destroyItem(): eliminar la página en una posición dada. El adaptador tiene la responsabilidad de eliminar esta vista del contenedor. Esto es para asegurar que la vista pueda ser eliminada cuando finishUpdate(viewGroup) regrese.

Los otros dos métodos involucran una cosa llamada key:

  • instantiateItem(): ① Agregar la vista en la posición dada al ViewGroup (contenedor), crearla y mostrarla. ② Devolver un Object (key) que represente la página recién agregada; normalmente puedes devolver directamente la propia vista. Por supuesto, también puedes personalizar tu propio key, pero cada key y cada view deben tener una relación uno a uno.
  • isViewFromObject(): Determinar si el Key devuelto por la función instantiateItem(ViewGroup, int) y una vista de página representan la misma vista (es decir, si corresponden; si corresponden, representan la misma View). Normalmente escribimos directamente return view == object!

Luego escribir un PagerAdapter personalizado:

MyPagerAdapter.java：

public class MyPagerAdapter extends PagerAdapter {
    private ArrayList<View> viewLists;

    public MyPagerAdapter() {
    }

    public MyPagerAdapter(ArrayList<View> viewLists) {
        super();
        this.viewLists = viewLists;
    }

    @Override
    public int getCount() {
        return viewLists.size();
    }

    @Override
    public boolean isViewFromObject(View view, Object object) {
        return view == object;
    }

    @Override
    public Object instantiateItem(ViewGroup container, int position) {
        container.addView(viewLists.get(position));
        return viewLists.get(position);
    }

    @Override
    public void destroyItem(ViewGroup container, int position, Object object) {
        container.removeView(viewLists.get(position));
    }
}

Luego pasamos a la Activity, muy similar al ListView que aprendimos antes:

OneActivity.java：

public class OneActivity extends AppCompatActivity{

    private ViewPager vpager_one;
    private ArrayList<View> aList;
    private MyPagerAdapter mAdapter;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_one);
        vpager_one = (ViewPager) findViewById(R.id.vpager_one);

        aList = new ArrayList<View>();
        LayoutInflater li = getLayoutInflater();
        aList.add(li.inflate(R.layout.view_one,null,false));
        aList.add(li.inflate(R.layout.view_two,null,false));
        aList.add(li.inflate(R.layout.view_three,null,false));
        mAdapter = new MyPagerAdapter(aList);
        vpager_one.setAdapter(mAdapter);
    }
}

public class MyPagerAdapter2 extends PagerAdapter {
    private ArrayList<View> viewLists;
    private ArrayList<String> titleLists;

    public MyPagerAdapter2() {}
    public MyPagerAdapter2(ArrayList<View> viewLists,ArrayList<String> titleLists)
    {
        this.viewLists = viewLists;
        this.titleLists = titleLists;
    }

    @Override
    public int getCount() {
        return viewLists.size();
    }

    @Override
    public boolean isViewFromObject(View view, Object object) {
        return view == object;
    }

    @Override
    public Object instantiateItem(ViewGroup container, int position) {
        container.addView(viewLists.get(position));
        return viewLists.get(position);
    }

    @Override
    public void destroyItem(ViewGroup container, int position, Object object) {
        container.removeView(viewLists.get(position));
    }

    @Override
    public CharSequence getPageTitle(int position) {
        return titleLists.get(position);
    }
}

  • all: todas las cachés de dibujo deben guardarse en memoria;
Se pueden usar dos a la vez, como animation|scrolling ~

Luego pasamos a nuestra Activity, ordenemos las ideas:

  • Step 1: Necesitamos centrar nuestro bloque deslizante debajo del primer texto, así que aquí debemos calcular el desplazamiento: Primero obtener el ancho de la imagen pw, luego obtener el ancho de la pantalla sw. El método de cálculo es muy simple:
    offset (desplazamiento) = ((sw / 3) - pw) / 2// ancho de pantalla / 3 - ancho de imagen, luego dividir entre 2, ¡los lados izquierdo y derecho!
    Luego llamamos a setImageMatrix para establecer la posición actual del deslizador:
    Al mismo tiempo, también calculamos la distancia de movimiento del deslizador para cambiar una página y dos páginas; es muy simple:
    one = offset * 2 + pw;
    two = one * 2;

  • Step 2: Cuando deslicemos la página, nuestro deslizador debe moverse. Tenemos que agregar un evento OnPageChangeListener al ViewPager. Necesitamos hacer un juicio sobre la página después del deslizamiento y registrar en qué página estábamos antes de deslizar. A continuación, dibujé un diagrama, ¡quizás sea más fácil de entender!

FourActvitiy.java：

/**
 * Created by Jay on 2015/10/8 0008.
 */
public class FourActivity extends AppCompatActivity implements View.OnClickListener,
        ViewPager.OnPageChangeListener {

    private ViewPager vpager_four;
    private ImageView img_cursor;
    private TextView tv_one;
    private TextView tv_two;
    private TextView tv_three;

    private ArrayList<View> listViews;
    private int offset = 0;//移动条图片的偏移量
    private int currIndex = 0;//当前页面的编号
    private int bmpWidth;// 移动条图片的长度
    private int one = 0; //移动条滑动一页的距离
    private int two = 0; //滑动条移动两页的距离

    @Override
    public void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_four);
        initViews();
    }


    private void initViews() {
        vpager_four = (ViewPager) findViewById(R.id.vpager_four);
        tv_one = (TextView) findViewById(R.id.tv_one);
        tv_two = (TextView) findViewById(R.id.tv_two);
        tv_three = (TextView) findViewById(R.id.tv_three);
        img_cursor = (ImageView) findViewById(R.id.img_cursor);

        //下划线动画的相关设置：
        bmpWidth = BitmapFactory.decodeResource(getResources(), R.mipmap.line).getWidth();// 获取图片宽度
        DisplayMetrics dm = new DisplayMetrics();
        getWindowManager().getDefaultDisplay().getMetrics(dm);
        int screenW = dm.widthPixels;// 获取分辨率宽度
        offset = (screenW / 3 - bmpWidth) / 2;// 计算偏移量
        Matrix matrix = new Matrix();
        matrix.postTranslate(offset, 0);
        img_cursor.setImageMatrix(matrix);// 设置动画初始位置
        //移动的距离
        one = offset * 2 + bmpWidth;// 移动一页的偏移量,比如1->2,或者2->3
        two = one * 2;// 移动两页的偏移量,比如1直接跳3


        //往ViewPager填充View，同时设置点击事件与页面切换事件
        listViews = new ArrayList<View>();
        LayoutInflater mInflater = getLayoutInflater();
        listViews.add(mInflater.inflate(R.layout.view_one, null, false));
        listViews.add(mInflater.inflate(R.layout.view_two, null, false));
        listViews.add(mInflater.inflate(R.layout.view_three, null, false));
        vpager_four.setAdapter(new MyPagerAdapter(listViews));
        vpager_four.setCurrentItem(0);          //设置ViewPager当前页，从0开始算

        tv_one.setOnClickListener(this);
        tv_two.setOnClickListener(this);
        tv_three.setOnClickListener(this);

        vpager_four.addOnPageChangeListener(this);
    }

    @Override
    public void onClick(View v) {
        switch (v.getId()) {
            case R.id.tv_one:
                vpager_four.setCurrentItem(0);
                break;
            case R.id.tv_two:
                vpager_four.setCurrentItem(1);
                break;
            case R.id.tv_three:
                vpager_four.setCurrentItem(2);
                break;
        }
    }

    @Override
    public void onPageSelected(int index) {
        Animation animation = null;
        switch (index) {
            case 0:
                if (currIndex == 1) {
                    animation = new TranslateAnimation(one, 0, 0, 0);
                } else if (currIndex == 2) {
                    animation = new TranslateAnimation(two, 0, 0, 0);
                }
                break;
            case 1:
                if (currIndex == 0) {
                    animation = new TranslateAnimation(offset, one, 0, 0);
                } else if (currIndex == 2) {
                    animation = new TranslateAnimation(two, one, 0, 0);
                }
                break;
            case 2:
                if (currIndex == 0) {
                    animation = new TranslateAnimation(offset, two, 0, 0);
                } else if (currIndex == 1) {
                    animation = new TranslateAnimation(one, two, 0, 0);
                }
                break;
        }
        currIndex = index;
        animation.setFillAfter(true);// true表示图片停在动画结束位置
        animation.setDuration(300); //设置动画时间为300毫秒
        img_cursor.startAnimation(animation);//开始动画
    }

    @Override
    public void onPageScrollStateChanged(int i) {

    }

    @Override
    public void onPageScrolled(int i, float v, int i1) {

    }
}
