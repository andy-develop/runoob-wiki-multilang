Resumen de conceptos básicos de PHP

Categoría Tecnología de programación

  • PHP significa PHP: Hypertext Preprocessor
  • Los archivos PHP pueden contener texto, HTML, código JavaScript y código PHP
  • El código PHP se ejecuta en el servidor y el resultado se devuelve al navegador en forma de HTML puro
  • La extensión de archivo predeterminada para archivos PHP es ".php"

¿Qué puede hacer PHP?

  • PHP puede generar contenido dinámico para páginas
  • PHP puede crear, abrir, leer, escribir y cerrar archivos en el servidor
  • PHP puede recopilar datos de formularios
  • PHP puede enviar y recibir cookies
  • PHP puede agregar, eliminar y modificar datos en su base de datos
  • PHP puede restringir el acceso de los usuarios a algunas páginas de su sitio web
  • PHP puede cifrar datos

Variables en PHP

Las variables comienzan con el símbolo $, seguido del nombre de la variable

PHP no tiene un comando para declarar variables.

La variable se crea cuando usted le asigna un valor por primera vez:

PHP es un lenguaje de tipado débil
PHP convierte automáticamente la variable al tipo de dato correcto según su valor.

En lenguajes de programación de tipado fuerte, debemos declarar (definir) el tipo y el nombre de la variable antes de usarla.

Ámbito de las variables en PHP

PHP tiene cuatro ámbitos diferentes para las variables:

  • local
  • global
  • static
  • parameter

Ámbito local y global

Las variables definidas fuera de todas las funciones tienen ámbito global. Excepto dentro de las funciones, las variables globales pueden ser accedidas por cualquier parte del script. Para acceder a una variable global dentro de una función, se necesita utilizar la palabra clave global.

Las variables declaradas dentro de una función en PHP son variables locales, y solo se pueden acceder dentro de la función:

<?php
$x=5; // 全局变量

function myTest()
{
    $y=10; // 局部变量
    echo "<p>测试变量在函数内部:<p>";
    echo "变量 x 为: $x";
    echo "<br>";
    echo "变量 y 为: $y";
} 

myTest();

echo "<p>测试变量在函数外部:<p>";
echo "变量 x 为: $x";
echo "<br>";
echo "变量 y 为: $y";
?>

Para acceder dentro de una función a una variable global definida fuera de la función, debemos anteponer la palabra clave global a la variable dentro de la función:

<?php
$x=5;
$y=10;

function myTest()
{
    global $x,$y;
    $y=$x+$y;
}

myTest();
echo $y; // 输出 15
?>

PHP almacena todas las variables globales en un array llamado $GLOBALS[index]. index guarda el nombre de la variable. Este array se puede acceder dentro de las funciones y también se puede usar directamente para actualizar variables globales.

<?php
$x=5;
$y=10;

function myTest()
{
    $GLOBALS['y']=$GLOBALS['x']+$GLOBALS['y'];
} 

myTest();
echo $y;
?>

Ámbito Static

Cuando una función termina, todas sus variables normalmente se eliminan. Sin embargo, a veces desea que una variable local no se elimine; puede usarstaticla palabra clave

<?php

function myTest()
{
    static $x=0;
    echo $x;
    $x++;
}

myTest();
myTest();
myTest();

?>

Ámbito de los parámetros

Los parámetros son variables locales que reciben valores desde el código que llama a la función.

Los parámetros se declaran en la lista de parámetros, como parte de la declaración de la función:

<?php

{
    echo $x;
}

myTest(5);

?>

Objetos

En PHP, los objetos deben ser declarados.

Primero, debe declarar un objeto de clase usando la palabra clave class. Una clase es una estructura que puede contener propiedades y métodos.
Luego definimos el tipo de dato en la clase y después lo usamos en la clase instanciada:

<?php
class Car
{
    var $color;
    function Car($color="green") {
      $this->color = $color;
    }
    function what_color() {
      return $this->color;
    }
}

function print_vars($obj) {
   foreach (get_object_vars($obj) as $prop => $val) {
     echo "\t$prop = $val\n";
   }
}

// instantiate one object
$herbie = new Car("white");

// show herbie properties
echo "\herbie: Properties\n";
print_vars($herbie);

?>

Constantes

Una constante es un identificador de un valor simple. Ese valor no puede cambiar durante el script. (El nombre de una constante no necesita el prefijo $).

Nota: las constantes se pueden usar en todo el script.

Para definir una constante se usa la función define(), cuya sintaxis es la siguiente:

define(string constant_name, mixed value, case_sensitive = true)
Esta función tiene tres parámetros:

  • constant_name: parámetro obligatorio, el nombre de la constante, es decir, el identificador.
  • value: parámetro obligatorio, el valor de la constante.
  • case_sensitive: parámetro opcional, especifica si distingue entre mayúsculas y minúsculas; si se establece en true, no distingue.

En el siguiente ejemplo creamos una constante que distingue entre mayúsculas y minúsculas, con el valor "Welcome to runoob.com!":

<?php
define("GREETING", "Welcome to runoob.com!");
echo GREETING;
?>

Variables mágicas

Hay ocho constantes mágicas cuyos valores cambian según su posición en el código.

  • _LINE__
    El número de línea actual del archivo.
  • FILE
    La ruta completa y el nombre del archivo. Si se usa en un archivo incluido, se devuelve el nombre del archivo incluido.
  • DIR
    El directorio donde se encuentra el archivo. Si se usa en un archivo incluido, se devuelve el directorio donde se encuentra el archivo incluido.
  • FUNCTION
    Nombre de la función (nuevo en PHP 4.3.0). Desde PHP 5, esta constante devuelve el nombre de la función tal como fue definida (distingue mayúsculas y minúsculas). En PHP 4, este valor siempre estaba en minúsculas.
<?php
function test() {
    echo  '函数名为：' . __FUNCTION__ ;
}
test();
?>
  • CLASSNombre de la clase (nuevo en PHP 4.3.0). Desde PHP 5, esta constante devuelve el nombre de la clase tal como fue definida (distingue mayúsculas y minúsculas).

En PHP 4, este valor siempre estaba en minúsculas. El nombre de la clase incluye el espacio de nombres donde fue declarada (por ejemplo, Foo\Bar). Tenga en cuenta que desde PHP 5.4CLASStambién funciona con traits. Cuando se usa en un método de un trait,CLASSes el nombre de la clase que invoca el método del trait.

<?php
class test {
    function _print() {
        echo '类名为：'  . __CLASS__ . "<br>";
        echo  '函数名为：' . __FUNCTION__ ;
    }
}
$t = new test();
$t->_print();
?>
  • TRAITNombre del trait (nuevo en PHP 5.4.0). Desde PHP 5.4.0, PHP implementó un método de reutilización de código llamado traits.

El nombre del trait incluye el espacio de nombres donde fue declarado (por ejemplo, Foo\Bar).

Los miembros heredados de la clase base son reemplazados por el método MyHelloWorld del trait SayWorld insertado. Su comportamiento es el mismo que el método definido en la clase MyHelloWorld. El orden de prioridad es que los métodos de la clase actual reemplazan a los métodos del trait, y los métodos del trait reemplazan a los métodos de la clase base.

<?php
class Base {
    public function sayHello() {
        echo 'Hello ';
    }
}

trait SayWorld {
    public function sayHello() {
        parent::sayHello();
        echo 'World!';
    }
}

class MyHelloWorld extends Base {
    use SayWorld;
}

$o = new MyHelloWorld();
$o->sayHello();
?>
  • METHODNombre del método de la clase (nuevo en PHP 5.0.0). Devuelve el nombre del método tal como fue definido (distingue mayúsculas y minúsculas).
<?php
function test() {
    echo  '函数名为：' . __METHOD__ ;
}
test();
?>
  • NAMESPACENombre del espacio de nombres actual (distingue mayúsculas y minúsculas). Esta constante se define en tiempo de compilación (nuevo en PHP 5.3.0).
<?php
namespace MyProject;

echo '命名空间为："', __NAMESPACE__, '"'; // 输出 "MyProject"
?>

Espacios de nombres

Los espacios de nombres (namespace) en PHP se introdujeron en PHP 5.3. Si has aprendido C# y Java, los espacios de nombres no son nada nuevo. Sin embargo, en PHP tienen una importancia bastante significativa.

Los espacios de nombres en PHP pueden resolver los siguientes dos tipos de problemas:

  • Conflictos de nombres entre el código del usuario y las clases/funciones/constantes internas de PHP.
  • Crear nombres con alias (o más cortos) para mejorar la legibilidad del código fuente.

De forma predeterminada, todos los nombres de constantes, clases y funciones se colocan en el espacio global, igual que antes de que PHP admitiera espacios de nombres.
Si un archivo contiene un espacio de nombres, debe declarar el espacio de nombres antes que cualquier otro código.

< ?php  
// 定义代码在 'MyProject' 命名空间中  
namespace MyProject;  
 
// ... 代码 ...  

//也可以在同一个文件中定义不同的命名空间代码
namespace MyProject1;  
// MyProject1 命名空间中的PHP代码  
 
namespace MyProject2;  
// MyProject2 命名空间中的PHP代码    
 
// 另一种语法
namespace MyProject3 {  
 // MyProject3 命名空间中的PHP代码    
}  

?>

El único código legal antes de declarar un espacio de nombres es la sentencia declare utilizada para definir la codificación del archivo fuente. Ningún código que no sea PHP, incluidos los espacios en blanco, puede aparecer antes de la declaración del espacio de nombres.

<?php
declare(encoding='UTF-8'); //定义多个命名空间和不包含在命名空间中的代码
namespace MyProject {
    const CONNECT_OK = 1;
    class Connection { /* ... */ }
    function connect() { /* ... */  }
}

namespace { // 全局代码
    session_start();
    $a = MyProject\connect();
    echo MyProject\Connection::start();
}
?>

Uso de espacios de nombres
Los nombres de clase en los espacios de nombres de PHP se pueden referenciar de tres formas:

  1. Nombre no calificado, o nombre de clase sin prefijo, por ejemplo $a=new foo(); o foo::staticmethod();. Si el espacio de nombres actual es currentnamespace, foo se resolverá como currentnamespace\foo. Si el código que usa foo es global, es decir, código que no está en ningún espacio de nombres, foo se resolverá como foo. Advertencia: si una función o constante en el espacio de nombres no está definida, el nombre de función o constante no calificado se resolverá como el nombre de función o constante global.~~Referencia sin prefijo de espacio de nombres: por defecto busca en el espacio de nombres actual y luego en el espacio de nombres global.

  2. Nombre calificado, o nombre con prefijo, por ejemplo $a = new subnamespace\foo(); o subnamespace\foo::staticmethod();. Si el espacio de nombres actual es currentnamespace, foo se resolverá como currentnamespace\subnamespace\foo. Si el código que usa foo es global, es decir, código que no está en ningún espacio de nombres, foo se resolverá como subnamespace\foo.~~Referencia con prefijo de espacio de nombres relativo (similar a una ruta relativa), agrega automáticamente al inicio el espacio de nombres donde se encuentra el código que realiza la llamada.

  3. Nombre totalmente calificado, o nombre que incluye el operador de prefijo global, por ejemplo, $a = new \currentnamespace\foo(); o \currentnamespace\foo::staticmethod();. En este caso, foo siempre se resuelve como el nombre literal (literal name) del código: currentnamespace\foo.~~Referencia con prefijo de espacio de nombres absoluto (similar a una ruta absoluta). La ruta de referencia ya está definida, no necesita búsqueda.

La palabra clave namespace se puede utilizar para acceder explícitamente a elementos del espacio de nombres actual o de un subespacio de nombres. Es equivalente al operador self en las clases.

<?php

Usar espacios de nombres: funciones/constantes globales de respaldo

Dentro de un espacio de nombres, cuando PHP encuentra un nombre de clase, función o constante no calificado, utiliza diferentes estrategias de prioridad para resolver dicho nombre.

  • Los nombres de clase siempre se resuelven al nombre en el espacio de nombres actual (si no se encuentra, se produce un error).Por lo tanto, al acceder a nombres de clase internos del sistema o que no están en un espacio de nombres, se debe utilizar el nombre totalmente calificado.
  • En cuanto a funciones y constantes, si la función o constante no existe en el espacio de nombres actual, PHP recurre a la función o constante del espacio global.
<?php
namespace A\B\C;
class Exception extends \Exception {}

$a = new Exception('hi'); // $a 是类 A\B\C\Exception 的一个对象
$b = new \Exception('hi'); // $b 是类 Exception 的一个对象

$c = new ArrayObject; // 致命错误, 找不到 A\B\C\ArrayObject 类
?>

Espacio global
Si no se define ningún espacio de nombres, todas las definiciones de clases y funciones se encuentran en el espacio global, igual que antes de que PHP introdujera el concepto de espacios de nombres. Anteponer el prefijo \ a un nombre indica que dicho nombre pertenece al espacio global, incluso si ese nombre se encuentra en otro espacio de nombres.

<?php
namespace A\B\C;

/* 这个函数是 A\B\C\fopen */
function fopen() { 
     /* ... */
     $f = \fopen(...); // 调用全局的fopen函数
     return $f;
} 
?>

Manejo de archivos en PHP

Abrir archivos

$file = fopen($fname, mode) //Nombre del archivo, modo de apertura

  • r Solo lectura. Comienza al inicio del archivo.
  • r+ Lectura/escritura. Comienza al inicio del archivo.
  • w Solo escritura. Abre y vacía el contenido del archivo; si el archivo no existe, crea un archivo nuevo.
  • w+ Lectura/escritura. Abre y vacía el contenido del archivo; si el archivo no existe, crea un archivo nuevo.
  • a Añadir (append). Abre y escribe al final del archivo; si el archivo no existe, crea un archivo nuevo.
  • a+ Lectura/adicional. Mantiene el contenido del archivo escribiendo al final del mismo.
  • x Solo escritura. Crea un archivo nuevo. Si el archivo ya existe, devuelve FALSE y un error.
  • x+ Lectura/escritura. Crea un archivo nuevo. Si el archivo ya existe, devuelve FALSE y un error.

Nota: si la función fopen() no puede abrir el archivo especificado, devuelve 0 (false).

Parámetros

mixed json_decode ($json [,$assoc = false [, $depth = 512 [, $options = 0 ]]])
Parámetros

json_string: La cadena JSON a decodificar, debe ser datos codificados en UTF-8.

assoc: Cuando este parámetro es TRUE, se devuelve una matriz; cuando es FALSE, se devuelve un objeto.

depth: Parámetro de tipo entero que especifica la profundidad de recursión.

options: Máscara binaria, actualmente solo compatible con JSON_BIGINT_AS_STRING.
