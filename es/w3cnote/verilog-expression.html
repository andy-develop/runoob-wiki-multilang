2.4 Expresiones de Verilog

Clasificación Tutorial de Verilog

Expresión

Una expresión está compuesta por operadores y operandos, y su objetivo es obtener un resultado de cálculo según el significado de los operadores. Las expresiones se pueden usar en cualquier lugar donde aparezcan valores numéricos. Por ejemplo:

Ejemplo

a^b ;          // operación XOR entre a y b
address[9:0] + 10'b1 ;  // acumulación de dirección
flag1 && flag2 ;  // operación AND lógica

Operandos

Los operandos pueden ser de cualquier tipo de datos, solo que ciertas estructuras sintácticas específicas requieren el uso de un tipo de operando concreto.

Los operandos pueden ser constantes, enteros, reales, redes (nets), registros, tiempos, selección de bits, selección de campos, memorias, llamadas a funciones, etc.

Ejemplo

module test;

// real
real a, b, c;
c = a + b ;

// registro
reg  [3:0]       cprmu_1, cprmu_2 ;
always @(posedge clk) begin
        cprmu_2 = cprmu_1 ^ cprmu_2 ;
end
         
// función
reg  flag1 ;
flag = calculate_result(A, B);
 
// operando ilegal
reg [3:0]         res;
wire [3:0]        temp;
always@ （*）begin
    res    = cprmu_2 – cprmu_1 ;
    //temp = cprmu_2 – cprmu_1 ; // no válido, el objeto de asignación en un bloque always no puede ser de tipo wire
end

endmodule

Operadores

Verilog proporciona alrededor de 9 tipos de operadores: aritméticos, relacionales, de igualdad, lógicos, bit a bit, de reducción, de desplazamiento, de concatenación y condicionales.

La mayoría de los operadores son similares a los del lenguaje C. Entre operadores del mismo tipo, excepto el operador condicional que se asocia de derecha a izquierda, el resto se asocia de izquierda a derecha. Las expresiones entre paréntesis se ejecutan primero. Por ejemplo, las dos formas de escritura de cada grupo siguiente son equivalentes.

//自右向左关联，两种写法等价
A+B-C ;
(A+B）-C ;

//自右向左关联，两种写法等价，结果为 B、D 或 F
A ? B : C ? D : F ;
A ? B : (C ? D : F) ;

//自右向左关联，两种写法不等价
(A ? B : C) ? D : F ;  //结果 D 或 F
A ? B : C ? D : F ; //结果为 B、D 或 F

Entre operadores distintos, la precedencia es diferente. La siguiente tabla enumera el orden de precedencia de los operadores de mayor a menor. Cuando no hay paréntesis, Verilog evalúa las expresiones según la precedencia de los operadores. Para evitar confusiones de cálculo debidas a la precedencia, cuando no esté seguro de la precedencia, se recomienda usar paréntesis para distinguir las expresiones.

Operadores aritméticos

Los operadores aritméticos incluyen operadores unarios y operadores binarios.

Los operadores binarios realizan operaciones aritméticas sobre 2 operandos, incluyendo multiplicación (*), división (/), suma (+), resta (-), potencia (**) y módulo (%).

Ejemplo

reg [3:0]  a, b;
reg [4:0]  c ;
a = 4'b0010; // el valor de a es 2
b = 4'b1001; // el valor de b es 9
c = a+b;     // el resultado es c=b'b1011
c = b/a;     // el resultado es c=4, truncado

Si algún bit de un operando es X, el resultado del cálculo también será todo X. Por ejemplo:

Ejemplo

b = 4'b100x ;
c = a+b ;       // el resultado es c=4'bxxxx

Al declarar variables, se debe declarar razonablemente el ancho de bits de la variable según los operadores involucrados, para no provocar desbordamiento del resultado. En el ejemplo anterior, los 2 operandos que se suman tienen un ancho de 4 bits, por lo que el ancho de bits de la variable de resultado (registro) debe ser al menos de 5 bits. De lo contrario, los bits altos se truncarán y se perderán. En la multiplicación de números sin signo, el ancho de bits de la variable de resultado debe ser la suma de los anchos de bits de los 2 operandos.

Ejemplo

reg [3:0]        mula ;
reg [1:0]        mulb;
reg [5:0]        res ;
mula = 4'he   ;
mulb = 2'h3   ;
res  = mula * mulb ; // el resultado es res=6'h2a, el resultado de datos no pierde bits

+ y - también se pueden usar como operadores unarios, indicando el signo positivo o negativo del operando. Este tipo de operadores tiene la precedencia más alta.

-4  //表示负4
+3  //表示正3

Para representar números negativos, se puede añadir directamente un signo menos delante del número decimal-, o se puede especificar el ancho de bits. Debido a que los números negativos se representan en complemento a dos, si no se especifica el ancho de bits para representar un número negativo, el compilador asignará automáticamente el ancho de bits durante la conversión, lo que puede producir resultados inesperados. Por ejemplo:

Ejemplo

mula = -4'd4 ;
mulb = 2 ;
res = mula * mulb ;      // el resultado es res=-6'd8, es decir, res=6'h38, normal
res = mula * (-'d4) ;    // (4 elevado a 32 - 4) * 2, resultado anormal

Operadores relacionales

Los operadores relacionales son mayor que (>), menor que (<), mayor o igual que (>=), menor o igual que (<=).

Los resultados normales de los operadores relacionales son 2: verdadero (1) o falso (0).

Si algún bit de los operandos es x o z, el resultado de la expresión relacional es x.

Ejemplo

A = 4 ;
B = 3 ;
X = 3'b1xx ;
   
A > B     // verdadero
A <= B    // falso
A >= Z    // es X, indeterminado

Operadores de igualdad

Los operadores de igualdad incluyen igualdad lógica (==), desigualdad lógica (!=), identidad (===) y no identidad (!==).

Los resultados normales de los operadores de igualdad son 2: verdadero (1) o falso (0).

Los operadores de igualdad/desigualdad lógica no pueden comparar x o z; cuando un operando contiene un x o z, el resultado es un valor indeterminado.

En la comparación de identidad, si la comparación bit a bit tiene los mismos x o z, el resultado devuelto también puede ser 1, es decir, la comparación de identidad puede comparar x o z. Por lo tanto, el resultado de la comparación de identidad nunca contiene x. Ejemplos:

Ejemplo

A = 4 ;
B = 8'h04 ;
C = 4'bxxxx ;
D = 4'hx ;
A == B        // verdadero
A == (B + 1)  // falso
A == C        // es X, indeterminado
A === C       // falso, valor de retorno 0
C === D       // verdadero, valor de retorno 1

Operadores lógicos

Los operadores lógicos principales son 3: && (AND lógico), || (OR lógico), ! (NOT lógico).

El resultado del cálculo de los operadores lógicos es un valor de 1 bit; 0 representa falso, 1 verdadero, y x indeterminado.

Si un operando no es 0, equivale a lógico 1; si un operando es 0, equivale a lógico 0. Si cualquier bit de él es x o z, equivale a x.

Si cualquier operando contiene x, el resultado de la operación lógica no es necesariamente x.

Los operandos de los operadores lógicos pueden ser variables o expresiones. Por ejemplo:

Ejemplo

A = 3;
B = 0;
C = 2'b1x ;
   
A && B    // falso
A || B    // verdadero
! A       // falso
! B       // verdadero
A && C    // es X, indeterminado
A || C    // verdadero, porque A es verdadero
(A==2) && (! B)  // verdadero, en este caso el primer operando es una expresión

Operadores bit a bit

Los operadores bit a bit incluyen: negación (~), AND (&), OR (|), XOR (^), XNOR (~^).

Los operadores bit a bit operan sobre cada bit de los 2 operandos.

Si los dos operandos no tienen el mismo ancho de bits, se rellena el operando más corto con ceros a la izquierda.

El operador de negación tiene un solo operando y realiza la negación de cada bit del operando.

La siguiente figura muestra las reglas lógicas de los operadores bit a bit.

& (AND)01x |(OR)01x
0000 001x
101x 1111
x0xx xx1x
^ (XOR)01x ~^ (XNOR)01x
001x 010x
110x 101x
xxxx xxxx

Ejemplo

A = 4'b0101 ;
B = 4'b1001 ;
C = 4'bx010 ;
   
~A        //4'b1010
A & B     //4'b0001
A | B     //4'b1101
A^B       //4'b1100
A ~^ B    //4'b0011
B | C     //4'b1011
B&C       //4'bx000

Operadores de reducción

Los operadores de reducción incluyen: reducción AND (&), reducción NAND (~&), reducción OR (|), reducción NOR (~|), reducción XOR (^), reducción XNOR (~^).

Los operadores de reducción tienen un solo operando; operan bit a bit sobre ese operando vectorial y producen un resultado de 1 bit.

Los operadores lógicos, bit a bit y de reducción usan los mismos símbolos, por lo que a veces son fáciles de confundir. La clave para distinguirlos es identificar el número de operandos y la regla del resultado.

A = 4'b1010 ;
&A ;      //结果为 1 & 0 & 1 & 0 = 1'b0，可用来判断变量A是否全1
~|A ;     //结果为 ~(1 | 0 | 1 | 0) = 1'b0, 可用来判断变量A是否为全0
^A ;      //结果为 1 ^ 0 ^ 1 ^ 0 = 1'b0

Operadores de desplazamiento

Los operadores de desplazamiento incluyen: desplazamiento a la izquierda (<<), desplazamiento a la derecha (>>), desplazamiento aritmético a la izquierda (<<<) y desplazamiento aritmético a la derecha (>>>).

Los operadores de desplazamiento son operadores binarios; los dos operandos representan respectivamente la señal vectorial a desplazar (lado izquierdo del operador) y el número de posiciones a desplazar (lado derecho del operador).

En el desplazamiento aritmético a la izquierda y en el desplazamiento lógico a la izquierda, los bits bajos de la derecha se rellenan con 0.

En el desplazamiento lógico a la derecha, los bits altos de la izquierda se rellenan con 0; mientras que en el desplazamiento aritmético a la derecha, los bits altos de la izquierda se rellenan con el bit de signo, para garantizar la corrección del valor al reducir los datos.

Ejemplo

A = 4'b1100 ;
B = 4'b0010 ;
A = A >> 2 ;        // el resultado es 4'b0011
A = A << 1;         // el resultado es 4'b1000
A = A <<< 1 ;       // el resultado es 4'b1000
C = B + (A>>>2);    // el resultado es 2 + (-4/4) = 1, 4'b0001

Operador de concatenación

El operador de concatenación se representa con llaves{，}para concatenar múltiples operandos (vectores) en un nuevo operando (vector); las señales se separan con comas.

Los operandos del operador de concatenación deben especificar el ancho de bits; incluso las constantes también deben especificar el ancho de bits. Por ejemplo:

Ejemplo

A = 4'b1010 ;
B = 1'b1 ;
Y1 = {B, A[3:2], A[0], 4'h3 };  //El resultado es Y1='b1100_0011
Y2 = {4{B}, 3'd4};  //El resultado es Y2=7'b111_1100
Y3 = {32{1'b0}};  //El resultado es Y3=32h0, comúnmente utilizado para asignar el valor inicial que coincide con el ancho de bits en la inicialización de registros

Operador condicional

La expresión condicional tiene 3 operandos, y su estructura se describe de la siguiente manera:

condition_expression ? true_expression : false_expression

Al evaluar, si condition_expression es verdadero (valor lógico 1), el resultado de la operación es true_expression; si condition_expression es falso (valor lógico 0), el resultado es false_expression.

assign hsel    = (addr[9:8] == 2'b0) ? hsel_p1 : hsel_p2 ;
//当信号 addr 高 2bit 为 0 时，hsel 赋值为 hsel_p1; 否则，将 hsel_p2 赋值给 hsel。

En realidad, la expresión condicional es similar a un selector de 2 vías (o múltiples vías), y su forma de descripción puede reemplazarse completamente con sentencias if-else.

Por supuesto, el operador condicional también puede anidarse para implementar una lógica de selección múltiple. Por ejemplo:

Ejemplo

assign   hsel = (addr[9:8] == 2'b00) ? hsel_p1 :
                (addr[9:8] == 2'b01) ? hsel_p2 :
                (addr[9:8] == 2'b10) ? hsel_p3 :
                (addr[9:8] == 2'b11) ? hsel_p4 ;
