1.1 Ordenamiento de burbuja

Categoría Algoritmo

El ordenamiento de burbuja (Bubble Sort) es un algoritmo de ordenamiento simple que ordena recorriendo repetidamente la lista a ordenar, comparando elementos adyacentes e intercambiando sus posiciones. El nombre del algoritmo proviene de que los elementos más pequeños "flotan" gradualmente hacia la parte superior de la lista como "burbujas".

1. Pasos del algoritmo

  1. Comparar elementos adyacentes: Comience desde el primer elemento de la lista y compare los dos elementos adyacentes.

  2. Intercambiar posiciones: Si el elemento anterior es mayor que el siguiente, intercambie sus posiciones.

  3. Repetir el recorrido: Repita los pasos anteriores para cada par de elementos adyacentes de la lista hasta llegar al final de la lista. De esta manera, el elemento más grande "burbujeará" hasta el final de la lista.

  4. Reducir el rango: Ignore el último elemento ya ordenado y repita los pasos anteriores hasta que toda la lista esté ordenada.

2. Demostración animada

Supongamos que hay una lista a ordenar [5, 3, 8, 4, 6], el proceso del ordenamiento de burbuja es el siguiente:

  1. Primera pasada：

    • Compare 5 y 3, intercambie posiciones, la lista se convierte en[3, 5, 8, 4, 6]。

    • Compare 5 y 8, no hay intercambio.

    • Compare 8 y 4, intercambie posiciones, la lista se convierte en[3, 5, 4, 8, 6]。

    • Compare 8 y 6, intercambie posiciones, la lista se convierte en[3, 5, 4, 6, 8]。

    • Después de la primera pasada, el elemento más grande, 8, ya ha "burbujeado" hasta el final de la lista.

  2. Segunda pasada：

    • Compare 3 y 5, no hay intercambio.

    • Compare 5 y 4, intercambie posiciones, la lista se convierte en[3, 4, 5, 6, 8]。

    • Compare 5 y 6, no hay intercambio.

    • Después de la segunda pasada, el segundo elemento más grande, 6, ya ha "burbujeado" hasta la penúltima posición de la lista.

  3. Tercera pasada：

    • Compare 3 y 4, no hay intercambio.

    • Compare 4 y 5, no hay intercambio.

    • Después de la tercera pasada, la lista ya está ordenada.

  4. Cuarta pasada：

    • Compare 3 y 4, no hay intercambio.

    • La lista ya está completamente ordenada.

Ejemplo

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        # Marcar si se ha producido un intercambio
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                # Intercambiar posiciones
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        # Si no se ha producido ningún intercambio, significa que la lista ya está ordenada y se sale antes
        if not swapped:
            break
    return arr

# Ejemplo
arr = [5, 3, 8, 4, 6]
sorted_arr = bubble_sort(arr)
print(sorted_arr)  # Salida: [3, 4, 5, 6, 8]

3. Complejidad temporal

  • Peor caso: O(n²), cuando la lista está en orden inverso.

  • Mejor caso: O(n), cuando la lista ya está ordenada.

  • Caso promedio：O(n²)。

4. Complejidad espacial

  • O(1), porque el ordenamiento de burbuja es un algoritmo de ordenamiento in situ y no necesita espacio de almacenamiento adicional.

5. Ventajas y desventajas

  • Ventajas：

    • Implementación simple, código fácil de entender.

    • Ordenamiento in situ, no requiere espacio de almacenamiento adicional.

  • Desventajas：

    • Baja eficiencia, especialmente para conjuntos de datos a gran escala.

    • No es adecuado para listas casi ordenadas, porque todavía requiere múltiples recorridos.

6. Cuándo es más rápido

Cuando los datos de entrada ya están en orden ascendente (si ya están en orden ascendente, ¿para qué necesito tu ordenamiento de burbuja?).

7. Cuándo es más lento

Cuando los datos de entrada están en orden inverso (¿no bastaría con escribir un bucle for para generar los datos en orden inverso? ¿Por qué usar tu ordenamiento de burbuja? ¿Acaso no tengo nada mejor que hacer?).

8. Implementación en JavaScript

Ejemplo

function bubbleSort(arr) {
    var len = arr.length;
    for (var i = 0; i < len - 1; i++) {
        for (var j = 0; j < len - 1 - i; j++) {
            if (arr[j] > arr[j+1]) {        // Comparar elementos adyacentes por pares
                var temp = arr[j+1];        // Intercambio de elementos
                arr[j+1] = arr[j];
                arr[j] = temp;
            }
        }
    }
    return arr;
}

static void BubbleSort(int[] intArray) {
    int temp = 0;
    bool swapped;
    for (int i = 0; i < intArray.Length; i++)
    {
        swapped = false;
        for (int j = 0; j < intArray.Length - 1 - i; j++)
            if (intArray[j] > intArray[j + 1])
            {
                temp = intArray[j];
                intArray[j] = intArray[j + 1];
                intArray[j + 1] = temp;
                if (!swapped)
                    swapped = true;
            }
        if (!swapped)
            return;
    }
}

    Ordenamiento de burbuja mejorado

    • Después de la primera pasada del ordenamiento de burbuja, el valor máximo se coloca en el extremo derecho; este valor máximo también es el máximo global.
    • El ordenamiento de burbuja estándar compara todos los elementos en cada pasada, aunque el valor más a la derecha ya sea el máximo.
    • Con la mejora, después de cada pasada, el valor máximo, el segundo máximo, etc., quedan fijos en el lado derecho, evitando comparaciones repetidas.

    Implementación en Python:

    def bubbleSort(arr):
    for i in range(len(arr) - 1, 0, -1):  # 反向遍历
        for j in range(0, i):  # 由于最右侧的值已经有序，不再比较，每次都减少遍历次数
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

    Implementación en Go:

}
