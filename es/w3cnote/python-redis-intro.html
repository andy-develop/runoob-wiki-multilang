连接池 -> Grupo de conexiones

redis-py 使用 connection pool 来管理对一个 redis server 的所有连接，避免每次建立、释放连接的开销。 -> redis-py utiliza un connection pool para gestionar todas las conexiones a un servidor redis, evitando la sobrecarga de establecer y liberar conexiones cada vez.

默认，每个Redis实例都会维护一个自己的连接池。可以直接建立一个连接池，然后作为参数 Redis，这样就可以实现多个 Redis 实例共享一个连接池。 -> Por defecto, cada instancia de Redis mantiene su propio grupo de conexiones. Se puede crear un grupo de conexiones directamente y luego pasarlo como parámetro a Redis, logrando así que múltiples instancias de Redis compartan un mismo grupo de conexiones.

实例 -> Ejemplo

import redis    # 导入redis 模块 -> # Importar el módulo redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(host='localhost', port=6379, decode_responses=True)  
r.set('name', 'runoob')  # 设置 name 对应的值 -> # Establecer el valor correspondiente a 'name'
print(r.get('name'))  # 取出键 name 对应的值 -> # Obtener el valor correspondiente a la clave 'name'

redis 基本命令 String -> Comandos básicos de redis: String

set(name, value, ex=None, px=None, nx=False, xx=False)

在 Redis 中设置值，默认，不存在则创建，存在则修改。 -> Al establecer un valor en Redis, por defecto, si no existe se crea; si existe, se modifica.

参数： -> Parámetros:

  • ex - 过期时间（秒） -> ex - tiempo de expiración (segundos)
  • px - 过期时间（毫秒） -> px - tiempo de expiración (milisegundos)
  • nx - 如果设置为True，则只有name不存在时，当前set操作才执行 -> nx - si se establece como True, la operación set solo se ejecuta cuando 'name' no existe
  • xx - 如果设置为True，则只有name存在时，当前set操作才执行 -> xx - si se establece como True, la operación set solo se ejecuta cuando 'name' existe

1.ex - 过期时间（秒） 这里过期时间是3秒，3秒后p，键food的值就变成None -> 1. ex - tiempo de expiración (segundos). Aquí el tiempo de expiración es 3 segundos; después de 3 segundos, el valor de la clave 'food' se convierte en None.

实例 -> Ejemplo

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
r.set('food', 'mutton', ex=3)    # key是"food" value是"mutton" 将键值对存入redis缓存 -> # La clave es 'food' y el valor es 'mutton'; almacenar el par clave-valor en la caché de redis
print(r.get('food'))  # mutton 取出键food对应的值 -> # 'mutton' - obtener el valor correspondiente a la clave 'food'

2.px - 过期时间（豪秒） 这里过期时间是3豪秒，3毫秒后，键foo的值就变成None -> 2. px - tiempo de expiración (milisegundos). Aquí el tiempo de expiración es 3 milisegundos; después de 3 milisegundos, el valor de la clave 'foo' se convierte en None.

实例 -> Ejemplo

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
r.set('food', 'beef', px=3)
print(r.get('food'))

3.nx - 如果设置为True，则只有name不存在时，当前set操作才执行 （新建） -> 3. nx - si se establece como True, la operación set solo se ejecuta cuando 'name' no existe (crear nuevo)

实例 -> Ejemplo

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
print(r.set('fruit', 'watermelon', nx=True))    # True--不存在 -> # True -- no existe
# 如果键fruit不存在，那么输出是True；如果键fruit已经存在，输出是None -> # Si la clave 'fruit' no existe, la salida es True; si la clave 'fruit' ya existe, la salida es None

4.xx - 如果设置为True，则只有name存在时，当前set操作才执行 （修改） -> 4. xx - si se establece como True, la operación set solo se ejecuta cuando 'name' existe (modificar)

实例 -> Ejemplo

print((r.set('fruit', 'watermelon', xx=True)))   # True--已经存在 -> # True -- ya existe
# 如果键fruit已经存在，那么输出是True；如果键fruit不存在，输出是None -> # Si la clave 'fruit' ya existe, la salida es True; si la clave 'fruit' no existe, la salida es None

如： "君惜大大" ，0-3表示 "君" -> Por ejemplo: "君惜大大", 0-3 representa "君"

实例 -> Ejemplo

r.set("cn_name", "君惜大大" -> "君惜大大") # 汉字 -> # Caracteres chinos

13.setbit(name, offset, value)

Operar sobre los bits de la representación binaria del valor correspondiente a name

Parámetros:

  • name - El name de redis
  • offset - Índice del bit (indexar después de convertir el valor a binario)
  • value - El valor solo puede ser 1 o 0

Nota: Si en Redis hay una correspondencia: n1 = "foo",

entonces la representación binaria de la cadena foo es: 01100110 01101111 01101111

Por lo tanto, si se ejecuta setbit('n1', 7, 1), el séptimo bit se establecerá en 1,

entonces el binario final se convierte en 01100111 01101111 01101111, es decir: "goo"

Extensión, conversión de representación binaria:

实例 -> Ejemplo

source = "陈思维"
source = "foo"
for i in source:
num = ord(i)
print bin(num).replace('b','')

Especialmente, ¿qué pasa si source es el carácter chino "陈思维"?

Respuesta: Para utf-8, cada carácter chino ocupa 3 bytes, entonces "陈思维" tiene 9 bytes. Para caracteres chinos, el bucle for itera por bytes. Al iterar, convertir cada byte a número decimal, y luego el número decimal a binario. 11100110 10101101 10100110 11100110 10110010 10011011 11101001 10111101 10010000

18.incr(self, name, amount=1)

Incrementa el valor correspondiente a name; si name no existe, se crea name=amount; de lo contrario, se incrementa.

Parámetros:

  • name - El name de Redis
  • amount - Número de incremento (debe ser un entero)

Nota: igual que incrby

实例 -> Ejemplo

r.set("foo", 123)
print(r.mget("foo", "foo1", "foo2", "k1", "k2"))
r.incr("foo", amount=1)
print(r.mget("foo", "foo1", "foo2", "k1", "k2"))

应用场景 – 页面点击数 -> Escenario de aplicación: contador de clics de página

Supongamos que necesitamos registrar el número de clics para una serie de páginas. Por ejemplo, cada publicación de un foro debe registrar el número de clics, y el número de clics es mucho mayor que el número de respuestas. Si se utiliza una base de datos relacional para almacenar los clics, puede haber mucha contención de bloqueos a nivel de fila. Por lo tanto, usar el comando INCR de redis para incrementar el contador de clics es lo mejor.

Cuando el servidor redis se inicia, se puede leer el valor inicial del contador de clics desde la base de datos relacional (la página 12306 fue visitada 34634 veces)

r.set("visit:12306:totals", 34634)
print(r.get("visit:12306:totals"))

Cada vez que hay un clic en una página, basta con usar INCR para incrementar el contador de clics.

r.incr("visit:12306:totals")
r.incr("visit:12306:totals")

Al cargar la página, se puede obtener este valor directamente.

print(r.get("visit:12306:totals"))

hset(name, key, value)

Establecer un par clave-valor en el hash correspondiente a name (si no existe, se crea; de lo contrario, se modifica)

Parámetros:

  • name - El name de redis
  • key - La key en el hash correspondiente a name
  • value - El value en el hash correspondiente a name

Nota: hsetnx(name, key, value) crea la key si no existe actualmente en el hash correspondiente a name (equivalente a agregar)

实例 -> Ejemplo

import redis
import time

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)

r.hset("hash1", "k1", "v1")
r.hset("hash1", "k2", "v2")
print(r.hkeys("hash1")) # Obtener todas las keys del hash
print(r.hget("hash1", "k1"))    # Obtener individualmente el value correspondiente a la key del hash
print(r.hmget("hash1", "k1", "k2")) # Obtener múltiples values correspondientes a keys del hash
r.hsetnx("hash1", "k2", "v3") # Solo se puede crear nuevo
print(r.hget("hash1", "k2"))

Obtener los values de múltiples keys en el hash correspondiente a name

Parámetros:

14. Iteración incremental personalizada

Debido a que la biblioteca de redis no proporciona iteración incremental para los elementos de una lista, si se quieren recorrer todos los elementos de la lista correspondiente a name, entonces es necesario obtener todas las listas correspondientes a name.

Recorrer la lista

Pero si la lista es muy grande, es posible que en el primer paso se desborde el contenido del programa, por lo que es necesario personalizar una función de iteración incremental:

实例 -> Ejemplo

def list_iter(name):
    """
Iteración incremental personalizada para listas de redis
:param name: el name en redis, es decir: iterar la lista correspondiente a name
:return: yield devuelve elementos de la lista
    """
    list_count = r.llen(name)
    for index in range(list_count):
        yield r.lindex(name, index)

# Uso
for item in list_iter('list2'): # Recorre esta lista
    print(item)

7、redis基本命令 有序set -> 7. Comandos básicos de redis: set ordenado

Set操作，Set集合就是不允许重复的列表，本身是无序的。 Operaciones de Set. Un conjunto Set es una lista que no permite duplicados y, en sí mismo, no está ordenado.

有序集合，在集合的基础上，为每元素排序；元素的排序需要根据另外一个值来进行比较，所以，对于有序集合，每一个元素有两个值，即：值和分数，分数专门用来做排序。 Un conjunto ordenado, sobre la base del conjunto, ordena cada elemento; la clasificación de los elementos requiere comparar según otro valor, por lo que, para un conjunto ordenado, cada elemento tiene dos valores: valor y puntuación; la puntuación se utiliza específicamente para ordenar.

1.新增 1. Agregar

3.获取有序集合的所有元素 3. Obtener todos los elementos del conjunto ordenado

r.zrange( name, start, end, desc=False, withscores=False, score_cast_func=float)

按照索引范围获取name对应的有序集合的元素 Obtener los elementos del conjunto ordenado correspondiente a name según un rango de índices.

参数： Parámetros:

  • name - redis的name name - el name de redis
  • start - 有序集合索引起始位置（非分数） start - posición inicial del índice del conjunto ordenado (no puntuación)
  • end - 有序集合索引结束位置（非分数） end - posición final del índice del conjunto ordenado (no puntuación)
  • desc - 排序规则，默认按照分数从小到大排序 desc - regla de ordenación; por defecto se ordena por puntuación de menor a mayor

管道（pipeline） -> Tubería (pipeline)

redis默认在执行每次请求都会创建（连接池申请连接）和断开（归还连接池）一次连接操作，如果想要在一次请求中指定多个命令，则可以使用pipline实现一次请求指定多个命令，并且默认情况下一次pipline 是原子性操作。 De forma predeterminada, redis crea y cierra una conexión (solicita conexión del grupo de conexiones y la devuelve al grupo) en cada solicitud. Si se desea especificar múltiples comandos en una sola solicitud, se puede usar pipeline para lograrlo, y de forma predeterminada un pipeline es una operación atómica.

管道（pipeline）是redis在提供单个请求中缓冲多条服务器命令的基类的子类。它通过减少服务器-客户端之间反复的TCP数据库包，从而大大提高了执行批量命令的功能。 Pipeline es una subclase de la clase base que redis proporciona para almacenar en búfer múltiples comandos de servidor en una sola solicitud. Al reducir los paquetes TCP repetidos entre el servidor y el cliente, mejora enormemente la ejecución de comandos en lote.

实例 -> Ejemplo

import redis
import time

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)

# pipe = r.pipeline(transaction=False) # 默认的情况下，管道里执行的命令可以保证执行的原子性，执行pipe = r.pipeline(transaction=False)可以禁用这一特性。 # pipe = r.pipeline(transaction=False) # De forma predeterminada, los comandos ejecutados en el pipeline pueden garantizar la atomicidad; ejecutar pipe = r.pipeline(transaction=False) puede deshabilitar esta característica.
# pipe = r.pipeline(transaction=True)
pipe = r.pipeline() # 创建一个管道 # Crear un pipeline

pipe.set('name', 'jack')
pipe.set('role', 'sb')
pipe.sadd('faz', 'baz')
pipe.incr('num')    # 如果num不存在则vaule为1，如果存在，则value自增1 # Si num no existe, value es 1; si existe, value se incrementa en 1.
pipe.execute()

print(r.get("name"))
print(r.get("role"))
print(r.get("num"))

管道的命令可以写在一起，如： Los comandos del pipeline se pueden escribir juntos, por ejemplo:

实例 -> Ejemplo

pipe.set('hello', 'redis').sadd('faz', 'baz').incr('num').execute()
print(r.get("name"))
print(r.get("role"))
print(r.get("num"))
