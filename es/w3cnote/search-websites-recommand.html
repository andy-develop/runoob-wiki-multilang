Recomendar algunos sitios web de recursos de búsqueda

Categoría Tecnología de programación

En el proceso de aprendizaje técnico, a menudo necesitamos usar motores de búsqueda para recuperar información; el más utilizado en el país es, por ejemplo, Baidu.

Por supuesto, si es posible, se recomienda usar Google como motor de búsqueda principal; si no puedes usarlo, puedes usar los siguientes como respaldo:

Bing

Bing versión internacional:https://cn.bing.com/

Es mejor que Baidu; de hecho estuvo suspendido por unos días, pero recientemente ya funciona.

DuckDuckGo

DuckDuckGo：https://duckduckgo.com/

Según la introducción del sitio oficial, este motor de búsqueda no recopila información de los usuarios y no tiene anuncios.

Stack Overflow

Stack Overflow：https://stackoverflow.com/

Si solemos usar Google, las respuestas a muchos problemas técnicos están en este sitio web; si no puedes usar Google, puedes buscar directamente en este sitio.

Gitlogs

Gitlogs：https://www.gitlogs.com/

Gitlogs es un motor de búsqueda específico para proyectos de GitHub; a través de él podemos encontrar rápidamente el proyecto que queremos.

jiumo search

Motor de búsqueda de documentos jiumo search 鸠摩搜书:https://www.jiumodiary.com/。

Se puede usar para encontrar manuales y documentos técnicos; muchos están en Baidu Netdisk.

Ebooke

Ebooke：https://ebookee.org/

Ebookee es un sitio web de motor de búsqueda basado en Internet que ofrece descargas gratuitas de libros electrónicos.

Iconfinder

Búsqueda de iconos:https://www.iconfinder.com/

Se usa para buscar imágenes de logotipos.

TinEye

TinEye：https://www.tineye.com

Para buscar imágenes mediante imágenes, podemos subir una imagen o ingresar la URL de la imagen para buscar.

SemanticScholar

SemanticScholar：https://www.semanticscholar.org/

SemanticScholar es un motor de búsqueda académico gratuito; sus resultados provienen de revistas, materiales de conferencias académicas o documentos de instituciones académicas.

LibreStock

LibreStock：https://librestock.com/

En LibreStock se pueden buscar imágenes de alta calidad en HD.

CC Search

CC Search：https://ccsearch.creativecommons.org/

Los recursos de imágenes encontrados en CC Search no tienen derechos de autor; podemos usarlos gratuitamente.

The App Store

The App Store：https://theappstore.org/

The App Store es una herramienta de búsqueda de aplicaciones para dispositivos iPhone, iPad y Mac.
