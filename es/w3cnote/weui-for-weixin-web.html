WeUI está diseñado a medida para servicios web de WeChat

Resumen

WeUI es una biblioteca de estilos básica que coincide con la experiencia visual nativa de WeChat, diseñada a medida por el equipo de diseño oficial de WeChat para el desarrollo web de WeChat, lo que hace que la percepción de uso del usuario sea más uniforme. Incluyebutton、cell、dialog、toast、article、icony otros diversos elementos.

Instalación

Método 1 (recomendado)

WeChat oficial, Staticfile CDN y cdnjs proporcionan enlaces CDN para WeUI; se recomienda usarlos. Los enlaces son los siguientes:

Fuente Dirección
WeChat oficial https://res.wx.qq.com/open/libs/weui/0.4.3/weui.min.css
Staticfile CDN https://cdn.staticfile.net/weui/0.4.3/style/weui.css
cdnjs https://cdnjs.cloudflare.com/ajax/libs/weui/0.4.3/style/weui.css

Método 2:

Instalar usando bower

bower install --save weui

Método 3:

Instalar usando npm

npm install --save weui

Desarrollo

git clone https://github.com/weui/weui.git
cd weui
npm install -g gulp
npm install
gulp -ws

Ejecutargulp -wsel comando, se supervisaránsrclos cambios de todos los archivos en el directorio, y por defecto en el8080puerto se iniciará el servidor, y luego abra en el navegadorhttp://localhost:8080/example。

Página de resultados (Msg Page)

La página de resultados, en general, puede considerarse como la página de resumen que concluye el flujo después de una serie de pasos de operación. Su función principal es informar al usuario sobre el resultado del procesamiento de la operación y los detalles necesarios relacionados (que se pueden usar para confirmar si la operación anterior fue correcta), entre otra información; si el flujo se utiliza para activar o desactivar ciertas funciones importantes, se puede agregar contenido descriptivo relacionado con la función en la página de resultados; además, la página de resultados también puede contener operaciones de valor agregado, como proporcionar entradas a funciones como sorteos y seguir la cuenta oficial.

<div class="weui_msg">
    <div class="weui_icon_area"><i class="weui_icon_success weui_icon_msg"></i></div>
    <div class="weui_text_area">
        <h2 class="weui_msg_title">操作成功</h2>
        <p class="weui_msg_desc">内容详情，可根据实际需要安排</p>
    </div>
    <div class="weui_opr_area">
        <p class="weui_btn_area">
            <a href=".." class="weui_btn weui_btn_primary">确定</a>
            <a href=".." class="weui_btn weui_btn_default">取消</a>
        </p>
    </div>
    <div class="weui_extra_area">
        <a href="">查看详情</a>
    </div>
</div>

Página de artículo

La vista de texto muestra grandes bloques de texto, que generalmente son el contenido principal de la página.ArticleAdmite estilos de texto enriquecido como párrafos, títulos de varios niveles, citas, imágenes incrustadas, listas ordenadas/no ordenadas, y puede responder a las operaciones de selección del usuario.

Al usar en la webview del cliente de WeChatArticle, se debe garantizar que el texto tenga suficiente legibilidad y claridad, usar tipografías estándar, garantizar un espacio adecuado entre párrafos y sin sangría al inicio del párrafo.

<article class="weui_article">
    <h1>大标题</h1>
    <section>
        <h2 class="title">章标题</h2>
        <section>
