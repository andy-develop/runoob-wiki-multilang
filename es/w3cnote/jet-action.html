2.4 Jet Action

Categoría Tutorial de uso de JMR

Jmr permite a los usuarios personalizar Action. En Action podemos definir variables personalizadas y pasarlas a la plantilla.

La ventaja es que Action se encarga de obtener las variables, y la plantilla utiliza las variables pasadas por Action para mostrarlas, logrando una separación razonable de capas.

Crear Action

En Eclipse, haga clic derecho en la ubicación donde desea crear el archivo, o en el menú Archivo (File); luego haga clic en Nuevo (New) y seleccione Jmr Action. Si no lo encuentra, también está en el directorio JMR de Otros (Other).

Nota: El proyecto debe tener una carpeta de fuentes Java para poder usar Action; por ejemplo, proyectos Java, Java Web, Android, etc. tienen carpeta de fuentes Java.

Ingrese el nombre personalizado MyAction y haga clic en Finalizar (Finish).

Si el proyecto actual no tiene cargada la biblioteca de Jmr, haga clic en Aceptar para importar la biblioteca de Jmr. Esta biblioteca importada es similar a la biblioteca JUnit y no afecta la estructura de dependencias real del proyecto.

Usar Action

Action tiene un método execute, cuyo parámetro es el objeto integrado context de la sección anterior. Podemos llamar a context.setVariable(String name, Object object) para establecer variables y pasarlas a la plantilla.

En la tarea, haga clic en Examinar y seleccione el MyAction configurado anteriormente.

Obtener variables de Action desde la plantilla

Método uno

En la plantilla, llame a context.getVariable(String name) para obtener la variable; su uso es similar a request.getAttribute(String name) de Jsp.
Después de obtener la variable, use <%=%> para mostrarla.
