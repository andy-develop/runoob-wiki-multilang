1.4 Orden de Shell

Categoría Algoritmo

El orden de Shell (Shell Sort) es una versión mejorada del orden por inserción, también conocido como ordenación por incrementos decrecientes. Divide la lista a ordenar en varias sublistas, aplica el orden por inserción a cada sublista, reduce gradualmente el intervalo entre sublistas y finalmente completa toda la

El orden de Shell propone mejoras basándose en las siguientes dos propiedades del orden por inserción:

  • El orden por inserción es altamente eficiente al operar sobre datos casi ordenados, pudiendo alcanzar una eficiencia de ordenación lineal;
  • Pero el orden por inserción generalmente es ineficiente, porque solo puede mover los datos una posición a la vez;

La idea básica del orden de Shell es: primero dividir toda la secuencia de registros a ordenar en varias subsecuencias y realizar un orden por inserción directa en cada una; cuando los registros de toda la secuencia estén "básicamente ordenados", realizar un orden por inserción directa sobre todos los registros.

1. Pasos del algoritmo

  1. Elegir la secuencia de incrementos: elegir una secuencia de incrementos (gap sequence) para dividir la lista en varias sublistas. Las secuencias de incrementos comunes incluyen el incremento de Shell (n/2, n/4, ..., 1) y otras.

  2. Orden por inserción por grupos: dividir la lista en varias sublistas según la secuencia de incrementos y aplicar el orden por inserción a cada sublista.

  3. Reducir el incremento: reducir gradualmente el incremento, repetir el proceso de agrupación y ordenación anterior hasta que el incremento sea 1.

  4. Ordenación final: cuando el incremento sea 1, realizar un orden por inserción sobre toda la lista para completar la ordenación.

2. Demostración animada

Supongamos que hay una lista a ordenar [8, 3, 1, 2, 7, 5, 6, 4], usando el incremento de Shell (incremento inicial n/2), el proceso de ordenación es el siguiente:

  1. Estado inicial：

    • Lista:[8, 3, 1, 2, 7, 5, 6, 4]。

    • Incremento inicial:4(la mitad de la longitud de la lista8).

  2. Primera ronda (incremento de 4)：

    • Dividir la lista en 4 sublistas:

      • Sublista 1:[8, 7]。

      • Sublista 2:[3, 5]。

      • Sublista 3:[1, 6]。

      • Sublista 4:[2, 4]。

    • Aplicar el orden por inserción a cada sublista:

      • Sublista 1:[7, 8]。

      • Sublista 2:[3, 5]。

      • Sublista 3:[1, 6]。

      • Sublista 4:[2, 4]。

    • Lista ordenada:[7, 3, 1, 2, 8, 5, 6, 4]。

  3. Segunda ronda (incremento de 2)：

    • Dividir la lista en 2 sublistas:

      • Sublista 1:[7, 1, 8, 6]。

      • Sublista 2:[3, 2, 5, 4]。

    • Aplicar el orden por inserción a cada sublista:

      • Sublista 1:[1, 6, 7, 8]。

      • Sublista 2:[2, 3, 4, 5]。

    • Lista ordenada:[1, 2, 6, 3, 7, 4, 8, 5]。

  4. Tercera ronda (incremento de 1)：

    • Tratar toda la lista como una sola sublista y aplicar el orden por inserción.

    • Lista ordenada:[1, 2, 3, 4, 5, 6, 7, 8]。

Ejemplo

def shell_sort(arr):
    n = len(arr)
    gap = n // 2  # Incremento inicial
    while gap > 0:
        # Aplicar el orden por inserción a cada sublista
        for i in range(gap, n):
            temp = arr[i]  # Elemento actual a insertar
            j = i
            # Encontrar la posición adecuada en la sublista para insertar
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 2  # Reducir el incremento
    return arr

# Ejemplo
arr = [8, 3, 1, 2, 7, 5, 6, 4]
sorted_arr = shell_sort(arr)
print(sorted_arr)  # Salida: [1, 2, 3, 4, 5, 6, 7, 8]

Complejidad temporal

La complejidad temporal del orden de Shell depende de la elección de la secuencia de incrementos:

  • Peor caso: O(n²), cuando la secuencia de incrementos se elige de forma inadecuada.

  • Mejor caso: O(n log n), cuando la secuencia de incrementos se elige adecuadamente.

  • Caso promedio: entre O(n log n) y O(n²).

Secuencias de incrementos comunes:

  • Incremento de Shell:n/2, n/4, ..., 1, con complejidad temporal O(n²).

  • Incremento de Hibbard:1, 3, 7, 15, ..., 2^k - 1, con complejidad temporal O(n^(3/2)).

  • Incremento de Sedgewick:1, 5, 19, 41, 109, ..., con complejidad temporal O(n^(4/3)).

Complejidad espacial

  • O(1), el orden de Shell es un algoritmo de ordenación in situ que no requiere espacio de almacenamiento adicional.

Ventajas y desventajas

  • Ventajas：

    • En comparación con el orden por inserción simple, es más eficiente.

    • Ordenación in situ, no requiere espacio de almacenamiento adicional.

    • Adecuado para conjuntos de datos de tamaño mediano.

  • Desventajas：

    • La complejidad temporal depende de la elección de la secuencia de incrementos.

    • Algoritmo de ordenación inestable (puede cambiar el orden relativo de elementos iguales).

Escenarios aplicables

  • Conjuntos de datos de tamaño mediano.

  • Escenarios donde no se requieren altas prestaciones pero se necesita mayor eficiencia que el orden por inserción simple.

  • Como paso de preprocesamiento para algoritmos de ordenación más complejos.

function shellSort(arr) {
    var len = arr.length,
        temp,
        gap = 1;
    while(gap < len/3) {          // Definir dinámicamente la secuencia de intervalos
        gap =gap*3+1;
    }
    for (gap; gap > 0; gap = Math.floor(gap/3)) {
        for (var i = gap; i < len; i++) {
            temp = arr[i];
            for (var j = i-gap; j >= 0 && arr[j] > temp; j-=gap) {
                arr[j+gap] = arr[j];
            }
            arr[j+gap] = temp;
        }
    }
    return arr;
}

public static void shellSort(int[] arr) {

template<typename T>
void shell_sort(T array[], int length) {
    int h = 1;
    while (h < length / 3) {
        h = 3 * h + 1;
    }
    while (h >= 1) {
        for (int i = h; i < length; i++) {
            for (int j = i; j >= h && array[j] < array[j - h]; j -= h) {
                std::swap(array[j], array[j - h]);
            }
        }
        h = h / 3;
    }
}

    fn shell_sort<T: Ord + Debug>(array: &mut [T]) {
    let mut grad = [1, 3, 5];
    grad.reverse();
    for step in grad {
        insert_sort_step(array, step)
    }
}

fn insert_sort_step<T: Ord + Debug>(array: &mut [T], step: usize) {
    for i in (0..array.len()).step_by(step) {
        for j in (0..i).step_by(step).rev() {
            if array[j + step] < array[j] {
                array.swap(j + step, j);
            } else {
                break;
            }
        }
    }
}
