Jmr Experiencia rápida

Vamos a experimentar rápidamente con Jmr mediante 2 ejemplos.

Hello Jmr!

A continuación se muestra un ejemplo sencillo de generación, que se resume en solo 3 pasos:
1. Escribir la plantilla
2. Configurar la tarea
3. Ejecutar la generación

Para más detalles, lea:Primer ejemplo - Hello Jmr

Java Web

A continuación se muestra un ejemplo de Java Web: a partir de las tablas de la base de datos, se convierte el modelo y se genera un módulo completo de agregar, eliminar, consultar y modificar (CRUD). Se resume en 4 pasos:
1. Escribir la plantilla
2. Configurar la tarea
3. Configurar el modelo (base de datos)
4. Ejecutar la generación

Resultado de la ejecución: todo el código de un módulo (incluyendo CRUD, frontend y backend). El desarrollador puede escribir plantillas según su propio proyecto, y esta es también la característica distintiva de Jmr.
