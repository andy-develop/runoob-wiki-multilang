Dirección de código abierto en Github: https://github.com/EbookFoundation/free-programming-books

Página de búsqueda (inglés): https://ebookfoundation.github.io/

Página de búsqueda (chino): https://ebookfoundation.github.io/free-programming-books/books/free-programming-books-zh.html

Proyectos similares en chino: https://github.com/justjavac/free-programming-books-zh_CN

free-programming-books es un proyecto de código abierto en GitHub, destinado a recopilar y compartir recursos gratuitos de aprendizaje de programación. Este proyecto incluye una gran cantidad de libros electrónicos gratuitos sobre diversos lenguajes de programación, frameworks, herramientas y áreas de las ciencias de la computación, cubriendo todos los niveles desde principiantes hasta desarrolladores avanzados.

El objetivo principal de este proyecto es proporcionar materiales de aprendizaje gratuitos y de alta calidad para quienes aprenden programación, incluyendo, entre otros, libros y materiales sobre lenguajes de programación, algoritmos, estructuras de datos, bases de datos, desarrollo frontend y backend.

En este proyecto podemos encontrar libros relacionados con la programación, por ejemplo, sobre lenguajes como Python, Java, JavaScript, C++, así como recursos de aprendizaje sobre diferentes campos como desarrollo web, ciencia de datos, inteligencia artificial y seguridad de redes.
