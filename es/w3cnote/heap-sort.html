1.7 Ordenamiento por montículos

Clasificación Algoritmo

El ordenamiento por montículos (Heapsort) es un algoritmo de ordenamiento diseñado utilizando la estructura de datos del montículo. El montículo es una estructura aproximadamente de árbol binario completo que cumple al mismo tiempo la propiedad del montículo: es decir, el valor clave o el índice de un nodo hijo siempre es menor (o mayor) que el de su nodo padre. El ordenamiento por montículos puede considerarse un tipo de ordenamiento por selección que utiliza el concepto de montículo para ordenar. Se divide en dos métodos:

  1. Montículo máximo: el valor de cada nodo es mayor o igual que el valor de sus nodos hijos, y se utiliza para ordenamiento ascendente en el algoritmo de ordenamiento por montículos;
  2. Montículo mínimo: el valor de cada nodo es menor o igual que el valor de sus nodos hijos, y se utiliza para ordenamiento descendente en el algoritmo de ordenamiento por montículos;

La complejidad temporal promedio del ordenamiento por montículos es Ο(nlogn).

1. Pasos del algoritmo

  1. Crear un montículo H[0……n-1];

  2. Intercambiar la cima del montículo (el valor máximo) con el último elemento;

  3. Reducir el tamaño del montículo en 1 y llamar a shift_down(0), con el objetivo de ajustar el nuevo dato en la parte superior de la matriz a la posición correspondiente;

  4. Repetir el paso 2 hasta que el tamaño del montículo sea 1.

2. Demostración animada

Supongamos que hay una lista por ordenar [4, 10, 3, 5, 1], el proceso de ordenamiento por montículos es el siguiente:

  1. Construir el montículo máximo：

    • Lista inicial:[4, 10, 3, 5, 1]。

    • Comenzando desde el último nodo no hoja, ajustar el montículo gradualmente:

      • Ajustar el nodo5：[4, 10, 3, 5, 1](no es necesario ajustar).

      • Ajustar el nodo10：[4, 10, 3, 5, 1](no es necesario ajustar).

      • Ajustar el nodo4：[10, 5, 3, 4, 1]。

    • Montículo máximo final:[10, 5, 3, 4, 1]。

  2. Intercambiar el elemento superior del montículo：

    • Colocar el elemento superior del montículo10con el último elemento1Intercambiar, la lista se convierte en[1, 5, 3, 4, 10]。

    • El tamaño del montículo se reduce en 1, la parte ordenada es[10]。

  3. Ajustar el montículo：

    • Para el nuevo elemento superior del montículo1realizar la operación de hundimiento:

      • Comparar1con sus nodos hijos5、3, y1 与 5intercambiar.

      • La lista se convierte en[5, 1, 3, 4, 10]。

      • Continuar comparando1con sus nodos hijos4, y1 与 4intercambiar.

      • La lista se convierte en[5, 4, 3, 1, 10]。

    • El montículo ajustado:[5, 4, 3, 1]。

  4. Repetir los pasos：

    • Colocar el elemento superior del montículo5con el último elemento1Intercambiar, la lista se convierte en[1, 4, 3, 5, 10]。

    • El tamaño del montículo se reduce en 1, la parte ordenada es[5, 10]。

    • Para el nuevo elemento superior del montículo1realizar la operación de hundimiento:

      • Comparar1con sus nodos hijos4、3, y1 与 4intercambiar.

      • La lista se convierte en[4, 1, 3, 5, 10]。

    • El montículo ajustado:[4, 1, 3]。

  5. Continuar repitiendo：

    • Colocar el elemento superior del montículo4con el último elemento3Intercambiar, la lista se convierte en[3, 1, 4, 5, 10]。

    • El tamaño del montículo se reduce en 1, la parte ordenada es[4, 5, 10]。

    • Para el nuevo elemento superior del montículo3realizar la operación de hundimiento:

      • Comparar3con sus nodos hijos1, no es necesario intercambiar.

    • El montículo ajustado:[3, 1]。

  6. Paso final：

    • Colocar el elemento superior del montículo3con el último elemento1Intercambiar, la lista se convierte en[1, 3, 4, 5, 10]。

    • El tamaño del montículo se reduce en 1, la parte ordenada es[3, 4, 5, 10]。

    • El tamaño del montículo es 1, el ordenamiento está completo.

Ejemplo

def heapify(arr, n, i):
    # Encontrar el valor máximo entre el nodo actual, el nodo hijo izquierdo y el nodo hijo derecho
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right

    # Si el valor máximo no es el nodo actual, intercambiar y continuar ajustando
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

def heap_sort(arr):
    n = len(arr)

    # Construir el montículo máximo
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # Extraer uno por uno el elemento superior del montículo y ajustar el montículo
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # Intercambiar el elemento superior del montículo y el último elemento
        heapify(arr, i, 0)  # Ajustar el montículo

    return arr

# Ejemplo
arr = [4, 10, 3, 5, 1]
sorted_arr = heap_sort(arr)
print(sorted_arr)  # Salida: [1, 3, 4, 5, 10]

Complejidad temporal

  • Construir el montículo máximo：O(n)。

  • Cada ajuste del montículo: O(log n), en total es necesario ajustar n-1 veces.

  • Complejidad temporal total：O(n log n)。

Complejidad espacial

  • O(1), el ordenamiento por montículos es un algoritmo de ordenamiento in situ, no necesita espacio de almacenamiento adicional.

Ventajas y desventajas

  • Ventajas：

    • La complejidad temporal es estable en O(n log n), adecuado para datos a gran escala.

    • Ordenamiento in situ, no necesita espacio de almacenamiento adicional.

  • Desventajas：

    • Algoritmo de ordenamiento inestable (puede cambiar el orden relativo de elementos iguales).

    • Para datos a pequeña escala, el rendimiento puede no ser tan bueno como el de algoritmos simples como el ordenamiento por inserción.

Escenarios de aplicación

  • Ordenamiento de conjuntos de datos a gran escala.

  • Escenarios con altos requisitos de rendimiento.

  • Adecuado para ordenamiento en memoria (no adecuado para ordenamiento externo).

function buildMaxHeap(arr) {   // Establecer el montículo máximo
    len = arr.length;
    for (var i = Math.floor(len/2); i >= 0; i--) {
        heapify(arr, i);
    }
}

function heapify(arr, i) {     // Ajuste del montículo
    var left = 2 * i + 1,
        right = 2 * i + 2,
        largest = i;

    if (left < len && arr[left] > arr[largest]) {
        largest = left;
    }

    if (right < len && arr[right] > arr[largest]) {
        largest = right;
    }

    if (largest != i) {
        swap(arr, i, largest);
        heapify(arr, largest);
    }
}

function swap(arr, i, j) {
    var temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

function heapSort(arr) {
    buildMaxHeap(arr);

    for (var i = arr.length-1; i > 0; i--) {
        swap(arr, 0, i);
        len--;
        heapify(arr, 0);
    }
    return arr;
}

public class HeapSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copiar arr, sin cambiar el contenido del parámetro
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        int len = arr.length;

        buildMaxHeap(arr, len);

        for (int i = len - 1; i > 0; i--) {
            swap(arr, 0, i);
            len--;
            heapify(arr, 0, len);
        }
        return arr;
    }

    private void buildMaxHeap(int[] arr, int len) {
        for (int i = (int) Math.floor(len / 2); i >= 0; i--) {
            heapify(arr, i, len);
        }
    }

    private void heapify(int[] arr, int i, int len) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int largest = i;

        if (left < len && arr[left] > arr[largest]) {
            largest = left;
        }

        if (right < len && arr[right] > arr[largest]) {
            largest = right;
        }

        if (largest != i) {
            swap(arr, i, largest);
            heapify(arr, largest, len);
        }
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

#include <stdio.h>
#include <stdlib.h>

void swap(int *a, int *b) {
    int temp = *b;
    *b = *a;

}

void max_heapify(int arr[], int start, int end) {
    // Establecer el puntero del nodo padre y el puntero del nodo hijo
    int dad = start;
    int son = dad * 2 + 1;
    while (son <= end) { // Solo comparar si el puntero del nodo hijo está dentro del rango
        if (son + 1 <= end && arr[son] < arr[son + 1]) // Primero comparar el tamaño de los dos nodos hijos, elegir el mayor
            son++;
        if (arr[dad] > arr[son]) // Si el nodo padre es mayor que el nodo hijo, significa que el ajuste ha terminado, salir directamente de la función
            return;
        else { // De lo contrario, intercambiar el contenido entre padre e hijo y continuar comparando el nodo hijo con el nodo nieto
            swap(&arr[dad], &arr[son]);
            dad = son;
            son = dad * 2 + 1;
        }
    }
}

void heap_sort(int arr[], int len) {
    int i;
    // Inicialización, i comienza a ajustar desde el último nodo padre
    for (i = len / 2 - 1; i >= 0; i--)
        max_heapify(arr, i, len - 1);
    // Primero intercambiar el primer elemento con el elemento anterior a los ya ordenados, y luego reajustar, hasta que el ordenamiento esté completo
    for (i = len - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);
        max_heapify(arr, 0, i - 1);
    }
}

    for (i = 0; i < len; i++)
        printf("%d ", arr[i]);
    printf("\n");
    return 0;
}

    /// <summary>
/// 堆排序
/// </summary>
/// <param name="arr">待排序数组</param>
static void HeapSort(int[] arr)
{
    int vCount = arr.Length;
    int[] tempKey = new int[vCount + 1];
    // 元素索引从1开始
    for (int i = 0; i < vCount; i++)
    {
        tempKey[i + 1] = arr[i];
    }
    // 初始数据建堆（从含最后一个结点的子树开始构建，依次向前，形成整个二叉堆）
    for (int i = vCount / 2; i >= 1; i--)
    {
        Restore(tempKey, i, vCount);
    }
    // 不断输出堆顶元素、重构堆，进行排序
    for (int i = vCount; i > 1; i--)
    {
        int temp = tempKey[i];
        tempKey[i] = tempKey[1];
        tempKey[1] = temp;
        Restore(tempKey, 1, i - 1);
    }
    //排序结果
    for (int i = 0; i < vCount; i++)
    {
        arr[i] = tempKey[i + 1];
    }
}
/// <summary>
/// 二叉堆的重构（针对于已构建好的二叉堆首尾互换之后的重构）
/// </summary>
/// <param name="arr"></param>
/// <param name="rootNode">根结点j</param>
/// <param name="nodeCount">结点数</param>
static void Restore(int[] arr, int rootNode, int nodeCount)
{
    while (rootNode <= nodeCount / 2) // 保证根结点有子树
    {
        //找出左右儿子的最大值
        int m = (2 * rootNode + 1 <= nodeCount && arr[2 * rootNode + 1] > arr[2 * rootNode]) ? 2 * rootNode + 1 : 2 * rootNode;
        if (arr[m] > arr[rootNode])
        {
            int temp = arr[m];
            arr[m] = arr[rootNode];
            arr[rootNode] = temp;
            rootNode = m;
        }
        else
        {
            break;
        }
    }
}

    ¡El ordenamiento por montículos es un ordenamiento inestable!

    Dado que es así, al construir el montículo máximo cada vez, basta con tomar el mayor de los tres (nodo padre, nodo hijo izquierdo, nodo hijo derecho) como nodo padre. Lo que buscamos es solo el resultado final después del ordenamiento, por lo que se pueden simplificar algunos pasos.

    Pondré el núcleo del código Java que escribí personalmente a continuación, los compañeros interesados pueden discutirlo juntos:

    public int[] sort(int a[]) {
    int len = a.length - 1;    
    for (int i = len; i > 0; i--) {
        maxHeap(a, i);        
        //交换 跟节点root 与 最后一个子节点i 的位置        
        swap(a, 0, i);        
        //i--无序数组尺寸减少了 
    }  
    return a;
}

/**构建一个大顶堆（完全二叉树 ） 
* 从  最后一个非叶子节点  开始，若父节点小于子节点，则互换他们两的位置。然后依次从右至左，从下到上进行！ 
* 最后一个非叶子节点，它的叶子节点 必定包括了最后一个（叶子）节点，所以 最后一个非叶子节点是 a[（n+1）/2-1] 
 
* @param a 
* @param lastIndex 这个数组的最后一个元素 
*/
static void maxHeap(int a[], int lastIndex) {
    for (int i = (lastIndex + 1) / 2 - 1; i >= 0; i--) {
       //反正 堆排序不稳定，先比较父与左子，大则交换；与右子同理。（不care 左子与右子位置是否变了！） 
        if (i * 2 + 1 <= lastIndex && a[i] < a[i * 2 + 1]) {
            swap(a, i, i * 2 + 1);        
        }    
        if (i * 2 + 2 <= lastIndex && a[i] < a[i * 2 + 2]) {
            swap(a, i, i * 2 + 2);        
        }
    }
}

private void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
