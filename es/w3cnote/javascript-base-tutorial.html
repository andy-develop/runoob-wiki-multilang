Aplicación de for

Escenarios de uso del bucle for:
  • Si se quiere ejecutar cierto código repetidamente
  • Cada vez que se ejecuta, hay un número que cambia
Orden de ejecución del bucle for: 1→234→234……
  1. var i = 0;
  2. i < 3; paso clave
  3. Todo el código dentro de los paréntesis
  4. i++
Presta atención al siguiente bucle:
for (var i=0; i<aLi.length; i++) {
  aLi[i].onclick = function(){
    alert(i);
  }
}
El código anterior mostrará un 3, en lugar de 0, 1, 2 sucesivamente; presta atención aquí: si dentro del bucle for se envuelve una función y la función usa i, entonces debido al ámbito (scope), i no aumentará de forma incremental como imaginas.

Aplicación de atributos personalizados

Con atributos personalizados se puede añadir una propiedad de interruptor al elemento, como control de conmutación. Como en el siguiente ejemplo:
window.onload = function(){
  var aLi = document.getElementsByTagName('li');
  // var onOff = true; 一个onOff只能控制一个开关。要为多个元素设置各自的开关，就要给每个元素加个onOff开关。
  
  for(var i=0; i<aLi.length; i++) {
    aLi[i].onOff = true;
    aLi[i].onclick = function(){
      if (this.onOff){
        this.style.background = 'url(img/active.png)';
        this.onOff = false;
      } else {
        this.style.background = 'url(img/normal.png)';
        this.onOff = true;
      }
    }
  }
}

Ejemplo de aplicación de isNaN

NaN: (not a number). NaN es un tipo numérico que no es un número. Todos los números son de tipo numérico, pero no todos los tipos numéricos son números.
  • NaN es un tipo numérico, pero no es un número.
  • Una vez que aparece NaN en un programa, seguramente indica que se ha realizado una operación ilegal.
  • NaN es un false.
  • NaN ni siquiera es igual a sí mismo.
var a = Number('abc');
//alert(a); //NaN
//alert(typeof(a)); //number

if(a) { //会弹出‘假’，说明NaN是false
  alert('真');
} else {
  alert('假');
}

//alert(a === a); //false NaN比较，比出false
isNaN：is not a Number: significa "no es un número" (no es un número). isNaN(); es un método, se usa para trabajar.
  • Ayuda a determinar si ciertos valores son números.
  • No le gustan los números, odia los números (no es que odie el tipo numérico; cuando isNaN se encuentra con NaN, le encanta, devuelve true, pero NaN es un tipo numérico). Se usa para determinar números. Por ejemplo, alert(isNaN(2)); devuelve false. alert(isNaN('我爱你')); devuelve true. alert(isNaN(function(){})); devuelve true.
El proceso de evaluación de isNaN: lanza lo que hay dentro de los paréntesis a Number; si Number logra convertirlo en número, devuelve false; si no puede convertirlo, devuelve true.
alert(isNaN('250'));
//Number() '250' => 250 => false

alert(isNaN(true));
//Number() true => 1 => false

alert(isNaN([]));
//Number() [] => 0 => false

El proceso del código anterior en el pre-análisis es el siguiente: 1) Pre-análisis: var function parámetros ... Se lee var a = 1 => a es undefined. Se lee function a(){alert(2);} => a = function a(){alert(2);} Si la variable y la función tienen el mismo nombre, se deja solo la función: a = function(){alert(2);} Se lee var a = 3 => a es undefined, aquí hay conflicto de nombre con la función a anterior, así que se sigue manteniendo a = function(){alert(2);} Se lee function a(){alert(4);} => a = function a(){alert(4);} hay conflicto de nombre con el anterior a = function(){alert(2);}, según el contexto, la función posterior sobrescribe a la función anterior, por lo que el pre-análisis solo deja a = function(){alert(4);}. 2) Interpretar el código línea por línea. Al leer una expresión, la expresión puede modificar el valor del pre-análisis. Los parámetros también pueden cambiar el valor del pre-análisis. Cuando se encuentra una llamada a función, se deben hacer dos cosas: pre-análisis y análisis línea por línea del código. La declaración de función no es una expresión y no cambia el valor dentro del pre-análisis.

Clase de comparación, clase de extracción

  • La comparación de tamaños de cadenas compara los códigos Unicode de los caracteres en la posición 0 de las cadenas.
  • .substring(n, m)Extrae los caracteres desde la posición n hasta la posición m. Si no se indica m, por defecto extrae hasta la última posición. `str.substring(2, 0);` y `str.substring(0, 2);` dan el mismo resultado. `substring` puede detectar el tamaño de los dos parámetros; si el segundo parámetro es menor que el primero, invierte automáticamente los dos parámetros. Si no hay ningún parámetro entre paréntesis, equivale a extraer desde la posición 0 hasta la última, es decir, toda la cadena. Si algún parámetro es negativo, se trata como 0.
  • .slice(n, m)`str.slice(0, 2)` y `str.slice(2, 0)` dan resultados diferentes. El segundo no encuentra resultado, porque el método `.slice()` no compara el tamaño de los parámetros ni intercambia sus posiciones. `str.slice(-2);` extrae desde la última posición hasta la penúltima. -1 representa el último carácter de la cadena. `str.slice(-4, -2);` extrae la subcadena desde la cuarta posición desde el final hasta la segunda desde el final.

  • .join()Método que se usa para unir los elementos de un array. `var arr = ['aa', 'bb', 'cc]; arr.join(); => 'aa,bb,cc'`. Si no se escribe nada entre paréntesis en `.join()`, por defecto separa con comas. `arr.join(''); => 'aabbcc'`; `arr.join('-'); => 'aa-bb-cc'`

Operaciones con arrays

Añadir
  • Método push: `arr.push();` añade contenido al final del array. El método `.push()` tiene un valor de retorno, que es la nueva longitud del array.
  • Método unshift: `arr.unshift();` añade contenido al principio del array, el valor de retorno es la nueva longitud del array (IE6 e IE7 no soportan el valor de retorno de `unshift`).
Eliminar
  • Método pop: `arr.pop();` elimina el último elemento del array, el valor de retorno es el valor eliminado.
  • Método shift: `arr.shift();` elimina el primer elemento del array, el valor de retorno es el valor eliminado.
Pequeños trucos 
var arr = ['TM', '钟毅', '张森', '杜鹏', 'Leo'];
arr.unshift(arr.pop()); //数组变为：['Leo', '钟毅', '张森', '杜鹏', 'TM']
或
arr.push(arr.shift()); //数组变为：['钟毅', '张森', '杜鹏', 'Leo', 'TM']
Método `splice`
  • El método `splice` tiene tres funciones: eliminar, reemplazar y añadir.
var arr = ['TM', '钟毅', '张森', '杜鹏', 'Leo'];
//删除
//arr.splice(0, 1); //删掉第0位，删1个。两个参数第一个是从第几位开始，第二个是删掉几个。splice删除的时候有返回值，返回的是被删除的内容
//替换
//arr.splice(0, 1, '莫涛'); //替换第0位，替换1个，替换为'莫涛'。返回的还是删除的东西
//添加
arr.splice(1, 0, '李贤'); //在第1位那里，删除0个，添加了一个'李贤'到了第1位，'钟毅'就变成了arr[2]了。后面也可以添加多个。如果splice删除了0个，那么就没有返回值。

Eliminación de duplicados en arrays

var arr = [1, 2, 2, 4, 2];
for ( var i=0; i<arr.length; i++ ) {
    for ( var j = i+1; j<arr.length; j++) {
        if( arr[i]==arr[j] ){
            arr.splice( j, 1 );
            j--;
        }
    }
}
