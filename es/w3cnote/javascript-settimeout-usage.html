Uso detallado de JavaScript setTimeout()

Categoría Tecnología de programación

setTimeout() es un método que pertenece a window; este método se utiliza para llamar a una función o evaluar una expresión después del número de milisegundos especificado.

El formato de sintaxis puede ser uno de los siguientes dos:

setTimeout(要执行的代码, 等待的毫秒数)
setTimeout(JavaScript 函数, 等待的毫秒数)

A continuación, veamos un ejemplo sencillo:

Ejemplo

setTimeout("alert('对不起, 要你久候')", 3000 )

Pruébalo »

En el código de prueba, podemos ver que, tres segundos después de abrir la página, aparece un cuadro de diálogo alert.

setTimeout() establece un tiempo de espera especificado (la unidad es la milésima de segundo, millisecond). Cuando el tiempo se cumple, el navegador ejecuta un código específico, como se muestra a continuación:

setTimeout() también se puede usar para ejecutar una función especificada (function). Como en el siguiente ejemplo, el texto de la página web se modificará después de tres segundos.

Ejemplo

<p id="content">¡Espera tres segundos!</p> <script> setTimeout("changeState()",3000 ); function changeState(){ let content=document.getElementById('content'); content.innerHTML="<div style='color:red'>¡Soy el contenido que se muestra después de tres segundos!</div>"; } </script>

Pruébalo »

En el ejemplo se establece una espera de 3 segundos (3000 milliseconds) y luego el navegador ejecuta la función changeState().

A continuación, podemos usar setTimeout() para ejecutar repetidamente una función especificada y así implementar un contador:

Ejemplo

<input type="text" id="displayBox" name="displayBox" value="0"> <script>x = 0 function countSecond() {　 x = x+1 document.getElementById("displayBox").value=x setTimeout("countSecond()", 1000) } // 执行函数 countSecond()</script>

Pruébalo »

En el ejemplo, después de cargar la página, se ejecuta la función countSecond(). Esta función utiliza el método setTimeout(), que llama a la función countSecond() cada segundo, por lo que countSecond() se ejecuta una vez por segundo, logrando el efecto de contador.

Por supuesto, también podemos agregar algunos fragmentos a la función del contador para detener el conteo bajo condiciones específicas:

Ejemplo

<input type="text" id="displayBox" name="displayBox" value="0"> <script> x = 0 function countSecond() {　 if(x<20) { x = x+1 document.getElementById("displayBox").value=x setTimeout("countSecond()", 1000) } } // 执行函数countSecond() </script>

Pruébalo »

En el ejemplo, cuando x es menor que 20, la función countSecond() se ejecuta cada segundo; cuando x es mayor o igual que 20, se detiene la ejecución.

Ya que se puede iniciar el conteo, de manera correspondiente también se debe poder detenerlo; la función utilizada para detener el temporizador es clearTimeout().

El método setTimeout() puede hacer que el navegador ejecute continuamente un fragmento de código o una función. Cuando un setTimeout() ha comenzado un trabajo en bucle, si queremos detenerlo, podemos usar el método clearTimeout().

Sintaxis de clearTimeout():

clearTimeout(timeoutID)

timeoutID es el valor de retorno obtenido al llamar a la función setTimeout(). Usando este identificador de retorno como parámetro, se puede cancelar la operación de ejecución programada establecida por ese setTimeout().

meter1 =setTimeout("count1()", 1000)
meter2 =setTimeout("count2()", 1000)

Al usar meter1 y meter2 como nombres de timeoutID, al establecer clearTimeout() se puede especificar a cuál setTimeout() afecta, sin afectar la operación del otro setTimeout().

Como en el siguiente ejemplo:

Ejemplo

<form name="display1"> <input type="text" id="box1" name="box1" value="0" size="4" /> <input type="button" value="Detener cronómetro" onclick="clearTimeout(meter1)" /> <input type="button" value="Continuar cronómetro" onclick="count1() " /> </form> <p></p> <form name="display2"> <input type="text" id="box2" name="box2" value="0" size="4" /> <input type="button" value="Detener cronómetro" onclick="clearTimeout(meter2) " /> <input type="button" value="Continuar cronómetro" onclick="count2( ) " /> </form> <script>x = 0 y = 0 function count1( ) {　 x = x+ 1 document.getElementById("box1").value= x meter1=setTimeout("count1()", 1000) } function count2( ) {　 y = y+ 1 document.getElementById("box2").value= y meter2=setTimeout("count2()", 1000) } // 执行函数 count1( ) count2( )</script>
