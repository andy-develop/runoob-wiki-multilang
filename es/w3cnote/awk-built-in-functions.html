, . . ., A[n], y devuelve el valor de la variable n. Esta separación se puede realizar mediante la expresión regular extendida especificada por el parámetro Ere, o mediante el separador de campos actual (variable especial FS) (si no se proporciona el parámetro Ere). Los elementos del arreglo A se crean con valores de cadena, a menos que el contexto indique que un elemento específico también debe tener un valor numérico.

  • Funciones aritméticas
  • Funciones de cadenas
  • Funciones de tiempo
  • Funciones de manipulación de bits
  • Otras funciones

Funciones de cadenas

Función Descripción Ejemplo
gsub( Ere, Repl, [ In ] ) gsub es la abreviatura de sustitución global (global substitution). Excepto que se reemplazan todos los valores concretos de la expresión regular, se ejecuta exactamente igual que la función sub. 
$ awk 'BEGIN {

}'

El resultado de salida es:

String before replacement = Hello, World
String after replacement = Hello, Jerry
sub(regex,sub,string) La función sub realiza una sustitución de subcadena. Reemplaza la primera aparición de la subcadena por regex. El tercer parámetro es opcional y por defecto es $0. 
$ awk 'BEGIN {

String before replacement = Hello, World
String after replacement = Hello, Jerry

Substring = Hello

$ awk 'BEGIN {

Substring "Two" found at 5 location.

substr( String, M, [ N ] ) Devuelve una subcadena con el número de caracteres especificado por el parámetro N. La subcadena se obtiene de la cadena especificada por el parámetro String, comenzando sus caracteres en la posición especificada por el parámetro M. El parámetro M se especifica tomando el primer carácter del parámetro String como número 1. Si no se especifica el parámetro N, la longitud de la subcadena será desde la posición especificada por M hasta el final del parámetro String. 
$ awk 'BEGIN {

El resultado de salida es:

Substring = Hello
match( String, Ere ) En la cadena especificada por el parámetro String (donde aparece la expresión regular extendida especificada por el parámetro Ere), devuelve la posición (en caracteres), numerada desde 1, o si el parámetro Ere no aparece, devuelve 0 (cero). La variable especial RSTART se establece al valor devuelto. La variable especial RLENGTH se establece a la longitud de la cadena coincidente, o a -1 (menos uno) si no se encuentra ninguna coincidencia. 
$ awk 'BEGIN {

}'

El resultado de salida es:

Substring "Two" found at 5 location.

Nota:EreLa parte puede ser una expresión regular.

1. Uso de gsub y sub

$ awk 'BEGIN{info="this is a test2012test!";gsub(/[0-9]+/,"||",info);print info}'
this is a test||test!

2. Búsqueda de cadenas (uso de index)

Se utiliza el operador ternario:expresión ? acción1 : acción2

$ awk 'BEGIN{info="this is a test2012test!";print index(info,"11111")?"ok":"no found";}'
no found
$ awk 'BEGIN{info="this is a test2012test!";print index(info,"is")?"ok":"no found";}'
ok
$ awk 'BEGIN{info="this is a test2012test!";print index(info,"test")?"ok":"no found";}'
ok

3. Búsqueda de coincidencias de expresiones regulares (uso de match)

$ awk 'BEGIN{info="this is a test2012test!";print match(info,/[0-9]+/)?"ok":"no found";}'
ok

4. Extracción de subcadenas (uso de substr)

Comenzando desde el cuarto carácter, extraer una cadena de 10 caracteres de longitud.

$ awk 'BEGIN{info="this is a test2012test!";print substr(info,4,10);}'
s is a tes

5. División de cadenas (uso de split)

$ awk 'BEGIN{info="this is a test";split(info,tA," ");print length(tA);for(k in tA){print k,tA[k];}}'
4
2 is
3 a
4 test
1 this

Dividir info, usando espacios para separar la cadena info en un arreglo dinámico tA. Tenga en cuenta que el bucle for...in de awk es un bucle desordenado. No recorre los índices del arreglo de 1...n, por lo que se debe tener especial cuidado al usarlo.

6. Salida de cadenas formateadas (uso de sprintf)

La cadena de formato incluye dos partes: una parte son caracteres normales, que se emitirán tal cual; la otra parte son caracteres de especificación de formato, que comienzan con%comienza, seguido de uno o varios caracteres de especificación, para determinar el formato del contenido de salida. Se debe tener especial cuidado en que al usarprintfpor defecto no se añade un salto de línea, mientras queprintla función, por defecto, añade al final de cada línea un\nsalto de línea.

Especificador de formato Descripción
%d Entero decimal con signo
%u Entero decimal sin signo
%f Número de punto flotante
%s Cadena
%c Carácter individual
%p Valor de puntero
%e Número de punto flotante en forma exponencial
%x %X Entero sin signo representado en hexadecimal
%o Entero sin signo representado en octal
%g Selecciona automáticamente la representación adecuada 
$ awk 'BEGIN{n1=124.113;n2=-1.224;n3=1.2345; printf("%.2f,%.2u,%.2g,%X,%o\n",n1,n2,n3,n1,n1);}'
124.11,4294967295,1.2,7C,174
$  awk 'BEGIN{n1=124.113;n2=-1.224;n3=1.2645; printf("%.2f,%.2u,%.2g,%X,%o\n",n1,n2,n3,n1,n1);}'
124.11,4294967295,1.3,7C,174

Nota:Al observar el valor de salida de n3 anterior, se puede ver que una función bastante inteligente al usar printf es que puede redondear y conservar decimales.

Otras funciones

Nombre de la función. Descripción. Ejemplo.
close(expr) Cierra el archivo de la tubería (pipe). 
$ awk 'BEGIN {
    cmd = "tr [a-z] [A-Z]"
    print "hello, world !!!" |& cmd
    close(cmd, "to")
    cmd |& getline out
    print out;
    close(cmd);
}'

El resultado es:

HELLO, WORLD !!!
  • La primera declaración cmd = "tr [a-z] [A-Z]" establece un canal de comunicación bidireccional en AWK.
  • La segunda declaración print proporciona entrada al comando tr. &| indica comunicación bidireccional.
  • La tercera declaración close(cmd, "to") cierra el proceso "to" después de completar la ejecución.
  • La cuarta declaración cmd |& getline out usa la función getline para almacenar la salida en la variable out.
  • La siguiente declaración de salida imprime el contenido de la salida, y finalmente la función close cierra cmd.
delete Se utiliza para eliminar elementos de un array. 
$ awk 'BEGIN {
    arr[0] = "One"
    arr[1] = "Two"
    arr[2] = "Three"
    arr[3] = "Four"

    print "Array elements before delete operation:"
    for (i in arr) {
        print arr[i]
    }

    delete arr[0]
    delete arr[1]

    print "Array elements after delete operation:"
    for (i in arr) {
        print arr[i]
    }
}'

El resultado es:

Array elements before delete operation:
One
Two
Three
Four

Array elements after delete operation:
Three
Four
exit Termina la ejecución del script; puede aceptar un parámetro opcional expr para pasar el estado de retorno de AWK. 
$ awk 'BEGIN {
    print "Hello, World !!!"

    exit 10

    print "AWK never executes this statement."
}'

El resultado es:

Hello, World !!!
flush Vacía el búfer de un archivo o tubería abiertos.  
getline Lee la siguiente línea.

Usa getline para leer una línea del archivo marks.txt y mostrarla:

$ awk '{getline; print $0}' marks.txt

AWK lee una línea del archivo marks.txt y la almacena en la variable 0. En la siguiente declaración, usamos getline para leer la siguiente línea. Por lo tanto, AWK lee la segunda línea y la almacena en 0. Finalmente, AWK usa print para mostrar el contenido de la segunda línea. Este proceso continúa hasta el final del archivo.
next Detiene el procesamiento del registro actual y pasa al procesamiento del siguiente registro.

Cuando el patrón coincide, el programa no realiza ninguna acción:

$ awk '{if ($0 ~/Shyam/) next; print $0}' marks.txt
nextfile Detiene el procesamiento del archivo actual y comienza a procesar desde el primer registro del siguiente archivo.

Primero creamos dos archivos. El contenido de file1.txt es el siguiente:

file1:str1
file1:str2
file1:str3
file1:str4

El contenido del archivo file2.txt es el siguiente:

file2:str1
file2:str2
file2:str3
file2:str4

Ahora probemos la función nextfile.

$ awk '{ if ($0 ~ /file1:str2/) nextfile; print $0 }' file1.txt file2.txt

El resultado es:

file1:str1
file2:str1
file2:str2
file2:str3
file2:str4
return Devuelve un valor desde una función definida por el usuario. Tenga en cuenta que si no se especifica un valor de retorno, el valor de retorno no está definido.

Cree el archivo functions.awk, con el siguiente contenido:

function addition(num1, num2)
{
    result = num1 + num2

    return result
}

BEGIN {
    res = addition(10, 20)
    print "10 + 20 = " res
}

Ejecute el archivo:

$ awk -f functions.awk 
10 + 20 = 30
system Ejecuta un comando específico y devuelve su estado de salida. Un valor de retorno de 0 indica que el comando se ejecutó con éxito; distinto de 0 indica que falló. 
$ awk 'BEGIN { ret = system("date"); print "Return value = " ret }'

El resultado es:

Sun Dec 21 23:16:07 IST 2014
Return value = 0
