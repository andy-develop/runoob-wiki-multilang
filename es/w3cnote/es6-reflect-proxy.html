分类 → Categorías ES6 教程 → Tutorial de ES6

概述 → Resumen

Proxy 与 Reflect 是 ES6 为了操作对象引入的 API 。 → Proxy y Reflect son API introducidas por ES6 para operar con objetos.

Proxy 可以对目标对象的读取、函数调用等操作进行拦截，然后进行操作处理。它不直接操作对象，而是像代理模式，通过对象的代理对象进行操作，在进行这些操作时，可以添加一些需要的额外操作。 → Proxy puede interceptar operaciones como la lectura y la invocación de funciones en el objeto objetivo, y luego realizar el procesamiento de la operación. No opera directamente sobre el objeto, sino que, como el patrón proxy, opera a través de un objeto proxy del objeto; al realizar estas operaciones, se pueden añadir algunas operaciones adicionales necesarias.

Reflect 可以用于获取目标对象的行为，它与 Object 类似，但是更易读，为操作对象提供了一种更优雅的方式。它的方法与 Proxy 是对应的。 → Reflect se puede utilizar para obtener el comportamiento del objeto objetivo. Es similar a Object, pero más legible, y proporciona una forma más elegante de operar con objetos. Sus métodos se corresponden con los de Proxy.

基本用法 → Uso básico

Proxy

一个 Proxy 对象由两个部分组成： target 、 handler 。在通过 Proxy 构造函数生成实例对象时，需要提供这两个参数。 target 即目标对象， handler 是一个对象，声明了代理 target 的指定行为。 → Un objeto Proxy consta de dos partes: target y handler. Al generar un objeto de instancia mediante el constructor de Proxy, se deben proporcionar estos dos parámetros. target es el objeto objetivo, y handler es un objeto que declara el comportamiento específico del proxy de target.

let target = { name: 'Tom', age: 24 } let handler = { get: function(target, key) { console.log('getting '+key); return target[key]; //不是target.key → No es target.key }, set: function(target, key, value) { console.log('setting '+key); target[key] = value; } } let proxy = new Proxy(target, handler) proxy.name //实际执行 handler.get → En realidad se ejecuta handler.get proxy.age = 25 //实际执行 handler.set → En realidad se ejecuta handler.set // getting name // setting age // 25 //target 可以为空对象 → target puede ser un objeto vacío let targetEpt = {} let proxyEpt = new Proxy(targetEpt, handler) //调用 get 方法，此时目标对象为空，没有 name 属性 → Se llama al método get; en este momento el objeto objetivo está vacío y no tiene la propiedad name. proxyEpt.name // getting name //调用 set 方法，向目标对象中添加了 name 属性 → Se llama al método set, añadiendo la propiedad name al objeto objetivo. proxyEpt.name = 'Tom' // setting name // "Tom" //再次调用 get ，此时已经存在 name 属性 → Se vuelve a llamar a get; ahora la propiedad name ya existe. proxyEpt.name // getting name // "Tom" //通过构造函数新建实例时其实是对目标对象进行了浅拷贝，因此目标对象与代理对象会互相 → Al crear una nueva instancia mediante el constructor, en realidad se realiza una copia superficial del objeto objetivo, por lo que el objeto objetivo y el objeto proxy se influyen //影响 → mutuamente targetEpt // {name: "Tom"} //handler 对象也可以为空，相当于不设置拦截操作，直接访问目标对象 → El objeto handler también puede estar vacío, lo que equivale a no establecer operaciones de interceptación y acceder directamente al objeto objetivo. let targetEmpty = {} let proxyEmpty = new Proxy(targetEmpty,{}) proxyEmpty.name = "Tom" targetEmpty // {name: "Tom"}

实例方法 → Métodos de instancia

get(target, propKey, receiver)

用于 target 对象上 propKey 的读取操作。 → Se utiliza para la operación de lectura de propKey en el objeto target.

let exam ={ name: "Tom", age: 24 } let proxy = new Proxy(exam, { get(target, propKey, receiver) { console.log('Getting ' + propKey); return target[propKey]; } }) proxy.name // Getting name // "Tom"

get() 方法可以继承。 → El método get() puede heredarse.

let proxy = new Proxy({}, { get(target, propKey, receiver) { //实现私有属性读取保护 → Implementa la protección de lectura de propiedades privadas. if(propKey[0] === '_'){ throw new Erro(`Invalid attempt to get private "${propKey}"`); } console.log('Getting ' + propKey); return target[propKey]; } }); let obj = Object.create(proxy); obj.name // Getting name
set(target, propKey, value, receiver)

用于拦截 target 对象上的 propKey 的赋值操作。如果目标对象自身的某个属性，不可写且不可配置，那么set方法将不起作用。 → Se utiliza para interceptar la operación de asignación de propKey en el objeto target. Si una propiedad propia del objeto objetivo no es escribible ni configurable, el método set no tendrá efecto.

let validator = { set: function(obj, prop, value) { if (prop === 'age') { if (!Number.isInteger(value)) { throw new TypeError('The age is not an integer'); } if (value > 200) { throw new RangeError('The age seems invalid'); } } //对于满足条件的 age 属性以及其他属性，直接保存 → Para la propiedad age y otras propiedades que cumplan las condiciones, se guardan directamente. obj[prop] = value; } }; let proxy= new Proxy({}, validator) proxy.age = 100; proxy.age // 100 proxy.age = 'oppps' //报错 → Error proxy.age = 300 //报错 → Error

第四个参数 receiver 表示原始操作行为所在对象，一般是 Proxy 实例本身。 → El cuarto parámetro receiver representa el objeto donde se encuentra el comportamiento de la operación original, generalmente la propia instancia de Proxy.

const handler = { set: function(obj, prop, value, receiver) { obj[prop] = receiver; } }; const proxy = new Proxy({}, handler); proxy.name= 'Tom'; proxy.name=== proxy // true const exam = {} Object.setPrototypeOf(exam, proxy) exam.name = "Tom" exam.name === exam // true

注意，严格模式下，set代理如果没有返回true，就会报错。 → Nota: en modo estricto, si el proxy set no devuelve true, se producirá un error.

apply(target, ctx, args)

用于拦截函数的调用、call 和 reply 操作。target 表示目标对象，ctx 表示目标对象上下文，args 表示目标对象的参数数组。 → Se utiliza para interceptar las operaciones de invocación de funciones, call y reply. target representa el objeto objetivo, ctx representa el contexto del objeto objetivo y args representa la matriz de argumentos del objeto objetivo.

function sub(a, b){ return a - b; } let handler = { apply: function(target, ctx, args){ console.log('handle apply'); return Reflect.apply(...arguments); } } let proxy = new Proxy(sub, handler) proxy(2, 1) // handle apply // 1
has(target, propKey)

用于拦截 HasProperty 操作，即在判断 target 对象是否存在 propKey 属性时，会被这个方法拦截。此方法不判断一个属性是对象自身的属性，还是继承的属性。 → Se utiliza para interceptar la operación HasProperty, es decir, cuando se determina si la propiedad propKey existe en el objeto target, será interceptada por este método. Este método no distingue si una propiedad es propia del objeto o heredada.

let handler = { has: function(target, propKey){ console.log("handle has"); return propKey in target; } } let exam = {name: "Tom"} let proxy = new Proxy(exam, handler) 'name' in proxy // handle has // true

注意：此方法不拦截 for ... in 循环。 → Nota: este método no intercepta el bucle for ... in.

construct(target, args)

用于拦截 new 命令。返回值必须为对象。 → Se utiliza para interceptar el comando new. El valor de retorno debe ser un objeto.

let handler = { construct: function (target, args, newTarget) { console.log('handle construct') return Reflect.construct(target, args, newTarget) } } class Exam { constructor (name) { this.name = name } } let ExamProxy = new Proxy(Exam, handler) let proxyObj = new ExamProxy('Tom') console.log(proxyObj) // handle construct // exam {name: "Tom"}
deleteProperty(target, propKey)

用于拦截 delete 操作，如果这个方法抛出错误或者返回 false ，propKey 属性就无法被 delete 命令删除。 → Se utiliza para interceptar la operación delete. Si este método lanza un error o devuelve false, la propiedad propKey no podrá ser eliminada por el comando delete.

defineProperty(target, propKey, propDesc)

用于拦截 Object.definePro若目标对象不可扩展，增加目标对象上不存在的属性会报错；若属性不可写或不可配置，则不能改变这些属性。 → Se utiliza para interceptar Object.definePro. Si el objeto objetivo no es extensible, añadir una propiedad que no existe en el objeto objetivo provocará un error; si la propiedad no es escribible ni configurable, no se pueden cambiar estas propiedades.

let handler = { defineProperty: function(target, propKey, propDesc){ console.log("handle defineProperty"); return true; } } let target = {} let proxy = new Proxy(target, handler) proxy.name = "Tom" // handle defineProperty target // {name: "Tom"} //defineProperty 返回值为false，添加属性操作无效 → Si defineProperty devuelve false, la operación de añadir propiedades no es válida. let handler1 = { defineProperty: function(target, propKey, propDesc){ console.log("handle defineProperty"); return false; } } let target1 = {} let proxy1 = new Proxy(target1, handler1) proxy1.name = "Jerry" target1 // {}

getOwnPropertyDescriptor(target, propKey)

用于拦截 Object.getOwnPropertyD() 返回值为属性描述对象或者 undefined 。 → Se utiliza para interceptar Object.getOwnPropertyD(). El valor de retorno es un objeto de descripción de propiedad o undefined.

let handler = { getOwnPropertyDescriptor: function(target, propKey){ return Object.getOwnPropertyDescriptor(target, propKey); } } let target = {name: "Tom"} let proxy = new Proxy(target, handler) Object.getOwnPropertyDescriptor(proxy, 'name') // {value: "Tom", writable: true, enumerable: true, configurable: // true}

getPrototypeOf(target)

主要用于拦截获取对象原型的操作。包括以下操作： → Se utiliza principalmente para interceptar operaciones de obtención del prototipo de un objeto. Incluye las siguientes operaciones:

- Object.prototype._proto_
- Object.prototype.isPrototypeOf()
- Object.getPrototypeOf()
- Reflect.getPrototypeOf()
- instanceof
let exam = {} let proxy = new Proxy({},{ getPrototypeOf: function(target){ return exam; } }) Object.getPrototypeOf(proxy) // {}

注意，返回值必须是对象或者 null ，否则报错。另外，如果目标对象不可扩展（non-extensible），getPrototypeOf 方法必须返回目标对象的原型对象。 → Nota: el valor de retorno debe ser un objeto o null; de lo contrario, se produce un error. Además, si el objeto objetivo no es extensible, el método getPrototypeOf debe devolver el objeto prototipo del objeto objetivo.

let proxy = new Proxy({},{ getPrototypeOf: function(target){ return true; } }) Object.getPrototypeOf(proxy) // TypeError: 'getPrototypeOf' on proxy: trap returned neither object // nor null
isExtensible(target)

用于拦截 Object.isExtensible 操作。 → Se utiliza para interceptar la operación Object.isExtensible.

该方法只能返回布尔值，否则返回值会被自动转为布尔值。 → Este método solo puede devolver un valor booleano; de lo contrario, el valor de retorno se convertirá automáticamente a booleano.

let proxy = new Proxy({},{ isExtensible:function(target){ return true; } }) Object.isExtensible(proxy) // true

注意：它的返回值必须与目标对象的isExtensible属性保持一致，否则会抛出错误。 → Nota: su valor de retorno debe ser coherente con la propiedad isExtensible del objeto objetivo; de lo contrario, se lanzará un error.

let proxy = new Proxy({},{ isExtensible:function(target){ return false; } }) Object.isExtensible(proxy) // TypeError: 'isExtensible' on proxy: trap result does not reflect // extensibility of proxy target (which is 'true')
ownKeys(target)

用于拦截对象自身属性的读取操作。主要包括以下操作： → Se utiliza para interceptar operaciones de lectura de las propiedades propias del objeto. Incluye principalmente las siguientes operaciones:

- Object.getOwnPropertyNames()
- Object.getOwnPropertySymbols()
- Object.keys()
- or...in

方法返回的数组成员，只能是字符串或 Symbol 值，否则会报错。 → Los miembros de la matriz devuelta por el método solo pueden ser cadenas o valores Symbol; de lo contrario, se producirá un error.

若目标对象中含有不可配置的属性，则必须将这些属性在结果中返回，否则就会报错。 → Si el objeto objetivo contiene propiedades no configurables, estas propiedades deben devolverse en el resultado; de lo contrario, se producirá un error.

若目标对象不可扩展，则必须全部返回且只能返回目标对象包含的所有属性，不能包含不存在的属性，否则也会报错。 → Si el objeto objetivo no es extensible, se deben devolver todas y solo las propiedades que contiene el objeto objetivo; no se pueden incluir propiedades inexistentes; de lo contrario, también se producirá un error.

let proxy = new Proxy( { name: "Tom", age: 24 }, { ownKeys(target) { return ['name']; } }); Object.keys(proxy) //[ 'name' ]f返回结果中，三类属性会被过滤： → [ 'name' ]f En el resultado devuelto, se filtran tres tipos de propiedades: //- 目标对象上没有的属性 → - Propiedades que no existen en el objeto objetivo //- 属性名为 Symbol 值的属性 → - Propiedades cuyo nombre es un valor Symbol //- 不可遍历的属性 → - Propiedades no enumerables let target = { name: "Tom", [Symbol.for('age')]: 24, }; //添加不可遍历属性 'gender' → Añadir la propiedad no enumerable 'gender' Object.defineProperty(target, 'gender', { enumerable: false, configurable: true, writable: true, value: 'male' }); let handler = { ownKeys(target) { return ['name', 'parent', Symbol.for('age'), 'gender']; } }; let proxy = new Proxy(target, handler); Object.keys(proxy) // ['name']
preventExtensions(target)

拦截 Object.preventExtensions 操作。 → Interceptar la operación Object.preventExtensions.

该方法必须返回一个布尔值，否则会自动转为布尔值。 → Este método debe devolver un valor booleano; de lo contrario, se convertirá automáticamente a booleano.

//只有目标对象不可扩展时（即 Object.isExtensible(proxy) 为 false ）， → Solo cuando el objeto objetivo no es extensible (es decir, Object.isExtensible(proxy) es false), //proxy.preventExtensions 才能返回 true ，否则会报错 → proxy.preventExtensions puede devolver true; de lo contrario, se producirá un error. var proxy = new Proxy({}, { preventExtensions: function(target) { return true; } }); //由于 proxy.preventExtensions 返回 true，此处也会返回 true，因此会报错 → Dado que proxy.preventExtensions devuelve true, aquí también devolverá true, por lo que se producirá un error. Object.preventExtensions(proxy) 被// TypeError: 'preventExtensions' on proxy: trap returned truish but // the proxy target is extensible //解决方案 → Solución var proxy = new Proxy({}, { preventExtensions: function(target) { //返回前先调用 Object.preventExtensions → Antes de devolver, llamar primero a Object.preventExtensions Object.preventExtensions(target); return true; } }); Object.preventExtensions(proxy) // Proxy {}
setPrototypeOf

主要用来拦截 Object.setPrototypeOf 方法。 → Se utiliza principalmente para interceptar el método Object.setPrototypeOf.

返回值必须为布尔值，否则会被自动转为布尔值。 → El valor de retorno debe ser booleano; de lo contrario, se convertirá automáticamente a booleano.

若目标对象不可扩展，setPrototypeOf 方法不得改变目标对象的原型。 → Si el objeto objetivo no es extensible, el método setPrototypeOf no debe cambiar el prototipo del objeto objetivo.

let proto = {} let proxy = new Proxy(function () {}, { setPrototypeOf: function(target, proto) { console.log("setPrototypeOf"); return true; } } ); Object.setPrototypeOf(proxy, proto); // setPrototypeOf
Proxy.revocable()

用于返回一个可取消的 Proxy 实例。 → Se utiliza para devolver una instancia de Proxy cancelable.

let {proxy, revoke} = Proxy.revocable({}, {}); proxy.name = "Tom"; revoke(); proxy.name // TypeError: Cannot perform 'get' on a proxy that has been revoked

Reflect

ES6 中将 Object 的一些明显属于语言内部的方法移植到了 Reflect 对象上（当前某些方法会同时存在于 Object 和 Reflect 对象上），未来的新方法会只部署在 Reflect 对象上。 → En ES6, algunos métodos de Object que claramente pertenecen a la parte interna del lenguaje se trasladaron al objeto Reflect (actualmente algunos métodos existen tanto en Object como en Reflect), y los nuevos métodos futuros se implementarán solo en el objeto Reflect.

Reflect 对象对某些方法的返回结果进行了修改，使其更合理。 → El objeto Reflect ha modificado los resultados de retorno de algunos métodos para hacerlos más razonables.

Reflect 对象使用函数的方式实现了 Object 的命令式操作。 → El objeto Reflect implementa las operaciones imperativas de Object mediante funciones.

静态方法 → Métodos estáticos

Reflect.get(target, name, receiver)

查找并返回 target 对象的 name 属性。 → Busca y devuelve la propiedad name del objeto target.

let exam = { name: "Tom", age: 24, get info(){ return this.name + this.age; } } Reflect.get(exam, 'name'); // "Tom" //当 target 对象中存在 name 属性的 getter 方法， getter 方法的 this 会绑定 // receiver → Cuando en el objeto target existe un método getter para la propiedad name, el this del método getter se vinculará a // receiver let receiver = { name: "Jerry", age: 20 } Reflect.get(exam, 'info', receiver); // Jerry20 //当 name 为不存在于 target 对象的属性时，返回 undefined → Cuando name es una propiedad que no existe en el objeto target, devuelve undefined. Reflect.get(exam, 'birth'); // undefined //当 target 不是对象时，会报错 → Cuando target no es un objeto, se producirá un error. Reflect.get(1, 'name'); // TypeError
Reflect.set(target, name, value, receiver)

将 target 的 name 属性设置为 value。返回值为 boolean ，true 表示修改成功，false 表示失败。当 target 为不存在的对象时，会报错。 → Establece la propiedad name de target como value. El valor de retorno es boolean; true indica que la modificación fue exitosa, false indica fallo. Cuando target no es un objeto, se producirá un error.

let exam = { name: "Tom", age: 24, set info(value){ return this.age = value; } } exam.age; // 24 Reflect.set(exam, 'age', 25); // true exam.age; // 25 //value 为空时会将 name 属性清除 → Cuando value está vacío, la propiedad name se eliminará. Reflect.set(exam, 'age', ); // true exam.age; // undefined //当 target 对象中存在 name 属性 setter 方法时，setter 方法中的 this 会绑定 // receiver , 所以修改的实际上是 receiver 的属性, → Cuando en el objeto target existe un método setter para la propiedad name, el this del método setter se vinculará a // receiver, por lo que lo que se modifica en realidad es la propiedad de receiver, let receiver = { age: 18 } Reflect.set(exam, 'info', 1, receiver); // true receiver.age; // 1 let receiver1 = { name: 'oppps' } Reflect.set(exam, 'info', 1, receiver1); receiver1.age; // 1
Reflect.has(obj, name)

是 name in obj 指令的函数化，用于查找 name 属性在 obj 对象中是否存在。返回值为 boolean。如果 obj 不是对象则会报错 TypeError。 → Es la versión funcional de la instrucción name in obj; se utiliza para comprobar si la propiedad name existe en el objeto obj. El valor de retorno es boolean. Si obj no es un objeto, se lanzará un error TypeError.

let exam = { name: "Tom", age: 24 } Reflect.has(exam, 'name'); // true
Reflect.deleteProperty(obj, property)

是 delete obj[property] 的函数化，用于删除 obj 对象的 property 属性，返回值为 boolean。如果 obj 不是对象则会报错 TypeError。 → Es la versión funcional de delete obj[property]; se utiliza para eliminar la propiedad property del objeto obj. El valor de retorno es boolean. Si obj no es un objeto, se lanzará un error TypeError.

let exam = { name: "Tom", age: 24 } Reflect.deleteProperty(exam , 'name'); // true exam // {age: 24} //property 不存在时，也会返回 true → Cuando property no existe, también devolverá true. Reflect.deleteProperty(exam , 'name'); // true
Reflect.construct(obj, args)

等同于 new target(...args)。 → Equivale a new target(...args).

function exam(name){ this.name = name; } Reflect.construct(exam, ['Tom']); // exam {name: "Tom"}
Reflect.getPrototypeOf(obj)

用于读取 obj 的 _proto_ 属性。在 obj 不是对象时不会像 Object 一样把 obj 转为对象，而是会报错。 → Se utiliza para leer la propiedad _proto_ de obj. Cuando obj no es un objeto, a diferencia de Object, no convertirá obj en objeto, sino que se producirá un error.

用于设置目标对象的 prototype。 → Se utiliza para establecer el prototype del objeto objetivo.

Reflect.apply(func, thisArg, args)

Equivalente a Function.prototype.apply.call(func, thisArg, args). func representa la función objetivo; thisArg representa el objeto this al que está vinculada la función objetivo; args representa la lista de parámetros pasados al llamar a la función objetivo, que puede ser un array o un objeto similar a un array. Si la función objetivo no se puede invocar, se lanzará un TypeError.

Se utiliza para definir propiedades en el objeto objetivo. Si target no es un objeto, se lanzará un error.

Se utiliza para obtener el objeto descriptor de la propiedad propertyKey del objeto target. Cuando target no es un objeto, se lanzará un error indicando que el parámetro no es válido, y no se convertirá el no-objeto en un objeto.

Reflect.ownKeys(target)

Se utiliza para devolver todas las propiedades del objeto target, equivalente a la suma de Object.getOwnPropertyNames y Object.getOwnPropertySymbols.

组合使用 → Uso combinado

Los métodos del objeto Reflect se corresponden uno a uno con los métodos del objeto Proxy. Por lo tanto, los métodos del objeto Proxy pueden obtener el comportamiento predeterminado llamando a los métodos del objeto Reflect y luego realizar operaciones adicionales.

let exam = { name: "Tom", age: 24 } let handler = { get: function(target, key){ console.log("getting "+key); return Reflect.get(target,key); }, set: function(target, key, value){ console.log("setting "+key+" to "+value) Reflect.set(target, key, value); } } let proxy = new Proxy(exam, handler) proxy.name = "Jerry" proxy.name // setting name to Jerry // getting name // "Jerry"
