Algoritmo de ajuste por interpolación promedio lineal basado en vértices

Categoría Tecnología de programación

Recientemente usé Matlab para hacer experimentos de simulación con datos tridimensionales de diversos modelos. Muchos de ellos requieren ajuste de datos tridimensionales. Matlab trae un toolbox de ajuste (cftool) que es realmente potente. Usar el toolbox para el ajuste de datos ahorra mucho trabajo. Para modelos originales con conjuntos de datos suficientes, cftool puede ajustar con precisión los resultados que queremos. Por supuesto, no hablamos de Matlab; este artículo no tiene nada que ver con Matlab en absoluto. ~~He hablado demasiado, comencemos.
