Uso de rand y srand en C++

Categoría Tecnología de programación

Los números aleatorios de una computadora son todos pseudoaleatorios, es decir, son generados por una secuencia polinómica M pequeña, donde cada secuencia pequeña tiene un valor inicial, que es la semilla aleatoria. (Nota: el período de la secuencia polinómica M pequeña es 65535, es decir, el período de los números aleatorios generados con cada semilla aleatoria es 65535; cuando obtienes 65535 números aleatorios, aparecen repetidos de nuevo).

Sabemos que la función rand() se puede usar para generar números aleatorios, pero no son números aleatorios en el sentido real, son números pseudoaleatorios, que se calculan a partir de un número (podemos llamarlo semilla) como base mediante una fórmula recursiva. Cuando esta serie de números es muy grande, se ajusta a la distribución normal, lo que equivale a generar números aleatorios, pero no son números verdaderamente aleatorios. Cuando la computadora se enciende normalmente, el valor de esta semilla está fijado, a menos que se dañe el sistema.

1.rand()

Función:

Generador de números aleatorios

Uso:

int rand(void)

Archivo de cabecera donde se encuentra:

stdlib.h

La implementación interna de rand() se basa en el método de congruencia lineal. No es un número verdaderamente aleatorio, pero debido a que su período es especialmente largo, puede considerarse aleatorio dentro de cierto rango.

rand() devuelve un valor aleatorio en el rango de 0 a RAND_MAX. El alcance de RAND_MAX es al menos 32767 (int). Con unsigned int de doble byte es 65535, y de cuatro bytes es el rango entero de 4294967295. La probabilidad de que cada número de 0~RAND_MAX sea seleccionado es la misma.

Cuando el usuario no establece la semilla aleatoria, la semilla aleatoria predeterminada del sistema es 1.

rand() genera números pseudoaleatorios que son los mismos en cada ejecución; si se desea que sean diferentes, use la función srand() para inicializarla.

2.srand()

Función:

Inicializar el generador de números aleatorios

Uso:

void srand(unsigned int seed)

Archivo de cabecera donde se encuentra:

stdlib.h

srand() se usa para establecer la semilla aleatoria cuando rand() genera números aleatorios. El parámetro seed debe ser un entero. Si cada vez se establece el mismo valor de seed, los valores aleatorios generados por rand() serán los mismos cada vez.

3. Usar el reloj actual como semilla de números aleatorios

Los números aleatorios generados por rand() son los mismos en cada ejecución en comparación con la ejecución anterior. Si se desea que sean diferentes, use la función srand() para inicializarla. Se puede usar el método srand((unsigned int)(time(NULL)) para generar diferentes semillas aleatorias, porque el tiempo de ejecución del programa es diferente cada vez.

4. Uso para generar números aleatorios

  • 1) Proporcione una semilla a srand(), que sea de tipo unsigned int;
  • 2) Llame a rand(), que devolverá un número aleatorio (entre 0 y RAND_MAX) según el valor de la semilla proporcionado a srand();
  • 3) Llame a rand() varias veces según sea necesario, obteniendo así nuevos números aleatorios de forma continua;
  • 4) En cualquier momento, puede proporcionar una nueva semilla a srand(), para "aleatorizar" aún más el resultado de salida de rand().

Programa de números aleatorios entre 0 y RAND_MAX

#include <iostream>
#include <stdlib.h>
#include <time.h> 

using namespace std; 

int main()
{ 
        srand((unsigned)time(NULL)); 
        for(int i = 0; i < 10;i++ ) 
                cout << rand() << '/t';
        cout << endl; 
        return 0;
}

5. Fórmula general para generar números aleatorios en un rango determinado

Para obtener un entero aleatorio en [a,b), use (rand() % (b-a))+ a;

Para obtener un entero aleatorio en [a,b], use (rand() % (b-a+1))+ a;

Para obtener un entero aleatorio en (a,b], use (rand() % (b-a))+ a + 1;

Fórmula general: a + rand() % n; donde a es el valor inicial y n es el rango de enteros.

Para obtener un entero aleatorio entre a y b, otra representación: a + (int)b * rand() / (RAND_MAX + 1).

Para obtener un número de punto flotante entre 0 y 1, puede usar rand() / double(RAND_MAX).
