Resumen del uso de la función print de Python3

Categoría Tecnología de programación

1. Salida de cadenas y números

>>>print("runoob") # Salida de cadena runoob >>> print(100) # Salida de número 100 >>> str = 'runoob' >>> print(str) # Salida de variable runoob >>> L = [1,2,'a'] # Lista >>> print(L) [1, 2, 'a'] >>> t = (1,2,'a') # Tupla >>> print(t) (1, 2, 'a') >>> d = {'a':1, 'b':2} # Diccionario >>> print(d) {'a': 1, 'b': 2}

2. Salida formateada de enteros

Admite formato de parámetros, similar a printf en C

>>>str = "the length of (%s) is %d" %('runoob',len('runoob')) >>> print(str) the length of (runoob) is 6

Símbolos de formato de cadenas de Python:

Símbolo Descripción
      %cCarácter formateado y su código ASCII
      %sCadena formateada
      %dEntero formateado
      %uEntero sin signo formateado
      %oNúmero octal sin signo formateado
      %xNúmero hexadecimal sin signo formateado
      %XNúmero hexadecimal sin signo formateado (mayúsculas)
      %fFormatea números flotantes, se puede especificar la precisión después del punto decimal
      %eFormatea números flotantes con notación científica
      %EIgual que %e, formatea números flotantes con notación científica
      %gAbreviatura de %f y %e
      %GAbreviatura de %f y %E
      %pFormatea la dirección de una variable en hexadecimal

Instrucciones auxiliares del operador de formato:

+Muestra un signo más (+) delante de los números positivos
<sp>Muestra un espacio delante de los números positivos
#Muestra cero ('0') delante de números octales, y '0x' o '0X' delante de hexadecimales (dependiendo de si se usa 'x' o 'X')

3. Salida formateada de enteros en hexadecimal, decimal y octal

#%x--- hex hexadecimal

#%d--- dec decimal

#%o--- oct octal

>>>nHex = 0xFF >>> print("nHex = %x,nDec = %d,nOct = %o" %(nHex,nHex,nHex)) nHex = ff,nDec = 255,nOct = 377

4. Salida formateada de números flotantes (float)

>>>pi = 3.141592653 >>> print('%10.3f' % pi) # Ancho de campo 10, precisión 3 3.142 >>> print("pi = %.*f" % (3,pi)) # Usa * para leer el ancho de campo o la precisión desde la tupla posterior pi = 3.142 >>> print('%010.3f' % pi) # Rellena los espacios en blanco con 0 000003.142 >>> print('%-10.3f' % pi) # Alinear a la izquierda 3.142 >>> print('%+f' % pi) # Muestra el signo positivo y negativo +3.141593

5. Salto de línea automático

print agrega automáticamente un retorno de carro al final de la línea; si no se necesita retorno, solo agrega una coma al final de la declaración print,y configura el parámetro separador end, para cambiar su comportamiento.
>>>for i in range(0,6): ... print(i) ... 0 1 2 3 4 5 >>> for i in range(0,6): ... print(i, end=" ") ... 0 1 2 3 4 5

6. print sin salto de línea

En Python, print salta de línea por defecto:

>>>for i in range(0,3): ... print (i) ... 0 1 2 >>>

Para evitar el salto de línea, debes escribirprint(i, end = '' )

>>>for i in range(0,3): ... print(i, end = '' ) ... 012
