Uso de printf para salida formateada en Java

Categoría Tecnología de programación

El método printf en Java se utiliza para dar formato a la salida.

El formato especifica la forma de la salida, incluida la precisión de los números, el ancho de los caracteres, el formato de fecha, etc. A continuación se muestran algunos símbolos de formato y usos comunes:

Formato de cadenas

  • %s : Salida de una cadena

Ejemplo

System.out.printf("%s", "hello world"); // Salida "hello world"

Formato de enteros

  • %d : Salida de un entero decimal
  • %o : Salida de un entero octal
  • %x : Salida de un entero hexadecimal
  • %X : Salida de un entero hexadecimal en mayúsculas

Ejemplo

System.out.printf("%d %o %x %X", 10, 10, 10, 10); // Salida "10 12 a A"

Formato de números de punto flotante

  • %f : Salida de un número de punto flotante
  • %e : Salida de un número de punto flotante en notación científica (e minúscula)
  • %E : Salida de un número de punto flotante en notación científica (E mayúscula)
  • %.nf : Controla el número de dígitos después del punto decimal, n es un número

Ejemplo

System.out.printf("%.2f %e %E", 3.1415926, 3.1415926, 3.1415926); // Salida "3.14 3.141593e+00 3.141593E+00"

Formato de valores booleanos

  • %b : Salida de un valor booleano

Ejemplo

System.out.printf("%b", true); // Salida "true"

Formato de caracteres

  • %c : Salida de un carácter

Ejemplo

System.out.printf("%c", 'a'); // Salida "a"

Formato de ancho y precisión

  • %n$ : Especifica el enésimo parámetro
  • %m.n : Controla el ancho y la precisión, m representa el ancho mínimo, n representa el número de dígitos después del punto decimal.

Ejemplo

System.out.printf("%2d %5.2f %s", 10, 3.1415926, "hello"); // Salida "10 3.14 hello"

La siguiente es una lista completa de los símbolos de formato disponibles en el método printf de Java:

  • %d: entero decimal con signo
  • %o: entero octal sin signo
  • %x, %X: enteros hexadecimales sin signo, representados con letras minúsculas y mayúsculas respectivamente.
  • %f, %F: números de punto flotante decimales con punto decimal, representados con letras minúsculas y mayúsculas respectivamente.
  • %e, %E: números de punto flotante con exponente, representados con letras minúsculas y mayúsculas respectivamente.
  • %g, %G: selecciona automáticamente el formato %f o %e según el tamaño del valor, representado con letras minúsculas y mayúsculas respectivamente.
  • %a, %A: números de punto flotante hexadecimales, representados con letras minúsculas y mayúsculas respectivamente.
  • %c: tipo carácter, imprime un solo carácter.
  • %s: tipo cadena, imprime una cadena.
  • %n: salto de línea.
  • %%: imprime un signo de porcentaje %.
  • %h, %H: código hash, representado en hexadecimal y hexadecimal en mayúsculas respectivamente.
  • %t, %T: formato de fecha y hora, utilizando caracteres de conversión específicos; por ejemplo, %tY representa el año, %tB representa el nombre completo del mes.
  • %b, %B: tipo booleano, imprime true o false, representado con letras minúsculas y mayúsculas respectivamente.
  • %S: imprime una cadena en letras mayúsculas.

La siguiente es una lista de símbolos que se pueden usar para formatear fechas en el método printf de Java:

  • %tB: nombre completo del mes localizado.
  • %tb: abreviatura del mes localizada.
  • %tA: nombre completo del día de la semana localizado.
  • %ta: abreviatura del día de la semana localizada.
  • %tY: año de cuatro dígitos.
  • %ty: año de dos dígitos.
  • %tm: mes de dos dígitos.
  • %td: día del mes de dos dígitos.
  • %te: día del mes de uno o dos dígitos.
  • %tH: hora en formato de 24 horas.
  • %tI: hora en formato de 12 horas.
  • %tM: minutos.
  • %tS: segundos.
  • %tp: a.m. o p.m.
  • %tZ: zona horaria.

System.out.printf("%s", new Integer(1212)); //%n indica un salto de línea. System.out.printf("%s%n", "end line"); //También puede soportar múltiples parámetros. System.out.printf("%s = %s%n", "Name", "Zhangsan"); //%S imprime la cadena en mayúsculas. System.out.printf("%S = %s%n", "Name", "Zhangsan"); //Cuando admite múltiples parámetros, puede insertar el número de variable entre %s; 1$ indica la primera cadena, 3$ indica la tercera cadena. System.out.printf("%1$s = %3$s %2$s%n", "Name", "san", "Zhang"); /*** Salida del tipo boolean ***/ System.out.printf("true = %b; false = ", true); System.out.printf("%b%n", false); /*** Salida del tipo entero ***/ Integer iObj = 342; //%d indica formatear el entero como un entero decimal. System.out.printf("%1$tY-%1$tB-%1$td; %2$tY-%2$tb-%2$td%n", date, dataL); //A continuación se muestran combinaciones de fechas comunes. //Después de %t, D indica formatear la fecha como "%tm/%td/%ty". System.out.printf("%1$tD%n", date); //Después de %t, F indica formatear la fecha como "%tY-%tm-%td". System.out.printf("%1$tF%n", date); /*** Salida del tipo de hora ***/ //Salida de horas, minutos y segundos. //Después de %t, H indica la hora de salida (formato de 24 horas); después de %t, I indica la hora de salida (formato de 12 horas). //Después de %t, M indica los minutos de salida; después de %t, S indica los segundos de salida. System.out.printf("%1$tH:%1$tM:%1$tS %1$tL%n", date); //Después de %t, p indica la información de a.m. o p.m. de la hora de salida. System.out.printf("%1$tH:%1$tM:%1$tS %1$tL %1$tp%n", date); //A continuación se muestran combinaciones de hora comunes. //Después de %t, R indica formatear la hora como "%tH:%tM". System.out.printf("%1$tR%n", date); //Después de %t, T indica formatear la hora como "%tH:%tM:%tS". System.out.printf("%1$tT%n", date); //Después de %t, r indica formatear la hora como "%tI:%tM:%tS %Tp". System.out.printf("%1$tr%n", date); /*** Salida del día de la semana ***/ //Después de %t, A indica obtener el nombre completo del día de la semana. System.out.printf("%1$tF %1$tA%n", date); //Después de %t, a indica obtener la abreviatura del día de la semana. System.out.printf("%1$tF %1$ta%n", date); //Salida de la información completa de fecha y hora. System.out.printf("%1$tc%n", date); } } /** *En el método printf, el formato "%s" indica la salida, en forma de cadena, del primer valor del segundo parámetro de longitud variable; *el formato "%n" indica un salto de línea; el formato "%S" indica la salida de la cadena en mayúsculas; entre "%s" se usa "n$" para indicar *la salida del enésimo valor del parámetro de longitud variable. El formato "%b" indica la salida, en forma de valor booleano, del primer valor *del segundo parámetro de longitud variable.*/ /** * El formato "%d" indica la salida en forma de entero decimal; "%o" indica la salida en forma octal; "%x" indica la salida en hexadecimal; * "%X" indica la salida en hexadecimal y convierte las letras (A, B, C, D, E, F) a mayúsculas. Después de "%t", D * indica la salida de la fecha en el formato "%tm/%td/%ty", y F indica la salida de la fecha en el formato "%tY-%tm-%td".*/ /** * Después de "%t", use H para indicar la hora de salida en formato de 24 horas, I para indicar la hora de salida en formato de 12 horas, M para indicar los minutos * de salida, S para indicar los segundos de salida, L para indicar los milisegundos en los segundos de salida, y p para indicar si la hora de salida es AM o * PM. Después de "%t", use R para indicar el tiempo en formato "%tH:%tM", use T para indicar el tiempo en formato * "%tH:%tM:%tS", y use r para indicar el tiempo en formato "%tI:%tM:%tS %Tp".*/ /** * Después de "%t", use A para indicar el nombre completo de la fecha, y use a para indicar la abreviatura del día de la semana de la fecha.*/
