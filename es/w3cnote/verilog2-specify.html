3.2 Bloque specify de Verilog

Categoría Tutorial de Verilog: nivel avanzado

Palabras clave: specify, retardo de ruta

El retardo de ruta se describe con las palabras clave specify y endspecify, y entre estas palabras clave se forma un bloque specify.

specify es una parte independiente dentro del módulo y no puede aparecer en otros bloques de declaración (initial, always, etc.).

El bloque specify tiene principalmente las siguientes funciones:

  • Especificar el retardo de pin a pin en todas las rutas;
  • Definir constantes specparam;
  • Establecer comprobaciones de temporización en el circuito.

Conexión paralela

Cada ruta tiene un pin de origen y un pin de destino. Describir los retardos de estas rutas una por una con declaraciones specify se denomina conexión paralela.

El formato de uso de la conexión paralela es el siguiente:

(<source_io> => <destination_io>) = <delay_value> ;

Un módulo lógico AND de 4 entradas con retardo de ruta se describe de la siguiente manera:

Ejemplo

module and4(
   output       out,
   input        a, b, c, d);

   specify
      (a => out) = 2.5 ;
      (b => out) = 2.5 ;
      (c => out) = 3.5 ;
      (d => out) = 3.5 ;
   endspecify

   wire         an1, an2 ;
   and          (an1, a, b);
   and          (an2, c, d);
   and          (out, an1, an2);
endmodule

Se puede usar la palabra clave specparam para definir constantes de valor de retardo dentro del bloque specify y luego asignarlas al retardo de ruta.

Las constantes definidas con specparam solo se pueden usar dentro del bloque specify.

Ejemplo

   specify
      specparam ab_2_out = 2.5 ;
      specparam cd_2_out = 3.5 ;
     
      (a => out) = ab_2_out ;
      (b => out) = ab_2_out ;
      (c => out) = cd_2_out ;
      (d => out) = cd_2_out ;
   endspecify

En la conexión paralela, los pines de origen y destino se corresponden uno a uno. La conexión paralela también admite la descripción del retardo de ruta entre señales de múltiples bits, pero los anchos de bits deben mantenerse consistentes.

Ejemplo

module paral_conn(
    input [3:0]         d,
    output [3:0]        q);

   specify
      (d => q) = 3 ;
   endspecify

   assign q = d & 0101 ;
endmodule

Aquí, el bloque specify también se puede describir de forma expandida; ambas formas de expresión son equivalentes.

Ejemplo

   specify
      (d[0] => q[0]) = 3 ;
      (d[1] => q[1]) = 3 ;
      (d[2] => q[2]) = 3 ;
      (d[3] => q[3]) = 3 ;
   endspecify

Conexión completa

En la conexión completa, cada bit del pin de origen se conecta con cada bit del pin de destino.

La conexión entre los pines de origen y destino es un recorrido combinatorio, y no se requiere que los anchos de bits coincidan.

El formato de uso de la conexión completa es el siguiente:

(<multiple_source_io> *> <multiple_destination_io>) = <delay_value> ;

Por ejemplo, un módulo lógico AND de 4 entradas se puede describir de la siguiente manera:

Ejemplo

module and4(
   output       out,
   input        a, b, c, d);

   specify
      (a,b *> out) = 2.5 ;
      (c,d *> out) = 3.5 ;
   endspecify

   wire         an1, an2 ;
   and          (an1, a, b);
   and          (an2, c, d);
   and          (out, an1, an2);
endmodule

Ruta sensible al flanco

La ruta sensible al flanco se utiliza para el modelado de temporización de retardos de entrada a salida, y usa identificadores de flanco para indicar la condición de disparo. Si no se indica, cualquier cambio activará un cambio en el valor de retardo del pin de origen al pin de destino.

A continuación se muestran ejemplos de uso:

Ejemplo

    //En el flanco de subida de clk, el retardo de subida de la ruta de clk a out es 1, y el retardo de bajada es 2
    //La ruta de datos de in a out es no inversora, es decir, out = in
    (posedge clk => (out +: in)) = (1,2);
   
    //En el flanco de bajada de clk, el retardo de subida de la ruta de clk a out es 1, y el retardo de bajada es 2
    //La ruta de datos de in a out es inversora, es decir, out = ~in
    (negedge clk => (out -: in)) = (1,2);
   
    //Cuando clk cambia de cualquier manera, el retardo de subida de la ruta de clk a out es 1, y el retardo de bajada es 2
    //La ruta de datos de in a out es impredecible, no inversora, inversora o sin cambios
    (negedge clk => (out : in)) = (1,2);

Ruta condicional

Verilog también permite que, en el modelo, se asignen condicionalmente diferentes retardos de ruta según los diferentes valores de las señales.

Los operandos en la condición pueden ser escalares o vectores, y la expresión condicional también puede contener cualquier operador.

Cabe señalar que solo se debe usar la declaración if para declarar de forma completa todos los estados de entrada en la ruta condicional. Las rutas no declaradas usarán el retardo distribuido; si el retardo distribuido tampoco se declara, se usará retardo cero. Si se declaran tanto el retardo de ruta como el retardo distribuido, se seleccionará el mayor retardo como retardo de ruta.

Sin embargo, la declaración if dentro de specify no puede usar la estructura else; se puede usar ifnone para describir el retardo de ruta cuando la condición no se cumple (por defecto).

Ejemplo

   specify
      if (a)    (a => out) = 2.5 ;
      if (~a)   (a => out) = 1.5 ;

      if (b & c)        (b => out) = 2.5 ;
      if (!(b & c))     (b => out) = 1.5 ;

      if ({c, d} == 2'b01)
                (c,d *> out) = 3.5 ;
      ifnone    (c,d *> out) = 3 ;
   endspecify

Ruta de retardo de puerta

Los valores del retardo de puerta (retardo de subida, retardo de bajada, retardo de apagado) también se pueden describir mediante el método de retardo de ruta.

El número de rutas de retardo que se pueden definir es 1, 2, 3, 6 o 12; cualquier otra cantidad de valores de retardo es incorrecta.

A continuación se muestran ejemplos para explicar el método de representación del retardo de ruta en el modelo de retardo de puerta.

Ejemplo

   //1 parámetro: los retardos de subida, bajada y apagado usan solo un parámetro de retardo
   specify
      specparam t_delay = 1.5 ;
      (clk => q) = t_delay ;
   endspecify

   //2 parámetros: retardo de subida (0->1, z->1, 0->z) = 1.5
   // retardo de bajada (1->0, z->0, 1->z) = 2
   specify
      specparam t_rise = 1.5, t_fall = 2 ;
      (clk => q) = (t_rise, t_fall) ;
   endspecify
 
   //3 parámetros: retardo de subida (0->1, z->1) = 1.5
   // retardo de bajada (1->0, z->0) = 2
   // retardo de apagado (1->z, 0->z) = 1.8
   specify
      specparam t_rise = 1.5, t_fall = 2, t_turnoff = 1.8 ;
      (clk => q) = (t_rise, t_fall, t_turnoff);
   endspecify

   //6 parámetros: corresponden respectivamente a 0->1, 1->0, 0->z, z->1, 1->z, z->0
   specify
      specparam t_01 = 1.5, t_10 = 2,   t_0z = 1.8 ;
      specparam t_z1 = 2,   t_1z = 2.2, t_z0 = 2.1 ;
      (clk => q) = (t_01, t_10, t_0z, t_z1, t_1z, t_z0) ;
   endspecify

   //12 parámetros: corresponden respectivamente a 0->1, 1->0, 0->z, z->1, 1->z, z->0
   //                 0->x, x->1, 1->x, x->0, x->z, z->x
   specify
      specparam t_01 = 1.5, t_10 = 2,   t_0z = 1.8 ;
      specparam t_z1 = 2,   t_1z = 2.2, t_z0 = 2.1 ;
      specparam t_0x = 1.1, t_x1 = 1.2, t_1x = 2.1 ;
      specparam t_x0 = 2,   t_xz = 2  , t_zx = 2.1 ;

      (clk => q) = (t_01, t_10, t_0z, t_z1, t_1z, t_z0,
                    t_0x, t_x1, t_1x, t_x0, t_xz, t_zx) ;
   endspecify

En el modelo de retardo de ruta de puerta, también se pueden especificar los valores máximo, mínimo y típico.

Ejemplo

   //Valores de retardo de subida, bajada y apagado: min: typical: max
   specify
      specparam t_rise    = 1:1.5:1.8;
      specparam t_fall    = 1:1.8:2 ;
      specparam t_turnoff = 1.1:1.2:1.3 ;
      (clk => q) = (t_rise, t_fall, t_turnoff);
   endspecify

Retardo de transmisión de X

Si no se especifica el retardo del tiempo de transición de x (cuando no se proporcionan los 12 parámetros de retardo en el retardo de ruta de puerta), se establece que:

  • El retardo para la transición de x a un estado conocido es el tiempo de retardo máximo que pueda ser necesario;
  • El retardo para la transición de un estado conocido a x es el tiempo de retardo mínimo que pueda ser necesario.

Por ejemplo, cuando se proporcionan 6 parámetros de retardo en el retardo de ruta de puerta, el tiempo de retardo de transmisión de x se define como se muestra en la siguiente tabla:

Transición de xValor de retardo
0->xmin(t_01, t_0z)
1->xmin(t_10, t_1z)
z->xmin(t_z1, t_z0)
  
x->0max(t_10, t_z0)
x->1max(t_01, t_z1)
x->zmax(t_1z, t_0z)
