  • Idea básica:Se comparan dos números; el número mayor se hunde, el número menor sube (burbujea).

  • Proceso:

    • Compare dos datos adyacentes; si el segundo número es más pequeño, intercambie posiciones.
    • Compare por pares de atrás hacia adelante, hasta comparar los dos primeros datos. Finalmente, el número más pequeño se intercambia a la posición inicial, así queda ordenada la posición del primer número más pequeño.
    • Continúe repitiendo el proceso anterior, ordenando sucesivamente las posiciones del 2.º, 3.º ... hasta el (n-1)º número más pequeño.

      Ordenamiento de burbuja

  • Complejidad de tiempo promedio:O(n2)

  • Implementación en código Java:

    Ejemplo

    public static void BubbleSort(int [] arr){

         int temp;//variable temporal
         for(int i=0; i<arr.length-1; i++){   //Representa el número de pasadas, en total arr.length-1 veces.
             for(int j=arr.length-1; j>i; j--){

                 if(arr[j] < arr[j-1]){
                     temp = arr[j];
                     arr[j] = arr[j-1];
                     arr[j-1] = temp;
                 }
             }
         }
     }

  • Optimización:

    • Problema:
      Una vez que los datos están en orden, el algoritmo de burbuja todavía continúa con la siguiente ronda de comparaciones hasta arr.length-1 veces; las comparaciones posteriores no tienen sentido.

    • Solución:
      Establezca un indicador (flag); si se produce un intercambio, flag se establece en true; si no hay intercambio, se establece en false.
      De esta manera, cuando termina una ronda de comparaciones, si flag sigue siendo false, es decir, no hubo intercambios en esta ronda, significa que los datos ya están ordenados y no es necesario continuar.

      son todos mayores que él. Por lo tanto, basta con repetir los pasos anteriores en los dos subintervalos a[0...4] y a[6...9].

      public static void BubbleSort1(int [] arr){

         int temp;//variable temporal
         boolean flag;//indicador de si hay intercambio
         for(int i=0; i<arr.length-1; i++){   //representa el número de pasadas, en total arr.length-1 veces

             //Cada vez que se recorre, el indicador debe establecerse primero en false para poder determinar si los elementos posteriores han sufrido un intercambio.
             flag = false;
             
             for(int j=arr.length-1; j>i; j--){ //Seleccione el valor máximo de esta pasada y muévalo hacia atrás.

                 if(arr[j] < arr[j-1]){
                     temp = arr[j];
                     arr[j] = arr[j-1];
                     arr[j-1] = temp;
                     flag = true;    //Si ocurre un intercambio, flag se establece en true.
                 }
             }
             //Compruebe si el indicador es false; si es false, significa que los elementos posteriores ya están ordenados, y se retorna directamente.
             if(!flag) break;
         }
      }

2. Ordenamiento por selección (SelctionSort)

  • Idea básica:
    En un arreglo desordenado de longitud N, en la primera pasada se recorren n-1 números, se encuentra el valor mínimo y se intercambia con el primer elemento;
    En la segunda pasada se recorren n-2 números, se encuentra el valor mínimo y se intercambia con el segundo elemento;
    。。。
    En la pasada n-1, se encuentra el valor mínimo y se intercambia con el elemento n-1, completando el ordenamiento.

  • Proceso:

    Ordenamiento por selección

  • Complejidad de tiempo promedio:O(n2)

  • Implementación en código Java:

    Ejemplo

    public static void select_sort(int array[],int lenth){

       for(int i=0;i<lenth-1;i++){

           int minIndex = i;
           for(int j=i+1;j<lenth;j++){
              if(array[j]<array[minIndex]){
                  minIndex = j;
              }
           }
           if(minIndex != i){
               int temp = array[i];
               array[i] = array[minIndex];
               array[minIndex] = temp;
           }
       }
    }

4. Ordenamiento Shell (Shell Sort)

  • Prefacio:
    Secuencia de datos 1: 13-17-20-42-28. Usando ordenamiento por inserción, 13-17-20-28-42. Number of swap:1;
    Secuencia de datos 2: 13-17-20-42-14. Usando ordenamiento por inserción, 13-14-17-20-42. Number of swap:3;
    Si la secuencia de datos está casi ordenada, usar el ordenamiento por inserción es más eficiente.

  • Idea básica:
    En un conjunto de números a ordenar, se divide en varias subsecuencias según un cierto incremento, y se aplica ordenamiento por inserción a cada subsecuencia.
    Luego se reduce gradualmente el incremento y se repite el proceso anterior. Hasta que el incremento sea 1, en ese momento la secuencia de datos está casi ordenada, y finalmente se realiza el ordenamiento por inserción.

  • Proceso:

    Ordenamiento Shell

  • Complejidad de tiempo promedio:

  • Implementación en código Java:

    Ejemplo

    public static void shell_sort(int array[],int lenth){

       int temp = 0;
       int incre = lenth;

       while(true){
           incre = incre/2;

           for(int k = 0;k<incre;k++){    //Dividir en varias subsecuencias según el incremento

               for(int i=k+incre;i<lenth;i+=incre){

                   for(int j=i;j>k;j-=incre){
                       if(array[j]<array[j-incre]){
                           temp = array[j-incre];
                           array[j-incre] = array[j];
                           array[j] = temp;
                       }else{
                           break;
                       }
                   }
               }
           }

           if(incre == 1){
               break;
           }
       }
    }

5. Ordenamiento rápido (Quicksort)

  • Idea básica: (divide y vencerás)

    • Primero tome un número de la secuencia como valor clave (key);
    • Coloque todos los números menores que este número a su izquierda, y todos los números mayores o iguales a su derecha;
    • Repita el segundo paso en las dos subsecuencias izquierda y derecha, hasta que cada intervalo tenga solo 1 número.

  • Complejidad de tiempo promedio:O(N*logN)

  • Implementación en código:

    Ejemplo

    public static void quickSort(int a[],int l,int r){
         if(l>=r)
           return;

         int i = l; int j = r; int key = a[l];//Seleccionar el primer número como key

         while(i<j){

             while(i<j && a[j]>=key)//Buscar de derecha a izquierda el primer valor menor que key
                 j--;
             if(i<j){
                 a[i] = a[j];
                 i++;
             }

             while(i<j && a[i]<key)//Buscar de izquierda a derecha el primer valor mayor que key
                 i++;

             if(i<j){
                 a[j] = a[i];
                 j--;
             }
         }
         //i == j
         a[i] = key;
         quickSort(a, l, i-1);//Llamada recursiva
         quickSort(a, i+1, r);//Llamada recursiva
     }

    La selección del valor de key puede tener varias formas, por ejemplo el número del medio o un número aleatorio, lo que afecta de manera diferente a la complejidad del algoritmo.

6. Ordenamiento por mezcla (Merge Sort)

  • Idea básica:Referencia
    El ordenamiento por mezcla es un algoritmo de ordenamiento eficiente basado en la operación de mezcla. Este algoritmo es una aplicación muy típica del método de divide y vencerás.
    Primero consideremos cómo combinar 2 secuencias ordenadas. Esto es muy simple: solo hay que comparar el primer número de las dos secuencias, tomar el menor primero, y después de tomarlo, eliminarlo de la secuencia correspondiente. Luego se vuelve a comparar; si una secuencia queda vacía, basta con tomar los datos de la otra secuencia uno por uno.

    Ejemplo

    //Combinar los arreglos ordenados a[] y b[] en c[]
    void MemeryArray(int a[], int n, int b[], int m, int c[])
    {
     int i, j, k;

     i = j = k = 0;
     while (i < n && j < m)
     {
         if (a[i] < b[j])
             c[k++] = a[i++];
         else
             c[k++] = b[j++];
     }

     while (i < n)
         c[k++] = a[i++];

     while (j < m)
         c[k++] = b[j++];
    }

    Resuelto el problema anterior de combinar secuencias ordenadas, veamos ahora el ordenamiento por mezcla. Su idea básica es dividir el arreglo en 2 grupos, A y B. Si los datos dentro de estos 2 grupos están ordenados, entonces se pueden ordenar estos 2 grupos fácilmente. ¿Cómo hacer que los datos dentro de estos 2 grupos estén ordenados?
    Se pueden dividir los grupos A y B, cada uno, en 2 grupos nuevamente. Y así sucesivamente. Cuando el grupo resultante tenga solo 1 dato, se puede considerar que ese grupo ya está ordenado internamente, y luego se combinan los 2 grupos adyacentes. Así, medianteprimero descomponer recursivamente la secuencia,，y luego combinar las secuencias,se completa el ordenamiento por mezcla.

  • Proceso:

    Ordenamiento por mezcla

  • Complejidad de tiempo promedio:O(NlogN)
    La eficiencia de la ordenación por mezcla es relativamente alta. Supongamos que la longitud de la secuencia es N. Dividir la secuencia en subsecuencias requiere un total de logN pasos. Cada paso es un proceso de fusionar secuencias ordenadas. La complejidad temporal puede registrarse como O(N), por lo que en total es O(N*logN).

  • Implementación del código:

    Ejemplo

    public static void merge_sort(int a[],int first,int last,int temp[]){

      if(first < last){
          int middle = (first + last)/2;
          merge_sort(a,first,middle,temp);//La mitad izquierda queda ordenada
          merge_sort(a,middle+1,last,temp);//La mitad derecha queda ordenada
          mergeArray(a,first,middle,last,temp); //Fusionar las partes izquierda y derecha
      }
    }

    Ejemplo

    //Fusionar: fusionar las dos secuencias a[first-middle], a[middle+1-end]
    public static void mergeArray(int a[],int first,int middle,int end,int temp[]){    
      int i = first;
      int m = middle;
      int j = middle+1;
      int n = end;
      int k = 0;
      while(i<=m && j<=n){
          if(a[i] <= a[j]){
              temp[k] = a[i];
              k++;
              i++;
          }else{
              temp[k] = a[j];
              k++;
              j++;
          }
      }    
      while(i<=m){
          temp[k] = a[i];
          k++;
          i++;
      }    
      while(j<=n){
          temp[k] = a[j];
          k++;
          j++;
      }

      for(int ii=0;ii<k;ii++){
          a[first + ii] = temp[ii];
      }
    }

7. Ordenamiento de montón (HeapSort)

  • Idea básica:

    • Diagrama: （88,85,83,73,72,60,57,48,42,6）

      Heap Sort

  • Complejidad temporal promedio:O(NlogN)
    Dado que la complejidad temporal de restaurar el montón cada vez es O(logN), hay un total de N - 1 operaciones de restauración del montón. Además, durante la construcción inicial del montón se realizan N / 2 ajustes descendentes, y cada ajuste también tiene una complejidad temporal de O(logN). Al sumar el tiempo de ambas operaciones, el resultado sigue siendo O(N * logN).

  • Implementación en código Java:

    Ejemplo

    //Construir el montón mínimo
    public static void MakeMinHeap(int a[], int n){
     for(int i=(n-1)/2 ; i>=0 ; i--){
         MinHeapFixdown(a,i,n);
     }
    }
    //Ajustar desde el nodo i; n es el número total de nodos, contando desde 0; los nodos hijos del nodo i son 2*i+1, 2*i+2
    public static void MinHeapFixdown(int a[],int i,int n){

       int j = 2*i+1; //Nodos hijos
       int temp = 0;

       while(j<n){
           //Buscar el menor entre los nodos hijos izquierdo y derecho
           if(j+1<n && a[j+1]<a[j]){  
               j++;
           }

           if(a[i] <= a[j])
               break;

           //El nodo mayor se mueve hacia abajo
           temp = a[i];
           a[i] = a[j];
           a[j] = temp;

           i = j;
           j = 2*i+1;
       }
    }

    Ejemplo

    public static void MinHeap_Sort(int a[],int n){
      int temp = 0;
      MakeMinHeap(a,n);

      for(int i=n-1;i>0;i--){
          temp = a[0];
          a[0] = a[i];
          a[i] = temp;
          MinHeapFixdown(a,0,i);
      }    
    }

8. Ordenamiento por base (RadixSort)

BinSort

  • Idea básica:
    La idea de BinSort es muy simple: primero se crea un array A[MaxValue]; luego se coloca cada número en su posición correspondiente (por ejemplo, 17 se coloca en la posición del array con índice 17); finalmente se recorre el array, que es el resultado ordenado.

  • Diagrama:

    BinSort

    • Problema:Cuando la secuencia contiene valores grandes, el método de ordenación de BinSort desperdicia una gran cantidad de espacio.
    RadixSort
    • Idea básica:La ordenación por bases se basa en BinSort y reduce el consumo de espacio mediante la restricción de la base.
    • Proceso:

      Proceso 1

      Proceso 2

    (1) Primero se determina que la base es 10, por lo que la longitud del array también es 10. Cada número (por ejemplo, 34) buscará su posición entre estos 10 números.
    (2) A diferencia de BinSort, que coloca directamente el número 34 en el índice 34 del array, la ordenación por bases separa 34 en 3 y 4. En la primera ronda se coloca según el último dígito en el índice 4 del array; en la segunda ronda, según el penúltimo dígito, en el índice 3; luego se recorre el array.

  • Implementación en código Java:

    Ejemplo

    public static void RadixSort(int A[],int temp[],int n,int k,int r,int cnt[]){

       //A: array original
       //temp: array temporal
       //n: cantidad de números en la secuencia
       //k: el número máximo de dígitos (2)
       //r: base 10
       //cnt: almacena la cantidad de bin[i]

       for(int i=0 , rtok=1; i<k ; i++ ,rtok = rtok*r){

           //Inicialización
           for(int j=0;j<r;j++){
               cnt[j] = 0;
           }
           //Calcular la cantidad de números de cada caja
           for(int j=0;j<n;j++){
               cnt[(A[j]/rtok)%r]++;
           }
           //Modificar cnt[j] para que sea el total de números en las primeras j cajas
           for(int j=1;j<r;j++){
               cnt[j] = cnt[j-1] + cnt[j];
           }
           for(int j = n-1;j>=0;j--){      //Punto clave de comprensión
               cnt[(A[j]/rtok)%r]--;
               temp[cnt[(A[j]/rtok)%r]] = A[j];
           }
           for(int j=0;j<n;j++){
               A[j] = temp[j];
           }
       }
    }
