2.2 Instrucciones de Jet

Categoría Tutorial de uso de JMR

Las directivas de Jet se utilizan para establecer propiedades relacionadas con toda la página de plantilla, como las directivas de compilación y las directivas de importación.

Directiva de compilación

La primera línea del archivo de plantilla contiene la directiva de compilación. La plantilla Jet se compila en una clase Java; el principio es similar al de JSP, que se compila en una clase Java.
La clase de compilación especifica el nombre del paquete y el nombre de la clase de esta clase Java; el desarrollador no necesita preocuparse por la clase de compilación específica.

Formato de sintaxis de la directiva de compilación:

<%@jet package="包名" class="类名" ...  %>

Atributos incluidos:

  • package (obligatorio): el nombre del paquete de compilación; al crearlo, el valor predeterminado es `translated`, y se puede personalizar como una estructura de paquete XX.XX.XX.
  • class (obligatorio): el nombre de la clase de compilación; por favor, rellene el nombre de la clase según las convenciones de nomenclatura de Java.
  • startTag y endTag (opcionales): el startTag predeterminado de Jet es: `<%`, y el endTag es: `%>`; podemos reespecificarlos.

Cuando el código generado contiene `<%` y `%>`, por ejemplo en JSP, el `<%` y `%>` del código entran en conflicto con el `<%` y `%>` de la plantilla; en este caso se pueden modificar startTag y endTag.

El siguiente ejemplo reemplaza `<%` y `%>` por `<$` y `$>`, de este modo `<%%>` se generará tal cual.

Otra forma es usar el carácter de escape `\` para cambiar `<%` y `%>` a `<\%` y `\%>`, de modo que `<%%>` también se puede generar tal cual.

Directiva de importación

Importe las clases Java que se van a utilizar; se pueden importar todas las dependencias del proyecto donde se encuentra la plantilla Jet.

Formato de sintaxis de la directiva de importación:

<%@jet imports="..."%>

Por ejemplo, importar List

Se puede especificar el "nombre del paquete.nombre de la clase" concreto, o también se puede especificar "nombre del paquete.*"; la sintaxis es igual que la de `<%@ page import="..." %>` en JSP.
