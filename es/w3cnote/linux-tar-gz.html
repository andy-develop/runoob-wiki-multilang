Explicación detallada de los comandos de compresión y descompresión de Linux: tar.gz, tar, bz2, zip, etc.

Categoría Tecnología de programación

Los comandos de compresión y descompresión más comunes en Linux son: tar, gzip, gunzip, bzip2, bunzip2, compress, uncompress, zip, unzip, rar, unrar, etc.

tar

El comando de empaquetado más utilizado es tar. Los paquetes creados con el programa tar generalmente se llaman paquetes tar. Los nombres de archivos de los paquetes tar suelen terminar en .tar. Una vez generado el paquete tar, se pueden usar otros programas para comprimirlo, así que primero hablaremos sobre el uso básico del comando tar.

El comando tar tiene muchas opciones (puedes verlas con man tar), pero solo se usan algunas. A continuación se explica con ejemplos.

# tar -cf all.tar *.jpg

Este comando empaqueta todos los archivos .jpg en un paquete llamado all.tar. -c indica que se crea un nuevo paquete, y -f especifica el nombre del archivo del paquete.

# tar -rf all.tar *.gif

Este comando agrega todos los archivos .gif al paquete all.tar. -r indica agregar archivos.

# tar -uf all.tar logo.gif

Este comando actualiza el archivo logo.gif en el paquete tar original all.tar. -u indica actualizar archivos.

# tar -tf all.tar

Este comando lista todos los archivos del paquete all.tar. -t indica listar archivos.

# tar -xf all.tar

Este comando extrae todos los archivos del paquete all.tar. -x indica extraer.

Lo anterior es el uso más básico de tar. Para que los usuarios puedan comprimir o descomprimir archivos mientras empaquetan o desempaquetan, tar ofrece una función especial: puede invocar otros programas de compresión mientras empaqueta o desempaqueta, como gzip, bzip2, etc.

1) Invocación de tar

gzip es un programa de compresión desarrollado por la organización GNU. Los archivos que terminan en .gz son el resultado de la compresión con gzip. El programa de descompresión correspondiente a gzip es gunzip. En tar se usa el parámetro -z para invocar a gzip. A continuación se explica con ejemplos.

# tar -czf all.tar.gz *.jpg

Este comando empaqueta todos los archivos .jpg en un paquete tar, lo comprime con gzip y genera un paquete comprimido con gzip llamado all.tar.gz.

# tar -xzf all.tar.gz

Este comando extrae el paquete generado anteriormente.

2) tar invoca a bzip2

bzip2 es un programa de compresión con una capacidad de compresión más fuerte. Los archivos que terminan en .bz2 son el resultado de la compresión con bzip2.

El programa de descompresión correspondiente a bzip2 es bunzip2. En tar se usa el parámetro -j para invocar a gzip. A continuación se explica con ejemplos.

# tar -cjf all.tar.bz2 *.jpg

Este comando empaqueta todos los archivos .jpg en un paquete tar, lo comprime con bzip2 y genera un paquete comprimido con bzip2 llamado all.tar.bz2.

# tar -xjf all.tar.bz2

Este comando extrae el paquete generado anteriormente.

3) tar invoca a compress

compress también es un programa de compresión, pero parece que no tantas personas usan compress como gzip y bzip2. Los archivos que terminan en .Z son el resultado de la compresión con bzip2. El programa de descompresión correspondiente a compress es uncompress. En tar se usa el parámetro -Z para invocar a compress. A continuación se explica con ejemplos.

# tar -cZf all.tar.Z *.jpg

Este comando empaqueta todos los archivos .jpg en un paquete tar, lo comprime con compress y genera un paquete comprimido con uncompress llamado all.tar.Z.

# tar -xZf all.tar.Z

Este comando extrae el paquete generado anteriormente.

Con el conocimiento anterior, ya deberías poder extraer varios tipos de archivos comprimidos. A continuación se hace un resumen de los archivos comprimidos de la serie tar:

1) Para archivos que terminan en .tar

tar -xf all.tar

2) Para archivos que terminan en .gz

gzip -d all.gz
gunzip all.gz

3) Para archivos que terminan en .tgz o .tar.gz

tar -xzf all.tar.gz
tar -xzf all.tgz

4) Para archivos que terminan en .bz2

bzip2 -d all.bz2
bunzip2 all.bz2

5) Para archivos que terminan en tar.bz2

tar -xjf all.tar.bz2

6) Para archivos que terminan en .Z

uncompress all.Z

7) Para archivos que terminan en .tar.Z

tar -xZf all.tar.z

Además, para los archivos comprimidos comunes de Windows, .zip y .rar, Linux también tiene métodos correspondientes para descomprimirlos.

1) Para .zip

Linux proporciona los programas zip y unzip; zip es el programa de compresión y unzip es el programa de descompresión. Tienen muchas opciones de parámetros. Aquí solo se ofrece una breve introducción y ejemplos de su uso.

# zip all.zip *.jpg

Este comando comprime todos los archivos .jpg en un paquete zip:

# unzip all.zip

Este comando extrae todos los archivos de all.zip.

2) Para .rar

Para procesar archivos .rar en Linux, se necesita instalar RAR for Linux. Dirección de descarga:http://www.rarsoft.com/download.htmDespués de descargarlo, instálalo.

# tar -xzpvf rarlinux-x64-5.6.b5.tar.gz
# cd rar 
# make

Así queda instalado. Después de la instalación, se tienen los programas rar y unrar; rar es el programa de compresión y unrar es el programa de descompresión. Tienen muchas opciones de parámetros. Aquí solo se ofrece una breve introducción y ejemplos de su uso.

# rar a all *.jpg

Este comando comprime todos los archivos .jpg en un paquete rar llamado all.rar. El programa agregará automáticamente la extensión .rar al nombre del paquete.

# unrar e all.rar

Este comando extrae todos los archivos de all.rar.

# unrar x all.rar

Este comando extrae todos los archivos de all.rar, según la jerarquía de directorios.

tar

-c: 建立压缩档案 
-x：解压 
-t：查看内容 
-r：向压缩归档文件末尾追加文件 
-u：更新原压缩包中的文件

Estos cinco son comandos independientes; para comprimir o descomprimir se debe usar uno de ellos. Se pueden combinar con otros comandos, pero solo se puede usar uno de ellos. Los siguientes parámetros son opcionales al comprimir o descomprimir archivos según sea necesario.

-z：有gzip属性的 
-j：有bz2属性的 
-Z：有compress属性的 
-v：显示所有过程 
-O：将文件解开到标准输出

El siguiente parámetro -f es obligatorio:

Compresión

tar –cvf jpg.tar *.jpg       // 将目录里所有jpg文件打包成 jpg.tar
tar –czf jpg.tar.gz *.jpg    // 将目录里所有jpg文件打包成 jpg.tar 后，并且将其用 gzip 压缩，生成一个 gzip 压缩过的包，命名为 jpg.tar.gz 
tar –cjf jpg.tar.bz2 *.jpg   // 将目录里所有jpg文件打包成 jpg.tar 后，并且将其用 bzip2 压缩，生成一个 bzip2 压缩过的包，命名为jpg.tar.bz2 
tar –cZf jpg.tar.Z *.jpg     // 将目录里所有 jpg 文件打包成 jpg.tar 后，并且将其用 compress 压缩，生成一个 umcompress 压缩过的包，命名为jpg.tar.Z 
rar a jpg.rar *.jpg          // rar格式的压缩，需要先下载 rar for linux 
zip jpg.zip *.jpg            // zip格式的压缩，需要先下载 zip for linux

Descompresión

tar –xvf file.tar         // 解压 tar 包 
tar -xzvf file.tar.gz     // 解压 tar.gz 
tar -xjvf file.tar.bz2    // 解压 tar.bz2 
tar –xZvf file.tar.Z      // 解压 tar.Z 
unrar e file.rar          // 解压 rar 
unzip file.zip            // 解压 zip

Resumen

1、*.tar 用 tar –xvf 解压 
2、*.gz 用 gzip -d或者gunzip 解压 
3、*.tar.gz和*.tgz 用 tar –xzf 解压 
4、*.bz2 用 bzip2 -d或者用bunzip2 解压 
5、*.tar.bz2用tar –xjf 解压 
6、*.Z 用 uncompress 解压 
7、*.tar.Z 用tar –xZf 解压 
8、*.rar 用 unrar e解压 
9、*.zip 用 unzip 解压
