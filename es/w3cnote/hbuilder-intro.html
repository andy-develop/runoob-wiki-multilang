Tutorial de uso de HBuilder

Categoría Tecnología de programación

¿Qué es HBuilder?

HBuilder es un IDE de desarrollo web compatible con HTML5 lanzado por DCloud (Digital Heaven). Para su desarrollo se utilizaron Java, C, Web y Ruby. El cuerpo principal de HBuilder está escrito en Java y está basado en Eclipse, por lo que, naturalmente, es compatible con los complementos de Eclipse. La velocidad es la mayor ventaja de HBuilder: gracias a las completas sugerencias de sintaxis, el método de entrada de código y los bloques de código, se mejora enormemente la eficiencia del desarrollo en HTML, JS y CSS.

¿Cómo instalar HBuilder?

Dirección de descarga de HBuilder: en el sitio web oficial de HBuilderhttp://www.dcloud.io/Haz clic en Descargar gratis y descarga la última versión de HBuilder.

Actualmente HBuilder tiene dos versiones: una para Windows y otra para Mac. Al descargar, elige la versión adecuada según tu computadora.

Crear un nuevo proyecto con HBuilder

Haz clic sucesivamente en Archivo → Nuevo → Elegir proyecto web (puedes presionar Ctrl+N, W para crear uno rápidamente; en macOS usa Command+N y luego haz clic con el botón izquierdo en Proyecto web).

Como se muestra arriba, en el campo A escribe el nombre del nuevo proyecto; en el campo B escribe (o selecciona) la ruta de guardado del proyecto (HBuilder recordará esta ruta y la usará por defecto la próxima vez); en el campo C puedes elegir la plantilla a usar (puedes hacer clic en Plantilla personalizada y consultar el archivo readme.txt de la carpeta abierta para personalizarla).

Crear una página HTML con HBuilder

En el explorador de proyectos, selecciona el proyecto recién creado, haz clic sucesivamente en Archivo → Nuevo → Elegir archivo HTML (puedes presionar Ctrl+N, W para crearlo rápidamente; en macOS usa Command+N y luego haz clic con el botón izquierdo en Archivo HTML) y elige la plantilla de archivo en blanco, como se muestra a continuación.

Usa la función de edición con vista previa en vivo de HBuilder para ver el efecto de la programación

En Windows presiona Ctrl+P (en macOS, Command+P) para entrar en el modo de edición con vista previa en vivo. En este modo, si el archivo abierto actualmente es HTML, cada vez que guardes se actualizará automáticamente para mostrar el efecto de la página actual (si son archivos JS o CSS y tienen relación de referencia con la página abierta en la vista del navegador, también se actualizarán).

¿Qué es un bloque de código?

Un bloque de código es una combinación de código de uso frecuente. Por ejemplo, en JS, si escribes $ y pulsas Enter, se inserta automáticamente document.getElementById(id).

Para ver y editar bloques de código, puedes ir a Herramientas - Bloques de código personalizados y seleccionar el bloque correspondiente para verlo y editarlo. También puedes hacer clic en el icono de modificar en la esquina inferior derecha de los detalles en el asistente de código que activa el bloque de código para modificarlo y verlo.

  • Principio 1 de los caracteres de activación de bloques de código:Las letras iniciales de palabras consecutivas. Por ejemplo: dg activa document.getElementById(""); vari activa var i=0; dn activa display: none;

  • Principio 2 de los caracteres de activación de bloques de código:Para bloques HTML completos se suele usar el nombre de la etiqueta. Por ejemplo, script, style. Normalmente, basta con escribir como máximo 4 letras para encontrar el bloque de código deseado, sin necesidad de escribirlo completo. Por ejemplo, sc + Enter, st + Enter completan la inserción de las etiquetas script y style.

  • Principio 3 de los caracteres de activación de bloques de código:Para una misma etiqueta, si hay varios bloques de código de salida, se añade un sufijo al final. Por ejemplo, meta genera <meta name="" content=""/> pero metau genera <meta charset="UTF-8"/>; metag es similar.

  • Principio 4 de los caracteres de activación de bloques de código:Si la sintaxis original tiene más de 4 caracteres, para las sintaxis comunes se usa una abreviatura para activar la primera palabra. Por ejemplo, input button se abrevia como inbutton; de manera similar, intext es un cuadro de entrada.

  • Principio 5 de los caracteres de activación de bloques de código:Los bloques de código de palabras clave de JS consisten en añadir una letra repetida al final de la palabra clave. Por ejemplo, si escribes if directamente, aparece la palabra clave if, pero con iff + Enter aparece el bloque de código if. Otros casos similares son forr, withh, etc. Dado que la palabra function es larga, para acelerar la escritura se usa la abreviatura fun. Por ejemplo, funn genera el bloque de código function, mientras que funa y func generan respectivamente una función anónima y un closure.
