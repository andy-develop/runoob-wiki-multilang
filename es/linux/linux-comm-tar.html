Comando Linux tar

Compendio de comandos Linux

El comando Linux tar (acrónimo en inglés: tape archive) se utiliza para hacer copias de seguridad de archivos.

tar es una potente herramienta de línea de comandos en los sistemas Linux y Unix para archivar archivos y directorios.

El nombre tar proviene de "tape archive" (archivo de cinta), originalmente se usaba para empaquetar archivos en dispositivos de cinta, pero ahora se usa ampliamente para empaquetar y comprimir archivos en el sistema de archivos.

tar se usa generalmente para empaquetar múltiples archivos y directorios en un archivo de almacenamiento, llamado "tarball" (normalmente con la extensión .tar).

tar por sí mismo no comprime archivos, pero puede combinarse con herramientas de compresión (como gzip o bzip2) para crear archivos de almacenamiento comprimidos (como .tar.gz o .tar.bz2).

Sintaxis

tar [options] -f archive.tar [files...]
  • -f archive.tar: especifica el nombre del archivo de almacenamiento.
  • [files...]: los archivos y directorios a empaquetar.

Parámetros de opciones

Opciones de operaciones básicas

  • -c: crear un nuevo archivo de almacenamiento.
  • -x: extraer el archivo de almacenamiento.
  • -t: listar el contenido del archivo de almacenamiento.
  • -r: añadir archivos a un archivo de almacenamiento existente.
  • -u: añadir solo los archivos más recientes que los ya existentes en el archivo de almacenamiento.
  • -d: encontrar las diferencias no sincronizadas entre el archivo de almacenamiento y el sistema de archivos.
  • -A: añadir un.tararchivo a otro.tararchivo.

Selección y exclusión de archivos

  • -f <file>: especifica el nombre del archivo de almacenamiento (debe colocarse al final de la lista de opciones).
  • -C <directory>: cambiar al directorio especificado para operar.
  • --exclude=<pattern>: excluir archivos que coincidan con el patrón especificado.
  • --exclude-from=<file>: leer los patrones a excluir desde el archivo especificado.
  • --exclude-caches: excluir archivos de caché del directorio.
  • --exclude-backups: excluir los que terminen en~archivos de respaldo.
  • --exclude-vcs: excluir archivos generados por sistemas de control de versiones (como.git、.svnetc.).

Opciones de compresión y descompresión

  • -z: usargzippara comprimir el archivo de almacenamiento.
  • -j: usarbzip2para comprimir el archivo de almacenamiento.
  • -J: usarxzpara comprimir el archivo de almacenamiento.
  • --lzip: usarlzippara comprimir el archivo de almacenamiento.
  • --lzma: usarlzmapara comprimir el archivo de almacenamiento.
  • --lzop: usarlzoppara comprimir el archivo de almacenamiento.
  • --zstd: usarzstdpara comprimir el archivo de almacenamiento.
  • -a: seleccionar automáticamente el método de compresión (según la extensión del archivo de almacenamiento, como.tar.gz、.tar.bz2etc.).
  • -I <command>: usar el programa de compresión especificado para comprimir o descomprimir.

Opciones de salida e interacción

  • -v: mostrar el proceso detallado de la operación (verbose).
  • --progress: mostrar una barra de progreso (cuando se usa con-vla opción correspondiente).
  • -w 或 --interactive: pedir confirmación al usuario antes de cada operación.
  • --checkpoint: mostrar un punto de control después de procesar cada archivo.
  • --checkpoint-action=<action>: ejecutar una acción específica en los puntos de control, por ejemploecho、dotetc.
  • --totals: mostrar el número total de bytes procesados al final de la operación.
  • --verbose: mostrar información detallada del procesamiento.
  • --quiet: mostrar la menor cantidad posible de información de salida.

Opciones relacionadas con archivos y permisos

  • -p: conservar los permisos originales de los archivos (al extraer).
  • --same-owner: intentar establecer el propietario original de los archivos extraídos (requiere privilegios de superusuario).
  • --no-same-owner: no establecer el propietario del archivo.
  • --same-permissions: conservar los permisos originales de los archivos (igual que-pla opción antes mencionada).
  • --no-same-permissions: no conservar los permisos originales; usar la máscara umask del usuario actual para establecer los permisos.
  • -m: al extraer, no restaurar la hora de modificación de los archivos, sino usar la hora actual.

Opciones de gestión de archivos de almacenamiento

  • -k 或 --keep-old-files: al extraer, conservar los archivos existentes sin sobrescribirlos.
  • --overwrite: al extraer, sobrescribir forzosamente los archivos existentes.
  • --remove-files: eliminar los archivos originales después de un archivado exitoso.
  • --delete: eliminar los archivos especificados del archivo de almacenamiento (solognu tar）。
  • --keep-newer-files: al extraer, conservar los archivos más recientes que los del archivo de almacenamiento.
  • --listed-incremental=<file>: crear una copia de seguridad incremental o restaurar desde una copia de seguridad incremental.

Opciones de sistema de archivos y dispositivos

  • -L <N>: dividir archivos de almacenamiento de más deNbytes (para unidades de cinta).
  • --tape-length=<number>: especificar la longitud de la cinta (para unidades de cinta).
  • --multi-volume: crear o restaurar archivos de almacenamiento multivolumen.
  • -M: utilizado con--multi-volumela opción correspondiente, procesar archivos de almacenamiento multivolumen.
  • --use-compress-program=<prog>: usar el programa de compresión especificado.

Otras opciones útiles

  • --transform=<expression>: renombrar archivos dentro del archivo de almacenamiento.
  • --strip-components=<number>: al extraer, eliminar un número especificado de componentes de ruta.
  • --ignore-failed-read: ignorar errores de lectura y continuar la operación.
  • --occurrence=<number>: seleccionar el enésimonumberarchivo que aparece.
  • -S: procesar archivos dispersos (archivar solo los bloques realmente utilizados).
  • --no-recursion: no entrar recursivamente en los directorios.
  • -h 或 --dereference: archivar los archivos a los que apuntan los enlaces simbólicos en lugar de los enlaces en sí.

Información de ayuda y versión

  • --help: mostrar información de ayuda.
  • --version: mostrartarla información de versión de.

Ejemplos

1. Crear un archivo de almacenamiento:Empaquetar los archivos file1, file2 y el directorio directory en un archivo de almacenamiento llamado archive.tar.

tar -cvf archive.tar file1 file2 directory
  • -c: crear un nuevo archivo de almacenamiento.
  • -v: mostrar salida detallada, enumerando los archivos añadidos al archivo de almacenamiento.
  • -f: especificar el nombre del archivo de almacenamiento.

2. Extraer un archivo de almacenamiento:Extraer el archivo de almacenamiento llamado archive.tar, restaurando los archivos y directorios que contiene.

tar -xvf archive.tar
  • -x: extraer el archivo de almacenamiento.
  • -v: mostrar salida detallada, enumerando los archivos extraídos.
  • -f: especificar el nombre del archivo de almacenamiento a extraer.

3. Comprimir un archivo de almacenamiento:Empaquetar el directorio llamado directory en un archivo de almacenamiento y luego comprimirlo con gzip, generando un archivo llamado archive.tar.gz.

tar -czvf archive.tar.gz directory
  • -c: crear un nuevo archivo de almacenamiento.
  • -z: usar gzip para comprimir el archivo de almacenamiento.
  • -v: mostrar salida detallada, enumerando los archivos añadidos al archivo de almacenamiento.
  • -f: especificar el nombre del archivo de almacenamiento.

4. Listar el contenido del archivo de almacenamiento:Listar todos los archivos y directorios contenidos en el archivo de almacenamiento llamado archive.tar.

tar -tvf archive.tar
  • -t: listar el contenido del archivo de almacenamiento.
  • -v: mostrar salida detallada, enumerando todos los archivos y directorios del archivo de almacenamiento.
  • -f: especificar el nombre del archivo de almacenamiento cuyo contenido se va a listar.

5. Añadir archivos a un archivo de almacenamiento existente:Añadir el archivo llamado newfile al archivo de almacenamiento existente llamado archive.tar.

tar -rvf archive.tar newfile
  • -r: añadir archivos a un archivo de almacenamiento existente.
  • -v: mostrar salida detallada, enumerando los archivos añadidos al archivo de almacenamiento.
  • -f: especificar el nombre del archivo de almacenamiento existente.

6. Crear un archivo de almacenamiento comprimido con gzip:Empaquetar todos los archivos y subdirectorios del directorio directory y comprimirlos con gzip, generando un archivo de almacenamiento llamado archive.tar.gz.

tar -zcvf archive.tar.gz directory
  • -z: indica que se usará gzip para comprimir.
  • -c: indica la creación de un nuevo archivo de almacenamiento.
  • -v: indica salida detallada, enumerando los archivos añadidos al archivo de almacenamiento.
  • -f archive.tar.gz: especifica el nombre del archivo de almacenamiento comoarchive.tar.gz。

7. Extraer un archivo de almacenamiento ya comprimido con gzip:Extraer el archivo example.tar.gz y restaurar en el directorio actual los archivos y directorios que contiene.

tar -zxvf example.tar.gz
  • -z: indica que se usará gzip para descomprimir el archivo de almacenamiento.
  • -x: indica la operación de extracción.
  • -v: indica salida detallada, enumerando los archivos extraídos.
  • -f example.tar.gz: especifica el nombre del archivo de almacenamiento a extraer comoexample.tar.gz。

Especificar formato de compresión

tar se puede combinar con diferentes programas de compresión para crear y extraer archivos de almacenamiento comprimidos.

z: comprimir con gzip.

tar -czvf archive.tar.gz directory
tar -xzvf archive.tar.gz

j: comprimir con bzip2.

tar -cjvf archive.tar.bz2 directory
tar -xjvf archive.tar.bz2

J: comprimir con xz.

tar -cJvf archive.tar.xz directory
tar -xJvf archive.tar.xz

    Excluir ciertos archivos del directorio y luego comprimir.

    El formato del comando es el siguiente:

    tar --exclude=目录名/* 或者 文件名 -zcvf 备份文件名.tgz 目录名

    Ejemplo específico:

    # 创建一个名为 abc 的目录
mkdir abc

# 进入 abc 这个目录
cd abc

# 创建两个文件,文件名为1.txt 2.txt
touch 1.txt 2.txt

# 切换到 abc 的父目录
cd ..

# 将文件 abc 进行压缩时，排除1.txt，压缩后的文件名为 abc.tar
tar --exclude=abc/1.txt -zcvf abc.tgz abc

# 解压文件
tar -zxvf abc.tgz

# 删除压缩文件
rm abc.tgz

# 删除解压后的文件，并删除文件夹
rm -rf abc
