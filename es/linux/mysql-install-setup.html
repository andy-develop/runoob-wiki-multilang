Instalación y configuración de MySQL

MySQL es el sistema de gestión de bases de datos relacional más popular, desarrollado por la empresa sueca MySQL AB, y actualmente pertenece a Oracle.

El lenguaje SQL utilizado por MySQL es el lenguaje estándar más común para acceder a bases de datos.

Debido a su pequeño tamaño, alta velocidad, bajo costo total de propiedad y especialmente su característica de código abierto, el desarrollo de sitios web pequeños y medianos generalmente elige MySQL como base de datos del sitio web.

Instalación de MySQL

Plataforma del sistema en este tutorial: CentOS release 6.6 (Final) de 64 bits.

1. Instalar herramientas de compilación y archivos de biblioteca

yum -y install gcc gcc-c++ make autoconf libtool-ltdl-devel gd-devel freetype-devel libxml2-devel libjpeg-devel libpng-devel openssl-devel curl-devel bison patch unzip libmcrypt-devel libmhash-devel ncurses-devel sudo bzip2 flex libaio-devel

2. Instalar el compilador cmake

Versión de cmake: cmake-3.1.1.

1. Dirección de descarga:http://www.cmake.org/files/v3.1/cmake-3.1.1.tar.gz 

$ wget http://www.cmake.org/files/v3.1/cmake-3.1.1.tar.gz

2. Descomprimir el paquete de instalación

$ tar zxvf cmake-3.1.1.tar.gz

3. Entrar en el directorio del paquete de instalación

$ cd cmake-3.1.1

4. Compilar e instalar

$ ./bootstrap
$ make && make install

3. Instalar MySQL

Versión de MySQL: mysql-5.6.15.

1. Dirección de descarga:http://dev.mysql.com/get/Downloads/MySQL-5.6/mysql-5.6.15.tar.gz 

$ wget http://dev.mysql.com/get/Downloads/MySQL-5.6/mysql-5.6.15.tar.gz

2. Descomprimir el paquete de instalación

$ tar zxvf mysql-5.6.15.tar.gz

3. Entrar en el directorio del paquete de instalación

$ cd mysql-5.6.15

4. Compilar e instalar

$ cmake -DCMAKE_INSTALL_PREFIX=/usr/local/webserver/mysql/ -DMYSQL_UNIX_ADDR=/tmp/mysql.sock -DDEFAULT_CHARSET=utf8 -DDEFAULT_COLLATION=utf8_general_ci -DWITH_EXTRA_CHARSETS=all -DWITH_MYISAM_STORAGE_ENGINE=1 -DWITH_INNOBASE_STORAGE_ENGINE=1 -DWITH_MEMORY_STORAGE_ENGINE=1 -DWITH_READLINE=1 -DWITH_INNODB_MEMCACHED=1 -DWITH_DEBUG=OFF -DWITH_ZLIB=bundled -DENABLED_LOCAL_INFILE=1 -DENABLED_PROFILING=ON -DMYSQL_MAINTAINER_MODE=OFF -DMYSQL_DATADIR=/usr/local/webserver/mysql/data -DMYSQL_TCP_PORT=3306
$ make && make install

5. Ver la versión de MySQL:

$ /usr/local/webserver/mysql/bin/mysql --version

En este punto, la instalación de MySQL está completa.

Configuración de MySQL

1. Crear el usuario mysql que utiliza MySQL para ejecutarse:

$ /usr/sbin/groupadd mysql
$ /usr/sbin/useradd -g mysql mysql

2. Crear las rutas de almacenamiento para binlog y las bases de datos, y otorgar permisos al usuario mysql

$ mkdir -p /usr/local/webserver/mysql/binlog /www/data_mysql
$ chown mysql.mysql /usr/local/webserver/mysql/binlog/ /www/data_mysql/

5. Crear script de inicio automático

$ cd /usr/local/webserver/mysql/
$ cp support-files/mysql.server /etc/rc.d/init.d/mysqld 
$ chkconfig --add mysqld 
$ chkconfig --level 35 mysqld on

6. Iniciar el servidor MySQL

$ service mysqld start

7. Conectar a MySQL

$ /usr/local/webserver/mysql/bin/mysql -u root -p

Cambiar la contraseña del usuario de MySQL

mysqladmin -u用户名 -p旧密码 password 新密码

O entrar en la línea de comandos de MySQL

SET PASSWORD FOR '用户名'@'主机' = PASSWORD(‘密码');

Crear un nuevo usuario y otorgar permisos:

grant all privileges on *.* to 用户名@'%' identified by '密码' with grant option;

Otros comandos

  • Iniciar: service mysqld start
  • Detener: service mysqld stop
  • Reiniciar: service mysqld restart
  • Recargar configuración: service mysqld reload
