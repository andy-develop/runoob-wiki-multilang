Linux Gestión de usuarios y grupos de usuarios

El sistema Linux es un sistema operativo de tiempo compartido multiusuario y multitarea. Cualquier usuario que desee utilizar los recursos del sistema debe primero solicitar una cuenta al administrador del sistema y luego ingresar al sistema con esa cuenta.

La cuenta de usuario, por un lado, ayuda al administrador del sistema a rastrear a los usuarios que utilizan el sistema y a controlar su acceso a los recursos del sistema; por otro lado, también ayuda al usuario a organizar archivos y le proporciona protección de seguridad.

Cada cuenta de usuario tiene un nombre de usuario único y su propia contraseña.

Cuando el usuario ingresa el nombre de usuario y la contraseña correctos al iniciar sesión, puede acceder al sistema y a su directorio principal.

Para llevar a cabo la gestión de cuentas de usuario, el trabajo a realizar incluye principalmente los siguientes aspectos:

  • Adición, eliminación y modificación de cuentas de usuario.
  • Gestión de contraseñas de usuario.
  • Gestión de grupos de usuarios.

I. Gestión de cuentas de usuario en el sistema Linux

La gestión de cuentas de usuario implica principalmente la adición, modificación y eliminación de cuentas de usuario.

Agregar una cuenta de usuario consiste en crear una nueva cuenta en el sistema y asignarle recursos como identificador de usuario, grupo de usuarios, directorio principal y shell de inicio de sesión. La cuenta recién agregada está bloqueada y no se puede utilizar.

1. Para agregar una nueva cuenta de usuario, se utiliza el comando useradd; su sintaxis es la siguiente:

useradd 选项 用户名

Descripción de parámetros:

  • Opciones:

    • -c comment Especifica una descripción comentada.
    • -d directorio Especifica el directorio principal del usuario. Si este directorio no existe, se puede usar la opción -m al mismo tiempo para crearlo.
    • -g grupo Especifica el grupo de usuarios al que pertenece el usuario.
    • -G grupo,grupo Especifica los grupos de usuarios adicionales a los que pertenece el usuario.
    • -s archivo Shell Especifica el shell de inicio de sesión del usuario.
    • -u identificador_de_usuario Especifica el identificador del usuario. Si se usa junto con la opción -o, se puede reutilizar el identificador de otro usuario.

  • Nombre de usuario:

    Especifica el nombre de inicio de sesión de la nueva cuenta.

Ejemplo 1

# useradd –d  /home/sam -m sam

Este comando crea un usuario llamado sam; las opciones -d y -m se utilizan para generar un directorio principal /home/sam para el nombre de inicio de sesión sam (/home es el directorio padre predeterminado que contiene los directorios principales de los usuarios).

Ejemplo 2

# useradd -s /bin/sh -g group –G adm,root gem

Este comando crea un nuevo usuario gem; el shell de inicio de sesión de este usuario es/bin/sh, pertenece al grupo de usuarios group, y también a los grupos adm y root, siendo group su grupo principal.

Aquí es posible que se necesite crear nuevos grupos:#groupadd group及groupadd adm

Agregar una cuenta de usuario consiste en añadir un registro para el nuevo usuario en el archivo /etc/passwd y actualizar otros archivos del sistema como /etc/shadow, /etc/group, etc.

Linux proporciona la herramienta integrada de administración del sistema userconf, que se puede utilizar para gestionar de forma unificada las cuentas de usuario.

2. Eliminar cuentas

Si la cuenta de un usuario ya no se utiliza, se puede eliminar del sistema. Eliminar una cuenta de usuario consiste en borrar el registro de ese usuario en archivos del sistema como /etc/passwd y, si es necesario, también eliminar su directorio principal.

Para eliminar una cuenta de usuario existente se utilizauserdelcomando, cuyo formato es el siguiente:

userdel 选项 用户名

La opción de uso común es-r, cuya función es eliminar también el directorio principal del usuario.

Por ejemplo:

# userdel -r sam

Este comando elimina el registro del usuario sam en los archivos del sistema (principalmente /etc/passwd, /etc/shadow, /etc/group, etc.) y también elimina su directorio principal.

3. Modificar cuentas

Modificar una cuenta de usuario consiste en cambiar los atributos relevantes del usuario según la situación real, como el identificador de usuario, el directorio principal, el grupo de usuarios, el shell de inicio de sesión, etc.

Para modificar la información de un usuario existente se utilizausermodcomando, cuyo formato es el siguiente:

usermod 选项 用户名

Las opciones de uso común incluyen-c, -d, -m, -g, -G, -s, -u以及-o等, estas opciones tienen el mismo significado que las opciones deluseraddcomando; pueden asignar al usuario nuevos valores de recursos.

Además, algunos sistemas permiten usar la opción: -l nuevo_nombre_de_usuario

Esta opción especifica una nueva cuenta, es decir, cambia el nombre de usuario original por un nuevo nombre de usuario.

Por ejemplo:

# usermod -s /bin/ksh -d /home/z –g developer sam

Este comando cambia el shell de inicio de sesión del usuario sam a ksh, el directorio principal a /home/z y el grupo de usuarios a developer.

4. Gestión de contraseñas de usuario

Un aspecto importante de la gestión de usuarios es la gestión de contraseñas. Cuando se crea una cuenta de usuario, esta no tiene contraseña, pero está bloqueada por el sistema y no se puede usar; solo se puede utilizar después de asignarle una contraseña, incluso si se asigna una contraseña vacía.

El comando Shell para asignar y modificar la contraseña de un usuario espasswdEl superusuario puede asignar contraseñas para sí mismo y para otros usuarios, mientras que un usuario normal solo puede usarlo para modificar su propia contraseña. El formato del comando es:

passwd 选项 用户名

Opciones disponibles:

  • -l Bloquea la contraseña, es decir, desactiva la cuenta.
  • -u Desbloquea la contraseña.
  • -d Hace que la cuenta no tenga contraseña.
  • -f Obliga al usuario a cambiar la contraseña en el próximo inicio de sesión.

Si se omite el nombre de usuario, se modifica la contraseña del usuario actual.

Por ejemplo, si el usuario actual es sam, el siguiente comando modifica la contraseña de este usuario:

$ passwd 
Old password:****** 
New password:******* 
Re-enter new password:*******

Si es superusuario, puede asignar la contraseña de cualquier usuario de la siguiente manera:

# passwd sam 
New password:******* 
Re-enter new password:*******

Cuando un usuario normal modifica su propia contraseña, el comando passwd primero solicita la contraseña original, y tras verificarla pide al usuario que ingrese la nueva contraseña dos veces; si las dos entradas coinciden, se asigna esa contraseña al usuario. En cambio, cuando el superusuario asigna una contraseña a un usuario, no necesita conocer la contraseña original.

Por seguridad del sistema, el usuario debe elegir una contraseña relativamente compleja; por ejemplo, es mejor usar una contraseña de 8 caracteres que contenga letras mayúsculas, minúsculas y números, y que no sea igual al nombre, fecha de nacimiento, etc.

Para asignar una contraseña vacía a un usuario, ejecute el comando de la siguiente forma:

# passwd -d sam

Este comando elimina la contraseña del usuario sam, de modo que cuando sam intente iniciar sesión la próxima vez, el sistema ya no le permitirá acceder.

El comando passwd también puede usar la opción -l (lock) para bloquear a un usuario e impedir que inicie sesión, por ejemplo:

# passwd -l sam

II. Gestión de grupos de usuarios en el sistema Linux

Cada usuario tiene un grupo de usuarios; el sistema puede gestionar de forma centralizada a todos los usuarios de un grupo. Los diferentes sistemas Linux tienen reglas distintas para los grupos de usuarios; por ejemplo, en Linux un usuario pertenece al grupo de usuarios con el mismo nombre, y este grupo se crea al mismo tiempo que se crea el usuario.

La gestión de grupos de usuarios implica la adición, eliminación y modificación de grupos de usuarios. Agregar, eliminar y modificar grupos es, en realidad, una actualización del archivo /etc/group.

1. Para agregar un nuevo grupo de usuarios, se utiliza el comando groupadd. Su formato es el siguiente:

groupadd 选项 用户组

Las opciones disponibles son:

  • -g GID especifica el identificador de grupo (GID) del nuevo grupo de usuarios.
  • -o Generalmente se usa junto con la opción -g; indica que el GID del nuevo grupo de usuarios puede ser el mismo que el GID de un grupo de usuarios ya existente en el sistema.

Ejemplo 1:

# groupadd group1

Este comando agrega un nuevo grupo group1 al sistema; el identificador de grupo del nuevo grupo es el máximo identificador de grupo existente actualmente más 1.

Ejemplo 2:

# groupadd -g 101 group2

Este comando agrega un nuevo grupo group2 al sistema y especifica que el identificador de grupo del nuevo grupo es 101.

2. Si se desea eliminar un grupo de usuarios existente, se utiliza el comando groupdel; su formato es el siguiente:

groupdel 用户组

Por ejemplo:

# groupdel group1

Este comando elimina el grupo group1 del sistema.

3. Para modificar los atributos de un grupo de usuarios se utiliza el comando groupmod. Su sintaxis es la siguiente:

groupmod 选项 用户组

Las opciones comunes son:

  • -g GID Especifica un nuevo identificador de grupo para el grupo de usuarios.
  • -o Se usa junto con la opción -g; el nuevo GID del grupo de usuarios puede ser el mismo que el GID de un grupo de usuarios ya existente en el sistema.
  • -n nuevo_grupo Cambia el nombre del grupo de usuarios a un nombre nuevo.

Ejemplo 1:

# groupmod -g 102 group2

Este comando modifica el identificador de grupo del grupo group2 a 102.

Ejemplo 2:

# groupmod –g 10000 -n group3 group2

Este comando cambia el identificador del grupo group2 a 10000 y el nombre del grupo a group3.

4. Si un usuario pertenece a varios grupos de usuarios a la vez, puede cambiar entre los grupos para tener los permisos de los otros grupos.

Después de iniciar sesión, el usuario puede usar el comando newgrp para cambiar a otro grupo de usuarios; el parámetro de este comando es el grupo de usuarios de destino. Por ejemplo:

$ newgrp root

Este comando cambia al usuario actual al grupo de usuarios root, siempre que el grupo de usuarios root sea realmente el grupo principal o un grupo adicional de ese usuario. De manera similar a la administración de cuentas de usuario, la administración de grupos de usuarios también puede realizarse mediante herramientas integradas de administración del sistema.

III. Archivos del sistema relacionados con las cuentas de usuario

Hay muchas formas de realizar la administración de usuarios, pero cada método consiste, en realidad, en modificar los archivos del sistema correspondientes.

La información relacionada con los usuarios y los grupos de usuarios se almacena en algunos archivos del sistema, como /etc/passwd, /etc/shadow, /etc/group, etc.

A continuación se describe el contenido de estos archivos por separado.

1. El archivo /etc/passwd es uno de los archivos más importantes implicados en la gestión de usuarios.

Cada usuario en un sistema Linux tiene una línea de registro correspondiente en el archivo /etc/passwd, que registra algunos atributos básicos de ese usuario.

Este archivo es legible por todos los usuarios. Su contenido es similar al siguiente ejemplo:

＃ cat /etc/passwd

root:x:0:0:Superuser:/:
daemon:x:1:1:System daemons:/etc:
bin:x:2:2:Owner of system commands:/bin:
sys:x:3:3:Owner of system files:/usr/sys:
adm:x:4:4:System accounting:/usr/adm:
uucp:x:5:5:UUCP administrator:/usr/lib/uucp:
auth:x:7:21:Authentication administrator:/tcb/files/auth:
cron:x:9:16:Cron daemon:/usr/spool/cron:
listen:x:37:4:Network daemon:/usr/net/nls:
lp:x:71:18:Printer administrator:/usr/spool/lp:
sam:x:200:50:Sam san:/home/sam:/bin/sh

Del ejemplo anterior podemos ver que en /etc/passwd una línea de registro corresponde a un usuario, y cada línea de registro está separada por dos puntos (:) en 7 campos. Su formato y significado específico son los siguientes:

用户名:口令:用户标识号:组标识号:注释性描述:主目录:登录Shell

1) El "nombre de usuario" es la cadena que representa la cuenta de usuario.

Normalmente no supera los 8 caracteres y está compuesto por letras mayúsculas, minúsculas y/o números. El nombre de inicio de sesión no puede contener dos puntos (:), porque aquí los dos puntos son el separador.

Por compatibilidad, es mejor que el nombre de inicio de sesión no contenga el carácter de punto (.) y no comience con guion (-) ni signo más (+).

2) La "contraseña" en algunos sistemas almacena la contraseña de usuario cifrada.

Aunque este campo solo contiene la cadena cifrada de la contraseña del usuario, no el texto plano, como el archivo /etc/passwd es legible por todos los usuarios, esto sigue siendo un riesgo de seguridad. Por lo tanto, muchos sistemas Linux actuales (como SVR4) utilizan la tecnología shadow, que almacena la contraseña real cifrada del usuario en el archivo /etc/shadow, y en el campo de contraseña del archivo /etc/passwd solo se guarda un carácter especial, como "x" o "*".

3) El "identificador de usuario" es un entero que el sistema utiliza internamente para identificar al usuario.

En circunstancias normales, tiene una correspondencia uno a uno con el nombre de usuario. Si varios nombres de usuario corresponden al mismo identificador de usuario, el sistema internamente los tratará como el mismo usuario, pero pueden tener diferentes contraseñas, diferentes directorios de inicio y diferentes shells de inicio de sesión, etc.

Normalmente, el rango de valores del identificador de usuario es de 0 a 65535. 0 es el identificador del superusuario root; del 1 al 99 están reservados por el sistema como cuentas de administración; el identificador de los usuarios normales comienza en 100. En los sistemas Linux, este límite es 500.

4) El campo "identificador de grupo" registra el grupo de usuarios al que pertenece el usuario.

Corresponde a un registro en el archivo /etc/group.

5) El campo "descripción comentada" registra alguna información personal del usuario.

Por ejemplo, el nombre real, teléfono, dirección, etc. Este campo no tiene un propósito práctico real. En diferentes sistemas Linux, el formato de este campo no es uniforme. En muchos sistemas Linux, este campo contiene un texto descriptivo de comentario arbitrario, utilizado como salida del comando finger.

6) El "directorio principal", es decir, el directorio de trabajo inicial del usuario.

Es el directorio en el que se encuentra el usuario después de iniciar sesión en el sistema. En la mayoría de los sistemas, los directorios de inicio de los usuarios están organizados bajo un mismo directorio específico, y el nombre del directorio de inicio del usuario es el nombre de inicio de sesión de ese usuario. Cada usuario tiene permisos de lectura, escritura y ejecución (búsqueda) sobre su propio directorio de inicio; los permisos de acceso de otros usuarios a este directorio se establecen según el caso.

7) Después de que el usuario inicia sesión, se inicia un proceso encargado de transmitir las operaciones del usuario al kernel. Este proceso es el intérprete de comandos o un programa específico que se ejecuta tras el inicio de sesión, es decir, el shell.

El Shell es la interfaz entre el usuario y el sistema Linux. Hay muchos tipos de Shell en Linux, y cada uno tiene características diferentes. Los más comunes son sh (Bourne Shell), csh (C Shell), ksh (Korn Shell), tcsh (TENEX/TOPS-20 type C Shell), bash (Bourne Again Shell), etc.

El administrador del sistema puede asignar un Shell al usuario según las condiciones del sistema y los hábitos del usuario. Si no se especifica un Shell, el sistema usa sh como Shell de inicio de sesión predeterminado, es decir, el valor de este campo es /bin/sh.

El Shell de inicio de sesión del usuario también puede especificarse como un programa específico (este programa no es un intérprete de comandos).

Aprovechando esta característica, podemos limitar al usuario para que solo pueda ejecutar la aplicación especificada; cuando la aplicación termina, el usuario sale automáticamente del sistema. Algunos sistemas Linux exigen que solo los programas registrados en el sistema puedan aparecer en este campo.

8) En el sistema hay un tipo de usuarios llamados pseudo-usuarios (pseudo users).

Estos usuarios también ocupan un registro en el archivo /etc/passwd, pero no pueden iniciar sesión porque su Shell de inicio de sesión está vacío. Su existencia facilita principalmente la administración del sistema y satisface los requisitos de los procesos del sistema correspondientes sobre el propietario de los archivos.

Los pseudo usuarios más comunes son los siguientes:

伪 用 户 含 义 
bin 拥有可执行的用户命令文件 
sys 拥有系统文件 
adm 拥有帐户文件 
uucp UUCP使用 
lp lp或lpd子系统使用 
nobody NFS使用

Tienen archivos de cuenta

1. Además de los pseudo usuarios enumerados anteriormente, hay muchos pseudo usuarios estándar, como: audit, cron, mail, usenet, etc., que también son necesarios para los procesos y archivos correspondientes.

Dado que el archivo /etc/passwd es legible por todos los usuarios, si la contraseña de un usuario es demasiado simple o tiene un patrón evidente, una computadora común puede descifrarla fácilmente. Por lo tanto, los sistemas Linux con altos requisitos de seguridad separan la contraseña cifrada y la almacenan en un archivo independiente: el archivo /etc/shadow. Solo el superusuario tiene permiso de lectura sobre este archivo, lo que garantiza la seguridad de las contraseñas de los usuarios.

2. Las líneas de registro en /etc/shadow se corresponden una a una con las de /etc/passwd; este archivo se genera automáticamente mediante el comando pwconv a partir de los datos en /etc/passwd.

Su formato de archivo es similar al de /etc/passwd; está compuesto por varios campos separados por ":". Estos campos son:

登录名:加密口令:最后一次修改时间:最小时间间隔:最大时间间隔:警告时间:不活动时间:失效时间:标志
  1. "Nombre de inicio de sesión" es la cuenta de usuario que coincide con el nombre de inicio de sesión en el archivo /etc/passwd.
  2. El campo "Contraseña" almacena la contraseña cifrada del usuario, con una longitud de 13 caracteres. Si está vacío, el usuario correspondiente no tiene contraseña y no se necesita contraseña al iniciar sesión; si contiene caracteres que no pertenecen al conjunto { ./0-9A-Za-z }, el usuario correspondiente no puede iniciar sesión.
  3. "Última modificación" indica el número de días transcurridos desde un momento determinado hasta la última vez que el usuario modificó su contraseña. El punto de inicio del tiempo puede variar según el sistema. Por ejemplo, en SCO Linux, este punto de inicio es el 1 de enero de 1970.
  4. "Intervalo mínimo" se refiere al número mínimo de días requerido entre dos cambios de contraseña.
  5. "Intervalo máximo" se refiere al número máximo de días durante el cual la contraseña permanece válida.
  6. El campo "Tiempo de advertencia" indica el número de días entre el momento en que el sistema comienza a advertir al usuario y el momento en que la contraseña del usuario caduca oficialmente.
  7. "Tiempo de inactividad" indica el número máximo de días en que la cuenta puede seguir siendo válida sin actividad de inicio de sesión del usuario.
  8. El campo "Tiempo de caducidad" da un número absoluto de días; si se utiliza este campo, se establece el tiempo de vida de la cuenta correspondiente. Una vez transcurrido, la cuenta ya no es una cuenta válida y no puede usarse para iniciar sesión.

sam:EkdiSECLWPdSa:9740:0:0::::

3. Toda la información de los grupos de usuarios se almacena en el archivo /etc/group.

Agrupar a los usuarios es un medio para administrar a los usuarios y controlar los permisos de acceso en los sistemas Linux.

Cada usuario pertenece a un grupo de usuarios; un grupo puede tener varios usuarios, y un usuario también puede pertenecer a diferentes grupos.

Cuando un usuario es miembro de varios grupos a la vez, en el archivo /etc/passwd se registra el grupo principal al que pertenece el usuario, es decir, el grupo predeterminado al que pertenece al iniciar sesión; los demás grupos se denominan grupos adicionales.

Cuando un usuario necesite acceder a archivos que pertenecen a un grupo adicional, primero debe usar el comando newgrp para convertirse en miembro del grupo al que desea acceder.

Toda la información de los grupos de usuarios se almacena en el archivo /etc/group. El formato de este archivo es similar al archivo /etc/passwd, con varios campos separados por dos puntos (:), estos campos son:

组名:口令:组标识号:组内用户列表
  1. "Nombre de grupo" es el nombre del grupo de usuarios, compuesto por letras o números. Al igual que los nombres de inicio de sesión en /etc/passwd, los nombres de grupo no deben repetirse.
  2. El campo "contraseña" almacena la contraseña cifrada del grupo de usuarios. Generalmente, los grupos de usuarios en sistemas Linux no tienen contraseña, por lo que este campo suele estar vacío o contener un *.
  3. El "identificador de grupo" es similar al identificador de usuario; también es un número entero que el sistema utiliza internamente para identificar al grupo.
  4. La "lista de usuarios del grupo" es la lista de todos los usuarios que pertenecen a este grupo; los diferentes usuarios están separados por comas (,). Este grupo puede ser el grupo principal del usuario o un grupo adicional.

Un ejemplo del archivo /etc/group es el siguiente:

root::0:root
bin::2:root,bin
sys::3:root,uucp
adm::4:root,adm
daemon::5:root,daemon
lp::7:root,lp
users::20:root,sam

IV. Agregar usuarios por lotes

Agregar y eliminar usuarios es algo sencillo para cualquier administrador de sistemas Linux. Lo más complicado es cuando hay que añadir decenas, cientos o incluso miles de usuarios; no es posible usar useradd uno por uno, por lo que es necesario encontrar un método sencillo para crear una gran cantidad de usuarios. Linux proporciona herramientas para crear muchos usuarios, que le permiten crear una gran cantidad de usuarios de inmediato. El método es el siguiente:

(1) Primero edite un archivo de texto de usuarios.

Cada columna se escribe según/etc/passwdel formato del archivo de contraseñas. Tenga en cuenta que el nombre de usuario, UID y directorio de inicio de cada usuario no pueden ser iguales; el campo de contraseña puede dejarse en blanco o introducir una x. Un archivo de ejemplo user.txt tiene el siguiente contenido:

user001::600:100:user:/home/user001:/bin/bash
user002::601:100:user:/home/user002:/bin/bash
user003::602:100:user:/home/user003:/bin/bash
user004::603:100:user:/home/user004:/bin/bash
user005::604:100:user:/home/user005:/bin/bash
user006::605:100:user:/home/user006:/bin/bash

(2) Ejecute el comando como root/usr/sbin/newusers, desde el archivo de usuarios recién creadouser.txtse importan los datos y se crean los usuarios:

# newusers < user.txt
