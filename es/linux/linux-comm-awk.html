Comando awk de Linux

Referencia completa de comandos Linux

awk es un lenguaje para procesar archivos de texto y una poderosa herramienta de análisis de texto.

awk puede leer archivos de texto línea por línea y ofrece funcionalidades similares a las de un lenguaje de programación, por ejemplo:

  • Definición de variables y cálculo
  • Condiciones y bucles
  • Procesamiento de cadenas y salida formateada

Estas características hacen que AWK sea muy eficiente al procesar texto estructurado (como archivos CSV o de registro).

Se llama awk porque toma las iniciales de los apellidos de sus tres creadores: Alfred Aho, Peter Weinberger y Brian Kernighan.

Sintaxis

awk options 'pattern {action}' file

Descripción de los parámetros de opción:

  • options: son algunas opciones que se utilizan para controlarawkel comportamiento.
  • pattern: es el patrón que se utiliza para hacer coincidir los datos de entrada. Si se omite, entoncesawkoperará sobre todas las líneas.
  • {action}: es la acción que se ejecuta sobre las líneas que coinciden con el patrón. Si se omite, la acción predeterminada es imprimir la línea completa.

Descripción de los parámetros de options:

  • -F <分隔符> 或 --field-separator=<分隔符>: especifica el separador de campos de entrada; por defecto es un espacio. Con esta opción se puede especificar un separador de campos distinto del separador predeterminado.

  • -v <变量名>=<值>: estableceawkel valor de la variable interna. Con esta opción se pueden pasar valores externos aawklas variables del script.

  • -f <脚本文件>: especifica un archivo que contieneawkel script. Así se pueden escribir scripts más grandes en un archivoawky luego, mediante la-fopción, cargarlo.

  • -V 或 --version: muestraawkla información de versión.

  • -h 或 --help: muestraawkla información de ayuda, incluyendo opciones y ejemplos de uso.

A continuación se presentan algunos usos comunes del comando awk:

Imprimir toda la línea:

awk '{print}' file

Imprimir una columna específica:

awk '{print $1, $2}' file

Usar un delimitador para especificar columnas:

awk -F',' '{print $1, $2}' file

Imprimir el número de líneas:

awk '{print NR, $0}' file

Imprimir las líneas cuyo número cumpla una condición:

awk '/pattern/ {print NR, $0}' file

Calcular la suma de una columna:

awk '{sum += $1} END {print sum}' file

Imprimir el valor máximo:

awk 'max < $1 {max = $1} END {print max}' file

Salida formateada:

awk '{printf "%-10s %-10s\n", $1, $2}' file

Uso básico

El contenido del archivo de texto log.txt es el siguiente:

2 this is a test
3 Do you like awk
This's a test
10 There are orange,apple,mongo

Uso 1: Sintaxis básica

awk '{ [pattern] action }' filenames

Nota:La parte del script de awk debe usar comillas simples' 'para encerrarla.

Ejemplo 1: Imprimir la 1.ª y la 4.ª columna de cada línea.

awk '{print $1, $4}' log.txt

Salida:

2 a
3 like
This's
10 orange,apple,mongo

Ejemplo 2: Salida formateada

printf puede personalizar el formato de salida (similar al printf del lenguaje C):

awk '{printf "%-8s %-10s\n", $1, $4}' log.txt

Salida:

2        a
3        like
This's
10       orange,apple,mongo

Uso 2: Especificar el delimitador -F

-FLa opción se utiliza para especificar el separador entre columnas, equivalente a la variable integradaFS (Field Separator)。

Ejemplo 1: Usar la coma,como delimitador

awk -F, '{print $1, $2}' log.txt

Salida:

2 this is a test
3 Do you like awk
This's a test
10 There are orange apple

Ejemplo 2: Usar la variable integrada FS para establecer el delimitador

awk 'BEGIN { FS="," } {print $1, $2}' log.txt

El resultado de salida es el mismo:

2 this is a test
3 Do you like awk
This's a test
10 There are orange apple

Ejemplo 3: Usar múltiples delimitadores (espacio o coma)

[ ,]Indica que tanto el espacio como la coma se utilizan como delimitadores.

awk -F '[ ,]' '{print $1, $2, $5}' log.txt

Salida:

2 this test
3 Do awk
This's a
10 There apple

Uso 3: Usar -v para establecer variables

-vLa opción se utiliza para pasar variables externas antes de ejecutar el script AWK; se usa comúnmente para asignación dinámica.

Formato de sintaxis:

awk -v 变量名=值 '{动作}' 文件名

Ejemplo 1: Definir una variable numérica y usarla en operaciones

awk -va=1 '{print $1, $1+a}' log.txt

Salida:

2 3
3 4
This's 1
10 11

Explicación:

  • -v a=1 significa definir la variable a=1;
  • $1+a significa sumar la primera columna con la variable a.

Cuando $1 no es un número (por ejemplo, This's), el resultado es vacío o se imprime tal cual.

Ejemplo 2: Definir varias variables a la vez

awk -va=1 -vb=s '{print $1, $1+a, $1b}' log.txt

Salida:

2 3 2s
3 4 3s
This's 1 This'ss
10 11 10s

Explicación:

  • -vb=s define la variable de cadena b;
  • $1b significa concatenar la primera columna con la variable b (por ejemplo, 2s, 10s).

Uso 4: Usar -f para invocar un script AWK externo

Cuando el script AWK es largo, se puede escribir la lógica en un archivo separado y cargarlo mediante el parámetro -f.

Formato de sintaxis:

awk -f 脚本文件 文件名

Supongamos que tenemos un archivo de script cal.awk con el siguiente contenido:

{ print $1, $1 + 10 }

Ejecutar el comando:

awk -f cal.awk log.txt

Salida:

2 12
3 13
This's 10
10 20

Explicación:

  • -f cal.awk significa ejecutar el script externo cal.awk;
  • AWK ejecutará las acciones definidas en el script para cada línea de log.txt.

Uso de expresiones regulares, coincidencia de cadenas

# 输出第二列包含 "th"，并打印第二列与第四列
$ awk '$2 ~ /th/ {print $2,$4}' log.txt
---------------------------------------------
this a

~ indica el inicio del patrón. El patrón está dentro de //.

# 输出包含 "re" 的行
$ awk '/re/ ' log.txt
---------------------------------------------
3 Do you like awk
10 There are orange,apple,mongo

Ignorar mayúsculas y minúsculas

$ awk 'BEGIN{IGNORECASE=1} /this/' log.txt
---------------------------------------------
2 this is a test
This's a test

Negación del patrón

$ awk '$2 !~ /th/ {print $2,$4}' log.txt
---------------------------------------------
Are like
a
There orange,apple,mongo
$ awk '!/th/ {print $2,$4}' log.txt
---------------------------------------------
Are like
a
There orange,apple,mongo

Script de awk

Respecto a los scripts de awk, debemos prestar atención a dos palabras clave: BEGIN y END.

  • BEGIN{ aquí se colocan las sentencias que se ejecutan antes del procesamiento }
  • END { aquí se colocan las sentencias que se ejecutan después de procesar todas las líneas }
  • { aquí se colocan las sentencias que se ejecutan al procesar cada línea }

Supongamos que tenemos un archivo como este (tabla de calificaciones de estudiantes):

$ cat score.txt
Marry   2143 78 84 77
Jack    2321 66 78 45
Tom     2122 48 77 71
Mike    2537 87 97 95
Bob     2415 40 57 62

Nuestro script de awk es el siguiente:

$ cat cal.awk
#!/bin/awk -f
#运行前
BEGIN {
    math = 0
    english = 0
    computer = 0
 
    printf "NAME    NO.   MATH  ENGLISH  COMPUTER   TOTAL\n"
    printf "---------------------------------------------\n"
}
#运行中
{
    math+=$3
    english+=$4
    computer+=$5
    printf "%-6s %-6s %4d %8d %8d %8d\n", $1, $2, $3,$4,$5, $3+$4+$5
}
#运行后
END {
    printf "---------------------------------------------\n"
    printf "  TOTAL:%10d %8d %8d \n", math, english, computer
    printf "AVERAGE:%10.2f %8.2f %8.2f\n", math/NR, english/NR, computer/NR
}

Veamos el resultado de la ejecución:

$ awk -f cal.awk score.txt
NAME    NO.   MATH  ENGLISH  COMPUTER   TOTAL
---------------------------------------------
Marry  2143     78       84       77      239
Jack   2321     66       78       45      189
Tom    2122     48       77       71      196
Mike   2537     87       97       95      279
Bob    2415     40       57       62      159
---------------------------------------------
  TOTAL:       319      393      350
AVERAGE:     63.80    78.60    70.00

seq 9 | sed 'H;g' | awk -v RS='' '{for(i=1;i<=NF;i++)printf("%dx%d=%d%s", i, NR, i*NR, i==NR?"\n":"\t")}'

    Campos más adecuados para awk, sed y grep:

    • grep es más adecuado para buscar o hacer coincidir texto simple
    • sed es más adecuado para editar el texto coincidente
    • awk es más adecuado para formatear texto y realizar un procesamiento de formato más complejo

    Opiniones personales sobre las variables integradas de awk, simples y fáciles de entender

    Expliquemos las variables:

    Variables: se dividen en variables integradas y variables personalizadas; el separador de entrada FS y el separador de salida OFS pertenecen a las variables integradas.

    Las variables integradas son variables predefinidas e internas de awk, mientras que las variables personalizadas son definidas por el usuario.

    • FS (Field Separator): separador de campos de entrada, por defecto es un carácter en blanco
    • OFS (Out of Field Separator): separador de campos de salida, por defecto es un carácter en blanco
    • RS (Record Separator): separador de registros de entrada (salto de línea de entrada), especifica el salto de línea usado en la entrada
    • ORS (Output Record Separator): separador de registros de salida (salto de línea de salida), al generar la salida reemplaza el salto de línea con el símbolo especificado
    • NF (Number for Field): el número de campos de la línea actual (es decir, en cuántas columnas se divide la línea actual)
    • NR (Number of Record): número de línea, el número de línea de la línea de texto que se está procesando actualmente
    • FNR: número de línea contado por separado para cada archivo
    • ARGC: número de argumentos de la línea de comandos
    • ARGV: array que guarda los argumentos dados en la línea de comandos

    Métodos para definir variables personalizadas

    • Método 1: -v varname=value, los nombres de las variables distinguen entre mayúsculas y minúsculas.
    • Método 2: definir directamente en el programa.
