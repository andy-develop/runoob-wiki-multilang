VBScript SetLocaleFunción

Manual de referencia completo de VBScript

La función SetLocale establece el ID de locale y devuelve el ID de locale anterior. function sets the locale ID and returns the previous locale ID.

Un locale es un conjunto de información de referencia del usuario, como idioma, país, región y costumbres culturales. El locale determina la distribución del teclado, el orden de clasificación alfabético, el formato de fecha, hora, números y moneda, etc.

Consejo:Utilice la función GetLocale para obtener el ID de locale.

Sintaxis

SetLocale(lcid)

Parámetros Descripción
lcid Obligatorio. Cualquiera enTabla de ID de Localede la tabla: una cadena corta, un valor hexadecimal o un valor decimal; el valor debe identificar de forma única una región geográfica. Si el parámetro lcid se establece en 0, el locale será determinado por la configuración del sistema.

Ejemplo

Ejemplo 1 (solo para IE)

Utilice la función GetLocale para comprobar el ID de locale actual. Establezca el ID de locale = 2057 y vuelva a comprobar el ID de locale:

<script type="text/vbscript">

document.write(GetLocale() & "<br />")
SetLocale(2057)
document.write(GetLocale())

</script>

La salida del ejemplo anterior es:

document.write(GetLocale() & "
") SetLocale(2057) document.write(GetLocale())

Ejemplo 2 (solo para IE)

La función SetLocale tambiéndevuelveel ID anterior:

<script type="text/vbscript">

document.write(SetLocale(1044))

</script>

La salida del ejemplo anterior es:

document.write(SetLocale(1044)) SetLocale(0)
