Automatización de flujos de trabajo con IA

Todos hemos tenido alguna vez esta experiencia:

  • Cada mañana al llegar a la oficina, pasas media hora revisando correos, seleccionas los importantes y luego respondes uno a uno.

  • Después de recibir comentarios de clientes, tienes que organizarlos y clasificarlos manualmente, y luego enviarlos al responsable correspondiente.

  • Las redes sociales deben actualizarse periódicamente; cada vez hay que redactar el texto, seleccionar imágenes y programar la publicación.

Estas tareas repetitivas consumen mucho de tu tiempo, pero en realidad no requieren demasiado pensamiento.

La automatización de flujos de trabajo con IA sirve para resolver este tipo de problemas: delegar las tareas repetitivas y con reglas claras a la IA para que las complete automáticamente.

El objetivo central de la automatización de flujos de trabajo es:Liberar tu tiempo de la ejecución para dedicarlo a la toma de decisiones。

¿Qué es un flujo de trabajo con IA?

Un flujo de trabajo con IA conecta múltiples capacidades y herramientas de IA para formar un proceso automatizado.

En pocas palabras: cuando ocurre un evento, se desencadena una serie de acciones, y la IA interviene para comprender, evaluar y generar.

El concepto de automatización de flujos de trabajo

Un flujo de trabajo típico consta de tres partes:

ComponenteFunciónEjemplo común
Disparador (Trigger)En qué circunstancia se inicia la ejecuciónRecibir un correo nuevo, llegar a una hora programada, alguien envía un formulario
Acción (Action)Qué operación se ejecutaEnviar mensajes, guardar datos, generar contenido
Condición (Condition)Manejar de forma distinta según cada situaciónSi es un correo urgente, notificar; de lo contrario, preparar un resumen

Pongamos un ejemplo concreto:

  • Disparador: revisar el sitio web de noticias designado cada 6 horas.

  • Acción 1: la IA extrae el contenido de las noticias y selecciona las relevantes para tu sector.

  • Acción 2: la IA resume las noticias relevantes en un resumen de menos de 100 caracteres.

  • Acción 3: enviar el resumen a tu canal de Slack.

Este es un flujo de trabajo completo con IA. Una vez configurado, se ejecutará automáticamente sin necesidad de que hagas nada.

Flujo de trabajo con IA vs automatización tradicional

La mayor diferencia entre el flujo de trabajo con IA y la automatización tradicional es que la IA puede procesar contenido no estructurado y tomar decisiones.

Elemento de comparaciónAutomatización tradicionalFlujo de trabajo con IA
Contenido procesadoSolo puede procesar datos estructuradosPuede comprender texto, imágenes y voz
Origen de las reglasRequiere reglas fijas escritas por personasLa IA puede tomar decisiones según el contenido
FlexibilidadSi cambian las reglas, hay que reescribirlasCon ajustar el prompt se puede cambiar el comportamiento
Escenarios de aplicaciónTareas simples, repetitivas y deterministasTareas complejas que requieren comprensión y criterio

Por ejemplo, reenviar un correo a Zhang San al recibirlo: esto es automatización tradicional, con reglas claras.

Después de recibir un correo, la IA evalúa su importancia: si es importante, notifica de inmediato; si no, prepara un resumen y lo envía una vez por semana. Esto es un flujo de trabajo con IA, que requiere comprensión y criterio.

Plataforma de flujos de trabajo n8n

n8n es una herramienta de automatización de flujos de trabajo de código abierto; se puede alojar por cuenta propia o usar la versión en la nube.

n8n se caracteriza por una operación completamente visual; puedes crear flujos de trabajo complejos mediante arrastrar y soltar.

Dirección del código abierto:https://github.com/n8n-io/n8n

Instalación de n8n

Prueba n8n con un solo comando mediante npx (requiere tener instalado Node.js previamente):

npx n8n

También puedes desplegarlo y ejecutarlo con Docker:

# 创建数据持久化卷
docker volume create n8n_data
# 启动 n8n 容器
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

Una vez desplegado, abre http://localhost:5678 en el navegador y verás la interfaz de n8n.

Si no quieres montarlo tú mismo, también puedes usar la versión en la nube n8n Cloudhttps://n8n.io/, solo tienes que registrarte y ya puedes usarla.

Conceptos clave: nodos, conexiones, disparadores

La interfaz de n8n se compone de un lienzo y nodos. Con entender tres conceptos clave puedes empezar a usarla:

ConceptoFunciónDescripción
Nodo (Node)Ejecuta operaciones concretasPor ejemplo, "enviar correo", "llamar a OpenAI", "guardar datos"
Conexión (Connection)Conecta nodosArrastra de un nodo a otro para definir el orden de ejecución
Disparador (Trigger)Inicia el flujo de trabajoEl primer nodo de cada flujo de trabajo define "cuándo empezar"

Pasos básicos para crear un flujo de trabajo:

  • 1. Añade un nodo disparador en el lienzo (por ejemplo, "disparador programado" o "Webhook").

  • 2. Añade el primer nodo de acción y configura sus parámetros.

  • 3. Arrastra una línea desde el disparador hasta el nodo de acción.

  • 4. Continúa añadiendo más nodos y conéctalos en orden.

  • 5. Haz clic en "Probar" para ver si el flujo funciona correctamente.

  • 6. Activa el flujo de trabajo para que se ejecute automáticamente.

Integración del nodo de OpenAI

n8n incluye un nodo de OpenAI integrado que permite llamar directamente a los modelos GPT.

Pasos de configuración:

  • 1. Busca OpenAI en la lista de nodos y arrástralo al lienzo.

  • 2. Añade tu clave de API de OpenAI en la configuración del nodo.

  • 3. Selecciona el modelo a usar (por ejemplo, gpt-3.5-turbo o gpt-4).

  • 4. Escribe el prompt; puedes hacer referencia a los datos de salida de los nodos anteriores.

Una configuración típica de prompt podría verse así:

请把下面的邮件内容总结成 3 句话摘要：

{{$json.body}}

摘要：

Aquí {{$json.body}} hace referencia al contenido del cuerpo del nodo de correo anterior.

Práctica: resumir correos automáticamente y enviar notificaciones a Slack

Vamos a crear un flujo de trabajo completo: al recibir un correo, la IA resume el contenido y luego lo envía a Slack.

Este flujo de trabajo necesita tres nodos:

  • 1. Disparador de correo: se activa cuando se recibe un nuevo correo.

  • 2. Nodo de OpenAI: resume el contenido del correo en un resumen.

  • 3. Nodo de Slack: envía el resumen al canal especificado.

Puntos clave de configuración:

  • Nodo de correo: configura IMAP o usa el disparador de correo de n8n.

  • Nodo de OpenAI: configura el prompt para resumir este correo en no más de 100 caracteres y haz referencia al cuerpo del correo en la entrada.

  • Nodo de Slack: configura el Slack Bot Token, selecciona el canal y haz referencia a la salida de OpenAI en el contenido del mensaje.

Conecta estos tres nodos, pruébalos y, si funciona, actívalo. El flujo de trabajo se ejecutará automáticamente.

La biblioteca de nodos de n8n es muy amplia; admite cientos de servicios como Gmail, Notion, Airtable, Google Sheets, etc. Dedica tiempo a explorar la biblioteca de nodos y descubrirás muchos escenarios que se pueden automatizar.

Make (antes Integromat)

Make es otra plataforma popular de automatización de flujos de trabajo, originalmente llamada Integromat; en 2021 cambió su nombre a Make.

En comparación con n8n, Make está más orientado a usuarios comerciales, tiene una interfaz más refinada y su versión de pago ofrece más funciones.

Comparación entre Make y n8n

Elemento de comparaciónn8nMake
Código abiertoSí, se puede autoalojar.No, SaaS puro.
Versión gratuita.Autoalojamiento completamente gratuito.Sí, con funciones limitadas.
Interfaz.Orientada a usuarios técnicos.Más amigable y pulida.
Número de nodos.Cientos.Miles.
Funciones empresariales.Requiere versión de pago.Completas.
Curva de aprendizaje.Algo empinada.Más suave.

Resumen: si quieres tener el control total y tienes habilidades técnicas, elige n8n; si prefieres algo más sencillo de usar y con soporte empresarial, elige Make.

Uso de módulos de IA

Make incluye varios módulos relacionados con IA:

Módulo de OpenAI: permite llamar a modelos como GPT, DALL-E, Whisper, etc.

Módulo Make AI: las funciones de IA propias de Make, que pueden procesar datos de forma inteligente.

Otras herramientas de IA: compatible con Anthropic Claude, Google AI, Midjourney, etc.

Flujo para usar IA en Make:

  • 1. Busca OpenAI u otra herramienta de IA que quieras usar en la biblioteca de módulos.

  • 2. Arrástralo al lienzo del escenario.

  • 3. Configura la clave de API y los parámetros.

  • 4. Pasa los datos de los módulos anteriores al módulo de IA.

  • 5. Pasa la salida de la IA a los módulos siguientes.

Una característica de Make es el asistente de prompts de IA: puedes describir con lenguaje natural lo que quieres hacer y te ayudará a generar el prompt.

Ejemplo práctico

Vamos a crear un flujo de trabajo de "generación automática de contenido para redes sociales" con Make:

  • 1. Disparador: se activa cada lunes a las 9 de la mañana.

  • 2. Módulo de Google Sheets: lee las actualizaciones de productos y la información de actividades que preparaste de antemano.

  • 3. Módulo de OpenAI: genera textos para Weibo, LinkedIn y Twitter según el contenido de la hoja de cálculo.

  • 4. Módulo de Airtable: guarda los textos generados en la tabla de revisión.

  • 5. Módulo de Slack: te notifica "El contenido de esta semana ha sido generado, por favor revísalo en Airtable".

Una vez configurado todo el flujo, se ejecutará automáticamente cada lunes. Solo necesitas revisar y ajustar el contenido, sin tener que escribir los textos desde cero.

Automatización con IA en Zapier

Zapier es el pionero en automatización de flujos de trabajo, fundado en 2011.

La característica de Zapier es que tiene la mayor cantidad de aplicaciones conectadas (más de 6000) y es el más sencillo de usar.

Uso básico de Zapier

Zapier llama a los flujos de trabajo "Zap". Pasos para crear un Zap:

  • 1. Elige la aplicación desencadenante y el evento desencadenante (por ejemplo, "Gmail recibe un nuevo correo").

  • 2. Conecta tu cuenta y configura las condiciones de activación.

  • 3. Elige la primera aplicación de acción y el evento de acción (por ejemplo, "OpenAI genera texto").

  • 4. Configura los parámetros de la acción y referencia los datos del disparador.

  • 5. Puedes seguir añadiendo más acciones.

  • 6. Prueba y activa el Zap.

La interfaz de Zapier es más simplificada que la de n8n y Make; cada paso es un formulario, sin necesidad de arrastrar y conectar.

Función AI Actions

Zapier ha lanzado una función especial llamada AI Actions, que te permite describir con lenguaje natural lo que quieres hacer y configura automáticamente todo el Zap.

Por ejemplo, si escribes:

当我收到带有"发票"标签的邮件时，把附件保存到 Google Drive，
然后用 AI 提取金额和日期，记录到 Airtable，
最后给我发一条 Slack 通知。

La IA de Zapier identificará automáticamente los pasos necesarios y configurará cada nodo por ti.

También puedes usar IA para que te ayude a escribir prompts. Por ejemplo, al llamar a GPT, si dices "ayúdame a escribir un prompt para resumir este correo", la IA generará una plantilla de prompt profesional.

Escenarios adecuados

Zapier es el más adecuado para estos escenarios:

Escenario.Por qué elegir Zapier.
Conexión de aplicaciones especializadas.Zapier admite más de 6000 aplicaciones, muchas que otros no tienen.
Automatización personal sencilla.La interfaz es la más simple y la curva de aprendizaje es la más rápida.
Usuarios no técnicos.No requiere ningún conocimiento técnico.
Validación rápida de prototipos.Puedes montar un flujo de trabajo en unos minutos.

Recomendaciones para elegir herramienta:Los principiantes empiecen con Zapier; si quieres un control más profundo, usa n8n; para necesidades empresariales, elige Make.En realidad, la idea central de las tres herramientas es la misma; es fácil pasar de una a otra una vez que aprendes una.

GPT personalizado y Proyectos de Claude

Además de usar herramientas de flujo de trabajo para conectar múltiples servicios, también puedes crear asistentes de IA especializados para tareas concretas.

Los GPTs de OpenAI y los Claude Projects de Anthropic son ejemplos de este tipo de herramientas.

Crear un asistente de IA exclusivo

Tomando OpenAI GPTs como ejemplo, los pasos para crear un asistente personalizado:

  • 1. Visita el sitio web oficial de ChatGPT y haz clic en "Explore" → "Create a GPT".

  • 2. En la pestaña "Create", describe con lenguaje natural el asistente que deseas.

  • Por ejemplo: "Eres un editor de documentación técnica de runoob, encargado de explicar conceptos técnicos complejos de forma clara y comprensible para principiantes."

  • 3. En la pestaña "Configure", ajusta configuraciones más detalladas.

  • 4. Añade archivos a la base de conocimiento (opcional).

  • 5. Configura funciones (por ejemplo, búsqueda en internet, intérprete de código).

  • 6. Prueba, ajusta y finalmente publica.

El proceso de creación en Claude Projects es similar; se realiza en la función Projects del sitio web oficial de Claude.

Carga de base de conocimientos

Una gran ventaja de los asistentes de IA personalizados es que puedes subir tu propia base de conocimiento.

Los formatos de archivo compatibles suelen incluir:

Formato.Descripción.
PDFEl más común, adecuado para documentos, informes y libros.
TXTTexto plano, simple y versátil.
DOCXDocumentos de Word.
CSVDatos de tablas.
JSONDatos estructurados.

Una vez subida, la IA responderá preguntas basándose en este conocimiento.

Por ejemplo, puedes subir los documentos de productos de la empresa, manuales de atención al cliente y casos históricos para crear un "asistente de conocimiento interno" al que los empleados pueden consultar directamente.

O sube todos los artículos que hayas escrito para crear un "asistente de estilo de escritura" que imite tu estilo al crear nuevo contenido.

Personalización de instrucciones

Las instrucciones (Instructions) son el núcleo de un asistente personalizado; definen el rol, el comportamiento y el formato de salida de la IA.

Una buena instrucción suele incluir:

  • Definición del rol: quién eres y a qué te dedicas.

  • Reglas de comportamiento: qué debes hacer y qué no debes hacer.

  • Formato de salida: cómo se estructura la respuesta.

  • Restricciones: qué está prohibido y qué precauciones tomar.

Ejemplo de instrucción:

你是 runoob 的技术文档助手。

你的任务是把复杂的技术概念解释得通俗易懂，适合初学者。

回答时请遵循这些规则：
1. 先用一句话简单解释是什么
2. 然后用生活中的例子类比
3. 最后给出一个最简单的代码示例
4. 如果有重要的注意事项，用加粗标出

不要使用太深的术语，必要术语要解释。
保持语气友好、鼓励，像老师在教学生。

Cuanto más específica sea la instrucción, más estable será el rendimiento de la IA.

Webhooks y disparadores

Webhook es un concepto muy importante en la automatización de flujos de trabajo; permite que sistemas externos activen tu flujo en tiempo real.

Cómo funcionan los webhooks

En pocas palabras, un webhook es una "URL de callback".

El método tradicional es el "polling": tu sistema pregunta periódicamente al sistema externo "¿hay datos nuevos?" — esto es muy ineficiente.

El webhook es "push": cuando el sistema externo tiene datos nuevos, te envía activamente una solicitud HTTP para notificarte.

Flujo de trabajo de un webhook:

  • 1. Crea un disparador de Webhook en n8n/Make/Zapier y obtienes una URL.

  • 2. Configura esta URL en el sistema externo (por ejemplo, GitHub, Stripe, tu sitio web).

  • 3. Cuando ocurre un evento en el sistema externo (por ejemplo, alguien hace un commit, alguien realiza un pago), envía datos a esta URL.

  • 4. Tu flujo de trabajo recibe los datos y comienza a ejecutarse.

Los webhooks son en tiempo real; pueden activar el flujo de trabajo en milisegundos después de que ocurre el evento.

Automatización basada en eventos

Los webhooks hacen posible la automatización basada en eventos.

Fuentes de eventos Webhook comunes:

Fuente de evento.Evento típico.Ejemplo de uso.
GitHubAlguien hace commit de código, alguien abre un Issue.Responder automáticamente con IA al recibir un Issue.
StripeAlguien realiza un pago, la suscripción caduca.Enviar un correo de agradecimiento al recibir el pago.
TypeformAlguien envía un formulario.Después del envío del formulario, la IA analiza el contenido y lo asigna
ShopifyNuevos pedidos, alertas de inventarioGenerar automáticamente la nota de entrega al realizar un nuevo pedido
Tu sitio webRegistro de usuarios, mensajesCorreo de bienvenida al registrarse un nuevo usuario

Usamos Python para implementar un flujo simple de recepción de Webhook + procesamiento con IA:

Ejemplo

# ============================================
# Servidor Webhook simple + flujo de procesamiento con IA
# Usar Flask para recibir el Webhook y llamar a OpenAI para procesar
# ============================================

from flask import Flask, request, jsonify
import openai
import json

# Inicializar la aplicación Flask
app = Flask(__name__)

# Configurar OpenAI (reemplaza con tu API Key)
openai.api_key = "sk-your-api-key-here"

def process_with_ai(content: str) -> str:
    """
Procesar el contenido recibido con IA
Aquí hacemos una simple "clasificación de contenido + resumen"
    """
    prompt = f"""
Analiza el siguiente contenido y haz dos cosas:
1. Clasificación: determina si es "problema", "sugerencia" o "agradecimiento"
2. Resumen: resume el contenido principal en una frase

Contenido:
    {content}

Devuelve en formato JSON, con el siguiente formato:
    {{
"category": "problema/sugerencia/agradecimiento",
"summary": "contenido del resumen"
    }}
    """

    response = openai.ChatCompletion.create(
        model="gpt-3.5-turbo",
        messages=[
            {"role": "system", "content": "Eres el asistente de análisis de contenido de runoob."},
            {"role": "user", "content": prompt}
        ],
        temperature=0.7
    )

    return response.choices[0].message.content


@app.route("/webhook", methods=["POST"])
def webhook_handler():
    """
Endpoint para recibir el Webhook
Los sistemas externos envían una solicitud POST a esta URL
    """
    # Obtener los datos de la solicitud
    data = request.get_json()

    print(f"Datos de Webhook recibidos: {data}")

    # Extraer el contenido que necesitamos (ajusta el nombre del campo según el caso)
    # Aquí se asume que los datos enviados tienen un campo "content"
    content = data.get("content", "")

    if not content:
        return jsonify({"status": "error", "message": "Falta el campo content"}), 400

    # Procesar el contenido con IA
    try:
        ai_result = process_with_ai(content)
        print(f"Resultado del procesamiento con IA: {ai_result}")

        # Analizar el JSON devuelto por la IA
        parsed_result = json.loads(ai_result)

        # Aquí puedes guardar el resultado en una base de datos, enviar notificaciones, etc.
        # Para la demostración, solo lo imprimimos
        category = parsed_result.get("category", "Desconocido")
        summary = parsed_result.get("summary", "")

        print(f"Categoría: {category}")
        print(f"Resumen: {summary}")

        # Devolver una respuesta de éxito
        return jsonify({
            "status": "success",
            "category": category,
            "summary": summary
        })

    except Exception as e:
        print(f"Error al procesar: {e}")
        return jsonify({"status": "error", "message": str(e)}), 500


@app.route("/test", methods=["GET"])
def test_page():
    """
Una página de prueba simple para probar el Webhook
    """
    return """
    <html>
        <body>
<h1>Probar Webhook</h1>
            <form action="/webhook" method="post">
<textarea name="content" placeholder="Ingresa contenido de prueba"></textarea>
                <br>
<button type="submit">Enviar</button>
            </form>
        </body>
    </html>
    """


if __name__ == "__main__":
    print("Servidor Webhook iniciado en http://localhost:5000")
    print("Dirección del Webhook: http://localhost:5000/webhook")
    print("Página de prueba: http://localhost:5000/test")
    app.run(port=5000, debug=True)

Después de ejecutar este servidor, puedes abrir http://localhost:5000/test en el navegador para probarlo, o usar curl para enviar una solicitud de prueba:

Ejemplo

# Enviar una solicitud Webhook de prueba
curl -X POST http://localhost:5000/webhook \
  -H "Content-Type: application/json" \
  -d '{
"content": "¡Los tutoriales de runoob son geniales! Sería mejor si hubiera más ejemplos prácticos de flujos de trabajo con IA."
  }'

Si todo funciona correctamente, verás la categoría y el resumen devueltos por la IA.

Al usar Webhook en producción, recuerda añadir mecanismos de verificación — por ejemplo, verificar la firma, comprobar la IP de origen, usar API Key. De lo contrario, cualquiera podría enviar solicitudes a tu Webhook, lo que podría provocar problemas de seguridad.

Colección de proyectos prácticos

En esta sección te ofrecemos tres ideas completas de proyectos prácticos; puedes aplicar directamente estas plantillas.

Generar automáticamente un resumen de noticias diario

Objetivo: recopilar automáticamente noticias del sector cada mañana, que la IA filtre y resuma, y enviarlas a tu correo o Slack.

Herramientas necesarias: n8n/Make/Zapier, fuentes RSS, OpenAI, correo/Slack.

Pasos del flujo de trabajo:

  • 1. Disparador programado: se activa todos los días a las 8 a. m.

  • 2. Nodo RSS: lee las RSS de varios medios del sector que sigues.

  • 3. Nodo de deduplicación: filtra noticias duplicadas.

  • 4. Nodo OpenAI: lee las noticias una a una y determina si son relevantes para tu sector.

  • 5. Nodo OpenAI: resume las noticias relevantes en un resumen.

  • 6. Nodo OpenAI: organiza todos los resúmenes en un correo, añadiendo título e introducción.

  • 7. Nodo de correo: envía a tu correo.

Publicación automática de contenido en redes sociales

Objetivo: generar automáticamente textos para redes sociales en múltiples plataformas según las novedades del producto, y publicarlos de forma programada tras la revisión.

Herramientas necesarias: Make/Zapier, Airtable, OpenAI, Buffer/Hootsuite.

Pasos del flujo de trabajo:

  • 1. Disparador de Airtable: se activa cuando añades un registro de "novedades del producto" en Airtable.

  • 2. Nodo OpenAI: genera un texto para Weibo (estilo vivaz) según las novedades del producto.

  • 3. Nodo OpenAI: genera un texto para LinkedIn (estilo profesional) según las novedades del producto.

  • 4. Nodo OpenAI: genera un texto para Twitter (estilo conciso) según las novedades del producto.

  • 5. Nodo Airtable: escribe los textos de las tres plataformas en la tabla "pendiente de revisión".

  • 6. Nodo Slack: te notifica que hay nuevo contenido pendiente de revisión.

  • 7. (Después de la revisión manual) Nodo Buffer: publica de forma programada en cada plataforma.

Este flujo es automático, pero conserva el control de la revisión manual — después de todo, las redes sociales están directamente orientadas al cliente, así que conviene supervisarlas.

Clasificación automática de comentarios de clientes

Objetivo: tras recibir un comentario del cliente, la IA lo clasifica automáticamente, analiza el sentimiento y lo asigna al responsable correspondiente.

Herramientas necesarias: n8n, Typeform/herramienta de formularios, OpenAI, Airtable, Slack.

Pasos del flujo de trabajo:

  • 1. Disparador Webhook: se activa cuando el cliente envía un comentario en el sitio web.

  • 2. Nodo OpenAI: analiza el sentimiento del comentario (positivo/neutral/negativo).

  • 3. Nodo OpenAI: clasifica el tipo de comentario (Bug/solicitud de función/problema de uso/agradecimiento).

  • 4. Nodo OpenAI: extrae palabras clave y prioridad.

  • 5. Nodo Airtable: guarda toda la información en la base de datos de comentarios.

  • 6. Rama condicional: si es un comentario negativo y de alta prioridad, sigue el flujo urgente; de lo contrario, sigue el flujo normal.

  • 7. Nodo Slack: notifica los comentarios urgentes al responsable técnico y los normales al servicio de atención al cliente.

  • 8. Nodo OpenAI: genera una respuesta automática cortés agradeciendo el comentario del cliente.

9. Nodo de correo: envía la respuesta automática al cliente.

Este flujo permite que el cliente reciba una respuesta de inmediato, mientras que internamente también se pueden atender rápidamente los problemas importantes.

Un principio al diseñar flujos de trabajo:Primero automatiza los trabajos mecánicos como "recopilar, organizar y distribuir", y deja los de "juicio, decisión y creatividad" para las personas. No intentes que la IA tome todas las decisiones; la colaboración entre humanos y máquinas funciona mejor.
