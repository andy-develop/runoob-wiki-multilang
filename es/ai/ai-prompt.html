Introducción a la IA
Panorama de herramientas de IA

Prompt

Aprende las habilidades básicas para dialogar con la IA: escribe buenos prompts y usa bien las herramientas de IA.

Por qué es importante el prompt

Para una misma pregunta, diferentes maneras de formularla producen respuestas de calidad muy distinta.

Puede que hayas tenido esta experiencia:

Le preguntas a la IA: ayúdame a escribir un informe. La IA te da un artículo genérico, vacío y sin contenido.

Pero si cambias la forma de preguntar: Soy gerente de producto, ayúdame a escribir un informe de hoja de ruta del producto para el Q2 de 2026, dirigido al equipo técnico, necesito 5 puntos de función principales, cada uno con ciclo de desarrollo y evaluación de riesgos, y la extensión debe ser de menos de 800 caracteres. La IA te da un documento con estructura clara, contenido específico y listo para usar.

Esa es la diferencia que hace el prompt.

El prompt es el lenguaje con el que te comunicas con la IA.

La IA solo puede responder según la información que le das; cuanto más específica y clara sea esa información, más se ajustará el resultado a lo que esperas.

La regla de oro del prompt:Entrada vaga, salida vaga; entrada específica, salida específica.。

Qué es un Prompt

El prompt es el contenido de texto que le ingresas a la IA.

Un prompt puede ser una pregunta, una instrucción, una descripción, o una combinación de estos.

Buen Prompt vs. mal Prompt

Usamos una comparación para explicar la diferencia entre ambos:

Dimensión❌ Lo que no se recomienda✅ Lo que se recomienda
Claridad"Ayúdame a escribir algo""Ayúdame a redactar un correo electrónico para los clientes informándoles que nuestro producto subirá de precio un 10% el próximo mes"
Configuración de rol"Traduce este párrafo""Eres un traductor profesional de inglés, especializado en documentos técnicos. Traduce el siguiente contenido al chino y mantén la precisión de los términos técnicos"
Requisitos de formato"Haz una lista""Enumera 5 puntos en una lista con viñetas, cada punto no debe superar los 20 caracteres"
Contexto"Ayúdame a revisar este código""Este es un código de rastreador en Python, al ejecutarlo da un error de 'tiempo de espera de conexión', ayúdame a analizar las posibles causas y dame 3 soluciones"
Estilo y tono"Escribe un aviso""Redacta un aviso de vacaciones dirigido a todos los empleados de la empresa, con tono formal, contenido conciso, que incluya tres partes: fechas de vacaciones, precauciones y disposición de turnos"

¿Ves el patrón?

Un buen prompt le dice a la IA: quién eres, qué quieres hacer, para quién es, en qué formato y qué restricciones hay.

Estructura básica del prompt

Un prompt completo suele incluir los siguientes cuatro elementos.

No es necesario escribirlos siempre todos, pero cuanto más completo sea, más controlable será el resultado.

Descripción de la tarea (qué hacer)

Indica claramente a la IA qué tarea quieres que realice.

Esta es la parte central del prompt y debe estar clara.

Resume los puntos principales de este artículo.

Convierte este código de Python a JavaScript.

Ayúdame a pensar 10 nombres adecuados para una tienda de té con leche.

Información de fondo (contexto)

Proporciona a la IA el contexto relevante para que comprenda el escenario de la tarea.

Sin contexto, la IA solo puede adivinar. Con contexto, sus respuestas serán pertinentes.

Soy estudiante de tercer año de informática, preparándome para entrevistas...

Esta es la introducción de producto de nuestra empresa, el cliente objetivo son los dueños de pequeñas y medianas empresas...

Quiero escribir un artículo de divulgación científica para estudiantes de primaria, no se pueden usar términos complejos...

Requisitos de formato de salida (cómo presentarlo)

Especifica el formato de salida de la IA: lista, tabla, párrafo, código, JSON, etc.

Un requisito de formato claro te ahorra tiempo de reorganización posterior.

Preséntalo en forma de tabla con tres columnas: nombre del paso, descripción de la operación, precauciones.

Salida en formato JSON, con tres campos: 'id', 'name', 'description'.

Responde en tres párrafos, cada uno de no más de 100 caracteres.

Ejemplo (como referencia)

Dale a la IA uno o dos ejemplos para que entienda qué tipo de salida quieres.

Esto se llamaFew-shot Learning, es decir, dar algunos ejemplos para que aprenda.

Por ejemplo:

Entrada: feliz, salida: eufórico, exultante, contentísimo

Ahora procesa: triste

Tres tipos básicos de prompts

Según tu objetivo, los prompts se pueden dividir en tres tipos básicos.

Tipo pregunta: hacer una pregunta directa

Se usa para obtener información, explicar conceptos o buscar consejos.

Es el tipo de prompt más simple y adecuado para escenarios de consulta de información.

¿Cuál es la diferencia entre list y tuple en Python?

¿Cómo mejorar la eficiencia de comunicación del equipo?

¿Cuáles son los frameworks de frontend más recomendables para aprender en 2026?

Al preguntar, ten en cuenta: cuanto más específico, mejor.

No preguntes solo: ¿cómo aprender programación? Pregunta: soy principiante, quiero hacer desarrollo web, ¿debo aprender primero HTML/CSS o JavaScript? Por favor, dame un plan de estudio de 3 meses.

Tipo instrucción: decirle a la IA qué hacer

Se usa para completar tareas específicas: escribir, traducir, modificar código, organizar datos, etc.

Un prompt de tipo instrucción debe ser claro, específico y ejecutable.

Traduce este texto al inglés conservando el humor del original.

Divide este párrafo largo en 5 puntos pequeños y añade un subtítulo a cada punto.

Ayúdame a optimizar este código, añade comentarios y encuentra posibles bugs.

Tipo conversación: intercambio de múltiples turnos

No es una pregunta única, sino una conversación continua que va profundizando poco a poco.

Este método es adecuado para tareas complejas, puedes ajustar el rumbo mientras conversas.

Tú: 'Quiero hacer un sitio web de blog personal, ¿qué opciones técnicas recomiendas?'

IA: 'Según tus necesidades, se pueden considerar las siguientes opciones: ...'

Tú: 'Elijo Hugo, ¿cómo empiezo concretamente?'

IA: 'Bien, los pasos para crear un blog con Hugo son los siguientes: ...'

Tú: 'Espera, no quiero usar GitHub Pages, ¿hay otras opciones de alojamiento gratuitas?'

La clave del prompt de tipo conversación es: recuerda que la IA tiene memoria de contexto. No necesitas repetir lo anterior cada vez, solo continúa la conversación.

Prompt de rol

Asigna un rol a la IA y sus respuestas serán más profesionales y acordes al escenario.

Es una de las técnicas más simples pero más efectivas.

Por qué es útil el juego de roles

La IA ha visto una gran cantidad de textos de distintos roles durante el entrenamiento. Cuando le dices 'eres un abogado', automáticamente ajusta su tono, vocabulario y forma de pensar, y se vuelve más similar a un abogado real.

La misma pregunta, con diferentes roles, produce respuestas completamente distintas.

Por ejemplo, preguntas: '¿Cómo hacer que más personas conozcan mi producto?'

Rol asignadoEnfoque de la respuesta
Experto en marketingPosicionamiento de marca, elección de canales, planificación de actividades
Director de ventasEmbudo de conversión, seguimiento de clientes, técnicas de cierre de ventas
Gerente de productoPuntos de venta del producto, experiencia de usuario, diferenciación
Responsable técnicoImplementación técnica, optimización de rendimiento, análisis de datos

Plantillas de roles comunes

Aquí tienes algunas configuraciones de roles de uso común; puedes aplicarlas directamente o modificarlas según sea necesario:

Eres un ingeniero de desarrollo de Python con amplia experiencia, especializado en revisión de código y optimización de rendimiento. Por favor, revisa este código...

Eres un redactor publicitario profesional con 10 años de experiencia en la industria publicitaria. Por favor, ayúdame a reescribir esta descripción de producto...

Eres mi profesor particular de japonés, con pronunciación estándar y habilidad para corregir errores de principiantes. Por favor, revisa la gramática de esta conversación...

Eres un mentor de emprendimiento que ha fundado con éxito tres empresas tecnológicas. Por favor, analiza este plan de negocios...

Cuanto más específica sea la configuración del rol, mejores serán los resultados.

No digas solo "eres un experto", di "eres un experto en análisis de datos de comercio electrónico con 5 años de experiencia, especialmente hábil en análisis de comportamiento de usuarios".

Técnicas para hacer la salida más precisa

Domina estas técnicas y tu habilidad con los prompts mejorará enormemente.

Especificar el formato de salida

Indicarle claramente a la IA en qué formato debe generar la salida te ahorrará mucho tiempo de organización.

Los formatos comunes incluyen:

Tipo de formatoEjemplo de instrucción
Lista"Usa una lista con viñetas para enumerar 5 puntos clave..."
Tabla"Preséntalo en una tabla con las columnas: función, ventajas, desventajas..."
Código"Genera el código Python completo, incluidos los comentarios..."
JSON"Genera en formato JSON, con los campos: id, name, price..."
Markdown"Usa formato Markdown, con 3 títulos de segundo nivel..."

Controlar la longitud

Dile a la IA la longitud que deseas para la salida, para evitar que se extienda demasiado o que sea demasiado breve.

Resume en una frase...

Escribe una introducción de unas 300 palabras...

Explícalo en detalle, con al menos 500 palabras...

Especificar tono y estilo

Indícale a la IA qué tono debe usar para adaptarse a diferentes escenarios de comunicación.

Tono formal, adecuado para presentarlo a los superiores...

Exprésalo de manera ligera y con humor...

Con un lenguaje sencillo y fácil de entender, adecuado para que lo comprendan estudiantes de primaria...

Mantén un tono profesional, objetivo y neutral...

Cadena de pensamiento (Chain of Thought)

Para problemas complejos, haz que la IA verbalice su proceso de pensamiento en lugar de dar la respuesta directamente.

Esto puede mejorar significativamente la precisión de las respuestas y también te facilita verificar su proceso de razonamiento.

Analiza este problema paso a paso: primero explica tu razonamiento y luego da la respuesta.

Cuando encuentres puntos inciertos, explica tus suposiciones y tu proceso de razonamiento.

Errores comunes y correcciones

Los principiantes suelen cometer estos errores; veamos cómo corregirlos.

Error 1: el prompt es demasiado vago

Este es el problema más común.

❌ Prompt ambiguo✅ Prompt mejorado
"Ayúdame a escribir un texto publicitario""Ayúdame a escribir un artículo para la cuenta oficial de WeChat sobre el lanzamiento de un nuevo producto en una tienda de té con leche, dirigido a jóvenes de 18 a 25 años, con un estilo vivaz e interesante, destacando la promoción de 'segunda unidad a mitad de precio', con una extensión de 300 a 500 palabras"
"Ayúdame a revisar este código""Este es un código de una interfaz de registro de usuarios escrito en Python. Revísalo para verificar si hay riesgo de inyección SQL, si el cifrado de contraseñas es seguro y si el manejo de errores es adecuado. Enumera por separado los problemas y las sugerencias de corrección"
"Ayúdame a hacer un plan""Ayúdame a crear un plan de ejercicios de 3 meses con el objetivo de perder 5 kg, haciendo ejercicio 3 veces por semana, 1 hora cada vez, principalmente con carrera y entrenamiento de fuerza. Proporciona un plan detallado por semanas"

Error 2: pedir demasiado, no se puede decir todo de una vez

No intentes hacerlo todo en un solo prompt.

Las tareas complejas deben dividirse en varias rondas de conversación, avanzando paso a paso.

❌ No hagas esto: "Ayúdame a crear un sitio web de comercio electrónico que tenga registro de usuarios, exhibición de productos, carrito de compras, gestión de pedidos y funciones de pago, desarrollado con React y Node.js, con base de datos MySQL. Dame el código completo."

✅ Deberías hacerlo así:

Tú: "Quiero crear un sitio web de comercio electrónico sencillo, con una pila tecnológica de React + Node.js + MySQL. ¿Cuál debería ser el primer paso?"

IA: "Recomiendo diseñar primero la estructura de las tablas de la base de datos. Podemos comenzar con la tabla de usuarios y la de productos..."

Tú: "De acuerdo, ayúdame a diseñar la estructura de las tablas de usuarios y productos. ¿Qué campos deberían incluir?"

... (profundizando paso a paso)

Error 3: no dar retroalimentación y persistir en el error

La primera salida de la IA puede que no sea perfecta.

No importa; dile qué está mal y pídele que lo corrija.

Tú: "Este artículo es demasiado largo y demasiado técnico. Mis lectores son principiantes y no lo entenderán."

IA: "Lo siento, lo reescribiré de forma más concisa y fácil de entender..."

Tú: "Mucho mejor, pero la segunda parte sigue siendo un poco compleja. ¿Puedes explicar este concepto usando una analogía?"

IA: "Claro, usemos la analogía de 'enviar un paquete' para explicar este proceso de comunicación en red..."

Recuerda: el prompt es un proceso iterativo. Rara vez sale perfecto a la primera.

Ejemplo de invocación de IA con código

Además de escribir prompts en la interfaz de chat, también puedes llamar a la API de IA mediante código.

Vamos a demostrarlo con Python:

Ejemplo

# ============================================
# Usa Python para llamar a la API de IA y enviar un prompt
# Este ejemplo muestra cómo estructurar tu prompt
# ============================================

import json
from typing import Dict, Optional


class PromptBuilder:
    """Constructor de prompts, te ayuda a organizar tus prompts de manera estructurada"""

    def __init__(self):
        self.role = None          # Configuración del rol
        self.task = None          # Descripción de la tarea
        self.context = None       # Información de contexto
        self.format = None        # Formato de salida
        self.examples = []        # Ejemplo
        self.constraints = []     # Restricciones

    def set_role(self, role: str) -> "PromptBuilder":
        """Establece el rol de la IA"""
        self.role = role
        return self

    def set_task(self, task: str) -> "PromptBuilder":
        """Establece la tarea"""
        self.task = task
        return self

    def set_context(self, context: str) -> "PromptBuilder":
        """Establece la información de contexto"""
        self.context = context
        return self

    def set_format(self, format_spec: str) -> "PromptBuilder":
        """Establece el formato de salida"""
        self.format = format_spec
        return self

    def add_example(self, input_example: str, output_example: str) -> "PromptBuilder":
        """Agrega un ejemplo"""
        self.examples.append({"input": input_example, "output": output_example})
        return self

    def add_constraint(self, constraint: str) -> "PromptBuilder":
        """Agrega restricciones"""
        self.constraints.append(constraint)
        return self

    def build(self) -> str:
        """Construye el prompt final"""
        parts = []

        if self.role:
            parts.append(f"Rol: {self.role}")

        if self.context:
            parts.append(f"Contexto: {self.context}")

        if self.task:
            parts.append(f"Tarea: {self.task}")

        if self.examples:
            parts.append("Ejemplo:")
            for i, example in enumerate(self.examples, 1):
                parts.append(f" Entrada {i}: {example['input']}")
                parts.append(f" Salida {i}: {example['output']}")

        if self.format:
            parts.append(f"Formato de salida: {self.format}")

        if self.constraints:
            parts.append("Restricciones:")
            for constraint in self.constraints:
                parts.append(f"  - {constraint}")

        return "\n".join(parts)


def simulate_ai_call(prompt: str, api_key: Optional[str] = None) -> Dict:
    """
Simular llamada a la API de IA (en un proyecto real, reemplazar por una llamada real a la API)
Aquí solo se demuestra cómo usar prompts estructurados
    """
    print("=" * 60)
    print("Prompt enviado a la IA:")
    print("-" * 60)
    print(prompt)
    print("=" * 60)

    # Aquí solo es una demostración, en un proyecto real se llamará a la API real
    # Por ejemplo: OpenAI API, Anthropic API, etc.

    return {
        "status": "success",
        "prompt_sent": prompt,
        "message": "Esta es una respuesta simulada de la IA (en uso real se reemplazará por la respuesta real de la API)",
        "tips": "En el proyecto real de runoob, configura tu API Key y llama a la API real"
    }


# ============================================
# Ejemplo de uso 1: Escribir un correo electrónico
# ============================================

print("\n【Ejemplo 1: Escribir un correo electrónico】)

prompt1 = (PromptBuilder()
           .set_role("Eres un asistente profesional de escritura empresarial, experto en redactar correos electrónicos en inglés")
           .set_context("Soy el gerente de marketing de la empresa runoob, necesito escribir un correo de seguimiento a un cliente")
           .set_task("Escribe un correo para preguntar al cliente su opinión sobre nuestra propuesta de producto y programar una reunión para la próxima semana")
           .set_format("Formato del correo: asunto, saludo, cuerpo, despedida")
           .add_constraint("Tono amigable pero profesional")
           .add_constraint("No exceder 200 palabras")
           .build())

result1 = simulate_ai_call(prompt1)
print(f"Estado de la API: {result1['status']}")


# ============================================
# Ejemplo de uso 2: Optimización de código
# ============================================

print("\n【Ejemplo 2: Optimización de código】)

prompt2 = (PromptBuilder()
           .set_role("Eres un ingeniero senior de Python con experiencia, experto en revisión de código")
           .set_task("Optimiza el siguiente código para que sea más eficiente y legible")
           .set_context("Este es un código que procesa datos de calificaciones de estudiantes, es un poco lento")
           .set_format("Muestra el código optimizado y explica con comentarios los motivos de los cambios")
           .add_constraint("Mantén la funcionalidad original sin cambios")
           .add_constraint("Compatible con Python 3.8+")
           .build())

result2 = simulate_ai_call(prompt2)
print(f"Estado de la API: {result2['status']}")

Ejecuta este código y verás cómo se construyen los prompts estructurados.

En un proyecto real, debes reemplazarlo por llamadas reales a la API (como OpenAI, Anthropic u otras APIs de otros proveedores).
