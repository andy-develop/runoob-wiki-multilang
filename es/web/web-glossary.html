Web Glosario

Los siguientes términos están ordenados alfabéticamente

Access (Microsoft Access)

Un sistema de base de datos desarrollado por Microsoft. Parte de Microsoft Office Professional. Se utiliza principalmente para ejecutar sitios web de bajo tráfico en la plataforma Windows.

ActiveMovie

Un control lanzado por Microsoft para la programación multimedia

ActiveX

Permite a los navegadores web descargar y ejecutar Interfaces de Programación de Aplicaciones (API) de Windows. (Véase también complementos)

Address

Consulte URL.

AdSense

Sistema de publicidad en línea proporcionado por Google.

AJAX (Asynchronous JavaScript and XML)

El "arte" de usar JavaScript y XML para crear aplicaciones web interactivas. Con Ajax, las aplicaciones web pueden intercambiar datos con el servidor web en segundo plano (asincrónicamente) y actualizar partes de una página web sin recargar la página.

Obtenga más información sobre AJAX en nuestro tutorial de AJAX

Anchor

En la web: el punto de inicio o destino de un hiperenlace.

Obtenga más información sobre enlaces en nuestro tutorial de HTML

Adobe Air

Un sistema Adobe Integrated Runtime (AIR) que permite a los desarrolladores crear aplicaciones de escritorio utilizando tecnologías web (HTML, JavaScript, Flash).

Android

Un sistema operativo móvil desarrollado por Android Inc., posteriormente adquirido por Google.

FTP anónimo

Consulte servidor FTP.

ANSI (American National Standards Institute)

Organización que crea estándares para la industria informática. Responsable del estándar ANSI C.

ANSI C

Estándar internacional para el lenguaje de programación C.

ADO (ActiveX Data Object)

Tecnología de almacenamiento de datos de Microsoft que proporciona acceso a datos.

Obtenga más información sobre ADO en nuestro tutorial de ADO

ADSL (Asymmetric Digital Subscriber Line)

Un tipo especial de línea DSL donde la velocidad de subida y la de bajada son diferentes.

Agent

Consulte agente de búsqueda / motor de búsqueda.

Amaya

Un editor de navegador web de código abierto del W3C, utilizado para promover ideas avanzadas en el diseño de navegadores.

Animation

Una secuencia de fotografías que al reproducirse simulan movimiento.

Programa antivirus

Un programa informático que detecta y destruye todo tipo de virus informáticos.

Apache

Un servidor web de código abierto. Se utiliza principalmente en plataformas Unix, Linux y Solaris.

Applet

Consulte subprograma web (applet).

Archie

Programa informático para localizar archivos en servidores FTP públicos.

API (Application Programming Interface)

Interfaz que permite a un programa comunicarse con otro programa. En la web: interfaz que permite a un navegador web o servidor web comunicarse con otros programas. (Véase también complementos ActiveX)

ARPAnet

Experimento de pruebas de red, iniciado en la década de 1970 durante el desarrollo de Internet.

Authentication

En la web: método utilizado para verificar la identidad de un usuario en una red o programa informático.

ASCII (Código Estadounidense Estándar para el Intercambio de Información)

128 caracteres alfanuméricos y de control especiales utilizados para almacenar e imprimir texto en computadoras. Datos transmitidos a través de la web en HTML.

Consulte la lista completa de códigos ASCII en nuestra referencia de HTML

ASF (Advanced Streaming Format)

Un formato de flujo de datos multimedia. Desarrollado por Windows Media de Microsoft.

ASP (Active Server Pages)

Tecnología de Microsoft que permite al servidor ejecutar scripts insertados en páginas web.

Obtenga más información sobre ASP visitando nuestro tutorial de ASP

ASX (ASF Streaming Redirector)

Formato XML para almacenar información sobre archivos ASF. Desarrollado por Windows Media de Microsoft.

AVI (Audio Video Interleave)

Formato de archivo de video. Tecnología de compresión de video desarrollada por Microsoft.

Banner Ad

Anuncios (comúnmente gráficos) colocados en páginas web que actúan como hiperenlaces al sitio web del anunciante.

Bandwidth

Puede medir la velocidad de conexión a Internet por la cantidad de datos enviados. Más ancho de banda significa conexión más rápida.

Baud

Número de símbolos enviados por segundo en un canal.

BBS (Bulletin Board System)

Sistema público basado en la red para compartir discusiones, archivos y anuncios.

Binary Data

Datos en forma legible por máquina.

Bit (Binary Digit)

La unidad más pequeña de datos almacenados en una computadora. Un bit tiene un valor de 0 o 1. Una computadora utiliza 8 bits para almacenar un carácter de texto.

Blog (Web Log)

Un tipo de sitio web (generalmente mantenido por una persona) que contiene anotaciones, comentarios, opiniones, descripciones de eventos, etc.

Blogger

Una persona que mantiene o escribe contenido en un blog (weblog).

Blogging

Escribir o añadir contenido a un blog (weblog).

BMP (Bitmap)

Formato utilizado para almacenar imágenes.

Bookmark

En la web: almacenar un enlace a un sitio web específico (marcador) para que el usuario web pueda acceder fácilmente en el futuro.

Bounce Rate

Proporción de visitantes del sitio que ven solo una página antes de irse (rebote).

Browse

Término que describe el movimiento de un usuario web a través de la red, desplazándose de página en página mediante hiperenlaces y un navegador web. (Véase navegador web).

BPS (Bits Per Second)

Término utilizado para describir la velocidad de transferencia de datos en la red.

Browser

Consulte navegador web.

Byte (Binary Term)

Unidad de almacenamiento de computadora que contiene 8 bits. Cada byte puede almacenar un carácter de texto.

C

Un lenguaje de programación avanzado utilizado para programar aplicaciones informáticas avanzadas.

C++ (C Plus Plus)

El mismo C con funcionalidades de programación orientada a objetos añadidas.

C# (C Sharp)

La versión de Microsoft de C++ con funcionalidades similares a las de Java añadidas.

Case Sensitive

Utilizado para describir la sensibilidad al uso de letras mayúsculas o minúsculas.

Cache

En la web: función de almacenar copias de páginas web en el disco duro de un navegador o servidor web.

Chat

Comunicación en línea basada en texto entre usuarios de Internet.

CGI (Common Gateway Interface)

Reglas que describen cómo un programa CGI se comunica con el servidor web.

CGI Bin

Carpeta (o directorio) en el servidor web donde se almacenan los programas CGI.

CGI Program

Un programa pequeño que procesa la entrada y salida desde el servidor web. Los programas CGI se utilizan generalmente para procesar entradas de formularios o consultas a bases de datos.

Cinepac

Códec de video para computadoras.

Client

Consulte cliente web.

Client/Server

En la web: comunicación con separación de trabajo entre el cliente web y el servidor web.

Click

En la web: hacer clic con el ratón en un elemento de hiperenlace (como texto o imagen) en una página web crea un evento, como ir a otra página web o acceder a otra parte de la misma página.

Clickthrough Rate

Proporción de visitantes que hacen clic en un hiperenlace (o anuncio) de una página en relación con el número de veces que la página se ha mostrado.

Cloud Computing

Aplicaciones y datos almacenados en Internet (no en la computadora del usuario).

Codec (Compressor / Decompressor)

Término general para técnicas de compresión y descompresión de datos.

Communication Protocol

Estándar (lenguaje y conjunto de reglas) que permite a las computadoras interactuar de manera estándar. Por ejemplo, IP, FTP y HTTP.

Obtenga más información sobre protocolos de comunicación en nuestro tutorial de TCP/IP

Compression

Método para comprimir el tamaño de documentos web o gráficos para entregarlos más rápido a través de la red.

Computer Virus

Un programa informático que puede dañar la visualización de mensajes, eliminar archivos e incluso destruir el sistema operativo de la computadora.

Cookie

Información almacenada en su computadora por el servidor web a través del navegador web. El propósito de las cookies es proporcionar información sobre sus visitas a sitios web, que el servidor utiliza en visitas posteriores.

ColdFusion

Plataforma popular para software de desarrollo web (Linux, UNIX, Solaris y Windows).

CSS (Cascading Style Sheets)

Un lenguaje recomendado por el W3C que define el estilo de los documentos web (como fuentes, tamaños, colores, espaciado, etc.).

Obtenga más información sobre CSS en nuestro tutorial de CSS

Database

Almacenar datos en una computadora de tal manera que un programa informático pueda recuperarlos y manipularlos fácilmente.

Obtenga más información sobre bases de datos en nuestro tutorial de SQL

Database System

Programa informático para manipular datos en bases de datos (como MS Access, Oracle y MySQL).

DB2

Sistema de base de datos de IBM. Se utiliza principalmente en plataformas Unix y Solaris.

DBA (Data Base Administrator)

Persona (o software) que administra una base de datos. Tareas típicas: copias de seguridad, mantenimiento y ejecución.

DHCP (Dynamic Host Configuration Protocol)

Protocolo estándar de Internet que asigna nuevas direcciones IP a los usuarios.

DHTML (Dynamic HTML)

Término comúnmente utilizado para describir contenido HTML que puede cambiar dinámicamente.

Dial-up Connection

En la web: conexión a Internet a través de una línea telefónica y un módem.

Discussion Group

Consulte grupo de noticias.

DNS (Domain Name Service)

Programa informático que se ejecuta en un servidor web para traducir nombres de dominio a direcciones IP.

Obtenga más información sobre DNS en nuestro tutorial de alojamiento web.

DNS Server

Servidor web que ejecuta DNS.

DOM (Document Object Model)

Un modelo de programación de objetos para páginas web. (Véase DOM HTML y DOM XML)

Domain Name

Identificador del nombre de un sitio web. (Ej.: runoob.com)

Obtenga más información sobre dominios en nuestro tutorial de alojamiento web.

DOS (Disk Operating System)

Un sistema operativo de computadora común basado en disco (véase sistema operativo). Originalmente de Microsoft para las PC de IBM. Comúnmente abreviado como MS-DOS.

Download

Transferir archivos desde una computadora remota a una computadora local. En la web: el cliente web transfiere archivos desde el servidor web. (Véase también subida).

DSL (Digital Subscriber Line)

Tecnología de acceso de banda ancha basada en líneas telefónicas comunes.

DTD (Document Type Definition)

Un lenguaje que define reglas para la construcción legal de archivos web similares a HTML o XML.

Obtenga más información sobre DTD en nuestro tutorial de DTD

Dynamic IP

La dirección IP cambia cada vez que se conecta a Internet. (Véase DHCP e IP estática).

E-mail (Electronic Mail)

Envío de mensajes de una persona a otra a través de Internet.

E-mail Address

Dirección utilizada para enviar correo electrónico a una persona o una organización. El formato típico es nombredeusuario@nombredelhost.

E-mail Server

Una tarea de servicio de correo electrónico dedicada a un servidor web.

Encryption

Datos convertidos de su forma original a una forma cifrada que solo puede ser revertida por personas autorizadas. El propósito del cifrado es evitar la lectura no autorizada de los datos.

Error

Consulte Error de servidor web.

Ethernet

Un tipo de red de área local (ver LAN).

Firewall

Software que actúa como filtro de seguridad y puede limitar los tipos de comunicación de red. Se utiliza más comúnmente entre una computadora personal (o LAN) e Internet.

Flash

Formato multimedia basado en vectores para su uso en la Web, desarrollado por Adobe.

Form

Consulte Formulario HTML.

Forum

En la web: lo mismo que grupo de noticias (Newsgroup).

Frame

En la web: una parte específica de la pantalla mostrada en el navegador. Los marcos (frames) se utilizan a menudo para mostrar contenido de diferentes páginas web.

FrontPage

Software de desarrollo web para plataforma Windows. Desarrollado por Microsoft.

FTP (File Transfer Protocol)

Uno de los métodos más comunes para enviar archivos entre dos computadoras.

FTP Server

Un servidor web al que puede iniciar sesión y descargar archivos (o cargarlos). FTP anónimo es un método para descargar archivos de un servidor FTP sin usar una cuenta de inicio de sesión.

Gateway

Datos (formateados) que son incompatibles entre programas de computadora o que se transmiten a través de una red.

GIF (Graphics Interchange Format)

Un formato de compresión de imágenes desarrollado por CompuServe. Uno de los formatos de imagen más comunes en Internet.

GB

Gigabyte, un gigabyte, una unidad de almacenamiento de computadora.

Gigabyte

1024 megabytes. Generalmente se redondea a mil millones de bytes.

Graphics

En la web, presentar imágenes (en lugar de texto).

Graphic Monitor

Una pantalla que puede mostrar gráficos.

Graphic Printer

Una impresora que puede imprimir gráficos.

Graphical Banner

Consulte Anuncio de banner (Banner Ad).

Helper application

En la web: un programa que ayuda al navegador a mostrar, ver o trabajar con contenido que el navegador no puede manejar por sí mismo. (Véase complemento/plugin).

Hits

La cantidad de objetos web (páginas o imágenes) que han sido vistos o descargados. (Véase página vista/Page View).

Home Page

La página superior (principal) de un sitio web. La página predeterminada que se muestra cuando visita un sitio web.

Host

Consulte Alojamiento web (Web host).

Hosting

Consulte Alojamiento virtual (Virtual hosting).

Hotlink

Consulte Hipervínculo (Hyperlink).

HTML (Hypertext Markup Language)

HTML es el lenguaje de la web. HTML es un conjunto de etiquetas que se utilizan para definir el contenido, el diseño y el formato de los archivos de páginas web. Los navegadores web usan etiquetas HTML para definir cómo mostrar el texto.

Obtenga más información sobre HTML en nuestro tutorial de HTML.

HTML Document

Un archivo escrito en HTML.

HTML DOM (HTML Document Object Model)

Una interfaz de programación para documentos HTML.

Obtenga más información sobre HTML DOM en nuestro tutorial de HTML DOM.

HTML Editor

Un programa de software utilizado para editar páginas HTML. Con un editor HTML puede agregar elementos como listas, tablas, diseño, tamaño de fuente y colores a un documento HTML, como si usara un procesador de textos. Un editor HTML WYSIWYG (lo que ves es lo que obtienes) muestra el contenido que se está editando en la página mientras se edita.

HTML Form

El formulario con los datos ingresados por el usuario se envía de vuelta al servidor.

Obtenga más información sobre formularios HTML en nuestro tutorial de HTML.

HTML Page

Un archivo HTML.

HTML Tags

Código que identifica las diferentes partes de un documento para que el navegador web sepa cómo mostrarlas.

Obtenga más información sobre las etiquetas HTML en nuestro tutorial de HTML.

HTTP (Hyper Text Transfer Protocol)

Un conjunto estándar de reglas para enviar archivos de texto a través de Internet. Requiere un programa cliente HTTP en un extremo y un programa servidor HTTP en el otro.

HTTP Client

Un programa de computadora que solicita servicios a un servidor web.

HTTP Server

Un programa de computadora que proporciona servicios desde un servidor web.

HTTPS (Hyper Text Transfer Protocol Secure)

Igual que HTTP pero con comunicación segura por Internet mediante SSL. (Véase también SSL).

Hyperlink

Una cadena de texto en una página web que enlaza a otras páginas web se llama HIPERVÍNCULO (HYPERLINK).

Hypermedia

Extiende hipertexto, gráficos y audio.

Hypertext

El hipertexto está enlazado de forma cruzada, de manera que el lector puede leer documentos relacionados haciendo clic en una palabra resaltada, símbolo u otro texto que enlace a otros documentos. (Véase también Hipervínculo).

IAB (Internet Architecture Board)

Un consejo para la toma de decisiones sobre estándares de Internet (véase también W3C).

IE (Internet Explorer)

Consulte Internet Explorer.

IETF (Internet Engineering Task Force)

Un grupo dentro de la IAB (Junta de Arquitectura de Internet) que se centra en resolver problemas técnicos en Internet.

IIS (Internet Information Server)

Un servidor web para el sistema operativo Windows. Desarrollado por Microsoft.

IMAP (Internet Message Access Protocol)

Un protocolo de comunicación estándar para recuperar correos electrónicos de un servidor de correo. IMAP es muy similar a POP, pero más avanzado.

Obtenga más información sobre IMAP en nuestro tutorial de TCP/IP.

Indeo

Códec de video para computadoras desarrollado por Intel Corporation.

Internet

Una red mundial que conecta millones de computadoras. (Véase también World Wide Web).

Internet Browser

Consulte Navegador web (Web browser).

Internet Explorer

El navegador de Microsoft. El navegador más utilizado.

Obtenga más información sobre navegadores en nuestra sección de navegadores.

Internet Server

Consulte Servidor web.

Intranet

Una LAN (red de área local) que opera dentro de una intranet privada (cerrada).

IP (Internet Protocol)

Consulte protocolo TCP/IP.

IP Address (Internet Protocol Address)

Un número de identificación único para cada computadora en Internet (por ejemplo, 197.123.22.240).

IP Number (Internet Protocol Number)

Una dirección IP.

IP Packet

Consulte paquete TCP/IP.

IRC (Internet Relay Chat)

Un sistema de Internet que permite a los usuarios discutir en línea.

IRC Client

Un programa de computadora que permite a los usuarios conectarse a IRC.

IRC Server

Tarea de servicio de un servidor de Internet dedicado a conexiones IRC.

ISAPI (Internet Server API)

Interfaz de programación de aplicaciones (API) de Internet Information Server (ver IIS).

ISDN (Integrated Services Digital Network)

Estándar de telecomunicaciones que utiliza transmisión digital y admite comunicaciones de datos a través de líneas telefónicas ordinarias.

ISP (Internet Service Provider)

Proporciona acceso a Internet y alojamiento de sitios web.

Java

Un lenguaje de programación desarrollado por Sun. Se utiliza principalmente para programar servidores web y applets web.

Java Applet

Consulte Applet de página web.

JavaScript

El lenguaje de script más popular en Internet, desarrollado por Netscape.

Obtenga más información sobre JavaScript en nuestro tutorial de JavaScript.

JPEG (Joint Photographic Expert Group)

Formato de gráficos diseñado para almacenar imágenes comprimidas, relacionado con JPG y JPEG.

JPEG and JPG

Formato de gráficos que almacena imágenes comprimidas.

JScript

La versión de JavaScript de Microsoft.

JSP (Java Server Pages)

Una tecnología basada en Java que permite insertar scripts ejecutables en el servidor en páginas web. Se utiliza principalmente en plataformas Linux, Unix y Solaris.

K

Kilobyte. 10K es lo mismo que diez kilobytes.

KB

Kilobyte. 10K es lo mismo que diez kilobytes.

Keyword

En la web: una palabra que los motores de búsqueda utilizan para buscar información relevante en la red. En terminología de bases de datos: una palabra (o índice) utilizada para identificar registros en una base de datos.

Kilobyte

1024 bytes. A menudo se denomina 1K y se redondea a 1000 bytes.

LAN (Local Area Network)

Red entre computadoras en un área local (como un edificio), generalmente mediante conexiones por cable locales. Véase Red de área amplia (WAN).

Link

Lo mismo que hipervínculo (hyperlink).

Linux

Sistema operativo de computadora de código abierto, basado en UNIX. Se utiliza principalmente en servidores y servidores web.

Mail

En redes: lo mismo que correo electrónico (e-mail).

Mail Server

Consulte servidor de correo electrónico.

MB

Lo mismo que megabyte. 10 MB son 10 megabytes.

Megabyte

1024 kilobytes. Generalmente se redondea a un millón de bytes.

Meta Data

Datos que describen otros datos. (Metaetiqueta).

Meta Search

Método para buscar metadatos en archivos.

Meta Tags

Etiqueta insertada en un documento que describe el archivo.

Obtenga más información sobre metaetiquetas en nuestro tutorial de HTML.

MIDI (Musical Instrument Digital Interface)

Un protocolo estándar para la comunicación entre computadoras e instrumentos musicales.

Obtenga más información sobre MIDI en nuestro tutorial de medios.

MIME (Multipurpose Internet Mail Extensions)

Estándar de Internet que define los tipos de documento. Ejemplos de tipos MIME: texto/plano, texto/html, imagen/gif, imagen/jpg.

Obtenga más información sobre MIME en nuestro tutorial de medios.

MIME Types

Definido según el tipo de archivo MIME.

Modem

Dispositivo de hardware que conecta una computadora a la red telefónica, utilizado generalmente para conectarse a Internet a través de líneas telefónicas.

Mosaic

El primer navegador web de uso común. Mosaic fue lanzado en 1993 y comenzó a popularizar la Web.

MOV

Códec de video para computadoras desarrollado por Apple. Extensión de archivo común para archivos multimedia QuickTime.

MP3 (MPEG-1 Audio Layer-3)

Un formato de compresión de audio diseñado para facilitar la descarga desde Internet.

MP3 File

Archivo que contiene audio comprimido MP3. El más común para pistas de música.

MPEG (Moving Picture Expert Group)

Un códec de audio y video para computadoras, estándar ISO.

MPG

Extensión de archivo común para archivos MPEG.

MS-DOS (Microsoft Disk Operating System)

Un sistema operativo (SO) para computadoras basado en disco. Originalmente desarrollado por Microsoft para computadoras IBM, y luego fue la base de la primera versión de Windows de Microsoft.

Multimedia

En redes: una presentación que combina texto con imágenes, video o sonido.

MySQL

Software de base de datos gratuito y de código abierto, utilizado frecuentemente en la web.

NetBEUI (Net Bios Extended User Interface)

Una versión mejorada de NetBIOS.

NetBIOS (Network Basic Input Output System)

Una interfaz de programación de aplicaciones (API) para funciones de red de área local (LAN). Utilizada en DOS y Windows.

Navigate

En redes: lo mismo que navegar.

Netscape

El navegador Netscape de esa empresa. Fue el navegador más popular durante muchos años. Hoy, el navegador IE es el líder.

Obtenga más información sobre los navegadores en nuestra sección de navegadores.

Newsgroup

Un grupo de discusión en línea (una sección en un servidor de noticias), dedicado a un tema de interés.

News Reader

Un programa de computadora que puede leer (y publicar mensajes) desde grupos de noticias de Internet.

News Server

La tarea de un servidor de Internet dedicado al servicio de grupos de noticias de Internet.

Node

En redes conectadas a Internet: una computadora, utilizada más frecuentemente para describir un servidor web.

Opera

El navegador Opera de la compañía noruega Opera Software ASA.

Obtenga más información sobre los navegadores en nuestra sección de navegadores.

OS (Operating System)

Operaciones básicas de computadora para administrar software.

Packet

Consulte el paquete TCP/IP.

Page Hits

El número de veces que una página web es visitada por los usuarios.

Page Impressions

Lo mismo que número de clics.

Page Views

Lo mismo que número de clics.

PDF (Portable Document Format)

Un formato de archivo de documento desarrollado por Adobe. El archivo de texto más utilizado.

Perl (Practical Extraction and Reporting Language)

Un lenguaje de scripts para servidores web. Utilizado principalmente en servidores UNIX.

PHP (PHP: Hypertext Preprocessor)

Una tecnología que permite insertar scripts ejecutables del servidor en páginas web. Usada principalmente en plataformas Unix, Linux y Solaris.

Obtenga más información sobre PHP en nuestro tutorial de PHP.

Ping

Un método para comprobar la comunicación entre dos computadoras. Se envía un "ping" a una computadora remota para ver si responde.

Platform

En redes: el sistema operativo de una computadora, como Windows, Linux u OS X.

Plug-In

Aplicación construida para otra aplicación. En redes: un tipo especial de programa (o complemento) integrado en el navegador web para manejar datos como correo electrónico, sonido o archivos de película. (Véase también ActiveX).

PNG (Portable Network Graphics)

Un formato de almacenamiento de archivos de imagen cuyo propósito es intentar reemplazar los formatos GIF y TIFF, añadiendo además algunas características que el formato GIF no tiene.

POP (Post Office Protocol)

Un protocolo de comunicación estándar para recuperar correo electrónico de un servidor de correo. (Véase también IMAP).

Obtenga más información sobre POP e IMAP en nuestro tutorial de TCP/IP.

Port

Un canal de E/S (entrada/salida) que identifica a una computadora. En redes: un canal de E/S que identifica una aplicación de Internet (los servidores web suelen usar el puerto 80).

Protocol

Consulte protocolo de comunicaciones.

PPP (Point to Point Protocol)

Un protocolo de comunicación utilizado para la conexión directa entre dos computadoras.

Proxy Server

Servidores de Internet dedicados a mejorar el rendimiento de Internet.

QuickTime

Formato de archivo multimedia creado por Apple.

Puede obtener más información sobre QuickTime en nuestro tutorial de medios.

RAID (Redundant Array of Independent Disks)

Un estándar para conectar múltiples discos a un mismo servidor con mayor seguridad, velocidad y rendimiento. Utilizado generalmente en servidores web.

RDF (Resource Description Framework)

Un lenguaje utilizado para describir el marco de construcción de recursos web.

Obtenga más información sobre RDF en nuestro tutorial de RDF.

Real Audio

Un formato de audio multimedia común, creado por Real Networks.

Conozca RealAudio en nuestro tutorial de medios.

Real Video

Un formato de video multimedia común, creado por Real Networks.

Conozca RealVideo en nuestro tutorial de medios.

Redirect

En redes: la acción por la cual una página web reenvía (redirige) automáticamente al usuario a otra página web.

RGB (Red Green Blue)

La combinación de tres colores primarios que puede representar el espectro completo de color.

Obtenga más información sobre RGB en nuestro tutorial de HTML.

Robot

Consulte Robot de red.

Router

Un sistema de hardware (o software) (ruta) que indica la transmisión de datos en red entre diferentes computadoras.

Schema

Véase XML Schema.

Script

Conjunto de instrucciones escritas en un lenguaje de scripts.

Scripting Language

En redes: un lenguaje de programación simple que puede ejecutarse a través de un navegador web o un servidor web. Consulte JavaScript y VBScript.

Scripting

Escribir un guion (script).

Search Agent

Igual que motor de búsqueda.

Search Engine

Programa de computadora utilizado para buscar y catalogar (indexar) la información proporcionada en millones de páginas web. Los motores de búsqueda comunes son Google y AltaVista.

Semantic Web

El significado de un sitio web, en el sentido de que un programa de computadora puede comprender suficientes datos y procesarlos.

Server

Consulte Servidor web.

Server Errors

Consulte errores de servidor web.

Shareware

Software que puede probar de forma gratuita y, tras pagar una determinada tarifa, continuar usándolo legalmente.

Shockwave

Un formato (tecnología) desarrollado por Adobe para incrustar contenido multimedia en páginas web.

SGML (Standard Generalized Markup Language)

Estándar internacional para lenguajes de marcado. La base de HTML y XML.

SMIL (Synchronized Multimedia Integration Language)

Un lenguaje recomendado por el W3C para crear presentaciones multimedia.

SMTP (Simple Mail Transfer Protocol)

Un protocolo de comunicación estándar entre computadoras para enviar correo electrónico.

Obtenga más información sobre SMTP en nuestro tutorial de TCP/IP.

SOAP (Simple Object Access Protocol)

Un protocolo estándar que permite a las aplicaciones comunicarse entre sí utilizando XML.

Obtenga más información sobre SOAP en nuestro tutorial de SOAP.

Solaris

Sistema operativo de computadora de Sun.

SPAM

En redes: la acción de enviar múltiples correos no deseados a grupos de noticias o listas de correo.

Spider

Consulte Araña web (Web Spider).

Spoofing

Direccionamiento de páginas web o correos electrónicos con referencias falsas. Enviar correos electrónicos con direcciones falsas.

Spyware

Software de computadora oculto en una computadora con el propósito de recopilar información utilizando esa computadora.

SQL (Structured Query Language)

Un lenguaje de computadora estándar ANSI para acceder y manipular bases de datos.

Obtenga más información sobre SQL en nuestro tutorial de SQL.

SQL Server

Sistema de base de datos de Microsoft. Utilizado principalmente en sitios web de alto tráfico que se ejecutan en plataformas Windows.

SSI (Server Side Include)

Un tipo de comentario HTML insertado en una página web que indica al servidor web generar contenido dinámico. El uso más común es incluir encabezados o pies de página estándar en las páginas.

SSL (Secure Socket Layer)

Software que asegura y protege las comunicaciones del sitio web mediante transmisión de datos cifrados.

Static IP (address)

IP estática, correspondiente a IP dinámica.

Streaming

Un método para enviar archivos de video y audio a través de Internet de manera que el usuario pueda ver los archivos mientras se están transmitiendo.

Streaming Format

Formato de archivo utilizado en Internet para transmisión de medios (streaming). (Consulte Windows Media, RealVideo y QuickTime).

SVG (Scalable Vector Graphics)

Un lenguaje recomendado por el W3C para definir gráficos en XML.

Obtenga más información sobre SVG en nuestro tutorial de SVG.

Tag

En redes: comando escrito o notación insertada en un archivo de página web. (Consulte etiquetas HTML).

TCP (Transmission Control Protocol)

Consulte protocolo TCP/IP.

TCP/IP (Transmission Control Protocol / Internet Protocol)

Conjunto de protocolos de comunicación por Internet entre dos computadoras. El protocolo TCP es una conexión libre entre dos computadoras, mientras que el protocolo IP se encarga de los paquetes de datos enviados a través de la red.

Obtenga más información sobre TCP/IP en nuestro tutorial de TCP/IP.

TCP/IP Address

Consulte dirección IP.

TCP/IP Packet

Un "paquete" de datos transmitido en una red TCP/IP. (Los datos enviados a través de Internet se dividen en pequeños "paquetes" de 40 a 32000 bytes de longitud).

Trojan Horse

Programa de computadora que se oculta en otra computadora con el propósito de dañar software o recopilar información usando esa computadora.

UDDI (Universal Description Discovery and Integration)

Un marco (framework) independiente de la plataforma para describir servicios, descubrir negocios e integrar servicios empresariales utilizando Internet.

Obtenga más información sobre UDDI en nuestro tutorial de WSDL.

Unix

Sistema operativo de computadora desarrollado por Bell Labs. Utilizado principalmente en servidores y servidores web.

UNZIP

Descomprimir archivos comprimidos. Consulte zip.

Upload

Transferir archivos desde una computadora local a una computadora remota. En redes: archivos transferidos desde un cliente web a un servidor web. (Véase descarga).

URI (Uniform Resource Identifier)

Se utiliza para identificar recursos en Internet. Una URL es un tipo de URI.

URL (Uniform Resource Locator)

Dirección web. Método estándar para localizar archivos de página web en Internet (ejemplo: http://www.runoob.com/).

USENET

Un sistema de noticias mundial, accesible a través de Internet. (Consulte grupos de noticias).

User Agent

Igual que navegador web.

VB (Visual Basic)

Consulte Visual Basic.

VBScript

Lenguaje de scripts de Microsoft. VBScript es el lenguaje de scripts predeterminado en ASP. También puede utilizarse en el programa Internet Explorer.

Obtenga más información sobre VBScript en nuestro tutorial de VBScript.

Virus

Igual que virus informático.

Visit

En redes: una visita a un sitio web. Utilizado frecuentemente para describir la actividad de los visitantes de un sitio web.

Visitor

En redes: visitante de un sitio web. Utilizado frecuentemente para describir a una persona que visita (navega) un sitio web.

Visual Basic

Lenguaje de programación de Microsoft.

Acceso a Internet mediante una Red Privada Virtual (Virtual Private Network).

Red privada entre dos sitios remotos, a través de una conexión virtual de Internet segura y cifrada (túnel).

VRML (Virtual Reality Modeling Language)

Un lenguaje de programación que permite añadir efectos 3D a documentos HTML.

W3C (World Wide Web Consortium)

La organización encargada de gestionar los estándares de la WWW.

Obtenga más información sobre el W3C en nuestro tutorial de W3C.

WAN (Wide Area Network)

Una red amplia de computadoras conectadas entre sí, mayor que una red de área local, generalmente conectadas mediante líneas telefónicas. Véase también LAN.

WAP (Wireless Application Protocol)

Un antiguo estándar para servicios de información en terminales inalámbricos como los teléfonos móviles digitales.

Web Address

Es lo mismo que una URL o URI. Consulte la URL de referencia.

Web Applet

Un programa que se puede descargar de Internet y ejecutarse en el ordenador del usuario. Se escribe más frecuentemente en Java.

Web Client

Un programa de software que se utiliza para acceder a páginas web. A veces es lo mismo que un navegador web, pero a menudo se utiliza como un término amplio.

Web Browser

Un programa de software que se utiliza para mostrar páginas web.

Obtenga más información sobre los navegadores en nuestra sección de navegadores.

Web Document

Un formato de archivo que se distribuye por Internet. Los archivos web más comunes tienen formatos de lenguaje de marcado como HTML o XML.

Web Error

Consulte Error de servidor web.

Web Form

Consulte Formularios HTML.

Web Host

Un servidor web, como el servicio de alojamiento que una empresa o individuo proporciona con espacio para sitios web.

Web Hosting

La acción de proporcionar servicios de alojamiento web.

Web Page

Un documento (normalmente un archivo HTML) destinado a distribuirse a través de la web.

Web Log

Consulte Blog.

Web Robot

Consulte Araña web.

Web Server

Un servidor es un tipo de computadora que proporciona servicios o información a otras computadoras. En la web: un servidor que proporciona contenido web a los navegadores web.

Web Server Error

Un mensaje de error que se muestra desde un servidor web. El error de servidor web más común es "404 Archivo no encontrado".

Obtenga más información sobre los mensajes de error del servidor web en nuestro tutorial de HTML.

Web Services

Componentes de software y aplicaciones que se ejecutan en servidores web. El servidor proporciona estos servicios a otras computadoras, navegadores o individuos, utilizando protocolos de comunicación estándar.

Web Site

Sitio web: una colección de páginas web relacionadas que pertenecen a una empresa o individuo.

Web Spider

Un programa de computadora que busca páginas web en Internet. Las arañas web comunes indexan páginas web como lo hace un motor de búsqueda como Google. Las arañas web también se conocen como robots web o rastreadores.

Web Wanderer

Consulte Araña web.

Wildcard

Un carácter que se utiliza para reemplazar cualquier otro carácter. El más comúnmente utilizado es el asterisco (*) en herramientas de búsqueda.

Windows 2000, Windows NT, Windows 95/98, Windows XP

Sistema operativo de computadora de Microsoft.

Windows Media

Formatos de audio y video desarrollados por Microsoft para Internet. (Consulte ASF, ASX, WMA y WMF).

Obtenga más información sobre Windows Media en nuestro tutorial de medios.

WINZIP

Un programa de computadora que comprime y descomprime archivos. Consulte zip.

WMA

Formato de archivo de audio para Internet, desarrollado por Microsoft. (Consulte WMV).

Aprenda más sobre formatos multimedia en nuestro tutorial de medios.

WMV

Formato de archivo de video para Internet, desarrollado por Microsoft. (Consulte también WMA).

Aprenda más sobre formatos multimedia en nuestro tutorial de medios.

WML (Wireless Markup Language)

Estándar antiguo para servicios de información utilizado en terminales inalámbricos y teléfonos móviles digitales; heredado de HTML pero basado en XML, mucho más estricto que HTML.

WML Script

Lenguaje de script (lenguaje de programación) utilizado para WML.

Worm

Virus informático que puede hacer copias de sí mismo y propagarse a otras computadoras a través de Internet.

WSDL (Web Services Description Language)

Lenguaje basado en XML que se utiliza para describir servicios web y cómo acceder a ellos.

Obtenga más información sobre WSDL en nuestro tutorial de WSDL.

WWW (World Wide Web)

Una red global de computadoras que utilizan Internet para intercambiar documentos web. (Consulte Internet).

WWW Server

Lo mismo que servidor web.

WYSIWYG (What You See Is What You Get)

En términos web: mostrar la página web que se está editando exactamente de la misma manera en que se mostrará en la página web.

XForms

Versión alternativa de formularios HTML, basada en XML y XHTML. Diferente de los formularios HTML en que separa la definición de datos de la visualización de datos. Proporciona una entrada de usuario más rica e independiente del dispositivo.

XHTML (Extensible Hypertext Markup Language)

HTML reformulado en formato XML. Desarrollado por el W3C.

Aprenda más sobre XHTML en nuestro tutorial de XHTML.

XPath

XPath es un conjunto de reglas de sintaxis (lenguaje) utilizadas para definir partes de un documento XML. XPath es una parte importante del estándar XSL del W3C.

Aprenda más sobre XPath en nuestro tutorial de XPath.

XQuery

XQuery es un conjunto de reglas de sintaxis (lenguaje) utilizadas para extraer información de documentos XML. XQuery se basa en XPath. XQuery fue desarrollado por el W3C.

Aprenda más sobre XQuery en nuestro tutorial de XQuery.

XML (Extensible Markup Language)

Archivo web desarrollado por el W3C, diseñado como una versión simplificada de SGML.

Aprenda más sobre XML en nuestro tutorial de XML.

XML Document

Un archivo escrito en XML.

Aprenda más sobre XML en nuestro tutorial de XML.

XML DOM (XML Document Object Model)

Una interfaz de programación para documentos XML definida por el W3C.

Aprenda más sobre XML DOM en nuestro tutorial de XML DOM.

XMLHttpRequest

Interfaz de programación (objeto) soportada por todos los navegadores web modernos para JavaScript, utilizada para intercambiar datos entre el navegador web y el servidor web detrás de escena (AJAX).

Aprenda más sobre XMLHttp en nuestro tutorial de AJAX.

XML Schema

XML Schema se basa en XML y se utiliza como alternativa al DTD. Los archivos XML Schema describen la estructura de los documentos XML.

Aprenda más sobre XML Schema en nuestro tutorial de XML Schema.

XSD (XML Schema Definition)

Es aproximadamente lo mismo que XML Schema.

XSL (Extensible Stylesheet Language)

Un conjunto de lenguajes XML desarrollados por el W3C, que incluye XSLT, XSL-FO y XPath.

Aprenda más sobre XSL en nuestro tutorial de XSL.

XSL-FO (XSL Formatting Objects)

Lenguaje XML utilizado para formatear documentos XML. Parte del XSL del W3C.

Aprenda más sobre XSL-FO en nuestro tutorial de XSL-FO.

XSLT (XSL Transformations)

Lenguaje XML utilizado para transformar documentos XML. Parte del XSL del W3C.

Aprenda más sobre XSLT en nuestro tutorial de XSLT.

ZIP

Un formato de compresión de archivos en computadoras. Se utiliza comúnmente para comprimir archivos. Los archivos ZIP pueden comprimirse (zipped) y descomprimirse utilizando programas de computadora como WinZip.
