Una interfaz (interface) es un tipo en el lenguaje Go que se utiliza para definir un conjunto de comportamientos. Describe los métodos que un tipo debe implementar y establece el contrato de comportamiento del tipo.

Go proporciona otro tipo de datos, la interfaz, que agrupa todos los métodos comunes. Cualquier otro tipo que implemente estos métodos implementa dicha interfaz.

El diseño de las interfaces en Go es simple pero poderoso, y es una herramienta importante para lograr polimorfismo y desacoplamiento.

Las interfaces nos permiten vincular diferentes tipos a un conjunto común de métodos, logrando así polimorfismo y un diseño flexible.

Características de las interfaces

Implementación implícita：

  • En Go no existe una palabra clave para declarar explícitamente que un tipo implementa una interfaz.
  • Mientras un tipo implemente todos los métodos requeridos por la interfaz, se considera automáticamente que implementa dicha interfaz.

Variables de tipo interfaz：

  • Una variable de interfaz puede almacenar cualquier valor que implemente dicha interfaz.
  • Una variable de interfaz realmente contiene dos partes:
    • Tipo dinámico: almacena el tipo real del valor.
    • Valor dinámico: almacena el valor concreto.

Interfaz de valor cero：

  • El valor cero de la interfaz esnil。
  • Una variable de interfaz no inicializada tiene el valornily no contiene ningún tipo dinámico ni valor.

Interfaz vacía：

  • Se define comointerface{}y puede representar cualquier tipo.

Usos comunes de las interfaces

  1. Polimorfismo: diferentes tipos implementan la misma interfaz, logrando un comportamiento polimórfico.
  2. Desacoplamiento: se definen dependencias mediante interfaces, reduciendo el acoplamiento entre módulos.
  3. Generalización: usar la interfaz vacíainterface{}para representar cualquier tipo.

Definición e implementación de interfaces

La definición de una interfaz utiliza la palabra claveinterface, que contiene declaraciones de métodos.

Ejemplo

/* Definir la interfaz */
type interface_name interface {
   method_name1 [return_type]
   method_name2 [return_type]
   method_name3 [return_type]
   ...
   method_namen [return_type]
}

/* Definir la estructura */
type struct_name struct {
   /* variables */
}

/* Implementar el método de la interfaz */
func (struct_name_variable struct_name) method_name1() [return_type] {
   /* Implementación del método */
}
...
func (struct_name_variable struct_name) method_namen() [return_type] {
   /* Implementación del método */
}

Definir una interfaz simple:

type Shape interface {
    Area() float64
    Perimeter() float64
}
  • ShapeEs una interfaz que define dos métodos:Area 和 Perimeter。
  • Cualquier tipo que implemente estos dos métodos se considera que implementaShapela interfaz.

Implementar la interfaz:Un tipo implementa la interfaz al implementar todos los métodos que la interfaz requiere.

Ejemplo

package main

import (
        "fmt"
        "math"
)

// Definir interfaz
type Shape interface {
        Area() float64
        Perimeter() float64
}

// Definir una estructura
type Circle struct {
        Radius float64
}

// Circle implementa la interfaz Shape
func (c Circle) Area() float64 {
        return math.Pi * c.Radius * c.Radius
}

func (c Circle) Perimeter() float64 {
        return 2 * math.Pi * c.Radius
}

func main() {
        c := Circle{Radius: 5}
        var s Shape = c // La variable de interfaz puede almacenar un tipo que implementa la interfaz
        fmt.Println("Area:", s.Area())
        fmt.Println("Perimeter:", s.Perimeter())
}

Al ejecutar el código anterior, el resultado es:

Area: 78.53981633974483
Perimeter: 31.41592653589793

Interfaz vacía

Interfaz vacíainterface{}Es una interfaz especial de Go que representa el superconjunto de todos los tipos.

  • Cualquier tipo implementa la interfaz vacía.
  • Se usa a menudo en escenarios donde se necesita almacenar datos de cualquier tipo, como contenedores genéricos, parámetros universales, etc.

Ejemplo

package main

import "fmt"

func printValue(val interface{}) {
        fmt.Printf("Value: %v, Type: %T\n", val, val)
}

func main() {
        printValue(42)         // int
        printValue("hello")    // string
        printValue(3.14)       // float64
        printValue([]int{1, 2}) // slice
}

Al ejecutar el código anterior, el resultado es:

Value: 42, Type: int
Value: hello, Type: string
Value: 3.14, Type: float64
Value: [1 2], Type: []int

Aserción de tipo

La aserción de tipo se utiliza para extraer el valor subyacente de un tipo de interfaz.

Sintaxis básica:

value := iface.(Type)
  • ifacees la variable de interfaz.
  • Typees el tipo concreto que se va a afirmar.
  • Si el tipo no coincide, se desencadenapanic。

Ejemplo

package main

import "fmt"

func main() {
        var i interface{} = "hello"
        str := i.(string) // Aserción de tipo
        fmt.Println(str)  // Salida: hello
}

Aserción de tipo con verificación

Para evitar panic, se puede usar una aserción de tipo con verificación:

value, ok := iface.(Type)
  • okes un valor booleano que indica si la aserción fue exitosa.
  • Si la aserción falla,valuees el valor cero,ok 为 false。

Ejemplo

package main

import "fmt"

func main() {
        var i interface{} = 42
        if str, ok := i.(string); ok {
                fmt.Println("String:", str)
        } else {
                fmt.Println("Not a string")
        }
}

Al ejecutar el código anterior, el resultado es:

Not a string

Selección de tipo (type switch)

type switch es una estructura sintáctica en Go que se utiliza para ejecutar diferentes lógicas según el tipo concreto de una variable de interfaz.

Ejemplo

package main

import "fmt"

func printType(val interface{}) {
        switch v := val.(type) {
        case int:
                fmt.Println("Integer:", v)
        case string:
                fmt.Println("String:", v)
        case float64:
                fmt.Println("Float:", v)
        default:
                fmt.Println("Unknown type")
        }
}

func main() {
        printType(42)
        printType("hello")
        printType(3.14)
        printType([]int{1, 2, 3})
}

Al ejecutar el código anterior, el resultado es:

Integer: 42
String: hello
Float: 3.14
Unknown type

Composición de interfaces

Las interfaces se pueden combinar mediante anidamiento para lograr descripciones de comportamiento más complejas.

Ejemplo

package main

import "fmt"

type Reader interface {
        Read() string
}

type Writer interface {
        Write(data string)
}

type ReadWriter interface {
        Reader
        Writer
}

type File struct{}

func (f File) Read() string {
        return "Reading data"
}

func (f File) Write(data string) {
        fmt.Println("Writing data:", data)
}

func main() {
        var rw ReadWriter = File{}
        fmt.Println(rw.Read())
        rw.Write("Hello, Go!")
}

Valor dinámico y tipo dinámico

Una variable de interfaz realmente contiene dos partes:

  1. Tipo dinámico: el tipo concreto almacenado por la variable de interfaz.
  2. Valor dinámico: el valor del tipo concreto.

Ejemplo de valor dinámico y tipo dinámico:

Ejemplo

package main

import "fmt"

func main() {
        var i interface{} = 42
        fmt.Printf("Dynamic type: %T, Dynamic value: %v\n", i, i)
}

Al ejecutar el código anterior, el resultado es:

Dynamic type: int, Dynamic value: 42

Valor cero de la interfaz

El valor cero de la interfaz es nil.

Cuando tanto el tipo dinámico como el valor dinámico de una variable de interfaz son nil, la variable de interfaz es nil.

Ejemplo de valor cero de interfaz:

Ejemplo

package main

import "fmt"

func main() {
        var i interface{}
        fmt.Println(i == nil) // Salida: true
}

Ejemplos de práctica

Los siguientes dos ejemplos demuestran el uso de interfaces:

Ejemplo 1

package main

import (
    "fmt"
)

type Phone interface {
    call()
}

type NokiaPhone struct {
}

func (nokiaPhone NokiaPhone) call() {
    fmt.Println("I am Nokia, I can call you!")
}

type IPhone struct {
}

func (iPhone IPhone) call() {
    fmt.Println("I am iPhone, I can call you!")
}

func main() {
    var phone Phone

    phone = new(NokiaPhone)
    phone.call()

    phone = new(IPhone)
    phone.call()

}

En el ejemplo anterior, definimos una interfazPhoneque contiene un métodocall(). Luego, dentro de lamainfunción, definimos unaPhonevariable de tipo, y le asignamos respectivamenteNokiaPhone 和 IPhone. Luego llamamos alcall()método, y el resultado es el siguiente:

I am Nokia, I can call you!
I am iPhone, I can call you!

Segundo ejemplo de interfaz:

Ejemplo

package main

import "fmt"

type Shape interface {
    area() float64
}

type Rectangle struct {
    width  float64
    height float64
}

func (r Rectangle) area() float64 {
    return r.width * r.height
}

type Circle struct {
    radius float64
}

func (c Circle) area() float64 {
    return 3.14 * c.radius * c.radius
}

func main() {
    var s Shape

    s = Rectangle{width: 10, height: 5}
    fmt.Printf("Área del rectángulo: %f\n", s.area())

    s = Circle{radius: 3}
    fmt.Printf("Área del círculo: %f\n", s.area())
}

En el ejemplo anterior, definimos una interfaz Shape, que define un método area() que devuelve un valor de área de tipo float64. Luego definimos dos estructuras, Rectangle y Circle, que implementan respectivamente el método area() de la interfaz Shape. En la función main(), primero definimos una variable s de tipo Shape, luego asignamos a s las instancias de los tipos Rectangle y Circle respectivamente, y mediante el método area() calculamos sus áreas y las imprimimos. El resultado es el siguiente:

矩形面积: 50.000000
圆形面积: 28.260000

Es importante tener en cuenta que una variable de tipo interfaz puede almacenar valores de cualquier tipo que implemente esa interfaz. En el ejemplo, asignamos las instancias de los tipos Rectangle y Circle a la variable s de tipo Shape, y mediante el método area() llamamos a sus métodos de cálculo de área.

    En esencia, interface es un puntero:

    package main

import "fmt"

type Reader interface {  // interface本质就是一个指针
    ReadBook()
}

type Writer interface {
    WriteBook()
}

type Book struct{
}

func (t *Book) ReadBook() {
    fmt.Println("read a book")
}

func (t *Book) WriteBook() {
    fmt.Println("write a book")
}

func main() {
    // b : pair<type:Book, value:book{}地址>
    b := &Book{}
    
    // r: pair<type, value>
    var r Reader
    // r : pair<type:Book, value:book{}地址>   pair是不变的
    r = b   // interface r 本质就是一个指针，所以b也要是指针类型
    r.ReadBook()
    
    var w Writer
    // w : pair<type:Book, value:book{}地址>    pair是不变的
    w = r.(Writer)   // w和r的type一致，所以断言成功(断言就是强转?)
    
    w.WriteBook()
}
