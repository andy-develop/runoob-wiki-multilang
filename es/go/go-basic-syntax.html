Sintaxis básica del lenguaje Go

En el capítulo anterior ya hemos conocido la estructura básica del lenguaje Go. En este capítulo aprenderemos la sintaxis básica del lenguaje Go.

Tokens de Go

Un programa Go puede estar compuesto por múltiples tokens, que pueden ser palabras clave, identificadores, constantes, cadenas y símbolos. Por ejemplo, la siguiente sentencia GO está compuesta por 6 tokens:

fmt.Println("Hello, World!")

Los 6 tokens son (uno por línea):

1. fmt
2. .
3. Println
4. (
5. "Hello, World!"
6. )

Separador de líneas

En los programas Go, una línea representa el final de una sentencia. Cada sentencia no necesita terminar con un punto y coma ; como en otros lenguajes de la familia C, porque este trabajo lo realiza automáticamente el compilador de Go.

Si tienes la intención de escribir varias sentencias en la misma línea, debes separarlas manualmente con ;, pero en el desarrollo real no se recomienda esta práctica.

A continuación se muestran dos sentencias:

fmt.Println("Hello, World!")
fmt.Println("Tutorial para novatos: runoob.com")

Comentarios

Los comentarios no se compilan. Cada paquete debe tener comentarios relacionados.

Los comentarios de una sola línea son la forma más común de comentario; puedes usar comentarios de una sola línea que comiencen con // en cualquier lugar. Los comentarios de varias líneas, también llamados comentarios de bloque, comienzan con /* y terminan con */. Por ejemplo:

// 单行注释
/*
 Author by 菜鸟教程
 我是多行注释
 */

Identificadores

Los identificadores se utilizan para nombrar entidades de programa como variables, tipos, etc. Un identificador es en realidad una secuencia formada por una o más letras (A~Z y a~z), dígitos (0~9) y guiones bajos _, pero el primer carácter debe ser una letra o un guion bajo y no puede ser un dígito.

Los siguientes son identificadores válidos:

mahesh   kumar   abc   move_name   a_123
myname50   _temp   j   a23b9   retVal

Los siguientes son identificadores no válidos:

  • 1ab (comienza con un dígito)
  • case (palabra clave del lenguaje Go)
  • a+b (los operadores no están permitidos)

Concatenación de cadenas

La concatenación de cadenas en el lenguaje Go se puede realizar mediante+la siguiente implementación:

Ejemplo

package main
import "fmt"
func main() {
    fmt.Println("Google" + "Runoob")
}

La salida del ejemplo anterior es:

GoogleRunoob

Un programa generalmente se compone de palabras clave, constantes, variables, operadores, tipos y funciones.

En los programas se pueden utilizar estos separadores: paréntesis (), corchetes [] y llaves {}.

En los programas se pueden utilizar estos signos de puntuación:.、,、;、: 和 …。

Los espacios en el lenguaje Go

En el lenguaje Go, los espacios se utilizan normalmente para separar identificadores, palabras clave, operadores y expresiones, con el fin de mejorar la legibilidad del código.

En el lenguaje Go, la declaración de variables debe separarse con espacios, por ejemplo:

var x int
const Pi float64 = 3.14159265358979323846

Usar espacios entre operadores y operandos puede hacer que el programa sea más fácil de leer:

Sin espacios:

fruit=apples+oranges;

Añadir espacios entre variables y operadores hace que el programa se vea más estético, por ejemplo:

fruit = apples + oranges;

Se deben usar espacios entre palabras clave y expresiones.

Por ejemplo:

if x > 0 {
    // do something
}

Al llamar a una función, se deben usar espacios entre el nombre de la función y el signo igual a la izquierda, y también entre los parámetros.

Por ejemplo:

result := add(2, 3)

Formato de cadenas

En el lenguaje Go se utilizafmt.Sprintf 或 fmt.Printfpara formatear una cadena y asignarla a una nueva cadena:

  • SprintfGenera una cadena formateada según los parámetros de formato y devuelve esa cadena.
  • PrintfGenera una cadena formateada según los parámetros de formato y la escribe en la salida estándar.

Ejemplo de Sprintf

package main

import (
    "fmt"
)

func main() {
   // %d indica un número entero, %s indica una cadena
    var stockcode=123
    var enddate="2020-12-31"
    var url="Code=%d&endDate=%s"
    var target_url=fmt.Sprintf(url,stockcode,enddate)
    fmt.Println(target_url)
}

El resultado de la salida es:

Code=123&endDate=2020-12-31

    El paquete fmt de Golang

    La función Print() convierte cada parámetro de la lista de argumentos a en cadenas y las escribe en la salida estándar.

    Se añaden espacios entre los parámetros que no son cadenas y devuelve el número de bytes escritos.

    func Print(a ...interface{}) (n int, err error)

    La función Println() es similar a Print, excepto que añade un carácter de nueva línea al final.

    Se añaden espacios entre todos los parámetros y devuelve el número de bytes escritos.

    func Println(a ...interface{}) (n int, err error)

    La función Printf() rellena los marcadores de posición de la cadena de formato format con la lista de argumentos a.

    El resultado rellenado se escribe en la salida estándar y devuelve el número de bytes escritos.

    func Printf(format string, a ...interface{}) (n int, err error)

    Las siguientes tres funciones tienen la misma funcionalidad que las tres anteriores, excepto que escriben el resultado de la conversión enwun `io.Writer`.

    func Fprint(w io.Writer, a ...interface{}) (n int, err error)
func Fprintln(w io.Writer, a ...interface{}) (n int, err error)
func Fprintf(w io.Writer, format string, a ...interface{}) (n int, err error)

    Las siguientes tres funciones tienen la misma funcionalidad que las tres anteriores, excepto que devuelven el resultado de la conversión en forma de cadena.

    func Sprint(a ...interface{}) string
func Sprintln(a ...interface{}) string
func Sprintf(format string, a ...interface{}) string

    La siguiente función tiene la misma funcionalidad que Sprintf(), excepto que la cadena resultante se envuelve en un tipo error.

    func Errorf(format string, a ...interface{}) error

    Ejemplo:

    func main() {
    fmt.Print("a", "b", 1, 2, 3, "c", "d", "\n")
    fmt.Println("a", "b", 1, 2, 3, "c", "d")
    fmt.Printf("ab %d %d %d cd\n", 1, 2, 3)
    // ab1 2 3cd
    // a b 1 2 3 c d
    // ab 1 2 3 cd

    if err := percent(30, 70, 90, 160); err != nil {
        fmt.Println(err)
    }
    // 30%
    // 70%
    // 90%
    // 数值 160 超出范围（100）
}

func percent(i ...int) error {
    for _, n := range i {
        if n > 100 {
            return fmt.Errorf("数值 %d 超出范围（100）", n)
        }
        fmt.Print(n, "%\n")
    }
    return nil
}

    Formatter es implementado por tipos personalizados para llevar a cabo el proceso de formato personalizado de ese tipo.

    Cuando el formateador necesita formatear una variable de ese tipo, llama a su método Format.

    type Formatter interface {
    // f 用于获取占位符的旗标、宽度、精度等信息，也用于输出格式化的结果
    // c 是占位符中的动词
    Format(f State, c rune)
}

    Es implementado por el formateador (funciones como Print) para proporcionar información al proceso de formato personalizado:

    type State interface {
    // Formatter 通过 Write 方法将格式化结果写入格式化器中，以便输出。
    Write(b []byte) (ret int, err error)
    // Formatter 通过 Width 方法获取占位符中的宽度信息及其是否被设置。
    Width() (wid int, ok bool)
    // Formatter 通过 Precision 方法获取占位符中的精度信息及其是否被设置。
    Precision() (prec int, ok bool)
    // Formatter 通过 Flag 方法获取占位符中的旗标[+- 0#]是否被设置。
    Flag(c int) bool
}

    Stringer es implementado por tipos personalizados para llevar a cabo el proceso de formato personalizado de ese tipo.

    Cuando el formateador necesita generar la representación en cadena de ese tipo, llama a su método String.

    type Stringer interface {
    String() string
}

    Stringer es implementado por tipos personalizados para llevar a cabo el proceso de formato personalizado de ese tipo.

    Cuando el formateador necesita generar la cadena de sintaxis Go de ese tipo (%#v), llama a su método String.

    type GoStringer interface {
    GoString() string
}

    Ejemplo:

    type Ustr string

func (us Ustr) String() string {
    return strings.ToUpper(string(us))
}

func (us Ustr) GoString() string {
    return `"` + strings.ToUpper(string(us)) + `"`
}

func (u Ustr) Format(f fmt.State, c rune) {
    write := func(s string) {
        f.Write([]byte(s))
    }
    switch c {
    case 'm', 'M':
        write("旗标：[")
        for s := "+- 0#"; len(s) > 0; s = s[1:] {
            if f.Flag(int(s[0])) {
                write(s[:1])
            }
        }
        write("]")
        if v, ok := f.Width(); ok {
            write(" | 宽度：" + strconv.FormatInt(int64(v), 10))
        }
        if v, ok := f.Precision(); ok {
            write(" | 精度：" + strconv.FormatInt(int64(v), 10))
        }
    case 's', 'v': // 如果使用 Format 函数，则必须自己处理所有格式，包括 %#v
        if c == 'v' && f.Flag('#') {
            write(u.GoString())
        } else {
            write(u.String())
        }
    default: // 如果使用 Format 函数，则必须自己处理默认输出
        write("无效格式：" + string(c))
    }
}

func main() {
    u := Ustr("Hello World!")
    // "-" 标记和 "0" 标记不能同时存在
    fmt.Printf("%-+ 0#8.5m\n", u) // 旗标：[+- #] | 宽度：8 | 精度：5
    fmt.Printf("%+ 0#8.5M\n", u)  // 旗标：[+ 0#] | 宽度：8 | 精度：5
    fmt.Println(u)                // HELLO WORLD!
    fmt.Printf("%s\n", u)         // HELLO WORLD!
    fmt.Printf("%#v\n", u)        // "HELLO WORLD!"
    fmt.Printf("%d\n", u)         // 无效格式：d
}

    ScanLee datos de la entrada estándar, los divide por espacios en blanco, los analiza y los almacena en las variables proporcionadas por a (los caracteres de nueva línea se tratan como espacios en blanco); las variables deben pasarse como punteros.

    La exploración se detiene cuando se alcanza EOF o cuando todas las variables se han completado.

    Devuelve el número de argumentos analizados correctamente.
    func Scan(a ...interface{}) (n int, err error)

    Scanln 和 ScanSimilar, excepto que la exploración se detiene al encontrar un carácter de nueva línea.

    func Scanln(a ...interface{}) (n int, err error)

    Scanf lee datos de la entrada estándar, los analiza de acuerdo con la cadena de formato format y almacena los resultados del análisis en las variables proporcionadas por el parámetro a; las variables deben pasarse como punteros.

    Los caracteres de nueva línea en la entrada deben corresponder a los caracteres de nueva línea en format (si la cadena de formato contiene un carácter de nueva línea, la entrada debe incluir el carácter de nueva línea correspondiente).

    El marcador de posición %c siempre coincide con el siguiente carácter, incluidos los espacios en blanco, como espacios, tabulaciones y saltos de línea.

    Devuelve el número de argumentos analizados correctamente.

    func Scanf(format string, a ...interface{}) (n int, err error)

    ScannerImplementado por un tipo personalizado, se utiliza para implementar el proceso de escaneo personalizado de ese tipo.

    Cuando el escáner necesita analizar datos de ese tipo, se llama a su método Scan.

    type Scanner interface {
    // state 用于获取占位符中的宽度信息，也用于从扫描器中读取数据进行解析。
    // verb 是占位符中的动词
    Scan(state ScanState, verb rune) error
}

    Implementado por el escáner (funciones como Scan), se utiliza para proporcionar datos e información al proceso de escaneo personalizado.

    type ScanState interface {
    // ReadRune 从扫描器中读取一个字符，如果用在 Scanln 类的扫描器中，
    // 则该方法会在读到第一个换行符之后或读到指定宽度之后返回 EOF。
    // 返回“读取的字符”和“字符编码所占用的字节数”
    ReadRune() (r rune, size int, err error)
    // UnreadRune 撤消最后一次的 ReadRune 操作，
    // 使下次的 ReadRune 操作得到与前一次 ReadRune 相同的结果。
    UnreadRune() error
    // SkipSpace 为 Scan 方法提供跳过开头空白的能力。
    // 根据扫描器的不同（Scan 或 Scanln）决定是否跳过换行符。
    SkipSpace()
    // Token 用于从扫描器中读取符合要求的字符串，
    // Token 从扫描器中读取连续的符合 f(c) 的字符 c，准备解析。
    // 如果 f 为 nil，则使用 !unicode.IsSpace(c) 代替 f(c)。
    // skipSpace：是否跳过开头的连续空白。返回读取到的数据。
    // 注意：token 指向共享的数据，下次的 Token 操作可能会覆盖本次的结果。
    Token(skipSpace bool, f func(rune) bool) (token []byte, err error)
    // Width 返回占位符中的宽度值以及宽度值是否被设置
    Width() (wid int, ok bool)
    // 因为上面实现了 ReadRune 方法，所以 Read 方法永远不应该被调用。
    // 一个好的 ScanState 应该让 Read 直接返回相应的错误信息。
    Read(buf []byte) (n int, err error)
}

    Ejemplo:

    type Ustr string

func (u *Ustr) Scan(state fmt.ScanState, verb rune) (err error) {
    var s []byte
    switch verb {
    case 'S':
        s, err = state.Token(true, func(c rune) bool { return 'A' <= c && c <= 'Z' })
        if err != nil {
            return
        }
    case 's', 'v':
        s, err = state.Token(true, func(c rune) bool { return 'a' <= c && c <= 'z' })
        if err != nil {
            return
        }
    default:
        return fmt.Errorf("无效格式：%c", verb)
    }
    *u = Ustr(s)
    return nil
}

func main() {
    var a, b, c, d, e Ustr
    n, err := fmt.Scanf("%3S%S%3s%2v%x", &a, &b, &c, &d, &e)
    fmt.Println(a, b, c, d, e)
    fmt.Println(n, err)
    // 在终端执行后，输入 ABCDEFGabcdefg 回车
    // 结果：
    // ABC DEFG abc de
    // 4 无效格式：x
}
