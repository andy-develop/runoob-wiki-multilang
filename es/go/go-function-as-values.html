Funciones del lenguaje Go como argumentos

Funciones de Go

En el lenguaje Go, las funciones son ciudadanos de primera clase (First-class citizen), pueden asignarse, pasarse y usarse como variables normales. Pasar una función como argumento a otra función es un patrón de programación común en Go, utilizado a menudo en escenarios como callbacks y el patrón de estrategia.

Asignar una función a una variable

Una función se puede asignar a una variable, y a través de esa variable se llama a la función:

Ejemplo

package main

import (
    "fmt"
    "math"
)

func main() {
    /* Asignar la función anónima a la variable getSquareRoot */
    getSquareRoot := func(x float64) float64 {
        return math.Sqrt(x)
    }

    /* Llamar a la función a través de la variable */
    fmt.Println(getSquareRoot(9))   // Salida: 3
    fmt.Println(getSquareRoot(16))  // Salida: 4
}

El resultado de la ejecución del código anterior es:

3
4

Pasar una función como argumento

Al pasar una función como argumento a otra función, el receptor debe declarar el parámetro de tipo de función correspondiente. El siguiente ejemplo define unaapplyfunción que recibe una función de operación y dos operandos, y realiza cualquier operación especificada sobre los dos números:

Ejemplo

package main

import (
    "fmt"
    "math"
)

/* Definir una función que recibe un parámetro op de tipo función */
/* El tipo de op es func(float64, float64) float64, lo que indica una función que acepta dos parámetros float64 y devuelve float64 */
func apply(op func(float64, float64) float64, a, b float64) float64 {
    return op(a, b)
}

func main() {
    /* Definir la función de suma */
    add := func(a, b float64) float64 {
        return a + b
    }

    /* Definir la función de multiplicación */
    multiply := func(a, b float64) float64 {
        return a * b
    }

    /* Pasar la función add como argumento a apply */
    fmt.Println(apply(add, 3, 4))       // Salida: 7

    /* Pasar la función multiply como argumento a apply */
    fmt.Println(apply(multiply, 3, 4))  // Salida: 12

    /* También se puede pasar directamente una función anónima */
    fmt.Println(apply(func(a, b float64) float64 {
        return math.Pow(a, b) // a elevado a la potencia b
    }, 2, 10))                          // Salida: 1024
}

El resultado de la ejecución del código anterior es:

7
12
1024

Aplicación práctica: reglas de ordenación personalizadas

Una de las aplicaciones más comunes de las funciones como argumentos es personalizar las reglas de ordenación. La biblioteca estándar de Gosort.Sliceacepta una función de comparación como parámetro:

Ejemplo

package main

import (
    "fmt"
    "sort"
)

func main() {
    nums := []int{5, 2, 8, 1, 9, 3}

    /* Pasar la función de comparación como argumento a sort.Slice para ordenar de menor a mayor */
    sort.Slice(nums, func(i, j int) bool {
        return nums[i] < nums[j]
    })
    fmt.Println("Ascendente:", nums)  // Salida: Ascendente: [1 2 3 5 8 9]

    /* Pasar una función de comparación diferente para ordenar de mayor a menor */
    sort.Slice(nums, func(i, j int) bool {
        return nums[i] > nums[j]
    })
    fmt.Println("Descendente:", nums)  // Salida: Descendente: [9 8 5 3 2 1]
}

El resultado de la ejecución del código anterior es:

升序：[1 2 3 5 8 9]
降序：[9 8 5 3 2 1]

Al pasar diferentes funciones como argumentos, la mismasort.Slicepuede implementar lógicas de ordenación completamente diferentes; este es el valor central de las funciones como argumentos:Parametrizar el comportamiento para que el código sea más flexible y reutilizable。

    Función anónima:

    package main

import "fmt"

var (
    myRes = func (a int, b int) int {
        return a - b
    }
)


func main(){
    //匿名函数，只调用一次，定义时直接调用
    res1 := func (a int, b int) int {
        return a + b
    }(10,25)
    fmt.Printf("res1 =%d\n", res1)
    //匿名函数赋给变量用变量来调用,可多次使用，但作用域有限
    res2 := func (a int, b int) int {
        return a * b
    }
    res3 := res2(10,25)
    fmt.Printf("res3 =%d\n", res3)

    //将匿名函数用全局变量接收，则该函数为全局匿名函数
    
    res4 := myRes(10,25)
    fmt.Printf("res4 =%d\n", res4)
    
}
