Bootstrap Iconos de fuente (Glyphicons)

Este capítulo explicará los iconos de fuente (Glyphicons) y, mediante algunos ejemplos, aprenderá a usarlos. Bootstrap incluye más de 200 glifos en formato de fuente. Primero entendamos qué son los iconos de fuente.

¿Qué son los iconos de fuente?

Los iconos de fuente son fuentes de iconos utilizadas en proyectos web. AunqueGlyphicons Halflingsrequieren una licencia comercial, puede utilizar estos iconos de forma gratuita mediante Bootstrap en sus proyectos.

Como agradecimiento al autor de los iconos, esperamos que incluya un enlace al sitio web GLYPHICONS cuando los use.

Obtener los iconos de fuente

Ya hemosen el capítulo Instalación del entornodescargado la versión Bootstrap 3.x y entendido su estructura de directorios. En lafontscarpeta (fonts) se pueden encontrar los iconos de fuente, que contiene los siguientes archivos:

  • glyphicons-halflings-regular.eot
  • glyphicons-halflings-regular.svg
  • glyphicons-halflings-regular.ttf
  • glyphicons-halflings-regular.woff

Las reglas CSS relacionadas se escriben en eldistsubdirectorio css dentro de la carpeta de fuentes, en elbootstrap.css 和 bootstrap-min.cssarchivo correspondiente.

Lista de iconos de fuente

Haga clic aquí para ver la lista de iconos de fuente disponibles.

Explicación de las reglas CSS

Las siguientes reglas CSS constituyen la clase glyphicon.

@font-face { font-family: 'Glyphicons Halflings'; src: url('../fonts/glyphicons-halflings-regular.eot'); src: url('../fonts/glyphicons-halflings-regular.eot?#iefix') format('embedded-opentype'), url('../fonts/glyphicons-halflings-regular.woff') format('woff'), url('../fonts/glyphicons-halflings-regular.ttf') format('truetype'), url('../fonts/glyphicons-halflings-regular.svg#glyphicons_halflingsregular') format('svg'); } .glyphicon { position: relative; top: 1px; display: inline-block; font-family: 'Glyphicons Halflings'; -webkit-font-smoothing: antialiased; font-style: normal; font-weight: normal; line-height: 1; -moz-osx-font-smoothing: grayscale; }

Por lo tanto, la regla @font-face realmente declara font-family y la ubicación donde se encuentran los glyphicons.

.glyphiconLa clase declara una posición relativa con un desplazamiento de 1px desde la parte superior, se muestra como inline-block, declara la fuente, establece font-style y font-weight como normal, y fija la altura de línea (line-height) en 1. Además, se utiliza-webkit-font-smoothing: antialiased 和 -moz-osx-font-smoothing: grayscale;para obtener coherencia entre navegadores.

Entonces, el

.glyphicon:empty {
  width: 1em;
}

es el glyphicon vacío.

Hay 200 clases, cada una orientada a un icono. El formato común de estas clases es el siguiente:

.glyphicon-keyword:before {
  content: "hexvalue";
}

Por ejemplo, el icono de usuario utilizado tiene la siguiente clase:

.glyphicon-user:before {
  content: "\e008";
}

Uso

Para usar un icono, simplemente use el siguiente código. Asegúrese de dejar un espacio adecuado entre el icono y el texto.

<span class="glyphicon glyphicon-search"></span>

Personalizar iconos de fuente

Ya hemos visto cómo usar iconos de fuente; ahora veamos cómo personalizarlos.

Comenzaremos con el ejemplo anterior y personalizaremos los iconos cambiando el tamaño de la fuente, el color y aplicando sombra de texto.

A continuación se muestra el código inicial:

<button type="button" class="btn btn-primary btn-lg">
  <span class="glyphicon glyphicon-user"></span> User
</button>

El resultado es el siguiente:

Personalizar el tamaño de los iconos de fuente

Al aumentar o disminuir el tamaño de fuente del icono, puede hacer que el icono se vea más grande o más pequeño.

<button type="button" class="btn btn-primary btn-lg" style="font-size: 60px">
  <span class="glyphicon glyphicon-user"></span> User
</button>

Personalizar el color de los iconos de fuente

<button type="button" class="btn btn-primary btn-lg" style="color: rgb(212, 106, 64);">
  <span class="glyphicon glyphicon-user"></span> User
</button>

Aplicar sombra de texto

<button type="button" class="btn btn-primary btn-lg" style="text-shadow: black 5px 3px 3px;">
  <span class="glyphicon glyphicon-user"></span> User
</button>
