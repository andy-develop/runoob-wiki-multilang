Bootstrap Sistema de cuadrícula

Introducción

En este tutorial, aprenderá a usar Bootstrap para crear un sistema de cuadrícula (Grid System).

Como quizás sepa, en el diseño gráfico, un sistema de cuadrícula es una estructura bidimensional compuesta por áreas formadas por la intersección de ejes horizontales y verticales, utilizada para organizar contenido. Se aplica ampliamente en el diseño de maquetación y estructura de contenido en diseño gráfico. En el diseño web, es un método muy eficaz para crear diseños consistentes de forma rápida y eficiente mediante HTML y CSS. Por tanto, el sistema de cuadrícula se ha convertido en un componente/módulo importante del marco de trabajo o flujo de trabajo del diseño web.

En pocas palabras, en el diseño web, usamos HTML y CSS para crear filas y columnas para implementar una cuadrícula. Y las columnas contienen el contenido real.

Desde la versión 2.3.2, Bootstrap ofrece dos tipos de cuadrículas. El sistema de cuadrícula predeterminado tiene 940px de ancho y 12 columnas. Puede agregar una hoja de estilos responsiva para que su ancho se ajuste a 724px y 1170px según la ventana gráfica presentada.

También hay un sistema de cuadrícula fluido, basado en porcentajes en lugar de píxeles. Y puede ampliarse para ser responsivo como la cuadrícula fija predeterminada. En este tutorial, analizaremos la cuadrícula predeterminada con algunos ejemplos; el sistema de cuadrícula fluido se explicará en otro tutorial aparte.

Descargue la última versión de los archivos de Bootstrap desde "http://twitter.github.io/bootstrap/assets/bootstrap.zip". Puede conocer la estructura de archivos relevante en nuestrotutorial de introducciónpara conocer la estructura de archivos relacionada.

De esta manera, hemos creado una cuadrícula de tres columnas usando la clase "span4" para cada columna. La clase "container" se utiliza para contener toda la estructura.Puede ver un ejemplo en línea aquí. A partir de esto, podemos deducir la sintaxis general de las clases CSS para crear un número determinado de columnas.

Sintaxis general para crear una cuadrícula:

<div class=&quot;row&quot;>
<div class=&quot;spanx&quot;>
inline elements like span, block level elements like p, div.
</div>
repeat <div class=&quot;spanx&quot;> y times.

donde y es el número de columnas que desea crear y x equivale a 12 (el número máximo de columnas que puede crear) en total. x debe ser un entero positivo y su valor debe ser de 1 a 12.

Por ejemplo, si tiene tres columnas de igual ancho, cada columna tiene class="span4", pero si desea que la primera columna sea más grande que las otras dos, puede usar class="span6" para la primera y class="span3" para las otras dos.

Cómo crear filas en una cuadrícula fija

A continuación, antes de continuar con otros ejemplos, veamos las reglas CSS usadas para crear filas y columnas en una cuadrícula fija.

La clase row es la siguiente:

.row {
    margin-left: -20px;
    *zoom: 1;
}

Establece el margen izquierdo en -20px y define "*zoom: 1;". Aquí "*" indica que la propiedad zoom de todos los elementos se establece en 1, para corregir errores de IE6/7. Establecer zoom en 1 activa una propiedad interna llamada hasLayout, que se usa para corregir muchos problemas de zoom/renderizado en IE6/7.

.row:before,
.row:after {
    display: table;
    line-height: 0;
    content: "";
}

Bootstrap usa el código CSS anterior para crear filas. Utiliza las propiedades CSS ":before" y ":after". Estos son pseudoelementos. ":before" se usa para insertar contenido antes del elemento objetivo, y ":after" para insertar contenido después. "display:table;" hace que el elemento se muestre como una tabla. Al establecer "line-height: 0;" se garantiza que cada fila no tenga su propia altura de línea, y al usar 'content: ""' se asegura que no se inserte contenido antes ni después del elemento.

Luego se usan las siguientes reglas para asegurar que no haya elementos flotantes a la izquierda ni a la derecha de un elemento dado.

.row:after {
    clear: both;
}

Cómo crear columnas en una cuadrícula fija

[class*="span"] {
    float: left;
    min-height: 1px;
    margin-left: 20px;
}

Estas son las reglas CSS a utilizar. '[class*="span"]' selecciona todos los elementos cuyo valor del atributo class comience con 'span'. Ahora se usa "float: left;" para colocar cada columna una al lado de la otra. Use "min-height: 1px" para que todas las columnas tengan una altura mínima de 1px, y use "margin-left: 20px;" para establecer un margen izquierdo de 20px.

Añadir capacidad de respuesta a la cuadrícula predeterminada

Si desea agregar capacidad de respuesta a la cuadrícula predeterminada de Bootstrap, solo necesita agregar después del CSS nativo en el archivo HTML:

<meta name="viewport" content="width=device-width, initial-scale=1.0"><link href="bootstrap/css/bootstrap-responsive.min.css.html" rel="stylesheet">

El sistema de cuadrícula predeterminado es responsivo bajo dos condiciones. Cuando la ventana gráfica (el espacio disponible para representar la cuadrícula) es mayor que 1200px [obtenido mediante @media (min-width: 1200px)], y cuando la ventana gráfica es mayor que 768px pero menor que 979px [establecido mediante @media (min-width: 768px) y (max-width: 979px)].

Columnas desplazadas: cuadrícula predeterminada

Mediante el desplazamiento (offset), puede mover una columna a la derecha de su posición original. Esto se logra agregando un margen izquierdo a la columna. Con Bootstrap, puede usar la clase "offsetx" (donde x es un entero positivo) y la clase "spany" (donde y es un entero positivo). Según el valor de 'x' en 'offsetx', la columna correspondiente se desplaza a la derecha el ancho de 'x' columnas.

El ancho del desplazamiento se define en el CSS de Bootstrap. El margen izquierdo máximo para offset12 es 980px, y el margen izquierdo mínimo para offset1 es 100px.

Dado que el sistema de cuadrícula predeterminado se basa en píxeles, al aplicar desplazamientos debe conocer los píxeles que usará para el desplazamiento y los píxeles para las columnas. La suma de ambos no debe superar el número de píxeles de su ventana gráfica horizontal.

En el ejemplo anterior, la fila dentro del contenedor tiene dos columnas, definidas como 'class="span7"' y 'class="span5"'. Esto hace que el número total de columnas sea 12. Conclusión

En este tutorial, hemos discutido el sistema de cuadrícula predeterminado de Bootstrap. Este tutorial se basa en Bootstrap V2.3.2. A continuación se presenta un resumen de los puntos clave relevantes de este tutorial:

  • El sistema de cuadrícula predeterminado de Bootstrap tiene 940px de ancho y cuenta con 12 columnas.
  • En la cuadrícula, las filas se crean con 'class="row"', y las columnas con 'class="spanx"', donde x es un entero positivo. La suma de todas las columnas x no debe exceder 12.
  • Al agregar el CSS responsivo de Bootstrap, puede agregar capacidad de respuesta a la cuadrícula predeterminada.
  • Utilice el desplazamiento (offset) para crear espacio adicional para las columnas. Mediante el uso de 'class="offsetx"', donde x es un entero positivo. Si utiliza el desplazamiento, el número total de columnas, incluida la cantidad utilizada por el desplazamiento, no puede exceder 11.
  • Las columnas se pueden anidar. Si se utilizan columnas anidadas, al calcular el número total de columnas en la cuadrícula (una fila dentro del contenedor), las columnas anidadas también deben tenerse en cuenta.
  • El desplazamiento (offset) también se puede utilizar en columnas anidadas.
