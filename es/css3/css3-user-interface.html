Interfaz de usuario CSS3

En CSS3, se han añadido algunas nuevas características de interfaz de usuario para ajustar el tamaño de los elementos, el tamaño de la caja y el contorno.

En este capítulo, aprenderá sobre las siguientes propiedades de interfaz de usuario:

  • resize
  • box-sizing
  • outline-offset

CSS3 Redimensionamiento (Resizing)

En CSS3, la propiedad resize especifica si un elemento debe ser redimensionado por el usuario.

Este elemento div es redimensionado por el usuario. (En Firefox 4+, Chrome y Safari)

El código CSS es el siguiente:

Ejemplo

Permitir al usuario especificar el tamaño de un elemento div:

div { resize:both; overflow:auto; }

CSS3 Tamaño de caja (Box Sizing)

La propiedad box-sizing le permite definir de manera precisa cómo el contenido se ajusta a un área determinada.

Ejemplo

Especificar dos cajas con borde una al lado de la otra:

div { box-sizing:border-box; -moz-box-sizing:border-box; /* Firefox */ width:50%; float:left; }

CSS3 Modificación del contorno (outline-offset)

La propiedad outline-offset desplaza el contorno y lo dibuja en una posición más allá del borde.

El contorno y el borde tienen dos diferencias:

  • El contorno no ocupa espacio
  • El contorno puede no ser rectangular
Este div tiene un contorno a 15 píxeles fuera del borde.

El código CSS es el siguiente:

Ejemplo

Especificar un contorno a 15 píxeles fuera del borde:

div { border:2px solid black; outline:2px solid red; outline-offset:15px; }

    La propiedad resize especifica que el usuario puede estirar el tamaño del elemento para mostrar el contenido oculto por desbordamiento. El efecto es similar a la etiqueta de área de texto <textarea></textarea>.

    Se puede decir que la etiqueta <textarea> trae por defecto resize: both; por lo tanto, se puede evitar que el tamaño de <textarea> se estire estableciendo resize: none;.

    Pero es importante tener en cuenta la configuración de la forma de desbordamiento:

    1. Cuando overflow: hidden;, sin importar si se estira o no el tamaño, el contenido que excede el tamaño quedará oculto y recortado;

    2. Cuando overflow: scroll;, sin importar si se estira o no el tamaño, el elemento siempre mostrará la barra de desplazamiento;

    3. Cuando overflow: auto;, la barra de desplazamiento solo aparecerá cuando el tamaño sea menor que el contenido mostrado; se podría decir que esta es la configuración más estética (<textarea> también trae esta propiedad);

    ----------------------------------------------------------------------------------------------------

    La propiedad outline-offset se utiliza para establecer el espacio o "relleno" entre el contorno (borde exterior) y el borde (borde interior). De forma predeterminada, el contorno está pegado al borde, por lo que se necesita esta propiedad para separarlos.

    outline no altera el ancho y alto del elemento; de igual manera, el espacio establecido por outline-offset tampoco afecta el ancho y alto del elemento.

    ----------------------------------------------------------------------------------------------------

    box-sizing se utiliza para indicar al navegador qué modelo de caja debe usar para renderizar el documento.

    content-box es el modelo de caja predeterminado, es decir, el modelo de caja estándar del W3C. Hoy en día todos los navegadores principales lo soportan y lo usan para renderizar el diseño, incluido IE. Pero los problemas son muchos, porque en este modelo, la configuración de border y padding rompe el tamaño del elemento, haciendo que el resultado del diseño final no coincida con el efecto deseado. Si se quiere lograr el efecto deseado, se deben calcular el ancho y el alto, lo cual es muy problemático.

    (Otras propiedades son mejores cuanto más estándar, pero esta propiedad es al revés, va hacia el estándar de IE).

    Por otro lado, border-box se refiere al modelo de caja de IE, también llamado "modelo de caja extraño". En este modelo, el borde y el relleno no afectan el ancho y alto del elemento; es como si ocuparan el espacio del elemento como propio, el tamaño total del elemento no cambia, el espacio del contenido se reduce, y el borde y el relleno ocupan lo que originalmente era el espacio del contenido. Esto es muy cómodo al diseñar, porque después de especificar el tamaño del elemento y establecer este valor de propiedad, el tamaño del elemento no se altera y no hay que volver a calcularlo.
