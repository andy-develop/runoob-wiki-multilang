Sintaxis de configuración de ECharts

En este capítulo presentaremos algunas configuraciones para generar gráficos con ECharts.

Paso 1: Crear una página HTML

Crea una página HTML e incluye echarts.min.js:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <!-- 引入 ECharts 文件 -->
    <script src="echarts.min.js.html"></script>
</head>
</html>

Paso 2: Preparar un contenedor DOM con alto y ancho para ECharts

En el ejemplo, el div con id 'main' se utiliza para contener el gráfico dibujado por ECharts:

<body>
    <!-- 为 ECharts 准备一个具备大小（宽高）的 DOM -->
    <div id="main" style="width: 600px;height:400px;"></div>
</body>

Paso 3: Establecer la información de configuración

La librería ECharts utiliza el formato JSON para la configuración.

echarts.init(document.getElementById('main')).setOption(option);

Aquí, 'option' indica que se utiliza la configuración en formato de datos JSON para dibujar el gráfico. Los pasos son los siguientes:

Título

Configura el título para el gráfico:

title: {
    text: '第一个 ECharts 实例'
}

Tooltip

Configura el tooltip:

tooltip: {},

Componente de leyenda

El componente de leyenda muestra las marcas (symbol), colores y nombres de las diferentes series. Puedes hacer clic en la leyenda para controlar qué series no se muestran.

legend: {
    data: [{
        name: '系列1',
        // 强制设置图形为圆。
        icon: 'circle',
        // 设置文本为红色
        textStyle: {
            color: 'red'
        }
    }]
}

Eje X

Configura los elementos que se mostrarán en el eje X:

xAxis: {
    data: ["衬衫","羊毛衫","雪纺衫","裤子","高跟鞋","袜子"]
}

Eje Y

Configura los elementos que se mostrarán en el eje Y.

yAxis: {}

Lista de series

Cada serie determina su propio tipo de gráfico mediante 'type':

series: [{
    name: '销量',  // 系列名称
    type: 'bar',  // 系列图表类型
    data: [5, 20, 36, 10, 10, 20]  // 系列中的数据内容
}]

Cada serie determina su propio tipo de gráfico mediante 'type':

  • type: 'bar': Gráfico de barras
  • type: 'line': Gráfico de líneas/área
  • type: 'pie': Gráfico de pastel
  • type: 'scatter': Gráfico de dispersión (burbujas)
  • type: 'effectScatter': Gráfico de dispersión (burbujas) con efecto de ondas animadas
  • type: 'radar': Gráfico de radar
  • type: 'tree': Gráfico de árbol
  • type: 'treemap': Gráfico de árbol
  • type: 'sunburst': Gráfico de sol
  • type: 'boxplot': Gráfico de caja
  • type: 'candlestick': Gráfico de velas
  • type: 'heatmap': Mapa de calor
  • type: 'map': Mapa
  • type: 'parallel': Serie de coordenadas paralelas
  • type: 'lines': Gráfico de líneas
  • type: 'graph': Gráfico de relaciones
  • type: 'sankey': Diagrama de Sankey
  • type: 'funnel': Gráfico de embudo
  • type: 'gauge': Gauge
  • type: 'pictorialBar': Gráfico de columnas pictóricas
  • type: 'themeRiver': Río temático
  • type: 'custom': Serie personalizada

Ejemplo

A continuación se muestra un ejemplo completo:

Ejemplo

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <title>Primer ejemplo de ECharts</title> <!--Incluir echarts.js--> <script src="https://cdn.staticfile.org/echarts/4.3.0/echarts.min.js"></script> </head> <body> <!--Preparar un DOM con tamaño (ancho y alto) para ECharts--> <div id="main" style="width: 600px;height:400px;"></div> <script type="text/javascript">// 基于准备好的dom，初始化echarts实例 var myChart = echarts.init(document.getElementById('main')); // 指定图表的配置项和数据 var option = { title: { text: '第一个 ECharts 实例' }, tooltip: {}, legend: { data:['销量'] }, xAxis: { data: ["衬衫","羊毛衫","雪纺衫","裤子","高跟鞋","袜子"] }, yAxis: {}, series: [{ name: '销量', type: 'bar', data: [5, 20, 36, 10, 10, 20] }] }; // 使用刚指定的配置项和数据显示图表。 myChart.setOption(option);</script> </body> </html>
