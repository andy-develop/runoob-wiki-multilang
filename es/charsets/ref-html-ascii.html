HTML ASCIIManual de referencia

ASCII es el primer conjunto de caracteres (estándar de codificación) utilizado entre computadoras en Internet.

ISO-8859-1 (el predeterminado en HTML 4.01) y UTF-8 (el predeterminado en HTML5) se basan en ASCII.

Conjunto de caracteres ASCII

ASCII significa "American Standard Code for Information Interchange", es decir, Código Estándar Estadounidense para el Intercambio de Información.

Fue diseñado a principios de los años 60 como un conjunto de caracteres estándar para computadoras y dispositivos electrónicos.

ASCII es un conjunto de caracteres de 7 bits que contiene 128 caracteres.

Incluye los dígitos 0-9, las letras del alfabeto inglés en mayúsculas y minúsculas (a-z, A-Z) y algunos caracteres especiales.

Los conjuntos de caracteres utilizados en las computadoras modernas, en HTML y en Internet se basan en ASCII.

Caracteres de control de dispositivos ASCII

Los caracteres de control ASCII (00-31, más 127) fueron diseñados originalmente para controlar dispositivos de hardware como impresoras y unidades de cinta.

Los caracteres de control (excepto el tabulador horizontal, el salto de línea y el retorno de carro) no tienen ningún efecto en los documentos HTML.
