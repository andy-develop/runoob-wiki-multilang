C++ Tipos de datos

Al programar con un lenguaje de programación, se necesitan varias variables para almacenar diversa información. La variable conserva la ubicación de memoria del valor que almacena. Esto significa que, cuando se crea una variable, se reserva algo de espacio en la memoria.

Es posible que necesite almacenar información de varios tipos de datos (como tipo carácter, carácter ancho, entero, flotante, doble flotante, booleano, etc.). El sistema operativo asignará memoria y decidirá qué almacenar en la memoria reservada según el tipo de dato de la variable.

Declaración typedef

Puede utilizartypedefpara dar un nuevo nombre a un tipo existente. A continuación se muestra la sintaxis para definir un nuevo tipo con typedef:

typedef type newname;

Por ejemplo, la siguiente declaración le indica al compilador que feet es otro nombre para int:

typedef int feet;

Ahora, la siguiente declaración es completamente legal y crea una variable entera distance:

feet distance;

Tipo enumerado

El tipo enumerado (enumeration) es un tipo de datos derivado en C++, que es un conjunto de varias constantes de enumeración definidas por el usuario.

Si una variable solo tiene algunos valores posibles, se puede definir como tipo enumerado (enumeration). El llamado "enumerar" significa listar los valores de la variable uno a uno; el valor de la variable solo puede estar dentro del rango de los valores listados.

Para crear una enumeración, se necesita la palabra claveenum. La forma general del tipo enumerado es:

enum 枚举名{ 
     标识符[=整型常数], 
     标识符[=整型常数], 
... 
    标识符[=整型常数]
} 枚举变量;

Si la enumeración no está inicializada, es decir, se omite "= constante entera", entonces comienza desde el primer identificador.

Por ejemplo, el siguiente código define una enumeración de colores, y la variable c es de tipo color. Finalmente, a c se le asigna "blue".

enum color { red, green, blue } c;
c = blue;

De forma predeterminada, el valor del primer nombre es 0, el del segundo nombre es 1, el del tercero es 2, y así sucesivamente. Sin embargo, también puede asignar un valor especial a un nombre, solo necesita agregar un valor inicial. Por ejemplo, en la siguiente enumeración,greentiene el valor 5.

enum color { red, green=5, blue };

Aquí,bluetiene el valor 6, porque de forma predeterminada, cada nombre es 1 mayor que el nombre anterior, pero el valor de red sigue siendo 0.


Conversión de tipos

La conversión de tipos es convertir el valor de un tipo de datos al valor de otro tipo de datos.

En C++ hay cuatro conversiones de tipos: conversión estática, conversión dinámica, conversión de constante y conversión de reinterpretación.

Conversión estática (Static Cast)

La conversión estática es forzar el valor de un tipo de datos al valor de otro tipo de datos.

La conversión estática se usa generalmente para conversiones entre objetos de tipos similares, por ejemplo, convertir el tipo int al tipo float.

La conversión estática no realiza ninguna verificación de tipo en tiempo de ejecución, por lo que puede provocar errores en tiempo de ejecución.

Ejemplo

int i = 10; float f = static_cast<float>(i); // Convertir estáticamente el tipo int al tipo float

Conversión dinámica (Dynamic Cast)

La conversión dinámica (dynamic_cast) es un mecanismo en C++ utilizado para realizar downcasting dentro de una jerarquía de herencia.

La conversión dinámica se usa generalmente para convertir un puntero o referencia de clase base a un puntero o referencia de clase derivada.

La conversión dinámica realiza la verificación de tipos en tiempo de ejecución. Si la conversión falla, para tipos de puntero devuelve nullptr, y para tipos de referencia lanza una excepción std::bad_cast.

Sintaxis:

dynamic_cast<目标类型>(表达式)

  • Tipo de destino: debe ser un tipo de puntero o referencia.

  • Expresión: el puntero o referencia de clase base que se necesita convertir.

Ejemplo: conversión dinámica de tipos puntero

#include <iostream> class Base { public: virtual ~Base() = default; // La clase base debe tener funciones virtuales }; class Derived : public Base { public: void show() { std::cout << "Derived class method" << std::endl; } }; int main() { Base* ptr_base = new Derived; // El puntero de clase base apunta a un objeto de clase derivada // Convertir el puntero de clase base a puntero de clase derivada Derived* ptr_derived = dynamic_cast<Derived*>(ptr_base); if (ptr_derived) { ptr_derived->show(); // Conversión exitosa, llamar al método de la clase derivada } else { std::cout << "Dynamic cast failed!" << std::endl; } delete ptr_base; return 0; }

Salida:

Derived class method

Ejemplo: conversión dinámica de tipos de referencia

#include <iostream>
#include <typeinfo>

class Base {
public:
    virtual ~Base() = default; // La clase base debe tener funciones virtuales
};

class Derived : public Base {
public:
    void show() {
        std::cout << "Derived class method" << std::endl;
    }
};

int main() {
    Derived derived_obj;
    Base& ref_base = derived_obj; // La referencia de clase base se enlaza a un objeto de clase derivada

    try {
        // Convertir la referencia de clase base a referencia de clase derivada
        Derived& ref_derived = dynamic_cast<Derived&>(ref_base);
        ref_derived.show(); // Conversión exitosa, llamar al método de la clase derivada
    } catch (const std::bad_cast& e) {
        std::cout << "Dynamic cast failed: " << e.what() << std::endl;
    }

    return 0;
}

Conversión de constante (Const Cast)

La conversión de constante se utiliza para convertir un objeto de tipo const a un objeto de tipo no const.

La conversión de constante solo se puede usar para eliminar el atributo const; no puede cambiar el tipo del objeto.

Ejemplo

const int i = 10; int& r = const_cast<int&>(i); // Conversión de constante, convertir const int a int

Conversión de reinterpretación (Reinterpret Cast)

La conversión de reinterpretación reinterpreta el valor de un tipo de datos como el valor de otro tipo de datos, y se usa generalmente para convertir entre diferentes tipos de datos.

La conversión de reinterpretación no realiza ninguna verificación de tipos, por lo que puede provocar un comportamiento indefinido.

Ejemplo

int i = 10; float f = reinterpret_cast<float&>(i); // Reinterpretar convirtiendo el tipo int al tipo float

    Algunas explicaciones sobre typedef:

    1. typedef puede declarar varios tipos de nombres, pero no se puede usar para definir variables. Con typedef se pueden declarar tipos de arreglos, tipos de cadenas, lo cual es más conveniente.
    2. Usar typedef solo agrega un nombre de tipo a un tipo ya existente, no crea un tipo nuevo.
    3. Cuando se usan los mismos tipos de datos en diferentes archivos fuente (especialmente tipos como arreglos, punteros, estructuras, uniones, etc.), a menudo se usa typedef para declarar algunos tipos de datos, colocarlos por separado en un archivo de cabecera, y luego en los archivos que los necesiten se incluyen con el comando #include, para mejorar la eficiencia de programación.
    4. Usar typedef favorece la portabilidad y generalización del programa. A veces el programa depende de características del hardware; usar typedef facilita la portabilidad.

    Diferencia entre typedef y #define

    1. El tiempo de ejecución es diferente.

    La palabra clave typedef es válida en la fase de compilación; dado que ocurre en dicha fase, typedef tiene la función de verificación de tipos.

    #define es una definición de macro, ocurre en la fase de preprocesamiento, es decir, antes de la compilación; solo realiza un reemplazo de cadenas simple y mecánico, sin realizar ninguna verificación.

    【Ejemplo 1.1】typedef realiza la verificación de tipos correspondiente:

    typedef unsigned int UINT;
 
void func()
{
    UINT value = "abc"; // error C2440: 'initializing' : cannot convert from 'const char [4]' to 'UINT'
    cout << value << endl;
}

    【Ejemplo 1.2】#define no realiza verificación de tipos:

    // #define用法例子：
#define f(x) x*x
int main()
{
    int a=6, b=2, c;
    c=f(a) / f(b);
    printf("%d\n", c);
    return 0;
}

    El resultado de salida del programa es: 36; la razón fundamental es que #define es solo un simple reemplazo de cadenas.

    2. Difieren en funcionalidad.

    typedef se usa para definir alias de tipos, definir tipos de datos independientes de la plataforma, su combinación con struct, etc.

    #define no solo puede asignar alias a tipos, sino que también puede definir constantes, variables, interruptores de compilación, etc.

    3. El ámbito es diferente.

    #define no tiene restricciones de ámbito; siempre que sea una macro predefinida con anterioridad, se puede usar en programas posteriores.

    Mientras que typedef tiene su propio ámbito.

    【Ejemplo 3.1】No hay restricción de ámbito; siempre que se haya predefinido previamente, se puede usar.

    void func1()
{
    #define HW "HelloWorld";
}
 
void func2()
{
    string str = HW;
    cout << str << endl;
}

    【Ejemplo 3.2】Pero typedef tiene su propio ámbito.

    void func1()
{
    typedef unsigned int UINT;
}
 
void func2()
{
    UINT uValue = 5;//error C2065: 'UINT' : undeclared identifier
}

    【Ejemplo 3.3】

    class A
{
    typedef unsigned int UINT;
    UINT valueA;
    A() : valueA(0){}
};
 
class B
{
    UINT valueB;
    //error C2146: syntax error : missing ';' before identifier 'valueB'
    //error C4430: missing type specifier - int assumed. Note: C++ does not support default-int
};

    En el ejemplo anterior, usar UINT en la clase B provocará un error, porque UINT solo está en el ámbito de la clase A. Además, los alias de tipo definidos con typedef dentro de una clase también tienen permisos de acceso correspondientes, 【Ejemplo 3.4】:

    class A
{
    typedef unsigned int UINT;
    UINT valueA;
    A() : valueA(0){}
};
 
void func3()
{
    A::UINT i = 1;
    // error C2248: 'A::UINT' : cannot access private typedef declared in class 'A'
}

    Sin embargo, al agregar el permiso de acceso public a UINT, la compilación será exitosa.

    【Ejemplo 3.5】:

    class A
{
public:
    typedef unsigned int UINT;
    UINT valueA;
    A() : valueA(0){}
};
 
void func3()
{
    A::UINT i = 1;
    cout << i << endl;
}

    Cuando ambos modifican tipos de puntero, sus efectos son diferentes.

#define PINT int *

    También se puede usar typedef para definir tipos independientes de la plataforma.

    Por ejemplo, si se define un tipo de punto flotante llamado FALSE, en la primera plataforma objetivo se le asigna el tipo de mayor precisión:

    typedef long double FALSE;

    En la segunda plataforma, que no admite long double, se cambia a:

    typedef double FALSE;

    En la tercera plataforma, que ni siquiera admite double, se cambia a:

    typedef float FALSE;

    Es decir, al ser multiplataforma, solo hay que modificar el propio typedef, sin necesidad de realizar cambios en el resto del código fuente.

    La biblioteca estándar utiliza ampliamente esta técnica, por ejemplo, size_t.

    Además, dado que typedef define un nuevo alias para un tipo y no es un simple reemplazo de cadenas, es más robusto que la macro (aunque a veces la macro también puede lograr los propósitos anteriores).

    reinterpret_cast 和 static_castSon operadores de conversión de tipos en C++, pero tienen diferencias significativas en su propósito y seguridad.

    1、reinterpret_cast

    reinterpret_castSe utiliza para realizar conversiones de bajo nivel, casi sin verificación de tipos, entre casi cualquier tipo. Esta conversión reinterpreta los datos directamente a nivel de bits, por lo que es la conversión más insegura. Generalmente se usa para:

    • Convertir tipos de puntero a otros tipos de puntero.
    • Convertir un puntero a un tipo entero lo suficientemente grande, y viceversa.
    • Realizar conversiones de bajo nivel entre objetos de diferentes tipos.

    Esta conversión no realiza ninguna verificación, por lo que el programador debe asegurarse de que dicha conversión sea razonable y segura.

    2、static_cast

    static_castSe utiliza para realizar conversiones entre tipos relacionados; es relativamente seguro y pasa por verificación de tipos en tiempo de compilación. Es adecuado para:

    • Conversión entre tipos básicos, por ejemplo deint 到 float。
    • Conversiones ascendentes y descendentes de punteros y referencias en jerarquías de clases relacionadas.
    • Conversión de punteros y referencias ordinarios avoid*, y viceversa.
