C++ Memoria dinámica

Entender cómo funciona la memoria dinámica en C++ es esencial para convertirte en un programador de C++ competente. La memoria en un programa de C++ se divide en dos partes:

  • Pila (stack):Todas las variables declaradas dentro de una función ocuparán memoria de la pila.
  • Montón (heap):Esta es la memoria no utilizada del programa, que se puede usar para asignar memoria dinámicamente durante la ejecución del programa.

Muchas veces no puedes predecir de antemano cuánta memoria necesitas para almacenar información específica en una variable definida; el tamaño de memoria requerido solo puede determinarse en tiempo de ejecución.

En C++, puedes usar operadores especiales para asignar memoria en el montón en tiempo de ejecución para variables de un tipo dado, lo que devuelve la dirección del espacio asignado. Este tipo de operador esnewoperador.

Si ya no necesitas el espacio de memoria asignado dinámicamente, puedes usardeleteoperador para liberar la memoria asignada previamente por el operador new.

Los operadores new y delete

A continuación se muestra la sintaxis general para usar el operador new a fin de asignar memoria dinámicamente para cualquier tipo de datos:

new data-type;

Aquí,data-typepuede ser cualquier tipo de datos integrado, incluidos los arreglos, o cualquier tipo de datos definido por el usuario, incluidas clases o estructuras. Veamos primero los tipos de datos integrados. Por ejemplo, podemos definir un puntero al tipo double y luego solicitar memoria, la cual se asigna en tiempo de ejecución. Podemos usar la siguiente declaración connewoperador para lograr esto:

double* pvalue = NULL; // puntero inicializado a null pvalue = new double; // solicitar memoria para la variable

Si el área de almacenamiento libre se ha agotado, es posible que la asignación de memoria no se realice correctamente. Por lo tanto, se recomienda verificar si el operador new devuelve un puntero NULL y tomar las medidas adecuadas:

double* pvalue = NULL; if( !(pvalue = new double )) { cout << "Error: out of memory." <<endl; exit(1); }

malloc()La función ya apareció en el lenguaje C y todavía existe en C++, pero se recomienda evitar el uso de la función malloc() en la medida de lo posible. En comparación con malloc(), la principal ventaja de new es que new no solo asigna memoria, sino que también crea objetos.

En cualquier momento, cuando consideres que una variable con memoria asignada dinámicamente ya no es necesaria, puedes usar el operador delete para liberar la memoria que ocupa, como se muestra a continuación:

delete pvalue;        // 释放 pvalue 所指向的内存

El siguiente ejemplo utiliza los conceptos anteriores y demuestra cómo usar los operadores new y delete:

Ejemplo

#include <iostream> using namespace std; int main () { double* pvalue = NULL; // puntero inicializado a null pvalue = new double; // solicitar memoria para la variable *pvalue = 29494.99; // almacenar el valor en la dirección asignada cout << "Value of pvalue : " << *pvalue << endl; delete pvalue; // liberar memoria return 0; }

Cuando el código anterior se compila y se ejecuta, produce los siguientes resultados:

Value of pvalue : 29495

Asignación dinámica de memoria para arreglos

Supongamos que queremos asignar memoria para un arreglo de caracteres (una cadena de 20 caracteres). Podemos usar la sintaxis del ejemplo anterior para asignar memoria dinámicamente al arreglo, de la siguiente manera:

char* pvalue  = NULL;   // 初始化为 null 的指针
pvalue  = new char[20]; // 为变量请求内存

Para eliminar el arreglo que acabamos de crear, la declaración es la siguiente:

delete [] pvalue;        // 删除 pvalue 所指向的数组

A continuación se muestra la sintaxis general del operador new para asignar memoria a arreglos multidimensionales:

Arreglo unidimensional

// asignación dinámica, longitud del arreglo m int *array=new int [m]; // liberar memoria delete [] array;

Arreglo bidimensional

int **array; // supongamos que la primera dimensión del arreglo tiene longitud m y la segunda dimensión tiene longitud n // asignar espacio dinámicamente array = new int *[m]; for( int i=0; i<m; i++ ) { array[i] = new int [n]; } // liberar for( int i=0; i<m; i++ ) { delete [] array[i]; } delete [] array;

Prueba de ejemplo de arreglo bidimensional:

Ejemplo

#include <iostream> using namespace std; int main() { int **p; int i,j; //p[4][8] // comenzar a asignar datos bidimensionales de 4 filas y 8 columnas p = new int *[4]; for(i=0;i<4;i++){ p[i]=new int [8]; } for(i=0; i<4; i++){ for(j=0; j<8; j++){ p[i][j] = j*i; } } // imprimir datos for(i=0; i<4; i++){ for(j=0; j<8; j++) { if(j==0) cout<<endl; cout<<p[i][j]<<"\t"; } } // comenzar a liberar el montón solicitado for(i=0; i<4; i++){ delete [] p[i]; } delete [] p; return 0; }

Arreglo tridimensional

int ***array; // supongamos que la primera dimensión del arreglo es m, la segunda es n y la tercera es h // asignar espacio dinámicamente array = new int **[m]; for( int i=0; i<m; i++ ) { array[i] = new int *[n]; for( int j=0; j<n; j++ ) { array[i][j] = new int [h]; } } // liberar for( int i=0; i<m; i++ ) { for( int j=0; j<n; j++ ) { delete[] array[i][j]; } delete[] array[i]; } delete[] array;

Ejemplo de prueba de arreglo tridimensional:

Ejemplo

#include <iostream> using namespace std; int main() { int i,j,k; // p[2][3][4] int ***p; p = new int **[2]; for(i=0; i<2; i++) { p[i]=new int *[3]; for(j=0; j<3; j++) p[i][j]=new int[4]; } // generar los datos tridimensionales p[i][j][k] for(i=0; i<2; i++) { for(j=0; j<3; j++) { for(k=0;k<4;k++) { p[i][j][k]=i+j+k; cout<<p[i][j][k]<<" "; } cout<<endl; } cout<<endl; } // liberar memoria for(i=0; i<2; i++) { for(j=0; j<3; j++) { delete [] p[i][j]; } } for(i=0; i<2; i++) { delete [] p[i]; } delete [] p; return 0; }

Asignación dinámica de memoria para objetos

Los objetos no son diferentes de los tipos de datos simples. Por ejemplo, mira el siguiente código; usaremos un arreglo de objetos para aclarar este concepto:

Ejemplo

#include <iostream> using namespace std; class Box { public: Box() { cout << "¡Llamando al constructor!" <<endl; } ~Box() { cout << "¡Llamando al destructor!" <<endl; } }; int main( ) { Box* myBoxArray = new Box[4]; delete [] myBoxArray; // eliminar el arreglo return 0; }

Si deseas asignar memoria para un arreglo que contiene cuatro objetos Box, el constructor se llamará 4 veces; de manera similar, al eliminar estos objetos, el destructor también se llamará la misma cantidad de veces (4 veces).

    Diferencias entre delete y delete[]:

    1. Para tipos simples, después de usar new para asignar memoria, ya sea en forma de arreglo o no, ambos métodos son válidos. Por ejemplo:

    int *a = new int[10];   
delete a;   
delete [] a;

    En este caso, el efecto de liberación es el mismo, porque al asignar memoria de tipos simples, el tamaño de la memoria ya está determinado y el sistema puede recordarlo y gestionarlo. Al destruir, el sistema no llama al destructor; obtiene directamente el espacio de memoria realmente asignado a través del puntero, incluso si es un espacio de memoria de un arreglo (durante la asignación, el sistema registra información como el tamaño de la memoria asignada; esta información se guarda en la estructura _CrtMemBlockHeader; para más detalles, consulta CRT\SRC\DBGDEL.cpp en el directorio de instalación de VC).

    2. Para clases, los dos métodos muestran diferencias concretas

    Cuando asignas un arreglo de objetos de clase de la siguiente manera:

    class A
{
    private:
        char *m_cBuffer;
        int m_nLen;
    public:
        A(){ m_cBuffer = new char[m_nLen]; }
        ~A() { delete [] m_cBuffer; }
};
A *a = new A[10];

// 仅释放了a指针指向的全部内存空间 但是只调用了a[0]对象的析构函数 剩下的从a[1]到a[9]这9个用户自行分配的m_cBuffer对应内存空间将不能释放 从而造成内存泄漏
delete a;

// 调用使用类对象的析构函数释放用户自己分配内存空间并且   释放了a指针指向的全部内存空间
delete [] a;

    En resumen, si ptr representa la dirección del espacio de memoria devuelto por una asignación con new, es decir, el llamado puntero, entonces:

    • delete ptr-- se usa para liberar memoria, y solo se usa para liberar la memoria a la que apunta ptr.
    • delete[] rg-- se usa para liberar la memoria a la que apunta rg, ¡¡y además llama al destructor de cada objeto del arreglo uno por uno!!

    Para tipos de datos simples como int/char/long/int*/struct, etc., como los objetos no tienen destructor, usar delete y delete [] es lo mismo. ¡Pero si se trata de un arreglo de objetos de C++, la cosa es diferente!

    Usando memoria dinámica, también podemos crear listas enlazadas y arreglos que pueden crecer continuamente:

    #include <iostream>
#include <cstdio>

using namespace std;

struct node
{    
    //链表的节点
    int data;//数据
    int num;//节点编号
    struct node *next;//指向下一个节点
};

int main()
{
    struct node *head/*头节点*/, *p, *q;
    head=NULL;
    p=NULL;
    q=new node;
    q->next=NULL;
    q->num=1;
    int a=-1;
    cout<<"请输入第1个数字:";
    cin>>a;
    q->data=a;
    head=q;
    while (a!=0)
    {
        p=q;
        q=new node;
        q->next=NULL;
        p->next=q;
        q->num=p->num+1;
        cout<<"请输入第"<<q->num<<"个数字:";
        cin>>a;
        q->data=a;
    }

    //前面都是输入,这以下都是输出

    q=head;
    p=NULL;
    while (q->data!=0)
    {
        printf("%d %d\n",q->num,q->data);
        q=q->next;
    }
    
    //释放内存

    q=head;
    p=q;
    while(q->next!=NULL)
    {
        p=q->next;
        delete []q;
        q = p;  
    }
    return 0;
}

    ¿Cuál es la diferencia en la implementación interna de new y malloc?

    La función de new es crear un nuevo objeto en el área del montón y devolver un puntero a dicho objeto.

    Lo que se llama【crear un nuevo objeto】significa que se llamará al constructor de la clase, porque si no se construye, no se puede considerar un objeto.

    Por otro lado, malloc solo asigna un bloque de memoria mecánicamente; si se usa malloc para crear un objeto en el área del montón, no se llamará al constructor.

    Estrictamente hablando, usar malloc no se puede considerar como crear un nuevo objeto; solo se puede decir que se asignó un bloque de memoria que coincide con el objeto de esa clase, y luego se interpreta a la fuerza como 【esto es un objeto】. Siguiendo esta lógica, el constructor no tiene intervención.

    De manera similar, usar delete para liberar un objeto en el área del montón llamará al destructor de ese objeto.

    Usar free para liberar un objeto en el área del montón no llamará al destructor de ese objeto.

    Basta con hacer un experimento sencillo para entenderlo:

    #include <iostream>
#include <malloc.h>

class TEST
{
private:
    int num1;
    int num2;
public:
    TEST()
    {
        num1 = 10;
        num2 = 20;
    }
    void Print()
    {
        std::cout << num1 << " " << num2 << std::endl;
    }
};

int main(void)
{
    // 用malloc()函数在堆区分配一块内存空间，然后用强制类型转换将该块内存空间
    // 解释为是一个TEST类对象，这不会调用TEST的默认构造函数
    TEST * pObj1 = (TEST *)malloc(sizeof(TEST));
    pObj1->Print();

    // 用new在堆区创建一个TEST类的对象，这会调用TEST类的默认构造函数
    TEST * pObj2 = new TEST;
    pObj2->Print();

    return 0;
}
/*
运行结果：

10 20                       |
请按任意键继续. . .         |
-----------------------------

我们可以看到pObj1所指的对象中，字段num1与num2都是垃圾值
而pObj2所指的对象中，字段num1与num2显然是经过了构造后的值
*/

    La segunda nota tiene una buena idea, pero es incorrecta. Esta forma de escribir terminará con un nodo cuyo data es 0, pero al recorrer y destruir se usa data == 0 para determinar el final, lo que omite la operación sobre el nodo con data == 0. La corrección es la siguiente:

    #include<iostream>
using namespace std;

struct node
{
    //链表的节点
    int data;//数据
    int num;//节点编号
    struct node *next;//指向下一个节点
};

int main()
{
    struct node *head/*头节点*/, *p, *q;
    head = NULL;
    p = NULL;
    q = new node;
    q->next = NULL;
    q->num = 1;
    int a = -1;
    cout << "请输入第1个数字:";
    cin >> a;
    q->data = a;
    head = q;
    while (a != 0)
    {
        p = q;
        q = new node;
        q->next = NULL;
        p->next = q;
        q->num = p->num + 1;
        cout << "请输入第" << q->num << "个数字:";
        cin >> a;
        q->data = a;
    }

    //前面都是输入,这以下都是输出

    q = head;
    p = NULL;
    while (1)
    {
        printf("%d %d\n", q->num, q->data);
        if (q->data == 0)
            break;
        q = q->next;
    }

    //释放内存

    q = head;
    p = q;
    while (1)
    {
        p = q->next;
        delete[]q;
        q = p;
        if (!q)
            break;
    }
    return 0;
}

    Respecto a la pregunta anterior, delete[] p y delete p no tienen mucha diferencia en la liberación de tipos simples, pero para el ejemplo dado, el primero sí libera toda la memoria del array, mientras que el segundo solo libera la memoria del elemento inicial del array. Sin embargo, el método de verificación no es correcto: después de la operación delete, p en realidad se convierte en un puntero salvaje y ya no apunta a ningún valor válido. Esta es también la razón por la que se imprimieron dos valores extraños.
