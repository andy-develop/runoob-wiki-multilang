C++ Sintaxis básica

Un programa C++ puede definirse como una colección de objetos que interactúan llamando a los métodos de los demás. Ahora veamos brevemente qué son las clases, los objetos, los métodos y las variables de instancia.

  • Objeto -Un objeto tiene estado y comportamiento. Por ejemplo: el estado de un perro - color, nombre, raza; comportamiento - mover la cola, ladrar, comer. Un objeto es una instancia de una clase.
  • Clase -Una clase puede definirse como una plantilla/modelo que describe el comportamiento/estado de los objetos.
  • Método -Básicamente, un método representa un comportamiento. Una clase puede contener múltiples métodos. Se puede escribir lógica, manipular datos y realizar todas las acciones dentro de los métodos.
  • Variables de instancia -Cada objeto tiene sus propias variables de instancia únicas. El estado de un objeto se crea a partir de los valores de estas variables de instancia.

Estructura de un programa C++

Veamos un fragmento de código simple que puede imprimir la palabraHello World。

Ejemplo

#include <iostream> using namespace std; // main() es donde el programa comienza a ejecutarse int main() { cout << "Hello World"; // Imprime Hello World return 0; }

A continuación, explicamos el programa anterior:

  • El lenguaje C++ define algunos archivos de encabezado que contienen información necesaria o útil para el programa. En el programa anterior, se incluye el archivo de encabezado<iostream>。
  • La siguiente líneausing namespace std;le dice al compilador que use el espacio de nombres std. El espacio de nombres es un concepto relativamente nuevo en C++.
  • La siguiente línea// main() es donde el programa comienza a ejecutarsees un comentario de una sola línea. Los comentarios de una sola línea comienzan con // y terminan al final de la línea.
  • La siguiente líneaint main()es la función principal, desde donde el programa comienza a ejecutarse.
  • La siguiente líneacout << "Hello World";mostrará el mensaje "Hello World" en la pantalla.
  • La siguiente líneareturn 0;finaliza la función main() y devuelve el valor 0 al proceso que la invocó.

Compilar y ejecutar programas C++

A continuación, veamos cómo guardar el código fuente en un archivo y cómo compilarlo y ejecutarlo. Estos son los pasos simples:

  • Abra un editor de texto y agregue el código anterior.
  • Guarde el archivo como hello.cpp.
  • Abra el símbolo del sistema y acceda al directorio donde se guardó el archivo.
  • Escriba 'g++ hello.cpp' y presione Enter para compilar el código. Si no hay errores en el código, el símbolo del sistema saltará a la siguiente línea y generará el archivo ejecutable a.out.
  • Ahora, escriba 'a.out' para ejecutar el programa.
  • Puede ver que se muestra 'Hello World' en la pantalla.
$ g++ hello.cpp
$ ./a.out
Hello World

Asegúrese de que el compilador g++ esté incluido en su ruta (PATH) y de ejecutarlo en el directorio que contiene el archivo fuente hello.cpp.

También puede usar un makefile para compilar programas C/C++.

Punto y coma y bloques de declaraciones en C++

En C++, el punto y coma es el terminador de declaraciones. Es decir, cada declaración debe terminar con un punto y coma. Indica el final de una entidad lógica.

Por ejemplo, las siguientes son tres declaraciones diferentes:

x = y; y = y+1; add(x, y);

Un bloque de declaraciones es un conjunto de declaraciones lógicamente conectadas encerradas entre llaves. Por ejemplo:

{ cout << "Hello World"; // Imprime Hello World return 0; }

C++ no usa el final de línea como indicador de terminación, por lo que puede colocar varias declaraciones en una línea. Por ejemplo:

x = y; y = y+1; add(x, y);

es equivalente a

x = y; y = y+1; add(x, y);

Identificadores de C++

Los identificadores de C++ son nombres utilizados para identificar variables, funciones, clases, módulos o cualquier otro elemento definido por el usuario. Un identificador comienza con una letra A-Z o a-z o un guion bajo _, seguido de cero o más letras, guiones bajos y dígitos (0-9).

No se permiten caracteres de puntuación como @, & y % dentro de los identificadores de C++. C++ es un lenguaje de programación que distingue entre mayúsculas y minúsculas. Por lo tanto, en C++,Manpower 和 manpowerson dos identificadores diferentes.

Trígrafos

Un trígrafo es una secuencia de tres caracteres que se utiliza para representar otro carácter, también conocida como secuencia de tres caracteres. Las secuencias de trígrafos siempre comienzan con dos signos de interrogación.

Las secuencias de trígrafos no son muy comunes, pero el estándar C++ permite designar ciertos caracteres como secuencias de trígrafos. Antiguamente, era un método indispensable para representar caracteres que no estaban en el teclado.

Las secuencias de trígrafos pueden aparecer en cualquier lugar, incluidas cadenas, secuencias de caracteres, comentarios y directivas de preprocesamiento.

A continuación se enumeran las secuencias de trígrafos más comunes:

Si desea tener dos signos de interrogación consecutivos en el programa fuente y no desea que el preprocesador los reemplace, lo cual ocurre en constantes de caracteres, literales de cadena o comentarios del programa, una opción es usar la concatenación automática de cadenas: "...?""?..." o la secuencia de escape: "...?\?...".

A partir de Microsoft Visual C++ 2010, este compilador ya no reemplaza automáticamente los trígrafos de forma predeterminada. Si necesita usar el reemplazo de trígrafos (por ejemplo, para compatibilidad con código de software antiguo), debe configurar la opción de línea de comandos del compilador /Zc:trigraphs

g++ todavía admite trígrafos de forma predeterminada, pero emitirá una advertencia de compilación.

Espacios en blanco en C++

Una línea que solo contiene espacios en blanco se denomina línea en blanco, puede tener comentarios, y el compilador de C++ la ignora por completo.

En C++, los espacios en blanco se utilizan para describir espacios, tabulaciones, saltos de línea y comentarios. Los espacios en blanco separan las distintas partes de una declaración, permitiendo que el compilador identifique dónde termina un elemento (como int) y dónde comienza el siguiente. Por lo tanto, en la siguiente declaración:

int age;

Aquí, debe haber al menos un carácter de espacio (generalmente un espacio en blanco) entre int y age, para que el compilador pueda distinguirlos. Por otro lado, en la siguiente declaración:

fruit = apples + oranges;   // 获取水果的总数

Los caracteres de espacio entre fruit y =, o entre = y apples, no son necesarios, pero para mejorar la legibilidad, puede agregar algunos espacios según sea necesario.

    En C++, ¿por qué se debe agregar un tipo de datos delante de la función main, por ejemplo:int void ?

    mainEl valor de retorno de la función se devuelve al proceso que la invoca, para que el proceso que la invoca conozca el resultado de la ejecución del programa llamado.

    El estándar especifica quemainel valor de retorno de la función esint, generalmente se acuerda que devolver 0 significa que el programa se ejecutó sin errores; los demás valores son números de error, pero esta convención no es obligatoria.

    Si el resultado de la ejecución del programa no necesita devolverse al proceso que lo invoca, o si el desarrollador del programa confirma que este estado no es importante, por ejemplo, cuando todos los mensajes de error se muestran claramente en el programa, se puede omitir el valor de retorno de la función main. En algunos compiladores que no son muy estrictos en la verificación, como VC, VS, etc., se permite main de tipo void. Sin embargo, en algunos compiladores con verificación estricta, como g++, se requiere que el valor de retorno de la función main sea de tipo int.

    Por lo tanto, al programar, distinguir el resultado de la ejecución del programa y devolverlo como tipo int es un buen hábito de programación.

    ¿Cuál es la diferencia entre int main() e int main(void) en C?

    int main(void)Se refiere a que los parámetros de esta función están vacíos; no se pueden pasar argumentos. Si pasas argumentos, se producirá un error.

    int main()Indica que se pueden pasar argumentos.

    // 这样是正确的
int main()
{
  if (0) main(42);
}

// 这样会出错
int main(void)
{
  if (0) main(42);
}

    En C++int main() 和 int main(void)son equivalentes, pero en C dejar los paréntesis vacíos significa que el compilador guarda silencio sobre si acepta parámetros. En C, omitir el tipo de retorno en main() equivale a indicar que el tipo de retorno es int, aunque este uso se está eliminando gradualmente en C++. Aunque void main() es aplicable en muchos sistemas, no es estándar, por lo que se debe evitar este uso; se debe usar esta formaint main(void)de escribir, que es más adecuada.

    Algunos nombres son propensos a conflictos, por lo que se utiliza el espacio de nombres para distinguirlos; específicamente, se añade un prefijo.
