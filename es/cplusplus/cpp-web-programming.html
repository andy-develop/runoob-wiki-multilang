C++ Programación web

¿Qué es CGI?

  • La Interfaz de Puerta de Enlace Común (CGI, por sus siglas en inglés) es un conjunto de estándares que define cómo se intercambia la información entre el servidor web y los scripts del cliente.
  • La especificación CGI actualmente es mantenida por NCSA, y NCSA define CGI de la siguiente manera:
  • La Interfaz de Puerta de Enlace Común (CGI) es un estándar de interfaz utilizado para conectar programas de puerta de enlace externos con servidores de información (como servidores HTTP).
  • La versión actual es CGI/1.1, y la versión CGI/1.2 está en desarrollo.

Navegación web

Para comprender mejor el concepto de CGI, hagamos clic en un hipervínculo, naveguemos a una página web o URL específica y veamos qué sucede.

  • Su navegador se conecta al servidor web HTTP y solicita la URL, es decir, el nombre del archivo.
  • El servidor web analizará la URL y buscará el nombre del archivo. Si encuentra el archivo solicitado, el servidor web enviará el archivo de vuelta al navegador; de lo contrario, enviará un mensaje de error indicando que ha solicitado un archivo incorrecto.
  • El navegador web obtiene la respuesta del servidor web y muestra el archivo o el mensaje de error según la respuesta recibida.

Sin embargo, en un servidor HTTP configurado de esta manera, cada vez que se solicita un archivo en el directorio, el servidor HTTP no envía el archivo, sino que lo ejecuta como programa y envía la salida generada por la ejecución de vuelta al navegador para que se muestre.

La Interfaz de Puerta de Enlace Común (CGI) es un protocolo estándar que permite que las aplicaciones (llamadas programas CGI o scripts CGI) puedan interactuar con el servidor web y con el cliente. Estos programas CGI pueden escribirse en Python, PERL, Shell, C o C++, entre otros.

Configuración del servidor web

Antes de realizar programación CGI, asegúrese de que su servidor web sea compatible con CGI y esté configurado para manejar programas CGI. Todos los programas CGI ejecutados por el servidor HTTP deben estar en un directorio preconfigurado. Este directorio se llama directorio CGI y, por convención, se denomina /var/www/cgi-bin. Aunque los archivos CGI son ejecutables de C++, por convención su extensión es.cgi。

De forma predeterminada, el servidor web Apache está configurado para ejecutar programas CGI en /var/www/cgi-bin. Si desea especificar otro directorio para ejecutar scripts CGI, puede modificar la siguiente sección en el archivo httpd.conf:

<Directory "/var/www/cgi-bin">
   AllowOverride None
   Options ExecCGI
   Order allow,deny
   Allow from all
</Directory>
 
<Directory "/var/www/cgi-bin">
Options All
</Directory>

Aquí asumimos que el servidor web ya está configurado y funciona correctamente; puede ejecutar cualquier programa CGI, como Perl o Shell, etc.

Los programas CGI en C++ pueden interactuar con cualquier otro sistema externo (como RDBMS).

Cabeceras HTTP

行 Content-type:text/html\r\n\r\nEs parte de las cabeceras HTTP y se envía al navegador para que comprenda mejor el contenido de la página. El formato de las cabeceras HTTP es el siguiente:

HTTP 字段名称: 字段内容
 
例如
Content-type: text/html\r\n\r\n

También hay otras cabeceras HTTP importantes que se utilizan con frecuencia en su programación CGI.

Cabecera Descripción
Content-type: Cadena MIME que define el formato del archivo devuelto. Por ejemplo, Content-type:text/html.
Expires: Date Fecha en la que la información deja de ser válida. El navegador la utiliza para determinar cuándo debe actualizarse una página. El formato de una cadena de fecha válida debe ser 01 Jan 1998 12:00:00 GMT.
Location: URL Esta URL se refiere a la URL que debe devolverse, no a la URL solicitada. Puede usarla para redirigir una solicitud a cualquier archivo.
Last-modified: Date Fecha de última modificación del recurso.
Content-length: N Longitud de los datos a devolver, en bytes. El navegador utiliza este valor para indicar el tiempo estimado de descarga de un archivo.
Set-Cookie: String MediantestringEstablecer cookie.

Variables de entorno CGI

Todos los programas CGI pueden acceder a las siguientes variables de entorno. Estas variables desempeñan un papel muy importante al escribir programas CGI.

Nombre de la variable Descripción
CONTENT_TYPE Tipo de datos del contenido. Se utiliza cuando el cliente envía contenido adicional al servidor. Por ejemplo, funciones como la subida de archivos.
CONTENT_LENGTH Longitud de la información de la consulta. Solo disponible para solicitudes POST.
HTTP_COOKIE Devuelve las cookies configuradas en forma de pares clave y valor.
HTTP_USER_AGENT Campo de cabecera de solicitud de agente de usuario que proporciona información sobre la solicitud realizada por el usuario, incluyendo el nombre del navegador, la versión y otra información adicional de la plataforma.
PATH_INFO Ruta del script CGI.
QUERY_STRING Información codificada en URL cuando se envía una solicitud mediante el método GET, incluye los parámetros después del signo de interrogación en la URL.
REMOTE_ADDR Dirección IP del host remoto que realiza la solicitud. Esto es muy útil para el registro de logs y la autenticación.
REMOTE_HOST Nombre completamente calificado del host que realiza la solicitud. Si esta información no está disponible, se puede usar REMOTE_ADDR para obtener la dirección IP.
REQUEST_METHOD Método utilizado para realizar la solicitud. Los métodos más comunes son GET y POST.
SCRIPT_FILENAME Ruta completa del script CGI.
SCRIPT_NAME Nombre del script CGI.
SERVER_NAME Nombre de host o dirección IP del servidor.
SERVER_SOFTWARE Nombre y versión del software que se ejecuta en el servidor.

Métodos GET y POST

Es posible que haya encontrado una situación en la que necesite pasar información desde el navegador al servidor web y, finalmente, al programa CGI. Normalmente, el navegador utiliza dos métodos para enviar esta información al servidor web: los métodos GET y POST.

Enviar información usando el método GET

El método GET envía la información de usuario codificada añadida a la petición de la página. La página y la información codificada se separan mediante el carácter ?, como se muestra a continuación:

http://www.test.com/cgi-bin/cpp.cgi?key1=value1&key2=value2

El método GET es el método predeterminado para enviar información desde el navegador al servidor web. Genera una cadena larga en la barra de direcciones del navegador. Cuando envíe contraseñas u otra información sensible al servidor, no utilice el método GET. El método GET tiene una limitación de tamaño: se pueden enviar como máximo 1024 caracteres en una cadena de solicitud.

Cuando se utiliza el método GET, la información se envía mediante la cabecera HTTP QUERY_STRING, y se puede acceder a ella en un programa CGI mediante la variable de entorno QUERY_STRING.

Puede pasar información añadiendo pares clave-valor simples al final de la URL, o mediante el método GET de la etiqueta HTML <FORM>.

Ejemplo simple de URL: método GET

A continuación se muestra una URL simple que utiliza el método GET para pasar dos valores al programa cpp_get.cgi.

/cgi-bin/cpp_get.cgi?first_name=ZARA&last_name=ALI

El siguiente ejemplo generacpp_get.cgiPrograma CGI para procesar la entrada proporcionada por el navegador web. Utilizando la biblioteca CGI de C++, se puede acceder fácilmente a la información pasada:

Ejemplo

Un método más fiable para pasar información a un programa CGI es el método POST. Este método empaqueta la información de la misma manera que el método GET, pero en lugar de pasarla como una cadena de texto después del ? en la URL, la envía como un mensaje separado. Dicho mensaje se pasa al script CGI a través de la entrada estándar.

Uso de cookies en CGI

El protocolo HTTP es un protocolo sin estado. Sin embargo, para un sitio web comercial, es necesario mantener la información de sesión entre diferentes páginas. Por ejemplo, un usuario finaliza su registro después de completar varios pasos en diferentes páginas. Pero, ¿cómo mantener la información de sesión del usuario en todas las páginas web?

En muchos casos, el uso de cookies es el método más eficaz para recordar y rastrear información sobre las preferencias, compras, comisiones del usuario y otros datos necesarios para una mejor experiencia del visitante o para las estadísticas del sitio web.

Cómo funciona

El servidor envía algunos datos al navegador del visitante en forma de cookie. Si el navegador acepta la cookie, esta se almacena en el disco duro del visitante como un registro de texto plano. Luego, cuando el visitante accede a otra página del sitio, se recupera la cookie. Una vez encontrada la cookie, el servidor sabe qué se ha almacenado.

Una cookie es un registro de datos en texto plano con 5 campos de longitud variable:

  • Expires :La fecha de caducidad de la cookie. Si este campo se deja vacío, la cookie caduca cuando el visitante cierra el navegador.
  • Domain :El dominio del sitio web.
  • Path :La ruta del directorio o página web que establece la cookie. Si desea recuperar la cookie desde cualquier directorio o página, este campo puede dejarse vacío.
  • Secure :Si este campo contiene la palabra "secure", la cookie solo puede recuperarse a través de un servidor seguro. Si este campo se deja vacío, no existe dicha restricción.
  • Name=Value :Las cookies se establecen y se obtienen en forma de pares clave-valor.

Configuración de cookies

Enviar cookies al navegador es muy sencillo. Estas cookies se envían junto con las cabeceras HTTP, antes del campo Content-type. Supongamos que desea establecer UserID y Password como cookies; los pasos para establecer las cookies son los siguientes:

Ejemplo

#include <iostream> using namespace std; int main () { cout << "Set-Cookie:UserID=XYZ;\r\n"; cout << "Set-Cookie:Password=XYZ123;\r\n"; cout << "Set-Cookie:Domain=www.w3cschool.cc;\r\n"; cout << "Set-Cookie:Path=/perl;\n"; cout << "Content-type:text/html\r\n\r\n"; cout << "<html>\n"; cout << "<head>\n"; cout << "<title>Cookies en CGI</title>\n"; cout << "</head>\n"; cout << "<body>\n"; cout << "Establecer cookies" << endl; cout << "<br/>\n"; cout << "</body>\n"; cout << "</html>\n"; return 0; }

De este ejemplo aprendimos cómo establecer cookies. UsamosSet-Cookiela cabecera HTTP para establecer cookies.

Aquí, algunos atributos para establecer cookies son opcionales, como Expires, Domain y Path. Es importante destacar que las cookies se establecen antes de la línea"Content-type:text/html\r\n\r\nde envío.

Compile el programa anterior, genere setcookies.cgi e intente usar el siguiente enlace para establecer cookies. Establecerá cuatro cookies en su computadora:

/cgi-bin/setcookies.cgi

Obtener cookies

Recuperar todas las cookies establecidas es muy sencillo. Las cookies se almacenan en la variable de entorno CGI HTTP_COOKIE, y tienen la siguiente forma:

key1=value1;key2=value2;key3=value3....

El siguiente ejemplo demuestra cómo obtener las cookies.

Ejemplo

#include <iostream> #include <vector> #include <string> #include <stdio.h> #include <stdlib.h> #include <cgicc/CgiDefs.h> #include <cgicc/Cgicc.h> #include <cgicc/HTTPHTMLHeader.h> #include <cgicc/HTMLClasses.h> using namespace std; using namespace cgicc; int main () { Cgicc cgi; const_cookie_iterator cci; cout << "Content-type:text/html\r\n\r\n"; cout << "<html>\n"; cout << "<head>\n"; cout << "<title>Cookies en CGI</title>\n"; cout << "</head>\n"; cout << "<body>\n"; cout << "<table border = \"0\" cellspacing = \"2\">"; // Obtener la variable de entorno const CgiEnvironment& env = cgi.getEnvironment(); for( cci = env.getCookieList().begin(); cci != env.getCookieList().end(); ++cci ) { cout << "<tr><td>" << cci->getName() << "</td><td>"; cout << cci->getValue(); cout << "</td></tr>\n"; } cout << "</table><\n"; cout << "<br/>\n"; cout << "</body>\n"; cout << "</html>\n"; return 0; }

Ahora, compile el programa anterior, genere getcookies.cgi e intente usar el siguiente enlace para obtener todas las cookies disponibles en su computadora:

/cgi-bin/getcookies.cgi

Esto producirá una lista que muestra las cuatro cookies establecidas en la sección anterior, así como todas las demás cookies de su computadora:

UserID XYZ 
Password XYZ123 
Domain www.w3cschool.cc 
Path /perl

Ejemplo de subida de archivos

Para cargar un archivo, el formulario HTML debe establecer el atributo enctype enmultipart/form-data. La etiqueta input con tipo file creará un botón "Examinar".

<html> <body> <form enctype="multipart/form-data" action="/cgi-bin/cpp_uploadfile.cgi" method="post"> <p>Archivo:<input type="file" name="userfile" /></p> <p><input type="submit" value="Cargar" /></p> </form> </body> </html>

El resultado de este código es el siguiente formulario:

Archivo:

Nota:El ejemplo anterior ha deshabilitado deliberadamente guardar los archivos subidos en nuestro servidor. Puede probar el código anterior en su propio servidor.

El siguiente es el script utilizado para manejar la subida de archivos:cpp_uploadfile.cpp：

Ejemplo

#include <iostream> #include <vector> #include <string> #include <stdio.h> #include <stdlib.h> #include <cgicc/CgiDefs.h> #include <cgicc/Cgicc.h> #include <cgicc/HTTPHTMLHeader.h> #include <cgicc/HTMLClasses.h> using namespace std; using namespace cgicc; int main () { Cgicc cgi; cout << "Content-type:text/html\r\n\r\n"; cout << "<html>\n"; cout << "<head>\n"; cout << "<title>Subida de archivos en CGI</title>\n"; cout << "</head>\n"; cout << "<body>\n"; // Obtener la lista de archivos que se van a subir const_file_iterator file = cgi.getFile("userfile"); if(file != cgi.getFiles().end()) { // Enviar el tipo de datos en cout cout << HTTPContentHeader(file->getDataType()); // Escribir el contenido en cout file->writeToStream(cout); } cout << "<Subida de archivo exitosa>\n"; cout << "</body>\n"; cout << "</html>\n"; return 0; }

El ejemplo anterior consiste encoutescribir contenido en el flujo, pero puede abrir un flujo de archivo y guardar el contenido del archivo subido en un archivo en la ubicación de destino.
