C++ Configuración del entorno

Si desea configurar el entorno del lenguaje C++, debe asegurarse de tener los siguientes dos programas disponibles en su computadora: un editor de texto y un compilador de C++.

Editor de texto

Los archivos creados con un editor se denominan generalmente archivos fuente, que contienen el código fuente del programa.

Los archivos fuente de los programas en C++ suelen usar la extensión.cpp、.cp 或 .c。

Antes de comenzar a programar, asegúrese de tener un editor de texto y la experiencia suficiente para escribir un programa de computadora, guardarlo en un archivo, compilarlo y ejecutarlo.

  • Visual Studio Code: Aunque es un editor de texto de propósito general, tiene muchos complementos que admiten el desarrollo en C/C++, lo que lo convierte en una opción popular. Al instalar complementos de C/C++ y ajustar la configuración, puede convertirlo en un excelente entorno de desarrollo para el lenguaje C.

    Tutorial de instalación:https://www.runoob.com/w3cnote/vscode-tutorial.html

    Dirección de descarga:https://code.visualstudio.com/

  • Visual Studio: Un IDE integral de Windows para desarrolladores de .NET y C++, que se puede utilizar para crear aplicaciones web, en la nube, de escritorio, móviles, servicios y juegos.

    Dirección de descarga:https://visualstudio.microsoft.com/zh-hans/downloads/。

  • Vim 和 Emacs: Estos dos son editores de texto tradicionales. Tienen potentes funciones de edición y una alta personalización. Son muy potentes para usuarios experimentados, y hay muchos complementos y configuraciones que admiten el desarrollo en C.

  • Eclipse: Eclipse es otro potente entorno de desarrollo integrado. Aunque originalmente fue diseñado para el desarrollo en Java, mediante la instalación de complementos de C/C++ se puede hacer que admita el desarrollo en C.

Más herramientas relacionadas

Compilador de C++

El código fuente escrito en archivos fuente es legible por humanos. Necesita ser "compilado" a lenguaje de máquina para que la CPU pueda ejecutar el programa según las instrucciones dadas.

El compilador de C++ se utiliza para compilar el código fuente en un programa ejecutable final.

La mayoría de los compiladores de C++ no se preocupan por la extensión del archivo fuente, pero si usted no especifica la extensión, se utiliza por defecto..cpp。

El compilador gratuito más utilizado es el compilador de C/C++ de GNU. Si usted usa HP o Solaris, puede utilizar los compiladores de sus respectivos sistemas operativos.

Las siguientes secciones le guiarán sobre cómo instalar el compilador de C/C++ de GNU en diferentes sistemas operativos. Aquí se menciona C/C++ a la vez principalmente porque el compilador gcc de GNU es adecuado para los lenguajes de programación C y C++.

Instalación en UNIX/Linux

Si usted está usandoLinux o UNIX, use el siguiente comando en la línea de comandos para comprobar si GCC está instalado en su sistema:

$ g++ -v

Si el compilador GNU ya está instalado en su computadora, se mostrará un mensaje como el siguiente:

Using built-in specs.
Target: i386-redhat-linux
Configured with: ../configure --prefix=/usr .......
Thread model: posix
gcc version 4.1.2 20080704 (Red Hat 4.1.2-46)

Si GCC no está instalado, sigahttps://gcc.gnu.org/install/las instrucciones detalladas en [URL] para instalar GCC.

Instalación en Mac OS X

Si usted está usando Mac OS X, la forma más rápida de obtener GCC es descargar el entorno de desarrollo Xcode del sitio web de Apple e instalarlo siguiendo las instrucciones de instalación. Una vez instalado Xcode, podrá utilizar el compilador GNU.

Xcode actualmente se puede descargar desdehttps://developer.apple.com/download, se requiere iniciar sesión con un Apple ID.

Instrucciones de uso de g++

El programa g++ es una versión especial de gcc que establece el lenguaje predeterminado como C++. Al enlazar, utiliza automáticamente la biblioteca estándar de C++ en lugar de la biblioteca estándar de C. Siguiendo las convenciones de nomenclatura del código fuente y especificando el nombre de la biblioteca correspondiente, es posible compilar y enlazar programas de C++ con gcc, como se muestra en el siguiente ejemplo:

$ gcc main.cpp -lstdc++ -o main

A continuación se muestra el código de un programa simple de C++ guardado en el archivo helloworld.cpp:

#include <iostream>
using namespace std;
int main()
{
    cout << "Hello, world!" << endl;
    return 0;
}

La forma más sencilla de compilar:

$ g++ helloworld.cpp

Debido a que no se especificó el nombre del archivo ejecutable en la línea de comandos, el compilador utiliza el predeterminado a.out. El programa se puede ejecutar de la siguiente manera:

$ ./a.out
Hello, world!

Normalmente usamos-ola opción para especificar el nombre del archivo ejecutable. El siguiente ejemplo genera un archivo ejecutable llamado helloworld:

$ g++ helloworld.cpp -o helloworld

Ejecutar helloworld:

$ ./helloworld
Hello, world!

Si hay varios archivos de código C++, como runoob1.cpp, runoob2.cpp, el comando de compilación es el siguiente:

$ g++ runoob1.cpp runoob2.cpp -o runoob

Genera un archivo ejecutable runoob.

En algunos sistemas, g++ usa C++98 por defecto; podemos especificar el uso de C++11 para compilar el archivo main.cpp:

g++ -g -Wall -std=c++11 main.cpp

    En cuanto al problema de que la ventana desaparece rápidamente mencionado anteriormente, yo, con 3 años de experiencia en C++, indico la causa y la solución.

    La desaparición rápida se debe a que tu programa no tiene entradas, solo salidas fijas. El programa termina cuando llega a la sentencia return.

    Explico una por una las tres soluciones dadas anteriormente:

    Primera:

    cin.clear();  // 清空缓存
cin.sync();   // 清空缓存
cin.get();    // 接收键盘输入
// From:本帖，"但对于太突然"

    Esta utiliza un método de entrada para evitar que el programa termine; sale del programa después de leer datos (cin.get).

    #include <stdio.h>
int main()
{
  getchar();
  return 0;
}
// From:本帖，"xuezy"

    Esta también utiliza un método de entrada, pero a diferencia de la anterior, en esta se usa la función getchar para obtener un tipo char, sin almacenar los datos leídos en ninguna variable.

    #include <stdlib.h>
int main()
{
  system("pause"); //注意：“system("pause")”;语句会显示“请按任意键继续……”
  return 0;
}
// From:本帖，"xuezy"

    Este método utiliza el comando pause dentro de la función system() para pausar el programa.

    Acerca de GNU y GCC:

    Después de que se inventó el sistema Unix, todos lo usaban muy a gusto. Pero luego comenzó a ser de pago y de código cerrado comercial. Un señor llamado RMS se sintió muy molesto, por lo que inició el proyecto GNU, imitando la interfaz y la forma de uso de Unix para crear desde cero una versión de código abierto. Luego él mismo creó el editor Emacs y el compilador GCC.

    Después, bajo el proyecto GNU, todos hicieron numerosos trabajos y proyectos, logrando básicamente el plan original, incluidos el núcleo gcc y glibc. Pero al sistema GNU le faltaba un núcleo de sistema operativo. El núcleo previsto originalmente se llamaba HURD y nunca se completó. Al mismo tiempo, BSD (una distribución de UNIX) se vio envuelto en disputas de derechos de autor, y el desarrollo para la plataforma x86 quedó suspendido. Luego, un estudiante llamado Linus, para ejecutar Unix en una PC, desarrolló Linux inspirado en Minix. Nota: Linux es solo un núcleo de sistema; después de arrancar el sistema, todavía se usan programas como gcc y bash. Al publicar Linux, Linus eligió GPL, por lo que cumple con los principios de GNU.

    Finalmente, todos se dieron cuenta de que esto era exactamente lo que le faltaba al proyecto GNU. Entonces lo empaquetaron juntos y lo lanzaron como GNU/Linux. Luego, al repetirlo, la gente omitió la primera parte, y se convirtió en el sistema Linux. De hecho, en distribuciones de Linux como Debian, RedHat, etc., el núcleo ocupa solo una pequeña parte de la capacidad.
