C++ Funciones

Una función es un conjunto de declaraciones que ejecutan juntas una tarea. Cada programa de C++ tiene al menos una función, la función principal,main()y todos los programas simples pueden definir otras funciones adicionales.

Puede dividir el código en diferentes funciones. La forma de dividir el código en diferentes funciones depende de usted, pero lógicamente, la división suele realizarse de manera que cada función ejecute una tarea específica.

FunciónDeclaraciónle dice al compilador el nombre de la función, el tipo de retorno y los parámetros. La funcióndefiniciónproporciona el cuerpo real de la función.

La biblioteca estándar de C++ proporciona una gran cantidad de funciones integradas que los programas pueden invocar. Por ejemplo, la funciónstrcat()se utiliza para concatenar dos cadenas, la funciónmemcpy()se utiliza para copiar memoria a otra ubicación.

Las funciones también reciben muchos otros nombres, como métodos, subrutinas o procedimientos, entre otros.

Definición de funciones

La forma general de la definición de una función en C++ es la siguiente:

return_type function_name( parameter list ) { body of the function }

En C++, una función se compone de un encabezado de función y un cuerpo de función. A continuación se enumeran todas las partes que componen una función:

  • Tipo de retorno:Una función puede devolver un valor.return_typees el tipo de dato del valor que devuelve la función. Algunas funciones realizan la operación deseada sin devolver un valor; en ese caso, return_type es la palabra clavevoid。
  • Nombre de la función:Este es el nombre real de la función. El nombre de la función y la lista de parámetros juntos constituyen la firma de la función.
  • Parámetros:Los parámetros son como marcadores de posición. Cuando se llama a la función, se pasa un valor al parámetro; este valor se denomina argumento real. La lista de parámetros incluye el tipo, el orden y la cantidad de parámetros de la función. Los parámetros son opcionales, es decir, la función puede no contener parámetros.
  • Cuerpo de la función:El cuerpo de la función contiene un conjunto de declaraciones que definen la tarea que realiza la función.

Ejemplo

A continuación se presenta elmax()código fuente de la función. Esta función tiene dos parámetros num1 y num2, y devuelve el mayor de los dos números:

// La función devuelve el mayor de los dos números int max(int num1, int num2) { // Declaración de variables locales int result; if (num1 > num2) result = num1; else result = num2; return result; }

Declaración de funciones

Una funcióndeclaraciónle dice al compilador el nombre de la función y cómo invocarla. El cuerpo real de la función se puede definir por separado.

La declaración de la función incluye las siguientes partes:

return_type function_name( parameter list );

Para la función max() definida anteriormente, la declaración es la siguiente:

int max(int num1, int num2);

En la declaración de la función, el nombre de los parámetros no es importante; solo el tipo de los parámetros es necesario. Por lo tanto, la siguiente también es una declaración válida:

int max(int, int);

Cuando define una función en un archivo fuente y la invoca en otro archivo, la declaración de la función es necesaria. En ese caso, debe declarar la función en la parte superior del archivo donde se invoca la función.

Llamada a funciones

Al crear una función en C++, se define lo que hace la función y luego se llama a la función para realizar la tarea definida.

Cuando el programa llama a una función, el control del programa se transfiere a la función invocada. La función invocada ejecuta la tarea definida; cuando se ejecuta la declaración de retorno de la función o se alcanza la llave de cierre de la función, el control del programa se devuelve al programa principal.

Al llamar a una función, se pasan los parámetros requeridos; si la función devuelve un valor, se puede almacenar el valor de retorno. Por ejemplo:

Ejemplo

#include <iostream> using namespace std; // Declaración de la función int max(int num1, int num2); int main () { // Declaración de variables locales int a = 100; int b = 200; int ret; // Llamar a la función para obtener el valor máximo ret = max(a, b); cout << "Max value is : " << ret << endl; return 0; } // La función devuelve el mayor de los dos números int max(int num1, int num2) { // Declaración de variables locales int result; if (num1 > num2) result = num1; else result = num2; return result; }

Coloque la función max() y la función main() juntas y compile el código fuente. Al ejecutar el archivo ejecutable final, se producirá el siguiente resultado:

Max value is : 200

Parámetros de funciones

Si la función va a utilizar parámetros, debe declarar variables que acepten los valores de los parámetros. Estas variables se denominanparámetros formales。

Los parámetros formales son como otras variables locales dentro de la función: se crean al entrar en la función y se destruyen al salir de ella.

Al llamar a una función, hay tres formas de pasar parámetros a la función:

Tipo de llamadaDescripción
Llamada por valorEste método asigna el valor real del parámetro al parámetro formal de la función. En este caso, modificar el parámetro formal dentro de la función no tiene efecto sobre el parámetro real.
Llamada por punteroEste método asigna la dirección del parámetro al parámetro formal. Dentro de la función, esa dirección se utiliza para acceder al parámetro real utilizado en la llamada. Esto significa que modificar el parámetro formal afecta al parámetro real.
Llamada por referenciaEste método asigna la referencia del parámetro al parámetro formal. Dentro de la función, esa referencia se utiliza para acceder al parámetro real utilizado en la llamada. Esto significa que modificar el parámetro formal afecta al parámetro real.

Por defecto, C++ utilizala llamada por valorpara pasar parámetros. En general, esto significa que el código dentro de la función no puede cambiar los argumentos utilizados para llamar a la función. En el ejemplo mencionado anteriormente, al llamar a la función max() se utilizó el mismo método.

Valores predeterminados de los parámetros

Cuando define una función, puede especificar un valor predeterminado para cada parámetro que se encuentra al final de la lista de parámetros. Al llamar a la función, si el valor del argumento real se deja vacío, se utiliza este valor predeterminado.

Esto se hace asignando un valor al parámetro mediante el operador de asignación en la definición de la función. Al llamar a la función, si no se pasa el valor del parámetro, se utiliza el valor predeterminado; si se especifica un valor, se ignora el valor predeterminado y se utiliza el valor pasado. Vea el siguiente ejemplo:

Ejemplo

#include <iostream> using namespace std; int sum(int a, int b=20) { int result; result = a + b; return (result); } int main () { // Declaración de variables locales int a = 100; int b = 200; int result; // Llamar a la función para sumar valores result = sum(a, b); cout << "Total value is :" << result << endl; // Llamar a la función nuevamente result = sum(a); cout << "Total value is :" << result << endl; return 0; }

Cuando el código anterior se compila y se ejecuta, produce el siguiente resultado:

Total value is :300
Total value is :120

Funciones y expresiones Lambda

C++11 proporciona soporte para funciones anónimas, denominadas funciones Lambda (también llamadas expresiones Lambda).

Las expresiones Lambda tratan las funciones como objetos. Las expresiones Lambda pueden usarse como objetos, por ejemplo, pueden asignarse a variables y pasarse como parámetros, y también pueden evaluarse como funciones.

Una expresión Lambda es esencialmente muy similar a una declaración de función. La forma concreta de una expresión Lambda es la siguiente:

[capture](parameters)->return-type{body}

Por ejemplo:

[](int x, int y){ return x < y ; }

Si no hay valor de retorno, se puede expresar como:

[capture](parameters){body}

Por ejemplo:

[]{ ++global_x; }

En un ejemplo más complejo, el tipo de retorno puede especificarse explícitamente de la siguiente manera:

[](int x, int y) -> int { int z = x + y; return z + x; }

En este ejemplo, se crea un parámetro temporal z para almacenar el resultado intermedio. Como en una función normal, el valor de z no se conserva hasta la próxima vez que se vuelva a llamar a esta función anónima.

Si la función lambda no devuelve un valor (por ejemplo, void), su tipo de retorno puede omitirse por completo.

Dentro de una expresión Lambda se puede acceder a las variables del ámbito actual; este es el comportamiento de cierre (closure) de la expresión Lambda. A diferencia de los cierres de JavaScript, en C++ la transferencia de variables tiene la distinción entre paso por valor y paso por referencia. Esto se puede especificar mediante [] al inicio:

[]      // 沒有定义任何变量。使用未定义变量会引发错误。
[x, &y] // x以传值方式传入（默认），y以引用方式传入。
[&]     // 任何被使用到的外部变量都隐式地以引用方式加以引用。
[=]     // 任何被使用到的外部变量都隐式地以传值方式加以引用。
[&, x]  // x显式地以传值方式加以引用。其余变量以引用方式加以引用。
[=, &z] // z显式地以引用方式加以引用。其余变量以传值方式加以引用。

Además, hay un punto a tener en cuenta. Para las formas [=] o [&], la expresión lambda puede usar directamente el puntero this. Sin embargo, para la forma [], si se quiere usar el puntero this, debe pasarse explícitamente:

[this]() { this->someFunc(); }();

    Funciones y expresiones Lambda

    La sintaxis de la función Lambda se define de la siguiente manera:

    [capture](parameters) mutable ->return-type{statement}

    Donde:

    • [capture]Lista de captura: la lista de captura siempre aparece al comienzo de la expresión lambda. De hecho, [] es el inductor lambda. El compilador utiliza este inductor para determinar si el código siguiente es una función lambda. La lista de captura puede capturar variables del contexto para que las use la función lambda.
    • (parameters): lista de parámetros. Es igual que la lista de parámetros de una función normal. Si no se necesita pasar parámetros, se puede omitir junto con los paréntesis ().
    • mutablemodificador mutable: de forma predeterminada, una función lambda siempre es una función const; mutable puede eliminar su constancia. Al usar este modificador, la lista de parámetros no se puede omitir (incluso si los parámetros están vacíos).
    • ->return_typetipo de retorno: declara el tipo de retorno de la función mediante la forma de tipo de retorno final. Por conveniencia, cuando no se necesita un valor de retorno, también se puede omitir junto con el símbolo ->. Además, cuando el tipo de retorno es evidente, esta parte también se puede omitir para que el compilador deduzca el tipo de retorno.
    • {statement}cuerpo de la función: el contenido es igual que el de una función normal, pero además de poder usar parámetros, también puede usar todas las variables capturadas.

    En la definición de una función lambda, la lista de parámetros y el tipo de retorno son partes opcionales, mientras que la lista de captura y el cuerpo de la función pueden estar vacíos. La función lambda más simple en C++ solo necesita declararse como:

    []{};

    Las funciones lambda son muy concisas, pero tienen muchas variaciones.

    1. No capturar nada, o deliberadamente no usar variables externas a la función Lambda.

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024;
    auto func = [] { cout << i; };
    func();
}  // 结果报错，因为未指定默认捕获模式

    Lo correcto es lo siguiente:

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024;
    auto func = [=]{  // [=] 表明将外部的所有变量拷贝一份到该Lambda函数内部
        cout << i;
    };
    func();
}

    2. Captura por referencia

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024;
    cout << &i << endl;
    auto fun1 = [&]{
        cout << &i << endl;
    };
    fun1();
}

    3. Captura por copia y referencia

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024, j = 2048;
 
    cout << "i:" << &i << endl;
    cout << "j:" << &j << endl;
 
    auto fun1 = [=, &i]{ // 默认拷贝外部所有变量，但引用变量 i
        cout << "i:" << &i << endl;
        cout << "j:" << &j << endl;
    };
    fun1();
}

    4. Especificar referencia o copia

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024, j = 2048;
 
    cout << "outside i value:" << i << " addr:" << &i << endl;
 
    auto fun1 = [i]{
        cout << "inside  i value:" << i << " addr:" << &i << endl;
        // cout << j << endl; // j 未捕获
    };
    fun1();
}

    5. Capturar el puntero this

    #include <iostream>
using namespace std;
 
class test
{
public:
    void hello() {
        cout << "test hello!n";
    };
    void lambda() {
        auto fun = [this]{ // 捕获了 this 指针
            this->hello(); // 这里 this 调用的就是 class test 的对象了
        };
        fun();
    }
};
 
int main()
{
    test t;
    t.lambda();
}

    Un error que un novato puede cometer

    Dado que en el proceso real de escribir código, puede ocurrir que la definición y la declaración de una función no estén en el mismo archivo, y que la declaración aparezca en el archivo de cabecera.

    En este caso, al declarar y definir una función con valores predeterminados, hay que tener en cuenta que el valor predeterminado aparece en el código de la declaración; en la definición no se puede volver a asignar un valor predeterminado a los parámetros, de lo contrario se producirá un error.

    <Plus.h> //声明在头文件中
int Plus(int a, int b = 10)
<Plus.cpp>//定义在cpp文件中
int Plus(int a, int b)//不能再对b赋值了
{
    return a + b;

    [*this]: captura el objeto actual por valor (copia del objeto, y solo es un valor de dirección, se podría decir que no tiene sentido)

    Ejemplo:

    #include <iostream>
using namepsace std;

//定义一个类
class MM 
{
public:
  void print() {}
};

int main()
{
  MM mm;

  //打印对象地址作对比
  cout << "对象本身地址：" << &mm << endl;
  
  [&mm](){cout << "[&mm]: " << &mm << endl;}();    //相当于[this]
  [mm](){cout << "[mm]: " << &mm << endl;}();      //相当于[*this]
  [mm](){cout << "[mm]: " << &mm << endl;}();      //相当于[*this]

  return 0;
}

    Resultado:

[&mm]: 012FF984
[mm]: 012FF878
[mm]: 012FF850
