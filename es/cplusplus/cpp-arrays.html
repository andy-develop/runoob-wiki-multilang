C++ Arreglos

C++ admitearreglosEstructura de datos que puede almacenar una colección secuencial de elementos del mismo tipo con un tamaño fijo. Los arreglos se utilizan para almacenar una serie de datos, pero a menudo se consideran como una serie de variables del mismo tipo.

Declarar un arreglo no es declarar variables individuales, como number0, number1, ..., number99, sino declarar una variable de arreglo, como numbers, y luego usar numbers

Todos los arreglos están compuestos por posiciones de memoria contiguas. La dirección más baja corresponde al primer elemento y la dirección más alta al último elemento.

Declaración de arreglos

En C++, para declarar un arreglo, se debe especificar el tipo de los elementos y la cantidad de elementos, como se muestra a continuación:

type arrayName [ arraySize ];

Esto se llama arreglo unidimensional.arraySizedebe ser una constante entera mayor que cero,typepuede ser cualquier tipo de datos válido de C++. Por ejemplo, para declarar un arreglo de 10 elementos de tipo doublebalance, la declaración es la siguiente:

double balance[10];

Ahorabalancees un arreglo utilizable que puede contener 10 números de tipo double.

Inicialización de arreglos

En C++, puede inicializar un arreglo elemento por elemento, o usar una declaración de inicialización, como se muestra a continuación:

double balance[5] = {1000.0, 2.0, 3.4, 7.0, 50.0};

El número de valores entre llaves { } no debe ser mayor que el número de elementos especificado entre corchetes [ ] al declarar el arreglo.

Si omite el tamaño del arreglo, el tamaño será el número de elementos en la inicialización. Por lo tanto, si:

double balance[] = {1000.0, 2.0, 3.4, 7.0, 50.0};

creará un arreglo exactamente igual al creado en el ejemplo anterior. A continuación se muestra un ejemplo de asignación de valor a un elemento del arreglo:

balance[4] = 50.0;

La instrucción anterior asigna el valor 50.0 al quinto elemento del arreglo. Todos los arreglos usan 0 como índice del primer elemento, también llamado índice base; el último índice de un arreglo es el tamaño total del arreglo menos 1. Acceso a los elementos del arreglo

Los elementos de un arreglo se pueden acceder mediante el nombre del arreglo más un índice. El índice del elemento se coloca entre corchetes, después del nombre del arreglo. Por ejemplo:

double salary = balance[9];

La instrucción anterior asignará el valor del décimo elemento del arreglo a la variable salary. El siguiente ejemplo utiliza los tres conceptos mencionados: declaración del arreglo, asignación del arreglo y acceso al arreglo:

Ejemplo

#include <iostream> using namespace std; #include <iomanip> using std::setw; int main () { int n[ 10 ]; // n es un arreglo que contiene 10 enteros // inicializa los elementos del arreglo for ( int i = 0; i < 10; i++ ) { n[ i ] = i + 100; // establece el elemento i como i + 100 } cout << "Element" << setw( 13 ) << "Value" << endl; // genera el valor de cada elemento del arreglo for ( int j = 0; j < 10; j++ ) { cout << setw( 7 )<< j << setw( 13 ) << n[ j ] << endl; } return 0; }

El programa anterior utilizala función setw()para formatear la salida. Cuando el código anterior se compila y se ejecuta, produce el siguiente resultado:

    Array es de tamaño fijo, no se pueden agregar elementos adicionales. Cuando queremos definir caracteres de tamaño variable, podemos usar la biblioteca estándar vector.

    Ejemplo

    #include <iostream>
#include <vector>
using namespace std;
 
int main() {
   // 创建向量用于存储整型数据
   vector<int> vec; 
   int i;

   // 显示 vec 初始大小
   cout << "vector size = " << vec.size() << endl;

   // 向向量 vec 追加 5 个整数值
   for(i = 0; i < 5; i++){
      vec.push_back(i);
   }

   // 显示追加后 vec 的大小
   cout << "extended vector size = " << vec.size() << endl;

   return 0;
}

    El tamaño de vec aumenta con la entrada del bucle for.

    vector size = 0
extended vector size = 5

    Al usar un arreglo, este puede ser una expresión que contenga variables, pero al declararlo se debe usar una expresión constante. Por ejemplo:

    // 合法
const int a=19;
long b[a];

// 合法
const int a=19;
long b[a+5];

// 不合法
int a=19;
long b[a+5];

    Si desea declarar un arreglo de longitud arbitraria, puede usar una conversión de tipo explícita, por ejemplo:

    int a=19;
int b[(const int)a];

    También puede definir una constante para declararlo, por ejemplo:

    int a=19;
const int a1=a;
int b[a1];

    Para el operador de subíndice [], a[i] siempre se interpreta como *(a+i). Esta es una regla en C que trata el nombre del arreglo y el nombre del puntero como equivalentes.

    Puedes considerar [] como una especie de azúcar sintáctica, que te permite acceder a los elementos de un array de una manera más concisa, sin tener que escribir * y +. Pero a los ojos del compilador, son iguales; todos se convierten en aritmética de punteros.

    Puedes entenderlo con la siguiente fórmula:

    a[i] = *(a+i) = *(i+a) = i[a]

    Aquí, a[i] y *(a+i) son equivalentes; ambos representan el valor en la dirección apuntada por a más i, es decir, el i-ésimo elemento de a. Y *(i+a) e i[a] también son equivalentes; ambos representan el valor en la dirección apuntada por i más a, igualmente el i-ésimo elemento de a. Aquí, i y a pueden intercambiarse porque la suma es conmutativa.

    Puede que i[a] te parezca extraño, pero realmente es código C legal, solo que muy pocas personas lo escriben así.
