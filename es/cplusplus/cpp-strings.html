C++ Cadenas

C++ proporciona los siguientes dos tipos de representación de cadenas:

  • Cadenas de estilo C
  • El tipo de clase string introducido por C++

Cadenas de estilo C

Las cadenas de estilo C se originaron en el lenguaje C y continúan siendo compatibles en C++. Las cadenas son en realidad un array unidimensional de caracteres que usanullun carácter nulo\0como terminación.

La siguiente declaración e inicialización crea unaRUNOOBcadena. Dado que se almacena un carácter nulo al final del array, el tamaño del array de caracteres es una unidad mayor que elRUNOOBnúmero de caracteres de la palabra.

char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'};

De acuerdo con las reglas de inicialización de arrays, puede escribir la declaración anterior de la siguiente manera:

char site[] = "RUNOOB";

De hecho, no necesita poner elnullcarácter al final de la constante de cadena. El compilador de C++, al inicializar el array, lo pondrá automáticamente\0al final de la cadena.

Ejemplo

#include <iostream> using namespace std; int main () { char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'}; cout << "Tutorial para novatos:"; cout << site << endl; return 0; }

C++ tiene una gran cantidad de funciones para manipular cadenas terminadas en null:

Concatena la cadena s2 al final de la cadena s1. Las cadenas también se pueden concatenar usando el+signo +, por ejemplo:
string str1 = "runoob";

Devuelve la longitud de la cadena s1.

Si s1 y s2 son iguales, devuelve 0; si s1<s2, devuelve un valor menor que 0; si s1>s2, devuelve un valor mayor que 0.

Devuelve un puntero a la primera aparición del carácter ch en la cadena s1.

    La clase string proporciona una serie de operaciones para cadenas, como:

    • 1. append() -- agrega caracteres al final de la cadena
    • 2. find() -- busca una cadena dentro de la cadena
    • 4. insert() -- inserta caracteres
    • 5. length() -- devuelve la longitud de la cadena
    • 6. replace() -- reemplaza la cadena
    • 7. substr() -- devuelve una subcadena
    • 8. ...

    A continuación se muestra un ejemplo sobre la clase string:

    #include <iostream>
#include <string>
using namespace std;

int main()
{
    //定义一个string类对象
    string http = "www.runoob.com";

   //打印字符串长度
   cout<<http.length()<<endl;

    //拼接
    http.append("/C++");
    cout<<http<<endl; //打印结果为：www.runoob.com/C++

    //删除
    int pos = http.find("/C++"); //查找"C++"在字符串中的位置
    cout<<pos<<endl;
    http.replace(pos, 4, "");   //从位置pos开始，之后的4个字符替换为空，即删除
    cout<<http<<endl;

    //找子串runoob
    int first = http.find_first_of("."); //从头开始寻找字符'.'的位置
    int last = http.find_last_of(".");   //从尾开始寻找字符'.'的位置
    cout<<http.substr(first+1, last-first-1)<<endl; //提取"runoob"子串并打印

    return 0;
}

    Cadenas y vector

    Los literales de cadena y el string de la biblioteca estándar no son del mismo tipo.

    string s("hello");
cout<<s.size()<<endl;        //OK
cout<<"hello".size()<<endl;  //ERROR
cout<<s+"world"<<endl;       //OK
cout<<"hello"+"world"<<endl; //ERROR

    Diferencias entre strlen, sizeof y size() para calcular la longitud de una cadena

    cout<<strlen("123")<<endl;   //返回 3
cout<<sizeof("123")<<endl;   //返回 4
string s = "123";
cout<<s.size()<<endl;        //返回 3

    La función getline de la biblioteca estándar string descarta el carácter de nueva línea al devolver; diferencia entre const iterator y const_iterator.

    vector<int>::const_iterator //不能改变指向的值，自身的值可以改变
const vector<int>::iterator //可以改变指向的值，自身的值不能改变
const vector<int>::const_iterator //自身的值和指向的值都是只读的

    Cualquier operación que cambie la longitud de un vector invalida los iteradores existentes. Por ejemplo, después de llamar a push_back, ya no se puede confiar en los iteradores que apuntan al vector.

    Antes no tenía claro cómo distinguir entre sizeof y strlen; recientemente consulté información:

    1. El tipo de resultado del operador sizeof es size_t, que está typedef como unsigned int en el archivo de cabecera. Este tipo garantiza que puede contener el tamaño en bytes del objeto más grande que pueda crear la implementación.

    2. sizeof es un operador, strlen es una función.

    3. sizeof puede usar un tipo como parámetro,strlenmientras que solo puede usarchar*un puntero como parámetro, y debe ser una cadena que termine en\0el carácter nulo.

    sizeof también puede usar una función como parámetro, por ejemplo:

    short f();
printf("%d\n", sizeof(f()));

    El resultado de la salida es sizeof(short), es decir, 2.

    4. Cuando un array se usa comosizeofparámetro de sizeof, no se degrada; al pasarlo astrlenstrlen, se degrada a un puntero.

    5. La mayoría de los compiladores, en tiempo de compilación, yasizeofcalculan sizeof, que es la longitud del tipo o de la variable; esta es la razón por la quesizeof(x)sizeof puede usarse para definir las dimensiones de un array.

    char str[20]="0123456789";
int a=strlen(str); // a=10;
int b=sizeof(str); // 而 b=20;

    6. El resultado de strlen solo se puede calcular en tiempo de ejecución; se usa para calcular la longitud de una cadena, no el tamaño que ocupa un tipo en memoria.

    7. Después de sizeof, si es un tipo se deben agregar paréntesis; si es un nombre de variable, no es necesario. Esto se debe a quesizeofsizeof es un operador, no una función.

    8. Cuando se aplica a un tipo de estructura o variable, sizeof devuelve el tamaño real; cuando se aplica a un array de espacio estático, sizeof devuelve el tamaño completo del array; el operador sizeof no puede devolver el tamaño de arrays asignados dinámicamente o arrays externos.

    Cuando un array se pasa como parámetro a una función, se pasa un puntero, no el array; se pasa la dirección del primer elemento del array, por ejemplo:

    fun(char [8])
fun(char [])

    todos son equivalentes a

    fun(char *)

    En C++, pasar un array como parámetro siempre es pasar un puntero al primer elemento del array; el compilador no conoce el tamaño del array.

    Si se quiere conocer el tamaño del array dentro de la función, se debe hacer así:

    Después de entrar en la función, usar memcpy para copiarlo, y la longitud se pasa mediante otro parámetro formal.

    fun(unsiged char *p1, int len)
{
    unsigned char* buf = new unsigned char[len+1]
    memcpy(buf, p1, len);
}

    Después de leer la explicación detallada anterior, se descubre que el uso de ambos todavía tiene diferencias; esto se puede ver claramente con este ejemplo:

    char str[20]="0123456789";
int a=strlen(str);         // a=10; >>>> strlen 计算字符串的长度，以结束符 0x00 为字符串结束。
int b=sizeof(str);         // 而 b=20; >>>> sizeof 计算的则是分配的数组 str[20] 所占的内存空间的大小，不受里面存储的内容改变。

    Lo anterior es el resultado del procesamiento de un array estático; si se trata de un puntero, el resultado es diferente.

    char* ss = "0123456789";
sizeof(ss) 结果 4 ＝＝＝》ss 是指向字符串常量的字符指针，sizeof 获得的是一个指针的之所占的空间,应该是长整型的，所以是 4。
sizeof(*ss) 结果 1 ＝＝＝》*ss 是第一个字符 其实就是获得了字符串的第一位 '0' 所占的内存空间，是 char 类型的，占了 1 位
strlen(ss)= 10      ＝＝＝》 如果要获得这个字符串的长度，则一定要使用 strlen。strlen 用来求字符串的长度；而 sizeof 是用来求指定变量或者变量类型等所占内存大小。

    Sobre por qué un array de caracteres puede usar el nombre del array con cout para generar el contenido del array, mientras que un array normal no puede.

    Primero, veamos un ejemplo:

    int a[10] = {1,2,3,6,7};
char b[6] = {'h','a','p','p','y','\0'};
char c[] = "happy";
cout<<a<<endl;
cout<<b<<endl;
cout<<c<<endl;

    El resultado de la salida es:

    0x22fe6c
happy
happy

    Del ejemplo anterior se puede ver que, en un array normal, usar el nombre del array con cout para la salida solo produce una dirección; con un array de caracteres se genera el contenido del array.

    ¿Por qué sucede esto?

    Respuesta:Porquecharen un array de tipo char, cada elemento es un byte, por lo que las direcciones entre cada carácter son consecutivas (+1). Así, cuando cout genera la salida y encuentra el\0carácter nulo, detiene la salida; mientras que un array int, cada elemento ocupa 4 bytes, por lo que el intervalo de direcciones entre elementos es 4, pero en realidad también es consecutivo; el código basura aparece porque no se encuentra el terminador.

    #include<iostream>

    return 0;
}
    ​

    Delimitador personalizado

    El delimitador admite personalización, se escribe fuera de los paréntesis, los lados izquierdo y derecho deben coincidir; no todos los caracteres pueden establecerse como delimitadores:

    #include<iostream>
using namespace std;
int main ()
{
    cout << R"#%^&*(1231)"123)#%^&*" << endl;
    return 0;
}

    Salida:

    1231)"123

    L : 类型 wchar_t      编码 : Unicode

u8 : 类型 char          编码 : UTF-8     (C++11)

    Hay un punto que el tutorial de Runoob no explica claramente, es decir, sobre el uso de la función strcmp(s1, s2) en cadenas de estilo C. En el tutorial de Runoob se describe así:

    strcmp(s1, s2);

    Si s1 y s2 son iguales, devuelve 0; si s1<s2, el valor de retorno es menor que 0; si s1>s2, el valor de retorno es mayor que 0.

    Sin embargo, en realidad, de forma más precisa, solo si las dos cadenas no coinciden y el primer carácter de la primera cadena es menor que el primer carácter de la segunda cadena, devuelve un valor menor que 0; de lo contrario, devuelve un valor mayor que 0.
