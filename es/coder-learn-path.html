Hoja de ruta de aprendizaje para varios tipos de programadores

El programador es un animal muy especial que puede dedicarse al desarrollo y mantenimiento de programas. Generalmente se divide en programador de diseño y programador de codificación, pero la frontera entre ambos no está muy clara; ambos pueden realizar trabajos de desarrollo y mantenimiento.

Ingeniero de front-end

  1. Fundamentos:Tutorial de HTML，Tutorial de CSS
  2. Intermedio:Javascript，jQuery
  3. Avanzado:Tutorial de AJAX，Tutorial de JSON，Tutorial de XML，Tutorial de Vue，Tutorial de React
  4. Aprendizaje ampliado de frameworks:Tutorial de Bootstrap，Tutorial de jQuery UI，Tutorial de jQuery EasyUI，Tutorial de jQuery Mobile
  5. Herramientas de depuración:Tutorial de Firebug
  6. Herramientas de desarrollo: HBuilder, Dreamweaver, VSCode, Photoshop

Ingeniero PHP

  1. Fundamentos:Tutorial de HTML，Tutorial de PHP
  2. Intermedio:Tutorial de SQL，Tutorial de MySQL
  3. Avanzado:Tutorial de expresiones regulares，Tutorial de MongoDB， Tutorial de AJAX，Tutorial de JSON，Tutorial de XML，
  4. Herramientas de desarrollo: VSCode, phpMyAdmin, EasyEclipse for PHP

Ingeniero Python

  1. Fundamentos:Tutorial de Python
  2. Intermedio:Tutorial de SQL，Tutorial de MySQL
  3. Avanzado:Tutorial de expresiones regulares，Tutorial de MongoDB， Tutorial de AJAX，Tutorial de JSON，Tutorial de XML，
