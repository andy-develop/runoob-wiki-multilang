OpenClaw (Clawdbot) Tutorial

OpenClaw (originalmente Clawdbot, nombre de transición Moltbot) es un proyecto de asistente personal de IA de código abierto que se volvió repentinamente popular en enero de 2026, desarrollado por Peter Steinberger (fundador de PSPDFKit).

OpenClaw es un agente inteligente capaz de ejecutar tareas; cuando le damos instrucciones, no solo responde, sino que también puede operar el sistema de forma proactiva, acceder a páginas web, gestionar correos electrónicos, organizar archivos, crear recordatorios e incluso escribir código automáticamente.

OpenClaw es una herramienta que llevala potencia de cómputo local + la automatización de agentes con modelos grandesal extremo, una herramienta de productividad para desarrolladores.

El objetivo de OpenClaw es que la IA no solo dé sugerencias, sino que complete directamente tareas de ingeniería completas.

Debido a que Anthropic envió una carta de cese y desistimiento el 27 de enero afirmando que Clawd / Clawdbot se parecían demasiado a Claude, el proyecto fue renombrado urgentemente a Moltbot (que significa langosta que muda de piel; la mascota es la langosta Molty 🦞), pero las funciones son exactamente las mismas y el antiguo comando clawdbot sigue siendo compatible.

Moltbot es un nombre de transición ideado por el equipo del proyecto para hacer frente al riesgo de infracción; OpenClaw es el nombre oficial final actual.

  • Sitio web oficial de OpenClaw:https://openclaw.ai/

  • Documentación en chino:https://docs.openclaw.ai/zh-CN

  • Dirección de GitHub:https://github.com/openclaw/openclaw

  • Colección de habilidades de OpenClaw:https://github.com/VoltAgent/awesome-openclaw-skills

Clawbot, Moltbot y OpenClaw son en realidad el mismo proyecto de código abierto; el orden de evolución del nombre es:

Clawdbot → Moltbot → OpenClaw
Nombre Cronología Contexto/Motivo Relación esencial
Clawdbot / Clawbot Desde finales de 2025 hasta principios de enero de 2026 Nombre inicial del proyecto; inspirado enClaude 和 clawel meme de la (pinza de langosta) Nombre original; fue la primera identidad que apareció en GitHub
Moltbot 27 de enero de 2026 Se solicitó el cambio de nombre debido a las preocupaciones de marca registrada de Anthropic Nombre de transición intermedio; funciones y código idénticos a Clawdbot
OpenClaw Después del 30 de enero de 2026 Abandona el conflicto de derechos de autor, enfatiza el código abierto / la marca a largo plazo Nombre oficial actual, también es la identificación unificada para futuros documentos, repositorios, etc.

Métodos de instalación

La instalación de OpenClaw está diseñada para ser extremadamente amigable; incluso quienes no son desarrolladores pueden empezar rápidamente.

Requisitos del sistema (no necesariamente Mac mini):

  • Hardware: muy bajo, basta con 2 GB de RAM para funcionar.
  • Entorno: compatible con Mac, Windows y Linux; requiere instalar Node.js (pnpm) o usar Docker.

1. Método de instalación recomendado (script de un clic):

Ejecuta el siguiente comando directamente desde la terminal.

Sistemas macOS/Linux:

curl -fsSL https://openclaw.ai/install.sh | bash

Sistema Windows:

#PowerShell
iwr -useb https://openclaw.ai/install.ps1 | iex

#CMD
curl -fsSL https://openclaw.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Esto instalará automáticamente Node.js (≥22) y completará la configuración básica.

2. Instalación manual

Se necesitaNode.js ≥22y completar la configuración básica:

Con npm:

npm i -g openclaw

# 如果速度慢可以指定国内镜像
npm i -g openclaw --registry=https://registry.npmmirror.com

O con pnpm:

pnpm add -g openclaw

Una vez completada la instalación, inicializa e instala el servicio en segundo plano (servicio de usuario launchd / systemd):

openclaw onboard

3. Instalación desde el código fuente (modo de desarrollo)

git clone https://github.com/openclaw/openclaw.git
cd openclaw

pnpm install

pnpm ui:build   # 首次运行会自动安装 UI 相关依赖并构建前端界面
pnpm build      # 构建整个项目（包含后端与相关模块）

# 初始化 OpenClaw 并安装为系统后台服务（开机自动运行）
pnpm openclaw onboard --install-daemon

# 开发模式：监听 TypeScript 代码变更并自动重载网关服务
pnpm gateway:watch

Desinstalación

Usar el desinstalador integrado:

openclaw uninstall

No interactivo (automatización / npx):

openclaw uninstall --all --yes --non-interactive
npx -y openclaw uninstall --all --yes --non-interactive

Uso de habilidades (skills)

Las habilidades son carpetas independientes que contienen un archivo SKILL.md. Si deseas ampliar las funciones del agente OpenClaw, ClawHub es la mejor opción para buscar e instalar habilidades.

Dirección del repositorio de habilidades de ClawHub:https://clawhub.ai/

Espejo nacional de ClawHub:https://skillhub.tencent.com/

Instalar la herramienta ClawHub:

# 推荐方式（npx 无需全局安装）
npx clawhub@latest --version

# 或全局安装（方便以后直接用 clawhub 命令）
npm install -g clawhub
# 或者用 pnpm
pnpm add -g clawhub

Iniciar sesión:

clawhub login

Buscar habilidades:

clawhub search "postgres backups"

Descargar e instalar nuevas habilidades:

clawhub install my-skill-pack

Actualizar en lote las habilidades instaladas:

clawhub update --all

Gestión de plugins

Los plugins son módulos de código ligero que pueden ampliar las funciones de OpenClaw añadiendo comandos, herramientas y capacidades RPC de Gateway.

Ver los plugins cargados:

openclaw plugins list

Instalar un plugin oficial (ejemplo: plugin de llamadas de voz):

openclaw plugins install @openclaw/voice-call

Después de instalar el plugin, reinicia la puerta de enlace para que surta efecto:

openclaw gateway restart

Gestión de canales

  • WhatsApp：openclaw channels login(o escanear código QR)
  • Telegram：openclaw channels add --channel telegram(requiere token de bot)
  • Discord：openclaw channels add --channel discord(requiere token de bot)
  • iMessage: puente nativo de macOS
  • Slack：openclaw channels add --channel slack(requiere token de bot)

Estructura del espacio de trabajo (Workspace Anatomy)

  • AGENTS.md: instrucciones
  • USER.md: preferencias
  • MEMORY.md: memoria a largo plazo
  • HEARTBEAT.md: lista de verificación
  • SOUL.md: personalidad / tono
  • IDENTITY.md: nombre / tema
  • BOOT.md: configuración de inicio
  • Directorio raíz:~/.openclaw/workspace

Comandos de barra diagonal en el chat

  • /status: salud + contexto
  • /context list: contribuyentes de contexto
  • /model <m>: cambiar modelo
  • /compact: liberar espacio de ventana
  • /new: nueva sesión
  • /stop: abortar ejecución actual
  • /tts on|off: cambiar voz
  • /think: cambiar modo de razonamiento

Mapa de rutas esenciales (Essential Path Map)

  • Configuración principal:~/.openclaw/openclaw.json
  • Espacio de trabajo predeterminado:~/.openclaw/workspace/
  • Directorio de estado del agente:~/.openclaw/agents/<cid>/
  • Claves OAuth y API:~/.openclaw/agents/<agentId>/agent/auth-profiles.json, si es una versión anterior, está en~/.openclaw/credentials/
  • Almacenamiento de índices vectoriales:~/.openclaw/memory/<cid>.sqlite
  • Habilidades compartidas globales:~/.openclaw/skills/
  • Registros de archivos del gateway:/tmp/openclaw/*.log

Voz y TTS

  • De pago: OpenAI / ElevenLabs
  • Gratis: Edge TTS (sin necesidad de clave API)
  • TTS automático:messages.tts.auto: "always"

Memoria y modelos

  • Búsqueda vectorial:memory search "X"
  • Cambio de modelo:models set <model>
  • Configuración de autenticación:models auth setup
  • Registros:memory/YYYY-MM-DD.md

Hooks y habilidades

  • ClawHub：clawhub install <slug>
  • Lista de hooks:openclaw hooks list

Solución de problemas

  • Sin respuesta en DM → lista de emparejamiento → aprobar
  • Silencio en grupos → verificar configuración del modo de menciones
  • Autenticación caducada →models auth setup-token
  • Gateway apagado →doctor --deep
  • Bug de memoria → reconstruir índice de memoria

Automatización e investigación

  • Navegador:browser start/screenshot
  • Subagentes:/subagents list/info
  • Tareas programadas:cron list/run <cid>
  • Heartbeat:heartbeat.every: "30m"

¿Por qué se ha vuelto tan popular recientemente?

  • Realmente logra ser "como JARVIS": puede leer y escribir archivos, ejecutar comandos de terminal, operar el navegador, enviar y recibir correos, calendario, escribir código, reservar vuelos, vaciar la bandeja de entrada...
  • Prioridad local + memoria a largo plazo: todas las conversaciones comparten contexto entre plataformas, y USER.md y el directorio memory/ se vuelven más inteligentes con el uso
  • Compatible con casi todos los modelos grandes: Claude, Gemini, OpenAI, modelos locales de Ollama, Pi, etc.
  • Ecosistema de habilidades comunitarias en auge: ya hay más de 500 habilidades comunitarias en ClawdHub (Slack, Discord, GitHub, control del navegador, automatización de UI de macOS...)
  • La instalación es tan simple como npm install, pero su capacidad real es muy spicy (palabras del desarrollador)

Sus capacidades principales incluyen:

  • Descomponer objetivos de lenguaje natural en pasos ejecutables
  • Invocar automáticamente comandos de terminal
  • Crear y modificar archivos de proyecto
  • Ejecutar código y detectar resultados
  • Reparar automáticamente según los errores reportados

En comparación con herramientas de autocompletado de código como Claude Code/OpenCode, OpenClaw está más cerca de un agente de ingeniería con permisos de ejecución.

  • Claude Code y OpenCode destacan en calidad y comprensión de código
  • OpenClaw destaca en completar automáticamente todo el flujo de ingeniería
