Patrón Adaptador

El patrón adaptador (Adapter Pattern) actúa como un puente entre dos interfaces incompatibles y pertenece a los patrones de diseño estructurales. A través de un middleware (adaptador), convierte la interfaz de una clase en otra interfaz que el cliente espera, permitiendo que clases que originalmente no podían trabajar juntas cooperen.

Este patrón involucra una única clase que se encarga de añadir funcionalidades de interfaces independientes o incompatibles. Un ejemplo real: el lector de tarjetas actúa como adaptador entre la tarjeta de memoria y el portátil. Se inserta la tarjeta de memoria en el lector y este en el portátil, de modo que se puede leer la tarjeta de memoria a través del portátil.

Supongamos que hay un reproductor de audio que solo puede reproducir archivos MP3. Ahora necesitamos reproducir archivos VLC y MP4, lo cual se puede lograr creando un adaptador:

  • Interfaz objetivo: Define una interfaz de reproductor de audio que pueda reproducir archivos en múltiples formatos.
  • Clase adaptada (Adaptee): El reproductor de audio existente, que solo puede reproducir archivos MP3.
  • Clase adaptadora (Adapter): Crea una nueva clase que implemente la interfaz objetivo y, internamente, utilice la clase adaptada para reproducir archivos MP3, agregando también soporte para archivos VLC y MP4.

Resumen

El patrón adaptador es un patrón de diseño de software que tiene como objetivo resolver problemas de compatibilidad entre diferentes interfaces.

Propósito: Convertir la interfaz de una clase en otra interfaz, de modo que las clases originalmente incompatibles puedan trabajar juntas.

Problema principal que resuelve: En un sistema de software, se necesita colocar objetos existentes en un nuevo entorno, pero la interfaz requerida por el nuevo entorno no coincide con la de los objetos existentes.

Escenarios de uso

  • Se necesita usar una clase existente, pero su interfaz no cumple con los requisitos del sistema.
  • Se desea crear una clase reutilizable que trabaje con varias clases no relacionadas (incluidas las que puedan introducirse en el futuro), las cuales pueden no tener una interfaz uniforme.
  • Integrar una clase en otro sistema de clases mediante la conversión de interfaz.

Método de implementación

  • Herencia o dependencia: Se recomienda usar la relación de dependencia en lugar de la herencia para mantener la flexibilidad.

Código clave

El adaptador hereda o depende de un objeto existente e implementa la interfaz objetivo requerida.

Ejemplos de aplicación

  • Adaptador de voltaje: Convierte 110V a 220V para adaptarse a los estándares eléctricos de diferentes países.
  • Conversión de interfaz: Por ejemplo, convertir la interfaz Enumeration de Java JDK 1.1 a la interfaz Iterator de JDK 1.2.
  • Ejecución multiplataforma: Ejecutar programas de Windows en Linux.
  • Conexión de base de datos: JDBC en Java interactúa con diferentes tipos de bases de datos mediante el patrón adaptador.

Ventajas

  • Promueve la cooperación entre clases, incluso si no tienen una relación directa.
  • Mejora la reutilización de las clases.
  • Aumenta la transparencia de las clases.
  • Proporciona una buena flexibilidad.

Desventajas

  • El uso excesivo de adaptadores puede provocar una estructura del sistema desordenada, difícil de entender y mantener.
  • En Java, dado que solo se puede heredar de una clase, solo se puede adaptar una clase, y la clase objetivo debe ser abstracta.

Recomendaciones de uso

  • El patrón adaptador debe usarse con cautela, especialmente en la fase de diseño detallado; se utiliza más para resolver problemas en sistemas existentes.
  • Cuando se considera modificar la interfaz de un sistema que funciona correctamente, el patrón adaptador es una opción adecuada.

De esta manera, el patrón adaptador puede expresar claramente su concepto central y su aplicación, evitando complejidades innecesarias.

Estructura

El patrón adaptador incluye los siguientes roles principales:

  • Interfaz objetivo (Target): Define la interfaz que necesita el cliente.
  • Clase adaptada (Adaptee): Define una interfaz ya existente que necesita ser adaptada.
  • Clase adaptadora (Adapter): Implementa la interfaz objetivo y, mediante composición o herencia, invoca los métodos de la clase adaptada para lograr la interfaz objetivo.

Implementación

Tenemos unaMediaPlayerinterfaz y una clase de entidad que implementa laMediaPlayerinterfaz.AudioPlayer. De forma predeterminada,AudioPlayerpuede reproducir archivos de audio en formato mp3.

También tenemos otra interfazAdvancedMediaPlayery una clase de entidad que implementa laAdvancedMediaPlayerinterfaz. Esta clase puede reproducir archivos en formato vlc y mp4.

Queremos queAudioPlayerreproduzca archivos de audio en otros formatos. Para lograr esta funcionalidad, necesitamos crear una clase adaptadora que implemente laMediaPlayerinterfaz.MediaAdapter, y usarAdvancedMediaPlayerel objeto para reproducir el formato deseado.

public class Mp4Player implements AdvancedMediaPlayer{ @Override public void playVlc(String fileName) { //No hacer nada } @Override public void playMp4(String fileName) { System.out.println("Playing mp4 file. Name: "+ fileName); } }

    Compartir un ejemplo: el portátil lee una tarjeta TF mediante un lector de tarjetas.

    Primero, simular la lectura de una tarjeta SD por parte de la computadora:

    1. Primero, crear una interfaz para la tarjeta SD:

    public interface SDCard {
    //读取SD卡方法
    String readSD();
    //写入SD卡功能
    int writeSD(String msg);
}

    2. Crear una clase de implementación de la interfaz de la tarjeta SD para simular su funcionamiento:

    public class SDCardImpl implements SDCard {
    @Override    
    public String readSD() {
        String msg = "sdcard read a msg :hello word SD";
        return msg;  
    }
    @Override  
    public int writeSD(String msg) {      
        System.out.println("sd card write msg : " + msg);    
        return 1;   
    }
}

    3. Crear una interfaz de computadora que proporcione un método para leer la tarjeta SD:

    public interface Computer {    
    String readSD(SDCard sdCard);
}

    4. Crear una instancia de computadora que implemente la interfaz de computadora y su método de lectura de tarjeta SD:

    public class ThinkpadComputer implements Computer {
    @Override    
    public String readSD(SDCard sdCard) {        
        if(sdCard == null)throw new NullPointerException("sd card null");        
        return sdCard.readSD();    
    }
}

    5. En este punto, se puede simular la función de la computadora para leer la tarjeta SD:

    public class ComputerReadDemo {    
    public static void main(String[] args) {        
        Computer computer = new ThinkpadComputer();        
        SDCard sdCard = new SDCardImpl();       
        System.out.println(computer.readSD(sdCard));    
    }
}

    Segundo, a continuación, sin cambiar la interfaz de lectura de tarjeta SD de la computadora, leer la tarjeta TF mediante el patrón adaptador:

    1. Crear la interfaz de la tarjeta TF:

    public interface TFCard {    
    String readTF();    
    int writeTF(String msg);
}

    2. Crear una instancia de tarjeta TF:

    public class TFCardImpl implements TFCard {    
    @Override    
    public String readTF() {        
        String msg ="tf card reade msg : hello word tf card";        
        return msg;    
    }    
    @Override    
    public int writeTF(String msg) {        
        System.out.println("tf card write a msg : " + msg);        
        return 1;    
    }
}

    3. Crear un adaptador de SD a TF (también se puede decir que SD es compatible con TF, equivalente a un lector de tarjetas):

    Implementar la interfaz SDCard e introducir el objeto a adaptar como propiedad del adaptador.

    public class SDAdapterTF implements SDCard {    
    private TFCard tfCard;    
    public SDAdapterTF(TFCard tfCard) {        
        this.tfCard = tfCard;    
    }    
    @Override    
    public String readSD() {        
        System.out.println("adapter read tf card ");        
        return tfCard.readTF();    
    }    
    @Override    
    public int writeSD(String msg) {        
        System.out.println("adapter write tf card");        
        return tfCard.writeTF(msg);    
    }
}

    4. Probar, mediante el ejemplo anterior, que la computadora lea la tarjeta TF a través del lector de tarjetas SD:

    public class ComputerReadDemo {    
    public static void main(String[] args) {        
        Computer computer = new ThinkpadComputer();        
        SDCard sdCard = new SDCardImpl();        
        System.out.println(computer.readSD(sdCard));        
        System.out.println("====================================");        
        TFCard tfCard = new TFCardImpl();        
        SDCard tfCardAdapterSD = new SDAdapterTF(tfCard);        
        System.out.println(computer.readSD(tfCardAdapterSD));    
    }
}

    Salida:

    En este modo, la computadora no necesita saber qué tarjeta concreta es; solo se encarga de operar la interfaz. La clase específica que se opera la decide el adaptador.

    struct VlcPlayer: AdvancedMediaPlayer {
    func playVlc(fileName: String) {
        print("Play vlc file. Name:" + fileName)
    }

    func playMP4(fileName: String) {
    }
}

struct MP4Player: AdvancedMediaPlayer {
    func playVlc(fileName: String) {
    }

    func playMP4(fileName: String) {
        print("Play mp4 file. Name:" + fileName)
    }
}

struct MediaAdapter: MediaPlayer {
    let advancedMusicPlayer: AdvancedMediaPlayer

    init(audioType: AudioType) {
        if audioType == .mp4 {
            advancedMusicPlayer = MP4Player()
        } else {
            advancedMusicPlayer = VlcPlayer()
        }
    }

    func play(_ type: AudioType, fileName: String) {
        if type == .mp4 {
            advancedMusicPlayer.playMP4(fileName: fileName)
        } else {
            advancedMusicPlayer.playVlc(fileName: fileName)
        }
    }
}

class AudioPlayer: MediaPlayer {
    var mediaAdapter: MediaAdapter?
    func play(_ type: AudioType, fileName: String) {
        if type == .mp3 {
            print("Play mp3 file. Name:", fileName)
        } else  {
            mediaAdapter = MediaAdapter(audioType: type)
            mediaAdapter?.play(type, fileName: fileName)
        }
    }

    func play(_ type: String, fileName: String) {
        if let type = AudioType(rawValue: type) {
            play(type, fileName: fileName)
        } else {
            print("Invalid media.\(fileName) not supported.")
        }
    }
}

    #Adapter Pattern with Python Code
from abc import abstractmethod,ABCMeta

# 为媒体播放器和更高级的媒体播放器创建接口
class MediaPlayer(metaclass=ABCMeta):
    @abstractmethod
    def play(self, strAudioType, strFilename):
        pass
class AdvancedMediaPlayer(metaclass=ABCMeta):
    @abstractmethod
    def playVlc(self,strFilename):
        pass
    @abstractmethod
    def playMp4(self,strFilename):
        pass

# 实现AdvancedMediaPlayer接口的实体类
class VlcPlayer(AdvancedMediaPlayer):
    def playVlc(self,strFilename):
        print("Playing vlc file. Name: "+strFilename)
    def playMp4(self,strFilename):
        pass
class Mp4Player(AdvancedMediaPlayer):
    def playVlc(self,strFilename):
        pass
    def playMp4(self,strFilename):
        print("Playing MP4 file. Name: " + strFilename)

# 实现MediaPlayer的MediaAdapter实体类
class MediaAdapter(MediaPlayer):
    advancedMusicPlayer = None

    def __init__(self,strAudioType):
        strAudioType = str.lower(strAudioType)
        if strAudioType == "vlc" :
            self.advancedMusicPlayer = VlcPlayer()
        elif strAudioType == "mp4" :
            self.advancedMusicPlayer = Mp4Player()
    def play(self,strAudioType,strFilename):
        if strAudioType == "vlc" :
            self.advancedMusicPlayer.playVlc(strFilename)
        elif strAudioType == "mp4" :
            self.advancedMusicPlayer.playMp4(strFilename)

# 实现MediaPlayer的AudiPlayer实体类
class AudioPlayer(MediaPlayer):
    mediaAdapter = None
    def play(self,strAudioType,strFilename):
        strAudioType = str.lower(strAudioType)
        # 播放MP3音乐文件
        if strAudioType == "mp3" :
            print("Playing mp3 file. Name: "+ strFilename)
        elif (strAudioType == "vlc") or (strAudioType == "mp4") :
            self.mediaAdapter = MediaAdapter(strAudioType)
            self.mediaAdapter.play(strAudioType,strFilename)
        else :
            print("Invalid media. "+ strAudioType + " format not supported.")

# 调用输出
if __name__ == '__main__':
    audioPlayer = AudioPlayer()

    audioPlayer.play("mp3","beyond the horizon.mp3")
    audioPlayer.play("mp4","alone.mp4")
    audioPlayer.play("vlc", "far far away.vlc")
    audioPlayer.play("avi", "mind me.avi")

    // @brief SD卡接口类
class SD
{
public:
    virtual string read() = 0;
    virtual void write(const string&) = 0;
};
// @brief SD卡实例
class SDCard : public SD
{
private:
    string storage; // SD卡的存储空间
public:
    SDCard() {}
    string read() { return storage; }
    void write(const string& s) { storage = s; }

};
// @brief 计算机接口,只能读写SD卡
class Computer
{
public:
    virtual void insertSD(const shared_ptr<SD> &) = 0;
    virtual string readSD() = 0;
    virtual void writeSD(const string&) = 0;
};
// @brief 具体计算机
class HuaWeiComputer : public Computer
{
private:
    shared_ptr<SD> sd_slot; // SD卡插槽
public:
    HuaWeiComputer() {}
    void insertSD(const shared_ptr<SD>& sd) { sd_slot = sd; }
    string readSD() { if (sd_slot != nullptr) { return sd_slot->read(); } else { return (string)"[no sd card]"; } }
    void writeSD(const string& s) { if (sd_slot != nullptr) { sd_slot->write(s); } }
};
// @brief TF卡接口类
class TF
{
public:
    virtual string read() = 0;
    virtual void write(const string&) = 0;
};
// @brief TF卡实例
class TFCard : public TF
{
private:
    string storage; // TF卡的存储空间
public:
    TFCard() {}
    string read() { return storage; }
    void write(const string& s) { storage = s; }
};
// @brief TF转SD卡适配器
class SDAdapterTF : public SD
{
private:
    shared_ptr<TF> tf_slot; // TF卡插槽
public:
    void insertTF(const shared_ptr<TF>& tf) { tf_slot = tf; }
    string read() { if (tf_slot != nullptr) { return tf_slot->read(); } else { return (string)"[no tf card]"; } }
    void write(const string& s) { if (tf_slot != nullptr) { tf_slot->write(s); } }
};

// main 中执行
void demo()
{
    // 计算机读写SD卡demo
    shared_ptr<SD> sd(new SDCard());// 新建SD卡
    shared_ptr<Computer> pc(new HuaWeiComputer());// 新建电脑
    cout << "[1] " << pc->readSD() << endl; // 控制台输出：[1] [no sd card]
    pc->insertSD(sd);// TF卡插入电脑
    pc->writeSD("写入SD卡一些东西");
    cout << "[2] " << pc->readSD() << endl;  // 控制台输出：[2] 写入SD卡一些东西
    // 计算机通过适配器读写TF卡demo
    shared_ptr<TF> tf(new TFCard());
    shared_ptr<SDAdapterTF> adaptr(new SDAdapterTF()); // 新建一个适配器
