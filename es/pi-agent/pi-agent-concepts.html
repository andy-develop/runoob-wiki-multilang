Introducción a Pi Agent
Instalación de Pi Agent

Conceptos clave de Pi Agent

Antes de usar Pi Agent formalmente, entender sus conceptos clave y su forma de trabajar te ayudará a empezar más rápido.

Entender Pi Agent en una frase

Pi Agent es un asistente de programación con IA que se ejecuta en la terminal.

Al iniciarlo verás una interfaz similar a un software de chat. Introduce tus necesidades en lenguaje natural y la IA podrá leer tu código, ejecutar comandos y modificar archivos.

Cuatro modos de ejecución

Pi Agent admite cuatro modos de ejecución para diferentes escenarios:

ModoComandoDescripciónEscenario aplicable
Modo interactivopi (predeterminado)Interfaz TUI en terminal, conversación en tiempo real, admite todas las funciones.Desarrollo diario, programación interactiva
Modo Printpi -p "prompt"Consulta de una sola vez, sale después de mostrar el resultado.Integración de scripts, consultas rápidas
Modo JSONpi --mode jsonTodos los eventos se emiten como líneas JSON, adecuado para el análisis por programas.Integración de cadenas de herramientas, análisis de datos
Modo RPCpi --mode rpcIntegración mediante protocolo JSONL por stdin/stdoutComunicación entre procesos, complementos de editor

El modo interactivo se inicia directamente y entra a la interfaz TUI:

$ pi
Pi Agent 0.1.x  |  ~/projects/runoob-demo
claude-sonnet-4  |  上下文 2%  |  $0.0000
>

El modo Print sale después de responder, adecuado para incluir en scripts:

$ pi -p "总结这个项目"
这是一个 TypeScript 命令行工具，核心逻辑位于 src/ 目录，包含会话管理、工具调度和扩展加载三个模块。
Tokens: 1.2k 输入 / 320 输出  |  费用 $0.0081

El modo JSON emite cada evento como una línea JSON, facilitando el análisis por programas:

$ pi --mode json -p "总结这个项目"
{"type":"session","id":"a1b2c3d4"}
{"type":"message_start","role":"assistant"}
{"type":"message_end","usage":{"input":1200,"output":320}}

El modo RPC envía y recibe mensajes JSONL a través de stdin/stdout para que los complementos del editor lo llamen:

$ pi --mode rpc
{"id":1,"method":"prompt","params":{"message":"列出 src 目录"}}
{"id":1,"result":{"state":"idle","messages":2}}

Como principiante, trabajarás la mayor parte del tiempo en modo interactivo.

Cuando tengas más experiencia, el modo Print puede usarse para automatizar scripts.

Herramientas integradas

Al iniciarse, Pi Agent otorga a la IA las siguientes cuatro herramientas integradas por defecto; además, hay tres herramientas de solo lectura (grep, find, ls) que se pueden activar opcionalmente:

Nombre de la herramientaFunciónEjemploEstado por defecto
readLeer contenido de archivoLa IA lee src/main.ts para entender la lógica del código.Habilitado por defecto
writeCrear o sobrescribir archivoLa IA crea un archivo nuevo o reescribe todo el archivo.Habilitado por defecto
editReemplazar con precisión el contenido de un archivoLa IA modifica algunas líneas de código en una función.Habilitado por defecto
bashEjecutar comandos de shellLa IA ejecuta pruebas, instala dependencias y ejecuta el linter.Habilitado por defecto
grepBuscar texto en archivosLa IA busca en qué archivos se llama a una función.Activación opcional
findBuscar archivos por nombreLa IA encuentra todos los archivos llamados *.test.tsActivación opcional
lsListar contenido del directorioLa IA examina la estructura del directorio para localizar módulos.Activación opcional

Las tres herramientas de solo lectura se activan--toolsmanualmente mediante el parámetro, por ejemplo.pi --tools read,grep,find,ls。

Sistema de extensiones

Pi Agent amplía sus funciones mediante las siguientes cinco formas:

Forma de extensiónFormato de archivoUsoDificultad
Extensions (extensiones)TypeScript（.ts）Registrar herramientas personalizadas, escuchas de eventos, comandos y componentes de UI.Requiere programación
Skills (habilidades)Markdown（SKILL.md）Proporciona instrucciones de flujo de trabajo y scripts en dominios especializados.Basta con saber escribir Markdown
Prompt Templates (plantillas de indicaciones)Markdown（.md）Indicaciones reutilizables con soporte para parámetros.El más simple
Themes (temas)JSON（.json）Personaliza la combinación de colores de la interfaz de terminal.Simple
Packages (paquetes)Proyectos npm/gitEmpaquetar y compartir los cuatro recursos anterioresSegún la necesidad

Como principiante, no necesitas entender todas las formas de extensión de inmediato.

Comienza por el uso básico y explora gradualmente el sistema de extensiones a medida que crezcan tus necesidades.

Orden de carga de archivos

Al iniciarse, Pi Agent carga automáticamente los archivos de instrucciones del proyecto, permitiéndote definir las normas de comportamiento de la IA:

NivelRutaAlcancePrioridad
Configuración global~/.pi/agent/AGENTS.mdTodos los proyectosLa más baja, como línea base general
Configuración de proyectoAGENTS.md o CLAUDE.md en el directorio del proyecto y directorios superioresProyecto actualLa más alta, puede sobrescribir las instrucciones globales

La configuración de nivel de proyecto se carga recorriendo hacia arriba desde los directorios superiores y finalmente se combina con la configuración del directorio actual.

Si usabas Claude Code anteriormente, puedes reutilizar directamente los archivos CLAUDE.md existentes; Pi Agent los reconocerá y cargará automáticamente.

Sesiones y ramas

El sistema de sesiones de Pi Agent es una de sus características más distintivas.

Cada conversación se guarda automáticamente como un archivo de sesión~/.pi/agent/sessions/en el directorio correspondiente.

El interior de la sesión es una estructura de árbol: puedes "bifurcar" nuevas direcciones de exploración en cualquier nodo histórico sin perder las conversaciones anteriores.

Esto es muy útil cuando necesitas probar diferentes enfoques de implementación: cada idea se puede conservar de forma independiente y revisar en cualquier momento.
