Modo interactivo de Pi Agent

Primera conversación con Pi Agent

Después de completar la instalación y la configuración de autenticación, este capítulo te guiará a través de tu primera experiencia completa de conversación.

Te familiarizarás con la distribución de la interfaz y las operaciones básicas.

Iniciar Pi Agent

Entra en el directorio de tu proyecto e inicia Pi Agent:

$ cd ~/projects/runoob-demo
$ pi

Verás la interfaz interactiva de Pi Agent en la terminal.

La interfaz se divide en cuatro áreas principales:

ÁreaUbicaciónContenido mostrado
Cabecera de inicioParte superiorSugerencias de atajos de teclado, archivos de contexto cargados, plantillas de prompts, Skills, extensiones
Área de mensajesCentroMensajes del usuario, respuestas de la IA, detalles de llamadas a herramientas, notificaciones y errores
Área de ediciónLínea de entrada inferiorTu lugar de entrada; el color del borde indica el nivel de razonamiento actual
Barra de estado inferiorParte inferiorDirectorio de trabajo, nombre de la sesión, uso de tokens/caché, uso de contexto, costo, nombre del modelo actual (el total incluye las respuestas de la IA, el uso informado por las herramientas y el consumo de generación de resúmenes)

Si crees que la información del encabezado que se muestra al inicio es demasiada, puedes habilitar en la configuraciónquietStartupla opción para ocultarlo.

La primera tarea

Una vez en la interfaz, escribe tu primera solicitud y pulsa Enter:

帮我总结一下这个项目的结构和主要功能

Pi Agent utilizará herramientas integradas para leer los archivos de tu proyecto, analizar la estructura del código y luego devolver un resumen.

Puedes ver en el área de mensajes las operaciones que está ejecutando la IA, incluido qué herramientas ha llamado y qué archivos ha leído.

La salida de una conversación completa es similar a:

> read README.md（1.2k 字符）
> read src/main.ts（3.4k 字符）

这是一个基于 TypeScript 的终端编程助手，主要功能分为会话管理、工具调度和扩展加载三部分。
Tokens: 2.4k 输入 / 410 输出  |  费用 $0.0152

Pi Agent ofrece por defecto cuatro herramientas integradas: read, write, edit y bash. La explicación completa se encuentra en el capítulo «Visión general de conceptos básicos».

Referenciar archivos

Puedes referenciar archivos específicos en la conversación de dos maneras:

Método 1: sintaxis @ (búsqueda en el editor)

Escribe en el área de edición@y aparecerá automáticamente una búsqueda difusa de archivos del proyecto:

@src/app.ts 解释这个文件的功能

Método 2: parámetros de línea de comandos

Pasa directamente referencias de archivos al iniciar:

$ pi @README.md "总结一下这个文档"
$ pi @src/app.ts @src/app.test.ts "对比这两个文件"

También puedes referenciar archivos de imagen:

$ pi -p @screenshot.png "这张截图里显示了什么"

Pegar imágenes

Pi Agent admite el envío de imágenes en la conversación; el método de operación varía ligeramente según la plataforma.

PlataformaOperaciónDescripción
macOS / LinuxCtrl+VPegar imagen desde el portapapeles
WindowsAlt+VPegar imagen desde el portapapeles
Terminales compatiblesArrastrar una imagen a la ventana de la terminalEnviarla a la conversación como archivo

Ejecutar comandos en la conversación

Puedes ejecutar comandos de shell directamente desde el área de edición sin salir de Pi Agent:

!npm run lint
!git diff

以 !Los comandos que empiecen con dicho prefijo se ejecutarán y la salida se enviará automáticamente a la IA para que la revise.

El resultado de ejecutar!npm run lintes similar a:

> pi-agent@1.0.0 lint
> eslint .
0 errors, 0 warnings

以 !!Los comandos que empiecen con ... también se ejecutarán, peronoenviarán la salida a la IA:

!!echo "这只在本地显示"
这只在本地显示

Al usar!!el prefijo para ejecutar comandos que no necesitan ser revisados por la IA (como abrir archivos o ver variables de entorno), evitarás desperdiciar la ventana de contexto.

Entrada multilínea y editor externo

Los textos largos pueden escribirse con entrada multilínea o un editor externo. A continuación se muestran los atajos de teclado relacionados.

OperaciónAtajo de teclado
Insertar salto de líneaShift+Enter (usar Ctrl+Enter en Windows Terminal)
Abrir editor externoCtrl+G

Cuando necesites introducir un texto largo, pulsaCtrl+GSe abrirá el editor predeterminado del sistema (como nano, vim o VS Code). Tras guardar, el contenido se rellenará automáticamente en el área de edición de Pi Agent.

Cola de mensajes

Pi Agent permite enviar mensajes mientras la IA está trabajando, sin necesidad de esperar a que termine:

Atajo de tecladoComportamientoDescripción
EnterEnviar mensaje steeringSe envía a la IA inmediatamente después de que la herramienta actual termine de ejecutarse.
Alt+EnterEnviar mensaje follow-upSe envía después de que la IA complete todo su trabajo.
EscapeCancelar mensajes en colaRestaura los mensajes en cola al área de edición.
Alt+UpRecuperar mensajes en colaRecupera el mensaje en cola al área de edición para modificarlo.

En Windows Terminal, Alt+Enter es el atajo de pantalla completa de forma predeterminada. Si quieres que Pi Agent reciba este atajo, consultaDespliegue multiplataformalas instrucciones en ... para reasignarlo.

Modo no interactivo

Además del diálogo interactivo, también puedes usar Pi Agent rápidamente de las siguientes maneras:

Ejemplos

# Consulta de una sola vez; sale después de mostrar el resultado
pi -p "Resume este repositorio de código"

# Entrada mediante pipe: pasa el contenido del archivo a la IA
cat README.md | pi -p "Resume este texto"

# Consulta de una sola vez con imagen
pi -p @screenshot.png "¿Qué hay en esta imagen?"

# Sesión con nombre (para continuar después)
pi --name "Revisión de código" -p "Revisa el código en el directorio src/"

# Modo de solo lectura (no permite modificar archivos)
pi --tools read,grep,find,ls -p "Revisa el código sin modificar"

El modo Print (-p) es muy adecuado para integrarlo en scripts y flujos de CI.

Crear un archivo de instrucciones del proyecto

Para que la IA entienda mejor tu proyecto, se recomienda crear un archivo AGENTS.md.

Guarda el siguiente contenido como archivo Markdown, con la rutaDirectorio raíz del proyecto/AGENTS.md：

Ejemplos

# Instrucciones del proyecto

- Después de modificar el código, ejecuta `npm run check`
- No ejecutes migraciones de producción directamente en el entorno local
- Mantén las respuestas concisas, sin explicaciones excesivas
- Escribe código en modo estricto de TypeScript
- Sigue el estilo de código existente del proyecto

Pi Agent cargará automáticamente este archivo al iniciar.

También cargará las instrucciones globales de~/.pi/agent/AGENTS.mdy los archivos de instrucciones en el directorio padre.

Después de actualizar AGENTS.md, usa/reloadel comando para recargar en caliente sin necesidad de reiniciar.

Si antes usabas Claude Code, los archivos CLAUDE.md existentes pueden ser reconocidos y utilizados directamente por Pi Agent, sin necesidad de renombrarlos.

OperaciónAtajo de tecladoDescripción
Enviar entradaEnterEnvía el contenido actual del área de edición; si la IA está trabajando, entra en la cola de mensajes (ver «Cola de mensajes»).
Selección de modeloCtrl+LAbre el selector de modelos
Cambiar modeloCtrl+P / Shift+Ctrl+PCambia al modelo anterior/siguiente de forma cíclica
Nivel de razonamientoShift+TabCambia cíclicamente el nivel de razonamiento
Expandir/contraer salida de herramientasCtrl+OAlterna la visualización de los resultados de las llamadas a herramientas
Expandir/contraer proceso de razonamientoCtrl+TAlterna la visualización del proceso de razonamiento de la IA
Interrumpir operaciónEscapeCancela la operación actual de la IA (ver «Cola de mensajes»)
Vaciar área de ediciónCtrl+CVacía el contenido actual del área de edición
Copiar la última respuesta de la IACtrl+XCopia el contenido de la respuesta al portapapeles
Autocompletado de rutasTabCompleta rutas de archivos
Salir del programaCtrl+DSale del programa si el área de edición está vacía
Salir del programa (directo)/quitSale inmediatamente
