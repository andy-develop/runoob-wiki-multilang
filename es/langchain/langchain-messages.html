Tipos de mensajes de LangChain

En LangChain, todas las conversaciones se transmiten a través de objetos de mensaje (Message). Comprender el propósito de los distintos tipos de mensajes es la base para escribir un Agent.

Cuatro tipos de mensajes principales

LangChain define cuatro tipos de mensajes principales, que corresponden a los diferentes roles en la conversación:

TipoRolDescripciónContenido típico
HumanMessageUsuarioMensaje enviado por el usuario"¿Cómo está el clima hoy?"
AIMessageAsistente de IARespuesta del modelo, puede contener tool_calls"Hoy en Hangzhou hace sol, 25 °C"
SystemMessageSistemaInstrucciones del sistema, definen el rol y las reglas de comportamiento de la IA"Eres un asistente meteorológico profesional"
ToolMessageHerramientaResultado devuelto tras la ejecución de la herramienta"Despejado, 25 °C, humedad 60%"

HumanMessage: mensaje de usuario

HumanMessage representa el mensaje que el usuario envía a la IA. Es el tipo de mensaje más común y el punto de partida de la conversación.

Ejemplo

from langchain.messages import HumanMessage
from langchain.chat_models import init_chat_model

# Crear un mensaje de usuario
msg = HumanMessage(content="¿Qué es RUNOOB?")

print(f"Tipo: {msg.type}")        # human
print(f"Contenido: {msg.content}")      # ¿Qué es RUNOOB?
print(f"Rol: {msg.role}")         # user

# Crear una lista de mensajes (representa el historial de conversación de varias rondas)
messages = [
    HumanMessage(content="Hola"),
    HumanMessage(content="¿Qué cursos tiene RUNOOB?"),
    HumanMessage(content="¿El curso de Python es adecuado para principiantes sin experiencia?"),
]

model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
response = model.invoke(messages)
print(f"\nRespuesta del modelo: {response.content}")

Resultado de la ejecución:

类型: human
内容: 菜鸟教程 RUNOOB 是什么？
角色: user

模型回复: 菜鸟教程（RUNOOB）是一个面向编程初学者的学习网站，提供丰富的编程教程。
它的 Python 课程非常适合零基础学习者，从环境配置到基础语法再到实战项目都有覆盖。

Formas rápidas de crear HumanMessage

Al construir listas de mensajes, se pueden usar tuplas o diccionarios como atajos:

Ejemplo

from langchain.messages import HumanMessage

# Método 1: construcción estándar
msg1 = HumanMessage(content="Hola")

# Método 2: atajo con tupla (role, content)
msg2 = ("user", "Hola")
msg3 = ("human", "Hola")

# Método 3: atajo con diccionario
msg4 = {"role": "user", "content": "Hola"}

# Las cuatro formas son equivalentes; todas se convierten en HumanMessage dentro del Agent
print(type(msg1))  # <class 'langchain_core.messages.human.HumanMessage'>

AIMessage: respuesta de IA

AIMessage representa la respuesta del modelo. A diferencia del texto normal, AIMessage puede contenertool_calls(solicitudes de llamada a herramientas).

Ejemplo

from langchain.messages import AIMessage

# Respuesta de IA normal (sin llamada a herramienta)
ai_msg = AIMessage(content="RUNOOB es una plataforma de aprendizaje de programación")

# Respuesta de IA con llamada a herramienta
ai_with_tools = AIMessage(
    content="",  # En una llamada a herramienta, content normalmente está vacío
    tool_calls=[
        {
            "name": "get_weather",
            "args": {"city": "Hangzhou"},
            "id": "call_abc123",
            "type": "tool_call",
        }
    ]
)

print("=== Mensaje de IA normal ===")
print(f"content: {ai_msg.content}")
print(f"tool_calls: {ai_msg.tool_calls}")   # []

print("\n=== Mensaje de IA con llamada a herramienta ===")
print(f"content: {ai_with_tools.content}")
print(f"tool_calls: {ai_with_tools.tool_calls}")
# [{'name': 'get_weather', 'args': {'city': 'Hangzhou'}, ...}]

Ejemplo

from langchain.chat_models import init_chat_model

model = init_chat_model("deepseek:deepseek-v4-flash")
response = model.invoke("Presenta RUNOOB")

# AIMessage contiene metadatos enriquecidos
print(f"Contenido: {response.content}")

SystemMessage: instrucciones del sistema

SystemMessage se utiliza para establecer el comportamiento, el rol y las restricciones de la IA. Se coloca al principio de la lista de mensajes y guía al modelo sobre cómo responder.

Ejemplo

from langchain.messages import HumanMessage, SystemMessage
from langchain.chat_models import init_chat_model

model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0.7)

# Respuesta sin instrucciones del sistema
messages_no_system = [HumanMessage(content="Presenta RUNOOB")]
response = model.invoke(messages_no_system)
print(f"Sin instrucciones del sistema: {response.content[:80]}...")

# Respuesta con instrucciones del sistema
messages_with_system = [
    SystemMessage(content="Eres un blogger de estilo Xiaohongshu, las respuestas deben ser animadas, usar emojis y llevar hashtags"),
    HumanMessage(content="Presenta RUNOOB")
]
response = model.invoke(messages_with_system)
print(f"\nCon instrucciones del sistema: {response.content}")

Resultado de la ejecución:

无系统指令: 菜鸟教程是一个面向初学者的在线编程学习平台，提供丰富的教程和实例...

有系统指令: 宝藏网站！给所有想学编程的新手安利菜鸟教程 RUNOOB！
超全面的免费教程，从 HTML 到 Python 全部都有唷～
实例超多上手超快，绝对是编程小白的入门神器！
#编程学习 #免费教程 #零基础入门 #菜鸟教程

ToolMessage: resultado devuelto por la herramienta

ToolMessage contiene el resultado devuelto tras la ejecución de la herramienta. Debe estar asociado con el tool_call correspondiente.

Ejemplo

from langchain.messages import HumanMessage, AIMessage, ToolMessage
from langchain.chat_models import init_chat_model

# Simular una conversación completa de llamada a herramienta
messages = [
    HumanMessage(content="¿Cómo está el clima en Hangzhou?"),

    # El modelo solicita llamar a la herramienta
    AIMessage(
        content="",
        tool_calls=[
            {"name": "get_weather", "args": {"city": "Hangzhou"},
             "id": "call_abc", "type": "tool_call"}
        ]
    ),

    # Resultado devuelto por la herramienta (debe incluir tool_call_id que corresponda al id anterior)
    ToolMessage(
        content="Despejado, 25 °C, humedad 60%",
        tool_call_id="call_abc",   # Corresponde al id del tool_call
        name="get_weather",        # Nombre de la herramienta
    ),
]

model = init_chat_model("deepseek:deepseek-v4-flash")
response = model.invoke(messages)
print(f"Respuesta del modelo basada en el resultado de la herramienta: {response.content}")

Resultado de la ejecución:

模型基于工具结果的回复: 杭州今天天气晴朗，气温25°C，湿度60%，适合户外活动。

El tool_call_id de ToolMessage debe coincidir exactamente con el id del tool_call en AIMessage. Si no coincide, el modelo puede ignorar este resultado de herramienta o producir un comportamiento confuso.

AIMessageChunk: fragmentos de mensaje en salida de streaming

Cuando utilizas la salida en streaming con stream(), cada fragmento que llega es un AIMessageChunk, no un AIMessage completo:

Ejemplo

from langchain.chat_models import init_chat_model

model = init_chat_model("deepseek:deepseek-v4-flash")

print("Proceso de salida en streaming:")
# stream() devuelve un iterador de AIMessageChunk
for chunk in model.stream("Presenta RUNOOB en una frase"):
    # Cada chunk es un pequeño fragmento de texto
    print(chunk.content, end="", flush=True)
print()  # Salto de línea

Resultado de la ejecución:

流式输出过程：
菜鸟教程（RUNOOB）是一个面向编程初学者的免费在线学习平台，提供丰富的编程教程和实例。

ContentBlock: contenido de mensaje estructurado

Hasta ahora, el contenido de los mensajes que hemos usado son cadenas simples. Pero en realidad, el contenido de cada mensaje puede ser una lista de múltiplesContentBlock(bloques de contenido) que componen la lista.

Los tres tipos de bloques de contenido más comunes:

TipoDescripciónUso
PlainTextContentBlockContenido de texto sin formatoMensaje de texto normal
ImageContentBlockContenido de imagen (base64 o URL)Entrada de imagen para modelos multimodales
ToolCallSolicitud de llamada a herramientaLa IA solicita llamar a una herramienta

Ejemplo

from langchain.messages import HumanMessage
from langchain.messages import PlainTextContentBlock, ImageContentBlock

# Construyendo un mensaje con bloques de contenido
# content puede ser una cadena simple (caso simple)
simple_msg = HumanMessage(content="你好")

# content también puede ser una lista de ContentBlock (caso complejo)
complex_msg = HumanMessage(content=[
    PlainTextContentBlock(text="这张图片里是什么？"),
    # La imagen puede ser una URL o codificación base64
    ImageContentBlock(
        url="https://example.com/photo.jpg"
    ),
])

print(f"简单消息内容类型: {type(simple_msg.content)}")
# Salida: <class 'str'>

print(f"复杂消息内容类型: {type(complex_msg.content)}")
# Salida: <class 'list'>

print(f"内容块数量: {len(complex_msg.content)}")
# Salida: 2

Cuando solo necesitas enviar texto sin formato, pasa directamente una cadena; LangChain lo manejará automáticamente. Solo necesitas construir manualmente una lista de ContentBlock cuando debas mezclar texto e imágenes en un mismo mensaje.

Mensajes multimodales: permitir que el modelo "vea" imágenes

Si tu modelo admite entrada multimodal (como GPT-4o, Claude 3+), puedes hacer que analice el contenido de la imagen:

Ejemplo

import base64
from pathlib import Path
from langchain.messages import HumanMessage
from langchain.chat_models import init_chat_model

# Codificar la imagen local en base64
def encode_image(image_path: str) -> str:
    """Lee el archivo de imagen y conviértelo a codificación base64"""
    with open(image_path, "rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")

# Crear un modelo multimodal (debe admitir entrada de imágenes)
model = init_chat_model("deepseek:deepseek-v4-flash")

# Construir un mensaje que contenga la imagen
# Nota: content usa formato de lista, incluye bloques de texto y bloques de imagen
image_data = encode_image("screenshot.png")
messages = [
    HumanMessage(content=[
        {"type": "text", "text": "请描述这张菜鸟教程 RUNOOB 官网截图的内容"},
        {
            "type": "image_url",
            "image_url": {
                "url": f"data:image/png;base64,{image_data}",
                "detail": "auto"  # Opcional: low, high, auto
            }
        }
    ])
]

response = model.invoke(messages)
print(f"图片分析结果: {response.content}")

Si tu mensaje solo contiene una imagen y no texto, puedes usar directamente:

Ejemplo

from langchain.chat_models import init_chat_model

model = init_chat_model("deepseek:deepseek-v4-flash")

# Usar una URL para referenciar directamente una imagen en línea
messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "这张图描述了什么内容？"},
            {
                "type": "image_url",
                "image_url": {"url": "https://www.runoob.com/wp-content/uploads/2024/01/logo.png"}
            }
        ]
    }
]

response = model.invoke(messages)
print(response.content)

No todos los modelos admiten entrada multimodal. Lo hacen la serie GPT-4o de OpenAI, Claude 3+ de Anthropic y la serie Gemini de Google. Si envías una imagen a un modelo que no la admite, recibirás un error.

ToolCall: mensaje de llamada a herramienta

El campo tool_calls en AIMessage es una lista de ToolCall; cada ToolCall representa una solicitud del modelo para llamar a una herramienta:

Ejemplo

from langchain.messages import AIMessage
from langchain.messages.tool import ToolCall

# Construir manualmente un ToolCall
tool_call = ToolCall(
    name="get_weather",        # Nombre de la herramienta
    args={"city": "杭州"},     # Parámetros de la llamada
    id="call_abc123",         # Identificador único
    type="tool_call",         # Valor fijo
)

# Crear un AIMessage con tool_calls
ai_message = AIMessage(
    content="",               # Cuando hay tool_calls, content suele estar vacío
    tool_calls=[tool_call],
)

print(f"工具名称: {ai_message.tool_calls)
print(f"调用参数: {ai_message.tool_calls)
print(f"调用 ID: {ai_message.tool_calls)

Verificar si AIMessage contiene una llamada a herramienta

Ejemplo

from langchain.chat_models import init_chat_model

model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)

# Después de vincular la herramienta, el modelo puede devolver tool_calls
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询天气",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "城市名"}
            },
            "required": ["city"]
        }
    }
}]

model_with_tools = model.bind_tools(tools)

# Pregunta que activa la llamada a herramienta
response = model_with_tools.invoke("杭州天气怎么样？")

# Dos formas de determinar si hay una llamada a herramienta
# Método 1: comprobar si la lista tool_calls no está vacía
if response.tool_calls:
    print("模型请求调用工具")

# Método 2: comprobar si content está vacío
# (La mayoría de los modelos tienen content vacío cuando hay tool_calls)
if not response.content:
    print("模型的 content 为空，说明它想调用工具而非直接回复")

trim_messages(): recortar el historial de mensajes

Cuando la conversación se vuelve más larga, la lista de mensajes puede exceder la ventana de contexto del modelo.trim_messages()La función te ayuda a recortar el historial de mensajes de forma inteligente.

Ejemplo

from langchain.messages import (
    HumanMessage, AIMessage, SystemMessage, trim_messages
)
from langchain.chat_models import init_chat_model

# Simular un historial de conversación muy largo
messages = [
    SystemMessage(content="你是菜鸟教程 RUNOOB 的 AI 助手"),
    HumanMessage(content="Python 怎么入门？"),
    AIMessage(content="Python 入门可以从基础知识开始..."),
    HumanMessage(content="有推荐的 IDE 吗？"),
    AIMessage(content="推荐 VS Code 或 PyCharm..."),
    HumanMessage(content="如何安装第三方库？"),
    AIMessage(content="使用 pip install 命令..."),
    HumanMessage(content="NumPy 是什么？"),
    AIMessage(content="NumPy 是一个科学计算库..."),
    HumanMessage(content="pandas 和 NumPy 有什么区别？"),
]

model = init_chat_model("deepseek:deepseek-v4-flash")

# Recortar mensajes para ajustarse a la ventana de contexto del modelo (máximo 1000 tokens)
# strategy="last" conserva el último mensaje del sistema y la conversación reciente
trimmed = trim_messages(
    messages,
    max_tokens=1000,           # Conservar como máximo 1000 tokens
    strategy="last",           # Conservar el último mensaje del sistema + la conversación reciente
    token_counter=model,       # Usar el método de conteo de tokens del modelo
    include_system=True,       # Conservar siempre SystemMessage
    start_on="human",          # Después del recorte, comienza con un mensaje human
)

print(f"裁剪前: {len(messages)} 条消息")
print(f"裁剪后: {len(trimmed)} 条消息")
for msg in trimmed:
    snippet = msg.content[:50] if isinstance(msg.content, str) else str(msg.content)[:50]
    print(f"  [{msg.type}] {snippet}...")

Resultado de la ejecución:

裁剪前: 10 条消息
裁剪后: 5 条消息
  [system] 你是菜鸟教程 RUNOOB 的 AI 助手...
  [human] 如何安装第三方库？...
  [ai] 使用 pip install 命令...
  [human] NumPy 是什么？...
  [ai] NumPy 是一个科学计算库...
EstrategiaDescripciónEscenario de aplicación
strategy="last"Conservar mensaje system + conversación recienteEn conversaciones largas, solo importa el contexto más reciente
strategy="first"Conservar mensaje system + primeras conversacionesAsegurar que el contexto clave no se recorte

start_on="human" asegura que la lista de mensajes recortada comience con un mensaje del usuario (en lugar de un mensaje de IA), evitando que el modelo reciba una respuesta de IA aislada al inicio.

RemoveMessage: eliminar mensajes específicos

En algunos escenarios avanzados, es posible que necesites eliminar mensajes específicos del historial (como limpieza de contenido sensible, regeneración de respuestas, etc.):

Ejemplo

from langchain.messages import HumanMessage, AIMessage, RemoveMessage

# Supongamos que hay una conversación
messages = [
    HumanMessage(content="你好", id="msg_1"),
    AIMessage(content="你好！有什么可以帮你的？", id="msg_2"),
    HumanMessage(content="帮我查天气", id="msg_3"),
]

# Usar RemoveMessage para eliminar mensajes específicos (mediante ID)
# RemoveMessage se usa junto con el reducer add_messages
# Al actualizar el estado del agente, RemoveMessage elimina de la lista los mensajes con el ID correspondiente
removal = RemoveMessage(id="msg_3")

print(f"要删除的消息 ID: {removal.id}")
print(f"类型: {removal.type}")  # remove

RemoveMessage normalmente se usa con el reducer add_messages de AgentState. Devolver RemoveMessage en middleware o en el hook after_model permite limpiar dinámicamente el historial de mensajes.

Métodos comunes para las propiedades de mensajes

Todos los tipos de mensajes heredan de BaseMessage y comparten algunos métodos comunes:

Ejemplo

from langchain.messages import HumanMessage, AIMessage

msg = HumanMessage(content="你好，菜鸟教程")

# Atributos básicos
print(f"content: {msg.content}")      # Contenido del mensaje
print(f"type: {msg.type}")            # Tipo de mensaje (human/ai/system/tool)
print(f"id: {msg.id}")                # ID único generado automáticamente

# Propiedad text: si es contenido de texto, devuelve el texto; de lo contrario, devuelve ""
print(f"text: {msg.text}")

# pretty_repr(): impresión formateada, adecuada para depuración
print(f"Salida embellecida:\n{msg.pretty_repr()}")

Resultado de la ejecución:

content: 你好，菜鸟教程
type: human
id: 00000000-0000-4000-8000-000000000000
text: 你好，菜鸟教程
美化输出:
================================ Human Message =================================
你好，菜鸟教程
