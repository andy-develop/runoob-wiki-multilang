Python Patrón Memento (Memento)

El patrón Memento es un patrón de diseño de comportamiento que permite capturar y guardar el estado interno de un objeto sin romper la encapsulación, para poder restaurarlo a un estado anterior cuando sea necesario.

Imagina que estás jugando a un juego que ofrece la función de "guardar partida". Puedes guardar el progreso actual en cualquier momento; si luego pierdes o quieres reintentar un nivel, puedes cargar la partida guardada anteriormente. El patrón Memento es la solución de programación para implementar esta función de "guardar-cargar".

¿Por qué necesitamos el patrón Memento?

Escenarios de aplicación

  • Editor de texto: implementar las funciones de deshacer (Undo) y rehacer (Redo)
  • Desarrollo de juegos: guardar el progreso y el estado del juego
  • Software gráfico: soportar el historial de operaciones
  • Procesamiento de transacciones: revertir a un estado anterior cuando una operación falla

Problemas que resuelve

  • Necesita guardar el estado de un objeto sin exponer los detalles internos del objeto
  • Proporciona un mecanismo de restauración de estado, compatible con la función de "arrepentimiento"
  • Mantiene la encapsulación del objeto, evitando mezclar la lógica de guardado de estado con la lógica de negocio

Componentes principales del patrón Memento

El patrón Memento incluye tres roles principales:

1. Originador (Originator)

  • El objeto que necesita guardar el estado
  • Crea un memento para registrar el estado actual
  • Usa el memento para restaurar el estado anterior

2. Memento (Memento)

  • Almacena el estado interno del objeto originador
  • Impide que objetos distintos del originador accedan al contenido del memento

3. Administrador (Caretaker)

  • Se encarga de guardar los mementos
  • No puede operar ni inspeccionar el contenido del memento

Implementación del patrón Memento en Python

Implementemos el patrón Memento mediante un ejemplo de editor de texto.

Implementación básica

Ejemplo

class TextEditorMemento:
    """备忘录类 - 保存文本编辑器的状态"""
   
    def __init__(self, content):
        self._content = content
   
    def get_content(self):
        """获取保存的内容"""
        return self._content


class TextEditor:
    """发起人类 - 文本编辑器"""
   
    def __init__(self):
        self._content = ""
   
    def write(self, text):
        """写入文本"""
        self._content += text
   
    def get_content(self):
        """获取当前内容"""
        return self._content
   
    def save(self):
        """创建备忘录 - 保存当前状态"""
        return TextEditorMemento(self._content)
   
    def restore(self, memento):
        """恢复状态 - 从备忘录读取"""
        self._content = memento.get_content()


class HistoryManager:
    """管理者类 - 历史记录管理器"""
   
    def __init__(self):
        self._mementos = []
   
    def push(self, memento):
        """保存备忘录"""
        self._mementos.append(memento)
   
    def pop(self):
        """获取最新的备忘录"""
        if self._mementos:
            return self._mementos.pop()
        return None

Código de ejemplo completo

Ejemplo

# 备忘录模式完整示例
def memo_pattern_demo():
    # 创建文本编辑器和历史管理器
    editor = TextEditor()
    history = HistoryManager()
   
    print("=== 文本编辑器备忘录模式演示 ===\n")
   
    # 第一次编辑并保存
    editor.write("Hello, ")
    history.push(editor.save())
    print(f"当前内容: {editor.get_content()}")
    print("&#x2705; 已保存状态\n")
   
    # 第二次编辑并保存
    editor.write("World!")
    history.push(editor.save())
    print(f"当前内容: {editor.get_content()}")
    print("&#x2705; 已保存状态\n")
   
    # 第三次编辑但不保存
    editor.write(" This is new text.")
    print(f"当前内容: {editor.get_content()}")
    print("&#x274c; 未保存当前编辑\n")
   
    # 撤销操作 - 恢复到上一次保存的状态
    memento = history.pop()
    if memento:
        editor.restore(memento)
        print(f"撤销后内容: {editor.get_content()}")
        print("&#x21a9;&#xfe0f; 已撤销到上一个保存点\n")
   
    # 再次撤销
    memento = history.pop()
    if memento:
        editor.restore(memento)
        print(f"再次撤销后内容: {editor.get_content()}")
        print("&#x21a9;&#xfe0f; 已撤销到最初状态")


# 运行演示
if __name__ == "__main__":
    memo_pattern_demo()

Aplicación avanzada: Memento que admite múltiples estados

En aplicaciones reales, puede que necesitemos guardar múltiples atributos de un objeto. A continuación se muestra un ejemplo más complejo:

Ejemplo

import datetime
import json

class GameStateMemento:
    """游戏状态备忘录"""
   
    def __init__(self, level, score, player_health, inventory):
        self._state = {
            'level': level,
            'score': score,
            'player_health': player_health,
            'inventory': inventory.copy(),  # 创建副本避免引用问题
            'timestamp': datetime.datetime.now().isoformat()
        }
   
    def get_state(self):
        """获取完整状态"""
        return self._state.copy()
   
    def get_timestamp(self):
        """获取保存时间"""
        return self._state['timestamp']


class Game:
    """游戏类 - 发起人"""
   
    def __init__(self):
        self.level = 1
        self.score = 0
        self.player_health = 100
        self.inventory = ['sword', 'potion']
   
    def play(self, level_increase=1, score_increase=100, health_change=0, new_item=None):
        """模拟游戏进程"""
        self.level += level_increase
        self.score += score_increase
        self.player_health += health_change
       
        if new_item and new_item not in self.inventory:
            self.inventory.append(new_item)
       
        # 生命值不能为负
        self.player_health = max(0, self.player_health)
   
    def display_status(self):
        """显示当前状态"""
        status = f"""
&#x1f3ae; 游戏状态:
关卡: {self.level}
分数: {self.score}
生命值: {self.player_health}
背包: {', '.join(self.inventory)}
        """
        print(status)
   
    def save_game(self):
        """保存游戏状态"""
        return GameStateMemento(
            self.level,
            self.score,
            self.player_health,
            self.inventory
        )
   
    def load_game(self, memento):
        """加载游戏状态"""
        state = memento.get_state()
        self.level = state['level']
        self.score = state['score']
        self.player_health = state['player_health']
        self.inventory = state['inventory']


class SaveManager:
    """存档管理器"""
   
    def __init__(self):
        self.saves = {}
   
    def create_save(self, save_name, memento):
        """创建存档"""
        self.saves[save_name] = memento
        print(f"&#x1f4be; 存档 '{save_name}' 创建成功!")
   
    def load_save(self, save_name):
        """加载存档"""
        if save_name in self.saves:
            print(f"&#x1f504; 正在加载存档 '{save_name}'...")
            return self.saves[save_name]
        else:
            print(f"&#x274c; 存档 '{save_name}' 不存在!")
            return None
   
    def list_saves(self):
        """列出所有存档"""
        if not self.saves:
            print("&#x1f4c1; 暂无存档")
            return
       
        print("\n&#x1f4cb; 存档列表:")
        for name, memento in self.saves.items():
            timestamp = memento.get_timestamp()
            print(f" - {name} (保存于: {timestamp})")


# 高级示例演示
def advanced_memo_demo():
    print("=== 游戏存档系统演示 ===\n")
   
    game = Game()
    save_manager = SaveManager()
   
    # 初始状态
    print("&#x1f3af; 开始新游戏:")
    game.display_status()
   
    # 游戏进程
    print("&#x1f680; 进行游戏...")
    game.play(level_increase=2, score_increase=500, new_item='shield')
    game.display_status()
   
    # 保存第一个存档
    save_manager.create_save("第一关通关", game.save_game())
   
    # 继续游戏
    print("&#x2694;&#xfe0f; 继续冒险...")
    game.play(level_increase=1, score_increase=200, health_change=-30, new_item='magic_wand')
    game.display_status()
   
    # 保存第二个存档
    save_manager.create_save("第二关开始", game.save_game())
   
    # 显示存档列表
    save_manager.list_saves()
   
    # 加载第一个存档
    print("\n&#x23ea; 回到第一关通关状态:")
    first_save = save_manager.load_save("第一关通关")
    if first_save:
        game.load_game(first_save)
        game.display_status()


# 运行高级示例
if __name__ == "__main__":
    advanced_memo_demo()

Ventajas y desventajas del patrón Memento

Ventajas

  1. Protección de encapsulación: no expone el estado interno del objeto, mantiene la encapsulación
  2. Simplica el originador: separa la lógica de guardado de estado de la lógica de negocio
  3. Fácil de implementar la restauración: proporciona un mecanismo simple de restauración de estado
  4. Soporta múltiples deshaceres: puede guardar el estado en múltiples momentos

Desventajas

  1. Consumo de memoria: si el estado es muy grande o se guarda con frecuencia, consumirá mucha memoria
  2. Sobrecarga del administrador: requiere clases adicionales para administrar los mementos
  3. Gestión del ciclo de vida: es necesario manejar adecuadamente la creación y destrucción de los mementos

Mejores prácticas y consideraciones

1. Estrategias de optimización de memoria

Ejemplo

# Limitar el número de registros históricos guardados
class LimitedHistoryManager:
    def __init__(self, max_size=10):
        self._mementos = []
        self._max_size = max_size
   
    def push(self, memento):
        if len(self._mementos) >= self._max_size:
            # Eliminar el registro más antiguo
            self._mementos.pop(0)
        self._mementos.append(memento)

2. Manejo de estados de objetos complejos

Para objetos que contienen referencias complejas, es necesario asegurarse de que el memento cree una copia profunda:

Ejemplo

import copy

class ComplexMemento:
    def __init__(self, complex_state):
        # Usar copia profunda para evitar problemas de referencia
        self._state = copy.deepcopy(complex_state)

3. Guardado selectivo

No todos los estados necesitan ser guardados; se puede optar por guardar solo las propiedades importantes:

Ejemplo

def create_selective_memento(self):
    """Guardar selectivamente el estado importante"""
    important_state = {
        'essential_data': self.essential_data,
        'critical_settings': self.critical_settings
        # Ignorar datos temporales y cachés
    }
    return SelectiveMemento(important_state)

Resumen

El patrón Memento es un patrón de diseño potente y práctico que nos proporciona un elegante mecanismo de guardado y restauración de estados. Al separar la lógica de guardado de estados de la lógica de negocio, no solo mantiene la limpieza del código, sino que también mejora la mantenibilidad del sistema.

Puntos clave:

  • El núcleo del patrón Memento es el mecanismo de "guardar-restaurar"
  • Los tres roles principales cumplen cada uno sus funciones con responsabilidades claras
  • En el uso práctico, hay que prestar atención a la gestión de memoria y a la selección de estados
  • Es adecuado para escenarios que requieren deshacer, rehacer o revertir estados
