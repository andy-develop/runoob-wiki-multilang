Atributos de datos de jQuery

Uso de jQuery MobileAtributos data-* de HTML5para crear una apariencia más táctil y atractiva para dispositivos móviles.

En la lista de referencia a continuación,los valores mostrados en negritason los valores predeterminados.

Botones

Obsoleto desde la versión 1.4. Utiliceclases CSSen su lugar.Condata-role="button"los hipervínculos. Los elementos button, los enlaces en las barras de herramientas y los campos input se renderizan automáticamente como botones, sin necesidad de añadir data-role="button".

Atributos de datos 值 Descripción
data-corners true | false Especifica si el botón tiene esquinas redondeadas
data-icon Referencia de iconos Especifica el icono del botón. Por defecto no hay icono.
data-iconpos left | right | top | bottom | notext Especifica la posición del icono
data-iconshadow true | false Especifica si el icono del botón tiene sombra
data-inline true | false Especifica si el botón es en línea (inline)
data-mini true | false Especifica si el botón es de tamaño pequeño o normal
data-shadow true | false Especifica si el botón tiene sombra
data-theme Letra (a-z) Especifica el color de tema del botón

Para combinar varios botones, use un contenedor con los atributos data-role="controlgroup" y data-type="horizontal|vertical" para especificar si los botones se combinan horizontal o verticalmente.

Casillas de verificación

Contype="checkbox"pares de label e input. Se renderizan automáticamente como botones, no se requiere data-role.

Atributos de datos 值 Descripción
data-mini true | false Especifica si la casilla de verificación es de tamaño pequeño o normal
data-role none Evita que jQuery Mobile renderice la casilla de verificación como un botón
data-theme Letra (a-z) Especifica el color de tema de la casilla de verificación

Para combinar varias casillas de verificación, use un contenedor con los atributos data-role="controlgroup" y data-type="horizontal|vertical" para especificar si las casillas se combinan horizontal o verticalmente.

Bloques plegables

Dentro de un contenedor condata-role="collapsible"el elemento de encabezado seguido de cualquier marcado HTML dentro del contenedor.

Atributos de datos 值 Descripción
data-collapsed true | false Especifica si el contenido está plegado o expandido
data-collapsed-icon Referencia de iconos Especifica el icono del botón plegable. Por defecto es "plus".
data-content-theme Letra (a-z) Especifica el color de tema del contenido plegable. Si se añaden esquinas redondeadas al contenido plegable.
data-expanded-icon Referencia de iconos Especifica el icono del botón plegable cuando el contenido está expandido. Por defecto es "minus".
data-iconpos left | right | top | bottom Especifica la posición del icono
data-inset true | false Especifica si el botón plegable se renderiza con esquinas redondeadas y márgenes externos
data-mini true | false Especifica si el botón plegable es de tamaño pequeño o normal
data-theme Letra (a-z) Especifica el color de tema del botón plegable

Conjuntos plegables

Dentro de un contenedor condata-role="collapsible-set"bloques de contenido plegable dentro del contenedor.

Atributos de datos 值 Descripción
data-collapsed-icon Referencia de iconos Especifica el icono del botón plegable. Por defecto es "plus".
data-content-theme Letra (a-z) Especifica el color de tema del botón plegable
data-expanded-icon Referencia de iconos Especifica el icono del botón plegable cuando el contenido está expandido. Por defecto es "minus".
data-iconpos left | right | top | bottom | notext Especifica la posición del icono
data-inset true | false Especifica si los bloques plegables se renderizan con esquinas redondeadas y márgenes externos
data-mini true | false Especifica si el botón plegable es de tamaño pequeño o normal
data-theme Letra (a-z) Especifica el color de tema del conjunto plegable

Obsoleto en la versión 1.4, ya no se admite a partir de la versión 1.5.Utilicedata-role="content"un contenedor con.

Atributos de datos 值 Descripción

Grupos de controles

Condata-role="controlgroup"el contenedor <div> o <fieldset>. Combina múltiples entradas con estilo de botón de un solo tipo (botones basados en enlaces, botones de opción, casillas de verificación, elementos select). Para combinar casillas de verificación y botones de opción de formularios, se recomienda usar un contenedor <fieldset> dentro de un <div> con data-role="fieldcontain" para mejorar el estilo de las etiquetas.

Atributos de datos 值 Descripción
data-mini true | false Especifica si el grupo de controles es de tamaño pequeño o normal
data-type horizontal | vertical Especifica si el grupo de controles se muestra horizontal o verticalmente

Diálogos

Condata-role="dialog"un contenedor, o condata-rel="dialog"un enlace.

Atributos de datos 值 Descripción
data-close-btn-text sometext Especifica el texto del botón de cierre del diálogo
data-dom-cache true | false Especifica si se limpia la caché DOM de jQuery de las páginas (si se establece en true, debe administrar el DOM usted mismo y probar en todos los dispositivos móviles)
data-overlay-theme Letra (a-z) Especifica el color de la máscara (fondo) de la página del diálogo
data-theme Letra (a-z) Especifica el color de tema de la página del diálogo
data-title sometext Especifica el título de la página del diálogo

Mejora

Condata-enhance="false" 或 data-ajax="false"el contenedor.

Atributos de datos 值 Descripción
data-enhance true | false Si se establece en "true" (predeterminado), jQuery Mobile renderiza automáticamente la página para hacerla más adecuada para dispositivos móviles. Si se establece en "false", el framework no renderizará la página.
data-ajax true | false Especifica si la página se carga mediante ajax

Nota:data-enhance="false" debe usarse junto con $.mobile.ignoreContentEnabled=true" para evitar que jQuery Mobile renderice la página automáticamente.

Cuando $.mobile.ignoreContentEnabled se establece en true, cualquier enlace o elemento de formulario dentro de un contenedor data-ajax="false" será ignorado por la función de navegación del framework.

Contenedores de campo

Obsoleto desde la versión 1.4, ya no se admite a partir de la versión 1.5; en su lugar se usará class="ui-fieldcontain".Envuelve pares de elementos label/form, y condata-role="fieldcontain"el contenedor.

Atributos de datos 值 Descripción
data-disable-page-zoom true | false Especifica si el usuario puede hacer zoom en la página
data-fullscreen true | false Especifica si la barra de herramientas permanece fija en la parte superior o inferior
data-tap-toggle true | false Especifica si el usuario puede cambiar la visibilidad de la barra de herramientas mediante clic
data-transition slide | fade | none Especifica el efecto de alternancia cuando se produce el clic
data-update-page-padding true | false Especifica si el relleno superior e inferior de la página se actualiza cuando ocurren los eventos resize, transition y "updatelayout" (jQuery Mobile siempre actualiza el relleno cuando ocurre el evento "pageshow").
data-visible-on-page-show true | false Especifica la visibilidad de la barra de herramientas cuando se muestra la página principal

Barra de pie

Condata-role="footer"el contenedor.

Data-atributos 值 Descripción
data-id sometext Especifica un ID único. Es necesario para un pie de página persistente.
data-position inline | fixed Especifica si el pie de página está en línea con el contenido de la página o permanece fijo en la parte inferior.
data-fullscreen true | false Especifica si el pie de página está fijo en la parte inferior o se superpone al contenido de la página (mayor área de visualización).
data-theme Letra (a-z) Especifica el color del tema del pie de página. El valor predeterminado es "a".

Nota:Para habilitar la posición de pantalla completa, use data-position="fixed" y luego agregue el atributo data-fullscreen al elemento.

Barra de cabecera

Condata-role="header"el contenedor.

Data-atributos 值 Descripción
data-id sometext Especifica un ID único. Es necesario para una barra de encabezado persistente.
data-position inline | fixed Especifica si la barra de encabezado está en línea con el contenido de la página o permanece fija en la parte superior.
data-fullscreen true | false Especifica si la barra de encabezado está fija en la parte superior o se superpone al contenido de la página (mayor área de visualización).
data-theme Letra (a-z) Especifica el color del tema de la barra de encabezado. El valor predeterminado es "a".

Nota:Para habilitar la posición de pantalla completa, use data-position="fixed" y luego agregue el atributo data-fullscreen al elemento.

Enlaces

Todos los enlaces, incluidos aquellos con data-role="button" y los botones de envío de formularios.

Data-atributos 值 Descripción
data-ajax true | false Especifica si las páginas se cargan mediante ajax para mejorar la experiencia del usuario y la interacción. Si se establece en false, jQuery Mobile realizará una solicitud de página normal.
data-direction reverse Animación de transición inversa (solo para páginas y diálogos).
data-dom-cache true | false Especifica si se debe limpiar la caché del DOM de jQuery para cada página (si se establece en true, debe administrar el DOM usted mismo y probar en todos los dispositivos móviles).
data-prefetch true | false Especifica si se deben precargar páginas en el DOM para que estén disponibles cuando el usuario las visite.
data-rel back | dialog | external | popup Especifica las opciones de comportamiento del enlace. Back: retrocede a la página anterior en el historial. Dialog: abre el enlace como un diálogo, sin guardar en el historial. External: se usa para enlazar a otro dominio. Popup: abre una ventana emergente.
data-transition fade | flip | flow | pop | slide | slidedown | slidefade | slideup | turn | none Especifica el efecto de transición de una página a la siguiente. Consulte nuestrotransiciones de página de jQuery Mobilecapítulo.
data-position-to origin | jQuery selector | window Especifica la posición de la ventana emergente. Origin: predeterminado. Coloca la ventana emergente sobre el enlace que la abre. jQuery selector: coloca la ventana emergente sobre el elemento especificado. Window: coloca la ventana emergente en el centro de la pantalla de la ventana.

Condata-role="listview"el <ol> o <ul>.

Data-atributos 值 Descripción

data-count-theme Letra (a-z) Especifica el color del tema de las burbujas de recuento.
data-divider-theme Letra (a-z) Especifica el color del tema de los separadores de lista.
data-filter true | false Especifica si se agrega un cuadro de búsqueda a la lista.
data-filter-placeholder sometext Obsoleto desde la versión 1.4. Use el atributo placeholder de HTML en su lugar.Especifica el texto dentro del cuadro de búsqueda. El valor predeterminado es "Filter items..."
data-filter-theme Letra (a-z) Especifica el color del tema del filtro de búsqueda.
data-icon Referencia de iconos Especifica el icono de la lista.
data-inset true | false Especifica si la lista se renderiza con esquinas redondeadas y con márgenes externos.
data-split-icon Referencia de iconos Especifica el icono del botón dividido. El valor predeterminado es "arrow-r".
data-split-theme Letra (a-z) Especifica el color del tema del botón dividido.
data-theme Letra (a-z) Especifica el color del tema de la lista.

Elementos de lista

Condata-role="listview"el <li> dentro de un <ol> o <ul>.

Data-atributos 值 Descripción
data-filtertext sometext Especifica el texto que se buscará al filtrar elementos. Este texto será filtrado en lugar del texto real del elemento de la lista.
data-icon Referencia de iconos Especifica el icono del elemento de la lista.
data-role list-divider Especifica la división del elemento de la lista.
data-theme Letra (a-z) Especifica el color del tema del elemento de la lista.

Nota:El atributo data-icon solo se aplica a los elementos de lista con enlaces.

Barra de navegación

Condata-role="navbar"el elemento <li> dentro del contenedor.

Data-atributos 值 Descripción

data-iconpos left | right | top | bottom | notext Especifica la posición del icono.

La barra de navegación hereda la muestra de tema de su contenedor padre. No es posible establecer el atributo data-theme en la barra de navegación. Puede establecer el atributo data-theme individualmente en cada enlace de la barra de navegación.

Data-atributos 值 Descripción
data-add-back-btn true | false Agrega automáticamente un botón de retroceso, solo para la barra de encabezado.
data-back-btn-text sometext Especifica algún texto para el botón de retroceso.
data-back-btn-theme Letra (a-z) Especifica el color del tema del botón de retroceso.
data-close-btn-text Letra (a-z) Especifica algún texto para el botón de cierre en el cuadro de diálogo.
data-dom-cache true | false Especifica si se debe limpiar la caché del DOM de jQuery para cada página (si se establece en true, debe administrar el DOM usted mismo y probar en todos los dispositivos móviles).
data-overlay-theme Letra (a-z) Especifica el color de la máscara (fondo) de la página de diálogo.
data-theme Letra (a-z) Especifica el color del tema de la página.
data-title sometext Especifica el título de la página.
data-url url Actualiza el valor de la URL, en lugar de la URL utilizada para solicitar la página.

Botones de opción

Contype="radio"etiquetas (label) e inputs emparejados. Se renderizan automáticamente con estilo de botón, data-role no es necesario.

Data-atributos 值 Descripción
data-mini true | false Especifica si el botón es de tamaño pequeño o normal.
data-role none Evita que jQuery Mobile renderice los botones de opción como botones mejorados, haciendo que el elemento se muestre en su estado HTML nativo.
data-theme Letra (a-z) Especifica el color del tema del botón de opción.

Para agrupar varios botones de opción, use un contenedor con el atributo data-role="controlgroup" y data-type="horizontal|vertical" para especificar si los botones de opción se combinan horizontal o verticalmente.

Selecciones

Todos los<select>elementos. Estos se renderizan automáticamente con estilo de botón, data-role no es necesario.

Data-atributos 值 Descripción
data-icon Referencia de iconos Especifica el icono del elemento select. El valor predeterminado es "arrow-d".
data-iconpos left | right | top | bottom | notext Especifica la posición del icono.
data-inline true | false Especifica si el elemento select es en línea (inline).
data-mini true | false Especifica si el elemento select es de tamaño pequeño o normal.
data-native-menu true | false Cuando se establece en false, utiliza el menú de selección personalizado integrado de jQuery (recomendado si desea que los menús de selección se vean igual en todos los dispositivos móviles).
data-overlay-theme Letra (a-z) Especifica el color del tema del menú de selección personalizado integrado de jQuery (se usa junto con data-native-menu="false").
data-placeholder true | false Se puede establecer en un elemento <option> de un menú de selección no nativo.
data-role none Evita que jQuery Mobile renderice el elemento select con estilo de botón.
data-theme Letra (a-z) Especifica el color del tema del elemento select.

Si necesita combinar varios elementos select, use un contenedor con el atributo data-role="controlgroup" y data-type="horizontal|vertical" para especificar si los elementos select se combinan horizontal o verticalmente.
