Node.js Express Framework

Introducción a Express

Express es un framework de aplicaciones web de node.js simple y flexible que ofrece una serie de potentes características para ayudarte a crear varias aplicaciones web, así como abundantes herramientas HTTP.

Con Express puedes crear rápidamente un sitio web con todas las funciones.

Características principales del framework Express:

  • Se pueden configurar middleware para responder a las solicitudes HTTP.

  • Define una tabla de rutas para ejecutar diferentes acciones de solicitudes HTTP.

  • Se pueden renderizar páginas HTML dinámicamente pasando parámetros a las plantillas.

Instalación de Express

Instala Express y guárdalo en la lista de dependencias:

$ cnpm install express --save

El comando anterior instalará el framework Express en el directorio actual delnode_modulesdirectorio,node_modulesBajo el directorio se creará automáticamente el directorio express. Los siguientes módulos importantes deben instalarse junto con el framework express:

  • body-parser- Middleware de node.js, utilizado para procesar datos codificados en JSON, Raw, Text y URL.

  • cookie-parser- Esta es una herramienta para analizar cookies. A través de req.cookies se pueden obtener las cookies enviadas y convertirlas en objetos.

  • multer- Middleware de node.js, utilizado para procesar datos de formularios con enctype="multipart/form-data" (configura la codificación MIME del formulario).

$ cnpm install body-parser --save
$ cnpm install cookie-parser --save
$ cnpm install multer --save

Después de la instalación, podemos comprobar el número de versión de express utilizada:

$ cnpm list express
/data/www/node
└── express@4.15.2  -> /Users/tianqixin/www/node/node_modules/.4.15.2@express

Solicitudes y respuestas

Las aplicaciones Express utilizan los parámetros de la función de devolución de llamada (callback):request 和 responseobjetos para manejar los datos de las solicitudes y respuestas.

app.get('/', function (req, res) {
   // --
})

request 和 responseDescripción detallada de los objetos:

Objeto Request- El objeto request representa una solicitud HTTP y contiene propiedades como la cadena de consulta, parámetros, contenido, encabezados HTTP, etc. Las propiedades comunes son:

  1. req.app: cuando callback es un archivo externo, usa req.app para acceder a la instancia de express.
  2. req.baseUrl: obtiene la ruta URL donde está instalada actualmente la ruta.
  3. req.body / req.cookies: obtiene el "cuerpo de la solicitud" / Cookies.
  4. req.fresh / req.stale: determina si la solicitud aún es "fresca".
  5. req.hostname / req.ip: obtiene el nombre de host y la dirección IP.
  6. req.originalUrl: obtiene la URL de solicitud original.
  7. req.params: obtiene los parámetros de la ruta.
  8. req.path: obtiene la ruta de la solicitud.
  9. req.protocol: obtiene el tipo de protocolo.
  10. req.query: obtiene la cadena de parámetros de consulta de la URL.
  11. req.route: obtiene la ruta actualmente coincidente.
  12. req.subdomains: obtiene los subdominios.
  13. req.accepts(): comprueba los tipos de documento aceptables de la solicitud.
  14. req.acceptsCharsets / req.acceptsEncodings / req.acceptsLanguages: devuelve la primera codificación de caracteres aceptable del conjunto de caracteres especificado.
  15. req.get(): obtiene el encabezado de solicitud HTTP especificado.
  16. req.is(): determina el tipo MIME del encabezado Content-Type de la solicitud.

Objeto Response- El objeto response representa la respuesta HTTP, es decir, los datos de respuesta HTTP que se envían al cliente al recibir una solicitud. Las propiedades comunes son:

  1. res.app: igual que req.app.
  2. res.append(): agrega el encabezado HTTP especificado.
  3. res.set() restablecerá los encabezados establecidos anteriormente después de res.append().
  4. res.cookie(nombre, valor [, opción]): establece una Cookie.
  5. opition: domain / expires / httpOnly / maxAge / path / secure / signed
  6. res.clearCookie(): elimina una Cookie.
  7. res.download(): envía el archivo de la ruta especificada.
  8. res.get(): devuelve el encabezado HTTP especificado.
  9. res.json(): envía una respuesta JSON.
  10. res.jsonp(): envía una respuesta JSONP.
  11. res.location(): solo establece el encabezado HTTP Location de la respuesta, sin establecer el código de estado ni cerrar la respuesta (close response).
  12. res.redirect(): establece el encabezado HTTP Location de la respuesta y el código de estado 302.
  13. res.render(view, [locals], callback): renderiza una vista y pasa la cadena renderizada al callback. Si ocurre un error durante el renderizado, se llamará automáticamente a next(err). Al callback se le pasará un posible error y la página renderizada, de modo que no se realizará una salida automática.
  14. res.send(): envía una respuesta HTTP.
  15. res.sendFile(ruta [, opciones] [, fn]): envía el archivo de la ruta especificada. - Establece automáticamente el Content-Type según la extensión del archivo.
  16. res.set(): establece encabezados HTTP; si se pasa un objeto, se pueden establecer varios encabezados a la vez.
  17. res.status(): establece el código de estado HTTP.
  18. res.type(): establece el tipo MIME de Content-Type.

Enrutamiento

Ya hemos aprendido las aplicaciones básicas de las solicitudes HTTP, y el enrutamiento determina quién (script específico) responde a la solicitud del cliente.

En una solicitud HTTP, podemos extraer la URL de la solicitud y los parámetros GET/POST a través de las rutas.

A continuación, ampliaremos Hello World, añadiendo algunas funciones para manejar más tipos de solicitudes HTTP.

Crea el archivo express_demo2.js, con el siguiente código:

Código del archivo express_demo2.js:

var express = require('express'); var app = express(); //La página principal genera "Hello World". app.get('/', function (req, res) { console.log("Solicitud GET de la página principal."); res.send('Hello GET'); }) //Solicitud POST. app.post('/', function (req, res) { console.log("Solicitud POST de la página principal."); res.send('Hello POST'); }) //Respuesta de la página /del_user. app.get('/del_user', function (req, res) { console.log("/del_user responde a la solicitud DELETE."); res.send('Página de eliminación.'); }) //Solicitud GET de la página /list_user. app.get('/list_user', function (req, res) { console.log("Solicitud GET /list_user."); res.send('Página de lista de usuarios.'); }) //Responde a solicitudes GET para páginas como abcd, abxcd, ab123cd, etc. app.get('/ab*cd', function(req, res) { console.log("Solicitud GET /ab*cd."); res.send('Coincidencia de expresiones regulares.'); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("Ejemplo de aplicación, dirección de acceso: http://%s:%s", host, port) })

Ejecute el código anterior:

$ node express_demo2.js 
应用实例，访问地址为 http://0.0.0.0:8081

Archivos estáticos

Express proporciona un middleware integrado express.static para configurar archivos estáticos como: imágenes, CSS, JavaScript, etc.

Puede usar express.static middleware para establecer la ruta de los archivos estáticos. Por ejemplo, si coloca imágenes, CSS y archivos JavaScript en el directorio public, puede escribir:

app.use('/public', express.static('public'));

Método GET

El siguiente ejemplo demuestra cómo enviar dos parámetros a través del método GET en un formulario. Podemos usar el enrutador en el archivo server.jsprocess_getpara procesar la entrada:

Código del archivo index.html:

<html> <body> <form action="/process_get" method="GET"> First Name: <input type="text" name="first_name"> <br> Last Name: <input type="text" name="last_name"> <input type="submit" value="Submit"> </form> </body> </html>

Código del archivo server.js:

var express = require('express'); var app = express(); app.use('/public', express.static('public')); app.get('/index.html', function (req, res) { res.sendFile( __dirname + "/" + "index.html" ); }) app.get('/process_get', function (req, res) { //Salida en formato JSON var response = { "first_name":req.query.first_name, "last_name":req.query.last_name }; console.log(response); res.end(JSON.stringify(response)); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("Ejemplo de aplicación, dirección de acceso: http://%s:%s", host, port) })

Método POST

El siguiente ejemplo demuestra cómo enviar dos parámetros a través del método POST en un formulario. Podemos usar el enrutador en el archivo server.jsprocess_postpara procesar la entrada:

Código del archivo index.html:

<html> <body> <form action="http://127.0.0.1:8081/process_post" method="POST"> First Name: <input type="text" name="first_name"> <br> Last Name: <input type="text" name="last_name"> <input type="submit" value="Submit"> </form> </body> </html>

Código del archivo server.js:

var express = require('express'); var app = express(); var bodyParser = require('body-parser'); //Crear el analizador de codificación application/x-www-form-urlencoded var urlencodedParser = bodyParser.urlencoded({ extended: false }) app.use('/public', express.static('public')); app.get('/index.html', function (req, res) { res.sendFile( __dirname + "/" + "index.html" ); }) app.post('/process_post', urlencodedParser, function (req, res) { //Salida en formato JSON var response = { "first_name":req.body.first_name, "last_name":req.body.last_name }; console.log(response); res.end(JSON.stringify(response)); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("Ejemplo de aplicación, dirección de acceso: http://%s:%s", host, port) })

Ejecute el código anterior:

$ node server.js

Subida de archivos

A continuación creamos un formulario para subir archivos, usando el método POST, y el atributo enctype del formulario se establece en multipart/form-data.

Código del archivo index.html:

<html> <head> <title>Formulario de subida de archivos</title> </head> <body> <h3>Subir archivo:</h3>Seleccione un archivo para subir:<br /> <form action="/file_upload" method="post" enctype="multipart/form-data"> <input type="file" name="image" size="50" /> <br /> <input type="submit" value="Subir archivo" /> </form> </body> </html>

Código del archivo server.js:

var express = require('express'); var app = express(); var fs = require("fs"); var bodyParser = require('body-parser'); var multer = require('multer'); app.use('/public', express.static('public')); app.use(bodyParser.urlencoded({ extended: false })); app.use(multer({ dest: '/tmp/'}).array('image')); app.get('/index.html', function (req, res) { res.sendFile( __dirname + "/" + "index.html" ); }) app.post('/file_upload', function (req, res) { console.log(req.files[0]); //Información del archivo subido var des_file = __dirname + "/" + req.files[0].originalname; fs.readFile( req.files[0].path, function (err, data) { fs.writeFile(des_file, data, function (err) { if( err ){ console.log( err ); }else{ response = { message:'File uploaded successfully', filename:req.files[0].originalname }; } console.log( response ); res.end( JSON.stringify( response ) ); }); }); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("Ejemplo de aplicación, dirección de acceso: http://%s:%s", host, port) })

Gestión de cookies

Podemos usar middleware para enviar información de cookies al servidor Node.js. El siguiente código imprime la información de cookies enviada por el cliente:

Código del archivo express_cookie.js:

//Archivo express_cookie.js var express = require('express') var cookieParser = require('cookie-parser') var util = require('util'); var app = express() app.use(cookieParser()) app.get('/', function(req, res) { console.log("Cookies: " + util.inspect(req.cookies)); }) app.listen(8081)

Ejecute el código anterior:

$ node express_cookie.js

    El problema de que server.address().address devuelva :, consulte los documentos relacionados.

    As the docs say,

    Begin accepting connections on the specified port and hostname. If the hostname is omitted, the server will accept connections on any IPv6 address (::) when IPv6 is available, or any IPv4 address (0.0.0.0) otherwise. A port value of zero will assign a random port.

    So, the following code would print running at http://:::3456:

    var express      = require('express');
var app          = express();
var server = app.listen(3456, function () {
    var host = server.address().address;
    var port = server.address().port;
    console.log('running at http://' + host + ':' + port)
});

    But if you add an explicit hostname:

    var server = app.listen(3456, "127.0.0.1", function () {

    It would print what you want to see: running at http://127.0.0.1:3456

    Also you might want to use some IP lib as pointed in this answer

    Es decir, por defecto está en modo IPv6. En cuanto a cómo cambiarlo, quizás haya que investigarlo, por lo que es mejor declarar explícitamente la dirección como "127.0.0.1" o localhost.
