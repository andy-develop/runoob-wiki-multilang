Node.js sistema de archivos

El módulo de sistema de archivos de Node.js (fsmódulo) proporciona una API rica para leer, escribir, eliminar archivos y realizar otras operaciones del sistema de archivos.

El módulo fs admite tanto métodos síncronos como asíncronos, lo que permite a los desarrolladores elegir la forma adecuada de manejar las operaciones de archivos según sus necesidades específicas.

Importar el módulo fs

Primero, necesitas importar el módulo fs:

var fs = require("fs")

Asíncrono y síncrono

Los métodos del módulo de sistema de archivos de Node.js (módulo fs) tienen versiones asíncronas y síncronas. Por ejemplo, la función para leer el contenido de un archivo tiene fs.readFile() asíncrono y fs.readFileSync() síncrono.

En los métodos asíncronos, el último parámetro es la función de callback, y el primer parámetro de la función de callback contiene la información de error.

Se recomienda usar métodos asíncronos; en comparación con los síncronos, los métodos asíncronos tienen mayor rendimiento, son más rápidos y no bloquean.

Ejemplo

Crea el archivo example.txt, con el siguiente contenido:

菜鸟教程官网地址：www.runoob.com
文件读取实例

Crea el archivo file.js, con el siguiente código:

Ejemplo

var fs = require("fs");

// Lectura asíncrona
fs.readFile('input.txt', function (err, data) {
   if (err) {
       return console.error(err);
   }
   console.log("Lectura asíncrona: " + data.toString());
});

// Lectura síncrona
var data = fs.readFileSync('example.txt');
console.log("Lectura síncrona: " + data.toString());

console.log("El programa ha terminado.");

El resultado de ejecutar el código anterior es el siguiente:

$ node file.js

Uso avanzado

1. Flujo de archivos

Los flujos de archivos se pueden usar para leer y escribir archivos grandes de manera eficiente, sin cargar todo el archivo en la memoria de una sola vez.

Flujo de lectura de archivos:

const fs = require('fs');

const readableStream = fs.createReadStream('large_file.txt', 'utf8');

readableStream.on('data', (chunk) => {
    console.log('Received chunk:', chunk);
});

readableStream.on('end', () => {
    console.log('No more data.');
});

Flujo de escritura de archivos:

const fs = require('fs');

const writableStream = fs.createWriteStream('output.txt');

writableStream.write('Hello, ');
writableStream.write('World!\n');

writableStream.end();

writableStream.on('finish', () => {
    console.log('All writes are now complete.');
});

2. Información estadística del sistema de archivos

Se puede usarfs.stat 或 fs.lstatpara obtener la información estadística de un archivo o directorio.

Obtener información estadística de forma asíncrona:

fs.stat('example.txt', (err, stats) => {
    if (err) {
        console.error('Error getting stats:', err);
        return;
    }
    console.log('Is file?', stats.isFile());
    console.log('Is directory?', stats.isDirectory());
    console.log('Size:', stats.size);
});

Obtener información estadística de forma síncrona:

try {
    const stats = fs.statSync('example.txt');
    console.log('Is file?', stats.isFile());
    console.log('Is directory?', stats.isDirectory());
    console.log('Size:', stats.size);
} catch (err) {
    console.error('Error getting stats:', err);
}

A continuación, vamos a conocer en detalle los métodos del sistema de archivos de Node.js.

Abrir un archivo

Sintaxis

La siguiente es la sintaxis para abrir un archivo en modo asíncrono:

fs.open(path, flags[, mode], callback)

Parámetros

La descripción de los parámetros es la siguiente:

  • path- La ruta del archivo.

  • flags- El comportamiento de apertura del archivo. Vea los valores específicos a continuación.

  • mode- Establece el modo (permisos) del archivo, el permiso predeterminado para archivos nuevos es 0666 (lectura y escritura).

  • callback- Función de callback, con dos parámetros como: callback(err, fd).

El parámetro flags puede tener los siguientes valores:

FlagDescripción
rAbre el archivo en modo de solo lectura. El archivo debe existir. Si el archivo no existe, se lanzará una excepción.
r+Abre el archivo en modo lectura y escritura. El archivo debe existir.
rsAbre el archivo en modo de solo lectura de forma síncrona. Es una operación bloqueante, pero en algunos sistemas operativos puede ofrecer mejor estabilidad.
rs+Abre el archivo en modo lectura y escritura de forma síncrona. Es una operación bloqueante, pero en algunos sistemas operativos puede ofrecer mejor estabilidad.
wAbre el archivo en modo de solo escritura. Si el archivo no existe, se crea; si existe, se trunca.
wxSimilar a 'w', pero falla si la ruta existe.
w+Abre el archivo en modo lectura y escritura. Si el archivo no existe, se crea; si existe, se trunca.
wx+Similar a 'w+', pero falla si la ruta existe.
aAbre el archivo en modo de agregar (append). Si el archivo no existe, se crea.
axSimilar a 'a', pero falla si la ruta existe.
a+Abre el archivo en modo lectura y agregar. Si el archivo no existe, se crea.
ax+Similar a 'a+', pero falla si la ruta existe.

Ejemplo

A continuación, creamos el archivo file.js y abrimos input.txt para lectura y escritura, el código es el siguiente:

var fs = require("fs");

// 异步打开文件
console.log("准备打开文件！");
fs.open('input.txt', 'r+', function(err, fd) {
   if (err) {
       return console.error(err);
   }
  console.log("文件打开成功！");     
});

El resultado de ejecutar el código anterior es el siguiente:

$ node file.js 
准备打开文件！
文件打开成功！

Obtener información del archivo

Sintaxis

La siguiente es la sintaxis para obtener información del archivo en modo asíncrono:

fs.stat(path, callback)

Parámetros

La descripción de los parámetros es la siguiente:

  • path- Ruta del archivo.

  • callback- Función de callback, con dos parámetros como: (err, stats),statsstats es el objeto fs.Stats.

Después de ejecutar fs.stat(path), se devuelve una instancia de la clase stats a su función de callback. Se pueden usar los métodos proporcionados por la clase stats para determinar las propiedades del archivo. Por ejemplo, para determinar si es un archivo:

var fs = require('fs');

fs.stat('/Users/liuht/code/itbilu/demo/fs.js', function (err, stats) {
    console.log(stats.isFile());         //true
})

Los métodos de la clase stats incluyen:

MétodoDescripción
stats.isFile()Devuelve true si es un archivo; de lo contrario, devuelve false.
stats.isDirectory()Devuelve true si es un directorio; de lo contrario, devuelve false.
stats.isBlockDevice()Devuelve true si es un dispositivo de bloques; de lo contrario, devuelve false.
stats.isCharacterDevice()Devuelve true si es un dispositivo de caracteres; de lo contrario, devuelve false.
stats.isSymbolicLink()Devuelve true si es un enlace simbólico; de lo contrario, devuelve false.
stats.isFIFO()Devuelve true si es FIFO; de lo contrario, devuelve false. FIFO es un tipo especial de tubería de comandos en UNIX.
stats.isSocket()Devuelve true si es un socket; de lo contrario, devuelve false.

Ejemplo

A continuación, creamos el archivo file.js, el código es el siguiente:

var fs = require("fs");

console.log("准备打开文件！");
fs.stat('input.txt', function (err, stats) {
   if (err) {
       return console.error(err);
   }

   console.log("读取文件信息成功！");
   
   // 检测文件类型
   console.log("是否为文件(isFile) ? " + stats.isFile());
   console.log("是否为目录(isDirectory) ? " + stats.isDirectory());    
});

Escribir en un archivo

Sintaxis

La siguiente es la sintaxis para escribir en un archivo en modo asíncrono:

fs.writeFile(file, data[, options], callback)

writeFile abre directamente el archivo; el modo predeterminado eswmodo, por lo que si el archivo existe, el contenido escrito por este método sobrescribirá el contenido anterior.

Parámetros

La descripción de los parámetros es la siguiente:

  • file- Nombre del archivo o descriptor de archivo.

  • data- Datos a escribir en el archivo, pueden ser un objeto String (cadena) o Buffer (búfer).

  • options- Este parámetro es un objeto que contiene {encoding, mode, flag}. La codificación predeterminada es utf8, el modo es 0666 y flag es 'w'.

  • callback- Función de callback, que solo contiene el parámetro de información de error (err), devuelto cuando falla la escritura.

Ejemplo

A continuación, creamos el archivo file.js, el código es el siguiente:

var fs = require("fs");

console.log("准备写入文件");
fs.writeFile('input.txt', '我是通 过fs.writeFile 写入文件的内容',  function(err) {
   if (err) {
       return console.error(err);
   }
   console.log("数据写入成功！");
   console.log("--------我是分割线-------------")
   console.log("读取写入的数据！");
   fs.readFile('input.txt', function (err, data) {
      if (err) {
         return console.error(err);
      }
      console.log("异步读取文件数据: " + data.toString());
   });
});

El resultado de ejecutar el código anterior es el siguiente:

$ node file.js 
准备写入文件
数据写入成功！
--------我是分割线-------------
读取写入的数据！
异步读取文件数据: 我是通 过fs.writeFile 写入文件的内容

Leer un archivo

Sintaxis

La siguiente es la sintaxis para leer archivos en modo asíncrono:

fs.read(fd, buffer, offset, length, position, callback)

Este método utiliza un descriptor de archivo para leer el archivo.

Parámetros

La descripción del uso de los parámetros es la siguiente:

  • fd- El descriptor de archivo devuelto por el método fs.open().

  • buffer- El búfer donde se escriben los datos.

  • offset- El desplazamiento de escritura en el búfer.

  • length- El número de bytes que se van a leer del archivo.

  • position- La posición inicial de lectura del archivo. Si el valor de position es null, se leerá desde la posición actual del puntero del archivo.

  • callback- La función de devolución de llamada tiene tres parámetros: err, bytesRead, buffer. err es el mensaje de error, bytesRead indica el número de bytes leídos y buffer es el objeto del búfer.

Ejemplo

El contenido del archivo input.txt es:

菜鸟教程官网地址：www.runoob.com

A continuación, creamos el archivo file.js, el código es el siguiente:

var fs = require("fs");
var buf = new Buffer.alloc(1024);

console.log("准备打开已存在的文件！");
fs.open('input.txt', 'r+', function(err, fd) {
   if (err) {
       return console.error(err);
   }
   console.log("文件打开成功！");
   console.log("准备读取文件：");
   fs.read(fd, buf, 0, buf.length, 0, function(err, bytes){
      if (err){
         console.log(err);
      }
      console.log(bytes + "  字节被读取");
      
      // 仅输出读取的字节
      if(bytes > 0){
         console.log(buf.slice(0, bytes).toString());
      }
   });
});

El resultado de ejecutar el código anterior es el siguiente:

$ node file.js 
准备打开已存在的文件！
文件打开成功！
准备读取文件：
42  字节被读取
菜鸟教程官网地址：www.runoob.com

Sintaxis

La siguiente es la sintaxis para cerrar archivos en modo asíncrono:

fs.close(fd, callback)

Este método utiliza un descriptor de archivo para leer el archivo.

Parámetros

La descripción del uso de los parámetros es la siguiente:

  • fd- El descriptor de archivo devuelto por el método fs.open().

  • callback- La función de devolución de llamada, sin parámetros.

Ejemplo

El contenido del archivo input.txt es:

Truncar un archivo

Sintaxis

La siguiente es la sintaxis para truncar archivos en modo asíncrono:

fs.ftruncate(fd, len, callback)

Este método utiliza un descriptor de archivo para leer el archivo.

Parámetros

La descripción del uso de los parámetros es la siguiente:

  • fd- El descriptor de archivo devuelto por el método fs.open().

  • len- La longitud del truncado del contenido del archivo.

  • callback- La función de devolución de llamada, sin parámetros.

Ejemplo

El contenido del archivo input.txt es:

site:www.runoob.com

A continuación, creamos el archivo file.js, el código es el siguiente:

var fs = require("fs");

console.log("准备打开文件！");
fs.open('input.txt', 'r+', function(err, fd) {
   if (err) {
       return console.error(err);
   }
   console.log("文件打开成功！");

      if (err){
         console.log(err);
      } 
      console.log("文件截取成功。");
      console.log("读取相同的文件");

            console.log(err);
         }

         // 仅输出读取的字节
         if(bytes > 0){
            console.log(buf.slice(0, bytes).toString());
         }

         // 关闭文件
         fs.close(fd, function(err){
            if (err){
               console.log(err);
            } 
            console.log("文件关闭成功！");
         });
      });
   });
});

Crear un directorio

Sintaxis

La siguiente es la sintaxis para crear directorios:

fs.mkdir(path[, options], callback)

Parámetros

La descripción del uso de los parámetros es la siguiente:

  • path- La ruta del archivo.

  • El parámetro options puede ser:

    • recursive - Si se crea el directorio de forma recursiva, el valor predeterminado es false.
    • mode- Establece los permisos del directorio, el valor predeterminado es 0777.

  • callback- La función de devolución de llamada, sin parámetros.

Ejemplo

A continuación, creamos el archivo file.js, el código es el siguiente:

var fs = require("fs");
// tmp 目录必须存在
console.log("创建目录 /tmp/test/");
fs.mkdir("/tmp/test/",function(err){
   if (err) {
       return console.error(err);
   }
   console.log("目录创建成功。");
});

El resultado de ejecutar el código anterior es el siguiente:

$ node file.js 
创建目录 /tmp/test/
目录创建成功。

Se puede agregar el parámetro recursive: true, sin importar si los directorios /tmp y /tmp/a existen o no:

fs.mkdir('/tmp/a/apple', { recursive: true }, (err) => {
  if (err) throw err;
});

fs.readdir(path, callback)

var fs = require("fs");

A continuación, creamos el archivo file.js, el código es el siguiente:

var fs = require("fs");
// 执行前创建一个空的 /tmp/test 目录
console.log("准备删除目录 /tmp/test");
fs.rmdir("/tmp/test",function(err){
   if (err) {
       return console.error(err);
   }
   console.log("读取 /tmp 目录");
   fs.readdir("/tmp/",function(err, files){
      if (err) {
          return console.error(err);
      }
      files.forEach( function (file){
          console.log( file );
      });
   });
});

$ node file.js
