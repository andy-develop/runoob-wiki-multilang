Python3 Tuplas

Las tuplas de Python son similares a las listas, la diferencia es que los elementos de una tupla no se pueden modificar.

Las tuplas usan paréntesis( ), las listas usan corchetes[ ]。

Crear una tupla es muy sencillo, solo hay que añadir elementos entre paréntesis y separarlos con comas.

Ejemplo (Python 3.0+)

>>> tup1 = ('Google', 'Runoob', 1997, 2000)
>>> tup2 = (1, 2, 3, 4, 5 )
>>> tup3 = "a", "b", "c", "d"   # No se necesitan paréntesis tampoco
>>> type(tup3)
<class 'tuple'>

Crear una tupla vacía

tup1 = ()

Cuando una tupla contiene solo un elemento, se debe añadir una coma después del elemento,, de lo contrario los paréntesis se tratarán como operadores:

Ejemplo (Python 3.0+)

>>> tup1 = (50)
>>> type(tup1)     # Sin coma, el tipo es entero
<class 'int'>

>>> tup1 = (50,)
>>> type(tup1)     # Con coma, el tipo es tupla
<class 'tuple'>

Las tuplas son similares a las cadenas; el índice comienza en 0, y se pueden segmentar, combinar, etc.

Acceder a tuplas

Se pueden usar índices para acceder a los valores de una tupla, como en el siguiente ejemplo:

Ejemplo (Python 3.0+)

#!/usr/bin/python3 tup1 = ('Google', 'Runoob', 1997, 2000) tup2 = (1, 2, 3, 4, 5, 6, 7 ) print ("tup1[0]: ", tup1[0]) print ("tup2[1:5]: ", tup2[1:5])

El resultado del ejemplo anterior es:

tup1[0]:  Google
tup2[1:5]:  (2, 3, 4, 5)

Modificar tuplas

Los valores de los elementos de una tupla no se pueden modificar, pero podemos concatenar y combinar tuplas, como en el siguiente ejemplo:

Ejemplo (Python 3.0+)

#!/usr/bin/python3 tup1 = (12, 34.56) tup2 = ('abc', 'xyz') # La siguiente operación de modificación de elementos de una tupla es ilegal. # tup1[0] = 100 # Crear una nueva tupla tup3 = tup1 + tup2 print (tup3)

El resultado del ejemplo anterior es:

(12, 34.56, 'abc', 'xyz')

Eliminar tuplas

Los valores de los elementos de una tupla no se pueden eliminar, pero podemos usar la instrucción del para eliminar toda la tupla, como en el siguiente ejemplo:

Ejemplo (Python 3.0+)

#!/usr/bin/python3 tup = ('Google', 'Runoob', 1997, 2000) print (tup) del tup print ("La tupla tup después de eliminarla:") print (tup)

Después de eliminar la tupla en el ejemplo anterior, la variable de salida mostrará un mensaje de error, como se muestra a continuación:

删除后的元组 tup : 
Traceback (most recent call last):
  File "test.py", line 8, in <module>
    print (tup)
NameError: name 'tup' is not defined

Indexación y segmentación de tuplas

Como una tupla también es una secuencia, podemos acceder a elementos en posiciones específicas de la tupla, y también segmentar un rango de elementos según el índice, como se muestra a continuación:

Tupla:

tup = ('Google', 'Runoob', 'Taobao', 'Wiki', 'Weibo','Weixin')

Expresión de PythonResultadoDescripción
tup[1]'Runoob'Lee el segundo elemento
tup[-2]'Weibo'Lectura inversa, lee el penúltimo elemento
tup[1:]('Runoob', 'Taobao', 'Wiki', 'Weibo', 'Weixin')Segmenta los elementos, desde el segundo en adelante.
tup[1:4]('Runoob', 'Taobao', 'Wiki')Segmenta los elementos, desde el segundo hasta el cuarto elemento (índice 3).

A continuación se muestra un ejemplo en ejecución:

Ejemplo

>>> tup = ('Google', 'Runoob', 'Taobao', 'Wiki', 'Weibo','Weixin')
>>> tup[1]
'Runoob'
>>> tup[-2]
'Weibo'
>>> tup[1:]
('Runoob', 'Taobao', 'Wiki', 'Weibo', 'Weixin')
>>> tup[1:4]
('Runoob', 'Taobao', 'Wiki')
>>>

Acerca de que las tuplas son inmutables

La inmutabilidad de una tupla se refiere a que el contenido de la memoria a la que apunta la tupla no se puede cambiar.

>>> tup = ('r', 'u', 'n', 'o', 'o', 'b')
>>> tup[0] = 'g'     # No se permite modificar elementos
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
>>> id(tup)     # Ver la dirección de memoria
4440687904
>>> tup = (1,2,3)
>>> id(tup)
4441088800    # La dirección de memoria es diferente

En el ejemplo anterior se puede ver que la tupla tup, al ser reasignada, se vincula a un nuevo objeto, no se modifica el objeto original.

    tuple y list son muy similares, pero una vez que tuple se inicializa no se puede modificar; por ejemplo, al listar los nombres de los compañeros de clase:

    El código es el siguiente:

    >>> classmates = ('Michael', 'Bob', 'Tracy')

    Ahora, la tupla classmates no puede cambiar, y tampoco tiene métodos como append() e insert(). Los otros métodos para obtener elementos son iguales que en list; puedes usar classmates

    El código es el siguiente:

    >>> t = (1, 2)
>>> t
(1, 2)

    Si quieres definir una tupla vacía, puedes escribir () así:

    El código es el siguiente:

    >>> t = ()
>>> t
()

    Pero, para definir una tupla con solo 1 elemento, si la defines así:

    El código es el siguiente:

    >>> t = (1)
>>> t
1

    Lo que se define no es una tuple, ¡sino el número 1! Esto se debe a que los paréntesis () pueden representar tanto una tuple como los paréntesis de una fórmula matemática, lo que genera ambigüedad. Por lo tanto, Python establece que, en este caso, se calcula como paréntesis, y el resultado naturalmente es 1.

    Por lo tanto, al definir una tuple con solo 1 elemento, se debe añadir una coma,para eliminar la ambigüedad:

    El código es el siguiente:

    >>> t = (1,)
>>> t
(1,)

    Python, al mostrar una tuple con solo 1 elemento, también añade una coma, para que no la confundas con paréntesis en el sentido matemático.

    Veamos ahora una tuple "mutable":

    El código es el siguiente:

    >>> t = ('a', 'b', ['A', 'B'])
>>> t[2][0] = 'X'
>>> t[2][1] = 'Y'
>>> t
('a', 'b', ['X', 'Y'])

    Esta tuple se definió con 3 elementos: 'a', 'b' y una list. ¿No se decía que una tuple era inmutable una vez definida? ¿Cómo es que luego cambió?

    No te preocupes, primero veamos los 3 elementos que contenía la tuple al definirla: cuando modificamos los elementos 'A' y 'B' de la list a 'X' e 'Y', la tuple se convierte en: en apariencia, los elementos de la tuple realmente han cambiado, pero en realidad no cambiaron los elementos de la tuple, sino los elementos de la list. La list a la que apuntaba la tuple al principio no se cambió por otra list, por lo que la llamada "inmutabilidad" de tuple significa que cada elemento de la tuple apunta siempre al mismo lugar. Es decir, si apunta a 'a', no se puede cambiar para que apunte a 'b'; si apunta a una list, no se puede cambiar para que apunte a otro objeto, ¡pero la list a la que apunta en sí misma es mutable! Una vez entendido que "el apuntamiento no cambia", ¿cómo se crea una tuple cuyo contenido tampoco cambie? Entonces hay que asegurarse de que cada elemento de la tuple tampoco pueda cambiar.

    La versión mejorada de las tuplas de Python -- namedtuple (tupla con nombre)

    Debido a las limitaciones de las tuplas: no se pueden nombrar los datos internos de la tupla, por lo que a menudo no sabemos qué significado quiere expresar una tupla. Así que aquí se introducecollections.namedtupleesta función de fábrica, para construir una tupla con nombres de campos. Las instancias de una tupla con nombre consumen la misma memoria que una tupla normal, porque los nombres de los campos se almacenan en la clase correspondiente. Esta clase también es más pequeña que una instancia de objeto común, porque Python no usa __dict__ para almacenar los atributos de estas instancias.

    La definición de un objeto namedtuple tiene el siguiente formato:

    collections.namedtuple(typename, field_names, verbose=False, rename=False)

    Devuelve una subclase de tupla con nombre typename, donde el significado de los parámetros es el siguiente:

    • typename: nombre de la tupla
    • field_names: nombre de los elementos de la tupla
    • rename: si los nombres de los elementos contienen palabras clave de Python, se debe establecer rename=True
    • verbose: con el valor predeterminado está bien

    A continuación veamos cómo declarar una tupla con nombre y cómo instanciarla:

    import collections

# 两种方法来给 namedtuple 定义方法名
#User = collections.namedtuple('User', ['name', 'age', 'id'])
User = collections.namedtuple('User', 'name age id')
user = User('tester', '22', '464643123')

print(user)

    collections.namedtuple('User', 'name age id')Para crear una tupla con nombre se necesitan dos parámetros: uno es el nombre de la clase y el otro son los nombres de los campos de la clase. Este último puede ser un objeto iterable compuesto por varias cadenas, o una cadena de nombres de campo separados por espacios (como en este ejemplo). La información de un campo se puede obtener mediante el nombre del campo o mediante la posición.

    Resultado de salida:

    User(name='tester', age='22', id='464643123')

    Atributos específicos de la tupla con nombre:

    Atributo de clase_fields: una tupla que contiene todos los nombres de campo de esta clase Método de clase_make(iterable): acepta un objeto iterable para crear una instancia de esta clase Método de instancia_asdict(): devuelve la tupla con nombre en forma de collections.OrdereDict, que se puede utilizar para mostrar de forma amigable la información de la tupla

# 将User对象转换成字典，注意要使用"_asdict"

# OrderedDict([('name', 'Runoob'), ('sex', 'male'), ('age', 22)])

    La premisa de que las tuplas son inmutables es que la tupla solo puede contener elementos simples, por ejemplo: cadenas, números, etc.

    Pero cuando la tupla contiene una lista, el contenido de la lista dentro de la tupla se puede modificar, y el id de la tupla no cambia.

    Esto significa que el contenido de la tupla es variable; por supuesto, lo que en realidad se modifica es el valor de la lista.

    T = ('google', [0, 1, 2, 3, 4])
print(id(T), T)
T[1][0] = 99
print(id(T), T)

    3212880643136 ('google', [0, 1, 2, 3, 4])

    Empaquetado y desempaquetado de tuplas

    En Python, el empaquetado y desempaquetado de tuplas es automático, no requiere ninguna función, lo que causa que muchas personas se confundan con los valores de retorno de las funciones, a veces con paréntesis y a veces sin paréntesis.

    Primero veamos el código:

    a=1,2,3
#它其实等价于下面的代码
a=(1,2,3)
#因为等号左边只有1个变量，而等号右边有3个值，因此自动装包成为一个元组

    Luego veamos el siguiente código:

    a,b,c=(1,2,3)
#自动拆包，得到a=1,b=2,c=3

    Cuando una función utiliza return, en realidad solo puede devolver un valor, no puede devolver múltiples valores.

    Algunos preguntarán: devolví múltiples valores y no se produjo ningún error, funciona muy bien.

    Eso es precisamente porque Python empaqueta automáticamente los múltiples valores de retorno.

    Por lo tanto, cuando devuelves múltiples variables y afuera solo usas una variable para recibirlas, recibirás una tupla.

    Y cuando usas múltiples variables para recibir, puedes recibir cada valor de manera correspondiente, debido al desempaquetado automático.

    Entender este punto es útil para comprender los valores de retorno de funciones, los pares clave-valor en diccionarios, etc.

    =========================================================

    Para reforzar la comprensión, veamos el último grupo de código:

    a=10
b=20
a,b=b,a,1

    Al ejecutarlo se producirá un error:too many values to unpack

    Aquí es obvio que te dice que hay 3 valores en la tupla que necesitan desempaquetarse, pero solo usas 2 valores para recibirlos, lo que demuestra que la tupla realmente realizó una acción de desempaquetado.
