Python3 Operadores

¿Qué es un operador?

Este capítulo explica principalmente los operadores de Python.

Pon un ejemplo sencillo:

4 + 5 = 9

En el ejemplo,4 和 5se llamaoperando，+se llamaoperador。

El lenguaje Python admite los siguientes tipos de operadores:

  • Operadores aritméticos
  • Operadores de comparación (relacionales)
  • Operadores de asignación
  • Operadores lógicos
  • Operadores de bits
  • Operadores de pertenencia
  • Operadores de identidad
  • Precedencia de operadores

A continuación, aprendamos uno por uno los operadores de Python.

En Python 3.8 y versiones posteriores, se introdujo una nueva característica de sintaxis llamada "operador morsa" (Walrus Operator), que usa:=símbolo. El propósito principal de este operador es realizar una asignación y devolver el valor asignado al mismo tiempo en una expresión.

Usar el operador morsa puede simplificar el código en algunos casos, especialmente cuando se necesita utilizar el resultado de una asignación dentro de una expresión. Esto es útil para simplificar las condiciones de bucle o los cálculos repetidos en expresiones.

A continuación se muestra un ejemplo sencillo que demuestra el uso del operador morsa:

Ejemplo

# Escritura tradicional
n = 10
if n > 5:
    print(n)

# Usando el operador morsa
if (n := 10) > 5:
    print(n)
  • if (n := 10) > 5:: Esto es usando el operador morsa (:=). El operador morsa realiza una asignación dentro de una expresión.
    • (n := 10): Asigna la variablenasignándola a 10, y devuelve el resultado de esta asignación.
    • > 5: Comprueba si después de la asignaciónnes mayor que 5. Si la condición es verdadera, se ejecuta el siguiente bloque de código.
  • print(n): Si la condición es verdadera, imprime el valor de la variablen(es decir, 10).

Ventajas del operador morsa:

  • El operador morsa (:=) permite realizar asignaciones dentro de expresiones, lo que puede reducir la repetición de código y mejorar la legibilidad y concisión del código.
  • En el ejemplo anterior, la escritura tradicional necesita una línea separada para asignarn, y luegoifrealizar la comprobación de la condición en la sentencia. Sin embargo, la escritura con el operador morsa puedeifrealizar la asignación y la comprobación de la condición directamente en la sentencia.

Operadores de bits de Python

Los operadores de bits tratan los números como binarios para realizar cálculos. Las reglas de las operaciones de bits en Python son las siguientes:

En la siguiente tabla, la variable a es 60 y b es 13. El formato binario es el siguiente:

a = 0011 1100

b = 0000 1101

-----------------

a&b = 0000 1100

a|b = 0011 1101

a^b = 0011 0001

~a  = 1100 0011
OperadorDescripciónEjemplo
&Operador Y bit a bit: de los dos valores que participan en la operación, si los dos bits correspondientes son 1, el resultado de ese bit es 1; de lo contrario, es 0.(a & b) da como resultado 12, explicación binaria: 0000 1100
|Operador O bit a bit: si al menos uno de los dos bits correspondientes es 1, el bit de resultado es 1.(a | b) da como resultado 61, explicación binaria: 0011 1101
^Operador O exclusivo (XOR) bit a bit: cuando los dos bits correspondientes son diferentes, el resultado es 1.(a ^ b) da como resultado 49, explicación binaria: 0011 0001
~Operador de complemento bit a bit: invierte cada bit binario de los datos, es decir, convierte 1 en 0 y 0 en 1.~x, similar-x-1 (~a) da como resultado -61, explicación binaria: 1100 0011, en forma de complemento a dos de un número binario con signo.
<<Operador de desplazamiento a la izquierda: desplaza todos los bits binarios del operando a la izquierda un cierto número de posiciones; el número a la derecha de "<<" especifica la cantidad de posiciones a desplazar, se descartan los bits altos y se rellenan con 0 los bits bajos.a << 2 da como resultado 240, explicación binaria: 1111 0000
>>Operador de desplazamiento a la derecha: desplaza todos los bits binarios del operando a la izquierda de ">>" a la derecha un cierto número de posiciones; el número a la derecha de ">>" especifica la cantidad de posiciones a desplazar.a >> 2 da como resultado 15, explicación binaria: 0000 1111

El siguiente ejemplo demuestra las operaciones de todos los operadores bit a bit de Python:

Ejemplo (Python 3.0+)

#!/usr/bin/python3 a = 60 # 60 = 0011 1100 b = 13 # 13 = 0000 1101 c = 0 c = a & b # 12 = 0000 1100 print ("1 - el valor de c es:", c) c = a | b # 61 = 0011 1101 print ("2 - el valor de c es:", c) c = a ^ b # 49 = 0011 0001 print ("3 - el valor de c es:", c) c = ~a # -61 = 1100 0011 print ("4 - el valor de c es:", c) c = a << 2 # 240 = 1111 0000 print ("5 - el valor de c es:", c) c = a >> 2 # 15 = 0000 1111 print ("6 - el valor de c es:", c)

El resultado del ejemplo anterior es:

1 - c 的值为： 12
2 - c 的值为： 61
3 - c 的值为： 49
4 - c 的值为： -61
5 - c 的值为： 240
6 - c 的值为： 15

OperadorExpresión lógicaDescripciónEjemplo

orx or y"O" booleano: si x es True, devuelve el valor de x; de lo contrario, devuelve el valor calculado de y.(a or b) devuelve 10.

Ejemplo (Python 3.0+)

#!/usr/bin/python3 a = 10 b = 20 if ( a and b ): print ("1 - las variables a y b son ambas True") else: print ("1 - al menos una de las variables a y b no es True") if ( a or b ): print ("2 - las variables a y b son ambas True, o una de ellas es True") else: print ("2 - ninguna de las variables a y b es True") # modificar el valor de la variable a a = 0 if ( a and b ): print ("3 - las variables a y b son ambas True") else: print ("3 - al menos una de las variables a y b no es True") if ( a or b ): print ("4 - las variables a y b son ambas True, o una de ellas es True") else: print ("4 - ninguna de las variables a y b es True") if not( a and b ): print ("5 - las variables a y b son ambas False, o una de ellas es False") else: print ("5 - las variables a y b son ambas True")

5 - 变量 a 和 b 都为 false，或其中一个变量为 false

OperadorDescripciónEjemplo

not inDevuelve True si no se encuentra el valor en la secuencia especificada; de lo contrario, devuelve False. x no está en la secuencia y: si x no está en la secuencia y, devuelve True.

Operadores de identidad de Python

Los operadores de identidad se utilizan para comparar las unidades de almacenamiento de dos objetos.

OperadorDescripciónEjemplo

is notis not se utiliza para determinar si dos identificadores hacen referencia a objetos diferentes. x is not y, similarid(x) != id(y). Si no hacen referencia al mismo objeto, devuelve True; de lo contrario, devuelve False.

Diferencia entre is y ==:

is se utiliza para determinar si los objetos referenciados por dos variables son el mismo; == se utiliza para determinar si los valores de las variables referenciadas son iguales.

>>>a = [1, 2, 3] >>> b = a >>> b is a True >>> b == a True >>> b = a[:] >>> b is a False >>> b == a True

Esto también demuestra que una variable en Python puede ser accedida por varios nombres.

    Esta lógica de diseño determina que los valores numéricos en Python sean inmutables, porque si, como en el ejemplo anterior, a y b son ambos 5, cuando cambias a, b también cambiaría; eso, por supuesto, no es lo que queremos.

    Por lo tanto, la operación de incremento correcta debería ser a = a + 1 o a += 1. Cuando esta a se incrementa, al observar con id() se nota que el valor de id ha cambiado, es decir, a ya es el nombre del nuevo valor.
