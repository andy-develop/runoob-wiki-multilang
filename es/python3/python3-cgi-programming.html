Programación CGI en Python

Qué es CGI

CGI actualmente es mantenido por NCSA, que define CGI de la siguiente manera:

CGI (Common Gateway Interface), interfaz de puerta de enlace común, es un programa que se ejecuta en un servidor, como un servidor HTTP, y proporciona una interfaz con las páginas HTML del cliente.

Navegación web

Para comprender mejor cómo funciona CGI, podemos partir del flujo al hacer clic en un enlace o URL en una página web:

  • 1. Usa tu navegador para acceder a la URL y conectarte al servidor web HTTP.
  • 2. El servidor web, tras recibir la solicitud, analiza la URL y verifica si el archivo solicitado existe en el servidor. Si existe, devuelve el contenido del archivo; si no, devuelve el mensaje de error correspondiente.
  • 3. El navegador recibe la información del servidor y muestra el archivo recibido o el mensaje de error.

Un programa CGI puede ser un script de Python, un script de PERL, un script de SHELL, un programa en C o C++, etc.

Diagrama de arquitectura CGI

Soporte y configuración del servidor web

Antes de realizar programación CGI, asegúrate de que tu servidor web soporte CGI y de que ya esté configurado el manejador de CGI.

Configuración de soporte CGI en Apache:

Configura el directorio CGI:

ScriptAlias /cgi-bin/ /var/www/cgi-bin/

Todos los programas CGI que ejecutan los servidores HTTP se guardan en un directorio preconfigurado. Este directorio se llama directorio CGI y, por convención, se denomina /var/www/cgi-bin.

La extensión de los archivos CGI es .cgi, aunque Python también puede usar la extensión .py.

Por defecto, el directorio cgi-bin configurado en el servidor Linux es /var/www.

Si deseas especificar otro directorio para ejecutar scripts CGI, puedes modificar el archivo de configuración httpd.conf, como se muestra a continuación:

<Directory "/var/www/cgi-bin">
   AllowOverride None
   Options +ExecCGI
   Order allow,deny
   Allow from all
</Directory>

Añade la extensión .py en AddHandler, de esta manera podremos acceder a los archivos de script de Python que terminan en .py:

AddHandler cgi-script .cgi .pl .py

Creamos el primer programa CGI con Python, el archivo se llama hello.py, está ubicado en el directorio /var/www/cgi-bin, y su contenido es el siguiente:

Cabeceras HTTP

El "Content-type:text/html" en el contenido del archivo hello.py es parte de la cabecera HTTP; se envía al navegador para indicarle el tipo de contenido del archivo.

El formato de la cabecera HTTP es el siguiente:

HTTP 字段名: 字段内容

Por ejemplo:

Content-type: text/html

La siguiente tabla describe la información que se usa frecuentemente en las cabeceras HTTP en programas CGI:

头Descripción
Content-type: Información MIME correspondiente al cuerpo de la solicitud. Por ejemplo: Content-type:text/html
Expires: Date Fecha y hora de caducidad de la respuesta
Location: URL Se utiliza para redirigir al receptor a una URL distinta de la solicitada para completar la solicitud o identificar un nuevo recurso
Last-modified: DateFecha y hora de la última modificación del recurso solicitado
Content-length: NLongitud del contenido de la solicitud
Set-Cookie: String Configurar cookie HTTP

CONTENT_LENGTHCuando el servidor se comunica con el programa CGI mediante el método POST, esta variable de entorno indica el número de bytes de datos válidos que se pueden leer desde la entrada estándar (STDIN); es necesario usar esta variable al leer los datos de entrada.
HTTP_COOKIEContenido de las COOKIES en el cliente.
HTTP_USER_AGENTProporciona información del navegador del cliente, incluido el número de versión u otros datos propietarios.

REMOTE_ADDREl valor de esta variable de entorno es la dirección IP del cliente que envía la solicitud, por ejemplo, 192.168.1.67. Este valor siempre está presente. Métodos GET y POST

El navegador cliente transmite información al servidor mediante dos métodos: el método GET y el método POST.

Transferencia de datos usando el método GET

El método GET envía la información del usuario codificada al servidor; los datos se incluyen en la URL de la página solicitada, separados por el signo '?', como se muestra a continuación:

http://www.test.com/cgi-bin/hello.py?key1=value1&key2=value2
Otras notas sobre las solicitudes GET:
  • Las solicitudes GET pueden almacenarse en caché
  • Las solicitudes GET se conservan en el historial del navegador
  • Las solicitudes GET se pueden guardar como marcadores
  • Las solicitudes GET no deben usarse al manejar datos sensibles
  • Las solicitudes GET tienen limitación de longitud
  • Las solicitudes GET solo deben usarse para recuperar datos

Uso de cookies en CGI

Una gran desventaja del protocolo HTTP es que no juzga la identidad del usuario, lo que causa grandes inconvenientes a los programadores. La aparición de la función de cookie ha compensado esta deficiencia.

Una cookie consiste en escribir datos de registro en el disco duro del cliente a través del navegador del cliente mientras este accede al script. Cuando el cliente accede al script la próxima vez, se recupera la información de datos, logrando así la función de identificación. Las cookies se usan comúnmente en la verificación de identidad.

　

Sintaxis de las cookies

El envío de cookies HTTP se implementa a través de la cabecera HTTP, que precede a la transferencia del archivo. La sintaxis de la cabecera Set-Cookie es la siguiente:

Set-cookie:name=name;expires=date;path=path;domain=domain;secure
  • name=name:El valor de la cookie que se debe establecer (el nombre no puede usar ";y,signo), cuando hay varios valores de nombre, use ";para separarlos, por ejemplo:name1=name1;name2=name2;name3=name3。
  • expires=date:Período de validez de la cookie, formato: expires="Wdy,DD-Mon-YYYY HH:MM:SS"
  • path=path: La ruta admitida por la cookie. Si path es una ruta, la cookie es efectiva para todos los archivos y subdirectorios de este directorio, por ejemplo: path="/cgi-bin/". Si path es un archivo, la cookie solo es efectiva para este archivo, por ejemplo: path="/cgi-bin/cookie.cgi".
  • domain=domain:El dominio para el cual la cookie es efectiva, por ejemplo: domain="www.runoob.com"
  • secure:Si se da esta marca, indica que la cookie solo se puede transferir a través de un servidor https con protocolo SSL.
  • La recepción de cookies se implementa mediante la variable de entorno HTTP_COOKIE. El programa CGI puede obtener la información de la cookie consultando esta variable.

Configuración de cookies

La configuración de Cookie es muy simple. La cookie se envía por separado en la cabecera HTTP. El siguiente ejemplo establece name y expires en la cookie:

Ejemplo

#!/usr/bin/python3

print ('Set-Cookie: name="Tutorial de Novato";expires=Wed, 28 Aug 2016 18:30:00 GMT')
print ('Content-Type: text/html')

print ()
print ("""
<html>
  <head>
    <meta charset="utf-8">
<title>Tutorial de Novato (runoob.com)</title>
  </head>
    <body>
        <h1>Cookie set OK!</h1>
    </body>
</html>
""")

Recuperar información de cookies

La página de recuperación de información de Cookie es muy simple. La información de Cookie se almacena en la variable de entorno HTTP_COOKIE del CGI. El formato de almacenamiento es el siguiente:

key1=value1;key2=value2;key3=value3....

A continuación hay un programa CGI simple para recuperar información de cookie:

Ejemplo

#!/usr/bin/python3

# Importar módulo
import os
import http.cookies

print ("Content-type: text/html")
print ()

print ("""
<html>
<head>
<meta charset="utf-8">
<title>Tutorial para novatos (runoob.com)</title>
</head>
<body>
<h1>Leer información de cookie</h1>
""")

if 'HTTP_COOKIE' in os.environ:
    cookie_string=os.environ.get('HTTP_COOKIE')
    c= http.cookies.SimpleCookie()
   # c=Cookie.SimpleCookie()
    c.load(cookie_string)

    try:
        data=c['name'].value
        print ("cookie data: "+data+"<br>")
    except KeyError:
        print ("La cookie no está configurada o ha expirado<br>")
print ("""
</body>
</html>
""")

#!/usr/bin/python3

import cgi, os
import cgitb; cgitb.enable()

form = cgi.FieldStorage()

# Obtener el nombre del archivo
fileitem = form['filename']

# Verificar si el archivo se ha subido
if fileitem.filename:
   # Establecer la ruta del archivo
   fn = os.path.basename(fileitem.filename)
   open('/tmp/' + fn, 'wb').write(fileitem.file.read())

   message = 'Archivo "' + fn + '" subido correctamente'
   
else:
   message = 'El archivo no se ha subido'
   
print ("""\
