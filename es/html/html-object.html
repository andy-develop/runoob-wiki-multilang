HTML Plugins

La función de los plugins es ampliar las funciones del navegador HTML.

Asistentes HTML (plugins)

Una aplicación auxiliar (helper application) es un programa que puede ser iniciado por el navegador. Las aplicaciones auxiliares también se denominan plugins.

Las aplicaciones auxiliares se pueden utilizar para reproducir audio y video (entre otros). Las aplicaciones auxiliares se cargan mediante la etiqueta <object>.

Una ventaja de usar aplicaciones auxiliares para reproducir video y audio es que puedes permitir que el usuario controle parte o todos los ajustes de reproducción.

Los plugins se pueden añadir a la página mediante la etiqueta <object> o la etiqueta <embed>.

La mayoría de las aplicaciones auxiliares permiten el control manual (o programático) de los ajustes de volumen y las funciones de reproducción (como retroceder, pausar, detener y reproducir).

Nota:

La mayoría de los navegadores ya no soportan los applets de Java ni los plugins.

La mayoría de los navegadores modernos han desactivado el soporte de Flash.

Los siguientes ejemplos de archivos SWF no se ejecutarán correctamente en los navegadores modernos.

Podemos usar las etiquetas <video> y <audio> para mostrar video y audio.

Elemento <object>

Todos los navegadores principales soportan la etiqueta <object>.

El elemento <object> define un objeto incrustado en un documento HTML.

Esta etiqueta se utiliza para insertar objetos (por ejemplo, incrustar applets de Java, lectores de PDF, reproductores de Flash) en una página web.

Ejemplo

<object width="400" height="50" data="bookmark.swf"></object>

Pruébalo »

El elemento <object> también se puede utilizar para incluir archivos HTML:

Ejemplo

<object width="100%" height="500px" data="snippet.html"></object>

Pruébalo »

O insertar una imagen:

Ejemplo

<object data="audi.jpeg"></object>

Pruébalo »

Elemento <embed>

Todos los navegadores principales soportan el elemento <embed>.

El elemento <embed> representa un objeto HTML Embed.

El elemento <embed> ha existido durante bastante tiempo, pero no fue especificado en detalle antes de HTML5. Este elemento se valida en páginas HTML5, pero no en HTML 4.

Ejemplo

<embed width="400" height="50" src="bookmark.swf">

Pruébalo »

Nota: el elemento <embed> no tiene etiqueta de cierre. No se puede usar texto alternativo.

El elemento <embed> también se puede utilizar para incluir archivos HTML:

Ejemplo

<embed width="100%" height="500px" src="snippet.html">

Pruébalo »

O insertar una imagen:

Ejemplo

<embed src="audi.jpeg">

Pruébalo »
