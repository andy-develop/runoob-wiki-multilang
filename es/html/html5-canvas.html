HTML5 Canvas

La etiqueta <canvas> define gráficos, como diagramas y otras imágenes; debe utilizar un script para dibujar los gráficos.

En el lienzo (canvas), dibuje un rectángulo rojo, un rectángulo con degradado, un rectángulo de color y algo de texto en color.

Su navegador no admite el elemento <canvas> de HTML5.

¿Qué es canvas?

El elemento <canvas> de HTML5 se utiliza para dibujar gráficos, lo cual se realiza mediante scripts (normalmente JavaScript).

La etiqueta <canvas> es solo un contenedor de gráficos; usted debe usar scripts para dibujar los gráficos.

Puede usar canvas de diversas maneras para dibujar trazados, cajas, círculos, caracteres y añadir imágenes.

Soporte del navegador

Los números en la tabla indican la primera versión del navegador que admite el elemento <canvas>.

Elemento
<canvas> 4.0 9.0 2.0 3.1 9.0

Crear un lienzo (Canvas)

Un lienzo en una página web es un marco rectangular, dibujado mediante el elemento <canvas>.

Nota:Por defecto, el elemento <canvas> no tiene borde ni contenido.

Un ejemplo sencillo de <canvas> es el siguiente:

<canvas id="myCanvas" width="200" height="100"></canvas>

Nota:La etiqueta generalmente necesita especificar un atributo id (a menudo referenciado en los scripts); los atributos width y height definen el tamaño del lienzo.

Consejo:Puede usar varios elementos <canvas> en una página HTML.

Use el atributo style para añadir un borde:

Ejemplo

<canvas id="myCanvas" width="200" height="100" style="border:1px solid #000000;"> </canvas>

Usar JavaScript para dibujar imágenes

El elemento canvas en sí no tiene capacidad de dibujo. Todo el trabajo de dibujo debe realizarse dentro de JavaScript:

Ejemplo

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); ctx.fillStyle="#FF0000"; ctx.fillRect(0,0,150,75);

Pruébelo »

Explicación del ejemplo:

Primero, encuentre el elemento <canvas>:

var c=document.getElementById("myCanvas");

Luego, cree el objeto context:

var ctx=c.getContext("2d");

El objeto getContext("2d") es un objeto integrado de HTML5 que tiene varios métodos para dibujar rutas, rectángulos, círculos, caracteres y añadir imágenes.

Las siguientes dos líneas de código dibujan un rectángulo rojo:

ctx.fillStyle="#FF0000";
ctx.fillRect(0,0,150,75);

La propiedad fillStyle puede ser un color CSS, un degradado o un patrón. El valor predeterminado de fillStyle es #000000 (negro).

fillRect(x,y,width,height) El método define el modo de relleno actual del rectángulo.

Coordenadas de Canvas

canvas es una cuadrícula bidimensional.

La coordenada de la esquina superior izquierda de canvas es (0,0).

El método fillRect anterior tiene parámetros (0,0,150,75).

Significa: dibujar un rectángulo de 150x75 en el lienzo, comenzando desde la esquina superior izquierda (0,0).

Como se muestra en la siguiente figura, las coordenadas X e Y del lienzo se utilizan para ubicar los dibujos en el lienzo. Al mover el ratón sobre el rectángulo, se muestran las coordenadas de posición.

Canvas - Trazados

Para dibujar líneas en canvas, usaremos los siguientes dos métodos:

  • moveTo(x,y) Define las coordenadas de inicio de la línea.
  • lineTo(x,y) Define las coordenadas de fin de la línea.

Para dibujar líneas debemos usar el método de "tinta", como stroke().

Ejemplo

Defina las coordenadas de inicio (0,0) y las coordenadas de fin (200,100). Luego use el método stroke() para dibujar la línea:

Su navegador no admite el elemento <canvas> de HTML5.

JavaScript:

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); ctx.moveTo(0,0); ctx.lineTo(200,100); ctx.stroke();

Pruébelo »

Para dibujar un círculo en canvas, usaremos el siguiente método:

arc(x,y,r,start,stop)

En realidad, al dibujar un círculo usamos el método de "tinta", como stroke() o fill().

Ejemplo

Use el método arc() para dibujar un círculo:

Su navegador no admite el elemento <canvas> de HTML5.

JavaScript:

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); ctx.beginPath(); ctx.arc(95,50,40,0,2*Math.PI); ctx.stroke();

Canvas - Texto

Las propiedades y métodos importantes para dibujar texto con canvas son los siguientes:

  • font - define la fuente
  • fillText(text,x,y) - Dibuja texto relleno en el canvas.
  • strokeText(text,x,y) - Dibuja texto contorneado en el canvas.

Usar fillText():

Ejemplo

Use la fuente "Arial" para dibujar un texto de 30px de alto (relleno) en el lienzo:

Su navegador no admite el elemento <canvas> de HTML5.

JavaScript:

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); ctx.font="30px Arial"; ctx.fillText("Hello World",10,50);

Usar strokeText():

Ejemplo

Use la fuente "Arial" para dibujar un texto de 30px de alto (contorneado) en el lienzo:

Su navegador no admite el elemento <canvas> de HTML5.

JavaScript:

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); ctx.font="30px Arial"; ctx.strokeText("Hello World",10,50);

Canvas - Degradado

Los degradados pueden rellenar rectángulos, círculos, líneas, texto, etc. Puede definir diferentes colores para varias formas.

A continuación hay dos formas diferentes de establecer degradados en canvas:

  • createLinearGradient(x,y,x1,y1) - Crear un degradado lineal
  • createRadialGradient(x,y,r,x1,y1,r1) - Crear un degradado radial/circular

Cuando usamos un objeto de degradado, debemos usar dos o más colores de parada.

El método addColorStop() especifica las paradas de color; los parámetros se describen mediante coordenadas y pueden ser de 0 a 1.

Para usar un degradado, establezca el valor de fillStyle o strokeStyle al degradado, y luego dibuje una forma, como un rectángulo, texto o una línea.

Usar createLinearGradient():

Ejemplo

Cree un degradado lineal. Rellene el rectángulo con el degradado:

Su navegador no admite el elemento <canvas> de HTML5.

JavaScript:

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); //Crear degradado var grd=ctx.createLinearGradient(0,0,200,0); grd.addColorStop(0,"red"); grd.addColorStop(1,"white"); //Rellenar degradado ctx.fillStyle=grd; ctx.fillRect(10,10,150,80);

Usar createRadialGradient():

var c=document.getElementById("myCanvas"); var ctx=c.getContext("2d"); //Crear degradado var grd=ctx.createRadialGradient(75,50,5,90,60,100); grd.addColorStop(0,"red"); grd.addColorStop(1,"white"); //Rellenar degradado ctx.fillStyle=grd; ctx.fillRect(10,10,150,80);

    Al crear un degradado radialcontext.createRadialGradient(x , y , r , x1 , y1 , r1)El significado de los parámetros entre paréntesis es el siguiente:

    • x: coordenada x del círculo inicial del degradado

    Convertir Canvas a imagen

    Podemos usar la librería Canvas2image para convertir el canvas en una imagen.

    Descarga local:http://static.runoob.com/assets/canvas2image/canvas2image.js。

    Dirección de Github:https://github.com/hongru/canvas2image

    La forma de uso es la siguiente:

    Canvas2Image.saveAsImage(canvasObj, width, height, type)
Canvas2Image.saveAsPNG(canvasObj, width, height)
Canvas2Image.saveAsJPEG(canvasObj, width, height)
Canvas2Image.saveAsGIF(canvasObj, width, height)
Canvas2Image.saveAsBMP(canvasObj, width, height)

Canvas2Image.convertToImage(canvasObj, width, height, type)
Canvas2Image.convertToPNG(canvasObj, width, height)
Canvas2Image.convertToJPEG(canvasObj, width, height)
Canvas2Image.convertToGIF(canvasObj, width, height)
Canvas2Image.convertToBMP(canvasObj, width, height)

    Ejemplo de prueba:

    var canvas, ctx, bMouseIsDown = false, iLastX, iLastY,
$save, $imgs,
$convert, $imgW, $imgH,
$sel;
function init () {
    canvas = document.getElementById('cvs');
    ctx = canvas.getContext('2d');
    $save = document.getElementById('save');
    $convert = document.getElementById('convert');
    $sel = document.getElementById('sel');
    $imgs = document.getElementById('imgs');
    $imgW = document.getElementById('imgW');
    $imgH = document.getElementById('imgH');
    bind();
    draw();
}
function bind () {
    canvas.onmousedown = function(e) {
        bMouseIsDown = true;
        iLastX = e.clientX - canvas.offsetLeft + (window.pageXOffset||document.body.scrollLeft||document.documentElement.scrollLeft);
        iLastY = e.clientY - canvas.offsetTop + (window.pageYOffset||document.body.scrollTop||document.documentElement.scrollTop);
    }
    canvas.onmouseup = function() {
        bMouseIsDown = false;
        iLastX = -1;
        iLastY = -1;
    }
    canvas.onmousemove = function(e) {
        if (bMouseIsDown) {
            var iX = e.clientX - canvas.offsetLeft + (window.pageXOffset||document.body.scrollLeft||document.documentElement.scrollLeft);
            var iY = e.clientY - canvas.offsetTop + (window.pageYOffset||document.body.scrollTop||document.documentElement.scrollTop);
            ctx.moveTo(iLastX, iLastY);
            ctx.lineTo(iX, iY);
            ctx.stroke();
            iLastX = iX;
            iLastY = iY;
        }
    };
    
    $save.onclick = function (e) {
        var type = $sel.value,
            w = $imgW.value,
            h = $imgH.value;
        Canvas2Image.saveAsImage(canvas, w, h, type);
    }
    $convert.onclick = function (e) {
        var type = $sel.value,
            w = $imgW.value,
            h = $imgH.value;
        $imgs.appendChild(Canvas2Image.convertToImage(canvas, w, h, type))
    }
    
}
function draw () {
    ctx.fillStyle = '#ffffff';
    ctx.fillRect(0, 0, 600, 400);
    ctx.fillStyle = 'red';
    ctx.fillRect(100, 100, 50, 50);
}
