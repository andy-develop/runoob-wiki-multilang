Node.jsTutorial

En pocas palabras, Node.js es JavaScript que se ejecuta en el servidor.

Node.js es una plataforma construida sobre el runtime de JavaScript de Chrome.

Node.js es un entorno de JavaScript del lado del servidor con E/S impulsada por eventos, basado en el motor V8 de Google. El motor V8 ejecuta JavaScript muy rápido y tiene un excelente rendimiento.

¿Quién debería leer este tutorial?

Si eres un programador frontend, no conoces lenguajes de programación dinámicos como PHP, Python o Ruby, y quieres crear tu propio servicio, Node.js es una muy buena opción.

Node.js es JavaScript que se ejecuta en el servidor. Si estás familiarizado con JavaScript, te resultará muy fácil aprender Node.js.

Por supuesto, si eres programador backend y quieres implementar servicios de alto rendimiento, aprender Node.js también es una muy buena opción.

Lo que necesitas saber antes de seguir este tutorial

Antes de continuar con este tutorial, deberías conocer algunos términos básicos de programación informática. Si has estudiado lenguajes de programación como JavaScript, PHP, Java, etc., te ayudará a comprender la programación en Node.js más rápidamente.

Características de Node.js

  • Arquitectura de un solo hilo y controlada por eventos: Node.js utiliza un solo hilo para manejar las solicitudes, pero gracias a las características de control por eventos y operaciones de E/S no bloqueantes, puede manejar eficientemente una gran cantidad de conexiones concurrentes sin bloquear el hilo.
  • E/S asíncrona y no bloqueante: Esto permite que Node.js maneje solicitudes de alta concurrencia, siendo muy adecuado para aplicaciones intensivas en E/S, como lectura de archivos, operaciones de base de datos y solicitudes de red.
  • Soporte multiplataforma: Node.js puede ejecutarse en múltiples sistemas operativos como Windows, Linux y macOS.
  • Gran ecosistema: Node.js tiene un ecosistema llamado npm (Node Package Manager), que cuenta con una gran variedad de bibliotecas y módulos de terceros que se pueden usar para ampliar funciones y acelerar el desarrollo.

Casos de uso de Node.js

  • Servidor web: Debido a su capacidad para manejar solicitudes concurrentes de manera eficiente, Node.js se utiliza a menudo para construir servidores web rápidos y escalables.
  • Aplicaciones en tiempo real: Por ejemplo, aplicaciones de chat, herramientas de colaboración en tiempo real, etc.
  • Servicios API: Node.js es muy adecuado para desarrollar API RESTful y servicios GraphQL.
  • Herramientas de línea de comandos: Node.js también se puede utilizar para construir herramientas CLI, aprovechando sus bibliotecas fáciles de usar y su gestor de paquetes para un desarrollo rápido.

Versión utilizada

Podemos usar el siguiente comando para ver la versión actual de Node:

$ node -v
v4.4.3

Nota:Puede haber diferencias entre las distintas versiones.

Primer programa Node.js: ¡Hola Mundo!

Modo script

A continuación se muestra nuestro primer programa Node.js:

Ejemplo

console.log("Hello World");

Ejecutar ejemplo »

Guarda el archivo con el nombre helloworld.js y ejecútalo con el comando node:

node helloworld.js

Después de ejecutar el programa, si todo es normal, se mostrará 'Hello World' en la terminal.

Modo interactivo

Abre la terminal, escribe 'node' para entrar en el modo interactivo de comandos. Puedes ingresar una línea de código y se ejecutará de inmediato mostrando el resultado, por ejemplo:

$ node
> console.log('Hello World!');
Hello World!
