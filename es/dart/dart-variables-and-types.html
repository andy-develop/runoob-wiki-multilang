Variables y tipos de datos en Dart

Las variables son la unidad básica para almacenar datos en un programa; el tipo de dato determina qué valores puede almacenar una variable.

Este capítulo presenta las formas de declarar variables en Dart, los tipos de datos básicos y el importante mecanismo de seguridad contra nulos.

Formas de declarar variables: var, final, const

Dart ofrece tres palabras clave para declarar variables, cada una adecuada para diferentes escenarios.

Entender sus diferencias es el primer paso para aprender Dart correctamente.

var: variable con inferencia de tipo

Las variables declaradas con var infieren automáticamente su tipo a partir del valor inicial, y una vez determinado, el tipo no puede cambiar.

Ejemplo

void main() {
  // Inferencia de tipo: el tipo de name se infiere como String
  var name = 'RUNOOB';

  // Inferencia de tipo: el tipo de age se infiere como int
  var age = 10;

  print('$name ya tiene $age años');

  // La siguiente escritura dará error: una vez determinado el tipo, no se puede asignar otro tipo de valor
  // name = 123; // Error: no se puede asignar int a String
}
RUNOOB 已经 10 年了

var no es 'sin tipo' ni 'tipo dinámico'; su tipo se fija en el momento de la asignación. Esto es completamente diferente del var de JavaScript.

final: constante en tiempo de ejecución

Una variable declarada con final solo puede asignarse una vez, pero el momento de la asignación puede retrasarse hasta el tiempo de ejecución.

Ejemplo

void main() {
  // Variable final: una vez asignada, no se puede modificar
  final currentTime = DateTime.now();
  print('Hora actual: $currentTime');

  // La asignación diferida también está permitida
  final String greeting;
  greeting = 'Hello, RUNOOB!';  // Primera asignación OK
  // greeting = 'Hello again'; // Error: una variable final no se puede reasignar

  print(greeting);
}
当前时间: 2026-06-12 10:30:00.000
Hello, RUNOOB!

const: constante en tiempo de compilación

const es más estricto que final: su valor debe poder determinarse en tiempo de compilación.

Ejemplo

void main() {
  // const debe poder determinar su valor en tiempo de compilación
  const siteName = 'RUNOOB';
  const maxUsers = 100;

  print('Sitio: $siteName, número máximo de usuarios: $maxUsers');

  // La siguiente escritura dará error: DateTime.now() es un valor que solo se puede determinar en tiempo de ejecución
  // const currentTime = DateTime.now(); // ¡Error!
}
站点: RUNOOB, 最大用户数: 100

Resumen comparativo de los tres

Palabra claveModificableMomento de asignaciónCaso típico
varSíCualquier momentoVariables ordinarias cuyo valor cambia
finalNo modificableSe determina en tiempo de ejecuciónConfiguración obtenida de una API, hora actual
constNo modificableSe determina en tiempo de compilaciónConstantes matemáticas, configuración fija, valores de color

Un consejo práctico: usa final por defecto. Cuando descubras que necesitas modificarla, cámbiala a var. Este hábito hace que el código sea más seguro y reduce errores causados por modificaciones accidentales.

Tipos numéricos: int y double

Los tipos numéricos de Dart se dividen en dos: int (entero) y double (número de punto flotante).

Su clase padre común es num.

Ejemplo

void main() {
  // int: entero, rango de -2^63 a 2^63-1
  int viewCount = 10000;
  int negativeNumber = -42;

  // double: número de punto flotante de doble precisión
  double price = 9.99;
  double pi = 3.1415926;

  // num puede aceptar tanto int como double
  num someNumber = 10;
  someNumber = 10.5;  // Válido

  print('Vistas: $viewCount');
  print('Precio: ¥$price');
  print('Pi: $pi');
}
浏览次数: 10000
价格: ¥9.99
圆周率: 3.1415926

Métodos comunes para números

Ejemplo

import 'dart:math';  // Importar librería matemática

void main() {
  int a = -10;
  double b = 3.7;

  // Valor absoluto
  print('Valor absoluto de a: ${a.abs()}');   // 10

  // Redondear al entero más cercano
  print('b redondeado: ${b.round()}');  // 4

  // Redondear hacia abajo
  print('b redondeado hacia abajo: ${b.floor()}');  // 3

  // Redondear hacia arriba
  print('b redondeado hacia arriba: ${b.ceil()}');   // 4

  // Convertir cadena a número
  int parsed = int.parse('42');
  double parsedDouble = double.parse('3.14');
  print('Resultado del parseo: $parsed, $parsedDouble');

  // Generar número aleatorio (requiere import 'dart:math')
  var random = Random().nextInt(100);
  print('Número aleatorio (0-99): $random');
}
a 的绝对值: 10
b 四舍五入: 4
b 向下取整: 3
b 向上取整: 4
解析结果: 42, 3.14
随机数(0-99): 67

Cadenas: String y sintaxis de interpolación

String se usa para representar texto. Las cadenas de Dart admiten comillas simples y dobles.

La interpolación de cadenas (String Interpolation) es una de las características más convenientes de Dart.

Ejemplo

void main() {
  // Las cadenas pueden usar comillas simples o dobles
  String singleQuoted = 'Hello';
  String doubleQuoted = "World";

  // Cadena de varias líneas: usa tres comillas
  String multiLine = '''
Esta es la primera línea
Esta es la segunda línea
Esta es la tercera línea - RUNOOB
  ''';

  // Interpolación de cadenas: usa $nombreVariable o ${expresión}
  String site = 'RUNOOB';
  int years = 10;

  // $nombreVariable: referencia directa a la variable
  print('Bienvenido a $site');

  // ${expresión}: inserta expresiones complejas
  print('$site nos ha acompañado durante ${years + 1} años');

  // Caracteres de escape
  print('Salto de línea: primera línea\nsegunda línea');
  print('Tabulador: columna 1\tcolumna 2');
}
欢迎来到 RUNOOB
RUNOOB 已经陪伴我们 11 年了
换行符: 第一行
第二行
制表符: 列1    列2

Métodos comunes para cadenas

Ejemplo

void main() {
  String text = '  Hello, RUNOOB!  ';

  // Eliminar espacios al inicio y al final
  print('trim: [${text.trim()}]');

  // Convertir a mayúsculas / minúsculas
  print('Mayúsculas: ${text.toUpperCase()}');
  print('Minúsculas: ${text.toLowerCase()}');

  // Verificar si contiene una subcadena
  print('¿Contiene RUNOOB? ${text.contains('RUNOOB')}');

  // Verificar si comienza o termina con una cadena
  print('¿Comienza con espacio? ${text.startsWith(' ')}');
  print('¿Termina con !? ${text.trim().endsWith('!')}');

  // Reemplazo de cadena
  print('Reemplazo: ${text.replaceAll('RUNOOB', 'DART')}');

  // Dividir cadena
  String csv = 'Dart,Flutter,Google';
  List<String> items = csv.split(',');
  print('Resultado de la división: $items');

  // Concatenar cadenas
  print('Concatenación: ' + 'Hello' + ', ' + 'World');
}

大写:   HELLO, RUNOOB!
小写:   hello, runoob!
包含 RUNOOB? true
以空格开头? true
以!结尾? true
替换:   Hello, DART!
分割结果: [Dart, Flutter, Google]
拼接: Hello, World

Valor booleano bool

El tipo bool solo tiene dos valores: true y false.

Se usa principalmente para condiciones, junto con la sentencia if.

Ejemplo

void main() {
  bool isLoggedIn = true;
  bool hasPermission = false;

  // Expresión booleana
  bool canAccess = isLoggedIn && hasPermission;  // Y: ambos son true
  bool isGuest = !isLoggedIn;                    // No: negación

  print('Puede acceder: $canAccess');
  print('Es visitante: $isGuest');

  // Las operaciones de comparación producen valores bool
  int age = 20;
  bool isAdult = age >= 18;
  print('Es mayor de edad: $isAdult');

  // Usar directamente en condiciones
  if (isAdult) {
    print('Bienvenido a RUNOOB');
  }
}
可以访问: false
是访客: false
是否成年: true
欢迎访问 RUNOOB

Dart 是强类型语言，条件判断中只接受 bool 类型。这和 JavaScript 不同——在 Dart 中，if(0) 或 if('') 这样的写法会直接报错。

Seguridad contra nulos (Null Safety)

La seguridad de nulos es la característica más importante introducida en Dart 2.12.

Su idea central es: por defecto, todas las variables no pueden ser null, a menos que lo declares explícitamente.

Tipos anulables y no anulables

Agregar ? después del tipo indica que la variable puede ser null.

Ejemplo

void main() {
  // Tipo no anulable: no se puede asignar null
  String name = 'RUNOOB';
  // name = null; // ¡Error! name no puede ser null

  // Tipo anulable: se permite null
  String? nickname;
  nickname = null;  // OK
  nickname = 'R';   // También OK

  print('Apodo: $nickname');

  // int? también es anulable
  int? score;
  print('Puntuación: $score');  // Imprime null
}
昵称: R
分数: null

Operadores para el manejo de valores nulos

OperadorDescripciónEjemplo
??Si el lado izquierdo es null, usa el valor del lado derechoname ?? 'Nombre predeterminado'
??=Si la variable es null, se le asigna el valor de la derechaname ??= 'Nombre predeterminado'
?.Acceso seguro: omite la llamada cuando el objeto es nulluser?.name
!Aseverar no null (usar con precaución)name!

Ejemplo

void main() {
  String? username;

  // Operador ??: si username es null, usa el valor predeterminado
  String displayName = username ?? 'Visitante RUNOOB';
  print(displayName);  // Visitante RUNOOB

  // Operador ??=: asigna si es null
  username ??= 'Nuevo usuario';
  print(username);  // Nuevo usuario

  // ?. Acceso seguro: solo llama cuando no es null
  String? maybeNull;
  print(maybeNull?.length);  // null (no genera error)

  maybeNull = 'Hello';
  print(maybeNull?.length);  // 5

  // ! Aseveración: estoy seguro de que no es null (si es null, lanza una excepción)
  String definitelyNotNull = 'RUNOOB';
  print(definitelyNotNull!.length);  // 6
}
RUNOOB 访客
新用户
null
5
6

Evita usar el operador de aserción ! siempre que sea posible. Si usas ! con frecuencia, indica que el diseño de tus tipos puede tener problemas. Prioriza el uso de ??, ??= y ?. para manejar valores nulos de forma segura.

Conversión de tipos

En Dart, los valores de diferentes tipos se pueden convertir entre sí.

Ejemplo

void main() {
  // Número → Cadena
  int count = 42;
  String countStr = count.toString();
  print('Número a cadena: $countStr (Tipo: ${countStr.runtimeType})');

  // Cadena → Número
  String priceStr = '19.99';
  double price = double.parse(priceStr);
  print('Cadena a número: ¥$price');

  // int &#x2194; double
  int integer = 10;
  double decimal = integer.toDouble();
  print('int a double: $decimal');

  double pi = 3.14;
  int piInt = pi.toInt();  // Trunca la parte decimal
  print('double a int (truncado): $piInt');

  // Cualquier valor → Cadena
  bool flag = true;
  print('bool a cadena: ${flag.toString()}');

  // Cadena → bool (requiere evaluación manual)
  String boolStr = 'true';
  bool parsed = boolStr == 'true';
  print('Cadena a bool: $parsed');
}
数字转字符串: 42 (类型: String)
字符串转数字: ¥19.99
int 转 double: 10.0
double 转 int (截断): 3
bool 转字符串: true
字符串转 bool: true
