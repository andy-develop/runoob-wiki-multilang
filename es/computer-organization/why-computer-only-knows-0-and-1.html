Principios de organización de computadoras
Conversión entre bases: binario, decimal, hexadecimal

¿Por qué las computadoras solo reconocen 0 y 1?

En esta lección entenderás: por qué la computadora eligió el binario en lugar del decimal, y cómo esta elección determinó toda la arquitectura de las computadoras modernas.

Empecemos por el interruptor

Imagina que tienes una fila de interruptores de luz frente a ti.

Cada interruptor tiene solo dos estados:开或关。

No puedes dejar un interruptor "medio abierto" o "abierto al 37%": es de dos estados, no tiene estados intermedios.

El componente más básico dentro de una computadora, el transistor, es esencialmente lo mismo que un interruptor.

Solo tiene dos estados estables:Conducción (encendido)和Corte (apagado)。

Los dos estados del voltaje

En los circuitos digitales, asignamos un símbolo a cada uno de estos dos estados:

  • El voltaje alto (por ejemplo, 3.3V o 5V) representa1
  • El voltaje bajo (cerca de 0V) representa0

La relación entre el voltaje y el binario

La siguiente franja de colores simula el rango de voltaje del transistor de 0V a 3.3V, mostrando intuitivamente la relación entre el 0 lógico, el 1 lógico y la zona prohibida.

Nota: el circuito no necesita medir con precisión el valor del voltaje, solo necesita determinar "alto o bajo".

Esto es mucho más fácil que determinar "qué número es".

¿Por qué no usar el sistema decimal?

Los humanos usamos el sistema decimal porque tenemos diez dedos.

Pero, ¿por qué una computadora no puede usar el sistema decimal?

Razón 1: Es extremadamente difícil de implementar en ingeniería

Para que un circuito represente los 10 dígitos decimales (0~9), necesita distinguir con precisión 10 niveles de voltaje diferentes.

Por ejemplo: 0V = 0, 0.33V = 1, 0.66V = 2, ..., 3.3V = 9.

Aquí surge el problema: la señal sufre pérdidas e interferencias durante la transmisión.

Supón que envías 0.66V para representar el número 2, pero al llegar al destino el voltaje se convierte en 0.71V.

El receptor se confundiría: ¿esto es 2 (0.66V) o 3 (0.99V)?

Razón 2: El binario es naturalmente resistente a las interferencias

El binario solo necesita distinguir dos estados, por lo que tiene un margen de tolerancia enorme.

Como se muestra: el rango del 0 lógico es de 0~1.5V, el rango del 1 lógico es de 1.8V~3.3V.

En el medio hay una zona de protección de 0.3V.

Incluso si la señal fluctúa considerablemente, mientras no cruce la zona de protección, los datos no se corromperán.

Razón 3: Encaja perfectamente con las matemáticas

El 0 y el 1 corresponden exactamente a "falso" y "verdadero" en el álgebra de Boole.

El álgebra de Boole (operaciones lógicas como AND, OR, NOT) tiene una teoría matemática completa.

Los ingenieros pueden usar esta teoría para diseñar, analizar y optimizar circuitos: esto es algo muy afortunado.

La elección del binario por parte de las computadoras no es casualidad. Es el resultado de la combinación de restricciones de ingeniería (fácil de implementar), características físicas (resistencia a interferencias) y herramientas matemáticas (álgebra de Boole).

Bit y byte: la unidad básica de la información

Un dígito binario se llama 1bit(bit), solo puede representar 0 o 1.

Obviamente, un solo bit puede representar muy poca información.

Así que agrupamos 8 bits y lo llamamos 1byte(byte).

¿Cuántos valores diferentes puede representar un byte?

Cada bit tiene 2 opciones (0 o 1), el número de combinaciones de 8 bits es:

2 x 2 x 2 x 2 x 2 x 2 x 2 x 2 = 28 = 256

Es decir, desde 00000000 (0 en decimal) hasta 11111111 (255 en decimal), un total de 256 valores diferentes.

Número de bytesRango de valores representableUsos comunes
1 byte (8 bits)0 ~ 255Un carácter ASCII, un valor de canal en un color RGB
2 bytes (16 bits)0 ~ 65,535Número de puerto, tamaño de registro de CPUs antiguas
4 bytes (32 bits)0 ~ 4,294,967,295Dirección IPv4, tipo int
8 bytes (64 bits)0 ~ aproximadamente 1.8 x 1019Tamaño de palabra de CPUs modernas, tipo long

El siguiente panel interactivo te permite visualizar cómo 8 bits se combinan para formar cualquier valor entre 0 y 255.

Cada bombilla representa un bit.Haz clic en una bombilla para alternar el estado 0/1, y a la derecha se muestra en tiempo real el valor decimal correspondiente.

Simulador de bombillas: un byte = 8 bits

Haz clic en las bombillas para cambiar su estado y observa cómo el binario se asigna al decimal.

Decimal:0
Binario:00000000

Observa con atención las etiquetas de peso debajo de cada bombilla.

La bombilla más a la izquierda tiene el mayor peso (128), y la más a la derecha el menor (1).

Este es el concepto de "expansión por pesos": el valor de cada posición se multiplica por su peso, y la suma de todos es el resultado final.

Entender el binario con código

Python tiene soporte integrado para el binario; podemos usarlo directamente para verificar la demostración de las bombillas anterior.

Ejemplo

# 二进制的基本操作（runoob 演示）

# 1. 查看一个数字的二进制表示
print("十进制 → 二进制：")
for n in [0, 1, 2, 7, 8, 15, 16, 42, 65, 97, 127, 255]:
    # bin() 返回 '0b...' 格式，用 [2:] 去掉前缀
    # zfill(8) 补齐到 8 位
    print(f"  {n:3d} → {bin(n)[2:].zfill(8)}")

print()

# 2. 从二进制字符串解析为十进制
print("二进制 → 十进制：")
binary_strings = ["00000000", "01000001", "01100001", "11111111"]
for b in binary_strings:
    # int(string, 2) 将二进制字符串转为整数
    dec = int(b, 2)
    print(f"  {b} → {dec:3d}")

print()

# 3. 验证：一个字节正好 256 个值
print("一个字节的范围：")
print(f" 最小值: {int('00000000', 2)}")
print(f" 最大值: {int('11111111', 2)}")
print(f" 总个数: {int('11111111', 2) - int('00000000', 2) + 1}")

print()

# 4. 位操作：按位与、或、左移、右移
print("位运算示例：")
a = 0b0011  # 3
b = 0b0101  # 5
print(f" {bin(a)} & {bin(b)} = {bin(a & b)} (按位与)")
print(f" {bin(a)} | {bin(b)} = {bin(a | b)} (按位或)")
print(f" {bin(a)} << 1 = {bin(a << 1)} (左移1位，相当于乘以2)")
print(f" {bin(b)} >> 1 = {bin(b >> 1)} (右移1位，相当于除以2)")

print()

# 5. RUNOOB 测试字符串
text = "RUNOOB"
print(f"字符串 '{text}' 每个字符的二进制表示：")
for ch in text:
    ascii_val = ord(ch)
    print(f" '{ch}' → ASCII={ascii_val:3d} → 二进制={bin(ascii_val)[2:].zfill(8)}")

¿Por qué el binario es la base de la "representación de la información"?

Al entender el binario, entiendes un hecho clave:

Todo dentro de una computadora (números, texto, imágenes, sonido, video) se almacena y procesa finalmente en forma de 0 y 1.

En las próximas lecciones verás:

  • Lección 2: cómo convertir entre diferentes bases numéricas.
  • Lección 3: Cómo se representan los números negativos en binario (complemento a dos)
  • Lección 4: Cómo se representan los decimales en binario (números de punto flotante)
  • Lección 5: Cómo se representa el texto en binario (codificación de caracteres)

Todo esto se basa en el principio de que «todo son 0 y 1».

La conclusión central de las 5 lecciones de este módulo: la computadora no «entiende» la información, sino que, mediante ingeniosas reglas de codificación, mapea todo en el mundo a combinaciones de 0 y 1.
