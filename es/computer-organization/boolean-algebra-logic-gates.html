Fundamentos del álgebra booleana -- AND / OR / NOT / XOR

El álgebra booleana es la base matemática de todos los circuitos digitales; la combinación de las cuatro operaciones lógicas básicas puede construir cualquier circuito, por complejo que sea.

Analogía cotidiana: puertas automáticas y sistemas de control de acceso

Al entrar en un edificio de alta seguridad, te encuentras con varias reglas de acceso. Estas reglas corresponden exactamente a las operaciones básicas del álgebra booleana. Usemos escenarios cotidianos para entenderlas.

Puerta AND — solo se puede entrar si dos puertas están abiertas al mismo tiempo: Una cámara acorazada requiere dos llaves que se giren simultáneamente para abrir la puerta. Solo si ambas llaves están insertadas y giradas (ambas entradas son 1), la puerta se abre (salida 1). Si falta cualquiera de las llaves, la puerta no se mueve.

Puerta OR — se puede entrar si cualquier puerta está abierta: La oficina tiene dos entradas; si la puerta delantera o la trasera está abierta, puedes entrar. Si cualquier entrada está abierta (al menos una entrada es 1), puedes pasar (salida 1).

Puerta NOT — un botón invierte el letrero: Frente al baño hay un letrero giratorio "libre/ocupado"; al presionar el botón se invierte el estado actual. Si la entrada es 0 (libre), la salida es 1 (ocupado), y viceversa.

Puerta XOR — en una habitación, dos luces deben estar una encendida y la otra apagada: Una habitación tiene dos luces instaladas. La regla es que sus estados deben ser opuestos (una encendida y una apagada); de lo contrario, se activa el sistema de alarma. Por lo tanto, cuando las dos entradas son diferentes, la salida es 1; cuando son iguales, la salida es 0.

Breve historia del álgebra booleana

El álgebra booleana fue formulada por el matemático británicoGeorge BooleFue presentada sistemáticamente por primera vez en 1854 en la obra "Una investigación sobre las leyes del pensamiento". El objetivo de Boole era matematizar el razonamiento lógico humano; creó un método para expresar "verdadero" y "falso" mediante símbolos algebraicos.

En 1938,Claude ShannonEn su tesis de maestría en el MIT demostró que el álgebra booleana podía usarse para describir y simplificar circuitos de conmutación de relés. Este trabajo, conocido como "la tesis de maestría más importante de la historia", sentó las bases teóricas del diseño de todos los circuitos digitales.

Se puede decir que sin álgebra booleana no habría circuitos digitales, y sin circuitos digitales no habría computadoras modernas. Dentro del dispositivo con el que estás leyendo este texto, se realizan cientos de millones de operaciones booleanas cada segundo.

Explicación detallada de las cuatro operaciones lógicas básicas

Operación AND

La regla de la operación AND se resume en una frase:Solo cuando todas las entradas son 1, la salida es 1.; de lo contrario, la salida es 0. Puedes entenderlo como interruptores en serie: ambos interruptores deben estar cerrados para que la bombilla se encienda.

Expresión lógica:Y = A · B(A veces se omite el punto y se escribe directamente Y = AB). Fórmula mnemotécnica: solo todo 1 da 1.

Operación OR

La regla de la operación OR:Con tal de que una entrada sea 1, la salida es 1.; solo cuando todas las entradas son 0, la salida es 0. Analogía con interruptores en paralelo: si cualquier interruptor se cierra, la bombilla se enciende.

Expresión lógica:Y = A + B(Ojo: no es suma aritmética; 1+1 en álgebra booleana sigue siendo 1). Fórmula mnemotécnica: si hay un 1, resulta 1.

Operación NOT

NOT es la única operación básica que acepta una sola entrada, y su regla es la más sencilla:La salida es la opuesta a la entrada.Si la entrada es 1, la salida es 0; si la entrada es 0, la salida es 1.

Expresión lógica:Y = A' 或 Y = NOT AEn los diagramas de circuitos se suele usar un círculo pequeño en la línea de entrada para indicar la negación. Fórmula mnemotécnica: 0 se convierte en 1, 1 se convierte en 0.

Operación XOR

La regla de XOR:Cuando las dos entradas son diferentes, la salida es 1; cuando son iguales, la salida es 0.XOR se puede implementar combinando AND, OR y NOT: A XOR B = (A' · B) + (A · B').

Símbolos de puertas lógicas

En los diagramas de circuitos digitales, cada operación lógica básica tiene su correspondiente símbolo estándar de puerta lógica:

Puerta AND: el símbolo tiene forma de D — un lado recto más un arco semicircular; dos líneas de entrada a la izquierda y una línea de salida a la derecha.

Puerta OR: el símbolo tiene forma de escudo — una curva cóncava que se estrecha y converge en un punto en la parte trasera, representando el significado lógico de "o".

Puerta NOT (inversor): un triángulo seguido de un círculo pequeño — el triángulo representa búfer/excitación, el círculo representa la inversión de la señal.

Puerta XOR: de forma similar a la puerta OR, pero con una curva adicional antes del arco en el lado de entrada, para distinguir la "o exclusiva".

Cualquier circuito digital complejo —incluyendo la unidad aritmética y el controlador dentro de la CPU— puede, en última instancia, descomponerse en combinaciones de estas cuatro puertas lógicas básicas. Esta es la razón fundamental por la que el álgebra booleana es la base teórica de los circuitos digitales.

Demostración de código Python

A continuación se implementan en Python funciones para las cuatro operaciones lógicas básicas, se generan automáticamente las tablas de verdad completas y también se verifica la ley de De Morgan:

Ejemplo

# runoob test: implementación completa en Python del álgebra booleana

def AND(a, b):
    """Operación AND: solo todo 1 da 1"""
    return 1 if a == 1 and b == 1 else 0

def OR(a, b):
    """Operación OR: si hay un 1, resulta 1"""
    return 1 if a == 1 or b == 1 else 0

def NOT(a):
    """Operación NOT: negación"""
    return 1 if a == 0 else 0

def XOR(a, b):
    """Operación XOR: diferente es 1"""
    return 1 if a != b else 0

def print_truth_table(title, func, inputs):
    """Función genérica para imprimir tablas de verdad"""
    print(f"\n{'='*40}")
    print(f"  {title}")
    print(f"{'='*40}")

    if func.__code__.co_argcount == 1:
        print(f" {'A':>4} | {'Salida':>4}")
        print(f"  {'-'*13}")
        for a in inputs:
            print(f"  {a:>4} | {func(a):>4}")
    else:
        print(f" {'A':>4} | {'B':>4} | {'Salida':>4}")
        print(f"  {'-'*20}")
        for a in inputs:
            for b in inputs:
                print(f"  {a:>4} | {b:>4} | {func(a, b):>4}")

# Programa principal: imprime todas las tablas de verdad
inputs = [0, 1]
print("Demostración completa de tablas de verdad del álgebra booleana de runoob")
print_truth_table("Operación AND", AND, inputs)
print_truth_table("Operación OR", OR, inputs)
print_truth_table("Operación NOT", NOT, inputs)
print_truth_table("Operación XOR", XOR, inputs)

# Verificación de las leyes de De Morgan
print(f"\n{'='*40}")
print(" Verificación de las leyes de De Morgan")
print(f"{'='*40}")
print(" Ley 1: NOT(A AND B) = NOT A OR NOT B")
print(" Ley 2: NOT(A OR B) = NOT A AND NOT B")
for a in inputs:
    for b in inputs:
        left1 = NOT(AND(a, b))
        right1 = OR(NOT(a), NOT(b))
        left2 = NOT(OR(a, b))
        right2 = AND(NOT(a), NOT(b))
        print(f"  A={a}, B={b}:")
        print(f" Ley 1: {left1} = {right1} -> {'OK' if left1 == right1 else 'FAIL'}")
        print(f" Ley 2: {left2} = {right2} -> {'OK' if left2 == right2 else 'FAIL'}")
