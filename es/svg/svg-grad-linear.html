SVG Gradientes

Un gradiente es una transición suave de un color a otro. Además, se pueden aplicar transiciones de múltiples colores al mismo elemento.

Los gradientes SVG son principalmente de dos tipos:

  • Gradiente lineal - <linearGradient>
  • Gradiente radial - <radialGradient>

SVG Gradiente Lineal - <linearGradient>

En SVG, el<linearGradient>elemento se utiliza para crear gradientes lineales, que pueden transicionar de un color a otro a lo largo de una línea recta, creando así un efecto de gradiente suave.

Un gradiente lineal se puede utilizar para rellenar o trazar elementos gráficos SVG, permitiéndoles mostrar una rica variedad de colores.

Sintaxis básica

<linearGradient id="gradient_id" x1="x1" y1="y1" x2="x2" y2="y2">
  <stop offset="offset1" stop-color="color1" />
  <stop offset="offset2" stop-color="color2" />
  <!-- 更多的 <stop> 元素 -->
</linearGradient>

Descripción de parámetros:

  • idEl atributo define un identificador único para el gradiente lineal, utilizado para hacer referencia a este gradiente en imágenes SVG.

  • x1 和 y1El atributo define las coordenadas del punto de inicio del gradiente.

  • x2 和 y2El atributo define las coordenadas del punto final del gradiente.

  • <stop>El elemento se utiliza para especificar los colores y sus posiciones dentro del gradiente.

Los gradientes lineales pueden definirse como gradientes horizontales, verticales o en ángulo:

  • Cuando y1 y y2 son iguales, y x1 y x2 son diferentes, se puede crear un gradiente horizontal.
  • Cuando x1 y x2 son iguales, y y1 y y2 son diferentes, se puede crear un gradiente vertical.
  • Cuando x1 y x2 son diferentes, y y1 y y2 también son diferentes, se puede crear un gradiente angular.

El siguiente código define un gradiente lineal horizontal de rojo a azul, y luego lo aplica a un rectángulo relleno, haciendo que el rectángulo muestre un efecto de relleno degradado.

Ejemplo

<svg width="200" height="200" xmlns="http://www.w3.org/2000/svg">
  <!-- Definir gradiente lineal -->
  <linearGradient id="gradient" x1="0%" y1="0%" x2="100%" y2="0%">
    <stop offset="0%" stop-color="red" />
    <stop offset="100%" stop-color="blue" />
  </linearGradient>
 
  <!-- Rectángulo que aplica el gradiente lineal -->
  <rect x="50" y="50" width="100" height="80" fill="url(#gradient)" />
</svg>

Ejemplo 1

Definir una elipse con un gradiente lineal horizontal de amarillo a rojo:

Aquí está el código SVG:

Ejemplo

<svg xmlns="http://www.w3.org/2000/svg" version="1.1"> <defs> <linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="0%"> <stop offset="0%" style="stop-color:rgb(255,255,0);stop-opacity:1" /> <stop offset="100%" style="stop-color:rgb(255,0,0);stop-opacity:1" /> </linearGradient> </defs> <ellipse cx="200" cy="70" rx="85" ry="55" fill="url(#grad1)" /> </svg>

Análisis del código:

  • El atributo id de la etiqueta <linearGradient> puede definir un nombre único para el gradiente.
  • Los atributos X1, X2, Y1, Y2 de la etiqueta <linearGradient> definen las posiciones de inicio y fin del gradiente.
  • El rango de colores de un gradiente puede estar compuesto por dos o más colores. Cada color se especifica mediante una etiqueta <stop>. El atributo offset se utiliza para definir las posiciones de inicio y fin del gradiente.
  • El atributo fill vincula el elemento ellipse a este gradiente.

Ejemplo 3

Definir una elipse con un gradiente lineal horizontal de amarillo a rojo y agregar un texto dentro de la elipse:

Aquí está el código SVG:

Ejemplo

<svg xmlns="http://www.w3.org/2000/svg" version="1.1"> <defs> <linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="0%"> <stop offset="0%" style="stop-color:rgb(255,255,0);stop-opacity:1" /> <stop offset="100%" style="stop-color:rgb(255,0,0);stop-opacity:1" /> </linearGradient> </defs> <ellipse cx="200" cy="70" rx="85" ry="55" fill="url(#grad1)" /> <text fill="#ffffff" font-size="45" font-family="Verdana" x="150" y="86"> SVG</text> </svg>

Análisis del código:

  • La etiqueta <text> se utiliza para agregar un texto.

Notas

  • Un gradiente puede contener múltiples<stop>elementos, cada<stop>elemento representa un color y una posición en el gradiente.

  • El punto de inicio y el punto final de un gradiente pueden estar en cualquier posición; el gradiente interpolará a lo largo de la línea recta entre el punto de inicio y el punto final definidos.

  • Los valores de coordenadas del gradiente pueden usar porcentajes o valores de longitud concretos; los valores porcentuales son relativos al tamaño del elemento gráfico.

  • Se puede aplicar un gradiente lineal al relleno o al trazo de elementos gráficos SVG.
