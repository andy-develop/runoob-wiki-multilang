Documentación de referencia de Matplotlib

Matplotlib es la biblioteca de visualización de datos más utilizada en Python, compatible con la creación de gráficos estáticos, dinámicos e interactivos.

Este documento recopila por completo las funciones y métodos de todas las interfaces públicas de Matplotlib, para facilitar la consulta rápida de funcionalidades y usos correspondientes.

Dos interfaces de programación

Matplotlib ofrece dos formas de uso, adecuadas para diferentes escenarios.

Característica Interfaz Axes (explícita / orientada a objetos) Interfaz pyplot (implícita / funcional)
Forma de uso Primero crear los objetos Figure y Axes, luego llamar a los métodos del objeto Llamar directamente a las funciones del módulo pyplot, operando implícitamente sobre el gráfico actual
Escenario aplicable Gráficos complejos, múltiples subtramas, necesidad de control fino Dibujo rápido, exploración interactiva, gráficos simples
Ejemplo de código fig, ax = plt.subplots(); ax.plot(x, y) plt.plot(x, y); plt.title("título")
Nivel de recomendación Recomendado(Más claro y más controlable) Adecuado para escenarios simples y prototipos rápidos

La interfaz Axes es el método de programación recomendado oficialmente; la lógica del código es más clara y es menos propenso a errores al manejar múltiples subtramas y gráficos complejos. Para facilitar la consulta rápida, a continuación se enumeran tanto las funciones de pyplot como los métodos de Axes correspondientes.

Ejemplos comunes

Ejemplo 1: Gráfico de líneas y diagrama de dispersión básicos

Usar la interfaz explícita de Axes para crear una gráfica con múltiples curvas y anotaciones.

Ejemplo

import matplotlib.pyplot as plt
import numpy as np

# Generar datos: 100 puntos equiespaciados entre 0 y 10
x = np.linspace(0, 10, 100)
y1 = np.sin(x)   # Función seno
y2 = np.cos(x)   # Función coseno

# Crear Figure y Axes (interfaz explícita, recomendada)
fig, ax = plt.subplots(figsize=(8, 4), layout='constrained')

# Dibujar dos líneas, establecer color, tipo de línea y etiquetas
ax.plot(x, y1, label='sin(x)', color='blue', linewidth=2)
ax.plot(x, y2, label='cos(x)', color='red', linestyle='--', linewidth=2)

# Añadir un punto de dispersión destacado en la posición del pico
peak_idx_sin = np.argmax(y1)
peak_idx_cos = np.argmax(y2)
ax.scatter(x[peak_idx_sin], y1[peak_idx_sin],
           color='blue', s=100, zorder=5)
ax.scatter(x[peak_idx_cos], y2[peak_idx_cos],
           color='red', s=100, zorder=5)

# Decoración: título, etiquetas de ejes, leyenda, cuadrícula
ax.set_title('Sine and Cosine Functions', fontsize=14)
ax.set_xlabel('x (radians)')
ax.set_ylabel('Amplitude')
ax.legend(loc='upper right')
ax.grid(True, alpha=0.3)

plt.show()
print("runoob: plot displayed successfully")

Ejemplo 2: Disposición de múltiples subtramas (2x2)

Muestra cómo crear diferentes tipos de subgráficos en un mismo Figure.

Ejemplo

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 2 * np.pi, 100)

# Crear subgráficos 2x2 (interfaz orientada a objetos)
fig, axes = plt.subplots(2, 2, figsize=(10, 8), layout='constrained')
fig.suptitle('Multi-panel RUNOOB Demo', fontsize=16)

# Subgráfico (0,0): gráfico de líneas
axes[0, 0].plot(x, np.sin(x), color='tab:blue', linewidth=2)
axes[0, 0].set_title('Line Plot')
axes[0, 0].set_ylabel('sin(x)')

# Subgráfico (0,1): gráfico de dispersión
np.random.seed(42)
colors = np.random.rand(50)
sizes = np.random.rand(50) * 200
axes[0, 1].scatter(np.random.rand(50), np.random.rand(50),
                   c=colors, s=sizes, alpha=0.6, cmap='viridis')
axes[0, 1].set_title('Scatter Plot')

# Subgráfico (1,0): gráfico de barras (con etiquetas de valor)
categories = ['A', 'B', 'C', 'D', 'E']
values = [23, 45, 56, 78, 32]
bars = axes[1, 0].bar(categories, values,
                       color='tab:green', edgecolor='white')
axes[1, 0].bar_label(bars)  # Mostrar valores sobre las barras
axes[1, 0].set_title('Bar Chart')

# Subgráfico (1,1): histograma
data = np.random.randn(1000)
axes[1, 1].hist(data, bins=30, color='tab:orange',
                edgecolor='white', alpha=0.8)
axes[1, 1].axvline(x=0, color='red', linestyle='--', linewidth=2)
axes[1, 1].set_title('Histogram')

plt.show()

Ejemplo 3: Comparación entre mapa de calor y curvas de nivel

Muestra el uso de imshow y contourf en el mismo Figure para visualizar datos bidimensionales.

Ejemplo

import matplotlib.pyplot as plt
import numpy as np

# Crear datos de cuadrícula bidimensional
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)  # Valores de la función bidimensional

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5),
                                layout='constrained')

# Gráfico izquierdo: mapa de calor (imshow)
im = ax1.imshow(Z, extent=[-3, 3, -3, 3], origin='lower',
                cmap='viridis', aspect='auto')
ax1.set_title('Heatmap (imshow)', fontsize=14)
ax1.set_xlabel('X')
ax1.set_ylabel('Y')
fig.colorbar(im, ax=ax1, label='Amplitude', shrink=0.8)

# Gráfico derecho: curvas de nivel rellenas (contourf)
contour = ax2.contourf(X, Y, Z, levels=15, cmap='RdYlBu')
# Superponer bordes de curvas de nivel
ax2.contour(X, Y, Z, levels=15, colors='black', linewidths=0.5)
ax2.set_title('Filled Contour (contourf)', fontsize=14)
ax2.set_xlabel('X')
ax2.set_ylabel('Y')
fig.colorbar(contour, ax=ax2, label='Amplitude', shrink=0.8)

Ejemplo 6: Doble eje y y subtrama incrustada

Muestra el uso de secondary_axis, twinx e inset_axes.

Ejemplo

import matplotlib.pyplot as plt
import numpy as np

fig, ax = plt.subplots(figsize=(8, 5), layout='constrained')

x = np.linspace(0, 10, 100)

# Gráfico principal: dibujar dos curvas con diferentes magnitudes
ax.plot(x, np.sin(x), 'b-', label='sin(x) [amplitude]')
ax.set_xlabel('x (radians)')
ax.set_ylabel('sin(x)', color='blue')
ax.tick_params(axis='y', labelcolor='blue')

# Crear doble eje y (compartiendo el eje x)
ax2 = ax.twinx()
ax2.plot(x, np.exp(x/5), 'r--', label='exp(x/5) [growth]')
ax2.set_ylabel('exp(x/5)', color='red')
ax2.tick_params(axis='y', labelcolor='red')

# Añadir un subgráfico incrustado en ax (para ampliar una región local)
axins = ax.inset_axes([0.15, 0.5, 0.3, 0.35])
axins.plot(x, np.sin(x), 'b-')
axins.set_xlim(3, 5)
axins.set_ylim(-1.2, 1.2)
axins.set_title('Zoomed Region')
axins.grid(True, alpha=0.3)

# Marcar la región incrustada en el gráfico principal
ax.indicate_inset_zoom(axins, edgecolor='gray')

ax.set_title('Dual Y-Axes with Inset Zoom', fontsize=14)
plt.show()

Preguntas frecuentes

El gráfico no se muestra

Verificar si se ha llamado aplt.show()。

En backends no interactivos (como Agg) se debe llamar explícitamente ashow()。

En Jupyter Notebook, usar%matplotlib inlineEl comando mágico garantiza que los gráficos se muestren incrustados.

Demasiadas marcas o desorden en el orden

Una causa común es pasar una lista de cadenas como datos (en lugar de valores numéricos o de fecha y hora).

Matplotlib trata una lista de cadenas como una variable categórica: un tick por cada valor único, ordenados según su aparición.

Solución: convertir las cadenas a valores numéricos, por ejemplonp.asarray(data, dtype='float') 或 np.asarray(data, dtype='datetime64[s]')。

El chino se muestra como recuadros

La fuente predeterminada de Matplotlib (DejaVu Sans) no incluye glifos chinos; debe especificar una fuente compatible con chino.

Configuraciónplt.rcParams['font.sans-serif'] = ['SimHei', 'Arial Unicode MS', ...]y asegúrese de que el sistema tenga instalada la fuente correspondiente.

Etiquetas superpuestas o truncadas

Se recomienda usar al crear la Figurelayout='constrained' 或 layout='compressed'parámetro, que gestiona automáticamente los problemas de solapamiento de etiquetas, títulos y leyendas.

También se puede usarfig.tight_layout() 或 fig.subplots_adjust()para ajustar manualmente.

Diferencia entre pcolor y pcolormesh

pcolor()Crea un PolyCollection, cuyo renderizado es más lento pero más preciso.

pcolormesh()Crea un QuadMesh, con renderizado más rápido; es la opción recomendada en la mayoría de los escenarios.

Para cuadrículas muy grandes,pcolorfast()use imshow para dibujar; es el método más rápido, pero el de menor precisión.
