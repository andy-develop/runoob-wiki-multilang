Construir proyectos Java con Maven

Maven usa el arquetipoarchetypeEl complemento crea proyectos. Para crear una aplicación Java simple, usaremos elmaven-archetype-quickstartcomplemento.

En el siguiente ejemplo, crearemos un proyecto de aplicación Java basado en Maven en la carpeta C:\MVN.

El formato del comando es el siguiente:

mvn archetype:generate "-DgroupId=com.companyname.bank" "-DartifactId=consumerBanking" "-DarchetypeArtifactId=maven-archetype-quickstart" "-DinteractiveMode=false"

Descripción de los parámetros:

  • -DgroupId: nombre de la organización, la inversa de la URL de la empresa + nombre del proyecto
  • -DartifactId: nombre del proyecto - nombre del módulo
  • -DarchetypeArtifactId: especifica el ArchetypeId, maven-archetype-quickstart, crea una aplicación Java simple
  • -DinteractiveMode: si usar el modo interactivo

La estructura de carpetas generada es la siguiente:

Descripción de cada carpeta:

Estructura de carpetas Descripción
consumerBanking Contiene la carpeta src y pom.xml
src/main/java contains Los archivos de código Java están bajo la estructura de paquetes (com/companyName/bank).
src/main/java test Los archivos de código de prueba están bajo la estructura de paquetes (com/companyName/bank).
src/main/resources Contiene archivos de imágenes / propiedades (en el ejemplo anterior, necesitamos crear manualmente esta estructura).

在 C:\MVN\consumerBanking\src\main\java\com\companyname\bankEn la carpeta, se puede ver un App.java, con el siguiente código:

App.java

package com.companyname.bank; /** * Hello world! * */ public class App { public static void main( String[] args ) { System.out.println( "Hello World!" ); } }

AbrirC:\MVN\consumerBanking\src\test\java\com\companyname\bankla carpeta, puedes ver el archivo de prueba Java AppTest.java.

AppTest.java

package com.companyname.bank; import junit.framework.Test; import junit.framework.TestCase; import junit.framework.TestSuite; /** * Unit test for simple App. */ public class AppTest extends TestCase { /** * Create the test case * * @param testName name of the test case */ public AppTest( String testName ) { super( testName ); } /** * @return the suite of tests being tested */ public static Test suite() { return new TestSuite( AppTest.class ); } /** * Rigourous Test :-) */ public void testApp() { assertTrue( true ); } }

En el siguiente proceso de desarrollo, solo necesitamos colocar los archivos según la estructura mencionada en la tabla anterior; Maven se encargará del resto.

    http://repo1.maven.org/maven2/archetype-catalog.xml

    Solución:Modifique el archivo setting.xml y cambie el mirror al espejo de Alibaba.

    1. Abra conf/setting.xml en el directorio de Maven; asegúrese de que sea el Maven que usa IDEA.

    2. Busque <mirrors>; localice <mirrors>. Agregue bajo el nodo <mirrors>.

    <mirror>
      <id>alimaven</id>
      <name>aliyun maven</name>
      <url>http://maven.aliyun.com/nexus/content/groups/public/</url>
      <mirrorOf>central</mirrorOf>        
</mirror>
