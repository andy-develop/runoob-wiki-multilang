Ejemplo de documento Swagger

A continuación se muestra un ejemplo completo de documento Swagger, que es una especificación detallada de una API de sistema de gestión de usuarios.

Este documento describe una API de sistema de gestión de usuarios, que incluye información básica del usuario, servicio de autenticación, modelo de datos, etc.

Esta API sigue el estilo RESTful y utiliza el formato JSON para el intercambio de datos.

Podemos usar Swagger Editor para probar tu documento en línea. La dirección en línea es:https://editor.swagger.io/Solo tienes que copiar y pegar tu YAML o JSON en el editor, y el panel derecho mostrará el documento de API visualizado.

A continuación se presentan los componentes principales del documento:

1. Sección de información básica

  • Título y descripción de la API: funciones básicas del sistema de gestión de usuarios
  • Información de versión：1.0.0
  • Información de contacto: información de contacto del equipo de soporte de API
  • Licencia：Apache 2.0

2. Configuración del servidor

  • Entorno de producción
  • Entorno de preproducción
  • Entorno de desarrollo

3. Clasificación de etiquetas de API

  • Operaciones relacionadas con usuarios
  • Operaciones relacionadas con autenticación

4. Rutas y operaciones

Esta API incluye los siguientes endpoints:

Gestión de usuarios

  • GET /users- Obtener lista de todos los usuarios (con soporte para paginación y filtrado)
  • POST /users- Crear nuevo usuario
  • GET /users/{userId}- Obtener detalles de un usuario específico
  • PUT /users/{userId}- Actualizar información del usuario
  • DELETE /users/{userId}- Eliminar usuario

Servicio de autenticación

  • POST /auth/login- Inicio de sesión de usuario
  • POST /auth/register- Registro de usuario

5. Modelo de datos

  • User- Información básica del usuario
  • UserDetail- Información detallada del usuario
  • NewUser- Cuerpo de solicitud para crear usuario
  • UpdateUser- Cuerpo de solicitud para actualizar usuario
  • Error- Respuesta de error

6. Definición de seguridad

Utiliza token Bearer JWT para la autenticación de la API.
