Funciones de MySQL

MySQL tiene muchas funciones integradas. A continuación se enumeran las descripciones de estas funciones.

Funciones de cadenas de MySQL

Función Descripción Ejemplo
ASCII(s) Devuelve el código ASCII del primer carácter de la cadena s.

Devuelve el código ASCII de la primera letra del campo CustomerName:

SELECT ASCII(CustomerName) AS NumCodeOfFirstChar
FROM Customers;
CHAR_LENGTH(s) Devuelve el número de caracteres de la cadena s.

Devuelve el número de caracteres de la cadena RUNOOB.

SELECT CHAR_LENGTH("RUNOOB") AS LengthOfString;
CHARACTER_LENGTH(s) Devuelve el número de caracteres de la cadena s, equivalente a CHAR_LENGTH(s).

Devuelve el número de caracteres de la cadena RUNOOB.

SELECT CHARACTER_LENGTH("RUNOOB") AS LengthOfString;
CONCAT(s1,s2...sn) Combina varias cadenas como s1, s2, etc., en una sola cadena.

Combina varias cadenas.

SELECT CONCAT("SQL ", "Runoob ", "Gooogle ", "Facebook") AS ConcatenatedString;
CONCAT_WS(x, s1,s2...sn) Igual que la función CONCAT(s1,s2,...), pero se añade x entre cada cadena; x puede ser un separador.

Combina varias cadenas y añade un separador:

SELECT CONCAT_WS("-", "SQL", "Tutorial", "is", "fun!")AS ConcatenatedString;
FIELD(s,s1,s2...) Devuelve la posición de la primera cadena s en la lista de cadenas (s1,s2...).

Devuelve la posición de la cadena c en los valores de la lista:

SELECT FIELD("c", "a", "b", "c", "d", "e");
FIND_IN_SET(s1,s2) Devuelve la posición de la cadena que coincide con s1 dentro de la cadena s2.

Devuelve la posición de la cadena c en la cadena especificada:

SELECT FIND_IN_SET("c", "a,b,c,d,e");
FORMAT(x,n) La función formatea el número x en el formato '#,###.##', conservando n decimales y redondeando el último dígito.

Formatea el número en el formato '#,###.##':

SELECT FORMAT(250500.5634, 2);     -- 输出 250,500.56
INSERT(s1,x,len,s2) La cadena s2 reemplaza la subcadena de s1 que comienza en la posición x y tiene una longitud de len.

Reemplaza los 6 caracteres desde la primera posición de la cadena por 'runoob':

SELECT INSERT("google.com", 1, 6, "runoob");  -- 输出：runoob.com
LOCATE(s1,s) Obtiene la posición inicial de s1 dentro de la cadena s.

Obtiene la posición de 'b' en la cadena 'abc':

SELECT LOCATE('st','myteststring');  -- 5

Devuelve la posición de 'b' en la cadena 'abc':

SELECT LOCATE('b', 'abc') -- 2
LCASE(s) Convierte todas las letras de la cadena s a minúsculas.

Convierte la cadena RUNOOB a minúsculas:

SELECT LCASE('RUNOOB') -- runoob
LEFT(s,n) Devuelve los primeros n caracteres de la cadena s.

Devuelve los primeros dos caracteres de la cadena 'runoob':

SELECT LEFT('runoob',2) -- ru
LOWER(s) Convierte todas las letras de la cadena s a minúsculas.

Convierte la cadena RUNOOB a minúsculas:

SELECT LOWER('RUNOOB') -- runoob
LPAD(s1,len,s2) Rellena el inicio de la cadena s1 con la cadena s2 hasta que la longitud de la cadena alcance len.

Rellena el inicio de la cadena 'abc' con la cadena 'xx':

SELECT LPAD('abc',5,'xx') -- xxabc
LTRIM(s) Elimina los espacios al inicio de la cadena s.

Elimina los espacios al inicio de la cadena RUNOOB:

SELECT LTRIM("    RUNOOB") AS LeftTrimmedString;-- RUNOOB
MID(s,n,len) Extrae una subcadena de longitud len desde la posición n de la cadena s, igual que SUBSTRING(s,n,len).

Extrae 3 caracteres desde la segunda posición de la cadena RUNOOB:

SELECT MID("RUNOOB", 2, 3) AS ExtractString; -- UNO
POSITION(s1 IN s) Obtiene la posición inicial de s1 dentro de la cadena s.

Devuelve la posición de 'b' en la cadena 'abc':

SELECT POSITION('b' in 'abc') -- 2
REPEAT(s,n) Repite la cadena s n veces.

Repite la cadena 'runoob' tres veces:

SELECT REPEAT('runoob',3) -- runoobrunoobrunoob
REPLACE(s,s1,s2) Reemplaza la cadena s1 en la cadena s con la cadena s2.

Reemplaza el carácter 'a' en la cadena 'abc' por el carácter 'x':

SELECT REPLACE('abc','a','x') --xbc
REVERSE(s) Invierte el orden de la cadena s.

Invierte el orden de la cadena 'abc':

SELECT REVERSE('abc') -- cba
RIGHT(s,n) Devuelve los últimos n caracteres de la cadena s.

Devuelve los últimos dos caracteres de la cadena 'runoob':

SELECT RIGHT('runoob',2) -- ob
RPAD(s1,len,s2) Agrega la cadena s2 al final de la cadena s1 hasta que la longitud de la cadena alcance len.

Agrega la cadena 'xx' al final de la cadena 'abc':

SELECT RPAD('abc',5,'xx') -- abcxx
RTRIM(s) Elimina los espacios al final de la cadena s.

Elimina los espacios al final de la cadena RUNOOB:

SELECT RTRIM("RUNOOB     ") AS RightTrimmedString;   -- RUNOOB
SPACE(n) Devuelve n espacios.

Devuelve 10 espacios:

SELECT SPACE(10);
STRCMP(s1,s2) Compara las cadenas s1 y s2. Si s1 es igual a s2 devuelve 0, si s1>s2 devuelve 1, si s1<s2 devuelve -1.

Compara cadenas:

SELECT STRCMP("runoob", "runoob");  -- 0
SUBSTR(s, start, length) Extrae una subcadena de longitud length desde la posición start de la cadena s.

Extrae 3 caracteres desde la segunda posición de la cadena RUNOOB:

SELECT SUBSTR("RUNOOB", 2, 3) AS ExtractString; -- UNO
SUBSTRING(s, start, length) Extrae una subcadena de longitud length desde la posición start de la cadena s, equivalente a SUBSTR(s, start, length).

Extrae 3 caracteres desde la segunda posición de la cadena RUNOOB:

SELECT SUBSTRING("RUNOOB", 2, 3) AS ExtractString; -- UNO
SUBSTRING_INDEX(s, delimiter, number) Devuelve la subcadena después de la enésima aparición del delimitador delimiter en la cadena s.
Si number es positivo, devuelve la cadena a la izquierda del delimitador número number.
Si number es negativo, devuelve la cadena a la derecha del delimitador número (valor absoluto de number contando desde la derecha).		 
SELECT SUBSTRING_INDEX('a*b','*',1) -- a
SELECT SUBSTRING_INDEX('a*b','*',-1)    -- b
SELECT SUBSTRING_INDEX(SUBSTRING_INDEX('a*b*c*d*e','*',3),'*',-1)    -- c
TRIM(s) Elimina los espacios al inicio y al final de la cadena s.

Elimina los espacios al inicio y al final de la cadena RUNOOB:

SELECT TRIM('    RUNOOB    ') AS TrimmedString;
UCASE(s) Convierte la cadena a mayúsculas.

Convierte la cadena 'runoob' a mayúsculas:

SELECT UCASE("runoob"); -- RUNOOB
UPPER(s) Convierte la cadena a mayúsculas.

Convierte la cadena 'runoob' a mayúsculas:

SELECT UPPER("runoob"); -- RUNOOB

Funciones numéricas de MySQL

Nombre de la función Descripción Ejemplo
ABS(x) Devuelve el valor absoluto de x.

Devuelve el valor absoluto de -1:

SELECT ABS(-1) -- 返回1
ACOS(x) Devuelve el arcocoseno de x (en radianes); x es un valor numérico. 
SELECT ACOS(0.25);
ASIN(x) Devuelve el arcoseno de x (en radianes); x es un valor numérico. 
SELECT ASIN(0.25);
ATAN(x) Devuelve el arcotangente de x (en radianes); x es un valor numérico. 
SELECT ATAN(2.5);
ATAN2(n, m) Devuelve el arcotangente (en radianes). 
SELECT ATAN2(-0.8, 2);
AVG(expression) Devuelve el valor promedio de una expresión; expression es un campo.

Devuelve el valor promedio del campo Price en la tabla Products:

SELECT AVG(Price) AS AveragePrice FROM Products;
CEIL(x) Devuelve el entero más pequeño mayor o igual que x. 
SELECT CEIL(1.5) -- 返回2
CEILING(x) Devuelve el entero más pequeño mayor o igual que x. 
SELECT CEILING(1.5); -- 返回2
COS(x) Devuelve el coseno (el parámetro está en radianes). 
SELECT COS(2);
COT(x) Devuelve la cotangente (el parámetro está en radianes). 
SELECT COT(6);
COUNT(expression) Devuelve el número total de registros de la consulta; el parámetro expression es un campo o un asterisco.

Devuelve el número total de registros del campo products en la tabla Products:

SELECT COUNT(ProductID) AS NumberOfProducts FROM Products;
DEGREES(x) Convierte radianes a grados. 
SELECT DEGREES(3.1415926535898) -- 180
n DIV m División entera; n es el dividendo, m es el divisor.

Calcula 10 dividido entre 5:

SELECT 10 DIV 5;  -- 2
EXP(x) Devuelve e elevado a la x.

Calcula e elevado a la tercera potencia:

SELECT EXP(3) -- 20.085536923188
FLOOR(x) Devuelve el entero más grande menor o igual que x.

El entero menor o igual que 1.5:

SELECT FLOOR(1.5) -- 返回1
GREATEST(expr1, expr2, expr3, ...) Devuelve el valor máximo de la lista.

Devuelve el valor máximo de la siguiente lista de números:

SELECT GREATEST(3, 12, 34, 8, 25); -- 34

Devuelve el valor máximo de la siguiente lista de cadenas:

SELECT GREATEST("Google", "Runoob", "Apple");   -- Runoob
LEAST(expr1, expr2, expr3, ...) Devuelve el valor mínimo de la lista.

Devuelve el valor mínimo de la siguiente lista de números:

SELECT LEAST(3, 12, 34, 8, 25); -- 3

Devuelve el valor mínimo de la siguiente lista de cadenas:

SELECT LEAST("Google", "Runoob", "Apple");   -- Apple
LN Devuelve el logaritmo natural de un número, en base e.

Devuelve el logaritmo natural de 2:

SELECT LN(2);  -- 0.6931471805599453
LOG(x) o LOG(base, x) Devuelve el logaritmo natural (logaritmo en base e). Si se proporciona el parámetro base, entonces base es la base especificada. 
SELECT LOG(20.085536923188) -- 3
SELECT LOG(2, 4); -- 2
LOG10(x) Devuelve el logaritmo en base 10. 
SELECT LOG10(100) -- 2
LOG2(x) Devuelve el logaritmo en base 2.

Devuelve el logaritmo de 6 en base 2:

SELECT LOG2(6);  -- 2.584962500721156
MAX(expression) Devuelve el valor máximo del campo expression.

Devuelve el valor máximo del campo Price en la tabla Products:

SELECT MAX(Price) AS LargestPrice FROM Products;
MIN(expression) Devuelve el valor mínimo del campo expression.

Devuelve el valor mínimo del campo Price en la tabla Products:

SELECT MIN(Price) AS MinPrice FROM Products;
MOD(x,y) Devuelve el resto de dividir x entre y.

El resto de dividir 5 entre 2:

SELECT MOD(5,2) -- 1
PI() Devuelve el número pi (3.141593). 
SELECT PI() --3.141593
POW(x,y) Devuelve x elevado a la y.

2 elevado a la 3:

SELECT POW(2,3) -- 8
POWER(x,y) Devuelve x elevado a la y.

2 elevado a la 3:

SELECT POWER(2,3) -- 8
RADIANS(x) Convierte grados a radianes.

Convierte 180 grados a radianes:

SELECT RADIANS(180) -- 3.1415926535898
RAND() Devuelve un número aleatorio entre 0 y 1. 
SELECT RAND() --0.93099315644334
ROUND(x [,y]) Devuelve el entero más cercano a x; el parámetro opcional y indica el número de decimales para redondear. Si se omite, devuelve un entero. 
SELECT ROUND(1.23456) --1

SELECT ROUND(345.156, 2) -- 345.16
SIGN(x) Devuelve el signo de x. Si x es negativo, 0 o positivo, devuelve -1, 0 y 1 respectivamente. 
SELECT SIGN(-10) -- (-1)
SIN(x) Calcular el seno (el parámetro está en radianes) 
SELECT SIN(RADIANS(30)) -- 0.5
SQRT(x) Devuelve la raíz cuadrada de x

Raíz cuadrada de 25:

SELECT SQRT(25) -- 5
SUM(expression) Devuelve la suma de un campo especificado

Calcula la suma del campo Quantity en la tabla OrderDetails:

SELECT SUM(Quantity) AS TotalItemsOrdered FROM OrderDetails;
TAN(x) Calcular la tangente (el parámetro está en radianes) 
SELECT TAN(1.75);  -- -5.52037992250933
TRUNCATE(x,y) Devuelve el valor de x con y decimales (la mayor diferencia con ROUND es que no realiza redondeo) 
SELECT TRUNCATE(1.23456,3) -- 1.234

Funciones de fecha de MySQL

Nombre de la función Descripción Ejemplo

SELECT ADDDATE("2017-06-15", INTERVAL 10 DAY);
->2017-06-25

Sumar 5 segundos:

SELECT ADDTIME('2011-11-11 11:11:11', 5);
->2011-11-11 11:11:16 (秒)

Agregar 2 horas, 10 minutos, 5 segundos:

SELECT ADDTIME("2020-06-15 09:34:21", "2:10:5"); 
-> 2020-06-15 11:44:26

-> 2018-09-19

-> 2018-09-19

SELECT CURRENT_TIMESTAMP()
-> 2018-09-19 20:57:43
CURTIME() Devuelve la hora actual 
SELECT CURTIME();
-> 19:59:02
DATE() Extrae el valor de fecha de una expresión de fecha o fecha-hora 
SELECT DATE("2017-06-15");    
-> 2017-06-15
DATEDIFF(d1,d2) Calcula el número de días entre las fechas d1 y d2 
SELECT DATEDIFF('2001-01-01','2001-02-02')
-> -32
DATE_ADD(d，INTERVAL expr type) Calcula la fecha resultante de sumar un intervalo a la fecha inicial d; el valor de type puede ser:
  • MICROSECOND
  • SECOND
  • MINUTE
  • HOUR
  • DAY
  • WEEK
  • MONTH
  • QUARTER
  • YEAR
  • SECOND_MICROSECOND
  • MINUTE_MICROSECOND
  • MINUTE_SECOND
  • HOUR_MICROSECOND
  • HOUR_SECOND
  • HOUR_MINUTE
  • DAY_MICROSECOND
  • DAY_SECOND
  • DAY_MINUTE
  • DAY_HOUR
  • YEAR_MONTH
 
SELECT DATE_ADD("2017-06-15", INTERVAL 10 DAY);    
-> 2017-06-25

SELECT DATE_ADD("2017-06-15 09:34:21", INTERVAL 15 MINUTE);
-> 2017-06-15 09:49:21

SELECT DATE_ADD("2017-06-15 09:34:21", INTERVAL -3 HOUR);
->2017-06-15 06:34:21

SELECT DATE_ADD("2017-06-15 09:34:21", INTERVAL -3 MONTH);
->2017-03-15 09:34:21
DATE_FORMAT(d,f) Muestra la fecha d según lo requerido por la expresión f 
SELECT DATE_FORMAT('2011-11-11 11:11:11','%Y-%m-%d %r')
-> 2011-11-11 11:11:11 AM
DATE_SUB(date,INTERVAL expr type) La función resta el intervalo de tiempo especificado a una fecha.

Restar 2 días al campo OrderDate de la tabla Orders:

SELECT OrderId,DATE_SUB(OrderDate,INTERVAL 2 DAY) AS OrderPayDate
FROM Orders
DAY(d) Devuelve la parte de fecha del valor de fecha d

-> 15
DAYNAME(d) Devuelve el día de la semana de la fecha d, como Monday, Tuesday

DAYOFMONTH(d) Calcula qué día del mes es la fecha d

DAYOFWEEK(d) Devuelve el día de la semana de la fecha d: 1 es domingo, 2 es lunes, etc.

DAYOFYEAR(d) Calcula qué día del año es la fecha d

->315

11:11:11 AM

-> 00:00:01

    ->                 '2000:01:01 00:00:00.000001');
        -> '-00:00:00.000001'

    ->                 '2008-12-30 01:01:01.000002');
        -> '46:58:57.999999'
TIMESTAMP(expression, interval) Con un solo parámetro, la función devuelve una fecha o expresión de fecha-hora; con dos parámetros, suma los parámetros 
mysql> SELECT TIMESTAMP("2017-07-23",  "13:10:11");
-> 2017-07-23 13:10:11
mysql> SELECT TIMESTAMP('2003-12-31');
        -> '2003-12-31 00:00:00'
mysql> SELECT TIMESTAMP('2003-12-31 12:00:00','12:00:00');
        -> '2004-01-01 00:00:00'
TIMESTAMPDIFF(unit,datetime_expr1,datetime_expr2) Calcula la diferencia de tiempo y devuelve la diferencia entre datetime_expr2 y datetime_expr1

mysql> SELECT TIMESTAMPDIFF(MONTH,'2003-02-01','2003-05-01');   // 计算两个时间相隔多少月
        -> 3
mysql> SELECT TIMESTAMPDIFF(YEAR,'2002-05-01','2001-01-01');    // 计算两个时间相隔多少年
        -> -1
mysql> SELECT TIMESTAMPDIFF(MINUTE,'2003-02-01','2003-05-01 12:05:55');  // 计算两个时间相隔多少分钟
        -> 128885

SELECT YEAR("2017-06-15");
-> 2017
YEARWEEK(date, mode) Devuelve el año y el número de semana (0 a 53); en mode, 0 significa domingo, 1 significa lunes, etc. 
SELECT YEARWEEK("2017-06-15");
-> 201724

Funciones avanzadas de MySQL

Nombre de la función Descripción Ejemplo
BIN(x) Devuelve la representación binaria de x, donde x es un número decimal

Representación binaria de 15:

SELECT BIN(15); -- 1111
BINARY(s) Convierte la cadena s a una cadena binaria 
SELECT BINARY "RUNOOB";
-> RUNOOB

    ELSE result

SELECT CASE 
　　WHEN 1 > 0
　　THEN '1 > 0'
　　WHEN 2 > 0
　　THEN '2 > 0'
　　ELSE '3 > 0'
　　END

    Requisito:Tomar de la base de datos una tabla con un registro por minuto, desde 9:30 hasta 22:00, resumir en intervalos de media hora y exportar a Excel.

    Campos de la tabla de datos: id (número de secuencia), incount (conteo), cdate (fecha/hora del dato)

    Nombre de la tabla: m_temp

    Dificultad: procesamiento del tiempo

    Solución: utilizar las funciones DATE_FORMAT, CONCAT, Date, Hour, Minute y Floor para convertir el tiempo a intervalos de media hora; al consultar los datos de este período, transformar la salida de cdate a 09:30, luego agrupar por cdate y sumar con sum(incount).

    1. Procesar el tiempo:

    Ejemplo: de 2018-08-21 09:30:00 a 2018-08-21 22:00:00

    Primer intervalo de media hora: 09:30 a 10:00

    Al consultar los datos de este período, transformar la salida de cdate a 09:30, luego agrupar por cdate y sumar con sum(incount)

    Dividir los minutos entre 30: los minutos 0-29 dan como resultado 0, y los minutos 30-59 dan como resultado 1; luego multiplicar por 30 minutos para convertirlo en 00 o 30.

    date(cdate): extrae el año, mes y día;

    hour(cdate): extrae la hora;

    minute(cdate): extrae los minutos;

    Calcular (minute(cdate) / 30) * 30; el resultado es 0 o 30;

    floor((minute(cdate) / 30) * 30): se procesa como entero;

    concat(date(cdate),' ',hour(cdate),':',floor((minute(cdate))/30)*30): se concatena según el formato de fecha

    DATE_FORMAT(concat(date(cdate),' ',hour(cdate),':',floor(minute(cdate)/30)*30+12),'%Y-%m-%d %H:%i'): se convierte al tipo de dato date.

    SQL completo:

    select sum(incount),dataStartTime from (
select incount, DATE_FORMAT( concat(date(cdate),' ',hour(cdate),':',floor( minute(cdate)/30 )*30+12) ,'%Y-%m-%d %H:%i')  as dataStartTime   
 from m_temp WHERE cdate>='2018-08-21 09:30' and cdate<='2018-08-21 22:00'  ORDER BY dataStartTime
) a
group by DATE_FORMAT( dataStartTime ,'%Y-%m-%d %H:%i')
into outfile('c:/2018-08-21Data.xls');
