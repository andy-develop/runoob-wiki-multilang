Example Analysis - showHint() Function

When the user types a character in the input box above, the function "showHint()" is executed. This function is triggered by the "onkeyup" event:

function showHint(str) { var xmlhttp; if (str.length==0) { document.getElementById("txtHint").innerHTML=""; return; } if (window.XMLHttpRequest) { //Code for IE7+, Firefox, Chrome, Opera, Safari browsers xmlhttp=new XMLHttpRequest(); } else { //Code for IE6, IE5 browsers xmlhttp=new ActiveXObject("Microsoft.XMLHTTP"); } xmlhttp.onreadystatechange=function() { if (xmlhttp.readyState==4 && xmlhttp.status==200) { document.getElementById("txtHint").innerHTML=xmlhttp.responseText; } } xmlhttp.open("GET","/try/ajax/gethint.php?q="+str,true); xmlhttp.send(); }

Source code analysis:

If the input box is empty,str.length==0then the function clearstxtHintthe placeholder's content, and exits the function.

If the input box is not empty,showHint()the function performs the following tasks:

  • CreateXMLHttpRequestobject
  • Execute a function when the server response is ready
  • Send the request to a file on the server
  • Note that we added a parameter q (with the content of the input box) to the URL

    The values of xmlhttp.readyState and their explanations:

    0: Request not initialized (open() has not been called yet).

    1: Request established, but not sent yet (send() has not been called yet).

    2: Request sent, processing in progress (usually the content headers can now be retrieved from the response).

    3: Request in process; usually part of the response data is already available, but the server has not finished generating the response.

    4: Response complete; you can retrieve and use the server's response.

    The values of xmlhttp.status and their explanations:

    100 – The client must continue making the request

    101 – The client requests the server to switch HTTP protocol versions according to the request

    200 – Transaction successful

    201 – Indicates that the URL of the new file is known

    202 – Accepted and processing, but processing is incomplete

    203 – Returned information is uncertain or incomplete

    204 – Request received, but the returned information is empty

    205 – The server completed the request; the user agent must reset the currently viewed file

    206 – The server has completed a partial GET request

    300 – The requested resource is available in multiple locations

    301 – Delete requested data

    302 – The requested data was found at another address

    303 – Suggest the client visit another URL or use another access method

    304 – The client has already performed a GET, but the file has not changed

    305—The requested resource must be obtained from the address specified by the server

    306—Code used in previous versions of HTTP, no longer used in the current version

    307—Declares that the requested resource has been temporarily deleted

    400—Bad request, such as a syntax error

    401—Request authorization failed

    402—Reserved for a valid ChargeTo header response

    403—Request not allowed

    404—No file, query, or URL found

    405—The method defined by the user in the Request-Line field is not allowed

    406—The requested resource is not accessible according to the Accept header sent by the user

    407—Similar to 401, the user must first obtain authorization from the proxy server

    408—The client did not complete the request within the user-specified time

    409—The request cannot be completed due to the current resource state

    410—The resource no longer exists on the server and there is no further reference address

    411—The server rejects the request with a user-defined Content-Length attribute

    412—One or more request header fields are incorrect in the current request

    413—The requested resource is larger than the size allowed by the server

    414—The URL of the requested resource is longer than the length allowed by the server

    415—The requested resource does not support the format of the request item

    416—The request contains a Range request header field, but there is no range indicator value within the current requested resource range, and the request does not contain an If-Range request header field

    417—The server cannot satisfy the expectation specified in the Expect request header field. If it is a proxy server, it may be that the next-level server cannot satisfy the request

    Combined

    500—The server generated an internal error

    501—The server does not support the requested function

    502—The server is temporarily unavailable, sometimes to prevent system overload

    503—The server is overloaded or temporarily down for maintenance

    504—Gateway overload; the server uses another gateway or service to respond to the user, and the waiting time setting is long

    505—The server does not support or refuses the HTTP version specified in the request header

    1xx: Informational response class, indicating that the request has been received and processing continues

    2xx: Successful processing response class, indicating that the action was successfully received, understood, and accepted

    3xx: Redirection response class; to complete the specified action, further processing must be accepted

    4xx: Client error — the client request contains a syntax error or cannot be executed correctly

    5xx: Server error — the server cannot correctly execute a valid request

    xmlhttp.readyState==4 && xmlhttp.status==200Explanation: The request completed and returned successfully
