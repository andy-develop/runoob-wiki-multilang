HTML DOM Events

HTML DOM events allow JavaScript to register different event handlers on HTML document elements.

Events are usually used in combination with functions, and functions will not be executed before the event occurs! (such as when a user clicks a button).

Tip:The event model is standardized in the W3C DOM Level 2 Events.

HTML DOM Events

DOM：Indicates the DOM attribute level used.
