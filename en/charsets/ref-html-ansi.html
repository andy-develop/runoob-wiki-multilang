ANSI（Windows-1252）

ANSI is the default character set in Windows 95 and earlier Windows systems.

ANSI is also known as Windows-1252.

Important Notes

ANSI and ISO-8859-1 are very similar, differing only in 32 characters.

In ANSI, characters from 128 to 159 are used for useful characters, such as the euro sign.

In ISO-8859-1, these characters map to control characters that do not function in HTML.

Many web developers declare ISO-8859-1 and use these 32 values as if they were Windows-1252.

Due to this common misunderstanding, browsers will switch to Windows-1252 when ISO-8859-1 is declared. This applies to the following document types: HTML4, HTML5, and XHTML.

ANSI and ASCII

The first part of ANSI (entity numbers 0-127) is the original ASCII character set. It contains digits, uppercase and lowercase English letters, and some special characters.

For more information on ASCII, see thecomplete ASCII reference manual。

ANSI Control Characters

ANSI control characters (00-31, plus 127) were originally designed to control hardware devices such as printers and tape drives.

Control characters (other than horizontal tab, line feed, and carriage return) have no effect in HTML documents.
