UTF-8 Greek (Greek alphabet) and Coptic (Coptic alphabet)

Range: decimal 880-1023, hexadecimal 0370-03FF.

If you want to display these characters in HTML, you can use the HTML entities in the table below.

If a character does not have an HTML entity, you can use decimal or hexadecimal references.

Examples

<p>I will display &Delta;<p>
<p>I will display &#916;<p>
<p>I will display &#x0394;<p>

The result is as follows:

I will display Δ
I will display Δ
I will display Δ
