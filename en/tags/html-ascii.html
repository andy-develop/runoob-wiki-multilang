The ASCII character set is used to transmit information between different computers over the Internet.

ASCII Character Set

ASCII, whose full name is "American Standard Code for Information Interchange", was designed in the early 1960s and is the standard character set for computers and hardware devices such as printers and tape drives.

ASCII is a 7-bit character set containing 128 different character values.

ASCII supports the digits 0-9, uppercase and lowercase English letters A-Z, and some special characters.

The character sets widely used in modern computers, HTML, and the Internet are all based on ASCII.

The following table lists 128 ASCII characters and their corresponding HTML entity codes.

ASCII Device Control Characters

The ASCII control characters (00-31, plus 127) were originally designed to control hardware devices such as printers and tape drives.

Control characters (except horizontal tab, line feed, and carriage return) have no effect in HTML documents.
