Bootstrap Grid System

Introduction

In this tutorial, you will learn how to use Bootstrap to create a grid system.

As you may know, in graphic design, a grid system is a two-dimensional structure composed of intersecting horizontal and vertical axes used to build content. It is widely used in the layout design and content structure of graphic design. In web design, it is a very effective method for quickly and efficiently creating consistent layouts by using HTML and CSS. Therefore, the grid system has become an important component/module of the framework or workflow of web design.

Simply put, in web design, we use HTML and CSS to create rows and columns to implement a grid, and the columns contain the actual content.

Since version 2.3.2, Bootstrap has provided two types of grids. The default grid system is 940px wide with 12 columns. You can add a responsive stylesheet to make it adjust its width to 724px and 1170px according to the viewport.

There is also a fluid grid system, which is percentage-based rather than pixel-based. It can also be extended to be responsive like the default fixed grid. In this tutorial, we will discuss the default grid through some examples. The fluid grid system will be covered in a separate tutorial.

Please download the latest version of Bootstrap files from "http://twitter.github.io/bootstrap/assets/bootstrap.zip". You can find the relevant file structure in ourGetting Started Tutorialto learn about the relevant file structure.

In this way, we have created a three-column grid by using the "span4" class for each column. The "container" class is used to hold the entire structure.You can view the online example here. From this point, we can deduce the general syntax of the CSS class used to create a given number of columns.

General syntax for creating a grid:

<div class=&quot;row&quot;>
<div class=&quot;spanx&quot;>
inline elements like span, block level elements like p, div.
</div>
repeat <div class=&quot;spanx&quot;> y times.

Where y is the number of columns you want to create, and the sum of x equals 12 (this is the maximum number of columns you can create). x must be a positive integer, and its value must be from 1 to 12.

For example, if you have three equal-width columns, each column is class="span4", but if you want the first column to be larger than the other two, you can use class="span6" for the first column and class="span3" for the other two.

How to Create Rows in a Fixed Grid

Next, before we continue with other examples, let's take a look at the CSS rules used to create rows and columns in the fixed grid.

The row class is as follows

.row {
    margin-left: -20px;
    *zoom: 1;
}

Set the left margin to -20px and set "*zoom: 1;". The "*" here indicates that the zoom property of all elements is set to 1, used to fix IE6/7 bugs. Setting the zoom property to 1 sets an internal property named hasLayout, which is used to fix many scaling/rendering issues in IE6/7.

.row:before,
.row:after {
    display: table;
    line-height: 0;
    content: "";
}

Bootstrap uses the preceding CSS code to create rows. It uses the ":before" and ":after" CSS properties. These two are pseudo-elements. ":before" is used to insert some content before the target element, and ":after" is used to insert some content after the target element. "display:table;" makes the element render in table form. By setting "line-height: 0;" it ensures that each row does not have its own line height, and by using 'content: ""' it ensures that no content is inserted before or after the element.

Then the following rule is used to ensure that there are no floated elements on the left or right side of a given element.

.row:after {
    clear: both;
}

How to Create Columns in a Fixed Grid

[class*="span"] {
    float: left;
    min-height: 1px;
    margin-left: 20px;
}

These are the CSS rules to use. '[class*="span"]' selects all elements whose class attribute value starts with 'span'. Now use "float: left;" to position each column adjacent to each other. Use "min-height: 1px" to give all columns a minimum height of 1px, and use "margin-left: 20px;" to set the left margin to 20px.

Adding Responsiveness to the Default Grid

If you want to add responsiveness to Bootstrap's default grid, simply add the following after the original CSS in the HTML file:

<meta name="viewport" content="width=device-width, initial-scale=1.0"><link href="bootstrap/css/bootstrap-responsive.min.css.html" rel="stylesheet">

To view the responsive default grid,Click here to view the online demo.。Click here to download the related code.。

The default grid system becomes responsive under two conditions. When the viewport (the available space for grid rendering) is greater than 1200px [obtained via @media (min-width: 1200px)], and when the viewport is greater than 768px but less than 979px [set via @media (min-width: 768px) and (max-width: 979px)].

Offset Columns: Default Grid

By using offsets, you can move a column to the right of its original position. This is achieved by adding a left margin to the column. With Bootstrap, you can use the "offsetx" class (where x is a positive integer) and the class "spany" (where y is a positive integer). Depending on the value of 'x' in 'offestx', the relevant column moves to the right by the width of 'x' columns.

The offset widths are defined in the Bootstrap CSS. The maximum left margin for offset12 is 980px, and the minimum left margin for offset1 is 100px.

Since the default grid system is pixel-based, when applying offsets you must know the pixels you will use for the offset and the pixels to use for the columns. The sum of these two must not exceed the number of pixels in your horizontal viewport.

Conclusion

In this tutorial, we have discussed Bootstrap's default grid system. This tutorial is based on Bootstrap V2.3.2. The following is a summary of the key points in this tutorial:

  • Bootstrap's default grid system is 940px wide and has 12 columns.
  • In the grid, rows are created with 'class="row"', and columns are created with 'class="spanx"', where x is a positive integer. The sum of all column values x must not exceed 12.
  • You can add responsiveness to the default grid by adding Bootstrap's responsive CSS.
  • Use offsets to create extra space for columns. By using 'class="offsetx"', where x is a positive integer. If you use offsets, the total number of columns, including the number used for offsets, must not exceed 11.
  • Columns can be nested. If nested columns are used, they are also counted when calculating the total number of columns in the grid (a row within the container).
  • Offsets can also be used in nested columns.
