Linux find Command

Linux Command Encyclopedia

The Linux find command is used to search for files and directories under a specified directory.

It can use different options to filter and limit the search results.

Syntax

find [路径] [匹配条件] [动作]

Parameter Description :

PathThis is the directory path to search. It can be a directory or file name, or multiple paths, separated by spaces. If no path is specified, it defaults to the current directory.

expressionThis is an optional parameter used to specify the search condition; it can be a file name, file type, file size, and so on.

There are as many as twenty or thirty options available in the matching conditions. The most commonly used ones are listed below:

  • -name pattern: Search by file name; wildcards are supported.* 和 ?。
  • -type type: Search by file type; it can bef(regular files),d(directories),l(symbolic links), etc.
  • -size [+-]size[cwbkMG]: Search by file size; it supports using+ 或 -to indicate greater than or less than the specified size; the unit can bec(bytes),w(words),b(block count),k（KB）、M(MB), orG（GB）。
  • -mtime days: Search by modification time; it supports using+ 或 -to indicate before or after the specified number of days; days is an integer representing the number of days.
  • -user username: Search by file owner.
  • -group groupname: Search by file group.

Actions:Optional; used to perform operations on the matched files, such as deletion, copying, etc.

The time-related parameters in the find command are as follows:

  • -amin n: Find files that were accessed within n minutes.
  • -atime n: Find files that were accessed within n*24 hours.
  • -cmin n: Find files whose status changed within n minutes (e.g., permissions).
  • -ctime n: Find files whose status changed within n*24 hours (e.g., permissions).
  • -mmin n: Find files that were modified within n minutes.
  • -mtime n: Find files that were modified within n*24 hours.

In these parameters, n can be a positive number, a negative number, or zero. A positive number indicates files modified or accessed within the specified time, a negative number indicates files modified or accessed before the specified time, and zero indicates files modified or accessed at the current point in time.

Positive numbers should represent before the specified time, and negative numbers represent within the specified time.

For example:-mtime 0Indicates searching for files modified today,-mtime -7Indicates searching for files modified more than a week ago.

Explanation of the time n parameter:

  • +n: Find files or directories older than n days.

  • -n: Find files or directories whose attributes were changed within n days.

  • n: Find files or directories whose attributes were changed n days ago (on that specified day).

Examples

Find the file named file.txt in the current directory:

find . -name file.txt

List all files in the current directory and its subdirectories with the suffix.cand list the files:

# find . -name "*.c"

List all files in the current directory and its subdirectories:

# find . -type f

Find files larger than 1MB in the /home directory:

find /home -size +1M

Find files in the /var/log directory modified 7 days ago:

find /var/log -mtime +7

Find files accessed within the past 7 days:

find /path/to/search -atime -7

Find files and directories whose status has changed within the last 20 days in the current directory:

# find . -ctime  20

List all files in the current directory and its subdirectories that were updated 20 days ago or earlier:

# find . -ctime  +20

Find regular files in the /var/log directory whose modification time is more than 7 days ago, and ask for confirmation before deleting them:

# find /var/log -type f -mtime +7 -ok rm {} \;

Find files in the current directory where the file owner has read and write permissions, and the group users and other users have read permission:

# find . -type f -perm 644 -exec ls -l {} \;

Find all regular files with a file length of 0 in the system, and list their full paths:

# find / -type f -size 0 -exec ls -l {} \;

Find and perform operations (e.g., delete):

find /path/to/search -name "pattern" -exec rm {} \;

In this example,-execthe option allows you to execute a command,{}will be replaced by the matched file name,\;indicates the end of the command.

    Scenario 1: The server disk is full, usually caused by large log files; you need to find large files and delete them.

    Solution 1: find / -size +500M -print0|xargs -0 du -m|sort -nr

    The find command is used to find files larger than 500M. Use print0 in combination with xargs -0 to solve the problem of spaces or special characters in file names. du -m is to check the size of these files and display it in m units. Finally, sort -nr sorts in reverse numeric order (large files first).

    Solution 2: The above method searches from the root path and may list some system files. You can filter a bit before this search.

    Usedu -m -d 1 /|sort -nr First check under the root path which folder is relatively large and is suspected of being the culprit that causes the disk to be full. Then perform find based on that directory.

    Solution: find / -name *xxx*.cFuzzy search for this file.

    find searches for files by file modification time:

    ---(+n)----------|----------(n)----------|----------(-n)---
      (n+1)*24H前|   (n+1)*24H~n*24H间   |n*24H内
    • -ctime -n-- Find files modified within the last n*24H
    • -ctime n-- Find files modified between n*24H and (n+1)*24H ago
    • -ctime +n-- Find files modified more than (n+1)*24H ago
    • [a|c|m]min-- [last access|last status change|last content modification]min
    • [a|c|m]time-- [last access|last status change|last content modification]time

    Several types of time for Linux files (using find as an example):

    • atime is the last access time, such as ls, more, etc., but chmod, chown, ls, stat, etc. do not modify this time; use ls -utl to view in order of this time;
    • ctime is the last status change time. For example, chmod, chown, etc. change the status time, but the modification time does not change; use stat file to view it.
    • mtime is the last content modification time, such as after vi saves, etc. If the modification time changes, atime and ctime also change accordingly.

    Note: Linux does not record the creation time of a file. Unless this file has not been modified since its creation, in that case its creation time is its last modification time.

    View sorted by modification time:
    ls -lt  ./

    View sorted by access time:

    ls -lut ./

    If you want to view in reverse order, you need to add an option.-r。

    find   ~   -type "*.cpp"  -exec ls  -l {}\;

    exec sends the entire set of search results to the following command at once. If there are many search results, it can cause data overflow. When using ls, if the data exceeds 160,000, the command will report an error.

    Use pipes and xargs to avoid this problem:

    find   ~   -type "*.cpp"  | xargs ls  -l

    xargs sends the search results to the following command in chunks.
