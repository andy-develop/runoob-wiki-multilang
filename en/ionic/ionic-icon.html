ionic icon

Ionic also provides many icons by default, about 700+, with different styles for Android and iOS.

Ionic icons official website:http://ionicons.com/

Domestic icon style CDN address:https://cdn.staticfile.net/ionicons/2.0.1/css/ionicons.min.css。

The usage is also very simple, consisting of an icon class and a specified icon class, such as:

Example

<i class="icon ion-star"></i> <i class = "icon ion-happy-outline"></i> <i class = "icon ion-ios-analytics"></i> <i class = "icon ion-ios-eye"></i>

Try it »

We can set the size of the image by font-size:

Example

.icon { font-size: 50px; }

Try it »
