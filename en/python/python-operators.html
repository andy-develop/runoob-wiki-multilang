Python Operators

What is an Operator?

This chapter mainly explains Python operators. Let's take a simple example 4 +5 = 9 In the example,4 和 5is calledoperand，+is called an operator.

The Python language supports the following types of operators:

  • Arithmetic operators
  • Comparison (relational) operators
  • Assignment operators
  • Logical operators
  • Bitwise operators
  • Membership operators
  • Identity operators
  • Operator precedence

Next, let's learn Python operators one by one.

Python Bitwise Operators

Bitwise operators treat numbers as binary for calculation. The bitwise operation rules in Python are as follows:

In the table below, variable a is 60 and b is 13, with binary formats as follows:

a = 0011 1100

b = 0000 1101

-----------------

a&b = 0000 1100

a|b = 0011 1101

a^b = 0011 0001

~a  = 1100 0011
OperatorDescriptionExample
&Bitwise AND operator: For the two values involved in the operation, if both corresponding bits are 1, the result bit is 1; otherwise, it is 0.(a & b) outputs 12, binary explanation: 0000 1100
|Bitwise OR operator: As long as one of the two corresponding binary bits is 1, the result bit is 1.(a | b) outputs 61, binary explanation: 0011 1101
^Bitwise XOR operator: When the two corresponding binary bits are different, the result is 1.(a ^ b) outputs 49, binary explanation: 0011 0001
~Bitwise NOT operator: Inverts each bit in the binary representation, changing 0 to 1 and 1 to 0.~xSimilar to-x-1(~a ) outputs -61, binary explanation: 1100 0011 (represented in two's complement form), in the two's complement form of a signed binary number.
<<Left shift operator: All binary bits of the operand are shifted left by a number of bits, determined by<<The number on the right specifies the number of positions to shift. High-order bits are discarded, and low-order bits are filled with 0.a << 2 outputs 240, binary explanation: 1111 0000
>>Right shift operator: shifts all binary bits of the operand on the left of ">>" to the right by the specified number of places,>>The number on the right specifies the number of positions to shift.a >> 2 outputs 15, binary explanation: 0000 1111

The following example demonstrates the operations of all bitwise operators in Python:

Examples (Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 60 # 60 = 0011 1100 b = 13 # 13 = 0000 1101 c = 0 c = a & b; # 12 = 0000 1100 print "1 - the value of c is:", c c = a | b; # 61 = 0011 1101 print "2 - the value of c is:", c c = a ^ b; # 49 = 0011 0001 print "3 - the value of c is:", c c = ~a; # -61 = 1100 0011 print "4 - the value of c is:", c c = a << 2; # 240 = 1111 0000 print "5 - the value of c is:", c c = a >> 2; # 15 = 0000 1111 print "6 - the value of c is:", c

The output of the above example is:

1 - c 的值为： 12
2 - c 的值为： 61
3 - c 的值为： 49
4 - c 的值为： -61
5 - c 的值为： 240
6 - c 的值为： 15

Python Identity Operators

Identity operators are used to compare the storage units of two objects

OperatorDescriptionExample
isis determines whether two identifiers reference the same object x is y, similar toid(x) == id(y), if they reference the same object, returns True; otherwise returns False
is notis not determines whether two identifiers reference different objects x is not y, similar toid(a) != id(b). If they do not reference the same object, the result returns True; otherwise returns False.

Note: id()The function is used to get the memory address of an object.

The following example demonstrates the operations of all identity operators in Python:

Examples (Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 20 b = 20 if ( a is b ): print "1 - a and b have the same identity" else: print "1 - a and b do not have the same identity" if ( a is not b ): print "2 - a and b do not have the same identity" else: print "2 - a and b have the same identity" # modify the value of variable b b = 30 if ( a is b ): print "3 - a and b have the same identity" else: print "3 - a and b do not have the same identity" if ( a is not b ): print "4 - a and b do not have the same identity" else: print "4 - a and b have the same identity"

The output of the above example is:

3 - a 和 b 没有相同的标识
4 - a 和 b 没有相同的标识

Difference between is and ==:

is is used to determine whether two variable references refer to the same object (the same memory space), == is used to determine whether the values of the referenced variables are equal.

>>> a = [1, 2, 3]
>>> b = a
>>> b is a 
True
>>> b == a
True
>>> b = a[:]
>>> b is a
False
>>> b == a
True

    The following test conditions will appear in interactive mode; in script mode, the results of is and == are the same.

    In Python, memory is allocated for each object that appears, even if their values are completely equal (note: equal, not identical). For example, when executing the two statements a=2.0, b=2.0, memory is allocated for the Float type object 2.0 one after another, and then a and b respectively point to these two objects. So a and b do not point to the same object:

    >>> a=2.0
>>> b=2.0
>>> a is b
False
>>> a==b
True
>>> e

    However, in order to improve memory utilization efficiency, for some simple objects, such as some int objects with small values, Python adopts the method of reusing object memory. For example, when a=2, b=2, since 2 is a simple int type with a small value, Python does not allocate memory for it twice, but only allocates once, and then makes a and b both point to the allocated object:

    >>> a=2
>>> b=2
>>> a is b
True
>>> a==b
True

    But if the assigned value is not 2 but a large value, the situation is the same as before:

    >>> a=4444
>>> b=4444
>>> a is b
False
>>> a==b
True

    There are no ++ or -- auto-increment/decrement operators in Python

    Because numbers and strings in Python are immutable objects, operations on immutable objects always generate a new object.

    For example:

    a = 1
a += 1

    In languages such as C/Java, the data value of the memory address unit pointed to by a is changed from 1 to 2.

    But in Python, it is a completely different mechanism.

    The interpreter creates a new integer object 2.

    Then it assigns the address of this object to a again.

    See the code below:

    >>> id(1)
41116008L
>>> a = 1
>>> id(a)
41116008L
>>> id(2)
41115984L
>>>a += 1
>>> id(a)
41115984L
>>>

    So in Python, it is impossible to have the kind of thing like C/Java where there is one per linei++，i--of.

    >>> a=[1,2,3,4,5]
>>> b=a
>>> c=a[:]
>>> id(a)
4410359536

4410359536

4410358240

    From the above results, the memory addresses of id(a) and id(b) are the same, while the memory addresses of id(a) and id(c) are different.

    I verified the answer on the first floor. As it said, in Python, using the is keyword to judge two smaller numbers is indeed the same as the == operator, and the result is also true.     I speculate: 256 is exactly an 8-bit binary number, which is one byte. So it can be concluded that when a number can be represented by one byte, is and == give the same result. When the number exceeds one byte, it is treated as a different object. Python allocates different memory for different numbers. Different numbers are different objects, only with the same value. The is result is false, and == is still true.

    After reading the upstairs answer, I understood that Python created a small integer pool to store these numbers that can be represented by one byte. This avoids repeatedly allocating memory for small value numbers, i.e., repeatedly creating objects, improving the runtime performance of the language.
