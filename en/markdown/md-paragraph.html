Markdown Text Format

Markdown paragraphs do not have any special formatting; just write the text directly,A line break in a paragraph is created by using two or more spaces followed by Enter.。

Of course, you can also use a blank line after a paragraph to indicate the start of a new paragraph.

Fonts

Text emphasis is an important technique in writing. Markdown provides a concise way to achieve bold and italic effects.

Markdown can use the following font styles: bold and italic.

Bold syntax:Use two asterisks**or two underscores__to surround the text:

这是**粗体文字**使用星号
这是__粗体文字__使用下划线

Italic syntax:Use one asterisk*or one underscore_to surround the text:

这是*斜体文字*使用星号
这是_斜体文字_使用下划线

Bold and italic combination:Use three asterisks***or three underscores___。

*斜体文本*
_斜体文本_
**粗体文本**
__粗体文本__
***粗斜体文本***
___粗斜体文本___

Mixed usage tips:

这段文字包含**粗体**、*斜体*和***粗斜体***的组合效果。

Usage Recommendations：

  • It is recommended to use asterisks*rather than underscores_, because asterisks have better compatibility across various Markdown parsers.
  • Do not overuse emphasis; only highlighting key points is effective.
  • When mixing Chinese and English, it is recommended to add spaces around emphasis markers to improve readability.

Horizontal Rules

You can create a horizontal rule on a line by using three or more asterisks, hyphens, or underscores. There must be no other content on the line. You can also insert spaces between the asterisks or hyphens. Each of the following notations can create a horizontal rule:

***

* * *

*****

- - -

----------

Footnotes

Footnotes are supplementary explanations to the text.

The format of Markdown footnotes is as follows:

[^要注明的文本]

Text Highlighting (Extended Syntax)

Text highlighting is not standard Markdown syntax, but many extensions support it:

Common syntax(supported by some platforms):

这是==高亮文本==

HTML Alternative：

这是<mark>高亮文本</mark>

Paragraphs and Line Breaks

Creating Paragraphs

In Markdown, paragraphs are the basic units of text. Understanding paragraph rules is crucial for correctly formatting documents.

Basic Paragraph Rules：

  • A paragraph consists of one or more consecutive lines of text.
  • Paragraphs are separated by one or more blank lines.
  • Normal paragraphs should not be indented with spaces or tabs.

Correct paragraph formatting：

这是第一个段落。它可以包含多个句子，内容可以很长，会自动换行显示。

这是第二个段落。注意上面有一个空行分隔。

这是第三个段落。

Common mistakes：

这是第一段
这是第二段（错误：没有空行分隔）

    这是缩进段落（错误：不应该缩进）

Forced Line Break Techniques

Sometimes you need to break a line without creating a new paragraph. Markdown provides several methods:

Method 1: Two spaces at the end of the line
Add two or more spaces at the end of the line, then press Enter:

第一行内容（这里有两个空格）  
第二行内容

Method 2: HTML line break tag

第一行内容<br>
第二行内容

Method 3: Backslash (supported by some parsers)

第一行内容\
第二行内容

Practical Application Examples：

地址：北京市朝阳区  
电话：010-12345678

诗歌示例：

The Role of Blank Lines

Blank lines play an important role in Markdown:

Separate paragraphs：

第一段内容

第二段内容

Separate different elements：

# 标题

段落内容

- 列表项1
- 列表项2

另一段内容

Best practice recommendations：

  • Leave a blank line between headings and content
  • Leave blank lines before and after lists
  • Leave blank lines before and after code blocks
  • Maintain consistent blank line usage habits
