Opera Browser

Opera Browser is free, and it is currently the smallest and fastest browser!

Opera was started in 1994 as a research project of the Norwegian telecom company Telenor, and in 1995 developed into an independent development company, Opera Software ASA.

Opera Software ASA developed the Opera web browser and is an industry leader in web browser development for the desktop and device markets.

The Opera browser has earned international acclaim from end users and the industry because it is faster, smaller, and more standards-compliant than other browsers.

Opera is not only free but also Web standards compliant!

Opera Browser is free! The earlier banner advertising and licensing fee system has been abolished!

The Opera browser has the advantages of being faster, smaller, and more standards-compliant.

If your website works well in Opera, you can be sure it meets standards! You just need to write your pages with standards-compliant code to ensure your website works well, whether in all major browsers or on all major platforms and operating systems.

Opera supports all web standards in use, such as CSS, HTML, XHTML, HTTP, DOM, XML, XSL, ECMAScript (JavaScript), PNG, WML, SVG, Unicode, Unicode Bidirectional Algorithm, and more.

Opera 20

Opera 20 was released on March 4, 2014, with an update to the latest Chromium version 33.

Opera 20 is available on Mac and Windows.

New features:

  • Draggable bookmarks- Drag your tabs to the bookmark bar to save them. Drag your bookmarks to Speed Dial to create new entries.
  • New Speed Dial entries- In advanced settings, you can change the appearance of Speed Dial entries.

Opera 19

Opera 19 was released on January 28, 2014, with an update to the latest Chromium version 32.

Opera 19 is available on Mac and Windows.

New features:

  • Bookmark bar- You can save tabs to the bookmark bar, conveniently manage the tabs in the bookmark bar, and easily click tabs in the bookmark bar to visit web pages.
  • Theme creation- Upload an image or use an image from the web to customize the browser's appearance.

Opera 18

Opera 18 was released on November 19, 2013, with an update to the latest Chromium version 31.

Opera 18 is available on Mac and Windows.

New features:

  • Media access- Allows websites to access your camera and microphone, including support for HTML5 media access.
  • Themes- You can install via the theme manager fromaddons.opera.comthemes on.
  • Rocker gestures- Navigate back/forward through tab history by moving your fingers on the mouse buttons.
  • Enhanced tab functionality- You can drag tabs between open windows.

Opera 17

Opera 17 was released on October 10, 2013, with an update to the latest Chromium version 30.

Opera 17 is available on Mac and Windows.

New features:

  • Pinned tabs- Allows you to pin tabs to the tab bar (helps prevent you from accidentally closing tabs).
  • Custom search- You can add custom search engines to the combined search and address bar.

Opera 16

Opera 16 was released on August 27, 2013, with an update to the latest Chromium version 29.

Opera 16 is available on Mac and Windows.

New features:

  • AutoFill- You can securely store addresses, phone numbers, email addresses, and credit cards used online.
  • Geolocation- You can share your location information with websites.

Opera 15

Opera 15 was released on July 2, 2013.

Opera 15 is available on Mac and Windows.

Opera 15 is a major reinvention of Opera. The browser's source code is based on Chromium and Blink, as well as the WebKit rendering engine. Everything about this version of the browser is new:

  • New rendering engine, based on WebKit
  • New user interface
  • New capabilities
  • New features
  • Improved site compatibility
  • Automatic updates

New features:

  • Combined address and search bar
  • Enhanced Speed Dial- Allows you to group Speed Dial entries.
  • Reserved features- Record location, metadata, and webpage screenshots, and place this information in collapsible list items on the browser start page. You can search by keyword or browse visually via screenshots.
  • Acquire knowledge- Display news and feature content, which can be filtered by category or location/language.
  • Off-Road mode- Uses the server-side compression technology used by Opera Mobile.

Opera 12

Opera 12 was released on June 13, 2012.

Opera 12 runs on Linux, Mac, FreeBSD, and Windows.

New features:

  • Improved speed
  • Support for taking photos- The first browser to support the W3C getUserMedia specification.
  • Themes- Opera 12 introduced lightweight themes.
  • Better security badges
  • Improved support for HTML5 and CSS3- Such as HTML5 drag-and-drop, CSS3 transitions, and animations.
  • Added 5 new languages- Arabic, Persian, Urdu, Hebrew, and Kazakh.
  • A page zoom slider
  • SupportDo Not Track

Opera 11.60

Opera 11.60 was released on December 6, 2011.

Opera 11.60 runs on Linux, Mac, FreeBSD, and Windows.

New features:

  • New browser engine- Faster and more stable Internet experience.
  • New mail design- Cleaner layout, message grouping, easier navigation, and more intuitive views in the inbox.
  • Modified address field- Just press the star in the address bar to add a page to bookmarks or Speed Dial.
  • Improved support for HTML5, CSS3, and SVG.

Opera 11.50

Opera 11.50 was released on June 28, 2011.

Opera 11.50 runs on Linux, Mac, FreeBSD, and Windows.

New features:

  • Stylish user interface
  • Added features to Opera's Speed Dial feature- Embed extensions in your Speed Dial, allowing you to update instantly without adding thumbnail links to favorites.
  • Password sync -Allows you to securely synchronize passwords with other Opera browsers.
  • Faster graphics performance
  • Improved support for HTML5, CSS3, and SVG

Opera 11.10

Opera 11.10 was released in April 2011.

Opera 11.10 runs on Linux, Mac, FreeBSD, and Windows.

New features:

  • Speed Dial 2.0- Preview your favorite web pages more clearly, and dynamically display the latest content from websites. There is no limit to the number of Speed Dial items you can use.
  • Enhanced Opera Turbo- Improves your browsing speed in crowded Wi-Fi hotspots, or when using a mobile phone or dial-up connection.
  • Simple plugin installation- In this version, the most popular plugin, Adobe Flash Player, can be installed automatically and seamlessly.
  • New CSS3 support- Opera now supports CSS3 linear gradients and multi-column layouts.

Opera 11

Opera 11 was released in December 2010.

Opera 11 runs on Linux, Mac, FreeBSD, and Windows.

New features:

  • Opera Presto 2.7 rendering engine- Better support for CSS3 and HTML5.
  • Tab stacking- We often open so many tabs that they become difficult to arrange and manage. Opera 11 lets you drag one tab onto another to create tab groups. This allows you to keep dozens of open web pages organized, and you can easily arrange and manage them.
  • Secure address field- An improved address field that makes it easier to stay secure online and hides the complexity of long network addresses. It also provides more secure information to help keep you safe while browsing - just click the website's badge to see security information about the site you are visiting.
  • Visual Mouse Gestures- Complete common browser actions with quick flicks of the mouse. Hold down the right mouse button on a webpage and a visual guide will appear showing how to perform the available gestures.
  • Opera installer for Microsoft Windows platforms- Opera has a new installer that is much faster than the previously used MSI installer.
  • New extensions & mail panel- A bunch of new extensions and a new side panel for faster email access.
