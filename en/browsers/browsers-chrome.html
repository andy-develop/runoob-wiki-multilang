Google Chrome Browser

Google Chrome Browser, known as "谷歌浏览器" in Chinese, is a free open-source web browser developed by Google and released in 2008.

When Google decided to develop a browser, they needed to completely rethink the browser, because today's browsers are very different from when they only needed to browse simple text pages. Now, we use browsers to send email, shop, pay bills, and run other large applications.

Google Chrome is the most commonly used browser today:Download Chrome。

Google Chrome 34

Chrome 34 was released on April 8, 2014.

Chrome 34 runs on Windows, Mac, Linux, and Android (April 2).

New features:

  • When autocomplete=off is set, Chrome will still remember and fill in password fields.
  • Support for responsive images -Google introduced the "srcset" attribute, allowing website developers to provide multiple resources at different resolutions for one image. In short, this means the browser will choose the resource that matches the device, which can be desktops, laptops, tablets, phones, TVs.
  • The unprefixed version of the Web Audio API
  • Import supervised users to a new computer -Importing supervised users also imports all of their permissions, which will automatically sync to the device.
  • Many new apps/extensions APIs
  • A different look for Win8 Metro mode
  • 31 security fixes

Google Chrome 33

Chrome 33 was released on February 20, 2014.

Chrome 33 is available on Windows, Mac, Linux, and Android (February 26).

Chrome Frame (the Chrome plug-in for Internet Explorer) has been officially retired.

New features:

  • Web Speech API - Speech recognition and synthesis
  • Custom elements -You can create new HTML and DOM elements (you can use any names you want), and also extend new elements from other elements, and bundle custom functionality into a single element.
  • In offline mode, you can create, rename, and delete folders in Google Drive
  • In offline mode, you can rename files in Google Drive
  • 28 security fixes

  • 11 security fixes
