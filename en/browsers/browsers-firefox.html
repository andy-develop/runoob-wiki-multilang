Firefox Browser

Firefox Browser, known in Chinese as "火狐浏览器" (Firefox), is a free and open-source web browser from Mozilla.

Firefox was released in 2004 and is one of the most popular browsers today.

Firefox runs on Windows, Mac OS X, Linux, and Android.

Firefox 29

Firefox 29 was released on April 29, 2014.

Firefox 29 runs on Windows, Mac, Linux, and Android.

New features:

  • Some redesigned tools and a refreshed interface
  • Enhanced Firefox Sync service
  • Menu moved to the top-right corner
  • New "Customize" tool, where you can add or move features and add-ons
  • Users can create a bookmark by clicking
  • Support for the CSS box-sizing property (without -moz- prefix)
  • Support for HTML5 input type="number"
  • Support for HTML5 input type="color"

Firefox 28

Firefox 28 was released on March 18, 2014.

Firefox 28 runs on Windows, Mac, Linux, and Android.

New features:

  • Mac OS X: Notification Center supports web notifications
  • Horizontal volume controls for HTML5 audio/video
  • Support for Opus in WebM
  • Implementation of VP9 video decoding
  • Support for the MathML 2.0 'mathvariant' attribute
  • Background thread reporting
  • Support for multi-line flexbox in layout

Firefox 27

Firefox 27 was released on February 4, 2014.

Firefox 27 runs on Windows, Mac, Linux, and Android.

New features:

  • A major update to the Firefox Social API- Now allows users to run multiple services simultaneously
  • Support for Google's SPDY 3.1 protocol and Transport Layer Security (TLS) versions 1.1 and 1.2- These are essentially successors to the well-known SSL encryption protocol
  • Reset style sheets using "all:unset"
  • Support for scrolling field sets
  • CSS cursor keywords -moz-grab and -moz-grabbing are now unprefixed
  • Support for the mathematical function Math.hypot()
  • Support for dashed lines on Canvas

Firefox 26

Firefox 26 was released on December 10, 2013.

Firefox 26 runs on Windows, Mac, Linux, and Android.

New features:

  • All Java plugins default to "click to play"
  • Password Manager supports script-generated password fields
  • Support for H.264-encoded video on Linux
  • Support for MP3 audio on Windows XP- This completes MP3 support across Windows operating system versions
  • Removed prompt when a site requests AppCache
  • Support for the CSS3 image-orientation property
  • New App Manager- Allows you to deploy and debug HTML5 apps on Firefox OS phones and the Firefox OS emulator
  • IndexedDB can be used as an "optimistic" storage area- Uses LRU eviction policy, does not require storing any hints or data in the pool, just a short-lived temporary storage
  • Reduced memory usage, improved image processing
