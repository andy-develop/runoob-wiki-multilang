Internet Explorer Browser

Internet Explorer Browser, referred to as IE browser, is a free web browser released by Microsoft.

Internet Explorer was released in 1995, peaked at a 95% usage rate in 2002 and 2003, but is now no longer supported.

On March 17, 2015, Microsoft announced that Internet Explorer would no longer be the default browser for Windows 10, and would gradually phase out this brand, replacing it with Microsoft Edge.

Internet Explorer 11

For Windows 8.1: Internet Explorer 11 was released on October 17, 2013.

For Windows 7: Internet Explorer 11 was released on November 7, 2013.

New features:

  • Performance improvements
  • All-new F12 Developer Tools
  • WebGL support
  • High-resolution support
  • CSS3 border-image support
  • CSS Flexbox support
  • SPDY support (Windows 8.1 only)
  • Support for Full Screen and Orientation API
  • Enhanced support for touch-based device users
  • JavaScript enhancements
  • DOM Mutation Observer
  • Web Cryptography API
  • Video text track support
  • Encrypted media support
  • Improved HTML editor

IE 11 Removed features：

  • document.all is deprecated- Code that checks for its existence will not detect it, but code that actually uses it will continue to work.
  • attachEvent
  • Quick tabs (CTRL+Q)
  • The "Work offline" command was removed from the File menu.
  • Dragging and dropping selected content from IE to other programs such as Word
  • Using large icon command buttons
  • Ability to view all cookies at once in Developer Tools

IE 11 is fast and standards-compliant. However, its main drawback is that it cannot run on operating system versions prior to Windows 7, and it does not provide synchronization for that system!

Internet Explorer 10

Internet Explorer 10 was released on September 4, 2012, and is the default browser in Windows 8.

In February 2013, Internet Explorer 10 was made available for download to all Windows 7 SP1 users.

New features:

  • 20% faster than IE9
  • Updated HTML5 support- Now supports the async attribute in <script> tags, AppCache API, channel messaging, drag and drop API, history, parsing, sandbox, spell checking, video, Web Workers, and WebSockets.
  • Updated CSS3 support- Now supports transforms, animations, fonts, gradients, transition effects, text shadows, and removal of stylesheet limits.
  • Updated DOM support- Now supports advanced hit testing API, media query listeners, XMLHttpRequest enhancements, and pointer gesture events.
  • Updated SVG support- Now supports SVG and filters.
  • Updated Indexed Database API support
  • Integrated spell checking and auto-correction
  • Adobe Flash integration- Contains a built-in Adobe Flash Player.
  • Added features for touchscreen users.- Full-screen touch browser.
  • Flip forward- Quickly move to the next page of a website via swipe gestures on touchscreen devices.
  • New user agent string - Mozilla/5.0 (compatible; MSIE 10.0; Windows NT 6.2; [platform token] Trident/6.0; Touch)

IE 10 No longersupports the following:

  • XML data islands
  • VML- Vector Markup Language (VML).
  • HTC- Element behaviors and HTML components.
  • DX filters- DirectX-based filters/transitions.
  • Conditional comments- Conditional statements in HTML source code interpreted by IE, such as: <!--[if IE 6]>. Used to provide and hide code for IE.
  • Content Advisor- Taken over by Windows Parental Controls.

Internet Explorer 9

Internet Explorer 9 was released in March 2011.

New features:

  • Updated interface- Lets you control and focus on website viewing.
  • Swift speed- IE9 is much faster than previous versions of IE. Hardware-accelerated text, video, and graphics improve website performance, as if the program is already installed on your computer. At the same time, IE9 uses the video card to make everything faster.
  • Pin websites to the Windows 7 taskbar- Microsoft has partnerships with many websites such as Facebook, Twitter, and Pandora, and you can see a taskbar that supports jump lists.
  • Unified address bar- A unified address bar for navigating websites or starting a search.
  • Redesigned new tab page- Lets you quickly access sites you visit frequently. You can also reopen closed tabs, your last browsing session, or start a new non-private browsing session.
  • Improved add-on management- A new feature called Add-on Performance Adviser lets you see what is slowing down your browser and allows you to disable it.
  • Better privacy protection features- Tracking Protection can limit how websites track your information.
  • Better support for HTML5/CSS3- IE9 also supports SVG and Canvas graphics.
  • New Download Manager- Allows you to view files downloaded through the browser, and notifies you if a file is malicious or contains a virus. It also lets you pause downloads and resume them later.
  • Enhanced tab management- You can move tabs between windows by dragging them from one window to another. When you place a tab in a new window, it does not need to reload the page.

Internet Explorer 8

Internet Explorer 8 was released in March 2009.

New features:

  • Accelerators- Provides quick access to web services. Users can find and send information from the web. For example, on a restaurant website, a user can click within the webpage to get a map, news, and information about the restaurant, related blogs, or share it on Sina Weibo.
  • Web Slices- A feature similar to RSS that allows users to subscribe to content directly within a webpage.
  • Compatibility View- Displays webpages in IE7.
  • Search suggestions- Provides suggested content based on your input.
  • New tab features- Reopen accidentally closed tabs, and group related tabs by color code.
  • Tab isolation- Prevents the entire browser from closing because of a faulty website; only the faulty tab is closed.
  • InPrivate Browsing- Browse the web without saving any data (such as passwords, cookies, browsing history, etc.).
  • SmartScreen Filter- Helps protect you from installing malware that can expose your data, privacy, and identity, and potentially damage your computer and valuable data.

IE 8 fully supports CSS 2.1. Additionally, it fixed "many cross-browser inconsistencies, such as get/set/removeAttribute, default attributes, Attribute object, and the <q> tag."

Internet Explorer 7

Internet Explorer 7.0 was released in November 2006. IE7 is the standard browser in Windows XP with Service Pack 2.

Internet Explorer 7 provides improved navigation, web search through the toolbar, advanced printing, instant search, and RSS feeds.

New features:

  • Advanced printing- Internet Explorer 7 automatically scales web pages to be printed so that the entire page fits within the printed page. Print options also include adjustable margins, customizable page layouts, removable headers and footers, and the option to print only selected text.
  • Instant Search Box- Web search using your favorite search provider can now be added to the search box in the toolbar, eliminating the clutter of multiple separate toolbars. You can easily select a provider from the drop-down list or add more providers.
  • Favorites Center- Quick and convenient access to favorites, tab groups, browsing history, and RSS feed subscriptions. The Favorites Center can be expanded as needed and positioned anywhere for easy access.
  • RSS Feeds- Internet Explorer 7 automatically detects RSS feeds on sites and lights up the icon on the toolbar. You can click the icon to preview and subscribe to RSS feeds at will, and you will be automatically notified when content is updated. You can read RSS feeds directly in the browser, browse important events, and filter views by search terms or specific site categories.
  • Tabbed Browsing- View multiple sites in a single browser window. Use the tabs at the top of the browser frame to easily switch from one site to another.
  • Quick Tabs- By displaying all thumbnails in a single window, you can easily select and navigate among open tabs.
  • Tab Groups- Tabs can be grouped and saved by logical category, so you can open multiple tabs with a single click of the mouse. Tab groups can be conveniently set as the home page group, so that the entire tab group can be opened every time Internet Explorer is started.
  • Page Zoom- Zoom in on a single page, including text and images, so you can focus on specific content or make content clearer for people with visual impairments.

Internet Explorer 6

Internet Explorer 6.0 is the standard browser in Windows XP. Released in August 2001.

Windows XP is based on Windows 2000 and is the successor to Windows 98, Millennium, and Windows 2000.

Internet Explorer 5

Internet Explorer 5 was the first mainstream browser to support XML.

Version 5.5(Released in July 2000), for Windows 95, 98, NT 4.0, and Windows 2000. Supports XML/XSL, CSS, printing (print preview), and HTC behaviors.

Version 5.01(Released in November 1999), mainly fixed a bug in 5.0.

Version 5.0(Released in March 1999), was the first mainstream browser to support XML.

Older Internet Explorer Versions

Most users are no longer using older Internet Explorer versions. Web developers ignore them. And their features are outdated.

IE 4.0(Released in 1997). This version had very good support for CSS and DOM, but did not support XML.

IE 3.0(Released in 1996) had a usage rate of less than 0.1%.

IE 2.0(Released in 1995). This version is too old; no one uses it anymore.

IE 1.0(Released in 1995). Does anyone still remember it?

Internet Explorer for Macintosh

Version 5.1.7It was the last Internet Explorer for Mac OS 8 and 9, released in July 2003.

Version 5.2.3It was the last Internet Explorer for Mac OS X, released in June 2003.

Notes:version 5.2.3 requires special features in Mac OS X. Users of Mac OS 8 and 9 must download version 5.1.7.

Microsoft ended technical support for Internet Explorer for Mac on December 31, 2005.

Mac users are recommended to use other browsers, such asApple's Safari browser。
