Web Glossary

The following terms are listed in alphabetical order

Access (Microsoft Access)

A database system developed by Microsoft. Part of Microsoft Office Professional. Mainly used to run low-traffic websites on Windows platforms.

ActiveMovie

A control introduced by Microsoft for multimedia programming

ActiveX

Allows Web browsers to download and execute the Windows Application Programming Interface (API). (See also plug-in)

Address

Please refer to URL.

AdSense

A web advertising system provided by Google.

AJAX (Asynchronous JavaScript and XML)

The "art" of using JavaScript and XML to create interactive Web applications. With Ajax, Web applications can exchange data with a Web server in the background (asynchronously) and update parts of a Web page without reloading the page.

Learn more about AJAX in our AJAX tutorial

Anchor

On the web: the starting point or end point of a hyperlink.

Learn more about links in our HTML tutorial

Adobe Air

An Adobe Integrated Runtime (AIR) system that enables developers to use Web technologies (HTML, JavaScript, Flash) to create desktop applications.

Android

A mobile operating system developed by Android Inc., later acquired by Google.

Anonymous FTP

Please refer to FTP server.

ANSI (American National Standards Institute)

An organization that creates standards for the computer industry. Responsible for the ANSI C standard.

ANSI C

The international standard for the C programming language.

ADO (ActiveX Data Object)

Microsoft's data storage technology of any type, providing data access.

Learn more about ADO in our ADO tutorial

ADSL (Asymmetric Digital Subscriber Line)

A special type of DSL line where upload speed and download speed are different.

Agent

Please refer to search agent / search engine

Amaya

An open-source Web browser editor from W3C, used to promote leading ideas in browser design.

Animation

A series of photos played in sequence to simulate motion.

Antivirus program

A computer program that finds and destroys all types of computer viruses.

Apache

An open-source Web server. Mostly used on Unix, Linux, and Solaris platforms.

Applet

Please refer to Web applet.

Archie

A computer program to locate files on public FTP servers.

API (Application Programming Interface)

An interface that lets a program communicate with another program. On the web: an interface that lets a Web browser or Web server communicate with other programs. (See also Active-X plug-in)

ARPAnet

A network testing experiment that began during the development of the Internet in the 1970s.

Authentication

On the web: a method used to verify a user's identity on a network or computer program.

ASCII (American Standard Code for Information Interchange)

128 alphanumeric and special control characters used for computer storage and printed text. Data transmitted over the web in HTML.

In our HTML reference, see the complete list of ASCII codes

ASF (Advanced Streaming Format)

A format for multimedia data streaming. Developed by Microsoft's Windows Media.

ASP (Active Server Pages)

Microsoft's technology that allows servers to insert executable scripts into Web pages.

Learn more about ASP by visiting our ASP tutorial

ASX (ASF Streaming Redirector)

An XML format for storing information about ASF files. Developed by Microsoft's Windows Media.

AVI (Audio Video Interleave)

A video file format. A video compression technology developed by Microsoft.

Banner Ad

A (most commonly graphical) advertisement placed on a Web page as a hyperlink to the advertiser's website.

Bandwidth

The amount of data you can send over an Internet connection. More bandwidth means a faster connection.

Baud

The number of symbols sent per second on a channel.

BBS (Bulletin Board System)

A network-based public discussion, file, and bulletin system.

Binary Data

Data in machine-readable form.

Bit (Binary Digit)

The smallest unit of data stored in a computer. A bit has a value of 0 or 1. A computer uses 8 bits to store one text character.

Blog (Web Log)

A type of website (usually maintained by an individual) with journal entries (most often personal), opinions, commentary, events, etc.

Blogger

A person who maintains or writes content to a web log (blog).

Blogging

To write or add content to a web log (blog).

BMP (Bitmap)

A format used for storing images.

Bookmark

On the web: a stored link to a specific website (bookmark) for future convenient access by web users.

Bounce Rate

The percentage of website visitors who view only one page before they leave (bounce).

Browse

A term describing the movement of web users through the entire network, moving from page to page via hyperlinks using a Web browser. (See Web browser)

BPS (Bits Per Second)

A term used to describe the speed of data transmission over the web.

Browser

Please refer to Web browser.

Byte (Binary Term)

A computer storage unit containing 8 bits. Each byte can store one text character.

C

An advanced programming language used for advanced computer application programming.

C++ (C Plus Plus)

Same as C, with object-oriented features added.

C# (C Sharp)

Microsoft's version of C++ with Java-like features added.

Case Sensitive

Used to describe sensitivity to uppercase or lowercase letters.

Cache

On the web: a function that stores copies of Web pages on the hard drive of a Web browser or Web server computer.

Chat

Online, text-based communication between Internet users.

CGI (Common Gateway Interface)

Rules describing how a CGI program communicates with a Web server.

CGI Bin

A folder (or directory) on a Web server where CGI programs are stored.

CGI Program

A small program that processes input and output from a Web server. CGI programs are often used to process form input or database queries.

Cinepac

Computer video codec

Client

Please refer to Web client.

Client/Server

On the web: communication in which the workload is divided between a Web client and a Web server.

Click

On the web: clicking a hyperlink element (such as text or an image) on a Web page creates an event such as navigating to another Web page or visiting another part of the same page.

Clickthrough Rate

The ratio of the number of times visitors click a hyperlink (or ad) on a page to the number of times the page has been displayed.

Cloud Computing

Applications and data stored on the Internet (rather than on the user's computer).

Codec (Compressor / Decompressor)

A general term for data compression and decompression technology.

Communication Protocol

A standard (language and a set of rules) that allows computers to interact in a standard way. Examples: IP, FTP, and HTTP.

Learn more about communication protocols in our TCP/IP tutorial

Compression

A method of reducing the size of Web documents or graphics for faster delivery over the network.

Computer Virus

A computer program that can corrupt displayed messages, delete files, or even destroy a computer's operating system.

Cookie

Information stored on your computer by a Web server via a Web browser. The purpose of a cookie is to provide information about your visits to a website, which the server uses on subsequent visits.

ColdFusion

Web development software for most platforms (Linux, UNIX, Solaris, and Windows).

CSS (Cascading Style Sheets)

A W3C recommended language that defines the style of Web documents (such as fonts, sizes, colors, spacing, etc.).

Learn more about CSS in our CSS tutorial

Database

Storing computer data in such a way that a computer program can easily retrieve and manipulate the data.

Learn more about databases in our SQL tutorial

Database System

Computer programs that manipulate data in databases (such as MS Access, Oracle, and MySQL).

DB2

A database system from IBM. Mostly used on Unix and Solaris platforms.

DBA (Data Base Administrator)

A person (or software) who manages a database. Typical tasks: backup, maintenance, and execution.

DHCP (Dynamic Host Configuration Protocol)

An Internet standard protocol that assigns new IP addresses to users.

DHTML (Dynamic HTML)

A commonly used term to describe HTML content that may change dynamically.

Dial-up Connection

On the web: a connection to the Internet via a telephone and modem.

Discussion Group

Please refer to Newsgroup.

DNS (Domain Name Service)

A computer program running on a Web server that translates domain names into IP addresses.

Learn more about DNS in our Web hosting tutorial

DNS Server

A Web server that performs DNS.

DOM (Document Object Model)

A programming model for web page objects. (See HTML DOM and XML DOM)

Domain Name

The name identifier of a website. (e.g., runoob.com)

Learn more about domains in our Web hosting tutorial

DOS (Disk Operating System)

A general-purpose disk-based computer operating system (see operating system). Originally Microsoft for IBM personal computers. Often used as an abbreviation for MS-DOS.

Download

Transferring files from a remote computer to a local computer. On the web: a Web client transfers files from a Web server. (See also upload).

DSL (Digital Subscriber Line)

Broadband access technology based on ordinary telephone lines.

DTD (Document Type Definition)

A set of rules (a language) that defines the legal building blocks of web documents like HTML or XML.

Learn more about DTD in our DTD tutorial

Dynamic IP

An IP address that changes each time you connect to the Internet. (See DHCP and static IP).

E-mail (Electronic Mail)

Messages sent from one person to another over the Internet.

E-mail Address

An address used to send e-mail to a person or an organization. The typical format is username@hostname.

E-mail Server

A dedicated e-mail service task for a Web server.

Encryption

Data that is converted from its original form into an encrypted form that can only be reversed by authorized people. The purpose of encryption is to prevent unauthorized reading of data.

Error

See Web server error.

Ethernet

A type of local area network (see LAN).

Firewall

Software that acts as a security filter, restricting types of network communication. Most commonly used between a personal computer (or LAN) and the Internet.

Flash

A vector-based multimedia format used on the Web, developed by Adobe.

Form

See HTML forms.

Forum

On the Web: same as Newsgroup.

Frame

On the Web: a specific part of the screen displayed in the browser. Frames are often used to display different web page contents.

FrontPage

Web development software for the Windows platform. Developed by Microsoft.

FTP (File Transfer Protocol)

One of the most common methods for sending files between two computers.

FTP Server

A Web server you can log on to and download files (or upload files to). Anonymous FTP is a method of downloading files from an FTP server without using a login account.

Gateway

A computer program that formats data for transmission between incompatible applications or networks.

GIF (Graphics Interchange Format)

A compressed image storage format developed by CompuServe. One of the most common image formats on the Internet.

GB

Gigabyte, a unit of storage in computers.

Gigabyte

1024 megabytes. Usually rounded down to one billion bytes.

Graphics

On the Web: refers to images (as opposed to text).

Graphic Monitor

A display screen that can display graphics.

Graphic Printer

A printer that can print graphics.

Graphical Banner

See Banner Ad.

Helper application

On the Web: a program that helps the browser display, view, or work with content that the browser itself cannot handle. (See plug-in.)

Hits

The number of times a Web object (a web page or image) has been viewed or downloaded. (See page hit.)

Home Page

The top-level (main) page of a website. The default page displayed when you visit a website.

Host

See Web host.

Hosting

See virtual hosting.

Hotlink

See hyperlink.

HTML (Hypertext Markup Language)

HTML is the Web language. HTML is a set of tags used to define the content, layout, and format of web page files. Web browsers use HTML tags to define how text is displayed.

Learn more about HTML in our HTML tutorial.

HTML Document

A file written in HTML.

HTML DOM (HTML Document Object Model)

A programming interface for HTML documents.

Learn more about the HTML DOM in our HTML DOM tutorial.

HTML Editor

A software program used to edit HTML pages. With an HTML editor you can add elements such as lists, tables, layouts, font sizes, and colors to an HTML document like using a word processor. While editing, it displays the content being edited on the page (WYSIWYG).

HTML Form

A form that passes user input back to the server.

Learn more about HTML forms in our HTML tutorial.

HTML Page

An HTML file.

HTML Tags

Codes that identify different parts of a document so that a web browser knows how to display it.

Learn more about HTML tags in our HTML tutorial.

HTTP (Hyper Text Transfer Protocol)

A set of rules and standards for sending text files over the Internet. It requires an HTTP client program on one end and an HTTP server program on the other.

HTTP Client

A computer program that requests services from a Web server.

HTTP Server

A computer program that provides services on a Web server.

HTTPS (Hyper Text Transfer Protocol Secure)

Same as HTTP but provides secure Internet communication via SSL. (See also SSL.)

Hyperlink

In a web page, a text string that links to other web pages is called a HYPERLINK.

Hypermedia

Extends hypertext, graphics, and audio.

Hypertext

Hypertext is cross-linked in such a way that readers can read related documents by clicking on a highlighted word or symbol or other text to other documents. (See also hyperlink.)

IAB (Internet Architecture Board)

A council for making Internet standards decisions (see also W3C).

IE (Internet Explorer)

See Internet Explorer.

IETF (Internet Engineering Task Force)

A group under the IAB focused on solving technical problems on the Internet.

IIS (Internet Information Server)

A Web server for the Windows operating system. Developed by Microsoft.

IMAP (Internet Message Access Protocol)

A standard communication protocol for retrieving e-mail from an e-mail server. IMAP is very similar to POP, but more advanced.

Learn more about IMAP in our TCP/IP tutorial.

Indeo

A computer video codec developed by Intel.

Internet

A worldwide network connecting millions of computers. (See also the World Wide Web.)

Internet Browser

See Web browser.

Internet Explorer

Microsoft browser. The most commonly used browser.

Learn more about browsers in our browser section.

Internet Server

See Web server.

Intranet

Private (closed) Internet running inside a LAN (local area network).

IP (Internet Protocol)

See TCP/IP protocol.

IP Address (Internet Protocol Address)

A unique identification number for every computer on the Internet (e.g., 197.123.22.240).

IP Number (Internet Protocol Number)

An IP address.

IP Packet

See TCP/IP packet.

IRC (Internet Relay Chat)

An Internet system that allows users to discuss online.

IRC Client

A computer program that enables users to connect to IRC.

IRC Server

An Internet server dedicated to IRC connection services.

ISAPI (Internet Server API)

Internet Information Server application programming interface (API) (see IIS).

ISDN (Integrated Services Digital Network)

A telecommunications standard using digital transmission, supporting data communication over ordinary telephone lines.

ISP (Internet Service Provider)

Provides access to the Internet and website hosting.

Java

A programming language developed by Sun. Mostly used for programming Web servers and Web applets.

Java Applet

See applet on web pages.

JavaScript

The most popular scripting language on the Internet, developed by Netscape.

Learn more about JavaScript in our JavaScript tutorial.

JPEG (Joint Photographic Expert Group)

Designed to facilitate compressed image storage in JPG and JPEG graphics formats.

JPEG and JPG

A graphics format for storing compressed images.

JScript

Microsoft's version of JavaScript.

JSP (Java Server Pages)

A Java-based technology that allows server-executable scripts to be inserted in web pages. Mainly used on Linux, Unix, and Solaris platforms.

K

Kilobyte. 10K is the same as ten kilobytes.

KB

Kilobyte. 10K is the same as ten kilobytes.

Keyword

On the Web: a word used by search engines to search for related web information. In database terminology: a word (or index) used to identify a record in a database.

Kilobyte

1024 bytes. Often called 1K, rounded down to 1000 bytes.

LAN (Local Area Network)

A network between computers in a local area (such as within a building), usually connected by local cables. See Wide Area Network.

Link

Same as hyperlink.

Linux

An open-source computer operating system, based on UNIX. Mainly used on servers and Web servers.

Mail

On the Internet: same as e-mail.

Mail Server

See e-mail server.

MB

Same as megabyte. 10MB is ten megabytes.

Megabyte

1024 kilobytes. Usually rounded down to one million bytes.

Meta Data

Data that describes other data. (Meta tags.)

Meta Search

A method for searching metadata in a file.

Meta Tags

Tags inserted into a document to describe the document.

Learn more about meta tags in our HTML tutorial.

MIDI (Musical Instrument Digital Interface)

A standard protocol for communication between computers and musical instruments.

Learn more about MIDI in our media tutorial.

MIME (Multipurpose Internet Mail Extensions)

Internet standard defining document types. Examples of MIME types: text/plain, text/html, image/gif, image/jpg.

Learn more about MIME in our media tutorial.

MIME Types

Defined according to MIME file types.

Modem

A hardware device that connects a computer to the telephone network, usually used to connect to the Internet via a telephone line.

Mosaic

The first commonly used Web browser. Mosaic was released in 1993 and began to popularize the Web.

MOV

A computer video codec developed by Apple. A common file extension for QuickTime multimedia files.

MP3 (MPEG-1 Audio Layer-3)

An audio compression format designed for easy downloading from the Internet.

MP3 File

A file containing MP3 compressed audio. Most common for music tracks.

MPEG (Moving Picture Expert Group)

An ISO standard computer audio and video codec.

MPG

Common file extension for MPEG files.

MS-DOS (Microsoft Disk Operating System)

A general disk-based computer operating system (OS). Originally developed by Microsoft for IBM computers, and then became the basis for the first version of Windows developed by Microsoft.

Multimedia

On the Web: a presentation that combines text with images, video, or sound.

MySQL

Free open-source database software often used on the Web.

NetBEUI (Net Bios Extended User Interface)

An enhanced version of NetBIOS.

NetBIOS (Network Basic Input Output System)

An application programming interface (API) for local area network (LAN) functions. Used for DOS and Windows.

Navigate

In networking: the same as browsing.

Netscape

The company's Netscape browser. It was the most popular browser for many years. Today, IE browser leads.

Learn more about browsers in our browser section.

Newsgroup

An online discussion group (a section on a news server), dedicated to a particular topic of interest.

News Reader

A computer program that can read (and post messages to) Internet newsgroups.

News Server

An Internet server dedicated to the task of servicing Internet newsgroups.

Node

In networking, connected to the Internet: a computer, most often used to describe a Web server.

Opera

The Opera browser from Opera Software ASA in Norway.

Learn more about browsers in our browser section.

OS (Operating System)

Basic computer operations for managing software.

Packet

Please refer to the TCP/IP packet.

Page Hits

The number of times a web page is accessed by users.

Page Impressions

Same as click count.

Page Views

Same as click count.

PDF (Portable Document Format)

A document file format developed by Adobe. Most commonly used for text files.

Perl (Practical Extraction and Reporting Language)

A scripting language for Web servers. Most commonly used on UNIX servers.

PHP (PHP: Hypertext Preprocessor)

A technology that allows inserting server-executable scripts into web pages. Often used on Unix, Linux, and Solaris platforms.

Learn more about PHP in our PHP tutorial.

Ping

A method used to check communication between two computers. A "ping" is sent to a remote computer to see if it responds.

Platform

In networking: a computer's operating system, such as Windows, Linux, or OS X.

Plug-In

An application built into another application. In networking: a special type of program (or add-on) built into a Web browser to handle data such as email, sound, or movie files. (See also ActiveX).

PNG (Portable Network Graphics)

An image file storage format that aims to replace GIF and TIFF file formats, while adding some features that the GIF file format does not have.

POP (Post Office Protocol)

A standard communication protocol for retrieving email from an email server. (See also IMAP).

Learn more about POP and IMAP in our TCP/IP tutorial.

Port

An I/O (input/output) channel identifier for a computer. In networking: an identifier for the I/O channel used by an Internet application (Web servers usually use port 80).

Protocol

Please see communication protocol.

PPP (Point to Point Protocol)

A communication protocol used for direct connection between two computers.

Proxy Server

An Internet server dedicated to improving Internet performance.

QuickTime

A multimedia file format created by Apple.

Learn more about QuickTime in our media tutorial.

RAID (Redundant Array of Independent Disks)

A standard for connecting multiple disks to a server with higher security, speed, and performance. Often used on Web servers.

RDF (Resource Description Framework)

A language used to describe frameworks for building Web resources.

Learn more about RDF in our RDF tutorial.

Real Audio

A common multimedia audio format created by Real Networks.

Learn about RealAudio in our media tutorial.

Real Video

A common multimedia video format created by Real Networks.

Learn about RealVideo in our media tutorial.

Redirect

In networking: the action when a web page automatically forwards (redirects) a user to another web page.

RGB (Red Green Blue)

A combination of the three primary colors that can represent the full-color spectrum.

Learn more about RGB in our HTML tutorial.

Robot

See Web Robot.

Router

A hardware (or software) system (router) that directs data transmission on a network between different computers.

Schema

See XML Schema.

Script

A collection of statements written in a scripting language.

Scripting Language

In networking: a simple programming language that can be executed by a Web browser or a Web server. See JavaScript and VBScript.

Scripting

Write a script.

Search Agent

Same as search engine.

Search Engine

A computer program used to search and catalog (index) the information provided in millions of web pages. Common search engines are Google and AltaVista.

Semantic Web

A web of meaning, in which computer programs can understand and process data.

Server

See Web server.

Server Errors

See Web server errors.

Shareware

Software that you can try for free, and pay a certain fee to continue using it legally.

Shockwave

A format (technology) developed by Adobe for embedding multimedia content in web pages.

SGML (Standard Generalized Markup Language)

An international standard for markup languages. The basis of HTML and XML.

SMIL (Synchronized Multimedia Integration Language)

A W3C recommended language for creating multimedia presentations.

SMTP (Simple Mail Transfer Protocol)

A standard communication protocol between computers for sending email.

Learn more about SMTP in our TCP/IP tutorial.

SOAP (Simple Object Access Protocol)

A standard protocol that allows applications to communicate with each other using XML.

Learn more about SOAP in our SOAP tutorial.

Solaris

A computer operating system from Sun.

SPAM

In networking: the action of sending multiple unwanted messages to newsgroups or mailing lists.

Spider

See Web Spider.

Spoofing

The addressing of web pages or emails with false references. Sending email from a fake address.

Spyware

Computer software hidden on a computer, with the purpose of using the computer to collect information.

SQL (Structured Query Language)

An ANSI-standard computer language for accessing and manipulating databases.

Learn more about SQL in our SQL tutorial.

SQL Server

A database system from Microsoft. Mainly used on high-traffic websites running on the Windows platform.

SSI (Server Side Include)

A type of HTML comment inserted into a web page to instruct the Web server to generate dynamic content. The most common use is to include standard headers or footers on a page.

SSL (Secure Socket Layer)

Software that secures and protects website communication, using encrypted data transmission.

Static IP (address)

Static IP, corresponding to dynamic IP.

Streaming

A method of sending video and audio files over the Internet in such a way that the user can view the files while they are being transmitted.

Streaming Format

File formats used for streaming media on the Internet. (See Windows Media, RealVideo, and QuickTime).

SVG (Scalable Vector Graphics)

A W3C recommended language for defining graphics in XML.

Learn more about SVG in our SVG tutorial.

Tag

In networking: a written instruction or command inserted into a web page file. (See HTML tag).

TCP (Transmission Control Protocol)

See TCP/IP protocol.

TCP/IP (Transmission Control Protocol / Internet Protocol)

A collection of Internet communication protocols between two computers. The TCP protocol manages the connection between two computers, and the IP protocol is responsible for sending data packets over the network.

Learn more about TCP/IP in our TCP/IP tutorial.

TCP/IP Address

See IP address.

TCP/IP Packet

A "packet" of data transmitted on a TCP/IP network. (Data sent over the Internet is divided into small "packets" from 40 to 32,000 bytes in length.)

Trojan Horse

A computer program hidden on another computer for the purpose of destroying programs or software, or using the computer to collect information.

UDDI (Universal Description Discovery and Integration)

A platform-independent framework for describing services, discovering businesses, and integrating business services using the Internet.

Learn more about UDDI in our WSDL tutorial.

Unix

A computer operating system developed by Bell Labs. Mostly used on servers and Web servers.

UNZIP

To decompress a compressed file. See zip.

Upload

Transferring files from a local computer to a remote computer. In networking: transferring files from a Web client to a Web server. (See download).

URI (Uniform Resource Identifier)

Used to identify resources on the Internet. A URL is a type of URI.

URL (Uniform Resource Locator)

Web address. The standard method for locating web files (pages) on the Internet (e.g., http://www.runoob.com/).

USENET

A worldwide news system accessed via the Internet. (See newsgroups).

User Agent

Same as web browser.

VB (Visual Basic)

See Visual Basic.

VBScript

A scripting language from Microsoft. VBScript is the default scripting language in ASP. It can also be used in Internet Explorer.

Learn more about VBScript in our VBScript tutorial.

Virus

Same as computer virus.

Visit

In networking: a visit to a website. Often used to describe the activity of visitors to a Web site.

Visitor

In networking: a visitor to a Web site. Often used to describe a person who visits a Web site (to view it).

Visual Basic

A programming language from Microsoft.

Scientific Internet access (Virtual Private Network).

A private network between two remote sites, connected through a secure, encrypted virtual Internet connection (tunnel).

VRML (Virtual Reality Modeling Language)

A programming language that allows 3D effects to be added to HTML documents.

W3C (World Wide Web Consortium)

The organization responsible for managing the standards of the WWW.

Learn more about W3C in our W3C tutorial.

WAN (Wide Area Network)

Computers connected together in a wide network, larger than a local area network, usually connected by telephone lines. See also LAN.

WAP (Wireless Application Protocol)

An older standard for information services on wireless terminals, such as digital mobile phones.

Web Address

Same as a URL or URI. See URL.

Web Applet

A program that can be downloaded from the Internet and run on a user's computer. Most often written in Java.

Web Client

A software program used to access web pages. Sometimes the same as a web browser, but often used as a broad term.

Web Browser

A software program used to display web pages.

Learn more about browsers in our browser section.

Web Document

A file format distributed on the Internet. The most common web files are in markup language formats such as HTML or XML.

Web Error

See Web Server Error.

Web Form

See HTML Forms.

Web Host

A web server that provides "hosting" web services, such as a company or individual offering website space.

Web Hosting

The act of providing web hosting services.

Web Page

A document (usually an HTML file) designed for distribution via the Web.

Web Log

See Blog.

Web Robot

See Web Spider.

Web Server

A server is a computer that provides services or information to other computers. In web terms: a server provides web content to web browsers.

Web Server Error

An error message displayed from a web server. The most common web server error is "404 File Not Found".

Learn more about web server error messages in our HTML tutorial.

Web Services

Software components and applications that run on a web server. The server provides these services to other computers, browsers, or individuals using standard communication protocols.

Web Site

A related website, a collection of web pages belonging to a company or individual.

Web Spider

A computer program that searches Internet web pages. Common web spiders are like Google's search engine indexing web pages. Web spiders are also called web robots or crawlers.

Web Wanderer

See Web Spider.

Wildcard

A character used to replace any character(s). Most commonly used as an asterisk (*) in search tools.

Windows 2000, Windows NT, Windows 95/98, Windows XP

A computer operating system from Microsoft.

Windows Media

Audio and video formats developed by Microsoft for the Internet. (See ASF, ASX, WMA, and WMF.)

Learn more about Windows Media in our media tutorial.

WINZIP

A computer program that compresses and decompresses files. See zip.

WMA

An audio file format for the Internet, developed by Microsoft. (See WMV.)

Learn more about media formats in our media tutorial.

WMV

A video file format for the Internet, developed by Microsoft. (See also WMA.)

Learn more about media formats in our media tutorial.

WML (Wireless Markup Language)

A legacy standard used for wireless terminals, digital mobile phones, and information services. It is inherited from HTML but based on XML, and is far stricter than HTML.

WML Script

The scripting language (programming language) used for WML.

Worm

A computer virus that can make copies of itself and spread to other computers via the Internet.

WSDL (Web Services Description Language)

An XML-based language used to describe web services and how to access them.

Learn more about WSDL in our WSDL tutorial.

WWW (World Wide Web)

A global network of computers that uses the Internet to exchange web documents. (See Internet.)

WWW Server

Same as Web Server.

WYSIWYG (What You See Is What You Get)

In web terms: displaying the web page being edited in exactly the same way it will appear on the web.

XForms

An alternative version of HTML forms, based on XML and XHTML. Unlike HTML forms, it separates data definition from data display. It provides richer and more device-independent user input.

HTML redefined in XML format. Developed by the W3C.

XPath is a set of syntax rules (language) for defining parts of an XML document. XPath is an important part of the W3C XSL standard.

XQuery

XQuery is a set of syntax rules (language) for extracting information from XML documents. XQuery is based on XPath. XQuery was developed by the W3C.

Learn more about XQuery in our XQuery tutorial.
