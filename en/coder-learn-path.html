Learning Roadmaps for Programmers

A programmer ape is a very special kind of animal that can develop and maintain software. It is generally divided into program design apes and program coding apes, but the boundary between the two is not very clear; both can perform development and maintenance work.

Front-end Engineer

  1. Basic:HTML Tutorial，CSS Tutorial
  2. Intermediate:Javascript，jQuery
  3. Advanced:AJAX Tutorial，JSON Tutorial，XML Tutorial，Vue Tutorial，React Tutorial
  4. Extended Framework Learning:Bootstrap Tutorial，jQuery UI Tutorial，jQuery EasyUI Tutorial，jQuery Mobile Tutorial
  5. Debugging Tools:Firebug Tutorial
  6. Development Tools: HBuilder, Dreamweaver, VSCode, Photoshop

PHP Engineer

  1. Basic:HTML Tutorial，PHP Tutorial
  2. Intermediate:SQL Tutorial，MySQL Tutorial
  3. Advanced:Regular Expression Tutorial，MongoDB Tutorial， AJAX Tutorial，JSON Tutorial，XML Tutorial，
  4. Development Tools: VSCode, phpMyAdmin, EasyEclipse for PHP

Python Engineer

  1. Basic:Python Tutorial
  2. Intermediate:SQL Tutorial，MySQL Tutorial
  3. Advanced:Regular Expression Tutorial，MongoDB Tutorial， AJAX Tutorial，JSON Tutorial，XML Tutorial，
  4. Development Tools: PyDev for Eclipse

.NET Engineer

  1. Basic:C# Tutorial，ASP.NET Tutorial
  2. Intermediate:SQL Tutorial
  3. Advanced:Regular Expression Tutorial，MongoDB Tutorial， AJAX Tutorial，JSON Tutorial，XML Tutorial，
  4. Development Tools: Visual Studio 2010

JAVA Engineer

  1. Basic:Java Tutorial，JSP Tutorial
  2. Intermediate:SQL Tutorial，MySQL Tutorial
  3. Advanced:Regular Expression Tutorial，MongoDB Tutorial， AJAX Tutorial，JSON Tutorial，XML Tutorial，
  4. Development Tools: Eclipse

ASP Engineer

ASP is now used relatively rarely; the recommended learning path is:HTML Tutorial，ASP Tutorial，SQL Tutorial
