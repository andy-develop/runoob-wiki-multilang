PHP Variables

Variables are "containers" for storing information:

Examples

<?php $x=5; $y=6; $z=$x+$y; echo $z; ?>

Run Example »

Similar to algebra

x=5
y=6
z=x+y

In algebra, we use letters (like x), and assign values to them (like 5).

From the expression z=x+y above, we can calculate that the value of z is 11.

In PHP, these letters are calledvariables。

Variables are containers for storing data.

PHP Variables

Similar to algebra, you can assign a value (x=5) or an expression (z=x+y) to PHP variables.

Variables can have very short names (like x and y) or more descriptive names (like age, carname, totalvolume).

PHP Variable Rules:

  • Variables start with the $ sign, followed by the variable name
  • Variable names must start with a letter or an underscore character
  • Variable names can only contain letters, numbers, and underscores (A-z, 0-9, and _ )
  • Variable names cannot contain spaces
  • Variable names are case-sensitive ($y and $Y are two different variables)
PHP statements and PHP variables are case-sensitive.

Creating (Declaring) PHP Variables

PHP has no command for declaring variables.

A variable is created when you first assign a value to it:

Example

<?php $txt="Hello world!"; $x=5; $y=10.5; ?>

Run Example »

In the execution of the above statements, the variabletxtwill hold the valueHello world!, and the variablexwill hold the value5。

Note:When you assign a text value to a variable, put quotes around the text value.

PHP is a loosely typed language

In the above example, we notice that there is no need to declare the data type of the variable to PHP.

PHP automatically converts the variable to the correct data type based on its value.

In strongly typed programming languages, we must declare (define) the type and name of the variable before using it.

PHP Variable Scope

The scope of a variable is the part of the script where variables can be referenced/used.

PHP has four different variable scopes:

  • local
  • global
  • static
  • parameter

Local and Global Scope

Variables defined outside all functions have global scope. Apart from functions, global variables can be accessed by any part of the script. To access a global variable inside a function, you need to use the global keyword.

Variables declared inside a PHP function are local variables and can only be accessed inside the function:

Example

<?php
$x=5; // global variable

function myTest()
{
    $y=10; // local variable
    echo "<p>Test variables inside the function:<p>";
    echo "Variable x is:$x";
    echo "<br>";
    echo "Variable y is:$y";
}

myTest();

echo "<p>Test variables outside the function:<p>";
echo "Variable x is:$x";
echo "<br>";
echo "Variable y is:$y";
?>

In the above example, the myTest() function defines the $x and $y variables. The $x variable is declared outside the function, so it is a global variable , and the $y variable is declared inside the function, so it is a local variable.

When we call the myTest() function and output the values of the two variables, the function will output the value of the local variable $y, but cannot output the value of $x, because the $x variable is defined outside the function and cannot be used inside the function. If you want to access a global variable inside a function, you need to use the global keyword.

Then we output the values of the two variables outside the myTest() function. The script will output the value of the global variable $x, but cannot output the value of $y, because the $y variable is defined inside the function and is a local variable.

You can use the same variable names in different functions, because the variable names defined in these functions are local variables and only apply within that function.

PHP global Keyword

The global keyword is used to access global variables within a function.

To access a global variable defined outside a function from within a function, we need to add the global keyword before the variable inside the function:

Example

<?php $x=5; $y=10; function myTest() { global $x,$y; $y=$x+$y; } myTest(); echo $y; //Outputs 15 ?>

Run Example »

PHP stores all global variables in an array named $GLOBALS[index] in the array.indexStores the name of the variable. This array can be accessed inside functions, and can also be used to directly update global variables.

The above example can be written like this:

Example

<?php $x=5; $y=10; function myTest() { $GLOBALS['y']=$GLOBALS['x']+$GLOBALS['y']; } myTest(); echo $y; ?>

Run Example »

Static Scope

When a function completes, all of its variables are usually deleted. However, sometimes you want a local variable to not be deleted.

To do this, when you first declare the variable, usestaticthe keyword:

Example

<?php function myTest() { static $x=0; echo $x; $x++; echo PHP_EOL; //Newline character } myTest(); myTest(); myTest(); ?>

Run Example »

Then, each time the function is called, the variable will retain the value it had during the last call of the function.

Note:The variable is still a local variable of the function.

Parameter Scope

Parameters are local variables used to pass values to a function from the calling code.

Parameters are declared in the parameter list, as part of the function declaration:

Example

<?php function myTest($x) { echo $x; } myTest(5); ?>

We will, inPHP Functionschapter, discuss it in more detail.

    PHP Variable Scope

    The scope of a variable is the part of the script where variables can be referenced and used. PHP has four different variable scopes:

    No. Scope Description
    1 local Local scope
    2 global Global scope
    3 static Static scope
    4 parameter Function parameter scope

    1. local — scope of local variables

    Variables declared inside a PHP function are local variables and can only be accessed inside the function.

    <?php
function test()
{
    $a = 15;
    echo "内部输出结果：" . $a;
}
echo "外部输出结果：" . $a;  // 无法访问变量 a
echo PHP_EOL;
test();
?>

    Output result:

    外部输出结果：
内部输出结果：15

    2. global — scope of global variables

    Variables defined outside all functions are global variables. Apart from functions, global variables can be accessed by any part of the script. To access a global variable inside a function, you need to use the global keyword.

    <?php
$x = 5;
$y = 10;
$z = 0;

function test()
{
    global$x,$y,$z;
    $z = $x + $y;
}

test();
echo $z;
?>

    Result:15

    PHP stores all global variables in an array named$GLOBALS[index]in the array,indexstores the name of the variable.

    This array can be accessed inside functions, and can also be used directly to update global variables.

    <?php
$x = 5;
$y = 10;
$z = 0;
function test()
{
    $GLOBALS['z'] = $GLOBALS['x']+$GLOBALS['y'];
}

Test();
echo $z;
?>

    Result:15

    3. static — static scope

    When a function finishes executing, all of its variables are usually deleted.

    However, sometimes you need local variables to not be deleted. To do this, use the static keyword when you first declare the variable.

    When a function finishes, all of its variables are usually deleted. However, sometimes you may want a local variable to not be deleted.

    Result:0 1 2 3

    Each time the function is called, this variable will retain the value from the previous call.

    4. parameter - parameter scope

    Parameters are local variables that receive values passed to the function by the calling code.

    Regarding the precedence of local and global variables, because functions in PHP each have their own separate scope, the precedence of local variables is higher than that of global variables (before you declare this variable). After declaration, this variable becomes a local variable; if you modify its value, the value of the global variable will also change.

    Using life examples to explain class properties and methods

    Suppose you are developing an online store, and you need to define a "Product" class to manage all your products. Each product has some common properties, such as name, description, price, etc., and also some different properties, such as size, color, weight, etc.

    In this scenario, we can consider each product as a class, and the properties and methods of each product as the properties and methods of that class. For example, you can define a class named "Product" to represent your products, and this class can have the following properties and methods:

    Properties:

    • $name: Product name
    • $description: Product description
    • $price: Product price
    • $size: Product size
    • $color: Product color
    • $weight: Product weight

    Methods:

    • setName($name): Set product name
    • setDescription($description): Set product description
    • setPrice($price): Set product price
    • setSize($size): Set product size
    • setColor($color): Set product color
    • setWeight($weight): Set product weight

    By analogy to programming, you can manage all your products by defining a "Product" class. You can create multiple instances to represent different products, each instance has a unique set of properties and methods, and you can access and modify these properties by calling the class's methods. In this way, you can organize code into a logical unit and use the class's properties and methods to implement different functions.

    Using life examples to explain class scope

    Suppose you are a student, and your school has many teachers, each teacher has some special skills, such as painting, playing basketball, etc. In this scenario, we can consider each teacher as a class, and each skill as a property or method of this class.

    When you need to learn a specific skill, you need to find the teacher who has that skill and learn from him. In this process, you can only access this teacher's skills, not other teachers' skills. This is because each teacher's skills only belong to that teacher's class scope.

    By analogy to programming, class scope also means that properties and methods defined in a class can only be accessed within that class. This means that if you need to access a property or method in a class, you must first create an instance of that class and use that instance to access the property or method. Similar to the life example, this restriction can improve the security and maintainability of code, and also makes code easier to understand and organize.

    Using life

    Suppose you are an employee working at a company. Your company has a device that can record employees' attendance days. Whenever you arrive at the company and start work, you need to use this device to clock in to record your attendance time.

    In this scenario, this device can be regarded as a static variable, because it retains state between multiple clock-ins. Each time you clock in, the device records your attendance days and stores this number in memory for use at the next clock-in. In this way, whether it is your first day or your hundredth day at work, the device can correctly calculate your attendance days.

    By analogy to programming, static variables can also share state between multiple calls to a function and be used in the next call to the function, thereby improving code efficiency and maintainability.

    Examples in life explaining static scope

    Using life examples to explain what parameter scope is

    In life, "house rental" can be used as an analogy to explain the concept of parameter scope.

    Suppose you are a real estate agent, and your client wants to rent a house. Your task is to find a suitable house for them. To achieve this goal, you need to understand the client's requirements, such as how many bedrooms, how many bathrooms, etc. These requirements can be seen as the function's parameters.

    Once you understand the client's requirements, you can find a house that meets the conditions based on these requirements. In this process, you only need to process these requirements inside the function, without considering the possible requirements of other clients. This is the concept of parameter scope: the function's parameters only take effect inside the function; for other code outside the function, these parameters are invisible.

    By analogy to programming, parameter scope means that the function's parameters are only valid inside the function and are invisible to code outside the function. This means that inside the function, you can use these parameters to perform operations without worrying that these operations will affect other code.
