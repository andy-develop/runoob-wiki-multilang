    Python Calculate Cartesian Product

    Calculating the Cartesian product of multiple sets has a pattern, and the algorithm and code are not difficult. However, many languages do not provide a direct method to calculate the Cartesian product, requiring you to write long sections of code. Python provides the simplest way to calculate the Cartesian product (only one line of code). See the code below for details:

    #!/usr/bin/python3
# -*- coding: utf-8 -*-
# @file   : Cartesian.py
# @author : shlian
# @date   : 2018/5/29
# @version: 1.0
# @desc   : 用python实现求笛卡尔积
import itertools

class cartesian(object):
    def __init__(self):
        self._data_list=[]

    def add_data(self,data=[]): #添加生成笛卡尔积的数据列表
        self._data_list.append(data)

    def build(self): #计算笛卡尔积
        for item in itertools.product(*self._data_list):
            print(item)

if __name__=="__main__":
    car=cartesian()
    car.add_data([1,2,3,4])
    car.add_data([5,6,7,8])
    car.add_data([9,10,11,12])
    car.build()
