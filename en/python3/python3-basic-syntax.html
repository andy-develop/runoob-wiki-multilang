Python3 Basic Syntax

Encoding

By default, Python3 source files use theUTF-8encoding, and all strings are unicode strings.

Of course you can also specify a different encoding for the source file:

# -*- coding: cp-1252 -*-

The above definition allows the source file to use characters from the Windows-1252 character set, suitable for Bulgarian, Belarusian, Macedonian, Russian, and Serbian.

Identifiers

  • The first character must be a letter (a-z, A-Z) or an underscore_ 。
  • The other parts of an identifier consist of letters, digits, and underscores.
  • Identifiers are case-sensitive; count and Count are different identifiers.
  • Identifiers have no hard length limit, but it is recommended to keep them concise (generally no more than 20 characters).
  • Reserved keywords are prohibited; for example, if, for, and class cannot be used as identifiers.

Valid identifiers:

age = 25                # 普通变量名，最常见
user_name = "Alice"     # 用下划线连接单词，清晰易读
_total = 100            # 下划线开头通常表示“内部使用”或“私有”
MAX_SIZE = 1024         # 全大写通常表示“常量”（固定不变的值）
calculate_area()        # 函数名，动词+名词
StudentInfo             # 类名，首字母大写（驼峰命名法）
__private_var           # 双下划线开头，有特殊含义

Invalid identifiers:

2nd_place = "silver"    # 错误：以数字开头
user-name = "Bob"       # 错误：包含连字符
class = "Math"          # 错误：使用关键字
$price = 9.99          # 错误：包含特殊字符
for = "loop"           # 错误：使用关键字

Python 3 allows Unicode characters as identifiers, so Chinese can be used for variable names; non-ASCII identifiers are also allowed.

姓名 = "张三"  # 合法
π = 3.14159   # 合法

Test whether an identifier is valid:

Example

def is_valid_identifier(name):
    try:
        exec(f"{name} = None")
        return True
    except:
        return False

print(is_valid_identifier("2var"))  # False
print(is_valid_identifier("var2"))  # True

Comments

In Python, single-line comments start with#and are written as follows:

Example (Python 3.0+)

#!/usr/bin/python3 # First comment print ("Hello, Python!") # Second comment

Executing the above code, the output is:

Hello, Python!

Multi-line comments can use multiple#hash signs, and also''' 和 """：

Example (Python 3.0+)

#!/usr/bin/python3 # First comment # Second comment '''Third comment Fourth comment''' """Fifth comment Sixth comment""" print ("Hello, Python!")

Executing the above code, the output is:

Hello, Python!

Lines and Indentation

The most distinctive feature of Python is using indentation to represent code blocks; no curly braces are needed.{} 。

The number of spaces in indentation is variable, but statements in the same code block must contain the same number of indentation spaces. Example:

Example (Python 3.0+)

if True: print ("True") else: print ("False")

In the following code, the last line of statements has inconsistent indentation, which will cause a runtime error:

Example

if True:
    print ("Answer")
    print ("True")
else:
    print ("Answer")
  print ("False")    # Inconsistent indentation will cause a runtime error

Due to inconsistent indentation, the above program will produce an error similar to the following after execution:

 File "test.py", line 6
    print ("False")    # 缩进不一致，会导致运行错误
                                      ^
IndentationError: unindent does not match any outer indentation level

Multi-line Statements

Python usually writes one statement per line, but if a statement is very long, we can use a backslash\to implement multi-line statements, for example:

total = item_one + \
        item_two + \
        item_three

Example

item_one = 1
item_two = 2
item_three = 3
total = item_one + \
        item_two + \
        item_three
print(total) # Output is 6

Multi-line statements inside [], {}, or () do not need a backslash\, for example:

total = ['item_one', 'item_two', 'item_three',
        'item_four', 'item_five']

Number Types

Python has four types of numbers: integers, booleans, floats, and complex numbers.

  • int(Integer), such as 1; there is only one integer type, int, represented as a long integer, without the Long type in Python 2.
  • bool(Boolean), such as True.
  • float(Float), such as 1.23, 3E-2
  • complex(Complex) - Complex numbers consist of a real part and an imaginary part, in the form a + bj, where a is the real part, b is the imaginary part, and j represents the imaginary unit. For example, 1 + 2j, 1.1 + 2.2j

String

  • In Python, single quotes'and double quotes"are used exactly the same.
  • Using triple quotes (''' 或 """) can specify a multi-line string.
  • Escape Character\。
  • Backslashes can be used for escaping; usingrcan prevent the backslash from escaping. For example,r"this is a line with \n" 则 \nwill be displayed, not a line break.
  • Concatenate strings literally, such as"this " "is " "string"will be automatically converted tothis is string。
  • Strings can be concatenated using the+operator, and repeated using the*operator.
  • Strings in Python have two indexing methods: from left to right starting at0, and from right to left starting at-1.
  • Strings in Python cannot be changed.
  • Python has no separate character type; a character is just a string of length 1.
  • String Slicingstr[start:end], where start (inclusive) is the index where the slice begins, and end (exclusive) is the index where the slice ends.
  • String slicing can include a step parameter, step, with the following syntax:str[start:end:step]
word = '字符串'
sentence = "这是一个句子。"
paragraph = """这是一个段落，

Blank Lines

Use blank lines between functions or between class methods to indicate the start of a new block of code. Also use a blank line between the class and function entries to highlight the start of the function entry.

Blank lines are different from code indentation. Blank lines are not part of Python syntax. If you do not insert blank lines, the Python interpreter will still run without errors. However, the purpose of blank lines is to separate two pieces of code with different functions or meanings, making future code maintenance or refactoring easier.

Remember:Blank lines are also part of the program code.

Waiting for User Input

After executing the following program and pressing the Enter key, it will wait for user input:

Example (Python 3.0+)

#!/usr/bin/python3 input("\n\nExit after pressing the Enter key.")

In the above code,\n\ntwo new blank lines will be output before the result is output. Once the user presses theenterkey, the program will exit.

Multiple Statements on the Same Line

Python can use multiple statements on the same line, with semicolons between statements;as separators. The following is a simple example:

Example (Python 3.0+)

#!/usr/bin/python3 import sys; x = 'runoob'; sys.stdout.write(x + '\n')

Using a script to execute the above code, the output is:

runoob

Using the interactive command line to execute, the output is:

>>> import sys; x = 'runoob'; sys.stdout.write(x + '\n')
runoob
7

Here 7 indicates the number of characters,runoobthere are 6 characters,\nrepresenting one character, adding up to7characters.

>>> import sys
>>> sys.stdout.write(" hi ")    # hi 前后各有 1 个空格
 hi 4

Multiple Statements Form a Code Group

A group of statements with the same indentation constitutes a code block, which we call a code group.

Compound statements like if, while, def, and class start with a keyword on the first line and end with a colon ( : ). One or more lines of code after that line form a code group.

We call the first line and the following code group a clause.

The following is an example:

if expression : 
   suite
elif expression : 
   suite 
else : 
   suite

    Similar to C/C++'sprintf, Python'sprintcan also implement formatted output, using the%operator, which treats the string on the left as a format string and substitutes the parameter on the right into the format string:

    print("100 + 200 = %d" % 300) #左边的%d被替换成右边的300
print("A的小写是%s" % "a") #左边的%s被替换成右边的a

    The obtained result is:

    100 + 200 = 300A的小写是a

    If you want to substitute multiple parameters, you need to use()to wrap the multiple parameters. Separate parameters with commas, and the order of the parameters should correspond to the order in the format string:

    print("%d + %d = %d" % (100,200,300))
print("%s %s" % ("world","hello"))

    The obtained result is:

    100 + 200 = 300world hello

    The meanings of different placeholders in the format string:

    • %s: as a string
    • %d: as a signed decimal integer
    • %u: as an unsigned decimal integer
    • %o: as an unsigned octal integer
    • %x: As an unsigned hexadecimal integer, a-f are in lowercase form
    • %X: As an unsigned hexadecimal integer, A-F are in uppercase form
    • %f: As a floating-point number
    • %e，%E: As a floating-point number, using scientific notation
    • %g，%G: As a floating-point number, using the least significant digits

    In Python,from somemodule import * 和 import somemodulethere are some important differences, mainly reflected in namespaces and accessibility.

    import somemodule- Import the entire module.

    When using the content from the module, you need to use the module name as a prefix. For example, if somemodule has a function foo, you need to call it like this: somemodule.foo().

    The advantage is that the namespace remains clear, avoiding conflicts with variable and function names in the current module.

    import math
print(math.sqrt(16)) # 输出: 4.0

    from somemodule import * - Import all public objects (functions, variables, classes, etc.) from the module into the current namespace.

    When using the content from the module, you do not need to use the module name as a prefix. For example, if somemodule has a function foo, you can call it directly: foo().

    The disadvantage is that it may introduce naming conflicts, because variable and function names in the current namespace may conflict with some names in the imported module.

    from math import *
print(sqrt(16)) # 输出: 4.0

    In summary,import somemodulemaintains the clarity and safety of the namespace, reducing the risk of naming conflicts, whilefrom somemodule import *although concise, may lead to naming conflicts and reduced code readability. It is usually recommended to useimport somemoduleorfrom somemodule import specific_functionthis more explicit way of importing.

    For more information, you can refer to:The main difference between Python import and from ... import
