Python3 Environment Setup

Python3 has excellent cross-platform compatibility and can run stably on the three major operating systems: Windows, Linux, and Mac OS X. It also supports many other platforms and environments, including:

  • Unix series (Solaris, Linux, FreeBSD, AIX, HP/UX, SunOS, IRIX, etc.)
  • Traditional Windows systems (9x/NT/2000)
  • Classic Macintosh systems (Intel, PPC, 68K architectures)
  • Other specialized/niche platforms (OS/2, multiple versions of DOS, PalmOS, Nokia mobile phones, Windows CE, Acorn/RISC OS, BeOS, Amiga, VMS/OpenVMS, QNX, VxWorks, Psion)

In addition, Python can also be ported to run in Java and .NET virtual machine environments.

Python Installation

Python has excellent cross-platform compatibility and has been ported to multiple operating systems, running stably on mainstream platforms such as Windows, macOS, and Linux.

We can prioritize downloading the binary installation package for the corresponding platform and quickly complete the installation through a visual wizard or command line. This is the most convenient and efficient installation method.

If there is no corresponding binary installation package for the operating system, you can obtain the Python source code and manually compile and install it using a C compiler.

Compared to binary package installation, source code compilation provides richer feature customization options, making Python environment configuration more flexible.

Verify Whether the Python3 Environment Is Installed Successfully

To verify the Python3 version, open the command prompt (Windows) or terminal (macOS/Linux) and execute the following command:

# 通用命令（推荐，所有系统兼容）
python3 --version
# 补充：Windows系统若已配置PATH，也可执行
python --version

If output similar to Python 3.11.4 appears, Python3 was installed successfully.

Verify pip3 (Python package management tool). pip3 is the default package management tool for Python3, used to install third-party libraries. Verification command:

# 通用命令
pip3 --version
# Windows补充命令
pip --version

If output similar to pip 23.1.2 from xxx (python 3.11) appears, pip3 is available.

Environment Variable Configuration

If the above executionpythoncommand executes successfully, the environment is already configured and no additional configuration is needed. This section can be ignored.

The directory where program executable files are stored is often not in the system's default search path. The system's PATH environment variable (case-sensitive on Unix, case-insensitive on Windows) is used to store the search paths for executable files.

On Mac OS, if you need to reference Python in a non-default directory, you must manually add the Python installation directory to PATH.

Set Environment Variables on Unix/Linux

Note: /usr/local/bin/pythonis the Python installation directory; replace it with your actual path.

bash shell（Linux）：

export PATH="$PATH:/usr/local/bin/python"

csh shell：

setenv PATH "$PATH:/usr/local/bin/python"

sh/ksh shell：

PATH="$PATH:/usr/local/bin/python"

Set Environment Variables on Windows

If you did not checkAdd Python.exe to PATH, it will cause the command line to fail to recognizepython/python3command, you need to manually configure environment variables:

  • Find the installation path of Python3 (e.g., D:\Python311, C:\Program Files\Python311), and also find the Scripts folder under it (e.g., D:\Python311\Scripts, the directory where pip3 is located).
  • Right-click 'This PC' → 'Properties' → 'Advanced System Settings' → 'Environment Variables'.
  • In 'User Variables' or 'System Variables', find the Path variable and double-click to edit.
  • Click 'New', add the Python3 installation root path and the Scripts folder path respectively, then click 'OK' to save all configurations.

For more detailed configuration, refer to:https://www.runoob.com/w3cnote/add-python-to-path-on-windows-11.html

Close the original command prompt, reopen it, and execute the verification command for it to take effect.

The following are descriptions of several environment variables applied to Python:

Environment Variable Name Core Function
PATH Search path used by the system to find the Python interpreter and executable files.
PYTHONPATH Search path for Python to find third-party libraries and custom modules.
PYTHONHOME Specifies the Python installation root directory, telling the interpreter where the core library/standard library is located.
PYTHONSTARTUP Specifies the path of the script file to be automatically executed when the Python interactive interpreter starts.
PYTHONCASEOK Windows-specific; makes Python ignore case when importing modules.
PYTHONDONTWRITEBYTECODE Prohibit Python from generating at runtime.pyc / .pyobytecode cache files.

Run Python

There are three ways to run Python:

1. Interactive Interpreter:

You can enter Python through a command-line window and start writing Python code in the interactive interpreter.

You can do Python coding work on Unix, DOS, or any other system that provides a command line or shell.

python

The following are Python command-line arguments:

OptionDescription
-dEnable debug mode, display detailed debugging information during code parsing and interpreter runtime
-OGenerate optimized code, generate .pyo optimized bytecode file when compiling script (ignore assertion statements and other debug-related code)
-OODeeply optimize code, generate .pyo file and remove all docstrings in code, further reduce file size
-SWhen Python starts, do not automatically import the site module, i.e., do not load related configuration for finding Python module paths (such as site-packages directory)
-V / --versionOutput the currently installed Python version number and exit the interpreter directly
-vvOutput detailed version information (including compilation environment, dependency libraries and other additional information)
-XAfter Python 1.6, usage based on built-in exceptions (only for string types) is deprecated; this parameter is used for compatibility with old related features
-h / --helpView complete help for all Python command-line arguments and exit the interpreter directly
-c cmdExecute the specified Python code snippet directly on the command line (cmd is string-format code), no need to write a .py script file
-m moduleRun the specified Python module in the form of a module (such as pip, http.server, etc.), automatically find the module path and execute
-iAfter executing the specified Python script, automatically enter the interactive interpreter environment for subsequent debugging and supplementary code execution
-bWhen encountering incompatible comparison operations between bytes and str, issue a warning message
-bbWhen encountering incompatible comparison operations between bytes and str, directly raise an error and terminate the program
-uDisable buffering of standard output (stdout) and standard error (stderr), enabling real-time printing of logs or output content
fileSpecify the Python script file path to execute (absolute or relative path); the interpreter will load and run the code in the file
-qWhen entering the interactive interpreter, hide the welcome message and directly display the command prompt

2. Command-Line Scripts

You can execute Python scripts on the command line by introducing the interpreter in your application, as follows:

python script.py

Note:When executing the script, check whether the script has executable permissions.

    How to install python3 in the cygwin emulator

    Cygwin is a UNIX-like emulation environment that runs on the Windows platform. It is free software developed by Cygnus Solutions (the company also developed the famous tool eCos, but it has now been acquired by Red Hat). It is very useful for learning the UNIX/Linux operating environment, porting applications from UNIX to Windows, or doing certain special development work, especially embedded system development on Windows using the GNU toolset.

    Install cygwin:

    1. Download the executable filehttp://www.cygwin.com/setup-x86.exe

    2. Select "Install from internet", then click Next.

    3. Root directory C:\cygwin (other directories are not recommended, especially directory names with spaces). 4. Choose a download site; http://sourceware.mirror.tds.net is relatively stable for downloading. 5. In the "Select Packages" menu, choose "Category" and add the following packages:
    under Archive select zip and unzip
under Database, select postgresql
optional: under Editors select vim (if you want to be able to edit files with vi)
under Graphics, select gnuplot
under Libs, select libglib2.0_0
under Net select curl, inetutils, openssh, openssl
under Perl select perl, perl-XML-Simple, and perl-IO-Tty
under Python select python2
under Tcl select expect
    6. Click Next to start installation.

    7. Copy the file moshell/examples/cygwin_install/cygwin_install.txt to C:/Cygwin (you can also download it from: http://newtran01.au.ao.ericsson.se/moshell/cygwin_install.txt).

    8. On Windows, click Start -> Run.

    In the "Run" window, enter cmd and press Enter.

    Open the DOS window and execute the following commands in the DOS window:

    c:
cd cygwin
bin\perl.exe cygwin_install.txt

    Install python3

    wget rawgit.com/transcode-open/apt-cyg/master/apt-cyg
install apt-cyg /bin
apt-cyg install python3

    Verification:

    [~]$ python3
