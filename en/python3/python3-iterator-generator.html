Python3 Iterators and Generators

Iterator

Iteration is one of Python's most powerful features, and a way to access collection elements.

An iterator is an object that can remember the position of the traversal.

The iterator object starts accessing from the first element of the collection until all elements have been accessed. Iterators can only go forward, not backward.

Iterators have two basic methods:iter() 和 next()。

Strings, lists, or tuple objects can all be used to create iterators:

Example (Python 3.0+)

>>> list=[1,2,3,4]
>>> it = iter(list)    # Create an iterator object
>>> print (next(it))   # Output the next element of the iterator
1
>>> print (next(it))
2
>>>

Iterator objects can be traversed using a regular for statement:

Example (Python 3.0+)

#!/usr/bin/python3 list=[1,2,3,4] it = iter(list) # Create an iterator object for x in it: print (x, end=" ")

Executing the above program produces the following output:

1 2 3 4

You can also use the next() function:

Example (Python 3.0+)

#!/usr/bin/python3 import sys # Import the sys module list=[1,2,3,4] it = iter(list) # Create an iterator object while True: try: print (next(it)) except StopIteration: sys.exit()

Executing the above program produces the following output:

1
2
3
4

Create an Iterator

To use a class as an iterator, you need to implement two methods in the class: __iter__() and __next__().

If you already understand object-oriented programming, you know that classes have a constructor. Python's constructor is __init__(), which is executed when the object is initialized.

For more information, refer to:Python3 Object-Oriented Programming

The __iter__() method returns a special iterator object that implements the __next__() method and signals the completion of the iteration through a StopIteration exception.

The __next__() method (next() in Python 2) returns the next iterator object.

Generator

In Python, functions that use `yield`yieldare called generators (generator).

yield`yield` is a keyword used to define generator functions. A generator function is a special kind of function that can produce values step by step during iteration, rather than returning all results at once.

Unlike ordinary functions, a generator is a function that returns an iterator and can only be used for iteration operations. To put it simply, a generator is an iterator.

When using `yield` in a generator functionyieldstatement, the execution of the function pauses, andyieldthe expression after `yield` is returned as the value of the current iteration.

Then, every time the generator'snext()`__next__()` method is called orfor`for` loop is used for iteration, the function resumes execution from where it was last paused until it encounters anotheryield`yield` statement. In this way, the generator function can produce values step by step, without needing to compute and return all results at once.

Calling a generator function returns an iterator object.

The following is a simple example that demonstrates the use of generator functions:

Example

def countdown(n): while n > 0: yield n n -= 1 # Create a generator object generator = countdown(5) # Get values by iterating over the generator print(next(generator)) # Output: 5 print(next(generator)) # Output: 4 print(next(generator)) # Output: 3 # Use a for loop to iterate over the generator for value in generator: print(value) # Output: 2 1

In the above example,countdownthe function is a generator function. It uses yield statements to gradually produce countdown numbers from n to 1. Each time a yield statement is executed, the function returns the current countdown value and, on the next call, continues execution from where it was last paused.

By creating a generator object and using the next() function or a for loop to iterate over the generator, we can gradually obtain the values produced by the generator function. In this example, we first use the next() function to get the first three countdown values, then use a for loop to get the remaining two.

The advantage of generator functions is that they can produce values on demand, avoiding generating a large amount of data at once and occupying a large amount of memory. In addition, generators can work seamlessly with other iteration tools (such as for loops), providing a concise and efficient iteration method.

Executing the above program produces the following output:

5

The following example uses yield to implement the Fibonacci sequence:

Example (Python 3.0+)

#!/usr/bin/python3 import sys def fibonacci(n): # Generator function - Fibonacci a, b, counter = 0, 1, 0 while True: if (counter > n): return yield a a, b = b, a + b counter += 1 f = fibonacci(10) # f is an iterator, returned and generated by the generator while True: try: print (next(f), end=" ") except StopIteration: sys.exit()

Executing the above program produces the following output:

    When is it necessary to use yield?

    A function f returns a list. This list is dynamically calculated (whether it's mathematical computation or logical reading and formatting), and this list is very large (whether it's always large or grows as the input parameters increase). At this time, we want to get each list element one by one when calling the function and using an iterator to loop, instead of directly getting a complete list, to save memory. This is where yield is very useful.

    For details on how to use yield, refer to:A Brief Analysis of Python yield Usage

    Taking the Fibonacci function as an example, we generally want to return a list of n numbers from n:

    def fab(max): 
   n, a, b = 0, 0, 1 
   L = [] 
   while n < max: 
       L.append(b) 
       a, b = b, a + b 
       n = n + 1 
   return L

    The fab function above returns a list with max elements from the parameter max. When max is very large, it consumes a lot of memory.

    Usually when we use it, it looks like this, for example:

    f = iter(fab(1000))
while True:
    try:
        print (next(f), end=" ")
    except StopIteration:
        sys.exit()

    In this way, we actually first generate a list with 1000 elements: f, and then we use this f.

    Now, let's use a different method:

    Because what we actually use is the traversal of the list, that is, the iterator of the list. Then we can make the fab function return only one iterator each time — one calculation result — instead of a complete list:

    def fab(max): 
    n, a, b = 0, 0, 1 
    while n < max: 
        yield b 
        # print b 
        a, b = b, a + b 
        n = n + 1

    In this way, each time we call the fab function, for example like this:

    for x in fab(1000):
    print(x)

    Or with the next() function, the actual operation is that each call is interrupted at yield and returns a result, and then when called again, it resumes from the interruption and continues running.

    Implementing the Fibonacci sequence with a custom iterator

    class Fibonacci:
  def __init__(self, count):
    self.count = count

  def __iter__(self):
    self.i = 0
    self.a, self.b = 0, 1
    return self

  def __next__(self):
  if self.i < self.count:
    self.i += 1
    a_old = self.a
    self.a, self.b = self.b, self.a + self.b
    return a_old
  else:
    raise StopIteration

for i in Fibonacci(10):
  print(i, end=" ")

    As the tutorial says, iterators and generators are a major feature of Python, and their core is based on the iterator protocol.

    And what we often use in daily programmingfor inthe loop body, in essence, is a major application of the iterator protocol.

    Meanwhile, Python's built-in collection types (strings, lists, tuples, dictionaries) have all implemented the iterator protocol, so they can be iterated over using the for in statement. When the for in loop encounters a StopIteration exception, it terminates the iteration and traversal.

    Let me also talk about the connections and differences among the three concepts: iterable, iterator, and generator.

    1. The concept of iterable has the largest scope. Generators and iterators are certainly iterable, but iterables are not necessarily iterators or generators, such as the built-in collection data types mentioned above. It can be considered that in Python, anything with collection characteristics is iterable.

    2. Iterator. The characteristic of iterators is that they can all be traversed one by one using for in and next.

    3. Generator. A generator is definitely an iterator, and it is also definitely iterable.

    As for why Python introduces iterators and generators, besides saving memory space, they can also significantly improve code execution speed.

    An example and explanation of a custom iterator class are as follows:

    class MyIter():
  def __init__(self):
    #为了示例，用一个简单的列表作为需迭代的数据集合，并且私有化可视情况变为其他类型集合
    self.__list1=[1,2,3,4]
    self.__index=0

  def __iter__(self):
    #该魔法方法，必须返回一个迭代器对象，如果self已经定义了__next__()魔法方法，则只需要返回self即可
    #因为如上面所述，生成器一定是迭代器
    return iter(self.list1)    

  def __next__(self):
    #此处的魔法函数，python会自动记忆每次迭代的位置，无需再使用yield来处理
    #在使用next(obj)时，会自动调用该魔法方法
    res=self.__list1[self.__index]
    self.__index+=1
    return res

    The above is the mechanism of a custom iterator class.

    Next, I will demonstrate with an example how to define a custom generator function, because in most real-world scenarios, generator functions may be used more often:

    def my_gene_func():
  index=0
  li=[1,2,3,4,5]
  yield li[index]
  index+=1

    When the above function is called, it returns a generator object. Then, using next() on that generator object returns values one by one:

    gene=my_gene_func()
next(gene)

    Actually, the core concept is still remembering the position of the last iteration. In a class, it is implemented directly using the __next__ magic method; in a function, it is implemented using yield. I also suspect that the __next__ magic method in a class is implemented at the bottom level using yield.

    As for the specific application scenarios of iterators and generators, any situation where you need to improve runtime efficiency or save memory resources, and where the data to be traversed is in collection form, can be considered.

    Another niche use case is to indirectly achieve the effect of coroutines, that is, to implement alternating execution of different tasks within the same thread.

    def mytask1():
  print('task1 开始执行')
  '''
  task code
  '''
  yield

def mytask2():
  print('task2 开始执行')
  '''
  task code
  '''
  yield

gene1=mytask1()
gene2=mytask2()

for i in range(100):
  next(gene1)

    The usage of yield in Python is very similar to return; both provide a return value. But the biggest difference between yield and return is that once return returns, the code segment finishes execution, whereas after yield returns a value, it hands over the use of the CPU, and the code segment does not end directly but is interrupted at that point. When the send() or next() method is called, yield can continue execution from where it was interrupted.

    In a function, if the yield keyword is used, the current function becomes a generator.

    The following generates a Fibonacci sequence.

    def fib(n):
    index = 0
    a = 0
    b = 1

    while index < n:
        yield b
        a,b = b, a+b
        index += 1

    Generator object:

    fib = fib(100)
print(fib)

    The printed result is a generator object; it does not directly print the values we want.

    <generator object fib at 0x7fef20062ac0>
