JavaScript ArrayObject

The role of the array object is: to use a single variable name to store a series of values.

Online Examples

Create an array, assign values to it:

Example

var mycars = new Array();
mycars[0] = "Saab";
mycars[1] = "Volvo";
mycars[2] = "BMW";

Try it yourself »

At the bottom of the page you can find more examples.

What is an Array?

An array object uses a single variable name to store a series of values.

If you have a set of data (for example: car names), stored in separate variables as shown below:

var car1="Saab";
var car2="Volvo";
var car3="BMW";

However, if you want to find a particular car from them? And not 3 cars, but 300? That would not be an easy task!

The best way is to use an array.

An array can store all values with one variable name, and you can access any value using the variable name.

Each element in the array has its own ID so that it can be easily accessed.

Create an Array

There are three methods to create an array.

The following code defines an array object named myCars:

1: Conventional way:

var myCars=new Array();
myCars[0]="Saab";      
myCars[1]="Volvo";
myCars[2]="BMW";

2: Concise way:

var myCars=new Array("Saab","Volvo","BMW");

3: Literal:

var myCars=["Saab","Volvo","BMW"];

Access an Array

By specifying the array name and the index number, you can access a specific element.

The following example accesses the first value of the myCars array:

var name=myCars[0];

The following example modifies the first element of the array myCars:

myCars[0]="Opel";


You can have different objects in an array

All JavaScript variables are objects. Array elements are objects. Functions are objects.

Therefore, you can have different variable types in an array.

You can include object elements, functions, and arrays in an array:

myArray[0]=Date.now;
myArray[1]=myFunction;
myArray[2]=myCars;

Array Methods and Properties

Use the predefined properties and methods of the array object:

var x=myCars.length // the number of elements in myCars
var y=myCars.indexOf("Volvo") // the index of the "Volvo" value

Creating New Methods

Prototype is a JavaScript global constructor. It can build properties and methods for new JavaScript objects.

Example: Create a new method.

Array.prototype.myUcase=function(){
    for (i=0;i<this.length;i++){
        this[i]=this[i].toUpperCase();
    }
}

Try it yourself »

The above example creates a new array method for converting lowercase characters in an array to uppercase characters.

    Traversing a one-dimensional array: access each element in the array in sequence and perform the same operation on each element.

    for(var i=0;i<arr.length;i++){
    arr[i]//当前正在遍历的元素
}

    Traversing an associative array: for-in loop

    for(var key in hash){
    key//只是元素的下标名
    hash[key]//当前元素值
}

    Actually: at the underlying JS level, all objects are associative arrays:

    For example: indexed arrays, window, etc.

    Traversing a two-dimensional array: the outer loop traverses rows, the inner loop traverses columns.

    for(var r=0;r<arr.length;r++){
    for(var c=0;c<arr[r].length;c++){
        arr[r][c]//当前元素
    }
}

    JS provides multiple traversal methods for arrays.

    const ary = ['a', 'b', 'c'];

// 最基本的方式, 只能遍历下标有序递增的数组
for (let i=0; i<ary.length; i++) {
  console.log(i, ary[i]);   // 0 a  1 b  2 c
}

// in:每遍历一次数组指针向后移动一位, 并得到当前数组元素值的下标, 可以通过 ary[key] 来访问数组元素值
for (let key in ary) {
  console.log(key, ary[key]);  // 0 a  1 b  2 c
}

// of:每遍历一次数组指针向后移动一位, 并得到当前数组元素的值, 处理二维数组时极为方便
for (let value of ary) {
  console.log(value);    // a b c
}

    JS also has built-in multiple iteration methods for array objects, which is extremely convenient when handling arrays.

    /**
 *  forEach(function)
 *  
 *  该方法接受一个函数作为参数, 该函数拥有两个参数, 分别为数组的值、键
 *  该方法没有返回值
 */

 ary.forEach((value, key) => {
    console.log(key, value); // 0 a  1 b  2 c
 })


/**
 * map(function)
 *  
 * 该方法接受一个函数作为参数, 该函数拥有两个参数, 分别为数组的值、键
 * 可以在传入的函数中返回相应的值,你每次迭代时返回的值会被map方法组装成一个新数组作为返回值返回
 */

 var result = ary.map((value, key) => {
    return value + '_runoob.com';
 })

 console.log(result); // ['a_runoob.com', 'b_runoob.com', 'c_runoob.com']

    Numeric Indices and Non-numeric Indices

    JavaScript arrays only support numeric indices; non-numeric indices refer to object properties.

    JavaScript arrays can be regarded as special objects. There are two ways to represent object properties.
    var a=Object();
a.myattr="runoob";
a["myattr"]="runoob";

    See the following example:

    var a=new Array();
a['a1']=1;
a['a2']=2;
a.length  // 输出0

    In the example, because you did not assign values to the array elements, the length of array a has not been created. At this time, a.length outputs 0.

    var a=new Array();
a['a1']=1;
a['a2']=2;
a[2]=3;
a.length  // 输出3

    In the last line of code, the array elementa[2]is assigned a value. At this point, JavaScript creates a space of length 3 for array a and assigns 3 to the third element, but the first and second elements have no values assigned, so a

    If what you want to use is an array composed entirely of "string indices", it would be better to declare it as an Object type object.

    var a=new Array();
a['a1']=1;
a["100"]=3;
a.length  // 输出 101

    The range of JavaScript array index values is0 ~ 232. For any given numeric index value, if it is not within this range, JavaScript will convert it to a string, and the value corresponding to that index will be used as a property value of the array object rather than an array element, for examplearray[-1] = "yes"Actually, this is equivalent to adding a property named -1 to the array object, with the property value of yes. If the index value is within the valid range, then regardless of whether the index value is a number or a numeric string, it will be converted to a number and used. That is,array["100"] = 0 和 array[100] = 0the same operation is performed.
