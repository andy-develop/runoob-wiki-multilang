MIME Types

MIME (Multipurpose Internet Mail Extensions) is a standard for describing the content type of messages, used to represent the nature and format of documents, files, or byte streams.

MIME messages can contain text, images, audio, video, and other application-specific data.

Browsers typically use MIME types (rather than file extensions) to determine how to handle URLs. Therefore, it is very important that the web server adds the correct MIME type in the response header. If configured incorrectly, the browser may fail to parse file contents, the website may not work properly, and downloaded files may also be mishandled.

Syntax

General structure of MIME types:

type/subtype

The structure of MIME is very simple: a type and a subtype string are separated by a/slash, and no spaces are allowed. The type represents an independent category that can be divided into multiple subtypes, and the subtype represents each type after further division.

MIME types are case-insensitive, but conventionally they are written in lowercase.

Two primary MIME types play an important role in the default types:

  • text/plainRepresents the default value for text files.
  • application/octet-streamRepresents the default value for all other cases.

Common MIME Types

  • Hypertext Markup Language text.html、.html：text/html

  • Plain text.txt： text/plain

  • RTF text.rtf： application/rtf

  • GIF graphics.gif： image/gif

  • JPEG graphics.jpeg、.jpg： image/jpeg

  • au sound file.au： audio/basic

  • MIDI music filemid、.midi： audio/midi、audio/x-midi

  • RealAudio music file.ra、.ram： audio/x-pn-realaudio

  • MPEG file.mpg、.mpeg： video/mpeg

  • AVI file.avi： video/x-msvideo

  • GZIP file.gz： application/x-gzip

  • TAR file.tar： application/x-tar

audio Indicates some kind of audio file audio/midi, audio/mpeg, audio/webm, audio/ogg, audio/wav
