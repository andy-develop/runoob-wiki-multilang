Java Calendar Class

The Calendar class is an abstract class in Java for handling dates and times. It is located in thejava.utilpackage. This class provides a series of methods to operate on date and time fields (such as year, month, day, hour, minute, etc.), and can perform date calculations and comparisons.

Why do we need the Calendar class?

In Java, although the Date class can also represent dates and times, it has the following limitations:

  1. Most methods are deprecated
  2. Does not support internationalization
  3. Limited date calculation functionality

The Calendar class solves these problems and provides more powerful and flexible date-time manipulation capabilities.

Basic usage of the Calendar class

Getting a Calendar instance

Since Calendar is an abstract class, we cannot instantiate it directly. The standard way to obtain a Calendar instance is:

Example

Calendar calendar = Calendar.getInstance();

This method returns a Calendar instance (usually GregorianCalendar) based on the default time zone and locale.

Setting date and time

We can use theset()method to set the various fields of a Calendar object:

Example

// Set year, month, and day
calendar.set(2023, Calendar.NOVEMBER, 15);

// Set year, month, day, hour, minute, and second
calendar.set(2023, Calendar.NOVEMBER, 15, 14, 30, 0);

Note: Months are 0-based, where 0 represents January and 11 represents December. To avoid confusion, it is recommended to use the constants defined in the Calendar class (e.g., Calendar.JANUARY, Calendar.FEBRUARY, etc.).

Getting date and time information

Use theget()method to get the various fields of a Calendar object:

Example

int year = calendar.get(Calendar.YEAR);       // Get the year
int month = calendar.get(Calendar.MONTH);     // Get the month (0-11)
int day = calendar.get(Calendar.DAY_OF_MONTH);// Get the day
int hour = calendar.get(Calendar.HOUR_OF_DAY);// Get the hour (24-hour format)
int minute = calendar.get(Calendar.MINUTE);   // Get the minute
int second = calendar.get(Calendar.SECOND);   // Get the second

Common methods of the Calendar class

Date calculation

The Calendar class provides convenient date calculation methods:

Example

// Add 10 days to the current date
calendar.add(Calendar.DAY_OF_MONTH, 10);

// Subtract 3 months from the current month
calendar.add(Calendar.MONTH, -3);

Date comparison

We can use thecompareTo()method to compare two Calendar objects:

Example

Calendar cal1 = Calendar.getInstance();
Calendar cal2 = Calendar.getInstance();
cal2.add(Calendar.DAY_OF_MONTH, 1);

int result = cal1.compareTo(cal2);
// result < 0 indicates cal1 is earlier than cal2
// result == 0 indicates cal1 is equal to cal2
// result > 0 indicates cal1 is later than cal2

Getting a timestamp

You can use thegetTimeInMillis()method to get the timestamp (milliseconds) represented by a Calendar object:

Example

long timestamp = calendar.getTimeInMillis();

You can also use thegetTime()method to convert it to a Date object:

Example

Date date = calendar.getTime();

Advanced usage of the Calendar class

Setting time zone

We can set a specific time zone for a Calendar object:

Example

TimeZone timeZone = TimeZone.getTimeZone("America/New_York");
calendar.setTimeZone(timeZone);

Calendar field operations

The Calendar class provides theroll()method, which can roll a field without affecting other fields:

Example

// Add 1 to the month, but do not change the year
calendar.roll(Calendar.MONTH, true);  // Or calendar.roll(Calendar.MONTH, 1);

Getting the first day of the week

Different regions define the first day of the week differently (some use Sunday, some use Monday):

Example

int firstDayOfWeek = calendar.getFirstDayOfWeek();

Comprehensive example

Example

import java.util.Calendar;
import java.util.GregorianCalendar;
import java.text.SimpleDateFormat;

public class CalendarDemo {
    public static void main(String[] args) {
        // 1. Get a Calendar instance (uses current date and time by default)
        Calendar calendar = Calendar.getInstance();
       
        // 2. Get the values of various fields
        int year = calendar.get(Calendar.YEAR);
        int month = calendar.get(Calendar.MONTH) + 1; // The month is 0-based, so add 1
        int day = calendar.get(Calendar.DAY_OF_MONTH);
        int hour = calendar.get(Calendar.HOUR_OF_DAY); // 24-hour format
        int minute = calendar.get(Calendar.MINUTE);
        int second = calendar.get(Calendar.SECOND);
       
        System.out.printf("Current time: %d year %d month %d day %d:%d:%d%n",
                        year, month, day, hour, minute, second);
       
        // 3. Set a specific date and time
        calendar.set(2023, Calendar.MAY, 15, 10, 30, 0); // May 15, 2023 10:30:00
       
        // 4. Use SimpleDateFormat for formatted output
        SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
        System.out.println("Time after setting: " + sdf.format(calendar.getTime()));
       
        // 5. Date arithmetic
        calendar.add(Calendar.DAY_OF_MONTH, 5); // Add 5 days
        calendar.add(Calendar.HOUR, -3); // Subtract 3 hours
       
        System.out.println("Time after calculation: " + sdf.format(calendar.getTime()));
       
        // 6. Compare dates
        Calendar anotherCalendar = new GregorianCalendar(2023, Calendar.JUNE, 1);
        System.out.println("Comparison result: " +
            (calendar.before(anotherCalendar) ? "before" : "after"));
       
        // 7. Get the day of the week (Sunday=1, Saturday=7)
        int dayOfWeek = calendar.get(Calendar.DAY_OF_WEEK);
        System.out.println("Day of week" + getChineseWeekday(dayOfWeek));
    }
   
    private static String getChineseWeekday(int dayOfWeek) {
        String[] weekdays = {"", "Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"};
        return weekdays[dayOfWeek];
    }
}

运算后的时间: 2023-05-20 07:30:00

Notes on the Calendar class

  1. Months are 0-based: In the Calendar class, months are 0-based (0=January, 11=December), which can easily lead to errors.

  2. Mutability: Calendar objects are mutable; modifying one Calendar object affects all places that reference it.

  3. Thread safety: The Calendar class is not thread-safe, and extra synchronization is needed in multi-threaded environments.

  4. Performance: Frequently creating Calendar instances affects performance; consider reusing instances.

  5. Time zone issues: The system time zone is used by default, and special attention is needed for cross-time-zone applications.

Alternative in Java 8

Starting from Java 8, a new date-time API (thejava.timepackage) was introduced, providing a more modern and easier-to-use way to handle dates and times. If you are using Java 8 or later, it is recommended to prefer the new API:

Example

// New API to replace Calendar
LocalDate date = LocalDate.now();
LocalDateTime dateTime = LocalDateTime.now();
ZonedDateTime zonedDateTime = ZonedDateTime.now();

The new API solves many problems of the Calendar class, including better thread safety, a more intuitive API design, and more powerful functionality.
