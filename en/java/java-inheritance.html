Java Inheritance

Concept of Inheritance

Inheritance is a cornerstone of Java object-oriented programming technology because it allows creating hierarchical classes.

Inheritance means that a subclass inherits the characteristics and behaviors of a parent class, so that subclass objects (instances) have the parent class's instance fields and methods, or the subclass inherits methods from the parent class, giving the subclass the same behaviors as the parent class.

Inheritance in Daily Life:

Rabbits and sheep belong to the herbivore class, while lions and leopards belong to the carnivore class.

Herbivores and carnivores also belong to the animal class.

Therefore, the relationship that inheritance needs to satisfy is: is-a. The parent class is more general, and the subclass is more specific.

Although herbivores and carnivores both belong to animals, there are differences in their attributes and behaviors. Therefore, a subclass will have the general characteristics of the parent class as well as its own characteristics.

Class Inheritance Format

In Java, you can use the extends keyword to declare that a class inherits from another class. The general form is as follows:

Class Inheritance Format

classParent class{ } classSubclassextendsParent class{ }

Why Do We Need Inheritance?

Next, let's illustrate this need with an example.

Develop an animal class, where the animals are a penguin and a mouse, with the following requirements:

  • Penguin: attributes (name, id), methods (eat, sleep, self-introduction)
  • Mouse: attributes (name, id), methods (eat, sleep, self-introduction)

Penguin class:

public class Penguin { private String name; private int id; public Penguin(String myName, int myid) { name = myName; id = myid; } public void eat(){ System.out.println(name+"Eating"); } public void sleep(){ System.out.println(name+"Sleeping"); } public void introduction() { System.out.println("Hello everyone! I am" + id + "号" + name + "."); } }

Mouse class:

public class Mouse { private String name; private int id; public Mouse(String myName, int myid) { name = myName; id = myid; } public void eat(){ System.out.println(name+"Eating"); } public void sleep(){ System.out.println(name+"Sleeping"); } public void introduction() { System.out.println("Hello everyone! I am" + id + "号" + name + "."); } }

From these two pieces of code, we can see that the code is duplicated, making the code large and bloated, and maintainability is low (mainly because when changes are needed later, many parts of the code must be modified, which is error-prone). To fundamentally solve the problem of these two pieces of code, inheritance is needed. Extract the common parts of the two pieces of code to form a parent class:

Common parent class:

public class Animal { private String name; private int id; public Animal(String myName, int myid) { name = myName; id = myid; } public void eat(){ System.out.println(name+"Eating"); } public void sleep(){ System.out.println(name+"Sleeping"); } public void introduction() { System.out.println("Hello everyone! I am" + id + "号" + name + "."); } }

This Animal class can serve as a parent class. After the Penguin and Mouse classes inherit this class, they will have the attributes and methods of the parent class. The subclasses will no longer have duplicate code, maintainability is improved, the code is more concise, and code reusability is improved (reusability mainly means it can be used multiple times without writing the same code again). Code after inheritance:

Penguin class:

public class Penguin extends Animal { public Penguin(String myName, int myid) { super(myName, myid); } }

Mouse class:

public class Mouse extends Animal { public Mouse(String myName, int myid) { super(myName, myid); } }

Types of Inheritance

Note that Java does not support multiple inheritance, but it supports multilevel inheritance.

Characteristics of Inheritance

  • A subclass has all non-private attributes and methods of the parent class.

  • A subclass can have its own attributes and methods, meaning a subclass can extend the parent class.

  • A subclass can implement the parent class's methods in its own way.

  • Java inheritance is single inheritance, but multilevel inheritance is possible. Single inheritance means a subclass can only inherit from one parent class. Multilevel inheritance means, for example, class B inherits class A, and class C inherits class B. So in terms of relationships, class B is the parent of class C, and class A is the parent of class B. This is a feature that distinguishes Java inheritance from C++ inheritance.

  • It increases coupling between classes (a shortcoming of inheritance; high coupling makes the connections between code tighter and code independence weaker).

Inheritance Keywords

Inheritance can be implemented using the two keywords extends and implements. In addition, all classes inherit from java.lang.Object. When a class does not use these two inheritance keywords, it inherits Object by default (this class is in thejava.langpackage, so there is no need toimport) ancestor class.

In Java, class inheritance is single inheritance; that is, a subclass can have only one parent class, so extends can only inherit one class.

final keyword

final can be used to modify variables (including class attributes, object attributes, local variables, and formal parameters), methods (including class methods and object methods), and classes.

final means "final".

Using the final keyword to declare a class defines the class as a final class that cannot be inherited; or it is used to modify methods, and such methods cannot be overridden by subclasses:

Constructor

A subclass does not inherit the parent class's constructor (construction method or constructor function); it merely calls it (implicitly or explicitly). If the parent class's constructor has parameters, then in the subclass constructor you must explicitly use thesuperkeyword to call the parent class constructor with an appropriate parameter list.

If the parent class constructor has no parameters, then in the subclass constructor there is no need to use thesuperkeyword to call the parent class constructor; the system will automatically call the parent class's no-argument constructor.

    Object-Oriented Programming — Inheritance and Polymorphism

    //--- Quoted from my class teacher's lecture notes (Teacher Zhan)

    1. Why use inheritance

    Deriving new classes from existing classes is called inheritance.

    Different classes may also have common characteristics and behaviors. These common characteristics and behaviors can be placed in one class for other classes to share.

    Therefore, a general class can be defined and then extended into multiple specific classes, which inherit the characteristics and actions of the general class.

    Inheritance is an important means of achieving software reuse in Java. It avoids duplication, making it easy to maintain and understand.

    2. Parent class and subclass

    If class B is derived from class A, or class B extends class A, or class B inherits class A,then class A is called the "parent class", also known as the superclass or base class;

    class B is called the "child class", also known as the subclass, extended class, or derived class.

    The subclass inherits accessible data fields and methods from its parent class, and can also add new data fields and new methods.

    Syntax for defining inheritance:

    修饰符 class 子类名 extends 父类名

    For example: Shape is the parent class, and its subclasses can include Circle, Rectangle, Triangle, and so on.

    Notes on inheritance:

    • A subclass is not a subset of its parent class; a subclass generally contains more data fields and methods than its parent class.
    • Private data fields in the parent class are not visible in the subclass, so they cannot be used directly in the subclass.
    • Inheritance models "is-a" relationships. There must be an "is-a" relationship between a parent class and its subclass; otherwise, inheritance cannot be used.
      But not all "is-a" relationships should be implemented using inheritance. For example, a square is a rectangle, but the Square class should not inherit from the Rectangle class, because a square cannot extend anything from a rectangle. The correct inheritance relationship is for the Square class to inherit from the Shape class.
    • Java only allows single inheritance (that is, a subclass can have only one direct parent class), while C++ supports multiple inheritance (that is, a subclass can have multiple direct parent classes).

    3. The super keyword

    super represents the parent class of the class that uses it. super can be used to:

    • Call the parent class constructor;
    • Call a method of the parent class (when the subclass has overridden the parent class method);
    • Access a data field of the parent class (this is possible, but there is no need to use it this way).

    Syntax for calling the parent class constructor:

    super();  

或   

super(参数列表);

    Note: The super statement must be the first statement in the subclass constructor. You cannot use the parent class constructor name in the subclass to call the parent class constructor. The parent class constructor is not inherited by the subclass. The only way to call the parent class constructor is to use the super keyword. If the subclass does not explicitly call it, the compiler automatically adds super(); as the first statement of the subclass constructor. This forms a constructor chain.

    The super keyword cannot be used in static methods.

    Syntax for calling a parent class method:

    super.方法名(参数列表);

    For inherited methods, there is no need to use super; they can be called directly. However, if the subclass overrides the parent class method, only by using super can the overridden method in the parent class be called from the subclass.

    4. The this keyword

    The this keyword represents the current object. It can be used to:
    • Call the constructor of the current class, and it must be the first statement of the method. For example: this(); calls the default constructor. this(parameters); calls the parameterized constructor.
    • Qualify the data field variable of the current object. It is generally used when a local variable in a method has the same name as an object data field variable. For example, this.num = num. this.num refers to the data field variable num of the current object, while num refers to the local variable in the method.

    The effect of final varies depending on the type it modifies.

    1. final modifying an attribute or variable in a class

    Whether the attribute is of a primitive type or a reference type, final makes the "value" stored in the variable unchangeable.

    For primitive types, what is stored in the variable is the actual value, such as 1, "abc", etc.

    For reference type variables, what is stored is an address. Therefore, when final modifies a reference type variable, it means that the address inside it cannot change, not that the content of the object or array pointed to by the address cannot change. This must be noted carefully.

    For example: if a class has an attribute likefinal Person p=new Person("name");Then you cannot reassign p, but you can change the values of the attributes inside p.p.setName('newName');

    When final modifies an attribute, the variable does not have to be assigned at declaration time, but once assigned, it cannot be modified. A final attribute can be assigned in three places: at declaration, in an initializer block, or in the constructor. In any case, it must be assigned.

    2. final modifying a method in a class

    Effect: It can be inherited, but it cannot be overridden after inheritance.

    3. final modifying a class

    Effect: The class cannot be inherited.

    When a Java file is compiled into a class file, a super() statement is automatically added by default as the first line (first statement) in every constructor of the subclass. Before the subclass constructor is executed, the parent class constructor is always executed first.

    When writing code, pay attention to the following:

    • 1. If the parent class does not have a default constructor (that is, ClassName()), the super() statement in the subclass will fail to execute, and the system will report an error. Generally, the default constructor is automatically added during compilation, but if the class already has a constructor, it will not be added.
    • 2. The statement that calls the parent class constructor can only be placed as the first statement in the function body; otherwise, an error will be reported.

    In an inheritance relationship, when calling a function (method) or accessing a member variable of a class, the JVM (Java Virtual Machine) first checks whether the current class (that is, the subclass) contains that function or member variable.     The Java casting problem is actually not complicated. Just remember one sentence: a parent class reference points to a child class object.

    What does "a parent class reference points to a child class object" mean? Let me explain slowly.

    Starting from two terms:Upcasting 、Downcasting。

    For example: there are two classes, Father is the parent class, and Son class inherits from Father.

    Father f1 = new Son();   // 这就叫 upcasting （向上转型)
// 现在 f1 引用指向一个Son对象

Son s1 = (Son)f1;   // 这就叫 downcasting (向下转型)
// 现在f1 还是指向 Son对象

    The second example:

    Father f2 = new Father();
Son s2 = (Son)f2;       // 出错，子类引用不能指向父类对象

    You might ask: in the first example, why is Son s1 = (Son)f1; correct?

    It is simple, because f1 points to a child class object,Father f1 = new Son();so the child class reference s1 can naturally point to a child class object.

    But f2 has been passed a Father object,Father f2 = new Father();so the child class reference s1 cannot point to a parent class object.

    Summary:

    1. A parent class reference can point to a child class object, but a child class reference cannot point to a parent class object.

    2. Assigning a child class object directly to a parent class reference is called upcasting. Upcasting does not require a forced cast, for example:

    Father f1 = new Son();

    3. Assigning a parent class reference that points to a child class object to a child class reference is called downcasting, and it requires a forced cast, for example:

    f1 is a parent class reference that points to a child class object. Assigning f1 to the child class reference s1 is:Son s1 = (Son)f1;

    The (Son) in front of f1 must be added to perform a forced cast.

    For understanding inheritance, the most important thing is to know what is inherited; in other words, what the subclass gets from the parent class. The answer is: everything. All members of the parent class, including variables and methods, become members of the subclass, except for the constructor. The constructor is unique to the parent class because its name is the class name, so the parent class constructor does not exist in the subclass. Apart from that, the subclass inherits all members of the parent class.

    But obtaining them doesn't mean they can be used freely. Each member has different access attributes. A subclass inherits all members of its parent class, but different access attributes make the subclass use these members differently: some parent class members directly become the subclass's external interface, while some are deeply hidden, and even the subclass itself cannot directly access them. The following table lists the access attributes in the subclass of parent class members with different access attributes:

    Parent class member access attributeMeaning in the parent class Meaning in the subclass
    publicOpen to everyoneOpen to everyone
    protectedOnly other classes in the package, itself, and subclasses can accessOnly other classes in the package, itself, and subclasses can access
    DefaultOnly other classes in the package can accessIf the subclass is in the same package as the parent class: only other classes in the package can access; otherwise: equivalent to private, cannot access
    privateOnly itself can accessCannot access

    public members directly become public members of the subclass, and protected members also directly become protected members of the subclass. In Java, protected means accessible within the package and subclasses, so it is broader than the default access attribute. As for parent class members with the default undefined access attribute, they are visible within the package where the parent class is located. If the subclass does not belong to the parent class's package, then in the subclass, these default attribute members are the same as private members: invisible. The parent class's private members still exist in the subclass, but they cannot be directly accessed in the subclass. We cannot redefine the access attributes of inherited members in the subclass. If we try to redefine a member variable that already exists in the parent class, then we are defining a variable completely unrelated to the parent class's member variable. In the subclass, we can access the variable defined in the subclass, and in the parent class's methods, we access the parent class's variable. Although they have the same name, they do not affect each other.

    When constructing an object of a subclass, the parent class constructor is also called, and the parent class constructor is called before the subclass constructor. During program execution, part of the subclass object's space stores the parent class object. Because the subclass inherits from the parent class, the parent class members may be used during the initialization of the subclass object. So the parent class space must be initialized first, and then the subclass space is initialized. In this process, if the parent class constructor requires parameters, how to pass the parameters becomes very important.

    Regarding inheritance of member inner classes. Generally speaking, inner classes are rarely used for inheritance. But when used for inheritance, there are two points to note:

    • 1) The reference of a member inner class must be Outter.Inner.
    • 2) The constructor must have a reference to the outer class object, and call super() through this reference. This code is excerpted from "Thinking in Java".
    class WithInner {
    class Inner{
         
    }
}
class InheritInner extends WithInner.Inner {
      
    // InheritInner() 是不能通过编译的，一定要加上形参
    InheritInner(WithInner wi) {
        wi.super(); //必须有这句调用
    }
  
    public static void main(String[] args) {
        WithInner wi = new WithInner();
        InheritInner obj = new InheritInner(wi);
    }
}
