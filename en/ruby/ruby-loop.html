Ruby Loops

Loops in Ruby are used to execute the same block of code a number of times. This chapter will detail all the loop statements supported by Ruby.

Ruby whileStatement

Syntax

while conditional [do] code end

or

Syntax

while conditional [:] code end

当 conditionalWhen true, executecode。

In the syntax, do or : can be omitted. But if you want to write a while expression in one line, you must use do or : to separate the condition from the code block.

Example

#!/usr/bin/ruby # -*- coding: UTF-8 -*- $i = 0 $num = 5 while $i < $num do puts("#!/usr/bin/ruby # -*- coding: UTF-8 -*- $i = 0 $num = 5 while $i < $num do puts("In the loop statement i = #$i" ) $i +=1 end" ) $i +=1 end

First evaluate the expression to obtain an object, then forexpressioneach element in it, execute oncecode。

Ruby breakStatement

Syntax

break

Terminates the innermost loop. If called within a block, it terminates the method associated with the block (the method returns nil).

Example

#!/usr/bin/ruby # -*- coding: UTF-8 -*- for i in 0..5 if i > 2 then break end puts "#!/usr/bin/ruby # -*- coding: UTF-8 -*- for i in 0..5 if i > 2 then break end puts "The value of the local variable is #{i}" end" end

Try it »

The output of the above example is:

局部变量的值为 0
局部变量的值为 1
局部变量的值为 2

Ruby retryStatement

Note: Versions 1.9 and later do not support using retry in loops.

Syntax

retry

Ifretryappears in the rescue clause of a begin expression, then restarts from the beginning of the begin body.

begin do_something #the raised exception rescue #handle errors retry #restart from the beginning of begin end

If retry appears inside an iteration, a block, or the body of a for expression, it restarts the iteration call. The arguments of the iteration are re-evaluated.

for i in 1..5 retry if some_condition #restart from i == 1 end

Example

#!/usr/bin/ruby # -*- coding: UTF-8 -*- for i in 1..5 retry if i > 2 puts "#!/usr/bin/ruby # -*- coding: UTF-8 -*- for i in 0..5 retry if i > 2 puts "The value of the local variable is #{i}" end" end
