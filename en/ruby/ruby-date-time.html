Ruby Date & Time

TimeThe Time class in Ruby is used to represent dates and times. It is based on the system date and time provided by the operating system. This class may not be able to represent dates before 1970 or after 2038.

This tutorial will familiarize you with all the important concepts of date and time.

Creating the current date and time

The following is a simple example to get the current date and time:

Example

#!/usr/bin/ruby -w # -*- coding: UTF-8 -*- time1 = Time.new puts "Current time :" + time1.inspect #Time.now is equivalent time2 = Time.now puts "Current time :" + time2.inspect

Try it »

The output of the above example is:

当前时间 : 2015-09-17 15:23:14 +0800
当前时间 : 2015-09-17 15:23:14 +0800

Getting Date & Time Components

We can useTimeTime objects to get various date and time components. See the following example:

Example

#!/usr/bin/ruby -w # -*- coding: UTF-8 -*- time = Time.new #Components of Time puts "Current time :" + time.inspect puts time.year #=> Year of the date puts time.month #=> Month of the date (1 to 12) puts time.day #=> Day of the month (1 to 31) puts time.wday #=> Day of the week (0 is Sunday) puts time.yday #=> 365: Day of the year puts time.hour #=> 23: 24-hour clock puts time.min # => 59 puts time.sec # => 59 puts time.usec #=> 999999: microseconds puts time.zone #=> "UTC": Timezone name

The output of the above example is:

Time.utc、Time.gm 和 Time.localFunctions

These functions can be used to format dates in standard formats, as shown below:

# July 8, 2008 Time.local(2008, 7, 8) #July 8, 2008, 09:10am, local time Time.local(2008, 7, 8, 9, 10) # July 8, 2008, 09:10 UTC Time.utc(2008, 7, 8, 9, 10) #July 8, 2008, 09:10:11 GMT (same as UTC) Time.gm(2008, 7, 8, 9, 10, 11)

The following example gets all the components in an array:

[sec,min,hour,day,month,year,wday,yday,isdst,zone]

Try the following example:

Example

#!/usr/bin/ruby -w time = Time.new values = time.to_a p values

The output of the above example is:

[39, 25, 15, 17, 9, 2015, 4, 260, false, "CST"]

This array can be passed to theTime.utc 或 Time.localfunction to get different formats of the date, as shown below:

Example

#!/usr/bin/ruby -w time = Time.new values = time.to_a puts Time.utc(*values)

The output of the above example is:

2015-09-17 15:26:09 UTC

The following is a way to get the time, the number of seconds since the epoch (platform-dependent):

#Returns the number of seconds since the epoch time = Time.now.to_i #Convert seconds to a Time object Time.at(time) #Returns the number of seconds since the epoch, including microseconds time = Time.now.to_f

Time Zones and Daylight Saving Time

You can use TimeTimeobjects to get all information related to time zones and daylight saving time, as shown below:

time = Time.new #Here is the explanation: time.zone #=> "UTC": Returns the timezone time.utc_offset #=> 0: UTC is 0 seconds offset relative to UTC time.zone #=> "PST" (or other timezone) time.isdst #=> false: if UTC has no DST (daylight saving time) time.utc? #=> true: if in UTC timezone time.localtime #Convert to local timezone time.gmtime #Convert back to UTC time.getlocal #Returns a new Time object in the local zone time.getutc #Returns a new Time object in UTC

Formatting Time and Date

There are many ways to format date and time. The following example demonstrates some of them:

Example

#!/usr/bin/ruby -w time = Time.new puts time.to_s puts time.ctime puts time.localtime puts time.strftime("%Y-%m-%d %H:%M:%S")

The output of the above example is:

2015-09-17 15:26:42 +0800
Thu Sep 17 15:26:42 2015
2015-09-17 15:26:42 +0800
2015-09-17 15:26:42

Time Arithmetic

You can do some simple arithmetic with time, as shown below:

now = Time.now #Current time puts now past = now - 10 #10 seconds ago. Time - number => Time puts past future = now + 10 #10 seconds from now. Time + number => Time puts future diff = future - now #=> 10 Time - Time => seconds puts diff

The output of the above example is:

2015-09-17 15:27:08 +0800
2015-09-17 15:26:58 +0800
2015-09-17 15:27:18 +0800
