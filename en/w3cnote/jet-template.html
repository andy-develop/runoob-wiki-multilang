2.0 Jet Template

Categories JMR Usage Tutorial

Jet is a template language similar to JSP syntax, and also similar to PHP and ASP. It is a subproject of Eclipse Modeling.

Jet uses Java as its scripting language, and Jet files have the suffix (*.jet). In Jmr, the naming convention for Jet is (*.extension.jet).
