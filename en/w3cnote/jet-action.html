2.4 Jet Action

Category JMR Tutorial

Jmr allows users to customize Actions. In an Action, we can define variables and pass them to templates.

The benefit is that Action is responsible for obtaining variables, while the template uses the variables passed from Action for display, achieving a reasonable separation of layers.

Create Action

In Eclipse, right-click at the location where you need to create the file, or go to menu -> File; then click New and select Jmr Action. If you can't find it, it is also under Other in the JMR directory.

Note: The project must have a Java source folder to use Action. For example, Java, Java Web, Android projects have Java source folders.

Enter the custom name MyAction and click Finish.

If the current project has not loaded the Jmr library, click OK to import the Jmr library. This imported library is similar to the JUnit library and does not affect the actual project dependency structure.

Use Action

Action has an execute method. The method's parameter is the built-in object context from the previous section. We can call context.setVariable(String name, Object object) to set variables and pass them to the template.

In the task, click Browse and select the MyAction just set.

Template Gets Action Variables

Method 1

In the template, call context.getVariable(String name) to get the variable. The usage is similar to JSP's request.getAttribute(String name).
After getting the variable, use <%=%> to output it.

Method 2

Use Jmr tags to get variable values. The benefit is that you don't need to call context.getVariable(String name).

Switching to a different Action here gives you hints for the variables of that Action.
