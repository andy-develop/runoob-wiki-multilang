Similar Chinese projects: https://github.com/justjavac/free-programming-books-zh_CN

free-programming-books is an open-source project on GitHub that aims to collect and share free programming learning resources. The project contains a large number of free e-books about various programming languages, frameworks, tools, and computer science fields, covering levels from beginners to advanced developers.

The main goal of this project is to provide free and high-quality learning materials for people learning programming, including but not limited to books and resources on programming languages, algorithms, data structures, databases, front-end and back-end development.

In this project, we can find various programming-related books, such as those on Python, Java, JavaScript, C++ and other programming languages, as well as learning resources on different fields like Web development, data science, artificial intelligence, network security, and more.
