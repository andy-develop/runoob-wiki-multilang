Java printf formatted output usage

Category Programming Technology

The printf method in Java is used for formatted output.

Formatting specifies the form of output, including precision of numbers, character width, date formats, and so on. Below are some common format specifiers and their usage:

String formatting

  • %s : output string

Example

System.out.printf("%s", "hello world"); // output "hello world"

Integer formatting

  • %d : output decimal integer
  • %o : output octal integer
  • %x : output hexadecimal integer
  • %X : output uppercase hexadecimal integer

Example

System.out.printf("%d %o %x %X", 10, 10, 10, 10); // output "10 12 a A"

Floating-point formatting

  • %f : output floating-point number
  • %e : output floating-point number in scientific notation (lowercase e)
  • %E : output floating-point number in scientific notation (uppercase E)
  • %.nf : control the number of digits after the decimal point, n is a number

Example

System.out.printf("%.2f %e %E", 3.1415926, 3.1415926, 3.1415926); // output "3.14 3.141593e+00 3.141593E+00"

Boolean formatting

  • %b : output boolean value

Example

System.out.printf("%b", true); // output "true"

Character formatting

  • %c : output character

Example

System.out.printf("%c", 'a'); // output "a"

Width and precision formatting

  • %n$ : specify the nth parameter
  • %m.n : control width and precision, m is the minimum width, n is the number of digits after the decimal point

Example

System.out.printf("%2d %5.2f %s", 10, 3.1415926, "hello"); // output "10 3.14 hello"

Below is a complete list of format specifiers available in the printf method in Java:

  • %d: signed decimal integer
  • %o: unsigned octal integer
  • %x, %X: unsigned hexadecimal integer, represented using lowercase and uppercase letters respectively
  • %f, %F: decimal floating-point number with decimal point, represented using lowercase and uppercase letters respectively
  • %e, %E: floating-point number with exponent, represented using lowercase and uppercase letters respectively
  • %g, %G: automatically chooses %f or %e format based on the magnitude of the value, represented using lowercase and uppercase letters respectively
  • %a, %A: hexadecimal floating-point number, represented using lowercase and uppercase letters respectively
  • %c: character type, outputs a single character
  • %s: string type, outputs a string
  • %n: newline character
  • %%: outputs a percent sign %
  • %h, %H: hash code, represented in hexadecimal and uppercase hexadecimal respectively
  • %t, %T: date and time formatting, using specific conversion characters, e.g., %tY represents the year, %tB represents the full month name
  • %b, %B: boolean type, outputs true or false, represented using lowercase and uppercase letters respectively
  • %S: outputs the string in uppercase letters

Below is a list of symbols in the Java printf method that can be used to format dates:

  • %tB: localized full month name
  • %tb: localized abbreviated month name
  • %tA: localized full weekday name
  • %ta: localized abbreviated weekday name
  • %tY: four-digit year
  • %ty: two-digit year
  • %tm: two-digit month
  • %td: two-digit day of the month
  • %te: one- or two-digit day of the month
  • %tH: hour in 24-hour format
  • %tI: hour in 12-hour format
  • %tM: minutes
  • %tS: seconds
  • %tp: morning or afternoon (AM/PM)
  • %tZ: time zone
