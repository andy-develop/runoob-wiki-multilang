Platform tools (all open source goodies)

  • Redmine/Trac: Project management platforms

The so-called configuration management system is to manage resources such as files, users, processes, and software packages in machines. Web server performance/stress testing tools/load balancers

  • http_load: The program is very small, less than 100K after decompression
  • webbench: It is a website stress testing tool under Linux, can simulate up to 30,000 concurrent connections to test the load capacity of a website
  • ab: ab is a powerful testing tool that comes with Apache
  • Siege: An open-source stress testing tool that can perform multi-user concurrent access to a web site according to configuration, record the response time of all request processes for each user, and repeat under a certain number of concurrent accesses.
  • squid (front-end cache), nginx (load), nodejs (that's right, it can too, you can write a little code to implement a high-performance load balancer): common load balancers
  • Piwik: Open-source website traffic statistics system
  • ClickHeat: Open-source website click heatmap
  • HAProxy: High-performance TCP/HTTP load balancer
  • ElasticSearch: Search engine based on Lucene
  • Page Speed SDK and YSLOW
  • HAR Viewer: HAR analysis tool
  • Protractor: E2E (end-to-end) automated testing tool

Big data processing/data analysis/distributed tools

  • Hadoop: A distributed file system. Combined with its MapReduce programming model, it can be used for batch processing of massive data (not to mention Hive, Pig, HBase, etc.). Worth mentioning is Cloudera's Hadoop distribution CDH5, which is based on YARN MRv2 and integrates Spark, directly usable in production environments. It is very useful for enterprises to quickly build data warehouses.

  • Ceph: Linux distributed file system (feature: no central node)

  • Storm: Real-time streaming data processing. You can check out an introduction from IBM. (There's also Yahoo's S4, which also does streaming data processing.)

  • Spark: Large-scale streaming data processing (can handle three common data processing scenarios in enterprises: complex batch data processing; interactive query based on historical data; streaming data processing based on real-time data streams). CSDN has a good article introducing it.

  • Spark Streaming: Real-time computing framework based on Spark

  • Tachyon: Distributed in-memory file system

  • Mesos: A cluster manager for computing frameworks, providing efficient resource isolation and sharing across distributed applications or frameworks. Impala: A new-generation open-source big data analytics engine that provides SQL semantics, and is faster than Hive.

  • SNAPPY: Fast data compression system, suitable for use in the Hadoop ecosystem

  • Kafka: High-throughput distributed message queue system

  • ActiveMQ: Produced by Apache, the most popular and powerful open-source message bus

  • MQTT: Message Queuing Telemetry Transport, an instant messaging protocol developed by IBM, which may become an important component of the Internet of Things

  • RabbitMQ: I remember OpenStack uses this, right?

  • ZeroMQ: Claims to make distributed computing simpler; it is a distributed message queue. You can check out an article by Yunfeng introducing it. Open-source log collection systems: scribe, chukwa, kafka, flume. Here is a comparison article.

  • Zookeeper: Reliable open-source project for distributed coordination

  • Databus: LinkedIn's real-time low-latency data capture system

C & C++

Thrift: Used to develop scalable and cross-language services. (Similar ones include Avro, Google Protocol Buffers.)

libevent: An event-driven network library, supports Windows, Linux, BSD, and other platforms. Internally uses system calls such as select, epoll, and kqueue to manage the event mechanism. (By the way, there's also libev.)

Boost: Enough said, quasi C++ standard library

Ptmalloc\Valgrind\Purify

NetworkServer architecture: acceptor -> dispatcher -> worker (this is not a tool, by the way)

breakpad: Crash dump and analysis module, used in many crash reports

UI-related: Not to mention MFC, BCG, and Qt. More advanced ones include HTML and DirectUI technologies: libcef (based on the Chrome kernel; thinking about using HTML5 to develop pages is a bit exciting), HtmlLayout, Duilib, Bolt. For non-C++ there's also node-webkit, which is quite good, integrating Node.js and WebKit cores.

Common tools

  • Fiddler: A very useful Web front-end debugging tool, of course for the underlying HTTP protocol. Normally, the built-in debugging tools in browsers like Chrome are sufficient, but for special cases you still need to use it.
  • Wireshark: Well-known network packet analysis tool
  • PowerCmd: A powerful replacement for Windows Cmd
  • RegexBuddy: Powerful regular expression testing tool
  • Soure Insight: A magical tool for reading source code
  • SublimeText: Programmers' favorite editor
  • Database.NET: A generic relational database client based on .NET 4.0. It's quite handy for simple tasks.
  • Navicat Premium: Supports MySql, PostgreSQL, Oracle, Sqlite and SQL Server. It's not as versatile as Database.NET, but has much better performance. It also has built-in backup functionality for scheduled database backups.
  • Synergy: One keyboard and mouse to control multiple computers on a LAN
  • DameWare: Remote assistance toolset (I mainly use it at work to control the big screen)
  • Radmin: Remote control tool. I used it for a while.
  • DameWare, which also needs cracking and doesn't support Win7 well; instead I found this one works well.
  • Listary: A "super magical tool" that can greatly improve the speed and efficiency of browsing and searching files in Windows.
  • Clover: Adds tabs to Windows Explorer
  • WinLaunch: A Launch tool that simulates Mac OS
  • Fritzing: Drawing circuit schematics
  • LICEcap: GIF tutorial creation, git,
  • svn: Version control system. Enigma Virtual Box (wraps exe, dll, etc. into one executable program).
  • Open DBDiff (for SqlServer) database synchronization
  • SymmetricDS: Database synchronization
  • BIEE, Infomatica, SPSS, weka, R language: Data analysis
  • CodeSmith, LightSwitch: Code generation
  • Pandoc: A Markdown conversion tool for publishing books. I used to play with Docbook, but now Markdown is more popular.
  • Window Magnet [Mac]: Enhances Mac window management, with the ability like Win7 to drag windows to screen edges for automatic resizing.
  • log explorer: View SqlServer logs. dependency
  • walker: Query Windows application DLL dependencies
  • Shairport4w: Transmit audio from iPhone, iPad, iPod to PC via AirPlay protocol
  • ngrok: Intranet penetration tool. Axure: Rapid prototyping tool. There is also an online drawing tool made by a domestic startup team, which works very well.http://www.processon.com
  • tinyproxy: (Linux) A small proxy server supporting HTTP and HTTPS protocols. EaseUS Partition
  • Master: A super simple partition resizing tool, and it's quite fast. If your C drive is running out of space, use it to carve some space from the D drive — no need to reinstall the system.
  • CheatEngine: An essential tool for modifying memory values when playing games (I remember using it when playing Xuan-Yuan Sword 6, it was super convenient).
  • ApkIDE: Android decompilation artifact. Circumvention tools (Free Gate, Tianxing Browser)

Design tools: Sketch, OmniGraffle
