The Difference Between Scala Methods and Functions

Category Programming Technology

Scala has both functions and methods. In most cases, we can ignore the differences between them. But sometimes we must understand their differences.

Methods in Scala are like methods in Java; methods are part of a class. A method has a name, a type signature, sometimes annotations on the method, and the functional implementation code (bytecode) of the method.

Functions in Scala are complete objects. Scala uses 22 traits to abstract the concept of functions. These 22 traits range from Function1 to Function22:
