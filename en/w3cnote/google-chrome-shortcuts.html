Chrome Browser Shortcuts

Categories Programming Technology

At present, Chrome browser should be used by most front-end programmers for development and debugging. Below are the Chrome browser shortcuts.

Windows and Linux versions of Chrome

Tab and Window Shortcuts

Action Shortcut
Open a new window Ctrl + n
Open a new window in incognito mode Ctrl + Shift + n
Open a new tab and jump to it Ctrl + t
Reopen the last closed tab and jump to it Ctrl + Shift + t
Jump to the next open tab Ctrl + Tab or Ctrl + PgDn
Jump to the previous open tab Ctrl + Shift + Tab or Ctrl + PgUp
Jump to a specific tab Ctrl + 1 through Ctrl + 8
Jump to the last tab Ctrl + 9
Open the home page in the current tab Alt + Home
Close the current tab Ctrl + w or Ctrl + F4
Close all open tabs and the browser Ctrl + Shift + w
Minimize the current window Alt + Spacebar + n
Maximize the current window Alt + Spacebar + x
Exit Google Chrome Ctrl + Shift + q or Alt + F4
