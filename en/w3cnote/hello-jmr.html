1.3 Hello Jmr

Categories JMR Tutorial

We use a Hello Jmr example to understand the steps for using Jmr.

Create Jmr file

In Eclipse, right-click at the location where you want to create the file, or go to menu -> File; then click New and select Jmr. If it is not found, it is also in the JMR directory under Other.

Enter a file name, such as template.

The jmr file was created successfully.

After creating the new jmr file, open the file, right-click and create a project, then create a directory in sequence.

Create a task

After the creation is complete, you need a template file.

Create Jet template file

In Eclipse, right-click at the location where you want to create the file, or go to menu -> File; then click New and select Jet. If it is not found, it is also in the JMR directory under Other.

Enter the file name hello.

The template file was created successfully.

Start writing the template content. Write the following content in the template:

Hello Jmr! 

<%out.write("Hello Jmr!");%>

<%="Hello Jmr!"%>
  
<get value="'Hello Jmr!'"/>

All of these writing methods generate the string "Hello Jmr!".

Configure task

Now that we have the template, we can start configuring the task.

Perform the following steps to complete the configuration.

  • 1. Select the template file, choose hello.jet;
  • 2. Select the output directory;
  • 3. Fill in the generated file name (hello). You can double-click or press Enter to input it;
  • 4. Fill in the generated file extension (txt). You can double-click or press Enter to input it;
  • 5. Check the task to be executed;
  • 6. Click the Run button;

Run task

After clicking Run, information about the running task will be displayed in the "Run" view.

Compare the template with the generated content.

After clicking to open, we can see the generated file.

Compare the template with the generated content.
