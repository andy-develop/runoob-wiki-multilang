11 Ways to Become a Better Programmer

Category Programmer's Life

1. Practice and Make Mistakes

The first suggestion is that you should keep practicing continuously. The more code you write, the more efficient you become, and the more mistakes you make, the more you gain. Why is making mistakes so important when you practice? The more code you write, the more you will realize the mistakes you make when dealing with errors, design, threading, and other situations. You will learn from these mistakes, and then your skills will get better and better.

2. Self-study Using the Internet and Books

Obviously, the best way to improve your skills is to learn by yourself, focusing on the technologies you lack. For the vast majority of programmers, a good approach is to read technical documentation from various places, such as Google's website for developers, where many experienced programmers have written many high-quality introductory articles. Codecademy, Code.org,Runoob Tutorial, and HTML5 Rocks are all good learning websites.

3. Self-Reflection

It is very important to reflect on the code you write. After fixing a bug each time, you should reflect and think about how to avoid making such a mistake again in the future. This is also a very important programming principle. Recommend a book: "Code Craft".

4. Learn from Other Programmers

Try to work on a large number of different types of projects and treat each project as a learning opportunity. When you feel uncomfortable doing something, that's actually good. Push yourself out of your comfort zone and work with other programmers you are not familiar with; in this way, you will learn many new things.

If the opportunity allows, try to work with other programmers, because this can improve your code quality and help you improve your teamwork ability. When working with other programmers, treat it as a learning opportunity, and ask other programmers about anything you don't understand in your work. Normally, a team will have an experienced senior programmer and other programmers, and you can learn from them.

5. Work on Open Source Projects

You can develop on open source projects from sites like GitHub. Creating a fork of an open source project and then doing development is a very good way to improve your programming skills.

In open source projects, read and understand code written by others. Writing comments in your own projects or open source projects helps you understand your own code and makes it easier for others to understand you.

6. Read Code

Read open source project code, or other programmers' code, to understand how it works. Discover patterns in code, cultivate your own skills, and gradually you will develop your own "code sense". Cultivating your "code sense" can make you sense where errors are when programming, thus avoiding mistakes.

7. Master the Programming Language You Use

Should you be the best in your field, or know a little about everything but master none? In my personal opinion, at least be proficient in the language you are going to use, and then you can broadly learn other languages.

8. Join Online Learning and Developer Communities

Technology has made learning easier. It has essentially removed the barriers to learning, unlike the past when you had to enroll in classes. Now information is more accessible, so learning is easier too. Join some social media, online communities, and blogs. Various blogs often contain a lot of technical documentation, information, new technical features, and APIs, etc.

Join Stack Overflow, forums, and other communities. This is really very, very important, because you can learn from others' discussions. It will give you a better platform to solve your problems. Make sure to ask many questions in discussions and express your own opinions.

9. Write Unit Tests

If you use unit tests, you will find that they can help you improve your design thinking and coding process. In this way, you will become better at designing code. By writing unit tests, it will help you discover better names, abstract classes, interfaces, and abstract classes, etc. This will all improve your code quality.

10. Conduct Code Reviews and Have Your Code Reviewed by Others

Doing code reviews is very important; it can help you become a better programmer. Through code reviews, you can improve your "code sense" and get feedback from others. At the same time, you can help others improve their abilities. After receiving feedback, ask for more detailed information about anything you don't understand.

11. The Most Important... Discuss with Others and Have Fun

When programming, it is very easy to lose contact with the outside world, but discussing code with others and having a brief meeting can help improve this.

Go to discuss and communicate with colleagues and other programmers, attend some larger conferences, such as JavaOne, DevFest, etc., and enjoy the fun they bring.
