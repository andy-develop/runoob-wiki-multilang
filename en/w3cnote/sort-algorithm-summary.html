2. Selection Sort (SelctionSort)

  • Basic idea:
    In an unordered array of length N, traverse n-1 numbers for the first time, find the smallest value, and swap it with the first element.
    For the second traversal, traverse n-2 numbers, find the smallest value, and swap it with the second element.
    。。。
    On the (n-1)th traversal, find the smallest value and swap it with the (n-1)th element, and the sorting is complete.

  • Process:

    Selection Sort

  • Average time complexity:O(n2)

  • Java code implementation:

    Example

    public static void select_sort(int array[],int lenth){

       for(int i=0;i<lenth-1;i++){

           int minIndex = i;
           for(int j=i+1;j<lenth;j++){
              if(array[j]<array[minIndex]){
                  minIndex = j;
              }
           }
           if(minIndex != i){
               int temp = array[i];
               array[i] = array[minIndex];
               array[minIndex] = temp;
           }
       }
    }

4. Shell Sort

  • Preface:
    Data sequence 1: 13-17-20-42-28. Using insertion sort, 13-17-20-28-42. Number of swaps: 1;
    Data sequence 2: 13-17-20-42-14. Using insertion sort, 13-14-17-20-42. Number of swaps: 3;
    If the data sequence is basically ordered, insertion sort is more efficient.

  • Basic idea:
    In a set of numbers to be sorted, divide it into several subsequences based on a certain increment, and perform insertion sort on each subsequence separately.
    Then gradually reduce the increment and repeat the above process. Until the increment is 1, at which point the data sequence is basically ordered, and finally perform insertion sort.

  • Process:

    Shell Sort

  • Average time complexity:

  • Java code implementation:

    Example

    public static void shell_sort(int array[],int lenth){

       int temp = 0;
       int incre = lenth;

       while(true){
           incre = incre/2;

           for(int k = 0;k<incre;k++){    //Divide into several subsequences based on the increment

               for(int i=k+incre;i<lenth;i+=incre){

                   for(int j=i;j>k;j-=incre){
                       if(array[j]<array[j-incre]){
                           temp = array[j-incre];
                           array[j-incre] = array[j];
                           array[j] = temp;
                       }else{
                           break;
                       }
                   }
               }
           }

           if(incre == 1){
               break;
           }
       }
    }

5. Quicksort

  • Basic idea: (divide and conquer)

    • First take a number from the sequence as the key value.
    • Place all numbers smaller than this number to its left, and all numbers greater than or equal to it to its right.
    • Repeat the second step for the left and right sub-sequences until each interval has only 1 number.

    public static void quickSort(int a[],int l,int r){
         if(l>=r)
           return;

         int i = l; int j = r; int key = a[l];//Select the first number as key

         while(i<j){

             while(i<j && a[j]>=key)//Find the first value smaller than key from right to left
                 j--;
             if(i<j){
                 a[i] = a[j];
                 i++;
             }

             while(i<j && a[i]<key)//Find the first value greater than key from left to right
                 i++;

             if(i<j){
                 a[j] = a[i];
                 j--;
             }
         }
         //i == j
         a[i] = key;
         quickSort(a, l, i-1);//Recursive call
         quickSort(a, i+1, r);//Recursive call
     }

    The selection of the key value can take many forms, such as the middle number or a random number, which will have different effects on the algorithm's complexity.

6. Merge Sort

  • Basic idea:Reference
    Merge sort is an efficient sorting algorithm based on the merge operation. It is a very typical application of the divide-and-conquer method.
    First, consider how to merge two ordered sequences. This is very simple: just compare the first numbers of the two sequences, take the smaller one first, and then delete that number from its corresponding sequence. Then compare again. If one sequence becomes empty, just take out the remaining data of the other sequence in order.

    Example

    //Merge ordered arrays a[] and b[] into c[]
    void MemeryArray(int a[], int n, int b[], int m, int c[])
    {
     int i, j, k;

     i = j = k = 0;
     while (i < n && j < m)
     {
         if (a[i] < b[j])
             c[k++] = a[i++];
         else
             c[k++] = b[j++];
     }

     while (i < n)
         c[k++] = a[i++];

     while (j < m)
         c[k++] = b[j++];
    }

    Having solved the problem of merging ordered sequences, now look at merge sort. Its basic idea is to divide the array into two groups, A and B. If the data within each of these two groups is ordered, then it is very convenient to sort the two groups together. How can the data within these two groups be made ordered?
    Each of groups A and B can be further divided into two groups. By analogy, when a divided subgroup contains only 1 data item, the subgroup can be considered already ordered. Then just merge the two adjacent subgroups. In this way, throughfirst recursively decomposing the sequence,，then merging the sequences,merge sort is completed.

  • Process:

    Merge Sort

  • Average time complexity:O(NlogN)
    Merge sort is quite efficient. Assuming the sequence length is N, it takes logN steps to split the sequence into smaller sequences. Each step is a process of merging ordered sequences, and the time complexity can be recorded as O(N), so the total is O(N*logN).

  • Code implementation:

    Example

    public static void merge_sort(int a[],int first,int last,int temp[]){

      if(first < last){
          int middle = (first + last)/2;
          merge_sort(a,first,middle,temp);// The left half is sorted
          merge_sort(a,middle+1,last,temp);// The right half is sorted
          mergeArray(a,first,middle,last,temp); // Merge the left and right parts
      }
    }

    Example

    // Merge: merge the two sequences a[first-middle] and a[middle+1-end]
    public static void mergeArray(int a[],int first,int middle,int end,int temp[]){    
      int i = first;
      int m = middle;
      int j = middle+1;
      int n = end;
      int k = 0;
      while(i<=m && j<=n){
          if(a[i] <= a[j]){
              temp[k] = a[i];
              k++;
              i++;
          }else{
              temp[k] = a[j];
              k++;
              j++;
          }
      }    
      while(i<=m){
          temp[k] = a[i];
          k++;
          i++;
      }    
      while(j<=n){
          temp[k] = a[j];
          k++;
          j++;
      }

      for(int ii=0;ii<k;ii++){
          a[first + ii] = temp[ii];
      }
    }

7. Heap Sort (HeapSort)

  • Basic idea:

    • Diagram: （88,85,83,73,72,60,57,48,42,6）

      Heap Sort

  • Average time complexity:O(NlogN)
    Since each heap restoration has a time complexity of O(logN), there are N - 1 heap restoration operations in total, plus the N / 2 downward adjustments during the initial heap construction, each also with O(logN) time complexity. The total time for both operations is still O(N * logN).

  • Java code implementation:

    Example

    // Build a min-heap
    public static void MakeMinHeap(int a[], int n){
     for(int i=(n-1)/2 ; i>=0 ; i--){
         MinHeapFixdown(a,i,n);
     }
    }
    // Adjust starting from node i, n is the total number of nodes. Counting from 0, the child nodes of node i are 2*i+1, 2*i+2
    public static void MinHeapFixdown(int a[],int i,int n){

       int j = 2*i+1; // Child nodes
       int temp = 0;

       while(j<n){
           // Find the smallest among the left and right child nodes
           if(j+1<n && a[j+1]<a[j]){  
               j++;
           }

           if(a[i] <= a[j])
               break;

           // Move the larger node down
           temp = a[i];
           a[i] = a[j];
           a[j] = temp;

           i = j;
           j = 2*i+1;
       }
    }

    Example

    public static void MinHeap_Sort(int a[],int n){
      int temp = 0;
      MakeMinHeap(a,n);

      for(int i=n-1;i>0;i--){
          temp = a[0];
          a[0] = a[i];
          a[i] = temp;
          MinHeapFixdown(a,0,i);
      }    
    }

8. Radix Sort (RadixSort)

BinSort

  • Basic idea:
    The idea of BinSort is very simple: first create an array A[MaxValue]; then place each number in its corresponding position (for example, place 17 at the array position with index 17); finally traverse the array to get the sorted result.

  • Diagram:

    BinSort

    • Problem:When the sequence contains large values, the BinSort method wastes a large amount of space.
    RadixSort
    • Basic idea:Radix sort is based on BinSort and reduces space overhead by limiting the radix (base).
    • Process:

      Process 1

      Process 2

    (1) First determine the radix as 10, so the array length is also 10. Each number, such as 34, will find its position among these 10 numbers.
    (2) Unlike BinSort, which directly places the number 34 at array index 34, radix sort splits 34 into 3 and 4. In the first round of sorting, it is placed at array index 4 according to the last digit; in the second round, it is placed at array index 3 according to the second-to-last digit. Then traverse the array to get the result.

  • Java code implementation:

    Example

    public static void RadixSort(int A[],int temp[],int n,int k,int r,int cnt[]){

       // A: original array
       // temp: temporary array
       // n: number of digits in the sequence
       // k: maximum number of digits, 2
       // r: radix, 10
       // cnt: stores the count of bin[i]

       for(int i=0 , rtok=1; i<k ; i++ ,rtok = rtok*r){

           // Initialize
           for(int j=0;j<r;j++){
               cnt[j] = 0;
           }
           // Calculate the count of numbers in each box
           for(int j=0;j<n;j++){
               cnt[(A[j]/rtok)%r]++;
           }
           // Modify cnt[j] to the total number of digits in the first j boxes
           for(int j=1;j<r;j++){
               cnt[j] = cnt[j-1] + cnt[j];
           }
           for(int j = n-1;j>=0;j--){      // Key point to understand
               cnt[(A[j]/rtok)%r]--;
               temp[cnt[(A[j]/rtok)%r]] = A[j];
           }
           for(int j=0;j<n;j++){
               A[j] = temp[j];
           }
       }
    }
