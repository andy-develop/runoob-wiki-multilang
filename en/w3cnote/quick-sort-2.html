1.6 Quick Sort

Category Algorithm

Quick Sort is an efficient sorting algorithm based on the idea of Divide and Conquer. Its core is to select a pivot element, divide the list into two parts: one part is smaller than the pivot, and the other part is larger than the pivot, then recursively sort these two parts. The average time complexity of Quick Sort is O(n log n), and it performs excellently in practical applications.

Quick Sort is a sorting algorithm developed by Tony Hoare. On average, sorting n items requires O(n log n) comparisons. In the worst case, it requires O(n²) comparisons, but this situation is not common. In fact, Quick Sort is usually significantly faster than other O(n log n) algorithms because its inner loop can be implemented very efficiently on most architectures.

Quick Sort uses the Divide and Conquer strategy to divide a list into two sub-lists.

Quick Sort is another typical application of the divide-and-conquer idea in sorting algorithms. In essence, Quick Sort can be considered a recursive divide-and-conquer method based on Bubble Sort.

The name Quick Sort is simple and straightforward, because as soon as you hear it, you know its purpose: it is fast and efficient! It is one of the fastest sorting algorithms for processing big data. Although the worst-case time complexity reaches O(n²), it is still excellent, and in most cases it performs better than sorting algorithms with an average time complexity of O(n log n). But why is that? I do not know either. Fortunately, my obsessive-compulsive disorder kicked in again; after consulting many resources, I finally found a satisfactory answer in "Algorithm Art and Informatics Competitions":

The worst-case running time of Quick Sort is O(n²), for example, quick sort on an ordered sequence. But its amortized expected time is O(n log n), and the constant factor implied in the O(n log n) notation is very small, much smaller than that of Merge Sort, whose complexity is stably equal to O(n log n). Therefore, for the vast majority of random sequences with weak ordering, Quick Sort is always better than Merge Sort.

1. Algorithm Steps

  1. Select pivot element: Select an element from the list as the pivot. The selection can be the first element, the last element, the middle element, or a random element.

  2. Partition: Rearrange the list so that all elements smaller than the pivot are to the left of the pivot, and all elements greater than the pivot are to the right of the pivot. The position of the pivot is determined after the partition is complete.

  3. Recursively sort: Recursively apply Quick Sort to the sub-lists on the left and right sides of the pivot element.

  4. Merge: Since the partition operation is performed in-place, the entire list is already sorted after the recursion ends.

2. Animation Demo

Suppose there is a list to be sorted[3, 6, 8, 10, 1, 2, 1], select the last element as the pivot, the sorting process is as follows:

  1. Initial state：

    • List:[3, 6, 8, 10, 1, 2, 1]。

    • Pivot element:1(the last element).

  2. First partition：

    • Place elements smaller than the pivot on the left, and elements greater than the pivot on the right.

    • List after partition:[1, 1, 2, 10, 6, 8, 3]。

    • Pivot element1position is determined.

  3. Recursively sort：

    • For the left sub-list[1]and the right sub-list[2, 10, 6, 8, 3]apply Quick Sort separately.

    • The left sub-list is already sorted.

    • For the right sub-list[2, 10, 6, 8, 3]select pivot element3(the last element):

      • List after partition:[2, 3, 6, 8, 10]。

      • Pivot element3position is determined.

    • Continue recursively sorting the right sub-list[6, 8, 10]：

      • select pivot element10(the last element):

        • List after partition:[6, 8, 10]。

        • Pivot element10position is determined.

      • Continue recursively sorting the left sub-list[6, 8]：

        • select pivot element8(the last element):

          • List after partition:[6, 8]。

          • Pivot element8position is determined.

        • Continue recursively sorting the left sub-list[6], it is already sorted.

  4. Final result：

    • The list is completely sorted:[1, 1, 2, 3, 6, 8, 10]。

Example

def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    # Select pivot element (here, choose the last element)
    pivot = arr[-1]
    # Partition: place elements smaller than the pivot on the left, and elements greater than the pivot on the right
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
    # Recursively sort and merge
    return quick_sort(left) + [pivot] + quick_sort(right)

# Example
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quick_sort(arr)
print(sorted_arr)  # Output: [1, 1, 2, 3, 6, 8, 10]

Time Complexity

  • Divide: Each time the list is divided in half, requiring O(log n) levels of recursion.

  • Merge: Each level of recursion requires O(n) time to merge the sub-lists.

  • Total time complexity：O(n log n)。

Space Complexity

  • O(n); Merge Sort requires extra space to store temporary lists.

Advantages and Disadvantages

  • Advantages：

    • Average time complexity is O(n log n), very efficient in most cases.

    • In-place sorting algorithm, requiring only O(log n) extra space (recursion stack).

    • Suitable for sorting large-scale data in memory, commonly used in general-purpose sorting functions (such as std::sort).

  • Disadvantages：

    • Unstable sort; the relative order of equal elements may change.

    • Worst-case time complexity is O(n²) (e.g., when the array is nearly ordered), but it can be optimized by randomization or "median-of-three".

    • Performance is poor for small-scale data, not as good as simple algorithms like Insertion Sort.

Applicable Scenarios

  • Sorting large-scale datasets.

  • Scenarios that require a stable sorting algorithm.

  • External sorting (such as sorting disk files).

function quickSort(arr, left, right) {
    var len = arr.length,
        partitionIndex,
        left = typeof left != 'number' ? 0 : left,
        right = typeof right != 'number' ? len - 1 : right;

        partitionIndex = partition(arr, left, right);
        quickSort(arr, left, partitionIndex-1);
        quickSort(arr, partitionIndex+1, right);
    }
    return arr;
}

function partition(arr, left ,right) {     // Partition operation
    var pivot = left,                      // Set pivot value (pivot)
        index = pivot + 1;
    for (var i = index; i <= right; i++) {
        if (arr[i] < arr[pivot]) {
            swap(arr, i, index);
            index++;
        }        
    }
    swap(arr, pivot, index - 1);
    return index-1;
}

function swap(arr, i, j) {
    var temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
function partition2(arr, low, high) {
  let pivot = arr[low];
  while (low < high) {
    while (low < high && arr[high] > pivot) {
      --high;
    }
    arr[low] = arr[high];
    while (low < high && arr[low] <= pivot) {
      ++low;
    }
    arr[high] = arr[low];
  }
  arr[low] = pivot;
  return low;
}

public class QuickSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copy arr, do not change the parameter contents
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        return quickSort(arr, 0, arr.length - 1);
    }

    private int[] quickSort(int[] arr, int left, int right) {
        if (left < right) {
            int partitionIndex = partition(arr, left, right);
            quickSort(arr, left, partitionIndex - 1);
            quickSort(arr, partitionIndex + 1, right);
        }
        return arr;
    }

    private int partition(int[] arr, int left, int right) {
        // Set pivot value (pivot)
        int pivot = left;
        int index = pivot + 1;
        for (int i = index; i <= right; i++) {
            if (arr[i] < arr[pivot]) {
                swap(arr, i, index);
                index++;
            }
        }
        swap(arr, pivot, index - 1);
        return index - 1;
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

}

void quick_sort(int arr[], const int len) {
    if (len <= 0)
        return; // Avoid causing a segment fault when len is negative
    // r[] simulates a list, p is the count; r[p++] is push, r[--p] is pop and gets the element
    Range r[len];
    int p = 0;
    r[p++] = new_Range(0, len - 1);
    while (p) {
        Range range = r[--p];
        if (range.start >= range.end)
            continue;
        int mid = arr[(range.start + range.end) / 2]; // Select the middle point as the pivot
        int left = range.start, right = range.end;
        do {
            while (arr[left] < mid) ++left;   // Check whether the left side of the pivot meets the requirement
            while (arr[right] > mid) --right; // Check whether the right side of the pivot meets the requirement
            if (left <= right) {
                swap(&arr[left], &arr[right]);
                left++;
                right--;               // Move the pointer to continue
            }
        } while (left <= right);
        if (range.start < right) r[p++] = new_Range(range.start, right);
        if (range.end > left) r[p++] = new_Range(left, range.end);
    }
}

void quick_sort_recursive(T arr[], int start, int end) {
    if (start >= end)
        return;

    There is no C# implementation above, I'll add one as follows:

    //快速排序（目标数组，数组的起始位置，数组的终止位置）
static void QuickSort(int[] array, int left = 0, int right = -1)
{
    if (right.Equals(-1)) right = array.Length - 1;
    try
    {
        int keyValuePosition;   //记录关键值的下标
        //当传递的目标数组含有两个以上的元素时，进行递归调用。（即：当传递的目标数组只含有一个元素时，此趟排序结束）
        if (left < right)
        {
            keyValuePosition = Partion(array, left, right);  //获取关键值的下标（快排的核心）
            QuickSort(array, left, keyValuePosition - 1);    //递归调用，快排划分出来的左区间
            QuickSort(array, keyValuePosition + 1, right);   //递归调用，快排划分出来的右区间
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine("Exception: {0}", ex);
    }
}

///快速排序的核心部分：确定关键值在数组中的位置，以此将数组划分成左右两区间，关键值游离在外。（返回关键值应在数组中的下标）
static int Partion(int[] array, int left, int right)
{
    int leftIndex = left;        //记录目标数组的起始位置（后续动态的左侧下标）
    int rightIndex = right;      //记录目标数组的结束位置（后续动态的右侧下标）
    int keyValue = array[left];  //数组的第一个元素作为关键值
    int temp;
    //当 （左侧动态下标 == 右侧动态下标） 时跳出循环
    while (leftIndex < rightIndex)
    {
        while (leftIndex < rightIndex && array[leftIndex] <= keyValue)  //左侧动态下标逐渐增加，直至找到大于keyValue的下标
        {
            leftIndex++;
        }
        while (leftIndex < rightIndex && array[rightIndex] > keyValue)  //右侧动态下标逐渐减小，直至找到小于或等于keyValue的下标
        {
            rightIndex--;
        }
        if (leftIndex < rightIndex)  //如果leftIndex < rightIndex，则交换左右动态下标所指定的值；当leftIndex==rightIndex时，跳出整个循环
        {
            temp = array[leftIndex];
            array[leftIndex] = array[rightIndex];
            array[rightIndex] = temp;
        }
    }

    //当左右两个动态下标相等时（即：左右下标指向同一个位置），此时便可以确定keyValue的准确位置
    temp = keyValue;
    if (temp < array[rightIndex])   //当keyValue < 左右下标同时指向的值，将keyValue与rightIndex - 1指向的值交换，并返回rightIndex - 1
    {
        array[left] = array[rightIndex - 1];
        array[rightIndex - 1] = temp;
        return rightIndex - 1;
    }
    else //当keyValue >= 左右下标同时指向的值，将keyValue与rightIndex指向的值交换，并返回rightIndex
    {
        array[left] = array[rightIndex];
        array[rightIndex] = temp;
        return rightIndex;
    }
}

   * @param arr    
   * @param left

   * @return

def partition(arr:Array[Int],left:Int,right: Int):Int={
    // 获取基准元素 直接选取最右侧一个元素为基准元素   
    val pv=arr(right)

    // 把最左边一个索引作为堆叠索引   
     var storeIndex=left
    //操作数组 -1是因为 最右边一个元素是基准元素  
   for (i <- left to right-1 ){
       if(arr(i)<=pv){
         //把小于基准元素的元素 都堆到集合左端        
          swap(arr,storeIndex,i)
         // 把用于堆叠索引往前移动一个  
          storeIndex=storeIndex+1 
      }
      //如果出现了比基准元素大的元素,那么则不会移动堆叠索引  
      // 但是如果之后又出现了比基准元素小的元素,那边会与这个大的元素交换位置
      // 进而使大的元素永远出现在堆叠索引右侧
    }
    // 这里最有右的元素,其实是基准元素,我们把基准元素和最后堆叠索引对应的元素调换位置
    // 这样基准元素左边就都是大于它的元素了  
     swap(arr,right,storeIndex)
    // 返回堆叠索引位置,目前堆叠索引指向的就是基准元素 
     storeIndex
  }

    def _partition(array:list, start:int, end:int) -> int:
    """
    将数组指定片段进行左右划分，首先选择中位元素为中值。\n
    比中位元素小的置于其左，与中位元素相等或比中位元素大的置于其右，\n
    最后返回中位元素的下标位置。
    """
    # 以中位元素为中值划分，尽量避免极端情况
    mid = (start + end) >> 1
    array[start], array[mid] = array[mid], array[start]
    
    # 划分的实现
    i, j = start, end
    x = array[start]
    while (i < j):
        if (i < j and array[j] >= x): j -= 1
        array[i] = array[j]
        if (i < j and array[i] < x): i += 1
        array[j] = array[i]
    array[i] = x

    return i


def quickSort(array:list) -> list:
    """
    迭代法快速排序，队列结构辅助实现。
    """
    sorted_array = array.copy()
    length = len(sorted_array)
    # 使用队列保存每次划分的二元组：(起始下标，终止下标)
    queue = []
    queue.append((0, length - 1))

    # 队列为空，则所有划分操作执行完毕
    while len(queue):
        left, right = queue.pop(0)
        pos = _partition(sorted_array, left, right)
        # 默认长度为 1 的序列有序，那么区间长度 > 1 才需要划分，才需要保存到队列中
        if (left < pos - 1): queue.append((left, pos - 1))
        if (pos + 1 < right): queue.append((pos + 1, right))
    
    return sorted_array


if __name__ == "__main__":
    array = [21, -17, 1, -27, 41, 17, -5, -49]
    sorted_array = quickSort(array)
    print("排序前：{array1}\n排序后：{array2}".format(array1=array, array2=sorted_array))
