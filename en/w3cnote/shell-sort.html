1.4 Shell Sort

Category Algorithm

Shell Sort is an improved version of Insertion Sort, also known as diminishing increment sort. It divides the list to be sorted into several sublists, performs insertion sort on each sublist, gradually reduces the interval between sublists, and finally completes the entire...

Shell Sort proposes improvements based on the following two properties of Insertion Sort:

  • Insertion Sort is highly efficient when operating on data that is almost already sorted, achieving linear sorting efficiency;
  • But Insertion Sort is generally inefficient because it can only move data one position at a time;

The basic idea of Shell Sort is: first divide the entire sequence of records to be sorted into several subsequences and perform direct insertion sort on each separately. When the records in the entire sequence are "basically ordered", then perform direct insertion sort on all records one by one.

1. Algorithm Steps

  1. Choose a gap sequence: Choose a gap sequence to divide the list into several sublists. Common gap sequences include the Shell gap (n/2, n/4, ..., 1) and others.

  2. Grouped insertion sort: Divide the list into several sublists according to the gap sequence, and perform insertion sort on each sublist.

  3. Reduce the gap: Gradually reduce the gap, repeat the above grouping and sorting process until the gap is 1.

  4. Final sort: When the gap is 1, perform an insertion sort on the entire list to complete the sorting.

2. Animation Demonstration

Suppose there is a list to be sorted [8, 3, 1, 2, 7, 5, 6, 4], using the Shell gap (initial gap is n/2), the sorting process is as follows:

  1. Initial state：

    • List:[8, 3, 1, 2, 7, 5, 6, 4]。

    • Initial gap:4(half of the list8length).

  2. First round (gap is 4)：

    • Divide the list into 4 sublists:

      • Sublist 1:[8, 7]。

      • Sublist 2:[3, 5]。

      • Sublist 3:[1, 6]。

      • Sublist 4:[2, 4]。

    • Perform insertion sort on each sublist:

      • Sublist 1:[7, 8]。

      • Sublist 2:[3, 5]。

      • Sublist 3:[1, 6]。

      • Sublist 4:[2, 4]。

    • Sorted list:[7, 3, 1, 2, 8, 5, 6, 4]。

  3. Second round (gap is 2)：

    • Divide the list into 2 sublists:

      • Sublist 1:[7, 1, 8, 6]。

      • Sublist 2:[3, 2, 5, 4]。

    • Perform insertion sort on each sublist:

      • Sublist 1:[1, 6, 7, 8]。

      • Sublist 2:[2, 3, 4, 5]。

    • Sorted list:[1, 2, 6, 3, 7, 4, 8, 5]。

  4. Third round (gap is 1)：

    • Treat the entire list as one sublist and perform insertion sort.

    • Sorted list:[1, 2, 3, 4, 5, 6, 7, 8]。

Example

def shell_sort(arr):
    n = len(arr)
    gap = n // 2  # Initial gap
    while gap > 0:
        # Perform insertion sort on each sublist
        for i in range(gap, n):
            temp = arr[i]  # Current element to be inserted
            j = i
            # Find the appropriate position in the sublist to insert
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 2  # Reduce the gap
    return arr

# Example
arr = [8, 3, 1, 2, 7, 5, 6, 4]
sorted_arr = shell_sort(arr)
print(sorted_arr)  # Output: [1, 2, 3, 4, 5, 6, 7, 8]

Time Complexity

The time complexity of Shell Sort depends on the choice of the gap sequence:

  • Worst case: O(n²), when the gap sequence is poorly chosen.

  • Best case: O(n log n), when the gap sequence is appropriately chosen.

  • Average case: Between O(n log n) and O(n²).

Common gap sequences:

  • Shell gap:n/2, n/4, ..., 1, time complexity is O(n²).

  • Hibbard gap:1, 3, 7, 15, ..., 2^k - 1, time complexity is O(n^(3/2)).

  • Sedgewick gap:1, 5, 19, 41, 109, ..., time complexity is O(n^(4/3)).

Space Complexity

  • O(1). Shell Sort is an in-place sorting algorithm and does not require additional storage space.

Pros and Cons

  • Advantages：

    • More efficient than simple Insertion Sort.

    • In-place sorting, no additional storage space required.

    • Suitable for medium-sized datasets.

  • Disadvantages：

    • Time complexity depends on the choice of the gap sequence.

    • Unstable sorting algorithm (may change the relative order of equal elements).

Applicable Scenarios

  • Medium-sized datasets.

  • Scenarios where performance requirements are not high but better efficiency than simple Insertion Sort is needed.

  • As a preprocessing step for more complex sorting algorithms.

Example

function shellSort(arr) {
    var len = arr.length,
        temp,
        gap = 1;
    while(gap < len/3) {          // Dynamically define the gap sequence
        gap =gap*3+1;
    }
    for (gap; gap > 0; gap = Math.floor(gap/3)) {
        for (var i = gap; i < len; i++) {
            temp = arr[i];
            for (var j = i-gap; j >= 0 && arr[j] > temp; j-=gap) {
                arr[j+gap] = arr[j];
            }
            arr[j+gap] = temp;
        }
    }
    return arr;
}

Example

template<typename T>
void shell_sort(T array[], int length) {
    int h = 1;
    while (h < length / 3) {
        h = 3 * h + 1;
    }
    while (h >= 1) {
        for (int i = h; i < length; i++) {
            for (int j = i; j >= h && array[j] < array[j - h]; j -= h) {
                std::swap(array[j], array[j - h]);
            }
        }
        h = h / 3;
    }
}

    static void ShellSort(int[] arr)
{
    int gap = 1;

    while (gap < arr.Length)
    {
        gap = gap * 3 + 1;
    }

    while (gap > 0)
    {
        for (int i = gap; i < arr.Length; i++)
        {
            int tmp = arr[i];
            int j = i - gap;
            while (j >= 0 && arr[j] > tmp)
            {
                arr[j + gap] = arr[j];
                j -= gap;
            }
            arr[j + gap] = tmp;
        }
        gap /= 3;
    }
}

    Rust version:

    fn shell_sort<T: Ord + Debug>(array: &mut [T]) {
    let mut grad = [1, 3, 5];
    grad.reverse();
    for step in grad {
        insert_sort_step(array, step)
    }
}

fn insert_sort_step<T: Ord + Debug>(array: &mut [T], step: usize) {
    for i in (0..array.len()).step_by(step) {
        for j in (0..i).step_by(step).rev() {
            if array[j + step] < array[j] {
                array.swap(j + step, j);
            } else {
                break;
            }
        }
    }
}
