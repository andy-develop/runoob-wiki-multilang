1.9 Bucket Sort

Category Algorithm

Bucket Sort is a distributed sorting algorithm. It distributes the elements to be sorted into several buckets, then sorts the elements in each bucket, and finally merges the elements in all buckets in order. The core idea of bucket sort is to divide the data into a finite number of buckets, and then sort each bucket separately (using other sorting algorithms or recursively using bucket sort).

Bucket sort is an upgraded version of counting sort. It uses the mapping relationship of a function; the key to efficiency lies in the determination of this mapping function. To make bucket sort more efficient, we need to do the following two things:

  1. When there is sufficient extra space, increase the number of buckets as much as possible
  2. The mapping function used should be able to evenly distribute the input N data items into K buckets

At the same time, for sorting the elements in the buckets, the choice of comparison sorting algorithm is crucial to performance.

Algorithm steps:

  1. Initialize buckets: Create several buckets based on the range and distribution of the data.

  2. Distribute elements: Traverse the list to be sorted and assign each element to the corresponding bucket.

  3. Sort each bucket: Sort the elements in each bucket (insertion sort, quick sort, etc. can be used).

  4. Merge buckets: Merge the elements in all buckets in order to obtain the final sorted result.

1. When is it fastest?

When the input data can be evenly distributed into each bucket.

2. When is it slowest?

When the input data is distributed into the same bucket.

Suppose there is a list to be sorted [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]. The bucket sort process is as follows:

  1. Initialize buckets：

    • Assume the data range is [0, 1), create 10 buckets, each with a range of 0.1.

    • Bucket 0: [0.0, 0.1)

    • Bucket 1: [0.1, 0.2)

    • ...

    • Bucket 9: [0.9, 1.0)

  2. Distribute elements：

    • Traverse the list and assign elements to the corresponding buckets:

      • 0.42→ Bucket 4

      • 0.32→ Bucket 3

      • 0.33→ Bucket 3

      • 0.52→ Bucket 5

      • 0.37→ Bucket 3

      • 0.47→ Bucket 4

      • 0.51→ Bucket 5

    • Buckets after distribution:

      • Bucket 3:[0.32, 0.33, 0.37]

      • Bucket 4:[0.42, 0.47]

      • Bucket 5:[0.52, 0.51]

  3. Sort each bucket：

    • Sort the elements in each bucket:

      • Bucket 3:[0.32, 0.33, 0.37](already in order).

      • Bucket 4:[0.42, 0.47](already in order).

      • Bucket 5:[0.51, 0.52](after sorting).

  4. Merge buckets：

    • Merge the elements in all buckets in order:

      • Bucket 3:[0.32, 0.33, 0.37]

      • Bucket 4:[0.42, 0.47]

      • Bucket 5:[0.51, 0.52]

    • Merged list:[0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]。

Example

def bucket_sort(arr, bucket_size=10):
    if len(arr) == 0:
        return arr

    # Find the minimum and maximum values
    min_val = min(arr)
    max_val = max(arr)

    # Initialize buckets
    bucket_count = (max_val - min_val) // bucket_size + 1
    buckets = [[] for _ in range(bucket_count)]

    # Distribute elements into buckets
    for num in arr:
        index = int((num - min_val) // bucket_size)
        buckets[index].append(num)

    # Sort the elements in each bucket
    sorted_arr = []
    for bucket in buckets:
        sorted_arr.extend(sorted(bucket))  # Use built-in sort function

    return sorted_arr

# Example
arr = [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
sorted_arr = bucket_sort(arr)
print(sorted_arr)  # Output: [0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]

Time complexity

  • Distribute elements: O(n), traversing the list once.

  • Sort each bucket: Assuming the number of elements in each bucket is m, the time complexity to sort one bucket is O(m log m). If the number of buckets is k, the total time complexity is O(k * m log m).

  • Merge buckets: O(n), traversing all buckets once.

  • Total time complexity: O(n + k * m log m), where n is the length of the list, k is the number of buckets, and m is the average number of elements in each bucket.

Space complexity

  • O(n + k), requiring extra storage space for the buckets and the sorted result.

Advantages and disadvantages

  • Advantages：

    • When the data is evenly distributed, performance is excellent.

    • Suitable for external sorting (e.g., sorting disk files).

  • Disadvantages：

    • When the data distribution is uneven, some buckets may contain too many elements, causing performance degradation.

    • Requires extra storage space.

Applicable scenarios

  • Scenarios where data is evenly distributed.

  • Scenarios where the data range is known and limited.

  • Suitable for external sorting (e.g., sorting disk files).

function bucketSort(arr, bucketSize) {
    if (arr.length === 0) {
      return arr;
    }

    var i;
    var minValue = arr[0];
    var maxValue = arr[0];
    for (i = 1; i < arr.length; i++) {
      if (arr[i] < minValue) {
          minValue = arr[i];                // Minimum value of input data
      } else if (arr[i] > maxValue) {
          maxValue = arr[i];                // Maximum value of input data
      }
    }

    // Bucket initialization
    var DEFAULT_BUCKET_SIZE = 5;            // Set the default number of buckets to 5
    bucketSize = bucketSize || DEFAULT_BUCKET_SIZE;
    var bucketCount = Math.floor((maxValue - minValue) / bucketSize) + 1;  
    var buckets = new Array(bucketCount);
    for (i = 0; i < buckets.length; i++) {
        buckets[i] = [];
    }

    // Use the mapping function to distribute data into each bucket
    for (i = 0; i < arr.length; i++) {
        buckets[Math.floor((arr[i] - minValue) / bucketSize)].push(arr[i]);
    }

    arr.length = 0;
    for (i = 0; i < buckets.length; i++) {
        insertionSort(buckets[i]);                      // Sort each bucket, using insertion sort here
        for (var j = 0; j < buckets[i].length; j++) {
            arr.push(buckets[i][j]);                      
        }
    }

    return arr;
}

Java

Example

public class BucketSort implements IArraySort {

    private static final InsertSort insertSort = new InsertSort();

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copy arr without changing the parameter contents
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        return bucketSort(arr, 5);
    }

    private int[] bucketSort(int[] arr, int bucketSize) throws Exception {
        if (arr.length == 0) {
            return arr;
        }

        int minValue = arr[0];
        int maxValue = arr[0];
        for (int value : arr) {
            if (value < minValue) {
                minValue = value;
            } else if (value > maxValue) {
                maxValue = value;
            }
        }

        int bucketCount = (int) Math.floor((maxValue - minValue) / bucketSize) + 1;
        int[][] buckets = new int[bucketCount][0];

        // Use the mapping function to distribute data into each bucket
        for (int i = 0; i < arr.length; i++) {
            int index = (int) Math.floor((arr[i] - minValue) / bucketSize);
            buckets[index] = arrAppend(buckets[index], arr[i]);
        }

        int arrIndex = 0;
        for (int[] bucket : buckets) {
            if (bucket.length <= 0) {
                continue;
            }
            // Sort each bucket, using insertion sort here
            bucket = insertSort.sort(bucket);
            for (int value : bucket) {
                arr[arrIndex++] = value;
            }
        }

        return arr;
    }

    /**
* Automatically expands capacity and saves data
     *
     * @param arr
     * @param value
     */
    private int[] arrAppend(int[] arr, int value) {
        arr = Arrays.copyOf(arr, arr.length + 1);
        arr[arr.length - 1] = value;
        return arr;
    }

}

#include<iterator>

using namespace std;
const int BUCKET_NUM = 10;

struct ListNode{
        explicit ListNode(int i=0):mData(i),mNext(NULL){}
        ListNode* mNext;
        int mData;
};

ListNode* insert(ListNode* head,int val){
        ListNode dummyNode;
        ListNode *newNode = new ListNode(val);
        ListNode *pre,*curr;
        dummyNode.mNext = head;
        pre = &dummyNode;
        curr = head;
        while(NULL!=curr && curr->mData<=val){
                pre = curr;
                curr = curr->mNext;
        }
        newNode->mNext = curr;
        pre->mNext = newNode;
        return dummyNode.mNext;
}


ListNode* Merge(ListNode *head1,ListNode *head2){
        ListNode dummyNode;
        ListNode *dummy = &dummyNode;
        while(NULL!=head1 && NULL!=head2){
                if(head1->mData <= head2->mData){
                        dummy->mNext = head1;
                        head1 = head1->mNext;
                }else{
                        dummy->mNext = head2;
                        head2 = head2->mNext;
                }
                dummy = dummy->mNext;
        }
        if(NULL!=head1) dummy->mNext = head1;
        if(NULL!=head2) dummy->mNext = head2;
       
        return dummyNode.mNext;
}

void BucketSort(int n,int arr[]){
        vector<ListNode*> buckets(BUCKET_NUM,(ListNode*)(0));
        for(int i=0;i<n;++i){
                int index = arr[i]/BUCKET_NUM;
                ListNode *head = buckets.at(index);
                buckets.at(index) = insert(head,arr[i]);
        }
        ListNode *head = buckets.at(0);
        for(int i=1;i<BUCKET_NUM;++i){
                head = Merge(head,buckets.at(i));
        }
        for(int i=0;i<n;++i){
                arr[i] = head->mData;
                head = head->mNext;
        }
}

def bucket_sort_simplify(arr, max_num):
    """
    简化版
    """
    buf = {i: [] for i in range(int(max_num)+1)}  # 不能使用[[]]*(max+1)，这样新建的空间中各个[]是共享内存的
    arr_len = len(arr)
    for i in range(arr_len):
        num = arr[i]
        buf[int(num)].append(num)  # 将相应范围内的数据加入到[]中
    arr = []
    for i in range(len(buf)):
        if buf[i]:
            arr.extend(sorted(buf[i]))  # 这里还需要对一个范围内的数据进行排序，然后再进行输出
    return arr

    static void BucketSort(List<int> list, int bucketCount, int maxBucketCount)
{
    List<List<int>> buckets = new List<List<int>>(bucketCount);//二维列表
    for (int i = 0; i < bucketCount; i++)
    {
        buckets.Add(new List<int>());
    }
    for (int i = 0; i < list.Count; i++)
    {
        // int j = Mathf.Min(list[i] / (maxBucketCount / bucketCount), bucketCount - 1);//j表示改放的哪个桶,不能大于n-1
        int j = Math.Min(list[i] / (maxBucketCount / bucketCount), bucketCount - 1);//j表示改放的哪个桶,不能大于n-1
        buckets[j].Add(list[i]);//放入对应桶
        for (int x = buckets[j].Count - 1; x > 0; x--)//放一个排序一次，两两对比就可以
        {
            if (buckets[j][x] < buckets[j][x - 1])//升序
            {
                int tmp = buckets[j][x];//交换
                buckets[j][x] = buckets[j][x - 1];
                buckets[j][x - 1] = tmp;
            }
            else
            {
                break;//如果不发生交换直接退出，因为前面的之前就排序好了
            }
        }
    }
    list.Clear();//输出
    for (int i = 0; i < buckets.Count; i++)
    {
        list.AddRange(buckets[i]);
    }
}

    The following is a C# version of the bucket sort algorithm organized according to the reference answer's approach:

    public static void BucketSort(int[] arr, int bucketSize)
{
   if (arr.Length <= 1)
         return;

   int minValue = arr.Min();
   int maxValue = arr.Max();
   //根據原始數組最值差值，桶的大小來確定 桶的數量
   int bucketCount = (int)Math.Ceiling((decimal)(maxValue - minValue + 1) / bucketSize);

   List<List<int>> buckets = new List<List<int>>();
   //根據計算得到的桶數量添加桶列表
   for (int i = 0; i < bucketCount; i++)
         buckets.Add(new List<int>());

   for (int i = 0; i < arr.Length; i++)
   {
         //計算原始數組中的每一個元素應屬於哪一個桶
         int bucketIndex = (arr[i] - minValue) / bucketSize;
         //將元素分配至對應桶中
         buckets[bucketIndex].Add(arr[i]);
   }

   int index = 0;
   //遍歷桶列表，將每一個桶進行排序，並將排序好的元素順次取出放至原始數組中。
   foreach (var bucket in buckets)
   {
         bucket.Sort();
         //將桶中元素排序好後，順次取出放入原始數組
         foreach (var value in bucket)
            arr[index++] = value;
   }
}

    #include <stdio.h>
#include <stdlib.h>

// 定义桶的结构体
struct bucket {
    int count;
    int* value;
};

// 插入排序算法，对桶内元素进行排序
void InsertionSort(int * arr, int arrlen) {
    for (int index = 0; index < arrlen; index++) {
        int currentVal = arr[index];
        int position = index;
        // 找到合适的位置插入当前值
        while (position > 0 && arr[position - 1] > currentVal) {
            arr[position] = arr[position - 1];
            position -= 1;
        }
        arr[position] = currentVal;
    }
}

// 桶排序算法
void bucketSort(int array[], int n) {
    // 初始化三个桶
    struct bucket buckets[3];
    int i, j, k;
    for (i = 0; i < 3; i++ ){
        buckets[i].count = 0;
        buckets[i].value = (int*)malloc(sizeof(int) * n);
    }
    
    // 将元素放入对应的桶中
    for (i = 0; i < n; i++) {
        if (array[i] < 0) {
            buckets[0].value[buckets[0].count++] = array[i];
        } else if (array[i] > 10) {
            buckets[2].value[buckets[2].count++] = array[i];
        } else {
            buckets[1].value[buckets[1].count++] = array[i];
        }
    }
    
    // 对每个桶中的元素进行排序，并将排序后的元素放回原数组中
    for (k = 0, i = 0; i < 3; i++) {
        InsertionSort(buckets[i].value, buckets[i].count);
        for (j = 0; j < buckets[i].count; j++) {
            array[k + j] = buckets[i].value[j];
        }
        k += buckets[i].count;
        free(buckets[i].value);
    }
}

int main() {
    int array[] = {54, 26, 99, 17, 77, 31, 44, 55, 20};
    int n = sizeof(array) / sizeof(array[0]);

    // 调用桶排序算法
    bucketSort(array, n);

    // 打印排序后的数组
    for (int i = 0; i < n; i++)
        printf("%d ", array[i]);  

    return 0;
}
