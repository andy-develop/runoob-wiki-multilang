Node.js Routing

In Node.js, routing is a key part of handling HTTP requests. It determines how to distribute requests based on different URLs and HTTP methods (such as GET, POST, PUT, DELETE, etc.).

Routing is commonly used to build web applications, especially RESTful APIs.

Node.js itself does not have built-in routing mechanisms, but it can be implemented through middleware libraries (such as Express).

Routing usually involves the following aspects:

  • URL matching: Match routing rules according to the requested URL.
  • HTTP method matching: Match routing rules according to the requested HTTP method (GET, POST, PUT, DELETE, etc.).
  • Request handling: Once a matching routing rule is found, the corresponding handler function is called to process the request.

In Node.js, we can create a simple route through the http module, as in the following example:

Example

const http = require('http');

// Create server and define routes
const server = http.createServer((req, res) => {
  const { url, method } = req;

  if (url === '/' && method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('Home Page');
  } else if (url === '/about' && method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('About Page');
  } else {
    res.writeHead(404, { 'Content-Type': 'text/plain' });
    res.end('404 Not Found');
  }
});

server.listen(3000, () => {
  console.log('Server is running on http://localhost:3000');
});

Request Parameters

A complete URLhttp://localhost:8888/start?foo=bar&hello=worldcontains the host, path, and query string.

To parse this data, we can use theURLobject and thequerystringmodule.

const myUrl = new URL("http://localhost:8888/start?foo=bar&hello=world");

// 提取路径名
console.log(myUrl.pathname); // 输出: /start

// 提取查询参数
console.log(myUrl.searchParams.get("foo"));   // 输出: bar
console.log(myUrl.searchParams.get("hello")); // 输出: world

Of course, we can also use the querystring module to parse parameters in the POST request body. This will be introduced later inNode.js GET/POST Requests.

All the request data we need will be contained in the request object, which is passed as the first parameter to the onRequest() callback function.

Now let's add some logic to the onRequest() function of the http module to find out the URL path requested by the browser:

server.js file code:

var http = require("http"); var url = require("url"); function start() { function onRequest(request, response) { //Use the URL constructor to parse the request path const pathname = new URL(request.url, `http://${request.headers.host}`).pathname; console.log(`Request for ${pathname} received.`); //Print the request path //Set the response header and response content response.writeHead(200, { "Content-Type": "text/plain" }); //Set the status code and content type response.write("Hello World"); //Send the response content to the client response.end(); //End the response } //Create a server and listen on the specified port http.createServer(onRequest).listen(8888); console.log("Server has started."); //Print the server startup message } //Export the start function for use by other modules module.exports.start = start;

Okay, our application can now distinguish different requests based on the requested URL path - this allows us to use routing (not yet complete) to map requests to handlers based on the URL path.

In the application we are going to build, this means requests from /start and /upload can be handled with different code. Later we will see how these things fit together.

Now we can write the route. Create a file namedrouter.jsand add the following content:

router.js file code:

function route(pathname) { console.log("About to route a request for " + pathname); } //Export the route function exports.route = route;

router.js handles routing logic, defines and exports the route function, which is used to handle different paths when the server receives a request.

Our server should be aware of the route and use it effectively. We could of course hard-code this dependency to the server, but programming experience in other languages tells us this would be very painful, so we will use dependency injection to add the routing module in a loosely coupled way.

First, let's extend the server's start() function so that the route function can be passed in as a parameter.server.jsThe file code is as follows:

server.js file code:

// server.js const http = require("http"); //Import Node.js's http module to create a server const { URL } = require("url"); //Import the URL constructor from the url module //Define and export the start function to start the server function start(route) { //Define the onRequest function to handle each request function onRequest(request, response) { //Use the URL constructor to parse the request path const pathname = new URL(request.url, `http://${request.headers.host}`).pathname; console.log(`Request for ${pathname} received.`); //Print the request path route(pathname); //Call the route function to handle the path //Set the response header and response content response.writeHead(200, { "Content-Type": "text/plain" }); response.write("Hello World"); response.end(); } //Create a server and listen on the specified port http.createServer(onRequest).listen(8888); console.log("Server has started."); } //Export the start function for use by other modules module.exports.start = start;

server.js defines the server startup logic and calls the route function when a request is received.

At the same time, we will extend index.js accordingly so that the route function can be injected into the server:

index.js file code:

var server = require("./server"); var router = require("./router"); server.start(router.route);

index.js is the entry file of the program, responsible for starting the server and passing the routing module into the server module.

Now start the application (node index.js, always remember this command line), then request a URL. You will see the application output the corresponding information, which shows that our HTTP server is already using the routing module and will pass the request path to the route:

$ node index.js
Server has started.

Routing with Express

Express is a popular Node.js framework that provides powerful routing capabilities.

For more about Express, refer to:Node.js Express Framework。

Installing Express

First, make sure you have installed Express. If not, you can use npm to install it:

npm install express

Basic Routing

The following is a simple Express application that demonstrates how to set up basic routing:

Example

const express = require('express');
const app = express();
const port = 3000;

// Define a GET route
app.get('/', (req, res) => {
    res.send('Hello, World!');
});

// Define a POST route
app.post('/submit', (req, res) => {
    res.send('Form submitted!');
});

// Start the server
app.listen(port, () => {
    console.log(`Server is running on http://localhost:${port}`);
});

Dynamic Routing

Dynamic routing allows you to use parameterized URLs.

For example, you can define a route to handle/users/:id, where:idis a dynamic parameter.

app.get('/users/:id', (req, res) => {
    const userId = req.params.id;
    res.send(`User ID: ${userId}`);
});

Route Parameters

Express allows you to extract parameters from the URL and access them through the req.params object.

Example

app.get('/users/:id', (req, res) => {
    const userId = req.params.id;
    res.send(`User ID: ${userId}`);
});

app.get('/search/:query', (req, res) => {
    const query = req.params.query;
    res.send(`Search query: ${query}`);
});

Query Parameters

Query parameters are key-value pairs in the URL, usually used to pass additional information. You can access query parameters through the req.query object.

app.get('/search', (req, res) => {
    const query = req.query.q;
    res.send(`Search query: ${query}`);
});

Route Middleware

Route middleware are functions executed before or after processing a request. You can use middleware to handle tasks such as authentication, logging, and so on.

// 日志记录中间件
const logger = (req, res, next) => {
    console.log(`Request Type: ${req.method} ${req.url}`);
    next();
};

// 使用中间件
app.use(logger);

app.get('/', (req, res) => {
    res.send('Hello, World!');
});

Route Grouping

To better organize your code, you can use route grouping. Express provides the express.Router object, which can be used to create modular, mountable route handlers.

Example

const express = require('express');
const app = express();
const port = 3000;

// Create a router instance
const userRouter = express.Router();

// Define user-related routes
userRouter.get('/', (req, res) => {
    res.send('List of users');
});

userRouter.get('/:id', (req, res) => {
    const userId = req.params.id;
    res.send(`User ID: ${userId}`);
});

// Mount the user router
app.use('/users', userRouter);

// Start the server
app.listen(port, () => {
    console.log(`Server is running on http://localhost:${port}`);
});

Advanced Routing Techniques

1. Error handling:You can define error-handling middleware to catch and handle errors in routes.

app.use((err, req, res, next) => {
    console.error(err.stack);
    res.status(500).send('Something broke!');
});

2. Route priority:The order in which routes are defined determines their priority; routes defined first will be matched first.

3. Route restrictions:You can use middleware to restrict access to certain routes, for example, allowing only authenticated users.

Example

const authMiddleware = (req, res, next) => {
    if (req.headers.authorization) {
        next();
    } else {
        res.status(401).send('Unauthorized');
    }
};

app.get('/admin', authMiddleware, (req, res) => {
    res.send('Admin page');
});

    According to the previous event binding, it is quite good to define the event name directly as a path. However, it is necessary to distinguish whether request.method is GET or POST, and this can be handled in two separate files.

    var http = require("http");
var url = require('url');
const { exit } = require("process");
var events = require('events');

// 创建 eventEmitter 对象 
var eventEmitter = new events.EventEmitter();

// route 根路径 
eventEmitter.on('/', function(method, response){
    response.writeHead(200, {'Content-Type': 'text/plain'});
    response.end('Hello World\n');
});

// route 404 
eventEmitter.on('404', function(method, url, response){
    response.writeHead(404, {'Content-Type': 'text/plain'});
    response.end('404 Not Found\n');
});

// 启动服务 
http.createServer(function (request, response) {
    console.log(request.url);

    // 分发 
    if (eventEmitter.listenerCount(request.url) > 0){
        eventEmitter.emit(request.url, request.method, response);
    }
    else {
        eventEmitter.emit('404', request.method, request.url, response);
    }
    
}).listen(8888);

console.log('Server running at http://127.0.0.1:8888/');
