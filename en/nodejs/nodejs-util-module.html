Node.js util module

Node.js built-in modules

In Node.jsutilThe module is a core module that provides a series of utility functions. These functions are mainly used to help developers complete common programming tasks, such as type checking, inheritance implementation, debugging output, etc.utilThe module was originally designed to make up for the deficiencies of JavaScript's native features and provide developers with more convenience.

To useutilmodule, you just need to import it in your code:

const util = require('util');

Main features of the util module

1. Type checking utilities

utilThe module provides some functions for type checking, which are more precise and useful than JavaScript's nativetypeofoperators.

util.types.isArrayBuffer(value)

Check whether the given value is an ArrayBuffer instance.

Example

const arrBuffer = new ArrayBuffer(8);
console.log(util.types.isArrayBuffer(arrBuffer)); // true
console.log(util.types.isArrayBuffer([])); // false

util.types.isDate(value)

Check whether the given value is a Date instance.

Example

console.log(util.types.isDate(new Date())); // true
console.log(util.types.isDate('2023-01-01')); // false

2. Utility functions

util.format(format[, ...args])

Similar to the printfprintffunction in C language, used to format strings.

Example

const name = 'John';
const age = 30;
console.log(util.format('My name is %s and I am %d years old', name, age));
// Output: My name is John and I am 30 years old

util.inspect(object[, options])

Returns the string representation of an object, mainly for debugging. Options such as depth and colors can be configured.

Example

const obj = {
  name: 'Alice',
  details: {
    age: 25,
    hobbies: ['reading', 'coding']
  }
};

console.log(util.inspect(obj, { depth: 2, colors: true }));

3. Callback style conversion

util.promisify(original)

Converts functions that follow the Node.js callback style into functions that return Promises.

Example

const fs = require('fs');
const readFile = util.promisify(fs.readFile);

async function readConfig() {
  try {
    const data = await readFile('config.json', 'utf8');
    console.log(data);
  } catch (err) {
    console.error('Error reading file:', err);
  }
}

readConfig();

util.callbackify(original)

与 promisifyConversely, converts functions that return Promises into callback-style functions.

Example

async function asyncFunc() {
  return 'Hello World';
}

const callbackFunc = util.callbackify(asyncFunc);

callbackFunc((err, result) => {
  if (err) throw err;
  console.log(result); // Hello World
});

4. Inheritance utilities

util.inherits(constructor, superConstructor)

Implements prototype inheritance (ES5 style). Note: In ES6, it is recommended to use theclass 和 extendskeyword.

Example

function Animal(name) {
  this.name = name;
}

Animal.prototype.speak = function() {
  console.log(this.name + ' makes a noise.');
};

function Dog(name) {
  Animal.call(this, name);
}

util.inherits(Dog, Animal);

Dog.prototype.speak = function() {
  console.log(this.name + ' barks.');
};

const d = new Dog('Rex');
d.speak(); // Rex barks.

Practical application scenarios of the util module

1. Debugging complex objects

When you need to print the structure of a complex object,util.inspectis more powerful than simpleconsole.logconsole.log:

Example

const complexObj = {
  date: new Date(),
  regex: /test/g,
  nested: {
    array: [1, 2, 3],
    fn: function() {}
  }
};

console.log(util.inspect(complexObj, {
  showHidden: true,
  depth: null,
  colors: true
}));

2. Modernizing old code

Convert old callback-style code to Promise style:

Example

// Old callback-style code
function oldStyleFunc(param, callback) {
  // Some asynchronous operations
  setTimeout(() => {
    callback(null, `Result for ${param}`);
  }, 100);
}

// Convert to Promise style
const newStyleFunc = util.promisify(oldStyleFunc);

async function useNewStyle() {
  const result = await newStyleFunc('test');
  console.log(result); // Result for test
}

useNewStyle();

3. Custom object inspection

You can customize the object'sinspectmethod to changeutil.inspectthe output of util.inspect:

Example

class CustomObject {
  constructor(value) {
    this.value = value;
  }
 
  [util.inspect.custom](depth, options) {
    return `CustomObject: ${this.value}`;
  }
}

const obj = new CustomObject('test');
console.log(util.inspect(obj)); // CustomObject: test

Notes

  1. Performance considerations：util.inspectFor large objects, there may be performance impact; use with caution in production environments.
  2. API stability: AlthoughutilThe module is a core module, but some APIs may still be marked as experimental features.
  3. Modern alternatives: Some features (such asutil.inherits) have better alternatives in modern JavaScript (such as theclasssyntax).
  4. Error handling: When usingpromisifymake sure to handle errors correctly to avoid unhandled Promise rejections.

Summary

Node.js'sutilThe module provides many practical utility functions that can help developers write code more efficiently. From type checking to asynchronous flow control to debugging output,utilThe module covers many common development needs. Although modern JavaScript already provides many native solutions,utilThe module is still very useful in many scenarios, especially when dealing with legacy code or when specific utility functions are needed.

MasteringutilThe use of the module can make your Node.js development more comfortable and efficient, especially in debugging and code conversion.
