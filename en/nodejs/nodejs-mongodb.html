Node.js Connect to MongoDB

MongoDB is a document-oriented database management system, written in C++.

In this chapter, we will introduce how to use Node.js to connect to MongoDB and perform database operations.

If you don't have basic knowledge of MongoDB yet, you can refer to our tutorial:MongoDB Tutorial。

Install Driver

This tutorial uses theTaobao-customized cnpm commandto install:

$ cnpm install mongodb

After successful installation, we can use the MongoClient object to connect to the database:

Example

const { MongoClient } = require('mongodb');

async function main() {
    // MongoDB connection URI
    const uri = "mongodb://localhost:27017"; // If you are using a remote MongoDB, please change the URI accordingly

    // Create a new MongoClient
    const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true });

    try {
        // Connect to the MongoDB server
        await client.connect();

        console.log("Connected successfully to server");

     
    } finally {
        // Make sure to close the connection when finished
        await client.close();
    }
}

main().catch(console.error);

Executing the above code produces the following output:

Connected successfully to server

Connection parameter description:

  • MongoClient: This is the MongoDB client, used to connect to the database.
  • uri: This is the MongoDB connection string, in the formatmongodb://[username:password@]host1[:port1][,...hostN[:portN]][/[defaultauthdb][?options]]。
  • useNewUrlParser 和 useUnifiedTopologyare some options used to avoid some old connection behaviors.

Next, we will implement the create, read, update, and delete (CRUD) functions.

Create Database

To create a database in MongoDB, we first need to create a MongoClient object, then configure the specified URL and port number.

If the database does not exist, MongoDB will create the database and establish the connection.

Create Connection

const { MongoClient } = require('mongodb'); async function main() { //MongoDB connection URI const uri = "mongodb://localhost:27017"; //Please modify it according to your MongoDB server address //Create a new MongoClient const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //Connect to the MongoDB server await client.connect(); console.log("Successfully connected to the server"); //Specify the database const database = client.db('runoob'); //Here you can perform database operations, such as creating a collection or inserting documents const collection = database.collection('exampleCollection'); const doc = { name: "Example", type: "Test" }; const result = await collection.insertOne(doc); console.log(`New document created,IDis: ${result.insertedId}`); } finally { //Make sure to close the connection when finished await client.close(); } } main().catch(console.error);

Query Data

You can use find() to search for data. find() can return all data matching the conditions. If no conditions are specified, find() returns all data in the collection.

find()

const { MongoClient } = require('mongodb'); async function main() { //MongoDB connection URI const uri = "mongodb://localhost:27017"; //Please modify it according to your MongoDB server address //Create a new MongoClient const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //Connect to the MongoDB server await client.connect(); console.log("Successfully connected to the server"); //Specify the database const database = client.db('runoob'); //Use the createCollection method to create a collection const collectionName = 'exampleCollection'; await database.createCollection(collectionName); console.log(`Collection ${collectionName}created successfully`); //Get the collection const collection = database.collection(collectionName); //Create multiple new documents const docs = [ { name: "Alice", age: 25, address: "Wonderland" }, { name: "Bob", age: 30, address: "Builderland" }, { name: "Charlie", age: 35, address: "Chocolate Factory" } ]; //Insert multiple documents into the collection const result = await collection.insertMany(docs); console.log(`${result.insertedCount}new documents created,IDis:`); Object.keys(result.insertedIds).forEach((id, index) => { console.log(`Document ${index + 1}: ${id}`); }); //Query all documents in the collection const query = {}; //An empty query object means query all documents const options = { projection: { _id: 0, name: 1, age: 1, address: 1 } }; //Only select the required fields const cursor = collection.find(query, options); //Print all queried documents const allValues = await cursor.toArray(); console.log("Queried documents:"); console.log(allValues); } finally { //Make sure to close the connection when finished await client.close(); } } main().catch(console.error);

Sort

Sorting uses the sort() method, which accepts one parameter to specify whether the order is ascending (1) or descending (-1).

For example:

{ type: 1 }  // 按 type 字段升序
{ type: -1 } // 按 type 字段降序

Connection Operation

mongoDB is not a relational database, but we can use$lookupto implement left join.

$lookup is an aggregation pipeline operator in MongoDB used to perform left outer joins. It can be used to find documents in one collection that match the conditions in another collection and merge them together.

For example, we have two collections with data as follows:

Collection 1: orders

[
  { "_id": 1, "product_id": 101, "quantity": 2 },
  { "_id": 2, "product_id": 102, "quantity": 1 },
  { "_id": 3, "product_id": 103, "quantity": 4 }
]

Collection 2: products

[
  { "_id": 101, "name": "Product A", "price": 50 },
  { "_id": 102, "name": "Product B", "price": 70 },
  { "_id": 103, "name": "Product C", "price": 100 },
  { "_id": 104, "name": "Product D", "price": 120 }
]

Now we want to use the $lookup operation to associate the product_id field in the orders collection with the _id field in the products collection, and obtain detailed product information for each order.

The following is a MongoDB aggregation example that implements this functionality:

Example

const { MongoClient } = require('mongodb'); async function main() { //MongoDB connection URI const uri = "mongodb://localhost:27017"; //Please modify it according to your MongoDB server address //Create a new MongoClient const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //Connect to the MongoDB server await client.connect(); console.log("Successfully connected to the server"); //Specify the database const database = client.db('mydatabase'); //orders collection const ordersCollection = database.collection('orders'); //products collection const productsCollection = database.collection('products'); //Define the aggregation pipeline and use $lookup to perform a left outer join const pipeline = [ { $lookup: { from: 'products', //The name of the collection to join localField: 'product_id', //The field from the local collection to match foreignField: '_id', //The field from the joined collection to match as: 'productDetails' //The field name to include in the output results } } ]; //Execute the aggregation operation const result = await ordersCollection.aggregate(pipeline).toArray(); //Output the query results console.log("Left outer join query results:"); console.log(result); } finally { //Make sure to close the connection when finished await client.close(); } } main().catch(console.error);

If you don't understand Promise yet, you can refer toJavaScript Promise。

const { MongoClient } = require('mongodb'); //MongoDB connection URI const uri = "mongodb://localhost:27017"; //Please modify it according to your MongoDB server address //Create a new MongoClient const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); //Use Promise to wrap the process of connecting to the database function connectDB() { return new Promise((resolve, reject) => { //Connect to the MongoDB server client.connect((err) => { if (err) { reject(err); } else { console.log("Successfully connected to the MongoDB server"); resolve(client.db()); //Return the database instance } }); }); } //Usage example connectDB() .then(database => { //You can continue to perform database operations here console.log("Successfully connected to the database"); //Example: Output the name of the database console.log("Database name:", database.databaseName); //If you need to perform other operations, you can continue writing code here //For example, querying, inserting documents, etc. //Finally, close the connection client.close(); }) .catch(err => { console.error("An error occurred while connecting to the database:", err); });

Promise Data Operations

Now let's implement four consecutive operations in one program: add, query, update, and delete.

Example

//Use Promise to wrap the process of connecting to the database function connectDB() { return new Promise((resolve, reject) => { //Connect to the MongoDB server client.connect((err) => { if (err) { reject(err); } else { console.log("Successfully connected to the MongoDB server"); resolve(client.db()); //Return the database instance } }); }); } //Function to add a document function insertDocument(db, document) { const collection = db.collection('documents'); return new Promise((resolve, reject) => { collection.insertOne(document, (err, result) => { if (err) { reject(err); } else { console.log("Document added successfully"); resolve(result); } }); }); } //Function to query documents function findDocuments(db) { const collection = db.collection('documents'); return new Promise((resolve, reject) => { collection.find({}).toArray((err, docs) => { if (err) { reject(err); } else { console.log("Query documents result:"); console.log(docs); resolve(docs); } }); }); } //Function to update a document function updateDocument(db, id, updatedValues) { const collection = db.collection('documents'); return new Promise((resolve, reject) => { collection.updateOne({ _id: ObjectId(id) }, { $set: updatedValues }, (err, result) => { if (err) { reject(err); } else { console.log("Document updated successfully"); resolve(result); } }); }); } //Function to delete a document function deleteDocument(db, id) { const collection = db.collection('documents'); return new Promise((resolve, reject) => { collection.deleteOne({ _id: ObjectId(id) }, (err, result) => { if (err) { reject(err); } else { console.log("Document deleted successfully"); resolve(result); } }); }); } //Usage example: Perform add, query, update, and delete operations sequentially async function performOperations() { try { const database = await connectDB(); //Add document const insertResult = await insertDocument(database, { name: "Document 1" }); //Query documents const findResult = await findDocuments(database); //Update document const updatedDocId = insertResult.insertedId; //Use the ID returned when inserting the document to update const updateResult = await updateDocument(database, updatedDocId, { name: "Updated Document 1" }); //Delete document const deleteResult = await deleteDocument(database, updatedDocId); //Output operation results console.log("Final operation completed:"); console.log("Delete document result:", deleteResult); } catch (err) { console.error("An error occurred while performing the operation:", err); } finally { //Make sure to close the connection when finished await client.close(); } } //Execute the operation performOperations();
