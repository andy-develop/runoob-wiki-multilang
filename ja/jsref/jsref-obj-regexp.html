JavaScript RegExpオブジェクト

RegExp オブジェクト

正規表現は文字パターンを記述するオブジェクトです。

正規表現は、文字列のパターン照合、検索、置換に使用され、文字列に対してパターンマッチングを実行する強力なツールです。

構文

var patt=new RegExp(pattern,modifiers);

またはより簡単な方法:

var patt=/pattern/modifiers;
  • pattern (パターン) は式のパターンを記述します。
  • modifiers (修飾子) は、グローバルマッチ、大文字と小文字を区別するマッチ、複数行マッチを指定するために使用します。

注意：コンストラクタを使って正規表現オブジェクトを作成する場合は、通常の文字エスケープ規則（前にバックスラッシュ \ を付ける）が必要です。例えば、次は同等です：

var re = new RegExp("\\w+");
var re = /\w+/;

RegExp オブジェクトの詳細については、私たちのJavaScript RegExp オブジェクトチュートリアル。

修飾子

修飾子は、大文字と小文字の区別やグローバルマッチを実行するために使用します：

修飾子 説明
i 大文字と小文字を区別しないマッチを実行します。
g グローバルマッチを実行します（最初のマッチで停止するのではなく、すべてのマッチを検索します）。
m 複数行のマッチを実行します。

角括弧

角括弧は、特定の範囲内の文字を検索するために使用します：

式 説明
[abc] 角括弧内の任意の文字を検索します。
[^abc] 角括弧内にない任意の文字を検索します。
[0-9] 0 から 9 までの任意の数字を検索します。
[a-z] 小文字の a から小文字の z までの任意の文字を検索します。
[A-Z] 大文字の A から大文字の Z までの任意の文字を検索します。
[A-z] 大文字の A から小文字の z までの任意の文字を検索します。
[adgk] 指定された集合内の任意の文字を検索します。
[^adgk] 指定された集合外の任意の文字を検索します。
(red|blue|green) 指定されたオプションのいずれかを検索します。

メタ文字

メタ文字（Metacharacter）は特別な意味を持つ文字です：

メタ文字 説明
. 改行と行終端子以外の単一文字を検索します。
\w 数字、文字、アンダースコアを検索します。
\W 単語以外の文字を検索します。
\d 数字を検索します。
\D 数字以外の文字を検索します。
\s 空白文字を検索します。
\S 空白以外の文字を検索します。
\b 単語の境界にマッチします。
\B 単語の境界以外にマッチします。
\0 NULL 文字を検索します。
\n 改行文字を検索します。
\f 改ページ文字を検索します。
\r キャリッジリターン文字（復帰文字）を検索します。
\t タブ文字を検索します。
\v 垂直タブ文字を検索します。
\xxx 8進数 xxx で指定された文字を検索します。
\xdd 16進数 dd で指定された文字を検索します。
\uxxxx 16進数 xxxx で指定された Unicode 文字を検索します。

量指定子

量指定子 説明
n+

少なくとも1つの n を含む任意の文字列にマッチします。

例えば、/a+/ は "candy" の "a"、"caaaaaaandy" のすべての "a" にマッチします。
n*

0個以上の n を含む任意の文字列にマッチします。

例えば、/bo*/ は "A ghost booooed" の "boooo"、"A bird warbled" の "b" にマッチしますが、"A goat grunted" にはマッチしません。
n?

0個または1個の n を含む任意の文字列にマッチします。

例えば、/e?le?/ は "angel" の "el"、"angle" の "le" にマッチします。
n{X}

X 個の n のシーケンスを含む文字列にマッチします。

例えば、/a{2}/ は "candy," の "a" にはマッチしませんが、"caandy," の2つの "a" にはマッチし、"caaandy." の最初の2つの "a" にもマッチします。
n{X,}

X は正の整数です。直前のパターン n が少なくとも X 回連続して現れる場合にマッチします。

例えば、/a{2,}/ は "candy" の "a" にはマッチしませんが、"caandy" と "caaaaaaandy." のすべての "a" にマッチします。
n{X,Y}

X と Y は正の整数です。直前のパターン n が少なくとも X 回、最大で Y 回連続して現れる場合にマッチします。

例えば、/a{1,3}/ は "cndy" にはマッチしません。"candy," の "a"、"caandy," の2つの "a"、"caaaaaaandy" の最初の3つの "a" にマッチします。なお、"caaaaaaandy" にマッチする場合、元の文字列にそれ以上の "a" が含まれていても、マッチ結果は "aaa" です。
n$ 末尾が n である任意の文字列にマッチします。
^n 先頭が n である任意の文字列にマッチします。
?=n 指定された文字列 n が直後に続く任意の文字列にマッチします。
?!n 指定された文字列 n が直後に続かない任意の文字列にマッチします。
