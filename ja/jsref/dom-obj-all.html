HTML DOM 要素オブジェクト

HTML DOM ノード

HTML DOM（Document Object Model）では、すべてのものはノードです:

  • ドキュメント自体がドキュメントオブジェクトです
  • すべてのHTML要素は要素ノードです
  • すべてのHTML属性は属性ノードです
  • HTML要素に挿入されたテキストはテキストノードです
  • コメントはコメントノードです

要素オブジェクト

HTML DOMでは、要素オブジェクトはHTML要素を表します。

要素オブジェクトの子ノードには、要素ノード、テキストノード、コメントノードがあります。

NodeList オブジェクトノードのリストを表し、HTML要素の子ノードの集合に似ています。

要素は属性を持つことができます。属性は属性ノードに属します（次の章を参照してください）。

ブラウザサポート

すべての主要ブラウザは要素オブジェクトとNodeListオブジェクトをサポートしています。

element.getAttributeNode() 指定した属性ノードを返します
element.getElementsByTagName() 指定したタグ名を持つすべての子要素のコレクションを返します。

element.id 要素のidを設定または返します。
element.innerHTML 要素の内容を設定または返します。

element.isDefaultNamespace() namespaceURIが指定されている場合はtrueを返し、それ以外の場合はfalseを返します。
element.isEqualNode() 2つの要素が等しいかどうかを確認します

element.namespaceURI 名前空間のURIを返します。

element.nodeType 要素のノードタイプを返します
element.nodeValue 要素のノード値を返します

element.offsetHeight 要素の高さを返します。ボーダーとパディングを含みますが、マージンは含みません。
element.offsetWidth 要素の幅を返します。ボーダーとパディングを含みますが、マージンは含みません。
element.offsetLeft 現在の要素の相対的な水平オフセット位置を持つオフセットコンテナを返します
element.offsetParent 要素のオフセットコンテナを返します
element.offsetTop 現在の要素の相対的な垂直オフセット位置を持つオフセットコンテナを返します
element.ownerDocument 要素のルート要素（ドキュメントオブジェクト）を返します
element.parentNode 要素の親ノードを返します
element.previousSibling ある要素の直前にある要素を返します
element.previousElementSibling 指定した要素の前の兄弟要素（同じノードツリー階層内の前の要素ノード）を返します。
element.querySelector() 指定したCSSセレクタに一致する要素の最初の子要素を返します
document.querySelectorAll() 指定したCSSセレクタに一致する要素のすべての子要素ノードのリストを返します
element.removeAttribute() 要素から指定した属性を削除します
element.removeAttributeNode() 指定した属性ノードを削除し、削除後のノードを返します。
element.removeChild() 子要素を削除します
element.removeEventListener() addEventListener() メソッドで追加されたイベントハンドラを削除します
element.replaceChild() 子要素を置き換えます
element.scrollHeight 要素全体の高さを返します（スクロールバーのある隠れた部分を含む）
element.scrollLeft 現在のビュー内の実際の要素の左端と左端の間の距離を返します
element.scrollTop 現在のビュー内の実際の要素の上端と上端の間の距離を返します
element.scrollWidth 要素全体の幅を返します（スクロールバーのある隠れた部分を含む）
element.setAttribute() 指定した属性を設定または変更し、値を指定します。
element.setAttributeNode() 指定した属性ノードを設定または変更します。
element.setIdAttribute()
element.setIdAttributeNode()
element.setUserData() 要素内で指定したキーと値に関連するオブジェクトを設定します。
element.style 要素のスタイルプロパティを設定または返します
element.tabIndex 要素のタブ順序を設定または返します。
element.tagName 要素のタグ名を文字列として返します（大文字）
element.textContent ノードとそのテキストコンテンツを設定または返します
element.title 要素のtitle属性を設定または返します
element.toString() 要素を文字列に変換します
nodelist.item() ドキュメントツリーに基づく要素のインデックスを返します
nodelist.length ノードリストのノード数を返します。
