アダプターパターン

アダプターパターン（Adapter Pattern）は、互換性のない2つのインターフェース間の橋渡し役を担う構造型デザインパターンです。仲介役（アダプター）を通じて、あるクラスのインターフェースをクライアントが期待する別のインターフェースに変換し、元々一緒に動作できなかったクラスが連携して動作できるようにします。

このパターンは単一のクラスを含み、そのクラスは独立した、または互換性のないインターフェース機能を追加する役割を担います。実際の例を挙げると、カードリーダーはメモリーカードとノートパソコンの間のアダプターとして機能します。メモリーカードをカードリーダーに挿入し、カードリーダーをノートパソコンに挿入することで、ノートパソコンを通じてメモリーカードを読み取ることができます。

MP3ファイルしか再生できないオーディオプレーヤーがあるとします。VLCファイルとMP4ファイルを再生する必要がある場合、アダプターを作成することで実現できます：

  • ターゲットインターフェース：複数の形式のファイルを再生できるオーディオプレーヤーインターフェースを定義します。
  • アダプティクラス：既存のオーディオプレーヤーであり、MP3ファイルのみ再生できます。
  • アダプタークラス：新しいクラスを作成し、ターゲットインターフェースを実装して、内部でアダプティクラスを使用してMP3ファイルを再生し、同時にVLCおよびMP4ファイルのサポートを追加します。

概要

アダプターパターンは、異なるインターフェース間の互換性の問題を解決することを目的としたソフトウェアデザインパターンです。

目的：あるクラスのインターフェースを別のインターフェースに変換し、元々互換性のないクラスが連携して動作できるようにします。

主に解決する問題：ソフトウェアシステムにおいて、既存のオブジェクトを新しい環境に配置する必要があるが、新しい環境が要求するインターフェースが既存のオブジェクトと一致しない場合。

使用シーン

  • 既存のクラスを使用する必要があるが、そのインターフェースがシステムの要件を満たしていない場合。
  • 再利用可能なクラスを作成し、複数の無関係なクラス（将来導入される可能性のあるクラスを含む）と連携させたい場合。これらのクラスには統一されたインターフェースがない可能性があります。
  • インターフェース変換を通じて、あるクラスを別のクラス体系に統合します。

実装方法

  • 継承または依存：柔軟性を保つために、継承ではなく依存関係を使用することを推奨します。

主要コード

アダプターは既存のオブジェクトを継承または依存し、必要なターゲットインターフェースを実装します。

応用例

  • 電圧アダプター：110Vを220Vに変換して、さまざまな国の電気製品の規格に適合させます。
  • インターフェース変換：例えば、Java JDK 1.1 の Enumeration インターフェースを 1.2 の Iterator インターフェースに変換します。
  • クロスプラットフォーム実行：Linux上でWindowsプログラムを実行します。
  • データベース接続：JavaのJDBCは、アダプターパターンを通じてさまざまなタイプのデータベースと連携します。

利点

  • 直接的な関連のないクラス間の連携を促進します。
  • クラスの再利用性を高めます。
  • クラスの透過性を高めます。
  • 優れた柔軟性を提供します。

欠点

  • アダプターを過度に使用すると、システム構造が混乱し、理解や保守が困難になる可能性があります。
  • Javaでは、継承できるクラスが1つだけであるため、適合できるクラスも1つだけであり、ターゲットクラスは抽象クラスでなければなりません。

使用上のアドバイス

  • アダプターパターンは慎重に使用する必要があります。特に詳細設計段階では、既存システムの問題を解決するために主に使用されます。
  • 正常に動作しているシステムのインターフェースを変更することを検討している場合、アダプターパターンは適切な選択です。

このようにして、アダプターパターンは中核となる概念と応用を明確に表現でき、不必要な複雑さを回避できます。

構造

アダプターパターンには、以下の主要な役割が含まれます：

  • ターゲットインターフェース（Target）：クライアントが必要とするインターフェースを定義します。
  • アダプティクラス（Adaptee）：適合が必要な既存のインターフェースを定義します。
  • アダプタークラス（Adapter）：ターゲットインターフェースを実装し、コンポジションまたは継承の方法でアダプティクラスのメソッドを呼び出し、ターゲットインターフェースを実現します。

実装

私たちは...を持っていますMediaPlayerインターフェースと、それを実装したMediaPlayerインターフェースのエンティティクラスAudioPlayer。デフォルトでは、AudioPlayermp3形式のオーディオファイルを再生できます。

私たちはもう一つのインターフェースも持っていますAdvancedMediaPlayerと、それを実装したAdvancedMediaPlayerインターフェースのエンティティクラス。このクラスは vlc および mp4 形式のファイルを再生できます。

    例を共有します：ノートパソコンがカードリーダーを通じてTFカードを読み取ります；

    1. まず、コンピューターがSDカードを読み取ることをシミュレートします：

    1. まずSDカードのインターフェースを作成します：

    public interface SDCard {
    //读取SD卡方法
    String readSD();
    //写入SD卡功能
    int writeSD(String msg);
}

    2. SDカードインターフェースを実装するクラスを作成し、SDカードの機能をシミュレートします：

    public class SDCardImpl implements SDCard {
    @Override    
    public String readSD() {
        String msg = "sdcard read a msg :hello word SD";
        return msg;  
    }
    @Override  
    public int writeSD(String msg) {      
        System.out.println("sd card write msg : " + msg);    
        return 1;   
    }
}

    3. コンピューターインターフェースを作成し、コンピューターにSDカードを読み取るメソッドを提供させます：

    public interface Computer {    
    String readSD(SDCard sdCard);
}

    4. コンピューターインスタンスを作成し、コンピューターインターフェースを実装して、そのSDカード読み取りメソッドを実装します：

    public class ThinkpadComputer implements Computer {
    @Override    
    public String readSD(SDCard sdCard) {        
        if(sdCard == null)throw new NullPointerException("sd card null");        
        return sdCard.readSD();    
    }
}

    5. これでコンピューターがSDカードを読み取る機能をシミュレートできます：

    public class ComputerReadDemo {    
    public static void main(String[] args) {        
        Computer computer = new ThinkpadComputer();        
        SDCard sdCard = new SDCardImpl();       
        System.out.println(computer.readSD(sdCard));    
    }
}

    2. 次に、コンピューターのSDカード読み取りインターフェースを変更せずに、アダプターパターンを使用してTFカードを読み取ります：

    1. TFカードのインターフェースを作成します：

    public interface TFCard {    
    String readTF();    
    int writeTF(String msg);
}

    2. TFカードのインスタンスを作成します：

    public class TFCardImpl implements TFCard {    
    @Override    
    public String readTF() {        
        String msg ="tf card reade msg : hello word tf card";        
        return msg;    
    }    
    @Override    
    public int writeTF(String msg) {        
        System.out.println("tf card write a msg : " + msg);        
        return 1;    
    }
}

    3. SDをTFに適合させるものを作成します（SDがTFと互換性があるとも言えます。カードリーダーに相当します）：

    SDCardインターフェースを実装し、適合させる対象のオブジェクトをアダプターのプロパティとして導入します。

    public class SDAdapterTF implements SDCard {    
    private TFCard tfCard;    
    public SDAdapterTF(TFCard tfCard) {        
        this.tfCard = tfCard;    
    }    
    @Override    
    public String readSD() {        
        System.out.println("adapter read tf card ");        
        return tfCard.readTF();    
    }    
    @Override    
    public int writeSD(String msg) {        
        System.out.println("adapter write tf card");        
        return tfCard.writeTF(msg);    
    }
}

struct MediaAdapter: MediaPlayer {
    let advancedMusicPlayer: AdvancedMediaPlayer

    init(audioType: AudioType) {
        if audioType == .mp4 {
            advancedMusicPlayer = MP4Player()
        } else {
            advancedMusicPlayer = VlcPlayer()
        }
    }

    func play(_ type: AudioType, fileName: String) {
        if type == .mp4 {
            advancedMusicPlayer.playMP4(fileName: fileName)
        } else {
            advancedMusicPlayer.playVlc(fileName: fileName)
        }
    }
}

class AudioPlayer: MediaPlayer {
    var mediaAdapter: MediaAdapter?
    func play(_ type: AudioType, fileName: String) {
        if type == .mp3 {
            print("Play mp3 file. Name:", fileName)
        } else  {
            mediaAdapter = MediaAdapter(audioType: type)
            mediaAdapter?.play(type, fileName: fileName)
        }
    }

    func play(_ type: String, fileName: String) {
        if let type = AudioType(rawValue: type) {
            play(type, fileName: fileName)
        } else {
            print("Invalid media.\(fileName) not supported.")
        }
    }
}

    #Adapter Pattern with Python Code
from abc import abstractmethod,ABCMeta

# 为媒体播放器和更高级的媒体播放器创建接口
class MediaPlayer(metaclass=ABCMeta):
    @abstractmethod
    def play(self, strAudioType, strFilename):
        pass
class AdvancedMediaPlayer(metaclass=ABCMeta):
    @abstractmethod
    def playVlc(self,strFilename):
        pass
    @abstractmethod
    def playMp4(self,strFilename):
        pass

# 实现AdvancedMediaPlayer接口的实体类
class VlcPlayer(AdvancedMediaPlayer):
    def playVlc(self,strFilename):
        print("Playing vlc file. Name: "+strFilename)
    def playMp4(self,strFilename):
        pass
class Mp4Player(AdvancedMediaPlayer):
    def playVlc(self,strFilename):
        pass
    def playMp4(self,strFilename):
        print("Playing MP4 file. Name: " + strFilename)

# 实现MediaPlayer的MediaAdapter实体类
class MediaAdapter(MediaPlayer):
    advancedMusicPlayer = None

    def __init__(self,strAudioType):
        strAudioType = str.lower(strAudioType)
        if strAudioType == "vlc" :
            self.advancedMusicPlayer = VlcPlayer()
        elif strAudioType == "mp4" :
            self.advancedMusicPlayer = Mp4Player()
    def play(self,strAudioType,strFilename):
        if strAudioType == "vlc" :
            self.advancedMusicPlayer.playVlc(strFilename)
        elif strAudioType == "mp4" :
            self.advancedMusicPlayer.playMp4(strFilename)

# 实现MediaPlayer的AudiPlayer实体类
class AudioPlayer(MediaPlayer):
    mediaAdapter = None
    def play(self,strAudioType,strFilename):
        strAudioType = str.lower(strAudioType)
        # 播放MP3音乐文件
        if strAudioType == "mp3" :
            print("Playing mp3 file. Name: "+ strFilename)
        elif (strAudioType == "vlc") or (strAudioType == "mp4") :
            self.mediaAdapter = MediaAdapter(strAudioType)
            self.mediaAdapter.play(strAudioType,strFilename)
        else :
            print("Invalid media. "+ strAudioType + " format not supported.")

# 调用输出

};

    string storage; // TF卡的存储空间
public:
    TFCard() {}
    string read() { return storage; }
    void write(const string& s) { storage = s; }
};
// @brief TF转SD卡适配器
class SDAdapterTF : public SD
{
private:
    shared_ptr<TF> tf_slot; // TF卡插槽
public:
    void insertTF(const shared_ptr<TF>& tf) { tf_slot = tf; }
    string read() { if (tf_slot != nullptr) { return tf_slot->read(); } else { return (string)"[no tf card]"; } }
    void write(const string& s) { if (tf_slot != nullptr) { tf_slot->write(s); } }
};

// main 中执行
void demo()
{
    // 计算机读写SD卡demo
    shared_ptr<SD> sd(new SDCard());// 新建SD卡
    shared_ptr<Computer> pc(new HuaWeiComputer());// 新建电脑
    cout << "[1] " << pc->readSD() << endl; // 控制台输出：[1] [no sd card]
    pc->insertSD(sd);// TF卡插入电脑
    pc->writeSD("写入SD卡一些东西");
    cout << "[2] " << pc->readSD() << endl;  // 控制台输出：[2] 写入SD卡一些东西
    // 计算机通过适配器读写TF卡demo
    shared_ptr<TF> tf(new TFCard());
    shared_ptr<SDAdapterTF> adaptr(new SDAdapterTF()); // 新建一个适配器
    pc->insertSD((shared_ptr<SD>)adaptr);// 适配器插入电脑
    cout << "[3] " << pc->readSD() << endl; // 控制台输出：[3] [no tf card]
    adaptr->insertTF(tf);// TF卡插入适配器
    pc->writeSD("写入TF卡一些东西");
    cout << "[4] " << pc->readSD() << endl; // 控制台输出：[4] 写入TF卡一些东西
}
