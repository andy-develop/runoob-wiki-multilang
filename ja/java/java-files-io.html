Java ストリーム(Stream)、ファイル(File)とIO

Javaにおけるストリーム（Stream）、ファイル（File）、IO（入出力）はデータの読み書きを処理する基盤であり、プログラムが外部データ（ファイル、ネットワーク、システム入力など）とやり取りすることを可能にします。

java.ioパッケージはJava標準ライブラリの中核となるパッケージであり、システムの入出力に使用するクラスを提供します。データストリーム（バイトストリームと文字ストリーム）の処理、ファイルの読み書き、シリアル化、データフォーマットのユーティリティが含まれます。

java.ioはファイル操作、ストリーム操作、低レベルIO操作を処理するための基本パッケージです。

java.ioパッケージのストリームは、基本型、オブジェクト、ローカライズされた文字セットなど、多くの形式に対応しています。

ストリームはデータの並びと理解できます。入力ストリームはソースからデータを読み取ることを表し、出力ストリームはターゲットへデータを書き込むことを表します。

コンソール入力の読み取り

Javaのコンソール入力はSystem.inによって行われます。

コンソールにバインドされた文字ストリームを取得するには、System.inをBufferedReaderオブジェクトでラップして文字ストリームを作成できます。

以下はBufferedReaderを作成する基本構文です：

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

BufferedReaderオブジェクトを作成すると、read()メソッドを使用してコンソールから1文字を読み取ったり、readLine()メソッドを使用して文字列を読み取ったりできます。

コンソールから複数文字の入力を読み取る

BufferedReaderオブジェクトから1文字を読み取るにはread()メソッドを使用します。その構文は次のとおりです：

int read( ) throws IOException

read()メソッドを呼び出すたびに、入力ストリームから1文字を読み取り、その文字を整数値として返します。ストリームの終わりに達すると-1を返します。このメソッドはIOExceptionをスローします。

次のプログラムは、read()メソッドを使用してコンソールからユーザーが入力するまで文字を読み取り続けることを示しています。q。

BRRead.java ファイルコード：

//BufferedReaderを使用してコンソールで文字を読み取る import java.io.*; public class BRRead { public static void main(String[] args) throws IOException { char c; //System.inを使用してBufferedReaderを作成する BufferedReader br = new BufferedReader(new InputStreamReader(System.in)); System.out.println("文字を入力してください。'q'キーを押すと終了します。"); //文字を読み取ります do { c = (char) br.read(); System.out.println(c); } while (c != 'q'); } }

上記の例をコンパイルして実行した結果は次のとおりです：

コンソールから文字列を読み取る

標準入力から文字列を読み取るには、BufferedReaderのreadLine()メソッドを使用する必要があります。

一般的な形式は次のとおりです：

String readLine( ) throws IOException

次のプログラムは、単語"end"を入力するまで文字行を読み取って表示します。

BRReadLines.java ファイルコード：

//BufferedReaderを使用してコンソールで文字を読み取る import java.io.*; public class BRReadLines { public static void main(String[] args) throws IOException { //System.inを使用してBufferedReaderを作成する BufferedReader br = new BufferedReader(new InputStreamReader(System.in)); String str; System.out.println("Enter lines of text."); System.out.println("Enter 'end' to quit."); do { str = br.readLine(); System.out.println(str); } while (!str.equals("end")); } }

上記の例をコンパイルして実行した結果は次のとおりです：

Enter lines of text.
Enter 'end' to quit.
This is line one
This is line one
This is line two
This is line two
end
end

JDK 5以降のバージョンでは、次のクラスも使用できます。Java Scannerクラスを使用してコンソール入力を取得します。

コンソール出力

すでに説明したように、コンソール出力はprint()メソッドとprintln()メソッドによって行われます。これらのメソッドはすべてPrintStreamクラスによって定義されており、System.outはそのクラスのオブジェクトへの参照です。

PrintStreamはOutputStreamクラスを継承し、write()メソッドを実装しています。これにより、write()メソッドを使用してコンソールに書き込むこともできます。

PrintStreamが定義するwrite()の最も簡単な形式は次のとおりです：

void write(int byteval)

このメソッドはbytevalの下位8ビットをストリームに書き込みます。

例

次の例では、write()を使用して文字"A"とそれに続く改行文字を画面に出力します：

WriteDemo.java ファイルコード：

import java.io.*; //System.out.write()のデモ public class WriteDemo { public static void main(String[] args) { int b; b = 'A'; System.out.write(b); System.out.write('\n'); } }

上記の例を実行すると、出力ウィンドウに"A"文字が出力されます。

A

注意：write()メソッドはあまり使用されません。print()メソッドとprintln()メソッドの方がより便利だからです。

補助クラス（その他の重要なクラス）

次に説明する2つの重要なストリームはFileInputStream 和 FileOutputStream。

FileInputStream

このストリームはファイルからデータを読み取るために使用され、そのオブジェクトはキーワード new を使って作成できます。

オブジェクトを作成するための複数のコンストラクタメソッドがあります。

文字列型のファイル名を使用して、ファイルを読み取るための入力ストリームオブジェクトを作成できます：

InputStream f = new FileInputStream("C:/java/hello");

ファイルオブジェクトを使用して、ファイルを読み取るための入力ストリームオブジェクトを作成することもできます。まず File() メソッドを使用してファイルオブジェクトを作成する必要があります：

File f = new File("C:/java/hello"); InputStream in = new FileInputStream(f);

InputStream オブジェクトを作成したら、次のメソッドを使用してストリームを読み取ったり、他のストリーム操作を行ったりできます。

メソッド説明サンプルコード
int read()1バイトのデータを読み取り、戻り値は0から255の間の整数です。ストリームの終わりに達した場合は、-1を返します。int data = inputStream.read();
int read(byte[] b)入力ストリームからバイトを読み取り、バイト配列bに格納し、実際に読み取ったバイト数を返します。ストリームの終わりに達した場合は、-1を返します。byte[] buffer = new byte[1024]; int bytesRead = inputStream.read(buffer);
int read(byte[] b, int off, int len)入力ストリームから最大lenバイトを読み取り、バイト配列b 的 offのオフセット位置に格納し、実際に読み取ったバイト数を返します。ストリームの終わりに達した場合は、-1を返します。byte[] buffer = new byte[1024]; int bytesRead = inputStream.read(buffer, 0, buffer.length);
long skip(long n)入力ストリーム内のnバイトをスキップして破棄し、実際にスキップしたバイト数を返します。long skippedBytes = inputStream.skip(100);
int available()読み取り可能なバイト数を返します（ブロックされません）。int availableBytes = inputStream.available();
void close()入力ストリームを閉じ、そのストリームに関連するすべてのリソースを解放します。inputStream.close();
void mark(int readlimit)ストリーム内の現在位置にマークを設定し、readlimitは読み取り可能なバイト数の上限です。inputStream.mark(1024);
void reset()ストリームを最後にマークした位置に再配置します。マークがない場合やマークが無効な場合は、例外がスローされます。IOException。inputStream.reset();
boolean markSupported()現在の入力ストリームがmark() 和 reset()操作をサポートしているかどうかを確認します。boolean isMarkSupported = inputStream.markSupported();

InputStream 以外にも、他のいくつかの入力ストリームがあります。詳細は以下のリンクを参照してください：

  • ByteArrayInputStream
  • DataInputStream

FileOutputStream

このクラスはファイルを作成し、ファイルにデータを書き込むために使用されます。

出力のためにファイルを開く前にターゲットファイルが存在しない場合、このストリームはそのファイルを作成します。

FileOutputStream オブジェクトを作成するために使用できるコンストラクタメソッドが2つあります。

文字列型のファイル名を使用して出力ストリームオブジェクトを作成します：

OutputStream f = new FileOutputStream("C:/java/hello")

ファイルオブジェクトを使用して、ファイルに書き込むための出力ストリームを作成することもできます。まず File() メソッドを使用してファイルオブジェクトを作成する必要があります：

File f = new File("C:/java/hello"); OutputStream fOut = new FileOutputStream(f);

OutputStream オブジェクトの作成が完了したら、次のメソッドを使用してストリームに書き込んだり、他のストリーム操作を行ったりできます。

メソッド説明サンプルコード
void write(int b)指定されたバイトを出力ストリームに書き込むと、bの下位8ビットがストリームに書き込まれます。outputStream.write(255);
void write(byte[] b)バイト配列b内のすべてのバイトを出力ストリームに書き込みます。byte[] data = "Hello".getBytes(); outputStream.write(data);
void write(byte[] b, int off, int len)バイト配列b内のオフセットoffから始まるlenバイトを出力ストリームに書き込みます。byte[] data = "Hello".getBytes(); outputStream.write(data, 0, data.length);
void flush()出力ストリームをフラッシュし、バッファリングされたすべてのデータを強制的に書き出して、データがすぐにターゲット出力に書き込まれるようにします。outputStream.flush();
void close()出力ストリームを閉じ、そのストリームに関連するすべてのリソースを解放します。閉じた後は書き込めません。outputStream.close();

OutputStream 以外にも、他のいくつかの出力ストリームがあります。詳細は以下のリンクを参照してください：

  • ByteArrayOutputStream
  • DataOutputStream

例

以下は InputStream と OutputStream の使い方を示す例です：

fileStreamTest.java ファイルコード：

import java.io.*; public class fileStreamTest { public static void main(String[] args) { try { byte bWrite[] = { 11, 21, 3, 40, 5 }; OutputStream os = new FileOutputStream("test.txt"); for (int x = 0; x < bWrite.length; x++) { os.write(bWrite[x]); // writes the bytes } os.close(); InputStream is = new FileInputStream("test.txt"); int size = is.available(); for (int i = 0; i < size; i++) { System.out.print((char) is.read() + " "); } is.close(); } catch (IOException e) { System.out.print("Exception"); } } }

上記のプログラムは、まずファイル test.txt を作成し、指定された数値をバイナリ形式でそのファイルに書き込み、同時にコンソールに出力します。

上記のコードはバイナリ書き込みのため、文字化けが発生する可能性があります。以下のコード例を使用して文字化けの問題を解決できます：

fileStreamTest2.java ファイルコード：

//ファイル名: fileStreamTest2.java import java.io.*; public class fileStreamTest2 { public static void main(String[] args) throws IOException { File f = new File("a.txt"); FileOutputStream fop = new FileOutputStream(f); //FileOutputStream オブジェクトを構築します。ファイルが存在しない場合は自動的に新規作成されます。 OutputStreamWriter writer = new OutputStreamWriter(fop, "UTF-8"); //OutputStreamWriter オブジェクトを構築します。パラメータでエンコーディングを指定でき、デフォルトはオペレーティングシステムのデフォルトエンコーディングで、Windows では gbk です。 writer.append("中国語の入力"); //バッファに書き込む writer.append("\r\n"); //改行 writer.append("English"); //バッファをフラッシュしてファイルに書き込みます。この後書き込む内容がもうない場合でも、直接 close しても書き込まれます。 writer.close(); //書き込みストリームを閉じると、同時にバッファの内容がファイルに書き込まれるため、上記はコメントアウトされています。 fop.close(); //出力ストリームを閉じ、システムリソースを解放します。 FileInputStream fip = new FileInputStream(f); //FileInputStream オブジェクトを構築します。 InputStreamReader reader = new InputStreamReader(fip, "UTF-8"); //InputStreamReader オブジェクトを構築します。エンコーディングは書き込み時と同じです。 StringBuffer sb = new StringBuffer(); while (reader.ready()) { sb.append((char) reader.read()); //char に変換して StringBuffer オブジェクトに追加します。 } System.out.println(sb.toString()); reader.close(); //読み取りストリームを閉じます。 fip.close(); //入力ストリームを閉じ、システムリソースを解放します。 } }

Javaにおけるディレクトリ

ディレクトリの作成：

File クラスにはフォルダを作成するために使用できる2つのメソッドがあります：

  • mkdir( )メソッドはフォルダを作成し、成功した場合は true を返し、失敗した場合は false を返します。失敗は、File オブジェクトが指定したパスがすでに存在するか、パス全体がまだ存在しないためにフォルダを作成できないことを示します。
  • mkdirs()メソッドはフォルダとそのすべての親フォルダを作成します。

次の例では、"/tmp/user/java/bin" フォルダを作成します：

CreateDir.java ファイルコード：

import java.io.File; public class CreateDir { public static void main(String[] args) { String dirname = "/tmp/user/java/bin"; File d = new File(dirname); //ディレクトリを作成します d.mkdirs(); } }

上記のコードをコンパイルして実行し、ディレクトリ "/tmp/user/java/bin" を作成します。

注意：Java は UNIX と Windows で、規則に従ってファイルパスの区切り文字を自動的に判別します。Windows 版の Java で区切り文字 (/) を使用しても、パスは正しく解析されます。

ディレクトリの読み取り

ディレクトリは実際には File オブジェクトであり、他のファイルやフォルダを含みます。

File オブジェクトを作成し、それがディレクトリである場合、isDirectory() メソッドを呼び出すと true が返ります。

そのオブジェクトの list() メソッドを呼び出すことで、含まれているファイルとフォルダのリストを取得できます。

次の例は、list() メソッドを使用してフォルダ内の内容を確認する方法を示しています：

DirList.java ファイルコード：

import java.io.File; public class DirList { public static void main(String args[]) { String dirname = "/tmp"; File f1 = new File(dirname); if (f1.isDirectory()) { System.out.println("ディレクトリ" + dirname); String s[] = f1.list(); for (int i = 0; i < s.length; i++) { File f = new File(dirname + "/" + s[i]); if (f.isDirectory()) { System.out.println(s[i] + "はディレクトリです"); } else { System.out.println(s[i] + "はファイルです"); } } } else { System.out.println(dirname + "はディレクトリではありません"); } } }

上記の例をコンパイルして実行した結果は次のとおりです：

目录 /tmp
bin 是一个目录
lib 是一个目录
demo 是一个目录
test.txt 是一个文件
README 是一个文件
index.html 是一个文件
include 是一个目录

ディレクトリまたはファイルの削除

ファイルの削除にはjava.io.File.delete()メソッドを使用できます。

次のコードはディレクトリ/tmp/java/を削除します。ディレクトリを削除するときは、そのディレクトリ内に他のファイルがないことを確認する必要があります。そうしないと削除に失敗します。

テストディレクトリ構造：

/tmp/java/
|-- 1.log

    自分で簡単な小さなプログラムを書いて、特定の長さの音声を編集し、それらをミックスして切り貼りしました。おおまかな考え方は次のとおりです：

    1. FileInputStream を使用して2つの音声を入力します

    2. FileInputStreamのskip(long n)メソッドを使用して、特定のバイト長の音声ファイルをスキップします。例えば、skip(1024*1024*3)を入力すると、音声ファイルの先頭3MBの内容を破棄できます。

    3. 中間の特定の長さの音声ファイルを切り取る：毎回8KBの内容を入力し、countを使用して入力回数を記録し、設定した回数に達したら音声入力を終了します。例えば、2MBの音声を切り取る場合、毎回入力ストリームに8KBの内容を入力するので、1024*2/8回入力する必要があります。

    4. 同じ出力ストリームFileOutputStreamに音声を出力し、ファイルを生成して、音声ミキシングを実現します。

        try
        {

            {

        }
    }

    ディレクトリ内の指定されたタイプのファイルをリストアップする必要がある場合があります。例えば、.java、.txtなどの拡張子のファイルです。Fileクラスの以下の2つのメソッドを使用して、指定されたタイプのファイルをリストアップできます。

    • 1、public String[ ] list(FilenameFilter obj)このメソッドは、文字列の形式でディレクトリ内の指定されたタイプのすべてのファイルを返します。
    • 2、public File[ ] listFile(FilenameFilter obj)このメソッドは、Fileオブジェクトの形式でディレクトリ内の指定されたタイプのすべてのファイルを返します。

    上記2つのメソッドのパラメータFilenameFilterはインターフェースであり、このインターフェースには1つのメソッドがあります：

    public boolean accept(File f,String name);

    Fileオブジェクトfがlistメソッドを呼び出すとき、そのメソッドにFilenameFilterインターフェースを実装したオブジェクトを渡す必要があります。listメソッドの実行時、パラメータobjはインターフェースメソッドaccept(File f,String name)を繰り返しコールバックします。このメソッドのパラメータfは、listを呼び出した現在のディレクトリであり、パラメータnameは現在のディレクトリ内の1つのファイル名にインスタンス化されます。インターフェースメソッドがtrueを返すと、listメソッドは名前がnameであるファイルを返される配列に格納します。

    import java.io.*;

public class Filelei implements FilenameFilter {//此次使用本类作为接口

    /**
     * @param args
     */
    public void f(){
        File f=new File("E:\\Myworkspace\\08\\src");
        String []filename=f.list();//以字符串的形式，先列出当前目录下所有文件看一下（有什么类型的文件）
        for(int i=0;i<filename.length;i++){
            System.out.println(filename[i]);
        }
        System.out.println("********************************");
        String []fname=f.list(this);
        for(int i=0;i<fname.length;i++){
            System.out.println(fname[i]);
        }
        
    }
    public static void main(String[] args) {
        // TODO Auto-generated method stub
        new Filelei().f();
        
    }

    @Override
    public boolean accept(File f, String name) {//重写接口方法
        // TODO Auto-generated method stub
        return name.endsWith(".java");//返回当前目录下以.java结尾的文件
    }
}

    BufferedReaderは同期をサポートしていますが、Scannerはサポートしていません。マルチスレッドプログラムを扱う場合は、BufferedReaderを使用すべきです。

    BufferedReaderはScannerに比べて十分に大きなバッファメモリを持っています。

    ScannerはBufferedReader（8KBバイトバッファ）に比べて非常に少ないバッファ（1KB文字バッファ）しかありませんが、それで十分すぎるほどです。

    BufferedReaderはScannerに比べて少し速いです。なぜなら、Scannerは入力データを解析するのに対し、BufferedReaderは単に文字シーケンスを読み取るだけだからです。

public class Test {
    public static void main(String[] args) {
        File sourcefile = new File("./test.txt");
        File copyfile = new File("./testcopy.txt");
        FileInputStream fileInputStream = null;// 从文件中读数据
        FileOutputStream fileOutputStream = null;// 用于把数据写入文件
        BufferedWriter bufferedWriter = null;// 用于把数据写入文件
        try {
            if (!sourcefile.exists()) {
                sourcefile.createNewFile();
                bufferedWriter = new BufferedWriter(new FileWriter(sourcefile));
                // bufferedwriter 自动追加数据
                String s = new String(" I love Java");

                char bchar[] = s.toCharArray();
                for (int i = 0; i < 5; i++) {
                    // 两种方式往文件中写数据
                    bufferedWriter.write(bchar, 0, bchar.length);
                    bufferedWriter.write(", " + s + "\n");
                }
                // 写完之后才能关闭流,
                bufferedWriter.flush();
                bufferedWriter.close();
            }
            copyfile.createNewFile();
            fileInputStream = new FileInputStream(sourcefile);
            fileOutputStream = new FileOutputStream(copyfile);
            byte b[] = new byte[8192];
            int len = b.length;
            while ((len = fileInputStream.read(b, 0, len)) > 0) {
                fileOutputStream.write(b, 0, len);
                fileOutputStream.flush();
            }
            System.out.println("file copied");
            fileInputStream.close();
            fileOutputStream.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
