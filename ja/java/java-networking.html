Javaネットワークプログラミング

ネットワークプログラミングとは、ネットワークで接続された複数のデバイス（コンピュータ）上で動作するプログラムを作成することです。

java.netパッケージ内のJ2SEのAPIには、低レベルの通信の詳細を提供するクラスとインターフェースが含まれています。これらのクラスとインターフェースを直接使用することで、通信の詳細を気にせずに問題解決に集中できます。

java.netパッケージは、2つの一般的なネットワークプロトコルをサポートしています：

  • TCP：TCP（英語: Transmission Control Protocol、伝送制御プロトコル）は、コネクション指向で信頼性が高く、バイトストリームに基づくトランスポート層の通信プロトコルです。TCP層はIP層の上、アプリケーション層の下に位置する中間層です。TCPは2つのアプリケーション間の信頼性の高い通信を保証します。通常はインターネットプロトコルとして使用され、TCP/IPと呼ばれます。

  • UDP：UDP（英語: User Datagram Protocol、ユーザーデータグラムプロトコル）は、OSIモデルのトランスポート層に位置します。コネクションレス型のプロトコルです。アプリケーション間で送信するデータのデータグラムを提供します。UDPは信頼性に欠け、コネクションレス型プロトコルであるため、アプリケーションは通常、パケットの損失、エラー、重複をある程度許容する必要があります。

このチュートリアルでは、主に次の2つのトピックについて説明します。

  • Socketプログラミング：これは最も広く使用されているネットワーク概念であり、非常に詳細に説明されています。

  • URL処理：この部分は別の章で説明します。ここをクリックして、より詳しく学べます：Java言語でのURL処理。

Socketプログラミング

ソケットはTCPを使用して、2台のコンピュータ間の通信メカニズムを提供します。クライアントプログラムはソケットを作成し、サーバーのソケットへの接続を試みます。

接続が確立されると、サーバーはSocketオブジェクトを作成します。これでクライアントとサーバーはSocketオブジェクトへの書き込みと読み取りによって通信できます。

java.net.Socketクラスはソケットを表し、java.net.ServerSocketクラスはサーバープログラムにクライアントを監視し、クライアントとの接続を確立するメカニズムを提供します。

2台のコンピュータ間でソケットを使用してTCP接続を確立する際に、以下の手順が発生します：

  • サーバーはServerSocketオブジェクトをインスタンス化し、サーバー上のポートを介した通信を表します。

  • サーバーはServerSocketクラスのaccept()メソッドを呼び出します。このメソッドは、クライアントがサーバーの指定されたポートに接続するまで待機し続けます。

  • サーバーが待機している間に、クライアントはサーバー名とポート番号を指定してSocketオブジェクトをインスタンス化し、接続を要求します。

  • Socketクラスのコンストラクタは、クライアントを指定されたサーバーとポート番号に接続しようとします。通信が確立されると、クライアントにサーバーと通信できるSocketオブジェクトが作成されます。

  • サーバー側では、accept()メソッドがサーバー上の新しいソケット参照を返します。このソケットはクライアントのソケットに接続されます。

接続が確立された後、I/Oストリームを使用して通信します。各ソケットには出力ストリームと入力ストリームがあり、クライアントの出力ストリームはサーバーの入力ストリームに接続され、クライアントの入力ストリームはサーバーの出力ストリームに接続されます。

TCPは双方向の通信プロトコルであるため、2つのデータストリームを介して同時にデータを送信できます。以下に、ソケットを実装するための便利なメソッド一式を提供するクラスを示します。

ServerSocketクラスのメソッド

サーバーアプリケーションは、java.net.ServerSocketクラスを使用してポートを取得し、クライアントからのリクエストを監視します。

ServerSocketクラスには4つのコンストラクタがあります：

番号 メソッドの説明
1 public ServerSocket(int port) throws IOException
特定のポートにバインドされたサーバーソケットを作成します。
2 public ServerSocket(int port, int backlog) throws IOException
指定されたバックログを使用してサーバーソケットを作成し、指定されたローカルポート番号にバインドします。
3 public ServerSocket(int port, int backlog, InetAddress address) throws IOException
指定されたポート、リッスンバックログ、バインド先のローカルIPアドレスを使用してサーバーを作成します。
4 public ServerSocket() throws IOException
バインドされていないサーバーソケットを作成します。

バインドされていないサーバーソケットを作成します。ServerSocketコンストラクタが例外をスローしない場合、アプリケーションは指定されたポートへのバインドに成功し、クライアントからのリクエストを監視していることを意味します。

ここにServerSocketクラスの一般的なメソッドをいくつか示します：

番号 メソッドの説明

このソケットがリッスンしているポートを返します。

Socketクラスには5つのコンストラクタがあります。

番号 メソッドの説明
1 public Socket(String host, int port) throws UnknownHostException, IOException.
ストリームソケットを作成し、指定されたホストの指定されたポート番号に接続します。
2 public Socket(InetAddress host, int port) throws IOException
ストリームソケットを作成し、指定されたIPアドレスの指定されたポート番号に接続します。

5 public Socket()
システムのデフォルトタイプのSocketImplを使用して、未接続のソケットを作成します。

Socketコンストラクタが戻ったとき、単にSocketオブジェクトをインスタンス化したわけではなく、実際には指定されたサーバーとポートへの接続を試みます。

Socketクライアントの例

次のGreetingClientはクライアントプログラムです。このプログラムはソケットを介してサーバーに接続し、リクエストを送信して、応答を待ちます。

GreetingClient.java ファイルコード：

//ファイル名 GreetingClient.java import java.net.*; import java.io.*; public class GreetingClient { public static void main(String [] args) { String serverName = args[0]; int port = Integer.parseInt(args[1]); try { System.out.println("ホストに接続：" + serverName + "、ポート番号：" + port); Socket client = new Socket(serverName, port); System.out.println("リモートホストのアドレス：" + client.getRemoteSocketAddress()); OutputStream outToServer = client.getOutputStream(); DataOutputStream out = new DataOutputStream(outToServer); out.writeUTF("Hello from " + client.getLocalSocketAddress()); InputStream inFromServer = client.getInputStream(); DataInputStream in = new DataInputStream(inFromServer); System.out.println("サーバーの応答：" + in.readUTF()); client.close(); }catch(IOException e) { e.printStackTrace(); } } }

Socketサーバーの例

次のGreetingServerプログラムはサーバー側アプリケーションであり、Socketを使用して指定されたポートをリッスンします。

GreetingServer.java ファイルコード：

//ファイル名 GreetingServer.java import java.net.*; import java.io.*; public class GreetingServer extends Thread { private ServerSocket serverSocket; public GreetingServer(int port) throws IOException { serverSocket = new ServerSocket(port); serverSocket.setSoTimeout(10000); } public void run() { while(true) { try { System.out.println("リモート接続を待機中、ポート番号：" + serverSocket.getLocalPort() + "..."); Socket server = serverSocket.accept(); System.out.println("リモートホストのアドレス：" + server.getRemoteSocketAddress()); DataInputStream in = new DataInputStream(server.getInputStream()); System.out.println(in.readUTF()); DataOutputStream out = new DataOutputStream(server.getOutputStream()); out.writeUTF("接続してくれてありがとう：" + server.getLocalSocketAddress() + "\nGoodbye!"); server.close(); }catch(SocketTimeoutException s) { System.out.println("Socket timed out!"); break; }catch(IOException e) { e.printStackTrace(); break; } } } public static void main(String [] args) { int port = Integer.parseInt(args[0]); try { Thread t = new GreetingServer(port); t.run(); }catch(IOException e) { e.printStackTrace(); } } }

上記の2つのJavaファイルのコードをコンパイルし、次のコマンドを実行してサービスを起動します。ポート番号は6066を使用します：

$ javac GreetingServer.java 
$ java GreetingServer 6066
等待远程连接，端口号为：6066...

新しいコマンドウィンドウを開き、上記のコマンドを実行してクライアントを起動します：

$ javac GreetingClient.java 
$ java GreetingClient localhost 6066
连接到主机：localhost ，端口号：6066
远程主机地址：localhost/127.0.0.1:6066
服务器响应： 谢谢连接我：/127.0.0.1:6066
Goodbye!

    Socketの概念：上で既に説明したので、繰り返さない。

    同期と非同期：同期と非同期はアプリケーションとカーネルの相互作用に関するもので、同期とはユーザープロセスがIO操作をトリガーし、IO操作が準備できるかどうかを待つかポーリングして確認することです。一方、非同期とはユーザープロセスがIO操作をトリガーした後、自分の作業を開始し、IO操作が完了したときにIO完了の通知を受け取ることです。

    銀行での引き出しを例にすると：

    同期： 自分で銀行カードを持って銀行に行きお金を引き出す（同期IOを使用する場合、JavaはIOの読み書きを自分で処理する）；

    非同期： 子分に銀行カードを渡して銀行でお金を引き出してもらい、それを渡してもらう（非同期IOを使用する場合、JavaはIOの読み書きをOSに委任し、データバッファのアドレスとサイズをOSに渡す必要がある（銀行カードとパスワード）、OSは非同期IO操作APIをサポートする必要がある）；

    ブロッキングとノンブロッキング：ブロッキングとノンブロッキングは、プロセスがデータにアクセスする際に、IO操作の準備状態に応じて取る異なる方法であり、要するに読み取りまたは書き込み操作メソッドの実装方法です。ブロッキング方式では読み取りまたは書き込み関数はずっと待機しますが、ノンブロッキング方式では読み取りまたは書き込みメソッドはすぐにステータス値を返します。

    銀行での引き出しを例にすると：

    ブロッキング： ATMに並んで引き出し、あなたは待つしかない（ブロッキングIOを使用する場合、Javaの呼び出しは読み書きが完了するまでブロックされ、その後戻ります）；

    ノンブロッキング： 窓口での引き出し、整理券を取り、椅子に座って他のことをする、呼び出し放送があなたに知らせてくれ、順番が来なければ行けない。あなたはロビーマネージャーに何度も順番が来たか尋ねることができ、ロビーマネージャーがまだ来ていないと言ったら行けない（ノンブロッキングIOを使用する場合、読み書きができなければJavaの呼び出しはすぐに戻ります。IOイベントディスパッチャーが読み書き可能を通知したら読み書きを続行し、読み書きが完了するまでループします）。

    1.BIOプログラミング

    Blocking IO： 同期ブロッキングのプログラミング方式。

    BIOプログラミング方式は通常JDK1.4より前のバージョンでよく使われていたプログラミング方式です。プログラミングの実装プロセスは：まずサーバー側でServerSocketを起動してネットワークリクエストを監視し、クライアントがSocketを起動してネットワークリクエストを送信します。デフォルトではServerSocketはこのリクエストを処理するスレッドを1つ作成します。サーバー側に利用可能なスレッドがない場合、クライアントはブロックして待つか拒否されます。

    また、確立された接続は通信プロセス中に同期です。同時実行処理効率は比較的低いです。おおよその構造は次の通りです：

    同期かつブロッキングであり、サーバーの実装パターンは1接続につき1スレッドです。つまりクライアントに接続要求があるとサーバー側は処理のためにスレッドを起動する必要があり、この接続が何もしないと不要なスレッドオーバーヘッドが発生します。もちろんスレッドプール機構で改善できます。

    BIO方式は接続数が比較的少なく固定されたアーキテクチャに適しており、この方式はサーバーリソースへの要求が比較的高く、同時実行はアプリケーション内に限定されます。JDK1.4以前の唯一の選択肢ですが、プログラムは直感的でシンプルで理解しやすいです。

    スレッドプール機構を使用して改善したBIOモデル図は次の通りです：

    2.NIOプログラミング：Unblocking IO（New IO）： 同期ノンブロッキングのプログラミング方式。

    NIO自体はイベント駆動の考え方に基づいて実現されており、主にBIOの大規模同時実行問題を解決しようとしています。NIOはReactorに基づいており、ソケットに読み取り可能なストリームがあるかソケットに書き込み可能な場合、オペレーティングシステムは対応するアプリケーションに通知して処理させ、アプリケーションはストリームをバッファに読み取るかオペレーティングシステムに書き込みます。つまり、この時点では、1つの接続が1つの処理スレッドに対応するのではなく、有効なリクエストが1つのスレッドに対応し、接続にデータがない場合は処理するワーカースレッドはありません。

    NIOの最も重要な点は、接続が作成された後、スレッドを対応させる必要がなく、この接続がマルチプレクサに登録されることです。そのため、すべての接続は1つのスレッドだけで処理できます。このスレッド内のマルチプレクサがポーリングする際に、接続上にリクエストがあることを検出した場合にのみスレッドを起動して処理します。つまり、1リクエスト1スレッドモードです。

    NIOの処理方式では、リクエストが来た場合、スレッドを起動して処理しますが、バックエンドアプリケーションのリソース（JDBC接続など）を待つ可能性があり、実際にはこのスレッドはブロックされます。同時実行が増えると、BIOと同じ問題が発生します。

    3.AIOプログラミング：Asynchronous IO： 非同期ノンブロッキングのプログラミング方式。

    NIOとは異なり、読み書き操作を行う際は、APIのreadまたはwriteメソッドを直接呼び出すだけで済みます。これらの2つのメソッドはどちらも非同期です。読み取り操作については、読み取り可能なストリームがある場合、オペレーティングシステムは読み取り可能なストリームをreadメソッドのバッファに渡し、アプリケーションに通知します。書き込み操作については、オペレーティングシステムがwriteメソッドで渡されたストリームを書き込み終えると、オペレーティングシステムが自らアプリケーションに通知します。つまり、read/writeメソッドはどちらも非同期で、完了後にコールバック関数を自ら呼び出すと理解できます。JDK1.7では、この部分はNIO.2と呼ばれ、主にjava.nio.channelsパッケージの下に以下の4つの非同期チャネルが追加されました：AsynchronousSocketChannel、AsynchronousServerSocketChannel、AsynchronousFileChannel、AsynchronousDatagramChannel

    public class Server {

    public static void main(String[] args) {
        int port = genPort(args);
        
        ServerSocket server = null;
        ExecutorService service = Executors.newFixedThreadPool(50);
        
        try{
            server = new ServerSocket(port);
            System.out.println("server started!");
            while(true){
                Socket socket = server.accept();
                
                service.execute(new Handler(socket));
            }
        }catch(Exception e){
            e.printStackTrace();
        }finally{
            if(server != null){
                try {
                    server.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            server = null;
        }
    }
    
    static class Handler implements Runnable{
        Socket socket = null;
        public Handler(Socket socket){
            this.socket = socket;
        }
        @Override
        public void run() {
            BufferedReader reader = null;
            PrintWriter writer = null;
            try{
                
                reader = new BufferedReader(
                        new InputStreamReader(socket.getInputStream(), "UTF-8"));
                writer = new PrintWriter(
                        new OutputStreamWriter(socket.getOutputStream(), "UTF-8"));
                String readMessage = null;
                while(true){
                    System.out.println("server reading... ");
                    if((readMessage = reader.readLine()) == null){
                        break;
                    }
                    System.out.println(readMessage);
                    writer.println("server recive : " + readMessage);
                    writer.flush();
                }
            }catch(Exception e){
                e.printStackTrace();
            }finally{
                if(socket != null){
                    try {
                        socket.close();
                    } catch (IOException e) {
                        e.printStackTrace();
                    }
                }
                socket = null;
                if(reader != null){
                    try {
                        reader.close();
                    } catch (IOException e) {
                        e.printStackTrace();
                    }
                }
                reader = null;
                if(writer != null){
                    writer.close();
                }
                writer = null;
            }
        }
        
    }
    
    private static int genPort(String[] args){
        if(args.length > 0){
            try{
                return Integer.parseInt(args[0]);
            }catch(NumberFormatException e){
                return 9999;
            }
        }else{
            return 9999;
        }
    }

        int port = 0;
        if(args.length > 2){
            host = args[0];
            port = Integer.parseInt(args[1]);
        }else{
            host = "127.0.0.1";
            port = 9999;
        }
        
        Socket socket = null;
        BufferedReader reader = null;
        PrintWriter writer = null;
        Scanner s = new Scanner(System.in);
        try{
            socket = new Socket(host, port);
            String message = null;
            
            reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), "UTF-8"));
            writer = new PrintWriter(
                    socket.getOutputStream(), true);
            while(true){
                message = s.nextLine();
                if(message.equals("exit")){
                    break;
                }
                writer.println(message);
                writer.flush();
                System.out.println(reader.readLine());
            }
        }catch(Exception e){
            e.printStackTrace();
        }finally{
            if(socket != null){
                try {
                    socket.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            socket = null;
            if(reader != null){
                try {
                    reader.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            reader = null;
            if(writer != null){
                writer.close();
            }
            writer = null;
        }
    }
}
