Java String クラス

文字列はJavaプログラミングで広く利用されています。Javaでは文字列はオブジェクトであり、Javaは文字列を作成・操作するためにStringクラスを提供しています。

文字列の作成

文字列を作成する最も簡単な方法は次のとおりです：

String str = "Runoob";

コード内で文字列定数に遭遇すると、ここでの値は "Runoob、コンパイラはその値を使用して String オブジェクトを作成します。

他のオブジェクトと同様に、キーワードとコンストラクタメソッドを使用して String オブジェクトを作成できます。

コンストラクタを使用して文字列を作成する：

String str2=new String("Runoob");

String で作成された文字列は共通プールに格納され、new で作成された文字列オブジェクトはヒープ上にあります：

String s1 = "Runoob"; //String による直接作成 String s2 = "Runoob"; //String による直接作成 String s3 = s1; //同じ参照 String s4 = new String("Runoob"); //String オブジェクトの作成 String s5 = new String("Runoob"); //String オブジェクトの作成

String クラスには 11 種類のコンストラクタがあり、これらのメソッドは文字列を初期化するための異なるパラメータを提供します。たとえば、文字配列パラメータを提供します：

StringDemo.java のコード：

public class StringDemo{ public static void main(String args[]){ char[] helloArray = { 'r', 'u', 'n', 'o', 'o', 'b'}; String helloString = new String(helloArray); System.out.println( helloString ); } }

上記の例をコンパイルして実行した結果は次のとおりです：

runoob

注意：String クラスは不変です。つまり、String オブジェクトを作成すると、その値は変更できません（詳細はノートの解析を参照してください）。

文字列に多くの変更を加える必要がある場合は、次を使用することを選択する必要があります：StringBuffer & StringBuilder クラス。

文字列の長さ

オブジェクトに関する情報を取得するために使用されるメソッドは、アクセサメソッドと呼ばれます。

String クラスのアクセサメソッドの1つは length() メソッドで、文字列オブジェクトに含まれる文字数を返します。

次のコードを実行すると、len 変数は 14 になります：

StringDemo.java のコード：

public class StringDemo { public static void main(String args[]) { String site = "www.runoob.com"; int len = site.length(); System.out.println( "菜鸟教程のURL長さ：" + len ); } }

上記の例をコンパイルして実行した結果は次のとおりです：

菜鸟教程网址长度 : 14

文字列の連結

String クラスは、2つの文字列を連結するメソッドを提供します：

string1.concat(string2);

string2 を string1 に連結した新しい文字列を返します。文字列定数に対して concat() メソッドを使用することもできます。例：

"我的名字是 ".concat("Runoob");

より一般的なのは、'+' 演算子を使用して文字列を連結することです。例：

"Hello," + " runoob" + "!"

結果は次のとおりです：

"Hello, runoob!"

以下に例を示します：

StringDemo.java のコード：

public class StringDemo { public static void main(String args[]) { String string1 = "菜鸟教程のURL："; System.out.println("1、" + string1 + "www.runoob.com"); } }

上記の例をコンパイルして実行した結果は次のとおりです：

1、菜鸟教程网址：www.runoob.com

フォーマット文字列の作成

ご存知のとおり、フォーマットされた数値を出力するには printf() メソッドと format() メソッドを使用できます。

String クラスは静的メソッド format() を使用して、PrintStream オブジェクトではなく String オブジェクトを返します。

String クラスの静的メソッド format() は、1回限りの印刷出力だけでなく、再利用可能なフォーマット文字列を作成するために使用できます。

次に示すとおりです：

System.out.printf("浮動小数点型変数の値は" + "%f、整数型変数の値は" + "%d、文字列変数の値は" + "is %s", floatVar, intVar, stringVar);

次のように書くこともできます

String fs; fs = String.format("浮動小数点型変数の値は" + "%f、整数型変数の値は" + "%d、文字列変数の値は" + " %s", floatVar, intVar, stringVar);

    length() メソッド、length プロパティと size() メソッドの違い：

    • 1、length() メソッドは文字列に対するもので、文字列の長さを求めるにはその length() メソッドを使います。
    • 2、length プロパティこれは Java の配列に対するもので、配列の長さを求めるにはその length プロパティを使います。
    • 3、Java におけるsize()メソッドはジェネリックコレクションに対するもので、このジェネリックにいくつの要素があるかを見たい場合は、このメソッドを呼び出して確認します。

    この例は、これら2つのメソッドと1つのプロパティの使い方を示しています。

    import java.util.ArrayList;
import java.util.List;

public class Main {

    public static void main(String[] args) {
        String array[] = { "First", "Second", "Third" };
        String a = "HelloWorld";
        List<String> list = new ArrayList<String>();
        list.add(a);
        System.out.println("数组array的长度为" + array.length);
        System.out.println("字符串a的长度为" + a.length());
        System.out.println("list中元素个数为" + list.size());

    }
}

    出力される値は：

    数组array的长度为3
字符串a的长度为10
list中元素个数为1

    1. 整数をフォーマットする：%[index$][フラグ][最小幅]変換方式

    フォーマット文字列は4つの部分から構成されます。特別な形式は通常 %index$ で始まり、index は1から始まり、第 index 番目のパラメータをフォーマット対象として取り込むことを示します。[最小幅]の意味も理解しやすいです。つまり、最終的にその整数が変換された文字列が最低限含む桁数を示します。残り2つの部分の意味は次のとおりです：

    フラグ：

    • '-' 最小幅内で左揃えになります。"0で埋める"とは同時に使用できません。
    • '#' は8進数と16進数にのみ適用されます。8進数の場合は結果の前に0を付け、16進数の場合は結果の前に0xを付けます。
    • '+' 結果は常に符号を含みます（通常は10進数にのみ適用されます。オブジェクトが BigInteger の場合のみ8進数と16進数にも使用できます）。
    • ' ' 正の値の前にはスペースを付け、負の値の前にはマイナス記号を付けます（通常は10進数にのみ適用されます。オブジェクトが BigInteger の場合のみ8進数と16進数にも使用できます）。
    • '0' 結果はゼロで埋められます。
    • ',' は10進数にのみ適用され、3桁ごとに「,」で区切ります。
    • '(' パラメータが負の数の場合、結果にマイナス記号を付けず、代わりに数字を丸括弧で囲みます（'+'と同じ制限があります）。

    変換方式：

    d-10進数 o-8進数 xまたはX-16進数

    上記の説明は退屈すぎるので、具体的な例をいくつか見てみましょう。特に注意すべき点は、ほとんどのフラグ文字を同時に使用できることです。

    System.out.println(String.format("%1$,09d", -3123));
System.out.println(String.format("%1$9d", -31));
System.out.println(String.format("%1$-9d", -31));
System.out.println(String.format("%1$(9d", -31));
System.out.println(String.format("%1$#9x", 5689));
//结果为：
//-0003,123
// -31
//-31
// (31)
// 0x1639　

    2. 浮動小数点数をフォーマットする：%[index$][フラグ][最小幅][.精度]変換方式

    ご覧のとおり、浮動小数点数の変換には「精度」オプションが追加され、小数点以下の桁数を制御できます。

    フラグ：

    • '-' 最小幅内で左揃えになります。"0で埋める"とは同時に使用できません。
    • '+' 結果は常に符号を含みます。
    • ' ' 正の値の前にはスペースを付け、負の値の前にはマイナス記号を付けます。
    • '0' 結果はゼロで埋められます。
    • ',' 3桁ごとに「,」で区切ります（fgG の変換にのみ適用されます）。
    • '(' パラメータが負の数の場合、結果にマイナス記号を付けず、代わりに数字を丸括弧で囲みます（eEfgG の変換にのみ適用されます）。

    変換方式：

    • 'e', 'E' -- 結果はコンピュータ科学記数法で表された10進数としてフォーマットされます。
    • 'f' -- 結果は10進数の通常の表記方法としてフォーマットされます。
    • 'g', 'G' -- 状況に応じて、通常の表記方法と科学記数法のどちらかを自動的に選択します。
    • 'a', 'A' -- 結果は有効桁数と指数を持つ16進数の浮動小数点数としてフォーマットされます。

    3. 文字をフォーマットする：

    文字のフォーマットは非常に簡単です。c は文字を表し、フラグの '-' は左揃えを表します。他には特にありません。

    String がなぜ変更不可能なのかについて

    ここでは JDK のソースコードに基づいて分析できます。

    文字列は実際には char 配列であり、内部には char 配列がカプセル化されています。

    そして、この char 配列は final で修飾されています：

    public final class String
    implements java.io.Serializable, Comparable<String>, CharSequence {
    /** The value is used for character storage. */
    private final char value[];

    さらに、String のすべてのメソッドは char 配列に対する変更であり、それに対する変更はメソッド内部で常に新しい String インスタンスを返します。

    Java における文字列の加算アルゴリズム

    String a = "a";
String b = "b";
String c = a + b;

    次と同等です：

    String c = new StringBuffer().append(a).append(b).toString();

    文字列の加算演算については、class ファイルにコンパイルされるとき、文字列連結操作を行うために自動的に StringBuffer にコンパイルされます。

    また、文字列定数プールについては：

    文字列がリテラルである場合、それは定数プールに置かれ、再利用を待ちます。

    String a = "saff";
String b = "saff";
String c = new String("saff");
System.out.println(a.equal(b));  // true
System.out.println(a.equal(c));  // true

    これが文字列の定数プールです。

    String クラスのよくある面接問題

    面接問題1：

    String s1 = "abc";            // 常量池
String s2 = new String("abc");     // 堆内存中
System.out.println(s1==s2);        // false两个对象的地址值不一样。
System.out.println(s1.equals(s2)); // true

    面接問題2：

    String s1="a"+"b"+"c";
String s2="abc";
System.out.println(s1==s2);
System.out.println(s1.equals(s2));

    Java における定数最適化メカニズム。コンパイル時にs1すでに ～ になっています。abc定数プール内で検索して作成し、s2再作成する必要はありません。

    面接問題3：

    String s1="ab";
String s2="abc";
String s3=s1+"c";
System.out.println(s3==s2);         // false
System.out.println(s3.equals(s2));  // true

    まず定数プール内に作成し、ab、アドレスは ～ を指し、s1、次に ～ を作成し、abc、s2 を指します。s3 については、まず StringBuilder（または StringBuffer）オブジェクトを作成し、append で連結して ～ を得ます。abc、次に toString() を呼び出して変換して得られたアドレスは ～ を指します。s3。したがって(s3==s2) 为 false。

    Java：String、StringBuffer と StringBuilder の違い

    String：文字列定数であり、文字列の長さは変更できません。Java の String は immutable（不変）です。文字を格納する配列は final として宣言されているため、一度しか代入できず、変更できません。

    StringBuffer：文字列変数（Synchronized、つまりスレッドセーフ）。文字列の内容を頻繁に変更する必要がある場合、効率を考慮して StringBuffer を使用するのが最適です。String 型に変換したい場合は、StringBuffer の toString() メソッドを呼び出すことができます。Java.lang.StringBuffer はスレッドセーフな可変文字シーケンスです。任意の時点で特定の文字シーケンスを含みますが、いくつかのメソッド呼び出しによってそのシーケンスの長さと内容を変更できます。文字列バッファは複数のスレッドで安全に使用できます。

    StringBuilder：文字列変数（非スレッドセーフ）。内部では StringBuilder オブジェクトは文字シーケンスを含む可変長配列として扱われます。

    基本原則：

    • 少量のデータを操作する場合は String を使用します。
    • シングルスレッドで大量のデータを操作する場合は StringBuilder を使用します。
    • マルチスレッドで大量のデータを操作する場合は StringBuffer を使用します。
