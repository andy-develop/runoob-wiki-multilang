Java Character クラス

Character クラスは単一の文字を操作するために使用されます。

Character クラスはオブジェクト内でプリミティブ型のchar値をラップします。

例

char ch = 'a'; //Unicode 文字表現形式 char uniChar = '\u039A'; //文字配列 char[] charArray ={ 'a', 'b', 'c', 'd', 'e' };

しかし、実際の開発プロセスでは、組み込みデータ型ではなくオブジェクトを使用する必要がある場面によく遭遇します。この問題を解決するために、Java言語は組み込みデータ型charに対してラッパークラスCharacterクラスを提供しています。

Characterクラスは文字を操作する一連のメソッドを提供します。Characterのコンストラクタを使用してCharacterクラスのオブジェクトを作成できます。例：

Character ch = new Character('a');

特定の状況では、Javaコンパイラは自動的にCharacterオブジェクトを作成します。

例えば、char型の引数をCharacter型の引数を必要とするメソッドに渡すと、コンパイラは自動的にchar型の引数をCharacterオブジェクトに変換します。この特徴をボクシングと呼び、逆はアンボクシングと呼びます。

例

//プリミティブ文字 'a' は Character オブジェクト ch にボクシングされます。 Character ch = 'a'; //プリミティブ文字 'x' は test メソッドでボクシングされます。 //アンボクシングされた値を 'c' に返します。 char c = test('x');

前にバックスラッシュ（\）が付いた文字はエスケープ文字を表し、コンパイラにとって特別な意味を持ちます。

以下のリストはJavaのエスケープシーケンスを示しています：

エスケープシーケンス 説明
\t 文中のその場所にタブキーを挿入
\b 文中のその場所にバックスペースキーを挿入
\n 文中のその場所で改行
\r 文中のその場所にキャリッジリターンを挿入
\f 文中のその場所に改ページを挿入
\' 文中のその場所に一重引用符を挿入
\" 文中のその場所に二重引用符を挿入
\\ 文中のその場所にバックスラッシュを挿入

    \r： return は現在の行の一番左に移動します。

    \n： newline は下に1行移動し、左右には移動しません。

    Linuxでは\n表す：キャリッジリターン + ラインフィード；

    Windowsでは\r\n表す：キャリッジリターン + ラインフィード。

    Macでは\r表す：キャリッジリターン + ラインフィード。

    歴史：

    "キャリッジリターン"（Carriage Return）と"ラインフィード"（Line Feed）という2つの概念の由来と違い。コンピュータが登場する前、テレタイプライター（Teletype Model 33、linux/Unixのttyの概念もこれに由来します）と呼ばれる装置があり、毎秒10文字を打つことができました。しかし、1行打ち終えて改行するときに0.2秒かかり、ちょうど2文字打てる時間でした。この0.2秒の間に新しい文字が送られてくると、その文字は失われてしまいます。そこで、開発者たちはこの問題を解決する方法を考え出しました。各行の末尾に終了を示す2つの文字を追加するというものです。1つは"キャリッジリターン(return)"と呼ばれ、タイプライターに印字ヘッドを左端に移動するよう指示します。もう1つは"ラインフィード(newline)"と呼ばれ、タイプライターに用紙を1行下に移動するよう指示します。これが"ラインフィード"と"キャリッジリターン"の由来であり、英語の名前からもその一端がうかがえます。

    ソフトリターンとハードリターン：

    さらにリターンについていくつか知識を広げます。

    ハードリターンは、通常エンターキーを押すことで生成されるもので、改行と同時に段落の区切りの役割も果たします。

    ソフトリターンは Shift + Enter で生成され、改行はしますが段落は変わりません。つまり、前後の2つの段落はWord内で同じ「段落」に属します。書式を適用するとそのことがわかります。

    ソフトリターンは前後の行の行間を大幅に狭めることができます。段落マークではないため、正式な段落マークであるハードリターンと区別する必要があります。ハードリターンのHTMLコードは <p>..</p> で、段落の内容はその中に挟まれます。一方、ソフトリターンのコードは非常に簡潔で <br> です。Webページの文字をWordにコピーすると、ハードリターンは曲がった矢印になり、ソフトリターンは下向きの矢印になります。

    Character のコンストラクタはバージョン9以降非推奨です。

    The constructor Character(char) is deprecated since version 9

    原文：java.lang.Character​(char)：It is rarely appropriate to use this constructor. The static factoryCharacter.valueOf(char) is generally a better choice, as it is likely to yield significantly better space and time performance.

    翻訳：このコンストラクタが適切に使用されることはほとんどありません。静的ファクトリ Character.valueOf(char) の方が通常は良い選択です。スペースと時間のパフォーマンスが向上する可能性があるためです。

    Character ch = new Character('a');      // Java9 以前
Character ch = Character.valueOf('a');  // Java9 以后

    文字から大文字と小文字を抽出する：

    public class UpperLowerCase {
    public static void main(String []args) {
        String StrA="I am Tom.I am from China.";
        String StrB="";
        String StrC="";
        for(int i=0;i<StrA.length();i++){
            if(Character.isUpperCase(StrA.charAt(i)))
                StrB +=StrA.charAt(i)+"  ";
            if(Character.isLowerCase(StrA.charAt(i)))
                StrC +=StrA.charAt(i)+"  ";
            }
        System.out.println("字符串中大写字母有："+StrB);
        System.out.println("字符串中小写字母有："+StrC);
    }
}

    Characterを利用して文字列から大文字と小文字を抽出する：

    public class UpperLowerCase {
    
    /*
     * 利用Character类提取字符串中的大写字母和小写字母
     * @auther Anthony-Z
     */

    public static void main(String[] args) {
        
        String sr1 = "I Like JAVA ! I learn Java everyday.";
        String sr2 = "";
        String sr3 = "";
        
        for (int i = 0; i < sr1.length(); i++) {//获取字符串的长度用的是length();
            if(Character.isUpperCase(sr1.charAt(i))){//先将String类型的字符串转换成char类型                                                                            再获取每一个字符元素，用charAt(i)实现
                sr2 += sr1.charAt(i) + " ";//提取大写字母
            }
            
            if(Character.isLowerCase(sr1.charAt(i))){
                sr3 += sr1.charAt(i) + " ";//提取小写字母
            }
        }
        
        System.out.println("大写字母有：" + sr2);
        System.out.println("小写字母有：" + sr3);

    }

}

    実行結果：

    大写字母有：I L J A V A I J 
小写字母有：i k e l e a r n a v a e v e r y d a y
