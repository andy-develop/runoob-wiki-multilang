Java シリアライゼーション

Java シリアライゼーションは、オブジェクトをバイトストリームに変換するプロセスです。これにより、オブジェクトをディスクに保存したり、ネットワーク経由で転送したり、メモリ内に保存したりし、後でデシリアライズしてバイトストリームを再びオブジェクトに変換できます。

Java でのシリアライゼーションは、java.io.Serializableインターフェースを実装することによって行われます。このインターフェースにはメソッドがなく、クラスがシリアライズ可能であることを識別するための単なるマーカーインターフェースです。

オブジェクトをシリアライズするときは、それを特別なファイルにラップして、保存、転送、または格納できます。デシリアライズは、そのファイルを開き、シリアライズされたデータを読み取り、それをオブジェクトに復元してプログラムで使用できるようにします。

シリアライゼーションは、オブジェクトを保存、転送、復元するための方法であり、オブジェクトを異なるコンピュータ間で移動・共有できるようにします。これは、分散システム、データストレージ、クロスプラットフォーム通信に非常に役立ちます。

以下は、Java シリアライゼーションの基本的な概念と使い方です。

Serializable インターフェースの実装: クラスをシリアライズ可能にするには、そのクラスに java.io.Serializable インターフェースを実装させる必要があります。これにより、Java コンパイラにそのクラスがシリアライズ可能であることが伝わります。例:

例

import java.io.Serializable;

public class MyClass implements Serializable {
    // クラスのメンバーとメソッド
}

オブジェクトのシリアライズ:ObjectOutputStream クラスを使用してオブジェクトをバイトストリームにシリアライズします。以下は簡単な例です:

例

MyClass obj = new MyClass();
try {
    FileOutputStream fileOut = new FileOutputStream("object.ser");
    ObjectOutputStream out = new ObjectOutputStream(fileOut);
    out.writeObject(obj);
    out.close();
    fileOut.close();
} catch (IOException e) {
    e.printStackTrace();
}

上記のコードは、"object.ser" という名前のファイル内の obj オブジェクトをシリアライズします。

オブジェクトのデシリアライズ:ObjectInputStream クラスを使用してバイトストリームからオブジェクトをデシリアライズします。以下は簡単な例です:

例

MyClass obj = null;
try {
    FileInputStream fileIn = new FileInputStream("object.ser");
    ObjectInputStream in = new ObjectInputStream(fileIn);
    obj = (MyClass) in.readObject();
    in.close();
    fileIn.close();
} catch (IOException e) {
    e.printStackTrace();
} catch (ClassNotFoundException e) {
    e.printStackTrace();
}

上記のコードは、"object.ser" ファイルからバイトストリームを読み取り、それを MyClass オブジェクトにデシリアライズします。

ObjectInputStream クラスと ObjectOutputStream クラスは高レベルのデータストリームであり、オブジェクトのデシリアライズとシリアライズのメソッドを含みます。

ObjectOutputStream クラスには、さまざまなデータ型を書き込むための多くの書き込みメソッドが含まれていますが、特別なメソッドが 1 つあります:

public final void writeObject(Object x) throws IOException

上記のメソッドはオブジェクトをシリアライズし、それを出力ストリームに送信します。同様に、ObjectInputStream クラスには、オブジェクトをデシリアライズする次のメソッドが含まれています:

public final Object readObject() throws IOException, ClassNotFoundException

このメソッドはストリームから次のオブジェクトを取得し、オブジェクトをデシリアライズします。戻り値は Object 型なので、適切なデータ型にキャストする必要があります。

例

Java でシリアライゼーションがどのように機能するかを示すために、前のチュートリアルで説明した Employee クラスを使用します。次のような Employee クラスを定義したと仮定します。このクラスは Serializable インターフェースを実装しています。

Employee.java ファイルコード：

public class Employee implements java.io.Serializable { public String name; public String address; public transient int SSN; public int number; public void mailCheck() { System.out.println("Mailing a check to " + name + " " + address); } }

クラスのオブジェクトをシリアライズするには、次の 2 つの条件を満たす必要があることに注意してください:

クラスは java.io.Serializable インターフェースを実装する必要があります。

クラスのすべてのプロパティはシリアライズ可能である必要があります。シリアライズ不可能なプロパティがある場合は、そのプロパティを一時的 (transient) としてマークする必要があります。

Java 標準クラスがシリアライズ可能かどうかを確認したい場合は、そのクラスのドキュメントを参照してください。クラスのインスタンスがシリアライズ可能かどうかを調べるのは非常に簡単で、そのクラスが java.io.Serializable インターフェースを実装しているかどうかを確認するだけです。

オブジェクトのシリアライズ

ObjectOutputStream クラスはオブジェクトをシリアライズするために使用されます。次の SerializeDemo の例では、Employee オブジェクトをインスタンス化し、そのオブジェクトをファイルにシリアライズします。

このプログラムを実行すると、employee.ser という名前のファイルが作成されます。このプログラムには出力はありませんが、コードを調べることでプログラムの動作を理解できます。

注意:オブジェクトをファイルにシリアライズするとき、Java の標準的な慣例では、ファイルに .ser 拡張子を付けます。

SerializeDemo.java ファイルコード：

import java.io.*; public class SerializeDemo { public static void main(String [] args) { Employee e = new Employee(); e.name = "Reyan Ali"; e.address = "Phokka Kuan, Ambehta Peer"; e.SSN = 11122333; e.number = 101; try { FileOutputStream fileOut = new FileOutputStream("/tmp/employee.ser"); ObjectOutputStream out = new ObjectOutputStream(fileOut); out.writeObject(e); out.close(); fileOut.close(); System.out.printf("Serialized data is saved in /tmp/employee.ser"); }catch(IOException i) { i.printStackTrace(); } } }

オブジェクトのデシリアライズ

次の DeserializeDemo プログラムはデシリアライズの例です。/tmp/employee.ser には Employee オブジェクトが格納されています。

DeserializeDemo.java ファイルコード：

import java.io.*; public class DeserializeDemo { public static void main(String [] args) { Employee e = null; try { FileInputStream fileIn = new FileInputStream("/tmp/employee.ser"); ObjectInputStream in = new ObjectInputStream(fileIn); e = (Employee) in.readObject(); in.close(); fileIn.close(); }catch(IOException i) { i.printStackTrace(); return; }catch(ClassNotFoundException c) { System.out.println("Employee class not found"); c.printStackTrace(); return; } System.out.println("Deserialized Employee..."); System.out.println("Name: " + e.name); System.out.println("Address: " + e.address); System.out.println("SSN: " + e.SSN); System.out.println("Number: " + e.number); } }

上記のプログラムをコンパイルして実行した結果は次のとおりです:

Deserialized Employee...
Name: Reyan Ali
Address:Phokka Kuan, Ambehta Peer
SSN: 0
Number:101

ここで注意すべき点は次のとおりです:

readObject() メソッド内の try/catch コードブロックは、ClassNotFoundException 例外をキャッチしようとします。JVM がオブジェクトをデシリアライズできるためには、バイトコードを見つけられるクラスである必要があります。JVM がオブジェクトのデシリアライズ中にそのクラスを見つけられない場合、ClassNotFoundException 例外がスローされます。

readObject() メソッドの戻り値が Employee 参照にキャストされることに注意してください。

オブジェクトがシリアライズされるとき、SSN プロパティの値は 111222333 ですが、このプロパティは一時的 (transient) であるため、その値は出力ストリームに送信されません。したがって、デシリアライズ後の Employee オブジェクトの SSN プロパティは 0 になります。

    Serializable の役割

    なぜクラスが Serializable インターフェースを実装するとシリアライズできるのでしょうか？前のセクションの例では、ObjectOutputStream を使用してオブジェクトを永続化していますが、そのクラスには次のようなコードがあります:

    private void writeObject0(Object obj, boolean unshared) throws IOException {
      ...
    if (obj instanceof String) { 
        writeString((String) obj, unshared);
    } else if (cl.isArray()) { 
        writeArray(obj, desc, unshared);
    } else if (obj instanceof Enum) {
        writeEnum((Enum) obj, desc, unshared);
    } else if (obj instanceof Serializable) {
        writeOrdinaryObject(obj, desc, unshared);
    } else {
        if (extendedDebugInfo) {
            throw new NotSerializableException(cl.getName() + "\n"
                    + debugInfoStack.toString());
        } else {
            throw new NotSerializableException(cl.getName());
        }
    }
    ...
}

    上記のコードからわかるように、書き込まれるオブジェクトの型が String、配列、Enum、Serializable のいずれかである場合、そのオブジェクトをシリアライズできます。それ以外の場合は NotSerializableException がスローされます。

    Java におけるシリアライゼーションとデシリアライゼーションについて

    シリアライゼーションは、しばしば永続化とも呼ばれ、ディスクに書き込みます。

    さらに、コーディング規則としては：

    すべてのエンティティクラスは Serializable インターフェースを実装する必要があります。これにより、後でそのクラスを永続化したり、バイト配列に変換してネットワーク転送に使用したりできます。

    エンティティクラスで、すべてのプロパティをシリアライズしたくない場合、専用のキーワード transient があります：

    private transient String name;

    そのクラスをシリアライズするとき、transient で修飾されたプロパティは自動的に無視されます。

    SerializableID について

    SerializableID 番号は、クラスの特徴とクラスのシグネチャに基づいて計算されます。ID 番号がそれほど長いのは、重複を避けるためです。つまり、Serializable はクラスに ID を付けるために使われます。クラスとオブジェクトが同じバージョンかどうかを判断するために使用されます。

    シリアライズ可能なクラスが serialVersionUID を明示的に宣言していない場合、シリアライズランタイムはクラスのさまざまな側面に基づいてデフォルトの serialVersionUID 値を計算します。その理由は、デフォルトの serialVersionUID の計算はクラスの詳細情報に対して非常に敏感であり、コンパイラの実装によって大きく異なる可能性があるため、デシリアライズ中に予期しない InvalidClassException が発生する可能性があるからです。

    シリアライズストリームとデシリアライズストリーム

    ObjectOutputStream(シリアライズストリーム)

    ObjectOutputStream はシリアライズストリームであり、Java プログラム内のオブジェクトをファイルに書き込むことができます。

    ObjectOutputStream のコンストラクタ:

    ObjectOutputStream(OutputStream out): 引数にはバイト出力ストリームを渡します。

    ObjectOutputStream がオブジェクトを書き込むメソッド (固有のメソッド):

    void writeObject(Object obj): オブジェクトをファイルに書き込みます。

    ObjectOutputStream の使用手順:

    • シリアライズストリームを作成して書き込みに使用します。
    • writeObject メソッドを呼び出して、オブジェクトを書き込みます。
    • リソースを解放します。

    tips:シリアル化ストリームを使用してファイルにオブジェクトを書き込むには、Serializable インターフェースを実装する必要があります。

    public class Demo01ObjectOutputStream {
    public static void main(String[] args) throws IOException {
        //1. 创建序列化流，用来写
        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("day12\\file03-obj.txt"));
        //2. 调用writeObject方法，写对象
        Person p = new Person("张三丰", 100);
        oos.writeObject(p);
        //3. 释放资源。
        oos.close();
    }
}

    ObjectInputStream(デシリアライズストリーム)

    ObjectInputStream はデシリアル化ストリームであり、ファイル内のオブジェクトを Java プログラムに読み込むことができます。

    ObjectInputStream のコンストラクタ:

    ObjectInputStream(InputStream in)：引数にはバイト入力ストリームを渡します。

    ObjectInputStream がオブジェクトを読み取るメソッド（特有のメソッド）:

    Object readObject()：ファイルからオブジェクトを読み取り、そのオブジェクトを返します。

    デシリアル化ストリームの使用手順:

    • ObjectInputStream デシリアル化ストリームを作成します。
    • readObject メソッドを呼び出して、オブジェクトを読み取ります。
    • リソースを解放します。

    tips：readObject メソッドでオブジェクトを読み取るとき、オブジェクトに対応するクラスが存在しない場合、エラーが発生します（ClassNotFoundException）

    特別な場合:

    static で修飾されたメンバー変数はシリアル化できず、ファイルに書き込むことはできません。

    特定のメンバー変数をファイルに書き込みたくないが、static キーワードも使用したくない場合は、transient を使用できます。transient キーワードは一時的な状態を表し、transient で修飾されたメンバー変数はシリアル化できません。

    public class Demo03StaticAndTransient {
    public static void main(String[] args) throws IOException, ClassNotFoundException {
        writePerson();
        readPerson();
    }

    //从文件中读取Person对象
    public static void readPerson() throws IOException, ClassNotFoundException {
        //创建反序列化流
        ObjectInputStream ois = new ObjectInputStream(new FileInputStream("day12\\file04-obj.txt"));
        //从文件中读取对象
        Object obj = ois.readObject();
        System.out.println(obj);
        //释放资源
        ois.close();
    }

    //向文件中写Person对象
    public static void writePerson() throws IOException {
        //创建序列化流
        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("day12\\file04-obj.txt"));
        //向文件中写Person对象
        oos.writeObject(new Person("张三丰", 100));
        //关流
        oos.close();
    }
}
    public class Demo04SerialVersionUID {
    public static void main(String[] args) throws IOException, ClassNotFoundException {
        //writePerson();
        readPerson();
    }

    //从文件中读取Person对象
    public static void readPerson() throws IOException, ClassNotFoundException {
        //创建反序列化流
        ObjectInputStream ois = new ObjectInputStream(new FileInputStream("day12\\file04-obj.txt"));
        //从文件中读取对象
        Object obj = ois.readObject();
        System.out.println(obj);
        //释放资源
        ois.close();
    }

    //向文件中写Person对象
    public static void writePerson() throws IOException {
        //创建序列化流
        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("day12\\file04-obj.txt"));
        //向文件中写Person对象
        oos.writeObject(new Person("张三丰", 100));
        //关流
        oos.close();
    }
}

    例題

    /*
    练习：
        1. 将存有多个Student对象的集合序列化操作，保存到list.txt 文件中。
        2. 反序列化list.txt ，并遍历集合，打印对象信息。

    步骤：
        1. 创建集合，用来保存Student
        2. 向集合中添加Student对象。
        3. 创建ObjectOutputStream序列化流，用来写。
        4. 调用writeObject方法，向文件中写集合对象。
        5. 释放资源。
        6. 创建ObjectInputStream反序列化流对象，用来读取
        7. 调用readObject方法，从文件中读取对象。
        8. 将读取到的集合进行遍历，并输出结果。

    注意：如果想要将多个对象保存在文件中，最好的一个方式可以将多个对象放入到一个集合中，然后直接将集合写到文件中。
 */
public class Demo05Test {
    public static void main(String[] args) throws IOException, ClassNotFoundException {
        //1. 创建集合，用来保存Student
        List<Student> list = new ArrayList<>();
        //2. 向集合中添加Student对象。
        list.add(new Student("李云龙", 20));
        list.add(new Student("二营长", 22));
        list.add(new Student("秀琴", 25));
        //3. 创建ObjectOutputStream序列化流，用来写。
        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("day12\\list.txt"));
        //4. 调用writeObject方法，向文件中写集合对象。
        oos.writeObject(list);
        //5. 释放资源。
        oos.close();
        //6. 创建ObjectInputStream反序列化流对象，用来读取
        ObjectInputStream ois = new ObjectInputStream(new FileInputStream("day12\\list.txt"));
        //7. 调用readObject方法，从文件中读取对象。
        List<Student> list2 = (List<Student>) ois.readObject();
        //8. 将读取到的集合进行遍历，并输出结果。
        for (Student stu : list2) {
            System.out.println(stu);
        }
    }
}

    1）変数がtransientで修飾されると、その変数はオブジェクトの永続化の一部ではなくなり、シリアル化後にその変数の内容にアクセスできなくなります。

    2）transientキーワードは変数のみを修飾でき、メソッドやクラスは修飾できません。ローカル変数はtransientキーワードで修飾できないことに注意してください。変数がユーザー定義クラスの変数である場合、そのクラスはSerializableインターフェースを実装する必要があります。

    3）transientキーワードで修飾された変数はシリアル化できなくなります。静的変数は、transientで修飾されているかどうかに関係なく、シリアル化できません。
