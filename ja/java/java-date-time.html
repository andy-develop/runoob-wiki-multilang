Java 日付時刻

Java には複数の日付時刻 API が用意されています。以下は主要なカテゴリの比較と一般的なメソッドのまとめです。

カテゴリ 主要クラス スレッドセーフ 可変性 Java バージョン 特徴
従来の日付 Date, Calendar，GregorianCalendar 否 可変 1.0+ 設計上の欠陥が多く、推奨されません
新しい日付時刻 LocalDate, LocalTime, LocalDateTime, ZonedDateTime, ChronoUnit 是 不変 8+ 設計が良好で、推奨されます
タイムスタンプ Instant 是 不変 8+ マシン時間で、ナノ秒まで正確
フォーマット DateTimeFormatter 是 不変 8+ スレッドセーフなフォーマットクラス

LocalDate/DateTimeFormatter

LocalDate/DateTimeFormatter は Java 8 で導入された日付クラスです。LocalDate は時刻を含まない日付（年-月-日）を表すために使用され、DateTimeFormatter は日付時刻オブジェクトのフォーマットと解析に使用されます。

例

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

public class RunoobTest {
    public static void main(String[] args) {
        // 現在の日付を取得
        LocalDate today = LocalDate.now();
        System.out.println("現在の日付: " + today);
       
        // 特定の日付を作成
        LocalDate nationalDay = LocalDate.of(2025, 10, 1);
        System.out.println("国慶節: " + nationalDay);
       
        // 日付の加算と減算
        LocalDate tomorrow = today.plusDays(1);
        LocalDate nextMonth = today.plusMonths(1);
        LocalDate lastYear = today.minusYears(1);
       
        System.out.println("明日: " + tomorrow);
        System.out.println("来月: " + nextMonth);
        System.out.println("去年の今日: " + lastYear);
    }
}

上記の例の出力結果は次のとおりです。

当前日期: 2025-05-01
国庆节: 2025-10-01
明天: 2025-05-02
下个月: 2025-06-01
去年今天: 2024-05-01

  1. 新しいプロジェクトでは java.time パッケージを優先的に使用します (Java 8+)

  2. 古い Date クラスと Calendar クラスの使用は避けます

  3. タイムゾーンの使用を明確に区別します：

    • タイムゾーン不要：LocalDate/LocalTime/LocalDateTime

    • タイムゾーン必要：ZonedDateTime

  4. フォーマット時はスレッドセーフを考慮します：SimpleDateFormat ではなく DateTimeFormatter を使用

  5. データベース連携：

    • JDBC 4.2+ は java.time タイプを直接サポート

    • 旧バージョンでは java.sql.Date/Timestamp に変換可能

java.util パッケージは、現在の日付と時刻をカプセル化する Date クラスを提供します。Date クラスは、Date オブジェクトをインスタンス化するための 2 つのコンストラクタを提供します。

最初のコンストラクタは、現在の日付と時刻を使用してオブジェクトを初期化します。

Date( )

2 番目のコンストラクタは、1970 年 1 月 1 日からのミリ秒数であるパラメータを 1 つ受け取ります。

Date(long millisec)

日付の比較

Java では、2 つの日付を比較するために次の 3 つのメソッドを使用します：

  • getTime() メソッドを使用して 2 つの日付の値を取得し（1970 年 1 月 1 日からの経過ミリ秒数）、その後 2 つの値を比較します。
  • before()、after() および equals() メソッドを使用します。たとえば、月の 12 日は 18 日より早いので、new Date(99, 2, 12).before(new Date (99, 2, 18))true を返します。
  • compareTo() メソッドを使用します。これは Comparable インターフェースで定義されており、Date クラスはこのインターフェースを実装しています。

1. getTime() メソッドを使用した比較

この方法では、日付オブジェクトが 1970 年 1 月 1 日（Unix エポック）からの経過ミリ秒数を比較します。

例

import java.util.Date;

public class DateComparison {
    public static void main(String[] args) {
        Date date1 = new Date(121, 5, 15); // 2021年6月15日
        Date date2 = new Date(121, 5, 20); // 2021年6月20日
       
        // ミリ秒を比較
        if (date1.getTime() < date2.getTime()) {
            System.out.println("date1 は date2 より前");
        } else if (date1.getTime() > date2.getTime()) {
            System.out.println("date1 は date2 より後");
        } else {
            System.out.println("2 つの日付は同じ");
        }
    }
}

出力：

date1 在 date2 之前

2. before(), after() および equals() メソッドの使用

これらのメソッドは Date クラスに組み込まれた比較メソッドであり、意味がより明確です。

例

import java.util.Date;

public class DateComparison {
    public static void main(String[] args) {
        Date date1 = new Date(121, 5, 15); // 2021年6月15日
        Date date2 = new Date(121, 5, 20); // 2021年6月20日
       
        // before() メソッドを使用
        System.out.println("date1 は date2 より前ですか？ " + date1.before(date2));
       
        // after() メソッドを使用
        System.out.println("date1 は date2 より後ですか？ " + date1.after(date2));
       
        // equals() メソッドを使用
        System.out.println("2 つの日付は同じですか？ " + date1.equals(date2));
    }
}

出力：

date1 在 date2 之前吗？ true
date1 在 date2 之后吗？ false
两个日期相同吗？ false

3. compareTo() メソッドの使用

Date クラスは Comparable インターフェースを実装しており、compareTo() メソッドを使用して比較できます。

例

import java.util.Date;

public class DateComparison {
    public static void main(String[] args) {
        Date date1 = new Date(121, 5, 15); // 2021年6月15日
        Date date2 = new Date(121, 5, 20); // 2021年6月20日
       
        int result = date1.compareTo(date2);
       
        if (result < 0) {
            System.out.println("date1 は date2 より前");
        } else if (result > 0) {
            System.out.println("date1 は date2 より後");
        } else {
            System.out.println("2つの日付は同じ");
        }
    }
}

出力：

date1 在 date2 之前

SimpleDateFormat を使用した日付のフォーマット

SimpleDateFormat は、ロケールに依存する方法で日付をフォーマットおよび解析するクラスです。SimpleDateFormat を使用すると、任意のユーザー定義の日時形式を選択できます。例：

例

import java.util.*; import java.text.*; public class DateDemo { public static void main(String[] args) { Date dNow = new Date( ); SimpleDateFormat ft = new SimpleDateFormat ("yyyy-MM-dd hh:mm:ss"); System.out.println("現在の時刻は:" + ft.format(dNow)); } }

例を実行 » 
SimpleDateFormat ft = new SimpleDateFormat ("yyyy-MM-dd hh:mm:ss");

このコード行は変換の形式を定義しています。ここで、yyyy は西暦の年、MM は月、dd は日、HH:mm:ss は時、分、秒です。

注意:大文字の形式もあれば小文字の形式もあります。例えば、MM は月、mm は分、HH は24時間制、hh は12時間制です。

printfを使用した日付のフォーマット

printf メソッドは、時刻と日付を簡単にフォーマットできます。2文字の形式を使用し、それは%tで始まり、次の表のいずれかの文字で終わります。

  • %tY：4桁の年を出力します。例：2023
  • %ty：2桁の年を出力します。例：23
  • %tm：2桁の月を出力します。例：02
  • %tB：月のフルネームを出力します。例：February
  • %tb：月の省略名を出力します。例：Feb
  • %tA：曜日のフルネームを出力します。例：Wednesday
  • %ta：曜日の省略名を出力します。例：Wed
  • %td：2桁の日を出力します。例：24
  • %te：1桁または2桁の日を出力します。例：24 または 02
  • %tH：24時間制の時を出力します。例：23
  • %tI：12時間制の時を出力します。例：11
  • %tM：分を出力します。例：45
  • %tS：秒を出力します。例：30
  • %tp：午前か午後かを出力します。例：AM または PM
  • %tZ：タイムゾーンを出力します。例：GMT+08:00

Java スリープ(sleep)

sleep() は現在のスレッドを停止状態（現在のスレッドをブロック）にし、CPUの使用を譲ります。目的は、現在のスレッドがプロセスが取得したCPUリソースを独占しないようにし、他のスレッドに実行の機会を残すことです。

プログラムを1ミリ秒間スリープさせたり、コンピュータの寿命と同じくらい長い任意の時間スリープさせることができます。例えば、次のプログラムは3秒間スリープします：

例

import java.util.*; public class SleepDemo { public static void main(String[] args) { try { System.out.println(new Date( ) + "\n"); Thread.sleep(1000*3); //3秒間スリープ System.out.println(new Date( ) + "\n"); } catch (Exception e) { System.out.println("Got an exception!"); } } }

Calendar クラス

これで日付オブジェクトをフォーマットして作成できるようになりました。しかし、時、日、分などの日付データの特定の部分を設定および取得するにはどうすればよいでしょうか？また、日付のこれらの部分に値を加算または減算するにはどうすればよいでしょうか？答えは Calendar クラスを使用することです。

Calendarクラスの機能はDateクラスよりもはるかに強力で、実装方式もDateクラスよりも複雑です。

Calendarクラスは抽象クラスであり、実際に使用する際には特定のサブクラスのオブジェクトを実装します。オブジェクトを作成するプロセスはプログラマーにとって透過的で、getInstanceメソッドを使用して作成するだけで済みます。

システムの現在日付を表す Calendar オブジェクトを作成

Calendar c = Calendar.getInstance();//默认是当前日期

指定した日付の Calendar オブジェクトを作成

Calendarクラスを使用して特定の時間を表すには、まずCalendarオブジェクトを作成し、その後そのオブジェクトの年月日パラメータを設定する必要があります。

//创建一个代表2009年6月12日的Calendar对象
Calendar c1 = Calendar.getInstance();
c1.set(2009, 6 - 1, 12);

Calendar クラスオブジェクトのフィールド型

Calendarクラスでは以下の定数を使用して異なる意味を表します。JDK内の多くのクラスは実際にこの考え方を採用しています。

定数説明
Calendar.YEAR年
Calendar.MONTH月
Calendar.DATE日
Calendar.DAY_OF_MONTH日付。上記のフィールドと意味は完全に同じです
Calendar.HOUR12時間制の時
Calendar.HOUR_OF_DAY24時間制の時
Calendar.MINUTE分
Calendar.SECOND秒
Calendar.DAY_OF_WEEK曜日

Calendar クラスオブジェクト情報の設定

Set設定

例：

Calendar c1 = Calendar.getInstance();

呼び出し：

public final void set(int year,int month,int date)

c1.set(2009, 6, 12);//把Calendar对象c1的年月日分别设这为：2009、6、12

フィールド型を利用した設定

特定のフィールド（例えば日付の値）だけを設定する場合は、次のようなsetメソッドを使用できます：

public void set(int field,int value)

c1オブジェクトが表す日付を10日に設定します。他のすべての数値は再計算されます

c1.set(Calendar.DATE,10);

c1オブジェクトが表す年を2008年に設定します。他のすべての数値は再計算されます

c1.set(Calendar.YEAR,2008);

他のフィールド属性のsetの意味もこれに準じます

Add設定

Calendar c1 = Calendar.getInstance();

c1オブジェクトの日付に10を加えます。つまりc1は10日後の日付を表すことになり、他のすべての数値は再計算されます

c1.add(Calendar.DATE, 10);

c1オブジェクトの日付から10を引きます。つまりc1は10日前の日付を表すことになり、他のすべての数値は再計算されます

c1.add(Calendar.DATE, -10);

他のフィールド属性のaddの意味もこれに準じます

Calendar クラスオブジェクト情報の取得

Calendar c1 = Calendar.getInstance(); //年を取得 int year = c1.get(Calendar.YEAR); //月を取得 int month = c1.get(Calendar.MONTH) + 1; //日付を取得 int date = c1.get(Calendar.DATE); //時を取得 int hour = c1.get(Calendar.HOUR_OF_DAY); //分を取得 int minute = c1.get(Calendar.MINUTE); //秒を取得 int second = c1.get(Calendar.SECOND); //曜日を取得（注意：これはDateクラスとは異なります。1は日曜日、2は月曜日、3は火曜日を表し、以下同様です） int day = c1.get(Calendar.DAY_OF_WEEK);

GregorianCalendar クラス

Calendarクラスはグレゴリオ暦を実装しており、GregorianCalendarはCalendarクラスの具体的な実装の1つです。

CalendarのgetInstance()メソッドは、デフォルトで現在のロケールとタイムゾーンで初期化されたGregorianCalendarオブジェクトを返します。GregorianCalendarはADとBCという2つのフィールドを定義しています。これはグレゴリオ暦で定義された2つの時代を表します。
