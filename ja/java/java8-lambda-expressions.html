Java Lambda 式

Java 8 の新機能

Lambda 式は、クロージャとも呼ばれ、Java 8 のリリースを後押しした最も重要な新機能です。

Lambda では、関数をメソッドの引数として渡すことができます（関数をパラメータとしてメソッドに渡します）。

Lambda 式を使用すると、コードをより簡潔でコンパクトにできます。

構文

lambda 式の構文形式は次のとおりです。

(parameters) -> expression 或 (parameters) ->{ statements; }

parametersはパラメータリストです。expression 或 { statements; }は Lambda 式の本体です。パラメータが1つのみの場合は括弧を省略できます。パラメータがない場合は、空の括弧が必要です。

次は、Lambda 式を使用して2つの数値の合計を計算する簡単な例です。

例

// Lambda 式を使用して2つの数値の合計を計算する
MathOperation addition = (a, b) -> a + b;

// Lambda 式を呼び出す
int result = addition.operation(5, 3);
System.out.println("5 + 3 = " + result);

上記の例では、MathOperation は関数型インターフェースであり、抽象メソッド operation を含んでいます。Lambda 式は(a, b) -> a + bこの抽象メソッドを実装し、2つの引数を加算する操作を表します。

Lambda 式は、コレクション操作やイベント処理など、さまざまなシナリオで使用できます。次は、Lambda 式を使用してリストを走査する例です。

例

List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// Lambda 式を使用してリストを走査する
names.forEach(name -> System.out.println(name));

Lambda 式は Java により関数型プログラミングのスタイルをもたらし、コードをより簡潔で読みやすくします。これは Java 8 における関数型プログラミングへの重要な改良です。

重要な特徴

簡潔さ

Lambda 式は、特に関数型インターフェースに適した、より簡潔な構文を提供します。従来の匿名内部クラスと比較して、Lambda 式はコードをよりコンパクトにし、ボイラープレートコードの記述を減らします。

例

// 従来の匿名内部クラス
Runnable runnable1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
};

// Lambda 式を使用する
Runnable runnable2 = () -> System.out.println("Hello World!");

関数型プログラミングのサポート

Lambda 式は関数型プログラミングの一つの現れであり、関数をメソッドの引数として渡したり、関数を戻り値として返したりすることを可能にします。このサポートにより、Java は関数型プログラミングにおいてより柔軟になり、コレクション操作や並列計算などのタスクをより適切に処理できます。

例

// Lambda 式をメソッドの引数として渡す
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(name -> System.out.println(name));

変数のキャプチャ

Lambda 式は外部スコープの変数にアクセスできます。この特性を変数のキャプチャと呼びます。Lambda 式は、final または実質的に final であるローカル変数を暗黙的にキャプチャできます。

例

// 変数のキャプチャ
int x = 10;
MyFunction myFunction = y -> System.out.println(x + y);
myFunction.doSomething(5); // 15 を出力

メソッド参照

Lambda 式はメソッド参照によってさらに簡略化できます。メソッド参照を使用すると、冗長なコードを書くことなく、既存のクラスやオブジェクトのメソッドを直接参照できます。

例

// メソッド参照を使用する
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(System.out::println);

並列性

Lambda 式を使用すると、並列操作をより簡単に実装できます。Stream API と Lambda 式を組み合わせることで、並列計算を容易に実装し、プログラムのパフォーマンスを向上させることができます。

例

// Lambda 式と Stream API を使用して並列計算を行う
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
int sum = numbers.parallelStream().mapToInt(Integer::intValue).sum();

Lambda 式の導入により、Java プログラミングはより柔軟で簡潔になり、関数型プログラミングの発展を促進しました。

Lambda 式の例

Lambda 式の簡単な例:

// 1. 不需要参数,返回值为 5  
() -> 5  
  
// 2. 接收一个参数(数字类型),返回其2倍的值  
x -> 2 * x  
  
// 3. 接受2个参数(数字),并返回他们的差值  
(x, y) -> x – y  
  
// 4. 接收2个int型整数,返回他们的和  
(int x, int y) -> x + y  
  
// 5. 接受一个 string 对象,并在控制台打印,不返回任何值(看起来像是返回void)  
(String s) -> System.out.print(s)

Java8Tester.java ファイルに次のコードを入力します：

Java8Tester.java ファイル

public class Java8Tester { public static void main(String args[]){ Java8Tester tester = new Java8Tester(); //型宣言 MathOperation addition = (int a, int b) -> a + b; //型宣言なし MathOperation subtraction = (a, b) -> a - b; //中括弧内の return 文 MathOperation multiplication = (int a, int b) -> { return a * b; }; //中括弧と return 文なし MathOperation division = (int a, int b) -> a / b; System.out.println("10 + 5 = " + tester.operate(10, 5, addition)); System.out.println("10 - 5 = " + tester.operate(10, 5, subtraction)); System.out.println("10 x 5 = " + tester.operate(10, 5, multiplication)); System.out.println("10 / 5 = " + tester.operate(10, 5, division)); //括弧なし GreetingService greetService1 = message -> System.out.println("Hello " + message); //括弧あり GreetingService greetService2 = (message) -> System.out.println("Hello " + message); greetService1.sayMessage("Runoob"); greetService2.sayMessage("Google"); } interface MathOperation { int operation(int a, int b); } interface GreetingService { void sayMessage(String message); } private int operate(int a, int b, MathOperation mathOperation){ return mathOperation.operation(a, b); } }

上記のスクリプトを実行すると、出力結果は次のとおりです：

$ javac Java8Tester.java 
$ java Java8Tester
10 + 5 = 15
10 - 5 = 5
10 x 5 = 50
10 / 5 = 2
Hello Runoob
Hello Google

Lambda 式を使用する際は、次の2点に注意する必要があります：

  • Lambda 式は主に、インラインで実行されるメソッド型インターフェース（例: 単純なメソッドインターフェース）を定義するために使用されます。上記の例では、さまざまなタイプの Lambda 式を使用して MathOperation インターフェースのメソッドを定義し、その後 operation の実行を定義しました。

  • Lambda 式は匿名メソッドを使用する手間を省き、Java にシンプルかつ強力な関数型プログラミング能力をもたらします。

変数のスコープ

lambda 式は、final と宣言された外部ローカル変数のみを参照できます。つまり、lambda 内でスコープ外で定義されたローカル変数を変更することはできません。変更するとコンパイルエラーになります。

Java8Tester.java ファイルに次のコードを入力します：

Java8Tester.java ファイル

public class Java8Tester { final static String salutation = "Hello! "; public static void main(String args[]){ GreetingService greetService1 = message -> System.out.println(salutation + message); greetService1.sayMessage("Runoob"); } interface GreetingService { void sayMessage(String message); } }

上記のスクリプトを実行すると、出力結果は次のとおりです：

$ javac Java8Tester.java 
$ java Java8Tester
Hello! Runoob

lambda 式内で外部のローカル変数に直接アクセスすることもできます：

Java8Tester.java ファイル

public class Java8Tester { public static void main(String args[]) { final int num = 1; Converter<Integer, String> s = (param) -> System.out.println(String.valueOf(param + num)); s.convert(2); //出力結果は 3 です } public interface Converter<T1, T2> { void convert(int i); } }

lambda 式のローカル変数は final として宣言する必要はありませんが、後続のコードで変更されてはなりません（つまり、暗黙的に final のセマンティクスを持ちます）。

int num = 1;  
Converter<Integer, String> s = (param) -> System.out.println(String.valueOf(param + num));
s.convert(2);
num = 5;  
//报错信息：Local variable num defined in an enclosing scope must be final or effectively 
 final

Lambda 式内では、ローカル変数と同じ名前のパラメータまたはローカル変数を宣言することはできません。

String first = "";  
Comparator<String> comparator = (first, second) -> Integer.compare(first.length(), second.length());  //编译会出错

    次は、lambdas を使用して Runnable インターフェースを実装する例です:

new Thread(new Runnable() {  
    @Override  
    public void run() {  
        System.out.println("Hello world !");  
    }  
}).start();  
  
// 1.2使用 lambda expression  
new Thread(() -> System.out.println("Hello world !")).start();  
  
// 2.1使用匿名内部类  
Runnable race1 = new Runnable() {  
    @Override  
    public void run() {  
        System.out.println("Hello world !");  
    }  
};  
  
// 2.2使用 lambda expression  
Runnable race2 = () -> System.out.println("Hello world !");  
   
// 直接调用 run 方法(没开新线程哦!)  
race1.run();  
race2.run();

    surname、name の長さおよび最後の文字。前の例と同様に、最初に匿名内部クラスを使用してソートし、次に lambda 式を使用してコードを簡素化します。

    public void testOperation() {
        /*
         * 
         * 1.不需要参数,返回值为5
         * () -> 5
         * 
         * 2.接收一个参数(数字类型),返回其2倍的值
         * x -> 2 * x
         * 
         * 3.接收2个参数(数字类型),返回他们的差值
         * (x,y) -> x - y
         * 
         * 4.接收2个int型整数,返回他们的和
         * (int x, int y) -> x + y
         *

         * (String s) -> System.out.print(s)
         * 
         * 6.接收2个参数(数字类型),第1个数字加1,第2个数字加2,再求积
         * (int x, int y) -> { x += 1; y += 2; return x * y }
         * 
         */

        /*
         * 
         * MathOperation接口有且只有一个抽象方法operation时,
         * 可以使用 MathOperation addition = (int a, int b) -> a + b;
         * addition为实现了接口的一个对象,
         * (int a, int b) -> a + b;作为一个函数实现了MathOperation的抽象方法operation;
         * 当MathOperation接口存在两个抽象方法时;
         * MathOperation addition = (int a, int b) -> a + b;在编写时报错;
         * 
         */

        // 传入的参数带有类型声明
        MathOperation addition = (int a, int b) -> a + b;

        // 不用带类型声明
        MathOperation subtraction = (a, b) -> a = b;

        // 大括号中带返回语句
        MathOperation multiplication = (int a, int b) -> {
            return a * b;
        };

        // 没有带大括号及返回语句
        MathOperation division = (int a, int b) -> a / b;
        System.out.println("2 * 3 = " + operate(2, 3, multiplication));
        System.out.println("6 / 3 = " + operate(6, 3, (int a, int b) -> a / b));

        // 输出结果,无返回值
        GreetingService greetService = (String message) ->
        System.out.println("hello " + message);
        greetService.sayMessage("world");
    }

    interface MathOperation {
        int operation(int a, int b);
        // int operation2(int a, int b);
        default int operation3(int a, int b) {
            return a + b;
        }
    }

    interface GreetingService {
        void sayMessage(String message);
    }

    private int operate(int a, int b, MathOperation mathOperation) {
        return mathOperation.operation(a, b);
    }
}

    Lambda

    匿名内部クラスの形式：

    new 父类或接口() {​
    重写的方法;​ 
}

    匿名内部クラスには、冗長な部分が多くあります。

    例えば、匿名内部クラスを使用してマルチスレッドを実装するコードにおいて。

    • Thread のコンストラクタに Runnable インターフェース型のパラメータを渡す必要があるため、やむを得ず new Runnable と書かなければなりません。
    • Runnable の run メソッドをオーバーライドする必要があるため、public void run と書かなければなりませんでした。

    匿名内部クラス全体の中で最も重要なのはメソッドであり、メソッドの中で最も重要なのは「前・中・後」の3点です。

    • 前：パラメータ
    • 中：メソッド本体
    • 後：戻り値

    理想的なのは、匿名内部クラスの中で最も核となるこれらの内容（メソッドのパラメータ、メソッド本体、戻り値）だけに注目することです。Lambda 式を使えば、最も核となる内容だけに注目できます。Lambda 式は匿名内部クラスの簡略化した書き方です。

    Lambda は関数型プログラミングの思想に属します。

    • オブジェクト指向思想：どうやって行うか。
    • 関数型プログラミング思想：何を行うか。
    public class Demo01Inner {
    public static void main(String[] args) {
        //使用匿名内部类的方式实现多线程。
        new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println(Thread.currentThread().getName() + "执行了");
            }
        }).start();

        //使用Lambda表达式实现多线程
        new Thread(() -> System.out.println(Thread.currentThread().getName() + "执行了")).start();
    }
}

    匿名内部クラスは、個別にファイルを作成する操作を省けます。.javaしかし、匿名内部クラスにも欠点があり、書き方が冗長すぎて、多くの不要な部分が含まれています。

    匿名内部クラスにも簡略化した書き方があります。匿名内部クラスの簡略化した書き方は Lambda 式です。匿名内部クラスの中で最も重要な内容は、メソッドのパラメータ、メソッド本体、戻り値です。そして Lambda 式で注目するのは、まさにこの3つの重要な要素です。

    Lambda 式の標準フォーマット：

    (参数类型 参数名) -> {
    方法体;
    return 返回值;
}

    フォーマットの説明：

    • 小括弧内のパラメータは、以前のメソッドのパラメータの書き方と同じで、任意の数のパラメータを書けます。複数のパラメータがある場合は、カンマで区切ります。
    • -> は演算子であり、方向性のある動作を表します。
    • 中括弧内のメソッド本体と return の戻り値の書き方は、以前のメソッドの中括弧内の書き方と同じです。

    Lambda 式は関数型プログラミングの思想です。

    関数型プログラミング：導出可能であれば、省略可能であるということです。

    • Thread のコンストラクタで Runnable 型のパラメータが必要なため、new Runnable を省略できます。
    • Runnable の中には抽象メソッドが run しかないため、オーバーライドするのは必ずこの run メソッドになります。したがって、run メソッドの宣言部分（public void run）を省略できます。

    Lambda 式は、オブジェクト指向におけるさまざまな枠組みを省略でき、最も核となる内容だけに注目させてくれます。

    public class Demo02Lambda {
    public static void main(String[] args) {
        //实现多线程（单独创建.java）
        new Thread(new Task()).start();
        //使用匿名内部类的方式实现多线程
        new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println(Thread.currentThread().getName() + "执行了");
            }
        }).start();
        //使用Lambda表达式完成多线程
        new Thread(() -> {
            System.out.println(Thread.currentThread().getName() + "执行了");
        }).start();
    }
}

    匿名内部クラスと Lambda 関数の比較

    public class Demo03Collections {
    public static void main(String[] args) {
        //创建集合
        List<Student> list = new ArrayList<>();
        //添加元素
        list.add(new Student("嫐", 20));
        list.add(new Student("嬲", 18));
        list.add(new Student("挊", 22));
        //使用比较器排序对集合中的学生对象根据年龄升序排序
        //Collections.sort(list, new Rule());

        //使用匿名内部类
        Collections.sort(list, new Comparator<Student>() {
            @Override
            public int compare(Student o1, Student o2) {
                return o1.getAge() - o2.getAge();
            }
        });
       
        //使用Lambda表达式
        Collections.sort(list, (Student o1, Student o2) -> {
            return o1.getAge() - o2.getAge();
        });

        Collections.sort(list, (o1, o2) -> o1.getAge() - o2.getAge());

        System.out.println(list);

    }
}

    Lambda のフォーマット

    Lambda 式の標準フォーマット：

    (参数类型 参数名) -> {
    方法体;
    return 返回值;
}

    Lambda 式の省略ルール：

    • 1. 小括弧内のパラメータの型は省略できます。
    • 2. 小括弧内にパラメータが1つだけの場合は、小括弧を省略できます。
    • 3. 中括弧内に文が1つだけの場合は、中括弧、return、セミコロンを省略できます。
    public class Demo04SimpleLambda {
    //定义方法，使用接口当做参数
    public static void method(MyInterface m) {
        m.printStr("hello");
    }

    public static void main(String[] args) {
        //调用method方法，参数传递MyInterface实现类对象
        method(new MyInterface() {
            @Override
            public void printStr(String str) {
                System.out.println(str);
            }
        });
        //使用Lambda表达式的标准格式。
        method((String str) -> {
            System.out.println(str);
        });

        //1. 小括号中的参数类型可以省略。
        method((str) -> {
            System.out.println(str);
        });
        //2. 如果小括号中只有一个参数，那么可以省略小括号。
        method(str -> {
            System.out.println(str);
        });
        //3. 如果大括号中只有一条语句，那么可以省略大括号，return，分号。
        method(str -> System.out.println(str));
    }
}

    Lambda の使用条件

    Lambda 式を使用する前提条件：

    • インターフェース（抽象クラスでは不可）が必須であり、そのインターフェースにはオーバーライドが必要な抽象メソッドがただ1つだけ存在しなければなりません。
    • コンテキストからの推論をサポートしている必要があります。つまり、Lambda 式がどのインターフェースの内容を表しているかを推論できなければなりません。

    インターフェースをパラメータとして使用し、Lambda 式を渡すことができます（よく使われます）。また、Lambda 式をインターフェース型の変数に代入することもできます。

    public class Demo05BeforeLambda {
    //使用接口当做参数
    public static void method(MyInterface m) {//m = s -> System.out.println(s)
        m.printStr("HELLO");
    }

    public static void main(String[] args) {
        //使用接口当做参数，然后传递Lambda表达式。
        //method(s -> System.out.println(s));

        //使用匿名内部类方式创建对象
        /*
        MyInterface m = new MyInterface() {
            @Override
            public void printStr(String str) {
                System.out.println(str);
            }
        };
        */

        MyInterface m = str -> System.out.println(str);
        m.printStr("Hello");
    }
}
