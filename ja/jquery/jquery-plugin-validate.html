jQuery Validate

jQuery Validate プラグインはフォームに強力な検証機能を提供し、クライアント側のフォーム検証をより簡単にします。同時に、アプリケーションのさまざまなニーズを満たすための多数のカスタマイズオプションも提供します。このプラグインには、URL やメールアドレスの検証など、便利な検証メソッドのセットがバンドルされており、ユーザーが独自のメソッドを記述するための API も提供されています。バンドルされているすべてのメソッドはデフォルトで英語のエラーメッセージを使用しますが、他の 37 言語に翻訳されています。

このプラグインは Jörn Zaefferer によって作成・保守されています。彼は jQuery チームのメンバーであり、jQuery UI チームの主要開発者であり、QUnit のメンテナーでもあります。このプラグインは 2006 年の jQuery 初期の頃から登場し、現在まで更新され続けています。現在のバージョンは1.14.0。

アクセスjQuery Validate 公式サイト、最新版の jQuery Validate プラグインをダウンロードしてください。

デフォルトの検証ルール

番号 ルール 説明
1 required:true 必須入力フィールド。
2 remote:"check.php" ajax メソッドを使用して check.php を呼び出し、入力値を検証します。
3 email:true 正しい形式のメールアドレスを入力する必要があります。
4 url:true 正しい形式の URL を入力する必要があります。
5 date:true 正しい形式の日付を入力する必要があります。日付検証は IE6 でエラーになるため、使用には注意してください。
6 dateISO:true 正しい形式の日付（ISO）を入力する必要があります。例：2009-06-23、1998/01/22。形式のみを検証し、有効性は検証しません。
7 number:true 有効な数字（負数、小数）を入力する必要があります。
8 digits:true 整数を入力する必要があります。
9 creditcard: 有効なクレジットカード番号を入力する必要があります。
10 equalTo:"#field" 入力値は #field と同じである必要があります。
11 accept: 有効な拡張子を持つ文字列を入力してください（アップロードするファイルの拡張子）。
12 maxlength:5 最大長 5 の文字列を入力してください（漢字は 1 文字として数えます）。
13 minlength:10 最小長 10 の文字列を入力してください（漢字は 1 文字として数えます）。
14 rangelength:[5,10] 長さが 5 以上 10 以下の文字列を入力してください（漢字は 1 文字として数えます）。
15 range:[5,10] 入力値は 5 以上 10 以下である必要があります。
16 max:5 入力値は 5 より大きくすることはできません。
17 min:10 入力値は 10 より小さくすることはできません。

よく使う方法と注意点

1、デフォルトの SUBMIT を他の方法で置き換える

$().ready(function() {
 $("#signupForm").validate({
        submitHandler:function(form){
            alert("提交事件!");   
            form.submit();
        }    
    });
});

ajax 方式を使用する

 $(".selector").validate({     
 submitHandler: function(form) 
   {      
      $(form).ajaxSubmit();     
   }  
 })

validate のデフォルト値を設定できます。書き方は次のとおりです：

$.validator.setDefaults({
  submitHandler: function(form) { alert("提交事件!");form.submit(); }
});

フォームを送信する場合は、$(form).submit() ではなく form.submit() を使用する必要があります。

2、debug：検証のみ行いフォームを送信しない

このパラメータが true の場合、フォームは送信されず、チェックのみが行われます。デバッグ時に非常に便利です。

$().ready(function() {
 $("#signupForm").validate({
        debug:true
    });
});

1 つのページ内の複数のフォームをすべて debug に設定したい場合は、次を使用します：

$.validator.setDefaults({
   debug: true
})

3、ignore：特定の要素を無視して検証しない

ignore: ".ignore"

コードの役割は次のとおりです。通常はエラーメッセージを <td class="status"></td> に表示し、radio の場合は <td></td> に表示し、checkbox の場合は内容の後ろに表示します。

パラメータ 型 説明 デフォルト値
errorClass String エラーメッセージの CSS クラス名を指定します。エラーメッセージのスタイルをカスタマイズできます。 "error"
errorElement String エラーをマークするタグを指定します。デフォルトは label で、em に変更できます。 "label"

wrapper String 上記の errorELement をどのタグで包むかを指定します。

通常、これら 3 つの属性を同時に使用して、1 つのコンテナ内にすべてのエラーメッセージを表示し、メッセージがない場合は自動的に非表示にします。

errorLabelContainer: $("#signupForm div.error"),
wrapper: "li"

7、検証のトリガー方法を変更する

以下のオプションは boolean 型ですが、false に変更する場合を除き、むやみに追加しないことをお勧めします。

トリガー方法 型 説明 デフォルト値
onsubmit Boolean 送信時に検証します。false に設定すると他の方法で検証します。 true
onfocusout Boolean フォーカスが外れたときに検証します（チェックボックス/ラジオボタンは含みません）。 true
onkeyup Boolean keyup 時に検証します。 true
onclick Boolean チェックボックスとラジオボタンをクリックしたときに検証します。 true
focusInvalid Boolean フォーム送信後、検証に合格しなかったフォーム（最初のもの、または送信前にフォーカスを取得した検証不合格のフォーム）にフォーカスが移動します。 true
focusCleanup Boolean true の場合、検証に合格していない要素がフォーカスを取得したときにエラーメッセージを削除します。focusInvalid と一緒に使うのは避けてください。 false

8、非同期検証

remote：URL

ajax 方式を使用して検証します。デフォルトでは、現在検証している値をリモートアドレスに送信します。他の値を送信する必要がある場合は、data オプションを使用できます。

remote: "check-email.php"
remote: {
    url: "check-email.php",     //后台处理程序
    type: "post",               //数据发送方式
    dataType: "json",           //接受数据格式   
    data: {                     //要传递的数据
        username: function() {
            return $("#username").val();
        }
    }
}

リモートアドレスは "true" または "false" のみを出力でき、他の出力はできません。

9、カスタム検証を追加する

addMethod：name, method, message

カスタム検証メソッド

// 中文字两个字节
jQuery.validator.addMethod("byteRangeLength", function(value, element, param) {
    var length = value.length;
    for(var i = 0; i < value.length; i++){
        if(value.charCodeAt(i) > 127){
            length++;
        }
    }
  return this.optional(element) || ( length >= param[0] && length <= param[1] );   
}, $.validator.format("请确保输入的值在{0}-{1}个字节之间(一个中文字算2个字节)"));

// 邮政编码验证   
jQuery.validator.addMethod("isZipCode", function(value, element) {   
    var tel = /^[0-9]{6}$/;
    return this.optional(element) || (tel.test(value));
}, "请正确填写您的邮政编码");

注意：additional-methods.js ファイル内に追加するか、jquery.validate.js ファイル内に追加します。通常は additional-methods.js ファイルに記述することをお勧めします。

注意：messages_cn.js ファイルに追加します：isZipCode: "只能包括中文字、英文字母、数字和下划线"。呼び出す前に additional-methods.js ファイルへの参照を追加する必要があります。

10、radio・checkbox・select の検証

radio の required は、1 つを選択する必要があることを意味します。

<input  type="radio" id="gender_male" value="m" name="gender" required />
<input  type="radio" id="gender_female" value="f" name="gender"/>

checkbox の required は必須チェックを意味します。

<input type="checkbox" class="checkbox" id="agree" name="agree" required />

checkbox の minlength は選択必須の最小数、maxlength は最大選択数、rangelength:[2,3] は選択数の範囲を表します。

<input type="checkbox" class="checkbox" id="spam_email" value="email" name="spam[]" required minlength="2" />
<input type="checkbox" class="checkbox" id="spam_phone" value="phone" name="spam[]" />
<input type="checkbox" class="checkbox" id="spam_mail" value="mail" name="spam[]" />

select の required は選択された value が空であってはならないことを意味します。

<select id="jungle" name="jungle" title="Please select something!" required>
    <option value=""></option>
    <option value="1">Buga</option>
    <option value="2">Baga</option>
    <option value="3">Oi</option>
</select>

select の minlength は選択された最小数（複数選択可能な select）、maxlength は最大選択数、rangelength:[2,3] は選択数の範囲を表します。

<select id="fruit" name="fruit" title="Please select at least two fruits" class="{required:true, minlength:2}" multiple="multiple">
    <option value="b">Banana</option>
    <option value="a">Apple</option>
    <option value="p">Peach</option>
    <option value="t">Turtle</option>
</select>

validate() のオプション

説明 コード
debug: デバッグモードを実行します（フォームは送信されません）。 
$(".selector").validate
({
    debug:true
})
デバッグをデフォルトに設定します。 
$.validator.setDefaults({
    debug:true
})
submitHandler: 検証に合格した後に実行される関数。その中にフォーム送信の関数を追加する必要があります。そうしないとフォームは送信されません。 
$(".selector").validate({
    submitHandler:function(form) {
        $(form).ajaxSubmit();
    }
})
ignore: 特定の要素を検証しません。 
$("#myform").validate({
    ignore:".ignore"
})
rules: カスタムルール。key:value の形式で、key は検証する要素、value は文字列またはオブジェクトです。 
$(".selector").validate({
    rules:{
        name:"required",
        email:{
            required:true,
            email:true
        }
    }
})
messages: カスタムのヒントメッセージ。key:value の形式で、key は検証する要素、value は文字列または関数です。 
$(".selector").validate({
    rules:{
        name:"required",
        email:{
            required:true,
            email:true
        }
    },
    messages:{
        name:"Name不能为空",
        email:{       
            required:"E-mail不能为空",
            email:"E-mail地址不正确"
        }
    }
})
groups: 要素のグループに対する検証。1つのエラーメッセージを使用し、errorPlacement でエラー情報の表示場所を制御します。 
$("#myform").validate({
    groups:{
        username:"fname 
        lname"
    },
    errorPlacement:function(error,element) {
        if (element.attr("name") == "fname" || element.attr("name") == "lname")   
            error.insertAfter("#lastname");
        else    
            error.insertAfter(element);
    },
   debug:true
})
OnSubmit: 型 Boolean、デフォルトは true。送信時に検証するかどうかを指定します。 
$(".selector").validate({  
    onsubmit:false
})
onfocusout: 型 Boolean、デフォルトは true。フォーカスを取得したときに検証するかどうかを指定します。 
$(".selector").validate({   
    onfocusout:false
})
onkeyup: 型 Boolean、デフォルトは true。キーボードを押したときに検証するかどうかを指定します。 
$(".selector").validate({
   onkeyup:false
})
onclick: 型 Boolean、デフォルトは true。マウスクリック時に検証するかどうかを指定します（通常は checkbox、radiobox を検証します）。 
$(".selector").validate({
   onclick:false
})
focusInvalid: 型 Boolean、デフォルトは true。フォーム送信後、検証に合格しなかったフォーム（最初の、または送信前にフォーカスを取得していた検証不合格のフォーム）にフォーカスが移動します。 
$(".selector").validate({
   focusInvalid:false
})
focusCleanup: 型 Boolean、デフォルトは false。検証に合格しなかった要素がフォーカスを取得したとき、エラーメッセージを削除します（focusInvalid と一緒に使用しないでください）。 
$(".selector").validate({
   focusCleanup:true
})
errorClass: 型 String、デフォルトは "error"。エラーメッセージの CSS クラス名を指定します。エラーメッセージのスタイルをカスタマイズできます。 
$(".selector").validate({ 
    errorClass:"invalid"
})
errorElement: 型 String、デフォルトは "label"。エラーをマークするために使用するタグを指定します。 
$(".selector").validate
   errorElement:"em"
})
wrapper: 型 String。上記の errorElement をさらに包むために使用するタグを指定します。 
$(".selector").validate({
   wrapper:"li"
})
errorLabelContainer: 型 Selector。エラーメッセージをまとめて1つのコンテナに配置します。 
$("#myform").validate({   
    errorLabelContainer:"#messageBox",
    wrapper:"li",
    submitHandler:function() { 
        alert("Submitted!") 
    }
})
showErrors: 関数を指定します。検証に合格しなかった要素が全部でいくつあるかを表示できます。 
$(".selector").validate({  
    showErrors:function(errorMap,errorList) {
        $("#summary").html("Your form contains " + this.numberOfInvalids() + " errors,see details below.");
        this.defaultShowErrors();
    }
})
errorPlacement: 関数を指定します。エラーの表示場所をカスタマイズできます。 
$("#myform").validate({  
    errorPlacement:function(error,element) {  
        error.appendTo(element.parent("td").next("td"));
   },
   debug:true
})
success: 検証する要素が検証に合格した後の動作。文字列を指定すると CSS クラスとして扱われ、関数を指定することもできます。 
$("#myform").validate({        
    success:"valid",
        submitHandler:function() { 
            alert("Submitted!") 
        }
})
highlight: 検証に合格しなかった要素にエフェクトや点滅などを追加できます。

addMethod(name, method, message) メソッド

パラメータ name は追加するメソッドの名前です。

パラメータ method は関数で、3つのパラメータ (value,element,param) を受け取ります。
value は要素の値、element は要素自体、param はパラメータです。

addMethod を使用して、組み込みの Validation メソッド以外の検証メソッドを追加できます。たとえば、1つの文字だけを入力でき、範囲が a-f であるフィールドがある場合、書き方は次のとおりです。

$.validator.addMethod("af",function(value,element,params){  
    if(value.length>1){
        return false;
    }
    if(value>=params[0] && value<=params[1]){
        return true;
    }else{
        return false;
    }
},"必须是一个字母,且a-f");

フォームフィールドの name="username" がある場合、rules には次のように書きます：

username:{
   af:["a","f"]
}

addMethod の最初のパラメータは、追加する検証メソッドの名前です。この場合は af です。
addMethod の3番目のパラメータはカスタムのエラーメッセージです。ここでのメッセージは:「必须是一个字母,且a-f」です。
addMethod の2番目のパラメータは関数です。これは重要で、この検証メソッドを使用するときの書き方を決定します。

パラメータが1つだけの場合は直接書きます。たとえば af:"a" の場合、a が唯一のパラメータです。複数のパラメータがある場合は [] の中にカンマで区切って書きます。
