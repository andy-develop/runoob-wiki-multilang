Python3 タプル

Python のタプルはリストに似ていますが、タプルの要素は変更できない点が異なります。

タプルは小括弧を使用します( )、リストは角括弧を使用します[ ]。

タプルの作成はとても簡単で、括弧内に要素をカンマで区切って追加するだけです。

例(Python 3.0+)

>>> tup1 = ('Google', 'Runoob', 1997, 2000)
>>> tup2 = (1, 2, 3, 4, 5 )
>>> tup3 = "a", "b", "c", "d"   # 括弧は不要でも構いません
>>> type(tup3)
<class 'tuple'>

空のタプルを作成

tup1 = ()

タプルに要素が1つだけ含まれる場合は、要素の後にカンマを追加する必要があります,、そうしないと括弧が演算子として扱われます：

例(Python 3.0+)

>>> tup1 = (50)
>>> type(tup1)     # カンマを付けない場合、型は整数型になります
<class 'int'>

>>> tup1 = (50,)
>>> type(tup1)     # カンマを付けると、型はタプルになります
<class 'tuple'>

タプルは文字列と似ており、インデックスは 0 から始まり、スライスや結合などができます。

タプルのアクセス

タプルはインデックスを使用してタプル内の値にアクセスできます。次の例のとおりです:

例(Python 3.0+)

#!/usr/bin/python3 tup1 = ('Google', 'Runoob', 1997, 2000) tup2 = (1, 2, 3, 4, 5, 6, 7 ) print ("tup1[0]: ", tup1[0]) print ("tup2[1:5]: ", tup2[1:5])

上記の例の出力結果：

tup1[0]:  Google
tup2[1:5]:  (2, 3, 4, 5)

タプルの変更

タプルの要素の値は変更できませんが、タプルを結合することはできます。次の例のとおりです:

例(Python 3.0+)

#!/usr/bin/python3 tup1 = (12, 34.56) tup2 = ('abc', 'xyz') # 以下のタプル要素を変更する操作は無効です。 # tup1[0] = 100 # 新しいタプルを作成します tup3 = tup1 + tup2 print (tup3)

上記の例の出力結果：

(12, 34.56, 'abc', 'xyz')

タプルの削除

タプルの要素の値は削除できませんが、del文を使用してタプル全体を削除することはできます。次の例のとおりです:

例(Python 3.0+)

#!/usr/bin/python3 tup = ('Google', 'Runoob', 1997, 2000) print (tup) del tup print ("削除後のタプル tup :") print (tup)

上記の例でタプルが削除された後、変数を出力すると例外情報が表示されます。出力は次のようになります：

删除后的元组 tup : 
Traceback (most recent call last):
  File "test.py", line 8, in <module>
    print (tup)
NameError: name 'tup' is not defined

タプル演算子

文字列と同様に、タプル間では+、+=和 *+ 記号を使用して演算できます。つまり、タプルを結合したり複製したりでき、演算後は新しいタプルが生成されます。

Python 式結果説明
len((1, 2, 3))
3要素数を計算
>>> a = (1, 2, 3)
>>> b = (4, 5, 6)
>>> c = a+b
>>> c
(1, 2, 3, 4, 5, 6)
(1, 2, 3, 4, 5, 6)結合。c は新しいタプルで、a と b のすべての要素を含みます。
>>> a = (1, 2, 3)
>>> b = (4, 5, 6)
>>> a += b
>>> a
(1, 2, 3, 4, 5, 6)
(1, 2, 3, 4, 5, 6)結合。a は新しいタプルになり、a と b のすべての要素を含みます。
('Hi!',) * 4
('Hi!', 'Hi!', 'Hi!', 'Hi!')複製
3 in (1, 2, 3)

タプルのインデックス、スライス

タプルはシーケンスでもあるため、タプル内の指定した位置の要素にアクセスしたり、インデックス内の一部の要素をスライスしたりできます。次のようになります：

タプル：

tup = ('Google', 'Runoob', 'Taobao', 'Wiki', 'Weibo','Weixin')

Python 式結果説明
tup[1]'Runoob'2番目の要素を読み取る
tup[-2]'Weibo'逆方向に読み取り、最後から2番目の要素を読み取る
tup[1:]('Runoob', 'Taobao', 'Wiki', 'Weibo', 'Weixin')要素をスライス、2番目から後ろのすべての要素。
tup[1:4]('Runoob', 'Taobao', 'Wiki')要素をスライス、2番目から4番目の要素（インデックス 3）まで。

実行例は次のとおりです：

例

>>> tup = ('Google', 'Runoob', 'Taobao', 'Wiki', 'Weibo','Weixin')
>>> tup[1]
'Runoob'
>>> tup[-2]
'Weibo'
>>> tup[1:]
('Runoob', 'Taobao', 'Wiki', 'Weibo', 'Weixin')
>>> tup[1:4]
('Runoob', 'Taobao', 'Wiki')
>>>

タプルは不変であることについて

タプルの不変とは、タプルが指すメモリ上の内容が変更できないことを意味します。

>>> tup = ('r', 'u', 'n', 'o', 'o', 'b')
>>> tup[0] = 'g'     # 要素の変更はサポートされていません
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
>>> id(tup)     # メモリアドレスを確認
4440687904
>>> tup = (1,2,3)
>>> id(tup)
4441088800    # メモリアドレスが異なります

上記の例からわかるように、再代入されたタプル tup は新しいオブジェクトにバインドされており、元のオブジェクトが変更されたわけではありません。

    tuple は list と非常に似ていますが、tuple はいったん初期化すると変更できません。例えば、同級生の名前をリストアップする場合も同様です：

    コードは次のとおりです：

    >>> classmates = ('Michael', 'Bob', 'Tracy')

    さて、classmates という tuple は変更できません。append() や insert() などのメソッドもありません。他の要素を取得する方法は list と同じで、classmates

    コードは次のとおりです：

    >>> t = (1, 2)
>>> t
(1, 2)

    空の tuple を定義したい場合は、() と書けます：

    コードは次のとおりです：

    >>> t = ()
>>> t
()

    しかし、要素が1つだけの tuple を定義したい場合、次のように定義すると：

    コードは次のとおりです：

    >>> t = (1)
>>> t
1

    定義されるのは tuple ではなく、数値の 1 です！これは、括弧 () が tuple を表すことも、数式の小括弧を表すこともできるため、曖昧さが生じます。そのため、Python ではこの場合、小括弧として計算するという規則があり、計算結果は当然 1 になります。

    したがって、要素が1つだけの tuple を定義するときは、カンマを1つ付けなければなりません,曖昧さを解消するために：

    コードは次のとおりです:

    >>> t = (1,)
>>> t
(1,)

    Python は、要素が1つだけの tuple を表示するときにもカンマを1つ付けます。数式の括弧と誤解しないようにするためです。

    次に、「可変の」tuple を見てみましょう：

    コードは次のとおりです:

    >>> t = ('a', 'b', ['A', 'B'])
>>> t[2][0] = 'X'
>>> t[2][1] = 'Y'
>>> t
('a', 'b', ['X', 'Y'])

    この tuple は定義時に3つの要素、すなわち 'a'、'b'、そして1つの list を持っています。tuple はいったん定義したら不変ではないのですか？ どうして後で変わったのですか？

    落ち着いて、まず定義時の tuple に含まれる3つの要素を見てみましょう。list の要素 'A' と 'B' を 'X' と 'Y' に変更すると、tuple は次のようになります：表面的には tuple の要素が変わったように見えますが、実際に変わったのは tuple の要素ではなく、list の要素です。tuple が最初に指していた list は別の list に変更されていません。つまり、tuple のいわゆる「不変」とは、tuple の各要素の指す先が永遠に変わらないことを意味します。すなわち、'a' を指していたら 'b' を指すように変更できず、list を指していたら他のオブジェクトを指すように変更できません。ただし、指している list 自体は可変です！「指す先が変わらない」ことを理解したら、内容も変わらない tuple を作成するにはどうすればよいでしょうか？ そのためには、tuple の各要素自体も変更できないことを保証する必要があります。

    Python のタプルのアップグレード版 -- namedtuple(名前付きタプル)

    タプルには制限があります：タプル内部のデータに名前を付けることができないため、タプルが何を表しているのか分からないことがよくあります。そこでここではcollections.namedtupleこのファクトリ関数を導入して、フィールド名を持つタプルを構築します。名前付きタプルのインスタンスは通常のタプルと同じメモリを消費します。フィールド名は対応するクラスに格納されるからです。このクラスは通常のオブジェクトのインスタンスと比較しても小さくなります。Python はこれらのインスタンスの属性を __dict__ に格納しないためです。

    namedtuple オブジェクトの定義は次の形式です：

    collections.namedtuple(typename, field_names, verbose=False, rename=False)

    名前付きタプルのサブクラス typename を返します。各パラメータの意味は次のとおりです：

    • typename：タプル名
    • field_names: タプル内の要素の名前
    • rename: 要素名に Python のキーワードが含まれる場合は、rename=True に設定する必要があります
    • verbose: デフォルトで問題ありません

    次に、名前付きタプルの宣言とそのインスタンス化の方法を見てみましょう：

    import collections

# 两种方法来给 namedtuple 定义方法名
#User = collections.namedtuple('User', ['name', 'age', 'id'])
User = collections.namedtuple('User', 'name age id')
user = User('tester', '22', '464643123')

print(user)

    collections.namedtuple('User', 'name age id')名前付きタプルを作成するには、2つのパラメータが必要です。1つはクラス名、もう1つはクラスの各フィールド名です。後者は、複数の文字列からなる反復可能オブジェクト、またはスペースで区切られたフィールド名の文字列（この例のように）にすることができます。名前付きタプルは、フィールド名または位置によってフィールドの情報を取得できます。

    出力結果：

    User(name='tester', age='22', id='464643123')

    名前付きタプルの特有の属性:

    クラス属性_fields: このクラスのすべてのフィールド名を含むタプル_make(iterable): 反復可能オブジェクトを受け取り、このクラスのインスタンスを生成します_asdict(): 名前付きタプルを collections.OrdereDict の形式で返します。これを使って、タプル内の情報を分かりやすく表示できます。
    from collections import namedtuple

# 定义一个namedtuple类型User，并包含name，sex和age属性。
User = namedtuple('User', ['name', 'sex', 'age'])

# 创建一个User对象
user = User(name='Runoob', sex='male', age=12)

# 获取所有字段名
print( user._fields )

# 也可以通过一个list来创建一个User对象，这里注意需要使用"_make"方法
user = User._make(['Runoob', 'male', 12])

print( user )
# User(name='user1', sex='male', age=12)

# 获取用户的属性
print( user.name )
print( user.sex )
print( user.age )

# 修改对象属性，注意要使用"_replace"方法
user = user._replace(age=22)
print( user )
# User(name='user1', sex='male', age=21)

# 将User对象转换成字典，注意要使用"_asdict"
print( user._asdict() )
# OrderedDict([('name', 'Runoob'), ('sex', 'male'), ('age', 22)])

    上記のインスタンスの出力結果は次のとおりです：

    ('name', 'sex', 'age')
User(name='Runoob', sex='male', age=12)
Runoob
male
12
User(name='Runoob', sex='male', age=22)
OrderedDict([('name', 'Runoob'), ('sex', 'male'), ('age', 22)])

    タプルが指すメモリには、実際にはタプル内のデータのメモリアドレスの集合が保存されています（すなわちt[0], t[1]...t[n]のメモリアドレス）。そして、タプルが一度作成されると、この集合は追加・変更・削除ができません。集合内のアドレスが変わった場合、新しいアドレス集合を保存するためにタプル領域を再割り当てする必要があります（タプルはC言語のポインタ配列に似ていますが、この配列は変更できないだけです）。

print("t2[0]:",id(t2[0]))
print("t2[1]:",id(t2[1]))
print("t2[2]:",id(t2[2]))
print("连接后：")
t1= t1+t2
print("t1(t1+t2):",id(t1))
print("t1[0]:",id(t1[0]))
print("t1[1]:",id(t1[1]))
print("t1[2]:",id(t1[2]))
print("t1[3]:",id(t1[3]))
print("t1[4]:",id(t1[4]))
print("t1[5]:",id(t1[5]))

print("t1[5]增加d3:")
print("t1[5]=",t1[5])
print("t1[5]:",id(t1[5]))
print("t2=",t2)

    出力：

    >>> tup = (4,5,6,7,8)
>>> id(tup)
1953675198920

>>> id(tup)
195367

    この2つのタプルのidは同じではないことがわかります。同じタプル名を参照しているために誤解を招く可能性があるだけです。

    タプルのパッキングとアンパッキング

    Pythonでは、タプルのパッキングとアンパッキングは自動的に行われ、関数は必要ありません。そのため、関数の戻り値に括弧が付いたり付かなかったりすることに多くの人が非常に困惑します。

    まずコードを見てください：

    a=1,2,3
#它其实等价于下面的代码
a=(1,2,3)
#因为等号左边只有1个变量，而等号右边有3个值，因此自动装包成为一个元组

    次に以下のコードを見てください：

    a,b,c=(1,2,3)
#自动拆包，得到a=1,b=2,c=3

    関数がreturnするとき、実際には1つの値しか返せず、複数の値を返すことはできません。

    複数の値をreturnしてもエラーにならないし、正常に動作すると疑問に思う人もいるでしょう。

    それはまさにPythonが複数の戻り値を自動的にパッキングするためです。

    したがって、複数の変数を返し、外側で1つの変数だけを使って受け取ると、タプルを受け取ることになります。

    一方、複数の変数で受け取ると、それぞれの値に対応して受け取れます。これは自動アンパッキングによるものです。

    この点を理解することは、関数の戻り値や辞書のキーと値のペアなどを理解するのに役立ちます。

    =========================================================

    理解を深めるために、最後のコードをもう一度見てください：

    a=10
b=20
a,b=b,a,1

    実行するとエラーになります：too many values to unpack

    ここでは明らかに、タプル内に3つの値がありアンパッキングが必要なのに、2つの値だけを使って受け取っていると示されています。タプルが実際にアンパッキングの動作を実行したことが証明されます。
