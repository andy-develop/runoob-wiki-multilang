Python 指定範囲内の素数を出力

Python3 例

素数（prime number）は無限に存在する。1とそれ自身以外の約数で割り切れることはない。

以下の例は、指定範囲内の素数を出力できます：

例(Python 3.0+)

#!/usr/bin/python3 # 指定範囲内の素数を出力 # take input from the user lower = int(input("区間の最小値を入力:")) upper = int(input("区間の最大値を入力:")) for num in range(lower,upper + 1): # 素数は 1 より大きい if num > 1: for i in range(2,num): if (num % i) == 0: break else: print(num)

上記のプログラムを実行すると、出力結果は次のとおりです：

試し割り法を使用

試し割り法は基本的なアルゴリズムで、各数に対して割り算を試して素数かどうかを判定します。以下は試し割り法を使用して指定範囲内の素数を出力するコードです：

例

def is_prime(n):
    """数が素数かどうかを判定する"""
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True

def primes_in_range(start, end):
    """指定範囲内の素数を出力する"""
    for num in range(start, end + 1):
        if is_prime(num):
            print(num)

# 例：10 から 50 までの範囲の素数を出力
primes_in_range(10, 50)

エラトステネスの篩を使用

エラトステネスの篩はより効率的なアルゴリズムで、特に大きな範囲の素数を求めるのに適しています。以下はエラトステネスの篩を使用して指定範囲内の素数を出力するコードです：

例

def sieve_of_eratosthenes(max_num):
    """エラトステネスの篩を使用して max_num までのすべての素数を求める"""
    sieve = [True] * (max_num + 1)
    sieve[0] = sieve[1] = False  # 0 と 1 は素数ではない
    p = 2
    while p * p <= max_num:
        if sieve[p]:
            for multiple in range(p * p, max_num + 1, p):
                sieve[multiple] = False
        p += 1
    return [p for p, is_prime in enumerate(sieve) if is_prime]

def primes_in_range(start, end):
    """指定範囲内の素数を出力する"""
    primes = sieve_of_eratosthenes(end)
    for num in primes:
        if num >= start:
            print(num)

# 例：10 から 50 までの範囲の素数を出力
primes_in_range(10, 50)
