Python3 データ型変換

時には、データの組み込み型を変換する必要があります。データ型の変換は、一般的にはデータ型を関数名として使用するだけです。

Python のデータ型変換は2種類に分けられます：

  • 暗黙の型変換 - 自動で完了
  • 明示的な型変換 - 型関数を使用して変換する必要があります

暗黙の型変換

暗黙の型変換では、Python が自動的にあるデータ型を別のデータ型に変換するため、私たちが介入する必要はありません。

以下の例では、異なる2つの型のデータに対して演算を行います。低い方のデータ型（整数）は、データ損失を避けるために高い方のデータ型（浮動小数点数）に変換されます。

例

num_int = 123
num_flo = 1.23

num_new = num_int + num_flo

print("num_int のデータ型:",type(num_int))
print("num_flo のデータ型:",type(num_flo))

print("num_new の値:",num_new)
print("num_new のデータ型:",type(num_new))

上記の例の出力結果は次のとおりです：

num_int 数据类型为: <class 'int'>
num_flo 数据类型为: <class 'float'>
num_new: 值为: 124.23
num_new 数据类型为: <class 'float'>

コードの解説：

  • 例では、異なるデータ型の2つの変数num_int 和 num_floを加算演算し、変数num_newに格納しています。
  • 次に、3つの変数のデータ型を確認します。
  • 出力結果では、num_int 是 整型（integer） ， num_flo 是 浮点型（float）。
  • 同様に、新しい変数num_new 是 浮点型（float）は、Python が小さい方のデータ型を大きい方のデータ型に変換して、データ損失を避けるためです。

もう一つの例を見てみましょう。整数型データと文字列型データを加算します：

例

num_int = 123
num_str = "456"

print("num_int のデータ型:",type(num_int))
print("num_str のデータ型:",type(num_str))

print(num_int+num_str)

上記の例の出力結果は次のとおりです：

num_int 数据类型为: <class 'int'>
num_str 数据类型为: <class 'str'>
Traceback (most recent call last):
  File "/runoob-test/test.py", line 7, in <module>
    print(num_int+num_str)
TypeError: unsupported operand type(s) for +: 'int' and 'str'

出力からわかるように、整数型と文字列型の演算結果はエラーになり、TypeError が出力されます。Python はこの場合、暗黙の変換を使用できません。

しかし、Python はこれらの型の場合に対する解決策を提供しています。それが明示的な変換です。

明示的な型変換

明示的な型変換では、ユーザーがオブジェクトのデータ型を必要なデータ型に変換します。int()、float()、str() などの定義済み関数を使用して、明示的な型変換を実行します。

int()整数型への強制変換：

例

x = int(1)   # x の出力結果は 1
y = int(2.8) # y の出力結果は 2
z = int("3") # z の出力結果は 3

float()浮動小数点型への強制変換：

例

x = float(1)     # x の出力結果は 1.0
y = float(2.8)   # y の出力結果は 2.8
z = float("3")   # z の出力結果は 3.0
w = float("4.2") # w の出力結果は 4.2

str()文字列型への強制変換：

例

x = str("s1") # x の出力結果は 's1'
y = str(2)    # y の出力結果は '2'
z = str(3.0)  # z の出力結果は '3.0'

整数型と文字列型の演算は、強制型変換を使用して行うことができます：

例

num_int = 123
num_str = "456"

print("num_int のデータ型:",type(num_int))
print("型変換前の num_str のデータ型:",type(num_str))

num_str = int(num_str)    # 整数型に強制変換
print("型変換後の num_str のデータ型:",type(num_str))

num_sum = num_int + num_str

print("num_int と num_str を加算した結果:",num_sum)
print("sum のデータ型:",type(num_sum))

上記の例の出力結果は次のとおりです：

num_int 数据类型为: <class 'int'>
类型转换前，num_str 数据类型为: <class 'str'>
类型转换后，num_str 数据类型为: <class 'int'>
num_int 与 num_str 相加结果为: 579
sum 数据类型为: <class 'int'>

以下の組み込み関数は、データ型間の変換を実行できます。これらの関数は、変換された値を表す新しいオブジェクトを返します。

関数説明

int(x [,base])

x を整数に変換します

float(x)

x を浮動小数点数に変換します

complex(real [,imag])

複素数を作成します

str(x)

オブジェクト x を文字列に変換します

repr(x)

オブジェクト x を式の文字列に変換します

eval(str)

文字列内の有効な Python 式を評価し、オブジェクトを返します

tuple(s)

シーケンス s をタプルに変換します

list(s)

シーケンス s をリストに変換します

set(s)

変更可能な集合（set）に変換します

dict(d)

辞書を作成します。d は (key, value) タプルのシーケンスである必要があります。

frozenset(s)

変更不可能な集合（frozenset）に変換します

chr(x)

整数を文字に変換します

ord(x)

文字をその整数値に変換します

hex(x)

整数を16進数の文字列に変換します

oct(x)

整数を8進数の文字列に変換します

bool(x)

オブジェクト x をブール値（True または False）に変換します

bytes([source[, encoding[, errors]]])

オブジェクトをイミュータブルなバイトシーケンスに変換します

bytearray([source[, encoding[, errors]]])

オブジェクトをミュータブルなバイト配列（bytearray）に変換します

memoryview(obj)

指定された引数のメモリビューオブジェクトを返します（データはコピーされません）

bin(x)

整数を2進数の文字列に変換します

ascii(x)

オブジェクトの ASCII 表現を返します。非 ASCII 文字はエスケープされます
その他の拡張

    データ型の高低の区別：

    「より高いデータ型」と「より低いデータ型」は、暗黙の型変換においてデータの精度を説明するために使われる概念です。精度は、データ型が表すことができる情報量や詳細さと理解できます。Python では、データ型の「高さ」と「低さ」は主にその精度に基づいて判断されます。

    ここでの「より高い」データ型とは、より多くの情報（またはより正確な情報）を表すことができるデータ型を指し、「より低い」データ型は、表す情報が少ないことを指します。具体的には、浮動小数点数は整数よりも「高い」と言えます。なぜなら、浮動小数点数は整数だけでなく小数も表すことができるからです。したがって、この例では、情報が失われないように、整数は自動的に浮動小数点数に変換されます。

    さらに、複素数（complex）は浮動小数点数（float）や整数（int）よりも「高い」と言えます。なぜなら、複素数は実数と虚数を表すことができますが、浮動小数点数と整数は実数しか表せないからです。そのため、演算時にオペランドに複素数が含まれる場合、他の浮動小数点数や整数は複素数に変換されます。

    通常、Python のデータ型の「高低」は、次の順序で理解できます：ブール（bool）< 整数型（int）< 浮動小数点型（float）< 複素数（complex）。この順序は、主にデータ型が表すことができる情報の範囲と精度に基づいて決まります。

    異なるデータ型間で自由に変換できるかどうか：

    Python には異なるデータ型間の変換を実現する組み込み関数がいくつか用意されていますが、例えばint(), float(), str(), list(), tuple(), set()などがあります。しかし、すべての型のデータを他の任意の型に変換できるわけではありません。変換が可能かどうかは、主にデータ自体が対象の型を表すのに十分な情報を含んでいるかどうかに依存します。

    例えば：

    1. 整数を文字列に簡単に変換できます。なぜなら、すべての整数には明確な文字列表現があるからです（例えば、整数123は文字列"123"と表せます）。
    2. 同様に、数字の文字だけを含む文字列（"123"など）は、整数や浮動小数点数に変換できます。この文字列には数字を表すのに十分な情報が含まれているからです。

    しかし：

    1. 非数値の文字列（"Hello"など）は、整数や浮動小数点数に変換できません。この文字列には数字を表すための情報が一切含まれていないからです。
    2. リストやタプルは、セット（集合）に変換できます（その要素が変更不可能な場合）。しかし、整数に変換することはできません。セットやリストの要素は、単一の数字として合理的に表すことができないからです。

    総じて、データ型の変換は無制限ではなく、元のデータが対象の型を表すのに十分な情報を提供できるかどうかに依存します。プログラミングで型変換を行う際は、この点に注意する必要があります。
