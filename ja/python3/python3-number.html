Python3 数値(Number)

Python の数値データ型は数値を格納するために使用します。

データ型は変更できません。つまり、数値データ型の値を変更する場合は、メモリ領域を再割り当てすることになります。

次の例では、変数に代入するときに Number オブジェクトが作成されます：

var1 = 1
var2 = 10

また、del 文を使用して数値オブジェクトの参照を削除することもできます。

del 文の構文は次のとおりです：

del var1[,var2[,var3[....,varN]]]

del 文を使用して、単一または複数のオブジェクトの参照を削除できます。例：

del var
del var_a, var_b

Python は次の 3 つの異なる数値型をサポートします：

  • 整数型(int)- 通常は整数型または整数と呼ばれ、正または負の整数で、小数点はありません。Python3 の整数型にはサイズ制限がなく、Long 型として使用できます。そのため Python3 には Python2 の Long 型はありません。ブール(bool)は整数型のサブタイプです。

  • 浮動小数点型(float)- 浮動小数点型は整数部と小数部から構成されます。浮動小数点型は科学的記数法でも表せます（2.5e2 = 2.5 x 102 = 250）

  • 複素数( (complex))- 複素数は実数部と虚数部から構成され、a + bj または complex(a,b) で表せます。複素数の実部 a と虚部 b はどちらも浮動小数点型です。

Python 数値型変換

データの組み込み型を変換する必要がある場合があります。データ型の変換は、データ型を関数名として使うだけです。

  • int(x)x を整数に変換します。

  • float(x)x を浮動小数点数に変換します。

  • complex(x)x を複素数に変換します。実数部は x、虚数部は 0 です。

  • complex(x, y)x と y を複素数に変換します。実数部は x、虚数部は y です。x と y は数値式です。

次の例では、浮動小数点変数 a を整数に変換します：

>>> a = 1.0
>>> int(a)
1

Python 数値演算

Python インタプリタは簡単な計算機として使用できます。インタプリタに式を入力すると、その式の値を出力します。

式の構文はとても分かりやすいです：+, -, * 和 /、他の言語（PascalやCなど）と同じです。例：

>>> 2 + 2
4
>>> 50 - 5*6
20
>>> (50 - 5*6) / 4
5.0
>>> 8 / 5  # 总是返回一个浮点数
1.6

注意：異なるマシンでは、浮動小数点演算の結果が異なる場合があります。

整数除算では、除算/は常に浮動小数点数を返します。整数の結果だけが必要で、小数部分を切り捨てたい場合は、演算子// ：

>>> 17 / 3  # 整数除法返回浮点型
5.666666666666667
>>>
>>> 17 // 3  # 整数除法返回向下取整后的结果
5
>>> 17 % 3  # ％操作符返回除法的余数
2
>>> 5 * 3 + 2 
17

注意：//得られる結果は必ずしも整数型とは限らず、分母や分子のデータ型に関係します。

>>> 7//2
3
>>> 7.0//2
3.0
>>> 7//2.0
3.0
>>>

等号=は変数に値を代入するために使用します。代入後、インタプリタは次のプロンプト以外には何も表示しません。

>>> width = 20
>>> height = 5*9
>>> width * height
900

Python では**演算で冪乗を計算できます：

>>> 5 ** 2  # 5 的平方
25
>>> 2 ** 7  # 2的7次方
128

変数は使用する前に「定義」（つまり値を代入）する必要があります。そうしないとエラーが発生します：

>>> n   # 尝试访问一个未定义的变量
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'n' is not defined

異なる型の数を混在させて演算すると、整数は浮動小数点数に変換されます：

>>> 3 * 3.75 / 1.5
7.5
>>> 7.0 / 2
3.5

対話モードでは、最後に出力された式の結果が変数_ に代入されます。例：

>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _
113.0625
>>> round(_, 2)
113.06

ここで、_ 変数はユーザーによって読み取り専用変数と見なされるべきです。

乱数関数

乱数は数学、ゲーム、セキュリティなどの分野で使用でき、アルゴリズムに組み込まれてアルゴリズムの効率を向上させ、プログラムの安全性を高めることもよくあります。

Python には以下の一般的な乱数関数が含まれます：

関数説明
choice(seq)シーケンスの要素からランダムに1つの要素を選びます。例: random.choice(range(10)) は 0 から 9 の間からランダムに整数を選びます。
randrange ([start,] stop [,step]) 指定された範囲内で、指定された基数で増加する集合から乱数を取得します。基数のデフォルト値は 1 です。
random() 次の実数をランダムに生成します。範囲は [0,1) です。
seed([x]) 乱数生成器のシード(seed)を変更します。原理を理解していない場合は、特に seed を設定する必要はありません。Python が seed を選択します。
shuffle(lst) シーケンスのすべての要素をランダムに並べ替えます。
uniform(x, y)次の実数をランダムに生成します。範囲は [x,y] です。

    「4舍6入5看齐,奇进偶不进」（四捨六入五成双）は、浮動小数点数のコンピュータでの表現の問題ではないと思います。コンピュータの浮動小数点数の表現はIEEEで定義された標準規則であり、Pythonに存在するなら、他の言語に存在しない道理はありません。実際には、この丸め方法が従来の「四捨五入」より科学計算において正確だからです。また、国家標準でも「4舍6入5看齐,奇进偶不进」（四捨六入五成双）を使用して「四捨五入」に取って代わることが規定されています。

    統計学の観点から言えば、大量のデータを無造作に四捨五入すると統計結果が大きめになります。「奇進偶捨」は丸め誤差を最小限に抑えられます。

    奇進偶捨は、比較的正確で科学的な数値の保持方法であり、数字の丸め規則です。

    その具体的な要件は以下の通りです（小数第2位までを保持する場合を例とします）：

    • （1）保持したい位の次の位が4以下の数字の場合は切り捨てます。例：5.214を小数第2位まで保持すると5.21。
    • （2）保持したい位の次の位が6以上の数字の場合は切り上げます。例：5.216を小数第2位まで保持すると5.22。
    • （3）保持する位が整数部分または小数第1位までの場合は、保持する位に基づいて奇進偶捨を決定します：
      >>> round(5.215,2)#实际并没有进位
5.21
>>> round(5.225,2)
5.22
>>>
>>> round(1.5)#此处进位
2
>>> round(1.5)==round(2.5)#偶数舍去
True
>>> round(1.15,1)
1.1
>>> round(1.25,1)
1.2
>>> round(1.151,1)
1.2
>>> round(1.251,1)
1.3
    • （4）保持したい位の次の位が5で、その後に数字がある場合は切り上げます。例：5.2152を小数第2位まで保持すると5.22、5.2252は5.23、5.22500001は5.23。
    統計学の観点から、「奇進偶捨」は「四捨五入」より科学的です。大量の演算では、丸め後の結果の誤差の平均がゼロに近づきます。四捨五入のように5があれば必ず切り上げるのではなく、結果が大きい数に偏り、誤差が蓄積して系統誤差を生じることになります。「奇進偶捨」は測定結果が丸め誤差の影響を受けるのを最小限に抑えます。

    Pythonの整数比較に関する落とし穴：

    Pythonではすべてがオブジェクトです。オブジェクトの比較には==またはis。

    ==は2つのオブジェクトの内容が等しいかどうかを比較し、デフォルトでオブジェクトの__eq__()メソッドを呼び出します。

    isは2つのオブジェクトのidが等しいかどうか、つまり同じオブジェクトであるか、同じメモリアドレスを指しているかを比較します。

    >>> a = 4
>>> b = 4
>>> a == b
True
>>> a is b
True
>>> a = 256
>>> b = 256
>>> a == b
True
>>> a is b
True
>>> a = 257
>>> b = 257
>>> a == b
True
>>> a is b
False

    最初のいくつかの比較結果は理解できますが、最後にa/bがどちらも整数オブジェクト257を指している場合、isで比較した結果はFalseになります。

    これは、Pythonがパフォーマンスを考慮して内部で最適化を行っており、整数オブジェクトについて、頻繁に使用される一部の整数オブジェクトをキャッシュして、small_intsというリンクリストに保存しているためです。

    Pythonの全体のライフサイクル中、これらの整数オブジェクトを参照する必要がある場所では、新しい整数オブジェクトを再作成しません。範囲は[-5,256]。

    さらに以下の例を見てみましょう：

    >>> a = 259
>>> def foo () :
...     b = 259
...     c = 259
...     print(a is b)
...     print(b is c)
...
>>> foo()
False
True

    これは、Pythonプログラムがコードブロックで構成されており、コードブロックがプログラムの最小基本単位として実行されるためです。1つのモジュールファイル/1つの関数本体/1つのクラス/対話式コマンド内の単一行コードはすべてコードブロックと呼ばれます。

    上記のプログラムには2つのコードブロックがあります。1つは名前aがあるコードブロック、もう1つは名前b/cがあるコードブロックです。Pythonのもう1つの最適化点は、同じコードブロック内で作成された2つの整数オブジェクトの値が等しい場合、これら2つのオブジェクトが同じ整数オブジェクトを参照することです。Pythonはパフォーマンスを考慮して、不変オブジェクトであれば、同じコードブロック内で値が等しいオブジェクトは重複して作成されず、既存のオブジェクトを直接参照します。整数オブジェクトだけでなく、文字列オブジェクトも同じ原則に従います。

    本文およびメモ欄での _ 変数に関する議論について、個人的にテストして少しばかりまとめてみました：

    システムは自動的に直前の式の結果を変数 _ に代入します。ユーザーにとって、これは「読み取り専用変数」一方、ユーザーは自分で新しい _ 変数を手動で作成できます。新しい _ 変数が現れると、システムはこの新しい変数を優先的に参照します。新しい変数の値は自動的に更新されませんが、読み取り専用変数 _ は更新され続けます。ただし、ユーザーが自前の _ 変数を削除しない限り、参照されることはありません。

    >>> t=1
>>> p=2
>>> t+p
3
>>> _+1  # 系统将上一表达式结果 3 赋值给变量 _ ，3+1=4
4
>>> _+1  # 系统将上一表达式结果 4 赋值给变量 _ ，4+1=5
5
>>> _=10  # 系统将上一表达式结果 5 赋值给变量 _ ，同时用户手动创建变量 _=10
>>> _+1   # 优先引用用户变量（10），10+1=11,同时系统将11这个值赋给只读变量 _
11
>>> _+1   # 优先引用用户变量（10），10+1=11,同时系统将11这个值赋给只读变量 _
11
>>> del _ # 删除用户变量（10）
>>> _+1  # 此时只有只读变量 _ ，值为11，11+1=12
12

    上記で言及した2つの変数が同名である件について、個人的にはソースコードを見ていないため推測でしかありませんが、2つの変数は内部では異なるものの、識別子はユーザーにとって透過的ではないため、どちらも _ としか見えないのです。

    誤りがあればご指摘歓迎します

    randrange() 和 uniform()はPythonで乱数を生成するための関数で、どちらもrandomモジュールに属します。

    ニーズに応じて適切な関数を選択してください：

    • 整数の乱数を生成する場合は、randrange()。

    • 浮動小数点数の乱数を生成する場合は、uniform()。

    以下はそれらの違いと関連性です：

    違い

    1、所属モジュール

    • 両方ともrandomモジュールに属しており、使用前にそのモジュールをインポートする必要があります：import random

    2、生成する乱数のタイプ

    • randrange()生成されるのは整数の乱数。

    • uniform()生成されるのは浮動小数点数の乱数。

    3、乱数を生成する範囲

    • randrange()の範囲は[start, stop)、すなわちstartを含むがstopは含まない。stepパラメータでステップを指定でき、乱数同士の間隔を制御できます。

    • uniform()の範囲は[a, b]、すなわちa 和 bを含む。生成される乱数浮動小数点数はa 和 bの間で一様分布します。

    共通部分

    1、同じrandomモジュールに属する

    • どちらも乱数の生成に使用され、ともにrandomモジュールに依存します。

    2、範囲制御

    • どちらも生成する乱数の範囲を指定できます。

    3、ランダム性

    • 生成される乱数はすべて擬似乱数であり、同じ乱数シード（seed）に基づく場合、結果は再現可能です。

    サンプル比較

    1 から 10 までの乱数を生成する

    1 から 10 までの乱数を生成するには、randrange() を使用：

    import random
num = random.randrange(1, 11)  # 生成 1 到 10 之间的随机整数
print(num)

    1 から 10 までの乱数を生成するには、uniform() を使用：

    import random
num = random.uniform(1.0, 10.0)  # 生成 1.0 到 10.0 之间的随机浮点数
print(num)
    特性randrange()uniform()
    生成タイプ整数の乱数浮動小数点数の乱数
    範囲[start, stop)（左閉右開）[a, b]（閉区間）
    ステップ制御対応（stepパラメータによる）非対応
    適用場面整数の乱数を生成する必要がある場合浮動小数点数の乱数を生成する必要がある場合
