Python MySQL - mysql-connector ドライバ

MySQL は最も人気のあるリレーショナルデータベース管理システムです。MySQL に詳しくない場合は、私たちのMySQL チュートリアル

この章では、mysql-connectorMySQL への接続に使用するmysql-connector 是 MySQL公式提供のドライバを紹介します。

私たちは次を使用できますpipコマンドでインストールします。mysql-connector：

python -m pip install mysql-connector

次のコードで mysql-connector が正常にインストールされたかテストします：

demo_mysql_test.py:

import mysql.connector

上記のコードを実行し、エラーが発生しなければ、インストールは成功です。

注注意：MySQL が 8.0 の場合、パスワードプラグインの検証方法が変更されています。以前のバージョンは mysql_native_password、8.0 では caching_sha2_password です。そのため、いくつか変更が必要です：

最初に my.ini の設定を変更します：

[mysqld]
default_authentication_plugin=mysql_native_password

次に mysql で以下のコマンドを実行してパスワードを変更します：

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '新密码';

詳細は以下を参照してください：Python MySQL8.0 接続の問題。

データベース接続の作成

以下のコードでデータベースに接続できます：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", # データベースのホストアドレス user="yourusername", # データベースのユーザー名 passwd="yourpassword" # データベースのパスワード ) print(mydb)

データベースの作成

データベースの作成には「CREATE DATABASE」ステートメントを使用します。次に runoob_db という名前のデータベースを作成します：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456" ) mycursor = mydb.cursor() mycursor.execute("CREATE DATABASE runoob_db")

データベースを作成する前に、「SHOW DATABASES」ステートメントを使用してデータベースが存在するか確認することもできます：

demo_mysql_test.py:

すべてのデータベースのリストを出力します：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456" ) mycursor = mydb.cursor() mycursor.execute("SHOW DATABASES") for x in mycursor: print(x)

または、データベースに直接接続することもできます。データベースが存在しない場合はエラーメッセージが出力されます：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" )

データテーブルの作成

データテーブルの作成には"CREATE TABLE"ステートメントを使用します。作成前に、データベースが存在することを確認する必要があります。次に、sitesという名前のデータテーブルを作成します：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("CREATE TABLE sites (name VARCHAR(255), url VARCHAR(255))")
実行が成功すると、データベースに作成されたデータテーブル sites が表示されます。フィールドは name と url です。

私たちは次を使用することもできます"SHOW TABLES"ステートメントを使って、データテーブルが存在するかどうかを確認できます：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("SHOW TABLES") for x in mycursor: print(x)

主キーの設定

テーブル作成時には通常、主キー（PRIMARY KEY）を設定します。次を使用できます："INT AUTO_INCREMENT PRIMARY KEY"ステートメントで主キーを作成します。主キーの開始値は 1 で、自動的に増加します。

テーブルがすでに作成されている場合は、次を使用してALTER TABLE主キーをテーブルに追加する必要があります：

demo_mysql_test.py:

sites テーブルに主キーを追加します。

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("ALTER TABLE sites ADD COLUMN id INT AUTO_INCREMENT PRIMARY KEY")

sites テーブルをまだ作成していない場合は、次のコードを使用して直接作成できます。

demo_mysql_test.py:

テーブルに主キーを作成します。

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("CREATE TABLE sites (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(255), url VARCHAR(255))")

データの挿入

データの挿入には"INSERT INTO"ステートメントを使用します：

demo_mysql_test.py:

sites テーブルに 1 件のレコードを挿入します。

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "INSERT INTO sites (name, url) VALUES (%s, %s)" val = ("RUNOOB", "https://www.runoob.com") mycursor.execute(sql, val) mydb.commit() # データテーブルの内容が更新された場合は、このステートメントを使用する必要があります print(mycursor.rowcount, "レコードが正常に挿入されました。")

コードを実行すると、出力結果は次のとおりです：

1 记录插入成功

一括挿入

一括挿入にはexecutemany()メソッドを使用します。このメソッドの 2 番目のパラメータは、挿入するデータを含むタプルのリストです：

demo_mysql_test.py:

sites テーブルに複数のレコードを挿入します。

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "INSERT INTO sites (name, url) VALUES (%s, %s)" val = [ ('Google', 'https://www.google.com'), ('Github', 'https://www.github.com'), ('Taobao', 'https://www.taobao.com'), ('stackoverflow', 'https://www.stackoverflow.com/') ] mycursor.executemany(sql, val) mydb.commit() # データテーブルの内容が更新された場合は、このステートメントを使用する必要があります print(mycursor.rowcount, "レコードが正常に挿入されました。")

コードを実行すると、出力結果は次のとおりです：

4 记录插入成功。

上記のコードを実行した後、データテーブルのレコードを確認できます：

データレコードの挿入後にそのレコードの ID を取得したい場合は、次のコードを使用できます：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "INSERT INTO sites (name, url) VALUES (%s, %s)" val = ("Zhihu", "https://www.zhihu.com") mycursor.execute(sql, val) mydb.commit() print("1 件のレコードが挿入されました。ID:", mycursor.lastrowid)

コードを実行すると、出力結果は次のとおりです：

1 条记录已插入, ID: 6

データのクエリ

データのクエリにはSELECTステートメントを使用します：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("SELECT * FROM sites") myresult = mycursor.fetchall() # fetchall() はすべてのレコードを取得します for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(1, 'RUNOOB', 'https://www.runoob.com')
(2, 'Google', 'https://www.google.com')
(3, 'Github', 'https://www.github.com')
(4, 'Taobao', 'https://www.taobao.com')
(5, 'stackoverflow', 'https://www.stackoverflow.com/')
(6, 'Zhihu', 'https://www.zhihu.com')

指定したフィールドのデータを読み取ることもできます：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("SELECT name, url FROM sites") myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

('RUNOOB', 'https://www.runoob.com')
('Google', 'https://www.google.com')
('Github', 'https://www.github.com')
('Taobao', 'https://www.taobao.com')
('stackoverflow', 'https://www.stackoverflow.com/')
('Zhihu', 'https://www.zhihu.com')

1 件のデータだけを読み取りたい場合は、fetchone()メソッドを使用できます：

demo_mysql_test.py:

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("SELECT * FROM sites") myresult = mycursor.fetchone() print(myresult)

コードを実行すると、出力結果は次のとおりです：

(1, 'RUNOOB', 'https://www.runoob.com')

where 条件文

指定した条件のデータを読み取りたい場合は、whereステートメントを使用します：

demo_mysql_test.py

name フィールドが RUNOOB のレコードを読み取ります：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "SELECT * FROM sites WHERE name ='RUNOOB'" mycursor.execute(sql) myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(1, 'RUNOOB', 'https://www.runoob.com')

ワイルドカードを使用することもできます%：

demo_mysql_test.py

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "SELECT * FROM sites WHERE url LIKE '%oo%'" mycursor.execute(sql) myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(1, 'RUNOOB', 'https://www.runoob.com')
(2, 'Google', 'https://www.google.com')

データベースクエリへの SQL インジェクション攻撃を防ぐために、次を使用できます：%sプレースホルダを使用してクエリ条件をエスケープします：

demo_mysql_test.py

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "SELECT * FROM sites WHERE name = %s" na = ("RUNOOB", ) mycursor.execute(sql, na) myresult = mycursor.fetchall() for x in myresult: print(x)

ソート

クエリ結果のソートには、ORDER BYステートメントを使用します。デフォルトのソートは昇順で、キーワードはASCです。降順ソートを設定する場合は、キーワードDESC。

demo_mysql_test.py

name フィールドをアルファベットの昇順でソートします：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "SELECT * FROM sites ORDER BY name" mycursor.execute(sql) myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(3, 'Github', 'https://www.github.com')
(2, 'Google', 'https://www.google.com')
(1, 'RUNOOB', 'https://www.runoob.com')
(5, 'stackoverflow', 'https://www.stackoverflow.com/')
(4, 'Taobao', 'https://www.taobao.com')
(6, 'Zhihu', 'https://www.zhihu.com')

降順ソートの例：

demo_mysql_test.py

name フィールドをアルファベットの降順でソートします：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "SELECT * FROM sites ORDER BY name DESC" mycursor.execute(sql) myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(6, 'Zhihu', 'https://www.zhihu.com')
(4, 'Taobao', 'https://www.taobao.com')
(5, 'stackoverflow', 'https://www.stackoverflow.com/')
(1, 'RUNOOB', 'https://www.runoob.com')
(2, 'Google', 'https://www.google.com')
(3, 'Github', 'https://www.github.com')

Limit

クエリするデータ量を設定したい場合は、"LIMIT"ステートメントで指定できます：

demo_mysql_test.py

最初の 3 件のレコードを読み取ります：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("SELECT * FROM sites LIMIT 3") myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(1, 'RUNOOB', 'https://www.runoob.com')
(2, 'Google', 'https://www.google.com')
(3, 'Github', 'https://www.github.com')

開始位置を指定することもできます。使用するキーワードはOFFSET：

demo_mysql_test.py

2 番目から最初の 3 件のレコードを読み取ります：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() mycursor.execute("SELECT * FROM sites LIMIT 3 OFFSET 1") # 0 は 1 番目、1 は 2 番目、以下同様です myresult = mycursor.fetchall() for x in myresult: print(x)

コードを実行すると、出力結果は次のとおりです：

(2, 'Google', 'https://www.google.com')
(3, 'Github', 'https://www.github.com')
(4, 'Taobao', 'https://www.taobao.com')

レコードの削除

レコードの削除には"DELETE FROM"ステートメントを使用します：

demo_mysql_test.py

name が stackoverflow のレコードを削除します：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "DELETE FROM sites WHERE name = 'stackoverflow'" mycursor.execute(sql) mydb.commit() print(mycursor.rowcount, "件のレコードが削除されました")

コードを実行すると、出力結果は次のとおりです：

1  条记录删除

注意：削除ステートメントは慎重に使用してください。削除ステートメントでは WHERE 条件を必ず指定してください。指定しないと、テーブル全体のデータが削除されます。

データベースクエリへの SQL インジェクション攻撃を防ぐために、次を使用できます：%sプレースホルダを使用して削除ステートメントの条件をエスケープします：

demo_mysql_test.py

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "DELETE FROM sites WHERE name = %s" na = ("stackoverflow", ) mycursor.execute(sql, na) mydb.commit() print(mycursor.rowcount, "件のレコードが削除されました")

コードを実行すると、出力結果は次のとおりです：

1  条记录删除

テーブルデータの更新

データテーブルの更新には"UPDATE"ステートメントを使用します：

demo_mysql_test.py

name が Zhihu のフィールドデータを ZH に変更します：

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "UPDATE sites SET name = 'ZH' WHERE name = 'Zhihu'" mycursor.execute(sql) mydb.commit() print(mycursor.rowcount, "件のレコードが変更されました")

コードを実行すると、出力結果は次のとおりです：

1  条记录被修改

注意：UPDATE ステートメントでは WHERE 条件を必ず指定してください。指定しないと、テーブル全体のデータが更新されます。

データベースクエリへの SQL インジェクション攻撃を防ぐために、%s プレースホルダを使用して更新ステートメントの条件をエスケープします：

demo_mysql_test.py

import mysql.connector mydb = mysql.connector.connect( host="localhost", user="root", passwd="123456", database="runoob_db" ) mycursor = mydb.cursor() sql = "UPDATE sites SET name = %s WHERE name = %s" val = ("Zhihu", "ZH") mycursor.execute(sql, val) mydb.commit() print(mycursor.rowcount, "件のレコードが変更されました")

コードを実行すると、出力結果は次のとおりです：

1  条记录被修改

    Runoob で Python3 を学習し、python3 mysql(mysql-connector) まで進み、mysql-8.0.16 をインストールして、サンプルプログラムに従って python を実行したところ、この大きな問題に遭遇しました：

    authentication plugin 'calling_sha2_password' is not supported.

    ネット上で数多くの回答を探しましたが、今からまとめます。

    ルートディレクトリに my.ini ファイルを新規作成し、MySQL を設定します。以下の設定情報を新しく作成した my.ini ファイルにコピーしてください。

    [mysqld]
# 设置3306端口
port = 3306
# 设置mysql的安装目录
basedir=D:\\web\\mysql-8.0.16-winx64
# 设置 mysql数据库的数据的存放目录，MySQL 8+ 不需要以下配置，系统自己生成即可，否则有可能报错
# datadir=D:\\web\\sqldata
# 允许最大连接数
max_connections=20
# 服务端使用的字符集默认为8比特编码的latin1字符集
character-set-server=utf8
# 创建新表时将使用的默认存储引擎
default-storage-engine=INNODB
# 默认使用“mysql_native_password”插件认证
default_authentication_plugin=mysql_native_password
[mysql]
# 设置mysql客户端默认字符集
default-character-set=utf8
[client]
# 设置mysql客户端连接服务端时默认使用的端口
port=3306
default-character-set=utf8
    　　

    MySQL 8.0 では、認証プラグインとパスワード暗号化方式が変更され、caching_sha2_password がデフォルトの認証プラグインになりました。以前のバージョンの mysql_native_password ではありません。

    使用するコマンド：

    use mysql;

select plugin,authentication_string from user;

    確認します。

    したがって、以前の認証方式を維持し、以前のバージョンのパスワード暗号化方式を維持する必要がある場合は、設定ファイルで変更する必要があります。動的な変更にはまだ対応しておらず、再起動後に有効になります。つまり：

    # 默认使用 mysql_native_password 插件认证
default_authentication_plugin=mysql_native_password　

    8.0 の既存の sha2 パスワードを sha1 のモードに変更します：

    # 修改加密规则为永不过期
#注意：password 改为你的密码，别老老实实照抄，之前本人便以为 password 指代密码不用改变，结果一通指令下去，mysql 登不上了，只好重新初始化数据库
ALTER USER 'root'@'127.0.0.1' IDENTIFIED BY 'password' PASSWORD EXPIRE NEVER;

#更新一下用户的密码加密方式为之前版本的方式
ALTER USER 'root'@'127.0.0.1' IDENTIFIED WITH mysql_native_password BY 'password';　　　　

#刷新权限
FLUSH PRIVILEGES;

    再起動して、再度確認すると、認証プラグインが変更されています。

    このときにサンプルプログラムを少し修正すれば、接続できるようになります：

    import mysql.connector

mydb=mysql.connector.connect(
    host="localhost",
    user="ly",
    passwd="123456",
    auth_plugin='mysql_native_password'
)

print(mydb)

python3 -m pip install mysql-connector-python #这个是为python3版本安装，当你的电脑里有不同的python版本，而且默认版本不是python3时才使用
