jQuery Mobile ポップアップ

ポップアップは非常に人気のあるダイアログで、ページの上にオーバーレイ表示できます。

ポップアップは、テキスト、画像、地図、その他のコンテンツを表示するために使用できます。

ポップアップを作成するには、<a> 要素と <div> 要素を使用する必要があります。<a> 要素に data-rel="popup" 属性を追加し、<div> 要素に data-role="popup" 属性を追加します。次に、<div> に id を指定し、<a> の href の値を <div> で指定した id に設定します。<div> の中身がポップアップに表示されるコンテンツです。

注意：<div> ポップアップとクリックする <a> リンクは同じページになければなりません。

例

<a href="#myPopup" data-rel="popup"class="ui-btn ui-btn-inline ui-corner-all">ポップアップを表示</a>

<div data-role="popup" id="myPopup">
<p>これは簡単なポップアップです</p>
</div>

ポップアップにパディングとマージンを追加する必要がある場合は、<div> に "ui-content" クラスを追加します。

例

<div data-role="popup" id="myPopup" class="ui-content">

ポップアップを閉じる

デフォルトでは、ポップアップの外側をクリックするか、"Esc" キーを押すとポップアップを閉じることができます。ポップアップの外側をクリックして閉じたくない場合は、data-dismissible="false" 属性を追加できます（推奨されません）。ポップアップに閉じるボタンを追加することもできます。ボタンには data-rel="back" 属性を使用し、スタイルでボタンの位置を制御します。

ポップアップの位置指定

デフォルトでは、ポップアップはクリックした要素の上に直接表示されます。ポップアップの位置を制御する必要がある場合は、ポップアップを開くためにクリックされるリンクに data-position-to 属性を使用できます。

ポップアップの位置を制御する3つの方法：

属性値 説明
data-position-to="window" ポップアップがウィンドウの中央に表示されます。
data-position-to="#myId" ポップアップが指定された #id 要素の上に表示されます。
data-position-to="origin" デフォルト。ポップアップはクリックした要素の上に表示されます。

例

<a href="#myPopup1" data-rel="popup" class="ui-btn" data-position-to="window">Window</a>
<a href="#myPopup2" data-rel="popup" class="ui-btn" data-position-to="#demo">id="demo"</a>
<a href="#myPopup3" data-rel="popup" class="ui-btn" data-position-to="origin">Origin</a>

トランジション

デフォルトでは、ポップアップにトランジション効果はありません。必要に応じて、data-transition="value" 属性を使用してトランジション効果を追加できます（jQuery Mobile トランジション）：

すべてのトランジション効果の例

<a href="../index.html" data-rel="popup" class="ui-btn" data-transition="fade">Fade</a>

試してみる »

ポップアップの矢印

ポップアップの矢印を追加する必要がある場合は、data-arrow 属性を使用し、値を "l" (左)、"t" (上)、"r" (右) もしくは "b" (下) に指定します：

例

<a href="#myPopup" data-rel="popup" class="ui-btn">ポップアップを開く</a>

<div data-role="popup" id="myPopup" class="ui-content" data-arrow="l">
<p>左の矢印の方向。</p>
</div>

ポップアップダイアログ

ポップアップを標準的なダイアログ（ヘッダー、コンテンツ、フッターのマークアップ）にすることができます：

例

<a href="#myPopupDialog" data-rel="popup" class="ui-btn">ダイアログポップアップを開く</a>

<div data-role="popup" id="myPopupDialog">
<div data-role="header"><h1>ヘッダーテキスト..</h1></div>
<div data-role="main" class="ui-content"><p>いくつかのテキスト..</p><a href="#">いくつかのリンク..</a>
<div data-role="footer"><h1>フッターテキスト..</h1></div>
</div>

試してみる »

画像ポップアップ

ポップアップに画像を表示できます：

例

<a href="#myPopup" data-rel="popup" data-position-to="window">
<img src="/wp-content/uploads/2015/10/runoob.jpeg" alt="Runoob" style="width:200px;"></a>

<div data-role="popup" id="myPopup">
  <img src="/wp-content/uploads/2015/10/runoob.jpeg" style="width:800px;height:400px;" alt="Runoob">
</div>

ポップアップの背景オーバーレイ

data-overlay-theme 属性を使用して、ポップアップの後ろに背景色を追加できます。

デフォルトでは、オーバーレイの背景色は透明です。data-overlay-theme="a" を使用すると明るい背景、data-overlay-theme="b" を使用すると暗いオーバーレイ背景を追加できます：

例

<a href="#myPopup" data-rel="popup">Show Popup</a>

<div data-role="popup" id="myPopup" data-overlay-theme="b">
<p>私の後ろに暗い背景があります。</p>
</div>

試してみる »

一般的に、画像ポップアップでは背景オーバーレイがよく使用されます：

例

<a href="#myPopup" data-rel="popup" data-position-to="window">
<img src="/wp-content/uploads/2015/10/runoob.jpeg" alt="Runoob" style="width:200px;"></a>

<div data-role="popup" id="myPopup" data-overlay-theme="b">
  <img src="/wp-content/uploads/2015/10/runoob.jpeg" style="width:800px;height:400px;" alt="Runoob">
</div>
