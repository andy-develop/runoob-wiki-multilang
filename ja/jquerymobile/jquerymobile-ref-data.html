jQuery データ属性

jQuery Mobile の使用HTML5 data-* 属性モバイルデバイス向けに、よりタッチフレンドリーで魅力的な外観を作成します。

以下のリファレンスリストでは、太字で表示されている値がデフォルト値です。

ボタン

1.4 以降で非推奨になりました。代わりにCSS クラスを使用してください。を持つdata-role="button"超リンク。button 要素、ツールバー内のリンク、input フィールドは、data-role="button" を追加しなくても自動的にボタンスタイルにレンダリングされます。

データ属性 值 説明
data-corners true | false ボタンの角を丸くするかどうかを指定します。
data-icon アイコンリファレンス ボタンのアイコンを指定します。デフォルトではアイコンはありません。
data-iconpos left | right | top | bottom | notext アイコンの位置を指定します。
data-iconshadow true | false ボタンのアイコンに影を付けるかどうかを指定します。
data-inline true | false ボタンをインラインにするかどうかを指定します。
data-mini true | false ボタンのサイズを小と通常のどちらにするかを指定します。
data-shadow true | false ボタンに影を付けるかどうかを指定します。
data-theme アルファベット (a-z) ボタンのテーマカラーを指定します。

複数のボタンをグループ化するには、data-role="controlgroup" 属性と data-type="horizontal|vertical" を備えたコンテナを使用して、ボタンを水平または垂直にグループ化するかどうかを指定します。

type="checkbox" を持つtype="checkbox"ペアの label と input。これらは自動的にボタンスタイルにレンダリングされ、data-role は必要ありません。

データ属性 值 説明
data-mini true | false チェックボックスのサイズを小と通常のどちらにするかを指定します。
data-role none jQuery Mobile がチェックボックスをボタンスタイルにレンダリングしないようにします。
data-theme アルファベット (a-z) チェックボックスのテーマカラーを指定します。

複数のチェックボックスをグループ化するには、data-role="controlgroup" 属性と data-type="horizontal|vertical" を備えたコンテナを使用して、チェックボックスを水平または垂直にグループ化するかどうかを指定します。

拡張

data-enhance="false" を持つdata-enhance="false" 或 data-ajax="false"コンテナ。

データ属性 值 説明
data-enhance true | false true（デフォルト）に設定すると、jQuery Mobile はページを自動的にレンダリングしてモバイルデバイスに適したものにします。false に設定すると、フレームワークはページをレンダリングしません。
data-ajax true | false ajax 経由でページを読み込むかどうかを指定します。

注意：data-enhance="false" は、jQuery Mobile の自動レンダリングを防ぐために、$.mobile.ignoreContentEnabled=true と一緒に使用する必要があります。

$.mobile.ignoreContentEnabled が true に設定されている場合、data-ajax="false" コンテナ内のリンクまたはフォーム要素はフレームワークのナビゲーション機能によって無視されます。

リンク

すべてのリンク。data-role="button" を持つリンクやフォーム送信ボタンも含みます。

Data-属性 值 説明
data-ajax true | false ajax を使用してページを読み込み、ユーザーエクスペリエンスとインタラクションを向上させるかどうかを指定します。false に設定すると、jQuery Mobile は通常のページリクエストを実行します。
data-direction reverse 逆方向の遷移アニメーション（ページとダイアログのみに使用）
data-dom-cache true | false 各ページの jQuery DOM キャッシュをクリアするかどうかを指定します（true に設定する場合、DOM を自分で管理し、すべてのモバイルデバイスでテストする必要があります）。
data-prefetch true | false ユーザーがアクセスしたときに利用できるように、ページを事前に DOM に読み込むかどうかを指定します。
data-rel back | dialog | external | popup リンクの動作のオプションを指定します。Back - 履歴内の前のページに戻ります。Dialog - リンクをダイアログとして開き、履歴に保存しません。External - 別のドメインへのリンクに使用します。Popup - ポップアップウィンドウを開きます。
data-transition fade | flip | flow | pop | slide | slidedown | slidefade | slideup | turn | none あるページから次のページへの切り替え効果を指定します。私たちのjQuery Mobile ページ切り替えの章を参照してください。
data-position-to origin | jQuery selector | window ポップアップの位置を指定します。Origin - デフォルト。ポップアップを開いたリンク上に配置します。jQuery selector - 指定した要素上にポップアップを配置します。Window - ウィンドウ画面の中央にポップアップを配置します。
