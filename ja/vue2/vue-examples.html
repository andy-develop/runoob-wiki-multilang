ナビゲーションメニューのサンプル

ナビゲーションメニュー

シンプルなナビゲーションメニューを作成します：

<div id="main"> <!--アクティブなメニューのスタイルは active クラスです。--> <!--クリック時にリンクが遷移するのを防ぐため、"prevent" 修飾子（preventDefault の略）を使用します。--> <nav v-bind:class="active" v-on:click.prevent> <!--メニューのリンクがクリックされたとき、Vue インスタンス内で作成された makeActive メソッドを呼び出します。--> <a href="#" class="home" v-on:click="makeActive('home')">Home</a> <a href="#" class="projects" v-on:click="makeActive('projects')">Projects</a> <a href="#" class="services" v-on:click="makeActive('services')">Services</a> <a href="#" class="contact" v-on:click="makeActive('contact')">Contact</a> </nav> <!--以下の "active" 変数は、現在選択されている値に応じて自動的に変化します。--> <p>あなたが選択したのは<b>{{active}} メニュー</b></p> </div> <script>// 新しい Vue インスタンスを作成 var demo = new Vue({ // DOM 要素、ビューモデルをマウント el: '#main', // プロパティを定義し、初期値を設定 data: { active: 'home' }, // メニュークリック時に使用する関数 methods: { makeActive: function(item){ // モデルが変わると、ビューは自動的に更新されます this.active = item; } } });</script>

テキスト編集のサンプル

テキスト編集

指定したテキストをクリックして内容を編集：

<!--v-cloak は、Vue インスタンスの準備ができるまで未コンパイルの変数を非表示にします。--> <!--要素をクリックすると hideTooltp() メソッドが呼び出されます。--> <div id="main" v-cloak v-on:click="hideTooltip"> <!--これはツールチップです v-on:click.stop はクリックイベントハンドラーで、stop 修飾子はイベントの伝播を防ぎます v-if は show_tooltip が true のときのみ表示するために使います--> <div class="tooltip" v-on:click.stop v-if="show_tooltip"> <!--v-model はテキストエリアの内容をバインドします テキストエリアの内容が変わると、対応する変数もリアルタイムに変わります--> <input type="text" v-model="text_content" /> </div> <!--クリックすると "toggleTooltip" メソッドを呼び出し、イベントの伝播を防ぎます--> <!--"text_content" 変数はテキストエリアの内容の変化に応じて変化します--> <p v-on:click.stop="toggleTooltip">{{text_content}}</p> </div> <script>var demo = new Vue({ el: '#main', data: { show_tooltip: false, text_content: 'クリックして、内容を編集してください。' }, methods: { hideTooltip: function(){ // モデルが変わると、ビューも自動的に更新されます this.show_tooltip = false; }, toggleTooltip: function(){ this.show_tooltip = !this.show_tooltip; } } })</script>

注文リストのサンプル

注文リスト

注文リストを作成し、合計金額を計算します：

<form id="main" v-cloak> <h1>Services</h1> <ul> <!--services 配列をループ出力し、オプションクリック後のスタイルを設定します--> <li v-for="service in services" v-on:click="toggleActive(service)" v-bind:class="{ 'active': service.active}"> <!--注文のサービス名と価格を表示します Vue.js は価格をフォーマットするための通貨フィルターを定義しています--> {{service.name}} <span>{{service.price | currency}}</span> </li> </ul> <div class="total"> <!--すべてのサービスの価格を計算し、通貨をフォーマットします--> Total: <span>{{total() | currency}}</span> </div> </form> <script>// カスタムフィルター "currency" Vue.filter('currency', function (value) { return '$' + value.toFixed(2); }); var demo = new Vue({ el: '#main', data: { // モデルのプロパティを定義 // ビューは配列のデータをループ出力します services: [ { name: 'Web Development', price: 300, active:true },{ name: 'Design', price: 400, active:false },{ name: 'Integration', price: 250, active:false },{ name: 'Training', price: 220, active:false } ] }, methods: { toggleActive: function(s){ s.active = !s.active; }, total: function(){ var total = 0; this.services.forEach(function(s){ if (s.active){ total+= s.price; } }); return total; } } });</script>

    vue-cli（スキャフォールディング）で作成したシンプルな to do list の例を実装します。

    完全なプロジェクトのダウンロード：

    Download

    ダウンロード後、プロジェクトディレクトリに移動して実行npm installコマンドで依存モジュールをインポートします。

    以下のコマンドを実行してプロジェクトを起動します：
    npm run dev

    このプロジェクトのポート番号は 6060 です。

    プロジェクトのディレクトリ構造：

    src/App.vueファイルコード：

    <template>
  <div id="app">
    <h1 v-html = "title"></h1>
    <input v-model="newItem" v-on:keyup.enter="addNew" ></input>
    <ul>
      <li v-for="item in items" v-bind:class="{finished:item.isFinished}" v-on:click="toggleFinish(item)">{{item.label}}</li>
    </ul>
  </div>
 
</template>


<script>
import Store from './store'
export default {
  data:function(){
    return {
      title:"This is a Todolist",
      items:Store.fetch(),
      newItem:""
    }
  },
  watch:{
    items:{
      handler:function(items){
        Store.save(items)
      },
      deep:true
    }
  },
  methods:{
    toggleFinish:function(item){
      item.isFinished = !item.isFinished
    },
    addNew:function(){
      this.items.push({
        label:this.newItem,
        "isFinished":false 
      })
      this.newItem=""
    }
  }
}
</script>

    const STORAGE_KEY='todos-vuejs'
export default {
 fetch:function(){
