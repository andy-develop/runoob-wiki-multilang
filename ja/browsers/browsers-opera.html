Opera ブラウザ

Opera ブラウザは無料で、現在最小かつ最速のブラウザです！

Opera は、ノルウェーの通信会社 Telenor の研究プロジェクトとして 1994 年に開始され、1995 年に独立した開発会社 Opera Software ASA へと発展しました。

Opera Software ASA は Opera Web ブラウザを開発しており、デスクトップおよびデバイス市場における Web ブラウザ開発分野の業界リーダーです。

Opera ブラウザは、他のブラウザと比較して、より高速で、より小型で、標準互換性に優れているという利点により、エンドユーザーと業界から国際的な賞賛を得ています。

Opera は無料であるだけでなく、Web 標準にも準拠しています！

Opera ブラウザは無料です！初期のバナー広告とライセンス料制度は廃止されました！

Opera ブラウザは、より高速で、より小型で、標準互換性に優れているという利点があります。

あなたのウェブサイトが Opera で問題なく動作するなら、それが標準に準拠していると確信できます！標準準拠のコードでページを書くだけで、すべての主要ブラウザや、すべての主要プラットフォームやオペレーティングシステム上で、あなたのウェブサイトが問題なく動作することを保証できます。

Opera は、CSS、HTML、XHTML、HTTP、DOM、XML、XSL、ECMAScript（JavaScript）、PNG、WML、SVG、Unicode、Unicode Bidirectional Algorithm など、使用されているすべての Web 標準をサポートしています。

Opera 20

Opera 20 は 2014年3月4日にリリースされ、最新の Chromium バージョン 33 への更新が含まれています。

Opera 20 は Mac と Windows で実行できます。

新機能：

  • ドラッグ可能なブックマーク- タブをブックマークバーにドラッグすると、それらのタブを保存できます。ブックマークをスピードダイヤル（Speed Dial）にドラッグすると、新しいエントリを作成できます。
  • 新しいスピードダイヤル（Speed Dial）エントリ- 詳細設定で、スピードダイヤル（Speed Dial）エントリの外観を変更できます。

Opera 19 は Mac と Windows で実行できます。

新機能：

  • ブックマークバー- タブをブックマークバーに保存でき、ブックマークバー内のタブを簡単に管理でき、ブックマークバーのタブをクリックして Web ページに簡単にアクセスできます。
  • テーマ作成- 画像をアップロードするか、インターネット上の画像を使用して、ブラウザの外観をカスタマイズできます。

Opera 15

Opera 15 は 2013年7月2日にリリースされました。

Opera 15 は Mac と Windows で実行できます。

Opera 15 は Opera の大規模な再設計です。ブラウザのソースコードは、Chromium と Blink、そして WebKit レンダリングエンジンに基づいています。このバージョンのブラウザはすべてが新しいものになっています：

  • WebKit ベースの新しいレンダリングエンジン
  • 新しいユーザーインターフェース
  • 新しい能力
  • 新しい機能
  • 改善されたサイト互換性
  • 自動更新

新機能：

  • 統合されたアドレスバーと検索バー
  • 強化されたスピードダイヤル（Speed Dial）- スピードダイヤルエントリをグループ化できます。
  • 予備機能位置、メタデータ、Webページのスクリーンショットを記録し、これらの情報をブラウザのスタートページの折りたたみ可能なリスト項目に配置します。キーワードで検索したり、スクリーンショットで視覚的に閲覧したりできます。
  • 知識を得るニュースと特集コンテンツを表示し、カテゴリまたは場所/言語でフィルタリングできます。
  • オフロードモードOpera Mobile が使用するサーバーサイド圧縮技術を採用。

Opera 11 は 2010 年 12 月にリリースされました。

Opera 11 は Linux、Mac、FreeBSD、Windows で動作します。

  • Opera Presto 2.7 レンダリングエンジンCSS3 と HTML5 をより適切にサポート。
