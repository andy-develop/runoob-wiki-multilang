NumPy は複数のソート方法を提供しています。これらのソート関数は異なるソートアルゴリズムを実装しており、各ソートアルゴリズムの特徴は、実行速度、最悪時のパフォーマンス、必要なワークスペース、アルゴリズムの安定性にあります。次の表に3つのソートアルゴリズムの比較を示します。

種類 速度 最悪ケース ワークスペース 安定性
'quicksort'（クイックソート） 1 O(n^2) 0 否
'mergesort'（マージソート） 2 O(n*log(n)) ~n/2 是
'heapsort'（ヒープソート） 3 O(n*log(n)) 0 否

numpy.sort()

numpy.sort() 関数は、入力配列のソートされたコピーを返します。関数の形式は次のとおりです：

numpy.sort(a, axis, kind, order)

引数の説明：

  • a: ソートする配列
  • axis: 配列をソートする軸。未指定の場合は配列がフラット化され、最後の軸に沿ってソートされます。axis=0 は列方向のソート、axis=1 は行方向のソートです。
  • kind: デフォルトは 'quicksort'（クイックソート）です。
  • order: 配列がフィールドを含む場合、ソートするフィールドです。

で取得できることに注意してください。

import numpy as np a = np.array([[3,7],[9,1]]) print ('配列は次のとおりです：') print (a) print ('\n') print ('sort() 関数を呼び出します：') print (np.sort(a)) print ('\n') print ('列方向にソート：') print (np.sort(a, axis = 0)) print ('\n') # sort 関数内でフィールドをソートする dt = np.dtype([('name', 'S10'),('age', int)]) a = np.array([("raju",21),("anil",25),("ravi", 17), ("amar",27)], dtype = dt) print ('配列は次のとおりです：') print (a) print ('\n') print ('name でソート：') print (np.sort(a, order = 'name'))

出力結果は次のとおりです：

我们的数组是：
[[3 7]
 [9 1]]


调用 sort() 函数：
[[3 7]
 [1 9]]


按列排序：
[[3 1]
 [9 7]]


我们的数组是：
[(b'raju', 21) (b'anil', 25) (b'ravi', 17) (b'amar', 27)]


按 name 排序：
[(b'amar', 27) (b'anil', 25) (b'raju', 21) (b'ravi', 17)]

numpy.argsort()

numpy.argsort() 関数は、配列の値を小さい順から大きい順に並べたインデックスを返します。

例

import numpy as np x = np.array([3, 1, 2]) print ('配列は次のとおりです：') print (x) print ('\n') print ('x に対して argsort() 関数を呼び出します：') y = np.argsort(x) print (y) print ('\n') print ('ソート後の順序で元の配列を再構築します：') print (x[y]) print ('\n') print ('ループを使用して元の配列を再構築します：') for i in y: print (x[i], end=" ")

出力結果は次のとおりです：

我们的数组是：
[3 1 2]


对 x 调用 argsort() 函数：
[1 2 0]


以排序后的顺序重构原数组：
[1 2 3]


使用循环重构原数组

1 2 3

numpy.lexsort()

numpy.lexsort() は、複数のシーケンスをソートするために使用されます。これは、各列がシーケンスを表すスプレッドシートのソートと考えることができ、ソート時には後ろの列が優先されます。

ここで応用例を挙げます。中学受験では、重点クラスの合格者は総合点で決まります。総合点が同じ場合は数学の点数が高い人が優先され、総合点と数学の点数が両方同じ場合は、英語の点数で決まります... ここでは、総合点がスプレッドシートの最後の列、数学が最後から2番目の列、英語が最後から3番目の列にあります。

例

import numpy as np nm = ('raju','anil','ravi','amar') dv = ('f.y.', 's.y.', 's.y.', 'f.y.') ind = np.lexsort((dv,nm)) print ('lexsort() 関数を呼び出します：') print (ind) print ('\n') print ('このインデックスを使用して、ソート後のデータを取得します：') print ([nm[i] + ", " + dv[i] for i in ind])

出力結果は次のとおりです：

调用 lexsort() 函数：
[3 1 0 2]


使用这个索引来获取排序后的数据：
['amar, f.y.', 'anil, s.y.', 'raju, f.y.', 'ravi, s.y.']

上記で np.lexsort に渡したのはタプルで、ソート時にはまず nm がソートされ、その順序は amar、anil、raju、ravi です。以上により、ソート結果は [3 1 0 2] です。

msort、sort_complex、partition、argpartition

関数説明
msort(a)配列を最初の軸に沿ってソートし、ソートされた配列のコピーを返します。np.msort(a) は np.sort(a, axis=0) と同じです。
sort_complex(a) 複素数を、実部を先に、虚部を後にする順序でソートします。
partition(a, kth[, axis, kind, order]) 数値を指定して、配列をパーティション分割します。
argpartition(a, kth[, axis, kind, order]) キーワード kind でアルゴリズムを指定して、指定した軸に沿って配列をパーティション分割できます。

複素数のソート：

>>> import numpy as np
>>> np.sort_complex([5, 3, 6, 2, 1])
array([ 1.+0.j,  2.+0.j,  3.+0.j,  5.+0.j,  6.+0.j])
>>>
>>> np.sort_complex([1 + 2j, 2 - 1j, 3 - 2j, 3 - 3j, 3 + 5j])
array([ 1.+2.j,  2.-1.j,  3.-3.j,  3.-2.j,  3.+5.j])

partition() によるパーティションソート：

>>> a = np.array([3, 4, 2, 1])
>>> np.partition(a, 3)  # 将数组 a 中所有元素（包括重复元素）从小到大排列，3 表示的是排序数组索引为 3 的数字，比该数字小的排在该数字前面，比该数字大的排在该数字的后面
array([2, 1, 3, 4])
>>>
>>> np.partition(a, (1, 3)) # 小于 1 的在前面，大于 3 的在后面，1和3之间的在中间
array([1, 2, 3, 4])

配列の3番目に小さい値（index=2）と2番目に大きい値（index=-2）を見つけます。

>>> arr = np.array([46, 57, 23, 39, 1, 10, 0, 120])
>>> arr[np.argpartition(arr, 2)[2]]
10
>>> arr[np.argpartition(arr, -2)[-2]]
57

同時に3番目と4番目に小さい値を見つけます。ここでは、[2,3] で3番目と4番目に小さい値を同時にソートしておき、その後それぞれインデックス

>>> arr[np.argpartition(arr, [2,3])[2]]
10
>>> arr[np.argpartition(arr, [2,3])[3]]
23

numpy.argmax() と numpy.argmin()

numpy.argmax() 関数と numpy.argmin() 関数は、指定された軸に沿って、それぞれ最大要素と最小要素のインデックスを返します。

例

import numpy as np a = np.array([[30,40,70],[80,20,10],[50,90,60]]) print ('配列は次のとおりです：') print (a) print ('\n') print ('argmax() 関数を呼び出します：') print (np.argmax(a)) print ('\n') print ('配列をフラット化します：') print (a.flatten()) print ('\n') print ('軸 0 に沿った最大値のインデックス：') maxindex = np.argmax(a, axis = 0) print (maxindex) print ('\n') print ('軸 1 に沿った最大値のインデックス：') maxindex = np.argmax(a, axis = 1) print (maxindex) print ('\n') print ('argmin() 関数を呼び出します：') minindex = np.argmin(a) print (minindex) print ('\n') print ('フラット化した配列の最小値：') print (a.flatten()[minindex]) print ('\n') print ('軸 0 に沿った最小値のインデックス：') minindex = np.argmin(a, axis = 0) print (minindex) print ('\n') print ('軸 1 に沿った最小値のインデックス：') minindex = np.argmin(a, axis = 1) print (minindex)

出力結果は次のとおりです：

我们的数组是：
[[30 40 70]
 [80 20 10]
 [50 90 60]]


调用 argmax() 函数：
7


展开数组：
[30 40 70 80 20 10 50 90 60]


沿轴 0 的最大值索引：
[1 2 0]


沿轴 1 的最大值索引：
[2 0 1]


调用 argmin() 函数：
5


展开数组中的最小值：
10


沿轴 0 的最小值索引：
[0 1 1]


沿轴 1 的最小值索引：
[0 2 0]

    axis についての理解

    axis は軸の方向を表します。ここでは単に行や列と覚えるのではなく、軸の方向を表すと覚えると理解しやすくなります：

    • axis=0 は縦軸方向を表し、上から下に向かって計算します。
    • axis=1 は横軸方向を表し、左から右に向かって計算します。

    2次元データ（線形代数における通常の行列）の場合、axis=0 は行の変化として現れ、axis=1 は列の変化として現れます。

    例えば配列：

    a=np.array([[1,2,3],[1,1,1],[1,8,9]])

    それでは、各列のデータの分散を計算するとき、次のように表すことができます。np.var(a, axis=0)。

    各行のデータの分散は、次のように表すことができます。np.var(a,axis=1)。

    #!/usr/bin/python3
 
import numpy as np 
a=np.array([[1,2,3],[1,1,1],[1,8,9]])
print(a)
print(np.var(a, axis=0))
print(np.var(a,axis=1))

    出力結果は次のとおりです：

    [[1 2 3]
 [1 1 1]
 [1 8 9]]
[ 0.          9.55555556 11.55555556]
[ 0.66666667  0.         12.66666667]

    axis についての理解

    実は簡単な方法があります。それは次元と一緒に考えることです。最初の次元は 0、つまり最も外側の層です。最も内側の層のインデックスは、次元数、すなわち np.ndim - 1 に依存します。

    たとえば shape が (2, 3) の2次元配列の場合、axis=0 は最初の次元、つまり2つの行という次元を表します。これは列ごとに演算を処理すると考えることができ、各列には2つの要素があり、全部で3列あるため、出力は3つの要素になります。axis=1 は2番目の次元、つまり3つの列という次元で、最後の次元でもあります。これは行ごとに演算を処理すると考えることができ、各行には3つの要素があり、全部で2行あるため、出力は2つの要素になります。

    3次元の場合、axis=2 は、目に見える最も内側の角括弧内の要素リストに対して処理を行うことを意味し、axis=0 は、通常3Dで理解されるZ軸方向、つまり最も外側の層です。

    0 が最も外側の方向を表し、最大の値が最も内側の括弧内のリストの方向を表す、と覚えておけばOKです。

    正しい理解は、タプルでインデックス配列の値を取得する際のインデックスから見ると、axis=0これは最も右側のインデックスの変化方向を指します。

    a = np.array([[30,40,70],[80,20,10],[50,90,60]])

    配列の要素をインデックスするときに使用するのはa[i][j]、するとaxis=0v はまさに j の変化方向に沿ってソートされます。
