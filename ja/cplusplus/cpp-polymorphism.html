C++ ポリモーフィズム

ポリモーフィズム文字どおり、複数の形態を意味します。

クラス間に階層構造が存在し、クラス同士が継承によって関連付けられている場合に、ポリモーフィズムが使用されます。

C++ では、ポリモーフィズム（Polymorphism）はオブジェクト指向プログラミングの重要な特性の1つです。

C++ のポリモーフィズムでは、基本クラスのポインタまたは参照を使用して派生クラスのオーバーライド済みメソッドを呼び出せるため、同じインターフェースで異なる動作を表現できます。

ポリモーフィズムによりコードはより柔軟で汎用的になり、プログラムは基本クラスのポインタや参照を使って異なる型のオブジェクトを操作でき、オブジェクトの型を明示的に区別する必要がありません。これによりコードの拡張性が高まり、新しい形状クラスを追加するときにメインプログラムを変更する必要がありません。

以下はポリモーフィズムの重要なポイントです：

仮想関数（Virtual Functions）：

  • 基本クラスで関数を仮想関数として宣言するには、キーワードvirtual。
  • 派生クラスはこの仮想関数をオーバーライド（override）できます。
  • 仮想関数を呼び出すとき、オブジェクトの実際の型に基づいて、どのバージョンの関数を呼び出すかが決まります。

動的バインディング（Dynamic Binding）：

  • 遅延バインディング（Late Binding）とも呼ばれ、実行時に関数呼び出しの具体的な実装を決定します。
  • 基本クラスを指すポインタまたは参照を使用して仮想関数を呼び出す必要があります。コンパイラは実行時にオブジェクトの実際の型に基づいて、どの関数を呼び出すかを決定します。

純粋仮想関数（Pure Virtual Functions）：

  • 純粋仮想関数を含むクラスは抽象クラス（Abstract Class）と呼ばれ、直接インスタンス化することはできません。
  • 純粋仮想関数には関数本体がなく、宣言時には= 0。
  • 派生クラスに具体的な実装を提供することを強制します。

ポリモーフィズムの実装メカニズム：

  • 仮想関数テーブル（V-Table）：C++ の実行時は仮想関数テーブルを使用してポリモーフィズムを実現します。仮想関数を含むすべてのクラスには仮想関数テーブルがあり、そのテーブルにはクラス内のすべての仮想関数へのポインタが格納されます。
  • 仮想関数ポインタ（V-Ptr）：オブジェクトには、そのクラスの仮想関数テーブルを指すポインタが含まれます。

ポリモーフィズムを使用する利点：

  • コードの再利用：基本クラスのポインタまたは参照を使用して、異なる型の派生クラスオブジェクトを操作でき、コードの再利用を実現します。
  • 拡張性：新しい派生クラスを追加するとき、基本クラスに依存するコードを変更する必要はなく、新しいクラスが仮想関数を正しくオーバーライドしていることだけを確認すればよいです。
  • 疎結合化：ポリモーフィズムにより、プログラム設計をよりモジュール化し、クラス間の結合度を低減できます。

注意事項：

  • 基本クラスのポインタまたは参照を介して仮想関数を呼び出した場合にのみ、ポリモーフィズムが発生します。
  • 派生クラスのオブジェクトを直接使用して関数を呼び出す場合、呼び出されるのは基本クラスのバージョンではなく、派生クラスのバージョンです。
  • ポリモーフィズムには実行時型情報（RTTI）が必要であり、プログラムのオーバーヘッドが増加する可能性があります。

例 1

簡単な例を通じて、ポリモーフィズムの応用を理解しましょう：

例 1

#include <iostream>
using namespace std;

// 基本クラス Animal
class Animal {
public:
    // 仮想関数 sound。さまざまな動物の発声のためのインターフェースを提供
    virtual void sound() const {
        cout << "Animal makes a sound" << endl;
    }
   
    // 仮想デストラクタにより、派生クラスオブジェクトが正しく破棄されることを保証
    virtual ~Animal() {
        cout << "Animal destroyed" << endl;
    }
};

// 派生クラス Dog。Animal から継承
class Dog : public Animal {
public:
    // sound メソッドをオーバーライド
    void sound() const override {
        cout << "Dog barks" << endl;
    }
   
    ~Dog() {
        cout << "Dog destroyed" << endl;
    }
};

// 派生クラス Cat。Animal から継承
class Cat : public Animal {
public:
    // sound メソッドをオーバーライド
    void sound() const override {
        cout << "Cat meows" << endl;
    }
   
    ~Cat() {
        cout << "Cat destroyed" << endl;
    }
};

// ポリモーフィズムのテスト
int main() {
    Animal* animalPtr;  // 基本クラスポインタ

    // Dog オブジェクトを作成し、Animal ポインタに割り当て
    animalPtr = new Dog();
    animalPtr->sound();  // Dog の sound メソッドを呼び出す
    delete animalPtr;    // メモリを解放し、Dog と Animal のデストラクタを呼び出す

    // Cat オブジェクトを作成し、Animal ポインタに割り当て
    animalPtr = new Cat();
    animalPtr->sound();  // Cat の sound メソッドを呼び出す
    delete animalPtr;    // メモリを解放し、Cat と Animal のデストラクタを呼び出す

    return 0;
}

プログラムの実行結果は次のとおりです：

Dog barks
Dog destroyed
Animal destroyed
Cat meows
Cat destroyed
Animal destroyed

コードの説明

基本クラスAnimal：

  • Animalクラスには仮想関数が定義されていますsound()、これは仮想関数（virtual）であり、動物の発声動作を表します。
  • ~Animal()は仮想デストラクタであり、基本クラスポインタが指す派生クラスオブジェクトを解放する際、派生クラスのデストラクタを正しく呼び出してメモリリークを防ぎます。

派生クラスDog 和 Cat：

  • Dog 和 CatクラスはすべてAnimalクラスから派生し、それぞれsound()メソッドを実装しています。
  • Dog 的 sound()"Dog barks" と出力します；Cat 的 sound()"Cat meows" と出力します。これにより、同じメソッド（sound()）が異なるクラスで異なる動作を示します。

main関数main()：

  • 基本クラスポインタを作成しますanimalPtr。
  • を使用してnew Dog()作成しDogオブジェクトを生成し、そのアドレスをanimalPtrに代入します。このとき、animalPtr->sound()を呼び出すと "Dog barks" と出力されます。なぜならanimalPtrが実際に指しているのはDogオブジェクトだからです。
  • 解放Dogオブジェクトのときは、最初に呼び出しますDogのデストラクタを呼び出し、次にAnimalのデストラクタを呼び出します。
  • 使用してnew Cat()作成しCatオブジェクトを生成してanimalPtrに代入し、次に呼び出しますanimalPtr->sound()"Cat meows" を出力し、ポリモーフィズムの動作を示します。

重要な概念

  • 仮想関数：基本クラスでvirtualキーワードを使用して仮想関数を宣言すると、派生クラスはこの関数をオーバーライドでき、実行時にオブジェクトの型に応じて正しい関数を呼び出せます。

  • 動的バインディング：C++ のポリモーフィズムは動的バインディングによって実現されます。実行時に、基本クラスポインタanimalPtrは、それが実際に指すオブジェクトの型（Dog 或 Cat）に応じて対応するsound()メソッドを呼び出します。

  • 仮想デストラクタ：ポリモーフィズムの動作を持つ基本クラスでは、デストラクタはvirtualとして宣言する必要があります。これにより、派生クラスオブジェクトを削除する際に派生クラスのデストラクタが呼び出され、リソースリークを防ぎます。

例 2

次の例では、ポリモーフィズムを使用して、汎用の Shape 基本クラスと、Rectangle および Triangle という2つの派生クラスを実装します。

基本クラスポインタを介して異なる派生クラスのメソッドを呼び出し、ポリモーフィズムの動的バインディング特性を示しています。

例 2

#include <iostream> using namespace std; // 基本クラス Shape。形状を表す class Shape { protected: int width, height; // 幅と高さ public: // コンストラクタ。デフォルト引数付き Shape(int a = 0, int b = 0) : width(a), height(b) { } // 仮想関数 area。面積を計算する // virtual キーワードを使用して、ポリモーフィズムを実現 virtual int area() { cout << "Shape class area: " << endl; return 0; } }; // 派生クラス Rectangle。長方形を表す class Rectangle : public Shape { public: // コンストラクタ。基本クラスのコンストラクタを使用して width と height を初期化 Rectangle(int a = 0, int b = 0) : Shape(a, b) { } // area 関数をオーバーライドし、長方形の面積を計算 int area() override { cout << "Rectangle class area: " << endl; return width * height; } }; // 派生クラス Triangle。三角形を表す class Triangle : public Shape { public: // コンストラクタ。基本クラスのコンストラクタを使用して width と height を初期化 Triangle(int a = 0, int b = 0) : Shape(a, b) { } // area 関数をオーバーライドし、三角形の面積を計算 int area() override { cout << "Triangle class area: " << endl; return (width * height / 2); } }; // main関数 int main() { Shape *shape; // 基本クラスポインタ Rectangle rec(10, 7); // 長方形オブジェクト Triangle tri(10, 5); // 三角形オブジェクト // 基本クラスポインタを長方形オブジェクトに指し、area 関数を呼び出す shape = &rec; cout << "Rectangle Area: " << shape->area() << endl; // 基本クラスポインタを三角形オブジェクトに指し、area 関数を呼び出す shape = &tri; cout << "Triangle Area: " << shape->area() << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が得られます：

70

コード分析

Shape クラスの定義：

  • Shapeは抽象基本クラスであり、仮想関数を定義しています。area()。area()は面積を計算する仮想関数であり、virtualキーワードを使用しています。これにより、派生クラスでこの関数をオーバーライドしてポリモーフィズムを実現できます。
  • width 和 height 是 protected属性は、Shapeクラスおよびその派生クラス内でのみアクセスできます。
// 基类 Shape，表示形状
class Shape {
   protected:
      int width, height; // 宽度和高度

   public:
      // 构造函数，带有默认参数
      Shape(int a = 0, int b = 0) : width(a), height(b) { }

      // 虚函数 area，用于计算面积
      virtual int area() {
         cout << "Shape class area: " << endl;
         return 0;
      }
};

Rectangle クラスの定義：

  • RectangleはShapeクラスを継承し、area()メソッドをオーバーライドして、長方形の面積を計算します。
  • area()メソッドはoverrideキーワードを使用しており、これは基本クラスのShape 的 area()メソッドのオーバーライドであることを示します。
  • Rectangle::area()を返します。width * height、つまり長方形の面積です。
// 派生类 Rectangle，表示矩形
class Rectangle : public Shape {
   public:
      // 构造函数，使用基类构造函数初始化 width 和 height
      Rectangle(int a = 0, int b = 0) : Shape(a, b) { }

      // 重写 area 函数，计算矩形面积
      int area() override { 
         cout << "Rectangle class area: " << endl;
         return width * height;
      }
};

Triangle クラスの定義：

  • Triangleクラスも継承しShape、そしてオーバーライドしたarea()メソッドで、三角形の面積を計算します。
  • Triangle::area()返しますwidth * height / 2、これは三角形の面積の公式です。
// 派生类 Triangle，表示三角形
class Triangle : public Shape {
   public:
      // 构造函数，使用基类构造函数初始化 width 和 height
      Triangle(int a = 0, int b = 0) : Shape(a, b) { }

      // 重写 area 函数，计算三角形面积
      int area() override { 
         cout << "Triangle class area: " << endl;
         return (width * height / 2); 
      }
};

メイン関数における多態性の動作：

  • 基底クラスポインタを定義しましたshape、このポインタは任意のShapeクラスのオブジェクトまたはその派生クラスのオブジェクトを指すことができます。
  • まず、shapeポインタをRectangleオブジェクトに向けますrec、次にshape->area()を呼び出します。なぜならarea()は仮想関数であり、このとき動的にRectangle::area()にバインドされ、長方形の面積を出力します。
  • 続いて、shapeポインタをTriangleオブジェクトに向けますtri、shape->area()を呼び出すときは動的にTriangle::area()にバインドされ、三角形の面積を出力します。
// 主函数
int main() {
   Shape *shape;           // 基类指针
   Rectangle rec(10, 7);   // 矩形对象
   Triangle tri(10, 5);    // 三角形对象

   // 将基类指针指向矩形对象，并调用 area 函数
   shape = &rec;
   cout << "Rectangle Area: " << shape->area() << endl;

   // 将基类指针指向三角形对象，并调用 area 函数
   shape = &tri;
   cout << "Triangle Area: " << shape->area() << endl;

   return 0;
}

重要な概念

  • 仮想関数：基底クラスでShapeに仮想関数が定義されていますarea()。仮想関数の役割は、派生クラスがこの関数をオーバーライドできるようにし、実行時にポインタの実際のオブジェクト型に基づいて適切な関数実装を呼び出すことです。

  • 動的バインド：なぜならarea()は仮想関数であり、shape->area()呼び出し時には実行時にshape実際に指しているオブジェクトの型（Rectangle 或 Triangle）に応じて対応するarea()実装を呼び出します。実行時にどの関数を呼び出すかを決定するこのメカニズムは動的バインドと呼ばれ、多態性の核です。

  • 基底クラスポインタの多態性：基底クラスポインタshapeは、任意のShapeから派生したオブジェクトを指すことができます。...ときshapeが異なる派生クラスオブジェクトを指すとき、shape->area()を呼び出すと異なる動作が生じ、これは多態性の特性を示しています。

    • 仮想関数

    仮想関数は基底クラスでキーワードvirtualを使用して宣言される関数です。

    仮想関数はサブクラスがそれをオーバーライドすることを許可し、実行時に基底クラスのポインタまたは参照を通じてサブクラスのオーバーライド版を呼び出し、動的バインドを実現します。

    私たちが望むのは、プログラムの任意の時点で、呼び出されるオブジェクトの型に応じて呼び出す関数を選択できることであり、この操作は動的リンク、または後期バインドと呼ばれます。

    特徴：

    • 基底クラスで実装を持つことができる。通常、仮想関数は基底クラスでデフォルト実装を提供しますが、サブクラスはオーバーライドを選択できます。
    • 動的バインド：実行時にオブジェクトの実際の型に応じて対応する関数バージョンを呼び出します。
    • オプションのオーバーライド：派生クラスは仮想関数を選択的にオーバーライドできますが、必須ではありません。

    例

    #include <iostream>
    using namespace std;

    class Animal {
    public:
        virtual void sound() {  // 仮想関数
            cout << "Animal makes a sound" << endl;
        }
    };

    class Dog : public Animal {
    public:
        void sound() override {  // 仮想関数のオーバーライド
            cout << "Dog barks" << endl;
        }
    };

    int main() {
        Animal *animal = new Dog();
        animal->sound();  // 出力: Dog barks
        delete animal;
    }

    上記のコードでは、sound は Animal クラスの仮想関数です。Animal* ポインタ animal を介して sound() を呼び出すと、プログラムは実際のオブジェクト型（Dog）に基づいて Dog::sound() を呼び出します。

    純粋仮想関数

    基底クラスで仮想関数を定義したいが、派生クラスでその関数を再定義してオブジェクトにより適したものにしたい、しかし基底クラスでは仮想関数に意味のある実装を与えられない場合、このようなときに純粋仮想関数を使用します。

    純粋仮想関数は実装を持たない仮想関数であり、基底クラスで= 0を使用して宣言されます。

    純粋仮想関数は、基底クラスがインターフェースを定義するが、具体的な実装は派生クラスが担当することを示します。

    純粋仮想関数により基底クラスは抽象クラス（abstract class）となり、インスタンス化できません。

    特徴：

    • 基底クラスで= 0として宣言する必要があります。実装がないことを示し、サブクラスはオーバーライドする必要があります。
    • 抽象クラス：純粋仮想関数を含むクラスは直接インスタンス化できず、派生クラスがすべての純粋仮想関数を実装して初めてオブジェクトを作成できます。
    • インターフェース定義：純粋仮想関数は通常、インターフェースを定義し、派生クラスに具体的な動作を実装させるために使用されます。

    基底クラスの仮想関数 area() を次のように書き換えることができます：

    #include <iostream> using namespace std; class Shape { public: virtual int area() = 0; // 純粋仮想関数、サブクラスにこのメソッドの実装を強制 }; class Rectangle : public Shape { private: int width, height; public: Rectangle(int w, int h) : width(w), height(h) { } int area() override { // 純粋仮想関数の実装 return width * height; } }; int main() { Shape *shape = new Rectangle(10, 5); cout << "Rectangle Area: " << shape->area() << endl; // 出力: Rectangle Area: 50 delete shape; }

    = 0コンパイラに関数に本体がないことを伝え、上記の仮想関数は純粋仮想関数です。。

    1、純粋仮想関数の宣言は次のとおりです： virtual void funtion1()=0; 純粋仮想関数には必ず定義がありません。純粋仮想関数は派生クラスの動作を規定するために使用され、つまりインターフェースです。純粋仮想関数を含むクラスは抽象クラスであり、抽象クラスはインスタンスを定義できませんが、その抽象クラスを実装する具象クラスを指すポインタまたは参照を宣言することはできます。

    2、仮想関数の宣言は次のとおりです：virtual ReturnType FunctionName(Parameter) 仮想関数は実装する必要があります。実装しない場合、コンパイラはエラーを報告します。エラーメッセージは次のとおりです：

    error LNK****: unresolved external symbol "public: virtual void __thiscall ClassName::virtualFunctionName(void)"

    3、仮想関数に関して、親クラスと子クラスはそれぞれ独自のバージョンを持ちます。多態的な方法で呼び出すときは動的にバインドされます。

    4、純粋仮想関数を実装した子クラスでは、その純粋仮想関数は子クラス内で仮想関数になります。子クラスの子クラス、つまり孫クラスはその仮想関数をオーバーライドでき、多態的な方法で呼び出すときは動的にバインドされます。

    5、仮想関数はC++で多態性（polymorphism）を実装するためのメカニズムです。核となる考え方は、基底クラスを通じて派生クラスで定義された関数にアクセスすることです。

    6、ヒープ上にメモリを動的割り当てする場合、デストラクタは仮想関数である必要がありますが、純粋仮想である必要はありません。

    7、フレンドはメンバ関数ではありません。メンバ関数のみが仮想にできるため、フレンドは仮想関数にできません。ただし、フレンド関数に仮想メンバ関数を呼び出させることで、フレンドの仮想問題を解決できます。

    8、デストラクタは仮想関数であるべきです。対応するオブジェクト型のデストラクタが呼び出されます。したがって、ポインタが子クラスオブジェクトを指している場合、子クラスのデストラクタが呼び出され、その後自動的に基底クラスのデストラクタが呼び出されます。

    C++の多態性は、メンバ関数を呼び出す際、その関数を呼び出すオブジェクトの型に応じて異なる関数が実行されることを意味します；

    多態性を形成するには次の3つの条件が必要です：

    1、継承関係が存在する必要があります；

    2、継承関係には同名の仮想関数が必要です（ここで、仮想関数は基底クラスでキーワード Virtual を使用して宣言された関数です。派生クラスで基底クラスに定義された仮想関数を再定義するとき、コンパイラにその関数へ静的にリンクしないように指示します。）；

    3、基底クラス型のポインタまたは参照が存在し、そのポインタまたは参照を通じて仮想関数を呼び出します；

    動的束縛の実装メカニズム VTABLE

    コンパイラは仮想関数を含む各クラスに対して仮想関数テーブルVTABLEを作成します。テーブルの各項目は仮想関数のアドレスを指します。つまり、VTABLEテーブルは関数ポインタの配列と見なすことができ、各仮想関数のエントリアドレスはこの配列の1つの要素です。

    仮想関数を含む各クラスはそれぞれ独自の仮想関数テーブルVTABLEを持ちます。各派生クラスのVTABLEはその各基底クラスのVTABLEを継承します。基底クラスのVTABLEに特定の項目（仮想関数のエントリアドレス）が含まれている場合、その派生クラスのVTABLEにも同じ項目が含まれますが、2つの項目の値は異なる場合があります。派生クラスがその項目に対応する仮想関数をオーバーライドした場合、派生クラスのVTABLEのその項目はオーバーライド後の仮想関数を指します。派生クラスがその項目に対応する仮想関数を再定義していない場合は、基底クラスの仮想関数アドレスを使用します。

    仮想関数を含むクラスのオブジェクトを作成するとき、コンパイラは各オブジェクトのメモリレイアウトにvptrポインタ項目を追加し、そのポインタはそのクラスのVTABLEを指します。基底クラスオブジェクトを指すポインタ（bpとする）を介して仮想関数を呼び出すとき、コンパイラが生成するコードは、まず指されているオブジェクトのvtb1ポインタを取得し、次にvtb1が指すクラスのVTABLE内の対応する項目（具体的な仮想関数のエントリアドレス）を呼び出します。

    基底クラスが仮想関数を定義していない場合、その長さ＝データメンバの長さ；派生クラスの長さ＝自身のデータメンバの長さ＋基底クラスから継承したデータメンバの長さ；

    基底クラスが仮想関数を定義した後，その長さ=データメンバーの長さ+仮想関数テーブルのアドレス長；派生クラスの長さ=自身のデータメンバーの長さ+基底クラスから継承したデータメンバーの長さ+仮想関数テーブルのアドレス長。

    仮想関数を1つ含むクラスと複数の仮想関数を含むクラスの長さの増分は0です。仮想関数を含むクラスは、仮想関数テーブルの先頭アドレスを格納するためのポインタを1つ追加するだけです。

    派生クラスと基底クラスで同名の仮想関数は、VTABLE内で同じインデックス番号（または順序番号）を持ちます。

    仮想関数についてここでの説明はやや混乱しています。C++の書き方は奇抜なものが少なくないためです。実際にはシンプルに理解できます。

    仮想関数は実装（定義）しなくても構いません。実装（定義）されていない仮想関数は純粋仮想関数です。

    クラス内に未定義の仮想関数が存在する場合、そのクラスのインスタンスを直接使用することはできません。virtual関数が未定義であるため、そのクラスは抽象的であり、インスタンス化できないと理解できます。エラーが報告されます：

    undefined reference to `vtable for xxx'

    これは他の言語の抽象クラスや抽象メソッドに似ています。抽象クラスを実装しなければ、インスタンス化できません。（virtual と abstract にはまだいくつかの違いがあります）

    つまり、次のようなコードが存在する場合：

    using namespace std;

class Base {
public:
    virtual void tall();
};

class People : Base {
public:
    void tall() {
        cout << "people" << endl;
    };
};

    すると、mainメソッド内で「Base base;」というコード行を使用することはできません。このとき tall が実装されておらず、関数テーブル（vtable）の参照が未定義であるため、実行できません。しかし、「People people;」を使用してから、people.tall(); 或 (&people)->tall();PeopleがBaseの純粋仮想メソッド tall() を実装、つまり再定義・オーバーライドしたため、Peopleクラス内で定義を持つようになり、関数テーブルに紐付けられ、インスタンスを生成できるようになります。

    int main() {
//    Base base;//不可用

    People people;//可用
    people.tall();
    (&people)->tall();

    return 0;
}

    上記は仮想関数に関するものです。通常の関数では、宣言のみ行い定義しなくても、上記のような使用不可の問題は発生しません。

    親クラスの仮想関数または純粋仮想関数は、子クラスでも依然として仮想関数です。親クラスの特定の関数が子クラスで再定義（オーバーライド）されることを望まない場合があります。C++11 以降では、キーワード final を使用して、その関数が再度オーバーライドされるのを防ぐことができます。

    例：

    #include<iostream>
using namespace std;
class Base
{
    public:
        virtual void func()
        {
            cout<<"This is Base"<<endl;
        }
};
class _Base:public Base
{
    public:
        void func() final//正确，func在Base中是虚函数
        {
            cout<<"This is _Base"<<endl;
        }
};
class __Base:public _Base
{
/*    public://不正确，func在_Base中已经不再是虚函数，不能再被重写
        void func()
        {
            cout<<"This is __Base"<<endl;
        }*/
};
int main()
{
    _Base a;
    __Base b;
    Base* ptr=&a;
    ptr->func();
    ptr=&b;
    _Base* ptr2=&b;    ptr->func();
    ptr2->func();
}

    上記プログラムの実行結果：

    This is _Base
This is _Base
This is _Base

    クラスが継承されることを望まない場合も、final キーワードを使用できます。

    形式は次のとおりです：

    class Class_name final
{
    ...
};

    その場合、そのクラスは継承できなくなります。

    visual studio code 1、ポリモーフィズムの理念は主に純粋仮想関数または仮想関数を使うことです。このc++の特別な処理関数は、親オブジェクトのポインタを利用して子オブジェクトにアクセスし、子オブジェクトの関数に応じて呼び出しを行います。

    #include <iostream>
using namespace std;
class parent
{
    public:
        parent(int a =0):a(a){};
        ~parent(){};
        virtual void show_classname() = 0;
    private:
        int a;
};
class child1 : public parent
{
    public:
        child1(int a= 0, int b = 0):parent(a),b(b){};
        ~child1(){};
        void show_classname(){
            cout << "class name is child1" <<endl; 
        }
    private:
        int b;
};
class child2 : public parent
{
    public:
        child2(int a=0,int c =0):parent(a),c(c){};
        ~child2(){};
        void show_classname()
        {
          cout<< "class name is child2" <<endl;
        }
    private:
        int c;
};
int main()
{
  child1 b;
  child2 c;
  parent *a;
  a= &b;
  cout << "a ---> b"<<endl;
  a->show_classname();
  a= &c;
  cout << "a ---> c"<<endl;
  a->show_classname();
}

    結果：

    a ---> b
class name is child1
a ---> c
class name is child2

    AクラスがBクラスを継承し、AクラスがBクラスの仮想関数B2をオーバーライドしたとします。また、BクラスのB1内でB2が呼び出される場合、AクラスがB1を使用すると、実行時にB1内のB2はAクラスでオーバーライドされた仮想関数B2を実行します。

    サンプルコードは次のとおりです：

    #include <iostream>
using namespace std;
class B
{
public:    
void B1(void)
{
 B2();
}

virtual void B2(void)
{
 cout << "Hello, B2" << endl;
}
    
};

class A:public B
{
public:
virtual void B2(void)
{
 cout << "Hello, A" << endl;
}

};

int main()
{
    A *pA=new A;
    pA->B1();
    cout << "Hello, world!" << endl;
        return 0;
}

    実行結果：

    Hello, A
Hello, world!
