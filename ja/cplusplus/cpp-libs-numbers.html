C++ 標準ライブラリ<numbers>

C++20 より前は、数学定数を通常次のように書いていました：

const double PI = 3.14159265358979323846;

問題は非常に明らかです：精度がその場しのぎで、統一されておらず、間違いやすく、型も安全ではありません。</p>

C++20 で正式に導入され#include <numbers>、標準化された数学定数の集合を提供し、コンパイラによって精度と型の正確性が保証されます。

std::numbersC++20 で導入された標準ライブラリモジュールであり、主に一般的な数学定数のセットを提供するために使用され、標準的な数学・物理定数のリポジトリです。

std::numbers位置し<numbers>ヘッダーファイル内にあり、多くの数学定数が含まれており、円周率、自然対数の底、黄金比などの一般的な定数を網羅しています。

C++ でこれらの定数を使用すると、コードの可読性、精度、効率が向上し、定数の再定義や手動入力の手間を避けることができます。

std::numbers従来の記述との比較による利点：

観点 従来の記述 <numbers>
精度 適当に書く 標準の高精度
型 固定 自動的に一致
可読性 普通 意味が明確
コンパイル時定数 必ずしもそうではない 必ずそうである
規範性 差 標準ライブラリレベル

これらの定数と変数テンプレートは、円周率、自然対数の底、黄金比など一般的な数学定数を網羅し、float、double、long double などの異なる型の変数テンプレートによって精度オプションを提供します。

例

#include <iostream>
#include <iomanip>
#include <numbers>
#include <cmath> // 標準数学関数 sin, cos, log などのために使用

using namespace std;

int main()
{
    // デフォルトの double 型定数を使用
    cout << fixed << setprecision(15); // すべての出力を小数点以下15桁に設定

    // 円周率 π の値を出力
    cout << "円周率 pi の値は: " << numbers::pi << endl;

    // 自然対数の底 e の値を出力
    cout << "自然定数 e の値は: " << numbers::e << endl;

    // ルート2 (sqrt2) の値を出力
    cout << "ルート2 (sqrt2) の値は: " << numbers::sqrt2 << endl;

    // ルート3 (sqrt3) の値を出力
    cout << "ルート3 (sqrt3) の値は: " << numbers::sqrt3 << endl;

    // 黄金比 phi の値を出力
    cout << "黄金比 phi の値は: " << numbers::phi << endl;

    // オイラー＝マスケローニ定数 egamma の値を出力
    cout << "オイラー＝マスケローニ定数 egamma の値は: " << numbers::egamma << endl;

    // 1/π (inv_pi) の値を出力
    cout << "1/π (inv_pi) の値は: " << numbers::inv_pi << endl;

    // 1/√π (inv_sqrtpi) の値を出力
    cout << "1/√π (inv_sqrtpi) の値は: " << numbers::inv_sqrtpi << endl;

    // 2 を底とする e の対数 log2e の値を出力
    cout << "2 を底とする e の対数 log2e の値は: " << numbers::log2e << endl;

    // 10 を底とする e の対数 log10e の値を出力
    cout << "10 を底とする e の対数 log10e の値は: " << numbers::log10e << endl;

    // sin(π/2) の値を出力
    cout << "sin(π/2) の値は: " << sin(numbers::pi / 2) << endl;

    // cos(π) の値を出力
    cout << "cos(π) の値は: " << cos(numbers::pi) << endl;

    // ln(e) の値を出力
    cout << "ln(e) の値は: " << log(numbers::e) << endl;

    // 異なるデータ型の使用をデモする
    float pi_f = numbers::pi_v<float>;  // float 型の pi を使用
    cout << "\nfloat 型の pi を使用: " << setprecision(7) << pi_f << endl; // 小数点以下7桁を出力
   
    long double pi_ld = numbers::pi_v<long double>;  // long double 型の pi を使用
    cout << "long double 型の pi を使用: " << setprecision(21) << pi_ld << endl; // 小数点以下21桁を出力

    // 異なる精度の値を計算
    cout << "\nsin(π/2) を double で使用: " << sin(numbers::pi / 2) << endl;
    cout << "sin(π/2) を float で使用: " << sin(static_cast<float>(numbers::pi) / 2) << endl;
    cout << "sin(π/2) を long double で使用: " << sin(static_cast<long double>(numbers::pi) / 2) << endl;

    return 0;
}

フォーマット出力：

  • 使用してfixed 和 setprecision()出力の小数点以下が固定桁数になるようにします。ここではデフォルトで小数点以下15桁を出力しますが、データ型ごとに異なる精度を設定することもできます。

一般的な数学関数の計算：

  • 計算しましたsin(π/2)、cos(π) 和 ln(e)などの一般的な数学関数を計算し、使用しますcmath内の関数（例：sin、cos 和 log）を使用して、数学定数の使用方法を示します。

異なるデータ型の精度：

  • 使用してnumbers::pi_v<float> 和 numbers::pi_v<long double>異なる型の定数を示します。例えばfloat 和 long double、異なる精度で出力できます。

異なる型を使用した計算：

  • 計算の際にsinは、異なる精度の型を使って計算する方法を示し、実演しましたfloat、double 和 long double同じ数式での違いを示しました。

使用例

以下の例はカバーしています<numbers>最も一般的な定数をカバーしており、コードはそのままコンパイル・実行できます。標準パラメータを1つ追加するのを忘れないでください。-std=c++20：

g++ -std=c++20 main.cpp -o main

例1：基本使用

円周率 π で円の面積 / 周長を計算：

例

#include <iostream>
#include <numbers> // 数学定数を含む
#include <cmath> // powなどの数学関数を含む

using namespace std;
using namespace std::numbers;  // 定数の呼び出しを簡略化（オプション）

int main() {
    // 円の半径
    double r = 5.0;

    // 1. 円の周長を計算：2 * π * r
    double circumference = 2 * pi * r;  // double版のπを直接使用
    cout << 半径が << r << の円周長： << circumference << endl;  // 出力：31.4159

    // 2. 円の面積を計算：π * r²
    double area = pi * pow(r, 2);
    cout << 半径が << r << の円面積： << area << endl;  // 出力：78.5398

    // 3. 高精度版（long double）
    long double r_ld = 5.0L;
    long double area_ld = pi_v<long double> * powl(r_ld, 2);  // powlはlong double版のpow
    cout << "高精度円面積：" << area_ld << endl;  // より正確な78.53981633974483...を出力

    return 0;
}

例2：定数 e

自然定数 e と指数計算：

例

#include <iostream>
#include <numbers>
#include <cmath>

using namespace std;
using namespace std::numbers;

int main() {
    // 自然指数計算：e^x（exp関数はcmathの指数関数）
    double x = 2.0;
    double exp_result = exp(x);          // 手動でe^2を計算
    double exp_result_direct = pow(e, x); // numbers::eを使ってe^2を計算
    cout << "e^2 = " << exp_result << endl;          // 出力：7.38906
    cout << "e^2（直接計算）= " << exp_result_direct << endl;  // 結果は一致

    return 0;
}

例3：黄金比

黄金比 φ の応用：

例

#include <iostream>
#include <numbers>

using namespace std;
using namespace std::numbers;

int main() {
    // 黄金比：長さ/幅 = φ のとき黄金長方形
    double width = 10.0;
    double golden_height = width * phi;  // 黄金長方形の高さ
    cout << "幅が" << width << "の黄金長方形の高さ：" << golden_height << endl;  // 出力：16.1803

    // φの数学的定義を検証：φ = (1 + √5)/2
    double phi_manual = (1 + sqrt(5.0)) / 2;
    cout << "手動で計算した黄金比：" << phi_manual << endl;  // numbers::phiと一致

    return 0;
}

例4：浮動小数点型

異なる浮動小数点型への定数の適合：

例

#include <iostream>
#include <numbers>
#include <iomanip> // 出力精度を設定するため

using namespace std;

int main() {
    // 高精度出力を設定（小数15桁を表示）
    cout << fixed << setprecision(15);

    // float版π（単精度）
    float pi_float = std::numbers::pi_v<float>;
    cout << "float版π：" << pi_float << endl;  // 出力：3.141592741012573

    // double版π（倍精度、デフォルト）
    double pi_double = std::numbers::pi;
    cout << "double版π：" << pi_double << endl;  // 出力：3.141592653589793

    // long double版π（高精度）
    long double pi_long_double = std::numbers::pi_v<long double>;
    cout << "long double版π：" << pi_long_double << endl;  // より正確な3.1415926535897932385...を出力

    return 0;
}
