C++ 定数

定数は固定値であり、プログラムの実行中に変更されません。これらの固定値は、次のようにも呼ばれます。リテラル。

定数は任意の基本データ型にすることができ、整数型、浮動小数点型、文字、文字列、ブール値に分類できます。

定数は通常の変数のようなものですが、定数の値は定義後に変更できません。

整数定数

整数定数は、10進数、8進数、または16進数の定数にできます。接頭辞が基数を指定します: 0x または 0X は16進数、0 は8進数、接頭辞なしはデフォルトで10進数を表します。

整数定数には接尾辞を付けることもできます。接尾辞は U と L の組み合わせで、U は符号なし整数（unsigned）、L は長整数（long）を表します。接尾辞は大文字でも小文字でもよく、U と L の順序は任意です。

以下にいくつかの整数定数の例を示します。

212 // 有効 215u // 有効 0xFeeL // 有効 078 // 無効: 8 は8進数の数字ではない 032UU // 無効: 接尾辞を繰り返すことはできない

以下はさまざまな型の整数定数の例です。

85 // 10進数 0213 // 8進数 0x4b // 16進数 30 // 整数 30u // 符号なし整数 30l // 長整数 30ul // 符号なし長整数

浮動小数点定数

浮動小数点定数は、整数部、小数点、小数部、および指数部で構成されます。浮動小数点定数は、小数形式または指数形式で表すことができます。

小数形式で表す場合は、整数部、小数部、またはその両方を含める必要があります。指数形式で表す場合は、小数点、指数、またはその両方を含める必要があります。符号付き指数は e または E で導入されます。

以下にいくつかの浮動小数点定数の例を示します。

3.14159 // 有効 314159E-5L // 有効 510E // 無効: 不完全な指数 210f // 無効: 小数または指数がない .e55 // 無効: 整数または小数部が欠けている

ブール定数

ブール定数は2つあり、どちらも標準のC++キーワードです。

  • true値は真を表します。
  • false値は偽を表します。

true の値を 1 と見なしたり、false の値を 0 と見なしたりすべきではありません。

文字定数

文字定数は単一引用符で囲まれます。定数が L（大文字の場合のみ）で始まる場合、それはワイド文字定数（例: L'x'）を表し、その場合はwchar_t型の変数に格納する必要があります。それ以外の場合は、狭義文字定数（例: 'x'）であり、char型の単純変数に格納できます。

文字定数は、通常の文字（例: 'x'）、エスケープシーケンス（例: '\t'）、または汎用文字（例: '\u02C0'）のいずれかです。

C++ には、特定の文字があり、その前にバックスラッシュが付くと特別な意味を持ち、改行文字（\n）やタブ文字（\t）などを表すために使用されます。次の表に、そのようなエスケープシーケンスコードをいくつか示します。

\\\ 文字
\'' 文字
\"" 文字
\?? 文字

次の例は、いくつかのエスケープシーケンス文字を示しています。

例

#include <iostream> using namespace std; int main() { cout << "Hello\tWorld\n\n"; return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます。

Hello   World

文字列定数

文字列リテラルまたは定数は二重引用符""で囲まれます。文字列には、文字定数と同様の文字（通常の文字、エスケープシーケンス、汎用文字）が含まれます。

使用できるのは\を区切り文字として、長い文字列定数を複数の行に分割できます。

次の例は、いくつかの文字列定数を示しています。

例

#include <iostream>
#include <string>
using namespace std;

int main() {
    string greeting = "hello, runoob";
    cout << greeting;
    cout << "\n";     // 改行文字
    string greeting2 = "hello, \
                        runoob";
    cout << greeting2;
    return 0;
}
hello, runoob
hello, runoob

定数の定義

C++ には、定数を定義する簡単な方法が2つあります。

  • 使用#defineプリプロセッサ。
  • 使用constキーワード。

#define プリプロセッサ

#define プリプロセッサを使用して定数を定義する形式は次のとおりです。

#define identifier value

具体的には、次の例を参照してください。

例

#include <iostream> using namespace std; #define LENGTH 10 #define WIDTH 5 #define NEWLINE '\n' int main() { int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます。

50

const キーワード

あなたは使用できますconst接頭辞を付けて、指定した型の定数を宣言します。次のようになります。

const type variable = value;

具体的には、次の例を参照してください。

例

#include <iostream> using namespace std; int main() { const int LENGTH = 10; const int WIDTH = 5; const char NEWLINE = '\n'; int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます。

50

定数を大文字で定義することは、優れたプログラミング慣行であることに注意してください。

    マクロ定義 #define と定数 const の違い

    型と安全性チェックの違い

    マクロ定義は文字置換であり、データ型の区別がなく、同時にこの置換には型安全性チェックがないため、副作用などのエラーが発生する可能性があります。

    const 定数は定数の宣言であり、型の区別があり、コンパイル段階で型チェックを行う必要があります。

    コンパイラの処理の違い

    マクロ定義は「コンパイル時」の概念であり、前処理段階で展開されます。マクロ定義をデバッグすることはできず、ライフサイクルはコンパイル時に終了します。

    const 定数は「実行時」の概念であり、プログラムの実行時に使用され、読み取り専用データのようなものです。

    格納方法の違い

    マクロ定義は直接置換であり、メモリを割り当てず、プログラムのコードセグメントに格納されます。

    const 定数はメモリ割り当てが必要であり、プログラムのデータセグメントに格納されます。

    スコープの違い

    void f1 ()
{
    #define N 12
    const int n 12;
}
void f2 ()
{
    cout<<N <<endl; //正确，N已经定义过，不受定义域限制
    cout<<n <<endl; //错误，n定义域只在f1函数中
}

    定義後に取り消せるかどうか

    マクロ定義は #undef を使用して、以前のマクロ定義を無効にすることができます。

    const 定数は定義後、スコープ内で永続的に有効です。

    void f1()
{
  #define N 12
  const int n = 12;

  #undef N //取消宏定义后，即使在f1函数中，N也无效了
  #define N 21//取消后可以重新定义
}

    関数の引数にできるかどうか

    マクロ定義は関数に引数として渡すことはできません。

    const 定数は関数の引数リストに出現できます。

    const キーワード

    const是constantの略称であり、変数の前に const を付けて修飾すると、その変数内のデータはアクセスできても変更できないことを意味します。つまり、const は読み取り専用（readonly）を意味します。

    規則: const が誰に近いか、その誰は変更できません。

    const が変数を修飾する場合、必ずその変数に初期値を与える必要があります。初期化しないと、後で初期化できません。

    本質: const が誰の後ろにあるか、その誰は変更できません。const が先頭にある場合はそれを1つ後ろに移動します。この2つは同等です。

    constキーワードの役割

    • あなたのコードを読む人に非常に有用な情報を伝えるために、パラメータを定数として宣言するのは、そのパラメータの使用目的をユーザーに伝えるためです；
    • オプティマイザにいくつかの追加情報を与えることで、constキーワードはよりコンパクトなコードを生成できるかもしれません；
    • constキーワードを適切に使用することで、コンパイラは変更されたくないパラメータを自然に保護し、意図しないコードの変更を防ぎ、バグの発生を減らすことができます；

    constキーワードの応用

    • 変数が変更されるのを防ぎたい場合は、constを使用できます。そのconst変数を定義する際には、まず初期化する必要があり、以後変更する機会はありません；
    • ポインタに関しては、ポインタ自体をconstに指定することも、ポインタが指すデータをconstに指定することも、または両方をconstに指定することもできます；
    • 関数宣言において、constは仮引数を修飾して、それが入力パラメータであることを示すことができ、関数内部でその値を変更することはできません；
    • クラスのメンバ関数については、場合によってはconst型に指定する必要があります。これは、それがconstメンバ関数であり、クラスのメンバ変数を変更できないことを示します；
    • クラスのメンバ関数については、場合によっては戻り値をconst型に指定する必要があります。これにより、戻り値が「左辺値」にならないようにします。

    ポインタの修飾

    ポインタを修飾する場合は比較的多く、主に以下のようなケースがあります：

    1、const が修飾するのは*p、指すオブジェクトは読み取り専用で、ポインタの指す先は変更可能：

    int a = 9;
int b = 10;
const int *p = &a;//p是一个指向int类型的const值,与int const *p等价
*p = 11;    //编译错误，指向的对象是只读的，不可通过p进行改变
p = &b;     //合法，改变了p的指向

    ここでは理解を容易にするため、const が修飾するのは *p であると考えてください。通常は*ポインタをデリファレンスしてオブジェクトにアクセスするため、そのオブジェクトは読み取り専用です。

    2、const が p を修飾し、指すオブジェクトは変更可能だが、ポインタの指す先は変更不可：

    int a = 9;
int b = 10;
int * const p = &a;//p是一个const指针
*p = 11;    //合法，
p = &b;     //编译错误，p是一个const指针，只读，不可变

    3、ポインタは指す先を変更できず、指す内容も変更不可

    int a = 9;
int b = 10;
const int * const p = &a;//p既是一个const指针，同时也指向了int类型的const值
*p = 11;    //编译错误，指向的对象是只读的，不可通过p进行改变
p = &b;     //编译错误，p是一个const指针，只读，不可变

    上記のいくつかのケースを見た後、混乱し、記憶しにくいと感じるでしょうか？一言でまとめましょう：

    const を * の左側の任意の位置に置くと、そのポインタが指すオブジェクトが読み取り専用であると限定します；const を * の右側に置くと、ポインタ自体が読み取り専用、すなわち変更不可であると限定します。

    それでもあまり理解できない場合は、このように見てみましょう。型指定子を取り除いて、constが修飾する内容を確認します。上記の3つのケースから型指定子 int を取り除くと、次のようになります：

    const *p; //修饰*p，指针指向的对象不可变
* const p; //修饰p，指针不可变
const * const p; //第一个修饰了*p，第二个修饰了p，两者都不可变

    const の右側が何を修飾しているかによって、その何が変更不可であるかがわかります。上記の説明は理解と記憶を助けるためのものにすぎません。上記の理解を借りると、以下のようないくつかの等価なケースが見つかります：

    const int NUM = 10; //与int const NUM等价
int a = 9;
const int *p  = &a;//与int const *p等价
const int arr[] = {0,0,2,3,4}; //与int const arr[]等价

    const キーワードが * の左側に現れる：ポインタが指す内容は変更できません。これを「定数を指すポインタ」と呼び、このときは「低レベルconst」とも呼ばれます。

    const キーワードが * の右側に現れる：ポインタ自体は変更できません。これを「定数ポインタ」と呼び、このときは「トップレベルconst」とも呼ばれます。

    const キーワードが * の両側に現れる：ポインタが指す内容とポインタ自体の両方が変更できません。このときは低レベルconstとトップレベルconstの両方を持ちます。

    いくつかの注意点：

    （1）低レベルポインタが指す内容は変更できないわけではなく、そのポインタを通じて変更できないだけです。言い換えれば、低レベルポインタは「独りよがりに」自分が指す内容は変更できないと思い込んでいますが、実際には代入などの方法で指す内容を変更できます。

    （2）使用において、トップレベルconstはポインタのみを修飾するために使われ、参照を修飾することはできません（参照は変数ではないため）。一方、低レベルconstはポインタと参照を修飾でき、その意味は指すまたは参照する内容が定数であるということです。覚えておけばよいのは、低レベルconstは指すまたは参照するオブジェクトが定数であると限定し、ポインタや参照自体は限定しません；トップレベルconstはポインタが定数であると限定し、その指す内容は限定しません。

    （3）低レベルconstは変数に制限を課します。コピー操作を実行するとき、低レベルconstでないオブジェクトは低レベルconstを持つ変数に代入できません。

    int main()
{
    int a = 1;
    const int *p1 = &a;         //底层const, 也可以用int const *p1 = &a;.
    *p1 = 2;                    //非法, 无法通过p1更改a的值.
    p1++;                       //合法, p1的值(指向的地址)是可以更改的.
    a = 2;                      //合法, 只是无法通过p1解引用的方式更改a的值, 其他方式可以.

    int *const p2 = &a;         //顶层const, p2是常量.
    *p2 = 3;                    //合法, p2指向地址的内容可以更改.
    p2++;                       //非法, p2的值(指向的地址)无法更改.
    a = 4;                      //合法, p2指向地址的内容可以更改.
    const int *const p3 = &a;   //同时具有底层和顶层const, p3的值(指向的地址)无法修改, 且无法通过p3解引用进行更改.
    int *p4 = p1;               //非法, p1是const *int(底层const), 无法给普通int*赋值.
    int *p5 = p2;               //合法, p2是*const int(顶层const), 赋值时没有限制.
    const int *p6 = p1;         //合法, p6也是const *int(底层const), 可以获得p1的赋值.
}
