C++ 修飾子タイプ

C++ ではchar、int および double のデータ型の前に修飾子を置くことができます。

修飾子は、変数の型の動作を変更するために使用されるキーワードであり、さまざまな状況のニーズに応えることができます。

以下にデータ型修飾子を示します：

  • signed：変数が負の数を格納できることを示します。整数型変数の場合、整数型変数はデフォルトで符号付き型であるため、signed は省略できます。

  • unsigned：変数が負の数を格納できないことを示します。整数型変数の場合、unsigned は変数の範囲を2倍に拡大できます。

  • short：変数の範囲が int より小さいことを示します。short int は short と省略できます。

  • long：変数の範囲が int より大きいことを示します。long int は long と省略できます。

  • long long：変数の範囲が long より大きいことを示します。C++11 で追加されたデータ型修飾子です。

  • float：単精度浮動小数点数を示します。

  • double：倍精度浮動小数点数を示します。

  • bool：ブール型を示し、true と false の2つの値のみを持ちます。

  • char：文字型を示します。

  • wchar_t：ワイド文字型を示し、Unicode 文字を格納できます。

修飾子signed、unsigned、long および short は整数型に適用でき、signed 和 unsignedchar は文字型に適用でき、longdouble は倍精度型に適用できます。

これらの修飾子は組み合わせて使用することもでき、修飾子はsigned 和 unsignedまた、long 或 short修飾子の接頭辞としても使用できます。例えば：unsigned long int。

C++ では速記記号を使用して宣言できます符号なしショート整数或符号なしロング整数。int を書かずに、単語だけを書くことができますunsigned、short 或 long，intint は暗黙的です。例えば、次の2つの文はどちらも符号なし整数型変数を宣言しています。

signed int num1 = -10; // 定义有符号整型变量 num1，初始值为 -10
unsigned int num2 = 20; // 定义无符号整型变量 num2，初始值为 20

short int num1 = 10; // 定义短整型变量 num1，初始值为 10
long int num2 = 100000; // 定义长整型变量 num2，初始值为 100000

long long int num1 = 10000000000; // 定义长长整型变量 num1，初始值为 10000000000

float num1 = 3.14f; // 定义单精度浮点数变量 num1，初始值为 3.14
double num2 = 2.71828; // 定义双精度浮点数变量 num2，初始值为 2.71828

bool flag = true; // 定义布尔类型变量 flag，初始值为 true

char ch1 = 'a'; // 定义字符类型变量 ch1，初始值为 'a'
wchar_t ch2 = L'你'; // 定义宽字符类型变量 ch2，初始值为 '你'

C++ が符号付き整数修飾子と符号なし整数修飾子の違いをどのように解釈するかを理解するために、次の短いプログラムを実行してみましょう：

サンプル

#include <iostream> using namespace std; /** このプログラムは、符号付き整数と符号なし整数の違いを示しています。*/ int main() { short int i; // 符号付きショート整数 short unsigned int j; // 符号なしショート整数 j = 50000; i = j; cout << i << " " << j; return 0; }

上記のプログラムを実行すると、次の結果が出力されます：

-15536 50000

上記の結果では、符号なしショート整数 50,000 のビットパターンが符号付きショート整数 -15,536 として解釈されています。

C++ の型修飾子

型修飾子は、変数に関する追加情報を提供するキーワードであり、変数や関数を定義する際にそれらのデフォルトの動作を変更するために使用されます。

修飾子意味
constconst定数を定義し、その変数の値が変更できないことを示します。
volatile修飾子volatileその変数の値が、ハードウェアや他のスレッドなど、プログラム以外の要因によって変更される可能性があることを示します。
restrict由 restrictrestrict 修飾されたポインタは、それが指すオブジェクトにアクセスする唯一の方法です。C99 でのみ新しい型修飾子 restrict が追加されました。
mutable mutable はクラスのメンバ変数を修飾するために使用されます。mutable で修飾されたメンバ変数は、それらが属するオブジェクトが const であっても変更できます。
static static は静的変数を定義するために使用され、その変数のスコープが現在のファイルまたは現在の関数内に限定され、他のファイルや関数からアクセスされないことを示します。
register register はレジスタ変数を定義するために使用され、その変数が頻繁に使用されることを示し、プログラムの実行効率を向上させるためにCPUのレジスタに格納できます。

C++11 で非推奨(deprecated)としてマークされました。 C++17 で正式に削除されました。

const サンプル

const int NUM = 10; // 定义常量 NUM，其值不可修改
const int* ptr = &NUM; // 定义指向常量的指针，指针所指的值不可修改
int const* ptr2 = &NUM; // 和上面一行等价

volatile サンプル

volatile int num = 20; // 定义变量 num，其值可能会在未知的时间被改变

mutable サンプル

class Example {
public:
    int get_value() const {
        return value_; // const 关键字表示该成员函数不会修改对象中的数据成员
    }
    void set_value(int value) const {
        value_ = value; // mutable 关键字允许在 const 成员函数中修改成员变量
    }
private:
    mutable int value_;
};

static サンプル

void example_function() {
    static int count = 0; // static 关键字使变量 count 存储在程序生命周期内都存在
    count++;
}

register サンプル

void example_function(register int num) {
    // register 关键字建议编译器将变量 num 存储在寄存器中
    // 以提高程序执行速度
    // 但是实际上是否会存储在寄存器中由编译器决定
}

  • C++11 で非推奨(deprecated)としてマークされました。
  • C++17 で正式に削除されました。
  • キーワードとして保持されます（互換性または将来の用途のため）

    C++ はキーワード explicit を提供しており、許可されるべきでない、変換コンストラクタによる暗黙の変換の発生を防ぐことができます。explicit として宣言されたコンストラクタは、暗黙の変換では使用できません。

    C++ では、1つのパラメータを持つコンストラクタ（または最初のパラメータ以外の残りのパラメータがすべてデフォルト値を持つ複数パラメータのコンストラクタ）は、2つの役割を担います。1つはコンストラクタであり、2つ目はデフォルトで暗黙的な型変換演算子です。

    そのため、AAA = XXX のようなコードを書いたとき、ちょうど XXX の型が AAA の単一パラメータコンストラクタのパラメータ型と一致する場合、コンパイラは自動的にこのコンストラクタを呼び出して、AAA のオブジェクトを作成します。

    これはとてもクールで便利に見えます。しかし、特定の状況（下の権威ある例を参照）では、私たち（プログラマー）の意図に反します。この場合は、このコンストラクタの前に explicit 修飾子を付けて、このコンストラクタが明示的にのみ呼び出し/使用でき、型変換演算子として暗黙的に使用できないことを指定する必要があります。

    explicit コンストラクタの役割

    解説：

    explicit コンストラクタは暗黙の変換を防ぐために使用されます。次のコードを見てください：

    class Test1
{
public:
    Test1(int n)
    {
        num=n;
    }//普通构造函数
private:
    int num;
};
class Test2
{
public:
    explicit Test2(int n)
    {
        num=n;
    }//explicit(显式)构造函数
private:
    int num;
};
int main()
{
    Test1 t1=12;//隐式调用其构造函数,成功
    Test2 t2=12;//编译错误,不能隐式调用其构造函数
    Test2 t2(12);//显式调用成功
    return 0;
}

    Test1 のコンストラクタは int 型のパラメータを1つ持ち、コード23行目は暗黙的に Test1 のこのコンストラクタを呼び出すように変換されます。一方、Test2 のコンストラクタは explicit（明示的）として宣言されているため、暗黙の変換によってこのコンストラクタを呼び出すことはできません。したがって、コード24行目でコンパイルエラーが発生します。

    通常のコンストラクタは暗黙的に呼び出すことができます。一方、explicit コンストラクタは明示的にのみ呼び出すことができます。

    volatile はしばしばマルチスレッドの修飾に使用されます。例えば：

    volatile boolean isNext = false;

Thread A（） {
    // 第一个工作
    // isNext = true;
}

Thread B （）{
    if (isNext) {
        // 第二个工作
    }
}

    ここで volatile は isNext をマークするために使用され、スレッドBが毎回メモリから isNext の値を再読み取りすることを保証し、2番目の処理が必ず1番目の処理の後に実行されるようにします。

    ただし、ここでは順序性を保証できないことに注意してください。コンパイラはコンパイル時に2つの文の順序を並べ替える可能性があるため、1番目の処理を実行することと isNext に値を代入することは、必ずしもコードの順序どおりに実行されるとは限りません。

    詳細については、以下を参照してください：C/C++ における volatile キーワードの詳しい解説

    符号なしから符号付きへのビット演算については、N-2^nN - 2^n の計算方法を採用し、n は定義されたデータ型に依存します。int、short、char、long intなお、N は符号なし数の値です。例えば、文中の N=50000、short が16ビットの場合、計算方法は 50000-2^16 で -15536 となります。
