    C++ における"\n" 与 endlの違いは何ですか？

    "\n" は内容が1つの復帰文字である文字列を表します。std::endl はストリーム操作子であり、出力の働きは "\n" の出力と似ていますが、若干異なる場合があります。

    std::endl は改行文字を出力し、すぐにバッファをフラッシュします。

    例：

    std::cout << std::endl;

    次と同等です：

    std::cout << '\n' << std::flush;
或者
std::cout << '\n'; std::fflush(stdout);

    ストリーム演算子 << のオーバーロードにより、'\n' と "\n" では出力効果は同じです。

    出力バッファを持つストリーム（cout、clog など）の場合、手動でバッファのフラッシュ操作を行わなければ、バッファが満杯になった後に自動的に出力がフラッシュされます。ただし、cout に関しては（ファイル出力ストリームなどと比較して）、バッファリングは通常あまり顕著ではありません。しかし、必要な場合は '\n' の代わりに endl を使用するのが一般的に良い習慣です。

    バッファリングされないストリーム（標準エラー出力ストリーム cerr など）の場合、フラッシュは不要であり、直接 '\n' を使用できます。

    C++ では、.h と .cpp をそれぞれ使用してクラスを定義します。

    .h.h にはクラスの宣言、関数プロトタイプ（クラスの宣言内に置く）を格納します。

    .cpp.cpp には関数本体を格納します。

    つまり、一方は宣言（declaration）を格納し、もう一方は定義（definition）を格納します。

    ヘッダファイル内で関数を宣言した場合、その関数を定義する必要があるとき（この定義は一意であり、つまり一度しか定義できません）、またはその関数を使用する必要があるとき、cpp 内でこのヘッダファイルを include する必要があります。

    同様に、ヘッダファイル内でクラスを宣言した場合、クラスのメンバ関数を定義する必要があるとき、またはそのクラスを使用する必要があるとき、cpp 内でこのヘッダファイルを include する必要があります。

    クラスの設計者にとって、ヘッダファイルはクラスの利用者との契約のようなものであり、コンパイラはこの契約を強化します。クラス内の関数や構造体を使用する際には、必ず宣言することが要求されます。

    "\n"1つの文字列を表し、その唯一のデータは復帰文字です。

    '\n'1つの文字を表します。

    この2つは出力上では同じです！

    endl について：

    1、C++ で、端末に改行を出力するときは、cout<<......<<endlendl と "\n" のどちらでも使用できます。これは初級の認識です。しかし両者には小さな違いがあります。endl を使用するとバッファがフラッシュされ、スタック内のものが一度更新されますが、"\n" を使用するとフラッシュされず、改行するだけで、スタック内のデータは変化しません。ただし一般的な状況では、この両者の違いは非常に小さく、大規模なプログラムで使用されるかもしれません。改行には endl を使用することをお勧めします。

    2、endl は '\n' を書き込むだけでなく、flush 関数も呼び出してバッファをフラッシュし、バッファ内のデータをファイルまたは画面に書き込みます。効率を考慮するなら '\n' を使用します。

    3、cout << endl; は出力ストリームに '\n' を挿入するだけでなく、出力ストリームをフラッシュする作用もあります。

    cout << endl; 
等价于: 
\cout << '\n' << flush;

    出力ストリームをフラッシュする必要がない場合は、できるだけ '\n' を使用すべきです。cout << '\n'あまりに多くの endl はプログラムの実行効率を低下させる要因の一つです。

    C++ における using namespace std は一体どういう意味ですか？

    名前空間を宣言するという意味です。名前空間は複数人での共同作業の際に非常に役立ちます。なぜなら、あなたが変数 a を定義し、他の人も変数 a を定義すると、重複定義になってしまうからです。もしあなたが自分の名前空間で a を定義し、他の人が他の人の名前空間で a を定義すれば、重複しません。例えば：

    using namespace xx;
using namespace yy;

    xx::a 和 yy::aどちらも a という名前ですが、同じ変数ではありません。

    std はシステム標準の名前空間です。ユーザーが定義した名前と重複しないように、std という名前空間に宣言されています。また、この名前空間は大きなパッケージのようなもので、システムのすべてのサポートを含んでいます。

    :::: は C++ においてスコープ（有効範囲）と所属関係を表します。:::: は演算子の中で最も優先順位が高く、以下の3種類に分けられます：

    一、スコープ演算子：

    スコープ演算子（::）::の前には通常クラス名がきて、後ろには通常そのクラスのメンバ名がきます。C++ では、異なるクラスが同じ名前のメンバを持つことを避けるために、スコープによる方式で区別しています。

    例えば：A、B が2つのクラスを表し、A、B の両方にメンバ member があります。

    その場合：

    • 1、A::member はクラス A 内のメンバ member を表します。
    • 2、B::member はクラス B 内のメンバ member を表します。

    二、グローバルスコープ演算子：

    グローバルスコープ演算子：グローバル変数がローカル関数内の特定の変数と同名の場合、:: を使用して::区別できます。例えば：

    char  zhou;  //全局变量
void  sleep()
{
  char  zhou; //全局变量
  char(局部变量) = char(局部变量)*char(局部变量);
  ::char(全局变量) =::(全局变量) *char(全局变量)
}

    三、スコープ解決演算子：

    :: は C++ におけるスコープ解決演算子です。「例えば、クラス A を宣言し、クラス A 内でメンバ関数 void f() を宣言したが、クラスの宣言内で f の定義を与えなかった場合、クラス外で f を定義するときは、voidA::f() と書く必要があります。これは、この f() 関数がクラス A のメンバ関数であることを表します。例えば：

    class CA 
{
public:
  int ca_var;
  int add(int a, int b);
  int add(int a);
}
//那么在实现这个函数时，必须这样写：
int CA::add(int a, int b)
{
  return a + b;
}
//另外，双冒号也常常用于在类变量内部作为当前类实例的元素进行表示，比如：
int CA::add(int a)
{
  return a + ::ca_var;
}
//表示当前类实例中的变量ca_var。

    なぜ using namespace std; を使うのか

    単語ごとに理解していきましょう：

    • using：参照
    • namespace：名前空間（ネームスペース）
    • std：標準（standard、名前空間の名前です。cout、endlなどはこの名前空間に依存しています）

    では、この行のコードがないと何が起こるでしょうか

    #include <iostream>
// using namespace std;
int main()
{
    cout << "Hello, world!" << endl;
    return 0;
}//error

    では、どのように書けばいいのでしょうか？

    #include <iostream>
// using namespace std;
int main()
{
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

    見てわかるように、std::を追加すればOKです。
