C++ ポインタ

C++ のポインタを学ぶのは簡単で面白いです。ポインタを使うことで、いくつかの C++ プログラミングタスクの実行を簡素化できます。また、動的メモリ割り当てなど、ポインタなしでは実行できないタスクもあります。したがって、優れた C++ プログラマーになるためには、ポインタを学ぶことが非常に必要です。

ご存知のように、すべての変数にはメモリ位置があります。各メモリ位置は、アンパサンド（&）演算子を使用してアクセスできるアドレスを定義しており、それはメモリ内のアドレスを表します。次の例を見てください。定義された変数のアドレスを出力します。

実例

#include <iostream> using namespace std; int main () { int var1; char var2[10]; cout << "var1 変数のアドレス："; cout << &var1 << endl; cout << "var2 変数のアドレス："; cout << &var2 << endl; return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます。

var1 变量的地址： 0xbfebd5c0
var2 变量的地址： 0xbfebd5b6

上記の例を通じて、メモリアドレスとは何か、そしてそれにアクセスする方法を理解しました。次に、ポインタとは何かを見てみましょう。

ポインタとは？

ポインタは変数であり、その値は別の変数のアドレス、つまりメモリ位置の直接アドレスです。他の変数や定数と同様に、ポインタを使用して他の変数のアドレスを格納する前に、それを宣言する必要があります。ポインタ変数の宣言の一般的な形式は次のとおりです。

type *var-name;

ここで、typeはポインタの基本型であり、有効な C++ データ型でなければなりません。var-nameはポインタ変数の名前です。ポインタを宣言するために使用するアスタリスク * は、乗算で使用するアスタリスクと同じです。ただし、このステートメントでは、アスタリスクは変数がポインタであることを指定するために使用されます。以下は有効なポインタ宣言です。

int    *ip;    /* 一个整型的指针 */
double *dp;    /* 一个 double 型的指针 */
float  *fp;    /* 一个浮点型的指针 */
char   *ch;    /* 一个字符型的指针 */

すべてのポインタの値の実際のデータ型は、整数型、浮動小数点型、文字型、その他のデータ型に関係なく、同じであり、メモリアドレスを表す長い16進数です。異なるデータ型のポインタ間の唯一の違いは、ポインタが指す変数または定数のデータ型が異なることです。

C++ でのポインタの使用

ポインタを使用するときは、次の操作を頻繁に行います：ポインタ変数を定義する、変数のアドレスをポインタに代入する、ポインタ変数内の利用可能なアドレスの値にアクセスする。これらは、単項演算子*を使用して、オペランドが指定するアドレスにある変数の値を返します。次の例はこれらの操作に関連しています。

実例

#include <iostream> using namespace std; int main () { int var = 20; // 実際の変数の宣言 int *ip; // ポインタ変数の宣言 ip = &var; // ポインタ変数に var のアドレスを格納 cout << "Value of var variable: "; cout << var << endl; // ポインタ変数に格納されたアドレスを出力 cout << "Address stored in ip variable: "; cout << ip << endl; // ポインタ内のアドレスの値にアクセス cout << "Value of *ip variable: "; cout << *ip << endl; return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます。

Value of var variable: 20
Address stored in ip variable: 0xbfc601ac
Value of *ip variable: 20

C++ ポインタの詳細

C++ には、ポインタに関連する多くの概念があります。これらの概念はどれも単純ですが、すべて重要です。以下に、C++ プログラマーが明確に理解しておく必要があるポインタ関連の重要概念をいくつか示します。

概念説明
C++ Null ポインタC++ はヌルポインタをサポートしています。NULL ポインタは、標準ライブラリで定義されている値がゼロの定数です。
C++ ポインタの算術演算ポインタに対して 4 つの算術演算（++、--、+、-）を実行できます。
C++ ポインタと配列ポインタと配列の間には密接な関係があります。
C++ ポインタ配列ポインタを格納するための配列を定義できます。
C++ ポインタへのポインタC++ はポインタへのポインタを許可します。
C++ 関数にポインタを渡す参照またはアドレスによってパラメータを渡すと、渡されたパラメータが呼び出し先関数内で変更されます。
C++ 関数からポインタを返すC++ では、関数がローカル変数、静的変数、動的メモリ割り当てへのポインタを返すことができます。

    値渡し、ポインタ渡し、参照渡しのこれらの側面には、まだ誤解が存在します。

    値渡し：

    仮引数は実引数のコピーであり、仮引数の値を変更しても外部の実引数の値には影響しません。呼び出された関数の観点から見ると、値渡しは一方向（実引数 -> 仮引数）であり、パラメータの値は渡すだけで、外部に渡し戻すことはできません。関数内でパラメータを変更する必要があるが、その変更が呼び出し元に影響を与えたくない場合は、値渡しを使用します。

    ポインタ渡し：

    仮引数は実引数のアドレスを指すポインタであり、仮引数へのポインタ操作を行うことは、実引数自体に対する操作と同じです。

    参照渡し：

    仮引数は実引数の「別名」に相当し、仮引数に対する操作は実際には実引数に対する操作です。参照渡しの過程では、呼び出された関数の仮引数もローカル変数としてスタックにメモリ空間を確保しますが、このとき格納されるのは、呼び出し元の関数が渡した実引数変数のアドレスです。呼び出された関数が仮引数に対して行う操作はすべて間接アドレス指定として処理されます。つまり、スタックに格納されたアドレスを介して呼び出し元の関数の実引数変数にアクセスします。そのため、呼び出された関数が仮引数に対して行う操作はすべて呼び出し元の関数の実引数変数に影響を与えます。

    #include<iostream>
using namespace std;
//值传递 4  void change1(int n){
    cout<<"值传递--函数操作地址"<<&n<<endl;         //显示的是拷贝的地址而不是源地址  6   n++;
 }
 
 //引用传递10 void change2(int & n){
     cout<<"引用传递--函数操作地址"<<&n<<endl; 
     n++;
 }
  //指针传递15 void change3(int *n){
      cout<<"指针传递--函数操作地址 "<<n<<endl; 
     *n=*n+1;
  } 
 int     main(){
     int n=10;
     cout<<"实参的地址"<<&n<<endl;
     change1(n);
     cout<<"after change1() n="<<n<<endl;
     change2(n);
     cout<<"after change2() n="<<n<<endl;
     change3(&n);
     cout<<"after change3() n="<<n<<endl;
     return true;
 }

    C++ では、関数を指すポインタの宣言が許可されており、関数ポインタと呼ばれます。

    関数ポインタの宣言は関数の宣言に似ていますが、関数名が次のように変わるだけです。(*ポインタ名)定義方法は次のとおりです。

    data_types (*func_pointer)( data_types arg1, data_types arg2, ...,data_types argn);

    例：

    int (*fp)(int a);

    ここでは、関数（パラメータが int 型のみで、戻り値が int 型の関数）を指すポインタ fp を定義しています。

    関数ポインタは宣言後、条件に合致する関数を指すことができる。例えば：

    int a(int b);
{
    cout<<b;
    return ++b;
}

int(*p)(int);
p=a;

    この後、関数ポインタを介して関数を呼び出すことができる：

    (*p)(5);

    詳細は以下を参照：C++ 関数ポインタ & クラスメンバ関数ポインタ

    理解や記憶のために、複数の物事を同じ方法で理解するのは頭の負担を減らせる。

    そこで、次のように：

    • &記号 を一つのメソッドとして理解する：入力は「参照」、出力は「ポインタ」；
    • *記号 を一つのメソッドとして理解する：入力は「ポインタ」、出力は「参照」。

    「演算子オーバーロード」の仕組みを理解すれば、より深く理解できるはずだ。

    また、次のように考えることもできるのではないだろうか：

    • 参照高級プログラミング言語の特徴であり、高級プログラミング言語の制約に従う。
    • ポインタ低級プログラミング言語の特徴であり、高級プログラミング言語の制約を越えて操作できる。

    配列名とポインタの違い：

    char p[]= と char *p= の右辺の文字列リテラルは、使用上違いがある。

    前者は配列を宣言し、文字列リテラルは配列の初期化に使用される。配列の生存期間とスコープは宣言方法に関連する。また、配列に const 修飾子がない場合、文字列の内容は変更可能である。この配列の先頭アドレスは、static を使用して宣言しない限り、関数内で返すことはできない。

    後者はポインタを宣言する。文字列リテラル自体は静的記憶域期間の配列となり、それが暗黙的にポインタに変換されて宣言されたポインタを初期化する。この文字列は変更不可である（変更すると未定義動作を引き起こし、配列自体は読み取り専用メモリ領域に置くことができる）。その先頭アドレスは関数内で返すことができる。

    C++ ポインタ型のキャスト

    ポインタの値およびポインタが指すアドレスの値は、データのアドレスとそのアドレスに格納されているデータの値に対応する。したがって、CPUのエンディアン種別に応じて、ポインタの型を変換して操作を続行する際はエンディアンに注意する必要がある。

    #include <cstdlib>
#include <iostream>

using namespace std;

int main()
{
    char str1[4] = {0x12,0x34,0x56,0x78};
    char * ptr = str1;
    cout << "value of *ptr " << hex << (int)(*ptr) << endl;//hex输出必须对应int类型，否则输出ASCII码
    cout << "value of *ptr " << hex << (int)(*(int*)ptr) << endl;//hex输出必须对应int类型，否则输出ASCII码
    return 0;
}

    コンパイル出力：

    E:\CppTest\VScodeTest\pointer_t> g++ .\pointer_t.cpp -o pointer_t        
E:\CppTest\VScodeTest\pointer_t> .\pointer_t.exe 
value of *ptr 12
value of *ptr 78563412
E:\CppTest\VScodeTest\pointer_t>

    見てわかるように、望んでいた 0x12345678 ではない。
