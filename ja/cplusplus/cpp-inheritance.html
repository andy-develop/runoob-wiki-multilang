C++ 継承

オブジェクト指向プログラミングにおいて最も重要な概念の一つは継承です。継承により、別のクラスに基づいてクラスを定義することができ、アプリケーションの作成と保守が容易になります。これにより、コード機能の再利用と実行効率の向上も達成できます。

クラスを作成するとき、新しいデータメンバーとメンバー関数を書き直す必要はなく、新しく作成したクラスが既存のクラスのメンバーを継承するように指定するだけです。この既存のクラスを基底クラス、新しく作成したクラスを派生クラス。

継承はis a関係を表します。例えば、哺乳類は動物であり、犬は哺乳類です。したがって、犬は動物です、など。

コードは次のとおりです。

// 基底クラス
class Animal {
    // eat() 関数
    // sleep() 関数
};


//派生クラス
class Dog : public Animal {
    // bark() 関数
};

基底クラス & 派生クラス

クラスは複数のクラスから派生できます。つまり、複数の基底クラスからデータと関数を継承できます。派生クラスを定義するには、クラス派生リストを使用して基底クラスを指定します。クラス派生リストは1つ以上の基底クラスを名前で指定し、形式は次のとおりです。

class derived-class: access-specifier base-class

ここで、アクセス修飾子 access-specifier はpublic、protected 或 privateそのうちの1つであり、base-class は以前に定義したクラスの名前です。アクセス修飾子 access-specifier を使用しない場合、デフォルトは private です。

基底クラスがあるとしますShape，Rectangleその派生クラスは次のようになります。

例

#include <iostream> using namespace std; // 基底クラス class Shape { public: void setWidth(int w) { width = w; } void setHeight(int h) { height = h; } protected: int width; int height; }; // 派生クラス class Rectangle: public Shape { public: int getArea() { return (width * height); } }; int main(void) { Rectangle Rect; Rect.setWidth(5); Rect.setHeight(7); // オブジェクトの面積を出力 cout << "Total area: " << Rect.getArea() << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Total area: 35

アクセス制御と継承

派生クラスは基底クラスのすべての非プライベートメンバーにアクセスできます。したがって、基底クラスのメンバーを派生クラスのメンバー関数からアクセスされたくない場合は、基底クラスで private として宣言する必要があります。

アクセス権限に基づいて、さまざまなアクセスタイプを次のようにまとめることができます。

アクセスpublicprotectedprivate
同じクラスyesyesyes
派生クラスyesyesno
外部のクラスyesnono

派生クラスはすべての基底クラスのメソッドを継承しますが、次の場合は例外です。

  • 基底クラスのコンストラクタ、デストラクタ、コピーコンストラクタ。
  • 基底クラスのオーバーロードされた演算子。
  • 基底クラスのフレンド関数。

継承の種類

クラスが基底クラスから派生するとき、その基底クラスはpublic、protected 或 privateいくつかのタイプに継承できます。継承タイプは、上で説明したアクセス修飾子 access-specifier によって指定されます。

私たちはほとんど使用しませんprotected 或 private継承は、通常はpublic継承を使用します。異なるタイプの継承を使用する場合、次のルールに従います。

  • 公有継承（public）：クラスが公有基底クラスから派生するとき、基底クラスの公有メンバーは派生クラスの公有メンバーでもあり、基底クラスの保護メンバーは派生クラスの保護メンバーでもあり、基底クラスのプライベートメンバーは派生クラスから直接アクセスできませんが、基底クラスの公有和保護メンバーを呼び出してアクセスできます。
  • 保護継承（protected）：クラスが保護基底クラスから派生するとき、基底クラスの公有和保護メンバーは派生クラスの保護メンバーになります。
  • プライベート継承（private）：クラスがプライベート基底クラスから派生するとき、基底クラスの公有和保護メンバーは派生クラスのプライベートメンバーになります。

多重継承

多重継承とは、1つのサブクラスが複数の親クラスを持つことができ、複数の親クラスの特性を継承することです。

C++ クラスは複数のクラスからメンバーを継承できます。構文は次のとおりです。

class <派生类名>:<继承方式1><基类名1>,<继承方式2><基类名2>,…
{
<派生类类体>
};

ここで、アクセス修飾子の継承方法はpublic、protected 或 privateそのうちの1つで、各基底クラスを修飾するために使用し、各基底クラスは上記のようにカンマで区切ります。それでは、以下の例を見てみましょう。

例

#include <iostream> using namespace std; // 基底クラス Shape class Shape { public: void setWidth(int w) { width = w; } void setHeight(int h) { height = h; } protected: int width; int height; }; // 基底クラス PaintCost class PaintCost { public: int getCost(int area) { return area * 70; } }; // 派生クラス class Rectangle: public Shape, public PaintCost { public: int getArea() { return (width * height); } }; int main(void) { Rectangle Rect; int area; Rect.setWidth(5); Rect.setHeight(7); area = Rect.getArea(); // オブジェクトの面積を出力 cout << "Total area: " << Rect.getArea() << endl; // 総費用を出力 cout << "Total paint cost: $" << Rect.getCost(area) << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Total area: 35
Total paint cost: $2450

    また、多重継承（環状継承）、A->D, B->D, C->(A，B)、例えば：

    class D{......};
class B: public D{......};
class A: public D{......};
class C: public B, public A{.....};

    この継承ではDが2つのオブジェクトを作成することになります。上記の問題を解決するには仮想継承形式を使用します。

    形式：class クラス名: virtual 継承方式 親クラス名

    class D{......};
class B: virtual public D{......};
class A: virtual public D{......};
class C: public B, public A{.....};

    仮想継承--（オブジェクトを作成するときに仮想テーブルが作成されます）親クラスのオブジェクトを作成するとき

    A:virtual public D
B:virtual public D

    例：

    #include <iostream>

using namespace std;
//基类

class D
{
public:
    D(){cout<<"D()"<<endl;}
    ~D(){cout<<"~D()"<<endl;}
protected:
    int d;
};

class B:virtual public D
{
public:
    B(){cout<<"B()"<<endl;}
    ~B(){cout<<"~B()"<<endl;}
protected:
    int b;
};

class A:virtual public D
{
public:
    A(){cout<<"A()"<<endl;}
    ~A(){cout<<"~A()"<<endl;}
protected:
    int a;
};

class C:public B, public A
{
public:
    C(){cout<<"C()"<<endl;}
    ~C(){cout<<"~C()"<<endl;}
protected:
    int c;
};

int main()
{
    cout << "Hello World!" << endl;
    C c;   //D, B, A ,C
    cout<<sizeof(c)<<endl;
    return 0;
}

    なぜ子クラスのコンストラクタの初期化リストに現れるのでしょうか？その理由は、子クラスが基底クラスから継承できる内容に制限があるためです。

    ご存知のように、派生クラスはすべての基底クラスのメソッドを継承しますが、次の場合は例外です。

    • 基底クラスのコンストラクタ、デストラクタ、コピーコンストラクタ。
    • 基底クラスのオーバーロードされた演算子。
    • 基底クラスのフレンド関数。

    したがって、子クラスのメンバー関数の本体で基底クラスのコンストラクタを呼び出してメンバー変数を初期化することはできません。例えば、このような方法はできません。

    #include <iostream>
 
using namespace std;
 
// 基类
class Shape 
{
   public:
      Shape(int w,int h)
      {
        width=w;
        height=h;
      }
   protected:
      int width;
      int height;
};
 
// 派生类
class Rectangle: public Shape
{
   public:
      Rectangle(int a,int b)
      {
        Shape(a,b);
      }

     
};

    しかし、基底クラスのコンストラクタを子クラスのコンストラクタの初期化リストに置くことで、基底クラスのコンストラクタを呼び出して、子クラスが基底クラスから継承したメンバー変数を初期化することができます。

    #include <iostream>
 
using namespace std;
 
// 基类
class Shape 
{
   public:
      Shape(int w,int h)
      {
        width=w;
        height=h;
      }
   protected:
      int width;
      int height;
};
 
// 派生类
class Rectangle: public Shape
{
   public:
      Rectangle(int a,int b):Shape(a,b)
      {
        
      }
};

    コンストラクタの初期化リストの実行順序について補足します。

    #include<iostream>
using namespace std;

class A
{
public:
    A()
    {
        cout << "call A()" << endl;
    }
};

class B :A
{
public:
    B(int val) : A(), value(val)
    {
        val = 0;    // 重新赋值
        cout << "call B()" << endl;
        cout << val << endl;    
    }

private:
    int value;
};

int main()
{
    B b(10);
    return 0;
}

/*
* 结果如下 
* call A()
* call B()
* 0
* 说明放在初始化列表的部分在构造函数之前执行

    派生クラスは基底クラスのメンバー変数を継承するとき、基底クラスのメンバー変数を保存するために別のメモリ領域を確保します。そのため、派生クラス自身のメンバー変数が基底クラスのメンバー変数と同名でも、衝突することはありません。次のコードのとおりです。

    #include <iostream>
using namespace std;

//基类
class A
{
public:
   A(){n = 0;};
   ~A(){};
   int getA(){ return n;};
   void setA(int t){ n = t;};

private:
   int n;
};

//派生类
class B :public A
{
public:
   B(){ n = 0;};
   ~B(){};
   int getB(){ return n;};
   void setB(int t){ n = t;};

private:
  int n;
};

int main(int argc, char * argv[])
{
   B b;
   b.setA(10); //设置基类的成员变量n

   cout<<"A::n "<<b.getA()<<endl;                                                                       
   cout<<"B::n "<<b.getB()<<endl;                                                                                                                                                         
   b.setB(9);  //设置派生类的成员变量n                                                                                                                     
   cout<<"A::n "<<b.getA()<<endl;                                                                       
   cout<<"B::n "<<b.getB()<<endl;                                                                                                                            
   return 0;                                                                                 
}

    結果は次のとおりです。

    A::n 10
B::n 0
A::n 10
B::n 9

    コンストラクタの呼び出し順序：基底クラス > メンバークラス > 派生クラス；

    多重継承の派生クラス：基底クラスのコンストラクタは基底クラスの継承順序に従って呼び出されます。

    クラスメンバー：クラスメンバーオブジェクトの定義順序に従ってメンバークラスのコンストラクタが呼び出されます。

    #include <iostream>
using namespace std;

class Shape {   // 基类 Shape
public:
    Shape() {
        cout << "Shape" << endl;
    }
    ~Shape() {
        cout << "~Shape" << endl;
    }
};

class PaintCost {   // 基类 PaintCost
public:
    PaintCost() {
        cout << "PaintCost" << endl;
    }
    ~PaintCost() {
        cout << "~PaintCost" << endl;
    }
};

// 派生类
class Rectangle : public Shape, public PaintCost  //基类构造顺序 依照 继承顺序
{
public:
    Rectangle() :b(), a(), Shape(), PaintCost(){
        cout << "Rectangle" << endl;
    }
    ~Rectangle() {
        cout << "~Rectangle" << endl;
    }
    PaintCost b;        // 类成员变量构造顺序 依照 变量定义顺序
    Shape a; 
};

int main(void)
{
    Rectangle Rect;
    return 0;
}

    結果：

    Shape
PaintCost
PaintCost
Shape
Rectangle
~Rectangle
~Shape
~PaintCost
~PaintCost
~Shape

    2階（2番目の書き込み）の説明を補足すると、派生クラスは親クラスのコンストラクタを継承しますが、コンストラクタを継承する際にはいくつかの注意点があります。これは C++11 以降の標準でサポートされています。具体的な状況は、派生クラスが独自のコンストラクタを定義しているかどうか、および親クラスのコンストラクタのアクセス可能性によって異なります。

    #define _CRT_SECURE_NO_WARNINGS

#include <iostream>

using namespace std;

class Base {
public:
    Base() {
        num = 5;
        cout << "BaseConstructorCall:" << protectedMember << endl;
    }
    Base(int n) {
        num = n;
        cout << "BaseConstructorCallnum:" << protectedMember << endl;
    }
    ~Base() {
        cout << "BaseDestructorCall:" << protectedMember << endl;
    }
protected:
    int protectedMember = 0;
    int num;
};

class Derived1 : public Base {
public:
    using Base::Base; // 这行声明继承父类的构造方法
    void modifyMember(int newValue) {
        protectedMember = newValue; // 修改父类的成员
        cout << "Derived1:" << num << endl;
    }
};

class Derived2 : public Base {
public:
    void modifyMember(int newValue) {
        protectedMember = newValue; // 修改同一个父类的成员
        cout << "Derived2:" << num << endl;
    }
};

int main() {
    Derived1 d1(88);
    Derived2 d2;

    d1.modifyMember(10);
    d2.modifyMember(20);

    return 0;
}

    出力で確認できます。

    Derived：88

    主に基底クラスのコンストラクタ定義を使用する必要があります：

    using Base::Base; // 这行声明继承父类的构造方法

    基底クラスの公有メンバー関数を呼び出すことで、基底クラスのプライベートメンバー変数にアクセスします：

    #include <iostream>
using namespace std;

class Base {
private:
    int privateVar;
public:
    Base() : privateVar(10) {}
    void accessPrivateVar() {
        cout << "Base privateVar: " << privateVar << endl;
    }
};

class Derived : public Base {
public:
    void accessBasePrivateVar() {
        // 通过调用基类的公有成员函数来访问基类的私有成员变量
        accessPrivateVar();
    }
};

int main() {
    Derived d;
    d.accessBasePrivateVar(); // 输出 Base privateVar: 10
    return 0;
}
