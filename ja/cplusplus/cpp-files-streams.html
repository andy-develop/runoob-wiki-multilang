C++ ファイルとストリーム

これまでのところ、私たちは使用してきましたiostream標準ライブラリ、それは提供しますcin 和 coutメソッドは、標準入力からストリームを読み取り、標準出力へストリームを書き込むためにそれぞれ使用されます。

このチュートリアルでは、ファイルからストリームを読み取り、ファイルへストリームを書き込む方法を説明します。これには、C++ の別の標準ライブラリを使用する必要があります。fstreamこれは、3つの新しいデータ型を定義します：

データ型 説明
ofstream このデータ型は出力ファイルストリームを表し、ファイルを作成してファイルに情報を書き込むために使用されます。
ifstream このデータ型は入力ファイルストリームを表し、ファイルから情報を読み取るために使用されます。
fstream このデータ型は通常、ファイルストリームを表し、ofstream と ifstream の両方の機能を同時に持ちます。つまり、ファイルを作成し、ファイルに情報を書き込み、ファイルから情報を読み取ることができます。

C++ でファイル処理を行うには、C++ ソースコードファイルにヘッダファイル <iostream> と <fstream> を含める必要があります。

ファイルを開く

ファイルから情報を読み取る、またはファイルに情報を書き込む前に、ファイルを開く必要があります。ofstream 和 fstreamオブジェクトは、書き込み操作のためにファイルを開くために使用できます。読み取り操作のためにのみファイルを開く必要がある場合は、使用しますifstreamオブジェクト。

以下は open() 関数の標準構文です。open() 関数は fstream、ifstream、ofstream オブジェクトのメンバです。

void open(const char *filename, ios::openmode mode);

ここで、open()メンバ関数の最初のパラメータは開くファイルの名前と場所を指定し、2番目のパラメータはファイルが開かれるモードを定義します。

モードフラグ 説明
ios::app 追記モード。すべての書き込みはファイルの末尾に追加されます。
ios::ate ファイルを開いた後、ファイルの末尾に位置付けられます。
ios::in 読み取り用にファイルを開きます。
ios::out 書き込み用にファイルを開きます。
ios::trunc ファイルが既に存在する場合、その内容はファイルを開く前に切り詰められ、つまりファイル長が 0 に設定されます。

上記の2つ以上のモードを組み合わせて使用できます。例えば、書き込みモードでファイルを開き、ファイルが既に存在する場合に備えてファイルを切り詰めたい場合は、次の構文を使用できます：

ofstream outfile;
outfile.open("file.dat", ios::out | ios::trunc );

同様に、読み書き用にファイルを開きたい場合は、次の構文を使用できます：

ifstream  afile;
afile.open("file.dat", ios::out | ios::in );

ファイルを閉じる

C++ プログラムが終了すると、自動的にすべてのストリームを閉じてフラッシュし、割り当てられたすべてのメモリを解放し、開いているすべてのファイルを閉じます。しかし、プログラマはプログラム終了前に開いているすべてのファイルを閉じるという良い習慣を身につけるべきです。

以下は close() 関数の標準構文です。close() 関数は fstream、ifstream、ofstream オブジェクトのメンバです。

void close();

ファイルへの書き込み

C++ プログラミングでは、ストリーム挿入演算子（<<）を使用してファイルに情報を書き込みます。これは、この演算子を使用して画面に情報を出力するのと同じです。唯一の違いは、ここでは使用するのがofstream 或 fstreamオブジェクトであり、ではなくcoutオブジェクトです。

ファイルの読み取り

C++ プログラミングでは、ストリーム抽出演算子（>>）を使用してファイルから情報を読み取ります。これは、この演算子を使用してキーボードから情報を入力するのと同じです。唯一の違いは、ここでは使用するのがifstream 或 fstreamオブジェクトであり、ではなくcinオブジェクトです。

読み取り & 書き込みの例

次の C++ プログラムは、読み書きモードでファイルを開きます。ユーザーが入力した情報をファイル afile.dat に書き込んだ後、プログラムはファイルから情報を読み取り、それを画面に出力します：

例

#include <fstream> #include <iostream> using namespace std; int main() { char data[100]; // 書き込みモードでファイルを開く ofstream outfile; outfile.open("afile.dat"); cout << "Writing to the file" << endl; cout << "Enter your name: "; cin.getline(data, 100); // ユーザーが入力したデータをファイルに書き込む outfile << data << endl; cout << "Enter your age: "; cin >> data; cin.ignore(); // 再度ユーザーが入力したデータをファイルに書き込む outfile << data << endl; // 開いたファイルを閉じる outfile.close(); // 読み取りモードでファイルを開く ifstream infile; infile.open("afile.dat"); cout << "Reading from the file" << endl; infile >> data; // 画面にデータを書き込む cout << data << endl; // 再度ファイルからデータを読み取り、それを表示する infile >> data; cout << data << endl; // 開いたファイルを閉じる infile.close(); return 0; }

上記のコードがコンパイルされて実行されると、次の入力と出力が生成されます：

$./a.out
Writing to the file
Enter your name: Zara
Enter your age: 9
Reading from the file
Zara
9

上記の例では、cin オブジェクトの付加関数を使用しています。例えば、getline() 関数は外部から1行を読み取り、ignore() 関数は以前の読み取りステートメントが残した余分な文字を無視します。

ファイル位置ポインタ

istream 和 ostreamどちらも、ファイル位置ポインタを再配置するためのメンバ関数を提供します。これらのメンバ関数には、istream に関するseekg（"seek get"）と ostream に関するseekp（"seek put"）。

seekg と seekp のパラメータは通常 long 型です。2番目のパラメータは検索方向を指定するために使用できます。検索方向は次のいずれかです：ios::beg（デフォルトで、ストリームの先頭から位置を指定）、またはios::cur（ストリームの現在位置から位置を指定）、またはios::end（ストリームの末尾から位置を指定）。

ファイル位置ポインタは整数値であり、ファイルの開始位置からポインタの現在位置までのバイト数を指定します。以下は "get" ファイル位置ポインタの位置指定に関する例です：

// fileObject の n 番目のバイトに位置付ける（ios::beg と仮定） fileObject.seekg( n ); // ファイルの読み取りポインタを fileObject の現在位置から後ろに n バイト移動する fileObject.seekg( n, ios::cur ); // ファイルの読み取りポインタを fileObject の末尾から n バイト戻す fileObject.seekg( n, ios::end ); // fileObject の末尾に位置付ける fileObject.seekg( 0, ios::end );

    読み書き&コピーの例

    次の C++ プログラムは、読み書きモードでファイルを開きます。

    file_wr() は、ユーザーが入力した情報をファイル test.txt に書き込んだ後、プログラムがファイルから情報を読み取り、それを画面に出力します；

    file_copy() は、ファイル test.txt 内のデータを読み出した後、test_1.txt に書き込みます。

    #include "iostream"
#include "fstream"
using namespace std;

//向文件内部写入数据，并将数据读出
void file_wr(void)
{
    char data[100];
    //向文件写入数据
    ofstream outfile;
    outfile.open("test.txt");
    cout << "Write to the file" << endl;
    cout << "Enter your name:" << endl;
    cin.getline(data, 100);
    outfile << data << endl;
    cout << "Enter your age:" << endl;
    cin >> data;
    cin.ignore();
    outfile << data << endl;
    outfile.close();
    //从文件读取数据
    ifstream infile;
    infile.open("test.txt");
    cout << "Read from the file" << endl;
    infile >> data;
    cout << data << endl;
    infile >> data;
    cout << data << endl;
    infile.close();
}


//将数据从一文件复制到另一文件中
void file_copy(void)
{
    char data[100];
    ifstream infile;
    ofstream outfile;
    infile.open("test.txt");
    outfile.open("test_1.txt");
    cout << "copy from test.txt to test_1.txt" << endl;
    while (!infile.eof())
    {
        infile >> data;
        cout << data << endl;
        outfile << data << endl;
    }
    infile.close();
    outfile.close();
}

//测试上述读写文件，与文件数据复制
int _tmain(int argc, _TCHAR* argv[])
{
    file_wr();
    file_copy();
    return 0;
}

John

    cin.ignore() について、完全なバージョンは cin.ignore(int n, char a) です。入力ストリーム (cin) から文字を抽出し、抽出された文字は無視 (ignore) され、使用されません。文字を捨てるたびに、カウントと文字の比較が行われます：カウント値が n に達するか、捨てられた文字が a であれば、cin.ignore() 関数の実行は終了します；そうでなければ、待機を続けます。その一般的な用途の1つは、Enter で終了する入力バッファの内容をクリアして、前回の入力が次の入力に与える影響を排除することです。例えば、cin.ignore(1024,'\n') のように使用できます。通常、最初のパラメータは十分に大きく設定されるため、実際には常に2番目のパラメータ \n だけが機能します。つまり、この1文は、改行（改行を含む）より前のすべての文字を入力バッファ（ストリーム）からクリアします。

    #include <iostream>
using namespace std;
void main()
{
    int a,b,c;
    cout<<"input a:";
    cin>>a;
    cin.ignore(1024, '\n');
    cout<<"input b:";
    cin>>b;
    cin.ignore(1024, '\n');
    cout<< "input c:";
    cin>> c;
    cout<< a << "\t" << b << "\t" << c << endl;
}

    cin.ignore() にパラメータを与えない場合、デフォルトのパラメータは cin.ignore(1,EOF) です。ここで EOF は end of file の略で、"文字ストリーム" (stream) の終わりを表します。

    #include<iostream>  
using   namespace   std;  
int main()  
{  
    char   str1[30],str2[30],str3[30];  
    cout   <<   "请输入你的姓名：";  
    cin>>str1;  
    cout<<"请输入你的住址：";  
    cin.ignore();  
    cin.getline(str2,30,'a');  
    cout   <<   "请输入你的籍贯：";  
    cin.ignore();  
    cin.getline(str3,30);  
    cout<<str3;  
}

    もしアドレス欄に bcdabcd と入力した場合、その時点でストリームに残っているのは bcd\n です。このとき cin.ignore(); が消費するのは b です。するとストリームにはまだ cd\n が残っており、それがそのまま cin.getline(str3,30); に渡されます。\n があるため、ここで getline は直接戻ります。

    C言語の直感に反する話として、C++ではリソースを自動解放させることで、心的負担を減らすのが良いです。

    学習初期に close を忘れないように強調するのは、GCのない言語ではリソースの取得と解放をしっかり管理するように促すためです。しかし実際には、C++のファイルストリームはデストラクタで開いたファイルを自動的に閉じます。

    閉じた後に正常に閉じられたかどうかを確認する必要がある場合を除き、そのときだけファイルストリームオブジェクトを保持する必要があります。

    ここでstackoverflowの投稿を引用します：https://stackoverflow.com/questions/4802494/do-i-need-to-close-a-stdfstream

    > fstream は正しい RAII オブジェクトであり、スコープの終了時に自動的に閉じられます。スコープの終了時に閉じるだけで十分な場合、手動で close を呼び出す必要はまったくありません。特に、これは「ベストプラクティス」ではなく、出力をフラッシュする必要もありません。
