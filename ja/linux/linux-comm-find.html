Linux find コマンド

Linux コマンド大全

Linux find コマンドは、指定したディレクトリ内のファイルとディレクトリを検索するために使用されます。

さまざまなオプションを使用して、検索結果をフィルタリングしたり制限したりできます。

構文

find [路径] [匹配条件] [动作]

パラメータの説明 :

パスパスは検索するディレクトリのパスです。ディレクトリまたはファイル名を1つ指定できます。複数のパスをスペースで区切って指定することもできます。パスを指定しない場合は、デフォルトで現在のディレクトリになります。

expressionオプションのパラメータで、検索条件を指定するために使用します。ファイル名、ファイルタイプ、ファイルサイズなどを指定できます。

マッチング条件で使用できるオプションは20〜30個もあります。以下に最も一般的なものを示します。

  • -name pattern：ファイル名で検索します。ワイルドカードを使用できます。* 和 ?。
  • -type type：ファイルタイプで検索します。次のものを指定できます。f（通常ファイル）、d（ディレクトリ）、l（シンボリックリンク）など。
  • -size [+-]size[cwbkMG]：ファイルサイズで検索します。次のものを使用できます。+ 或 -指定サイズより大きいか小さいかを表します。単位は次のものを使用できます。c（バイト）、w（単語数）、b（ブロック数）、k（KB）、M（MB）またはG（GB）。
  • -mtime days：変更時刻で検索します。次のものを使用できます。+ 或 -指定した日数の前または後を表します。days は日数を表す整数です。
  • -user username：ファイル所有者で検索します。
  • -group groupname：ファイルの所属グループで検索します。

アクション:オプションで、マッチしたファイルに対して削除やコピーなどの操作を実行するために使用します。

find コマンドで時間に関連するパラメータは次のとおりです：

  • -amin n：n 分以内にアクセスされたファイルを検索します。
  • -atime n：n*24 時間以内にアクセスされたファイルを検索します。
  • -cmin n：n 分以内にステータスが変更されたファイル（例：パーミッション）を検索します。
  • -ctime n：n*24 時間以内にステータスが変更されたファイル（例：パーミッション）を検索します。
  • -mmin n：n 分以内に変更されたファイルを検索します。
  • -mtime n：n*24 時間以内に変更されたファイルを検索します。

これらのパラメータでは、n は正の数、負の数、またはゼロにできます。正の数は指定した時間内に変更またはアクセスされたファイルを表し、負の数は指定した時間より前に変更またはアクセスされたファイルを表し、ゼロは現在の時点で変更またはアクセスされたファイルを表します。

正の数は時間より前を表し、負の数は時間以内を表します。

例：-mtime 0今日変更されたファイルを検索することを示します。-mtime -71週間より前に変更されたファイルを検索することを示します。

時間 n パラメータに関する説明：

  • +n：n 日より前のファイルまたはディレクトリを検索します。

  • -n：n 日以内に属性を変更したファイルまたはディレクトリを検索します。

  • n：n 日前（指定した日）に属性を変更したファイルまたはディレクトリを検索します。

例

現在のディレクトリ内の file.txt という名前のファイルを検索する：

find . -name file.txt

現在のディレクトリとそのサブディレクトリ内のすべてのファイルについて、拡張子が.cであるファイルを一覧表示します：

# find . -name "*.c"

現在のディレクトリとそのサブディレクトリ内のすべてのファイルを一覧表示します：

# find . -type f

/home ディレクトリ内の 1MB より大きいファイルを検索する：

find /home -size +1M

/var/log ディレクトリ内の 7 日前に変更されたファイルを検索する：

find /var/log -mtime +7

過去 7 日以内にアクセスされたファイルを検索する：

find /path/to/search -atime -7

現在のディレクトリ内で、直近 20 日以内にステータスが変更されたファイルとディレクトリを検索する：

# find . -ctime  20

現在のディレクトリとそのサブディレクトリ内の、20 日以前およびそれより前に更新されたすべてのファイルを一覧表示します：

# find . -ctime  +20

/var/log ディレクトリ内の変更日時が 7 日より前の通常ファイルを検索し、削除する前にそれらを確認します：

# find /var/log -type f -mtime +7 -ok rm {} \;

現在のディレクトリ内で、ファイル所有者が読み取り・書き込み権限を持ち、ファイルの所属グループのユーザーとその他のユーザーが読み取り権限を持つファイルを検索する：

# find . -type f -perm 644 -exec ls -l {} \;

システム内のすべてのファイル長が 0 の通常ファイルを検索し、それらの完全なパスを一覧表示します：

# find / -type f -size 0 -exec ls -l {} \;

検索して操作（例：削除）を実行する：

find /path/to/search -name "pattern" -exec rm {} \;

この例では、-execオプションを使用するとコマンドを実行でき、{}マッチしたファイル名に置き換えられ、\;コマンドの終了を表します。

    シナリオ1：サーバーのディスクが満杯です。通常は大きなログファイルが原因です。大きなファイルを見つけて削除する必要があります。

    解決策1: find / -size +500M -print0|xargs -0 du -m|sort -nr

    find コマンドは500MB以上のファイルを探します。print0 と xargs -0 を組み合わせて使用し、ファイル名にスペースや特殊文字がある場合の問題を解決します。du -m はこれらのファイルのサイズを確認し、m単位で表示します。最後に sort -nr は数値で逆順にソートします（大きいファイルが先頭になります）。

    解決策2：上記の方法はルートパスから検索するため、一部のシステムファイルがリストされる可能性があります。この検索の前にフィルタリングを行うことができます。

    使用するdu -m -d 1 /|sort -nr まずルートパス下で、どのフォルダが比較的大きく、ディスク満杯の原因として疑わしいかを確認します。その後、そのディレクトリを基に find を実行します。

    解決： find / -name *xxx*.cこのファイルをあいまい検索してみる

    find でファイルの変更時刻を基準にファイルを検索する：

    ---(+n)----------|----------(n)----------|----------(-n)---
      (n+1)*24H前|   (n+1)*24H~n*24H间   |n*24H内
    • -ctime -n-- 現在から n*24H 以内に変更されたファイルを検索する
    • -ctime n-- 現在から n*24H 前と (n+1)*24H 前の間に変更されたファイルを検索する
    • -ctime +n-- 現在から (n+1)*24H より前に変更されたファイルを検索する
    • [a|c|m]min-- [最終アクセス|最終ステータス変更|最終内容変更]min
    • [a|c|m]time-- [最終アクセス|最終ステータス変更|最終内容変更]time

    Linux ファイルの時間の種類（find を例として）：

    • atime は最後のアクセス時刻です。例えば ls、more などが該当します。ただし、chmod、chown、ls、stat などはこの時刻を変更しません。ls -utl を使用すると、この時刻順に表示できます。
    • ctime は最後のステータス変更時刻です。chmod、chown などではステータス時刻は変わりますが、変更時刻は変わりません。stat file で確認できます。
    • mtime は最後の内容変更時刻です。vi で保存した後などに変更されます。変更時刻が変わると、atime と ctime もそれに応じて変わります。

    注意：Linux ではファイルの作成時刻は記録されません。ただし、そのファイルが作成以来変更されていない場合、作成時刻は最後の変更時刻と同じになります。

    変更時刻順に表示する：
    ls -lt  ./

    アクセス時刻順に表示する：

    ls -lut ./

    逆順で表示したい場合は、オプションを追加する必要があります-r。

    find   ~   -type "*.cpp"  -exec ls  -l {}\;

    exec は検索結果の範囲を一度に後続のコマンドへ送信します。検索結果が多いとデータオーバーフローが発生する可能性があります。ls のデータが16万を超えると、このコマンドはエラーになります。

    パイプと xargs を使用してこの問題を回避します：

    find   ~   -type "*.cpp"  | xargs ls  -l

    xargs は検索結果を分割して後続のコマンドに送信します。

    例えば検索する2013-08-08 到 2013-09-01日付の間のファイルは、次のコマンドを使用するだけです：

    find /log/ -name 'production.log-2013*' -newermt '2013-08-08' ! -newermt '2013-09-0

    2011/09/08 12:00 から1日以内を検索すると、2011/09/07 12:00 〜 2011/09/08 12:00 の時間内のファイルがリストされます。3日「以前」に変更されたファイルを探します（前の第3日以前 → 2011/09/05 12:00 以前のファイル）(> 72 時間)

    find /var/log/ -mtime +3 -type f -print

    3日以内に変更されたファイルを探す（2011/09/05 12:00 〜 2011/09/08 12:00 内のファイル）(0 〜 72 時間以内)

    find /var/log/ -mtime -3 -type f -print

    前の第3日に変更されたファイルを探す（2011/09/04 12:00 〜 2011/09/05 12:00 内のファイル）(72 〜 96 時間)

    find /var/log/ -mtime 3 -type f -print

    第3日に変更されたファイルを探す（このように書くこともできます）

    find /var/log/ -mtime +2 -mtime -4 -type f -print
