Go言語スライス(Slice)

Go言語のスライスは配列の抽象です。

Goの配列の長さは変更できず、特定のシナリオではこのようなコレクションはあまり適していません。Goには柔軟で機能が強力な組み込み型スライス("動的配列")が用意されています。配列と比較すると、スライスの長さは固定ではなく、要素を追加でき、追加時にスライスの容量が増える可能性があります。

スライスの定義

サイズを指定しない配列を宣言してスライスを定義できます：

var identifier []type

スライスは長さを指定する必要はありません。

または、次のmake()関数を使用してスライスを作成します：

var slice1 []type = make([]type, len)

也可以简写为

slice1 := make([]type, len)

容量を指定することもできます。ここでcapacityはオプションのパラメータです。

make([]T, length, capacity)

ここで len は配列の長さであり、スライスの初期長さでもあります。

スライスの初期化

s :=[] int {1,2,3 }

スライスを直接初期化します。[]これはスライス型を表します。{1,2,3}初期化値は順に1,2,3、そのcap=len=3。

s := arr[:]

スライスを初期化します。sこれは配列 arr の参照です。

s := arr[startIndex:endIndex]

arr の添字 startIndex から endIndex-1 までの要素を新しいスライスとして作成します。

s := arr[startIndex:]

デフォルトでは endIndex は、arr の最後の要素までを表します。

s := arr[:endIndex]

デフォルトでは startIndex は、arr の最初の要素から始まることを表します。

s1 := s[startIndex:endIndex]

スライス s を使用してスライス s1 を初期化します。

s :=make([]int,len,cap)

組み込み関数を使用してmake()スライスを初期化します。s，[]intこれは、その要素型が int のスライスとして識別されます。

len() と cap() 関数

スライスはインデックス可能であり、len() メソッドで長さを取得できます。

スライスには容量を計算するメソッド cap() が用意されており、スライスが最大どのくらいの長さに達することができるかを測定できます。

以下は具体的な例です：

実例

package main

import "fmt"

func main() {
   var numbers = make([]int,3,5)

   printSlice(numbers)
}

func printSlice(x []int){
   fmt.Printf("len=%d cap=%d slice=%v\n",len(x),cap(x),x)
}

上記の実例を実行した出力結果は次のとおりです：

len=3 cap=5 slice=[0 0 0]

スライスの切り出し

下限と上限を設定することで、切り出すスライスを設定できます[lower-bound:upper-bound]。例は次のとおりです：

実例

package main

import "fmt"

func main() {
   /* スライスを作成 */
   numbers := []int{0,1,2,3,4,5,6,7,8}  
   printSlice(numbers)

   /* 元のスライスを出力 */
   fmt.Println("numbers ==", numbers)

   /* インデックス1(含む)からインデックス4(含まない)までの部分スライスを出力 */
   fmt.Println("numbers[1:4] ==", numbers[1:4])

   /* デフォルトの下限は 0 */
   fmt.Println("numbers[:3] ==", numbers[:3])

   /* デフォルトの上限は len(s) */
   fmt.Println("numbers[4:] ==", numbers[4:])

   numbers1 := make([]int,0,5)
   printSlice(numbers1)

   /* インデックス0(含む)からインデックス2(含まない)までの部分スライスを出力 */
   number2 := numbers[:2]
   printSlice(number2)

   /* インデックス2(含む)からインデックス5(含まない)までの部分スライスを出力 */
   number3 := numbers[2:5]
   printSlice(number3)

}

func printSlice(x []int){
   fmt.Printf("len=%d cap=%d slice=%v\n",len(x),cap(x),x)
}

上記のコードを実行した出力結果は次のとおりです：

len=9 cap=9 slice=[0 1 2 3 4 5 6 7 8]
numbers == [0 1 2 3 4 5 6 7 8]
numbers[1:4] == [1 2 3]
numbers[:3] == [0 1 2]
numbers[4:] == [4 5 6 7 8]
len=0 cap=5 slice=[]
len=2 cap=9 slice=[0 1]
len=3 cap=7 slice=[2 3 4]

append() と copy() 関数

スライスの容量を増やしたい場合は、新しいより大きなスライスを作成し、元のスライスの内容をすべてコピーする必要があります。

次のコードは、スライスをコピーする copy メソッドと、スライスに新しい要素を追加する append メソッドを示しています。

実例

package main

import "fmt"

func main() {
   var numbers []int
   printSlice(numbers)

   /* 空スライスの追加を許可 */
   numbers = append(numbers, 0)
   printSlice(numbers)

   /* スライスに1つの要素を追加 */
   numbers = append(numbers, 1)
   printSlice(numbers)

   /* 複数の要素を同時に追加 */
   numbers = append(numbers, 2,3,4)
   printSlice(numbers)

   /* 以前のスライスの2倍の容量を持つスライス numbers1 を作成 */
   numbers1 := make([]int, len(numbers), (cap(numbers))*2)

   /* numbers の内容を numbers1 にコピー */
   copy(numbers1,numbers)
   printSlice(numbers1)  
}

func printSlice(x []int){
   fmt.Printf("len=%d cap=%d slice=%v\n",len(x),cap(x),x)
}

上記のコードを実行した出力結果は次のとおりです：

len=0 cap=0 slice=[]
len=1 cap=1 slice=[0]
len=2 cap=2 slice=[0 1]
len=5 cap=6 slice=[0 1 2 3 4]
len=5 cap=12 slice=[0 1 2 3 4]

    append() と copy() の部分は、説明が不十分なところがあるようです。

    当 numbers = [0, 1]のとき、append(numbers, 2, 3, 4)なぜ cap が 2 から 6 に変わるのですか？

    実践により、append(list, [params]) は、まず list の cap の長さがlen(list) + len([params])以上かどうかを判断します。大きければ cap は変わらず、そうでなければ cap はmax{cap(list), cap[params]}に等しくなります。したがって、append(numbers, 2, 3, 4) のとき cap は 2 から 6 に変わります。

    スライスの内部構造：

    struct Slice
{   
    byte*    array;       // actual data
    uintgo    len;        // number of elements
    uintgo    cap;        // allocated number of elements

};

    最初のフィールドは array のポインタ、つまり実際のデータのポインタを表します。2番目は slice の長さ、3番目は slice の容量を表します。

    したがってunsafe.Sizeof(スライス)常に 24 です。

    slice をパラメータとして渡す場合、それ自体は値渡しですが、その内容はbyte* array、実際には参照が渡されるため関数内部で変更できます。ただし、slice 自体に append を行い、slice が拡張された場合、実際に拡張されるのは関数内でコピーされたスライスであり、関数外部のスライスには変化はありません。

    package main

import (
"fmt"
"unsafe"
)

func main() {
    slice_test := []int{1, 2, 3, 4, 5}
    fmt.Println(unsafe.Sizeof(slice_test))
    fmt.Printf("main:%#v,%#v,%#v\n", slice_test, len(slice_test), cap(slice_test))
    slice_value(slice_test)
    fmt.Printf("main:%#v,%#v,%#v\n", slice_test, len(slice_test), cap(slice_test))
    slice_ptr(&slice_test)
    fmt.Printf("main:%#v,%#v,%#v\n", slice_test, len(slice_test), cap(slice_test))
    fmt.Println(unsafe.Sizeof(slice_test))
}

func slice_value(slice_test []int) {
    slice_test[1] = 100                // 函数外的slice确实有被修改
    slice_test = append(slice_test, 6) // 函数外的不变
    fmt.Printf("slice_value:%#v,%#v,%#v\n", slice_test, len(slice_test), cap(slice_test))
}

func slice_ptr(slice_test *[]int) { // 这样才能修改函数外的slice
    *slice_test = append(*slice_test, 7)
    fmt.Printf("slice_ptr:%#v,%#v,%#v\n", *slice_test, len(*slice_test), cap(*slice_test))
}

    結果は次のとおりです：

    24
main:[]int{1, 2, 3, 4, 5},5,5
slice_value:[]int{1, 100, 3, 4, 5, 6},6,10
main:[]int{1, 100, 3, 4, 5},5,5
slice_ptr:[]int{1, 100, 3, 4, 5, 7},6,10
main:[]int{1, 100, 3, 4, 5, 7},6,10
24

    cap がなぜ 6 になるのかという問題について、上記の説明はすべて間違っていると思います。7つの要素を追加してみてください

    cap は 10 になります。

    cap*2 がlen(list) + len([params])より小さい場合、cap =len(list) + len([params])+1となり、逆の場合 cap=cap*2 です。
