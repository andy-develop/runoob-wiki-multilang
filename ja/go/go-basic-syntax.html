Go言語の基本構文

前の章でGo言語の基本構成を学びました。この章ではGo言語の基本構文を学習します。

Goのトークン

Goプログラムは複数のトークンから構成され、キーワード、識別子、定数、文字列、記号などがあります。例えば、次のGO文は6つのトークンから構成されています：

fmt.Println("Hello, World!")

6つのトークンは（各行に1つ）：

1. fmt
2. .
3. Println
4. (
5. "Hello, World!"
6. )

行区切り文字

Goプログラムでは、1行が1つの文の終わりを表します。各文はC系言語のようにセミコロン ; で終える必要はありません。これらの作業はGoコンパイラが自動的に行うからです。

複数の文を同じ行に書く場合は、 ; を使って人為的に区切る必要がありますが、実際の開発ではこの方法は推奨されません。

以下は2つの文です：

fmt.Println("Hello, World!")
fmt.Println("菜鸟教程：runoob.com")

コメント

コメントはコンパイルされません。各パッケージには関連するコメントを付けるべきです。

単行コメントは最も一般的なコメント形式で、どこでも // で始まる単行コメントを使用できます。複数行コメントはブロックコメントとも呼ばれ、 /* で始まり */ で終わります。例：

// 单行注释
/*
 Author by 菜鸟教程
 我是多行注释
 */

識別子

識別子は変数や型などのプログラム実体に名前を付けるために使われます。識別子は実際には1つまたは複数の英字(A~Zおよびa~z)、数字(0~9)、アンダースコア_で構成される並びですが、最初の文字は英字またはアンダースコアでなければならず、数字は使えません。

以下は有効な識別子です：

mahesh   kumar   abc   move_name   a_123
myname50   _temp   j   a23b9   retVal

以下は無効な識別子です：

  • 1ab（数字で始まる）
  • case（Go言語のキーワード）
  • a+b（演算子は許可されない）

文字列の連結

Go言語の文字列連結は、+によって実現できます：

実例

package main
import "fmt"
func main() {
    fmt.Println("Google" + "Runoob")
}

上記の例の出力結果は次のとおりです：

GoogleRunoob

プログラムは一般に、キーワード、定数、変数、演算子、型、関数から構成されます。

プログラムでは以下の区切り文字が使用されます：括弧 ()、角括弧 []、波括弧 {}。

プログラムでは以下の句読点が使用されることがあります：.、,、;、: 和 …。

Go言語のスペース

Go言語では、スペースは通常、識別子、キーワード、演算子、式を区切ってコードの可読性を高めるために使われます。

Go言語では変数の宣言はスペースで区切る必要があります。例：

var x int
const Pi float64 = 3.14159265358979323846

演算子とオペランドの間にスペースを使うとプログラムが読みやすくなります：

スペースなし：

fruit=apples+oranges;

変数と演算子の間にスペースを入れると、プログラムが見栄え良くなります。例：

fruit = apples + oranges;

キーワードと式の間にはスペースを使用する必要があります。

例：

if x > 0 {
    // do something
}

関数呼び出しでは、関数名と左にある等号の間にスペースを使い、引数の間にもスペースを使う必要があります。

例：

result := add(2, 3)

文字列のフォーマット

Go言語では、次のようにしてfmt.Sprintf 或 fmt.Printf文字列をフォーマットして新しい文字列に代入します：

  • Sprintfフォーマット引数に基づいてフォーマットされた文字列を生成し、その文字列を返します。
  • Printfフォーマット引数に基づいてフォーマットされた文字列を生成し、標準出力に書き込みます。

Sprintfの例

package main

import (
    "fmt"
)

func main() {
   // %d は整数を表し、%s は文字列を表します
    var stockcode=123
    var enddate="2020-12-31"
    var url="Code=%d&endDate=%s"
    var target_url=fmt.Sprintf(url,stockcode,enddate)
    fmt.Println(target_url)
}

出力結果は次のとおりです：

Code=123&endDate=2020-12-31

Printfの例

package main

import (
    "fmt"
)

func main() {
   // %d は整数を表し、%s は文字列を表します
    var stockcode=123
    var enddate="2020-12-31"
    var url="Code=%d&endDate=%s"
    fmt.Printf(url,stockcode,enddate)
}

出力結果は次のとおりです：

Code=123&endDate=2020-12-31

    Golang fmt パッケージ

    Print() 関数は引数リスト a の各引数を文字列に変換し、標準出力に書き込みます。

    文字列以外の引数の間にはスペースが追加され、書き込んだバイト数を返します。

    func Print(a ...interface{}) (n int, err error)

    Println() 関数は Print と似ていますが、最後に改行文字が追加されます。

    すべての引数の間にスペースが追加され、書き込んだバイト数を返します。

    func Println(a ...interface{}) (n int, err error)

    Printf() 関数は引数リスト a をフォーマット文字列 format のプレースホルダーに埋め込みます。

    埋め込んだ結果を標準出力に書き込み、書き込んだバイト数を返します。

    func Printf(format string, a ...interface{}) (n int, err error)

    以下の3つの関数は上の3つの関数と同じ機能ですが、変換結果をwに書き込みます。

    func Fprint(w io.Writer, a ...interface{}) (n int, err error)
func Fprintln(w io.Writer, a ...interface{}) (n int, err error)
func Fprintf(w io.Writer, format string, a ...interface{}) (n int, err error)

    以下の3つの関数は上の3つの関数と同じ機能ですが、変換結果を文字列として返す点が異なります。

    func Sprint(a ...interface{}) string
func Sprintln(a ...interface{}) string
func Sprintf(format string, a ...interface{}) string

    以下の関数は Sprintf() 関数と同じ機能ですが、結果の文字列が error 型にラップされる点が異なります。

    func Errorf(format string, a ...interface{}) error

    例：

    func main() {
    fmt.Print("a", "b", 1, 2, 3, "c", "d", "\n")
    fmt.Println("a", "b", 1, 2, 3, "c", "d")
    fmt.Printf("ab %d %d %d cd\n", 1, 2, 3)
    // ab1 2 3cd
    // a b 1 2 3 c d
    // ab 1 2 3 cd

    if err := percent(30, 70, 90, 160); err != nil {
        fmt.Println(err)
    }
    // 30%
    // 70%
    // 90%
    // 数值 160 超出范围（100）
}

func percent(i ...int) error {
    for _, n := range i {
        if n > 100 {
            return fmt.Errorf("数值 %d 超出范围（100）", n)
        }
        fmt.Print(n, "%\n")
    }
    return nil
}

    Formatter はカスタム型によって実装され、その型のカスタムフォーマット処理を実現するために使われます。

    フォーマッターがその型の変数をフォーマットする必要があるとき、その Format メソッドが呼び出されます。

    type Formatter interface {
    // f 用于获取占位符的旗标、宽度、精度等信息，也用于输出格式化的结果
    // c 是占位符中的动词
    Format(f State, c rune)
}

    フォーマッター（Print などの関数）によって実装され、カスタムフォーマット処理に情報を提供するために使われます：

    type State interface {
    // Formatter 通过 Write 方法将格式化结果写入格式化器中，以便输出。
    Write(b []byte) (ret int, err error)
    // Formatter 通过 Width 方法获取占位符中的宽度信息及其是否被设置。
    Width() (wid int, ok bool)
    // Formatter 通过 Precision 方法获取占位符中的精度信息及其是否被设置。
    Precision() (prec int, ok bool)
    // Formatter 通过 Flag 方法获取占位符中的旗标[+- 0#]是否被设置。
    Flag(c int) bool
}

    Stringer はカスタム型によって実装され、その型のカスタムフォーマット処理を実現するために使われます。

    フォーマッターがその型の文字列形式を出力する必要があるとき、その String メソッドが呼び出されます。

    type Stringer interface {
    String() string
}

    Stringer はカスタム型によって実装され、その型のカスタムフォーマット処理を実現するために使われます。

    フォーマッターがその型のGo構文文字列（%#v）を出力する必要があるとき、その String メソッドが呼び出されます。

    type GoStringer interface {
    GoString() string
}

    例：

    type Ustr string

func (us Ustr) String() string {
    return strings.ToUpper(string(us))
}

func (us Ustr) GoString() string {
    return `"` + strings.ToUpper(string(us)) + `"`
}

func (u Ustr) Format(f fmt.State, c rune) {
    write := func(s string) {
        f.Write([]byte(s))
    }
    switch c {
    case 'm', 'M':
        write("旗标：[")
        for s := "+- 0#"; len(s) > 0; s = s[1:] {
            if f.Flag(int(s[0])) {
                write(s[:1])
            }
        }
        write("]")
        if v, ok := f.Width(); ok {
            write(" | 宽度：" + strconv.FormatInt(int64(v), 10))
        }
        if v, ok := f.Precision(); ok {
            write(" | 精度：" + strconv.FormatInt(int64(v), 10))
        }
    case 's', 'v': // 如果使用 Format 函数，则必须自己处理所有格式，包括 %#v
        if c == 'v' && f.Flag('#') {
            write(u.GoString())
        } else {
            write(u.String())
        }
    default: // 如果使用 Format 函数，则必须自己处理默认输出
        write("无效格式：" + string(c))
    }
}

func main() {
    u := Ustr("Hello World!")
    // "-" 标记和 "0" 标记不能同时存在
    fmt.Printf("%-+ 0#8.5m\n", u) // 旗标：[+- #] | 宽度：8 | 精度：5
    fmt.Printf("%+ 0#8.5M\n", u)  // 旗标：[+ 0#] | 宽度：8 | 精度：5
    fmt.Println(u)                // HELLO WORLD!
    fmt.Printf("%s\n", u)         // HELLO WORLD!
    fmt.Printf("%#v\n", u)        // "HELLO WORLD!"
    fmt.Printf("%d\n", u)         // 无效格式：d
}

    Scan標準入力からデータを読み取り、データを空白で分割して解析し、a が提供する変数に格納します（改行文字は空白として扱われます）。変数はポインタで渡す必要があります。

    EOF を読み取るか、すべての変数が埋められるとスキャンを停止します。

    正常に解析された引数の数を返します。
    func Scan(a ...interface{}) (n int, err error)

    Scanln 和 Scan同様ですが、改行文字に遭遇するとスキャンを停止する点が異なります。

    func Scanln(a ...interface{}) (n int, err error)

    Scanf は標準入力からデータを読み取り、フォーマット文字列 format に従ってデータを解析し、解析結果を引数 a が提供する変数に格納します。変数はポインタで渡す必要があります。

    入力側の改行文字は format 内の改行文字と対応していなければなりません（フォーマット文字列に改行文字がある場合、入力側には対応する改行文字を入力する必要があります）。

    プレースホルダー %c は常に次の文字とマッチします。空白（スペース、タブ、改行など）も含みます。

    正常に解析された引数の数を返します。

    func Scanf(format string, a ...interface{}) (n int, err error)

    以下の3つの関数は上記の3つの関数と同じ機能ですが、r からデータを読み取る点が異なります。

    func Fscan(r io.Reader, a ...interface{}) (n int, err error)
func Fscanln(r io.Reader, a ...interface{}) (n int, err error)
func Fscanf(r io.Reader, format string, a ...interface{}) (n int, err error)

    以下の3つの関数は上記の3つの関数と同じ機能ですが、str からデータを読み取る点が異なります。

    func Sscan(str string, a ...interface{}) (n int, err error)
func Sscanln(str string, a ...interface{}) (n int, err error)
func Sscanf(str string, format string, a ...interface{}) (n int, err error)

    Scannerカスタム型によって実装され、その型のカスタムスキャン処理を実装するために使用されます。

    スキャナーがその型のデータを解析する必要があるとき、その Scan メソッドが呼び出されます。

    type Scanner interface {
    // state 用于获取占位符中的宽度信息，也用于从扫描器中读取数据进行解析。
    // verb 是占位符中的动词
    Scan(state ScanState, verb rune) error
}

    スキャナー（Scan などの関数）によって実装され、カスタムスキャン処理にデータと情報を提供するために使用されます。

    type ScanState interface {
    // ReadRune 从扫描器中读取一个字符，如果用在 Scanln 类的扫描器中，
    // 则该方法会在读到第一个换行符之后或读到指定宽度之后返回 EOF。
    // 返回“读取的字符”和“字符编码所占用的字节数”
    ReadRune() (r rune, size int, err error)
    // UnreadRune 撤消最后一次的 ReadRune 操作，
    // 使下次的 ReadRune 操作得到与前一次 ReadRune 相同的结果。
    UnreadRune() error
    // SkipSpace 为 Scan 方法提供跳过开头空白的能力。
    // 根据扫描器的不同（Scan 或 Scanln）决定是否跳过换行符。
    SkipSpace()
    // Token 用于从扫描器中读取符合要求的字符串，
    // Token 从扫描器中读取连续的符合 f(c) 的字符 c，准备解析。
    // 如果 f 为 nil，则使用 !unicode.IsSpace(c) 代替 f(c)。
    // skipSpace：是否跳过开头的连续空白。返回读取到的数据。
    // 注意：token 指向共享的数据，下次的 Token 操作可能会覆盖本次的结果。
    Token(skipSpace bool, f func(rune) bool) (token []byte, err error)
    // Width 返回占位符中的宽度值以及宽度值是否被设置
    Width() (wid int, ok bool)
    // 因为上面实现了 ReadRune 方法，所以 Read 方法永远不应该被调用。
    // 一个好的 ScanState 应该让 Read 直接返回相应的错误信息。
    Read(buf []byte) (n int, err error)
}

    例：

    type Ustr string

func (u *Ustr) Scan(state fmt.ScanState, verb rune) (err error) {
    var s []byte
    switch verb {
    case 'S':
        s, err = state.Token(true, func(c rune) bool { return 'A' <= c && c <= 'Z' })
        if err != nil {
            return
        }
    case 's', 'v':
        s, err = state.Token(true, func(c rune) bool { return 'a' <= c && c <= 'z' })
        if err != nil {
            return
        }
    default:
        return fmt.Errorf("无效格式：%c", verb)
    }
    *u = Ustr(s)
    return nil
}

func main() {
    var a, b, c, d, e Ustr
    n, err := fmt.Scanf("%3S%S%3s%2v%x", &a, &b, &c, &d, &e)
    fmt.Println(a, b, c, d, e)
    fmt.Println(n, err)
    // 在终端执行后，输入 ABCDEFGabcdefg 回车
    // 结果：
    // ABC DEFG abc de
    // 4 无效格式：x
}
