Go言語の変数スコープ

スコープとは、宣言された識別子が表す定数、型、変数、関数、またはパッケージがソースコード内で作用する範囲のことです。

Go言語では変数は3つの場所で宣言できます：

  • 関数内で定義された変数はローカル変数と呼ばれます。
  • 関数の外で定義された変数はグローバル変数と呼ばれます。
  • 関数定義の中の変数は仮引数と呼ばれます。

次に、ローカル変数、グローバル変数、仮引数について具体的に見ていきましょう。

ローカル変数

関数本体内で宣言された変数をローカル変数と呼びます。そのスコープは関数本体内のみです。パラメータと戻り値の変数もローカル変数です。

次の実例では、main() 関数がローカル変数 a, b, c を使用しています：

実例

package main

import "fmt"

func main() {
   /* ローカル変数の宣言 */
   var a, b, c int

   /* パラメータの初期化 */
   a = 10
   b = 20
   c = a + b

   fmt.Printf ("結果： a = %d, b = %d and c = %d\n"\n", a, b, c)
}

上記の実例を実行すると、出力結果は次のようになります：

结果： a = 10, b = 20 and c = 30

グローバル変数

関数の外部で宣言された変数をグローバル変数と呼びます。グローバル変数はパッケージ全体、さらには外部のパッケージ（エクスポート後）でも使用できます。

グローバル変数はどの関数でも使用できます。次の実例は、グローバル変数の使用方法を示しています：

実例

package main

import "fmt"

/* グローバル変数の宣言 */
var g int

func main() {

   /* ローカル変数の宣言 */
   var a, b int

   /* パラメータの初期化 */
   a = 10
   b = 20
   g = a + b

   fmt.Printf("結果： a = %d, b = %d and g = %d\n"\n", a, b, g)
}

上記の実例を実行すると、出力結果は次のようになります：

结果： a = 10, b = 20 and g = 30

Go言語プログラムでは、グローバル変数とローカル変数の名前を同じにすることができますが、関数内のローカル変数が優先されます。実例は次のとおりです：

実例

package main

import "fmt"

/* グローバル変数の宣言 */
var g int = 20

func main() {
   /* ローカル変数の宣言 */
   var g int = 10

   fmt.Printf ("結果： g = %d\n"\n",  g)
}

上記の実例を実行すると、出力結果は次のようになります：

结果： g = 10

仮引数

仮引数は関数のローカル変数として使用されます。実例は次のとおりです：

実例

package main

import "fmt"

/* グローバル変数の宣言 */
var a int = 20;

func main() {
   /* main関数でローカル変数を宣言 */
   var a int = 10
   var b int = 20
   var c int = 0

   fmt.Printf("main()関数内 a = %d\n"\n",  a);
   c = sum( a, b);
   fmt.Printf("main()関数内 c = %d\n"\n",  c);
}

/* 関数定義 - 2つの数値を加算 */
func sum(a, b int) int {
   fmt.Printf("sum() 関数内 a = %d\n"\n",  a);
   fmt.Printf("sum() 関数内 b = %d\n"\n",  b);

   return a + b;
}

上記の実例を実行すると、出力結果は次のようになります：

main()函数中 a = 10
sum() 函数中 a = 10
sum() 函数中 b = 20
main()函数中 c = 30

    仮引数の使用。sum関数のaとmain関数のaを比較すると、sum関数では1が加算されますが、mainでは元の値10のままです：

    package main

import "fmt"

/* 声明全局变量 */
var a int = 20

func main() {
    /* main 函数中声明局部变量 */
    var a int = 10
    var b int = 20
    var c int = 0

    fmt.Printf("main()函数中 a = %d\n", a)
    c = sum(a, b)
    fmt.Printf("main()函数中 a = %d\n", a)
    fmt.Printf("main()函数中 c = %d\n", c)
}

/* 函数定义-两数相加 */
func sum(a, b int) int {
    a = a + 1
    fmt.Printf("sum() 函数中 a = %d\n", a)
    fmt.Printf("sum() 函数中 b = %d\n", b)
    return a + b
}

    出力は次のとおりです：

    main()函数中 a = 10
sum() 函数中 a = 11
sum() 函数中 b = 20
main()函数中 a = 10
main()函数中 c = 31

    for ループの初期化式（a:=0）では、このとき初期化式内の a は外側の a と同じ変数ではありません。初期化式内の a は for ループ内のローカル変数であるため、for ループの実行後も出力される a の値は依然として 0 です。

    package main

import "fmt"

func main(){
  var a int = 0
  fmt.Println("for start")
  for a = 0; a < 10; a++ {
    fmt.Println(a)
  }
  fmt.Println("for end")

  fmt.Println(a)

    for start

    この場合、初期化式内の a は外側の a と同じ変数であるため、for ループの実行後、出力される a の値は 10 です。

    下記のコードでは、test.go でグローバル変数 Total_sum を定義し、その後 hello.go で参照しています。

    test.go:

    package main
import "fmt"
var Total_sum int = 0
func Sum_test(a int, b int) int {
    fmt.Printf("%d + %d = %d\n", a, b, a+b)
    Total_sum += (a + b)
    fmt.Printf("Total_sum: %d\n", Total_sum)
    return a+b
}

    hello.go：

    package main

import (
    "fmt"
)

func main() {
    var sum int
    sum = Sum_test(2, 3)
    fmt.Printf("sum: %d; Total_sum: %d\n", sum, Total_sum)
}
