HTML 色

HTMLの色は、赤・緑・青を混ぜ合わせて作られます。

カラー値

HTMLの色は16進数の記号で定義され、この記号は赤・緑・青の値（RGB）で構成されています。

各色の最小値は0（16進数：#00）、最大値は255（16進数：#FF）です。

この表は、3つの色を混ぜ合わせた具体的な効果を示しています：

カラー値

色（カラー） 色の16進数（カラーヘックス） 色のRGB（カラーRGB）

Webセーフカラー?

数年前、ほとんどのコンピュータが256色しかサポートしていなかったとき、216色のWebセーフカラーがWeb標準として推奨されました。その理由は、MicrosoftとMacのオペレーティングシステムが40種類の異なる予約済み固定システムカラー（各約20色）を使用していたためです。

今日、これを行う意味がどれほどあるかは定かではありません。なぜなら、数百万色を処理できるコンピュータが増えているからです。ただし、選択するのはあなた自身です。

当初、216のクロスプラットフォームなWebセーフカラーは、コンピュータが256色のパレットを使用する場合でも、すべてのコンピュータがすべての色を正しく表示できることを保証するために使用されていました。

    RGBAの意味は（Red-Green-Blue-Alpha）で、RGBを拡張し、“alpha” アルファチャンネルを含むもので、カラー値に透明度を設定できます。

    div {

background:rgba(255,0,0,0.5);

}

    rgb(255,255,0) を使用する代わりに、rgba(255,255,0,0.5) を使用すると、色の透明度を設定する機能を実現できます。ここでの 0.5 は透明度を表し、範囲は0〜1で、0は完全に透明を意味します。

    通常、0を省略するために:

    div {
    background:rgba(255,0,0,.5);
}

    例：

    <p style="background-color:rgb(255,255,0)">
通过 rbg 值设置背景颜色
</p>
<p style="background-color:rgba(255,255,0,0.25)">
通过 rbg 值设置背景颜色
</p>
<p style="background-color:rgba(255,255,0,0.5)">
通过 rbg 值设置背景颜色
</p>
<p style="background-color:rgba(255,255,0,0.75)">
通过 rbg 值设置背景颜色
</p>
