Docker コンテナの使用

Ubuntu Docker インストール

Docker Engine-Community は以下の Ubuntu バージョンをサポートしています：

  • Xenial 16.04 (LTS)
  • Bionic 18.04 (LTS)
  • Cosmic 18.10
  • Disco 19.04
  • その他のより新しいバージョン……

Docker Engine - Community は x86_64（amd64）、armhf、arm64、s390x（IBM Z）、および ppc64le（IBM Power）アーキテクチャをサポートしています。

公式インストールスクリプトを使用した自動インストール

インストールコマンドは次のとおりです：

# 下载并执行Docker官方安装脚本
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker

手動インストール

古いバージョンのアンインストール

Docker の旧バージョンは docker、docker.io、または docker-engine と呼ばれていました。インストールされている場合は、それらをアンインストールしてください：

$ sudo apt-get remove docker docker-engine docker.io containerd runc

現在は Docker Engine-Community というソフトウェアパッケージ docker-ce と呼ばれています。

Docker Engine-Community をインストールするには、以下の2つの方法があります。

Docker リポジトリを使用したインストール

新しいホストに Docker Engine-Community を初めてインストールする前に、Docker リポジトリを設定する必要があります。その後、リポジトリから Docker をインストールおよび更新できます。

リポジトリの設定

apt パッケージインデックスを更新します。

$ sudo apt-get update

HTTPS でリポジトリにアクセスするための apt 依存パッケージをインストールします：

$ sudo apt-get install \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg-agent \
    software-properties-common

Docker の公式 GPG キーを追加します：

curl -fsSL https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

次のコマンドを使用して安定版リポジトリを設定します

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/ \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update

Docker Engine-Community のインストール

apt パッケージインデックスを更新します。

$ sudo apt-get update

Docker Engine-Community と containerd の最新バージョンをインストールするか、次のステップに進んで特定のバージョンをインストールします：

$ sudo apt-get install docker-ce docker-ce-cli containerd.io

特定のバージョンの Docker Engine-Community をインストールするには、リポジトリ内の利用可能なバージョンを一覧表示し、その中から選択してインストールします。リポジトリ内の利用可能なバージョンを一覧表示するには：

$ apt-cache madison docker-ce

  docker-ce | 5:18.09.1~3-0~ubuntu-xenial | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  docker-ce | 5:18.09.0~3-0~ubuntu-xenial | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  docker-ce | 18.06.1~ce~3-0~ubuntu       | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  docker-ce | 18.06.0~ce~3-0~ubuntu       | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  ...

2番目の列のバージョン文字列を使用して特定のバージョンをインストールします。例：5:18.09.1~3-0~ubuntu-xenial。

$ sudo apt-get install docker-ce=<VERSION_STRING> docker-ce-cli=<VERSION_STRING> containerd.io

Shell スクリプトを使用したインストール

Docker は、get.docker.com 和 test.docker.com上で便利なスクリプトを提供しています。これは、Docker Engine-Community のエッジ版とテスト版をすばやくインストールするためのものです。スクリプトのソースコードは docker-install リポジトリにあります。これらのスクリプトを本番環境で使用することはお勧めしません。使用する前に、潜在的なリスクを理解しておく必要があります：

  • スクリプトは root または sudo 権限を持つユーザーで実行する必要があります。したがって、スクリプトを実行する前に、スクリプトを慎重に確認および監査する必要があります。

  • これらのスクリプトは Linux ディストリビューションとバージョンを検出し、パッケージ管理システムを構成しようとします。さらに、スクリプトではインストールパラメータをカスタマイズすることはできません。これは、Docker の観点または組織のガイドラインや標準の観点から、サポートされていない構成につながる可能性があります。

  • これらのスクリプトは、確認なしでパッケージマネージャーのすべての依存関係と推奨パッケージをインストールします。ホストの現在の構成によっては、大量のパッケージがインストールされる可能性があります。

  • このスクリプトには、インストールする Docker のバージョンを指定するオプションはなく、代わりに edge チャネルで公開されている最新バージョンをインストールします。

  • すでに他のメカニズムを使用して Docker をホストにインストールしている場合は、便利なスクリプトを使用しないでください。

この例では、get.docker.com 上のスクリプトを使用して、Linux に最新バージョンの Docker Engine-Community をインストールします。最新のテストバージョンをインストールするには、test.docker.com を使用してください。以下の各コマンドで、get が出現するたびに test に置き換えてください。

$ curl -fsSL https://get.docker.com -o get-docker.sh
$ sudo sh get-docker.sh

Docker を root 以外のユーザーとして使用する場合は、次のような方法でユーザーを docker グループに追加することを検討してください：

$ sudo usermod -aG docker your-user

docker のアンインストール

インストールパッケージを削除します：

sudo apt-get purge docker-ce

イメージ、コンテナ、設定ファイルなどを削除します：

sudo rm -rf /var/lib/docker

    Ubuntu 16.04 に Docker をインストール

    1. 国内のクラウドサービスプロバイダーを選択します。ここでは例として Alibaba Cloud（阿里云）を選択します。

    curl -sSL http://acs-public-mirror.oss-cn-hangzhou.aliyuncs.com/docker-engine/internet | sh -

    2. 必要なパッケージをインストールします

    sudo apt-get install linux-image-extra-$(uname -r) linux-image-extra-virtual

    3. HTTPS で転送するためのソフトウェアパッケージと CA 証明書を追加します

    sudo apt-get update
sudo apt-get install apt-transport-https ca-certificates

    4. GPG キーを追加します

    sudo apt-key adv --keyserver hkp://p80.pool.sks-keyservers.net:80 --recv-keys 58118E89F3A912897C070ADBF76221572C52609D

    5. ソフトウェアソースを追加します

    echo "deb https://apt.dockerproject.org/repo ubuntu-xenial main" | sudo tee /etc/apt/sources.list.d/docker.list

    6. 追加が成功したら、ソフトウェアパッケージのキャッシュを更新します

    sudo apt-get update

    7. docker をインストールします

    sudo apt-get install docker-engine

    8. docker を起動します

    sudo systemctl enable docker
sudo systemctl start docker

    Ubuntu 18.04 に Docker-ce をインストール

    1. 国内のソフトウェアソースを変更します。中国科学技術大学のソースがおすすめです。安定していて高速です（任意）

    sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
sudo sed -i 's/archive.ubuntu.com/mirrors.ustc.edu.cn/g' /etc/apt/sources.list
sudo apt update

    2. 必要なパッケージをインストールします

    sudo apt install apt-transport-https ca-certificates software-properties-common curl

    3. GPG キーを追加し、Docker-ce のソフトウェアソースを追加します。ここでは中国科学技術大学の Docker-ce ソースを例とします。

    curl -fsSL https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/gpg | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu \
$(lsb_release -cs) stable"

    4. 追加が成功したら、ソフトウェアパッケージのキャッシュを更新します

    sudo apt update

    5. Docker-ce をインストールします

    sudo apt install docker-ce

    6. 自動起動を設定して Docker-ce を起動します（インストールが成功するとデフォルトで設定・起動されるため、省略可能です）

    sudo systemctl enable docker
sudo systemctl start docker

    7. テスト実行

    sudo docker run hello-world

    8. 現在のユーザーを docker ユーザーグループに追加すると、sudo なしで docker を実行できます（任意）

    sudo groupadd docker
sudo usermod -aG docker $USER

    9. ユーザーグループの追加をテストします（任意）

    docker run hello-world
