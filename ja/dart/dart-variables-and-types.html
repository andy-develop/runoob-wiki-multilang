Dart 変数とデータ型

変数はプログラム内でデータを格納する基本単位であり、データ型は変数がどのような値を格納できるかを決定します。

この章では、Dart の変数宣言方法、基本データ型、および重要な Null 安全メカニズムについて紹介します。

変数の宣言方法：var、final、const

Dart には変数を宣言するためのキーワードが3つあり、それぞれ異なるシナリオに適しています。

それらの違いを理解することが Dart を学ぶ第一歩です。

var——型推論の変数

var で宣言された変数は、型が初期値から自動的に推論され、一度確定した型は変更できません。

例

void main() {
  // 型推論：name の型は String と推論される
  var name = 'RUNOOB';

  // 型推論：age の型は int と推論される
  var age = 10;

  print('$name 已经 $age 年了');

  // 以下の書き方はエラーになる——型が確定した後は他の型の値を代入できない
  // name = 123; // エラー：int を String に代入できません
}
RUNOOB 已经 10 年了

var は「無型」や「動的型」ではありません。その型は代入した瞬間に固定されます。これは JavaScript の var とはまったく異なります。

final——実行時定数

final で宣言された変数は一度だけ代入できますが、代入のタイミングは実行時まで遅らせることができます。

例

void main() {
  // final 変数：一度代入すると変更できない
  final currentTime = DateTime.now();
  print('当前时间: $currentTime');

  // 遅延代入も許可されている
  final String greeting;
  greeting = 'Hello, RUNOOB!';  // 最初の代入は OK
  // greeting = 'Hello again'; // エラー：final 変数には再度代入できない

  print(greeting);
}
当前时间: 2026-06-12 10:30:00.000
Hello, RUNOOB!

const——コンパイル時定数

const は final よりも厳格です。その値はコンパイル時に確定している必要があります。

例

void main() {
  // const はコンパイル時に値が確定している必要がある
  const siteName = 'RUNOOB';
  const maxUsers = 100;

  print('站点: $siteName, 最大用户数: $maxUsers');

  // 以下の書き方はエラーになります——DateTime.now() は実行時にしか確定できない値です
  // const currentTime = DateTime.now(); // エラー！
}
站点: RUNOOB, 最大用户数: 100

三者比較のまとめ

キーワード変更可能代入のタイミング代表的なシナリオ
var可任意値が変化する普通の変数
final変更不可実行時に確定APIから取得した設定、現在時刻
const変更不可コンパイル時に確定数学定数、固定設定、色の値

実用的なアドバイス：デフォルトで final を使用してください。変更が必要になったときに var に変えましょう。この習慣はコードをより安全にし、意図しない変更によるバグを減らします。

数値型：int と double

Dart の数値型は2種類あります：int（整数）と double（浮動小数点数）です。

それらの共通の親クラスは num です。

例

void main() {
  // int：整数、範囲は -2^63 から 2^63-1
  int viewCount = 10000;
  int negativeNumber = -42;

  // double：倍精度浮動小数点数
  double price = 9.99;
  double pi = 3.1415926;

  // num は int と double の両方を受け取れる
  num someNumber = 10;
  someNumber = 10.5;  // 有効

  print('浏览次数: $viewCount');
  print('价格: ¥$price');
  print('圆周率: $pi');
}
浏览次数: 10000
价格: ¥9.99
圆周率: 3.1415926

数値のよく使うメソッド

例

import 'dart:math';  // 数学ライブラリをインポート

void main() {
  int a = -10;
  double b = 3.7;

  // 絶対値
  print('a 的绝对值: ${a.abs()}');   // 10

  // 四捨五入して整数に
  print('b 四舍五入: ${b.round()}');  // 4

  // 切り捨て
  print('b 向下取整: ${b.floor()}');  // 3

  // 切り上げ
  print('b 向上取整: ${b.ceil()}');   // 4

  // 文字列を数値に変換
  int parsed = int.parse('42');
  double parsedDouble = double.parse('3.14');
  print('解析结果: $parsed, $parsedDouble');

  // 乱数を生成（import 'dart:math' が必要）
  var random = Random().nextInt(100);
  print('随机数(0-99): $random');
}
a 的绝对值: 10
b 四舍五入: 4
b 向下取整: 3
b 向上取整: 4
解析结果: 42, 3.14
随机数(0-99): 67

文字列：String と補間構文

String はテキストを表すために使用します。Dart の文字列はシングルクォートとダブルクォートの両方の書き方をサポートしています。

文字列補間（String Interpolation）は Dart の最も便利な機能の一つです。

例

void main() {
  // 文字列はシングルクォートかダブルクォートで記述できます
  String singleQuoted = 'Hello';
  String doubleQuoted = "World";

  // 複数行文字列：3つの引用符を使用
  String multiLine = '''
这是第一行
这是第二行
这是第三行 - RUNOOB
  ''';

  // 文字列補間：$変数名 または ${式} を使用
  String site = 'RUNOOB';
  int years = 10;

  // $変数名：変数を直接参照
  print('欢迎来到 $site');

  // ${式}：複雑な式を埋め込む
  print('$site 已经陪伴我们 ${years + 1} 年了');

  // エスケープ文字
  print('换行符: 第一行\n第二行');
  print('制表符: 列1\t列2');
}
欢迎来到 RUNOOB
RUNOOB 已经陪伴我们 11 年了
换行符: 第一行
第二行
制表符: 列1    列2

文字列のよく使うメソッド

例

void main() {
  String text = '  Hello, RUNOOB!  ';

  // 先頭と末尾の空白を除去
  print('trim: [${text.trim()}]');

  // 大文字に変換 / 小文字に変換
  print('大写: ${text.toUpperCase()}');
  print('小写: ${text.toLowerCase()}');

  // 部分文字列が含まれているか
  print('包含 RUNOOB? ${text.contains('RUNOOB')}');

  // ある文字列で始まるか/終わるか
  print('以空格开头? ${text.startsWith(' ')}');
  print('以!结尾? ${text.trim().endsWith('!')}');

  // 文字列の置換
  print('替换: ${text.replaceAll('RUNOOB', 'DART')}');

  // 文字列の分割
  String csv = 'Dart,Flutter,Google';
  List<String> items = csv.split(',');
  print('分割结果: $items');

  // 文字列の連結
  print('拼接: ' + 'Hello' + ', ' + 'World');
}
trim: [Hello, RUNOOB!]
大写:   HELLO, RUNOOB!
小写:   hello, runoob!
包含 RUNOOB? true
以空格开头? true
以!结尾? true
替换:   Hello, DART!
分割结果: [Dart, Flutter, Google]
拼接: Hello, World

ブール値 bool

bool 型には true と false の2つの値しかありません。

主に条件判定に使用され、if 文と組み合わせて使われます。

例

void main() {
  bool isLoggedIn = true;
  bool hasPermission = false;

  // ブール式
  bool canAccess = isLoggedIn && hasPermission;  // かつ：両方とも true の場合
  bool isGuest = !isLoggedIn;                    // 否定：反転

  print('可以访问: $canAccess');
  print('是访客: $isGuest');

  // 比較演算は bool 値を生成する
  int age = 20;
  bool isAdult = age >= 18;
  print('是否成年: $isAdult');

  // 条件判定に直接使用
  if (isAdult) {
    print('欢迎访问 RUNOOB');
  }
}
可以访问: false
是访客: false
是否成年: true
欢迎访问 RUNOOB

Dart は静的型付け言語であり、条件判定では bool 型のみを受け付けます。これは JavaScript とは異なります——Dart では if(0) や if('') のような書き方は直接エラーになります。

Null 安全（Null Safety）

Null安全は Dart 2.12 で導入された最も重要な機能です。

その核となる考え方は、デフォルトではすべての変数が null を許可しないということです。明示的に宣言した場合のみ許可されます。

Null 許容型と非 Null 型

型の後ろに ? を付けると、その変数が null を許可することを示します。

例

void main() {
  // 非null型：null を代入できない
  String name = 'RUNOOB';
  // name = null; // エラー！name は null にできない

  // null許容型：null を許可する
  String? nickname;
  nickname = null;  // OK
  nickname = 'R';   // これもOK

  print('ニックネーム: $nickname');

  // int? も null を許可する
  int? score;
  print('点数: $score');  // null を出力
}
昵称: R
分数: null

Null 値処理演算子

演算子説明例
??左側が null の場合、右側の値を使用するname ?? 'デフォルト名'
??=変数が null の場合、右側の値を代入するname ??= 'デフォルト名'
?.安全アクセス：オブジェクトが null の場合、呼び出しをスキップするuser?.name
!非null アサーション（注意して使用）name!

例

void main() {
  String? username;

  // ?? 演算子：username が null の場合、デフォルト値を使用
  String displayName = username ?? 'RUNOOB ゲスト';
  print(displayName);  // RUNOOB ゲスト

  // ??= 演算子：null の場合に代入
  username ??= '新規ユーザー';
  print(username);  // 新規ユーザー

  // ?. 安全アクセス：非null の場合のみ呼び出す
  String? maybeNull;
  print(maybeNull?.length);  // null（エラーにならない）

  maybeNull = 'Hello';
  print(maybeNull?.length);  // 5

  // ! アサーション：null ではないと確信している（null だと例外が発生する）
  String definitelyNotNull = 'RUNOOB';
  print(definitelyNotNull!.length);  // 6
}
RUNOOB 访客
新用户
null
5
6

! アサーション演算子の使用はできるだけ避けてください。頻繁に ! を使用している場合は、型設計に問題がある可能性があります。??、??=、?. を優先的に使用して、null 値を安全に処理してください。

型変換

Dart では、異なる型の値を相互に変換できます。

例

void main() {
  // 数値 → 文字列
  int count = 42;
  String countStr = count.toString();
  print('数値を文字列に変換: $countStr (型: ${countStr.runtimeType})');

  // 文字列 → 数値
  String priceStr = '19.99';
  double price = double.parse(priceStr);
  print('文字列を数値に変換: ¥$price');

  // int &#x2194; double
  int integer = 10;
  double decimal = integer.toDouble();
  print('int を double に変換: $decimal');

  double pi = 3.14;
  int piInt = pi.toInt();  // 小数部分を切り捨て
  print('double を int に変換 (切り捨て): $piInt');

  // 任意の値 → 文字列
  bool flag = true;
  print('bool を文字列に変換: ${flag.toString()}');

  // 文字列 → bool（手動判断が必要）
  String boolStr = 'true';
  bool parsed = boolStr == 'true';
  print('文字列を bool に変換: $parsed');
}
数字转字符串: 42 (类型: String)
字符串转数字: ¥19.99
int 转 double: 10.0
double 转 int (截断): 3
bool 转字符串: true
字符串转 bool: true
