C データ型

C 言語において、データ型とは、さまざまな型の変数や関数を宣言するための広範なシステムを指します。変数の型は、変数の格納に必要なスペースと、格納されたビットパターンの解釈方法を決定します。

C の型は、以下のように分類できます。

番号型と説明
1基本データ型
これらは算術型であり、整数型（int）、文字型（char）、浮動小数点型（float）、倍精度浮動小数点型（double）を含みます。
2列挙型：
これらも算術型であり、プログラム内で特定の離散的な整数値のみを割り当てられる変数を定義するために使用されます。
3void 型：
型指定子void値を持たないデータ型を表し、通常は関数の戻り値に使用されます。
4派生型：
配列型、ポインタ型、構造体型を含みます。

配列型と構造体型は総称して集約型と呼ばれます。関数の型は関数の戻り値の型を指します。この章の以降の部分では基本型を紹介し、他のいくつかの型については後続の章で説明します。

void 型

void 型は、利用可能な値がないことを指定します。通常、以下の3つの場合に使用されます。

番号型と説明
1関数の戻り値が空
C には、値を返さないさまざまな関数があります。つまり、空を返すと言えます。値を返さない関数の戻り値の型は空です。例：void exit (int status);
2関数の引数が空
C には、引数を受け取らないさまざまな関数があります。引数なしの関数は void を受け取ることができます。例：int rand(void);
3void を指すポインタ
void * 型のポインタはオブジェクトのアドレスを表し、型ではありません。例えば、メモリ割り当て関数void *malloc( size_t size );は void を指すポインタを返し、任意のデータ型に変換できます。

今は void 型を完全に理解できなくても心配する必要はありません。後の章でこれらの概念について詳しく説明します。

型変換

型変換とは、あるデータ型の値を別のデータ型の値に変換することです。

C 言語には2種類の型変換があります。

  • 暗黙の型変換：暗黙の型変換は、式の中で自動的に行われ、明示的な指示や関数呼び出しを必要としません。通常は、小さい型をより大きい型に自動的に変換します。例えば、int 型を long 型に、または float 型を double 型に変換します。暗黙の型変換は、データの精度の喪失やデータの切り捨てを引き起こす可能性もあります。

  • 明示的な型変換：明示的な型変換では、キャスト演算子（type casting operator）を使用する必要があります。これにより、あるデータ型の値を別のデータ型の値に強制的に変換できます。キャストを使用すると、必要に応じてデータ型をより精密に制御できますが、データの喪失や切り捨てを引き起こす可能性もあります。

暗黙の型変換の例：

例

int i = 10;
float f = 3.14;
double d = i + f; // 暗黙的にint型をdouble型に変換

明示的な型変換の例：

例

double d = 3.14159;
int i = (int)d; // 明示的にdouble型をint型に変換

    1、データ型変換：C 言語では、ある式に異なる型の定数や変数が含まれている場合、計算時にそれらを自動的に同じ型に変換します。また、C 言語ではデータ型を強制的に変換することもできます。

    2、自動変換の規則：

    • a）浮動小数点数を整数型に代入すると、その浮動小数点数の小数部分は切り捨てられます。
    • b）整数を浮動小数点型に代入すると、値は変わりませんが、対応する浮動小数点型変数に格納されます。

    3、強制型変換の形式：(型指定子)(式)

    サンプルプログラム：

    #include<stdio.h>

int main()
{
    float f,x=3.6,y=5.2;
    int i=4,a,b;
    a=x+y;
    b=(int)(x+y);
    f=10/i;
    printf("a=%d,b=%d,f=%f,x=%f\n",a,b,f,x);
}

    例では、まず x+y の値を計算すると 8.8 になり、それを a に代入します。a は整数型なので、整数部分の 8 を取り、a=8 となります。

    次に b は x+y を整数型に強制的に変換します。

    最後に 10/i は2つの整数の除算であり、結果は依然として整数の2となり、その2を浮動小数点数 f に代入します。

    x は浮動小数点型なのでそのまま出力します。

    自動型変換ルール：

    • 1、オペランドの型が異なる場合、まず同じ型に変換してから演算を行います。

    • 2、変換はデータ長が増加する方向に行われ、精度が低下しないようにします。例えば int 型と long 型の演算時は、まず int 型を long 型に変換してから演算を行います。

      a、2つの型のバイト数が異なる場合、バイト数が多い型に変換します

      b、2つの型のバイト数が同じで、一方が符号付きで一方が符号なしの場合、符号なし型に変換します

    • 3、すべての浮動小数点演算は倍精度で行われます。float 単精度量のみを含む式でも、まず double 型に変換してから演算を行います。
    • 4、char 型と short 型（Visual C++ などの環境で）が演算に参加する場合、必ず先に int 型に変換する必要があります。
    • 5、代入演算では、代入演算子の両側の値のデータ型が異なる場合、代入演算子の右側の値の型は左側の値の型に変換されます。右側の値のデータ型の長さが左側より長い場合、一部のデータが失われ、精度が低下します。失われた部分は直接切り捨てられます。

    例えば：

    • 1、算術演算を実行するとき、低い型（短バイト）は高い型（長バイト）に変換できます。例：int 型は double 型に変換、char 型は int 型に変換など。
    • 2、代入式では、等号の右側の式の値の型が自動的に暗黙的に左側の変数の型に変換され、それに代入されます。
    • 3、関数呼び出し時、実引数の値が仮引数に渡されます。システムはまず実引数の値の型を自動的に暗黙的に仮引数の型に変換し、その後仮引数に代入します。
    • 4、関数に戻り値がある場合、システムはまず戻り式の値の型を自動的に暗黙的に関数の戻り型に変換し、その後呼び出し元の関数に返します。

    C言語でブール（bool）型を使用する方法について

    C言語では、ブール型はC言語の組み込みデータ型ではありません。C言語はデフォルトで0をfalse、1をtrueとみなします。しかし、C99からは _Bool 型が追加され、標準ライブラリファイル stdbool.h が導入されたことで、bool データ型をC言語のコードで直接使用できるようになりました。

    stdbool.h は実際には数行のコードしかありません：

    #ifndef _STDBOOL
#define _STDBOOL
#define __bool_true_false_are_defined 1
#ifndef __cplusplus
#define bool _Bool
#define false 0
#define true 1
#endif // __cplusplus
#endif // _STDBOOL

    その役割は次のとおりです：

    • __bool_true_false_are_defined を 1 と定義する
    • bool を C99 組み込み型 _Bool として定義する
    • true と false をそれぞれ 1 と 0 として定義する
    • _Bool 型には任意の値を代入できます。0 以外の値を代入した場合、この変数を呼び出すと常に 1 が返されます。

    以下は stdbool.h を使用したコード例です：

    #include <stdbool.h>
#include <stdio.h>

int main()
{
    printf("true = %d\n", true);
    printf("false = %d\n", false);
    bool a = 0;
    bool b = 'b';
    bool c = "Hello world";
    printf("bool a = %d\n", a);
    printf("bool b = %d\n", b);
    printf("bool c = %d\n", c);
    return 0;
}

    実行結果：

    true = 1
false = 0
bool a = 0
bool b = 1
bool c = 1
