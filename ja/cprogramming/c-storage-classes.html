C ストレージクラス

ストレージクラスは、Cプログラム内の変数/関数の格納場所、ライフサイクル、およびスコープ（有効範囲）を定義します。

これらの指定子は、修飾する型の前に置かれます。

以下にCプログラムで使用できるストレージクラスを示します：

  • auto
  • register
  • static
  • extern

auto ストレージクラス

autoauto ストレージクラスは、すべてのローカル変数のデフォルトのストレージクラスです。

関数内で定義された変数はデフォルトで auto ストレージクラスになります。これは、変数が関数の開始時に作成され、関数の終了時に破棄されることを意味します。

{
   int mount;
   auto int month;
}

上記の例では、同じストレージクラスを持つ2つの変数を定義しています。auto は関数内でのみ使用でき、つまり auto はローカル変数のみを修飾できます。

register ストレージクラス

registerregister ストレージクラスは、RAM ではなくレジスタに格納されるローカル変数を定義するために使用されます。これは、変数の最大サイズがレジスタのサイズ（通常は1ワード）に等しく、メモリ位置を持たないため、単項の '&' 演算子を適用できないことを意味します。

register ストレージクラスで定義された変数はレジスタに格納されるため、アクセス速度が速くなります。ただし、RAM に格納されていないため、アドレスを直接取得することはできません。頻繁にアクセスする必要がある変数に register ストレージクラスを使用すると、プログラムの実行速度を向上させることができます。

{
   register int  miles;
}

レジスタは、カウンタなど、高速アクセスが必要な変数にのみ使用されます。また、'register' と定義しても、変数がレジスタに格納されることを意味するわけではなく、ハードウェアと実装の制限に応じて、変数がレジスタに格納される可能性があることを意味することに注意してください。

static ストレージクラス

staticstatic ストレージクラスは、コンパイラに対して、変数がスコープに入るたびに毎回作成・破棄するのではなく、プログラムのライフサイクル全体にわたってローカル変数を存在させ続けるように指示します。したがって、static を使用してローカル変数を修飾すると、関数呼び出し間でローカル変数の値を保持できます。

static 修飾子はグローバル変数にも適用できます。static がグローバル変数を修飾すると、変数のスコープが宣言されたファイル内に制限されます。

グローバルに宣言された static 変数またはメソッドは、それらが static 変数またはメソッドと同じファイル内に現れる限り、任意の関数またはメソッドから呼び出すことができます。

静的変数はプログラム内で一度だけ初期化され、関数が複数回呼び出されても、その変数の値はリセットされません。

以下の例は、static がグローバル変数とローカル変数を修飾する適用例を示しています：

例

#include <stdio.h> /*関数宣言*/ void func1(void); static int count=10; /*グローバル変数 - static はデフォルト*/ int main() { while (count--) { func1(); } return 0; } void func1(void) { /*'thingy' は 'func1' のローカル変数 - 一度だけ初期化されます * 関数 'func1' を呼び出すたびに、'thingy' の値はリセットされません。*/ static int thingy=5; thingy++; printf("thingy は %d 、count は %d\n", thingy, count); }

この例では、count はグローバル変数として関数内で使用でき、thingy は static で修飾されているため、呼び出しのたびにリセットされません。

この例では、まだ説明していない関数とグローバル変数という2つの概念を使用しているため、現時点では理解できないかもしれません。完全に理解できなくても問題ありません。後の章で詳しく説明します。上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

 thingy 为 6 ， count 为 9
 thingy 为 7 ， count 为 8
 thingy 为 8 ， count 为 7
 thingy 为 9 ， count 为 6
 thingy 为 10 ， count 为 5
 thingy 为 11 ， count 为 4
 thingy 为 12 ， count 为 3
 thingy 为 13 ， count 为 2
 thingy 为 14 ， count 为 1
 thingy 为 15 ， count 为 0

extern ストレージクラス

externextern ストレージクラスは、他のファイルで宣言されたグローバル変数または関数を定義するために使用されます。extern キーワードを使用する場合、変数にはストレージ領域が割り当てられず、コンパイラに対してその変数が他のファイルで定義されていることを指示するだけです。

externextern ストレージクラスは、グローバル変数への参照を提供するために使用されます。グローバル変数はすべてのプログラムファイルから参照できます。extern を使用する場合、extern初期化できない変数については、変数名が以前に定義された格納場所を指すようにします。

複数のファイルがあり、他のファイルで使用できるグローバル変数または関数を定義している場合、他のファイルで extern を使用してextern定義済みの変数または関数への参照を取得できます。次のように理解できます。externextern は、別のファイルでグローバル変数または関数を宣言するために使用されます。

extern 修飾子は通常、2つ以上のファイルが同じグローバル変数または関数を共有する場合に使用されます。次に例を示します：

最初のファイル：main.c

例

#include <stdio.h> int count ; extern void write_extern(); int main() { count = 5; write_extern(); }

2番目のファイル：support.c

例

#include <stdio.h> extern int count; void write_extern(void) { printf("count is %d\n", count); }

ここで、2番目のファイルの externexternキーワードは、最初のファイル main.c ですでに定義されている countcountを宣言するために使用されます。ここで、これら2つのファイルをコンパイルします。次のようになります：

 $ gcc main.c support.c

これにより、a.out実行可能プログラムが生成されます。プログラムが実行されると、次の結果が生成されます：

count is 5

    C言語におけるグローバル変数、ローカル変数、静的グローバル変数、静的ローカル変数の違い

    スコープの観点から見ると：

    1、グローバル変数はグローバルスコープを持ちます。グローバル変数は1つのソースファイルで定義するだけで、すべてのソースファイルに作用します。もちろん、グローバル変数の定義を含まない他のソースファイルでは、extern キーワードを使用してこのグローバル変数を再度宣言する必要があります。

    2、静的ローカル変数はローカルスコープを持ち、一度だけ初期化され、最初の初期化からプログラムの実行終了まで存在し続けます。グローバル変数との違いは、グローバル変数はすべての関数に対して可視であるのに対し、静的ローカル変数は自分自身を定義した関数本体に対してのみ常に可視であることです。

    3、ローカル変数もローカルスコープのみを持ち、自動オブジェクト（auto）です。プログラムの実行中ずっと存在するわけではなく、関数の実行中にのみ存在し、関数の1回の呼び出しが終了すると、変数は破棄され、占有していたメモリも回収されます。

    4、静的グローバル変数もグローバルスコープを持ちます。グローバル変数との違いは、プログラムが複数のファイルを含む場合、定義されたファイル内でのみ作用し、他のファイルには作用しないことです。つまり、static キーワードで修飾された変数はファイルスコープを持ちます。このため、2つの異なるソースファイルが同じ名前の静的グローバル変数を定義している場合でも、それらは異なる変数です。

    メモリ空間の割り当ての観点から見ると：

    1、グローバル変数、静的ローカル変数、静的グローバル変数はすべて静的記憶域に空間が割り当てられますが、ローカル変数はスタックに空間が割り当てられます。

    2、グローバル変数自体が静的記憶方式であり、静的グローバル変数ももちろん静的記憶方式です。この2つは記憶方式において違いはありません。この2つの違いは、非静的グローバル変数のスコープがソースプログラム全体であることです。ソースプログラムが複数のソースファイルで構成される場合、非静的グローバル変数は各ソースファイルで有効です。一方、静的グローバル変数はそのスコープが制限され、つまりその変数を定義したソースファイル内でのみ有効であり、同じソースプログラムの他のソースファイルでは使用できません。静的グローバル変数のスコープは1つのソースファイル内に限られるため、そのソースファイル内の関数のみが共用でき、他のソースファイルでエラーを引き起こすことを防げます。

    • 1)静的変数はプログラムの静的データ記憶域（グローバルに可視）に置かれるため、次回の呼び出し時にも元の代入値を保持できます。この点が、スタック変数やヒープ変数との違いです。
    • 2)static を使用すると、変数は自身のスコープ内でのみ可視であることをコンパイラに伝えます。この点が、グローバル変数との違いです。

    以上の分析からわかるように、ローカル変数を静的変数に変更すると、その記憶方式、つまり生存期間が変わります。グローバル変数を静的変数に変更すると、そのスコープが変わり、使用範囲が制限されます。したがって、static という指定子は場所によって異なる役割を果たします。注意が必要です。

    Tips:

    • A.グローバル変数が単一のCファイル内でのみアクセスされる場合は、この変数を静的グローバル変数に変更して、モジュール間の結合度を下げることができます；
    • B.グローバル変数が単一の関数からのみアクセスされる場合は、この変数をその関数の静的ローカル変数に変更して、モジュール間の結合度を下げることができます；
    • C.動的グローバル変数、静的グローバル変数、静的ローカル変数にアクセスする関数を設計および使用する場合は、再入可能性の問題を考慮する必要があります。なぜなら、それらはすべて静的データ記憶域に配置され、グローバルに可視だからです；
    • D.再入可能な関数が必要な場合は、関数内でstatic変数を使用することを必ず避けなければなりません（そのような関数は「内部メモリ」機能を持つ関数と呼ばれます）
    • E.関数内でstatic変数を使用しなければならない状況：たとえば、ある関数の戻り値がポインタ型の場合、staticなローカル変数のアドレスを戻り値としなければなりません。auto型の場合は、誤ったポインタが返されます。

    auto 通常のローカルスタック変数、自動保存であり、このようなオブジェクトは自動的に生成・破棄されます。この変数はスタック上に置くことを推奨します。関数呼び出し時にメモリを割り当て、関数終了時にメモリを解放します。通常、autoは省略され、デフォルトで自動保存クラスとみなされます。プログラムの変数のほとんどは自動変数です。

    例 auto.c

    #include <stdio.h>

int main(void)
{
    auto int i = 9; /* 声明局部变量的关键字是 auto; 因可以省略, 几乎没人使用 */   
    printf("%d\n", i);  
    getchar();
    return 0;
}

    Register変数動的変数と静的変数はどちらもメモリ内に保存されます。プログラムがその値に遭遇すると、コントローラが命令を出して変数の値を演算器に送り、保存が必要な場合はメモリに保存し直します。変数を頻繁に使用する場合、例えば関数本体内の複数回のループで毎回そのローカル変数を参照する場合、ローカル変数の値をCPUのレジスタに置くことができます。これをレジスタ変数と呼びます。毎回メモリに読み書きする必要がないため、効率が上がります。ただし、レジスタ変数にできるのはローカル自動変数と仮引数のみです。関数呼び出し時には一部のレジスタを占有し、関数終了時に解放されます。システムによってregisterに対する要求は異なり、例えば定義できるregister変数の数やデータ型などの制限があります。一部のシステムでは自動変数として扱われます。そのため、通常プログラムではあまり使われません。

    例 register.c

    #include <stdio.h>
#include <time.h>

#define TIME 1000000000
int m, n = TIME; /* 全局变量 */

int main(void)
{   
    time_t start, stop;
    register int a, b = TIME; /* 寄存器变量 */
    int x, y = TIME;          /* 一般变量   */

    time(&start);
    for (a = 0; a < b; a++);
    time(&stop);
    printf("寄存器变量用时: %ld 秒\n", stop - start);
    
    time(&start);
    for (x = 0; x < y; x++);
    time(&stop);
    printf("一般变量用时: %ld 秒\n", stop - start);
    
    time(&start);
    for (m = 0; m < n; m++);
    time(&stop);
    printf("全局变量用时: %ld 秒\n", stop - start);

    return 0;
}

    出力結果：

    寄存器变量用时: 1 秒
一般变量用时: 8 秒
全局变量用时: 9 秒

    C言語では、staticはローカル変数、グローバル変数、および関数を修飾するために使用できます。状況によってstaticの役割は異なります。

    (1)ローカル変数を修飾する

    一般的に、ローカル変数はスタック領域に配置され、ローカル変数のライフサイクルはそのブロックの実行が終了すると終了します。しかし、staticで修飾すると、その変数は静的データ領域に格納され、ライフサイクルはプログラム全体の実行が終了するまで続きます。ただし、ここで注意すべき点は、staticでローカル変数を修飾するとライフサイクルと記憶領域は変わりますが、スコープは変わらず、依然としてローカル変数であり、スコープはそのブロック内に限定されるということです。

    staticでローカル変数を修飾すると、その変数は最初の実行時に一度だけ初期化が行われます。

    例：

    #include<stdio.h>  
void fun()  
{   
    static int a=1; a++;   
    printf("%d\n",a);  
}  
int main(void)  
{   
    fun();   
    fun();   
    return 0;  
}

    プログラムの実行結果は: 2 3

    つまり、2回目のfun()関数呼び出し時、aの値は2であり、初期化による代入は行われず、直接インクリメント演算が行われるため、結果は3になります。

    静的ローカル変数が初期化されていない場合、整数型変数にはシステムが自動的に0を代入し、文字配列には自動的に'\0'が代入されます。

    (2)グローバル変数を修飾する

    グローバル変数は、そのソースファイル内だけでなく、同じプロジェクトの他のソースファイルからもアクセスできます（externで宣言するだけでよい）。

    例：

    //有file1.c  
int a=1;  
file2.c  
#include<stdio.h>  
extern int a;  
int main(void)  
{  
    printf("%d\",a);  
    return 0;  
}

    この場合、実行結果は 1

    しかし、file1.c で int a=1 を static int a=1; に変更した場合、

    file2.c では変数aにアクセスできません。その理由は、staticでグローバル変数を修飾するとそのスコープが変わり、元はプロジェクト全体から参照可能だったのが、そのソースファイル内でのみ参照可能になるためです。

    (3)関数を修飾する

    staticで関数を修飾する場合、グローバル変数を修飾する場合とほぼ同じで、関数のスコープが変わります。

    その他の参考：C言語における static の役割

    static の使い方

    静的変数を説明するために使われます。関数内で定義された場合、その効果はグローバル変数に似ています。ただし、staticで定義された変数は現在のCプログラムファイル内でのみ使用でき、別のCコード内では、externキーワードを使ってもこのstatic変数にアクセスできません。関数内で定義された場合、この変数は一度だけ初期化され、その関数を再度呼び出しても、このstatic変数は再度初期化されません。この変数の値は保持され続けます。つまり、その関数を再度呼び出すと、そのstatic変数は前回の関数呼び出し時の結果のままであることがわかります。

    例 static.c:

    #include <stdio.h>

void varfunc(void)
{
    int var=0;
    static int static_var=0;
    printf("var equal: %d\n",var);
    printf("static_var equal: %d\n",static_var);
    printf("");
    var++;
    static_var++;
}

int main(int argc, char *argv[])
{
    int i;
    for(i=0;i<3;i++)
        varfunc();
    return 0;
}

    実行結果は次のとおりです：

    var equal: 0
static_var equal: 0
var equal: 0
static_var equal: 1
var equal: 0
static_var equal: 2

    このように、staticで修飾されたローカル変数は一度だけ初期化されることがわかります。

    静的グローバル変数と通常のグローバル変数の違い：

    グローバル変数（外部変数）の宣言の前にstaticを付けると、静的グローバル変数になります。

    グローバル変数自体が静的記憶域に置かれます。静的グローバル変数ももちろん静的記憶域に置かれます。この2つに記憶方式の違いはありません。

    この2つの違いは、非静的グローバル変数のスコープがソースプログラム全体であることです。ソースプログラムが複数のソースファイルで構成されている場合、非静的グローバル変数は各ソースファイルで有効です。一方、静的グローバル変数はそのスコープが制限され、つまりその変数を定義したソースファイル内でのみ有効であり、同じソースプログラムの他のソースファイルでは使用できません。
