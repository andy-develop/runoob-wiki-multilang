C 関数

関数とは、1つのタスクを一緒に実行する文のグループです。すべてのCプログラムには少なくとも1つの関数、すなわちmain関数があります。main()また、すべての単純なプログラムでも、追加の関数を定義することができます。

コードを異なる関数に分割することができます。コードをどのように異なる関数に分割するかはあなた次第ですが、論理的には通常、各関数が特定のタスクを実行するように分割されます。

関数宣言はコンパイラに関数の名前、戻り値の型、引数を伝えます。関数定義は関数の実際の本体を提供します。

C標準ライブラリは、プログラムが呼び出すことができる多くの組み込み関数を提供します。例えば、関数strcat()は2つの文字列を連結するために使われ、関数memcpy()はメモリを別の場所にコピーするために使われます。

関数には、メソッド、サブルーチン、プロシージャなど、さまざまな呼び方もあります。

関数の定義

C言語における関数定義の一般的な形式は次のとおりです。

return_type function_name( parameter list )
{
   body of the function
}

C言語では、関数は関数ヘッダと関数本体から構成されます。以下に関数のすべての構成要素を示します。

  • 戻り値の型：関数は値を返すことができます。return_typeは関数が返す値のデータ型です。一部の関数は必要な操作を実行しても値を返しません。その場合、return_type はキーワードvoid。
  • 関数名：これは関数の実際の名前です。関数名と引数リストを合わせて関数シグネチャと呼びます。
  • 引数：引数はプレースホルダーのようなものです。関数が呼び出されるとき、引数に値を渡します。この値は実引数と呼ばれます。引数リストには、関数の引数の型、順序、数が含まれます。引数はオプションであり、つまり関数が引数を含まない場合もあります。
  • 関数本体：関数本体には、関数が実行するタスクを定義する一連の文が含まれます。

例

以下はmax()関数のソースコードです。この関数は2つの引数 num1 と num2 を持ち、これらの2つの数のうち大きい方を返します。

/*関数は2つの数のうち大きい方を返す*/ int max(int num1, int num2) { /*ローカル変数の宣言*/ int result; if (num1 > num2) { result = num1; } else { result = num2; } return result; }

関数の宣言

関数宣言はコンパイラに関数名と呼び出し方法を伝えます。関数の実際の本体は別途定義することができます。

関数宣言には次の部分が含まれます。

return_type function_name( parameter list );

上で定義した関数 max() に対する関数宣言は次のとおりです。

int max(int num1, int num2);

関数宣言では、引数の名前は重要ではなく、引数の型のみが必要です。したがって、以下も有効な宣言です。

int max(int, int);

あるソースファイルで関数を定義し、別のファイルで関数を呼び出す場合、関数宣言が必要です。この場合、呼び出し側のファイルの先頭で関数を宣言する必要があります。

関数の呼び出し

C関数を作成するとき、関数が何を行うかを定義し、その後に関数を呼び出して定義したタスクを実行します。

プログラムが関数を呼び出すとき、プログラムの制御は呼び出された関数に移ります。呼び出された関数は定義されたタスクを実行し、関数のreturn文が実行されるか、関数の終わりの括弧に達すると、プログラムの制御をメインプログラムに返します。

関数を呼び出すとき、必要な引数を渡します。関数が値を返す場合は、戻り値を保存できます。例えば：

例

#include <stdio.h> /*関数の宣言*/ int max(int num1, int num2); int main () { /*ローカル変数の定義*/ int a = 100; int b = 200; int ret; /*関数を呼び出して最大値を取得*/ ret = max(a, b); printf( "Max value is : %d\n", ret ); return 0; } /*関数は2つの数のうち大きい方を返す*/ int max(int num1, int num2) { /*ローカル変数の宣言*/ int result; if (num1 > num2) result = num1; else result = num2; return result; }

max() 関数と main() 関数を一緒に置いて、ソースコードをコンパイルします。最終的な実行可能ファイルを実行すると、次の結果が生成されます。

Max value is : 200

関数の引数

関数が引数を使用する場合、引数の値を受け取る変数を宣言する必要があります。これらの変数は関数の仮引数。

仮引数は関数内の他のローカル変数と同様に、関数に入るときに作成され、関数を出るときに破棄されます。

関数を呼び出すとき、関数に引数を渡す方法は2つあります。

呼び出しの種類説明
値渡しこの方法は引数の実際の値を関数の仮引数にコピーします。この場合、関数内で仮引数を変更しても実引数には影響しません。
参照渡しポインタ渡しの方法では、仮引数は実引数のアドレスを指すポインタです。仮引数へのポインタ操作は、実引数自体への操作に相当します。

デフォルトでは、Cは値渡しを使用して引数を渡します。一般的に、これは関数内のコードが関数呼び出しに使用された実引数を変更できないことを意味します。

    関数が他のソースファイルから呼び出せるかどうかに応じて、関数は内部関数と外部関数に分類されます。

    内部関数

    関数がこのファイル内の他の関数からのみ呼び出せる場合、それを内部関数と呼びます。内部関数を定義するとき、関数名と関数型の前にstaticを付けます。すなわち

    static 类型名 函数名 （形参表）

    例えば、関数の最初の行：

    static int max(int a,int b)

    内部関数は静的関数とも呼ばれます。内部関数を使用することで、関数のスコープをそのファイル内に限定できます。異なるファイルに同じ名前の内部関数があっても、互いに干渉しません。プログラムの信頼性が向上します。

    外部関数

    関数を定義するとき、関数ヘッダの一番左端にキーワードexternを付けると、その関数は外部関数となり、他のファイルから呼び出すことができます。

    例えば、関数ヘッダは次のようにできます。

    extern int max (int a,int b)

    C言語では、関数を定義するときにexternを省略した場合、デフォルトで外部関数とみなされます。

    この関数を呼び出す必要がある他のファイルでは、この関数の宣言を行う必要があります（このファイル内で関数を呼び出す場合でも、関数プロトタイプで宣言することを忘れないでください）。この関数を宣言するときには、キーワードexternを付け、その関数が他のファイルで定義された外部関数であることを示します。

    例

    以下の例では、複数のファイルの関数を使用して、文字列を入力し、指定した文字を削除します。

    file1.c（ファイル1）

    #include <stdio.h>

static void delete_string(char str[],char ch);
int main()
{
    extern void enter(char str[]); // 对函数的声明
    extern void print(char str[]); // 对函数的声明
    char c,str[100];
    enter(str);
    scanf("%c",&c);
    delete_string(str,c);
    print(str);
    return 0;
}

static void delete_string(char str[],char ch)//内部函数
{
    int i,j;
    for(i=j=0;str[i]!='\0';i++)
    if(str[i]!=ch)
    str[j++]=str[i];
    str[j]='\0';
}

    file2.c（ファイル2）

    #include <stdio.h>

void enter(char str[100]) // 定义外部函数 enter
{
    fgets(str, 100, stdin); // 向字符数组输入字符串
}

    file3.c（ファイル3）

    #include <stdio.h>

void print(char str[]) // 定义外部函数 print
{
    printf("%s\n",str);
}

    文字列「abcdef」を入力し、文字配列 str に格納し、削除する文字「d」を入力します。 実行結果:

    $ gcc file1.c file2.c file3.c 
$ ./a.out
abcdef                   # 输入的字符串
d                        # 要删除的字符
abcef                    # 删除后的字符串

    インライン関数

    インライン関数とは、inlineキーワードで修飾された関数のことです。クラス内で定義された関数はデフォルトでインライン関数とみなされます。インライン関数はソースコードのレベルでは関数の構造を持ちますが、コンパイル後は関数の性質を持ちません。

    インライン展開は関数呼び出しの時間的オーバーヘッドを除去するために使用されます。これは通常、頻繁に実行される関数に使用され、小さなメモリ空間の関数にとって非常に有益です。インライン関数を使用する際の注意点：

    再帰関数はインライン関数として定義できません

    • インライン関数は一般に、whileやswitchなどの複雑な構造がなく、1〜5文のみの小さな関数に適しています。そうでない場合、コンパイルシステムはその関数を普通の関数とみなします。
    • インライン関数は、先に定義してから使用しなければなりません。そうでない場合、コンパイルシステムもそれを普通の関数とみなします。
    • インライン関数に対して例外のインターフェース宣言を行うことはできません。
    • 例：

    簡単な交換関数月影困

    inline void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

    関数の引数渡しでよく使われる3つの方法

    サンプルプログラムはすべて2つの整数を交換する例です。

    1. 値渡し

    #include <stdio.h>

void swap(int x, int y);
void swap(int x, int y)
{
    int temp;
    temp = x;
    x = y;
    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(a, b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    値渡しは単方向の受け渡しであり、渡す過程では仮引数の値が変わるだけで、実引数の値は変わらないため、aとbの元の値は変わりません。

    2. ポインタ渡し

    #include <stdio.h>

void swap(int *x, int *y);
void swap(int *x, int *y)
{
    int temp;
    temp = *x;
    *x = *y;
    *y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(&a, &b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    ポインタ渡しでは、aとbのアドレスをそれぞれxとyに渡します。関数本体内でa、bが存在するアドレスの値を変更する、つまりa、bの値を交換します。

    3. 参照渡し

    #include <stdio.h>

void swap(int &x, int &y);
void swap(int &x, int &y)
{
    int temp;
    temp = x;
    x = y;
    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(a, b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    参照渡しでは、swap(a, b); を呼び出すときに関数はa、bをそれぞれx、yの代わりに使用します。つまりx、yはそれぞれa、b変数を参照します。このため関数本体内で実際に演算に参加するのは実引数a、bそのものであり、値の交換も達成できます。

    注：厳密に言うと、C言語には参照渡しはありません。これはC++の言語機能です。そのため.cファイルで参照渡しを使用するとコンパイルエラーになります。

   int a=2,b=3;

int sum(int a,int b)

    return a+b ;

    int sum(int ,int );

    コンパイラは関数の戻り値の型、名前、パラメータの型が正しいことを確認できればよいのです。

    関数はコードの再利用を実現し、プログラマーの作業量を大幅に簡略化・短縮し、プログラムの可読性を大いに高めます。関数の再帰呼び出しは、さらにプログラムコードを簡素化する方法の一つです。再帰呼び出しとは、実は関数が自分自身を呼び出すことです。

    以下の例は、1+2+3.....+n を求める再帰の実例です：

    #include <stdio.h>  //导如输入输出头文件

int sum(int n);//声明函数 
int main(){
    //主函数 
    int a=sum(4);
    printf("%d",a);
  return 0;
}
int sum(int n){
    //求和函数实现 
    //如果n为1，无需求和，直接返回1 
    if(n==1){
        return 1;
    }
    //如果n大于1，就返回n加上1+2+3.....+n-1的和 
    return n+sum(n-1);
}

    再帰のコードは少ないことがわかりますが、再帰にも欠点があります。再帰が使用するメモリは反復より多く、時間も反復より長くなります。

    プレースホルダーとは、あらかじめ固定の位置を確保しておき、後から内容を追加するための記号であり、コンピュータ上のさまざまなドキュメント編集で広く使用されています。

    書式指定子(%)は、C/C++言語の書式付き入出力関数、例えば scanf、printf などで使用されます。その意味は書式のプレースホルダーとして機能し、その位置に入力または出力があることを示します。

    • %d, %i整数を表します
    • %f浮動小数点数
    • %s文字列
    • %c char
    • %pポインタ
    • %fLlong（長整数）
    • %e科学表記法
    • %g小数または科学表記法。
    • %a,%A浮動小数点値を読み込みます（C99のみ有効）。
    • %c1文字を読み込みます。
    • %d10進整数を読み込みます。
    • %i10進数、8進数、16進数の整数を読み込みます。
    • %o8進整数を読み込みます。
    • %x,%X16進整数を読み込みます。
    • %s文字列を読み込み、空白、タブ、または改行文字で終了します。
    • %f,%F,%e,%E,%g,%G実数の入力に使用され、小数形式または指数形式で入力できます。
    • %pポインタを読み込みます。
    • %u 符号なし10進整数を読み込みます。

    1、関数の呼び出し：プログラムは上から下へ実行されるため、関数は先に宣言してから呼び出す必要があります。この前後はドキュメント内の位置の前後であり、時間的な前後ではありません。以下の書き方が正解です。

    #include<stdio.h>

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我将在主函数中输出\n");
}

int main(void)
{
    f();  /*调用函数*/
}

    上記の例では、メイン関数内で関数を呼び出していますf()、そして関数の宣言は呼び出しより前に行われています。

    2、この書き方は間違いです

    #include<stdio.h>

int main(void)
{
    f();/*调用函数*/
}

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我将在主函数中输出\n");
}

    上記の例では、メイン関数内で関数を呼び出しています f()、しかし関数の宣言は呼び出しより後ろにあります。関数の実行は上から下へ行われるため、この書き方は間違いです。

    関数をどうしてもメイン関数の後に書きたい場合は、メイン関数の前に関数の前方宣言を追加します。

    #include<stdio.h>

void f(void); /*前置声明*/

    f();  /*调用函数*/
}

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我一定要先声明后调用\n");
}

    本質的に言えば、C のすべての関数パラメータ渡しは値渡しです。

    ポインタ渡しでパラメータ変数の値を変更できるのは、swap 関数が渡されたポインタ自体を交換するのではなく、ポインタが指す値を交換するからです。

    void swap(int *x, int *y);
void swap(int *x, int *y){
    int temp;
    //这里操作的是指针指向的值 而不是指针
    temp = *x;
    *x = *y;
    *y = temp;
//   倘若直接交换指针 a、b的值不会交换
//    temp = x;
//    x = y;
//    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(&a, &b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    参照渡しも同様です。
