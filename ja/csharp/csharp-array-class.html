C# Array クラス

C# 配列

Array クラスは C# のすべての配列の基底クラスであり、System 名前空間で定義されています。Array クラスは、配列に使用するさまざまなプロパティとメソッドを提供します。

C# の Array クラスはすべての配列の基底クラスであり、System 名前空間にあります。

配列は、固定サイズで同じ型の要素を格納するためのコレクションです。Array クラスの特徴とメソッドを理解することは、効率的な C# プログラムを書くために非常に重要です。

以下は、C# の Array クラスについての詳細な説明で、その特徴、よく使われるメソッド、プロパティ、および使用例を含みます。

特徴

  • 型安全性：配列は指定された型の要素のみを格納でき、型は宣言時に決定されます。
  • 固定長：配列の長さは作成後に変更できません。
  • インデックスアクセス：配列の要素にはインデックスでアクセスし、インデックスは 0 から始まります。
  • 多次元サポート：C# は、1次元、多次元、およびジャグ配列（配列の配列）をサポートしています。

例

次のプログラムは、Array クラスのいくつかのメソッドの使用方法を示しています。

例

using System;
namespace ArrayApplication
{
    class MyArray
    {
       
        static void Main(string[] args)
        {
            int[] list = { 34, 72, 13, 44, 25, 30, 10 };

            Console.Write("元の配列： ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();
           
            // 配列を反転
            Array.Reverse(list);
            Console.Write("反転した配列： ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();
           
            // 配列を並べ替え
            Array.Sort(list);
            Console.Write("並べ替えた配列： ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();

           Console.ReadKey();
        }
    }
}

上記のコードをコンパイルして実行すると、次の結果が生成されます。

原始数组： 34 72 13 44 25 30 10
逆转数组： 10 30 25 44 13 72 34
排序数组： 10 13 25 30 34 44 72

よく使用されるメソッドの例

1. Array.Clear(Array, int index, int length)

配列内の指定した範囲の要素を、その型の既定値に設定します。

int[] arr = {1, 2, 3, 4, 5};
Array.Clear(arr, 1, 2); // arr = {1, 0, 0, 4, 5}

2. Array.Copy(Array sourceArray, Array destinationArray, int length)

ソース配列からターゲット配列に要素をコピーします。

int[] source = {1, 2, 3};
int[] destination = new int[3];
Array.Copy(source, destination, 3); // destination = {1, 2, 3}

3. Array.Clone()

配列のシャローコピー（浅いコピー）を作成します。

int[] arr = {1, 2, 3};
int[] clonedArr = (int[])arr.Clone();

4. Array.IndexOf(Array array, object value)

指定した要素が 1 次元配列内で最初に出現するインデックスを返します。

int[] arr = {1, 2, 3, 2};
int index = Array.IndexOf(arr, 2); // index = 1

5. Array.LastIndexOf(Array array, object value)

指定した要素が 1 次元配列内で最後に出現するインデックスを返します。

int[] arr = {1, 2, 3, 2};
int lastIndex = Array.LastIndexOf(arr, 2); // lastIndex = 3

6. Array.Reverse(Array array)

1 次元配列内の要素の順序を反転します。

int[] arr = {1, 2, 3};
Array.Reverse(arr); // arr = {3, 2, 1}

7. Array.Sort(Array array)

1 次元配列の要素を昇順に並べ替えます。

int[] arr = {3, 1, 2};
Array.Sort(arr); // arr = {1, 2, 3}

8. Array.BinarySearch(Array array, object value)

並べ替えられた 1 次元配列内で要素を検索し、そのインデックスを返します。

int[] arr = {1, 2, 3, 4, 5};
int index = Array.BinarySearch(arr, 3); // index = 2

注意：BinarySearch を使用する前に、配列が並べ替えられている必要があります。

9. Array.Resize(ref T[] array, int newSize)

1 次元配列のサイズを変更します。

int[] arr = {1, 2, 3};
Array.Resize(ref arr, 5); // arr = {1, 2, 3, 0, 0}

10. Array.Exists<T>(T[] array, Predicate match)

配列内に条件を満たす要素が存在するかどうかを判断します。

int[] arr = {1, 2, 3};
bool exists = Array.Exists(arr, x => x == 2); // exists = true

11. Array.Find<T>(T[] array, Predicate match)

配列内で条件に一致する最初の要素を検索します。

int[] arr = {1, 2, 3, 4};
int result = Array.Find(arr, x => x > 2); // result = 3

12. Array.FindAll<T>(T[] array, Predicate match)

配列内で条件に一致するすべての要素を検索します。

int[] arr = {1, 2, 3, 4};
int[] results = Array.FindAll(arr, x => x > 2); // results = {3, 4}

13. Array.FindIndex<T>(T[] array, Predicate match)

条件に一致する最初の要素のインデックスを返します。

int[] arr = {1, 2, 3, 4};
int index = Array.FindIndex(arr, x => x > 2); // index = 2

14. Array.FindLast<T>(T[] array, Predicate match)

条件に一致する最後の要素を検索します。

int[] arr = {1, 2, 3, 4};
int result = Array.FindLast(arr, x => x > 2); // result = 4

15. Array.FindLastIndex<T>(T[] array, Predicate match)

条件に一致する最後の要素のインデックスを返します。

int[] arr = {1, 2, 3, 4};
int index = Array.FindLastIndex(arr, x => x > 2); // index = 3

16. Array.TrueForAll<T>(T[] array, Predicate match)

配列内のすべての要素が条件を満たすかどうかを判断します。

int[] arr = {1, 2, 3};
bool allPositive = Array.TrueForAll(arr, x => x > 0); // allPositive = true

17. Array.ForEach<T>(T[] array, Action action)

配列の各要素に対して指定された操作を実行します。

int[] arr = {1, 2, 3};
Array.ForEach(arr, x => Console.WriteLine(x)); // 输出 1 2 3

18. Array.ConstrainedCopy(Array sourceArray, int sourceIndex, Array destinationArray, int destinationIndex, int length)

配列の一部の要素を別の配列にコピーし、コピーが失敗した場合にデータが破損しないようにします。
int[] source = {1, 2, 3, 4, 5};
int[] destination = new int[5];
Array.ConstrainedCopy(source, 0, destination, 0, 5);

19. Array.Fill<T>(T[] array, T value)

配列のすべての要素を指定された値に設定します。

int[] arr = new int[5];
Array.Fill(arr, 10); // arr = {10, 10, 10, 10, 10}

20. Array.AsReadOnly<T>(T[] array)

配列の読み取り専用ラッパーを返します。

int[] arr = {1, 2, 3};
var readOnlyArr = Array.AsReadOnly(arr);
// readOnlyArr[0] = 5; // 编译错误，集合是只读的

例

using System;

class Program
{
    static void Main()
    {
        // 配列を作成して初期化する
        int[] numbers = {5, 2, 8, 1, 3};

        // 配列を並べ替える
        Array.Sort(numbers); // numbers = {1, 2, 3, 5, 8}

        // 要素を検索する
        int index = Array.BinarySearch(numbers, 5); // index = 3

        // 配列を反転する
        Array.Reverse(numbers); // numbers = {8, 5, 3, 2, 1}

        // 6 より大きい要素が存在するか確認する
        bool exists = Array.Exists(numbers, x => x > 6); // exists = true

        // 配列の要素を 2 倍にする
        Array.ForEach(numbers, x => Console.WriteLine(x * 2));

        // 配列のサイズを変更する
        Array.Resize(ref numbers, 7); // numbers = {8, 5, 3, 2, 1, 0, 0}

        // 新しい要素を埋め込む
        Array.Fill(numbers, 10, 5, 2); // インデックス 5 から始まる 2 つの要素を 10 に設定する
        // numbers = {8, 5, 3, 2, 1, 10, 10}
    }
}

    Array.Sort() は元の配列を直接変更します。このことからforeach (int i in list)この文からわかります。

    したがって、上記の例のデモ順序を「元の配列 → 並べ替え後の配列 → 反転後の配列」に変更し、このメソッドをさらに理解します。

    using System;
namespace ArrayApplication
{
    class MyArray
    {
        
        static void Main(string[] args)
        {
            int[] list = { 34, 72, 13, 44, 25, 30, 10 };

            Console.Write("原始数组： ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();
            
            // 排序数组
            Array.Sort(list);
            Console.Write("排序数组： ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();

            Console.ReadKey();

            // 逆转数组
            Array.Reverse(list);
            Console.Write("逆转数组： ");
            foreach (int i in list)
            {
                Console.Write(i + " ");
            }
            Console.WriteLine();
        }
    }
}

    出力結果は次のとおりです：

    原始数组： 34 72 13 44 25 30 10
排序数组： 10 13 25 30 34 44 72
逆转数组： 72 44 34 40 25 13 10

    元の配列と反転後の配列の比較から、Array.Sort() メソッドが元の配列を直接変更することがわかります。

    using System;

namespace MyTest

    {

        {
            int[] arry = { 1, 2, 3, 4, 5, 6, 7, 8 };
            int[] arry2 = (int[])arry.Clone();
            int[] arry3 = new int[arry.Length];
            arry.CopyTo(arry3, 0);

        }
    }
