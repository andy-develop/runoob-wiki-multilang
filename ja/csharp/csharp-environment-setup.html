C# 開発環境

仕事をうまくやろうとするなら、まず道具を整えよ。C#コードを書き始める前に、まずコンピューターに開発環境を構築する必要があります。

C#開発環境の構築は、それほど複雑ではありません。必要なのは2つのものをインストールするだけです：実行プラットフォーム（.NET SDK）和コードエディタこれでC#プログラミングの旅を始めることができます。

ステップ1：.NETとC#の関係を理解する

ツールをインストールする前に、よくある疑問を明確にしておきましょう：C#と.NETは同じものですか？

いいえ、違います。両者の関係は次のように理解できます：

  • C#C#は、コードを書くためのプログラミング言語で、文章を書くための「文字」のようなものです。
  • .NET.NETは、コードを実行するプラットフォームおよびツールセットであり、文字を印刷・流通させるための「印刷機と紙」のようなものです。

C#で書いたプログラムは、コンピューター上で実行するために.NETに依存する必要があります。したがって、C#開発環境を構築する最初のステップは、.NET SDKをインストールすることです。

.NETの現在の主流バージョンは.NET 8（長期サポート版）です。Windows、macOS、Linuxの3大プラットフォームに対応しており、以前のようにWindowsでしか動作しないということはありません。

ステップ2：.NET SDKをインストールする

.NET SDK（ソフトウェア開発キット）には、コンパイラ、ランタイム、さまざまな開発ツールが含まれており、C#開発の基盤です。インストール手順は次のとおりです：

  • .NET公式ダウンロードページにアクセスします：https://dotnet.microsoft.com/download
  • 最新のLTS（長期サポート）バージョンを選択します初心者にはLTS版を優先的に選ぶことをおすすめします。安定しており、資料も豊富です。
  • お使いのオペレーティングシステム（Windows / macOS / Linux）に応じたインストーラーをダウンロードし、指示に従ってインストールを完了します。

インストールが完了したら、コマンドライン（Windowsでは「コマンドプロンプト」または「PowerShell」、macOS/Linuxでは「ターミナル」）を開き、以下のコマンドを入力してインストールが成功したか確認します：

dotnet --version

バージョン番号が出力されたら（例：8.0.xxx）、.NET SDKが正しくインストールされています。

ステップ3：コードエディタを選ぶ

.NET SDKがあれば、理論上はメモ帳でコードを書き、コマンドラインでコンパイル・実行することができます。しかし実際の開発では、専用のコードエディタまたはIDE（統合開発環境）を使用しますこれらはコード補完、エラー通知、デバッグなどの機能を提供し、開発効率を大幅に向上させます。

C#初心者には、以下の2つのツールをおすすめします：

① Visual Studio（Windowsユーザーにおすすめ）

Visual Studioは、MicrosoftがC#のために開発したフラッグシップIDEで、機能が最も充実しており、デバッグ体験も優れています。現在、企業で最も広く使用されているC#開発ツールです。

  • 長所：機能が強力で、コード作成、デバッグ、テスト、公開が一体化しており、Windowsデスクトップアプリやエンタープライズ級プロジェクトの開発に特に適しています。
  • 短所：インストールパッケージが大きい（数GB）、起動が遅い、WindowsとmacOSのみ対応。
  • 価格：個人での学習利用はCommunity（コミュニティ版）が無料で、機能はすでに非常に充実しています。
  • ダウンロード先：https://visualstudio.microsoft.com/zh-hans/downloads/

💡 インストール時に「ワークロード」ページで「ASP.NET と Web 開発」 或 「.NET デスクトップ開発」にチェックを入れると、C#に必要なすべてのコンポーネントが自動的にインストールされ、個別の設定は不要です。

② Visual Studio Code（クロスプラットフォームユーザーにおすすめ）

VS Codeは軽量なコードエディタで、容量が小さく起動が速く、Windows、macOS、Linuxに対応しています。C#拡張プラグインをインストールすることで、同様に充実したC#開発体験が得られます。

  • 長所：軽量で柔軟、クロスプラットフォーム、プラグインエコシステムが豊富で、シンプルな環境を求める開発者に適しています。
  • 短所：プラグインを手動でインストールする必要があり、一部の高度なデバッグ機能はVisual Studioほど充実していません。
  • 価格：完全無料・オープンソース。
  • ダウンロード先：https://code.visualstudio.com/

💡 VS Codeをインストールしたら、拡張機能ストアでC# Dev Kitプラグイン（Microsoft公式）を検索してインストールすると、スマートヒント、デバッグ、プロジェクト管理などの完全な機能が利用できます。

どう選ぶ？

  • もしあなたがWindowsを使用していて、主な目的がC#の基礎学習またはWindowsアプリの開発であれば → を推奨Visual Studio Community。
  • もしあなたがmacOSまたはLinuxを使用している、またはより軽量なエディタを希望する場合 → を推奨Visual Studio Code + C# Dev Kit。

関連ツールをもっと見る

ステップ4：最初のC#プログラムを書く

環境が整ったら、検証してみましょう。コマンドラインを使用して、最もシンプルなC#プロジェクトを作成・実行します：

コマンドラインを開き、次のコマンドを順番に実行します：

dotnet new console -n HelloWorld
cd HelloWorld
dotnet run

次のような出力が表示されたら：

Hello, World!

おめでとうございます！C#開発環境の構築に成功し、最初のプログラムも正常に実行できました。

macOSとLinuxでC#を開発する

前述のとおり、最新の.NET（.NET 5以降）はネイティブでクロスプラットフォーム実行をサポートしており、macOSおよびLinuxユーザーは.NET SDKを直接インストールするだけで、Windowsとほぼ同じ体験ができます。

さらに、「Mono」というものを聞いたことがあるかもしれません。Monoは、初期のコミュニティによって開発された.NETのオープンソース・クロスプラットフォーム実装であり、かつてはLinuxやmacOSでC#を実行する主要な方法でした。しかし、Microsoft公式の.NETが全面的にクロスプラットフォーム化されたことで、Monoの使用場面は大幅に減少し、現在は主にUnityゲームエンジンなどの特定の用途に使用されています。新しいプロジェクトでは、公式の.NET SDKを直接使用することをおすすめします。Monoをインストールする必要はありません。

Monoの詳細については、以下を参照してください：http://www.mono-project.com/

    VCとVSの違い

    VSはVisual Studioのことで、Microsoftが提供するツールセットであり、さまざまなツールで構成されています。VSはC/C++、VB、JAVA、C#でのプログラミングをサポートできます。ただし、一度にサポートできるプログラミング言語は1つだけです。VSのインストール完了後、初回起動時によく使う言語を選択するように求められます。C/C++を選択すると、C/C++プログラミングが可能なプラットフォームになり、それがあなたの言うVCかもしれません。C/C++を使いたくない場合は、初期設定を変更して別のプログラミング言語を選択するだけで、別の言語のプログラミング環境になります。

    VCはVisual C++のことで、独立したC/C++開発ツールです。有名なのはVC6.0で、現在のVC2010は実際にはVC10.0です。

    もう少しわかりやすく言うと、VS2010とVC2010を例にとると、VS2010はOffice2010に相当し、Word2010、Excel2010などを含みます。一方、VC2010はWord2010に相当します。
