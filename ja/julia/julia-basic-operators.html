Julia 基本演算子

演算子は、コンパイラに特定の数学的または論理演算を実行させる記号です。例：3+2=5。

Julia 言語には豊富な演算子が組み込まれており、サポートされている演算は次のとおりです：

  • 算術演算子
  • 論理演算子
  • 関係演算子
  • ビット演算子
  • 代入演算子
  • ベクトル化「ドット」演算子

算術演算子

次の表は、Julia の基本的な算術演算子を示しています。これらはすべての基本的な数値型に適用されます：

式 名前 説明
+x 単項加算演算子 恒等演算
-x 単項減算演算子 値をその反数にする
x + y 二項加算演算子 2つの数を加算する
x - y 二項減算演算子 2つの数を減算する
x * y 乗算演算子 2つの数を乗算する
x / y 除算演算子 2つの数を除算する
x ÷ y 整数除算 x / y の整数部分を取る
x \ y 逆除算 等価y / x
x ^ y 冪乗演算子 x 的 yx の y 乗
x % y 剰余を取る 等価rem(x,y)

例

julia> 1 + 2 + 3
6
julia> 1 - 2
-1
julia> 3*2/12
0.5
julia> 2+20-5
17
julia> 50*2/10
10.0
julia> 23%2
1
julia> 2^4
16

ブール演算子

次の表は、Julia のブール演算子を示しています：

式 名前
!x 否定
x && y 短絡論理積。式 x && y において、部分式 y は x が true のときだけ実行されます。
x || y 短絡論理和。式 x || y において、部分式 y は x が false のときだけ実行されます。

例

julia> !true
false

julia> !false
true

julia> true && (x = (1, 2, 3))
(1, 2, 3)

julia> false && (x = (1, 2, 3))
false

julia> false || (x = (1, 2, 3))
(1, 2, 3)

次の表は、Julia の関係演算子を示しています：

演算子 名前
== 等しい
!=, ≠ 等しくない
< より小さい
<=, ≤ 以下
> より大きい
>=, ≥ 以上

例

julia> 100 == 100
true

julia> 100 == 101

true

false

連鎖比較

連鎖比較は数値コードを書くときに特に便利です。スカラーを比較するには && 演算子を使用し、配列は & で要素ごとに比較します。例えば、0 .< A .< 1 は boolean 配列を生成し、A の要素がすべて 0 と 1 の間にある場合は配列の要素はすべて true になります。

Julia は連鎖比較を許可しています：

例

julia> 1 < 2 <= 2 < 3 == 3 > 2 >= 1 == 1 < 3 != 5
true

連鎖比較の実行順序に注意してください：

例

julia> M(a) = (println(a); a)
M (generic function with 1 method)
julia> M(1) < M(2) <= M(3)
 2
 1
 3
true
julia> M(1) > M(2) <= M(3)
 2
 1
false

代入演算子

すべての二項演算子とビット演算子は、左オペランドへの複合代入を行うことができます。方法は、= を二項演算子の直後に置くことです。例えば、x += 3等価です。 x = x + 3 。

次の表は、Julia の代入演算子を示しています：

演算子説明例
=単純代入演算子。右オペランドの値を左オペランドに代入します。C = A + B は A + B の値を C に代入します。
+=加算代入演算子。右オペランドと左オペランドを加算した結果を左オペランドに代入します。C += A は C = C + A と同じです。
-=減算代入演算子。左オペランドから右オペランドを減算した結果を左オペランドに代入します。C -= A は C = C - A と同じです。
*=乗算代入演算子。右オペランドと左オペランドを乗算した結果を左オペランドに代入します。C *= A は C = C * A と同じです。
/=除算代入演算子。左オペランドを右オペランドで除算した結果を左オペランドに代入します。C /= A は C = C / A と同じです。
%=剰余代入演算子。2つのオペランドの剰余を左オペランドに代入します。C %= A は C = C % A と同じです。
<<=左シフト代入演算子C <<= 2 は C = C << 2 と同じです。
>>=右シフト代入演算子C >>= 2 は C = C >> 2 と同じです。
&=ビット論理積代入演算子C &= 2 は C = C & 2 と同じです。
^=ビット排他的論理和代入演算子C ^= 2 は C = C ^ 2 と同じです。
|=ビット論理和代入演算子C |= 2 は C = C | 2 と同じです。
>>>=論理右シフト代入演算子C >>>= 2 は C = C >>>2 と同じです。
⊻=排他的論理和（論理 XOR）代入演算子C ⊻= 2 は C = C ⊻= 2 と同じです。

例

julia> x = 1
1

julia> x += 3
4

julia> x
4

ベクトル化「ドット」演算子

Julia では、すべての二項演算子には対応する「ドット」演算子があります。例えば^には対応する.^が存在します。この対応する.^は、Julia によって自動的に要素ごとに実行すると定義されています。^演算。例えば[1,2,3] ^ 3は非合法です。数学では（長さが異なる）配列の立方（3乗）は定義されていないためです。しかし[1,2,3] .^ 3は Julia では合法です。^ 演算を要素ごとに実行（ベクトル化演算とも呼ばれます）し、[1^3, 2^3, 3^3] を得ます。同様に、! 或 √のような単項演算子にも、対応する.√ が要素ごとの演算を実行するために用意されています。

例

julia> [1,2,3] .^ 3
3-element Vector{Int64}:
  1
  8
 27

ドット演算子のほかに、ドット代入演算子もあります。例えばa .+= b（または@. a += b）は次のように解析されます：a .= a .+ b。

演算子の優先順位と結合性

演算子の優先順位は、式内の項の組み合わせ方を決定します。これは式の計算方法に影響します。一部の演算子は他の演算子よりも優先順位が高くなります。例えば、乗算・除算演算子は加算・減算演算子よりも優先順位が高くなります。

例えばx = 7 + 3 * 2、ここで x には 20 ではなく 13 が代入されます。なぜなら演算子*は+よりも優先順位が高いため、最初に乗算 3*2 が計算され、次に 7 が加算されます。

次の表は、演算子を優先順位の高い順に並べています。優先順位が高い演算子は表の上部に、優先順位が低い演算子は表の下部に表示されます。式内では、優先順位が高い演算子が先に計算されます。

分類 演算子 結合性
構文 . followed by :: 左結合
冪乗演算 ^ 右結合
単項演算子 + - √ 右結合
シフト演算 << >> >>> 左結合
除算 // 左結合
乗算 * / % & \ ÷ 左結合
加算 + - | ⊻ 左結合
構文 : .. 左結合
構文 |> 左結合
構文 <| 右結合
比較 > < >= <= == === != !== <: 結合性なし
フロー制御 && followed by || followed by ? 右結合
Pair 操作 => 右結合
代入 = += -= *= /= //= \= ^= ÷= %= |= &= ⊻= <<= >>= >>>= 右結合

組み込み関数を使用することでも、Base.operator_precedence任意の演算子の優先順位数値を確認できます。数値が大きいほど優先順位が高くなります：

例

julia> Base.operator_precedence(:+), Base.operator_precedence(:*), Base.operator_precedence(:.)
(11, 12, 17)

julia> Base.operator_precedence(:sin), Base.operator_precedence(:+=), Base.operator_precedence(:(=))  # (注意：等号の前後には括弧 `:(=)` が必要です)
(0, 1, 1)

さらに、組み込み関数Base.operator_associativity演算子の結合性の記号表現を返すことができます：

例

julia> Base.operator_associativity(:-), Base.operator_associativity(:+), Base.operator_associativity(:^)
(:left, :none, :right)

julia> Base.operator_associativity(:⊗), Base.operator_associativity(:sin), Base.operator_associativity(:→)
(:left, :none, :right)
