Julia 文字列

文字列（英語: string）は、0個以上の文字から構成される有限の並びです。これは、プログラミング言語でテキストを表すデータ型です。

Julia は通常、一重引用符を使用して'単一文字を作成し、二重引用符"または三重引用符"""で文字列を作成します。例：

c = 'x'

str = "RUNOOB"

runoob = """菜鸟教程 "RUNOOB"，包含了单个引号"""

Julia の文字列型の特徴：

  • Julia で文字列（および文字列リテラル）に使用される組み込みの具体的な型は String です。
  • Julia の文字列型はすべて抽象型 AbstractString のサブタイプです。
  • Julia には単一文字を表す優れた型である AbstractChar があります。Char は AbstractChar の組み込みサブタイプであり、任意の Unicode 文字を表すことができる32ビットのプリミティブ型です（UTF-8 エンコーディングに基づきます）。
  • Julia の文字列は変更不可です。つまり、任意の AbstractString オブジェクトの値は変更できません。

文字

単一の文字は Char 値で表されます。

Char は32ビットのプリミティブ型であり、それに対応する整数値（Unicode コード）に変換できます：

例

julia> c = 'x'
'x': ASCII/Unicode U+0078 (category Ll: Letter, lowercase)

julia> typeof(c)
Char

julia> c = Int('x')
120

julia> typeof(c)
Int64

整数値を Char に変換することもできます：

例

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> Char(120)
'x': ASCII/Unicode U+0078 (category Ll: Letter, lowercase)

Char の値に対して比較や限定的な算術演算を行うことができます：

例

julia> 'A' < 'a'
true

julia> 'A' <= 'a' <= 'Z'
false

julia> 'A' <= 'X' <= 'Z'
true

julia> 'x' - 'a'
23

julia> 'A' + 1
'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)

文字列

Julia の文字列は二重引用符"または三重引用符"""で宣言できます。文字列内の一部で引用符を使用する必要がある場合は、三重引用符を使用してそれを実行できます。次に示すように：

例

julia> str = "RUNOOB"
"RUNOOB"

julia> runoob = """菜鸟教程 "RUNOOB"，包含了单个引号"""
"菜鸟教程\"RUNOOB\"，包含了单个引号"

文字列が長すぎる場合は、バックスラッシュを使用して\分割できます：

例

julia> "This is a long \
       line"
"This is a long line"
Julia の文字列は配列と同様に、インデックスを使用して指定位置の文字を読み取ったり、指定位置の文字列を切り出したりできます。インデックスの開始位置は1またはbegin、終了位置はend ：

例

julia> str = "RUNOOB"
"RUNOOB"

julia> str[begin]
'R': ASCII/Unicode U+0052 (category Lu: Letter, uppercase)

julia> str[1]
'R': ASCII/Unicode U+0052 (category Lu: Letter, uppercase)

julia> str[2]
'U': ASCII/Unicode U+0055 (category Lu: Letter, uppercase)

julia> str[end]
'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)

julia> str[end-1]
'O': ASCII/Unicode U+004F (category Lu: Letter, uppercase)

範囲インデックスを使用して部分文字列を抽出できます：

例

julia> str = "RUNOOB"
"RUNOOB"

julia> str[begin:end]
"RUNOOB"

julia> str[begin:end-1]
"RUNOO"

julia> str[2:5]
"UNOO"

さらに、式str[k] 和 str[k:k]から得られる結果は異なります。前者はインデックスによって指定位置の文字を取得するもので、型は Char 型です。後者は指定された範囲で文字列を読み取るものですが、それは単に1つの文字を含む文字列にすぎません：

例

julia> str[6]
'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)

julia> str[6:6]
"B"

範囲の切り出しは、SubStringメソッドを使用して実現することもできます。例：

例

julia> str = "long string"
"long string"

julia> substr = SubString(str, 1, 4)
"long"

julia> typeof(substr)
SubString{String}

文字列連結

string() メソッドを使用して複数の文字列を連結できます：

例

julia> greet = "Hello"
"Hello"

julia> whom = "world"
"world"

julia> string(greet, ", ", whom, ".\n")
"Hello, world.\n"

補間

連結によって文字列を構築する方法は、時には面倒です。string への冗長な呼び出しや繰り返しの乗算を減らすために、Julia では Perl のように $ を使用して文字列リテラルを補間できます：

例

julia> "$greet, $whom.\n"
"Hello, world.\n"

これはより読みやすく便利で、上記の文字列連結と同等です。— システムはこの明らかに1行の文字列リテラルを、引数付きの文字列リテラル連結に書き換えます。string(greet, ", ", whom, ".\n")。

在 $その後、最短の完全な式が、その値を文字列に挿入する式と見なされます。したがって、括弧を使って任意の式を文字列に挿入できます：

例

julia> "1 + 2 = $(1 + 2)"
"1 + 2 = 3"

連結と補間はどちらも string を呼び出して、オブジェクトを文字列形式に変換します。しかし、string は実際には print の出力を単に返すだけです。そのため、新しい型には string メソッドではなく print または show メソッドを追加すべきです。

ほとんどの非 AbstractString オブジェクトは、テキスト式として入力された方法と密接に対応する文字列に変換されます：

例

julia> v = [1,2,3]
3-element Vector{Int64}:
 1
 2
 3

julia> "v: $v"
"v: [1, 2, 3]"

string は AbstractString と AbstractChar の値に対して恒等関数なので、それらは引用符もエスケープもなしで、そのまま文字列に挿入されます：

例

julia> c = 'x'
'x': ASCII/Unicode U+0078 (category Ll: Letter, lowercase)

julia> "hi, $c"
"hi, x"

文字列リテラルにテキスト$を含めたい場合は、バックスラッシュでエスケープします：

例

julia> print("I have \$100 in my account.\n")
I have $100 in my account.

Unicode と UTF-8

Julia は Unicode の文字と文字列を完全にサポートしています。

文字リテラルでは、Unicode コードは Unicode の \u および \U エスケープシーケンスで表すことができ、またすべての標準 C エスケープシーケンスでも表すことができます。これらは文字列リテラルを書くためにも同様に使用できます：

例

julia> s = "\u2200 x \u2203 y"
"∀ x ∃ y"

これらの Unicode 文字がエスケープとして表示されるか、特殊文字として表示されるかは、端末のロケール設定と、その端末の Unicode サポートに依存します。文字列リテラルは UTF-8 でエンコードされます。UTF-8 は可変長エンコーディングです。つまり、すべての文字が同じバイト数（コードユニット）でエンコードされるわけではありません。UTF-8 では、ASCII 文字（0x80(128) 未満のもの）は ASCII と同じように単一バイトでエンコードされますが、0x80 以上の文字は最大4バイトでエンコードされます。

三重引用符文字列リテラル

三重引用符"""..."""は、より長く複雑な文字列を作成するのに便利です。三重引用符の内部では、改行、引用符、インデントなどを特別に処理することなく簡単に使用できます。

例

julia> str = """
           Hello,
           world.
         """
"  Hello,\n  world.\n"

文字列比較

比較演算子を使用して、辞書順で文字列を比較できます：

例

julia> "abracadabra" < "xylophone"
true

julia> "abracadabra" == "xylophone"
false

julia> "Hello, world." != "Goodbye, world."
true

julia> "1 + 2 = 3" == "1 + 2 = $(1 + 2)"
true

findfirst 関数と findlast 関数を使用して、特定の文字のインデックスを検索できます：

例

julia> findfirst(isequal('o'), "xylophone")
4

julia> findlast(isequal('o'), "xylophone")
7

julia> findfirst(isequal('z'), "xylophone")

3番目の引数を指定して、findnext 関数と findprev 関数を使用すると、指定したオフセット位置で文字を検索できます：

例

julia> findnext(isequal('o'), "xylophone", 1)
4

julia> findnext(isequal('o'), "xylophone", 5)
7

julia> findprev(isequal('o'), "xylophone", 5)
4

julia> findnext(isequal('o'), "xylophone", 8)

occursin 関数を使用して、文字列内に部分文字列があるかどうかを確認できます。

例

julia> occursin("world", "Hello, world.")
true

julia> occursin("o", "Xylophon")
true

julia> occursin("a", "Xylophon")
false

julia> occursin('o', "Xylophon")
true

最後の例は、occursin が文字リテラルの検索にも使用できることを示しています。

他にも便利な文字列関数として repeat と join があります：

例

julia> repeat(".:Z:.", 10)
".:Z:..:Z:..:Z:..:Z:..:Z:..:Z:..:Z:..:Z:..:Z:..:Z:."

julia> join(["apples", "bananas", "pineapples"], ", ", " and ")
"apples, bananas and pineapples"

その他に役立つ関数には、以下もあります：

  • firstindex(str)- str へのインデックスに使用できる最小の（バイト）インデックスを与えます（文字列の場合は常に1ですが、他のコンテナではそうとは限りません）。
  • lastindex(str)- str へのインデックスに使用できる最大の（バイト）インデックスを与えます。
  • length(str)- str 内の文字数。
  • length(str, i, j)- str 内の i から j までの有効な文字インデックスの数。
  • ncodeunits(str)- 文字列内のコードユニット（符号単位）の数。
  • codeunit(str, i)- 文字列 str 内のインデックス i にあるコードユニットの値を与えます。
  • thisind(str, i)- 文字列の任意のインデックスが与えられたとき、そのインデックスポイントの最初のインデックスを見つけます。
  • nextind(str, i, n=1)- インデックス i の後にある n 番目の文字の先頭を見つけます。
  • prevind(str, i, n=1)- インデックス i の前にある n 番目の文字の先頭を見つけます。

生文字列リテラル

補間なし・エスケープなしの生文字列は、raw"..."という形式の非標準文字列リテラルで表すことができます。生文字列リテラルは普通の String オブジェクトを生成し、補間やエスケープなしで、入力とまったく同じ囲まれた内容を含みます。これは、他の言語で" 或 \"を特殊文字として使用するコードやマークアップを含む文字列に役立ちます。

例外として、引用符は依然としてエスケープする必要があります。例えばraw"\""は次と同等です"\""。すべての文字列を表現できるようにするには、バックスラッシュもエスケープする必要があります。ただし、それは引用符の直前に現れる場合に限ります。

julia> println(raw"\\ \\\"")
\\ \"

最初の2つのバックスラッシュが出力にそのまま表示されることに注意してください。これは、それらが引用符の前にないためです。しかし、次のバックスラッシュは後続のバックスラッシュをエスケープします。また、これらのバックスラッシュは引用符の前に現れるため、最後のバックスラッシュは引用符をエスケープします。
