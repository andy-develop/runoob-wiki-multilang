brew install nodejs

コンポーネントを触ってみよう

これまでは主にさまざまな一般的なコンポーネントのデータバインディングについて説明しました。次は Vue のコンポーネントの使い方について説明します。
プロジェクトディレクトリ/srcの下に作成componentフォルダを作成し、componentフォルダの下にfirstcomponent.vueを作成し、App.vue の形式とこれまで学んだ知識を参考にしてコンポーネントを書きます。

<template> <div id="firstcomponent"> <h1>I am a title.</h1> <a> written by {{ author }} </a> </div> </template> <script type="text/javascript">export default { data () { return { author: "微信公众号 jinkey-love" } } }</script> <style> </style>

duang... 公式ドキュメントの通りにやれと言われても、まず自分で試してから皆さんに伝えます。私がやったあとの結果はこうです。視聴者の皆さんもこうなることを願っています。（謎の微笑み）

次に App.vue でコンポーネントを使用します（なぜなら、その中にindex.html<div id="app"></div>が定義されているので、このコンポーネントをメインエントリとして使うと便利です）
第一歩、インポート。では<script></script>タグ内の最初の行に書きます

import firstcomponent from './component/firstcomponent.vue'

第二歩、登録。では<script></script>タグ内の data コードブロックの後に components: { firstcomponent } を追加します。間に必ず半角カンマを入れてください!!!

export default {
  data () {
    return {
      msg: 'Hello Vue!'
    }
  },
  components: { firstcomponent }
}

第三歩、使用。
在<template></template>内に<firstcomponent></firstcomponent>を追加します

<template> <div id="app"> <img src="./assets/logo.png"> <h1>{{ msg }}</h1> <firstcomponent></firstcomponent> </div> </template>

以前の方法でコンポーネント secondcomponent.vue を作成します

ここで main.js を修正し、インポートして登録しますvue-router

import VueRouter from "vue-router";

さらにルーティングルールを設定し、アプリ起動設定項目に router を追加します。旧バージョンの router.map メソッドはvue-router 2.0もう使えません。修正後のmain.js以下の通りです:

import Vue from 'vue' import App from './App.vue' import VueRouter from "vue-router"; import VueResource from 'vue-resource' //デバッグモードを有効にする Vue.config.debug = true; Vue.use(VueRouter); Vue.use(VueResource); //コンポーネントを定義します。以前のチュートリアルで教えた方法のように、他のファイルからインポートすることもできます const First = { template: '<div><h2>我是第 1 个子页面</h2></div>' } import secondcomponent from './component/secondcomponent.vue' //ルーターインスタンスを作成します //そしてルーティングルールを設定します const router = new VueRouter({ mode: 'history', base: __dirname, routes: [ { path: '/first', component: First }, { path: '/second', component: secondcomponent } ] }) //これでアプリケーションを起動できます！ //ルーターは App インスタンスを作成し、セレクタ #app に一致する要素にマウントします。 const app = new Vue({ router: router, render: h => h(App) }).$mount('#app')

このように修正したら、ブラウザを開いて確認してみてください。

その2つのリンクをクリックしてみると、<router-view class="view"></router-view>の内容が表示され、同時に注意してください：ブラウザのアドレスがすでに変更されています。。

ページに動的データを追加する

このときのページはすべて静的です（データはプログラム作成時に固定されており変更できません）。しかし、ほとんどのアプリケーションは外部データをリクエストしてページ内容を動的に変更します。それに対応するライブラリとしてvue-resourceがこの問題を解決してくれます。
コマンドラインでインストールします

cnpm install vue-resource --save

main.js でインポートして登録しますvue-resource:

import VueResource from 'vue-resource'
Vue.use(VueResource);

secondcomponent.vue でデータを動的に読み込みます
リストを追加します:

<ul>
  <li v-for="article in articles">
    {{article.title}}
  </li>
</ul>

data の中に配列 articles を追加し、[] を代入します
次に data の後にフック関数を追加しますmounted（詳細は公式ドキュメントの vue ライフサイクルの説明を参照してください）data と mount の間には忘れずにカンマを付けてください

mounted: function() { this.$http.jsonp('https://api.douban.com/v2/movie/top250?count=10', {}, { headers: { }, emulateJSON: true }).then(function(response) { //ここは成功時のコールバックを処理します this.articles = response.data.subjects //this.articles = response.data["subjects"] でも構いません }, function(response) { //ここはエラー時のコールバックを処理します console.log(response) }); }

ここでは豆瓣の公開 GET インターフェースを使用しています。インターフェースがクロスドメインの POST リクエストの場合は、サーバー側での設定が必要です:

Access-Control-Allow-Origin: *

この状態で実行してみてください。しばらく待つとインターフェースがデータを返します。おや、データが読み込まれましたね。素晴らしい！

こんなに見苦しいUIを救おう

コンポーネント、双方向バインディング、ルーティング、データリクエストなどの基本機能が使えるようになり、ここまで書くとシングルページアプリケーションの形がほぼ整いました。しかし、このインターフェースはあまりにもひどすぎます。自分で UI フレームワークを書くのは面倒ですか？それならネットで探しましょう。
本来は Vux を紹介しようと思っていました。Vux は微信（WeChat）の WeUI デザイン規格を使用しており、微信ミニプログラムや微信内の Web ページの開発に非常に適しています。しかし、この記事を書いた時点では Vux が vue2.0 をサポートしていなかったため、他のフレームワークを使うしかありませんでした。

Uncaught Error: Module parse failed: /Users/**/Desktop/vue2/node_modules/.1.0.0-rc.5@element-ui/lib/theme-default/index.css Unexpected character '@' (1:0)
You may need an appropriate loader to handle this file type.

公式ドキュメントにまた落とし穴がありました。インストールチュートリアルはこの手順を説明してくれず、私たちを全員上級者だと思っているようです...
エラーが発生したのは、私たちが次を導入したからです:index.cssこの CSS ファイルですが、webpack でバンドルする際に認識して js に変換することができません。そのため、CSS とフォントファイルを読み込むための設定が必要です。次のコマンドを実行して以下の3つをインストールしてください（以前にインストール済みの場合は不要です）

webpack.config.js の loaders 配列に以下の設定を追加してください。カンマを追加すべき場所には忘れずにカンマを追加してください！

{ test: /\\\\\\\\.css$/, loader: "style!css" }, { test: /\\\\\\\\.(eot|woff|woff2|ttf)([\\\\\\\\?]?.*)$/, loader: "file" }
