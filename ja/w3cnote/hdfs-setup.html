4.0 HDFS 設定と使用

カテゴリ Hadoop チュートリアル

以前に説明した Hadoop の 3 つのモード：スタンドアロンモード、擬似クラスターモード和クラスターモード。

スタンドアロンモード：Hadoop はライブラリとしてのみ存在し、単一のコンピューター上で MapReduce タスクを実行できます。開発者が学習・試験環境を構築するためだけに使用されます。

擬似クラスターモード：このモードでは、Hadoop はデーモンプロセスの形で単一マシン上で実行されます。通常、開発者が学習・試験環境を構築するために使用されます。

クラスターモード：このモードは Hadoop の本番環境モードです。つまり、これが Hadoop が実際に使用するモードであり、本番レベルのサービスを提供するために使われます。

HDFS 設定と起動

HDFS はデータベースと似ており、デーモンプロセスとして起動します。HDFS を使用するには、HDFS クライアントがネットワーク（ソケット）経由で HDFS サーバーに接続し、ファイルシステムを利用する必要があります。

在Hadoop 実行環境「Hadoop 実行環境」の章では、すでに Hadoop の基本環境を設定し、コンテナ名は hadoop_single です。前回そのコンテナをシャットダウンした、またはコンピューターをシャットダウンしてコンテナが停止した場合は、そのコンテナを起動して中に入ってください。

コンテナに入ったら、Hadoop が存在するか確認しましょう：

hadoop version

結果に Hadoop のバージョン番号が表示されれば、Hadoop が存在します。

次に、正式な手順に進みます。

hadoop ユーザーの新規作成

hadoop という名前の新しいユーザーを作成します：

adduser hadoop

ユーザーパスワードの変更と権限管理のための小さなツールをインストールします：

yum install -y passwd sudo

hadoop ユーザーのパスワードを設定します：

passwd hadoop

次にパスワードを 2 回入力します。必ず覚えておいてください！

hadoop インストールディレクトリの所有者を hadoop ユーザーに変更します：

chown -R hadoop /usr/local/hadoop

次にテキストエディタで /etc/sudoers ファイルを変更し、

root    ALL=(ALL)       ALL

その後に 1 行を追加します

hadoop  ALL=(ALL)       ALL

次にコンテナを終了します。

コンテナ hadoop_single をシャットダウンし、イメージ hadoop_proto としてコミットします：

docker stop hadoop_single
docker commit hadoop_single hadoop_proto

新しいコンテナ hdfs_single を作成します：

docker run -d --name=hdfs_single --privileged hadoop_proto /usr/sbin/init

これで、新しいユーザーが作成されました。

HDFS を起動

今、作成したばかりのコンテナに入ります：

docker exec -it hdfs_single su hadoop

今は hadoop ユーザーになっているはずです：

whoami

「hadoop」と表示されるはずです

SSH キーを生成します：

ssh-keygen -t rsa

ここでは、生成が終了するまで Enter キーを押し続けてください。

次に、生成したキーを信頼リストに追加します：

ssh-copy-id hadoop@172.17.0.2

コンテナの IP アドレスを確認します：

ip addr | grep 172

これにより、コンテナの IP アドレスが 172.17.0.2 であることがわかります。皆さんの IP はこれとは異なる場合があります。

HDFS を起動する前に、いくつか簡単な設定を行います。Hadoop の設定ファイルはすべてインストールディレクトリの etc/hadoop サブディレクトリに保存されているので、このディレクトリに入ります：

cd $HADOOP_HOME/etc/hadoop

ここでは、core-site.xml と hdfs-site.xml の 2 つのファイルを変更します。

core-site.xml では、<configuration> タグの下にプロパティを追加します：

<property>
    <name>fs.defaultFS</name>
    <value>hdfs://<你的IP>:9000</value>
</property>

hdfs-site.xml の <configuration> タグの下にプロパティを追加します：

<property>
    <name>dfs.replication</name>
    <value>1</value>
</property>

ファイル構造をフォーマットします：

hdfs namenode -format

次に HDFS を起動します：

start-dfs.sh

起動は 3 つのステップに分かれており、NameNode、DataNode、Secondary NameNode をそれぞれ起動します。

jps を実行して Java プロセスを確認できます：

ここまでで、HDFS デーモンプロセスが確立されました。HDFS 自体に HTTP パネルがあるため、ブラウザで http://你的容器IP:9870/ にアクセスして、HDFS パネルと詳細情報を確認できます：

このページが表示されれば、HDFS の設定と起動が成功しています。

注意：デスクトップ環境を含まない Linux システムを使用していて、ブラウザがない場合は、この手順をスキップできます。Windows システムを使用しているが Docker Desktop を使用していない場合、この手順を実行するのは難しいでしょう。

HDFS の使用

HDFS Shell

hdfs_single コンテナに戻って、以下のコマンドで HDFS を操作します：

# 显示根目录 / 下的文件和子目录，绝对路径
hadoop fs -ls /
# 新建文件夹，绝对路径
hadoop fs -mkdir /hello
# 上传文件
hadoop fs -put hello.txt /hello/
# 下载文件
hadoop fs -get /hello/hello.txt
# 输出文件内容
hadoop fs -cat /hello/hello.txt

HDFS の最も基本的なコマンドは上記のとおりです。これ以外にも、従来のファイルシステムがサポートする多くの操作があります。

HDFS API

HDFS は多くのバックエンドプラットフォームでサポートされています。現在、公式のディストリビューションには C/C++ と Java のプログラミングインターフェースが含まれています。さらに、node.js や Python 言語のパッケージマネージャーでも HDFS クライアントのインポートをサポートしています。

以下は、パッケージマネージャーの依存関係リストです：

Maven：

    <dependency>
        <groupId>org.apache.hadoop</groupId>
        <artifactId>hadoop-client</artifactId>
        <version>3.1.4</version>
    </dependency>

Gradle：

providedCompile group: 'org.apache.hadoop', name: 'hadoop-hdfs-client', version: '3.1.4'

NPM：

npm i webhdfs

pip：

pip install hdfs

ここでは、Java で HDFS に接続する例を紹介します（IP アドレスを変更するのを忘れないでください）：

例

package com.runoob;
import java.io.IOException;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.*;
public class Application {
    public static void main(String[] args) {
        try {
            // 接続アドレスの設定
            Configuration conf = new Configuration();
            conf.set("fs.defaultFS", "hdfs://172.17.0.2:9000");
            FileSystem fs = FileSystem.get(conf);
            // ファイルを開いて出力を読み取る
            Path hello = new Path("/hello/hello.txt");
            FSDataInputStream ins = fs.open(hello);
            int ch = ins.read();
            while (ch != -1) {
                System.out.print((char)ch);
                ch = ins.read();
            }
            System.out.println();
        } catch (IOException ioe) {
            ioe.printStackTrace();
        }
    }
}
