2.1 Verilog UDP 基礎知識

分類 Verilog チュートリアル上級編

ゲートレベルモデリングで紹介した組み込みゲートユニット（and、or、nor など）は、すべて Verilog が備える標準プリミティブ一式、すなわちいわゆる組み込みプリミティブに属します。

さらに、Verilog はユーザーが独自にプリミティブを記述する機能も提供します。このようなプリミティブはユーザー定義プリミティブ（User Defined Primitive、略称 UDP）と呼ばれます。

UDP 内では、他の module や primitive を呼び出すことはできません。呼び出し方法はゲートレベルプリミティブと完全に同じです。

UDP のタイプは主に以下の 2 つがあり、後で順に説明します。

  • 組み合わせ論理 UDP：出力は入力信号のみに依存する組み合わせ論理です。
  • 順序論理 UDP：次の出力値は現在の入力値だけでなく、現在の内部状態にも依存します。

UDP 定義

UDP の定義はモジュール定義に依存しないため、モジュール定義の外に記述することも、単独でファイル内に定義することもできます。

UDP の形式定義は以下のとおりです：

例

primitive UDP_name (
  output_name,
  list_of_input) ;

  output_declaration ;
  list_of_input_declaration ;
  [reg_declaration] ;
  [initial_statement] ;
 
  table
    list_of_table_entries ;
  endtable
endprimitive

UDP 説明

ポート宣言：

  • 1、ポート宣言部分は module と似ており、ポートリストの宣言時にポート信号のみを列挙してから primitive 本体でそのタイプを説明するか、ポートリストの宣言時に直接タイプを指定することもできます。
  • 2、入力ポートはスカラ（すなわち 1 ビット）のみ使用でき、複数の入力ポートが許可されます。
  • 3、出力ポートはスカラ（すなわち 1 ビット）を 1 つだけ許可し、出力ポートはポートリストの最初の位置に配置する必要があります。複数の出力ポートは絶対に許可されません。
  • 4、出力ポートは output キーワードで宣言します。順序論理 UDP は状態を保存する必要があるため、その出力ポートは reg 型としても宣言する必要があります。
  • 5、UDP は inout ポートタイプをサポートしません。

初期化

initial 文を使用して順序論理 UDP の出力ポート（reg 型）を初期化できます。この文はオプションです。

状態表

  • 1、UDP 状態表は UDP の中で最も重要な部分であり、キーワード table で宣言します。入力状態と現在の状態に基づいて出力値を得る方法を定義し、論理真理値表に似ています。
  • 2、状態表の項目は 0、1、または x にすることができます。UDP は z 値を処理できないため、UDP に渡される z 値は x として扱われます。
