6.3 Verilog ステートマシン

カテゴリ Verilog チュートリアル

キーワード：ステートマシン，自動販売機

有限状態機械（Finite-State Machine，FSM）、略してステートマシンは、有限個の状態およびこれらの状態間の遷移や動作などの振る舞いを表す数学的モデルである。ステートマシンは回路の記述ツールであるだけでなく、思考方法でもあり、回路設計のシステムレベルおよびRTLレベルで広く応用されている。

ステートマシンの種類

Verilogにおけるステートマシンは主に同期順序論理の設計に使用され、有限個の状態間で一定の要求と規則に従って順序回路の状態を切り替えることができる。状態の切り替え方向は、各入力値だけでなく、現在の状態にも依存する。ステートマシンは2種類に分類できる：Moore型ステートマシンとMealy型ステートマシン。

Moore型ステートマシン

Moore型ステートマシンの出力は現在の状態のみに関係し、現在の入力には関係しない。

出力は1つの完全なクロック周期の間安定に保持され、このとき入力信号に変化があっても出力は変化しない。入力が出力に与える影響は次のクロック周期になって初めて反映される。これもMoore型ステートマシンの重要な特徴である：入力と出力は分離されている。

Mealy型ステートマシン

Mealy型ステートマシンの出力は、現在の状態だけでなく、現在の入力信号にも依存する。

Mealy型ステートマシンの出力は入力信号の変化後すぐに変化し、入力の変化は任意の状態のクロック周期内で発生する可能性がある。したがって、同じ論理の下では、Mealy型ステートマシンの出力の入力に対する応答はMoore型ステートマシンより1クロック周期早い。

ステートマシン設計フロー

設計要件に基づいて状態遷移図を描き、使用するステートマシンの種類を決定し、各種の入出力信号を記入すると、プログラミングに役立つ。一般に最も多く使用されるのはMealy型3段式ステートマシンである。以下では自動販売機を設計する具体例を通して、ステートマシンの設計過程を説明する。

自動販売機

自動販売機の機能説明は次のとおりである：

飲料の単価は2元で、この自動販売機は0.5元と1元の硬貨のみを受け付ける。釣り銭と商品の払い出しを考慮する。硬貨の投入と商品の払い出しは毎回1つずつ行われ、一度に複数の硬貨を投入したり、一度に複数の飲料を払い出したりする現象は発生しない。毎回の自動販売機の硬貨投入、商品払い出し、釣り銭の処理が完了して初めて、新しい自動販売状態に入ることができる。

ここで、coin = 1 は0.5元硬貨の投入を表し、coin = 2 は1元硬貨の投入を表す。

ステートマシン設計：3段式（推奨）

ステートマシンの設計は次のとおりである：

  • (0) まず、ステートマシンの状態数に基づいてステートマシンエンコーディングを決定する。エンコーディングを使用して状態レジスタに値を代入すると、コードの可読性が向上する。
  • (1) ステートマシンの第1段は、順序論理、非ブロッキング代入であり、レジスタの状態を伝達する。
  • (2) ステートマシンの第2段は、組み合わせ論理、ブロッキング代入であり、現在の状態と現在の入力に基づいて、次のステートマシンの状態を決定する。
  • (3) ステートマシンの第3段は、順序論理、非ブロッキング代入であり、Mealy型ステートマシンであるため、現在の状態と現在の入力に基づいて出力信号を決定する。

例

// vending-machine
// 2 yuan for a bottle of drink
// only 2 coins supported: 5 jiao and 1 yuan
// finish the function of selling and changing

module  vending_machine_p3  (
    input           clk ,
    input           rstn ,
    input [1:0]     coin ,     //01 for 0.5 jiao, 10 for 1 yuan

    output [1:0]    change ,
    output          sell    //output the drink
    );

    //machine state decode
    parameter            IDLE   = 3'd0 ;
    parameter            GET05  = 3'd1 ;
    parameter            GET10  = 3'd2 ;
    parameter            GET15  = 3'd3 ;

    //machine variable
    reg [2:0]            st_next ;
    reg [2:0]            st_cur ;

    //(1) state transfer
    always @(posedge clk or negedge rstn) begin
        if (!rstn) begin
            st_cur      <= 'b0 ;
        end
        else begin
            st_cur      <= st_next ;
        end
    end

    //(2) state switch, using block assignment for combination-logic
    //all case items need to be displayed completely    
    always @(*) begin
        //st_next = st_cur ;//条件の選択肢がすべて考慮されていない場合、初期値を代入してlatchを除去できる
        case(st_cur)
            IDLE:
                case (coin)
                    2'b01:     st_next = GET05 ;
                    2'b10:     st_next = GET10 ;
                    default:   st_next = IDLE ;
                endcase
            GET05:
                case (coin)
                    2'b01:     st_next = GET10 ;
                    2'b10:     st_next = GET15 ;
                    default:   st_next = GET05 ;
                endcase

            GET10:
                case (coin)
                    2'b01:     st_next = GET15 ;
                    2'b10:     st_next = IDLE ;
                    default:   st_next = GET10 ;
                endcase
            GET15:
                case (coin)
                    2'b01,2'b10:
                               st_next = IDLE ;
                    default:   st_next = GET15 ;
                endcase
            default:    st_next = IDLE ;
        endcase
    end

    //(3) output logic, using non-block assignment
    reg  [1:0]   change_r ;
    reg          sell_r ;
    always @(posedge clk or negedge rstn) begin
        if (!rstn) begin
            change_r       <= 2'b0 ;
            sell_r         <= 1'b0 ;
        end
        else if ((st_cur == GET15 && coin ==2'h1)
               || (st_cur == GET10 && coin ==2'd2)) begin
            change_r       <= 2'b0 ;
            sell_r         <= 1'b1 ;
        end
        else if (st_cur == GET15 && coin == 2'h2) begin
            change_r       <= 2'b1 ;
            sell_r         <= 1'b1 ;
        end
        else begin
            change_r       <= 2'b0 ;
            sell_r         <= 1'b0 ;
        end
    end
    assign       sell    = sell_r ;
    assign       change  = change_r ;

endmodule

case1 は0.5元硬貨を4回連続で投入する場合に対応する；case2 は1元 - 0.5元 - 1元の投入順序に対応する；case3 は0.5元 - 1元 - 0.5元の投入順序に対応する；case4 は0.5元を3回連続して投入し、その後1元を投入する順序に対応する。

module test ;

        clk = 0 ; #(CYCLE_200MHz/2) ;

    end

        //case(2) 1 -> 0.5 -> 1, taking change

            buy_oper  = buy_oper >> 2 ;
        end

        #16 ;

            coin      = buy_oper[1:0] ;
            buy_oper  = buy_oper >> 2 ;
        end

        //case(4) 0.5 -> 0.5 -> 0.5 -> 1, taking change

        repeat(5) begin

   //(1) mealy state with 3-stage

        .change           (change),
        .sell             (sell)
        );

      #100;

   end

ステートマシン変更：Moore型

Moore型ステートマシンを使用して自動販売機の動作フローを記述する場合、Mealy型ステートマシンの出力時の入力信号とステートマシンの状態を記述するために、さらに2つの状態エンコーディングを追加する必要がある。

3段式Moore型ステートマシンで記述した自動販売機のVerilogコードは次のとおりである：

例

module  vending_machine_moore    (
    input           clk ,
    input           rstn ,
    input [1:0]     coin ,     //01 for 0.5 jiao, 10 for 1 yuan

    output [1:0]    change ,
    output          sell    //output the drink
    );

    //machine state decode
    parameter            IDLE   = 3'd0 ;
    parameter            GET05  = 3'd1 ;
    parameter            GET10  = 3'd2 ;
    parameter            GET15  = 3'd3 ;
    // new state for moore state-machine
    parameter            GET20  = 3'd4 ;
    parameter            GET25  = 3'd5 ;

    //machine variable
    reg [2:0]            st_next ;
    reg [2:0]            st_cur ;

    //(1) state transfer
    always @(posedge clk or negedge rstn) begin
        if (!rstn) begin
            st_cur      <= 'b0 ;
        end
        else begin
            st_cur      <= st_next ;
        end
    end

    //(2) state switch, using block assignment for combination-logic
    always @(*) begin //all case items need to be displayed completely
        case(st_cur)
            IDLE:
                case (coin)
                    2'b01:     st_next = GET05 ;
                    2'b10:     st_next = GET10 ;
                    default:   st_next = IDLE ;
                endcase
            GET05:
                case (coin)
                    2'b01:     st_next = GET10 ;
                    2'b10:     st_next = GET15 ;
                    default:   st_next = GET05 ;
                endcase

            GET10:
                case (coin)
                    2'b01:     st_next = GET15 ;
                    2'b10:     st_next = GET20 ;
                    default:   st_next = GET10 ;
                endcase
            GET15:
                case (coin)
                    2'b01:     st_next = GET20 ;
                    2'b10:     st_next = GET25 ;
                    default:   st_next = GET15 ;
                endcase
            GET20:         st_next = IDLE ;
            GET25:         st_next = IDLE ;
            default:       st_next = IDLE ;
        endcase // case (st_cur)
    end // always @ (*)

   // (3) output logic,
   // one cycle delayed when using non-block assignment
    reg  [1:0]   change_r ;
    reg          sell_r ;
    always @(posedge clk or negedge rstn) begin
        if (!rstn) begin
            change_r       <= 2'b0 ;
            sell_r         <= 1'b0 ;
        end
        else if (st_cur == GET20 ) begin
            sell_r         <= 1'b1 ;
        end
        else if (st_cur == GET25) begin
            change_r       <= 2'b1 ;
            sell_r         <= 1'b1 ;
        end
        else begin
            change_r       <= 2'b0 ;
            sell_r         <= 1'b0 ;
        end
    end
    assign       sell    = sell_r ;
    assign       change  = change_r ;

endmodule

図からわかるように、出力信号はMealy型3段式ステートマシンと比較して1クロック周期遅延している。これは、追加されたエンコーディング状態のステートマシンに入るときに1クロック周期の遅延が必要なためである。このとき、出力に非ブロッキング代入を使用すると、最終的な出力信号が1クロック周期遅延することになる。これもMoore型ステートマシンの特徴である。

出力信号の代入時にブロッキング代入を使用すると、1クロック周期早めることができる。

出力ロジックの変更は次のとおりである。
