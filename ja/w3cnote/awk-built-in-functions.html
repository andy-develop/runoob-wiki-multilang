, ..., A[n] に分割し、n 変数の値を返します。この分割は、Ere パラメータで指定された拡張正規表現、または（Ere パラメータが指定されていない場合は）現在のフィールド区切り文字（FS 特殊変数）を使用して行われます。文脈が特定の要素が数値も持つべきことを示さない限り、A 配列の要素は文字列値で作成されます。

文字列関数

関数 説明 例
gsub( Ere, Repl, [ In ] ) gsub はグローバル置換（global substitution）の略です。正規表現のすべての具体的な値が置き換えられる点を除いて、sub 関数とまったく同じように実行されます。 
$ awk 'BEGIN {
    str = "Hello, World"

    print "String before replacement = " str

    gsub("World", "Jerry", str)

    print "String after replacement = " str
}'

出力結果は次のとおりです：

String before replacement = Hello, World
String after replacement = Hello, Jerry
sub(regex,sub,string) sub 関数は一度だけ部分文字列の置換を実行します。最初に出現する部分文字列を regex で置き換えます。3 番目のパラメータは省略可能で、デフォルトは $0 です。 
$ awk 'BEGIN {
    str = "Hello, World"

    print "String before replacement = " str

    sub("World", "Jerry", str)

    print "String after replacement = " str
}'

出力結果は次のとおりです：

String before replacement = Hello, World
String after replacement = Hello, Jerry
substr(str, start, l) substr 関数は、str 文字列の start 番目の文字から始まる長さ l の部分文字列を返します。l の値が指定されていない場合、str の start 番目の文字から始まる末尾の部分文字列を返します。 
$ awk 'BEGIN {
    str = "Hello, World !!!"
    subs = substr(str, 1, 5)

    print "Substring = " subs
}'

出力結果は次のとおりです：

Substring = Hello

$ awk 'BEGIN {
    str = "One Two Three"
    subs = "Two"

    ret = index(str, subs)

    printf "Substring \"%s\" found at %d location.\n", subs, ret
}'

出力結果は次のとおりです：

Substring "Two" found at 5 location.
length [(String)] String パラメータで指定された文字列の長さ（文字単位）を返します。String パラメータが指定されていない場合は、レコード全体の長さ（$0 レコード変数）を返します。 
$ awk 'BEGIN {

    print "Length = ", length(str)
}'

出力結果は次のとおりです：

Substring "Two" found at 5 location.
blength [(String)] String パラメータで指定された文字列の長さ（バイト単位）を返します。String パラメータが指定されていない場合は、レコード全体の長さ（$0 レコード変数）を返します。  
substr( String, M, [ N ] ) N パラメータで指定された文字数を持つ部分文字列を返します。部分文字列は String パラメータで指定された文字列から取得され、その文字は M パラメータで指定された位置から始まります。M パラメータでは、String パラメータの最初の文字を番号 1 とします。N パラメータが指定されていない場合、部分文字列の長さは、M パラメータで指定された位置から String パラメータの末尾までの長さになります。 
$ awk 'BEGIN {
    str = "Hello, World !!!"

    print "Substring = " subs
}'

出力結果は次のとおりです：

Substring = Hello
match( String, Ere ) String パラメータで指定された文字列（Ere パラメータで指定された拡張正規表現が出現する場所）において、1 から始まる位置（文字単位）を返します。Ere パラメータが出現しない場合は 0（ゼロ）を返します。RSTART 特殊変数は戻り値に設定されます。RLENGTH 特殊変数はマッチした文字列の長さに設定され、マッチが見つからない場合は -1（マイナス 1）に設定されます。 
$ awk 'BEGIN {

}'

出力結果は次のとおりです：

Substring "Two" found at 5 location.

注：Ere部分は正規表現にすることができます。

1、gsub、sub の使用

$ awk 'BEGIN{info="this is a test2012test!";gsub(/[0-9]+/,"||",info);print info}'
this is a test||test!

2、文字列の検索（index の使用）

三項演算子を使用しています：式 ? アクション1 : アクション2

$ awk 'BEGIN{info="this is a test2012test!";print index(info,"11111")?"ok":"no found";}'
no found
$ awk 'BEGIN{info="this is a test2012test!";print index(info,"is")?"ok":"no found";}'
ok
$ awk 'BEGIN{info="this is a test2012test!";print index(info,"test")?"ok":"no found";}'
ok

3、正規表現マッチング検索（match の使用）

$ awk 'BEGIN{info="this is a test2012test!";print match(info,/[0-9]+/)?"ok":"no found";}'
ok

4、部分文字列の切り出し（substr の使用）

4 番目の文字から始めて、長さ 10 の文字列を切り出します。

$ awk 'BEGIN{info="this is a test2012test!";print substr(info,4,10);}'
s is a tes

5、文字列の分割（split の使用）

$ awk 'BEGIN{info="this is a test";split(info,tA," ");print length(tA);for(k in tA){print k,tA[k];}}'
4
2 is
3 a
4 test
1 this

info を分割し、info 文字列をスペースで動的配列 tA に分割します。awk の for...in ループは順序が保証されないループであることに注意してください。配列の添字 1...n の順にはならないため、使用時には特に注意が必要です。

6、文字列のフォーマット出力（sprintf の使用）

このうち、フォーマット文字列は 2 つの部分から構成されます。1 つは通常の文字で、これらの文字はそのまま出力されます。もう 1 つはフォーマット指定文字で、%始まり、その後に 1 つまたは複数の規定文字が続き、出力内容のフォーマットを決定します。特に注意が必要なのは、使用printf時、デフォルトでは改行されません。一方、print関数はデフォルトで各行の末尾に\n改行文字を追加します。

フォーマット指定子 説明
%d 10 進符号付き整数
%u 10 進符号なし整数
%f 浮動小数点数
%s 文字列
%c 単一文字
%p ポインタの値
%e 指数形式の浮動小数点数
%x %X 符号なし 16 進数で表される整数
%o 符号なし 8 進数で表される整数
%g 自動的に適切な表現を選択します 
$ awk 'BEGIN{n1=124.113;n2=-1.224;n3=1.2345; printf("%.2f,%.2u,%.2g,%X,%o\n",n1,n2,n3,n1,n1);}'
124.11,4294967295,1.2,7C,174
$  awk 'BEGIN{n1=124.113;n2=-1.224;n3=1.2645; printf("%.2f,%.2u,%.2g,%X,%o\n",n1,n2,n3,n1,n1);}'
124.11,4294967295,1.3,7C,174

注：上記の n3 の出力値を見るとわかるように、printf を使用して処理する際の比較的スマートな機能は、四捨五入して小数点以下の桁数を保持できることです。

strftime の日付と時刻のフォーマット指定子：

番号 説明
%a 曜日の略称（Mon-Sun）。
%A 曜日のフルネーム（Monday-Sunday）。
%b 月の略称（Jan）。
%B 月のフルネーム（January）。
%c ローカルの日付と時刻。
%C 年の世紀部分。その値は年を 100 で割った整数です。
%d 10 進数の日（01-31）
%D %m/%d/%y と同等です。
%e 日付。1 桁の場合はスペースで補完されます。
%F %Y-%m-%d と同等です。これは ISO 8601 標準の日付フォーマットでもあります。
%g ISO8610 標準週の属する年を 100 で割った余り（00-99）。たとえば、1993 年 1 月 1 日は 1992 年の第 53 週に属します。したがって、1993 年の第 1 日ですが、その ISO8601 標準週の属する年は 1992 です。同様に、1973 年 12 月 31 日は 1973 年に属しますが、1994 年の第 1 週に属します。したがって、1973 年 12 月 31 日の ISO8610 標準週の属する年は 1974 であり、1973 ではありません。
%G ISO 標準週が属する年のフル表記。
%h %b と同等。
%H 10進数で表す24時間形式の時（00-23）
%I 10進数で表す12時間形式の時（00-12）
%j 1年のうちの通算日（001-366）
%m 月（01-12）
%M 分（00-59）
%n 改行文字（ASCII LF）
%p 12時間表記（AM/PM）
%r 12時間表記の時刻（%I:%M:%S %p と同等）。
%R %H:%M と同等。
%S 時刻の秒の値（00-60）
%t タブ文字（tab）
%T %H:%M:%S と同等。
%u 数字で表す曜日（1-7）、1は月曜日。
%U 1年のうちの週番号（最初の日曜日を第1週の開始とする）、00-53
%V 1年のうちの週番号（最初の月曜日を第1週の開始とする）、01-53。
%w 数字で表す曜日（0-6）、0は日曜日。
%W 10進数で表す1年のうちの週番号（最初の月曜日を第1週の開始とする）、00-53。
%x ローカルの日付表現
%X ローカルの時刻表現
%y 年を100で割った余り。
%Y 10進数で表す完全な年。
%z タイムゾーン。+HHMM 形式で表します（例：RFC 822 または RFC 1036 の時刻ヘッダーを生成する場合の形式）
%Z タイムゾーン名または略称。タイムゾーンが未確定の場合は出力されません。

関数名 説明 例
close(expr) パイプのファイルを閉じる 
$ awk 'BEGIN {
    cmd = "tr [a-z] [A-Z]"

  • 4番目のステートメント cmd |& getline out は、getline 関数を使用して出力を out 変数に格納します。
  • 次の出力ステートメントは出力内容を出力し、最後に close 関数が cmd を閉じます。

Two

Four

flush 開いているファイルまたはパイプのバッファをフラッシュします  
getline 次の行を読み込みます

getline を使用してファイル marks.txt から1行読み込み、出力します：

$ awk '{getline; print $0}' marks.txt

、AWK はファイル marks.txt から1行読み込んで変数 0 に格納します。次のステートメントでは、getline を使用して次の行を読み込みます。したがって、AWK は2行目を読み込んで変数 0 に格納します。最後に、AWK は print を使用して2行目の内容を出力します。この処理はファイルの終端まで続きます。
next 現在のレコードの処理を停止し、次のレコードの処理に移ります。

パターンが正常にマッチした場合、プログラムは何も実行しません：

$ awk '{if ($0 ~/Shyam/) next; print $0}' marks.txt
nextfile 現在のファイルの処理を停止し、次のファイルの最初のレコードから処理を開始します。

file2:str1
file2:str2
file2:str3
file2:str4

それでは nextfile 関数をテストしてみましょう。

$ awk '{ if ($0 ~ /file1:str2/) nextfile; print $0 }' file1.txt file2.txt

出力結果は次のとおりです：

file1:str1
file2:str1
file2:str2
file2:str3
file2:str4
return ユーザー定義関数から値を返します。戻り値が指定されていない場合、戻り値は未定義であることに注意してください。

ファイル functions.awk を作成します。内容は次のとおりです：

function addition(num1, num2)

    return result
}

BEGIN {

このファイルを実行します：

$ awk -f functions.awk
