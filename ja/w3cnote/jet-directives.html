2.2 Jet ディレクティブ

カテゴリ JMR 使用チュートリアル

Jetディレクティブは、テンプレートページ全体に関連する属性を設定するために使用されます。例えば、コンパイルディレクティブやインポートディレクティブなどです。

コンパイルディレクティブ

テンプレートファイルの最初の行にはコンパイルディレクティブがあります。JetテンプレートはJavaクラスにコンパイルされ、その原理はJSPがJavaクラスにコンパイルされるのと似ています。
コンパイルクラスは、このJavaクラスのパッケージ名とクラス名を指定します。開発者は具体的なコンパイルクラスを気にする必要はありません。

コンパイルディレクティブの構文形式：

<%@jet package="包名" class="类名" ...  %>

含まれる属性

  • package（必須）：コンパイルするパッケージ名です。新規作成時はデフォルトでtranslatedになりますが、XX.XX.XXのパッケージ構造にカスタマイズできます。
  • class（必須）：コンパイルするクラス名です。Javaの命名規約に従ってクラス名を入力してください。
  • startTag、endTag（オプション）：JetのデフォルトのstartTagは <%、endTagは %> です。これらを再指定できます。

生成されたコードに <% と %> が含まれる場合、例えばJSPでは、コード内の <% と %> がテンプレート内の <% と %> と競合します。このような場合は、startTagとendTagを変更できます。

次の例では、<% と %> を <$ と $> に置き換えています。これにより、<%%> はそのまま生成されます。

別の方法として、エスケープ文字「\」を使用し、<% と %> を <\% と \%> に変更すると、<%%> もそのまま生成できます。

インポートディレクティブ

使用するJavaクラスをインポートします。Jetテンプレートが置かれているプロジェクトの依存関係はすべてインポートできます。
