C# における foreach ループの使い方

カテゴリ プログラミング技術

foreachループは、コレクション内のすべての要素を列挙するために使用されます。foreach文の式は、キーワードinで区切られた2つの項目から構成されます。inの右側の項目はコレクション名、inの左側の項目は変数名で、そのコレクションの各要素を格納するために使用します。

このループの実行プロセスは次のとおりです。ループのたびに、コレクションから新しい要素の値を取り出し、読み取り専用変数に格納します。括弧内の式全体の戻り値がtrueの場合、foreachブロック内の文が実行されます。コレクション内のすべての要素がアクセスされると、式全体の値がfalseになり、制御フローはforeachブロックの後の実行文に移ります。

foreach文はよく配列と一緒に使用されます。次の例では、foreach文を使用して配列の値を読み取り、表示します。

配列のプロパティ：Array.Length 配列の容量

このプロパティを利用すると、配列オブジェクトが格納できる容量値、すなわち配列の長さ、要素数を取得できます。これは理解しやすいでしょう。配列には他にも、配列の次元数などのプロパティがあります。プロパティの使い方は比較的簡単で、一つ覚えれば、他の形式もほぼ同じです。ここでは例を挙げません。

配列の次元や容量が多い場合、C# はコレクション/配列内のすべての要素を読み取るためのforeach文を提供しています。この機能を「走査（トラバース）」と呼びます。構文は次のとおりです。

配列の走査：foreach（type objName in collection/Array）

この文は、配列に格納されている変数の値を一つずつチェックし、一つずつ取り出します。ここでtypeは、読み取る配列オブジェクトの値をobjName変数に格納するためのデータ型です。objNameはtype型の変数名であり、毎回のループでコレクションや配列（collection/Array）から取得した要素を表します。collection/Arrayは、アクセスする配列オブジェクトです。この方法を使えば、foreachを1つ書くだけで、ジャグ配列（交差配列）を除くすべての次元の配列を走査できます。

注：objNameのデータ型typeは、collection/Arrayオブジェクトの型と同じか、それより大きい（より広い）型でなければなりません。

次に、foreachとforを使用して規則的配列を走査する例を挙げます。配列の次元を取得する方法も登場します。foreachが規則的配列を一度に走査する際の利点を比較します。

例

int[,,] a = new int[2, 2, 2] { {{ 1, 2 }, { 3,4}},{{ 5, 6 }, { 7,8}} };// 2行2列2深さの3次元配列aを定義する
for (int i = 0; i < a.GetLength (0) ;i++ )   //Array.GetLength(n)を使用して、配列[0,1,,,n]の次元の要素数を取得する。0は行、1は列、nはこの配列がn+1次元であることを表す
{
    for (int j = 0; j < a.GetLength(1); j++)
    {
        for (int z = 0; z < a.GetLength(2);z++ )//2は深さ方向の要素数を取得することを表す。配列がn次元ならn個のforループを書く必要がある
        {
            Console.WriteLine(a[i,j,z]);
        }
    }
}

foreachループでa配列を一度に走査する

例

int[,,] a = new int[2, 2, 2] { {{ 1, 2 }, { 3,4}},{{ 5, 6 }, { 7,8}} };//2行2列2深さの3次元配列aを定義する
foreach(int i in a)
{
    Console .WriteLine (i);
}

これら2つのコードの実行結果は同じです。それぞれ各行に1つの要素、合計8行で、要素はそれぞれ1 2 3 4 5 6 7 8です。

次に、forループとforeachループを使った配列要素の読み書きの例をもう一つ見てみましょう。まずユーザーに学生の人数を入力するよう促し、その学生数を学生の名前を格納する配列namesの要素数とします。forループを使用して、配列のインデックスiを0から始めて「学生の名前を入力してください」というプロンプトを繰り返し出力し、ユーザーが入力した学生の名前を配列のインデックス方式names[i]でnames配列に格納します。forループの最大回数（すなわちインデックスの最大値）は、配列プロパティ.Lengthによって取得します。先ほど説明したように、容量とインデックスの関係はindex=Array.Length-1であり、この問題ではiの最大値がこれに該当します。

注意しなければならないのは、foreachを利用すると、配列内の要素を一つずつ取得できるだけで、この文を使って配列に格納されている要素を変更することはできないということです。

例

using System;
class Program
{
    static void Main()
    {
        int count;
        Console.WriteLine("登録する学生数を入力してください");
        count = int.Parse(Console.ReadLine());
        string[]names = new string[count];
        for (int i = 0; i < names.Length; i++)
        {
            Console.WriteLine("第{0}番目の学生の名前を入力してください", i + 1);
            names[i] = Console.ReadLine();
        }
        Console.WriteLine("登録済みの学生は以下のとおりです");
        foreach (string name in names)
        {
            Console.WriteLine("{0}", name);
        }
        Console.ReadKey();
    }
}
