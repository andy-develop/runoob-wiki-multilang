C++におけるconst参照、定数へのポインタ、constポインタの違い

分類 プログラミング技術

まず、参照とポインタに関するいくつかの注意事項を理解しておこう。

  • 参照はオブジェクトではない
  • 参照は必ず初期化しなければならない
  • 参照はオブジェクトにのみバインドでき、リテラル値や何らかの式の計算結果にバインドすることはできない
  • 型は厳密に一致させなければならない
int &a = 10;             //错误：引用类型的初始值必须是一个对象  
  
double a = 3.14;  
int &b = a;              //错误：此处引用类型的初始值必须是int型对象

ポインタ自体はオブジェクトである

ポインタの型は、それが指すオブジェクトと厳密に一致しなければならない

double dval;  
double *pd = &dval;      //正确  
double *pd2 = pd;        //正确  
  
int *pi = pd;            //错误：指针pi的类型和pd的类型不匹配  
pi = &dval;              //错误：试图把double型对象的地址赋给int型指针

例外がある：const修飾子を導入する場合

const参照

const参照を初期化するときは、任意の式を初期値として使用することができる

int i = 42;  
const int &r1 = i;       //正确：允许将const int & 绑定到一个普通int对象上  
const int &r2 = 42;      //正确  
const int &r3 = r1 * 2;  //正确  
int &r4 = r1 * 2;        //错误  
  
double dval = 3.14;  
const int &ri = dval;    //正确  
//等价于  
const int temp = dval;  
const int &ri = temp;  
  
int i = 42;  
int &r1 = i;  
const int &r2 = i;  
r1 = 0;                  //正确  
r2 = 0;                  //错误

constポインタ

定義：別名「定数ポインタ」とも呼ばれ、「定数のポインタ」と理解できる。つまり、これはポインタであるが、指しているのは定数であり、この定数とはポインタの値（アドレス）のことであり、アドレスが指す値のことではない。

重要なポイント：

  • 1. constポインタが指すオブジェクトは、このポインタを介して変更することはできないが、元の宣言を介して変更することはできる。
  • 2. constポインタには変数のアドレスを代入できる。constポインタと呼ばれるのは、このポインタを介して変数の値を変更することを制限しているためである。
  • 3. ポインタは他の場所も指すことができる。ポインタ自体は単なる変数であり、任意のアドレスを指すことができるからである。
　

コード形式：

  1. 定数へのポインタ（const int* ptr）：ポインタが指す内容は定数であり、そのポインタを介して変更することはできない。ただし、ポインタ自体（つまりポインタが保持するアドレス）は変更できる。

  2. constポインタ（int* const ptr）：ポインタ自体（つまりポインタが保持するアドレス）は定数であり、変更できない。ただし、ポインタが指す内容は変更できる。

  3. 定数へのconstポインタ（const int* const ptr）：ポインタ自体（つまりポインタが保持するアドレス）とポインタが指す内容はどちらも定数である。ポインタのアドレスも指す内容も変更できない。

constポインタ

定義：本質は定数であり、それをポインタで修飾したものである。その値自体（つまりポインタのアドレス）は定数であり、変更できない。言い換えれば、ポインタ変数は初期化後、常に同じアドレスを指し続ける。ポインタのアドレスは固定されているが、ポインタが指す内容は、ポインタを介して変更することができる。

重要なポイント：ポインタ自体（つまりポインタが保持するアドレス）は定数であり、変更できないが、ポインタが指す内容は変更できる。

　

コード形式：

int* const p;

定数へのconstポインタ

定義：定数を指すポインタ定数は、それ自体が定数であり、かつ、それが指すオブジェクトも定数である。

重要なポイント：

  • 1. 1つのポインタ定数は、ポインタオブジェクトを指している。
  • 2. それが指すポインタオブジェクトは定数でもあり、つまり、それが指すオブジェクトは変更できない。

コード形式：

const int* const p;

では、これらの種類をどのように区別するのか？ constが2つ付いているものは間違いなく定数へのconstポインタであり、理解しやすい。主に問題なのは、constポインタとポインタ定数をどのように区別するかである。

1つの方法は、* と const の並び順を見ることである。例えば

int const* p;    //const * 即常量指针
const int* p;    //const * 即常量指针
int* const p;    //* const 即指针常量

もう1つの方法は、constがどちらに近いかを見ることである。つまり、右から左へ見ていく。例えば

int const* p;    //const修饰的是*p，即*p的内容不可通过p改变，但p不是const，p可以修改，*p不可修改；
const int* p;    //同上
int* const p;    //const修饰的是p，p是指针，p指向的地址不能修改，p不能修改，但*p可以修改；

実例

//-------常量指针-------
const int *p1 = &a;
a = 300;     //OK,仍然可以通过原来的声明修改值，
//*p1 = 56;  //Error,*p1是const int的，不可修改，即常量指针不可修改其指向地址
p1 = &b;     //OK,指针还可以指向别处，因为指针只是个变量，可以随意指向；

//-------指针常量-------//
int*  const p2 = &a;
a = 500;     //OK,仍然可以通过原来的声明修改值，
*p2 = 400;   //OK,指针是常量，指向的地址不可以变化,但是指向的地址所对应的内容可以变化
//p2 = &b;     //Error,因为p2是const 指针，因此不能改变p2指向的内容

//-------指向常量的常量指针-------//
const int* const p3 = &a;
//*p3 = 1;    //Error
//p3 = &b;    //Error
a = 5000;    //OK,仍然可以通过原来的声明修改值

実際の応用では、constポインタはポインタ定数よりも使用頻度が高い。例えば、constポインタは関数の引数渡しでよく使われ、関数内部での内容の変更を防ぐ。

size_t strlen(const char* src); //常量指针，src的值不可改变；
char a[] = "hello";
char b[] = "world";
size_t a1 = strlen(a);
size_t b1 = strlen(b);

a、bは変更可能であるが、strlen関数の内部ではa、bの内容が変更されないことを保証できる。

ヌルポインタ、ダングリングポインタ

ポインタについて述べたので、ついでにヌルポインタとダングリングポインタの問題を説明しよう。

ヌルポインタとは、格納しているアドレスが空であるポインタのことである。ポインタを使用するときは、必ず先にヌルポインタかどうかを判断しなければならない。多くの問題は、この判断を怠ったために発生する。

ダングリングポインタは、ポインタをdeleteした後に0を代入しなかったために、ポインタが任意のメモリアドレスを指してしまうものである。使い続けると、予測不能なメモリエラーを引き起こす。

また、ポインタの誤用はバグやメモリリークを引き起こしやすい。

コードを見てみよう：

//-------空指针-------//
int *p4 = NULL;
//printf("%d",*p4); //运行Error，使用指针时必须先判断是否空指针

//-------野指针（悬浮、迷途指针）-------//
int *p5 = new int(5);
delete p5;
p5 = NULL; //一定要有这一步
printf("%d",*p5);  //隐藏bug，delete掉指针后一定要置0，不然指针指向位置不可控，运行中可导致系统挂掉

//-------指针的内存泄漏-------//
int *p6 = new int(6);
p6 = new int(7); //p6原本指向的那块内存尚未释放，结果p6又指向了别处，原来new的内存无法访问，也无法delete了，造成memory leak
