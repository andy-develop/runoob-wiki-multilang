PHP基礎知識まとめ

カテゴリ プログラミング技術

  • PHPはPHP: Hypertext Preprocessorを表します
  • PHPファイルにはテキスト、HTML、JavaScriptコード、PHPコードを含めることができます
  • PHPコードはサーバー上で実行され、結果は純粋なHTML形式でブラウザに返されます
  • PHPファイルのデフォルトの拡張子は「.php」です

PHPでできること

  • PHPは動的なページコンテンツを生成できます
  • PHPはサーバー上のファイルの作成、開く、読み取り、書き込み、閉じるができます
  • PHPはフォームデータを収集できます
  • PHPはCookieを送受信できます
  • PHPはデータベース内のデータを追加、削除、変更できます
  • PHPはユーザーがウェブサイト上の一部のページにアクセスするのを制限できます
  • PHPはデータを暗号化できます

インストール

サーバーがPHPをサポートしていない場合は、次の操作が必要です：

  1. Webサーバーをインストールする
  2. PHPをインストールする
  3. データベース（例：MySQL）をインストールする
    公式PHPサイト（PHP.net）にPHPのインストール手順があります：http://php.net/manual/en/install.php

統合開発環境としてはWAMPを推奨します：http://www.wampserver.com/

PHP変数

変数は$記号で始まり、その後に変数名が続きます

PHPには変数を宣言するコマンドはありません。

変数は最初に値を代入したときに作成されます：

PHPは弱い型付けの言語です

強い型付けのプログラミング言語では、変数を使用する前に変数の型と名前を宣言（定義）する必要があります。

PHP変数のスコープ

PHPには4つの異なる変数スコープがあります：

  • local
  • global
  • static
  • parameter

ローカルスコープとグローバルスコープ

すべての関数の外部で定義された変数はグローバルスコープを持ちます。関数以外では、グローバル変数はスクリプトの任意の部分からアクセスできます。関数内でグローバル変数にアクセスするには、globalキーワードを使用する必要があります。

PHP関数内で宣言された変数はローカル変数であり、関数内でのみアクセスできます：

<?php
$x=5; // 全局变量

function myTest()
{
    $y=10; // 局部变量
    echo "<p>测试变量在函数内部:<p>";
    echo "变量 x 为: $x";
    echo "<br>";
    echo "变量 y 为: $y";
} 

myTest();

echo "<p>测试变量在函数外部:<p>";
echo "变量 x 为: $x";
echo "<br>";
echo "变量 y 为: $y";
?>

関数内で関数外に定義されたグローバル変数を呼び出すには、関数内の変数の前にglobalキーワードを付ける必要があります：

<?php
$x=5;
$y=10;

function myTest()
{
    global $x,$y;
    $y=$x+$y;
}

myTest();
echo $y; // 输出 15
?>

PHPはすべてのグローバル変数を$GLOBALS[index]という名前の配列に格納します。indexには変数名が格納されます。この配列は関数内でアクセスでき、グローバル変数を直接更新するためにも使えます。

<?php
$x=5;
$y=10;

function myTest()
{
    $GLOBALS['y']=$GLOBALS['x']+$GLOBALS['y'];
} 

myTest();
echo $y;
?>

関数の実行が完了すると、そのすべての変数は通常削除されます。しかし、特定のローカル変数を削除したくない場合があります。その場合は使用できますstaticキーワード

<?php

function myTest()
{
    static $x=0;
    echo $x;

?>

echoとprintはどちらも言語構造であり、使用時に括弧を付けなくても、括弧を付けても構いません：echoまたはecho()、printまたはprint()。

?>

定数

定数は単純な値の識別子です。この値はスクリプト内で変更できません。（定数名には$修飾子を付ける必要はありません。）

注意：定数はスクリプト全体で使用できます。

定数を設定するには、define()関数を使用します。関数の構文は次のとおりです：

define(string constant_name, mixed value, case_sensitive = true)
この関数には3つのパラメータがあります：

  • constant_name：必須パラメータ、定数名、つまり識別子です。
  • value：必須パラメータ、定数の値です。
  • case_sensitive：オプションのパラメータで、大文字小文字を区別するかどうかを指定します。trueに設定すると区別しません。

次の例では、大文字小文字を区別する定数を作成します。定数値は"Welcome to runoob.com!"です：

<?php
define("GREETING", "Welcome to runoob.com!");
echo GREETING;
?>

マジック変数

8つのマジック定数があり、その値はコード内の位置によって変わります。

  • _LINE__
    ファイル内の現在の行番号。
  • FILE
    ファイルの完全パスとファイル名。インクルードされたファイル内で使用された場合は、インクルードされたファイルのファイル名を返します。
  • DIR
    ファイルが存在するディレクトリ。インクルードされたファイル内で使用された場合は、インクルードされたファイルが存在するディレクトリを返します。
  • FUNCTION
    関数名（PHP 4.3.0 で追加）。PHP 5 以降、この定数は関数が定義されたときの名前（大文字小文字を区別）を返します。PHP 4 では、この値は常に小文字でした。
<?php
function test() {
    echo  '函数名为：' . __FUNCTION__ ;
}
test();
?>
  • CLASSクラス名（PHP 4.3.0 で追加）。PHP 5 以降、この定数はクラスが定義されたときの名前（大文字小文字を区別）を返します。

PHP 4 では、この値は常に小文字でした。クラス名には、宣言されたスコープ（例: Foo\Bar）が含まれます。注意：PHP 5.4 以降、CLASStrait にも作用します。trait メソッド内で使用された場合、CLASSその trait メソッドを呼び出したクラスの名前です。

<?php
class test {
    function _print() {
        echo '类名为：'  . __CLASS__ . "<br>";
        echo  '函数名为：' . __FUNCTION__ ;
    }
}
$t = new test();
$t->_print();
?>
  • TRAITTrait の名前（PHP 5.4.0 で追加）。PHP 5.4.0 以降、PHP ではコード再利用の方法として trait が実装されています。

Trait 名には、宣言されたスコープ（例: Foo\Bar）が含まれます。

基底クラスから継承したメンバーは、挿入された SayWorld Trait の MyHelloWorld メソッドによって上書きされます。その動作は MyHelloWorld クラスで定義されたメソッドと一致します。優先順位は、現在のクラスのメソッドが trait メソッドを上書きし、trait メソッドが基底クラスのメソッドを上書きします。

<?php
class Base {
    public function sayHello() {
        echo 'Hello ';
    }
}

trait SayWorld {
    public function sayHello() {
        parent::sayHello();
        echo 'World!';
    }
}

class MyHelloWorld extends Base {
    use SayWorld;
}

$o = new MyHelloWorld();
$o->sayHello();
?>
  • METHODクラスのメソッド名（PHP 5.0.0 で追加）。このメソッドが定義されたときの名前（大文字小文字を区別）を返します。
<?php
function test() {
    echo  '函数名为：' . __METHOD__ ;
}
test();
?>
  • NAMESPACE現在の名前空間の名前（大文字小文字を区別）。この定数はコンパイル時に定義されます（PHP 5.3.0 で追加）。
<?php
namespace MyProject;

echo '命名空间为："', __NAMESPACE__, '"'; // 输出 "MyProject"
?>

名前空間

PHP の名前空間（namespace）は PHP 5.3 で追加されました。C# や Java を学んだことがあれば、名前空間は新しいものではありません。しかし、PHP では依然として非常に重要な意味を持ちます。

PHP の名前空間は、次の 2 種類の問題を解決できます。

  • ユーザーコードと PHP 内部のクラス/関数/定数との間の名前の衝突。
  • エイリアス（または短い）名前を作成し、ソースコードの可読性を向上させます。

デフォルトでは、すべての定数、クラス、関数名はグローバル空間に置かれます。これは PHP が名前空間をサポートする前と同じです。
ファイルに名前空間が含まれる場合、他のすべてのコードより前に名前空間を宣言する必要があります。

< ?php  
// 定义代码在 'MyProject' 命名空间中  
namespace MyProject;  
 
// ... 代码 ...  

//也可以在同一个文件中定义不同的命名空间代码
namespace MyProject1;  
// MyProject1 命名空间中的PHP代码  
 
namespace MyProject2;  
// MyProject2 命名空间中的PHP代码    
 
// 另一种语法
namespace MyProject3 {  
 // MyProject3 命名空间中的PHP代码    
}  

?>

名前空間を宣言する前に合法なコードは、ソースファイルのエンコーディングを定義する declare 文だけです。空白文字を含むすべての非 PHP コードは、名前空間の宣言より前に出現できません。

<?php
declare(encoding='UTF-8'); //定义多个命名空间和不包含在命名空间中的代码
namespace MyProject {
    const CONNECT_OK = 1;
    class Connection { /* ... */ }
    function connect() { /* ... */  }
}

namespace { // 全局代码
    session_start();
    $a = MyProject\connect();
    echo MyProject\Connection::start();
}
?>

名前空間の使用
PHP の名前空間内のクラス名は、次の 3 つの方法で参照できます。

  1. 非修飾名、またはプレフィックスを含まないクラス名。例: $a=new foo(); や foo::staticmethod();。現在の名前空間が currentnamespace の場合、foo は currentnamespace\foo として解決されます。foo を使用するコードがグローバルで、いずれの名前空間にも含まれていない場合、foo は foo として解決されます。警告: 名前空間内の関数または定数が定義されていない場合、その非修飾の関数名または定数名はグローバル関数名または定数名として解決されます。~~名前空間プレフィックスなしの参照。デフォルトで現在の名前空間で検索し、次にグローバル名前空間で検索します。

  2. 修飾名、またはプレフィックスを含む名前。例: $a = new subnamespace\foo(); や subnamespace\foo::staticmethod();。現在の名前空間が currentnamespace の場合、foo は currentnamespace\subnamespace\foo として解決されます。foo を使用するコードがグローバルで、いずれの名前空間にも含まれていない場合、foo は subnamespace\foo として解決されます。~~相対名前空間プレフィックス付きの（相対パスのような）参照。呼び出しコードが存在する名前空間を自動的に先頭に追加します。

  3. 完全修飾名、またはグローバルプレフィックス演算子を含む名前。例: $a = new \currentnamespace\foo(); や \currentnamespace\foo::staticmethod();。この場合、foo は常にコード内のリテラル名（literal name）currentnamespace\foo として解決されます。~~絶対名前空間プレフィックス付きの参照（絶対パスのようなもの）。参照パスが明確であるため、検索は不要です。

<?php

include 'file1.php';

{
    static function staticmethod() {}
}

foo::staticmethod(); // 解析为类 Foo\Bar\foo的静态方法staticmethod。

/* 限定名称 */
subnamespace\foo(); // 解析为函数 Foo\Bar\subnamespace\foo
subnamespace\foo::staticmethod(); // 解析为类 Foo\Bar\subnamespace\foo,
                                  // 以及类的方法 staticmethod
echo subnamespace\FOO; // 解析为常量 Foo\Bar\subnamespace\FOO
                                  
/* 完全限定名称 */
\Foo\Bar\foo(); // 解析为函数 Foo\Bar\foo
\Foo\Bar\foo::staticmethod(); // 解析为类 Foo\Bar\foo, 以及类的方法 staticmethod
echo \Foo\Bar\FOO; // 解析为常量 Foo\Bar\FOO
?>

名前空間と動的言語機能

PHP の名前空間の実装は、言語自体の動的な特徴の影響を受けます。そのため、次のコードを名前空間に変換する場合は、要素に動的にアクセスします。

//example.php

<?php
class classname
{
    function __construct()
    {
        echo __METHOD__,"\n";
    }
}
function funcname()
{
    echo __FUNCTION__,"\n";
}
const constname = "global";

$a = 'classname';
$obj = new $a; // prints classname::__construct
$b = 'funcname';
$b(); // prints funcname
echo constant('constname'), "\n"; // prints global
?>
<?php
namespace namespacename;
class classname
{
    function __construct()
    {
        echo __METHOD__,"\n";
    }
}
function funcname()
{
    echo __FUNCTION__,"\n";
}
const constname = "namespaced";

include 'example1.php';//全局命名空间和某个命名空间有相同类 函数 和 常量 分别区别访问

$a = 'classname';
$obj = new $a; // prints classname::__construct
$b = 'funcname';
$b(); // prints funcname
echo constant('constname'), "\n"; // prints global

/* note that if using double quotes, "\\namespacename\\classname" must be used */
$a = '\namespacename\classname';
$obj = new $a; // prints namespacename\classname::__construct
$a = 'namespacename\classname';
$obj = new $a; // also prints namespacename\classname::__construct
$b = 'namespacename\funcname';

$b = '\namespacename\funcname';
$b(); // also prints namespacename\funcname
echo constant('\namespacename\constname'), "\n"; // prints namespaced
echo constant('namespacename\constname'), "\n"; // also prints namespaced
?>

名前空間の使用：グローバル関数/定数へのフォールバック

名前空間内で、PHP が非修飾のクラス、関数、または定数名に遭遇した場合、その名前を解決するために異なる優先戦略を使用します。

  • クラス名は常に現在の名前空間内の名前に解決されます（見つからない場合はエラーになります）。したがって、システム内部または名前空間に含まれていないクラス名にアクセスする場合は、完全修飾名を使用する必要があります。
  • 関数と定数については、現在の名前空間に関数または定数が存在しない場合、PHP はグローバル空間の関数または定数を使用します。
<?php
namespace A\B\C;
class Exception extends \Exception {}

$a = new Exception('hi'); // $a 是类 A\B\C\Exception 的一个对象
$b = new \Exception('hi'); // $b 是类 Exception 的一个对象

$c = new ArrayObject; // 致命错误, 找不到 A\B\C\ArrayObject 类
?>

グローバル空間
名前空間が定義されていない場合、すべてのクラスと関数の定義はグローバル空間に置かれます。これは PHP が名前空間の概念を導入する前と同じです。名前の前にプレフィックス \ を付けると、その名前がグローバル空間の名前であることを示します。その名前が他の名前空間にある場合でも同様です。

<?php
namespace A\B\C;

/* 这个函数是 A\B\C\fopen */
function fopen() { 
     /* ... */
     $f = \fopen(...); // 调用全局的fopen函数
     return $f;
} 
?>

PHPファイル処理

ファイルを開く

$file = fopen($fname, mode) //ファイル名、オープンモード

  • r 読み取り専用。ファイルの先頭から開始します。
  • r+ 読み取り/書き込み。ファイルの先頭から開始します。
  • w 書き込み専用。ファイルを開いて内容を空にします。ファイルが存在しない場合は、新しいファイルを作成します。
  • w+ 読み取り/書き込み。ファイルを開いて内容を空にします。ファイルが存在しない場合は、新しいファイルを作成します。
  • a 追記。ファイルを開いてファイルの末尾に書き込みます。ファイルが存在しない場合は、新しいファイルを作成します。
  • a+ 読み取り/追記。ファイルの末尾に書き込むことで、ファイルの内容を保持します。
  • x 書き込み専用。新しいファイルを作成します。ファイルがすでに存在する場合は、FALSE とエラーを返します。
  • x+ 読み取り/書き込み。新しいファイルを作成します。ファイルがすでに存在する場合は、FALSE とエラーを返します。

注記：fopen() 関数が指定されたファイルを開けない場合、0 (false) を返します。

<?php

{

    //echo fgetc($file); //逐字符读取

}
//关闭文件
fclose($file);
?>

string json_encode ( $value [, $options = 0 ] )
パラメータ

value: エンコードする値。この関数は UTF-8 エンコードされたデータに対してのみ有効です。
options: 以下の定数で構成されるバイナリマスク: JSON_HEX_QUOT, JSON_HEX_TAG, JSON_HEX_AMP, JSON_HEX_APOS, JSON_NUMERIC_CHECK,JSON_PRETTY_PRINT, JSON_UNESCAPED_SLASHES, JSON_FORCE_OBJECT

mixed json_decode ($json [,$assoc = false [, $depth = 512 [, $options = 0 ]]])
パラメータ

json_string: デコードする JSON 文字列。UTF-8 エンコードされたデータである必要があります

assoc: このパラメータが TRUE の場合は配列を返し、FALSE の場合はオブジェクトを返します。

depth: 再帰の深さを指定する整数型のパラメータ

options: バイナリマスク。現在は JSON_BIGINT_AS_STRING のみサポートしています。
