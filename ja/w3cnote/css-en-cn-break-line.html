CSS 英語・中国語の強制改行と非改行のコード

カテゴリ プログラミング技術

  • 1. word-break:break-all;英語にのみ有効で、アルファベット単位で改行します
  • 2. word-wrap:break-word;英語にのみ有効で、単語単位で改行します
  • 3. white-space:pre-wrap;中国語にのみ有効で、強制的に改行します
  • 4. white-space:nowrap;改行しないよう強制し、すべての言語に有効です
  • 5. white-space:nowrap; overflow:hidden; text-overflow:ellipsis;改行せず、はみ出した部分を非表示にし、省略記号で表示します

注意：必ずコンテナの幅（width）を指定してください。指定しないと効果がありません。

例

.p1{ word-break:break-all; width:150px;} .p2{ word-wrap:break-word; width:150px;} .p3{white-space:pre-wrap; width:150px;} .p4{white-space:nowrap; width:10px;} .p5{white-space:nowrap; overflow:hidden; text-overflow:ellipsis; width:100px;}

word-break 構文

word-break : normal | break-all | keep-all

パラメータ：

  • normal : アジア言語および非アジア言語のテキスト規則に従い、文字内での改行を許可します
  • break-all : この動作はアジア言語のnormalと同じです。非アジア言語のテキスト行でも、任意の文字内での改行を許可します。この値は、非アジア言語のテキストを一部含むアジア言語のテキストに適しています。
  • keep-all : すべての非アジア言語のnormalと同じです。中国語、韓国語、日本語では、文字の分割は許可されません。アジア言語のテキストを少量含む非アジア言語のテキストに適しています。
