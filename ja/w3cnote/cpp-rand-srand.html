C++ rand と srand の使い方

カテゴリ プログラミング技術

コンピュータの乱数はすべて擬似乱数であり、すなわち小M多項式系列によって生成されます。その際、それぞれの小系列を生成するには初期値、すなわち乱数シードがあります。（注意：小M多項式系列の周期は65535です。つまり、各乱数シードを使って生成される乱数の周期は65535であり、65535個の乱数を取得すると、それらは再び繰り返し現れます。）

rand() 関数が乱数の生成に使えることは知っていますが、これは本当の意味での乱数ではなく、擬似乱数です。ある数（シードと呼べます）を基準として、何らかの漸化式によって算出される一連の数です。この一連の数が十分に大きくなると正規分布に従うため、乱数が生成されたように見えますが、これは本当の乱数ではありません。コンピュータが正常に起動している間は、このシードの値は固定されており、システムを破壊しない限り変わりません。

1.rand()

機能:

乱数生成器

使い方:

int rand(void)

ヘッダーファイル:

stdlib.h

rand() の内部実装は線形合同法で行われています。それは本当の乱数ではありませんが、周期が特に長いため、一定の範囲ではランダムと見なせます。

rand() は 0 から RAND_MAX の範囲の乱数値を返します。RAND_MAX の範囲は少なくとも 32767 の間(int)です。unsigned int が2バイトなら 65535、4バイトなら 4294967295 の整数範囲です。0〜RAND_MAX の各数字が選ばれる確率は同じです。

ユーザーが乱数シードを設定しない場合、システムのデフォルトの乱数シードは 1 です。

rand() が生成するのは擬似乱数であり、実行するたびに同じです。異なるものにしたい場合は、関数 srand() で初期化してください。

2.srand()

機能:

乱数生成器の初期化

使い方:

void srand(unsigned int seed)

ヘッダーファイル:

stdlib.h

srand() は、rand() が乱数を生成するときの乱数シードを設定するために使います。引数 seed は整数である必要があります。毎回 seed に同じ値を設定すると、rand() が生成する乱数値も毎回同じになります。

3.現在のクロックを乱数シードとして使用

rand() が生成する乱数は、実行のたびに前回と同じになります。異なるものにしたい場合は、関数 srand() で初期化します。srand((unsigned int)(time(NULL)) を利用すると、毎回プログラムを実行する時刻が異なるため、異なる乱数シードを生成できます。

4.乱数を生成する使い方

  • 1) srand() にシードを渡します。それは unsigned int 型です。
  • 2) rand() を呼び出すと、srand() に渡したシード値に基づいて乱数を返します（0 から RAND_MAX の間）。
  • 3) 必要に応じて rand() を複数回呼び出し、絶えず新しい乱数を取得します。
  • 4) いつでも srand() に新しいシードを渡すことで、rand() の出力結果をさらに"ランダム化"できます。

0〜RAND_MAX の間の乱数を生成するプログラム

#include <iostream>
#include <stdlib.h>
#include <time.h> 

using namespace std; 

int main()
{ 
        srand((unsigned)time(NULL)); 
        for(int i = 0; i < 10;i++ ) 
                cout << rand() << '/t';
        cout << endl; 
        return 0;
}

5.一定範囲の乱数を生成する一般的な表現式

区間 [a,b) のランダムな整数を取得するには、(rand() % (b-a))+ a; を使用します。

区間 [a,b] のランダムな整数を取得するには、(rand() % (b-a+1))+ a; を使用します。

区間 (a,b] のランダムな整数を取得するには、(rand() % (b-a))+ a + 1; を使用します。

一般的な式: a + rand() % n; ここで a は開始値、n は整数の範囲です。

a から b の間のランダムな整数を取得する別の表現: a + (int)b * rand() / (RAND_MAX + 1)。

0〜1 の間の浮動小数点数を取得するには、rand() / double(RAND_MAX) を使用できます。
