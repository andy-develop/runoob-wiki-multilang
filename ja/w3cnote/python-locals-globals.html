Python 两个内置函数: locals 和 globals → Pythonの2つの組み込み関数: localsとglobals

分类 → カテゴリ 编程技术 → プログラミング技術

这两个函数主要提供，基于字典的访问局部和全局变量的方式。 → これらの2つの関数は主に、辞書ベースでローカル変数とグローバル変数にアクセスする方法を提供します。

在理解这两个函数时，首先来理解一下 Python 中的名字空间概念。Python 使用叫做名字空间的东西来记录变量的轨迹。名字空间只是一个字典，它的键字就是变量名，字典的值就是那些变量的值。 → これらの2つの関数を理解するには、まずPythonの名前空間の概念を理解しましょう。Pythonは名前空間と呼ばれるものを使って変数の軌跡を記録します。名前空間は単なる辞書であり、そのキーは変数名、辞書の値はそれらの変数の値です。

实际上，名字空间可以像 Python 的字典一样进行访问。 → 実際には、名前空間はPythonの辞書のようにアクセスすることができます。

每个函数都有着自已的名字空间，叫做局部名字空间，它记录了函数的变量，包括函数的参数和局部定义的变量。每个模块拥有它自已的名字空间，叫做全局名字空间，它记录了模块的变量，包括函数、类、其它导入的模块、模块级的变量和常量。还有就是内置名字空间，任何模块均可访问它，它存放着内置的函数和异常。 → すべての関数には独自の名前空間があり、ローカル名前空間と呼ばれ、関数の変数（関数のパラメータとローカルに定義された変数を含む）を記録します。各モジュールは独自の名前空間を持ち、グローバル名前空間と呼ばれ、モジュールの変数（関数、クラス、その他のインポートされたモジュール、モジュールレベルの変数と定数を含む）を記録します。さらに、組み込み名前空間があり、どのモジュールからもアクセスでき、組み込み関数と例外が格納されています。

当一行代码要使用变量 x 的值时，Python 会到所有可用的名字空间去查找变量，按照如下顺序： → コードのある行が変数xの値を使用するとき、Pythonは利用可能なすべての名前空間で変数を検索し、次の順序で探します：

  • 1、局部名字空间 → 1. ローカル名前空間- 特指当前函数或类的方法。如果函数定义了一个局部变量 x，Python将使用这个变量，然后停止搜索。 → - 現在の関数またはクラスのメソッドを指します。関数がローカル変数xを定義している場合、Pythonはこの変数を使用し、検索を停止します。
  • 2、全局名字空间 → 2. グローバル名前空間- 特指当前的模块。如果模块定义了一个名为 x 的变量，函数或类，Python将使用这个变量然后停止搜索。 → - 現在のモジュールを指します。モジュールがxという名前の変数、関数、またはクラスを定義している場合、Pythonはこの変数を使用して検索を停止します。
  • 3、内置名字空间 → 3. 組み込み名前空間- 对每个模块都是全局的。作为最后的尝试，Python 将假设 x 是内置函数或变量。 → - すべてのモジュールに対してグローバルです。最後の試みとして、Pythonはxが組み込み関数または変数であると仮定します。

如果 Python 在这些名字空间找不到 x，它将放弃查找并引发一个 NameError 的异常，同时传递 → Pythonがこれらの名前空間でxを見つけられない場合、検索を放棄してNameError例外を発生させ、同時に次の情報を渡します。There is no variable named 'x'这样一条信息。 → このようなメッセージです。

局部变量函数 locals 例子（locals 返回一个名字/值对的字典）： → ローカル変数関数localsの例（localsは名前と値のペアの辞書を返します）：

实例 → 例

def foo(arg, a):
    x = 1
    y = 'xxxxxx'
    for i in range(10):
        j = 1
        k = i
    print(locals())
#调用函数的打印结果 → #関数を呼び出したときの出力結果
foo(1,2)
#{'k': 9, 'j': 1, 'i': 9, 'y': 'xxxxxx', 'x': 1, 'a': 2, 'arg': 1}

from module import 和 import module之间的不同。使用 import module，模块自身被导入，但是它保持着自已的名字空间，这就是为什么你需要使用模块名来访问它的函数或属性（module.function）的原因。但是使用 from module import，实际上是从另一个模块中将指定的函数和属性导入到你自己的名字空间，这就是为什么你可以直接访问它们却不需要引用它们所来源的模块的原因。 → import moduleとfrom module importの間の違い。import moduleを使用すると、モジュール自体がインポートされますが、モジュールは自身の名前空間を保持します。そのため、モジュール名を使用してその関数や属性（module.function）にアクセスする必要があります。一方、from module importを使用すると、実際には別のモジュールから指定した関数や属性を自分の名前空間にインポートします。そのため、それらの出所となるモジュールを参照することなく直接アクセスできます。

locals 是只读的，globals 不是。 → localsは読み取り専用ですが、globalsはそうではありません。

locals 不可修改，globals 可以修改，原因是： → localsは変更できませんが、globalsは変更できます。理由は次のとおりです：

  • locals()实际上没有返回局部名字空间，它返回的是一个拷贝。所以对它进行修改，修改的是拷贝，而对实际的局部名字空间中的变量值并无影响。 → 実際にはローカル名前空間を返すのではなく、そのコピーを返します。そのため、それを変更しても、変更されるのはコピーであり、実際のローカル名前空間内の変数の値には影響しません。
  • globals() 返回的是实际的全局名字空间，而不是一个拷贝与 locals 的行为完全相反。 → globals()はコピーではなく実際のグローバル名前空間を返します。これはlocalsの動作とまったく逆です。

所以对 globals 所返回的 dictionary 的任何的改动都会直接影响到全局变量的取值。 → したがって、globalsが返す辞書への変更は、グローバル変数の値に直接影響します。

实例 → 例

#!/usr/bin/env python    

z = 7 #定义全局变量 → #グローバル変数を定義する
def foo(arg):  
    x = 1  
    print( locals() )  
    print('x=',x)
    locals()['x'] = 2 #修改的是局部名字空间的拷贝，而实际的局部名字空间中的变量值并无影响。 → #変更されるのはローカル名前空間のコピーであり、実際のローカル名前空間の変数の値には影響しません。
    print( locals() )
    print( "x=",x )
 
foo(3)  
print( globals() )
print( 'z=',z )
globals()["z"] = 8 #globals（）返回的是实际的全局名字空间，修改变量z的值 → #globals()は実際のグローバル名前空間を返すため、変数zの値を変更します
print( globals() )
print( "z=",z )
