Eclipse よく使うショートカットキーと使用テクニック

カテゴリ プログラミング技術

Java開発をしていると、よくEclipseまたはMyEclise統合開発環境を使用します。いくつかの実用的なEclipseショートカットキーと使用テクニックは、普段の開発で多くの時間を節約し、作業効率を向上させることができます。以下では、自分の開発での使用に基づいて、Eclipseでよく使うショートカットキーとテクニックを皆さんと共有します。

15個のEclipseでよく使う開発ショートカットキーの使用テクニック

1、alt+? 或 alt+/：コードを自動補完またはコードをプロンプト表示する

これは私が最も誇りに思うショートカットキーの組み合わせです。特に「syso」と入力した後、2本の指でこの2つのキーを軽く押すと、自動的に補完されます。System.out.println();され、しかもEclipseのデフォルトでは表示されます.メソッドのヒントを表示します。途中でヒントが途切れて再度確認したい場合は、対応するクラスや変数の前に再度入力する必要があります。.そうして初めてヒントを再度確認できます。ただし、この2つのキーを組み合わせて使用しても同様にヒントの役割を果たせます。試してみてください。また、「for」と入力した後、上にある反復処理が必要なローカル変数があれば、選択ポップアップが表示され、次のいずれかを使用するか選択します。for each反復処理を使用するか、それともfor(int;;)それともwhile()その後、コードが自動生成されます。

2、ctrl+o：クイックOutlineビュー

現在のクラスのメソッドまたは特定のメソッドを確認したいが、コードを上下にスクロールしたくない、また検索機能も使いたくない場合は、次のショートカットキーを使用します。ctrl+o特に、メソッドが非常に多いクラスを直接開いたり追跡したりする場合、これは非常に便利です。メソッドやメンバー変数を直接確認でき、現在のクラス内のすべてのメソッドと属性を一覧表示します。確認したいメソッド名を入力し、クリックするだけでenter目的の位置に直接ジャンプできます。

3、ctrl+shift+r：リソースリストを開く

これはおそらくすべてのショートカットキーの組み合わせの中で最も時間を節約できるもので、私もよく使います。特に名前を使ってプロジェクトやワークスペース内のファイルを直接探す場合です。このショートカットキーを使うと、ワークスペース内の任意のファイルを開くことができます。ファイル名またはマスク名の最初の数文字を入力するだけで、例えば「applic*.xml」のようにします。残念なのは、このショートカットキーがすべてのビューで使用できるわけではないことです。

4、ctrl+shift+f：コードをフォーマットする

デフォルトでは80文字で改行されますが、これは設定で変更できます。また、コードスタイルに基づいてコードを再フォーマットすることもできます。私たちのチームには統一されたコード形式があり、それをwikiに置いています。これを行うには、Eclipseを開き、「Window」→「Style」を選択し、「Code Formatter」、「Code Style」、「Organize Imports」を設定します。エクスポート（Export）機能を使用して設定ファイルを生成します。これらの設定ファイルをwikiに置き、チームの全員が自分のEclipseにインポートします。

5、ctrl+e：エディターをすばやく切り替える

このショートカットキーは、開いているエディター間を移動するのに役立ちます。特に多くのファイルが開いている状態では、ctrl+eより効率的で、非常に役立ちます。

6、ctrl+page down 或 ctrl+page up：タブ間をすばやく切り替える

前後のタブを閲覧できます。使い慣れると、各ページの切り替えが非常に速くなり、とても良い感じです。

7、shift+enter 及 ctrl+shift+enter：現在の行の上または下に空白行を作成する。

Shift+enter現在の行の下に空白行を作成します。カーソルが行末にあるかどうかは関係ありません。Ctrl+shift+enterもう一方は現在の行の前に空白行を挿入します。この2つのショートカットキーも非常に役立ちます。最初は慣れないかもしれませんが、何度も使ううちに便利だと感じるでしょう。少なくとも私はそうです。

8、Alt+上下方向キー：上下の行を入れ替える、または現在の行を上や下に移動する

これも時間を節約できる優れた機能です。この組み合わせは現在の行の内容を上または下に移動します。try/catchの部分では、このショートカットキーが特に便利です。

9、Control+Alt+上下方向キー：ハイライト表示された1行または複数行をコピーする

これも非常に便利なショートカットキーで、現在のコードを上の行または下の行に非常に簡単にコピーできます。私もよく使います。

10、ctrl+m：現在の編集ページウィンドウを最大化する

大きなディスプレイ画面が作業効率を向上させることは誰もが知っています。Ctrl+mエディターウィンドウを最大化するショートカットキーで、もう一度押すと通常のウィンドウに戻ります。

11、ctrl+/：現在の行または選択した複数行を自動的にコメントアウトする

現在の行または複数行のコードを自動的にコメントアウトし、//コメントアウトには、ctrl+\コメントアウトを解除できます。

12、ctrl+shift+/：選択したコードブロックを自動的にコメントアウトする

これは注意してください、使用しているのは/* */コメントアウトです（プログラミング言語コードの場合）。開発中にも非常に便利です。HTML、CSSなどでもこのコメントを使用して、対応するコメントタグを生成できます。ctrl+shift+\コメントアウトを解除できます。

13、ctrl+d：現在の行を削除する

現在の行を削除します。これは非常に便利で、私もよく使います。特にデバッグ中に、現在の誤った行を削除するときです。Ctrl+Z（編集の取り消し）のショートカットキーと組み合わせると、自在に操作できます。

14、ctrl+shift+x 和 ctrl+shift+y：英文字の大文字と小文字の変換

このショートカットキーはSQL文の作成でよく使われます。私もよく使います。SQL文のキーワードは大文字で統一することをお勧めします。データベースでは大文字と小文字を区別しませんが、特にSQL文が非常に長い場合、他の人や自分自身が読みやすくなり、また見た目も整います。

15、ctrl+shift+o：パッケージを自動的にインポートし、不要なパッケージを削除する

このショートカットキーも非常に便利です。他のパッケージ内のクラスを使用するとき、対応するパッケージやクラスがインポートされていないと、赤い波線の警告が表示されます。そのときにこのショートカットキーを押すと、赤い警告が自動的に消えて正常に戻ります。同じクラスを含むパッケージが複数ある場合は、選択するように促されます。また、使用していないパッケージをインポートしている場合（通常はコードのコピー＆ペーストを繰り返すうちに発生することが多い）も、このキーで素早く削除できます。

いくつかの小技を添付します：

コマンドラインウィンドウをロックする：コマンドライン表示（Window -> Show View -> Other -> Basic -> Console）で、スクロールロックボタンを使用してコンソール出力をロックし、スクロールしないようにしてみてください。

Antビューを使用する：私のJavaまたはDebugモードでは、Antビューを表示しておくと、Antタスクをすばやく実行できます。このビューは、Window → Ant で見つけることができます。Antビューを画面の隅に置き、「ビルドファイルの追加（Add -> Other -> Show View -> Buildfiles）」ボタンでbuild.xmlファイルを追加します。バージョン3.1では、Antデバッグスクリプト言語もサポートされています。

コレクションを自動的に反復処理する：for + Control-Space: もしご存じないなら、Control-Spaceが自動補完機能であることを覚えておくべきです。Eclipseでは、構造を自動補完することもできます。配列またはコレクションの範囲内で、「for」と入力してControl-Spaceキーを押してみてください。Eclipseがどのコレクションを反復処理したいかを尋ね、ループコードを自動的に完成させます。

階層レイアウトを使用する：パッケージ・エクスプローラービュー（Package Explorer view）のデフォルトのレイアウト（フラット形式）は私を困惑させます。パッケージの完全名がナビゲーションツリー（navigation tree）に表示されるからです。私はソースコードのパッケージとファイルシステムのビューの方が好きで、Eclipseでは階層レイアウト（Hierarchical Layout）と呼ばれています。このモードに切り替えるには、パッケージ・エクスプローラービューの下向きボタンをクリックし、レイアウト（Layout）を選択して、階層（Hierarchial）を選択します。

一度に複数のファイルを表示する：一度に複数のファイルを閲覧できます。アクティブではない編集ウィンドウを、アクティブなウィンドウの下部または側面のスクロールバーにドラッグすると、その編集ウィンドウを開くことができます。これがこのコツを説明する最良の方法です。

2つのEclipseを同時に開く：変更をあるCVSブランチから別のCVSブランチにマージするには、異なるワークスペース（Workspace）を持つ2つのEclipseを同時に開くのが好きです。これにより、CVS上の最新バージョンと比較してすべての変更を確認し（プロジェクトを右クリックして「Compare Lastest from HEAD」を選択）、各変更を別のCVSブランチにマージできます。複数のEclipseを起動する最も簡単な方法は、Eclipse→launcher（Eclipse with Launcher）を利用することです。

Implementorsプラグイン：インターフェースの実装にジャンプできるプラグインをインストールします。あなたがdependency injectionファンであるか、優れたインターフェースに基づいて作業しているなら、コードナビゲーションを高速化するためにこのようなプラグインが必要です。このプラグインはSourceForgeで見つけることができます。

getter と setter メソッドの自動生成：対応するPOJOで、空白部分を右クリックし、【Source】を選択し、次に【Generate Getters and Setters】を選択し、どのプロパティに対してこのようなメソッドを生成するかを選択して、【OK】をクリックすれば完了です。特にメンバー変数が非常に多い場合、時間を節約できます。

Eclipseショートカットキー大全を添付します：

  • Ctrl+1:クイックフィックス（最も定番のショートカットキーなので、説明不要）
  • Ctrl+D:現在の行を削除
  • Ctrl+Alt+↓:現在の行を次の行にコピー（コピー追加）
  • Ctrl+Alt+↑:現在の行を前の行にコピー（コピー追加）
  • Alt+↓:現在の行と次の行を入れ替える（非常に便利で、切り取って貼り付ける手間が省ける）
  • Alt+↑:現在の行と前の行を入れ替える（上と同じ）
  • Alt+←:前の編集ページ
  • Alt+→:次の編集ページ（もちろん上記の項目に対して）
  • Alt+Enter:現在選択中のリソース（プロジェクト、またはファイル）のプロパティを表示
  • Shift+Enter:現在の行の次の行に空行を挿入（このときマウスは現在の行のどこにあってもよい。必ずしも最後である必要はない）
  • Shift+Ctrl+Enter:現在の行に空行を挿入（原理は上記と同じ）
  • Ctrl+Q:最後に編集した場所に移動
  • Ctrl+L:特定の行に移動（プログラムが100行を超える人には福音である）
  • Ctrl+M:現在のEditまたはViewを最大化（もう一度押すと元に戻る）
  • Ctrl+/:現在の行をコメントアウト、もう一度押すとコメント解除
  • Ctrl+O:OutLineをすばやく表示
  • Ctrl+T:現在のクラスの継承構造をすばやく表示
  • Ctrl+W:現在のエディターを閉じる
  • Ctrl+K:選択中のワードを参照して次へすばやく移動
  • Ctrl+E:現在のエディターのドロップダウンリストをすばやく表示（現在のページに表示されていないものは太字で表示）
  • Ctrl+/（テンキー）:現在のクラス内のすべてのコードを折りたたむ
  • Ctrl+×（テンキー）:現在のクラス内のすべてのコードを展開する
  • Ctrl+Space:コードアシスタントによるコード挿入（通常は入力メソッドと競合するため、入力メソッドのホットキーを変更するか、一時的にAlt+/で代用できる）
  • Ctrl+Shift+E:現在開いているすべてのViewを管理するマネージャーを表示（閉じる、アクティブ化などの操作を選択できる）
  • Ctrl+J:前方増分検索（Ctrl+Jを押した後、入力した各文字に対してエディターがクイックマッチで単語を検索し、見つからない場合はステータスラインに「見つかりません」と表示される。単語を検索するときに非常に便利。この機能はIdeaでは2年前からあった）
  • Ctrl+Shift+J:後方増分検索（上記と同じだが、後ろから前に向かって検索する）
  • Ctrl+Shift+F4:開いているすべてのエディターを閉じる
  • Ctrl+Shift+X:現在選択中のテキストをすべて小文字に変換する
  • Ctrl+Shift+Y:現在選択中のテキストをすべて小文字に変換する
  • Ctrl+Shift+F:現在のコードをフォーマットする
  • Ctrl+Shift+P:対応するマッチング記号（例: {}）に移動（前から後ろに移動する場合、カーソルはマッチング記号の中にある必要がある。後ろから前へはその逆）

以下のショートカットキーはリファクタリングでよく使うもので、自分が好きでよく使うものをまとめた（注: 一般的にリファクタリングのショートカットキーはAlt+Shiftで始まる）

  • Alt+Shift+R:名前の変更（自分が最も愛用しているものの一つ。特に変数やクラスのRenameは、手動の方法に比べて労力を大幅に節約できる）
  • Alt+Shift+M:メソッドの抽出（リファクタリングで最もよく使われる方法の一つ。特に大量のゴチャゴチャしたコードに有効）
  • Alt+Shift+C:関数シグネチャの変更（比較的実用的。N個の関数がこのメソッドを呼んでいる場合、一度の修正で済む）
  • Alt+Shift+L:ローカル変数の抽出（マジックナンバーや文字列を直接変数に抽出できる。特に複数箇所で使用している場合に便利）
  • Alt+Shift+F:クラス内のローカル変数をフィールド変数に変換（比較的実用的な機能）
  • Alt+Shift+I:変数のインライン化（Inlineと言う方が適切かもしれない）
  • Alt+Shift+V:関数と変数の移動（あまり使われない）
  • Alt+Shift+Z:リファクタリングの取り消し（Undo）
