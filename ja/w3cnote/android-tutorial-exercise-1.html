1. ちょっとした雑談：

入門チュートリアルは去年の11月に書き終え、今に至るまで約9か月以上が経ちました。当時は仕事の都合で実戦的なプロジェクトを書けず、とても残念に思っていました。最近ようやくプロジェクトもほぼ終盤になり、少し時間ができるかもしれないので、この悔いを埋めることにしました。せっかく入門チュートリアルで多くのことを学んだのですから、実戦プロジェクトを書いて統合する必要があります。入門シリーズを見ているのは初心者だということと自分の時間の関係を考慮し、このプロジェクトは簡単な女の子閲覧アプリに設定しました：DrySisterこの名前の由来を、ゆっくりお話しします。女の子の画像はGank.io、Gank の発音は「干客」で、略して「干」です。本来は直接 GanMeizi と名付けようと思いましたが、Github 上で既に使っている人がいたので、その後、つい Google 翻訳で「干妹子」を翻訳してみました。その翻訳結果は：DrySister、思い切ってこの名前にしましょう！何もおかしくないですよね！

また、これを実戦プロジェクトに選んだ理由は、女の子を見ると目が癒されるからです。例えば私のAS：

さて、話を戻すと、この実戦プロジェクトをどう進めるかということですが。Gank.io の API を使った小規模プロジェクトは Github 上にたくさん見つかります。そして、どれも Rx、Retrofit、Glide、Butterknife といったクールなフレームワークを使っています。私にも直接書くことはできます：MVPパターン，BufferKnife + Dagger2 + Retrofit + Rx + retrolambda + Glide + Relamのプロジェクトも書けますが、あまり意味はありません。私は最も簡単な Handler から始めて、徐々に機能を追加し、少しずつ最適化していきたいと思っています。まるでプロジェクトの反復開発のようなものです。書き終えたらそのプロジェクトを放ったらかしにするのではなく、それで終わりにしないようにしたいのです。実際、プロジェクトを最適化・リファクタリングするときにもっと多くのことを学べます。本当です。では、Hello world! から始めましょう！

ワクワクするかって？

はい、冗談です。ただ、この節はまだ簡単で、ネットワーク画像を表示する簡単なプロトタイプを書くだけです。後から少しずつ反復して最適化し、あれこれ余計なものも全部追加していきます！ また、プロジェクトの全コードは Github にホスティングします。ブランチ管理を導入し、master ブランチを正式なメジャーバージョンとし、develop を日常の開発ブランチとします。新機能を追加するときは develop ブランチから機能ブランチを切り、作成完了後に develop ブランチへマージし戻します。だいたいそんな感じです。詳細は自分でゆっくり見てください！

1. GitHubリポジトリの作成

AS 上に新しいプロジェクトを作成し、名前はDrySister、パッケージ名：com.coderpig.drysisterプロジェクトのルートディレクトリで git bash を開き、以下のコマンドを入力して Git リポジトリを作成します： git init Github 上に新しいリポジトリを作成し、名前を DrySister にします。続いてリモートリポジトリを設定し、コマンドを入力します： git remote add origin git@github.com:coder-pig/DrySister.git master ブランチを pull し、それから add、commit、push で github リポジトリに送ります。続いて、私は .gitignore ファイルを変更し、新しい develop ブランチを作成しました。そしてそのブランチ上でコミットし、master ブランチにマージしました。はい、Git に関する準備はだいたい完了です。

2. プログラムの作成開始

ローカルで develop ブランチを切り、コードを書き始めます。レイアウトはとても簡単で、女の子の画像を表示する ImageView と Button があります。activity_main.xml続いて、画像をダウンロードして読み込む簡単なクラスを書きます。PictureLoader.javaロジックは簡単です。スレッドが入力ストリームをバイト配列に変換し、変換完了後、handler 内で decodeByteArray がバイト配列をビットマップにデコードして、表示します～

public class PictureLoader {
    private ImageView loadImg;
    private String imgUrl;
    private byte[] picByte;

    Handler handler = new Handler() {
        @Override
        public void handleMessage(Message msg) {
            super.handleMessage(msg);
            if (msg.what == 0x123) {
                if (picByte != null) {
                    Bitmap bitmap = BitmapFactory.decodeByteArray(picByte, 0, picByte.length);
                    loadImg.setImageBitmap(bitmap);
                }
            }
        }
    };

    public void load(ImageView loadImg, String imgUrl) {
        this.loadImg = loadImg;
        this.imgUrl = imgUrl;
        Drawable drawable = loadImg.getDrawable();
        if(drawable != null && drawable instanceof BitmapDrawable) {
            Bitmap bitmap = ((BitmapDrawable)drawable).getBitmap();
            if(bitmap != null && !bitmap.isRecycled()) {
                bitmap.recycle();
            }
        }
        new Thread(runnable).start();
    }

    Runnable runnable = new Runnable() {
        @Override
        public void run() {
            try {
                URL url = new URL(imgUrl);
                HttpURLConnection conn = (HttpURLConnection) url.openConnection();
                conn.setRequestMethod("GET");
                conn.setReadTimeout(10000);
                if (conn.getResponseCode() == 200) {
                    InputStream in = conn.getInputStream();
                    ByteArrayOutputStream out = new ByteArrayOutputStream();
                    byte[] bytes = new byte[1024];
                    int length = -1;
                    while ((length = in.read(bytes)) != -1) {
                        out.write(bytes, 0, length);
                    }
                    picByte = out.toByteArray();
                    in.close();
                    out.close();
                    handler.sendEmptyMessage(0x123);
                }

            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    };
}

public class MainActivity extends AppCompatActivity implements View.OnClickListener {
    private Button showBtn;
    private ImageView showImg;
    private ArrayList<String> urls;
    private int curPos = 0;
    private PictureLoader loader;

    @Override protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        loader = new PictureLoader();
        initData();
        initUI();
    }

    private void initData() {

    private void initUI() {
        showBtn = (Button) findViewById(R.id.btn_show);
        showImg = (ImageView) findViewById(R.id.img_show);
        showBtn.setOnClickListener(this);

    @Override public void onClick(View v) {
        switch (v.getId()) {

4. まとめ

まず、この節で私たちがやったことを説明します。：

  • 1. DrySister プロジェクトを作成し、プロジェクトを Github にホスティングしました。

最適化待ち・追加したいもの：

  • 1. コード内の画像ソースはハードコーディングしているため、毎日見られる画像は同じ数枚だけです。Gank が提供する API は使っていません。

  • 1. Android 標準の簡易パーサーを使用して API データを解析し、画像表示用のデータソースを取得します。
