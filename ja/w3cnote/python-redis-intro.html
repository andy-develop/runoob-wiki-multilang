Python redis 使用紹介

カテゴリ プログラミング技術

この章では、Python で redis を操作する方法を紹介します。redis は Key-Value データベースであり、Value は string（文字列）、list（リスト）、set（集合）、zset（ソート済み集合）、hash（ハッシュ型）などの型をサポートしています。

redis の詳細については、私たちのredis チュートリアル、この章を学習する前に、redis サービスがインストールされていることを確認してください。

redis モジュールをインストール

Python で redis を使用するには、まず redis モジュールをインストールする必要があります：

sudo pip3 install redis
或
sudo easy_install redis
或
sudo python setup.py install

ソースコードアドレス：https://github.com/WoLpH/redis-py

インストールが成功したかどうかをテストする：

>>> import redis
>>> r = redis.StrictRedis(host='localhost', port=6379, db=0)
>>> r.set('foo', 'bar')
True
>>> r.get('foo')
'bar'

redis は Redis と StrictRedis の2つのクラスを提供します。StrictRedis は公式コマンドの大部分を実装するために使用され、Redis は StrictRedis のサブクラスで、旧バージョンとの後方互換性のために使用されます。

redis から取得される結果はデフォルトではバイト型です。設定できます。decode_responses=True文字列に変更します。

例

import redis   # redis モジュールをインポート

r = redis.Redis(host='localhost', port=6379, decode_responses=True)  
r.set('name', 'runoob')  # name に対応する値を設定
print(r['name'])
print(r.get('name'))  # キー name に対応する値を取得
print(type(r.get('name')))  # 型を確認

出力結果は次のとおりです：

runoob
runoob
<class 'str'>

コネクションプール

redis-py は connection pool を使用して、1つの redis server へのすべての接続を管理し、接続の確立・解放のたびのオーバーヘッドを回避します。

デフォルトでは、各 Redis インスタンスは自身のコネクションプールを維持します。コネクションプールを直接作成し、それをパラメータとして Redis に渡すことで、複数の Redis インスタンスで1つのコネクションプールを共有できます。

例

import redis    # redis モジュールをインポート

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(host='localhost', port=6379, decode_responses=True)  
r.set('name', 'runoob')  # name に対応する値を設定
print(r.get('name'))  # キー name に対応する値を取得

redis 基本コマンド String

set(name, value, ex=None, px=None, nx=False, xx=False)

Redis で値を設定する場合、デフォルトでは、存在しなければ作成し、存在すれば変更します。

パラメータ：

  • ex - 有効期限（秒）
  • px - 有効期限（ミリ秒）
  • nx - Trueに設定すると、nameが存在しない場合にのみ、現在のset操作が実行されます
  • xx - Trueに設定すると、nameが存在する場合にのみ、現在のset操作が実行されます

1. ex - 有効期限（秒） ここでは有効期限は3秒です。3秒後、キー food の値は None になります。

例

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
r.set('food', 'mutton', ex=3)    # key は "food"、value は "mutton" で、キーと値のペアを redis キャッシュに保存します
print(r.get('food'))  # mutton キー food に対応する値を取得

2. px - 有効期限（ミリ秒） ここでは有効期限は3ミリ秒です。3ミリ秒後、キー foo の値は None になります。

例

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
r.set('food', 'beef', px=3)
print(r.get('food'))

3. nx - Trueに設定すると、nameが存在しない場合にのみ、現在のset操作が実行されます（新規作成）

例

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
print(r.set('fruit', 'watermelon', nx=True))    # True--存在しない
# キー fruit が存在しなければ、出力は True；キー fruit がすでに存在すれば、出力は None

4. xx - Trueに設定すると、nameが存在する場合にのみ、現在のset操作が実行されます（変更）

例

print((r.set('fruit', 'watermelon', xx=True)))   # True--すでに存在
# キー fruit がすでに存在すれば、出力は True；キー fruit が存在しなければ、出力は None

5.setnx(name, value)

値を設定します。nameが存在しない場合のみ、設定操作を実行します（追加）

print(r.setnx('fruit1', 'banana'))  # fruit1不存在，输出为True

6.setex(name, time, value)

値を設定

パラメータ：

time - 有効期限（数値の秒 または timedelta オブジェクト）

例

import redis
import time

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)
r.setex("fruit2", 5, "orange")
time.sleep(5)
print(r.get('fruit2'))  # 5秒後、値は orange から None に変わります

7.psetex(name, time_ms, value)

値を設定

パラメータ：

time_ms - 有効期限（数値のミリ秒 または timedelta オブジェクト）

例

r.psetex("fruit3", 5000, "apple")
time.sleep(5)
print(r.get('fruit3'))  # 5000ミリ秒後、値は apple から None に変わります

一括で値を設定

10.getset(name, value)

新しい値を設定し、元の値を取得します

print(r.getset("food", "barbecue"))  # 设置的新值是barbecue 设置前的值是beef

11.getrange(key, start, end)

サブシーケンスを取得（バイト単位で取得、文字ではない）

パラメータ：

  • name - Redis の name
  • start - 開始位置（バイト）
  • end - 終了位置（バイト）

例： "君惜大大" の場合、0-3 は "君" を表します

例

r.set("cn_name", "君惜大大") # 漢字
print(r.getrange("cn_name", 0, 2))   # インデックスが0-2の最初の3バイトを取得 君 スライス操作 （漢字1文字は3バイト、英字1文字は1バイト、各バイトは8bit）
print(r.getrange("cn_name", 0, -1))  # すべてのバイトを取得 君惜大大 スライス操作
r.set("en_name","junxi") # 英字
print(r.getrange("en_name", 0, 2))  # インデックスが0-2の最初の3バイトを取得 jun スライス操作 （漢字1文字は3バイト、英字1文字は1バイト、各バイトは8bit）
print(r.getrange("en_name", 0, -1)) # すべてのバイトを取得 junxi スライス操作

12.setrange(name, offset, value)

文字列の内容を変更し、指定した文字列インデックスから後ろを置換します（新しい値が長すぎる場合は、後ろに追加します）

パラメータ：

  • offset - 文字列のインデックス、バイト（漢字1文字は3バイト）
  • value - 設定する値

例

r.setrange("en_name", 1, "ccc")
print(r.get("en_name"))    # jccci 元の値はjunxi、インデックス番号1からcccに置換すると jccci になります

13.setbit(name, offset, value)

nameに対応する値のバイナリ表現のビットに対して操作します

パラメータ：

  • name - Redisのname
  • offset - ビットのインデックス（値をバイナリに変換してからインデックス付けします）
  • value - 値は1または0のみ

注：Redisに次のような対応がある場合： n1 = "foo"、

その場合、文字列fooのバイナリ表現は：01100110 01101111 01101111

したがって、setbit('n1', 7, 1) を実行すると、7ビット目が1に設定され、

その場合、最終的なバイナリは 01100111 01101111 01101111 となり、つまり："goo" になります

拡張、バイナリ表現の変換：

例

source = "陈思维"
source = "foo"
for i in source:
num = ord(i)
print bin(num).replace('b','')

特に、sourceが漢字 "陈思维" の場合はどうしますか？

答：utf-8の場合、漢字1文字は3バイトを占めるため、"陈思维" は9バイトになります。 漢字の場合、forループはバイト単位で反復します。反復時に各バイトを10進数に変換し、その10進数を2進数に変換します。 11100110 10101101 10100110 11100110 10110010 10011011 11101001 10111101 10010000

14.getbit(name, offset)

nameに対応する値のバイナリ表現における特定のビットの値（0または1）を取得します

print(r.getbit("foo1", 0)) # 0 foo1 对应的二进制 4个字节 32位 第0位是0还是1

15.bitcount(key, start=None, end=None)

nameに対応する値のバイナリ表現における1の数を取得します

パラメータ：

  • key - Redisのname
  • start - バイトの開始位置
  • end - バイトの終了位置

例

print(r.get("foo"))  # goo1 01100111
print(r.bitcount("foo",0,1))  # 11 は先頭2バイトの中に1が出現する回数を示します

16.bitop(operation, dest, *keys)

複数の値を取得し、値に対してビット演算を行い、最後の結果を新しいnameに対応する値に保存します

パラメータ：

  • operation - AND（論理積）、OR（論理和）、NOT（否定）、XOR（排他的論理和）
  • dest - 新しいRedisのname
  • *keys - 検索するRedisのname

例：

bitop("AND", 'new_name', 'n1', 'n2', 'n3')

Redis内のn1,n2,n3に対応する値を取得し、すべての値に対してビット演算（論理和）を行い、結果をnew_nameに対応する値に保存します

例

r.set("foo","1")  # 0110001
r.set("foo1","2")  # 0110010
print(r.mget("foo","foo1"))  # ['goo1', 'baaanew']
print(r.bitop("AND","new","foo","foo1"))  # "new" 0 0110000
print(r.mget("foo","foo1","new"))

source = "12"
for i in source:
num = ord(i)
print(num)  # 各英字または漢字に対応するASCIIコード値を出力 f-102-0b100111-01100111
print(bin(num))  # 各10進数のASCIIコード値を2進数に変換した値を出力 0b1100110（0bは2進数を示す）
print bin(num).replace('b','')  # 2進数の0b1100110を01100110に置き換える

17.strlen(name)

nameに対応する値のバイト長を返します（漢字1文字は3バイト）

print(r.strlen("foo"))  # 4 'goo1'的长度是4

18.incr(self, name, amount=1)

nameに対応する値をインクリメントします。nameが存在しない場合は name＝amount を作成し、存在する場合はインクリメントします。

パラメータ：

  • name - Redisのname
  • amount - インクリメント数（整数である必要があります）

注：incrby と同じ

例

r.set("foo", 123)
print(r.mget("foo", "foo1", "foo2", "k1", "k2"))
r.incr("foo", amount=1)
print(r.mget("foo", "foo1", "foo2", "k1", "k2"))

適用シナリオ – ページクリック数

一系列のページについてクリック数を記録する必要があると仮定します。例えばフォーラムの各投稿のクリック数を記録する必要があり、クリック数は返信数よりはるかに多くなります。リレーショナルデータベースを使用してクリック数を保存する場合、大量の行レベルのロック競合が発生する可能性があります。したがって、クリック数の増加にはredisのINCRコマンドを使用するのが最適です。

redisサーバー起動時に、リレーショナルデータベースからクリック数の初期値を読み込むことができます（12306というページは34634回アクセスされました）

r.set("visit:12306:totals", 34634)
print(r.get("visit:12306:totals"))

ページがクリックされるたびに、INCRを使用してクリック数を増やせばよいです。

r.incr("visit:12306:totals")
r.incr("visit:12306:totals")

ページ読み込み時にこの値を直接取得できます。

print(r.get("visit:12306:totals"))

19.incrbyfloat(self, name, amount=1.0)

nameに対応する値をインクリメントします。nameが存在しない場合は name＝amount を作成し、存在する場合はインクリメントします。

パラメータ：

  • name - Redisのname
  • amount - インクリメント数（浮動小数点型）

例

r.set("foo1", "123.0")
r.set("foo2", "221.0")
print(r.mget("foo1", "foo2"))
r.incrbyfloat("foo1", amount=2.0)
r.incrbyfloat("foo2", amount=3.0)
print(r.mget("foo1", "foo2"))

20.decr(self, name, amount=1)

nameに対応する値をデクリメントします。nameが存在しない場合は name＝amount を作成し、存在する場合はデクリメントします。

パラメータ：

  • name - Redisのname
  • amount - デクリメント数（整数）

例

r.decr("foo1", amount=1) # 1減算
print(r.mget("foo1", "foo4"))

redis 基本コマンド hash

1、単一追加--変更（単一取得）--なければ新規追加、あれば変更

hset(name, key, value)

nameに対応するhashにキーと値のペアを設定します（存在しない場合は作成、存在する場合は修正）

パラメータ：

  • name - redisのname
  • key - nameに対応するhash内のキー
  • value - nameに対応するhash内のバリュー

注：hsetnx(name, key, value) は、nameに対応するhash内に現在のkeyが存在しない場合に作成します（追加に相当）

例

import redis
import time

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)

r.hset("hash1", "k1", "v1")
r.hset("hash1", "k2", "v2")
print(r.hkeys("hash1")) # hash内のすべてのkeyを取得
print(r.hget("hash1", "k1"))    # hashのkeyに対応する値を単一で取得
print(r.hmget("hash1", "k1", "k2")) # hashのkeyに対応する値を複数で取得
r.hsetnx("hash1", "k2", "v3") # 新規作成のみ可能
print(r.hget("hash1", "k2"))

2、一括追加（取得）

hmset(name, mapping)

nameに対応するhash内にキーと値のペアを一括設定します

パラメータ：

  • name - redisのname
  • mapping - 辞書、例：{'k1':'v1', 'k2': 'v2'}

例：

例

r.hmset("hash2", {"k2": "v2", "k3": "v3"})
hget(name,key)

nameに対応するhash内でkeyに基づいてvalueを取得します

hmget(name, keys, *args)

nameに対応するhash内で複数のkeyの値を取得します

パラメータ：

  • name - reidsに対応するname
  • keys - 取得するkeyの集合、例：['k1', 'k2', 'k3']
  • *args - 取得するkey、例：k1,k2,k3

例：

例

print(r.hget("hash2", "k2"))  # "hash2"のkey-k2に対応するvalueを単一で取得
print(r.hmget("hash2", "k2", "k3"))  # "hash2"のkey-k2 k3に対応するvalueを一括取得 --方法1
print(r.hmget("hash2", ["k2", "k3"]))  # "hash2"のkey-k2 k3に対応するvalueを一括取得 --方法2

7、メンバーが存在するかどうかを判断する（辞書の in と同様）

hexists(name, key)

nameに対応するhashに現在渡されたkeyが存在するかどうかを確認します

例

print(r.hexists("hash1", "k1"))  # True 存在する

8、キーと値のペアを削除する

hdel(name,*keys)

nameに対応するhash内の指定されたkeyのキーと値のペアを削除します

例

print(r.hgetall("hash1"))
r.hset("hash1", "k2", "v222")   # 既存のkey k2を修正
r.hset("hash1", "k11", "v1")   # キーと値のペア k11 を新規追加
r.hdel("hash1", "k1")    # 1つのキーと値のペアを削除
print(r.hgetall("hash1"))

9、整数のインクリメント・デクリメント（keyに対応するvalue（整数）を1または2、または他の整数だけインクリメント、負数ならデクリメント）

hincrby(name, key, amount=1)

nameに対応するhash内の指定されたkeyの値をインクリメントし、存在しない場合は key=amount を作成します

パラメータ：

  • name - redis内のname
  • key - hashに対応するkey
  • amount - 増分値（整数）

例

r.hset("hash1", "k3", 123)
r.hincrby("hash1", "k3", amount=-1)
print(r.hgetall("hash1"))

14.カスタムの増分反復

リストをループ

しかし、リストが非常に大きい場合、最初のステップでプログラムのメモリを圧迫する可能性があります。そのため、カスタムの増分反復機能を定義する必要があります：

例

def list_iter(name):
    """
redisリストのカスタム・増分反復
:param name: redis内のname、つまり：nameに対応するリストを反復します
:return: yield でリスト要素を返します
    """
    list_count = r.llen(name)
    for index in range(list_count):
        yield r.lindex(name, index)

# 使用
for item in list_iter('list2'): # このリストを走査
    print(item)

zscore(name, value)

nameに対応する順序付き集合内でvalueに対応するスコアを取得

print(r.zscore("zset3", "n27"))   # 获取元素n27对应的分数27

パイプライン（pipeline）

redisはデフォルトで、各リクエストの実行時に接続の作成（接続プールから接続を取得）と切断（接続プールへ返却）という1回の接続操作を行います。1回のリクエストで複数のコマンドを指定したい場合は、pipelineを使用して1回のリクエストで複数のコマンドを指定でき、デフォルトでは1回のpipelineは原子性のある操作です。

パイプライン（pipeline）は、redisが単一のリクエスト内で複数のサーバーコマンドをバッファリングするための基本クラスのサブクラスです。サーバーとクライアント間で繰り返し送受信されるTCPデータパケットを減らすことで、バッチコマンドを実行する機能を大幅に向上させます。

例

import redis
import time

pool = redis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = redis.Redis(connection_pool=pool)

# pipe = r.pipeline(transaction=False) # デフォルトでは、パイプライン内で実行されるコマンドは実行の原子性が保証されます。pipe = r.pipeline(transaction=False)を実行するとこの特性を無効にできます。
# pipe = r.pipeline(transaction=True)
pipe = r.pipeline() # パイプラインを作成

pipe.set('name', 'jack')
pipe.set('role', 'sb')
pipe.sadd('faz', 'baz')
pipe.incr('num')    # numが存在しない場合vauleは1、存在する場合valueは1ずつインクリメント
pipe.execute()

print(r.get("name"))
print(r.get("role"))
print(r.get("num"))

パイプラインのコマンドはまとめて書くこともできます。例：

例

pipe.set('hello', 'redis').sadd('faz', 'baz').incr('num').execute()
print(r.get("name"))
print(r.get("role"))
print(r.get("num"))
