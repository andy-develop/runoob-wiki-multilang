中国トップ10の最高のインターネット企業リスト、転職の参考にどうぞ

カテゴリ インターネット

No.10 新浪

福利厚生：

  • 彼らの収入は？毎年約14%昇給。年1回の旅行、四半期ボーナスあり。
  • 彼らの食事は？昼食には食事手当あり。
  • 彼らの住居と通勤は？オフィスには専用の仮眠室がある。通勤には便利な送迎バスがある。
  • その他の特典は？だいたい五険一金（社会保険・住宅積立金）、有給休暇、社員研修といった定番項目。

評価：3点

No.9 去哪儿网

福利厚生：

  • 彼らの収入は？一部の部門では年俸16か月分、5年間無利息の住宅ローン、さらにストックオプションがある。半年ごとに給与改定があり、試用期間中の社員も全額給与が維持される。
  • 彼らの食事は？食事手当とお菓子。
  • 彼らの住居と通勤は？旅行補助と部門単位の海外旅行でのチームビルディングは、去哪儿网の得意分野。
  • その他の特典は？五険一金や社員研修など。

評価：3点

No.8 奇虎360

福利厚生：

  • 彼らの収入は？四半期ごとに月給*25%*個人業績の四半期ボーナスがあり、1年間の四半期ボーナスを合計すると月給1か月分になる。年末ボーナスは月給*会社業績*個人業績で計算され、年間の総支給はおおむね14〜16か月分。
  • 彼らの食事は？360の社員食堂は「控えめな贅沢」で有名。料理がとても美味しいため、筆頭料理長の王シェフはこれまで4回もストックオプションを付与され、資産は1000万超え——いったいどれほど美味しいのか？！
  • 彼らの住居と通勤は？さまざまなテーマのオフィスや休憩室があり、なんと「喜羊羊」テーマまである！
  • その他の特典は？料理長がいれば、他はすべてどうでもいい！

評価：3点

No.7 百度

福利厚生：

  • 彼らの収入は？百度のオファーには年俸14.6か月分と書かれており、規定では年度途中に1か月分、年末に1.6か月分支給される。年末ボーナスは会社業績と個人業績が加味されるため固定ではないが、大きく変動することもない。
  • 彼らの食事は？1日2回、カートが席まで軽食を届けてくれる。休憩室の飲み物や果物は食べ放題。しかし百度が7位なのは減点項目があるからだ。百度の社員寮は、なんとダイエット効果があると言われている。
  • 彼らの住居と通勤は？百度の各ビルには「健康空間」が設置されている。健康空間では、医学的な背景を持つ健康アシスタントが、社員の日常の健康、健康診断、通院などに関する相談業務を担当している。健康空間には一般的なOTC医薬品が備えられており、社員の不調の症状に応じて24時間分の薬が配布される。

評価：3点

No.6 网易

福利厚生：

  • 彼らの収入は？過半数の社員が約25%昇給。年末ボーナスはなく、四半期ボーナスのみ。年間の最高で18か月分の給与に達する。主な特典はやはりゲーム部門にやや偏っており、彼らが全社の97%の利益をもたらしているからだ。
  • 彼らの食事は？网易の社員食堂も業界の良心と言われており、広州と杭州の本社では3食無料、上海支社では毎月300元の食事手当がある。
  • 彼らの住居と通勤は？杭州本社のオフィス環境は間違いなく中国ナンバーワンだ。他の追随を許さない。
  • その他の特典は？社員クラブとハイエンドなジムが网易の最大の見どころ。

評価：3.5点

No.5 搜狐

福利厚生：

  • 彼らの収入は？年間で約10%昇給。年末ボーナスはなく、四半期ボーナスのみ。年間の最高で18か月分の給与に達する。
  • 彼らの食事は？さらに毎月400元の食事手当がある。
  • 彼らの住居と通勤は？オープンなテーマの休憩室は、グループでのレジャー活動に適している。無料の送迎バスがあり、有給休暇はなんと15日間。
  • その他の特典は？目移りするほど豊富な社員研修プランと人材育成：各職種の研修クラス、職業スキル研修、イノベーションアイデア会、読書交流会、技術交流会など。

評価：3.5点

No.4 人人网

福利厚生：

  • 彼らの収入は？年末の特典は四半期ボーナス方式で、会社評価に応じて採点される。各四半期の上限は月給1.5か月分、下限はもちろんゼロ。この計算だと、社員は最高で年俸18か月分を受け取れる。特典はかなり良い方だ。
  • 彼らの食事は？コーヒー、アイス、果物、飲み物などがすべて揃っており、休憩エリアには社員が仮眠できるベッドまである。さらに毎月400元の食事手当がある。
  • 彼らの住居と通勤は？人人网の最もヤバい特典は、テンセントやアリババでさえ太刀打ちできない大技を用意していることだ：40万元の無利子住宅ローン計画！コーヒー、アイス、果物、飲み物などがすべて揃っており、休憩エリアには社員が仮眠できるベッドまである。
  • その他の特典は？家まで手に入るのに、これ以上何を望むの！

評価：4点

No.3 高德

福利厚生：

  • 彼らの収入は？高德地图部門の今年の年末ボーナスは月給4か月分超えと見込まれており、他の部門の年俸もすべて15か月分前後。高德内部にはチームのイノベーションを奨励するため、1000万元の社内クリエイティブ基金が設置されているほか、社員には最高30万元の大型無利子ローンも提供されている。
  • 彼らの食事は？社員には果物、飲み物、大量のお菓子が提供される。
  • 彼らの住居と通勤は？無料のフィットネスと無料の送迎バスを提供。
  • その他の特典は？なんと会社は、志玲お姉さん（リン・チーリン）が誕生日の社員を「お祝い」し、いち早く誕生日の祝福を届けてくれるという。こんな特典はIT男子には到底耐えられないだろう。全企業を秒殺する勢いだ！

評価：4点

No.2 阿里巴巴

福利厚生：

  • 彼らの収入は？給与なんて何だ。アリババは35億4千万元の福利厚生プランを打ち出した。内訳は30億元の無利子住宅購入ローン、5億元の教育基金、4000万元の物価補助だ。
  • 彼らの食事は？阿里巴巴杭州本社の社員食堂の運営は、専門の給食グループが請け負っている。社員が1万人以上いるため、アリババの食堂は規模も味も大学の食堂に似ている。
  • 彼らの住居と通勤は？テンセントと同様に、勤続3年を満了した社員は住宅購入のための20万〜30万元の無利子ローンを利用でき、さらに割引も受けられる。
  • その他の特典は？住宅など最も魅力的な実質的な特典に加えて、アリババの最も面白い点は、超大規模なチームビルディング活動を頻繁に開催していることだ。例えば、千人以上が参加するDota大会、集団結婚式、さまざまな大型祝典イベントなどがある。グループの規模が非常に大きくなっても、社員同士の結束力を維持できるよう努めている。

評価：4.5点

No.1 腾讯

福利厚生：

  • 彼らの収入は？基本給が高く、手当に依存していない。テンセントの平均給与は他のポータルサイトより約30%高い。
  • 彼らの食事は？社員食堂のほかに、テンセントで最も有名なのは社員専用のカフェ「image」（爱马哥）だ。あんなに素敵な環境なら、社員たちが爱马哥を好きになるのも無理はない。
  • 彼らの住居と通勤は？テンセントの「安居計画」――3年以内に10億元を投入し、初めて住宅を購入する社員に無利子の借入を提供する予定。昇給率は9.3%で、まさに最強の福利厚生と言える。勤続3年を満了した社員は20万〜30万元の無利子ローンを利用でき、6年以内に返済すればよい。
  • その他の特典は？フィットネス、水泳、酸素吸入、カラオケ、ダンス、ゲームなど、テンセントの社員向けレジャー・娯楽特典はすべて揃っている。

評価：5点満点〜
