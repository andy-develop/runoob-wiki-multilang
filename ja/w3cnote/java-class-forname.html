Java class.forname 詳解

カテゴリ プログラミング技術

ほとんどの人にとって、初めて目にするのはclass.forName(String className)このコードは、おそらくJDBCJDBC方式でデータベースに接続するときです。

例

import com.mysql.jdbc.Driver; import java.sql.*; public class JdbcDemo { public static void main(String[] args) throws SQLException, ClassNotFoundException { String url = "jdbc:mysql://127.0.0.1:3306/mydb"; String username = "root"; String password = "redhat"; Class.forName("com.mysql.jdbc.Driver"); Connection connection = DriverManager.getConnection(url, username, password); String sql = "SELECT * FROM msg"; PreparedStatement prepareStatement = connection.prepareStatement(sql); ResultSet resultSet = prepareStatement.executeQuery(); resultSet.next(); String address = resultSet.getString("address"); System.out.println(address); } }

Class.forNamecom.mysql.jdbc.Driver を渡すと、接続するデータベースが mysql であるとわかります。なぜでしょうか？ソースコードを見てみましょう。

@CallerSensitive public static Class<?> forName(String className) throws ClassNotFoundException { Class<?> caller = Reflection.getCallerClass(); return forName0(className, true, ClassLoader.getClassLoader(caller), caller); }

それが forName0 メソッドを呼び出していることがわかります。さらに追跡して見てみましょう。

private static native Class<?> forName0(String name, boolean initialize, ClassLoader loader, Class<?> caller) throws ClassNotFoundException;

native メソッドなので、ソースコードもここまでです。公式ドキュメントの説明を見てみましょう。https://docs.oracle.com/javase/7/docs/api/java/lang/Class.html#forName(java.lang.String)

Returns the Class object associated with the class or interface with the given string name, using the given class loader. Given the fully qualified name for a class or interface (in the same format returned by getName) this method attempts to locate, load, and link the class or interface. The specified class loader is used to load the class or interface. If the parameter loader is null, the class is loaded through the bootstrap class loader. The class is initialized only if the initialize parameter is true and if it has not been initialized earlier.

おおまかに訳すと次のようになります：指定されたクラスまたはインターフェースの Class オブジェクトを返します。classloader が指定されていない場合は、ルートクラスローダーが使用されます。initalize パラメータに true が渡された場合、指定されたクラスが以前に初期化されていなければ、初期化されます。JDBC の最初のステップでは、渡すパラメータは com.mysql.jdbc.Driver です。つまり、このクラスが初期化されることになります。このクラスの内容を見てみましょう。

public class Driver extends NonRegisteringDriver implements java.sql.Driver { static { try { java.sql.DriverManager.registerDriver(new Driver()); } catch (SQLException E) { throw new RuntimeException("Can't register driver!"); } } public Driver() throws SQLException { // Required for Class.forName().newInstance() } }

このクラスも非常にシンプルであることがわかります。コンストラクタと静的コードブロックがあります。クラスの初期化時には静的コードブロックの内容が実行されることは既に知っています。つまり、私たちがClass.forNameと直接書くことはDriverManager.registerDriver(new Driver)両者の機能は同等です。この書き方に変えて、もう一度試してみましょう。

public class JdbcDemo { public static void main(String[] args) throws SQLException, ClassNotFoundException { String url = "jdbc:mysql://127.0.0.1:3306/mydb"; String username = "root"; String password = "redhat"; //Class.forName("com.mysql.jdbc.Driver"); DriverManager.registerDriver(new Driver()); Connection connection = DriverManager.getConnection(url, username, password); String sql = "SELECT * FROM msg"; PreparedStatement prepareStatement = connection.prepareStatement(sql); ResultSet resultSet = prepareStatement.executeQuery(); resultSet.next(); String address = resultSet.getString("address"); System.out.println(address); } }

コードは正常に実行されました。

まとめると： Class.forNameこのメソッドの役割は、指定されたクラスを初期化することです。そして、私たちが指定した MySQL の Driver クラスでは、静的コードブロック内で JDBC の DriverManager を通じてドライバを登録しています。また、JDBC のドライバマネージャを直接使用して mysql ドライバを登録し、それによって（Class.forName() メソッドの）使用を代替することもできます。Class.forName。

    Class.forName() を理解する

    Class クラスの概念

    Class も Java クラスの一つであり、対応する Java クラスのメタ情報（メタ情報）を保持します。このクラスの構造を記述するために使われます。例えば、あるクラスにどのようなメンバーがあるか、どのようなメソッドがあるかなどを記述します。一般にリフレクションで使用されます。

    詳細な説明：Java ソースプログラム（.java ファイル）は、Java コンパイラによってコンパイルされた後、Java バイトコード（.class ファイル）に変換されます。クラスローダーは Java バイトコードを読み取り、java.lang.Class クラスのインスタンス（Class オブジェクト）に変換する役割を担います。つまり、Java では、各 Java クラスには対応する Class オブジェクトが存在し、この Java クラスの型情報を表します。

    クラスローディングの概念

    クラスを使用するとき（例えば、クラスのインスタンスを new するとき）、そのクラスがメモリにロードされているかどうかがチェックされ、されていなければロード操作が実行されます。

    クラスに対応する class ファイルのデータを読み取り、このデータを解析して、このクラスに対応する Class クラスのインスタンスを構築します。このとき JVM はそのクラスを使用できるようになります。例えば、そのクラスをインスタンス化したり、そのクラスの静的メソッドを呼び出したりできます。

    Java にはクラスを手動でロードするためのインターフェースも用意されており、class.forName() メソッドもその一つです。（結局のところ、これはそのクラスの Class を生成することです。）

    クラスローダーの概念

    名前の通り、クラスローダー（class loader）は Java クラスを Java 仮想マシンにロードするために使われます。一般に、Java 仮想マシンが Java クラスを使用する方法は次のとおりです。Java ソースプログラム（.java ファイル）は、Java コンパイラによるコンパイル後に Java バイトコード（.class ファイル）に変換されます。クラスローダーは Java バイトコードを読み取り、java.lang.Class クラスのインスタンスに変換します。そのような各インスタンスは 1 つの Java クラスを表します。このインスタンスの newInstance() メソッドを使用することで、そのクラスのオブジェクトを作成できます。基本的に、すべてのクラスローダーは java.lang.ClassLoader クラスのインスタンスです。

    クラス初期化の概念

    クラスがロードされた後、JVM はクラスの構造を記述する Class インスタンスを取得しています。しかし、このクラスを正常に使用するには、クラス初期化操作を行う必要があります。クラス初期化操作とは、静的変数の宣言や静的コードブロックを含む、クラスの静的ステートメントを一通り実行することです。

    Class.forName() メソッド

    このメソッドの意味は、パラメータで指定されたクラスをロードし、それを初期化することです。

    JDBC でのデータベース接続への応用

    ここまで来れば、説明するまでもなく、読者も理解できるでしょう。JDBC 方式でデータベースに接続する際に、なぜClass.forName('ドライバクラス名')メソッドを実行するのかがわかります：ドライバクラスの class ファイルをメモリにロードし、このドライバクラスの構造を記述する Class クラスのインスタンスを形成し、このドライバクラスを初期化します。これにより JVM はそれを使用できるようになります。これが Class.forName() メソッドの意味です。

    データベース開発の経験がある方は気づくかもしれません。データベースドライバパッケージをロードするとき、newInstance() メソッドを呼び出さないものもあるのはなぜでしょうか？つまり、JDBC でデータベースに接続する書き方には、Class.forName(xxx.xx.xx); というものと、Class.forName(xxx.xx.xx).newInstance() というものがあります。なぜこの2つの書き方があるのでしょうか？

    先ほど述べたように、Class.forName("");の役割は、JVM に指定されたクラスを検索してロードするよう要求することです。クラス内に静的初期化子があれば、JVM は必ずそのクラスの静的コードブロックを実行します。そして JDBC 仕様では、この Driver クラスが DriverManager に自身を登録することが明確に要求されています。つまり、どの JDBC Driver の Driver クラスのコードも、次のようでなければなりません：

    public class MyJDBCDriver implements Driver { 
    static { 
        DriverManager.registerDriver(new MyJDBCDriver()); 
    } 
}

    静的初期化子の中で既に登録が行われているので、JDBC を使用する際にはClass.forName(XXX.XXX);だけでよいのです。

    Class.forName() と xxx.class の違い

    すべてのクラスは、最初に使用されるときに JVM に動的にロードされます。プログラムがクラスの静的メンバーへの最初の参照を作成すると、そのクラスがロードされます。これは、コンストラクタがクラスの静的メソッドでもあることを証明しています。たとえコンストラクタの前に static キーワードがなくてもです。したがって、new 演算子を使用してクラスのオブジェクトを作成することも、クラスの静的メンバーへの参照とみなされます。

    したがって、Java プログラムは実行開始前に完全にロードされるわけではなく、各部分が必要になったときにロードされます。

    クラスローダーはまず、このクラスの Class オブジェクトが既にロードされているかどうかを確認します。まだロードされていない場合、デフォルトのクラスローダーはクラス名に基づいて .class ファイルを検索します。このクラスのバイトコードがロードされるとき、それらは検証を受け、破損していないことが確認されます。

    Class オブジェクトは必要なときにだけロードされます。static 初期化はクラスロード時に行われます。

    一方、Class.forName()、このメソッドは Class クラスの static メンバーです。Class オブジェクトは他のオブジェクトと同じように、その参照を取得して操作することができます。forName() は Class オブジェクトの参照を取得する方法の一つです。これは、対象クラスのテキスト名を含む String を入力パラメータとして受け取り、Class オブジェクトの参照を返します。forName() メソッドは、あるクラスがまだロードされていないことを見つけると、積極的にそのクラスをロードし、その過程でそのクラスの static 節が実行されます。

    Java には、Class オブジェクトへの参照を生成するもう一つの方法も用意されています。それはクラスリテラルを使用するものです。形式は：xxx.class の形です。しかし、この形式で Class オブジェクトの参照を作成する場合、Class オブジェクトは自動的に初期化されません。初期化は、静的メソッドまたは非定数静的フィールドへの最初の参照が行われたときに初めて実行されるよう遅延されます。

    public class Initable {  
    static final int staticFinal = 47;  
    static final int staticFianl2 = ClassInitialization.rand.nextInt(1000);  
    static {  
        System.out.println("Initializing Initable");  
    }  
}
    public class Initable2 {  
    static int staticNonFinal = 147;  
    static {  
        System.out.println("Initializing Initable2");  
    }  
}
    public class Initable3 {  
    static int staticNonFinal = 74;  
    static {  
        System.out.println("Initializing Initable3");  
    }  
}
    public class ClassInitialization {  
    public static Random rand = new Random(47);  
    public static void main(String[] args) throws ClassNotFoundException {  
        Class initable = Initable.class;  
        System.out.println("after creating Initable ref");  
        //Does not trigger initialization  
        System.out.println(Initable.staticFinal);  
        //Does trigger initialization  
        System.out.println(Initable.staticFianl2);  
        //Does trigger initialization  
        System.out.println(Initable2.staticNonFinal);  
        Class initable3 = Class.forName("chapter13.t2.Initable3");  
        System.out.println("after creating Initable3 ref");  
        System.out.println(Initable3.staticNonFinal);  
    }  
}

    実行出力結果：

    after creating Initable ref  
47  
Initializing Initable  
258  
Initializing Initable2  
147  
Initializing Initable3  
after creating Initable3 ref  
74

    initable 参照の作成からわかるように、.class 構文を使用してクラスへの参照を取得するだけでは初期化は発生しません。しかし Class.forName() は即座に初期化を実行します。static final 値が「コンパイル時定数」である場合、Initable.staticFinal のように、その値は Initable クラスの初期化を必要とせずに読み取ることができます。しかし、単にフィールドを static および final に設定しただけでは、この動作を保証するには十分ではありません。例えば、Initable.staticFianl2 へのアクセスは、コンパイラ定数ではないため、型の初期化を強制します。
