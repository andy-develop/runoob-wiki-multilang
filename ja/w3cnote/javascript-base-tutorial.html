属性の読み書き操作の注意点

  • JSのプロパティには「-」を使用できない。例えば font-size は fontSize に変更する
  • class はJSでは予約語である。JSでclassを使用する場合は className を使う
  • すべての相対パスを判定に使ってはいけない（例：imgのsrc、またhref）
  • 色の値は判定に使わないこと（red、#f00、rgb(250, 0, 0)などの書き方があるため）
  • 相対パスも判定に使わないこと
  • innerHTMLの値を判定に使わないこと
  • IE6、IE7、IE8ではフォーム要素のtypeは変更できない。サポートされておらず、エラーが発生する。その他はすべて可能。
  • 一部のブラウザでは、float値を直接変更することはサポートされていない場合がある。JSでは、IE(styleFloat)と非IE(cssFloat)で区別して対応できる。
  • 判定に使えないものは、スイッチを作成し、ブール値を利用して実現できる

カスタム属性の応用

カスタム属性を使用すると、要素にスイッチ属性を追加して、制御スイッチとして使用できる。次の例のとおりである：
window.onload = function(){
  var aLi = document.getElementsByTagName('li');
  // var onOff = true; 一个onOff只能控制一个开关。要为多个元素设置各自的开关，就要给每个元素加个onOff开关。
  
  for(var i=0; i<aLi.length; i++) {
    aLi[i].onOff = true;
    aLi[i].onclick = function(){
      if (this.onOff){
        this.style.background = 'url(img/active.png)';
        this.onOff = false;
      } else {
        this.style.background = 'url(img/normal.png)';
        this.onOff = true;
      }
    }
  }
}

isNaNの応用実例

NaN: (not a number)。NaNは数字ではない数値型である。すべての数値は数値型であるが、すべての数値型が数値であるとは限らない。
  • NaNは数値型であるが、数字ではない。
  • プログラム内にNaNが出現した場合、それは必ず不正な演算操作が行われたことを示している。
  • NaNはfalseである。
  • NaNは自分自身とも等しくない。
var a = Number('abc');
//alert(a); //NaN
//alert(typeof(a)); //number

if(a) { //会弹出‘假’，说明NaN是false
  alert('真');
} else {
  alert('假');
}

//alert(a === a); //false NaN比较，比出false
isNaN：is not a Number は「数字ではないかどうか」（数字ではない）という意味である。 isNaN(); はメソッドであり、処理を行うために使用する。
  • 特定の値が数字かどうかを判定するのに役立つ。
  • 数字を好まない、数字を嫌う（数値型を嫌うわけではない。isNaNはNaNに出会うと非常に喜び、trueを返す。しかしNaNは数値型である）。数字を判定するために使用する。例：alert(isNaN(2)); はfalseを返す。alert(isNaN('我爱你')); はtrueを返す。alert(isNaN(function(){})); はtrueを返す。
isNaNの判定プロセスは、括弧内のものをNumberに渡し、Numberが数値に変換できればfalseを返し、変換できなければtrueを返す。
alert(isNaN('250'));
//Number() '250' => 250 => false

alert(isNaN(true));
//Number() true => 1 => false

alert(isNaN([]));
//Number() [] => 0 => false

ブラウザの「JSパーサー」

"JSパーサー"：ブラウザ内でJSを読み取るための専用プログラム。少なくとも次の2つのことを行います（もちろん他にもあります）：
  1. 準備作業（「何かを探す」）：var、function、引数に基づいてものを探す——JSの事前解析（プリパース）a = 未定義（undefined） すべての変数は、コードを正式に実行する前に、事前に値が代入されています：未定義。 fn1 = function fn1(){alert(2);} すべての関数は、コードを正式に実行する前に、関数ブロック全体です。 同名のものが出てきたら、1つだけ残す。
  2. コードを1行ずつ解釈する。1行読むごとに、事前解析したライブラリの中を確認しに行く。式（= + - * / % ++ – ! 引数……が付いているものはすべて式。値を変更できるのは式）に出会うと、ライブラリの中の値を変更しに行く。

function fn1(){alert(2);}

alert(a); //弹出：function a(){alert(4);}
var a=1; //预解析中的a改为了1
alert(a);  //弹出1
function a(){alert(2);}//函数声明，没有改变a的值。什么也没发生。
alert(a); //继续弹出1，因为a在预处理库里面的值没有被改过。

alert(a); //继续弹出3
a(); //报错 a is not a function
上記のコードの事前解析でのプロセスは次のとおりです： 1）事前解析： var function 引数 …… var a = 1 を読む => a は未定義 function a(){alert(2);} を読む => a = function a(){alert(2);} 変数と関数が同名になった場合は、関数だけを残す： a = function(){alert(2);} var a = 3 を読む => a は未定義。ここでは上記の名前がaの関数と同名なので、やはり a = function(){alert(2);} を保持する。 function a(){alert(4);} を読む => a = function a(){alert(4);} 先ほどの a = function(){alert(2);} と同名になり、文脈から、後の関数が前の関数を上書きする。したがって、事前解析では a = function(){alert(4);} だけが残る。 2）1行ずつコードを解釈する。式を読むと、式は事前解析の値を変更できる。引数も事前解析の値を変更できる。関数呼び出しに遭遇すると、また2つのことを行う：事前解析、1行ずつのコード解析。関数宣言は式ではないので、事前解析内の値を変更しない。

currentStyleとgetComputedStyleの応用

  • getComputedStyleが取得するのはコンピューター（ブラウザ）が計算した後のスタイルですが、IE6、7、8とは互換性がありません。

属性判定法、バージョン検出法でブラウザ間の互換性問題を解決します。 ~~~ js function getStyle( obj, attr) { return obj.currentStyle ? obj.currentStyle[attr] : getComputedStyle( obj )[attr]; } ~~~注意事項：
  • 上記の方法で background などの複合スタイルを取得する場合は、その方法で取得しないでください。ブラウザ間で互換性の問題があります。上記の方法は単一スタイルを取得するために使い、複合スタイルを取得するためには使わないでください。
  • 上記の方法を使うときは、余分なスペースを入れないよう注意してください。
  • 上記の方法を使うときは、未設定のスタイルを取得しないでください。ブラウザ間で互換性がないためです。
  • Firefox 4.0より前では、getComputedStyleの後に引数を付けないと問題が発生するバグがありました。そのため、getComputedStyle(obj, false)と書く人もいました。そのfalseはこのバグを解決するためのものです。ここは0でも、他の任意の引数でも構いません。ただし、現在のFirefoxはバージョンが高いため、この問題はあまり見られません。

  • .indexOf()ある文字または文字列が文字列全体の中でどの位置にあるかを返します。str.indexOf('m', 5) は、str文字列の5番目から後方に文字mの位置を探すことを意味します。indexOf()で見つからない場合は-1を返します。左から右へ探します。2番目の引数が負の数の場合は、デフォルトで0として扱われます。
var str = '菜鸟教程 - 学的不仅是技术，更是梦想！'；
var s = '菜鸟教程';
var i = 0;

for ( ; str.indexOf(s, i) != -1; ){
    alert(str.indexOf(s, i));
    i = str.indexOf(s, i) + s.length;
}

或

while(str.indexOf(s, i) != -1) {
    alert(str.indexOf(s, i));
    i = str.indexOf(s, i) + s.length;
}
  • .lastIndexOf()右から左へ探します。数字の引数を指定して、どこから前に探し始めるかを指定することもできます。

比較系、切り出し系

  • 文字列の大小比較は、文字列の0番目の文字のUnicodeエンコーディングを比較します。
  • .substring(n, m)n番目からm番目までの文字を切り出します。mがない場合は、デフォルトで最後まで切り出します。str.substring(2, 0); と str.substring(0, 2); の結果は同じです。substringは2つの引数の大小を判定し、後の引数が前の引数より小さい場合は、自動的に2つの引数を入れ替えます。括弧内に引数がない場合は、0番目から最後まで、つまり文字列全体を切り出すことになります。引数に負の数がある場合は0として扱われます。
  • .slice(n, m)str.slice(0, 2) と str.slide(2, 0) は結果が異なります。後者は結果が見つかりません。なぜなら、.slice()メソッドは引数の大小を判定して位置を交換しないからです。str.slice(-2); は最後の1文字から最後から2番目までを切り出します。-1は最後の1文字を表します。str.slice(-4, -2); は最後から4番目から最後から2番目までの文字列を切り出します。

大文字・小文字変換、splitによる文字列分割

  • .toUpperCase()大文字に変換
  • .toLowerCase()小文字に変換
  • .split()文字列を配列に分割します。var str = 'www.miaov.com'; str.split('.'); => ["www", "miaov", "com"]；var str1 = 'leo'; str1.split(); => ['leo']；str2 = 'leo'; str2.split(''); => ["l", "e", "o"]；var str3 = '/www.miaov.com/'; str3.split('/'); => ["", "www.miaov.com", ""]；var str4 = '2013-11-29-23-07'; str4.split('-', 3); => ["2013", "11", "29"]
  • .join()メソッドは、配列内の各要素を連結するために使用します。var arr = ['aa', 'bb', 'cc]; arr.join(); => 'aa,bb,cc' .join() の括弧内に何も書かない場合、デフォルトでカンマで区切られます。arr.join(''); => 'aabbcc' ； arr.join('-'); => 'aa-bb-cc'
