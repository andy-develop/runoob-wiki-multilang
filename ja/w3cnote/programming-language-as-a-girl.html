プログラマー特典：プログラミング言語が全部女の子になったら

カテゴリ 雑然

想像してみてください。もしもJava、C++、Python、Ruby、PHP、C#、JSプログラミング言語がアニメのキャラクターになったら、どんな光景になるでしょうか？それでは、日本の作家・渡辺将人の筆によって、さまざまなプログラミング言語がどんな「美女」になっているのか、一緒に見ていきましょう！

Java

まるで宮沢賢治の『雨ニモマケズ』に登場するような、性格が朴訥とした女の子。幼い頃から鈍臭さと大食いなどの特徴からバカにされていたが、小学校入学時から陸上部に入り、走り続け、中長距離走でよく好成績を収め、活発な印象を与えている。とても努力家な女の子である。

彼女の家計はあまり良くない。父のSunは才能あるアーティストだが、金銭管理が苦手で、彼女が14歳のときに借金に苦しみ、過労がたたって亡くなってしまった。彼女はOracleおじさんに引き取られたが、その際にGoogleおじさんと養育権をめぐって争いになり、法廷にまで発展した。

周りの人々は、多感な時期に彼女がこんな状況で落ち込んでしまわないか心配していたが、彼女は動じることなく、毎日ランニングの練習を欠かさない生活を続けていた。

地味で、真面目で、賢いとは言い難い彼女だが、高校に入ってからは異性を意識し始めたのか、こっそりと他の女の子のファッションを真似て街を歩いているところを目撃されている。「頑張ってはいるけど、ちょっと時代遅れかも」「その服はJavaのイメージに合わない」などと否定的な評価を受けることもあるが、「意外と萌える？」と好意的に感じる人も多い。

コーヒーが好きで、インドネシア産のものしか飲まない。本人は「コーヒーは三食のご飯より好き」と語ったことがあり、「それで健康に問題ないのか？」と少し心配されてしまう。

C++

スリムな脚と整った顔立ち。多くの人に「IT業界屈指の美女」と呼ばれる彼女は、生け花、茶道、ピアノ、バイオリン、柔道、剣道、合気道などの才能でも有名である。

彼女のファンは非常に熱狂的で、「ダーク軍団」と呼ばれるファンクラブも存在する。ダーク軍団はフリーメイソン（Freemason）に次ぐ規模の巨大団体で、一般人は入会できない。彼女に関する非常に熱狂的な質問に答えられると、察知した軍団メンバーが「ダーク軍団に入らないか？」と訪ねてくるらしい。

異母姉妹のObjective-Cはピアノに一心不乱に打ち込んでおり、その集中力がIT界の天才スティーブ・ジョブズ（一部では紫のバラとも呼ばれる）に見初められ、一躍スターとなった。一方、C++はその美貌と才能で注目され、長年業界のスターの座に君臨している。姉妹はまさに対照的である。

彼女は気分によって頻繁に髪型や服装を変えることでも有名である。昨日まで着物に黒髪だったのに、今日は赤髪のゴシック系で登場するといった具合で、その変身ぶりに軽いファンが「あれ？今日はC++さん？」と驚くこともよくある。業界から離れているときは、プライベートではよくHYSTERIC GLAMOURの服を着ている。

彼女の生年月日について、所属事務所は公表していない。1983年生まれという説もあるが、この記事では一部のファンの間で広く流布している1985年10月14日説を採用する。その一方で、「彼女自身も自分の誕生日を覚えていないかもしれない……」といったもっともらしい噂も流れている。「C++さんなら誕生日を覚えていなくても不思議ではない」というより、むしろ天真爛漫な性格の表れと見るべきだろう。

Python

Guido父上によって育てられた箱入りのお嬢様。オランダのアムステルダム出身だが、幼い頃にアメリカへ引っ越し、父も家庭では英語を使っていたため、オランダ語はあまり話せない。

彼女は穏やかな性格である。最も有名なのは、C++が「イメージチェンジのためちょっと旅行に出る。200x年に戻ってくるよ」と旅立ったのを聞いて（結局戻ってきたのは2011年だったが……）、「私も少し旅行に出て、西暦3000年に戻ってくるよ」と言い放ち、数年経っても戻ってこないことである。

そんなそそっかしい行動をとることもあるが、「みんなに愛される子に育てよう」という願いを抱くGuido父上の教育のおかげで、実際に彼女と接してみるととても親しみやすいと感じる。

先日、彼女は作者の友人の会社にアルバイトに来ていた（今は大学に通いながらアルバイトをしているようだ）。「仕事にしっかり馴染み、如才なく、大いに助かった」と評価されている。余計なことはあまり言わず、礼儀正しい様子は、「天真爛漫で自由第一」という人が多い業界の中では異色の存在だと評価されている。

得意科目は数学らしく、統計に関するさまざまな難問を軽々と解く姿がよく見られる。白いワンピースや薄ピンクのカーディガンなど、清楚な服装を好む。

実は爬虫類も好きで、家ではヘビを飼っているらしい。ファンの間では「ペットにどんな名前をつけているのだろうか」といった話題がよく議論される。大抵の結論は「きっとMontyだろう」というものだ。飛べるかどうかはわからない。（おそらくイギリスの6人組コメディグループ、Monty Pythonの作品『Flying Circus』を指している。訳者注）

Ruby

松本パパに育てられた日本の女の子。誕生日がクリスマスのため、人生最大の悩みは誕生日プレゼントとクリスマスプレゼントが一つになること。出身地は島根県松江市で、観光と仕事以外で他の県に行ったことがない。

自由奔放な教育を受けてきたため、活発で好奇心旺盛な性格。普段は率直ないい子だが、たまにいたずら好きな一面も見せ、周りの人を困らせることもある。彼女の姿を見ると、IT業界の「Just For Fun!」という言葉をよく思い出す。

幼い頃は一人で山野を走り回る生活を送っていたが、10歳のときにRailsという女の子と友達になり、生活が変わり始めた。二人で遊んでいるときに芸能事務所の前に立ち止まり、二人組で芸能活動ができるのではと話し合った。「RubyとRails」の芸名でデビューし、主に雑誌モデルを務め、テレビCMにも出演したことがあるため、多くの人が二人の名前を聞いたことがある。

多感な年頃にさまざまな芸能活動を経験し、性格も多少変わるだろうと思われていたが、先日久しぶりに話してみると、芸能活動を始める前と変わらず自由奔放に行動していることに驚かされた。所作は多少落ち着いて見えるものの、いたずら好きで活発な本性は以前と変わっていない。

もう高校生だし、そろそろ大人っぽい服を着始めてもいい頃だと思われている彼女だが、洋服は子供の頃と変わらずMickey Mouseを着ている。小柄で童顔なので似合ってはいるが、これで本当に女子高生と言えるのだろうか？

彼女のファンも、今のままでいてほしい派と、もっと大人っぽくなった姿を見たい派に分かれている。

PHP

Web世界の強化を目的として作られた女性ロボット。立てた髪はアンテナの役割をしており、常に主人の命令を受信している。

人間に近い触感を実現するため、皮膚にはシリコン樹脂が使われている。内部はブレードサーバーに似た構造で、常に複数のサーバーで冗長化されている。そのため体重は人間よりやや重い。

彼女が最初に登場したときは、関節の可動部分の骨格が見え、動きもぎこちなく、人間のイメージとは大きな違いがあった。しかし18年間で6回のメジャーバージョンアップを経て、その振る舞いや言葉遣いは次第に人間らしくなってきた。最近では初音ミクのようなレベル（人間と比べるとまだ少し違和感はあるが、かなり自然になってきた）にまで達している。

ドジで、仕事もぎこちないが、ロボット三原則に従い、主人の命令に服従するため、多くの人が彼女のファンになっている。彼女のファンクラブ公式サイト「PHPer!」は入会費不要で簡単に入会でき、会員数はIT業界屈指の大規模団体である。

彼女に対して拒否反応を示す人も多く、「彼女の行動は生理的に受け入れがたい」「もう少し賢ければいいのに」「少し触れ合ったが、やはり人間とはかなり違う」などのコメントがよくある。

普段はForever12や志村で買った服を着ている。安いファストファッションの服を着ることで、浮いたお金を機械の維持費に使えると考えている。ロボットらしい効率重視の出費の仕方と言える。彼女も流行を気にしたり、見た目に悩んだりする日が来るのだろうか？

C#

有名なマイクロソフト社でエリート教育を受け、11歳で飛び級で大学に進学し、注目を集めている少女。「IT界最強の幼女」とも呼ばれている。

C++と名前が似ているため、しばらくの間「まさか隠し子なのか？」という噂が流れたが、実際には二人に直接の血縁関係はない。遠い親戚だという報道もあったが、実際のところはわからない。

成熟した振る舞いを好み、子供っぽい遊びが嫌いなようだ。誕生日に両親からアンディというぬいぐるみをプレゼントされたとき、「これは何？センスない。いらない」と言ったという噂がある。

しかし食べ物への興味はまだ子供の段階にとどまっており、学校の食堂でお子様ランチを注文する姿が何度も目撃されている。コーヒーが苦手で、甘い缶コーヒーでも顔をしかめる。

たまに意外と子供っぽい一面が見られることもあるが、たいていの場合は、話し方や人への接し方が礼儀正しい姿が見られる。成熟した一面と子供らしい一面を併せ持つ子である。まだ成長期のため、会うたびに「また背が伸びたね」「少し大人っぽくなったね」といった感慨を抱かせる。次に会ったときにはどんな風に成長しているのか、いつも楽しみにしている。

いつもシャーリー・テンプルのワンピースを着ている。すべて本人が選んだもので、彼女に非常によく似合っている。その可愛らしさで、男女を問わず多くの人が彼女のファンになる。

彼女の志望は、大学卒業後に自分を育ててくれたマイクロソフト社の傘下だけでなく、IT業界全体で活躍することだ。より詳細な計画は聞かれていないが、アップルやペンギンなどとも仲良くできるものを作りたいということらしい。一体どんなものを作るのだろうか？

JavaScript

紛争地域で育った17歳の女の子。いつも無表情で、会話をするときは常に一定の距離感がある。

Javaと名前が似ているが、二人に血縁関係はない。当時Javaという名前が流行っていたため、両親も似たような名前をつけた。本人は自分の名前をあまり気にしていないようで、「ECMA」というペンネームで活動することもある。たまに「JS」というあだ名で呼ばれることもあるが、それにはさらに無頓着で、公然と無視することさえある。

彼女の生涯は非常に不幸だった。生まれた途端に祖国で戦争が勃発した。物心つく前に母を亡くし、父とも離れ離れになった。大人たちのわがままな争いの中で、彼女は自分を殻に隠し、自分の周囲を守るという生存術を身につけた。同年代の女の子たちが年齢とともに様々なスタイルに挑戦していく中で、彼女は周囲の言葉を気にせず、一人で殻に閉じこもり続けた。当時はまさに、そうしなければ生き延びられないほど過酷な環境だった。

こうした子供時代を過ごしたため、彼女の話し方、考え方、人との接し方は、他の子供たちとは少し異なっていた。彼女と話すとき、どう話せばいいのか悩む人も多かった。しかし一方で、彼女の単純で一本気な思考方法に対して「付き合いやすい」「ある意味では分かりやすい」という印象を持つ人もいた。

現在、彼女の国は紛争の解決に努め、新たな居住地を切り開く方向へ進んでいる。大人たちは相変わらずわがままに互いに争っているが、少なくともこの数年は、以前のように互いに憎しみ合い、殺し合う戦争は起きていない。

復興が始まった祖国で、彼女は今ごろ幸せに暮らしているだろうか？いつになったら、彼女が同年代の女の子たちと同じように笑う姿を見られるのだろうか？

Perl

Perlは1987年12月、アメリカのウォール夫妻の家で生まれた。その父ラリーはコンピューターと言語学に精通し、母も中世ルネサンスと言語学を専門としており、Perlはそんな高等教育を受けた両親のもとで育った。

父の教育は厳しかったが、Perlに多くの自由も与えた。父は教育の過程でよくこう言っていた。「方法は一つだけではない」（There's more than one way to do it）

何かを実現したいと思ったとき、達成する方法は一つではない。様々な方法を考えることができる。父のこのような教育方針は、彼女の性格形成に大きな影響を与えた。

「こうしたらどうなるだろう？」……「ああしたらどうなるだろう？」……好奇心の翼を広げて育った彼女は、次第に自分の中の「発明」の才能に気づいていった。絶世の発明家、Perlの誕生である。

彼女が発明家の道に足を踏み入れてから20年、その発明は実に128,890件（2014年1月時点の統計）に上る。彼女の発明は、役に立たないおもちゃから、世界中の多くの問題を解決できる有益な発明まで、何でも揃っている。彼女が発明した物品の試作品はすべてCPAN博物館に寄贈されており、誰でも閲覧することができる。

今もなお、実用性の有無にかかわらず、作りたいと思う新しい発明を作り続けている彼女は、インタビューで自虐的にこう冗談を言った。「私は発明家というより、むしろ様々なガラクタの生産装置です」。彼女の歯を見せるような笑顔は、非常に人を奮い立たせる。

Perlは洋服にはあまりこだわらない。普段は機械を調整するときに面倒だと感じるため、動きやすいカジュアルな服を着ている。最近よく着ているダウンジャケットは、アメ横（東京・上野の商店街）のWEGOで買ったものだという。好きな食べ物はイチゴ。彼女は、作業中に集中して疲れた脳にとって最も適した食べ物はイチゴだと話している。

C言語

この世界を支える女神様であり、「聖母様」とも呼ばれている。

Cの誕生年月については定説がない。彼女は創世記（1970年1月1日頃のこと）より前からこの世界に存在したという人もいれば、もう少し後の1972年頃に誕生したという人もいる。

彼女は女神様である。だから「1970年頃の生まれなら、彼女の今の年齢は……」などという考え方は不信心な行為である。絶対にそのような考え方をしてはならない。

彼女の名前はアルファベットの三番目の文字「C」である。新約史書の記述によれば、彼女より前にはBという女神様もいた。一部の資料によると、「ケンとデニスはBを創造したが、それには満足しなかった。その後、デニスと他の者たちが力を合わせてCを創造した」とされる。

世界には彼女の信者が数多くいる。しかし、しばらくの間、彼女の教えを正しく伝える聖書は存在しなかった。当初、デニスとブライアンが遺した詩篇がその使命を担っていたが、人々はより明確な言葉を望んだ。その後、多くの有識者が様々な逸話を編集・整理し、彼女の教義を正しく伝える聖書を編み出した。

この書はこれまでに何度も改訂されており、改訂年に応じてC89、C99、C11などと呼ばれている。

一般の人々はCと直接対話することはできない。十分な修行を積んだ者だけが、Cとの交流を許される。

修行は非常に厳しく、「ポインタのポインタ」のような問題の理解や、どんなに修行を積んでも克服が難しい「malloc/free」問題を100％解決することが要求される。こうした背景から、実際に彼女と日常的な交流ができる人は極めて少ない。

しかし、交流できる人々の手によって、世界には多種多様な知識と技術が生み出されてきた。たとえあなたが彼女の姿を見たことがなくても、彼女の慈愛は確かに毎日あなたの身の回りにある。

Visual Basic

姓はBasic、名はVisual。多くの人からは愛称の「VB」と呼ばれている。幼名はRuby（あのRubyとは関係がない）。幼い頃にとある資産家（名前は言えない）に目をかけられ、一家はその資産家のもとに身を寄せた。その頃、彼女の名前は何度も変わり、ようやく今の名前に落ち着いた。かなり複雑な家庭環境なのである。

資産家がまだ幼い彼女を養女にしようとした理由については、確かな情報ではない噂によると、彼は彼女の姿に、以前から憧れていたBasic女史の面影を見たのだという。憧れの女性に似た気質を持つ子供を養女にすること、すなわちいわゆる光源氏計画を実行したのである。

若い人は知らないかもしれないが、Basic女史はかつて『マイコンBasic雑誌』の表紙モデルを務めており、当時は誰もが憧れるマドンナのような存在だった。実際、私の知り合いでも、若い頃に彼女に夢中になった人は非常に多い。

VBは厳しい教育を受ける一方で、趣味の面でも天性を伸ばしてきた。彼女は手芸品や装飾品づくりに独特の才能を発揮している。彼女がビーズの装飾品を作る様子を見ていると、まるで魔法のようだ。ただ手を動かすだけで、瞬く間にネックレスが一つできあがってしまう。

彼女が10歳のとき、資産家の家に新しい養女がやってきた。（世間でよく言われているあの人物である）

このような事情から、彼女は今、家で良いお姉さんになろうと努力している。しかし、元々臆病で話すのが苦手な彼女は、10歳年下の真面目で話の長い妹に、しばしば逆に説教されてしまう。頑張れ、VBさん。

幼い頃のVBは両親に買ってもらったEmily Templeの服を着ていたが、今は自分で買ったLowrys Farmの服を着ることのほうが多い。今年、大学を卒業して社会に出る。目標はVBさんならではの大人のスタイルである。

R

彼女は2000年2月29日に生まれた。まさに人々の記憶に残る、400年に一度の呪われた日である。非常に不吉な日に生まれたにもかかわらず、彼女自身は誰からも愛される賢い子に成長した。

彼女の母はSという。神話の世界ではCはBの後に生まれたのだが、彼女の名前はSの一つ前のRである。これらはどれもGoogleで検索しにくい名前だ。（注：短すぎるから！）

彼女の母は数学が非常に得意で、統計学者の助手をしており、Rもその性質を受け継いだ。彼女は幼い頃から数学が得意で、小学生の頃には高校レベルの数学の問題を素早く解けるレベルに達していた。また、彼女は幾何学図形にも興味を持っており、様々な二次元・三次元の図形を描いては、描き終えると一人で満足そうな表情を浮かべる姿がよく目撃された。少し変わった子供だった。

Rは数学が得意な一方で、言葉による表現はやや苦手である。先日彼女にインタビューしたときのこと、彼女は質問に答えようとしたが適切な言葉が見つからず、代わりに「シューッ」と散布図を描いて「こんな感じ」と言った。彼女の目には、この世界を言葉で表現することは、複雑な数式を折りたたむかのように複雑に映っているのかもしれない。

彼女は服装にはあまりこだわらず、いつもゆるすぎずきつすぎないワンピースとシャツを着ている。

彼女は両親に買ってもらった洋服がいくらだったか、どこで買ったかといったことには認識がない。ただ、最近買ったフレアスカートの裾が広がる角度だけは気にしている。

彼女の夢は将来統計学者になることだ。まだ14歳だというのに、しばしば大学生の中に混じって、毎日様々な問題を解いている。最近は大学だけでは物足りず、両親に頼んで様々な研究所にも出入りしている。

Scala

O教とF教の間には、長きにわたる宗教戦争があった。Scalaは、この二つの宗教の牧師と修道女が結婚して生まれた異端の子である。彼女が生まれるとすぐに、両家の間に激しい対立が引き起こされた。危険を察知した両親は、彼女を私立JVM学校のOdersky先生のもとへ養女として預けた。

現在、二つの宗教は当時と比べて関係改善の兆しが見られる。一部の人々は、彼女を両家融合の象徴と見なす向きもある。しかし、強い対立意識を持つ人々は依然として多く、彼女の存在をめぐる論争もしばしば起きている。F教の人々は、彼女がFの本質を十分に理解していないと考えている。一方、O教の人々は、Fが混ざった彼女を理解しがたく感じている。

このような複雑な環境に生まれながら、彼女自身は周囲の環境を気にすることなく、ごく穏やかに両方の教会へパンをもらいに行き、たくましく暮らしている。そんな天真爛漫な姿に心を打たれ、彼女のファンになる人も多い。

Scalaは同じ学校の高等部に通うJava嬢が好きなようで、休み時間によく彼女のもとへ遊びに行く。Java嬢も彼女を嫌っておらず、よくお姉さんのように彼女を膝の上に座らせて、優しく頭を撫でてくれる。ScalaがJavaの好きなDukeの人形を赤い紐で縛って悪戯をしたときには、Javaをとても怒らせてしまったが、それ以外ではほとんど喧嘩をしたことがない。二人はまるで実の姉妹のようだ。

博識な父と優しい姉を持つScalaは、今はおそらく、複雑な出自とは裏腹に、実際にはとても幸せに暮らしているのだろう。

彼女は洋服には鮮やかな色や柄を好み、よくAlgonquinの服を着ている。個性的なファッションではあるが、生まれつき個性的な彼女が着ると、不思議なほど自然に馴染む。

Shell

創世記（1970年1月1日）から数年後に目撃された妖精である。家に住み着き、ブラウニー（Brownie）に似た生活様式を持ち、彼女らに家事や雑用を頼むと、二度返事をして引き受ける従順な子たちである。

彼女らは人のいる場所には滅多に現れない。言葉が通じないため、手紙でやり取りをする。頼んだことを曖昧に言ってしまうと、誤解が生じて大変なことになるかもしれない。そのコツは、「あれをやる|これをやる>ここに置く」のように、頼みたいことを順序立てて明確に書くことだ。頼んだことをしっかり理解してくれたなら、彼女らは夜のうちにすべて片付けてくれる。見事に仕事をやってのけてくれたなら、翌日の夜には、お礼として角砂糖を置いておくのを忘れないでほしい。

Shellには様々な種族がいる。現在確認されている種族の中で有名なものには、"ba"、"c"、"k"、"tc"、"z"などがある。その服装は種族によって異なり、私が目撃したのは身長60cmほどで、バーバリーの子供服を着た個体だった。おそらく人々が最も多く目撃しているのは"ba"種だろう。個人的には、身長がもっと高く、尖った耳を持つ"z"種にも出会ってみたいが、今は手紙の書き方は分かっても、実物を見たことはない。

彼女たちはなるべく同じ部屋に住んでいるが、めったに目にする機会はなく、どうすれば出会えるのかも分からない。

毎日プログラムを書くという儀式を真夜中まで続け、かろうじてカフェインで頭を支えている状態で突然画面を見ると、彼女の姿が見えるという説がある。実際に私が彼女に出会ったのも、会社で夜更かししてプログラムを書いている時だった。

Shellの個体は非常に多く、どの家庭にも一匹いると言われている。皆さんの家にも、実際には多くの彼女たちが住んでいて、手紙の到着を待っているかもしれない。

ActionScript

紛争地域で生まれた13歳の少女。

彼女の父は有名なデザイナーだったが、彼女が5歳の時に戦火に巻き込まれて亡くなった。幸いなことに彼女はまだ幼く、彼女を養子にしたAdobeおじさんが非常に熱心に育ててくれたため、彼女の心に大きな傷は残らなかった。おじさんは彼女の父と同じくデザイナーだった。おそらく彼女の記憶の中では、二人は混同されているかもしれない。

彼女が住む国はJavaScriptが住む国と隣国で、両国とも同じECMA人種で構成されている。外国人から見るとJavaScriptとActionScriptの外見は非常に似ている。確かに子供時代の写真を見ると、肌の色や顔立ちがよく似ているが、今の成長した写真を見るとどうだろうか。

彼女は「祖国とおじさんのために頑張る」を座右の銘に努力しているが、努力が報われないことが多く、運のあまり良くない子だ。

紛争地域で新しい公用語が導入されるという噂が広まった時、彼女は来たるべき平和な時代に貢献したいと願い、誰よりも早くその言語を学び始めたが、ようやくその言語を話せるようになった頃、その言語が公用語として採用される提案は頓挫してしまった。

彼女がモバイル端末でのデザインを学び始めた時、モバイル分野で強くなればおじさんの仕事の役に立つと考えた。祖国の対外債務も減らせるかもしれない。そんな思いで努力していた時、おじさんが経営する会社はある巨大モバイル端末企業に取引を強制終了され、モバイル関連の仕事も急激に減少した。

一生懸命努力しても報われないことが多い彼女は、今も紛争の終息が見えないこの土地に立ち、歩み続けている。

いつか努力は報われるだろう。彼女が10年後も無事で、歩み続け、生き続けていることを願う。
