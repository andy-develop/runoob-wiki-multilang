5.2 ES6 Generator 関数

分類 ES6 チュートリアル

ES6 では新しく Generator 関数が導入されました。yield キーワードを使って関数の実行フローを一時停止でき、実行フローを変更する可能性を提供し、それによって非同期プログラミングに解決策を提供します。基本的な使い方

Generator 関数の構成

Generator には通常の関数と区別される2つの部分があります：

  • 1つ目は、function の後、関数名の前に * があることです；

  • 関数内部に yield 式があること。

ここで * は関数が Generator 関数であることを示し、yield は関数内部の状態を定義するために使われます。

function* func(){ console.log("one"); yield '1'; console.log("two"); yield '2'; console.log("three"); return '3'; }

実行メカニズム

Generator 関数の呼び出しは通常の関数と同じように、関数名の後に()を付けるだけです。しかし、Generator 関数は通常の関数のようにすぐには実行されず、内部状態オブジェクトを指すポインタを返します。そのため、イテレータオブジェクト Iterator の next メソッドを呼び出すと、ポインタは関数の先頭または前回停止した場所から実行を開始します。

f.next(); // one // {value: "1", done: false} f.next(); // two // {value: "2", done: false} f.next(); // three // {value: "3", done: true} f.next(); // {value: undefined, done: true}

next メソッドを初めて呼び出すと、Generator 関数の先頭から実行を開始し、最初に one を出力し、yield のところまで実行すると停止します。そして yield の後ろの式の値 '1' を、返されるオブジェクトの value プロパティの値とします。このとき関数はまだ実行し終えていないので、返されるオブジェクトの done プロパティの値は false です。

next メソッドを2回目に呼び出すときは、前のステップと同じです。

next メソッドを3回目に呼び出すときは、最初に three を出力し、次に関数の return 操作を実行し、return の後ろの式の値を、返されるオブジェクトの value プロパティの値とします。このとき関数はすでに終了しているので、done プロパティの値は true です。

next メソッドを4回目に呼び出すときは、関数はすでに実行し終えているので、返される value プロパティの値は undefined、done プロパティの値は true です。3番目のステップを実行するときに return 文がない場合は、直接 {value: undefined, done: true} を返します。

関数が返すイテレータオブジェクトのメソッド

next メソッド

通常、next メソッドに引数を渡さない場合、yield 式の戻り値は undefined です。next に引数を渡す場合、その引数は前のステップの yield の戻り値となります。

function* sendParameter(){ console.log("start"); var x = yield '2'; console.log("one:" + x); var y = yield '3'; console.log("two:" + y); console.log("total:" + (x + y)); }

next に引数を渡さない

var sendp1 = sendParameter(); sendp1.next(); // start // {value: "2", done: false} sendp1.next(); // one:undefined // {value: "3", done: false} sendp1.next(); // two:undefined // total:NaN // {value: undefined, done: true} next引数を渡すvar sendp2 = sendParameter(); sendp2.next(10); // start // {value: "2", done: false} sendp2.next(20); // one:20 // {value: "3", done: false} sendp2.next(30); // two:30 // total:50 // {value: undefined, done: true}

next を使う以外にも、for...of ループを使って Generator 関数が生成する Iterator オブジェクトを反復処理できます。

return メソッド

return メソッドは指定された値を返し、Generator 関数の反復を終了します。

return メソッドが引数を提供する場合はその引数を返し、引数を提供しない場合は undefined を返します。

function* foo(){ yield 1; yield 2; yield 3; } var f = foo(); f.next(); // {value: 1, done: false} f.return("foo"); // {value: "foo", done: true} f.next(); // {value: undefined, done: true} throwメソッドthrowメソッドはGenerator関数本体の外で例外をスローし、関数本体の内部でキャッチします。var g = function* () { try { yield; } catch (e) { console.log('catch inner', e); } }; var i = g(); i.next(); try { i.throw('a'); i.throw('b'); } catch (e) { console.log('catch outside', e); } // catch inner a // catch outside b

イテレータオブジェクトは2つのエラーをスローしました。1つ目は Generator 関数内部でキャッチされ、2つ目は関数本体の内部の catch 関数がすでに実行されているため、このエラーは再度キャッチされず、そのためこのエラーは Generator 関数本体の外にスローされ、関数本体の外の catch によってキャッチされます。

yield* 式

yield* 式は、yield がイテレータオブジェクトを返すことを表し、Generator 関数の内部で別の Generator 関数を呼び出すために使用されます。

function* callee() { console.log('callee: ' + (yield)); } function* caller() { while (true) { yield* callee(); } } const callerObj = caller(); callerObj.next(); // {value: undefined, done: false} callerObj.next("a"); // callee: a // {value: undefined, done: false} callerObj.next("b"); // callee: b // {value: undefined, done: false} //次と同等です function* caller() { while (true) { for (var value of callee) { yield value; } } }

使用シーン

Iterator の実装

Iterator インターフェースを持たないオブジェクトに反復処理のメソッドを提供します。

function* objectEntries(obj) { const propKeys = Reflect.ownKeys(obj); for (const propKey of propKeys) { yield [propKey, obj[propKey]]; } } const jane = { first: 'Jane', last: 'Doe' }; for (const [key,value] of objectEntries(jane)) { console.log(`${key}: ${value}`); } // first: Jane // last: Doe

Reflect.ownKeys() は、列挙可能かどうかに関係なく、Symbol を含むオブジェクトのすべてのプロパティを返します。

jane はネイティブでは Iterator インターフェースを持っておらず、for...of で反復処理できません。ここでは Generator 関数を使って Iterator インターフェースを追加したので、jane オブジェクトを反復処理できます。
