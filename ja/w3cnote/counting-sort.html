1.8 計数ソート

分類 アルゴリズム

計数ソート（Counting Sort）は比較を行わないソートアルゴリズムで、整数や有限範囲のデータのソートに適しています。その核となる考え方は、各要素の出現回数を統計し、その結果に基づいて要素を正しい位置に戻すことです。計数ソートの時間計算量は O(n + k) で、n はソート対象の要素数、k はデータの範囲の大きさです。

計数ソートの核心は、入力されたデータ値をキーに変換し、追加で確保した配列空間に格納することです。線形時間計算量のソートとして、計数ソートは入力データが確定した範囲を持つ整数であることを要求します。

1. 計数ソートの特徴

入力される要素が n 個の 0 から k までの整数である場合、実行時間は Θ(n + k) です。計数ソートは比較ソートではなく、そのソート速度はあらゆる比較ソートアルゴリズムよりも高速です。

計数に使用する配列 C の長さは、ソート対象の配列におけるデータの範囲（ソート対象の配列の最大値と最小値の差に 1 を加えたもの）に依存するため、計数ソートはデータ範囲が非常に大きい配列の場合、大量の時間とメモリを必要とします。例えば、計数ソートは 0 から 100 の間の数値をソートするのに最適なアルゴリズムですが、人名をアルファベット順にソートするのには適していません。ただし、基数ソート内のアルゴリズムとして使用することで、データ範囲が非常に大きい配列をソートできます。

わかりやすく言うと、例えば年齢が異なる 10 人がいる場合、8 人の年齢が A より小さいと統計されれば、A の年齢は 9 番目に並びます。この方法で他の全員の位置も分かり、ソートが完了します。もちろん、年齢に重複がある場合は特別な処理（安定性の保証）が必要です。これが、最後に目標配列を逆方向に埋め、各数値の統計から 1 を減算する理由です。

アルゴリズムの手順は以下のとおりです：

  1. 頻度の集計：ソート対象のリストを走査し、各要素の出現回数を数えて、計数配列に格納します。

  2. 頻度の累積：計数配列の値を累積し、各要素がソート後のリストで最後に現れる位置を求めます。

  3. ソート済みリストの構築：ソート対象のリストを走査し、計数配列の位置情報に基づいて要素を正しい位置に配置します。

  4. 結果の出力：ソート後のリストを出力します。

2. アニメーション図解

ソート対象のリスト [4, 2, 2, 8, 3, 3, 1] があり、データの範囲が 1 から 8 であるとします。計数ソートの過程は以下のとおりです：

  1. 頻度の集計：

    • 計数配列の初期化count、サイズは 9（範囲 0〜8）です。

    • リストを走査し、各要素の出現回数を数えます：

      • count[1] = 1

      • count[2] = 2

      • count[3] = 2

      • count[4] = 1

      • count[8] = 1

    • 計数配列：[0, 1, 2, 2, 1, 0, 0, 0, 1]。

  2. 頻度の累積：

    • 計数配列の値を累積し、各要素の最終位置を求めます：

      • count[1] = 1

      • count[2] = 1 + 2 = 3

      • count[3] = 3 + 2 = 5

      • count[4] = 5 + 1 = 6

      • count[8] = 6 + 1 = 7

    • 累積後の計数配列：[0, 1, 3, 5, 6, 6, 6, 6, 7]。

  3. 要素の配置：

    • 結果配列の初期化output、サイズは 7 です。

    • 元のリストを走査し、計数配列の位置情報に基づいて要素を結果配列に配置します：

      • 要素4：count[4] = 6を配置output[5]，count[4] -= 1。

      • 要素2：count[2] = 3を配置output[2]，count[2] -= 1。

      • 要素2：count[2] = 2を配置output[1]，count[2] -= 1。

      • 要素8：count[8] = 7を配置output[6]，count[8] -= 1。

      • 要素3：count[3] = 5を配置output[4]，count[3] -= 1。

      • 要素3：count[3] = 4を配置output[3]，count[3] -= 1。

      • 要素1：count[1] = 1を配置output[0]，count[1] -= 1。

    • 結果配列：[1, 2, 2, 3, 3, 4, 8]。

  4. 結果の出力：

    • ソート後のリスト：[1, 2, 2, 3, 3, 4, 8]。

例

def counting_sort(arr):
    # リスト内の最大値を見つける
    max_val = max(arr)
    # 計数配列を初期化する
    count = [0] * (max_val + 1)
    # 各要素の出現回数を数える
    for num in arr:
        count[num] += 1
    # 計数配列を累積し、各要素の最終位置を求める
    for i in range(1, len(count)):
        count[i] += count[i - 1]
    # 結果配列を初期化する
    output = [0] * len(arr)
    # 元のリストを逆方向に走査し、要素を結果配列に配置する
    for num in reversed(arr):
        output[count[num] - 1] = num
        count[num] -= 1
    return output

# 例
arr = [4, 2, 2, 8, 3, 3, 1]
sorted_arr = counting_sort(arr)
print(sorted_arr)  # 出力: [1, 2, 2, 3, 3, 4, 8]

時間計算量

  • 頻度の集計：O(n)、リストを 1 回走査します。

  • 頻度の累積：O(k)、計数配列を 1 回走査します。

  • 要素の配置：O(n)、リストを 1 回走査します。

  • 全体の時間計算量：O(n + k)、n はリストの長さ、k はデータの範囲の大きさです。

空間計算量

  • O(n + k)、追加の計数配列と結果配列が必要です。

長所と短所

  • 長所：

    • 時間計算量が O(n + k) であり、k が小さい場合に優れた性能を発揮します。

    • 安定ソートアルゴリズムです（同じ要素の相対的な順序は変わりません）。

  • 短所：

    • 整数または有限範囲のデータにのみ適用可能です。

    • データ範囲 k が非常に大きい場合、空間計算量が高くなります。

適用シーン

  • データ範囲が小さい整数のソート。

  • 安定ソートアルゴリズムが必要な場面。

  • 外部ソート（ディスクファイルのソートなど）に適しています。

コード実装

JavaScript

例

function countingSort(arr, maxValue) {
    var bucket = new Array(maxValue+1),
        sortedIndex = 0;
        arrLen = arr.length,
        bucketLen = maxValue + 1;

    for (var i = 0; i < arrLen; i++) {
        if (!bucket[arr[i]]) {
            bucket[arr[i]] = 0;
        }
        bucket[arr[i]]++;
    }

    for (var j = 0; j < bucketLen; j++) {
        while(bucket[j] > 0) {
            arr[sortedIndex++] = j;
            bucket[j]--;
        }
    }

    return arr;
}

public class CountingSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、引数の内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        int maxValue = getMaxValue(arr);

        return countingSort(arr, maxValue);
    }

    private int[] countingSort(int[] arr, int maxValue) {
        int bucketLen = maxValue + 1;
        int[] bucket = new int[bucketLen];

        for (int value : arr) {
            bucket[value]++;
        }

        int sortedIndex = 0;
        for (int j = 0; j < bucketLen; j++) {
            while (bucket[j] > 0) {
                arr[sortedIndex++] = j;
                bucket[j]--;
            }
        }
        return arr;
    }

    private int getMaxValue(int[] arr) {
        int maxValue = arr[0];
        for (int value : arr) {
            if (maxValue < value) {
                maxValue = value;
            }
        }
        return maxValue;
    }

}

    // 使用计数排序对输入数组进行排序
public static void CountSort(int[] arr) {
   // 查找数组中的最大值和最小值
   int max = arr[0];
   int min = arr[0];

   // 遍历数组以找到最大和最小值
   for(int i = 0; i < arr.Length; i++) {
      // 更新最大值
      if (arr[i] > max)  {
         max = arr[i];
      }

      // 更新最小值
      if (arr[i] < min) {
         min = arr[i];
      }
   }

   // 创建计数数组，长度为最大值和最小值之差加1
   int[] count = new int[max - min + 1];

   // 遍历数组并在计数数组中对应位置增加计数
   for(int i = 0; i < arr.Length; i++) {
         count[arr[i] - min]++;
   }

   // 重新排列原始数组
   int index = 0;
   for(int i = 0; i < count.Length; i++) {
      // 根据计数数组中的计数，将元素回写到原始数组中
      while (count[i]-- > 0) {
         arr[index++] = i + min;
      }
   }
}
