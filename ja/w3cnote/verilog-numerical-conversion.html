8.1 Verilog 数值変換

カテゴリ Verilog チュートリアル

この節では、符号付き数値の10進数と2進数の表現、およびいくつかの数値変換について簡単にまとめます。

幅が DW の2の補数形式のデータ dbin を定義すると、それが表す符号付き10進数は ddec です。

reg [DW-1:0]     dbin ;

1. 10進符号付き数値を2の補数に変換

正の数の2の補数は、元の符号付き絶対値表現と同じです。

もし10進数 ddec が負の場合、対応する2の補数を計算する方法は主に2つあります：

ddec の最上位ビット（符号ビット）を1に書き換え、残りの数値部分は反転して1を加えます。

例えば、4ビットの数値 -6 の数値部分は 4'b0110、反転して1を加えると 4'b0010、上位ビットを書き換えると 4'b1010 になります。

dbin = {1'b1, ~3'b110 + 3'b1} ;    //4'b1010

負の数 ddec を、それが表す最大の数値範囲の数（モジュラスと呼ぶ人もいます）に直接加算します。

例えば、4ビット数 -6 と 16（2の4乗）の和は10で、これは 4'b1010 に対応します。

dbin = ddec + (1<<4) ;        //4'b1010

2. 2の補数を10進符号付き数値に変換

dbin の最上位ビットが0の場合、その数値は表す10進正数そのものになります。

dbin の最上位ビットが1の場合、表される10進符号付き数値を計算する方法は主に2つあります：

dbin を反転して1を加え、符号ビットを追加します。

例えば、4ビット数 -6 の2の補数は 4'b1010、反転して1を加えると 4'b0110、符号ビットを追加すると -6 になります。

ddec = -(~4'b1010 + 1'b1) ;  //-6

dbin が表す符号なし数値から、それが表す最大数値範囲の数値を直接引きます。

例えば、4ビット数 -6 の2の補数は 4'b1010、すなわち符号なし数値は10で、10から16を引くと -6 が得られます。

ddec = dbin - (1<<4) ;  //-6

3. 絶対値

dbin の絶対値を求める論理は次のとおりです：

dbin_abs = (dbin[DW-1]? ~dbin : dbin) + 1'b1 ;

例えば、4ビット数 -6 の2の補数は 4'b1010、反転して1を加えた値は 4'b0110（6）で、これが -6 の絶対値になります。

しかし、dbin が正の数の場合、1を加えた値は実際の絶対値より1大きくなります。この操作は、正の数部分の絶対値の個数を負の数部分と一致させるためだけのものです。なぜなら、特定のビット幅では0が存在するため、符号付き数値で表現できる負の数の個数は正の数の個数より1多くなるからです。

4. 符号付き数値を符号なし数値に変換

符号付き数値を符号なし数値に拡張する論理は次のとおりです：

dbin_unsigned = {!dbin[DW-1], dbin[DW-2:0]) ;

例：

4'b1010 (-6) -> 4'b0010 (2)，4'b0010 (2) -> 4'b1010 (10)

実際には、変換の原則はデータが表す数値範囲を0以上に移動することであり、符号付き数値を符号なし数値に変換しても、データ間の相対的な差は変わりません。

5. 符号ビットの拡張

計算時には、必要に応じて符号付き数値のビット幅を拡張することがあります。ビット幅の増分を W とすると、拡張論理は次のとおりです：

dbin_extend = {{(W){dbin[DW-1]}}, dbin} ;

拡張の原則は、符号ビットを表す最上位ビットを、拡張された上位データビットに埋め込むことです。

例えば、4'b1010 (-6) を8ビットに拡張すると 8'b11111010 になり、対応する負の数を計算してもやはり -6 です。
