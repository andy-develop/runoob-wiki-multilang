プラットフォームツール（すべてオープンソースの素晴らしいものだよ）

  • Redmine/Trac：プロジェクト管理プラットフォーム
  • Jenkins/Jira（非オープンソース）：継続的インテグレーションシステム（Apache Continuum、これはApacheのCIシステムで、まだ研究できていない）

  • Travis-ci：オープンソースプロジェクトの継続的インテグレーションに必須、GitHubと連携する、https://travis-ci.org/
  • オープンソーステストツール、コミュニティ（Selenium、OpenQA.org）
  • Puppet：Linux、Unix、Windowsプラットフォームに対応した自動管理エンジン。いわゆる構成管理システムとは、マシン内のファイル、ユーザー、プロセス、ソフトウェアパッケージといったリソースを管理するもの。Puppetは1台でも数万台でも簡単に管理できる。

  • Ganglia：分散監視システム
  • fleet：分散initシステム

ビッグデータ処理/データ分析/分散ツール

  • Hadoop: 分散ファイルシステムであり、そのMapReduceプログラミングモデルと組み合わせて大量データのバッチ処理に使用できる（Hive、Pig、HBaseなどは言うまでもない）。特筆すべきはClouderaのHadoopディストリビューションCDH5で、YARN MRv2ベースでSparkを統合し、本番環境で直接使用できるHadoopであり、企業がデータウェアハウスを迅速に構築するのに非常に有用である。

  • Ceph: Linux分散ファイルシステム（特徴：中央集権なし）

  • Storm: リアルタイムストリームデータ処理。IBMの紹介記事を参照のこと（YahooのS4もストリームデータ処理を行う）

  • Spark: 大規模ストリーミングデータ処理（企業で一般的な3種類のデータ処理シナリオに対応可能：複雑なバッチデータ処理（batch data processing）；履歴データに基づくインタラクティブクエリ（interactive query）；リアルタイムデータストリームに基づくデータ処理（streaming data processing））。CSNDに良い紹介記事がある

  • Spark Streaming: Sparkベースのリアルタイム計算フレームワーク

  • Tachyon: 分散インメモリファイルシステム

  • Mesos: コンピューティングフレームワークのクラスタマネージャであり、分散アプリケーションやフレームワーク間で効果的なリソース分離と共有を提供する。Impala: 次世代のオープンソースビッグデータ分析エンジンで、SQLセマンティクスを提供し、速度においてHiveより優れている。

  • SNAPPY: 高速データ圧縮システムで、Hadoopエコシステムに適している

  • Kafka: 高スループットの分散メッセージキューシステム

  • ActiveMQ: Apache提供の、最も人気があり、高性能なオープンソースメッセージバス

  • MQTT: Message Queuing Telemetry Transport（メッセージキューイングテレメトリトランスポート）はIBMが開発した即時通信プロトコルであり、IoTの重要な構成要素となる可能性がある

  • RabbitMQ: OpenStackがこれを使っていたのを覚えているだろう

  • ZeroMQ: 分散コンピューティングをよりシンプルにすると謳われている分散メッセージキュー。雲風の記事の紹介を参照のこと。オープンソースのログ収集システム：scribe、chukwa、kafka、flume。比較記事がこれ

  • Zookeeper: 信頼性の高い分散調整を行うオープンソースプロジェクト

  • Databus: LinkedInのリアルタイム低遅延データ取得システム

  • Navicat Premium: MySql、PostgreSQL、Oracle、Sqlite、SQL Serverをサポートするクライアント。汎用性はDatabase.NETに及ばないが、性能はDatabase.NETよりはるかに優れている。バックアップ機能も内蔵されており、データベースの定期バックアップにも使える
  • Synergy: ローカルネットワーク内で1セットのキーボードとマウスで複数のPCを操作
  • DameWare: リモート支援ツールセット（会社では主に大画面の制御に使用）
  • Radmin: リモート制御ツール。しばらく使っていた
  • DameWareはクラックが必要だし、Win7のサポートも良くない。結局これ（Radmin）が使いやすいと分かった
  • Listary: Windowsのファイル閲覧・検索速度と効率を飛躍的に向上させる「超神ツール」
  • Clover: エクスプローラーにマルチタブを追加
  • WinLaunch: Mac OSのLaunchをシミュレートするツール
  • Fritzing: 回路図の描画
  • LICEcap: GIFチュートリアル作成ツール
  • svn: バージョン管理システム。Enigma Virtual Box（exe、dllなどを1つの実行可能プログラムにカプセル化）
  • Open DBDiff（SqlServer向け）: データベース同期
  • SymmetricDS: データベース同期
  • BIEE、Infomatica、SPSS、weka、R言語: データ分析
  • CodeSmith、LightSwitch: コード生成
  • Pandoc: Markdown変換ツール、書籍出版用。以前docbookを使っていたが、今はやはりMarkdownが主流だね
  • Window Magnet[Mac]: Macのウィンドウ管理機能を強化。Win7のようにウィンドウを画面端にドラッグすると自動的にサイズ調整される
  • log explorer: SqlServerログを表示
  • dependency walker: WindowsアプリケーションのDLL依存関係を照会
  • Shairport4w: iPhone、iPad、iPodのオーディオをAirPlayプロトコルでPCに転送
  • ngrok: 内網トンネルツール。Axure: 高速プロトタイピングツール。オンラインで作図できるツールもあり、中国のスタートアップチームが作ったもので、なかなか使いやすいhttp://www.processon.com
  • tinyproxy:（Linux）HTTPとHTTPSプロトコルをサポートする小規模なプロキシサーバー
  • EaseUS Partition Master: 非常に簡単なパーティション調整ツール。速度もかなり速い。Cドライブの容量が足りなくなったら、これでDドライブから領域を移動しよう。OSを再インストールする手間は不要だ
  • CheatEngine: ゲームのメモリ値変更に必須の神ツール（軒轅剣6をプレイしていたときこれを使っていた、超便利だった）
  • ApkIDE: Android逆コンパイルの神ツール。グレートファイアウォール回避ツール（自|由|门、天行浏览器）
