スレッドの作成

Windowsプラットフォームでは、Windows APIがマルチスレッドをサポートしています。前述のプロセスとスレッドの概念で述べたように、プログラムには少なくとも1つのスレッドがあり、このスレッドをメインスレッド(main thread)と呼びます。明示的にスレッドを作成しない場合、作成したプログラムはメインスレッドのみを持つシングルスレッドプログラムです。

次に、Windowsにおけるスレッド関連の操作とメソッドを見てみましょう。

CreateThread と CloseHandle

CreateThread はスレッドを作成するために使用され、その関数プロトタイプは次のとおりです：

HANDLE WINAPI CreateThread(
    LPSECURITY_ATTRIBUTES   lpThreadAttributes, //线程安全相关的属性，常置为NULL
    SIZE_T                  dwStackSize,        //新线程的初始化栈在大小，可设置为0
    LPTHREAD_START_ROUTINE  lpStartAddress,     //被线程执行的回调函数，也称为线程函数
    LPVOID                  lpParameter,        //传入线程函数的参数，不需传递参数时为NULL
    DWORD                   dwCreationFlags,    //控制线程创建的标志
    LPDWORD                 lpThreadId          //传出参数，用于获得线程ID，如果为NULL则不返回线程ID
);

説明：

  • lpThreadAttributes：SECURITY_ATTRIBUTES構造体へのポインタ。返されるハンドルが子プロセスに継承できるかどうかを決定します。NULLの場合は、返されるハンドルが子プロセスに継承できないことを示します。

  • dwStackSize：スレッドスタックの初期サイズ（バイト単位）。システムはこの値を割り当てます。

  • lpStartAddress：関数ポインタを指します。この関数はスレッドによって呼び出されて実行されます。したがって、この関数はスレッド関数(ThreadProc)とも呼ばれ、スレッド実行の開始アドレスです。スレッド関数はコールバック関数であり、オペレーティングシステムによってスレッド内で呼び出されます。スレッド関数のプロトタイプは次のとおりです：

    DWORD WINAPI ThreadProc(LPVOID lpParameter);    //lpParameter是传入的参数，是一个空指针

  • lpParameter：スレッド関数(ThreadProc)に渡すパラメータ。パラメータを渡す必要がない場合はNULLです。

  • dwCreationFlags：スレッドの作成を制御するフラグで、3つのタイプがあります。0：スレッド作成後すぐに実行します。CREATE_SUSPENDED：スレッド作成後は準備完了状態になり、スレッドが起こされるまで呼び出されません。STACK_SIZE_PARAM_IS_A_RESERVATION：dwStackSize パラメータがスレッドの初期スタックサイズを指定します。STACK_SIZE_PARAM_IS_A_RESERVATION フラグが指定されていない場合、dwStackSize はシステムが予約した値に設定されます。

  • 戻り値：スレッドの作成に成功した場合は新しいスレッドのハンドルを返し、失敗した場合はNULLを返します。スレッドの作成に失敗した場合は、GetLastError関数でエラー情報を取得できます。

    BOOL WINAPI CloseHandle(HANDLE hObject);        //关闭一个被打开的对象句柄
    この関数を使用して作成したスレッドハンドルを閉じることができます。関数の実行が成功するとtrue(0以外)を返し、失敗するとfalse(0)を返します。実行に失敗した場合は、GetLastError関数を呼び出してエラー情報を取得できます。

CreateMutex、WaitForSingleObject、ReleaseMutex

【Demo2】からわかるように、作成した子スレッドはすべて正常に実行されていますが、出力結果は私たちが期待した効果ではありません。期待した効果は、各ステートメントを出力した後に自動的に改行することですが、結果はそのようにはなりませんでした。これは、スレッド実行時に同期処理が行われていないためです。例えば、最初の行の出力では、メインスレッドが「主スレッド ===」を出力した後にタイムスライスが使い尽くされ、その時点で子スレッド1の出力に移り、子スレッドが「スレッド1 —」を出力した後にもタイムスライスが使い尽くされ、再びメインスレッドが「0」を出力し、その後また子スレッド1が「0」を出力します。そこで、「主スレッド === スレッド1 — 0 0」という結果が現れます。

主スレッド：cout << "主スレッド === " << i << endl;
子スレッド：cout << pThreadData->strThreadName << " — " << i << endl;

この状況を回避するために、スレッドに対して簡単な同期処理を行います。ここではミューテックス(Mutex)を使用します。

ミューテックス(Mutex)はバイナリセマフォに似ており、リソースへのアクセスは1つのスレッドのみに許可されます。バイナリセマフォと異なる点は、セマフォはシステム全体で任意のスレッドが取得および解放できることです。つまり、同じセマフォをあるスレッドが取得し、別のスレッドが解放することができます。一方、ミューテックスは、どのスレッドがミューテックスロックを取得したかによって、そのスレッドだけが解放でき、他のスレッドが代わりにミューテックスを解放しても無効です。

ミューテックスを使用してスレッド同期を行うときには、次の関数を使用します：

HANDLE WINAPI CreateMutex(
    LPSECURITY_ATTRIBUTES lpMutexAttributes,        //线程安全相关的属性，常置为NULL
    BOOL                  bInitialOwner,            //创建Mutex时的当前线程是否拥有Mutex的所有权
    LPCTSTR               lpName                    //Mutex的名称
);

説明：lpMutexAttributes もセキュリティを表す構造体で、CreateThread の lpThreadAttributes と同じ機能です。返されるハンドルが子プロセスに継承できるかどうかを決定し、NULL の場合は返されるハンドルが子プロセスに継承できないことを示します。bInitialOwner は、Mutex 作成時の現在のスレッドが Mutex の所有権を持つかどうかを示します。TRUE の場合は、現在の作成スレッドが Mutex オブジェクトの所有者であると指定され、他のスレッドがアクセスするにはまず ReleaseMutex を呼び出す必要があります。lpName は Mutex の名前です。

DWORD WINAPI WaitForSingleObject(
    HANDLE hHandle,                             //要获取的锁的句柄
    DWORD  dwMilliseconds                           //超时间隔
);

説明：WaitForSingleObject の役割は、指定されたオブジェクト（Mutex オブジェクトなど）が非占有状態（例えば Mutex オブジェクトが解放される）になるまで、または設定された時間間隔を超えるまで待機することです。これ以外にも、これに似た関数 WaitForMultipleObjects があります。これは、1つまたはすべての指定されたオブジェクトを、すべてのオブジェクトが非占有状態になるまで、または設定された時間間隔を超えるまで待機します。

hHandle：待機する指定オブジェクトのハンドル。dwMilliseconds：タイムアウトの間隔（ミリ秒単位）。dwMilliseconds が 0 以外の場合、dwMilliseconds の時間間隔が使い切られるか、オブジェクトが非占有状態になるまで待機します。dwMilliseconds が INFINITE の場合は、待機しているオブジェクトが非占有状態になるまで無限に待機します。

BOOL WINAPI ReleaseMutex(HANDLE hMutex);

説明：所有しているミューテックスロックオブジェクトを解放します。hMutex は解放するミューテックスのハンドルです。

スレッド同期の重要性とミューテックスの使用方法をさらに理解するために、もう1つの例を見てみましょう。

列車の切符を買うことは、春節に帰省する皆さんが最も気にかけることです。ここでは、列車切符の販売システムを簡単にシミュレーションしてみます（プログラムを簡単にするため、最も単純なモデルを取り出してシミュレーションします）。北京から贛州までの列車切符が500枚あり、8つの窓口で同時に販売され、システムの安定性とデータの原子性を保証します。

【Demo4】：列車切符販売システムのシミュレーション

SaleTickets.h

#include "stdafx.h" #include <windows.h> #include <iostream> #include <strstream> #include <string> using namespace std; #define NAME_LINE 40 //スレッド関数に渡すパラメータの構造体を定義する typedef struct __TICKET { int nCount; char strTicketName[NAME_LINE]; __TICKET() : nCount(0) { memset(strTicketName, 0, NAME_LINE * sizeof(char)); } }TICKET; typedef struct __THD_DATA { TICKET* pTicket; char strThreadName[NAME_LINE]; __THD_DATA() : pTicket(NULL) { memset(strThreadName, 0, NAME_LINE * sizeof(char)); } }THD_DATA; //基本型データを文字列に変換する template<class T> string convertToString(const T val) { string s; std::strstream ss; ss << val; ss >> s; return s; } //販売プログラム DWORD WINAPI SaleTicket(LPVOID lpParameter);

SaleTickets.cpp

#include "stdafx.h" #include <windows.h> #include <iostream> #include "SaleTickets.h" using namespace std; extern HANDLE g_hMutex; //販売プログラム DWORD WINAPI SaleTicket(LPVOID lpParameter) { THD_DATA* pThreadData = (THD_DATA*)lpParameter; TICKET* pSaleData = pThreadData->pTicket; while(pSaleData->nCount > 0) { //ミューテックスロックの取得を要求する WaitForSingleObject(g_hMutex, INFINITE); if (pSaleData->nCount > 0) { cout << pThreadData->strThreadName << "第" << pSaleData->nCount -- << "の切符を販売、"; if (pSaleData->nCount >= 0) { cout << "発券成功！残り" << pSaleData->nCount << "枚." << endl; } else { cout << "発券失敗！その切符は売り切れました。" << endl; } } Sleep(10); //ミューテックスロックを解放する ReleaseMutex(g_hMutex); } return 0L; }

テストプログラム：

//售票系统
void Test2()
{
    //创建一个互斥量
    g_hMutex = CreateMutex(NULL, FALSE, NULL);

    //初始化火车票
    TICKET ticket;
    ticket.nCount = 100;
    strcpy(ticket.strTicketName, "北京-->赣州");

    const int THREAD_NUMM = 8;
    THD_DATA threadSale[THREAD_NUMM];
    HANDLE hThread[THREAD_NUMM];
    for(int i = 0; i < THREAD_NUMM; ++ i)
    {
        threadSale[i].pTicket = &ticket;
        string strThreadName = convertToString(i);

        strThreadName = "窗口" + strThreadName;

        strcpy(threadSale[i].strThreadName, strThreadName.c_str());

        //创建线程
        hThread[i] = CreateThread(NULL, NULL, SaleTicket, &threadSale[i], 0, NULL);

        //请求获得一个互斥量锁
        WaitForSingleObject(g_hMutex, INFINITE);
        cout << threadSale[i].strThreadName << "开始出售 " << threadSale[i].pTicket->strTicketName << " 的票..." << endl;
        //释放互斥量锁
        ReleaseMutex(g_hMutex);

        //关闭线程
        CloseHandle(hThread[i]);
    }

    system("pause");
}
