4.4 ES6 モジュール

分類 ES6 チュートリアル

概要

ES6 以前は、モジュール化の実装には RequireJS または seaJS が使用されていました（それぞれ AMD 仕様に基づくモジュール化ライブラリと、CMD 仕様に基づくモジュール化ライブラリです）。

ES6 はモジュール化を導入し、その設計思想はコンパイル時にモジュールの依存関係、および入力と出力の変数を決定できることです。

ES6 のモジュール化は、エクスポート（export）とインポート（import）の2つのモジュールに分けられます。

特徴

ES6 のモジュールは、モジュールの先頭に追加するかどうかに関係なく、自動的に厳格モード（strict mode）が有効になります。use strict;。

モジュールでは、関数、オブジェクト、文字列、数値、ブール値、クラスなど、さまざまな型の変数をインポートおよびエクスポートできます。

各モジュールには独自のコンテキストがあり、各モジュール内で宣言された変数はローカル変数であり、グローバルスコープを汚染しません。

各モジュールは一度だけロードされます（シングルトンです）。同じディレクトリ内の同じファイルを再度ロードする場合は、メモリから直接読み取られます。

export と import

基本的な使い方

モジュールは、文字列、数値、関数、クラスなど、さまざまな型の変数をインポートおよびエクスポートします。

  • エクスポートする関数宣言とクラス宣言には名前が必要です（export default コマンドは別途考慮します）。
  • 宣言だけでなく参照（例えば関数）もエクスポートできます。
  • export コマンドはモジュールの任意の位置に記述できますが、モジュールの最上位にある必要があります。
  • import コマンドはモジュール全体の先頭に巻き上げられ、最初に実行されます。
/*-----export [test.js]-----*/ let myName = "Tom"; let myAge = 20; let myfn = function(){ return "My name is" + myName + "! I'm '" + myAge + "years old." } let myClass = class myClass { static a = "yeah!"; } export { myName, myAge, myfn, myClass } /*-----import [xxx.js]-----*/ import { myName, myAge, myfn, myClass } from "./test.js"; console.log(myfn());// My name is Tom! I'm 20 years old. console.log(myAge);// 20 console.log(myName);// Tom console.log(myClass.a );// yeah!

エクスポートする一連の変数を中括弧で指定してドキュメントの末尾に書き、エクスポートするインターフェースを明確にすることをお勧めします。

関数とクラスにはそれぞれ対応する名前が必要であり、ドキュメントの末尾にエクスポートすることで、対応する名前がない事態も回避できます。

as の使い方

export コマンドでエクスポートするインターフェース名は、モジュール内部の変数と一対一で対応している必要があります。

インポートする変数名は、エクスポートされたインターフェース名と同じである必要があります。つまり、順序は一致しなくても構いません。

/*-----export [test.js]-----*/ let myName = "Tom"; export { myName as exportName } /*-----import [xxx.js]-----*/ import { exportName } from "./test.js"; console.log(exportName);// Tom使用asエクスポートするインターフェース名を再定義し、モジュール内部の変数を隠します/*-----export [test1.js]-----*/ let myName = "Tom"; export { myName } /*-----export [test2.js]-----*/ let myName = "Jerry"; export { myName } /*-----import [xxx.js]-----*/ import { myName as name1 } from "./test1.js"; import { myName as name2 } from "./test2.js"; console.log(name1);// Tom console.log(name2);// Jerry

異なるモジュールでエクスポートするインターフェース名が重複する場合は、as を使用して変数名を再定義します。

import コマンドの特徴

読み取り専用属性：モジュールをロードするスクリプト内で、インターフェースの参照先を書き換えることはできません。つまり、import した変数の型がオブジェクトであればそのプロパティ値は書き換えられますが、import した変数の型が基本型であればその値は書き換えられません。

import {a} from "./xxx.js" a = {}; // error import {a} from "./xxx.js" a.foo = "hello"; // a = { foo : 'hello' }

シングルトンパターン：同じ import 文を複数回繰り返し実行しても、1回だけ実行され、複数回実行されることはありません。同じモジュールを import して異なるインターフェース参照を宣言すると、対応する変数が宣言されますが、import は1回だけ実行されます。

import { a } "./xxx.js"; import { a } "./xxx.js"; //次と同等です: import { a } "./xxx.js"; import { a } from "./xxx.js"; import { b } from "./xxx.js"; //次と同等です: import { a, b } from "./xxx.js";

静的実行特性：import は静的に実行されるため、式や変数を使用することはできません。

import { "f" + "oo" } from "methods"; // error let module = "methods"; import { foo } from module; // error if (true) { import { foo } from "method1"; } else { import { foo } from "method2"; } // error

export default コマンド

  • 1つのファイルまたはモジュール内で、export と import は複数持てますが、export default は1つだけです。
  • export default における default は、対応するエクスポートインターフェース変数です。
  • export 方式でエクスポートした場合は、インポート時に { } を付ける必要がありますが、export default の場合は不要です。
  • export default が外部に公開するメンバーは、任意の変数で受け取ることができます。
var a = "My name is Tom!"; export default a; //1つだけ export default var c = "error"; //error。default はすでに対応するエクスポート変数であるため、変数宣言文に続けることはできません import b from "./xxx.js"; //{ } を付ける必要はなく、任意の変数で受け取ります

複合的な使用

注：import() はプロポーザル（提案段階）であるため、ここではこれ以上詳しく説明しません。

export と import は同じモジュール内で使用できます。使用上の特徴：

  • エクスポートインターフェースの名前を変更できます。default も含みます。
  • export と import を複合的に使用してすべてをエクスポートすることもできます。現在のモジュールでエクスポートしたインターフェースが、継承したエクスポートを上書きします。
export { foo, bar } from "methods"; //以下の2つの文にほぼ相当します。ただし、上記のインポート/エクスポート方式では、そのモジュールは foo と bar をインポートしません。 import { foo, bar } from "methods"; export { foo, bar }; /*------- 特徴 1 --------*/ //通常の名前変更 export { foo as bar } from "methods"; //foo を default として再エクスポートする export { foo as default } from "methods"; //default を foo として再エクスポートする export { default as foo } from "methods"; /*------- 特徴 2 --------*/ export * from "methods";
