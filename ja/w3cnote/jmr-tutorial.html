Jmr 紹介

Jmr（正式名称: Jet Model Robotization）は、モデル駆動開発に基づき、自分のプロジェクトやフレームワークに合わせてテンプレートを記述し、コードを生成するツールです。
JmrはJetテンプレートを使用してコードを生成します。JetはEclipseがオープンソースで提供するテンプレートエンジンで、モデリングツールEMFの一部です。Jspのように<%...%>を使用してテンプレートを記述できます。

Jmrの目標

規則的で反復的なコードを自動化します。

なぜJmrを使うのか？

学びやすい：テンプレートはJsp構文に似ており、Javaスクリプトを使用できるため、学習コストが低いです。
汎用性：あらゆる種類のコード、テストケース、ドキュメントを生成できます。
モデリング：データベースやXMLなどをモデルに変換でき、カスタムActionも使用できます。モデルはテンプレートに渡され、生成に使用されます。
タスク：自分のプロジェクトの実際の状況に応じて生成タスクを設定できます。
独立性：あらゆるプロジェクトやフレームワークに統合でき、プロジェクト構造を変更する必要はありません。

Jmrの利点

  • ほとんどのコード生成ツールは生成されるコードが固定されており、テンプレートで生成内容を変更できませんが、Jmrはそれができます。
  • ほとんどのコード生成ツールは固定のプロジェクトにしか使用できませんが、Jmrは汎用性があり、Eclipseプロジェクトであれば統合できます。
  • ほとんどのコード生成ツールは固定言語のコードしか生成できませんが、Jmrはあらゆる言語のコード、テストケース、ドキュメントを生成できます。
  • 他のテンプレート言語（freemarker、velocityなど）と比較して、Jspに似た構文により、Jmrの学習コストは低くなっています。
  • 充実したエディタとタスク管理は、freemarkerやvelocityなどの付属ツールをはるかに上回ります。
  • 単なるテンプレート言語とコード生成だけでなく、モデル駆動開発の利点を取り入れ、タスク+モデル+テンプレートの組み合わせです。

Jmrは私に何をもたらすのか？

プロジェクトでは、一部のモジュールのコードは規則的で反復的であり、開発者は「コピー」「ペースト」に多大な時間を費やしています。
Jmrを使用すると、これらの規則的で反復的なコードをテンプレートとして記述し、一括自動生成を実現できます。
開発効率が大幅に向上し、開発者は技術的な難所とビジネス要件に集中できるようになります。

Java Webプロジェクトを例にとると、以下の部分には大量の反復的かつ規則的なコードが存在します。

  • Javaエンティティクラス
  • struts/spring/hibernateの設定ファイル
  • dao/service/actionの実装コード
  • jspの追加・削除・検索・更新ページ

従来はすべて手書きが必要だった部分を、今はJmrでテンプレートとして記述します。データベーステーブルをモデルに変換すれば、追加・削除・検索・更新などを備えた多くのモジュールを生成できます。
