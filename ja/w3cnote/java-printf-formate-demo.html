Java フォーマット出力 printf の使い方

カテゴリ プログラミング技術

Java の printf メソッドはフォーマット出力に使用されます。

フォーマットは出力の形式を指定し、数値の精度、文字幅、日付形式などを含みます。以下は一般的に使用されるフォーマット記号と使い方です：

文字列フォーマット

  • %s : 文字列を出力

例

System.out.printf("%s", "hello world"); // "hello world" を出力

整数フォーマット

  • %d : 10進整数を出力
  • %o : 8進整数を出力
  • %x : 16進整数を出力
  • %X : 大文字の16進整数を出力

例

System.out.printf("%d %o %x %X", 10, 10, 10, 10); // "10 12 a A" を出力

浮動小数点数フォーマット

  • %f : 浮動小数点数を出力
  • %e : 科学表記法で表された浮動小数点数を出力（小文字のe）
  • %E : 科学表記法で表された浮動小数点数を出力（大文字のE）
  • %.nf : 小数点以下の桁数を制御します。nは数値です。

例

System.out.printf("%.2f %e %E", 3.1415926, 3.1415926, 3.1415926); // "3.14 3.141593e+00 3.141593E+00" を出力

ブール値フォーマット

  • %b : ブール値を出力

例

System.out.printf("%b", true); // "true" を出力

文字フォーマット

  • %c : 文字を出力

例

System.out.printf("%c", 'a'); // "a" を出力

幅と精度のフォーマット

  • %n$ : 第n引数を指定
  • %m.n : 幅と精度を制御します。mは最小幅、nは小数点以下の桁数を示します。

例

System.out.printf("%2d %5.2f %s", 10, 3.1415926, "hello"); // "10 3.14 hello" を出力

以下は、Java の printf メソッドで使用可能な完全なフォーマット記号のリストです：

  • %d：符号付き10進整数
  • %o：符号なし8進整数
  • %x、%X：符号なし16進整数。それぞれ小文字と大文字で表します。
  • %f、%F：小数点付きの10進浮動小数点数。それぞれ小文字と大文字で表します。
  • %e、%E：指数付き浮動小数点数。それぞれ小文字と大文字で表します。
  • %g、%G：数値の大きさに応じて%fまたは%e形式を自動選択します。それぞれ小文字と大文字で表します。
  • %a、%A：16進浮動小数点数。それぞれ小文字と大文字で表します。
  • %c：文字型。単一の文字を出力します。
  • %s：文字列型。文字列を出力します。
  • %n：改行文字
  • %%：パーセント記号%を1つ出力
  • %h、%H：ハッシュコード。それぞれ16進数と16進数の大文字で表します。
  • %t、%T：日時フォーマット。特定の変換文字を使用して表します。例えば、%tYは年を表し、%tBは月の完全な名前を表します。
  • %b、%B：ブール値型。trueまたはfalseを出力します。それぞれ小文字と大文字で表します。
  • %S：大文字の文字列を出力

以下は、Java の printf メソッドで日付をフォーマットするために使用できる記号のリストです：

  • %tB：ローカライズされた月の完全な名前
  • %tb：ローカライズされた月の省略名
  • %tA：ローカライズされた曜日の完全な名前
  • %ta：ローカライズされた曜日の省略名
  • %tY：4桁の年
  • %ty：2桁の年
  • %tm：2桁の月
  • %td：2桁の日
  • %te：1桁または2桁の日
  • %tH：24時間制の時
  • %tI：12時間制の時
  • %tM：分
  • %tS：秒
  • %tp：午前または午後
  • %tZ：タイムゾーン

例

//%nは改行を表します。 System.out.printf("%s%n", "end line"); //複数の引数もサポートできます。 System.out.printf("%s = %s%n", "Name", "Zhangsan"); //%Sは文字列を大文字で出力します。 System.out.printf("%S = %s%n", "Name", "Zhangsan"); //複数の引数をサポートする場合、%sの間に変数番号を挿入できます。1$は最初の文字列、3$は3番目の文字列を表します。 System.out.printf("%1$s = %3$s %2$s%n", "Name", "san", "Zhang");
