プロジェクト名: free-programming-books -- 様々なプログラミング言語の無料学習リソース

Github オープンソースアドレス： https://github.com/EbookFoundation/free-programming-books

検索ページ（英語）： https://ebookfoundation.github.io/

検索ページ（中国語）： https://ebookfoundation.github.io/free-programming-books/books/free-programming-books-zh.html

中国語の類似プロジェクト： https://github.com/justjavac/free-programming-books-zh_CN

free-programming-books は GitHub 上のオープンソースプロジェクトであり、無料のプログラミング学習リソースを収集・共有することを目的としています。このプロジェクトには、さまざまなプログラミング言語、フレームワーク、ツール、コンピューターサイエンス分野に関する多数の無料電子書籍が含まれており、初心者から上級開発者までの各レベルをカバーしています。

このプロジェクトの主な目標は、プログラミングを学ぶ人々に無料かつ高品質な学習資料を提供することです。これには、プログラミング言語、アルゴリズム、データ構造、データベース、フロントエンドおよびバックエンド開発などの分野の書籍や資料が含まれますが、これらに限定されません。

このプロジェクトでは、Python、Java、JavaScript、C++ などのプログラミング言語に関する書籍や、Web開発、データサイエンス、人工知能、ネットワークセキュリティといったさまざまな分野の学習リソースを見つけることができます。
