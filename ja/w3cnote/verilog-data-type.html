2.3 Verilog データ型

分類 Verilog チュートリアル

Verilog で最もよく使われる2つのデータ型は、ネット（wire）とレジスタ（reg）です。その他の型は、これら2つのデータ型の拡張または補助と考えることができます。

[3:0] = 4'hF と等価で、幅を省略できます。

wire型はハードウェア素子間の物理的な配線を表し、接続された素子の出力端子によって連続的に駆動されます。wire型変数に駆動素子が接続されていない場合、デフォルト値は通常 "Z" です。以下に例を示します。

例

wire   interrupt ;
wire   flag1, flag2 ;
wire   gnd = 1'b0 ;  

ネット型には他にも、wand、wor、wri、triand、trior、trireg などのデータ型があります。これらのデータ型は使用頻度がそれほど高くないため、ここでは紹介しません。

レジスタ（reg）

レジスタ（reg）は記憶素子を表すために使われ、データが書き換えられるまで元の値を保持します。宣言の例は次のとおりです。

例

reg    clk_temp;
reg    flag1, flag2 ;

たとえば always ブロック内では、レジスタはエッジトリガフリップフロップに合成されることがあり、組み合わせ論理では wire 型変数に合成されることがあります。レジスタは駆動源を必要とせず、クロック信号も必ずしも必要ありません。シミュレーション時には、レジスタの値は任意の時点で代入操作によって書き換えることができます。例：

例

reg rstn ;
initial begin
    rstn = 1'b0 ;
    #100 ;
    rstn = 1'b1 ;
end

ベクトル

ビット幅が1より大きい場合、wire または reg はベクトル形式で宣言できます。例：

例

reg [3:0]      counter ;    //4bit幅のレジスタcounterを宣言
wire [32-1:0]  gpio_data;   //32bit幅のネット型変数gpio_dataを宣言
wire [8:2]     addr ;       //7bit幅のネット型変数addrを宣言、ビット幅範囲は8:2
reg [0:31]     data ;       //32bit幅のレジスタ変数dataを宣言、最上位ビットは0

上記のベクトルについて、特定の1ビットまたは隣接する数ビットを指定して、他のロジックとして使用できます。例：

例

wire [9:0]     data_low = data[0:9] ;
addr_temp[3:2] = addr[8:7] + 1'b1 ;

Verilog は可変のベクトルフィールド選択をサポートしています。例：

例

reg [31:0]     data1 ;
reg [7:0]      byte1 [3:0];
integer j ;
always@* begin
    for (j=0; j<=3;j=j+1) begin
        byte1[j] = data1[(j+1)*8-1 : j*8];
        //data1[7:0]…data1[31:24] を順に byte1
    end
end

Verilog は、開始ビットを指定してからビット幅を固定するベクトルフィールド選択アクセスもサポートしています。

  • [bit+: width]: 開始ビットから増加方向に、ビット幅は width。
  • [bit-: width]: 開始ビットから減少方向に、ビット幅は width。

例

//以下の2つの代入は等価です
A = data1[31-: 8] ;
A = data1[31:24] ;

//以下の2つの代入は等価です
B = data1[0+ : 8] ;
B = data1[0:7] ;

信号を再結合して新しいベクトルを作成するには、中括弧を使用する必要があります。例：

例

wire [31:0]    temp1, temp2 ;
assign temp1 = {byte1[0][7:0], data1[31:8]};  //データ連結
assign temp2 = {32{1'b0}};  //32ビットの値0を代入

整数、実数、時間レジスタ変数

整数、実数、時間などのデータ型も実際にはレジスタ型に属します。

整数（integer）

整数型はキーワード integer で宣言します。宣言時にビット幅を指定する必要はなく、ビット幅はコンパイラに依存しますが、通常は32ビットです。reg型変数は符号なし数ですが、integer型変数は符号付き数です。例：

例

reg [31:0]      data1 ;
reg [7:0]       byte1 [3:0]; //配列変数、後述
integer j ;  //整数型変数、デジタル回路の生成を補助するために使用
always@* begin
    for (j=0; j<=3;j=j+1) begin
        byte1[j] = data1[(j+1)*8-1 : j*8];
        //data1[7:0]…data1[31:24] を順に byte1
        end
end

この例では、integer 信号 j は補助信号として、data1 のデータを順に配列 byte1 に代入しています。合成後の実際の回路に j という信号は存在せず、j は対応するハードウェア回路を生成するための補助にすぎません。

実数（real）

実数はキーワード real で宣言し、10進数または科学的記数法で表すことができます。実数の宣言に範囲は指定できず、デフォルト値は 0 です。実数を整数に代入すると、実数の整数部分のみが整数に代入されます。例：

例

real        data1 ;
integer     temp ;
initial begin
    data1 = 2e3 ;
    data1 = 3.75 ;
end
 
initial begin
    temp = data1 ; //temp の値は 3
end

時間（time）

Verilog は特殊な時間レジスタ time 型変数を使用して、シミュレーション時間を保存します。そのビット幅は通常64ビットで、システム関数 $time を呼び出して現在のシミュレーション時間を取得します。例：

例

time       current_time ;
initial begin
       #100 ;
       current_time = $time ; //current_time の値は 100
end

配列

Verilog では、reg、wire、integer、time、real およびそのベクトル型の配列を宣言できます。

配列の次元数に制限はありません。ネット配列は、モジュールインスタンスのポートを接続するためにも使用できます。配列の各要素はスカラまたはベクトルとして同様に使用でき、形式は次のとおりです。<配列名>[<添え字>]。多次元配列の場合、ユーザーは各次元のインデックスを指定する必要があります。例：

例

integer          flag [7:0] ; //8個の整数からなる配列
reg  [3:0]       counter [3:0] ; //4ビットカウンタ4個からなる配列
wire [7:0]       addr_bus [3:0] ; //8ビットのwire型変数4個からなる配列
wire             data_bit[7:0][5:0] ; //1ビットwire型変数の2次元配列を宣言
reg [31:0]       data_4d[11:0][3:0][3:0][255:0] ; //4次元の32ビットデータ変数配列を宣言

以下に配列要素への代入操作を示します。

例

flag [1]   = 32'd0 ; //flag配列の2番目の要素に32ビットの0を代入
counter[3] = 4'hF ;  //配列counterの4番目の要素に4ビットの16進数Fを代入。これは counter
assign addr_bus[0]        = 8'b0 ; //配列addr_busの1番目の要素の値を0に代入
assign data_bit[0][1]     = 1'b1;  //配列data_bitの1行2列目の要素に1を代入。ここでは2番目のアクセスラベルを省略できません。つまり assign data_bit
data_4d[0][0][0][0][15:0] = 15'd3 ;  //配列data_4dのラベル

配列とベクトルのアクセス方法はある程度似ていますが、ベクトルと配列を混同しないようにしてください。ベクトルは単一の要素であり、ビット幅は n です。配列は複数の要素から構成され、各要素のビット幅は n または 1 です。両者は構造の定義において異なります。

メモリ

メモリ変数はレジスタ配列の一種であり、RAM や ROM の動作を記述するために使用できます。例：

例

reg               membit[0:255] ;  //256ビットの1ビットメモリ
reg  [7:0]        mem[0:1023] ;    //1Kバイトのメモリ、ビット幅8ビット
mem[511] = 8'b0 ;                  //512番目の8ビット記憶ユニットの値を0にする

パラメータ

パラメータは定数を表すために使われ、キーワード parameter で宣言し、代入は1回だけ行えます。例：

例

parameter      data_width = 10'd32 ;
parameter      i=1, j=2, k=3 ;
parameter      mem_size = data_width * 10 ;

ただし、インスタンス化によってモジュール内のパラメータの値を変更できます。この部分については後で紹介します。

ローカルパラメータは localparam で宣言します。その作用と使い方は parameter と同じですが、値が変更できない点が異なります。そのため、パラメータがこのモジュール内でのみ使用される場合は、localparam で記述できます。

文字列

文字列は reg 型の変数に保存され、各文字は1バイト（8ビット）を占有します。したがって、レジスタ変数のビット幅はオーバーフローしないように十分な大きさが必要です。

文字列は複数行にわたって記述できません。つまり、文字列に復帰文字を含めることはできません。レジスタ変数のビット幅が文字列のサイズより大きい場合は、左側の余ったビットを 0 で埋めます。レジスタ変数のビット幅が文字列サイズより小さい場合は、文字列の左側の余分なデータが切り捨てられます。たとえば、文字列 "run.runoob.com" を格納するには、14*8ビットの記憶ユニットが必要です。

例

reg [0: 14*8-1]       str ;
initial begin
    str = "run.runoob.com";
end  

一部の特殊文字は、表示される文字列の中で特別な意味を持ちます。たとえば改行文字やタブ文字などです。これらの特殊文字を文字列内で表示する必要がある場合は、前にエスケープ文字の接頭辞を付ける必要があります。\。次の表のようになります。

エスケープ文字表示文字
\n改行
\tタブ文字
%%%
\\
\""
\ooo1〜3桁の8進数字文字

実は、SystemVerilog（主にVerilogシミュレーション用のプログラミング言語）では、すでにキーワード string を使って文字列変数型を直接表すことができ、これによりVerilogのシミュレーションが非常に便利になりました。興味のある方はSystemVerilogを簡単に学んでみてください。
