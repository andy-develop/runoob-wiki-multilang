1.7 ヒープソート

分類 アルゴリズム

ヒープソート（Heapsort）は、ヒープというデータ構造を利用して設計されたソートアルゴリズムです。ヒープはほぼ完全二分木の構造であり、同時にヒープの性質を満たします：すなわち、子ノードのキー値またはインデックスは常にその親ノードより小さい（または大きい）という性質です。ヒープソートは、ヒープの概念を利用してソートする選択ソートの一種と言えます。2つの方法に分けられます：

  1. 大頂ヒープ：各ノードの値がその子ノードの値以上であり、ヒープソートアルゴリズムでは昇順に使用されます；
  2. 小頂ヒープ：各ノードの値がその子ノードの値以下であり、ヒープソートアルゴリズムでは降順に使用されます；

ヒープソートの平均時間計算量は Ο(nlogn) です。

1. アルゴリズムの手順

  1. ヒープ H[0……n-1] を作成します；

  2. ヒープの先頭（最大値）とヒープの末尾を交換します；

  3. ヒープのサイズを 1 縮小し、shift_down(0) を呼び出します。目的は、新しい配列の先頭データを対応する位置に調整することです；

  4. ヒープのサイズが 1 になるまでステップ 2 を繰り返します。

2. 動画デモ

ソート対象のリスト [4, 10, 3, 5, 1] があると仮定すると、ヒープソートの過程は次のとおりです：

  1. 最大ヒープの構築：

    • 初期リスト：[4, 10, 3, 5, 1]。

    • 最後の非リーフノードから始めて、ヒープを段階的に調整します：

      • ノードを調整5：[4, 10, 3, 5, 1]（調整不要）。

      • ノードを調整10：[4, 10, 3, 5, 1]（調整不要）。

      • ノードを調整4：[10, 5, 3, 4, 1]。

    • 最終的な最大ヒープ：[10, 5, 3, 4, 1]。

  2. ヒープの先頭要素を交換：

    • ヒープの先頭要素を10最後の要素と1交換すると、リストは次のようになります[1, 5, 3, 4, 10]。

    • ヒープのサイズが 1 減り、ソート済み部分は次のようになります[10]。

  3. ヒープを調整：

    • 新しいヒープの先頭要素に対して1沈降操作を行います：

      • 比較1とその子ノード5、3、1 与 5交換します。

      • リストは次のようになります[5, 1, 3, 4, 10]。

      • 比較を続けます1とその子ノード4、1 与 4交換します。

      • リストは次のようになります[5, 4, 3, 1, 10]。

    • 調整後のヒープ：[5, 4, 3, 1]。

  4. 手順を繰り返します：

    • ヒープの先頭要素を5最後の要素と1交換すると、リストは次のようになります[1, 4, 3, 5, 10]。

    • ヒープのサイズが 1 減り、ソート済み部分は次のようになります[5, 10]。

    • 新しいヒープの先頭要素に対して1沈降操作を行います：

      • 比較1とその子ノード4、3、1 与 4交換します。

      • リストは次のようになります[4, 1, 3, 5, 10]。

    • 調整後のヒープ：[4, 1, 3]。

  5. 繰り返しを続けます：

    • ヒープの先頭要素を4最後の要素と3交換すると、リストは次のようになります[3, 1, 4, 5, 10]。

    • ヒープのサイズが 1 減り、ソート済み部分は次のようになります[4, 5, 10]。

    • 新しいヒープの先頭要素に対して3沈降操作を行います：

      • 比較3とその子ノード1、交換は不要です。

    • 調整後のヒープ：[3, 1]。

  6. 最終ステップ：

    • ヒープの先頭要素を3最後の要素と1交換すると、リストは次のようになります[1, 3, 4, 5, 10]。

    • ヒープのサイズが 1 減り、ソート済み部分は次のようになります[3, 4, 5, 10]。

    • ヒープのサイズが 1 になり、ソートが完了します。

例

def heapify(arr, n, i):
    # 現在のノード、左の子ノード、右の子ノードの中から最大値を見つけます
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right

    # 最大値が現在のノードでない場合は、交換して調整を続けます
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

def heap_sort(arr):
    n = len(arr)

    # 最大ヒープを構築します
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # ヒープの先頭要素を1つずつ取り出してヒープを調整します
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # ヒープの先頭要素と最後の要素を交換します
        heapify(arr, i, 0)  # ヒープを調整します

    return arr

# 例
arr = [4, 10, 3, 5, 1]
sorted_arr = heap_sort(arr)
print(sorted_arr)  # 出力: [1, 3, 4, 5, 10]

時間計算量

  • 最大ヒープの構築：O(n)。

  • ヒープの調整ごと：O(log n)、合計 n-1 回の調整が必要です。

  • 総時間計算量：O(n log n)。

空間計算量

  • O(1)、ヒープソートはインプレースソートアルゴリズムであり、追加の記憶領域は必要ありません。

長所と短所

  • 長所：

    • 時間計算量が安定して O(n log n) であり、大規模なデータに適しています。

    • インプレースソートであり、追加の記憶領域は必要ありません。

  • 短所：

    • 不安定なソートアルゴリズムです（同じ要素の相対的な順序が変わる可能性があります）。

    • 小規模なデータの場合、挿入ソートなどの単純なアルゴリズムよりも性能が劣る可能性があります。

適用シーン

  • 大規模なデータセットのソート。

  • 性能要求が高いシーン。

  • メモリ内ソートに適しています（外部ソートには適しません）。

function buildMaxHeap(arr) {   // 大頂ヒープを構築します
    len = arr.length;
    for (var i = Math.floor(len/2); i >= 0; i--) {
        heapify(arr, i);

function heapify(arr, i) {     // ヒープ調整
    var left = 2 * i + 1,
        right = 2 * i + 2,
        largest = i;

    if (left < len && arr[left] > arr[largest]) {
        largest = left;
    }

    if (right < len && arr[right] > arr[largest]) {
        largest = right;
    }

    if (largest != i) {
        swap(arr, i, largest);
        heapify(arr, largest);
    }
}

function swap(arr, i, j) {
    var temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

function heapSort(arr) {
    buildMaxHeap(arr);

    for (var i = arr.length-1; i > 0; i--) {
        swap(arr, 0, i);
        len--;
        heapify(arr, 0);
    }
    return arr;
}

        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;

void swap(int *a, int *b) {
    int temp = *b;

void max_heapify(int arr[], int start, int end) {
    // 親ノードのインデックスと子ノードのインデックスを設定します
    int dad = start;
    int son = dad * 2 + 1;
    while (son <= end) { // 子ノードのインデックスが範囲内にある場合のみ比較します
        if (son + 1 <= end && arr[son] < arr[son + 1]) // まず2つの子ノードのサイズを比較し、最大のものを選択します
            son++;
        if (arr[dad] > arr[son]) // 親ノードが子ノードより大きい場合は調整完了なので、直接関数を抜けます
            return;
        else { // そうでなければ親子の内容を交換し、子ノードと孫ノードの比較を続けます
            swap(&arr[dad], &arr[son]);
            dad = son;
            son = dad * 2 + 1;
        }
    }
}

void heap_sort(int arr[], int len) {
    int i;
    // 初期化、i は最後の親ノードから調整を開始します
    for (i = len / 2 - 1; i >= 0; i--)
        max_heapify(arr, i, len - 1);
    // 最初に最初の要素とソート済み要素の前の要素を交換し、再調整して、ソートが完了するまで繰り返します
    for (i = len - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);
        max_heapify(arr, 0, i - 1);
    }
}

    上記には C# のヒープソートがなかったので、艾孜尔江が以下のように補足します：

    /// <summary>
/// 堆排序
/// </summary>
/// <param name="arr">待排序数组</param>
static void HeapSort(int[] arr)
{
    int vCount = arr.Length;
    int[] tempKey = new int[vCount + 1];
    // 元素索引从1开始
    for (int i = 0; i < vCount; i++)
    {
        tempKey[i + 1] = arr[i];
    }
    // 初始数据建堆（从含最后一个结点的子树开始构建，依次向前，形成整个二叉堆）
    for (int i = vCount / 2; i >= 1; i--)
    {
        Restore(tempKey, i, vCount);
    }
    // 不断输出堆顶元素、重构堆，进行排序
    for (int i = vCount; i > 1; i--)
    {
        int temp = tempKey[i];
        tempKey[i] = tempKey[1];
        tempKey[1] = temp;
        Restore(tempKey, 1, i - 1);
    }
    //排序结果
    for (int i = 0; i < vCount; i++)
    {
        arr[i] = tempKey[i + 1];
    }
}
/// <summary>
/// 二叉堆的重构（针对于已构建好的二叉堆首尾互换之后的重构）
/// </summary>
/// <param name="arr"></param>
/// <param name="rootNode">根结点j</param>
/// <param name="nodeCount">结点数</param>
static void Restore(int[] arr, int rootNode, int nodeCount)
{
    while (rootNode <= nodeCount / 2) // 保证根结点有子树
    {
        //找出左右儿子的最大值
        int m = (2 * rootNode + 1 <= nodeCount && arr[2 * rootNode + 1] > arr[2 * rootNode]) ? 2 * rootNode + 1 : 2 * rootNode;
        if (arr[m] > arr[rootNode])
        {
            int temp = arr[m];
            arr[m] = arr[rootNode];
            arr[rootNode] = temp;
            rootNode = m;
        }
        else
        {
            break;
        }
    }
}

    ヒープソートは不安定なソートです！

    それならば、毎回大頂ヒープを構築する際に、親ノード、左の子ノード、右の子ノードの3つの中から最大のものを親ノードとすればよいのです。私たちが求めているのは最終的なソート結果だけなので、その手順を簡略化することができます。

    私が個人的に書いた Java コードの核心を以下に置いておきます。興味のある方は一緒に議論しましょう：

    public int[] sort(int a[]) {
    int len = a.length - 1;    
    for (int i = len; i > 0; i--) {
        maxHeap(a, i);        
        //交换 跟节点root 与 最后一个子节点i 的位置        
        swap(a, 0, i);        
        //i--无序数组尺寸减少了 
    }  
    return a;
}

/**构建一个大顶堆（完全二叉树 ） 
* 从  最后一个非叶子节点  开始，若父节点小于子节点，则互换他们两的位置。然后依次从右至左，从下到上进行！ 
* 最后一个非叶子节点，它的叶子节点 必定包括了最后一个（叶子）节点，所以 最后一个非叶子节点是 a[（n+1）/2-1] 
 
* @param a 
* @param lastIndex 这个数组的最后一个元素 
*/
static void maxHeap(int a[], int lastIndex) {
    for (int i = (lastIndex + 1) / 2 - 1; i >= 0; i--) {
       //反正 堆排序不稳定，先比较父与左子，大则交换；与右子同理。（不care 左子与右子位置是否变了！） 
        if (i * 2 + 1 <= lastIndex && a[i] < a[i * 2 + 1]) {
            swap(a, i, i * 2 + 1);        
        }    
        if (i * 2 + 2 <= lastIndex && a[i] < a[i * 2 + 2]) {
            swap(a, i, i * 2 + 2);        
        }
    }
}

private void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
