Androidの6大レイアウトを学び終えたら、この節からAndroidのUIコントロールを一つ一つ解説していきます。この節で紹介するUIコントロールはTextView(テキストボックス)で、テキストを表示するためのコントロールです。また一つ断っておきますが、私はAPIドキュメントを翻訳しているわけではなく、属性を一つ一つ細かく取り上げることはしません。実際の開発でよく使う、役に立つものだけを学びます。皆さんが遭遇して馴染みのない属性があれば、対応するAPIを調べることができます！もちろん、各節の冒頭にはこの節に対応するAPIドキュメントのリンクを貼ります。TextView APIさて、本節の内容を始める前に、いくつかの単位を紹介しておきます。

dp(dip):device independent pixels（デバイス非依存ピクセル）。デバイスによって表示効果が異なり、これはデバイスのハードウェアに関係します。一般的にWVGA、HVGA、QVGAをサポートするためにこれを使用することをお勧めします。ピクセルに依存しません。px: pixels（ピクセル）異なるデバイスでも表示効果は同じです。一般的にHVGAは320x480ピクセルを表し、これはよく使われます。pt: pointptは標準的な長さの単位で、1pt＝1/72インチです。印刷業界で使われ、非常に簡単で使いやすいです。sp: scaled pixels（拡大ピクセル）主にフォント表示に使用され、textsizeに最適です。

1. 基本属性詳解：

次のシンプルな画面を通して、いくつかの最も基本的な属性を理解しましょう。

レイアウトコード：

<RelativeLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context=".MainActivity"
    android:gravity="center"
    android:background="#8fffad">

    <TextView
        android:id="@+id/txtOne"
        android:layout_width="200dp"
        android:layout_height="200dp"
        android:gravity="center"
        android:text="TextView(显示框)"
        android:textColor="#EA5246"
        android:textStyle="bold|italic"
        android:background="#000000"
        android:textSize="18sp" />

</RelativeLayout>

上記のTextViewには以下の属性があります：

  • id：TextViewにコンポーネントidを設定します。このidに基づいて、JavaコードでfindViewById()メソッドを使ってそのオブジェクトを取得し、関連する属性を設定できます。またRelativeLayoutを使用する際に、他のコンポーネントを参照するときもidを使用します！
  • layout_width：コンポーネントの幅。通常は**wrap_content**または**match_parent(fill_parent)**を指定します。前者はコントロールが表示する内容のサイズに合わせてコントロールもその大きさになり、後者はコントロールが属する親コンテナを埋め尽くします。もちろん特定のサイズに設定することもできます。例えばここでは表示効果のために200dpに設定しました。
  • layout_height：コンポーネントの高さ。内容は上記と同じです。
  • gravity：コントロール内のコンテンツの配置方向を設定します。TextViewでは文字、ImageViewでは画像などの場合です。
  • text：表示するテキスト内容を設定します。通常は文字列をstring.xmlファイルに書き、@String/xxx で対応する文字列内容を取得します。ここでは便宜上直接""に書いていますが、この書き方は推奨しません！！！
  • textColor：フォントの色を設定します。上記と同様にcolors.xmlリソースを参照して使います。直接このように書いてはいけません！
  • textStyle：フォントスタイルを設定します。3つの選択可能な値：**normal**(効果なし)、**bold**(太字)、**italic**(斜体)
  • textSize：フォントサイズ。単位は通常spを使います！
  • background：コントロールの背景色。コントロール全体を埋める色と理解できます。画像にすることもできますよ！

2.2 枠線付きTextView：

TextViewに枠線の背景を設定したい場合、通常の長方形の枠線や角丸の枠線など、次の方法が役立つかもしれません。また、TextViewはButtonなど多くの他のコントロールの親クラスであり、同様の枠線を設定することもできます！実装の原理は非常に簡単で、ShapeDrawableのリソースファイルを自分で作成し、TextViewのbackgroundをこのdrawableリソースに設定するだけです！

shapeDrawableリソースファイルのいくつかのノードと属性について簡単に説明します：

  • <solidandroid:color = "xxx"> これは背景色を設定するものです。
  • <strokeandroid:width = "xdp" android:color="xxx"> これは枠線の太さと枠線の色を設定するものです。
  • <paddingandroidLbottom = "xdp"...> これは余白を設定するものです。
  • <cornersandroid:topLeftRadius="10px"...> これは角丸を設定するものです。
  • <gradient> これはグラデーションの色を設定するもので、選択可能な属性は次のとおりです：startColor：開始色endColor：終了色centerColor：中間色angle：方向角度。0のときは左から右へ、そこから反時計回りに回転します。angle = 90度のときは下から上へ向きます。type：グラデーションのタイプを設定します。

2.5 TextViewでHTMLを使いこなす

タイトルの通り、普通のテキストを表示する以外に、TextViewにはHTMLに似たタグがいくつか事前定義されています。これらのタグを使うことで、TextViewに異なるフォントの色、サイズ、書体、さらには画像やリンクなどを表示できます。HTMLのいくつかのタグとandroid.text.HTMLクラスのサポートを使うだけで、上記の機能を実現できます！

PS: もちろん、すべてのタグがサポートされているわけではなく、よく使われるものは以下の通りです：

  • <font>：色とフォントを設定します。
  • <big>：フォントを大に設定
  • <small>：フォントを小に設定
  • <i><b>：斜体・太字
  • <a>：URLにリンク
  • <img>：画像

直接setTextを呼んでも効果はありません。Html.fromHtml()メソッドを呼び出して文字列をCharSequenceインターフェースに変換してから設定する必要があります。さらに、対応する設定が必要な場合は、TextViewに設定するために以下のメソッドを呼び出します：Java setMovementMethod(LinkMovementMethod.getInstance())

では、コードを書いて試してみましょう：

1）テキストとハイパーリンクタグのテスト

package jay.com.example.textviewdemo;

import android.os.Bundle;
import android.support.v7.app.AppCompatActivity;
import android.text.Html;
import android.text.method.LinkMovementMethod;
import android.text.util.Linkify;
import android.widget.TextView;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        TextView t1 = (TextView)findViewById(R.id.txtOne);
        String s1 = "<font color='blue'><b>百度一下，你就知道~：</b></font><br>";
        s1 += "<a href = 'http://www.baidu.com'>百度</a>";
        t1.setText(Html.fromHtml(s1));
        t1.setMovementMethod(LinkMovementMethod.getInstance());
    }
}

2.6 SpannableString&SpannableStringBuilderでテキストをカスタマイズする

上記のHTMLでTextViewのスタイルをカスタマイズできるだけでなく、SpannableStringとSpannableStringBuilderを使っても実現できます。両者の違い: 前者は不変テキストを対象とし、後者は可変テキストを対象とします。ここでは前者のみを解説します。後者に興味がある方はご自身で資料を調べてください。

SpannableStringで利用できるAPIは以下の通りです：

  • BackgroundColorSpan背景色
  • ClickableSpanテキストをクリック可能にし、クリックイベントを持たせる
  • ForegroundColorSpanテキストの色（前景色）
  • MaskFilterSpan装飾効果、例えばぼかし(BlurMaskFilter)、エンボス(EmbossMaskFilter)
  • MetricAffectingSpan親クラス、通常は使用しない
  • RasterizerSpanラスタライズ効果
  • StrikethroughSpan取り消し線（中線）
  • SuggestionSpanプレースホルダーに相当
  • UnderlineSpan下線
  • AbsoluteSizeSpan絶対サイズ（テキストのフォント）
  • DynamicDrawableSpan画像を設定し、テキストのベースラインまたは下部に揃える。
  • ImageSpan画像
  • RelativeSizeSpan相対サイズ（テキストのフォント）
  • ReplacementSpan親クラス、通常は使用しない
  • ScaleXSpanX軸に基づくスケーリング
  • StyleSpanフォントスタイル: 太字、斜体など
  • SubscriptSpan下付き文字（数式で使用）
  • SuperscriptSpan上付き文字（数式で使用）
  • TextAppearanceSpanテキストの外観（フォント、サイズ、スタイル、色を含む）
  • TypefaceSpanテキストのフォント
  • URLSpanテキストのハイパーリンク

まあ、かなり多いですね。ここでは最も簡単な例を示します。他のパラメータの呼び出しはご自身でBaiduやGoogleで調べてください〜1）最も簡単な例：実行結果画像：

実装コード：

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        TextView t1 = (TextView) findViewById(R.id.txtOne);
        TextView t2 = (TextView) findViewById(R.id.txtTwo);

        SpannableString span = new SpannableString("红色打电话斜体删除线绿色下划线图片:.");
        //1.设置背景色,setSpan时需要指定的flag,Spanned.SPAN_EXCLUSIVE_EXCLUSIVE(前后都不包括)
        span.setSpan(new ForegroundColorSpan(Color.RED), 0, 2, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //2.用超链接标记文本
        span.setSpan(new URLSpan("tel:4155551212"), 2, 5, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //3.用样式标记文本（斜体）
        span.setSpan(new StyleSpan(Typeface.BOLD_ITALIC), 5, 7, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //4.用删除线标记文本
        span.setSpan(new StrikethroughSpan(), 7, 10, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //5.用下划线标记文本
        span.setSpan(new UnderlineSpan(), 10, 16, Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //6.用颜色标记
        span.setSpan(new ForegroundColorSpan(Color.GREEN), 10, 13,Spanned.SPAN_EXCLUSIVE_EXCLUSIVE);
        //7.//获取Drawable资源
        Drawable d = getResources().getDrawable(R.drawable.icon);
        d.setBounds(0, 0, d.getIntrinsicWidth(), d.getIntrinsicHeight());
        //8.创建ImageSpan,然后用ImageSpan来替换文本
        ImageSpan imgspan = new ImageSpan(d, ImageSpan.ALIGN_BASELINE);
        span.setSpan(imgspan, 18, 19, Spannable.SPAN_INCLUSIVE_EXCLUSIVE);
        t1.setText(span);
    }
}

2）部分的にクリック可能なTextViewを実装するQQ空間や微信（WeChat）のモーメンツをやったことがある人なら、以下のものには馴染みがあるでしょう。対応するユーザーをクリックして、そのユーザーに関する情報を見に行くことができますよね！

では、簡単な例を書いてこの効果を実現してみましょう：

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        TextView t1 = (TextView) findViewById(R.id.txtOne);

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 20; i++) {
            sb.append("好友" + i + "，");
        }

        String likeUsers = sb.substring(0, sb.lastIndexOf("，")).toString();
        t1.setMovementMethod(LinkMovementMethod.getInstance());
        t1.setText(addClickPart(likeUsers), TextView.BufferType.SPANNABLE);
    }

    //定义一个点击每个部分文字的处理方法
    private SpannableStringBuilder addClickPart(String str) {
        //赞的图标，这里没有素材，就找个笑脸代替下~
        ImageSpan imgspan = new ImageSpan(MainActivity.this, R.drawable.ic_widget_face);
        SpannableString spanStr = new SpannableString("p.");
        spanStr.setSpan(imgspan, 0, 1, Spannable.SPAN_INCLUSIVE_EXCLUSIVE);

        //创建一个SpannableStringBuilder对象，连接多个字符串
        SpannableStringBuilder ssb = new SpannableStringBuilder(spanStr);
        ssb.append(str);
        String[] likeUsers = str.split("，");
        if (likeUsers.length > 0) {
            for (int i = 0; i < likeUsers.length; i++) {
                final String name = likeUsers[i];
                final int start = str.indexOf(name) + spanStr.length();
                ssb.setSpan(new ClickableSpan() {
                    @Override
                    public void onClick(View widget) {
                        Toast.makeText(MainActivity.this, name,
                                Toast.LENGTH_SHORT).show();
                    }

                    @Override
                    public void updateDrawState(TextPaint ds) {
                        super.updateDrawState(ds);
                        //删除下划线，设置字体颜色为蓝色
                        ds.setColor(Color.BLUE);
                        ds.setUnderlineText(false);
                    }
                },start,start + name.length(),0);
            }
        }
    return ssb.append("等" + likeUsers.length + "个人觉得很赞");
    }
}

2.8 TextViewの文字間隔と行間隔を設定する

普段ドキュメントを作成するときのように、レイアウトを整えて行間や文字間の間隔を設定する必要がありますよね。AndroidのTextViewでもこのような設定ができます：

文字間隔： 

android:textScaleX：控制字体水平方向的缩放，默认值1.0f，值是float
Java中setScaleX(2.0f);

行間隔：AndroidシステムのTextViewはデフォルトで中国語を表示するときにやや密集しています。各行の行間隔を保つために

android:lineSpacingExtra：行間隔を設定します。例: "3dp"android:lineSpacingMultiplier：行間隔の倍数を設定します。例: "1.2"

Javaコードでは次のようにして設定できます:setLineSpacingメソッドで設定します

2.9 自動改行

自動折り返しはandroid:singleLine設定で、デフォルトはfalseです。

自動折り返しが必要な場合は、次を使用できます：

android:singleLine = "false"

1行で全部表示したい場合（折り返さない）は、次を使用できます：

android:singleLine = "true"

その他にも、複数行で表示しきれない場合は、maxLines属性を追加すればOKです！
