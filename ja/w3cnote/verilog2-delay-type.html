3.1 Verilog 遅延モデル

分類 Verilog チュートリアル 上級編

キーワード： 分布遅延、集中遅延、パス遅延

これまでのほとんどのシミュレーションは、デジタル回路の機能の正確性を検証するものであり、信号伝送は理想的で遅延はありませんでした。しかし、実際の論理素子やそれらの間の伝送経路には遅延が存在します。したがって、設計内の遅延が実際の回路のタイミング制約要件を満たすかどうかを確認する必要があります。タイミングを確認するには、タイミングシミュレーションを使用する方法があります。つまり、シミュレーション時に素子や経路に実際の遅延と一致する遅延情報を追加し、関連する計算を行うことで、タイミングが満たされているかを判定します。

静的タイミング解析 (Static Timing Analysis, STA) も、タイミング検証技術の一つです。これは論理機能の正しさには関心を持たず、設計内のタイミングのみを計算・分析して、回路内にタイミング制約に違反 (violation) する設計が存在するかどうかを判定します。STA は分析速度が速く、問題を迅速に特定できますが、いくつかの非同期の問題は無視されます。

したがって、「STA + タイミングシミュレーション」は比較的完全で安全なタイミング検証方法です。本チュートリアルではタイミングシミュレーションについて簡単に紹介するだけで、STA については今のところ議論しません。

遅延モデルには主に3種類あります：分布遅延、集中遅延（lumped）、パス遅延です。

分布遅延

分布遅延は、回路内の個々の独立した素子ごとに遅延を定義する必要があり、経路ごとに異なる遅延時間を持ちます。下図に示すとおりです。

分布遅延の Verilog モデルは、論理ゲートをインスタンス化して遅延値を指定する方法と基本的に同じです。

例

module and4(
   output       out,
   input        a, b, c, d);

   wire         an1, an2 ;
   and #1       (an1, a, b);
   and #2       (an2, c, d);
   and #1.5     (out, an1, an2);
endmodule

分布遅延は、連続代入文 assign を使用して記述することもできます。

例

module and4(
   output       out,
   input        a, b, c, d);

   wire         an1, an2 ;
   assign #1    an1 = a & b ;
   assign #2    an2 = c & d ;
   assign #1.5  out = an1 & an2 ;
endmodule

集中遅延

集中遅延は、すべての経路の累積遅延を最後のゲートユニットに集中させるものです。

最後のゲートユニットに到達する遅延は経路によって異なるため、このとき最大遅延を最後のゲートユニットの遅延とします。

上記の分布遅延図を集中遅延図に変換すると、下図のようになります。

集中遅延の Verilog モデルは次のとおりです。

例

module and4(
   output       out,
   input        a, b, c, d);

   wire         an1, an2 ;
   and          (an1, a, b);
   and          (an2, c, d);
   and #3.5     (out, an1, an2); //set the max delay at the last gate
endmodule

パス遅延

パス遅延は、各入力ピンから各出力ピンまでのすべての経路に対して遅延時間を指定するものです。

パス遅延の模式図は以下のとおりです。

パス遅延モデルは、キーワード specify を使用して定義する必要があります。

パス遅延の Verilog モデルは以下のとおりです。具体的な定義方法は次のセクションで詳しく説明します。

例

module and4(
   output       out,
   input        a, b, c, d);

   specify
      (a => out) = 2.5 ;
      (b => out) = 2.5 ;
      (c => out) = 3.5 ;
      (d => out) = 3.5 ;
   endspecify

   wire         an1, an2 ;
   and          (an1, a, b);
   and          (an2, c, d);
   and          (out, an1, an2);
endmodule

遅延モデルの比較

  • 分布遅延：分布遅延は遅延時間を各ゲートユニットに分散させますが、基本ユニット内の異なるピン間の遅延の違いは依然として記述できません。設計規模が大きくなると、構造が複雑になります。
  • 集中遅延：この方式はモデルが単純で、小規模な回路に適していますが、入力端から出力端までの異なる経路の遅延を記述することはできません。
  • パス遅延：ピンからピンへの遅延を指定するため、遅延情報が比較的充実しています。情報は多いですが、大規模回路でも実装が容易です。設計者はモジュール内部の実装ロジックを気にする必要がなく、入力から出力ピンまでの遅延を理解するだけで済むからです。モジュール内部のロジックが変更されても、パス遅延の記述はそのまま維持できます。

したがって、ほとんどの論理ゲートユニットライブラリの遅延情報は、パス遅延の形式で提供されています。多くの集積モジュールでも、データシートからパス遅延を直接取得できるため、非常に便利です。
