请不要做浮躁的IT人 → 浮ついたIT人にならないでください

分类 → カテゴリ 程序员人生 → プログラマーの人生

  • 1、不要看到别人的回复第一句话就说：给个代码吧！你应该想想为什么。当你自己想出来再参考别人的提示，你就知道自己和别人思路的差异。 → 1、他人の返信を見て最初の一言で「コードをくれ！」と言わないこと。なぜなのかを考えるべきだ。自分で考え出してから他人のヒントを参考にすれば、自分と他人の考え方の違いが分かる。
  • 2、初学者请不要看太多太多的书那会误人子弟的，先找本系统的学，很多人用了很久都是只对部分功能熟悉而已，不系统还是不够的。 → 2、初心者はあまりにも多くの本を読まないこと。それは人を誤らせる。まず体系的な本を探して学ぶこと。多くの人は長く使っていても一部の機能に慣れているだけで、体系的でなければ十分とは言えない。
  • 3、看帮助,不要因为很难而自己是初学者所以就不看；帮助永远是最好的参考手册，虽然帮助的文字有时候很难看懂，总觉得不够直观。 → 3、ヘルプを見ること。難しいから、初心者だからといって見ないのはやめよう。ヘルプは常に最良のリファレンスマニュアルだ。ヘルプの文章は時々とても理解しにくく、直感的ではないと感じるかもしれないが。
  • 4、不要被对象、属性、方法等词汇所迷惑；最根本的是先了解最基础知识。 → 4、オブジェクト、プロパティ、メソッドなどの言葉に惑わされてはいけない。最も根本的なのは、まず基礎知識を理解することだ。
  • 5、不要放过任何一个看上去很简单的小问题--他们往往并不那么简单，或者可以引伸出很多知识点；不会举一反三你就永远学不会。 → 5、一見簡単そうに見える小さな問題も見逃してはいけない。それらは往々にしてそんなに簡単ではなく、多くの知識ポイントを導き出すことができる。類推できなければ永遠に学べない。
  • 6、知道一点东西，并不能说明你会写脚本，脚本是需要经验积累的。 → 6、少し知っているからといって、スクリプトが書けるわけではない。スクリプトは経験の蓄積が必要だ。
  • 7、学脚本并不难，JSP、ASP、PHP等等也不过如此--难的是长期坚持实践和不遗余力的博览群书； → 7、スクリプトを学ぶのは難しくない。JSP、ASP、PHPなども大したことはない。難しいのは、長期的に実践を続け、全力を尽くして多くの本を読むことだ。
  • 8、看再多的书是学不全脚本的，要多实践。 → 8、どんなに多くの本を読んでもスクリプトを完全に学ぶことはできない。多く実践することだ。
  • 9、把时髦的技术挂在嘴边，还不如把过时的技术记在心里； → 9、流行りの技術を口にするよりも、時代遅れの技術を心に留めておくほうがましだ。
  • 10、学习脚本最好的方法之一就是多练习； → 10、スクリプトを学ぶ最良の方法の一つは、多く練習することだ。
  • 11、在任何时刻都不要认为自己手中的书已经足够了； → 11、どんな時も、自分の手元の本で十分だと思ってはいけない。
  • 12、看得懂的书，请仔细看；看不懂的书，请硬着头皮看； → 12、理解できる本はじっくり読むこと。理解できない本は、無理やりにでも読むこと。
  • 13、别指望看第一遍书就能记住和掌握什么——请看第二遍、第三遍； → 13、一回読んだだけで何かを覚えたり習得したりできると期待してはいけない。二回目、三回目と読むこと。
  • 14、请把书上的例子亲手到电脑上实践，即使配套光盘中有源文件； → 14、本の例を実際に自分でコンピュータで実践すること。たとえ付属のCDにソースファイルがあっても。
  • 15、把在书中看到的有意义的例子扩充；并将其切实的运用到自己的工作中； → 15、本で見た意味のある例を拡張し、それを実際に自分の仕事に応用すること。
  • 16、不要漏掉书中任何一个练习——请全部做完并记录下思路； → 16、本の中のどの練習問題も逃さないこと。すべてやり遂げて、考え方を記録すること。
  • 17、当你用脚本到一半却发现自己用的方法很拙劣时，请不要马上停手；请尽快将余下的部分粗略的完成以保证这个代码的完整性，然后分析自己的错误并重新编写和工作。 → 17、スクリプトを半分書いたところで自分のやり方が稚拙だと気づいても、すぐに手を止めてはいけない。残りの部分を早急に大まかに完成させてコードの完全性を保証し、それから自分の間違いを分析して、書き直して作り直すこと。
  • 18、别心急，写脚本确实不容易；水平是在不断的实践中完善和发展的； → 18、焦ってはいけない。スクリプトを書くのは確かに簡単ではない。レベルは絶え間ない実践の中で向上し発展していくものだ。
  • 19、每学到一个脚本难点的时候，尝试着对别人讲解这个知识点并让他理解----你能讲清楚才说明你真的理解了； → 19、スクリプトの難所を学ぶたびに、他の人にその知識ポイントを説明して理解させようと試みること。うまく説明できて初めて、本当に理解したと言える。
  • 20、记录下在和别人交流时发现的自己忽视或不理解的知识点； → 20、他の人と交流する際に、自分が見落としていた、または理解していなかった知識ポイントを記録すること。
  • 21、保存好你做过的所有的源文件----那是你最好的积累之一； → 21、作成したすべてのソースファイルをしっかり保存すること。それはあなたの最良の蓄積の一つだ。
  • 22、对于网络，还是希望大家能多利用一下，很多问题不是非要到论坛来问的，首先你要学会自己找答案，比如google、百度都是很好的搜索引擎，你只要输入关键字就能找到很多相关资料，别老是等待别人给你希望，看的出你平时一定也很懒！ → 22、ネットワークについては、皆さんにもっと活用してほしい。多くの問題はわざわざフォーラムで質問する必要はない。まず自分で答えを探すことを学ぶべきだ。例えばGoogleや百度はとても良い検索エンジンで、キーワードを入力するだけで多くの関連資料が見つかる。いつまでも他人が希望を与えてくれるのを待っていてはいけない。普段からきっとあなたも怠けているのが見えるよ！
  • 23、到一个论坛，你学会去看以前的帖子，不要什么都不看就发帖子问，也许你的问题早就有人问过了，你再问，别人已经不想再重复了，做为初学者，谁也不希望自己的帖子没人回的。 → 23、フォーラムに来たら、以前のスレッドを読むことを覚えること。何も見ずにいきなりスレッドを立てて質問してはいけない。あなたの質問はもしかしたら誰かが既に質問しているかもしれない。もう一度聞いても、誰も繰り返したくない。初心者として、自分のスレッドに返信がないのは誰だって嫌なものだ。
  • 24、虽然不是打击初学者，但是这句话还是要说：论坛论坛，就是大家讨论的地方，如果你总期望有高手总无偿指点你，除非他是你亲戚！！讨论者，起码是水平相当的才有讨论的说法，如果水平真差距太远了，连基本操作都需要别人给解答，谁还跟你讨论呢。能找到很多相关资料，别老是等待别人给你希望，看的出你平时一定也很懒！ → 24、初心者を落ち込ませるつもりはないが、この言葉は言っておくべきだ。フォーラムとは、皆が議論する場所だ。もし常に上級者が無償で教えてくれることを期待しているなら、彼があなたの親戚でない限り無理だ！！議論するには、少なくともレベルが同等でなければ議論にならない。もしレベルの差が大きすぎて、基本的な操作まで誰かに答えてもらわなければならないなら、誰があなたと議論するだろうか。多くの関連資料が見つかるのだから、いつまでも他人が希望を与えてくれるのを待っていてはいけない。普段からきっとあなたも怠けているのが見えるよ！

浮躁的人容易问：我到底该学什么；----别问，学就对了； → 浮ついた人はこう聞きがちだ。「一体何を学べばいいのか？」----聞くな、学べばいいんだ。

浮躁的人容易问：JS有钱途吗；----建议你去抢银行； → 浮ついた人はこう聞きがちだ。「JSに将来性はあるのか？」----銀行を強奪することを勧める。

浮躁的人容易说：我要中文版！我英文不行！----不行？学呀！ → 浮ついた人はこう言いがちだ。「中国語版が欲しい！英語ができない！」----できない？学べばいいだろ！

浮躁的人分两种：只观望而不学的人；只学而不坚持的人； → 浮ついた人には二種類いる。見ているだけで学ばない人と、学んでも続けない人だ。

浮躁的人永远不是一个高手。 → 浮ついた人は決して達人にはなれない。
