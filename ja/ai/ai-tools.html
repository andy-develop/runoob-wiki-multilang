AI の動作原理

AI ツール全景

2023年以降、AIツールの数は指数関数的に増加しています。

文章を書くにはAIライティングアシスタント、絵を描くにはAIイラストツール、コードを書くにはAIプログラミングアシスタント、PPT作成や動画編集に至るまで専用のAIツールがあります。

何百ものAIツールを前にして、多くの人の最初の反応は「どこから始めればいいのか」「どれが自分に合っているのか」でしょう。

この章では、AIツールの認知フレームワークを構築します。どのようなカテゴリーがあるのか、各カテゴリーの代表的なツール、それらの長所と短所、どのシーンで何を使うべきかを理解できます。

すべての新ツールを試す必要はありません。自分に合った3〜5個を見つけて使いこなせば十分です。

ツールは人に仕えるものです。ツールを使うために使うのではなく、解決したい問題を明確にし、その問題を解決できるツールを探しましょう。

テキスト生成ツールの選択アドバイス

初めてAIに触れるなら、ChatGPT 或 Claudeから始めるのがおすすめです——それらは現在のテキスト生成の最高水準を代表しています。

コードアシスタントの使用例

Cursor を例に挙げます。これはAIのために特別に設計されたコードエディターです。

Cursor では、次のようにAIと協力できます。

シーン1：AIに runoob チュートリアルページを生成させる

次のように入力するだけです：

创建一个简单的 Python 入门教程网页，包含标题、代码示例、说明

AIが完全なHTMLファイルを直接生成してくれます。

シーン2：AI にコードを説明させる

理解できないコードを選択し、Cmd+K（Mac）または Ctrl+K（Windows）を押します。

その後、次のように入力します：

解释这段代码在做什么

AI がコードを1行ずつ解析し、各ステップの実行プロセスを説明します。

シナリオ3：AI にバグを修正させる

エラーが発生しているコードを選択します。

その後、次のように入力します：

这段代码报错了，帮我看看问题在哪，修复它

AI がエラーの原因を特定し、実行可能な修正案を提示します。

シナリオ4：コードをリファクタリングする

最適化が必要なコードを選択します。

その後、次のように入力します：

这段代码太乱了，帮我重构得更清晰，加上注释

AI がコード構造を最適化し、責務を分割し、必要なコメントを自動的に追加して、可読性と保守性を高めます。

GitHub Copilot はどちらかというと超自動補完のようなもので、コメントを書けばコードを書いてくれ、途中まで書けば残りを補完してくれます。

実例

# VS Code に Copilot をインストールしているとします
# 次のようなコメントを書きます：

def calculate_runoob_score(student_data):
    """学生の runoob 総合スコアを計算する
入力は宿題、試験、出席を含む辞書
出力は 0-100 の合計点
    """
    # ここまで書くと、Copilot が関数全体を自動補完するかもしれません：

    # Copilot が自動補完した内容（例）：
    homework_weight = 0.3
    exam_weight = 0.5
    attendance_weight = 0.2

    homework_score = student_data.get("homework", 0)
    exam_score = student_data.get("exam", 0)
    attendance_score = student_data.get("attendance", 0)

    total = (homework_score * homework_weight +
             exam_score * exam_weight +
             attendance_score * attendance_weight)

    return min(max(total, 0), 100)

# ゼロから書くのではなく、正しいかどうか確認するだけでよい

コードアシスタントの選択アドバイス

学生または駆け出しのエンジニアなら、GitHub Copilot（https://github.com/copilot）は必ず入れるべきです。書けないというハードルを素早く越えられます。

よりスマートな AI プログラミングを体験したいなら、試してみてくださいCursor/Qoder/Trae——これで一度プロジェクトを書けば、AI時代のプログラミングがどういうものか分かります。

注意：AI が書いたコードにはバグやセキュリティ問題がある可能性があります。あなたはプログラマーであり、コードに対して責任を持つ必要があります。AI をアシスタントとして使い、権威として扱わないでください。

検索強化 AI の使用シーン

従来の検索エンジンではなく、検索強化 AI を使うべきなのはどんなとき？

情報を統合したいとき：例えば「2024 年の AI 分野にはどんな重要な進展があったか」——AI が各ソースの情報を統合して概要をまとめてくれます。何十本ものニュースを投げられるのではありません。

リンクではなく答えが必要なとき：例えば「Python でメールを送るにはどうすればいいか」——AI が完全なコード例と手順を直接教えてくれます。十数本のブログを読む必要はありません。

事実確認が必要なとき：例えば「ある会社の決算データはいくらか」——AI が最新の公式データを調べてくれます。古い情報を渡されることはありません。

ヒント：検索強化 AI でも間違うことがあります。重要な情報はクロスチェックし、ひとつのソースだけを見ないでください。

Whisper 使用例

Whisper は OpenAI がオープンソース化した音声認識モデルで、音声をテキストに変換するのに非常に便利です。

実例

# Whisper をインストール（事前に Python と ffmpeg が必要）
pip install openai-whisper

# 最も簡単な使い方：音声ファイルをテキストに変換
whisper runoob_podcast.mp3 --model base

# 中国語モデルを指定
whisper runoob_interview.wav --model small --language Chinese

# 字幕ファイル形式（SRT、VTT）で出力
whisper runoob_lecture.m4a --model medium --language Chinese --output_format srt

# Whisper は次のように出力します：
# [00:00:00.000 --> 00:00:05.000] runoob チュートリアルへようこそ
# [00:00:05.000 --> 00:00:10.000] 今日は AI ツールの使い方を学びます

注意：AI 音声ツールは悪用される可能性があります。法律・規制を守り、許可なく他人の声をクローンしたり、AI が生成したコンテンツで詐欺を行ったりしないでください。

ツール選びの基本原則

これだけ多くのツールがある中で、どう選べばよいでしょうか。意思決定に役立ついくつかの原則があります。

原則1：問題を明確にしてから、ツールを探す

誰かが良いツールだと言ったからといって、すぐ試さないこと。まず「何を解決したいのか」をはっきりさせましょう。

コードを速く書きたい？それならコードアシスタント。デザインを作りたい？それなら画像生成ツール。文章作成の効率を上げたい？それならテキスト生成ツールです。

ツールは手段であり、目的ではありません。

原則2：まず1つを極めてから、広げる

多くの人が犯す間違いは、あらゆるツールを試すものの、どれも深く使えていないことです。

より良い方法は、主要なツールを1つ選び、1〜2週間かけて使いこなし、その境界を把握することです。どのシーンでうまくいき、どのシーンでうまくいかないのか。

1つのツールを極めてから他のものを試すと、多くの設計思想が共通していることに気づくでしょう。

原則3：「使用頻度」を見て、「目新しさ」を見ない

毎日使えるツールは、年に一度しか使わないが派手でクールなツールよりもはるかに価値がある。

例えば、コードアシスタントは毎日コードを書くときに使えるので価値が非常に高い。動画生成ツールは半年に一度しか使わないかもしれないので、最も高価なプランを急いで購入する必要はない。

原則4：コストを考える。お金だけでなく

ツールのコストは購読料だけではなく、学習コスト、移行コスト、データセキュリティコストもある。

無料ツールでも多くの時間を費やして苦労する必要があるなら、その時間もコストだ。データをクラウドに保存するツールなら、データセキュリティもコストになる。

コストの種類説明どう判断するか
金銭的コスト購読料、従量課金など節約できる時間がその金額に見合うかどうか
学習コスト使い方を覚えるのに必要な時間大きな利益が得られない限り、シンプルで使いやすいものを優先
移行コストツールを変更する際のデータと習慣の移行エクスポート機能があり、エコシステムがオープンなツールを優先
データセキュリティデータの保存場所、閲覧可能な人機密データは、ローカルデプロイまたはプライバシーに配慮したツールを優先
