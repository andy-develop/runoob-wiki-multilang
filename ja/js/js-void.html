javascript:void(0)意味

私たちはよく使用しますjavascript:void(0)このようなコードですが、JavaScript ではjavascript:void(0)何を意味するのでしょうか？

javascript:void(0)の中で最も重要なのはvoidキーワード、voidは JavaScript で非常に重要なキーワードです。この演算子は、式を評価するが値を返さないことを指定します。

構文は次のとおりです：

void func()
javascript:void func()

または

void(func())
javascript:void(func())

次のコードはハイパーリンクを作成しますが、ユーザーがクリックしても何も起こりません。

例

<a href="javascript:void(0)">ここをクリックしても何も起こりません</a>

試してみる »

ユーザーがリンクをクリックすると、void(0) は 0 と評価されますが、JavaScript では何の効果もありません。

次の例では、ユーザーがリンクをクリックした後に警告メッセージを表示します：

例

<p>以下のリンクをクリックして結果を表示：</p> <a href="javascript:void(alert('Warning!!!'))">クリック！</a>

href="../index.html"とhref="#"の違い

## には位置情報が含まれており、デフォルトのアンカーは#topつまりウェブページの上端です。

一方、javascript:void(0) は単にデッドリンクを表します。

ページが長いときは、#を使用してページの特定の位置を特定します。形式は次のとおりです：# + id。

デッドリンクを定義する場合は、javascript:void(0) を使用してください。

例

<a href="javascript:void(0);">クリックしても反応しません！</a> <a href="#pos">クリックして指定した位置に移動！</a> <br> ... <br> <p id="pos">末尾のアンカーポイント</p>
