JavaScript 正規表現

正規表現(英語: Regular Expression、コード内ではよく regex、regexp または RE と略されます)は、単一の文字列を使用して、特定の構文規則に適合する一連の文字列を記述・照合する文字列検索パターンです。

検索パターンは、テキスト検索とテキスト置換に使用できます。

正規表現とは？

正規表現は、文字の並びによって形成される検索パターンです。

テキスト内でデータを検索するとき、検索パターンを使用して、照会したい内容を記述できます。

正規表現は、単純な1文字の場合もあれば、より複雑なパターンの場合もあります。

正規表現は、すべてのテキスト検索およびテキスト置換の操作に使用できます。

正規表現の詳細については、次を参照してください：正規表現 - チュートリアル。

構文

/正则表达式主体/修饰符(可选)

このうち、修飾子はオプションです。


例：

var patt = /runoob/i

例の解説：

/runoob/iは正規表現です。

runoobは正規表現の本体(検索に使用します)。

iは修飾子(大文字と小文字を区別しない検索です)。

文字列メソッドの使用

JavaScript では、正規表現は通常、search() と replace() の2つの文字列メソッドで使用されます。

search() メソッドは、文字列内の指定された部分文字列、または正規表現にマッチする部分文字列を検索し、その部分文字列の開始位置を返します。

replace() メソッドは、文字列内の一部の文字列を別の文字列で置換したり、正規表現にマッチする部分文字列を置換するために使用されます。

search() メソッドでの正規表現の使用

例

正規表現を使用して "Runoob" という文字列を大文字と小文字を区別せずに検索します：

var str = "Visit Runoob!"; var n = str.search(/Runoob/i);

出力結果は次のとおりです：

6

search() メソッドでの文字列の使用

search メソッドは文字列をパラメータとして使用できます。文字列パラメータは正規表現に変換されます：

例

文字列内の "Runoob" の部分文字列を検索します：

var str = "Visit Runoob!"; var n = str.search("Runoob");

replace() メソッドでの正規表現の使用

例

正規表現を使用し、大文字と小文字を区別せずに、文字列内の Microsoft を Runoob に置換します:

var str = document.getElementById("demo").innerHTML; var txt = str.replace(/microsoft/i,"Runoob");

結果の出力は次のとおりです:

Visit Runoob!

var str = document.getElementById("demo").innerHTML; var txt = str.replace("Microsoft","Runoob");

お気づきになりましたか？


正規表現パラメータは、上記のメソッドで使用できます(文字列パラメータの代わりとして)。
正規表現により、検索機能がより強力になります(例のように大文字と小文字を区別しない場合など)。

正規表現の修飾子

修飾子グローバル検索で大文字と小文字を区別しないようにできます:

修飾子 説明
i 大文字と小文字を区別しないマッチングを実行します。
g グローバルマッチングを実行します(最初のマッチを見つけた後に停止するのではなく、すべてのマッチを検索します)。
m 複数行マッチングを実行します。

正規表現のパターン

角括弧は、特定の範囲内の文字を検索するために使用されます：

式 説明
[abc] 角括弧内の任意の文字を検索します。
[0-9] 0 から 9 までの任意の数字を検索します。
(x|y) | で区切られた任意のオプションを検索します。

メタ文字は、特別な意味を持つ文字です：

メタ文字 説明
\d 数字を検索します。
\s 空白文字を検索します。
\b 単語の境界にマッチします。
\uxxxx 16進数 xxxx で規定された Unicode 文字を検索します。

量指定子:

量指定子 説明
n+ 任意の ... を少なくとも1つ含むn文字列にマッチします。
n* 任意の ... を0個以上含むn文字列にマッチします。
n? 任意の ... を0個または1個含むn文字列にマッチします。

RegExp オブジェクトの使用

JavaScript では、RegExp オブジェクトは、プロパティとメソッドがあらかじめ定義された正規表現オブジェクトです。

test() の使用

test() メソッドは正規表現メソッドです。

test() メソッドは、文字列がパターンにマッチするかどうかを検出するために使用されます。文字列にマッチするテキストが含まれている場合は true を返し、それ以外の場合は false を返します。

次の例は、文字列内の文字 "e" を検索するためのものです：

例

var patt = /e/;
patt.test("The best things in life are free!");

文字列には "e" が含まれているため、この例の出力は次のようになります：

true

試してみる »

正規表現の変数を設定する必要はなく、上記の2行のコードを1行にまとめることができます：

/e/.test("The best things in life are free!")

exec() の使用

exec() メソッドは正規表現メソッドです。

exec() メソッドは、文字列内の正規表現のマッチを検索するために使用されます。

この関数は、マッチした結果を格納した配列を返します。マッチが見つからない場合は、戻り値は null です。

次の例は、文字列内のアルファベット "e" を検索します：

例 1

/e/.exec("The best things in life are free!");

文字列には "e" が含まれているため、この例の出力は次のようになります:

e

    match()、replace()、search()、split()メソッドの正規表現パラメータは文字列で置き換えることもできます。この場合、文字列は暗黙的に正規表現に変換されます。例えば：

    var str = "abcdeabc";
console.log(str.match("abc")); // 输出["abc"]
console.log(str.replace("abc", "xyz")); // 输出"xyzdeabc"
console.log(str.search("abc")); // 输出0
console.log(str.split("abc")); // 输出["", "de", ""]

    ここで、文字列"abc"はリテラルの正規表現として扱われ、文字列内の"abc"部分にマッチします。

    ただし、文字列パラメータを正規表現に変換する際の規則はメソッドによって異なることに注意してください：

    split()メソッドとreplace()メソッドは、文字列パラメータ内のすべてのメタ文字( *、+、? など)を通常の文字として扱い、文字列内の実際の文字にマッチするように、前にバックスラッシュを付けてエスケープします。

    match()メソッドとsearch()メソッドは、文字列パラメータ内のすべてのメタ文字をメタ文字自体として扱い、文字列内の特定のパターンにマッチするように元の意味を保持します。

    例えば：

    var str = "a*b*c";
console.log(str.split("*")); // 相当于str.split(/\*/)，表示匹配一个星号字符。输出['a', 'b', 'c']
console.log(str.match("*")); // 相当于str.match(/*/)，/*/是一个无效的正则表达式。报错
console.log(str.search("*")); // 相当于str.search(/*/)。报错
console.log(str.replace("*", "+")); // 相当于str.replace(/\*/, "+")。输出a+b*c

    したがって、呼び出すときにmatch()メソッドとsearch()メソッドのときに、正規表現パラメータ内で特殊文字を表したい場合は、文字列から変換された正規表現内で、対応する文字の前にバックスラッシュを置いてエスケープする必要があります。つまり、渡す文字列内では、2つのバックスラッシュを使用してエスケープする必要があります。一方、呼び出すときにsplit()メソッドとreplace()メソッドのときは、その特別な変換規則により、文字列は正規表現内のメタ文字を表すことができません。文字列内のメタ文字の前にバックスラッシュを付けるか付けないかに関わらず、正規表現ではエスケープ文字と見なされます。

    注：split("\\")、replace("\\")、match("\\\\")、search("\\\\")バックスラッシュ1つにマッチすることを表し、xxx(/\\/) に相当します。一方split("\")、match("\")、match("\\")、match("\\\")などはすべて不正です。例えば：

    var str = "a\\b\\c";
console.log(str.split("\\")); // 输出["a", "b", "c"]
console.log(str.replace("\\","+")); // 输出a+b\c
console.log(str.match("\\\\")); // 输出['\\', index: 1, input: 'a\\b\\c', groups: undefined]
console.log(str.search("\\\\")); // 输出1

    また、文字列では正規表現のフラグを指定できず、グループを使用したり参照したりすることもできないことに注意してください。このような必要がある場合は、RegExp オブジェクトを使用しなければなりません。
