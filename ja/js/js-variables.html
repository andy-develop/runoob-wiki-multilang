JavaScript 変数

変数は情報を格納するための「コンテナ」です。

JavaScriptでは、変数はデータを格納するために使用され、プログラムの実行中に動的に変更できます。

JavaScriptでは、変数は数値、文字列、オブジェクト、関数など、さまざまな種類のデータを格納できます。

変数名は識別子であり、変数に格納されたデータを参照するために使用されます。

JavaScriptでは、以下を使用できますvar、let 和 constキーワードを使用して変数を宣言します。

  • var：ES5で導入された変数宣言方法で、関数スコープを持ちます。

  • let：ES6で導入された変数宣言方法で、ブロックスコープを持ちます。

  • const：ES6で導入された定数宣言方法で、ブロックスコープを持ち、値は変更できません。

例

var x=5; var y=6; var z=x+y;

試してみる »

代数のように

x=5
y=6
z=x+y

代数では、文字（例：x）を使用して値（例：5）を保持します。

上記の式 z=x+y により、z の値が 11 であると計算できます。

JavaScriptでは、これらの文字は変数と呼ばれます。

変数はデータを格納するコンテナと考えることができます。

JavaScript 変数

代数と同様に、JavaScript 変数は値（例：x = 5）や式（例：z = x + y）。

変数は短い名前（例：x や y）を使用できますが、より説明的な名前（例：age, sum, totalvolume）も使用できます。

  • 変数はアルファベットで始まる必要があります
  • 変数は $ と _ 記号で始めることもできます（ただし、お勧めしません）
  • 変数名は大文字と小文字を区別します（y と Y は異なる変数です）
JavaScript のステートメントと JavaScript 変数は、どちらも大文字と小文字を区別します。

JavaScript データ型

JavaScript 変数は、テキスト値 (name="Bill Gates") などの他のデータ型も保持できます。

JavaScriptでは、"Bill Gates" のようなテキストは文字列と呼ばれます。

JavaScript 変数には多くの種類がありますが、今回は数値と文字列にだけ注目します。

変数にテキスト値を代入する場合は、その値を二重引用符または一重引用符で囲む必要があります。

変数に数値を代入する場合は、引用符を使用しないでください。引用符で数値を囲むと、その値はテキストとして扱われます。

例

var pi=3.14; //ES6 に精通している場合、pi は const キーワードを使用して定数を表すことができます // const pi = 3.14; var person="John Doe"; var answer='Yes I am!';

宣言（作成） JavaScript 変数

JavaScript で変数を作成することは、通常「変数の宣言」と呼ばれます。

var キーワードを使用して変数を宣言します：

var carname;

変数を宣言した後、その変数は空です（値を持ちません）。

変数に値を代入するには、等号を使用します：

carname="Volvo";

ただし、変数を宣言するときに値を代入することもできます：

var carname="Volvo";

次の例では、carname という名前の変数を作成し、"Volvo" を代入して、id="demo" の HTML 段落に配置します：

例

var carname="Volvo"; document.getElementById("demo").innerHTML=carname;

試してみる »

var 宣言の特徴：

  • 変数は繰り返し宣言できます（元の変数を上書きします）。
  • 変数に値が代入されていない場合、デフォルト値は undefined です。
  • var で宣言された変数は巻き上げ（Hoisting）されますが、初期化はされません。

良いプログラミング習慣として、コードの先頭で必要な変数をまとめて宣言します。

1つの文で複数の変数

1つの文で多くの変数を宣言できます。その文は var で始まり、カンマで変数を区切ります：

var lastname="Doe", age=30, job="carpenter";

宣言は複数行にまたがることもできます：

var lastname="Doe",
age=30,
job="carpenter";

1つの文で宣言された複数の変数に同じ値を同時に代入することはできません:

var x, y, z = 1;

x, y は undefined で、z は 1 です。


Value = undefined

コンピュータープログラムでは、値を持たない変数を宣言することがよくあります。値を指定せずに宣言された変数の値は、実際にはundefined。

次のステートメントを実行した後、変数 carname の値は undefined になります：

var carname;

JavaScript 変数の再宣言

JavaScript 変数を再宣言しても、その変数の値は失われません：

次の2つのステートメントを実行した後、変数 carname の値は依然として "Volvo" です：

var
carname="Volvo"; 
var carname;

JavaScript 算術

JavaScript 変数を使用して算術演算を行うことができます。使用するのは = や + のような演算子です：

例

y=5; x=y+2;

let と const (ES6) を使用する

2015年以前は、var キーワードを使用して JavaScript 変数を宣言していました。

2015年以降の JavaScript バージョン (ES6) では、const キーワードを使用して定数を定義し、let キーワードを使用して限定されたスコープの変数を定義できます。

let

let は ES6 で導入された新しい変数宣言方法であり、推奨されています。

let 構文：

let variableName = value;

例

let city = "北京";
let age = 30;
console.log(city, age); // 出力: 北京 30

const

const は定数を定義するために使用され、一度代入すると変数の値は変更できません。

const 構文：

const variableName = value;

例

const z = 10;
// z = 20; // エラー、定数は再代入できません
if (true) {
    const z = 20; // 異なる定数
    console.log(z); // 出力 20
}
console.log(z); // 出力 10

const と let の詳細については、以下を参照してください：JavaScript の let と const。

    JS の let 変数の紹介:

    let var1 [= value1] [, var2 [= value2]] [, ..., varN [= valueN]];

    let を使用すると、スコープがブロックレベルに制限された変数、ステートメント、または式を宣言できます。Function 内のローカル変数には let 変数を使用することをお勧めし、変数名の衝突を避けます。

    スコープの規則

    let で宣言された変数は、宣言されたブロックまたはサブブロック内でのみ使用できます。この点は var と似ています。両者の最も重要な違いは、var で宣言された変数のスコープがそれを囲む関数全体であることです。

    function varTest() {
    var x = 1;
    if (true) {
        var x = 2;       // 同样的变量!
        console.log(x);  // 2
    }
    console.log(x);  // 2
}

function letTest() {
    let x = 1;
    if (true) {
        let x = 2;       // 不同的变量    
        console.log(x);  // 2  
    }
    console.log(x);  // 1
}

    本を読んでいるときに、「リテラル」という概念がありますが、初心者にはあまり理解しやすいものではありません。

    リテラル（literal）は、ソースコード内で固定値を表現するための記法（notation）です。整数、浮動小数点数、文字列などはすべてリテラルです。

    例：

    var a=1;   // a 是变量，1 是字面量

    また、

    var stooge = {    // stooge 是一个对象
   "frist-name" = "Julie",    // 等号左为属性名，右侧为属性值
    last_name = "beck"    // 属性名如果是合法的标识符，可省略引号

};    // "frist-name", last_name, "Julie", "beck" 都是对象字面量

    要するに、リテラルとは識別子でカプセル化されていない量であり、「値」の元の状態です。

    定数との違いは以下の通りです：

    //  C/C++:

const int A = 1;    // A 是常量，1 是字面量
A++;    // error，常量值不能改变

    JavaScriptにはオーバーロードという概念はなく、関数名のみで関数を区別します。

    後から定義した同名の関数が以前のものを上書きします。引数とは関係ありません。

    function test() {
    console.log("test");
}
test();     //输出 "test arg0 + undefined"

function test(arg1) {
    console.log("test arg" + arguments.length + " + " + arg1);
}
test(1,2);  //输出 "test arg2 + 1"

    実引数の数が仮引数より少ない場合、残りはデフォルトで代入され、undefined実引数が仮引数の数より多く渡された場合は、すべて渡されますが、対応する仮引数がないため参照できません（ただし、argumentsを使用して残りの引数を取得できます）。

    function test(arg1) {
    for(var i=0; i<arguments.length; i++) {
        console.log(arguments[i]);
    }
}
test(1,2); //输出 1 2

    変数と関数が同名の場合、変数が有効になります。

    これは変数と関数の事前解析に関係しています：

    • 変数宣言は巻き上げられ、関数宣言も巻き上げられますが、変数よりも先に宣言されます。
    • 変数の宣言と代入文を一緒に書いた場合、JSエンジンは解析時にそれを宣言と代入の2つの部分に分割し、宣言は先頭に巻き上げられ、代入は元の位置に残ります。
    • 既に宣言された変数は再度宣言されません。
    var a = 100;
function a() {
    return "function";

console.log(a);     //输出 100
console.log(a());

    前の投稿のある言葉は適切ではないと思う ——「JavaScriptでは変数の重複宣言が許可されており、後から宣言したものが以前のものを上書きします」。

    JavaScriptでは変数の重複宣言が許可されています。変数を宣言する際、JavaScriptはその変数が既に宣言されているかを自動的に判断します。既に宣言されている（つまり既に存在する）場合、重複宣言（つまり変数の初回以外の宣言）はスキップされ、宣言の操作は実行されません。

    JavaScriptの変数の値は繰り返し代入することができ、最後の代入がその変数の最終結果となります。

    var a=1;
var a=2;

//赋值覆盖相当于：
var a;
//a=1;
a=2;

//声明覆盖相当于：
//var a=1;
var a=2;

    このノートで言う「上書き」は、実は代入の上書きです。後から宣言したものが既に宣言されたものを上書きするというなら、後から宣言したものは最初の宣言時の代入ではなく undefined になるはずです。つまり、宣言の上書きであるなら、var a=1 がなく、宣言のみで代入がない変数の値は undefined になります。

    この上書きが宣言の上書きなのか代入の上書きなのかをどう検証するのでしょうか？ 次のコードを見てください：

    var a=1;
var a;

//赋值覆盖相当于：
var a;
//a=1;
a;

//声明覆盖相当于：
//var a=1;
var a;

    その後、aの値を出力して、undefined か 1 かを確認すれば分かります。

    console.log(a);

    同名の宣言・代入がある変数：順番に実行される - 後者が前者を上書きします。（同レベルの上書き）

    var a = 1; 
var a = 2;
console.log(a); // 输出结果：2

    同名の宣言・代入がある関数と変数：順番に実行される - 後者が前者を上書きします。（同レベルの上書き）

    var a = 1; 
var a = function () {     
}
console.log(a); //输出结果： a 函数

    -----------------------------------------------------------------

    注：var f = function () {} 和 function f () {}の違い（varがあればメモリが確保される）

    var f = function () {console.log("有var")} // 声明函数
function f () {} // 未声明函数
console.log(f); // 输出结果： 有var的f函数

    同名で宣言された変数：代入の優先度が高い。（同名で宣言のみで代入がない場合）

    var a = 1; // 赋值
var a; // 未赋值
console.log(a); // 输出结果： 1

    -----------------------------------------------------------------

    宣言された変数と未宣言の同名変数：後者は再代入です。（同名で未宣言の変数への代入）

console.log(a);    // 输出结果： 2

f = function () {console.log("赋值")} // 未声明变量
console.log(f);   // 输出结果：function () {console.log("赋值")}
