JavaScript スコープ

スコープとは、アクセス可能な変数の集合です。

JavaScript スコープ

JavaScript では、オブジェクトと関数も同様に変数です。

JavaScript では、スコープはアクセス可能な変数、オブジェクト、関数の集合です。

JavaScript 関数スコープ: スコープは関数内で変更されます。

JavaScript ローカルスコープ

関数内で宣言された変数はローカル変数であり、ローカルスコープを持ちます。

ローカル変数: 関数内部でのみアクセスできます。

サンプル

//ここでは carName 変数にアクセスできません function myFunction() { var carName = "Volvo"; //関数内では carName 変数にアクセスできます }

試してみる »

ローカル変数は関数内でのみ有効なため、異なる関数は同じ名前の変数を使用できます。

ローカル変数は関数の実行開始時に作成され、関数の実行完了後に自動的に破棄されます。

JavaScript グローバル変数

関数の外で定義された変数はグローバル変数になります。

グローバル変数にはグローバルスコープ: ページ内のすべてのスクリプトと関数が使用できます。

サンプル

var carName = " Volvo"; //ここでは carName 変数にアクセスできます function myFunction() { //関数内では carName 変数にアクセスできます }

試してみる »

関数内で変数が宣言されていない場合（var キーワードを使用していない場合）、その変数はグローバル変数です。

次のサンプルでは carName は関数内にありますが、グローバル変数です。

サンプル

//ここでは carName 変数にアクセスできます function myFunction() { carName = "Volvo"; //ここでは carName 変数にアクセスできます }

試してみる »

JavaScript 変数のライフサイクル

JavaScript の変数のライフサイクルは、宣言されたときに初期化されます。

ローカル変数は関数の実行が完了すると破棄されます。

グローバル変数はページが閉じられると破棄されます。

関数パラメータ

関数パラメータは関数内でのみ有効で、ローカル変数です。

HTML 内のグローバル変数

HTML では、グローバル変数は window オブジェクトです。そのため、window オブジェクトは関数内で宣言されていない（var を付けていない）ローカル変数にアクセスできます。

注意：すべてのグローバル変数は window オブジェクトに属します。

サンプル

//ここでは window.carName を使用できます function myFunction() { carName = "Volvo"; }

ご存知ですか？

あなたのグローバル変数または関数は、window オブジェクトの変数や関数を上書きできます。
ローカル変数は、window オブジェクトを含めて、グローバル変数や関数を上書きできます。

JavaScript では、関数内部のローカル変数は通常、外部スコープから直接アクセスできませんが、関数内のローカル変数を外部スコープに公開する方法はいくつかあります。具体的には次のとおりです。

  • グローバルオブジェクトを介する：関数内部では、ローカル変数を window オブジェクトのプロパティに代入することで、グローバルにアクセス可能にできます。例えば、window.a = a;ステートメントを使用すると、関数外部ではwindow.aこのローカル変数の値にアクセスできます。
  • グローバル変数を定義する：関数内部でvar、let 或 constなどのキーワードを使用せずに変数を宣言すると、その変数はグローバル変数と見なされ、関数外部からアクセスできます。ただし、この方法は予期しない副作用を引き起こし、コードの保守が難しくなる可能性があるため、通常は推奨されません。
  • 戻り値：関数内部でreturnステートメントを使用してローカル変数の値を返し、関数外部でその戻り値を受け取ることができます。これにより、ローカル変数自体は公開されませんが、その値は関数呼び出しを介して外部に渡すことができます。
  • クロージャ：JavaScript のクロージャ機能により、内部関数は外部関数のローカル変数にアクセスできます。外部関数の実行が完了した後でも、そのローカル変数は内部関数から参照できます。
  • プロパティとメソッド：グローバルスコープで定義された変数と関数はすべて window オブジェクトのプロパティとメソッドになるため、呼び出し時に window を省略して、変数名や関数名を直接使用できます。

    ES6 の let キーワード

    let を使用すると、スコープがブロックレベルに制限された変数、ステートメント、または式を宣言できます。var キーワードとは異なり、var で宣言される変数はグローバルまたは関数ブロック全体のみです。

    let 構文：

    let var1 [= value1] [, var2 [= value2]] [, ..., varN [= valueN]];

    let で宣言された変数は、宣言されたブロックまたはサブブロック内でのみ使用できます。この点は var と似ています。両者の主な違いは、var で宣言された変数のスコープがそれを囲む関数全体であることです。

    let と var の違いのコード例：

    function varTest() {
  var x = 1;
  if (true) {
    var x = 2;  // 同样的变量!
    console.log(x);  // 2
  }
  console.log(x);  // 2
}

function letTest() {
  let x = 1;
  if (true) {
    let x = 2;  // 不同的变量
    console.log(x);  // 2
  }
  console.log(x);  // 1
}

    let と var の違い

    基本的な使い方

    ES6 では let 命令が新たに追加され、変数の宣言に使用されます。使用方法は var に似ていますが、宣言された変数は let 命令が置かれているコードブロック内でのみ有効です。

    {
  let a = 10;
  var b = 1;
}

a // ReferenceError: a is not defined.
b // 1

    上記のコードでは、コードブロック内で let と var をそれぞれ使用して2つの変数を宣言しています。その後、コードブロックの外でこれらの2つの変数を呼び出すと、let で宣言された変数はエラーになり、var で宣言された変数は正しい値を返します。これは、let で宣言された変数がそのコードブロック内でのみ有効であることを示しています。

    for ループのカウンタには、let 命令が非常に適しています。

    for (let i = 0; i < 10; i++) {
  // ...
}

console.log(i);
// ReferenceError: i is not defined

    上記のコードでは、カウンタ i は for ループ内でのみ有効で、ループの外で参照するとエラーになります。

    以下のコードで var を使用すると、最終的に出力されるのは 10 です。

    var a = [];
for (var i = 0; i < 10; i++) {
  a[i] = function () {
    console.log(i);
  };
}
a[6](); // 10

    上記のコードでは、変数 i は var 命令で宣言されているため、グローバル範囲で有効であり、グローバルには変数 i が1つだけ存在します。ループのたびに変数 i の値は変化しますが、ループ内で配列 a に代入された関数内の console.log(i) の i は、グローバルの i を指しています。つまり、配列 a のすべてのメンバー内の i は同じ i を指しているため、実行時に出力されるのは最後のループの i の値、すなわち 10 です。

    let を使用すると、宣言された変数はブロックスコープ内でのみ有効になり、最終的に出力されるのは 6 です。

    var a = [];
for (let i = 0; i < 10; i++) {
  a[i] = function () {
    console.log(i);
  };
}
a[6](); // 6

    上記のコードでは、変数 i は let で宣言されており、現在の i はそのループ内でのみ有効です。そのため、ループのたびに i は実際には新しい変数となり、最終的に出力されるのは 6 です。各ループの変数 i が再宣言されるのであれば、どうやって前のループの値を知り、現在のループの値を計算するのか疑問に思うかもしれません。これは、JavaScript エンジンが内部で前のループの値を記憶しており、現在のループの変数 i を初期化するときに、前のループの値に基づいて計算するためです。

    また、forループには特別な点があり、ループ変数を設定する部分は親スコープであり、ループ本体の内部は独立した子スコープです。

    for (let i = 0; i < 3; i++) {
  let i = 'abc';
  console.log(i);
}
// abc
// abc
// abc

    上記のコードは正しく実行され、abcが3回出力されました。これは、関数内部の変数iとループ変数iが同じスコープになく、それぞれ独立したスコープを持つことを示しています。

    スコープ

    スコープとは、プログラムのソースコード内で変数を定義する領域のことです。

    スコープは変数の検索方法を規定し、つまり現在実行中のコードが変数にアクセスする権限を決定します。

    JavaScriptは語彙的スコープ（lexical scoping）、つまり静的スコープを採用しています。

    違いを理解するために、例をしっかり見てみましょう。

    var value = 1;

function foo() {
    console.log(value);
}

function bar() {
    var value = 2;
    foo();
}

bar();

// 结果是 1

    JavaScriptが静的スコープを採用すると仮定して、実行プロセスを分析してみましょう。

    foo関数を実行するとき、まずfoo関数の内部にローカル変数valueがあるか探します。なければ、記述された位置に基づいて、その上の層のコードを探します。つまりvalueは1なので、結果として1が出力されます。

    JavaScriptが動的スコープを採用すると仮定して、実行プロセスを分析してみましょう。

    foo関数を実行するとき、やはりfoo関数の内部にローカル変数valueがあるか探します。なければ、呼び出し元の関数のスコープ、つまりbar関数の内部でvalue変数を探すため、結果として2が出力されます。

    前述のとおり、JavaScriptは静的スコープを採用しているため、この例の結果は1です。
