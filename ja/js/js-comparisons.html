    JavaScript 多項演算子

    function test(p){
    var a=5,b=12;
    return p>1?p<b?p>b:p=6:p=3; // 这一行中出现了多个问号和冒号，看起来很乱怎么办呢
}

document.write(test(9));

    例 »

    実はとても簡単で、多項演算子の先頭 ? と末尾 : を見つければずっと簡単になります

    すると次のようになります：

    p>1?p<b?p>b:p=6:p=3

p>1? 整体 :p=3

    1、p>1 のときは p<b?p>b:p=6 を返します

    • 1.1、p<b のときは p>b を返します
    • 1.2、p>=b のときは p=6 を返します

    2、p<=1 のときは p=3 を返すため、最初に 1 を実行します

    3、例で p=9 のとき、p<b?p>b:p=6 を返し、続いて 1.1 を実行します。p=9<12 のとき、p>b、つまり 9>12 を返しますが、条件が成立しないため、最終結果は false になります。

    三項演算

    8>5  ?    true   :    false   ;

    条件 ？ 値1 ： 値2 ;

    平たく言うと、「8は5より大きいか？」です。大きければ true、大きくなければ false です；

    ？の前の条件が成立するかどうかを判定し、成立すれば最初の値を実行し、成立しなければ2番目の値を実行します。

    まず、他のデータ型をブール型に変換する規則について説明します：null、undefined、0、NaN、空文字列は false に変換されfalse、その他は true に変換されますtrue。

    JavaScript には3つの論理演算子があります：

    1. 否定 !

    まずデータをブール値に変換してから否定します。結果は true または false になります。

    <script type="text/javascript">
var a = [1,2,3];
var b = "hello";
var obj = new Object();
var d;

console.log(!"");   //true
console.log(!d);    //true
console.log(!a);    //false
console.log(!b);    //false
console.log(!obj);  //false
</script>

    2. 論理積（AND）&&

    JavaScript の論理積（AND）は他の言語とは少し異なります。最初のオペランドが true（または true に変換できる）の場合、計算結果は2番目のオペランドになり、最初のオペランドが false の場合、結果は false になります（短絡評価）。一部の特殊な数値は上記の規則に従いません。（個人的な理解：演算の最初のオペランドが true の場合は2番目のオペランドを返し、そうでない場合は最初のオペランドを返します）

    <script type="text/javascript">
var a = [1,2,3];
var b = "hello";
var obj = new Object();
var d;

console.log(true && 10);            //第一个操作数是true，结果是第二个操作，也就是10
console.log(false && b);            //第一个操作数是false，结果flase
console.log(100 && false);          //第一个操作数是100，结果flase
console.log(undefined && false);    //第一个操作数是undefined，结果undefined
console.log(NaN && false);          //第一个操作数是NaN，结果NaN
console.log(null && false);         //第一个操作数是null，结果null
console.log('' && false);           //第一个操作数是空串，结果空串
console.log(0 && 100);              //结果是0
console.log(5 && 100);              //100
console.log(a && b);                //hello
console.log(obj && 200);            //200
</script>

    3. 論理和（OR）||

    最初のオペランドが false でない場合、結果は最初のオペランドになり、そうでない場合、結果は2番目のオペランドになります。最初のオペランドが true に変換できる場合、結果は最初のオペランドになります（個人的な理解：演算の最初のオペランドが true の場合は最初のオペランドを返し、そうでない場合は2番目のオペランドを返します）

    <script type="text/javascript">
var a = [1,2,3];
var b = "hello";
var obj = new Object();
var d;

console.log(true || 10);        //第一个操作数是true，结果是第一个操作，也就是true
console.log(false || b);        //第一个操作数是false，结果是第二个操作数b
console.log(100 || false);      //第一个操作数是100，结果100
console.log(undefined || 9);    //第一个操作数是undefined转false，结果9
console.log(NaN || false);      //第一个操作数是NaN转false，结果第二个操作数
console.log(null || a);         //第一个操作数是null转false，结果a
console.log('' || false);       //第一个操作数是空串转false，结果第二操作数
console.log(0 || 100);          //结果是100
console.log(5 || 100);          //5
console.log(a || b);            //a
console.log(obj || 200);        //obj
</script>

    同意します4階の意見ですが、私の理解を補足します。

    1、論理積（AND）&&

    返されるのは単なる true や false ではなく、具体的な値です；

    && と同様に、返されるのは単なる true や false ではなく、具体的な値です。

    これは先頭から順に、true に変換できる値に遭遇したらその値を返し、true がない場合は最後の値を返します。

    JavaScript には2種類の等価演算子があります：==和===それらの比較規則は次のとおりです：

    • ==是抽象等価演算子は、比較の前に2つのオペランドを同じ型に変換しようとしてから、それらの値が等しいかどうかを比較します。例えば、1 == "1"は true を返します。文字列"1"が数値の1に変換されてから比較されるためです。
    • ===是厳密等価演算子は型変換を行わず、2つのオペランドの型と値が完全に同じかどうかを直接比較します。例えば、1 === "1"は false を返します。数値の1と文字列"1"は型が異なるため、値が同じでも true は返されません。

    一般的には、使用を推奨します===比較に使用します。予期しない結果を避けることができるからです。例えば：

    • null == undefinedtrueを返しますが、null === undefinedfalseを返します。
    • 0 == falsetrueを返しますが、0 === falsefalseを返します。
    • NaN == NaNfalseを返しますが、NaN === NaNこれもfalseを返します。

    抽象等価演算子は2つのオペランドを同じ型に変換しようとする際、以下の規則に従います：

    • 両方のオペランドがプリミティブ型の場合、以下の順序で型変換が行われます：
      • 一方のオペランドがブール値の場合、それを数値に変換します。trueは1に、falseは0に変換されます。
      • 一方のオペランドが文字列で、もう一方のオペランドが数値の場合、文字列を数値に変換します。
      • 一方のオペランドがnullで、もう一方のオペランドがundefinedの場合、型変換は行われず、直接trueが返されます。
      • 一方のオペランドがnullまたはundefinedで、もう一方のオペランドがnullでもundefinedでもないプリミティブ値の場合、型変換は行われず、直接falseが返されます。
      • 両方のオペランドが文字列の場合、型変換は行われず、それらのリテラル値が等しいかどうかが直接比較されます。
      • 両方のオペランドが数値の場合、型変換は行われず、それらの数値が等しいかどうかが直接比較されます（NaNはどの値とも等しくないことに注意してください）。

    例えば："1" == truetrueを返します。trueが1に変換され、文字列"1"も1に変換されるため、2つの1は等しくなります。同様に、"0" == falseこれもtrueを返します。

    • 2つのオペランドのうち一方がオブジェクト型で、もう一方がプリミティブ型の場合、オブジェクト型のオペランドをプリミティブ型に変換してから比較します。オブジェクト型のオペランドは、valueOf()メソッドまたはtoString()メソッド（valueOf()メソッドが存在しないか、プリミティブ値を返さない場合）を呼び出して、プリミティブ値を取得します。例えば、[1,2,3] == "1,2,3"trueを返します。配列がtoString()メソッドを呼び出して文字列"1,2,3"を返すためです。
    • 両方のオペランドがオブジェクト型の場合、型変換は行われず、それらの参照が同じかどうかが直接比較されます。つまり、2つのオブジェクトが同じメモリアドレスを指している場合にのみtrueが返されます。例えば、[1,2,3] == [1,2,3]falseを返します。それらは2つの異なる配列オブジェクトであるためです。
