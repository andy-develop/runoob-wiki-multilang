論理ゲート回路の構築

ブール代数の基礎 -- AND / OR / NOT / XOR

ブール代数はすべてのデジタル回路の数学的基盤であり、4つの基本論理演算の組み合わせによって、どんな複雑な回路でも構築できます。

身近な例え：自動ドアと入退室管理システム

高度なセキュリティを備えた建物に入るとき、さまざまな入退室ルールに出会います。これらのルールは、まさにブール代数の基本演算に対応しています。日常生活の場面を使って理解していきましょう。

AND（論理積）ゲート——2つのドアが同時に開かないと入れない：ある金庫では、2本の鍵を同時に回さないと開きません。2本とも挿して回すと（入力がどちらも1）、ドアが開きます（出力が1）。どちらか一方の鍵が欠けても、ドアはびくともしません。

OR（論理和）ゲート——どれか1つのドアが開いていれば入れる：オフィスビルには入口が2つあり、正面ドアか裏ドアのどちらかが開いていれば、中に入れます。どちらかの入口が開いていれば（少なくとも1つの入力が1）、通過できます（出力が1）。

NOT（否定）ゲート——ボタンで表示を切り替える：トイレの入口に「空き/使用中」を切り替える表示板があり、ボタンを押すと現在の状態が反転します。入力が0（空き）なら出力は1（使用中）、逆も同様です。

XOR（排他的論理和）ゲート——部屋の2つのランプは、必ず一方がオンでもう一方がオフ：ある部屋には2つのランプが設置されており、2つのランプの状態は必ず逆（一方がオン、もう一方がオフ）でなければならず、そうでないと警報システムが作動します。したがって、2つの入力が異なれば出力は1、同じなら出力は0です。

ブール代数の簡史

ブール代数は、英国の数学者ジョージ・ブール（George Boole）によって1854年の著書『思考の法則に関する研究』の中で初めて体系的に提唱されました。ブールの目標は、人間の論理的推論を数学化することであり、「真」と「偽」を代数記号で表現する手法を生み出しました。

1938年、クロード・シャノン（Claude Shannon）はMITの修士論文で、ブール代数を用いてリレー回路の記述と簡略化ができることを証明しました。「史上最も重要な修士論文」と呼ばれるこの研究は、デジタル回路設計全体の理論的基盤を築きました。

ブール代数がなければデジタル回路はなく、デジタル回路がなければ現代のコンピューターもなかったと言えるでしょう。あなたがこの文章を読んでいる機器の中では、毎秒何億ものブール演算が行われています。

4つの基本論理演算の詳細

AND（論理積）演算

AND演算のルールは、一言で言えば次の通りです。すべての入力が1のときだけ、出力は1になる；それ以外の場合は出力は0です。これは直列スイッチと考えると分かりやすいでしょう。2つのスイッチが両方とも閉じているときだけ、電球が点灯します。

ABA AND B
000
010
100
111

論理式：Y = A · B（ドットを省略して Y = AB と書くこともあります）。覚え方：全部1なら1。

OR（論理和）演算

OR演算のルール：どれか1つの入力が1なら、出力は1；すべての入力が0のときだけ、出力は0になります。並列スイッチにたとえられます。どれか1つのスイッチが閉じれば、電球が点灯します。

ABA OR B
000
011
101
111

論理式：Y = A + B（これは算術的な足し算ではないことに注意してください。ブール代数では 1 + 1 も 1 になります）。覚え方：1があれば1。

NOT（否定）演算

NOTは、1つの入力だけを受け取る唯一の基本演算で、ルールは最も簡単です。出力は入力の逆になる。入力が1なら出力は0、入力が0なら出力は1です。

ANOT A
01
10

論理式：Y = A' 或 Y = NOT A。回路図では、入力線上に付けた小さな丸で否定を表すのが一般的です。覚え方：0は1に、1は0に。

XOR（排他的論理和）演算

XOR演算のルール：2つの入力が異なれば出力は1、同じなら出力は0。XORはAND、OR、NOTを組み合わせて実現できます：A XOR B = (A' · B) + (A · B')。

ABA XOR B
000
011
101
110

論理式：Y = A XOR B。XORは加算器の設計、パリティチェック、データ暗号化などの分野で広く使われています。覚え方：異なれば1。

論理ゲートの記号

デジタル回路図では、各基本論理演算に対応する標準的な論理ゲート記号があります。

ANDゲート：記号はD形——直線の辺と半円の弧。2本の入力線が左側、1本の出力線が右側にあります。

ORゲート：記号は盾形——内側にカーブした弧線で、後端が尖った点に集まります。「または」の論理を表します。

NOTゲート（インバータ）：三角形の後ろに小さな丸が付いています。三角形はバッファ/ドライバを表し、丸は信号の否定を表します。

XORゲート：ORゲートと形が似ていますが、入力側の弧線の前にもう1本弧線が追加されており、「排他的論理和」を区別しています。

いかなる複雑なデジタル回路も——CPU内部の演算器や制御器を含めて——最終的にはこの4つの基本論理ゲートの組み合わせに分解できます。これが、ブール代数がデジタル回路の理論的基盤である根本的な理由です。

Pythonコードによるデモ

以下でPythonを使用して4つの基本論理演算の関数を実装し、完全な真理値表を自動生成するとともに、ド・モルガンの法則を検証します。

例

# runoob テスト：ブール代数 Python完全実装

def AND(a, b):
    """AND演算：全部1なら1"""
    return 1 if a == 1 and b == 1 else 0

def OR(a, b):
    """OR演算：1があれば1"""
    return 1 if a == 1 or b == 1 else 0

def NOT(a):
    """NOT演算：否定"""
    return 1 if a == 0 else 0

def XOR(a, b):
    """XOR演算：異なれば1"""
    return 1 if a != b else 0

def print_truth_table(title, func, inputs):
    """汎用の真理値表出力関数"""
    print(f"\n{'='*40}")
    print(f"  {title}")
    print(f"{'='*40}")

    if func.__code__.co_argcount == 1:
        print(f" {'A':>4} | {'出力':>4}")
        print(f"  {'-'*13}")
        for a in inputs:
            print(f"  {a:>4} | {func(a):>4}")
    else:
        print(f" {'A':>4} | {'B':>4} | {'出力':>4}")
        print(f"  {'-'*20}")
        for a in inputs:
            for b in inputs:
                print(f"  {a:>4} | {b:>4} | {func(a, b):>4}")

# メインプログラム：すべての真理値表を出力
inputs = [0, 1]
print("runoob ブール代数 真理値表 完全デモ")
print_truth_table("AND（論理積）演算", AND, inputs)
print_truth_table("OR（論理和）演算", OR, inputs)
print_truth_table("NOT（否定）演算", NOT, inputs)
print_truth_table("XOR（排他的論理和）演算", XOR, inputs)

# ド・モルガンの法則の検証
print(f"\n{'='*40}")
print(ド・モルガンの法則の検証)
print(f"{'='*40}")
print(法則 1: NOT(A AND B) = NOT A OR NOT B)
print(法則 2: NOT(A OR B) = NOT A AND NOT B)
for a in inputs:
    for b in inputs:
        left1 = NOT(AND(a, b))
        right1 = OR(NOT(a), NOT(b))
        left2 = NOT(OR(a, b))
        right2 = AND(NOT(a), NOT(b))
        print(f"  A={a}, B={b}:")
        print(f法則1: {left1} = {right1} -> {'OK' if left1 == right1 else 'FAIL'})
        print(f法則2: {left2} = {right2} -> {'OK' if left2 == right2 else 'FAIL'})
