Android 概要

Android とは？

Android は、スマートフォンやタブレットなどのモバイルデバイス向けの、Linux ベースのオープンソースオペレーティングシステムです。Android は、Google や他の企業が主導する Open Handset Alliance によって開発されました。

Android は統一されたアプリケーション開発アプローチを提供します。つまり、開発者は Android 向けに開発するだけでよく、そのアプリケーションは Android を搭載したさまざまなモバイルデバイスで実行できます。

Google は2007年に Android ソフトウェア開発キット（SDK）の最初のテスト版をリリースし、最初の商用版 Android 1.0 は2008年9月にリリースされました。

2012年6月27日、Google I/O カンファレンスで、Google は Android バージョン 4.1 Jelly Bean のリリースを発表しました。Jelly Bean は機能とパフォーマンスにおける段階的なアップデートであり、主な目的はユーザーインターフェースを改善することです。

Android のソースコードは、フリーかつオープンソースソフトウェアライセンスに基づいています。Google が公開するコードの大部分は Apache ライセンス バージョン 2.0 に従い、Linux カーネルの変更は GNU General Public License バージョン 2 に従います。

Android 開発の利点

  • オープンソース
  • 多数の開発者と強力なコミュニティ
  • 成長し続ける市場
  • 国際化されたアプリの統合
  • 低い開発コスト
  • より高い成功率
  • 豊富な開発環境

Android の特徴

Android は Apple 4GS と競合する強力なオペレーティングシステムであり、いくつかの優れた機能をサポートしています。以下にその一部を挙げます。

特徴 説明
美しい UI Android オペレーティングシステムの基本画面は、美しく直感的なユーザーインターフェースを提供します。
接続性 GSM/EDGE、IDEN、CDMA、EV-DO、UMTS、Bluetooth、Wi-Fi、LTE、NFC、WiMAX。
ストレージ データ保存用の軽量リレーショナルデータベース SQLite
メディアサポート H.263、H.264、MPEG-4 SP、AMR、AMR-WB、AAC、HE-AAC、AAC 5.1、MP3、MIDI、Ogg Vorbis、WAV、JPEG、PNG、GIF、BMP
メッセージ SMS と MMS
Web ブラウザ オープンソースの WebKit レイアウトエンジンと、HTML5 および CSS3 をサポートする Chrome の V8 JavaScript エンジンに基づいています。
マルチタッチ Android はマルチタッチをネイティブサポートしており、HTC Hero のような最初期の携帯端末から搭載されています。
マルチタスク ユーザーはあるタスクから別のタスクへ切り替えることができ、同時にさまざまなアプリを実行できます。
サイズ変更可能なウィジェット ウィジェットはサイズを変更できるため、ユーザーはコンテンツを拡大したり、スペースを節約するために縮小したりできます。
多言語 単方向および多方向のテキストをサポートします。
GCM Google Cloud Messaging（GCM）は、開発者が独自の同期ソリューションを必要とせずに、Android デバイスのユーザーにショートメッセージデータを送信できるようにするサービスです。
Wi-Fi Direct 高帯域幅のピアツーピアネットワーク接続を介して、アプリを直接検出およびペアリングするためのテクノロジーです。
Android Beam NFC ベースの人気のあるテクノロジーで、NFC 対応の2台の電話をタッチするだけで、ユーザーが即座に共有できるようにします。

Android アプリケーション

Android アプリケーションは通常、Android ソフトウェア開発キットを使用し、Java 言語で開発されます。

開発が完了すると、Android アプリケーションは簡単にパッケージ化され、Google Play や Amazon Appstore などで販売できます。

Android は、世界中の190以上の国々で数百万台のモバイルデバイスに搭載されています。これは、あらゆるモバイルプラットフォームの中で最大のインストールベースであり、急速に成長しています。世界中で毎日100万台以上の新しい Android デバイスがアクティベートされています。

本チュートリアルの目的は、Android アプリケーションを開発およびパッケージ化する方法を教えることです。Android アプリケーションのプログラミング環境の設定から始め、その後 Android アプリケーション開発のさまざまな側面を詳しく説明します。
