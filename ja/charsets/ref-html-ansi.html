ANSI（Windows-1252）

ANSI は、Windows 95 およびそれ以前の Windows システムにおけるデフォルトの文字セットです。

ANSI は Windows-1252 とも呼ばれます。

重要なヒント

ANSI と ISO-8859-1 は非常に似ていますが、唯一の違いは 32 文字にあります。

ANSI では、128 から 159 までの文字は、ユーロ記号などのいくつかの有用な文字に使用されます。

ISO-8859-1 では、これらの文字は HTML では機能しない制御文字にマッピングされます。

多くの Web 開発者は ISO-8859-1 を宣言し、まるで Windows-1252 を使用しているかのようにこれらの 32 個の値を使用します。

この一般的な誤解のため、ISO-8859-1 が宣言されると、ブラウザは Windows-1252 に変更されます。これは以下のドキュメントタイプに適用されます：HTML4、HTML5、XHTML。

ANSI と ASCII

ANSI の最初の部分（エンティティ番号 0-127）は、元の ASCII 文字セットです。数字、英大文字・小文字、およびいくつかの特殊文字が含まれています。

ANSI 制御文字

ANSI制御文字（00〜31、および127）は、当初はプリンターやテープドライブなどのハードウェア機器を制御するために設計されました。

制御文字は（水平タブ、改行、復帰を除いて）HTML文書では何の役割も果たしません。
