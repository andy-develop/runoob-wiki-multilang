C++ OpenCV 高度な画像処理

高度な画像処理とは、基礎的な画像処理（フィルタリング、エッジ検出など）の上に、画像分割、輪郭検出、モルフォロジー演算、ヒストグラム処理などのより複雑なタスクをさらに実現することを指します。これらの技術は、物体検出、画像解析、医用画像処理などの分野で広く応用されています。

高度な画像処理の応用シーン

医用画像解析：

  • 画像分割技術を使用して病変領域を抽出します。

  • モルフォロジー演算を使用してノイズを除去します。

物体検出と追跡：

  • 輪郭検出とテンプレートマッチングを使用して物体を特定します。

  • ヒストグラム処理を使用して物体の特徴を強調します。

画像強調：

  • ヒストグラム均等化を使用して画像のコントラストを向上させます。

  • 分水嶺アルゴリズムを使用して重なり合うオブジェクトを分離します。

画像分割

画像分割は画像処理における重要なステップの1つであり、画像を複数の領域またはオブジェクトに分割して、さらなる解析と処理を容易にします。一般的な画像分割方法には、閾値に基づく分割、エッジに基づく分割、領域に基づく分割があります。

閾値に基づく分割

閾値に基づく分割は、最も簡単な画像分割方法の1つです。1つまたは複数の閾値を設定することで、画像のピクセル値を異なるカテゴリに分類します。一般的な閾値分割方法には、大域的閾値と適応的閾値があります。

大域的閾値分割

大域的閾値分割は、固定された閾値を使用して画像を前景と背景に分割します。OpenCVはcv::threshold関数を提供してこの機能を実現します。

cv::Mat src = cv::imread("image.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat dst;
cv::threshold(src, dst, 128, 255, cv::THRESH_BINARY);

上記のコードにおいて、128は閾値であり、255は最大ピクセル値であり、cv::THRESH_BINARY二値化方式を使用することを示します。

適応的閾値分割

適応的閾値分割は、画像の局所領域に基づいて閾値を動的に調整します。OpenCVはcv::adaptiveThreshold関数を提供してこの機能を実現します。

cv::Mat src = cv::imread("image.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat dst;
cv::adaptiveThreshold(src, dst, 255, cv::ADAPTIVE_THRESH_MEAN_C, cv::THRESH_BINARY, 11, 2);

上記のコードにおいて、255は最大ピクセル値であり、cv::ADAPTIVE_THRESH_MEAN_C局所平均を閾値として使用することを示し、11は近傍サイズであり、2は定数です。

エッジに基づく分割

エッジに基づく分割は、画像内のエッジを検出して画像を分割します。一般的なエッジ検出アルゴリズムには、Cannyエッジ検出とSobelオペレーターがあります。

Cannyエッジ検出

Cannyエッジ検出は、多段階のエッジ検出アルゴリズムです。OpenCVはcv::Canny関数を提供してこの機能を実現します。

cv::Mat src = cv::imread("image.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat edges;
cv::Canny(src, edges, 100, 200);

上記のコードにおいて、100 和 200はCannyアルゴリズムの2つの閾値です。

領域に基づく分割（分水嶺アルゴリズム）

領域に基づく分割は、画像を複数の領域に分割することで分割を実現します。分水嶺アルゴリズムは、一般的に使用される領域ベースの分割方法です。

分水嶺アルゴリズム

分水嶺アルゴリズムは、画像を地形図と見なし、水流の拡散をシミュレーションして画像を分割します。OpenCVはcv::watershed関数を提供してこの機能を実現します。

cv::Mat src = cv::imread("image.jpg");
cv::Mat markers = cv::Mat::zeros(src.size(), CV_32S);
cv::watershed(src, markers);

上記のコードにおいて、markersはマーカー行列であり、分割結果を格納するために使用されます。

輪郭検出

輪郭検出は画像処理における重要なステップであり、画像内のオブジェクトの境界を検出するために使用されます。OpenCVは、輪郭の検出と処理のためのさまざまな関数を提供しています。

輪郭の検索

輪郭の検索は輪郭検出の最初のステップです。OpenCVはcv::findContours関数を提供してこの機能を実現します。

cv::Mat src = cv::imread("image.jpg", cv::IMREAD_GRAYSCALE);
std::vector<std::vector<cv::Point>> contours;
std::vector<cv::Vec4i> hierarchy;
cv::findContours(src, contours, hierarchy, cv::RETR_TREE, cv::CHAIN_APPROX_SIMPLE);

上記のコードにおいて、contoursは輪郭を格納するベクトルであり、hierarchyは輪郭の階層構造を格納するベクトルです。

輪郭の特徴

輪郭の特徴には、面積、周囲長、境界ボックスなどが含まれます。OpenCVは、これらの特徴を計算するためのさまざまな関数を提供しています。

面積

面積は輪郭の重要な特徴です。OpenCVはcv::contourArea関数を提供して輪郭の面積を計算します。

double area = cv::contourArea(contours[0]);

周囲長

周囲長は輪郭のもう1つの重要な特徴です。OpenCVはcv::arcLength関数を提供して輪郭の周囲長を計算します。

double perimeter = cv::arcLength(contours[0], true);

境界ボックス

境界ボックスは輪郭の最小外接矩形です。OpenCVはcv::boundingRect関数を提供して境界ボックスを計算します。

cv::Rect rect = cv::boundingRect(contours[0]);

輪郭の描画

輪郭の描画は、検出された輪郭を画像上に描画することです。OpenCVはcv::drawContours関数を提供してこの機能を実現します。

cv::Mat dst = cv::Mat::zeros(src.size(), CV_8UC3);
cv::drawContours(dst, contours, -1, cv::Scalar(0, 255, 0), 2);

上記のコードにおいて、dstは輪郭描画後の画像であり、cv::Scalar(0, 255, 0)は輪郭の色であり、2は輪郭の線幅です。

テンプレートマッチング

テンプレートマッチングは、画像内で特定のテンプレートを探す方法です。OpenCVはcv::matchTemplate関数を提供してこの機能を実現します。

単一テンプレートマッチング

単一テンプレートマッチングは、画像内で1つのテンプレートを探すことです。OpenCVはcv::matchTemplate関数を提供してこの機能を実現します。

cv::Mat src = cv::imread("image.jpg");
cv::Mat templ = cv::imread("template.jpg");
cv::Mat result;
cv::matchTemplate(src, templ, result, cv::TM_CCOEFF_NORMED);

上記のコードにおいて、resultはマッチング結果行列であり、cv::TM_CCOEFF_NORMEDはマッチング方法です。

複数テンプレートマッチング

複数テンプレートマッチングは、画像内で複数のテンプレートを探すことです。マッチング結果行列を走査することで、複数テンプレートマッチングを実現できます。

double minVal, maxVal;
cv::Point minLoc, maxLoc;
cv::minMaxLoc(result, &minVal, &maxVal, &minLoc, &maxLoc);

上記のコードにおいて、maxLocはマッチング結果の最大値の位置です。

分水嶺アルゴリズム

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 画像を読み込む
    Mat image = imread("objects.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat gray;
    cvtColor(image, gray, COLOR_BGR2GRAY);

    // 二値化
    Mat binary;
    threshold(gray, binary, 0, 255, THRESH_BINARY_INV + THRESH_OTSU);

    // ノイズ除去
    Mat kernel = getStructuringElement(MORPH_RECT, Size(3, 3));
    morphologyEx(binary, binary, MORPH_OPEN, kernel, Point(-1, -1), 2);

    // 距離変換を計算
    Mat dist;
    distanceTransform(binary, dist, DIST_L2, 5);

    // 距離変換画像を正規化
    normalize(dist, dist, 0, 1.0, NORM_MINMAX);

    // 距離変換画像を二値化
    threshold(dist, dist, 0.5, 1.0, THRESH_BINARY);

    // 輪郭を検索
    Mat dist_8u;
    dist.convertTo(dist_8u, CV_8U);
    vector<vector<Point>> contours;
    findContours(dist_8u, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);

    // マーカー画像を作成
    Mat markers = Mat::zeros(dist.size(), CV_32S);
    for (size_t i = 0; i < contours.size(); i++) {
        drawContours(markers, contours, static_cast<int>(i), Scalar(static_cast<int>(i) + 1), -1);
    }

    // 分水嶺アルゴリズムを適用
    watershed(image, markers);

    // 結果を表示
    Mat result = image.clone();
    for (int i = 0; i < markers.rows; i++) {
        for (int j = 0; j < markers.cols; j++) {
            if (markers.at<int>(i, j) == -1) {
                result.at<Vec3b>(i, j) = Vec3b(0, 255, 0); // 境界を緑色でマーク
            }
        }
    }

    imshow("Watershed Result", result);
    waitKey(0);

    return 0;
}

輪郭検出

輪郭検出は、画像内のオブジェクトの境界を抽出するために使用されます。

OpenCVは、輪郭を検出するための findContours 関数を提供しています。

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 画像を読み込む
    Mat image = imread("objects.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat gray;
    cvtColor(image, gray, COLOR_BGR2GRAY);

    // 二値化
    Mat binary;
    threshold(gray, binary, 0, 255, THRESH_BINARY_INV + THRESH_OTSU);

    // 輪郭を検索
    vector<vector<Point>> contours;
    vector<Vec4i> hierarchy;
    findContours(binary, contours, hierarchy, RETR_TREE, CHAIN_APPROX_SIMPLE);

    // 輪郭を描画
    Mat result = Mat::zeros(image.size(), CV_8UC3);
    for (size_t i = 0; i < contours.size(); i++) {
        drawContours(result, contours, i, Scalar(0, 255, 0), 2);
    }

    // 結果を表示
    imshow("Contours", result);
    waitKey(0);

    return 0;
}

モルフォロジー演算

モルフォロジー演算は、形状に基づく画像処理技術であり、ノイズ除去やオブジェクトの分離などによく使用されます。

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 画像を読み込む
    Mat image = imread("noisy_image.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat gray;
    cvtColor(image, gray, COLOR_BGR2GRAY);

    // 二値化
    Mat binary;
    threshold(gray, binary, 0, 255, THRESH_BINARY_INV + THRESH_OTSU);

    // カーネルを定義
    Mat kernel = getStructuringElement(MORPH_RECT, Size(5, 5));

    // オープニング演算（ノイズ除去）
    Mat opened;
    morphologyEx(binary, opened, MORPH_OPEN, kernel);

    // クロージング演算（穴の埋め込み）
    Mat closed;
    morphologyEx(opened, closed, MORPH_CLOSE, kernel);

    // 結果を表示
    imshow("Original Binary", binary);
    imshow("Opened Image", opened);
    imshow("Closed Image", closed);
    waitKey(0);

    return 0;
}

ヒストグラム処理

ヒストグラム処理は、画像のピクセル分布を解析するために使用されます。一般的な操作には、ヒストグラム均等化、ヒストグラムマッチングなどがあります。

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 画像を読み込む
    Mat image = imread("low_contrast.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat gray;
    cvtColor(image, gray, COLOR_BGR2GRAY);

    // ヒストグラム均等化
    Mat equalized;
    equalizeHist(gray, equalized);

    // 結果を表示
    imshow("Original Image", gray);
    imshow("Equalized Image", equalized);
    waitKey(0);

    return 0;
}

テンプレートマッチング

テンプレートマッチングは、画像内でテンプレートに類似した領域を探すために使用されます。

例


#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 画像とテンプレートを読み込む
    Mat image = imread("scene.jpg");
    Mat templ = imread("template.jpg");
    if (image.empty() || templ.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // テンプレートマッチング
    Mat result;
    matchTemplate(image, templ, result, TM_CCOEFF_NORMED);

    // 最適なマッチング位置を検出
    double minVal, maxVal;
    Point minLoc, maxLoc;
    minMaxLoc(result, &minVal, &maxVal, &minLoc, &maxLoc);

    // 矩形を描画
    rectangle(image, maxLoc, Point(maxLoc.x + templ.cols, maxLoc.y + templ.rows), Scalar(0, 255, 0), 2);

    // 結果を表示
    imshow("Template Matching", image);
    waitKey(0);

    return 0;
}
