OpenCV 画像ヒストグラム

画像処理において、ヒストグラムは非常に重要なツールであり、画像のピクセル分布状況を把握するのに役立ちます。

画像のヒストグラムを分析することで、画像強調、コントラスト調整、画像分割などの操作を行うことができます。

画像ヒストグラムとは？

画像ヒストグラムは、画像のピクセル強度分布をグラフィカルに表現したものです。グレースケール画像の場合、ヒストグラムは各グレースケールレベル（0〜255）が画像内に現れる頻度を示します。カラー画像の場合、各チャンネル（R、G、Bなど）のヒストグラムを個別に計算できます。

ヒストグラムは、画像の明るさやコントラストなどの情報を把握するのに役立ちます。例えば、ヒストグラムが低グレースケール領域に集中している場合、画像が暗いことを示します。ヒストグラムの分布が均一な場合、画像のコントラストが良好であることを示します。

  • ヒストグラム：画像内のピクセル強度の分布状況を示し、横軸はピクセル強度値を表し、縦軸はその強度値のピクセル数を表します。

  • グレースケールヒストグラム：グレースケール画像に対するヒストグラムであり、各グレースケールレベルのピクセル数を表します。

  • カラーヒストグラム：カラー画像に対するヒストグラムであり、各色チャンネル（BGRなど）のピクセル強度分布を個別に表します。

OpenCV は豊富なヒストグラム計算・操作関数を提供しています：

機能関数説明
ヒストグラム計算cv2.calcHist()画像のヒストグラムを計算します。
ヒストグラム均等化cv2.equalizeHist()画像のコントラストを強調します。
ヒストグラム比較cv2.compareHist()2つのヒストグラムの類似度を比較します。
ヒストグラム描画matplotlib.pyplot.plot()Matplotlib を使用してヒストグラムを描画します。

OpenCV におけるヒストグラム計算関数

OpenCV では、次の関数を使用できます：cv2.calcHist()関数を使用して、画像のヒストグラムを計算できます。

cv2.calcHist()関数の構文

cv2.calcHist(images, channels, mask, histSize, ranges[, hist[, accumulate]])

パラメータの説明

  • images：入力画像のリスト。通常は単一チャンネルまたは複数チャンネルの画像を含むリストです。例：[img]。
  • channels：ヒストグラムを計算するチャンネルのインデックス。グレースケール画像の場合は、[0]；カラー画像の場合は、次を使用できます[0]、[1]、[2]それぞれ青、緑、赤のチャンネルのヒストグラムを計算します。
  • mask：マスク画像。マスクを指定した場合、マスク領域内のピクセルのみを計算します。マスクが不要な場合は、None を渡すことができます。None。
  • histSize：ヒストグラムのビン数。グレースケール画像の場合、通常は 256 に設定します。[256]、グレースケールレベルを256個のビンに分割することを意味します。
  • ranges：ピクセル値の範囲。グレースケール画像の場合、通常は [0, 255] に設定します。[0, 256]、ピクセル値の範囲が0〜255であることを意味します。
  • hist：出力されるヒストグラム配列。
  • accumulate：ヒストグラムを累積するかどうか。True に設定すると、Trueヒストグラムはクリアされず、呼び出しのたびに累積されます。

グレースケール画像があると仮定します。img、次のコードを使用して、そのヒストグラムを計算できます：

例

import cv2
import numpy as np
import matplotlib.pyplot as plt

# 画像を読み込む
img = cv2.imread('image.jpg', cv2.IMREAD_GRAYSCALE)

# ヒストグラムを計算
hist = cv2.calcHist([img], [0], None, [256], [0, 256])

# ヒストグラムを描画
plt.plot(hist)
plt.title('Grayscale Histogram')
plt.xlabel('Pixel Value')
plt.ylabel('Frequency')
plt.show()

ヒストグラム均等化

ヒストグラム均等化は、画像のコントラストを強調する方法の1つで、ピクセル強度値を再配分することで、ヒストグラムをより均一にします。

構文：

equalized_image = cv2.equalizeHist(image)

例

# ヒストグラム均等化
equalized_image = cv2.equalizeHist(image)

# 結果を表示
cv2.imshow("Equalized Image", equalized_image)
cv2.waitKey(0)
cv2.destroyAllWindows()

カラーヒストグラム

カラーヒストグラムの計算

カラー画像の場合、各色チャンネルのヒストグラムを個別に計算できます。

例

# カラー画像を読み込む
image = cv2.imread("path/to/image")

# BGR各チャンネルのヒストグラムを計算
colors = ('b', 'g', 'r')
for i, color in enumerate(colors):
    hist = cv2.calcHist([image], [i], None, [256], [0, 256])
    plt.plot(hist, color=color)

# ヒストグラムを描画
plt.title("Color Histogram")
plt.xlabel("Pixel Intensity")
plt.ylabel("Pixel Count")
plt.show()

カラーヒストグラムの均等化

カラー画像の場合、各チャンネルに対して個別にヒストグラム均等化を行うことができます。

例

# チャンネルを分離
b, g, r = cv2.split(image)

# 各チャンネルに対してヒストグラム均等化を実行
b_eq = cv2.equalizeHist(b)
g_eq = cv2.equalizeHist(g)
r_eq = cv2.equalizeHist(r)

# チャンネルを結合
equalized_image = cv2.merge([b_eq, g_eq, r_eq])

# 結果を表示
cv2.imshow("Equalized Color Image", equalized_image)
cv2.waitKey(0)
cv2.destroyAllWindows()

ヒストグラム比較

OpenCV は cv2.compareHist() 関数を提供しており、2つのヒストグラムの類似度を比較するために使用します。

構文：

similarity = cv2.compareHist(hist1, hist2, method)

  • hist1：1つ目のヒストグラム。

  • hist2：2つ目のヒストグラム。

  • method：比較方法。例：cv2.HISTCMP_CORREL（相関比較）。

例

# 2つの画像のヒストグラムを計算
hist1 = cv2.calcHist([image1], [0], None, [256], [0, 256])
hist2 = cv2.calcHist([image2], [0], None, [256], [0, 256])

# ヒストグラムを比較
similarity = cv2.compareHist(hist1, hist2, cv2.HISTCMP_CORREL)
print("Histogram Similarity:", similarity)

ヒストグラムの応用

  • 画像強調：ヒストグラム均等化により、画像のコントラストを強調し、ディテールをより鮮明にすることができます。
  • 画像分割：ヒストグラムを分析することで閾値を決定し、画像分割に使用できます。
  • 画像マッチング：ヒストグラムを比較することで、2つの画像の類似度を判断でき、画像マッチングや検索に使用できます。
  • 色分析：カラーヒストグラムにより、画像の色分布を分析でき、色補正やスタイライゼーション処理に使用できます。

以下は、ヒストグラム計算と均等化の完全なサンプルコードです：

例

import cv2
import numpy as np
import matplotlib.pyplot as plt

# グレースケール画像を読み込む
image = cv2.imread("path/to/image", cv2.IMREAD_GRAYSCALE)

# グレースケールヒストグラムを計算
hist = cv2.calcHist([image], [0], None, [256], [0, 256])

# ヒストグラムを描画
plt.plot(hist)
plt.title("Grayscale Histogram")
plt.xlabel("Pixel Intensity")
plt.ylabel("Pixel Count")
plt.show()

# ヒストグラム均等化
equalized_image = cv2.equalizeHist(image)

# 結果を表示
cv2.imshow("Equalized Image", equalized_image)
cv2.waitKey(0)
cv2.destroyAllWindows()
