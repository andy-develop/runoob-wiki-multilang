OpenCV ビデオ背景差分 (MOG, MOG2)

コンピュータビジョンの分野では、背景差分（Background Subtraction）は、ビデオシーケンスから前景オブジェクトを抽出するために使用される一般的な技術です。

背景差分の核となる考え方は、背景をモデル化し、現在のフレームを背景モデルと比較して、前景オブジェクトを分離することです。

OpenCVは複数の背景差分アルゴリズムを提供しており、その中でMOG（Mixture of Gaussians）とMOG2が最も一般的に使用される2つの方法です。

背景差分の基本概念

背景差分はビデオ分析に使用される技術であり、主にビデオ内の動くオブジェクトを検出するために使用されます。その基本的な流れは次のとおりです：

  1. 背景モデリング：ビデオシーケンス内の複数フレームの画像を分析して、背景モデルを構築します。
  2. 前景検出：現在のフレームを背景モデルと比較し、背景との差異が大きい領域を見つけます。これらの領域が前景オブジェクトです。
  3. 背景更新：時間の経過とともに、背景は変化する可能性があります（照明の変化、背景オブジェクトの移動など）。そのため、背景モデルを継続的に更新する必要があります。

MOG（Mixture of Gaussians）アルゴリズム

原理

MOGアルゴリズムは、ガウス混合モデル（Gaussian Mixture Model, GMM）に基づく背景差分手法です。その核となる考え方は、複数のガウス分布を使用して背景の画素値をモデル化することです。各画素の値はランダム変数と見なされ、その分布は複数のガウス分布で構成されます。この方法により、MOGは照明の変化や影などの背景の複雑な変化を処理できます。

アルゴリズムの手順

  1. 初期化：各画素に対して複数のガウス分布を初期化します。
  2. モデル更新：各フレーム画像について、各画素のガウス分布のパラメータ（平均、分散、重み）を更新します。
  3. 前景検出：現在のフレームの画素値を背景モデル内のガウス分布と比較し、画素値がどのガウス分布の範囲にも含まれない場合、その画素を前景としてマークします。

OpenCVでの実装

OpenCVでは、MOGアルゴリズムはcv2.bgsegm.createBackgroundSubtractorMOG()関数を使用して背景差分器を作成できます。以下は簡単なサンプルコードです：

例

import cv2

# MOG背景差分器を作成
mog = cv2.bgsegm.createBackgroundSubtractorMOG()

# ビデオを読み込む
cap = cv2.VideoCapture('video.mp4')

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # 背景差分を適用
    fg_mask = mog.apply(frame)

    # 結果を表示
    cv2.imshow('Frame', frame)
    cv2.imshow('FG Mask', fg_mask)

    if cv2.waitKey(30) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

MOG2（Mixture of Gaussians Version 2）アルゴリズム

原理

MOG2はMOGの改良版であり、主な違いはガウス分布の数を自動的に選択でき、背景の変化により適応できることです。MOG2はガウス分布の数とパラメータを動的に調整することで、背景をより正確にモデル化でき、前景検出の精度を向上させます。

アルゴリズムの手順

  1. 初期化：各画素に対して複数のガウス分布を初期化します。
  2. モデル更新：各フレーム画像について、各画素のガウス分布のパラメータを更新し、必要に応じてガウス分布の数を増減します。
  3. 前景検出：現在のフレームの画素値を背景モデル内のガウス分布と比較し、画素値がどのガウス分布の範囲にも含まれない場合、その画素を前景としてマークします。

OpenCVでの実装

OpenCVでは、MOG2アルゴリズムはcv2.createBackgroundSubtractorMOG2()関数を使用して背景差分器を作成できます。以下は簡単なサンプルコードです：

例

import cv2

# MOG2背景差分器を作成
mog2 = cv2.createBackgroundSubtractorMOG2()

# ビデオを読み込む
cap = cv2.VideoCapture('video.mp4')

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # 背景差分を適用
    fg_mask = mog2.apply(frame)

    # 結果を表示
    cv2.imshow('Frame', frame)
    cv2.imshow('FG Mask', fg_mask)

    if cv2.waitKey(30) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

背景差分の応用

  • ビデオ監視：監視ビデオ内の移動物体（歩行者、車両など）を検出するために使用されます。

  • 動作分析：ビデオ内の物体の移動軌跡と行動を分析するために使用されます。

  • ヒューマンコンピュータインタラクション：ユーザーのジェスチャーや顔を検出して、ヒューマンコンピュータインタラクションを実現します。

以下は、完全なMOG2背景差分のサンプルコードです：

例

import cv2

# ビデオを読み込む
cap = cv2.VideoCapture("path/to/video.mp4")

# MOG2背景差分器を作成
fgbg = cv2.createBackgroundSubtractorMOG2()

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # 背景差分器を適用
    fgmask = fgbg.apply(frame)

    # 結果を表示
    cv2.imshow("MOG2 Background Subtraction", fgmask)

    # 'q'キーを押して終了
    if cv2.waitKey(30) & 0xFF == ord('q'):
        break

# リソースを解放
cap.release()
cv2.destroyAllWindows()

MOGとMOG2の比較

背景差分はビデオ分析における重要な技術であり、MOGとMOG2はOpenCVでよく使用される2つの背景差分アルゴリズムです。

MOGアルゴリズムは固定数のガウス分布を使用して背景をモデル化し、背景の変化が少ないシーンに適しています。一方、MOG2アルゴリズムはガウス分布の数とパラメータを動的に調整することで、背景の変化により適応でき、背景の変化が多いシーンに適しています。

特性 MOG MOG2
ガウス分布の数 固定 動的調整
背景更新速度 遅い 速い
背景変化への適応能力 弱い 強い
計算複雑度 低い 高い
適用シーン 背景の変化が少ないシーン 背景の変化が多いシーン
