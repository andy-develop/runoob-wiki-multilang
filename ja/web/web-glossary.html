Web 用語集

以下の用語はアルファベット順に並んでいます

Access (Microsoft Access)

マイクロソフトが開発したデータベースシステム。Microsoft Office Professional 版の一部。主にWindowsプラットフォーム上で低トラフィックのWebサイトを実行するために使用される。

ActiveMovie

マイクロソフトが発表したマルチメディアプログラミング用のコントロール

ActiveX

WebブラウザがWindowsプログラム用プログラミングインターフェース（API）をダウンロードして実行することを可能にする。（プラグインも参照）

Address

URLを参照してください。

AdSense

Googleが提供するネットワーク広告システム。

AJAX (Asynchronous JavaScript and XML)

JavaScriptとXMLを使用してインタラクティブなWebアプリケーションを作成する「技法」。Ajaxを使用すると、WebアプリケーションはバックグラウンドでWebサーバーと（非同期に）データを交換し、ページを再読み込みせずにWebページの一部を更新できる。

AJAXの詳細は、私たちのAJAXチュートリアルをご覧ください

Anchor

ネットワーク関連: ハイパーリンクの開始点または終了点。

リンクの詳細は、私たちのHTMLチュートリアルをご覧ください

Adobe Air

Adobe Integrated Runtime（AIR）システム。開発者がWebテクノロジー（HTML、JavaScript、Flash）を使用してデスクトップアプリケーションを作成できるようにする。

Android

Android社によって開発され、後にGoogleに買収されたスマートフォン向けオペレーティングシステム。

匿名FTP

FTPサーバーを参照してください。

ANSI (American National Standards Institute)

コンピュータ業界の標準を作成する組織。ANSI C標準を担当。

ANSI C

Cプログラミング言語の国際標準。

ADO (ActiveX Data Object)

マイクロソフトのあらゆるタイプのデータストレージ技術。データアクセスを提供する。

ADOの詳細は、私たちのADOチュートリアルをご覧ください

ADSL (Asymmetric Digital Subscriber Line)

アップロード速度とダウンロード速度が異なる特殊なタイプのDSL回線。

Agent

検索エージェント/検索エンジンを参照してください。

Amaya

W3CによるオープンソースのWebブラウザエディタ。ブラウザデザインにおける先進的なアイデアを推進するために使用される。

Animation

一連の写真を連続して再生することで動きを模倣するもの。

アンチウイルスプログラム

あらゆる種類のコンピュータウイルスを発見して破壊するコンピュータプログラム。

Apache

オープンソースのWebサーバー。主にUnix、Linux、Solarisプラットフォームで使用される。

Applet

Webアプレットを参照してください。

Archie

公開FTPサーバー上のファイルを検索するコンピュータプログラム。

API (Application Programming Interface)

プログラムが別のプログラムと通信するためのインターフェース。Web関連: WebブラウザまたはWebサーバーが他のプログラムと通信するためのインターフェース。（Active-Xプラグインも参照）

ARPAnet

1970年代のインターネット発展時に始まったネットワークテスト実験。

Authentication

Web関連: ネットワーク上またはコンピュータプログラム上でユーザーの身元を確認する方法。

ASCII（American Standard Code for Information Interchange）

コンピュータでのテキストの保存と印刷に使用される128個の英数字および特殊制御文字。HTMLではWebを介して送信されるデータ。

HTMLリファレンスでASCIIコードの完全なリストを参照してください。

ASF (Advanced Streaming Format)

マルチメディアデータストリームのフォーマット。マイクロソフトのWindows Mediaによって開発された。

ASP (Active Server Pages)

サーバーで実行可能なスクリプトをWebページに挿入できるようにするマイクロソフトの技術。

ASPの詳細は、私たちのASPチュートリアルをご覧ください

ASX (ASF Streaming Redirector)

ASFファイルに関する情報を格納するためのXML形式。マイクロソフトのWindows Mediaによって開発された。

AVI (Audio Video Interleave)

ビデオファイルのファイル形式。マイクロソフトが開発したビデオ圧縮技術。

Banner Ad

（最も一般的なグラフィック）広告。Webページ上に配置され、広告主のサイトへのハイパーリンクとして機能する。

Bandwidth

インターネット接続の速度（データ量）は、送信できるデータ量で測定されます。帯域幅が大きいほど、接続は速くなります。

Baud

チャネル上で毎秒送信されるシンボル数。

BBS (Bulletin Board System)

ネットワークベースの公開ディスカッション、ファイル、および掲示板システム。

Binary Data

機械可読形式のデータ。

Bit (Binary Digit)

コンピュータに保存されるデータの最小単位。1ビットの値は0または1。コンピュータは8ビットを使用して1文字のテキストを保存する。

Blog (Web Log)

ウェブサイトの一種（通常は個人が管理）。コメント（ほとんどは個人の）意見、出来事の説明などを記録する。

Blogger

ブログ（Webログ）を管理またはコンテンツを書く人。

Blogging

ブログ（Webログ）にコンテンツを書く、または追加すること。

BMP (Bitmap)

画像を保存するための形式。

Bookmark

Web関連: 特定のWebサイトへのリンクを保存（ブックマーク）し、後で簡単にアクセスできるようにするもの。

Bounce Rate

Webサイトの訪問者が1つのページだけを見て離れる（バウンスする）割合。

Browse

ユーザーがWebブラウザを使用してハイパーリンクをたどり、ページからページへ移動する、ネットワーク全体のユーザーの動きを表す用語。（Webブラウザを参照）

BPS (Bits Per Second)

ネットワーク上でのデータ転送速度を表す用語。

Browser

Webブラウザを参照してください。

Byte (Binary Term)

8ビットを含むコンピュータの記憶単位。各バイトは1文字のテキストを格納できる。

C

高度なコンピュータアプリケーションのプログラミングに使用される高度なプログラミング言語。

C++ (C Plus Plus)

C言語にオブジェクト指向機能を追加したもの。

C# (C Sharp)

C++にJavaのような機能を追加したマイクロソフト版。

Case Sensitive

大文字と小文字を区別することの説明に使われる。

Cache

Web関連: WebブラウザまたはWebサーバーがコンピュータのハードディスクにWebページのコピーを保存する機能。

Chat

オンラインでテキストベースのインターネットユーザー間通信。

CGI (Common Gateway Interface)

CGIプログラムがWebサーバーとどのように通信するかを記述する規則。

CGI Bin

Webサーバー上でCGIプログラムを保存するフォルダ（またはディレクトリ）。

CGI Program

Webサーバーからの入力と出力を処理する小さなプログラム。CGIプログラムは通常、フォーム入力やデータベースクエリの処理に使用される。

Cinepac

コンピュータビデオコーデック。

Client

Webクライアントを参照してください。

Client/Server

Web関連: WebクライアントとWebサーバー間で作業を分離する通信。

Click

Web関連: マウスでWebページ上のハイパーリンク要素（テキストや画像など）をクリックすると、別のWebページへの移動や同じページの別の部分への移動などのイベントが作成される。

Clickthrough Rate

訪問者がページ上のハイパーリンク（または広告）をクリックした回数の、ページが表示された回数に対する割合。

Cloud Computing

ユーザーのコンピュータではなくインターネット上に保存されるアプリケーションとデータ。

Codec (Compressor / Decompressor)

データの圧縮と解凍の技術を表す一般的な用語。

Communication Protocol

コンピュータが標準的な方法で対話するための標準（言語と一連の規則）。例: IP、FTP、HTTP。

通信プロトコルの詳細は、私たちのTCP/IPチュートリアルをご覧ください

Compression

Webドキュメントやグラフィックのサイズを小さくして、ネットワーク経由でより速く配信する方法。

Computer Virus

メッセージ表示の妨害、ファイルの削除、さらにはコンピュータのオペレーティングシステムの破壊などを行う可能性のあるコンピュータプログラム。

Cookie

WebサーバーからWebブラウザに送信され、コンピュータに保存される情報。Cookieの目的は、訪問したWebサイトに関する情報を提供し、後のアクセスでサーバーが使用できるようにすること。

ColdFusion

Web開発ソフトウェアの主要プラットフォーム（Linux、UNIX、Solaris、Windows）。

CSS (Cascading Style Sheets)

Webドキュメントのスタイル（フォント、サイズ、色、間隔など）を定義するW3C勧告の言語。

CSSの詳細は、私たちのCSSチュートリアルをご覧ください

Database

コンピュータプログラムがデータを簡単に取得および操作できるように、コンピュータがデータを保存する方法。

データベースの詳細は、私たちのSQLチュートリアルをご覧ください

Database System

データベース内のデータを操作するコンピュータプログラム（例: MS Access、Oracle、MySQL）。

DB2

IBMのデータベースシステム。主にUnixおよびSolarisプラットフォームで使用される。

DBA (Data Base Administrator)

データベースを管理する人（またはソフトウェア）。典型的なタスク: バックアップ、メンテナンス、実行。

DHCP (Dynamic Host Configuration Protocol)

ネットワークユーザーに新しいIPアドレスを割り当てるインターネット標準プロトコル。

DHTML (Dynamic HTML)

HTMLコンテンツが動的に変化する可能性があることを表すために一般的に使用される用語。

Dial-up Connection

Web関連: 電話とモデムを介してインターネットに接続すること。

Discussion Group

ニュースグループを参照してください。

DNS (Domain Name Service)

Webサーバー上で実行され、ドメイン名をIPアドレスに変換するコンピュータプログラム。

DNSの詳細は、私たちのウェブホスティングチュートリアルをご覧ください

DNS Server

DNSを実行するWebサーバー。

DOM (Document Object Model)

ウェブページのオブジェクトプログラミングモデル。（HTML DOMおよびXML DOMを参照）

Domain Name

Webサイトの名前を識別するもの。（例: runoob.com）

ドメインの詳細は、私たちのウェブホスティングチュートリアルをご覧ください

DOS (Disk Operating System)

ディスクベースの汎用コンピュータオペレーティングシステム（オペレーティングシステムを参照）。元々はマイクロソフトがIBM PC向けに開発。通常、MS-DOSの略称として使用される。

Download

リモートコンピュータからローカルコンピュータへのファイル転送。Web関連: WebクライアントがWebサーバーからファイルを転送すること。（アップロードも参照）

DSL (Digital Subscriber Line)

一般の電話回線に基づくブロードバンドアクセス技術。

DTD (Document Type Definition)

HTMLやXMLなどのWeb文書の有効な構成要素を定義する規則（言語）。

DTDの詳細は、私たちのDTDチュートリアルをご覧ください

Dynamic IP

インターネットに接続するたびにIPアドレスが変わること。（DHCPおよび静的IPを参照）

E-mail (Electronic Mail)

ある人から別の人へインターネットを介してメッセージを送信すること。

E-mail Address

電子メールを個人または組織に送信するために使用するアドレス。一般的な形式は、ユーザー名@ホスト名です。

E-mail Server

Webサーバー専用の電子メールサービス機能。

Encryption

元の形式から、人だけが元に戻して読むことができる暗号化形式に変換されたデータ。暗号化の目的は、不正なデータ読み取りを防ぐことです。

Error

Webサーバーエラーを参照してください。

Ethernet

ローカルエリアネットワークの一種（LANを参照）。

Firewall

セキュリティフィルタとして、ネットワーク通信の種類を制限できるソフトウェア。最も一般的にはパソコン（またはLAN）とインターネットの間で使用されます。

Flash

ベクターベースのマルチメディア形式。Web上で使用され、Adobeによって開発された。

Form

HTMLフォームを参照してください。

Forum

Web関連：ニュースグループと同じ。

Frame

Web関連：ブラウザで画面の一部に特定のコンテンツを表示する。フレームは通常、異なるWebページのコンテンツを表示するために使用される。

FrontPage

Windowsプラットフォーム向けWeb開発ソフトウェア。マイクロソフトによって開発された。

FTP (File Transfer Protocol)

2台のコンピュータ間でファイルを送信する最も一般的な方法の1つ。

FTP Server

Webサーバーで、ログインしてファイルをダウンロード（またはアップロード）できる。匿名FTPは、ログインアカウントを使わずにFTPサーバーからファイルをダウンロードする方法である。

Gateway

コンピュータプログラム間で互換性のない、アプリケーションまたはネットワーク転送用にフォーマットされたデータ。

GIF (Graphics Interchange Format)

CompuServeによって開発された画像保存用の圧縮形式。インターネット上で最も一般的な画像形式の1つ。

GB

ギガバイト。コンピュータの記憶容量の単位。

Gigabyte

1024メガバイト。通常は10億バイトに切り捨てられる。

Graphics

Web関連：画像を表示する（テキストに対して）。

Graphic Monitor

グラフィックを表示できるディスプレイ画面。

Graphic Printer

グラフィックを印刷できるプリンター。

Graphical Banner

バナー広告を参照してください。

Helper application

Web関連：ブラウザ自体が処理できないものを表示、閲覧、または操作するのを支援する仕組み（プラグインを参照）。

Hits

Webオブジェクト（Webページや画像）が閲覧またはダウンロードされた回数（ページビューを参照）。

Home Page

ウェブサイトの最上位（メイン）ページ。サイトにアクセスしたときに表示される既定のページ。

Host

Webホストを参照してください。

Hosting

バーチャルホスティングを参照してください。

Hotlink

ハイパーリンクを参照してください。

HTML (Hypertext Markup Language)

HTMLはWeb言語です。HTMLは、Webページのコンテンツ、レイアウト、ファイル形式を定義するために使用されるタグのセットです。WebブラウザはHTMLタグを使用してテキストの表示方法を定義します。

HTMLの詳細については、HTMLチュートリアルを参照してください。

HTML Document

HTMLで書かれたファイル。

HTML DOM (HTML Document Object Model)

HTMLドキュメントのためのプログラミングインターフェース。

HTML DOMの詳細については、HTML DOMチュートリアルを参照してください。

HTML Editor

HTMLページを編集するためのソフトウェアプログラム。HTMLエディタを使用すると、ワープロのように、リスト、テーブル、レイアウト、フォントサイズ、色などの要素をHTMLドキュメントに追加できます。編集中にWebページ上で表示される（WYSIWYG）HTMLエディタは、編集中のコンテンツをページに表示します。

HTML Form

ユーザー入力フォームをサーバーに送信する。

HTMLフォームの詳細については、HTMLチュートリアルを参照してください。

HTML Page

HTMLファイル。

HTML Tags

文書のさまざまな部分を識別するコードで、Webブラウザがどのように表示するかを知るためのものです。

HTMLタグの詳細については、HTMLチュートリアルを参照してください。

HTTP (Hyper Text Transfer Protocol)

インターネット経由でテキストファイルを送信するためのルールと標準のセット。一方の端にHTTPクライアントプログラム、もう一方の端にHTTPサーバープログラムが必要です。

HTTP Client

Webサーバーにサービスを要求するコンピュータプログラム。

HTTP Server

Webサーバーからサービスを提供するコンピュータプログラム。

HTTPS (Hyper Text Transfer Protocol Secure)

HTTPと同じですが、安全なインターネット通信を提供するSSL。 （SSLも参照）

Hyperlink

他のWebページへのリンクを含むWebページ内のテキスト文字列は、HYPERLINKと呼ばれます。

Hypermedia

ハイパーテキスト、グラフィック、オーディオを拡張する。

Hypertext

ハイパーテキストは相互にリンクされており、読者は強調表示された単語や記号、または他のファイルのテキストをクリックすることで関連ファイルを読むことができます。（ハイパーリンクも参照）

IAB (Internet Architecture Board)

インターネット標準を決定するための評議会（W3Cも参照）。

IE (Internet Explorer)

Internet Explorerを参照してください。

IETF (Internet Engineering Task Force)

インターネット上の技術的問題の解決に重点を置いたIABグループ。

IIS (Internet Information Server)

Windowsオペレーティングシステム用のWebサーバー。マイクロソフトによって開発された。

IMAP (Internet Message Access Protocol)

電子メールサーバーから電子メールを取得するための標準的な通信プロトコル。IMAPはPOPに似ていますが、より高度です。

IMAPの詳細については、TCP/IPチュートリアルを参照してください。

Indeo

Intelによって開発されたコンピュータビデオコーデック。

Internet

何百万台ものコンピュータを接続する世界的なネットワーク。（ワールドワイドウェブも参照）

Internet Browser

Webブラウザを参照してください。

Internet Explorer

マイクロソフトのブラウザ。最も一般的に使用されるブラウザ。

ブラウザの詳細については、ブラウザのセクションを参照してください。

Internet Server

Webサーバーを参照してください。

Intranet

プライベート（クローズド）インターネット。LAN（ローカルエリアネットワーク）内部で動作する。

IP (Internet Protocol)

TCP/IPプロトコルを参照してください。

IP Address (Internet Protocol Address)

インターネット上の各コンピュータに固有の識別番号（例：197.123.22.240）

IP Number (Internet Protocol Number)

IPアドレス。

IP Packet

TCP/IPパケットを参照してください。

IRC (Internet Relay Chat)

ユーザーがオンラインで議論できるようにするインターネットシステム。

IRC Client

ユーザーがIRCに接続できるようにするコンピュータプログラム。

IRC Server

IRC接続専用のインターネットサーバーサービス。

ISAPI (Internet Server API)

Internet Information Serverアプリケーションプログラミングインターフェース（API）（IISを参照）。

ISDN (Integrated Services Digital Network)

デジタル伝送を使用する電気通信標準で、通常の電話回線を介したデータ通信をサポートします。

ISP (Internet Service Provider)

インターネットへのアクセスとウェブサイトのホスティングを提供する。

Java

Sunによって開発されたプログラミング言語。主にWebサーバーとWebアプレットのプログラミングに使用されます。

Java Applet

Webアプレットを参照してください。

JavaScript

インターネット上で最も人気のあるスクリプト言語。Netscapeによって開発された。

JavaScriptの詳細については、JavaScriptチュートリアルを参照してください。

JPEG (Joint Photographic Expert Group)

JPGおよびJPEGグラフィック形式で圧縮画像を保存しやすくすることを目的としています。

JPEG and JPG

圧縮画像を保存するためのグラフィック形式。

JScript

Microsoft版のJavaScript。

JSP (Java Server Pages)

Javaテクノロジに基づき、Webページにサーバー実行可能なスクリプトを挿入できるようにするもの。主にLinux、Unix、Solarisプラットフォームで使用されます。

K

キロバイト。10Kは10キロバイトと同じです。

KB

キロバイト。10Kは10キロバイトと同じです。

Keyword

XMLチュートリアルでXMLの詳細を学びましょう。

XML DOM (XML Document Object Model)

W3Cによって開発されたXML文書用のプログラミングインターフェース。

XML DOMチュートリアルでXML DOMの詳細を学びましょう。

XMLHttpRequest

すべての最新のWebブラウザがサポートするJavaScriptプログラミングインターフェース（オブジェクト）。WebブラウザとWebサーバーの間で、バックグラウンド（AJAX）でデータを交換するために使用されます。

AJAXチュートリアルでXMLHttpの詳細を学びましょう。

XML Schema

XML SchemaはXMLベースの言語で、DTDの代替として使用されます。XMLスキーマファイルはXML文書の構造を記述します。

XML SchemaチュートリアルでXML Schemaの詳細を学びましょう。

XSD (XML Schema Definition)

XML Schemaとほぼ同じです。

XSL (Extensible Stylesheet Language)

W3Cによって開発されたXML言語のセットで、XSLT、XSL-FO、XPathが含まれます。

XSLチュートリアルでXSLの詳細を学びましょう。

XSL-FO (XSL Formatting Objects)

XML文書をフォーマットするためのXML言語。W3C XSLの一部です。

XSL-FOチュートリアルでXSL-FOの詳細を学びましょう。

XSLT (XSL Transformations)

XML文書を変換するためのXML言語。W3C XSLの一部です。

XSLTチュートリアルでXSLTの詳細を学びましょう。

ZIP

コンピュータ上のファイル圧縮形式。通常、ファイルの圧縮に使用されます。WinZipのようなコンピュータプログラムを使用すると、ZIPファイルを圧縮（zipped）および解凍できます。
