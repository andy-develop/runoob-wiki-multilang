TensorFlow環境構築

TensorFlow 2.xにはPythonバージョンに関する特定の要件があります：

TensorFlowバージョン Pythonバージョンのサポート
TensorFlow 2.15+ Python 3.9-3.12
TensorFlow 2.12-2.14 Python 3.8-3.11
TensorFlow 2.8-2.11 Python 3.7-3.10

Python 3.9〜3.11の使用を推奨これらのバージョンは最も優れた互換性と安定性を備えています。

現在のPythonバージョンを確認

# 检查 Python 版本
python --version
# 或
python3 --version

# 检查 pip 版本
pip --version
# 或
pip3 --version

Pythonのインストールオプション

オプション1：公式Python（初心者に推奨）

  • アクセスpython.orgダウンロードしてインストール
  • インストール時に「Add Python to PATH」にチェックを入れる
  • pipパッケージマネージャーを含む

オプション2：Anaconda/Miniconda（データサイエンスに推奨）

  • Anaconda：完全なデータサイエンス環境
  • Miniconda：軽量版
  • 環境管理とパッケージ管理を内蔵

オプション3：システムパッケージマネージャー

# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# macOS (使用 Homebrew)
brew install python3

# Windows (使用 Chocolatey)
choco install python3

仮想環境の設定（強く推奨）

なぜ仮想環境を使うのか

利点：

  • 依存関係の分離：異なるプロジェクト間のパッケージバージョン競合を回避
  • クリーンな環境：システムのPython環境を整理整頓された状態に保つ
  • 管理が容易：環境を簡単に削除・再構築できる
  • 再現性：異なるマシンで環境を再現しやすい

venvで仮想環境を作成

# 创建虚拟环境
python -m venv tensorflow_env

# 激活虚拟环境
# Windows:
tensorflow_env\Scripts\activate
# macOS/Linux:
source tensorflow_env/bin/activate

# 确认激活（提示符会显示环境名）
which python  # 应该指向虚拟环境中的 python

# 升级 pip
python -m pip install --upgrade pip

Condaで仮想環境を作成

# 创建新环境
conda create -n tensorflow_env python=3.10

# 激活环境
conda activate tensorflow_env

# 列出所有环境
conda env list

# 在环境中安装包
conda install pip

仮想環境の管理

# 查看已安装的包
pip list

# 生成依赖文件
pip freeze > requirements.txt

# 从文件安装依赖
pip install -r requirements.txt

# 退出虚拟环境
deactivate  # venv
conda deactivate  # conda

# 删除虚拟环境
rm -rf tensorflow_env  # venv
conda env remove -n tensorflow_env  # conda

TensorFlowのインストール

CPU版のインストール（学習や軽量タスク向け）

# 确保在虚拟环境中
pip install tensorflow

# 验证安装
python -c "import tensorflow as tf; print('TensorFlow version:', tf.__version__)"

CPU版の特徴：

  • 長所：インストールが簡単で、追加設定が不要
  • 短所：トレーニング速度が遅く、小規模データ向け
  • 適用シーン：学習、プロトタイプ開発、推論デプロイ

GPU版のインストール（大規模トレーニング向け）

GPUアクセラレーションはトレーニング速度を大幅に向上させることができ、特にディープラーニングタスクに有効です。

3.2.1 NVIDIA GPUの要件

ハードウェア要件：

  • NVIDIA GPU（Compute Capability 3.5以上）
  • 8GB以上のVRAM（推奨）

GPU情報の確認：

# Windows
nvidia-smi

# Linux
lspci | grep -i nvidia

CUDAとcuDNNのインストール

TensorFlow 2.15+とCUDAバージョンの対応：

TensorFlow CUDA cuDNN
2.15+ 12.2 8.9
2.12-2.14 11.8 8.6

インストール手順：

  1. CUDA Toolkitのダウンロードとインストール

    • アクセスNVIDIA CUDA Toolkit
    • 対応するバージョンを選択してダウンロード・インストール
    • システムのPATHに追加

  2. cuDNNのダウンロードとインストール

    • アクセスNVIDIA cuDNN
    • NVIDIAアカウントの登録が必要
    • CUDAインストールディレクトリに解凍

  3. CUDAインストールの検証

    nvcc --version
nvidia-smi

TensorFlow GPU版のインストール

# TensorFlow 2.10+ 统一包名

# 验证 GPU 可用性

print('GPU available:', tf.config.list_physical_devices('GPU'))
print('Built with CUDA:', tf.test.is_built_with_cuda())
"

設定の検証

完全なインストール検証スクリプト

作成verify_installation.pyファイル：

例

#!/usr/bin/env python3
"""
TensorFlowインストール検証スクリプト
"""

import sys
print("Python version:", sys.version)
print("-" * 50)

# TensorFlowを確認
try:
    import tensorflow as tf
    print(f"✓ TensorFlow version: {tf.__version__}")
    print(f"✓ Keras version: {tf.keras.__version__}")
   
    # GPUサポートを確認
    physical_devices = tf.config.list_physical_devices('GPU')
    if physical_devices:
        print(f"✓ GPU devices found: {len(physical_devices)}")
        for i, device in enumerate(physical_devices):
            print(f"  - GPU {i}: {device}")
        print(f"✓ CUDA built: {tf.test.is_built_with_cuda()}")
    else:
        print("&#x26a0; No GPU devices found (CPU only)")
   
    # 簡単な計算テスト
    a = tf.constant([1, 2, 3])
    b = tf.constant([4, 5, 6])
    c = tf.add(a, b)
    print(f"✓ Basic computation test: {a.numpy()} + {b.numpy()} = {c.numpy()}")
   
except ImportError as e:
    print(f"✗ TensorFlow import failed: {e}")

print("-" * 50)

# その他の重要なパッケージを確認
packages = ['numpy', 'pandas', 'matplotlib', 'sklearn', 'jupyter']
for package in packages:
    try:
        module = __import__(package)
        version = getattr(module, '__version__', 'unknown')
        print(f"✓ {package}: {version}")
    except ImportError:
        print(f"✗ {package}: not installed")

print("-" * 50)

# メモリとデバイス情報
print("System Information:")
if tf.config.list_physical_devices('GPU'):
    for gpu in tf.config.list_physical_devices('GPU'):
        try:
            tf.config.experimental.set_memory_growth(gpu, True)
            print(f"✓ GPU memory growth enabled for {gpu}")
        except:
            print(f"&#x26a0; Could not set memory growth for {gpu}")

print("Installation verification complete!")

検証を実行：

python verify_installation.py

パフォーマンスベンチマークテスト

簡単なパフォーマンステストを作成：

例

import tensorflow as tf
import time

print("TensorFlow Performance Test")
print("-" * 30)

# 行列乗算テスト
def benchmark_matmul(device_name, size=1000):
    with tf.device(device_name):
        a = tf.random.normal([size, size])
        b = tf.random.normal([size, size])
       
        # ウォームアップ
        for _ in range(5):
            c = tf.matmul(a, b)
       
        # 計測
        start_time = time.time()
        for _ in range(10):
            c = tf.matmul(a, b)
        end_time = time.time()
       
        avg_time = (end_time - start_time) / 10
        return avg_time

# CPUテスト
cpu_time = benchmark_matmul('/CPU:0')
print(f"CPU ({1000}x{1000} matmul): {cpu_time:.4f} seconds")

# GPUテスト（利用可能な場合）
if tf.config.list_physical_devices('GPU'):
    gpu_time = benchmark_matmul('/GPU:0')
    print(f"GPU ({1000}x{1000} matmul): {gpu_time:.4f} seconds")
    print(f"GPU speedup: {cpu_time/gpu_time:.2f}x")
else:
    print("No GPU available for testing")

GPU関連の問題

問題1：CUDAバージョンの不一致

  • TensorFlowとCUDAバージョンの互換性を確認
  • 一致するCUDAバージョンを再インストール

python -m ipykernel install --user --name tensorflow_env --display-name "Python (TensorFlow)"

# 或使用 conda

開発環境の最適化

GPUメモリ管理

# GPU 配置优化
import tensorflow as tf

# 方法 1：设置内存增长
gpus = tf.config.experimental.list_physical_devices('GPU')
if gpus:
    try:
        for gpu in gpus:
            tf.config.experimental.set_memory_growth(gpu, True)
    except RuntimeError as e:
        print(e)

# 方法 2：限制内存使用
if gpus:
    try:
        tf.config.experimental.set_memory_limit(gpus[0], 4096)  # 4GB
    except RuntimeError as e:
        print(e)

パフォーマンス最適化設定

# 启用混合精度训练（提升性能）
from tensorflow.keras.mixed_precision import experimental as mixed_precision

policy = mixed_precision.Policy('mixed_float16')
mixed_precision.set_policy(policy)

# 启用 XLA 编译优化
tf.config.optimizer.set_jit(True)
