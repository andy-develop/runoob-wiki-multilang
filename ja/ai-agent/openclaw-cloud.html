OpenClaw ワンクリックデプロイ

現在、各主要プラットフォームはこのエージェントをサポートしています。ローカルにインストールしたくない場合は、ワンクリックでクラウド上に OpenClaw をデプロイできます：

ByteDance ArkClaw
Volcengine のクラウドデプロイソリューションで、エージェントをすぐに体験できます
Alibaba Cloud OpenClaw
ワンクリックでクラウド型エージェントをデプロイ、ローカルインストールは不要

Token は Coding Plan パックを購入するとよりお得です：

ArkClaw ワンクリックデプロイ

ArkClawVolcengine が提供するクラウド AI エージェント（Agent）サービスで、開発者を支援しますOpenClaw をクラウドにワンクリックデプロイ、これにより、ローカルインストールや複雑な運用・設定が不要になります。

ByteDance ArkClaw
Volcengine のクラウドデプロイソリューションで、エージェントをすぐに体験できます

ArkClaw を使用すると、次のものが得られます：

  • 専用の独立した ECS リソース、一対一の分離デプロイ
  • 7×24 時間オンライン稼働、いつでも利用可能
  • ハードルゼロですぐに利用可能、手動での環境設定は不要
  • Ark Coding Plan にシームレスに接続、サブスクリプション枠を直接使用
  • Token の従量課金の心配から解放、開発コストをより制御しやすくなります

ArkClaw を作成して使用する

  • サブスクリプションプランを購読すると、次のことができます：
    • ログインVolcengine Ark 体験センター。
    • 左側のディレクトリで選択Agent > ArkClaw。
    • 「今すぐ開始」ボタンをクリックして、作成申請を送信します。

    作成が成功すると、Ark 上で ArkClaw と対話できます：

    OpenClaw を設定する

    OpenClaw の実行中は、デフォルトで百炼（Bailian）モデルを呼び出します。モデル呼び出しの主な課金方法は2つあります：

    • Coding Plan AI コーディングパッケージ（推奨）：固定月額制で、月間リクエスト枠を提供します。時間枠の上限を超えた呼び出しはエラーになり、課金は発生しません。予期しない費用の発生を防げます。現在、qwen3.5-plus、kimi-k2.5、MiniMax-M2.5、glm-5 などのモデルに対応しています。
    • Token 使用量による従量課金：OpenClaw 2026.2.26 バージョンでは、デフォルトでテキストおよび画像処理モデルとして qwen3.5-plus を使用します。使用量が多いとお得ではありません。

    まず Alibaba Cloud のメインアカウントを使用して百炼モデルサービスプラットフォームにアクセスできます：https://bailian.console.aliyun.com/次に右上隅の「ログイン」をクリックし、ログイン成功後、右上隅の歯車⚙️アイコンをクリックして「API key」を選択し、API key をコピーします。ない場合は API key を作成することもできます：

    Alibaba Cloud 百炼の有効化は無料ですが、モデル呼び出し（無料枠を超えた場合）、モデルデプロイ、モデルチューニングにはそれぞれ課金が発生します。

    OpenClaw は token をかなり消費します。長期的に使用する場合は、まず最安のパックを購入することをお勧めします：Alibaba Cloud 百炼大規模言語モデルサービスプラットフォーム。

    Coding Plan

    Coding Plan は基本的に入手が難しく、終了予定でもあります。Alibaba は現在すべて Token Plan に変更しました。参照：Alibaba Cloud 百炼 Token Plan

    • OpenAI 互換：https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
    • Anthropic 互換：https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic

    さらに、百炼の Coding Plan プランを利用するとより安くなります：https://www.aliyun.com/benefit/scene/codingplan

    Coding Plan プランを購入したら、次のCoding Planページで、Coding Plan 専用 API Key（形式: sk-sp-xxxxx）を取得できます。

    その後、AI ツールで以下のいずれかの Base URL を設定する必要があります（ツールによって異なります）：

    • OpenAI 互換プロトコル（OpenClaw で使用可能）：https://coding.dashscope.aliyuncs.com/v1
    • Anthropic 互換プロトコル：https://coding.dashscope.aliyuncs.com/apps/anthropic

    注：Coding Plan 専用の API Key および Base URL は、百炼の従量課金用 API Key（sk-xxxxx）および Base URL（https://dashscope.aliyuncs.com/xxxxxx）とは相互利用できません。混用しないでください。

    入手できない場合は、リソースパックを直接購入できます：https://cn.aliyun.com/benefit?from_alibabacloud=&userCode=i5mn5r7m

    在サーバーページ、サーバーカードのインスタンス ID をクリックして、サーバー概要ページに移動します。

    「アプリ詳細」タブをクリックして、OpenClaw を設定します。

    • ポートの開放：対応するポートのファイアウォールを開放する必要があります。「ワンクリック開放」をクリックするだけです。
    • OpenClaw を設定：「コマンドを実行」をクリックし、百炼の API-Key を入力して、「次へ」をクリックします。
    • アクセス制御ページ：「コマンドを実行」をクリックすると、Clawdbot 対話のアドレスを取得できます。
    • Token を表示：ヘルプ < Token 設定 で「コマンドを実行」をクリックして、Token を取得します。

    ResponseAPI アクセスを有効にします。以降、AppFlow は API 経由で OpenClaw にアクセスします。

    • Clawdbot ページの左側のナビゲーションバーで、[Setting] > [Config] をクリックします。
    • Config ページの左側のナビゲーションバーで [Gateway] をクリックし、[Http] タブに切り替えて、[Responses] 領域の [Enabled] をオンに切り替えて、[Save] をクリックします。

    （任意）オンライン検索機能を設定する

    現在、中国本土（香港を除く）ではオンライン検索はサポートされていません。香港および海外地域でオンライン機能を使用する場合は、次を参照してください：OpenClaw 公式サイトの設定。
