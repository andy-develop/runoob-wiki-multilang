CSS flex-shrink属性

CSS リファレンス


实例

A、B、C は flex-shrink:1 に設定し、D、E は flex-shrink:2 に設定します：

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <title>菜鸟教程（runoob.com）</title> <style>
#content { display: flex; width: 500px; } #content div { flex-basis: 120px; border: 3px solid rgba(0,0,0,.2); } .box { flex-shrink: 1; } .box1 { flex-shrink: 2; }
</style> </head> <body> <p>div の全幅は 500px、flex-basic は 120px です。</p> <p>A、B、C は flex-shrink:1 に設定します。D、E は flex-shrink:2 に設定します。</p> <p>D、E の幅は A、B、C と異なります</p> <div id="content"> <div class="box" style="background-color:red;">A</div> <div class="box" style="background-color:lightblue;">B</div> <div class="box" style="background-color:yellow;">C</div> <div class="box1" style="background-color:brown;">D</div> <div class="box1" style="background-color:lightgreen;">E</div> </div> </body> </html>

实例の解析：

flex-shrink のデフォルト値は 1 です。明示的にこの属性を定義しなかった場合、自動的にデフォルト値 1 に従い、すべての因子を合計した後に比率を計算して空間を縮小します。

この例では、A、B、C は flex-shrink を 1 と明示的に定義し、D、E は flex-shrink を 2 と定義しているため、計算により残りの空間は合計 7 つに分割され、そのうち A、B、C が 1 つ分、D、E が 2 つ分、すなわち 1:1:1:2:2 となります。

親コンテナは 500px と定義され、子項目は 120px と定義されているため、子項目を合計すると 600px となり、親コンテナを 100px 超えていることがわかります。この超えた 100px は A、B、C、D、E によって消化される必要があります。収縮係数を通じて、加重合計は次のようになります。100*1+100*1+100*1+100*2+100*2=700px。

そこで、A、B、C、D、E が除去されるオーバーフロー量を計算できます：
A 被移除溢出量：(100*1/700)*100，即约等于14px
B 被移除溢出量：(100*1/700)*100，即约等于14px
C 被移除溢出量：(100*1/700)*100，即约等于14px
D 被移除溢出量：(100*2/700)*100，即约等于28px
E 被移除溢出量：(100*2/700)*100，即约等于28px

最終的に A、B、C、D、E の実際の幅はそれぞれ次のようになります：120-14=106px, 120-14=106px, 120-14=106px, 120-28=92px,120-28=92pxまた、この幅にはボーダーが含まれます。

定義と使い方

flex-shrink 属性は、flex 要素の収縮ルールを指定します。flex 要素は、デフォルトの幅の合計がコンテナより大きい場合にのみ収縮し、その収縮の大きさは flex-shrink の値に基づきます。

注意：要素がフレックスボックスオブジェクトの要素でない場合、flex-shrink 属性は効果がありません。

デフォルト値： 1
継承： 否
アニメーション可能： はい。参照してください。アニメーション可能（animatable）。 試してみる
バージョン： CSS3
JavaScript 構文： object.style.flexShrink="5" 試してみる

CSS 構文

flex-shrink: number|initial|inherit;

属性値

值 説明
number 項目が他のフレックス項目に対してどれだけ収縮するかを示す数値。デフォルト値は 1 です。
initial この属性をデフォルト値に設定します。参照してください。initial。
inherit 親要素からこの属性を継承します。参照してください。inherit。

    flex-shrink は、子要素の幅の合計と親要素の幅の差を、子要素の flex-shrink の値に応じて各子要素に分配します。各子要素の元の幅から比例配分された値を引いた残りが実際の幅になります。

    元の例をモデルとして、親要素を div0 と命名し、1〜5 の 5 つの子要素をそれぞれ div1、div2、...、div5 と命名します。

    親要素は次のように設定する必要があります：

    display：flex，width：350px

    すべての子要素は次のように設定する必要があります：

    flex-basis：100px、すなわち収縮が発生しない場合の子要素の元の幅

    以上が前提条件です。

    子要素の幅の合計と親要素の幅の差：

    100*5-350=150px

    このとき、子要素の flex-shrink 属性を設定することで、150px の総縮小量を 5 つの子要素にどのように分配するかを決定します。

    前述の設定に従うと、div2 の実際の幅は他の子要素の 1/3 になります。

    子要素の幅をそれぞれ w1、w2、...、w5 とし、div2 の flex-shrink 値と他の子要素の flex-shrink 値の比を X とすると、次の連立方程式が得られます：

    w1=w3=w4=w5=100-150(1/X+4)
w2=100-150(X/X+4)
w1=w3=w4=w5=3w2

    連立方程式を解くと次のようになります

    X=19/5,w2=26.92,w1=w3=w4=w5=80.77

    mdn 公式サンプルコードを例にします：

    https://developer.mozilla.org/zh-CN/docs/Web/CSS/flex-shrink

    チュートリアルの計算形式には誤りがあります：

    1. 各要素の幅はそれぞれ w1 w2 w3 w4 w5 ====> それぞれ 120px

    2. 各要素の shrink はそれぞれ a、b、c、d、e ===> 1,1,1,2,2

    3. 超過幅は A = w1+w2+w3+w4+w5 - 親要素の幅 = 120+120+120+120+120 - 500 = 600px-500px = 100px

    4. 総圧縮ウェイト W = a * w1 + b * w2 + c * w3 + d*w4+ e*w5 = 120*1 + 120*1+ 120*1 + 120*2 + 120*2 = 840

    5. 圧縮率 S = a（flex-shrink）の値 * 幅（w1） / 総圧縮ウェイトW；（ここでは最初の要素を例に計算） 120 * 1/840 約 0.1428

    6. 最終結果の幅 = 自身の幅 w1 - S * 超過幅 A；120 - 120 * 1/840 *100 = 120 - 14.28 = 105.75px

    これは border を含んでいません。例で与えられたものには border があるため、幅の計算時に左右を加算し、各要素は 126px となり、計算結果は次のようになります

    126 * 5 = 630

    126 * 5 - 500 = 630 - 500 = 130

    126 * 1 +126*1+126*1 +126*2+126*2 = 378 + 504 = 882

    126 * 1 / 882 = 0.1428

    126 - 126 * 1/882 *130  = 126 - 18.57= 107.43 

    最終結果は 107.43 になるはずです
