TypeScript リテラル型

リテラル型（Literal Types）は、TypeScript において汎用型ではなく特定の値を表す機能です。

これにより、変数の型を広範な string や number などの型ではなく、具体的な値に制限することができます。

これにより、より精密な型制御が可能になり、コードの型安全性が高まります。

SVG 図解：リテラル型

なぜリテラル型が必要なのか

TypeScript では、string や number などのデフォルトの型は広範すぎます。

時には、より精密な型制御が必要です。例えば、変数が特定の値のみを取れるようにする場合です。

リテラル型はまさにこのような問題を解決するために生まれました。

概念の説明：リテラル型は汎用型（string、number）の具体的な値です。例えば"up" 是 stringのサブタイプであり、代入できるのは特定の文字列のみです。

文字列リテラル型

文字列リテラル型は、変数の値を特定の文字列に制限します。

これは、変数を特定の固定値のみに制限する必要がある場合に非常に役立ちます。

例

// 文字列リテラル型を定義
// direction は4つの特定の値のいずれかでなければならない
var direction: "up" | "down" | "left" | "right";

// 正しい：リテラル型の値を代入
direction = "up";

// エラー：リストにない値を代入
// direction = "upup"; // コンパイルエラー！

console.log("方向: " + direction);

// 型エイリアスを使って再利用可能なリテラル型を作成
// 状態型を定義：3つの固定値のいずれかでなければならない
type Status = "pending" | "active" | "completed";

// 型エイリアスを使用
var currentStatus: Status = "active";
console.log("状態: " + currentStatus);

実行結果：

方向: up
状态: active

適用場面：文字列リテラルは、列挙値、ステータスコード、設定オプションなど、特定の値に制限する必要がある場面でよく使用されます。

数値リテラル型

数値リテラル型は、変数の値を特定の数値に制限します。

これは、特定の数値（ステータスコード、エラーコードなど）を使用する必要がある場合に非常に役立ちます。

例

// 数値リテラル型を定義
// code は3つの特定の値のいずれかでなければならない
var code: 200 | 404 | 500;

// 正しい：200 を代入
code = 200;

// エラー：リストにない値を代入
// code = 301; // コンパイルエラー！

console.log("ステータスコード: " + code);

// 数値リテラルを使って列挙型を模倣
// 1週間の日数を定義
type Weekday = 1 | 2 | 3 | 4 | 5 | 6 | 7;

// 1〜7の間の数値のみ代入できる
var today: Weekday = 1;
console.log("今日は曜日: " + today);

説明：数値リテラルは、特に少数の固定値だけが必要な場合に、単純な列挙型（enum）の代わりとして使用できます。

ブールリテラル型

ブールリテラル型は、変数の値を true または false に制限します。

実際、TypeScript の boolean 型は true | false のエイリアスです。

例

// ブールリテラル型を定義
// isActive は true または false のみ
var isActive: true | false;

// true を代入
isActive = true;

// 実際、boolean は true | false のユニオン型
// したがって、この2つの書き方は等価
var flag: boolean = true;

console.log("アクティブか: " + isActive);

ヒント：boolean 自体で十分な場合もありますが、true と false の型を明確に区別する必要がある場合は、true または false を型として使用できます。

オブジェクトリテラル型

オブジェクトリテラル型はオブジェクトの構造を定義でき、readonly 修飾子を使ってプロパティを読み取り専用にできます。

これは、不変オブジェクトを作成する必要がある場合に非常に役立ちます。

例

// オブジェクトリテラル型を定義
// オブジェクトの構造とプロパティの型を指定
type Point = {
    // 点の x 座標
    x: number;
    // 点の y 座標
    y: number;
};

// オブジェクトリテラル型を使用
var p: Point = { x: 10, y: 20 };
console.log("点: " + JSON.stringify(p));

// 読み取り専用オブジェクト型を定義
// readonly 修飾子を使ってプロパティを読み取り専用にする
type ReadonlyPoint = {
    // 読み取り専用の x 座標
    readonly x: number;
    // 読み取り専用の y 座標
    readonly y: number;
};

// 読み取り専用オブジェクト型を使用
var rp: ReadonlyPoint = { x: 1, y: 2 };

// 読み取り専用プロパティを変更しようとするとエラーになる
// rp.x = 3; // コンパイルエラー：読み取り専用プロパティは変更できません

console.log("読み取り専用点: " + JSON.stringify(rp));

実行結果：

点: {"x":10,"y":20}
只读点: {"x":1,"y":2}

適用場面：読み取り専用オブジェクトは、設定オブジェクトや定数オブジェクトなど、変更されることを望まないデータを定義する際によく使用されます。

リテラル型と型推論

TypeScript は変数の宣言方法に応じて、リテラル型を自動的に推論します。

const で宣言された変数は、広範な型ではなく、具体的なリテラル型として推論されます。

例

// var で宣言して代入
// TypeScript は広範な型として推論する
var name = "Alice";    // 型: string（var は再代入できるため）
var age = 25;          // 型: number
var enabled = true;    // 型: boolean

console.log("名前: " + name + ", 年齢: " + age + ", 有効: " + enabled);

// as const を使って深い読み取り専用リテラルを作成
// 配列は読み取り専用タプルになり、値はリテラル型
var colors = ["red", "green", "blue"] as const;

// colors の型は次のようになる：
// readonly ["red", "green", "blue"]

// 配列要素にアクセス
console.log("色: " + colors[0]);

// 変更しようとするとエラーになる
// colors

説明：as const型を最も具体的なリテラル型として推論し、readonly 修飾子を追加します。

テンプレートリテラル型

テンプレートリテラル型は、JavaScript のテンプレート文字列の構文を使用して新しい型を作成します。

これにより、文字列型を動的に生成できます。

例

// テンプレートリテラル型を使ってイベント名を定義
// `on${string}` は "on" で始まる任意の文字列を表す
type EventName = `on${string}`;

// テンプレートリテラル型を使ってハンドラー名を定義
// Capitalize は文字列の先頭文字を大文字にする
type Handler = `handle${Capitalize<string>}`;

// テンプレートリテラル型を使用
var event: EventName = "onClick";
var handler: Handler = "handleSubmit";

console.log("イベント: " + event);
console.log("ハンドラー: " + handler);

// 错误：不符合模板格式
// var e: EventName = "click"; // 编译错误：不是以 "on" 开头

运行结果：

事件: onClick
处理器: handleSubmit

内置工具类型：模板字面量类型可以配合 Uppercase、Lowercase、Capitalize、Uncapitalize 等内置工具类型使用。

実践応用：Redux Action

字面量类型在实际开发中有广泛的应用。

下面展示如何使用字面量类型实现 Redux 风格的行为（Action）。

例

// 定义 Redux 风格的 Action 类型
// 使用联合类型定义不同类型的 Action
type Action =
    // 增加类型的 Action，包含数字类型的 payload
    | { type: "increment"; payload: number }
    // 减少类型的 Action，包含数字类型的 payload
    | { type: "decrement"; payload: number }
    // 重置类型的 Action，没有 payload
    | { type: "reset" };

// 使用 action 的 reducer 函数
function reducer(action: Action): void {
    // TypeScript 会根据 action.type 的值自动推断 action 的具体类型
    switch (action.type) {
        case "increment":
            // 在这个分支中，action 被推断为 { type: "increment"; payload: number }
            console.log("增加: " + action.payload);
            break;
        case "decrement":
            // 在这个分支中，action 被推断为 { type: "decrement"; payload: number }
            console.log("减少: " + action.payload);
            break;
        case "reset":
            // 在这个分支中，action 被推断为 { type: "reset" }
            console.log("重置");
            break;
    }
}

// 派发不同类型的 Action
reducer({ type: "increment", payload: 5 });
reducer({ type: "reset" });

运行结果：

增加: 5
重置

可辨识联合：这种模式叫做"可辨识联合"（Discriminated Union），是 TypeScript 中处理多种相关类型的最佳实践。

注意事項

  • 类型收窄：使用 switch 或 if 判断时，TypeScript 会自动收窄字面量类型
  • 类型别名：建议使用 type 别名为常用的字面量类型创建别名
  • const 推断：const 声明的变量会自动推断为字面量类型
  • as const：需要深度只读时使用 as const

最佳实践：在需要限制变量只能取特定值时，优先使用字面量类型而不是枚举。

まとめ

字面量类型是 TypeScript 实现精确类型控制的重要特性。

  • 字符串字面量：限制为特定字符串，如"up" | "down"
  • 数字字面量：限制为特定数字，如1 | 2 | 3
  • 布尔字面量：限制为 true 或 false
  • 对象字面量：定义对象结构，可使用 readonly
  • as const：创建深度只读字面量类型
  • 模板字面量：使用模板字符串动态生成类型

进阶：字面量类型与可辨识联合模式结合，可以实现强大的类型安全。
