TypeScript 演算子

演算子はプログラムコードの演算を実行するために使用され、1つ以上のオペランド項目に対して演算を行います。

次の計算を考えてみましょう：

7 + 5 = 12

上記の例では、7、5、12 はオペランドです。

演算子+加算に使用します。

演算子=代入に使用します。

TypeScript には主に以下の演算が含まれます：

  • 算術演算子
  • 論理演算子
  • 関係演算子
  • ビット演算子
  • 代入演算子
  • 三項/条件演算子
  • 文字列演算子
  • 型演算子

算術演算子

仮定しますy=5以下の表は、これらの算術演算子の操作を説明しています：

演算子 説明 例 x の演算結果 y の演算結果
+ 加算 x=y+2 7 5
- 減算 x=y-2 3 5
* 乗算 x=y*2 10 5
/ 除算 x=y/2 2.5 5
% 剰余（余り） x=y%2 1 5
++ インクリメント x=++y 6 6
x=y++ 5 6
-- デクリメント x=--y 4 4
x=y-- 5 4

例

var num1:number = 10
var num2:number = 2
var res:number = 0
   
res = num1 + num2
console.log("加算: "+res);

res = num1 - num2;
console.log("減算: "+res)

res = num1*num2
console.log("乗算: "+res)

res = num1/num2
console.log("除算: "+res)
   
res = num1%num2
console.log("余り: "+res)

num1++
console.log("num1 インクリメント演算: "+num1)

num2--
console.log("num2 デクリメント演算: "+num2)

使用してtscコマンドで上記のコードをコンパイルすると、次の JavaScript コードが得られます：

var num1 = 10; var num2 = 2; var res = 0; res = num1 + num2; console.log("加算:" + res); res = num1 - num2; console.log("減算:" + res); res = num1 * num2; console.log("乗算:" + res); res = num1 / num2; console.log("除算:" + res); res = num1 % num2; console.log("余り:" + res); num1++; console.log("num1 インクリメント演算:" + num1); num2--; console.log("num2 デクリメント演算:" + num2);

上記の JavaScript コードを実行すると、出力結果は次のようになります：

加:        12
减: 8
乘:    20
除:   5
余数:   0
num1 自增运算: 11
num2 自减运算: 1

関係演算子

関係演算子は、計算結果が true か false かを判定するために使用されます。

x=5 の場合、以下の表は関係演算子の操作を説明しています：

演算子 説明 比較 戻り値
== 等しい x==8 false
x==5 true
!= 等しくない x!=8 true
> より大きい x>8 false
< より小さい x<8 true
>= 以上 x>=8 false
<= 以下 x<=8 true

例

var num1:number = 5; var num2:number = 9; console.log("num1 の値:"+num1); console.log("num2 の値:"+num2); var res = num1>num2 console.log("num1 は num2 より大きい:"+res) res = num1<num2 console.log("num1 は num2 より小さい:"+res) res = num1>=num2 console.log("num1 は num2 以上:"+res) res = num1<=num2 console.log("num1 は num2 以下:"+res) res = num1==num2 console.log("num1 は num2 と等しい:"+res) res = num1!=num2 console.log("num1 は num2 と等しくない:"+res)

使用してtscコマンドで上記のコードをコンパイルすると、次の JavaScript コードが得られます：

var num1 = 5; var num2 = 9; console.log("num1 の値:" + num1); console.log("num2 の値:" + num2); var res = num1 > num2; console.log("num1 は num2 より大きい:" + res); res = num1 < num2; console.log("num1 は num2 より小さい:" + res); res = num1 >= num2; console.log("num1 は num2 以上:" + res); res = num1 <= num2; console.log("num1 は num2 以下:" + res); res = num1 == num2; console.log("num1 は num2 と等しい:" + res); res = num1 != num2; console.log("num1 は num2 と等しくない:" + res);

上記の JavaScript コードを実行すると、出力結果は次のようになります：

num1 的值为: 5
num2 的值为:9
num1 大于n num2: false
num1 小于 num2: true
num1 大于或等于  num2: false
num1 小于或等于 num2: true
num1 等于 num2: false
num1 不等于 num2: true

論理演算子

論理演算子は、変数や値の間の論理を判定するために使用されます。

x=6 および y=3 の場合、以下の表は論理演算子を説明しています：

演算子 説明 例
&& and (x < 10 && y > 1) は true
|| or (x==5 || y==5) は false
! not !(x==y) は true

例

var avg:number = 20; var percentage:number = 90; console.log("avg の値:"+avg+"、percentage の値:"+percentage); var res:boolean = ((avg>50)&&(percentage>80)); console.log("(avg>50)&&(percentage>80): ",res); var res:boolean = ((avg>50)||(percentage>80)); console.log("(avg>50)||(percentage>80): ",res); var res:boolean=!((avg>50)&&(percentage>80)); console.log("!((avg>50)&&(percentage>80)): ",res);

使用してtscコマンドで上記のコードをコンパイルすると、次の JavaScript コードが得られます：

var avg = 20; var percentage = 90; console.log("avg の値:" + avg + "、percentage の値:" + percentage); var res = ((avg > 50) && (percentage > 80)); console.log("(avg>50)&&(percentage>80): ", res); var res = ((avg > 50) || (percentage > 80)); console.log("(avg>50)||(percentage>80): ", res); var res = !((avg > 50) && (percentage > 80)); console.log("!((avg>50)&&(percentage>80)): ", res);

上記の JavaScript コードを実行すると、出力結果は次のようになります：

avg 值为: 20 ,percentage 值为: 90
(avg>50)&&(percentage>80):  false
(avg>50)||(percentage>80):  true
!((avg>50)&&(percentage>80)):  true

短絡演算子（&& と ||）

&& と || 演算子は式を組み合わせるために使用できます。 && 演算子は、左右の式が両方とも true の場合にのみ true を返します。

次の例を考えてみましょう：

var a = 10 
var result = ( a<10 && a>5)

上記の例では、a < 10 と a > 5 は && 演算子を使用した組み合わせ式です。最初の式が false を返したため、&& 演算は両方の式が true である必要があるので、最初が false の場合、後続の判定（a > 5 の計算はスキップ）を実行せず、直接 false を返します。

|| 演算子は、いずれか一方の式が true であれば、その組み合わせ式は true を返します。

次の例を考えてみましょう：

var a = 10 
var result = ( a>5 || a<10)

上記の例では、a > 5 と a < 10 は || 演算子を使用した組み合わせ式です。最初の式が true を返したため、|| 組み合わせ演算は1つの式が true であればよいので、最初が true の場合、後続の判定（a < 10 の計算はスキップ）を実行せず、直接 true を返します。

ビット演算子

ビット操作は、プログラミングにおいてビットパターンまたは2進数に対するビット単位の単項および二項演算です。


演算子 説明 例 類似 結果 10進数
& AND（ビット単位AND）は、同じ長さの2つの2進数を処理し、対応する2つのビットが両方とも1の場合のみ、そのビットの結果が1になり、それ以外は0になります。 x = 5 & 1 0101 & 0001 0001  1
| OR（ビット単位OR）は、同じ長さの2つの2進数を処理し、対応する2つのビットのいずれかが1であれば、そのビットの結果は1になります。 x = 5 | 1 0101 | 0001 0101  5
~ 否定（NOT）は単項演算子で、2進数の各ビットに対して論理否定演算を実行します。1 を 0 に、0 を 1 にします。 x = ~ 5  ~0101 1010  -6
^ 排他的論理和（XOR）は、同じ長さの2進数パターンまたは2進数の各ビットに対して論理XOR演算を実行します。演算の結果、ビットが異なればそのビットは1、同じなら0になります。 x = 5 ^ 1 0101 ^ 0001 0100  4
<< 左シフト（<<）は、<< の左のオペランドの各ビットをすべて左に指定ビット数だけシフトします。シフト数は << の右の数で指定され、上位ビットは捨てられ、下位ビットには0が詰められます。 x = 5 << 1 0101 << 1 1010  10
>> 右シフト（>>）は、>> の左のオペランドの各ビットをすべて右に指定ビット数だけシフトします。>> の右の数がシフトするビット数を指定します。 x = 5 >> 1 0101 >> 1 0010 2
>>> 符号なし右シフトは、符号付き右シフトと似ていますが、左側は常に0で埋められます。 x = 2 >>> 1 0010 >>> 1 0001 1

例

var a:number = 2; //2進数の10 var b:number = 3; //2進数の11 var result; result = (a & b); console.log("(a & b) => ",result) result = (a | b); console.log("(a | b) => ",result) result = (a ^ b); console.log("(a ^ b) => ",result); result = (~b); console.log("(~b) => ",result); result = (a << b); console.log("(a << b) => ",result); result = (a >> b); console.log("(a >> b) => ",result); result = (a >>> 1); console.log("(a >>> 1) => ",result);

使用してtscコマンドで上記のコードをコンパイルすると、次の JavaScript コードが得られます：

var a = 2; //2進数の10 var b = 3; //2進数の11 var result; result = (a & b); console.log("(a & b) => ", result); result = (a | b); console.log("(a | b) => ", result); result = (a ^ b); console.log("(a ^ b) => ", result); result = (~b); console.log("(~b) => ", result); result = (a << b); console.log("(a << b) => ", result); result = (a >> b); console.log("(a >> b) => ", result); result = (a >>> 1); console.log("(a >>> 1) => ", result);

上記の JavaScript コードを実行すると、出力結果は次のようになります：

(a & b) =>  2
(a | b) =>  3
(a ^ b) =>  1
(~b) =>  -4
(a << b) =>  16
(a >> b) =>  0
(a >>> 1) =>  1

代入演算子

代入演算子は、変数に値を代入するために使用されます。

指定しますx=10 和 y=5以下の表は代入演算子を説明しています：

演算子 例 例 x の値
= (代入) x = y x = y x = 5
+= (加算してから代入) x += y x = x + y x = 15
-= (減算してから代入) x -= y x = x - y x = 5
*= (乗算してから代入) x *= y x = x * y x = 50
/= (除算してから代入) x /= y x = x / y x = 2

同様に、論理演算子も代入演算子と組み合わせて使用できます：<<=, >>=, >>>=, &=, |= 与 ^=。

例

var a: number = 12 var b:number = 10 a = b console.log("a = b: "+a) a += b console.log("a+=b: "+a) a -= b console.log("a-=b: "+a) a *= b console.log("a*=b: "+a) a /= b console.log("a/=b: "+a) a %= b console.log("a%=b: "+a)

使用してtscコマンドで上記のコードをコンパイルすると、次の JavaScript コードが得られます：

var a = 12; var b = 10; a = b; console.log("a = b: " + a); a += b; console.log("a+=b: " + a); a -= b; console.log("a-=b: " + a); a *= b; console.log("a*=b: " + a); a /= b; console.log("a/=b: " + a); a %= b; console.log("a%=b: " + a);

上記のJavaScriptコードを実行すると、出力結果は次のようになります。

a = b: 10
a+=b: 20
a-=b: 10
a*=b: 100
a/=b: 10
a%=b: 0

三項演算子 (?)

三項演算には3つのオペランドがあり、ブール式の値を評価する必要があります。この演算子は主に、どの値を変数に代入するかを決定します。

Test ? expr1 : expr2
  • Test − 指定された条件文
  • expr1 − 条件文Testがtrueを返す場合に返される値
  • expr2 − 条件文Testがfalseを返す場合に返される値

以下の例を見てみましょう。

var num:number = -2 var result = num > 0 ? "0より大きい" : "0より小さい、または0に等しい" console.log(result)

この例では、変数が0より大きいかどうかを判定しています。

tscコマンドを使用して上記のコードをコンパイルすると、次のようなJavaScriptコードが得られます。

var num = -2; var result = num > 0 ? "0より大きい" : "0より小さい、または0に等しい"; console.log(result);

上記の例の出力結果は次の通りです。

小于 0，或等于 0

var num = 12; console.log(typeof num); //出力結果: number

上記の例の出力結果は次の通りです。

number
