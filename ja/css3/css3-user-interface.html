CSS3 ユーザーインターフェース

CSS3では、要素のサイズ、ボックスサイズ、および外枠線を調整するための新しいユーザーインターフェース機能がいくつか追加されました。

この章では、以下のユーザーインターフェースプロパティについて学習します：

  • resize
  • box-sizing
  • outline-offset

ブラウザサポート

表内の数字は、そのプロパティをサポートする最初のブラウザバージョン番号を示します。

-webkit-、-ms- または -moz- の直前にある数字は、その接頭辞付きプロパティをサポートする最初のブラウザバージョン番号です。

CSS3 リサイズ(Resizing)

CSS3では、resizeプロパティは、要素をユーザーがリサイズできるかどうかを指定します。

この div 要素はユーザーがサイズを調整できます。(Firefox 4+、Chrome、Safari の場合)

CSSコードは次のとおりです：

例

ユーザーがdiv要素のサイズを指定します：

div { resize:both; overflow:auto; }

CSS3 ボックスサイズ調整(Box Sizing)

box-sizing プロパティを使用すると、特定の領域に適合する具体的な内容を正確な方法で定義できます。

例

枠線付きの2つのボックスを並べて指定します：

div { box-sizing:border-box; -moz-box-sizing:border-box; /* Firefox */ width:50%; float:left; }

CSS3 アウトラインオフセット（outline-offset）

outline-offset プロパティはアウトラインをオフセットし、枠線の端を超えた位置にアウトラインを描画します。

アウトラインと枠線には2つの違いがあります：

  • アウトラインはスペースを占有しません
  • アウトラインは非矩形の場合があります
この div は枠線の外側 15 ピクセルの位置にアウトラインがあります。

CSSコードは次のとおりです：

例

枠線の端から15ピクセル外側のアウトラインを指定します：

div { border:2px solid black; outline:2px solid red; outline-offset:15px; }

    resize プロパティは、ユーザーが要素のサイズを引き伸ばすことで、はみ出して隠れた内容を表示できるように指定します。効果は <textarea></textarea> テキストエリアタグに似ています。

    <textarea> タグにはデフォルトで resize: both; が付いていると言えます。したがって、resize: none; を設定することで <textarea> のサイズが引き伸ばされるのを防ぐことができます。

    ただし、注目すべきはオーバーフローの設定です：

    1. overflow: hidden; の場合、サイズを引き伸ばすかどうかに関わらず、サイズを超えた内容は非表示になり切り取られます；

    2. overflow: scroll; の場合、サイズを引き伸ばすかどうかに関わらず、要素は常にスクロールバーを表示します；

    3. overflow: auto; の場合、サイズが内容の表示より小さい場合にのみスクロールバーが表示されます。これは最も美しい設定と言えます（<textarea> にもこのプロパティがデフォルトで設定されています）；

    ----------------------------------------------------------------------------------------------------

    outline-offset プロパティは、アウトライン（外枠線）と枠線（内枠線）の間の間隔、つまり「パディング」を設定するために使用します。デフォルトでは、アウトラインは枠線にぴったりとくっついているため、このプロパティを使用してそれらを分離する必要があります。

    outline は要素の幅と高さを壊しません。同様に、outline-offset で設定された間隔も要素の幅と高さに影響しません。

    ----------------------------------------------------------------------------------------------------

    box-sizing は、ブラウザにどのボックスモデルを使用してドキュメントをレンダリングするかを指示します。

    content-box はデフォルトのボックスモデル、つまりW3C標準ボックスモデルです。現在、IEを含むすべての主要ブラウザがこのモデルをサポートし、レイアウトのレンダリングに使用しています。しかし、面倒なことはたくさんあります。なぜなら、このモデルでは、borderとpaddingの設定が要素のサイズを壊してしまい、最終的に表示されるレイアウト効果が理想どおりにならず、理想的な効果を得たい場合は幅と高さを計算する必要があり、非常に面倒だからです。

    （他のプロパティは標準に近いほど使いやすいですが、このプロパティは逆にIE標準に合わせたものです）

    一方、border-box はIEボックスモデルを指し、「変則ボックスモデル」とも呼ばれます。このモデルでは、枠線とパディングは要素の幅と高さに影響しません。つまり、要素のスペースを自分のスペースとして占有し、要素の全体サイズは変わらず、コンテンツスペースは小さくなり、枠線とパディングが元々コンテンツスペースだった場所を占有します。これは通常のレイアウト設計時に非常に便利です。要素のサイズを指定してこのプロパティ値を設定すると、要素のサイズが壊れて再計算する必要がなくなるからです。

    例：

    <div class="box left"></div>
    <div class="box right"></div>
