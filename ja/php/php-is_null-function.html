PHP is_null() 関数

PHP で利用可能な関数

is_null()関数は、変数が NULL かどうかを検出するために使用されます。

PHP バージョン要件: PHP 4 >= 4.0.4, PHP 5, PHP 7

構文

bool is_null ( mixed $var )

パラメータの説明：

  • $var: 検出する変数。

戻り値

指定した変数が NULL の場合は TRUE を返し、それ以外の場合は FALSE を返します。

例

例

<?php $var_name = TRUE; $var_name2 = NULL; if (is_null($var_name)) { echo '変数 var_name は NULL です' . PHP_EOL; } else { echo '変数 var_name は NULL ではありません' . PHP_EOL; } if (is_null($var_name2)) { echo '変数 var_name2 は NULL です' . PHP_EOL; } else { echo '変数 var_name2 は NULL ではありません' . PHP_EOL; } ?>

出力結果は：

变量 var_name 不为 NULL
变量 var_name2 为 NULL
