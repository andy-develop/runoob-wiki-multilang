MySQL 関数

MySQL には多くの組み込み関数があります。以下にこれらの関数の説明を示します。

MySQL 文字列関数

関数 説明 例
ASCII(s) 文字列 s の最初の文字の ASCII コードを返します。

CustomerName フィールドの最初の文字の ASCII コードを返します：

SELECT ASCII(CustomerName) AS NumCodeOfFirstChar
FROM Customers;
CHAR_LENGTH(s) 文字列 s の文字数を返します

文字列 RUNOOB の文字数を返します

SELECT CHAR_LENGTH("RUNOOB") AS LengthOfString;
CHARACTER_LENGTH(s) 文字列 s の文字数を返します。CHAR_LENGTH(s) と同じです。

文字列 RUNOOB の文字数を返します

SELECT CHARACTER_LENGTH("RUNOOB") AS LengthOfString;
CONCAT(s1,s2...sn) 文字列 s1, s2 などの複数の文字列を1つの文字列に結合します

複数の文字列を結合します

SELECT CONCAT("SQL ", "Runoob ", "Gooogle ", "Facebook") AS ConcatenatedString;
CONCAT_WS(x, s1,s2...sn) CONCAT(s1,s2,...) 関数と同じですが、各文字列の間に x を追加します。x は区切り文字にできます。

複数の文字列を結合し、区切り文字を追加します：

SELECT CONCAT_WS("-", "SQL", "Tutorial", "is", "fun!")AS ConcatenatedString;
FIELD(s,s1,s2...) 文字列 s が文字列リスト (s1,s2...) 内にある位置を返します

文字列 c がリスト値内にある位置を返します：

SELECT FIELD("c", "a", "b", "c", "d", "e");
FIND_IN_SET(s1,s2) 文字列 s2 内で s1 に一致する文字列の位置を返します

指定された文字列内での文字列 c の位置を返します：

SELECT FIND_IN_SET("c", "a,b,c,d,e");
FORMAT(x,n) 関数は数値 x を "#,###.##" の形式にフォーマットし、x を小数点以下 n 桁に保ち、最後の桁を四捨五入します。

数値を "#,###.##" 形式でフォーマットします：

SELECT FORMAT(250500.5634, 2);     -- 输出 250,500.56
INSERT(s1,x,len,s2) 文字列 s2 は、s1 の x 位置から始まる長さ len の文字列を置き換えます。

文字列の最初の位置から始まる6文字を runoob に置き換えます：

SELECT INSERT("google.com", 1, 6, "runoob");  -- 输出：runoob.com
LOCATE(s1,s) 文字列 s 内で s1 の開始位置を取得します

文字列 abc 内での b の位置を取得します：

SELECT LOCATE('st','myteststring');  -- 5

文字列 abc 内の b の位置を返します：

SELECT LOCATE('b', 'abc') -- 2
LCASE(s) 文字列 s のすべての文字を小文字に変換します

文字列 RUNOOB を小文字に変換します：

SELECT LCASE('RUNOOB') -- runoob
LEFT(s,n) 文字列 s の最初の n 文字を返します

文字列 runoob の最初の2文字を返します：

SELECT LEFT('runoob',2) -- ru
LOWER(s) 文字列 s のすべての文字を小文字に変換します

文字列 RUNOOB を小文字に変換します：

SELECT LOWER('RUNOOB') -- runoob
LPAD(s1,len,s2) 文字列 s1 の先頭に文字列 s2 を埋めて、文字列の長さを len にします

文字列 xx を文字列 abc の先頭に埋めます：

SELECT LPAD('abc',5,'xx') -- xxabc
LTRIM(s) 文字列 s の先頭のスペースを削除します

文字列 RUNOOB の先頭のスペースを削除します：

SELECT LTRIM("    RUNOOB") AS LeftTrimmedString;-- RUNOOB
MID(s,n,len) 文字列 s の n 位置から長さ len の部分文字列を切り出します。SUBSTRING(s,n,len) と同じです。

文字列 RUNOOB の2番目の位置から3文字を切り出します：

SELECT MID("RUNOOB", 2, 3) AS ExtractString; -- UNO
POSITION(s1 IN s) 文字列 s 内で s1 の開始位置を取得します

文字列 abc 内の b の位置を返します：

SELECT POSITION('b' in 'abc') -- 2
REPEAT(s,n) 文字列 s を n 回繰り返します

文字列 runoob を3回繰り返します：

SELECT REPEAT('runoob',3) -- runoobrunoobrunoob
REPLACE(s,s1,s2) 文字列 s 内の文字列 s1 を文字列 s2 で置き換えます

文字列 abc 内の文字 a を文字 x に置き換えます：

SELECT REPLACE('abc','a','x') --xbc
REVERSE(s) 文字列 s の順序を逆にします

文字列 abc の順序を逆にします：

SELECT REVERSE('abc') -- cba
RIGHT(s,n) 文字列 s の最後の n 文字を返します

文字列 runoob の最後の2文字を返します：

SELECT RIGHT('runoob',2) -- ob
RPAD(s1,len,s2) 文字列 s1 の末尾に文字列 s2 を追加して、文字列の長さを len にします

文字列 xx を文字列 abc の末尾に埋めます：

SELECT RPAD('abc',5,'xx') -- abcxx
RTRIM(s) 文字列 s の末尾のスペースを削除します

文字列 RUNOOB の末尾のスペースを削除します：

SELECT RTRIM("RUNOOB     ") AS RightTrimmedString;   -- RUNOOB
SPACE(n) n 個のスペースを返します

10個のスペースを返します：

SELECT SPACE(10);
STRCMP(s1,s2) 文字列 s1 と s2 を比較し、s1 と s2 が等しい場合は 0 を返し、s1>s2 の場合は 1 を返し、s1<s2 の場合は -1 を返します

文字列を比較します：

SELECT STRCMP("runoob", "runoob");  -- 0
SUBSTR(s, start, length) 文字列 s の start 位置から長さ length の部分文字列を切り出します

文字列 RUNOOB の2番目の位置から3文字を切り出します：

SELECT SUBSTR("RUNOOB", 2, 3) AS ExtractString; -- UNO
SUBSTRING(s, start, length) 文字列 s の start 位置から長さ length の部分文字列を切り出します。SUBSTR(s, start, length) と同じです。

文字列 RUNOOB の2番目の位置から3文字を切り出します：

SELECT SUBSTRING("RUNOOB", 2, 3) AS ExtractString; -- UNO
SUBSTRING_INDEX(s, delimiter, number) 文字列 s 内の number 番目に出現する区切り文字 delimiter の後の部分文字列を返します。
number が正の場合は、number 番目の区切り文字の左側の文字列を返します。
number が負の場合は、number の絶対値（右から数えた）番目の区切り文字の右側の文字列を返します。		 
SELECT SUBSTRING_INDEX('a*b','*',1) -- a
SELECT SUBSTRING_INDEX('a*b','*',-1)    -- b
SELECT SUBSTRING_INDEX(SUBSTRING_INDEX('a*b*c*d*e','*',3),'*',-1)    -- c
TRIM(s) 文字列 s の先頭と末尾のスペースを削除します

文字列 RUNOOB の先頭と末尾のスペースを削除します：

SELECT TRIM('    RUNOOB    ') AS TrimmedString;
UCASE(s) 文字列を大文字に変換します

文字列 runoob を大文字に変換します：

SELECT UCASE("runoob"); -- RUNOOB
UPPER(s) 文字列を大文字に変換します

文字列 runoob を大文字に変換します：

SELECT UPPER("runoob"); -- RUNOOB

MySQL 数値関数

関数名 説明 例
ABS(x) x の絶対値を返します

-1 の絶対値を返します：

SELECT ABS(-1) -- 返回1
ACOS(x) x の逆余弦を求めます（単位はラジアン）。x は数値です。 
SELECT ACOS(0.25);
ASIN(x) 逆正弦を求めます（単位はラジアン）。x は数値です。 
SELECT ASIN(0.25);
ATAN(x) 逆正接を求めます（単位はラジアン）。x は数値です。 
SELECT ATAN(2.5);
ATAN2(n, m) 逆正接を求めます（単位はラジアン） 
SELECT ATAN2(-0.8, 2);
AVG(expression) 式の平均値を返します。expression はフィールドです。

Products テーブルの Price フィールドの平均値を返します：

SELECT AVG(Price) AS AveragePrice FROM Products;
CEIL(x) x 以上で最小の整数を返します 
SELECT CEIL(1.5) -- 返回2
CEILING(x) x 以上で最小の整数を返します 
SELECT CEILING(1.5); -- 返回2
COS(x) 余弦を求めます（引数はラジアン） 
SELECT COS(2);
COT(x) 余接（コタンジェント）を求めます（引数はラジアン） 
SELECT COT(6);
COUNT(expression) クエリのレコード総数を返します。expression パラメータはフィールドまたは * です。

Products テーブルの products フィールドに全部で何件のレコードがあるかを返します：

SELECT COUNT(ProductID) AS NumberOfProducts FROM Products;
DEGREES(x) ラジアンを度に変換します 
SELECT DEGREES(3.1415926535898) -- 180
n DIV m 整数除算、n は被除数、m は除数

10 を 5 で割った計算：

SELECT 10 DIV 5;  -- 2
EXP(x) e の x 乗を返します

e の3乗を計算します：

SELECT EXP(3) -- 20.085536923188
FLOOR(x) x 以下で最大の整数を返します

1.5 以下の整数：

SELECT FLOOR(1.5) -- 返回1
GREATEST(expr1, expr2, expr3, ...) リスト内の最大値を返します

次の数値リストの最大値を返します：

SELECT GREATEST(3, 12, 34, 8, 25); -- 34

次の文字列リストの最大値を返します：

SELECT GREATEST("Google", "Runoob", "Apple");   -- Runoob
LEAST(expr1, expr2, expr3, ...) リスト内の最小値を返します

次の数値リストの最小値を返します：

SELECT LEAST(3, 12, 34, 8, 25); -- 3

次の文字列リストの最小値を返します：

SELECT LEAST("Google", "Runoob", "Apple");   -- Apple
LN 数値の自然対数（底を e とする）を返します。

2 の自然対数を返します：

SELECT LN(2);  -- 0.6931471805599453
LOG(x) または LOG(base, x) 自然対数（底を e とする対数）を返します。base パラメータを指定する場合は、base が指定された底になります。 
SELECT LOG(20.085536923188) -- 3
SELECT LOG(2, 4); -- 2
LOG10(x) 底を 10 とする対数を返します 
SELECT LOG10(100) -- 2
LOG2(x) 底を 2 とする対数を返します

底を 2 とする 6 の対数を返します：

SELECT LOG2(6);  -- 2.584962500721156
MAX(expression) フィールド expression 内の最大値を返します

データテーブル Products のフィールド Price の最大値を返します：

SELECT MAX(Price) AS LargestPrice FROM Products;
MIN(expression) フィールド expression 内の最小値を返します

データテーブル Products のフィールド Price の最小値を返します：

SELECT MIN(Price) AS MinPrice FROM Products;
MOD(x,y) x を y で割った余りを返します

5 を 2 で割った余り：

SELECT MOD(5,2) -- 1
PI() 円周率（3.141593）を返します 
SELECT PI() --3.141593
POW(x,y) x の y 乗を返します

2 の 3 乗：

SELECT POW(2,3) -- 8
POWER(x,y) x の y 乗を返します

2 の 3 乗：

SELECT POWER(2,3) -- 8
RADIANS(x) 度をラジアンに変換します

180 度をラジアンに変換します：

SELECT RADIANS(180) -- 3.1415926535898
RAND() 0 から 1 の乱数を返します 
SELECT RAND() --0.93099315644334
ROUND(x [,y]) x に最も近い整数を返します。オプションのパラメータ y は四捨五入する小数桁数を示します。省略した場合は整数を返します。 
SELECT ROUND(1.23456) --1

SELECT ROUND(345.156, 2) -- 345.16
SIGN(x) x の符号を返します。x が負の数、0、正の数の場合、それぞれ -1、0、1 を返します。 
SELECT SIGN(-10) -- (-1)
SIN(x) サイン値を求める（引数はラジアン） 
SELECT SIN(RADIANS(30)) -- 0.5
SQRT(x) xの平方根を返す

25の平方根：

SELECT SQRT(25) -- 5
SUM(expression) 指定したフィールドの合計を返す

OrderDetails テーブルの Quantity フィールドの合計を計算する：

SELECT SUM(Quantity) AS TotalItemsOrdered FROM OrderDetails;
TAN(x) タンジェント値を求める（引数はラジアン） 
SELECT TAN(1.75);  -- -5.52037992250933
TRUNCATE(x,y) 数値 x を小数点以下 y 桁に保持した値を返す（ROUND との最大の違いは四捨五入を行わないことです） 
SELECT TRUNCATE(1.23456,3) -- 1.234

MySQL 日付関数

関数名 説明 例
ADDDATE(d,n) 開始日 d に n 日加算した日付を計算する 
SELECT ADDDATE("2017-06-15", INTERVAL 10 DAY);
->2017-06-25
ADDTIME(t,n) n は時間式で、時間 t に時間式 n を加算する

5秒加算：

SELECT ADDTIME('2011-11-11 11:11:11', 5);
->2011-11-11 11:11:16 (秒)

2時間、10分、5秒を追加：

SELECT ADDTIME("2020-06-15 09:34:21", "2:10:5"); 
-> 2020-06-15 11:44:26
CURDATE() 現在の日付を返す 
SELECT CURDATE();
-> 2018-09-19
CURRENT_DATE() 現在の日付を返す 
SELECT CURRENT_DATE();
-> 2018-09-19
CURRENT_TIME 現在の時刻を返す 
SELECT CURRENT_TIME();
-> 19:59:02
CURRENT_TIMESTAMP() 現在の日付と時刻を返す 
SELECT CURRENT_TIMESTAMP()
-> 2018-09-19 20:57:43
CURTIME() 現在の時刻を返す 
SELECT CURTIME();
-> 19:59:02
DATE() 日付または日時式から日付値を抽出する 
SELECT DATE("2017-06-15");    
-> 2017-06-15
DATEDIFF(d1,d2) 日付 d1->d2 の間の日数を計算する 
SELECT DATEDIFF('2001-01-01','2001-02-02')
-> -32
DATE_ADD(d，INTERVAL expr type) 開始日 d に期間を加算した後の日付を計算する。type の値は次のとおり：
  • MICROSECOND
  • SECOND
  • MINUTE
  • HOUR
  • DAY
  • WEEK
  • MONTH
  • QUARTER
  • YEAR
  • SECOND_MICROSECOND
  • MINUTE_MICROSECOND
  • MINUTE_SECOND
  • HOUR_MICROSECOND
  • HOUR_SECOND
  • HOUR_MINUTE
  • DAY_MICROSECOND
  • DAY_SECOND
  • DAY_MINUTE
  • DAY_HOUR
  • YEAR_MONTH
 
SELECT DATE_ADD("2017-06-15", INTERVAL 10 DAY);    
-> 2017-06-25

SELECT DATE_ADD("2017-06-15 09:34:21", INTERVAL 15 MINUTE);
-> 2017-06-15 09:49:21

SELECT DATE_ADD("2017-06-15 09:34:21", INTERVAL -3 HOUR);
->2017-06-15 06:34:21

SELECT DATE_ADD("2017-06-15 09:34:21", INTERVAL -3 MONTH);
->2017-03-15 09:34:21
DATE_FORMAT(d,f) 式 f の要求に従って日付 d を表示する 
SELECT DATE_FORMAT('2011-11-11 11:11:11','%Y-%m-%d %r')
-> 2011-11-11 11:11:11 AM
DATE_SUB(date,INTERVAL expr type) 関数は日付から指定した時間間隔を減算します。

Orders テーブルの OrderDate フィールドから2日減算：

SELECT OrderId,DATE_SUB(OrderDate,INTERVAL 2 DAY) AS OrderPayDate
FROM Orders
DAY(d) 日付値 d の日付部分を返す 
SELECT DAY("2017-06-15");  
-> 15
DAYNAME(d) 日付 d が何曜日かを返す。例：Monday、Tuesday 
SELECT DAYNAME('2011-11-11 11:11:11')
->Friday
DAYOFMONTH(d) 日付 d がその月の何日目かを計算する 
SELECT DAYOFMONTH('2011-11-11 11:11:11')
->11
DAYOFWEEK(d) 日付 d が何曜日かを返す。1 は日曜日、2 は月曜日、以降同様 
SELECT DAYOFWEEK('2011-11-11 11:11:11')
->6
DAYOFYEAR(d) 日付 d がその年の何日目かを計算する 
SELECT DAYOFYEAR('2011-11-11 11:11:11')
->315
EXTRACT(type FROM d) 日付 d から指定した値を取得する。type が返す値を指定する。
type に指定できる値：
  • MICROSECOND
  • SECOND
  • MINUTE
  • HOUR
  • DAY
  • WEEK
  • MONTH
  • QUARTER
  • YEAR
  • SECOND_MICROSECOND
  • MINUTE_MICROSECOND
  • MINUTE_SECOND
  • HOUR_MICROSECOND
  • HOUR_SECOND
  • HOUR_MINUTE
  • DAY_MICROSECOND
  • DAY_SECOND
  • DAY_MINUTE
  • DAY_HOUR
  • YEAR_MONTH
 
SELECT EXTRACT(MINUTE FROM '2011-11-11 11:11:11') 
-> 11
FROM_DAYS(n) 0000年1月1日から n 日後の日付を計算する 
SELECT FROM_DAYS(1111)
-> 0003-01-16
HOUR(t) t の時間の値を返す 
SELECT HOUR('1:2:3')
-> 1
LAST_DAY(d) 指定された日付のその月の最終日を返す 
SELECT LAST_DAY("2017-06-20");
-> 2017-06-30
LOCALTIME() 現在の日付と時刻を返す 
SELECT LOCALTIME()
-> 2018-09-19 20:57:43
LOCALTIMESTAMP() 現在の日付と時刻を返す 
SELECT LOCALTIMESTAMP()
-> 2018-09-19 20:57:43
MAKEDATE(year, day-of-year) 指定されたパラメータの年 year とその年の日番号 day-of-year に基づいて日付を返す 
SELECT MAKEDATE(2017, 3);
-> 2017-01-03
MAKETIME(hour, minute, second) 時間を組み合わせる。パラメータはそれぞれ時、分、秒 
SELECT MAKETIME(11, 35, 4);
-> 11:35:04
MICROSECOND(date) 日付パラメータに対応するマイクロ秒数を返す 
SELECT MICROSECOND("2017-06-20 09:34:00.000023");
-> 23
MINUTE(t) t の分の値を返す 
SELECT MINUTE('1:2:3')
-> 2
MONTHNAME(d) 日付の月名を返す。例：November 
SELECT MONTHNAME('2011-11-11 11:11:11')
-> November
MONTH(d) 日付 d の月の値を返す。1 から 12 
SELECT MONTH('2011-11-11 11:11:11')
->11
NOW() 現在の日付と時刻を返す 
SELECT NOW()
-> 2018-09-19 20:57:43
PERIOD_ADD(period, number) 年-月 の組み合わせ日付に期間を追加する 
SELECT PERIOD_ADD(201703, 5);   
-> 201708
PERIOD_DIFF(period1, period2) 2つの期間の間の月数の差を返す 
SELECT PERIOD_DIFF(201710, 201703);
-> 7
QUARTER(d) 日付 d が第何四半期かを返す。1 から 4 を返す 
SELECT QUARTER('2011-11-11 11:11:11')
-> 4
SECOND(t) t の秒の値を返す 
SELECT SECOND('1:2:3')
-> 3
SEC_TO_TIME(s) 秒単位の時間 s を時分秒の形式に変換する 
SELECT SEC_TO_TIME(4320)
-> 01:12:00
STR_TO_DATE(string, format_mask) 文字列を日付に変換する 
SELECT STR_TO_DATE("August 10 2017", "%M %d %Y");
-> 2017-08-10
SUBDATE(d,n) 日付 d から n 日減算した後の日付 
SELECT SUBDATE('2011-11-11 11:11:11', 1)
->2011-11-10 11:11:11 (默认是天)
SUBTIME(t,n) 時間 t から n 秒減算した時間 
SELECT SUBTIME('2011-11-11 11:11:11', 5)
->2011-11-11 11:11:06 (秒)
SYSDATE() 現在の日付と時刻を返す 
SELECT SYSDATE()
-> 2018-09-19 20:57:43
TIME(expression) 渡された式の時間部分を抽出する 
SELECT TIME("19:30:10");
-> 19:30:10
TIME_FORMAT(t,f) 式 f の要求に従って時間 t を表示する 
SELECT TIME_FORMAT('11:11:11','%r')
11:11:11 AM
TIME_TO_SEC(t) 時間 t を秒に変換する 
SELECT TIME_TO_SEC('1:12:00')
-> 4320
TIMEDIFF(time1, time2) 時間差を計算する 
mysql> SELECT TIMEDIFF("13:10:11", "13:10:10");
-> 00:00:01
mysql> SELECT TIMEDIFF('2000:01:01 00:00:00',
    ->                 '2000:01:01 00:00:00.000001');
        -> '-00:00:00.000001'
mysql> SELECT TIMEDIFF('2008-12-31 23:59:59.000001',
    ->                 '2008-12-30 01:01:01.000002');
        -> '46:58:57.999999'
TIMESTAMP(expression, interval) 単一パラメータの場合、関数は日付または日時式を返します。2つのパラメータがある場合は、パラメータを加算します 
mysql> SELECT TIMESTAMP("2017-07-23",  "13:10:11");
-> 2017-07-23 13:10:11
mysql> SELECT TIMESTAMP('2003-12-31');
        -> '2003-12-31 00:00:00'
mysql> SELECT TIMESTAMP('2003-12-31 12:00:00','12:00:00');
        -> '2004-01-01 00:00:00'
TIMESTAMPDIFF(unit,datetime_expr1,datetime_expr2) 時間差を計算し、datetime_expr2 − datetime_expr1 の時間差を返す

    要件：データベース内の1分ごとに1レコードのデータテーブルを、9:30 から 22:00 まで取得し、30分単位で集計して Excel に出力します。

    データテーブルのフィールド：id（連番）、incount（カウント）、cdate（データ時刻）

    テーブル名：m_temp

    難点：時刻処理

    解決策：DATE_FORMAT、CONCAT、Date、Hour、Minute、Floor 関数を使用して時刻を30分単位に処理します。この期間のデータをクエリするとき、出力する cdate を統一して 09:30 にし、その後 group by cdate で sum(incount) で合計します。

    1. 時刻の処理：

    例：2018-08-21 09:30:00 から 2018-08-21 22:00:00

    最初の30分 09:30 から 10:00

    この期間のデータをクエリするとき、出力する cdate を統一して 09:30 にし、その後 group by cdate で sum(incount) します

    分を取り出して /30 します。0〜29分の結果は 0、30〜59分の結果は 1 になり、さらに 30 分を乗算すると 00 または 30 になります

    date(cdate) で、年月日を取り出します；

    hour(cdate) で、時を取り出します；

    minute(cdate) で、分を取り出します；

    (minute(cdate))/30)*30 を計算すると、結果は 0 または 30 になります；

    floor((minute(cdate))/30)*30) で、整数に処理します；

    concat(date(cdate),' ',hour(cdate),':',floor((minute(cdate))/30)*30) で、日付形式に従って連結します

    DATE_FORMAT(concat(date(cdate),' ',hour(cdate),':',floor(minute(cdate)/30)*30+12),'%Y-%m-%d %H:%i') で、date 型に変換します

    完全な SQL：

    select sum(incount),dataStartTime from (
select incount, DATE_FORMAT( concat(date(cdate),' ',hour(cdate),':',floor( minute(cdate)/30 )*30+12) ,'%Y-%m-%d %H:%i')  as dataStartTime   
 from m_temp WHERE cdate>='2018-08-21 09:30' and cdate<='2018-08-21 22:00'  ORDER BY dataStartTime
) a
group by DATE_FORMAT( dataStartTime ,'%Y-%m-%d %H:%i')
into outfile('c:/2018-08-21Data.xls');
