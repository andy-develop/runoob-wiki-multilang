PyTorch テンソル（Tensor）
PyTorch torch.nn リファレンスマニュアル

Pytorch torch リファレンスマニュアル

PyTorch ソフトウェアパッケージには、多次元テンソル用のデータ構造が含まれており、これらのテンソル上で実行される数学演算が定義されています。さらに、テンソルや任意の型のデータを効率的にシリアライズするための多くのユーティリティや、その他の便利なツールも提供しています。

さらに、CUDA 版もあり、計算能力 >= 3.0 の NVIDIA GPU 上でテンソル計算を実行することができます。

例

import torch

# テンソルの作成
x = torch.tensor([1, 2, 3])
y = torch.zeros(2, 3)

# 数学演算
z = torch.add(x, 1)  # 要素ごとに 1 を加算
print(z)

# インデックスとスライス
mask = x > 1
selected = torch.masked_select(x, mask)
print(selected)

# デバイス管理
if torch.cuda.is_available():
    device = torch.device('cuda')
    x = x.to(device)
    print(x.device)

# 行列演算
a = torch.randn(3, 4)
b = torch.randn(4, 5)
c = torch.matmul(a, b)
print(c.shape)

# 勾配計算
x = torch.tensor([1., 2., 3.], requires_grad=True)
y = x.sum()
y.backward()
print(x.grad)
