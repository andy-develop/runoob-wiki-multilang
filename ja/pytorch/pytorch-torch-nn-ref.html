PyTorch torch.nn リファレンスマニュアル

PyTorch のtorch.nnモジュールはニューラルネットワークの構築とトレーニングの中核となるモジュールであり、ニューラルネットワークを定義・操作するための豊富なクラスと関数を提供します。

以下はtorch.nnモジュールの主要な構成要素とその機能：

1、nn.Module クラス：

  • nn.Moduleすべてのカスタムニューラルネットワークモデルの基底クラスです。ユーザーは通常、このクラスから独自のモデルクラスを派生させ、その中でネットワーク層の構造と順伝播関数（forward pass）を定義します。

2、定義済み層（Modules）：

  • さまざまな種類の層コンポーネントが含まれます。たとえば、畳み込み層（nn.Conv1d, nn.Conv2d, nn.Conv3d）、全結合層（nn.Linear）、活性化関数（nn.ReLU, nn.Sigmoid, nn.Tanh）など。

3、コンテナクラス：

  • nn.Sequential：複数の層を順番に組み合わせて、シンプルな線形積層ネットワークを形成することができます。
  • nn.ModuleList 和 nn.ModuleDict：サブモジュールを動的に保存およびアクセスでき、可変長または名前付きのモジュールコレクションをサポートします。

4、損失関数（Loss Functions）：

  • torch.nnモデルの予測と実際のラベルとの間の差異を測定するための一連の損失関数が含まれています。例：平均二乗誤差損失（nn.MSELoss）、交差エントロピー損失（nn.CrossEntropyLoss）など。

5、関数型インターフェース（Functional Interface）：

  • nn.functional（通常はFと略記されます）、テンソルに直接作用する多くの関数が含まれており、層オブジェクトと同じ機能を実装していますが、パラメータの保存や更新の機能はありません。たとえば、F.relu()を使用して直接 ReLU 操作を行うことができ、またはF.conv2d()を使用して畳み込み操作を行うことができます。

6、初期化メソッド：

  • torch.nn.initよく使われる重み初期化戦略を提供します。たとえば、Xavier 初期化（nn.init.xavier_uniform_()）や Kaiming 初期化（nn.init.kaiming_uniform_()）などは、ニューラルネットワークのトレーニングを成功させるために不可欠です。

7、Transformer 層：

  • PyTorch は完全な Transformer アーキテクチャコンポーネントを提供します。含まれるもの：nn.Transformer, nn.TransformerEncoder, nn.TransformerDecoderおよびアテンション機構nn.MultiheadAttentionなど。

8、正規化層：

  • バッチ正規化（BatchNorm）、層正規化（LayerNorm）、グループ正規化（GroupNorm）、インスタンス正規化（InstanceNorm）、および RMSNorm などが含まれます。

活性化関数（非線形活性化 - 重み付き和タイプ）

クラス/関数 説明
torch.nn.ReLU(inplace) ReLU 活性化関数、f(x) = max(0, x)。
torch.nn.ReLU6(inplace) ReLU6 活性化関数、f(x) = min(max(0, x), 6)。
torch.nn.Sigmoid() Sigmoid 活性化関数、f(x) = 1 / (1 + exp(-x))。
torch.nn.Tanh() Tanh 活性化関数、f(x) = (exp(x) - exp(-x)) / (exp(x) + exp(-x))。
torch.nn.LeakyReLU(negative_slope, inplace) LeakyReLU。負の値に小さな勾配を許容します。
torch.nn.PReLU(num_parameters, init) パラメータ化 ReLU。学習可能な負の傾きパラメータを持ちます。

torch.nn.SELU(inplace) 自己正規化指数線形ユニット。
torch.nn.GELU() ガウス誤差線形ユニット。Transformer でよく使用されます。
torch.nn.SiLU(inplace) Sigmoid 線形ユニット（Swish）、f(x) = x * sigmoid(x)。
torch.nn.Mish(inplace) Mish 活性化関数、f(x) = x * tanh(softplus(x))。
torch.nn.Hardtanh(min_value, max_value, inplace) ハード双曲線正接。出力範囲を制限します。
torch.nn.Hardswish(inplace) Hard Swish。ReLU6 の滑らかなバージョン。
torch.nn.Hardsigmoid(inplace) Hard Sigmoid。区分的線形近似。
torch.nn.RReLU(lower, upper, inplace) ランダム LeakyReLU。トレーニング時に負の傾きをランダムに選択します。
torch.nn.Softplus(beta, threshold) Softplus。ReLU の滑らかな近似。
torch.nn.Softshrink(lambda) Softshrink 活性化関数。
torch.nn.Hardshrink(lambda) Hardshrink 活性化関数。
torch.nn.Softsign() Softsign 活性化関数、f(x) = x / (1 + |x|)。
torch.nn.Tanhshrink() Tanhshrink，f(x) = x - tanh(x)。
torch.nn.LogSigmoid() Log Sigmoid，f(x) = log(sigmoid(x))。
torch.nn.Threshold(threshold, value, inplace) しきい値活性化関数。
torch.nn.GLU(dim) ゲート付き線形ユニット。入力を指定された次元に沿って2つの部分に分割し、要素ごとに乗算します。

例：CNNを使用した画像分類

import torch
import torch.nn as nn

class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        # 畳み込み層
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        self.conv3 = nn.Conv2d(32, 64, kernel_size=3, padding=1)

        # プーリング層
        self.pool = nn.MaxPool2d(2, 2)

        # バッチ正規化
        self.bn1 = nn.BatchNorm2d(16)
        self.bn2 = nn.BatchNorm2d(32)
        self.bn3 = nn.BatchNorm2d(64)

        # 活性化関数
        self.relu = nn.ReLU()

        # 全結合層
        self.fc1 = nn.Linear(64 * 4 * 4, 256)
        self.fc2 = nn.Linear(256, 10)

        # Dropout
        self.dropout = nn.Dropout(0.5)

    def forward(self, x):
        # Conv -> BN -> ReLU -> Pool
        x = self.pool(self.relu(self.bn1(self.conv1(x))))
        x = self.pool(self.relu(self.bn2(self.conv2(x))))
        x = self.pool(self.relu(self.bn3(self.conv3(x))))

        # Flatten
        x = x.view(x.size(0), -1)

        # FC -> ReLU -> Dropout -> FC
        x = self.dropout(self.relu(self.fc1(x)))
        x = self.fc2(x)
        return x

# モデルを作成
model = CNN()
print(model)

# 順伝播をテスト
input_tensor = torch.randn(1, 3, 32, 32)
output = model(input_tensor)
print("Output shape:", output.shape)

例：LSTMを使用したテキスト分類

import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, num_layers, output_dim):
        super(LSTMClassifier, self).__init__()

        # 埋め込み層
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)

        # LSTM層
        self.lstm = nn.LSTM(
            embedding_dim,
            hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            bidirectional=True,
            dropout=0.5
        )

        # 全結合層
        self.fc = nn.Linear(hidden_dim * 2, output_dim)

        # Dropout
        self.dropout = nn.Dropout(0.5)

    def forward(self, text, text_lengths):
        # 埋め込み
        embedded = self.embedding(text)

        # 可変長入力を処理するためにシーケンスをパッキング
        packed = nn.utils.rnn.pack_padded_sequence(
            embedded, text_lengths.cpu(), batch_first=True, enforce_sorted=False
        )

        # LSTM
        packed_output, (hidden, cell) = self.lstm(packed)

        # アンパック
        output, output_lengths = nn.utils.rnn.pad_packed_sequence(packed_output, batch_first=True)

        # 双方向の最終隠れ状態を結合
        hidden = torch.cat((hidden[-2,:,:], hidden[-1,:,:]), dim=1)

        # Dropoutと全結合
        hidden = self.dropout(hidden)
        output = self.fc(hidden)

        return output

# パラメータ
vocab_size = 10000
embedding_dim = 128
hidden_dim = 256
num_layers = 2
output_dim = 5  # 5分類

# モデルを作成
model = LSTMClassifier(vocab_size, embedding_dim, hidden_dim, num_layers, output_dim)
print(model)

例：Transformerエンコーダの使用

import torch
import torch.nn as nn

class TransformerClassifier(nn.Module):
    def __init__(self, input_dim, d_model, nhead, num_layers, dim_feedforward, output_dim, dropout):
        super(TransformerClassifier, self).__init__()

        # 埋め込み層
        self.embedding = nn.Linear(input_dim, d_model)

        # 位置エンコーディング
        self.positional_encoding = nn.Parameter(torch.randn(1, 1000, d_model) * 0.1)

        # Transformerエンコーダー層
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=dim_feedforward,
            dropout=dropout,
            batch_first=True
        )

        # Transformerエンコーダー
        self.transformer_encoder = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)

        # 分類ヘッド
        self.fc = nn.Linear(d_model, output_dim)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # 位置エンコーディングを追加
        seq_len = x.size(1)
        x = self.embedding(x) + self.positional_encoding[:, :seq_len, :]

        # Transformerエンコード
        x = self.transformer_encoder(x)

        # 最初の位置の出力を使用して分類（CLSトークンと同様）
        x = x[:, 0, :]

        x = self.dropout(x)
        x = self.fc(x)

        return x

# パラメータ
input_dim = 512
d_model = 512
nhead = 8
num_layers = 6
dim_feedforward = 2048
output_dim = 10
dropout = 0.1

# モデルを作成
model = TransformerClassifier(input_dim, d_model, nhead, num_layers, dim_feedforward, output_dim, dropout)
print(model)

# テスト
x = torch.randn(32, 100, input_dim)  # batch_size=32, seq_len=100
output = model(x)
print("Output shape:", output.shape)  # (32, 10)
