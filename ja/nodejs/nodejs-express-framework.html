Node.js Express フレームワーク

Express の紹介

Express は、簡潔で柔軟な node.js Web アプリケーションフレームワークであり、さまざまな Web アプリケーションを作成するための一連の強力な機能と、豊富な HTTP ツールを提供します。

Express を使用すると、完全な機能を備えた Web サイトを迅速に構築できます。

Express フレームワークのコア機能：

  • HTTP リクエストに応答するミドルウェアを設定できます。

  • さまざまな HTTP リクエストアクションを実行するためのルーティングテーブルを定義します。

  • テンプレートにパラメータを渡すことで、HTML ページを動的にレンダリングできます。

Express のインストール

Express をインストールして依存関係リストに保存します：

$ cnpm install express --save

上記のコマンドは、Express フレームワークを現在のディレクトリのnode_modulesディレクトリにインストールします。node_modulesディレクトリ内に express ディレクトリが自動的に作成されます。以下に、express フレームワークと一緒にインストールする必要がある重要なモジュールをいくつか示します：

  • body-parser- node.js ミドルウェア。JSON、Raw、Text、URLエンコードされたデータを処理するために使用します。

  • cookie-parser- これはCookieを解析するためのツールです。req.cookies を使用して送信されたCookieを取得し、それらをオブジェクトに変換します。

  • multer- node.js ミドルウェア。enctype="multipart/form-data"（フォームのMIMEエンコーディングを設定）のフォームデータを処理するために使用します。

$ cnpm install body-parser --save
$ cnpm install cookie-parser --save
$ cnpm install multer --save

インストールが完了したら、express で使用されているバージョン番号を確認できます：

$ cnpm list express
/data/www/node
└── express@4.15.2  -> /Users/tianqixin/www/node/node_modules/.4.15.2@express

リクエストとレスポンス

Express アプリケーションはコールバック関数のパラメータを使用します：request 和 responseオブジェクトを使用してリクエストとレスポンスのデータを処理します。

app.get('/', function (req, res) {
   // --
})

request 和 responseオブジェクトの具体的な説明：

Request オブジェクト- request オブジェクトは HTTP リクエストを表し、リクエストのクエリ文字列、パラメータ、コンテンツ、HTTP ヘッダーなどの属性が含まれます。一般的な属性は次のとおりです：

  1. req.app：callbackが外部ファイルの場合、req.appを使用してexpressのインスタンスにアクセスします
  2. req.baseUrl：ルートが現在インストールされているURLパスを取得します
  3. req.body / req.cookies：「リクエストボディ」/ Cookie を取得します
  4. req.fresh / req.stale：リクエストがまだ「新鮮」かどうかを判断します
  5. req.hostname / req.ip：ホスト名とIPアドレスを取得します
  6. req.originalUrl：元のリクエストURLを取得します
  7. req.params：ルートのパラメータを取得します
  8. req.path：リクエストパスを取得します
  9. req.protocol：プロトコルの種類を取得します
  10. req.query：URL のクエリパラメータ文字列を取得します
  11. req.route：現在一致しているルートを取得します
  12. req.subdomains：サブドメインを取得します
  13. req.accepts()：受け入れ可能なリクエストのドキュメントタイプをチェックします
  14. req.acceptsCharsets / req.acceptsEncodings / req.acceptsLanguages：指定された文字セットの最初に受け入れ可能な文字エンコーディングを返します
  15. req.get()：指定されたHTTPリクエストヘッダーを取得します
  16. req.is()：リクエストヘッダー Content-Type の MIME タイプを判断します

Response オブジェクト- response オブジェクトは HTTP レスポンスを表し、リクエスト受信時にクライアントに送信される HTTP レスポンスデータです。一般的なプロパティは次のとおりです：

  1. res.app：req.appと同じ
  2. res.append()：指定したHTTPヘッダーを追加します
  3. res.set() は res.append() の後に、以前に設定したヘッダーをリセットします
  4. res.cookie(name，value [，option])：Cookie を設定します
  5. opition: domain / expires / httpOnly / maxAge / path / secure / signed
  6. res.clearCookie()：Cookie をクリアします
  7. res.download()：指定されたパスのファイルを送信します
  8. res.get()：指定されたHTTPヘッダーを返します
  9. res.json()：JSONレスポンスを送信します
  10. res.jsonp()：JSONPレスポンスを送信します
  11. res.location()：レスポンスの Location HTTP ヘッダーのみを設定し、ステータスコードまたは close response は設定しません
  12. res.redirect()：レスポンスの Location HTTP ヘッダーを設定し、ステータスコード 302 も設定します
  13. res.render(view,[locals],callback)：ビューをレンダリングし、レンダリング後の文字列をコールバックに渡します。レンダリング中にエラーが発生した場合は、next(err) が自動的に呼び出されます。コールバックには、発生する可能性のあるエラーとレンダリング後のページが渡されるため、自動出力は行われません。
  14. res.send()：HTTPレスポンスを送信します
  15. res.sendFile(path [，options] [，fn])：指定されたパスのファイルを送信します - ファイルの拡張子に基づいて Content-Type を自動的に設定します
  16. res.set()：HTTPヘッダーを設定します。objectを渡すと複数のヘッダーを一度に設定できます
  17. res.status()：HTTPステータスコードを設定します
  18. res.type()：Content-Type の MIME タイプを設定します

ルーティング

HTTP リクエストの基本的な応用についてはすでに理解しました。ルーティングは、誰が（指定されたスクリプトが）クライアントリクエストに応答するかを決定します。

HTTP リクエストでは、ルーティングを通じてリクエストの URL と GET/POST パラメータを抽出できます。

次に、Hello World を拡張し、より多くの種類の HTTP リクエストを処理する機能を追加します。

express_demo2.js ファイルを作成し、コードは次のとおりです：

express_demo2.js ファイルのコード：

var express = require('express'); var app = express(); //ホームページに「Hello World」を出力 app.get('/', function (req, res) { console.log("ホームページ GET リクエスト"); res.send('Hello GET'); }) //POST リクエスト app.post('/', function (req, res) { console.log("ホームページ POST リクエスト"); res.send('Hello POST'); }) ///del_user ページのレスポンス app.get('/del_user', function (req, res) { console.log("/del_user は DELETE リクエストに応答"); res.send('削除ページ'); }) ///list_user ページ GET リクエスト app.get('/list_user', function (req, res) { console.log("/list_user GET リクエスト"); res.send('ユーザーリストページ'); }) //ページ abcd、abxcd、ab123cd などに対して GET リクエストで応答 app.get('/ab*cd', function(req, res) { console.log("/ab*cd GET リクエスト"); res.send('正規表現マッチング'); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("応用例、アクセスアドレスは http://%s:%s", host, port) })

上記のコードを実行します：

$ node express_demo2.js 
应用实例，访问地址为 http://0.0.0.0:8081

GET メソッド

以下の例では、フォームで GET メソッドを使用して2つのパラメータを送信する方法を示します。server.js ファイル内のprocess_getルーターを使用して入力を処理できます：

index.html ファイルのコード：

<html> <body> <form action="/process_get" method="GET"> First Name: <input type="text" name="first_name"> <br> Last Name: <input type="text" name="last_name"> <input type="submit" value="Submit"> </form> </body> </html>

server.js ファイルのコード：

var express = require('express'); var app = express(); app.use('/public', express.static('public')); app.get('/index.html', function (req, res) { res.sendFile( __dirname + "/" + "index.html" ); }) app.get('/process_get', function (req, res) { //JSON 形式で出力 var response = { "first_name":req.query.first_name, "last_name":req.query.last_name }; console.log(response); res.end(JSON.stringify(response)); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("応用例、アクセスアドレスは http://%s:%s", host, port) })

上記のコードを実行します：

POST メソッド

以下の例では、フォームで POST メソッドを使用して2つのパラメータを送信する方法を示します。server.js ファイル内のprocess_postルーターを使用して入力を処理できます：

index.html ファイルのコード：

<html> <body> <form action="http://127.0.0.1:8081/process_post" method="POST"> First Name: <input type="text" name="first_name"> <br> Last Name: <input type="text" name="last_name"> <input type="submit" value="Submit"> </form> </body> </html>

server.js ファイルのコード：

var express = require('express'); var app = express(); var bodyParser = require('body-parser'); //application/x-www-form-urlencoded エンコード解析を作成 var urlencodedParser = bodyParser.urlencoded({ extended: false }) app.use('/public', express.static('public')); app.get('/index.html', function (req, res) { res.sendFile( __dirname + "/" + "index.html" ); }) app.post('/process_post', urlencodedParser, function (req, res) { //JSON 形式で出力 var response = { "first_name":req.body.first_name, "last_name":req.body.last_name }; console.log(response); res.end(JSON.stringify(response)); }) var server = app.listen(8081, function () { var host = server.address().address var port = server.address().port console.log("応用例、アクセスアドレスは http://%s:%s", host, port) })

上記のコードを実行します：

$ node server.js
应用实例，访问地址为 http://0.0.0.0:8081

    server.address().address が : を返す問題について、関連ドキュメントを確認しました

    As the docs say,

    Begin accepting connections on the specified port and hostname. If the hostname is omitted, the server will accept connections on any IPv6 address (::) when IPv6 is available, or any IPv4 address (0.0.0.0) otherwise. A port value of zero will assign a random port.

    So, the following code would print running at http://:::3456:

    var express      = require('express');
var app          = express();
var server = app.listen(3456, function () {
    var host = server.address().address;
    var port = server.address().port;
    console.log('running at http://' + host + ':' + port)
});

    But if you add an explicit hostname:

    var server = app.listen(3456, "127.0.0.1", function () {

    It would print what you want to see: running at http://127.0.0.1:3456

    Also you might want to use some IP lib as pointed in this answer

    つまり、デフォルトで IPV6 モードになっています。どう変更するかは調査が必要かもしれません。そのため、アドレスは明示的に "127.0.0.1" または localhost と指定するのがよいでしょう。
