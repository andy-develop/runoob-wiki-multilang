Pi Agent がサポートする AI プロバイダー

以下は、Pi Agent がサポートするすべての AI プロバイダーの完全なリストです。

サブスクリプションログインをサポートするプロバイダー

以下の/loginコマンドで OAuth ログインを実行：

プロバイダー要件説明
Claude Pro/MaxAnthropic サブスクリプション追加使用量はトークン単位で課金
ChatGPT Plus/Pro (Codex)OpenAI サブスクリプションOpenAI 公式認定
GitHub CopilotGitHub Copilot サブスクリプションエンタープライズサーバーをサポート
xAI (Grok)X Premium サブスクリプションGrok モデルを使用
OpenRouterOpenRouter アカウントOAuth で API Key を作成
RadiusRadius アカウント動的 pi-messages ゲートウェイ

サブスクリプション系のエントリは、Pi Agent /login メニューの実際の表示に準拠します。バージョンによって若干異なる場合があります。

Cloudflare の2項目のアカウント ID とゲートウェイ ID は、環境変数として設定することも、auth.json の認証情報の env オブジェクトに記述することもできます。

ローカルおよびカスタムプロバイダー

ローカル推論バックエンドは設定ファイル経由で接続し、カスタム API は拡張方式で登録できます。

プロバイダー説明設定方法
llama.cppローカルオープンソースモデル推論/login llama.cpp、モデルは /llama で管理
カスタム APIExtensions 開発pi.registerProvider() で登録

拡張方式でプロバイダーを登録する完全な例は、「llama.cpp ローカルモデル」の章を参照してください。

以下の3つのローカルバックエンドはすべて OpenAI Compatible API 経由で接続します：

バックエンドデフォルトポート説明
Ollama11434そのまま使え、1つのコマンドでモデルを取得して実行できます
LM Studio1234グラフィカルインターフェースを提供し、デスクトップでのローカルモデル管理に適しています
vLLM8000高スループットのサービス化デプロイ向け

以下の最小限の例を~/.pi/agent/models.jsonに書き込みます。Ollama を例にとると、LM Studio と vLLM は名前と baseUrl を置き換えるだけです：

例

{
  "providers": {
    "ollama": {
      "baseUrl": "http://127.0.0.1:11434/v1",
      "api": "openai-completions",
      "apiKey": "ollama",
      "models": [
        {
          "id": "qwen3-coder-30b",
          "name": "Qwen3 Coder 30B",
          "contextWindow": 131072,
          "maxTokens": 8192,
          "input": ["text"]
        }
      ]
    }
  }
}

例の中の apiKey の値 ollama は単なるプレースホルダーで、ローカルサーバーはそれを直接無視します。

しかし、それを削除することはできません：認証フィールドを一切設定しないと、モデルは正常に読み込まれますが /model セレクターに表示されません。公式もプレースホルダーの値を残すことを推奨しています。

apiKey 以外の各フィールドの意味は次のとおりです：

フィールド説明
baseUrlOpenAI Compatible インターフェースアドレス。LM Studio は http://127.0.0.1:1234/v1、vLLM は実際のサービスアドレスを記入
apiOpenAI 互換プロトコルを使用。固定で openai-completions と記述
apiKeyプレースホルダー値。ローカルで認証なしのサービスでも残す必要がある。そうしないとモデルが /model に表示されない
models[].id呼び出し時に使用するモデル ID。ローカルで取得済みのモデル名と一致させる必要がある
models[].nameセレクターに表示される名前
models[].contextWindowコンテキストウィンドウサイズ（トークン）
models[].maxTokens1回の最大出力長（トークン）
models[].inputサポートされる入力タイプ
その他の拡張
