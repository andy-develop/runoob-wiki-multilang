VBScript 関数

このページでは、組み込みの VBScript 関数をすべてリストし、主に以下のカテゴリに分類しています：

  • Date/Time 関数
  • Conversion 関数
  • Format 関数
  • Math 関数
  • Array 関数
  • String 関数
  • その他の関数

Date/Time 関数

関数 説明
CDate 有効な日付と時刻の式を日付（Date）型に変換します。
Date 現在のシステム日付を返します。
DateAdd 指定した時間間隔が追加された日付を返します。
DateDiff 2 つの日付の間の時間間隔の数を返します。
DatePart 指定した日付の指定部分を返します。
DateSerial 指定した年、月、日の日付を返します。
DateValue 日付を返します。
Day 月のうちの 1 日を表す数値（1 ～ 31 の範囲）を返します。
FormatDateTime 日付または時刻として書式設定された式を返します。
Hour 1 日のうちの時間を表す数値（0 ～ 23 の範囲）を返します。
IsDate 式を日付に変換できるかどうかを示すブール値を返します。
Minute 時間の分を表す数値（0 ～ 59 の範囲）を返します。
Month 年の月を表す数値（1 ～ 12 の範囲）を返します。
MonthName 指定した月の名前を返します。
Now 現在のシステム日付と時刻を返します。
Second 分の秒を表す数値（0 ～ 59 の範囲）を返します。
Time 現在のシステム時刻を返します。
Timer 午前 12:00 からの秒数を返します。
TimeSerial 指定した時、分、秒の時刻を返します。
TimeValue 時刻を返します。
Weekday 曜日を表す数値（1 ～ 7 の範囲）を返します。
WeekdayName 指定した曜日の名前を返します。
Year 年を表す数値を返します。

Conversion 関数

 Top
関数 説明
Asc 文字列の最初の文字を ANSI 文字コードに変換します。
CBool 式をブール（Boolean）型に変換します。
CByte 式をバイト（Byte）型に変換します。
CCur 式を通貨（Currency）型に変換します。
CDate 有効な日付と時刻の式を日付（Date）型に変換します。
CDbl 式を倍精度浮動小数点（Double）型に変換します。
Chr 指定した ANSI 文字コードを文字に変換します。
CInt 式を整数（Integer）型に変換します。
CLng 式を長整数（Long）型に変換します。
CSng 式を単精度浮動小数点（Single）型に変換します。
CStr 式を文字列（String）型に変換します。
Hex 指定した数値の 16 進数値を返します。
Oct 指定した数値の 8 進数値を返します。

Format 関数

 Top
関数 説明
FormatCurrency 通貨値として書式設定された式を返します。
FormatDateTime 日付または時刻として書式設定された式を返します。
FormatNumber 数値として書式設定された式を返します。
FormatPercent パーセントとして書式設定された式を返します。

Math 関数

 Top
関数 説明
Abs 指定した数値の絶対値を返します。
Atn 指定した数値の逆正接（アークタンジェント）を返します。
Cos 指定した数値（角度）の余弦（コサイン）を返します。
Exp 返しますe（自然対数の底）のべき乗。
Hex 指定した数値の 16 進数値を返します。
Int 指定した数値の整数部を返します。
Fix 指定した数値の整数部を返します。
Log 指定した数値の自然対数を返します。
Oct 指定した数値の 8 進数値を返します。
Rnd 1 未満で 0 以上の乱数を返します。
Sgn 指定した数値の符号を示す整数を返します。
Sin 指定した数値（角度）の正弦（サイン）を返します。
Sqr 指定した数値の平方根を返します。
Tan 指定した数値（角度）の正接（タンジェント）を返します。

Array 関数

 Top
関数 説明
Array 配列を含む変数を返します。
Filter 特定のフィルター条件に基づく文字列配列のサブセットを含む、添え字が 0 から始まる配列を返します。
IsArray 指定した変数が配列かどうかを示すブール値を返します。
Join 配列内の複数の部分文字列から構成される文字列を返します。
LBound 配列の次元を示す最小の添え字を返します。
Split 指定した数の部分文字列を含む、添え字が 0 から始まる 1 次元配列を返します。
UBound 配列の次元を示す最大の添え字を返します。

String 関数

 Top
関数 説明
InStr 別の文字列内で文字列が最初に出現する位置を返します。検索は文字列の最初の文字から始まります。
InStrRev 別の文字列内で文字列が最初に出現する位置を返します。検索は文字列の最後の文字から始まります。
LCase 指定した文字列を小文字に変換します。
Left 文字列の左側から指定した数の文字を返します。
Len 文字列内の文字数を返します。
LTrim 文字列の左側のスペースを削除します。
RTrim 文字列の右側のスペースを削除します。
Trim 文字列の左右のスペースを削除します。
Mid 文字列から指定した数の文字を返します。
Replace 別の文字列を使用して、文字列の指定部分を指定された回数置換します。
Right 文字列の右側から指定した数の文字を返します。
Space 指定した数のスペースで構成される文字列を返します。
StrComp 2 つの文字列を比較し、比較結果を表す値を返します。
String 指定した長さの繰り返し文字を含む文字列を返します。
StrReverse 文字列を反転します。
UCase 指定した文字列を大文字に変換します。

その他の関数

 Top
関数 説明
CreateObject 指定した型のオブジェクトを作成します。
Eval 式を評価し、結果を返します。
GetLocale 現在のロケール ID を返します。
GetObject ファイル内の automation オブジェクトへの参照を返します。
GetRef VBScript サブルーチンをページ上の DHTML イベントに接続できます。
InputBox ユーザーがテキストを入力したり、ボタンをクリックしたりできるダイアログボックスを表示し、その内容を返します。
IsEmpty 指定した変数が初期化されているかどうかを示すブール値を返します。
IsNull 指定した式に無効なデータ（Null）が含まれているかどうかを示すブール値を返します。
IsNumeric 指定した式が数値として評価できるかどうかを示すブール値を返します。
IsObject 指定した式が automation オブジェクトかどうかを示すブール値を返します。
LoadPicture 画像オブジェクトを返します。32 ビットプラットフォームのみで使用できます。
MsgBox メッセージボックスを表示し、ユーザーがボタンをクリックするのを待ち、ユーザーがクリックしたボタンを示す値を返します。
RGB RGB カラー値を表す数値を返します。
Round 数値を四捨五入します。
ScriptEngine 使用中のスクリプト言語を返します。
ScriptEngineBuildVersion 使用中のスクリプトエンジンの内部バージョン番号を返します。
ScriptEngineMajorVersion 使用中のスクリプトエンジンのメジャーバージョン番号を返します。
ScriptEngineMinorVersion 使用中のスクリプトエンジンのマイナーバージョン番号を返します。
SetLocale ロケール ID を設定し、以前のロケール ID を返します。
TypeName 指定した変数のサブタイプを返します。
VarType 変数のサブタイプを示す値を返します。
