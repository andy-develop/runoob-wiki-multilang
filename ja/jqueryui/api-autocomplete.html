jQuery UI API - 自動補完ウィジェット（Autocomplete Widget）

所属カテゴリ

ウィジェット（Widgets）

使用方法

説明：自動補完機能は、ユーザーの入力値に基づいて検索およびフィルタリングを行い、ユーザーが事前定義された値のリストからすばやく見つけて選択できるようにします。

追加されたバージョン：1.8

入力を受け取ることができる任意のフィールドは Autocomplete に変換できます。つまり、<input>要素、<textarea>要素、およびcontenteditableプロパティを持つ要素です。

Autocomplete フィールドにフォーカスを与えるか、そこに文字を入力すると、プラグインは一致するエントリの検索を開始し、選択可能な値のリストを表示します。さらに文字を入力することで、ユーザーはリストをフィルタリングしてより良い一致を得ることができます。

このウィジェットは、以前に選択した値を選択するために使用できます。たとえば、記事のタグを入力したり、アドレス帳からアドレスやメールアドレスを入力したりする場合です。Autocomplete は、都市名を入力してその都市の郵便番号を取得するなど、関連情報を自動入力するためにも使用できます。

データはローカルソースまたはリモートソースから取得できます。ローカルソースは、50 エントリのアドレス帳などの小さなデータセットに適しています。リモートソースは、数百または数千のエントリを持つデータベースなどの大きなデータセットに適しています。カスタムデータソースの詳細については、sourceオプションのドキュメントを参照してください。

キーボード操作

メニューが開いているときは、次のキーボードコマンドを使用できます。

  • UP - フォーカスを前の項目に移動します。最初の項目にある場合は、入力（input）にフォーカスを移動します。入力（input）にある場合は、最後の項目にフォーカスを移動します。
  • DOWN - フォーカスを次の項目に移動します。最後の項目にある場合は、入力（input）にフォーカスを移動します。入力（input）にある場合は、最初の項目にフォーカスを移動します。
  • ESCAPE - メニューを閉じます。
  • ENTER - 現在フォーカスされている項目を選択し、メニューを閉じます。
  • TAB - 現在フォーカスされている項目を選択し、メニューを閉じ、フォーカスを次のフォーカス可能（focusable）な要素に移動します。
  • PAGE UP/DOWN - 1画面分の項目をスクロールします（メニューの高さに基づきます）。

メニューが閉じているときは、次のキーボードコマンドを使用できます。

  • UP/DOWN - 以下の条件を満たす場合、minLengthメニューを開きます。

テーマ化

自動補完ウィジェット（Autocomplete Widget）は、jQuery UI CSS フレームワークを使用して、その外観と感触のスタイルを定義します。自動補完ウィジェット固有のスタイルを使用する必要がある場合は、次の CSS クラス名を使用できます。

  • ui-autocomplete：ユーザーの入力に一致するものを表示するために使用されるメニュー（menu）
  • ui-autocomplete-input：自動補完ウィジェット（Autocomplete Widget）によってインスタンス化された input 要素。

補足説明

  • このウィジェットには機能的な CSS が必要です。そうしないと動作しません。カスタムテーマを作成する場合は、ウィジェット固有の CSS ファイルを開始点として使用してください。
  • このウィジェットは要素の値をプログラムで操作するため、要素の値が変更されてもネイティブのchangeイベントはトリガーされません。

source Array または String または Function( Object request, Function response( Object data ) ) 使用するデータを定義します。必ず指定する必要があります。

使用する変数に関係なく、ラベルは常にテキストとして扱われます。ラベルを html として扱いたい場合は、Scott González の html 拡張を使用できます。デモはsourceオプションのさまざまなバリエーションに焦点を当てています。自分の使用状況に一致するものを見つけて、関連するコードを確認できます。

複数の型をサポートしています：

  • Array：ローカルデータに使用できる配列。次の 2 つの形式をサポートします：
    • 文字列の配列：[ "Choice1", "Choice2" ]
    • 次のプロパティを持つlabel 和 valueオブジェクトの配列：[ { label: "Choice1", value: "value1" }, ... ]
    label プロパティは候補メニューに表示されます。ユーザーが項目を選択すると、value が input 要素に挿入されます。1 つのプロパティのみが指定された場合、そのプロパティは label と value の両方として扱われます。たとえば、valuevalue プロパティを提供した場合、value もラベルとして扱われます。
  • String：文字列を使用する場合、Autocomplete プラグインはその文字列が JSON データを返す URL リソースを指していることを期待します。同じホスト上でも、異なるホスト上でもかまいません（JSONP を提供する必要があります）。Autocomplete プラグインは結果をフィルタリングせず、termフィールドを介してクエリ文字列を追加し、サーバー側スクリプトが結果をフィルタリングできるようにします。たとえば、sourceオプションが"http://example.com"に設定され、ユーザーがfooと入力した場合、GET リクエストはhttp://example.com?term=fooになります。データ自体の形式は、前述のローカルデータの形式と同じにすることができます。
  • Function：3番目のバリアントであるコールバック関数は、最大の柔軟性を提供し、任意のデータソースを Autocomplete に接続するために使用できます。コールバック関数は 2 つの引数を受け取ります：
    • 1 つのrequestオブジェクト。このオブジェクトには 1 つのtermプロパティがあり、現在のテキスト入力の値を表します。たとえば、ユーザーが city フィールドに"new yo"、その場合、Autocomplete term は次と同等です。"new yo"。
    • 1 つのresponseコールバック関数で、単一の引数（ユーザーに提案するデータ）を受け取ります。このデータは指定された term に基づいてフィルタリングされ、上記で説明したローカルデータの任意の形式にすることができます。リクエスト中にエラーを処理するためのカスタム source コールバックを提供するために使用します。エラーが発生した場合でも、必ずresponseコールバック関数を呼び出さなければなりません。これにより、ウィジェットが常に正しい状態になることが保証されます。

    ローカルデータをフィルタリングするときは、組み込みの$.ui.autocomplete.escapeRegex関数を使用できます。この関数は文字列引数を受け取り、すべての正規表現文字をエスケープして、結果を安全に渡せるようにします。new RegExp()。

コード例：

指定されたsourceオプションを指定して autocomplete を初期化します：

$( ".selector" ).autocomplete({ source: [ "c++", "java", "php", "coldfusion", "javascript", "asp", "ruby" ] });
    

初期化後、sourceオプションを取得または設定します：

// getter
var source = $( ".selector" ).autocomplete( "option", "source" );
 
// setter
$( ".selector" ).autocomplete( "option", "source", [ "c++", "java", "php", "coldfusion", "javascript", "asp", "ruby" ] );
    
 none; must be specified

Note: At this time the<ul> element created must contain an <a> element for compatibility with the menu widget. See the example below.

    型：Event
  • ui
    型：Object
    • content

      説明：レスポンスデータを含み、表示結果を変更するために修正できます。このデータはすでに標準化されているため、データを変更する場合は、各項目にvalue 和 labelプロパティが含まれていることを確認してください。

<input id="autocomplete">
 
<script>
var tags = [ "c++", "java", "php", "coldfusion", "javascript", "asp", "ruby" ];
$( "#autocomplete" ).autocomplete({
  source: function( request, response ) {
          var matcher = new RegExp( "^" + $.ui.autocomplete.escapeRegex( request.term ), "i" );
          response( $.grep( tags, function( item ){
              return matcher.test( item );
          }) );
      }
});
</script>
 
</body>
