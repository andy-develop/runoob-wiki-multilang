jQuery.widget( name [, base ], prototype ) の使い方

説明：すべての jQuery UI ウィジェットと同じ抽象化を使用して、状態を持つ jQuery プラグインを作成します。

jQuery.widget( name [, base ], prototype )

パラメータ 型 型
name String 作成するウィジェットの名前。名前空間を含みます。
base Function() 継承するベースウィジェット。`new` キーワードでインスタンス化できるコンストラクターである必要があります。デフォルトは jQuery.Widget です。
prototype PlainObject ウィジェットのプロトタイプとして使用するオブジェクト。

使用できるのは$.Widgetオブジェクトを継承するベースとして使用するか、既存の jQuery UI またはサードパーティ製コントロールから、ゼロから新しいウィジェットを作成することもできます。同じ名前のウィジェットを定義してベースウィジェットを継承すると、ウィジェットを適切に拡張することもできます。

jQuery UI には状態を保持するウィジェットが多数含まれているため、典型的な jQuery プラグインとは少し異なる使用パターンになります。すべての jQuery UI ウィジェットは、ウィジェットファクトリー（Widget Factory）によって定義された同じパターンを使用します。したがって、1 つの使い方を覚えれば、他のウィジェット（Widget）の使い方もわかります。

注：この章ではプログレスバーウィジェット（Progressbar Widget）を例として使用していますが、構文はすべてのウィジェットに適用されます。

初期化

ウィジェットの状態を追跡するには、ウィジェットのライフサイクル全体を理解する必要があります。ライフサイクルはウィジェットの初期化時に始まります。ウィジェットを初期化するには、1 つ以上の要素でプラグインを呼び出すだけです。

$( "#elem" ).progressbar();

これにより、jQuery オブジェクト内の各要素が初期化されます。上記の例では、要素の id は"elem"。

オプション

なぜならprogressbar()呼び出し時に引数を指定しない場合、ウィジェットはデフォルトオプションで初期化されます。初期化時にオプションのセットを渡してデフォルトオプションを上書きできます：

$( "#elem" ).progressbar({ value: 20 });

必要に応じていくつでもオプションを渡すことができ、渡さなかったオプションはすべてデフォルト値が使用されます。

複数のオプション引数を渡すことができ、それらは 1 つのオブジェクトにマージされます（$.extend( true, target, object1, objectN )）。これは、すべてのインスタンスでいくつかの設定を上書きし、インスタンス間でオプションを共有する場合に便利です：

var options = { modal: true, show: "slow" };
$( "#dialog1" ).dialog( options );
$( "#dialog2" ).dialog( options, { autoOpen: false });

初期化時に渡されたすべてのオプションはディープコピーされ、後でウィジェットに影響を与えずにオブジェクトを変更できます。配列は唯一の例外で、そのまま参照されます。この例外は、データソースを参照として渡す必要があるデータバインディングを適切にサポートするためです。

デフォルト値はウィジェットのプロパティに保存されるため、jQuery UI が設定した値を上書きできます。たとえば、次の設定を行うと、今後作成されるすべてのプログレスバーインスタンスはデフォルトで値 80 になります：

$.ui.progressbar.prototype.options.value = 80;

オプションはウィジェットの状態の一部であるため、初期化後にもオプションを設定できます。option メソッドについては後ほど説明します。

メソッド

ウィジェットが初期化されたので、その状態を照会したり、ウィジェット上でアクションを実行したりできます。初期化後のすべてのアクションはメソッド呼び出しとして実行されます。ウィジェット上でメソッドを呼び出すには、jQuery プラグインにメソッド名を渡します。たとえば、プログレスバーウィジェット（Progressbar Widget）でvalue()メソッドを呼び出すには、次のようにします：

$( "#elem" ).progressbar( "value" );

メソッドが引数を受け取る場合、メソッド名の後に引数を渡すことができます。たとえば、引数を渡すには40 到 value()メソッドを使用できます：

$( "#elem" ).progressbar( "value", 40 );

jQuery の他のメソッドと同様に、ほとんどのウィジェットメソッドは jQuery オブジェクトを返します：

$( "#elem" )
  .progressbar( "value", 90 )
  .addClass( "almost-done" );

各ウィジェットには、ウィジェットが提供する機能に基づいた独自のメソッドセットがあります。ただし、すべてのウィジェットに存在するメソッドもいくつかあり、これらについては以下で詳しく説明します。

イベント

すべてのウィジェットには、さまざまな動作に関連するイベントがあり、状態が変化したときに通知します。ほとんどのウィジェットでは、イベントがトリガーされるとき、名前はウィジェット名の小文字形式が接頭辞として付きます。たとえば、プログレスバーのchangeイベントは、値が変更されたときにトリガーされます。

$( "#elem" ).bind( "progressbarchange", function() {
  alert( "The value has changed!" );
});

各イベントには対応するコールバックがあり、これはオプションとして提供されます。必要に応じて、プログレスバーのchangeコールバックを、バインドせずにprogressbarchangeイベント。

$( "#elem" ).progressbar({
  change: function() {
    alert( "The value has changed!" );
  }
});

すべてのウィジェットにはchangeイベントがあり、インスタンス化されたときにトリガーされます。

インスタンス化

ウィジェットのインスタンスは、ウィジェットの完全名をキーとするjQuery.data()に保存されます。したがって、次のコードを使用して、要素からプログレスバーウィジェット（Progressbar Widget）のインスタンスオブジェクトを取得できます。

$( "#elem" ).data( "ui-progressbar" );

要素が指定されたウィジェットにバインドされているかどうかは、:dataセレクターを使用して検出できます。

$( "#elem" ).is( ":data( 'ui-progressbar' )" ); // true
$( "#elem" ).is( ":data( 'ui-draggable' )" ); // false

また、:dataを使用して、指定されたウィジェットのインスタンスであるすべての要素のリストを取得できます。

$( ":data( 'ui-progressbar' )" );

プロパティ

すべてのウィジェットには次のプロパティがあります：

  • defaultElement：ウィジェットインスタンスの構築時に要素が提供されなかった場合に使用する要素。たとえば、プログレスバーのdefaultElement 是 "<div>"，$.ui.progressbar({ value: 50 })で、新しく作成された<div>上にプログレスバーウィジェットのインスタンスをインスタンス化します。
  • document：ウィジェット要素を含むdocument。フレームワーク内でウィジェットと対話する必要がある場合に便利です。
  • element：ウィジェットのインスタンス化に使用される要素を含む jQuery オブジェクト。複数の要素を選択して呼び出すと.myWidget()、各要素に対して個別のウィジェットインスタンスが作成されます。したがって、このプロパティは常に 1 つの要素を含みます。
  • namespace：ウィジェットプロトタイプが保存されているグローバル jQuery オブジェクトの場所。たとえば、"ui" 的 namespaceは、ウィジェットプロトタイプが$.ui。
  • options：ウィジェットが現在使用しているオプションを含むオブジェクト。インスタンス化時に、ユーザーが指定したオプションは自動的に$.myNamespace.myWidget.prototype.optionsで定義されたデフォルト値とマージされます。ユーザーが指定したオプションはデフォルト値を上書きします。
  • uuid：コントロール識別子を表す一意の整数。
  • version：ウィジェットの文字列バージョン。jQuery UI ウィジェットの場合、このプロパティはウィジェットが使用する jQuery UI のバージョンに設定されます。プラグイン開発者は、プロトタイプでこのプロパティを明示的に設定する必要があります。
  • widgetEventPrefix：ウィジェットのイベント名に追加される接頭辞。たとえば、ドラッグ可能ウィジェット（Draggable Widget） 的 widgetEventPrefix 是 "drag"であるため、draggable を作成すると、イベント名は"dragcreate"。デフォルトでは、ウィジェットのwidgetEventPrefixはその名前です。注：このプロパティは非推奨であり、将来のバージョンで削除される予定です。イベント名は widgetName:eventName に変更されます（例："draggable:create"）。
  • widgetFullName：名前空間を含むウィジェットの完全名。$.widget( "myNamespace.myWidget", {} )， widgetFullNameは"myNamespace-myWidget"。
  • widgetName：ウィジェットの名前。$.widget( "myNamespace.myWidget", {} )，widgetNameは"myWidget"。
  • window：ウィジェット要素を含むwindow。フレームワーク内でウィジェットと対話する必要がある場合に便利です。

    説明：文字列キーがイベントタイプを表し、オプションのセレクターが委任に使用され、値がイベント呼び出しのハンドラー関数を表すマップ。

コード例：

_setOption( key, value ) jQuery (plugin only) 個々のオプションごとに_setOptions()メソッドを呼び出します。ウィジェットの状態は変更に応じて更新されます。
  • key
    型：String
    説明：設定するオプションの名前。
  • value
    型：Object
    説明：オプションに設定する値。

コード例：

ウィジェットのheight 或 widthオプションが変更されたときに、ウィジェットの要素を更新します。

_setOption: function( key, value ) {
  if ( key === "width" ) {
    this.element.width( value );
  }
  if ( key === "height" ) {
    this.element.height( value );
  }
  this._super( key, value );
}

  • options
    型：Object
    説明：オプションに設定する値。

コード例：

_setOptions: function( options ) {
  var that = this,
    resize = false;

    that._setOption( key, value );

    }

  }
}
