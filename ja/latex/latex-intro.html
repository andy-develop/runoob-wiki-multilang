LaTeXのインストールと設定

LaTeX入門

LaTeXはTeXを基盤とした組版システムで、高品質な科学技術文書や数学文書の作成に広く使用されています。アメリカの計算機科学者レスリー・ランポートによって1980年代に開発されました。

TeXはドナルド・クヌースによって開発された低レベルの組版エンジンで、主に複雑な数式の処理と高品質な組版に使用されます。

LaTeXはTeXの上にさらに高レベルの抽象化を提供し、ユーザーは組版の詳細をあまり気にせずにコンテンツに集中できます。

一般的なワープロソフト（Microsoft Wordなど）とは異なり、LaTeXはプレーンテキストファイルを使用して文書の構造と内容を記述し、コンパイルによって最終的なPDFファイルを生成します。LaTeXは複雑な数式、参考文献、相互参照などの処理に特に適しています。

LaTeXは、学術論文や技術文書の組版を容易にすることを目的として設計されました。特に数学、物理学、コンピューターサイエンスなどの分野で重宝されています。時が経つにつれ、LaTeXは学界や出版界における標準的なツールの一つとなりました。

LaTeXの特徴

  • 高品質な組版：LaTeXはプロフェッショナルな組版効果で知られており、特に数式の処理に優れています。文書の形式を自動的に調整し、出版基準に適合した高品質な組版結果を生成できます。
  • マークアップ言語ベース：LaTeXはプレーンテキストのマークアップ言語形式を採用しており、ユーザーは特定のコマンドとタグを入力して文書の構造と形式を定義します。例えば、\section{} で章を定義し、\textbf{} で文字を太字にします。
  • クロスプラットフォーム対応：LaTeXはクロスプラットフォームであり、Windows、macOS、Linuxなどのオペレーティングシステムに対応しています。生成される文書は通常PDF形式で、異なるプラットフォームでも一貫した表示結果が得られます。
  • 学術執筆に最適：LaTeXは学術論文、書籍、技術文書、レポートなどの執筆に非常に適しています。特に、多数の数式、参考文献、複雑な組版要件を含む文書に適しています。文献管理、数式入力、組版効果に優れたサポートを提供します。
  • 自動化された文書管理：LaTeXは長文書、書籍、論文において、自動番号付け、目次の自動生成、相互参照、数式の自動組版など、強力な自動化機能を提供します。文献引用や参考文献リストなどを自動的に処理できるため、正確な形式が求められる文書に非常に適しています。
  • オープンソースで無料：LaTeXはオープンソースであり、誰でも無料でダウンロードして使用できます。また、LaTeXコミュニティは非常に活発で、多数のテンプレート、マクロパッケージ、テクニックを提供しており、ユーザーの組版効率向上を支援しています。

LaTeXはどのように動作するのか？

  • LaTeXは従来のWYSIWYG（見たまま編集）エディターとは異なり、最終的な組版結果を直接見ることはありません。代わりにプレーンテキストファイルを編集し、文書の内容、構造、書式の指示を入力します。このファイルの拡張子は通常 .tex です。
  • LaTeXソースコードの作成：まず、テキストエディター（TeXworksやTeXstudioなど）を使用してLaTeXソースファイルを作成します。ファイル内で文書の構造、タイトル、段落、数式、表などの内容を指定し、LaTeXコマンドを使用してそれらの書式設定方法を指定します。
  • コンパイル：次に、LaTeXコンパイラー（pdflatexなど）を使用して .tex ファイルをPDFやその他の出力形式にコンパイルします。コンパイル中に、LaTeXは目次、表、数式番号、参考文献などを自動的に生成します。
  • 最終文書の生成：コンパイル後の出力が最終的な文書となります。PDF版の結果を確認でき、書式の要件に従って高品質な組版が生成されます。

なぜLaTeXを使うのか？

  • 学術執筆：研究者、学者、学生であれば、LaTeXは学術論文、レポート、書籍などの作成に非常に適しています。特に、複雑な数式や参考文献の挿入が必要な文書に適しています。
  • 高品質な組版：LaTeXは組版の詳細を自動的に処理し、国際的な出版基準に適合した文書形式を生成できます。フォント、行間、余白、章見出しの形式など、LaTeXはすべてを正確に制御できます。
  • 複雑な文書構造：LaTeXは大規模な文書（書籍、論文、技術マニュアルなど）の処理に適しています。目次、索引、参考文献を自動的に生成し、相互参照と自動番号付けをサポートしています。
  • 数学・科学文献：LaTeXは数学、物理学、工学などの分野で選ばれるツールです。複雑な数式を簡単に入力・組版できるためです。

LaTeXのワークフローは3つのステップに要約できます：ソースコードを書く、コンパイルを実行する、PDFを得る。

私たちが書く .tex ファイルは普通のプレーンテキストファイルであり、どのエディターでも開くことができます。コンパイラーがそれを最終成果物であるPDFに変換します。

LaTeXの基本的なワークフロー

LaTeXで文書を作成する基本的な流れは次のとおりです：

  • ソースコードの作成：プレーンテキストエディターを使用して .tex ファイルを作成します。内容には文書構造、テキスト、コマンドが含まれます。
  • 文書のコンパイル：LaTeXコンパイラー（pdflatex、xelatexなど）を使用して .tex ファイルをPDFやその他の形式に変換します。
  • 結果の確認：生成されたPDFファイルを直接表示でき、内容はソースコードに基づいて自動的に組版されます。

例えば、簡単なLaTeX文書は次のようになります：

例

\documentclass{article} % 文書クラス
\title{私の最初のLaTeX文書} % タイトル
\author{著者} % 著者
\date{\today} % 日付

\begin{document}
\maketitle % タイトル生成

\section{はじめに} % 章
これは私の最初のLaTeX文書です！\\ % 改行
これは単純な段落です。

\section{数式}
これはインライン数式です：$E = mc^2$。\\ % インライン数式
これはディスプレイ数式です：
\[
\int_a^b f(x) \, dx
\]
\end{document}

LaTeXの核となる考え方

LaTeXの核となる考え方は、内容と書式の分離です：

  • ユーザーは文書の内容と構造にのみ集中すればよく、LaTeXが組版の詳細を自動的に処理します。
  • コマンドと環境（\section、\begin{itemize}など）を使用して、文書の構造とスタイルを定義します。
  • 書式の調整は、文書クラスの変更やマクロパッケージの読み込みによって実現でき、内容を直接変更する必要はありません。

TeX、LaTeX、マクロパッケージとディストリビューションの関係

これは初心者が最も混同しやすい概念のグループです。これらを整理しておけば、後でツールを選んだり環境を構築したりする際に迷うことはありません。

TeXエコシステム全体は4つの層に分けられます。下から上に、エンジン、フォーマット、マクロパッケージ、エディターです。

エンジンは実際に組版処理を行うプログラムで、一般的なものにはTeX、pdfTeX、XeTeX、LuaTeXがあります。このうちXeTeXとLuaTeXはUnicodeとシステムフォントをネイティブにサポートしており、これが中国語文書でこれらのエンジンでのコンパイルが推奨される理由です。

フォーマットはエンジンの上に構築された一連のコマンド規則であり、LaTeXは現在最も人気のあるフォーマットです。

マクロパッケージは、フォーマットの上でさらに機能を拡張するプラグインです。例えば、中国語サポート（ctex）、数式機能の拡張（amsmath）、ページ設定（geometry）などがあります。CTANには5,000以上のマクロパッケージが収録されています。

最後に、エンジン、フォーマット、そして大量のマクロパッケージを一つにまとめて、一度のインストールで済むようにした集合を、ディストリビューション（Distribution）と呼びます。例えば TeX Live や MiKTeX などです。

五つの名詞を一文で覚える

エンジン：ソースコードを実際に PDF に組版するプログラム。例：XeTeX。

LaTeX フォーマット：エンジンの上に定義された、使いやすいコマンド規則のセット。

マクロパッケージ：他の人が作成した機能拡張パッケージ。例：中国語サポートパッケージ ctex。

ディストリビューション：エンジン、フォーマット、マクロパッケージを一つにまとめたインストールパッケージ一式。

エディタ：コードを書くためのソフトウェアで、それ自体は組版に関与しません。

エディタはコンパイラとは異なります。Overleaf、TeXstudio、VS Code はコードを書いてコンパイルを起動するだけで、実際に組版するのはディストリビューション内のエンジンです。そのためローカル環境では、エディタだけをインストールしてディストリビューションをインストールしないと、PDF をコンパイルできません（Overleaf は例外で、そのクラウドには完全なディストリビューションが組み込まれています）。

LaTeXの利点と適用シーン

LaTeX は万能なツールではありませんが、以下のようなシーンでは、その効率性と品質の優位性が非常に顕著です。

シーン適している理由
学術論文と卒業論文ほとんどの学術雑誌や大学が公式の LaTeX テンプレートを提供しており、数式、図表、参考文献の番号付けはすべて自動
数学、物理などの理工系の講義資料数式の入力が速く、複雑な数式（行列、連立方程式、複数行の導出）の組版品質はリッチテキストエディタをはるかに上回る
書籍と長いレポート章の自動管理、スタイルのグローバルな統一により、数百ページの文書でも書式が一貫して保たれる
履歴書moderncv などのテンプレートは組版が美しく、内容とスタイルが分離されているため、内容を変更してもレイアウトが崩れない
プレゼンテーション資料Beamer を使うと数式の組版が完璧な学術スライドを作成できる。これは PPT では難しい

逆に、次のような場合は無理に LaTeX を使う必要はありません。高度なグラフィックデザインが必要なポスター、複数人でのリアルタイムコメントが必要なオフィス文書、数式が少なく当日中に仕上げる必要がある短い文書などは、Word や専用ツールの方が使いやすいでしょう。

LaTeX の学習曲線は前半が急で後半は緩やかです。最初の数日は「文字サイズを変えるだけでもコマンドを調べなければならない」と感じるでしょうが、このシリーズの基礎編を学び終えれば、自動組版による長期的なメリットを実感できます。

まずはお試し：完全なLaTeXソースコードの一例

本格的に環境を構築する前に、実際の LaTeX ドキュメントがどのようなものか見てみましょう。

以下のソースコードは完全にコンパイル可能で、中国語、タイトル、2つの数式が含まれています。

例

% ドキュメントクラス：ctexart は article に中国語サポートを加えたものに相当
\documentclass{ctexart}

\title{私の最初の\LaTeX{} ドキュメント}   % ドキュメントのタイトル
\author{RUNOOB}                    % 著者
\date{2026 年 8 月}                % 日付、\today と書くと自動的に当日が入力される

\begin{document}                   % 本文はここから始まる

\maketitle                         % タイトル部分を生成

LaTeX は数学数式の組版が特に得意です。質量とエネルギーの等価式の行内形式は$E = mc^2$，
これを単独で中央に表示する（別行立ての数式）場合は次のように書きます：

\[ E = mc^2 \]

ここで$E$はエネルギー、$m$は質量、$c$は真空中の光速です。

\end{document}                     % 本文はここで終了

このソースコードをコンパイルすると、得られる PDF ページは次のようになります：

今はこれらのコマンドが理解できなくてもまったく正常です。本シリーズの以降の各記事で、それらを一つずつ詳しく解説します。

ここでは2つの構造だけ覚えておけば十分です。\documentclass から \begin{document} までの間をプリアンブルと呼び、グローバル設定を行います。\begin{document} と \end{document} の間を本文部と呼び、内容を書く場所です。
