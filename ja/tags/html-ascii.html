ASCII 文字セット

ASCII は「American Standard Code for Information Interchange（アメリカ情報交換標準コード）」の略称です。1960年代初頭に設計され、コンピュータやプリンタ、テープドライブなどのハードウェアデバイスの標準文字セットです。

ASCII は7ビット文字セットで、128個の異なる文字値を含みます。

ASCII は 0-9 の数字、A-Z の大文字と小文字の英字、およびいくつかの特殊文字をサポートしています。

現代のコンピュータ、HTML、インターネットで広く使用されている文字セットはすべて ASCII に基づいています。

ASCII デバイス制御文字

ASCII 制御文字（00-31、および127）は、当初プリンタやテープドライブなどのハードウェアデバイスを制御するために設計されました。

制御文字（水平タブ、改行、キャリッジリターンを除く）は、HTML ドキュメントでは何の役割も果たしません。
