Python Number（数値）

Python Number データ型は数値を格納するために使用されます。

データ型は変更が許可されていません。つまり、Number データ型の値を変更すると、メモリ空間が再割り当てされます。

次の例では、変数への代入時に Number オブジェクトが作成されます：

var1 = 1
var2 = 10

del 文を使用して、いくつかの Number オブジェクト参照を削除することもできます。

del 文の構文は次のとおりです：

del var1[,var2[,var3[....,varN]]]]

del 文を使用して、単一または複数のオブジェクトを削除できます。例：

del var
del var_a, var_b

Python は4つの異なる数値型をサポートしています：

  • 整数型（Int）- 通常、整数型または整数と呼ばれ、正または負の整数で、小数点はありません。
  • 長整数型（long integers）- 無限の大きさの整数で、整数の最後には大文字または小文字の L が付きます。
  • 浮動小数点型（floating point real values）- 浮動小数点型は整数部と小数部から構成されます。浮動小数点型は科学表記法で表すこともできます（2.5e2 = 2.5 x 102 = 250）
  • 複素数型（complex numbers）- 複素数は実数部と虚数部から構成され、a + bj または complex(a,b) で表すことができます。複素数の実部 a と虚部 b はどちらも浮動小数点型です。

  • Python は複素数もサポートしています。複素数は実数部と虚数部から構成され、a + bj または complex(a,b) で表すことができます。複素数の実部 a と虚部 b はどちらも浮動小数点型です。

Python math モジュール、cmath モジュール

Python で数学演算によく使われる関数は、基本的に math モジュールと cmath モジュールにあります。

Python の math モジュールは、浮動小数点数の数学演算関数を多数提供しています。

Python の cmath モジュールには、複素数演算のための関数がいくつか含まれています。

cmath モジュールの関数は math モジュールの関数と基本的に同じです。違いは、cmath モジュールが演算するのは複素数であり、math モジュールが演算するのは数学演算であることです。

math または cmath の関数を使用するには、最初にインポートする必要があります：

import math

math を表示して、パッケージの内容を表示します：

Python 数学関数

関数戻り値（説明）
abs(x)数値の絶対値を返します。例：abs(-10) は 10 を返します。
ceil(x) 数値の切り上げ整数を返します。例：math.ceil(4.1) は 5 を返します。
cmp(x, y)x < y の場合は -1 を返し、x == y の場合は 0 を返し、x > y の場合は 1 を返します。
exp(x) e の x 乗を返します（ex）、例：math.exp(1) は 2.718281828459045 を返します。
fabs(x)数値の絶対値を浮動小数点数として返します。例：math.fabs(-10) は 10.0 を返します。
floor(x) 数値の切り捨て整数を返します。例：math.floor(4.9) は 4 を返します。
log(x) 例：math.log(math.e) は 1.0 を返し、math.log(100, 10) は 2.0 を返します。
log10(x) 10 を底とする x の対数を返します。例：math.log10(100) は 2.0 を返します。
max(x1, x2,...) 指定された引数の最大値を返します。引数はシーケンスでもかまいません。
min(x1, x2,...) 指定された引数の最小値を返します。引数はシーケンスでもかまいません。
modf(x) x の整数部分と小数部分を返します。2つの部分の数値の符号は x と同じで、整数部分は浮動小数点型で表されます。
pow(x, y)x**y を計算した後の値。
round(x [,n])浮動小数点数 x の四捨五入値を返します。n の値が指定された場合は、小数点以下の桁数への丸めを表します。
sqrt(x) 数値 x の平方根を返します。

Python 乱数関数

乱数は数学、ゲーム、セキュリティなどの分野で使用できます。また、アルゴリズムに組み込まれて、アルゴリズムの効率を向上させ、プログラムの安全性を高めるためによく使用されます。

Python には以下の一般的な乱数関数が含まれています：

関数説明
choice(seq)シーケンスの要素からランダムに1つの要素を選びます。例：random.choice(range(10)) は、0から9の中からランダムに整数を1つ選びます。
randrange ([start,] stop [,step]) 指定された範囲内で、指定された基数ずつ増加する集合から乱数を取得します。基数のデフォルト値は 1 です。
random() 次の実数をランダムに生成します。これは [0, 1) の範囲内です。
seed([x]) 乱数生成器のシード（seed）を変更します。その原理を理解していない場合でも、わざわざ seed を設定する必要はありません。Python が seed を選択してくれます。
shuffle(lst) シーケンスのすべての要素をランダムに並べ替えます。
uniform(x, y)次の実数をランダムに生成します。これは [x, y] の範囲内です。

    abs() と fabs() の違い

    • 1. abs() は組み込み関数ですが、fabs() は math モジュールで定義されています。
    • 2. fabs() 関数は float 型と integer 型にのみ適用されますが、abs() は複素数にも適用されます。
    >>> abs(-10)
10
>>> fabs(-10)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'fabs' is not defined
>>>import math
>>> math.fabs(-10)
10.0
>>>type(abs(-10))
<type 'int'>
>>> type(math.fabs(-10))
<type 'float'>

    上に示したように、abs(-10) は 10 を返しますが、math.fabs(-10) は 10.0 を返します。

    >>>type(abs(-10))
<type 'int'>
>>> type(math.fabs(-10))
<type 'float'>
>>>

    Python で整数を2進数文字列に変換する方法

    1. 自分で関数を書いて %2 の方法で計算することができます。

    >>> binary = lambda n: '' if n==0 else binary(n/2) + str(n%2)
>>> binary(5)
'101'
>>>

    2. Python が標準で備えている bin 関数を使用します。例えば bin(12345) は文字列 '0b11000000111001' を返すので、そのとき '0b' を取り除けばよいです：

    >>> bin(12345).replace('0b','')
'11000000111001'

    3. 文字列の format メソッドを使用して2進数を取得することもできます：

    >>> "{0:b}".format(12345)
'11000000111001'
>>>
