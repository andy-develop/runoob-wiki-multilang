問題：猿が桃を食べる問題：猿は初日にいくつかの桃を摘み、すぐに半分を食べたが、まだ足りず、もう一つ多く食べた。翌朝、また残りの桃の半分を食べ、もう一つ多く食べた。それから毎朝、前日に残った桃の半分と一つを食べた。10日目の朝にまた食べようとしたとき、桃が一つだけ残っているのを見た。初日に摘んだ桃の総数を求めよ。

プログラム分析：逆方向の思考方法を取り、後ろから前に推測する。

プログラムのソースコード：

例（Python 2.0+）

#!/usr/bin/python # -*- coding: UTF-8 -*- x2 = 1 for day in range(9,0,-1): x1 = (x2 + 1) * 2 x2 = x1 print (x1)

上記の例の出力結果は次のとおりです：

1534
