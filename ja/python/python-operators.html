Python 演算子

演算子とは？

この章では主にPythonの演算子について説明します。簡単な例を挙げます 4 +5 = 9 。この例では、4 和 54 と 5 はオペランド，+と呼ばれ、+ は演算子と呼ばれます。

Python言語は以下の種類の演算子をサポートしています:

  • 算術演算子
  • 比較（関係）演算子
  • 代入演算子
  • 論理演算子
  • ビット演算子
  • メンバー演算子
  • 同一性演算子
  • 演算子の優先順位

それでは、Pythonの演算子について一つずつ学んでいきましょう。

以下、変数を仮定します： a=10，b=20：

演算子説明例

-減算 - 負の数を得る、またはある数から別の数を引くa - b は結果 -10 を出力
*乗算 - 2つの数を掛け算する、または指定回数繰り返された文字列を返すa * b は結果 200 を出力
/除算 - x を y で割るb / a は結果 2 を出力
%剰余 - 除算の余りを返すb % a は結果 0 を出力
**べき乗 - x の y 乗を返すa**b は10の20乗で、結果 100000000000000000000 を出力
//切り捨て除算 - 商の整数部分を返す（切り捨て） 
>>> 9//2
4
>>> -9//2
-5

Python 比較演算子

以下、変数 a を10、変数 b を20と仮定します：

演算子説明例
==等しい - オブジェクトが等しいかどうかを比較する(a == b) は False を返す。
!=等しくない - 2つのオブジェクトが等しくないかどうかを比較する(a != b) は True を返す。
<>等しくない - 2つのオブジェクトが等しくないかどうかを比較する。python3 では廃止されました。(a <> b) は True を返す。この演算子は != に似ています。
>大なり - x が y より大きいかどうかを返す(a > b) は False を返す。
<小なり - x が y より小さいかどうかを返す。すべての比較演算子は、真の場合は1、偽の場合は0を返します。これはそれぞれ特別な変数 True と False に相当します。(a < b) は True を返す。
>=以上 - x が y 以上であるかどうかを返す。(a >= b) は False を返す。
<=以下 - x が y 以下であるかどうかを返す。(a <= b) は True を返す。

以下の例は、Pythonのすべての比較演算子の操作を示しています：

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 21 b = 10 c = 0 if a == b : print "1 - a は b に等しい" else: print "1 - a は b に等しくない" if a != b : print "2 - a は b に等しくない" else: print "2 - a は b に等しい" if a <> b : print "3 - a は b に等しくない" else: print "3 - a は b に等しい" if a < b : print "4 - a は b より小さい" else: print "4 - a は b 以上" if a > b : print "5 - a は b より大きい" else: print "5 - a は b 以下" # 変数 a と b の値を変更 a = 5 b = 20 if a <= b : print "6 - a は b 以下" else: print "6 - a は b より大きい" if b >= a : print "7 - b は a 以上" else: print "7 - b は a より小さい"

上記の例の出力結果：

1 - a 不等于 b
2 - a 不等于 b
3 - a 不等于 b
4 - a 大于等于 b
5 - a 大于 b
6 - a 小于等于 b
7 - b 大于等于 a

Python ビット演算子

ビット演算子は、数値を2進数として扱って計算します。Pythonのビット演算の規則は次のとおりです：

下の表では変数 a は 60、b は 13 で、2進数形式は次のとおりです：

a = 0011 1100

b = 0000 1101

-----------------

a&b = 0000 1100

a|b = 0011 1101

a^b = 0011 0001

~a  = 1100 0011
演算子説明例
&ビットごとのAND演算子：演算に関与する2つの値の対応するビットが両方とも1の場合、そのビットの結果は1になり、それ以外は0になります(a & b) は結果 12 を出力、2進数での説明： 0000 1100
|ビットごとのOR演算子：対応する2つの2進ビットのいずれかが1であれば、結果ビットは1になります。(a | b) は結果 61 を出力、2進数での説明： 0011 1101
^ビットごとのXOR演算子：対応する2つの2進ビットが異なる場合、結果は1になります(a ^ b) は結果 49 を出力、2進数での説明： 0011 0001
~ビットごとのNOT演算子：2進数表現の各ビットを反転し、0 は 1 に、1 は 0 になります。~xのような-x-1(~a ) は結果 -61 を出力、2進数での説明： 1100 0011（2の補数形式で表記）、符号付き2進数の2の補数形式です。
<<左シフト演算子：演算数の各2進ビットをすべて左に数ビットシフトし、そのシフト数は<<右側の数字で指定されます。上位ビットは破棄され、下位ビットには0が補われます。a << 2 は結果 240 を出力、2進数での説明： 1111 0000
>>右シフト演算子：「>>」の左側のオペランドの各2進ビットをすべて右に数ビットシフトします。>>右側の数値はシフトするビット数を指定します。a >> 2 の出力結果は 15、2進数での解釈は 0000 1111

以下の例は、Pythonのすべてのビット演算子の操作を示しています。

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 60 # 60 = 0011 1100 b = 13 # 13 = 0000 1101 c = 0 c = a & b; # 12 = 0000 1100 print "1 - c の値：", c c = a | b; # 61 = 0011 1101 print "2 - c の値：", c c = a ^ b; # 49 = 0011 0001 print "3 - c の値：", c c = ~a; # -61 = 1100 0011 print "4 - c の値：", c c = a << 2; # 240 = 1111 0000 print "5 - c の値：", c c = a >> 2; # 15 = 0000 1111 print "6 - c の値：", c

上記の例の出力結果：

1 - c 的值为： 12
2 - c 的值为： 61
3 - c 的值为： 49
4 - c 的值为： -61
5 - c 的值为： 240
6 - c 的值为： 15

Python 論理演算子

Python言語は論理演算子をサポートしています。以下、変数 a は 10、b は 20 と仮定します。

演算子論理式説明例
andx and yブール「AND」- x が False の場合、x and y は False を返し、それ以外の場合は y の計算値を返します。(a and b) は 20 を返します。
orx or yブール「OR」- x が 0 でない場合、x の計算値を返し、それ以外の場合は y の計算値を返します。(a or b) は 10 を返します。
notnot xブール「NOT」- x が True の場合、False を返します。x が False の場合、True を返します。not(a and b) は False を返します

上記の例の出力結果：

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 10 b = 20 if a and b : print "1 - 変数 a と b が両方とも True" else: print "1 - 変数 a と b の少なくとも一方が True ではない" if a or b : print "2 - 変数 a と b が両方とも True、またはいずれか一方が True" else: print "2 - 変数 a と b がどちらも True ではない" # 変数 a の値を変更 a = 0 if a and b : print "3 - 変数 a と b が両方とも True" else: print "3 - 変数 a と b の少なくとも一方が True ではない" if a or b : print "4 - 変数 a と b が両方とも True、またはいずれか一方が True" else: print "4 - 変数 a と b がどちらも True ではない" if not( a and b ): print "5 - 変数 a と b が両方とも False、またはいずれか一方が False" else: print "5 - 変数 a と b が両方とも True"

上記の例の出力結果：

1 - 变量 a 和 b 都为 True
2 - 变量 a 和 b 都为 True，或其中一个变量为 True
3 - 变量 a 和 b 有一个不为 True
4 - 变量 a 和 b 都为 True，或其中一个变量为 True
5 - 变量 a 和 b 都为 False，或其中一个变量为 False

Python メンバー演算子

上記のいくつかの演算子に加えて、Pythonはメンバー演算子もサポートしています。テスト例には、文字列、リスト、タプルなどの一連のメンバーが含まれています。

演算子説明例
in指定されたシーケンス内で値が見つかった場合は True を返し、それ以外の場合は False を返します。 x は y シーケンス内にある - x が y シーケンス内にある場合は True を返します。
not in指定されたシーケンス内で値が見つからない場合は True を返し、それ以外の場合は False を返します。 x は y シーケンス内にない - x が y シーケンス内にない場合は True を返します。

以下の例は、Pythonのすべてのメンバー演算子の操作を示しています。

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 10 b = 20 list = [1, 2, 3, 4, 5 ]; if ( a in list ): print "1 - 変数 a は指定されたリスト list 内にある" else: print "1 - 変数 a は指定されたリスト list 内にない" if ( b not in list ): print "2 - 変数 b は指定されたリスト list 内にない" else: print "2 - 変数 b は指定されたリスト list 内にある" # 変数 a の値を変更 a = 2 if ( a in list ): print "3 - 変数 a は指定されたリスト list 内にある" else: print "3 - 変数 a は指定されたリスト list 内にない"

上記の例の出力結果：

1 - 变量 a 不在给定的列表中 list 中
2 - 变量 b 不在给定的列表中 list 中
3 - 变量 a 在给定的列表中 list 中

Python 同一性演算子

同一性演算子は、2つのオブジェクトのメモリ上の位置を比較するために使用されます。

演算子説明例
isis は、2つの識別子が同一のオブジェクトを参照しているかどうかを判定します x is y、に類似id(x) == id(y)、参照しているオブジェクトが同じ場合は True を返し、それ以外の場合は False を返します
is notis not は、2つの識別子が異なるオブジェクトを参照しているかどうかを判定します x is not y、に類似id(a) != id(b)。参照しているオブジェクトが同じでない場合は True を返し、それ以外の場合は False を返します。

注： id()関数はオブジェクトのメモリアドレスを取得するために使用されます。

以下の例は、Pythonのすべての同一性演算子の操作を示しています。

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- a = 20 b = 20 if ( a is b ): print "1 - a と b は同じ同一性を持つ" else: print "1 - a と b は同じ同一性を持たない" if ( a is not b ): print "2 - a と b は同じ同一性を持たない" else: print "2 - a と b は同じ同一性を持つ" # 変数 b の値を変更 b = 30 if ( a is b ): print "3 - a と b は同じ同一性を持つ" else: print "3 - a と b は同じ同一性を持たない" if ( a is not b ): print "4 - a と b は同じ同一性を持たない" else: print "4 - a と b は同じ同一性を持つ"

上記の例の出力結果：

1 - a 和 b 有相同的标识
2 - a 和 b 有相同的标识
3 - a 和 b 没有相同的标识
4 - a 和 b 没有相同的标识

is と == の違い：

is は、2つの変数が参照するオブジェクトが同じ（同じメモリ空間）かどうかを判断するために使用され、== は変数が参照する値が等しいかどうかを判断するために使用されます。

>>> a = [1, 2, 3]
>>> b = a
>>> b is a 
True
>>> b == a
True
>>> b = a[:]
>>> b is a
False
>>> b == a
True

    以下のテスト状況は対話モードで発生します。スクリプトモードでは is と == の結果は同じです。

    Pythonでは、出現する各オブジェクトにメモリが割り当てられます。たとえそれらの値が完全に等しくても（注意：等しいだけであって同じではありません）。たとえば、a=2.0、b=2.0という2つの文を実行すると、2.0というFloat型オブジェクトに対して順にメモリが割り当てられ、aとbはそれぞれこれらの2つのオブジェクトを指します。したがって、aとbは同じオブジェクトを指していません。

    >>> a=2.0
>>> b=2.0
>>> a is b
False
>>> a==b
True
>>> e

    ただし、メモリ利用効率を高めるために、単純なオブジェクト（数値の小さいintオブジェクトなど）に対しては、Pythonはオブジェクトのメモリを再利用する方法をとります。たとえば、a=2、b=2 と代入する場合、2は単純なint型で値も小さいため、Pythonは2回メモリを割り当てず、1回だけ割り当てて、aとbをその割り当て済みのオブジェクトに同時に指させます。

    >>> a=2
>>> b=2
>>> a is b
True
>>> a==b
True

    しかし、代入する値が2ではなく大きい数値の場合は、状況は前述と同じになります。

    >>> a=4444
>>> b=4444
>>> a is b
False
>>> a==b
True

    Python には ++ や -- のインクリメント/デクリメント演算子はありません

    なぜなら、Python の数値や文字列などは不変オブジェクトであり、不変オブジェクトに対する操作の結果は常に新しいオブジェクトを生成するからです。

    例えば：

    a = 1
a += 1

    C/Java などの言語では、a が指すメモリアドレスユニットのデータ値を 1 から 2 に変更します。

    しかし、Pythonではまったく異なる仕組みになっています。

    インタプリタは新しい整数オブジェクト2を作成します。

    そして、このオブジェクトのアドレスを再度aに代入します。

    以下のコードを参照してください：

    >>> id(1)
41116008L
>>> a = 1
>>> id(a)
41116008L
>>> id(2)
41115984L
>>>a += 1
>>> id(a)

    Pythonの基礎で発見した問題があります。リストがありa=[1,2,3,4,5]、代入するb2つの方法：

    # 第一种
b=a 

# 第一种
b=a[:]

    結果はどちらも：[1, 2, 3, 4, 5]

    この2つの代入の結果はどちらも同じに見えますが、何か違いがあるのでしょうか？

    違いは以下の通りです：

    • 前者は参照を渡します。
    • 後者はコピーです。

    Pythonには、idという関数があり、オブジェクトのアドレスを取得できます。printして確認すればはっきり分かります。直接=は参照代入で、元のオブジェクトを参照します。一方[:]は再導出で、新しいオブジェクトを生成します。

    >>> a=[1,2,3,4,5]
>>> b=a
>>> c=a[:]
>>> id(a)
4410359536
>>> id(b)
4410359536
>>> id(c)
4410358240

    上記の結果から、id(a)とid(b)のメモリアドレスは同じですが、id(a)とid(c)のメモリアドレスは異なります。

    is と == の違い：

    is2つの変数が参照するオブジェクトが同じかどうかを判定するために使用されます。==参照する変数の値が等しいかどうかを判定するために使用されます。

    a is bに相当します。id(a)==id(b)，id()オブジェクトのメモリアドレスを取得できます。

    a=10;b=a; の場合、このときaとbのメモリアドレスは同じです;

    しかし、a=[1,2,3]; また b=a[:] の場合は、aとbの値は同じですが、メモリアドレスは異なります。

    ここで a=10、b=10 と定義して、続けて a is b を比較すると、返される結果は True になることが分かります。これは、Pythonでは範囲 [-5,256] の小さな整数プールが作成され、これらの整数のためにメモリ空間が確保されているためです。コードでこの範囲内の整数を定義する場合、メモリアドレスは再割り当てされません。そして、私はPycharmでテストしました：

    #coding=utf-8
a=100000000000;
b=100000000000;
print a is b

    結果：

    True

    後で調べて分かったのは、Pythonはパフォーマンス上の理由から、不変オブジェクトについては、同じコードブロック内で値が同じオブジェクトは重複して作成されず、既存のオブジェクトが直接参照されるということです。

    1コメント目の回答を検証しました。その言う通り、pythonではisキーワードを使って2つの小さな数値を判定すると、確かに==演算子と同じように、結果はどちらもtrueになります。しかし、この小さな数値の具体的な下限と上限がどこまでなのかをテストしたところ、数が256以下の場合は両者の結果は同じで、256を超えるとisの判定結果はfalseになります。

    本人の推測：256はちょうど8ビットの2進数、つまり1バイトです。そのため、数が1バイトで表せる場合はisと==の結果は同じになり、数が1バイトを超える場合は異なるオブジェクトとして扱われます。pythonは異なる数に異なるメモリを割り当てるため、異なる数は異なるオブジェクトであり、値が同じなだけです。isの結果はfalse、==は依然としてtrueです。

    上の回答を見て、pythonが1バイトで表現できるこれらの数を格納するために小さな整数プールを作成していることが分かりました。これにより、小さな数値に対してメモリを重複して割り当てる（つまりオブジェクトを重複して作成する）ことを回避し、言語の実行性能を向上させています。
