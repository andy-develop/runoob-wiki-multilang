Bootstrap5 フォーム

この章では、Bootstrap を使用してフォームを作成する方法を学びます。Bootstrap は、いくつかの簡単な HTML タグと拡張クラスを使用するだけで、さまざまなスタイルのフォームを作成できます。

フォーム要素<input>, <textarea>、および<select>elements.form-controlクラスの場合、幅はすべて 100% に設定されます。

Bootstrap5 フォームレイアウト

  • スタックフォーム (全画面幅): 垂直方向
  • インラインフォーム: 水平方向

Bootstrap は 2 種類のフォームレイアウトを提供しています:

スタックフォーム

次の例では、2 つの入力ボックス、1 つのチェックボックス、1 つの送信ボタンを使用してスタックフォームを作成します:

例

<form> <div class="mb-3 mt-3"> <label for="email" class="form-label">Email:</label> <input type="email" class="form-control" id="email" placeholder="Enter email" name="email"> </div> <div class="mb-3"> <label for="pwd" class="form-label">Password:</label> <input type="password" class="form-control" id="pwd" placeholder="Enter password" name="pswd"> </div> <div class="form-check mb-3"> <label class="form-check-label"> <input class="form-check-input" type="checkbox" name="remember"> Remember me </label> </div> <button type="submit" class="btn btn-primary">Submit</button> </form>

試してみる »

表示結果:

例では、.form-labelクラスを使用して、ラベル要素に一定のパディングを確保します。

チェックボックス（checkboxe）は異なるマークアップを使用します。それらは.form-checkコンテナ要素の周りにラップされます。チェックボックスとラジオボタンは.form-check-input、そのラベルには.form-check-labelクラス。

インラインフォーム

フォーム要素を並べて表示する場合は、.row 和 .col：

次の例では、2 つの入力ボックスが並んで表示され、インラインフォームを作成しています:

例

<form> <div class="row"> <div class="col"> <input type="text" class="form-control" placeholder="Enter email" name="email"> </div> <div class="col"> <input type="password" class="form-control" placeholder="Enter password" name="pswd"> </div> </div> </form>

テキストボックス

textarea タグを使用してフォーム送信用のテキストボックスを作成し、.form-controlクラスを使用して textarea タグをレンダリングします:

例

<label for="comment">コメントを入力してください:</label> <textarea class="form-control" rows="5" id="comment" name="text"></textarea>

入力ボックスのサイズ

私たちは、.form-control入力ボックス内で.form-control-lg 或 .form-control-smクラスを使用して入力ボックスのサイズを設定できます:

例

<input type="text" class="form-control form-control-lg" placeholder="大きな入力ボックス"> <input type="text" class="form-control" placeholder="通常サイズの入力ボックス"> <input type="text" class="form-control form-control-sm" placeholder="小さな入力ボックス">

表示結果:

無効/読み取り専用フォーム

を使用してdisabled/readonly属性で入力ボックスの無効/読み取り専用を設定します:

例

<input type="text" class="form-control" placeholder="Normal input"> <input type="text" class="form-control" placeholder="Disabled input" disabled> <input type="text" class="form-control" placeholder="Readonly input" readonly>

試してみる »

プレーンテキスト入力

を使用すると.form-control-plaintextクラスで入力ボックスの枠線を削除できます:

例

<input type="text" class="form-control-plaintext" placeholder="Plaintext input"> <input type="text" class="form-control" placeholder="Normal input">

カラーピッカー

を使用すると.form-control-colorクラスでカラーピッカーを作成できます:

例

<input type="color" class="form-control form-control-color" value="#CCCCCC">
